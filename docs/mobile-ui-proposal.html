REEL 01

设计理念

手机端不是 PC 的缩略版。创作决策（编排分镜、审剧本）留给桌面，手机承担「盯进度、审细节、随手创作、随时追剧」四个高频动作。

一部手机就是一个剧组

底部五 Tab 常驻动线：看剧（展示）、管项目、起项目（中央快门键）、接单、查账户。每个创作动作三次点击内可达。

POCKET STUDIO

拇指动线优先

高频操作沉底、低频操作收拢；主按钮统一 44px 高度落在拇指热区；二级页一律右滑推入、可手势返回。

THUMB-FIRST

不是缩小的网页

完整复用「电影工作室」令牌：影棚黑、描金、片头青 CTA、衬线标题、时间码等宽数字。同一部剧，换一块幕布放映。

移动规范四条

沿用现有约定，零新增心智
  • 触控热区 ≥ 44px：全部可点元素（含列表行、chip）按 44px 计，视觉小、热区大。

  • 安全区：底部操作条 padding 计入 env(safe-area-inset-bottom)，全面屏不被 Home 条压住。
  • 零 PC 回归：≤768 断点才启用移动布局；桌面端结构与样式不动。

REEL 06

落地路径

不新建工程：在现有 client 内以「≤768 断点 + 移动组件」落地，桌面端零回归。预计 5 个工作日完成主体。

01
令牌零新增

全部复用 theme.scss 的 --ad-* 变量；本方案中的移动组件只新增布局类（.m-btn/.tabbar 等），色值一律引用令牌，深浅主题自动跟随。

02
DefaultLayout 增 MobileTabBar

≤768 渲染五槽 TabBar（含中央创作键），路由 meta.tab 标注归属；沉浸式页（工作台 / 分镜 / 剪辑 / 分享播放）沿用现有 immersive meta 隐藏导航。

03
创作面板统一入口

AI 编剧 / 导入剧本 / 做同款三路汇入现有 ScriptWriter 与项目创建流；「模型 + 价格」确认页与 useCostAction 对象 API 不变，modelConfigId 端到端透传。

04
i18n 与文案

新增 mobile.* 键族覆盖 9 语言；路由只传键、params 永远尾参；叶子键直达字符串，避免对象键静默回退。

05
媒体与安全护栏

视频一律走全屏播放窗（复用 miniclient VideoPlayerPopup 交互范式）；/files 时效签名不变；弹层宽度 min(原始,94vw)；底部操作条计入 safe-area。
