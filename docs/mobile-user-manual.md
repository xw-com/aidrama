# AI 短剧 · 手机端使用手册

> 适用对象：AI 短剧小程序/H5 的普通用户。
> 全程手机操作，从一句话创意到成片发布，只需五个底部标签页：**首页 / 展示 / 项目 / 任务 / 我的**。

---

## 一、快速上手：一条完整创作动线

1. 登录（账号密码；App 端另支持 Apple / Google 一键登录）
2. 首页 → **新剧创作**：和 AI 聊创意 → 生成大纲 → 分集 → 逐集细化 → 导出项目
3. 项目工作台：**剧本大纲 → 资产库 → 分集视频** 三步走
4. 分镜编辑器：润色提示词 → 生成分镜视频 → 批量/串行生成
5. **合成全集**：选分辨率，一键把镜头拼成整集成片
6. 成片卡上：**分享**（24 小时二维码）或**发布到展示中心**

---

## 二、登录与账号

- 首次打开即可以**游客身份**浏览展示中心、观看全站作品。
- 点击任意带 🔒 的功能格，或「我的」页的登录卡，即可进入登录页。
- 登录采用**本地账号**（用户名 / 邮箱 / 手机号 + 密码，提交前过点选验证码）：「注册」页直接创建账号，成功即登录；忘记密码请联系站点管理员重置。登录后自动返回原页面，与 Web 端账号互通。

## 三、首页

- 顶部品牌栏 + **积分余额**（点击进入积分页）；游客显示欢迎横幅与登录/注册按钮。
- 3 列功能宫格，全部功能一屏直达：

| 格子 | 说明 |
| --- | --- |
| ✍️ 新剧创作 | 主推入口，AI 聊天式生成分集剧本 |
| 📁 我的项目 | 项目列表 |
| ⏳ 任务中心 | AI 生成任务进度（带进行中红点） |
| 🎬 展示中心 | 游客可用，浏览全站作品 |
| 💼 接单中心 | 悬赏任务广场 |
| 💰 积分 | 余额 / 充值 / 流水 |
| ✉️ 邀请 | 团队协作邀请（有待处理数红点） |
| ⚙️ 设置 | 主题 / 语言 / 账户 |

> 游客点击带 🔒 的格子会引导登录。

## 四、新剧创作（AI 编剧）

四步向导，右上角「📂 选择草稿」可管理多个剧本草稿、随时切换。

1. **对话**：先选题材（12 种叙事类型），再和 AI 聊天打磨创意。聊天阶段**免费**且流式输出，可随时中断。聊满意后点「✨ 生成大纲」（计费，弹出确认）。
2. **大纲分集**：大纲可直接编辑；设定目标集数（0 = AI 自动判断，最多 60 集）后点「✂️ 分集并生成概要」。每集的标题和概要都可以手改。
3. **逐集细化**：横滑选择集数，点「细化本集」或「批量细化未完成」（批量一次确认、一次计费）。正文可编辑。
4. **导出项目**：填项目名、叙事类型、风格与画幅，点「🎬 导出到项目」，自动创建项目并进入工作台。

## 五、项目列表

- 顶部「＋ 新建项目」：填写名称、美术风格、画幅、叙事类型，封面可上传或 AI 生成。
- 项目卡显示：封面、风格/叙事标签、我的角色（创建者或「共享自某某」）、集数、更新时间，以及**状态徽标 + 进度条**（大纲 → 资产 → 视频 → 完成）——点状态徽标可直接跳到工作台对应步骤。
- 创建者可在卡片上**编辑 / 管理成员 / 删除**；共享成员可**退出共享**，均有确认弹窗。

## 六、项目工作台

顶栏三大步骤按钮（完成的打 ✓，自动定位到第一个未完成步骤）：

1. **剧本大纲**：导入/上传剧本文本，自动拆分成集；分集卡片可点开阅读、编辑、删除。
2. **资产库**：角色 / 场景 / 道具 / 素材 / 视频五类。支持手工新建、上传参考图、**AI 提取资产**、**AI 生图**、AI 润色；角色还能配置服饰并试听音色。
3. **分集视频**：每集一张成片卡，平铺大按钮——
   - **提取资产 / 生成分镜 / 进分镜编辑器**
   - **合成全集**（6 档分辨率可选）
   - 单集成片：下载、提取/编辑字幕、在线剪辑、删除
   - 创建者：**一键分享**（24 小时有效二维码）或**发布到展示中心**

顶部设置行可改视觉风格、画幅（9:16 / 16:9 / 1:1），⚙️ 偏好设置弹层里还有字幕样式与成员管理。团队成员按权限灰置操作，只读成员会有横幅提示。

## 七、分镜编辑器

- 顶部胶片条直观展示镜头顺序、转场连接，可在镜头间**插入新镜头**。
- 展开单个镜头卡：编辑标题/镜号/场景/时长/转场/提示词；为本镜挑选资产（角色可试听音色）。
- 镜头级 AI 操作（均弹「模型 + 价格」确认）：
  - **AI 润色提示词** → **生成本镜视频**（选模型 + 分辨率）
  - 重新生成 / 去除字幕（AI 擦除）/ 在线剪辑 / 上传本地视频替换（≤10MB）/ 删除视频
- **批量面板**：全选后可批量润色，或选择
  - **串行生成**：相邻同场景镜头自动尾帧衔接，画面更连贯；
  - **并发生成**：最多 4 段同时生成，更快。
  汇总一次计费，进行中可取消（未执行的部分自动退积分），3 秒自动刷新进度。
- **分镜检查**：免费体检（缺资产引用、时长异常等），可一键修复。
- **合成全集**：勾选镜头，按转场拼接成整集；480p ~ 4K 共 6 档分辨率任选，确认价格后开始合成。

## 八、在线剪辑器

从分镜单镜「剪辑」、成片卡「在线剪辑」或任务中心进入，全屏触屏操作：

- 点画面播放/暂停；拖动时间线标尺或红色播放头定位。
- 点选片段弹出检查器：修剪两端、分割、删除、拖动调序。
- 支持撤销 / 重做 / 重置，适配与放大两档缩放。
- 点「导出」：选分辨率 + 估价确认后导出成片；分镜源导出会**直接替换该镜头的视频**。

## 九、任务中心

- 底部「任务」Tab，筛选：全部 / 进行中 / 已完成 / 失败；下拉刷新 + 上翻分页。
- 任务卡显示类型图标（📝 大纲、✂️ 分集、🎨 生图、🎥 视频、🎞️ 合成、💬 字幕等）、状态、**实时进度百分比**和耗时，全局自动轮询。
- **取消与退款**：排队任务随时取消；运行超 10 分钟或批量视频任务也可取消，预扣积分自动退还（有确认弹窗）。
- 已完成任务点「查看结果」直达对应页面：合成/剪辑 → 剪辑器；分集 → 分镜编辑器；其余 → 项目工作台。

## 十、积分与充值

- 入口：首页顶部余额 / 「我的」积分卡 / 设置页。
- 余额大数字卡 + **充值档位网格**（微信支付：浏览器扫码、微信内直接拉起、小程序内跳原生支付），支付弹层轮询到账后自动刷新。
- 页内附**功能定价表**（各 AI 能力单价）、充值订单与积分流水（充值 / 消费 / 退款 / 结算）。

> 💡 所有 AI 生成操作共用统一的**「模型 + 价格」确认弹层**：先估价（积分、条数、每秒单价、限时折扣一目了然），确认后才扣费；取消未执行部分自动退款。

## 十一、展示中心

- 单列大卡浏览全站已发布剧目；「全部 / 我发布的」切换、搜索、按视觉风格与叙事类型筛选；下拉刷新。
- 详情页：全屏播放器、逐集选集、播完自动连播。
- **做同款**：点底部大按钮，该作品的名称/简介/叙事类型/风格/画幅会自动带入「新剧创作」生成草稿（游客会先引导登录，登录后自动续起）。
- 发布者可下架自己的作品。

## 十二、接单中心

面向接单/发包的悬赏广场，需登录。

- **任务广场 / 我发布的 / 我接的** 三个视图，支持搜索。
- **发布任务**：填标题、需求、时长秒数、每秒单价、分辨率与画幅，实时显示总价；余额不足会提示。
- **接单**：卡片或详情页点「接单」，二次确认后锁定（防止重复接单）。
- 订单详情含事件时间线（发布 → 接单 → 交付 → 驳回 → 验收 → 仲裁）：
  - 接单人：**交付**（填说明 → 选自己项目 → 选成片分集）或退出；
  - 发布方：**验收**（积分放款给接单人）/ **驳回**（必填意见）/ 取消；
  - 有争议可申请**仲裁**，由管理员裁决。

## 十三、团队协作与邀请有礼

- **邀请中心**：查看项目协作邀请（项目名、邀请人、权限标签、有效期），接受后项目立即出现在项目列表；后台 30 秒自动轮询新邀请。
- **邀请有礼**：专属邀请链接 + 二维码，一键复制分享；被邀请人消费达标后奖励积分自动到账；页内可看累计邀请人数、积分与邀请记录。

## 十四、分享播放页

- 他人分享的链接 / 二维码，**免登录**直接观看。
- 全屏播放：上下滑动切集、自动连播、记住每集观看进度、静音开关、进度条。
- 分享链接 **24 小时有效**，过期会明确提示（重新分享即可生成新链接）。

## 十五、设置

- 账户信息与修改昵称
- 外观主题：浅色 / 深色 / 跟随系统
- 语言切换（多语种，按母语名显示）
- 退出登录
