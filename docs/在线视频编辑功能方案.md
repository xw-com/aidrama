# AIDrama 在线视频编辑器（Web Video Studio）功能方案

> 版本：v1.0（2026-08-18）
> 服务端：本系统 Node.js（Express + Sequelize）+ ffmpeg/ffprobe（`server/src/services/ffmpeg.service.js` 扩展）
> 客户端：本系统网页（Vue 3 + Element Plus + Pinia + vue-i18n，`client/src/views/workspace/EditorView.vue`）
> 定位：在现有「剧本 → 分镜 → 段视频 → 合成成片」流水线之上，提供**网页端全功能时间线剪辑器**，替代并超越「一键合成」的固定装配能力。

---

## 0. 摘要

本方案在不动摇现有架构的前提下，新增一套「编辑工程（Edit Project）」体系：客户端提供多轨时间线剪辑界面（媒体库 / 预览播放器 / 属性检查器 / 时间线），服务端以 Job 异步任务完成**代理转码、缩略图与波形提取、草稿预览渲染、最终成片渲染**四类 ffmpeg 工作，全部 AI 能力（字幕、配音、高光切片等）复用现有计费与任务中心。渲染管线沿用本系统已验证的**「逐段统一规格渲染 → concat 硬切装配 → 音频独立一遍混音 → 最终封装」**范式，从根上规避 xfade/settb 类音画漂移。

分四期落地：基建期（媒体接入/代理/时间线存取）→ MVP（剪切/排序/BGM/导出 1080p）→ 进阶（多轨/滤镜/转场/变速/文字贴纸/4K）→ 高级+AI（抠像/防抖/关键帧/智能剪辑/协作批注）。

## 1. 背景与目标

### 1.1 现状与痛点

- 现有 `POST /videos/episodes/:eid/compose` 只做「选中分镜 → 逐段拼接（仅手动设置的转场）」的固定装配，顺序、时长、取舍全部由分镜表决定；
- 用户对成片的微调诉求（掐头去尾、调整顺序、加 BGM、改字幕样式、加片头片尾、多版比选）只能回到分镜层反复重生成，成本高、周期长；
- 成片加字幕已是「两段式 + 草稿编辑器」模式（提取 → 网页校对 → 烧录），证明「成片级后处理」已有真实需求，缺的是一个完整剪辑器。

### 1.2 目标

| 目标 | 衡量 |
| --- | --- |
| 网页完成成片级剪辑 | 90% 常见剪辑操作（裁剪/排序/BGM/字幕/贴纸/变速/调色）不离开浏览器 |
| 段级素材可自由复用 | 分镜视频、资产库视频/音频/图片、用户上传，均可入轨 |
| 所见即所得 | 客户端近似预览 + 服务端草稿渲染两级预览，最终渲染零意外 |
| 导出质量对齐现有标准 | 4K/1080p/竖版/横版、钻石档免水印、字幕样式沿用 `projects.settings.subtitle` |
| 与现有体系无缝 | Job 任务中心、积分计费、团队共享权限、9 语言 i18n、≤768px 移动端、维护模式全部复用 |
| 性能可控 | 代理流媒体预览秒开；渲染按段并行、断点续渲；单用户并发受限 |

### 1.3 非目标（本期不做）

- 不做浏览器端 WebCodecs/MSE 级实时合成播放（成本高、浏览器差异大，用「近似预览 + 服务端草稿渲染」替代）；
- 不做多人实时协同编辑（做「协作批注 + 编辑锁」，见 §11）；
- 不做移动端原生 App（移动端走响应式精简模式）。

## 2. 术语

| 术语 | 含义 |
| --- | --- |
| EditProject（编辑工程） | 一次剪辑会话的顶层实体，归属 Project（项目），引用若干媒体 |
| Media（媒体） | 入库到编辑器的一次素材：分镜视频 / 资产视频 / 上传文件 / 生成的图片音频 / TTS 配音 |

| Track（轨道） | 轨道类型：`video`（主/副）、`audio`、`subtitle`、`overlay`（文字/贴纸） |

| Assembly（装配） | 段渲染产物按时间线顺序 concat 硬切拼接 |
| Draft Preview（草稿渲染） | 低规格（540p/高压缩）整条时间线的快速渲染，供精看预览 |
| Final Render（成片渲染） | 目标规格的正式导出 |

```
┌─────────────────────────── 客户端（Vue 3） ───────────────────────────┐
│ EditorView                                                            │
│  ├─ 媒体库面板（分镜/资产/上传/TTS/BGM 文库）                            │
│  ├─ 预览播放器（<video>×N 调度 + DOM overlay 近似合成 + 比例安全框）      │
│  ├─ 属性检查器（变换/裁剪/速度/音量/滤镜/文字/关键帧）                     │
│  ├─ 多轨时间线（标尺/缩略图条/波形/磁吸/拖拽修剪分割）                     │
│  └─ undo·redo 栈 + 自动保存（timeline JSON 每 5s/操作后防抖 PUT）        │
└──────────────┬────────────────────────────────────────────────────────┘
               │ REST（axios）＋ Job 轮询（复用任务中心）
┌──────────────▼─────────────── 服务端（Express） ───────────────────────┐
│ editor.routes.js        工程 CRUD / 媒体接入 / 预览与导出 / AI 入口       │
│ editor.service.js       时间线校验·版本·快照·编辑锁·清理                  │
│ editorRender.service.js 时间线 JSON → ffmpeg 渲染计划编译器 + 执行器      │
│ ffmpeg.service.js（扩展） proxy/thumbs/waveform/段渲染/混音/装配          │
│ job.service.js（复用）   进程内运行器 + 重启恢复 + 僵尸清理 + 取消退款     │
│ pricing/credits（复用）  导出与 AI 能力计费                               │
└──────────────┬────────────────────────────────────────────────────────┘
               │ 本地进程
        ffmpeg / ffprobe（统一规格段渲染 + concat + 独立音频混音）
```

### 3.1 设计原则

1. **时间线是纯 JSON，服务端无状态渲染**：客户端保存 `timeline` JSON（版本号递增），渲染时服务端把 JSON 编译成 ffmpeg 计划。任何渲染都可由「同一版本 JSON」精确复现。
2. **音画分离两遍法**：视频走「逐段渲染 → concat 装配」；**全部音频（人声/BGM/音效/ducking）在装配后单独一遍混音**，最后 mux。段内不嵌音频混图，规避漂移（沿用并强化现有 `concatVideos` 帧对齐经验）。
3. **转场沿用「独立 3 秒过渡片段」范式**：任意两 Clip 之间的转场 = 由前后段首尾帧为蓝本独立生成的过渡片段，参与 concat 硬切装配；不再回到 xfade 重叠式方案。
4. **一切长耗时操作皆 Job**：proxy / 草稿渲染 / 成片渲染 / 各 AI 能力全部走 `createJob + submit`，任务中心可见、可取消、可恢复；维护模式下 `createJob` 自动被拦（现状即满足）。
5. **纯本地确定性操作不计费，导出与 AI 计费**：trim/split/concat/滤镜等本地 ffmpeg 操作按「导出渲染」一次性计费；AI 能力按各自 feature 计费（详见 §12）。
6. **URL 只存相对路径**：所有产物落 `uploads/` 或 `output/`，DB 一律 `/files/...` 相对路径（`toUrl`/`urlToPath` 单点转换，`PUBLIC_BASE_URL` 仅外部回调用）。

## 5. 功能清单（详尽版）

### 5.1 时间线数据结构（schema v1）

```jsonc
{
  "schema": 1,
  "fps": 30,
  "aspect": "16:9",
  "canvas": { "width": 1920, "height": 1080 },      // canvasFor(aspect)，横版 1920x1080 / 竖版 1080x1920
  "durationMs": 615000,
  "tracks": [
    {
      "id": "t_main",
      "type": "video",          // video 主轨（唯一，装配基准）
      "clips": [
        {
          "id": "c_001",
          "mediaId": 12,
          "inMs": 1500,          // 媒体内入点
          "outMs": 6500,         // 媒体内出点
          "speed": 1.0,          // 0.25~4.0
          "reverse": false,
          "transitionOut": {     // 与下一 Clip 的转场（独立过渡片段范式）
            "type": "fade",      // none|fade|black|white|slideL|R|U|D|zoomIn|zoomOut|blur|glitch（§5.5）
            "durationMs": 3000   // 固定 3s（与现有 generateTransitionClip 一致），可 0=硬切
          },
          "transform": {         // 画中画/副轨用；主轨默认铺满
            "x": 0.5, "y": 0.5, "scale": 1.0, "rotate": 0, "opacity": 1.0,
            "crop": { "l": 0, "t": 0, "r": 0, "b": 0 },   // 归一化裁剪
            "corner": 0                                    // 圆角半径（px）
          },
          "filters": [           // 有序滤镜栈（§5.4 白名单）
            { "id": "eq", "params": { "brightness": 0.05, "contrast": 1.1, "saturation": 1.2 } },
            { "id": "preset:vibe_warm", "params": {} }
          ],
          "audio": {             // 该 Clip 自带音频的轨内处理
            "gain": 1.0, "mute": false,
            "fadeInMs": 0, "fadeOutMs": 0
          },
          "keyframes": [         // §5.7 进阶期
            { "prop": "transform.scale", "t": 0, "v": 1.0, "ease": "linear" },
            { "prop": "transform.scale", "t": 2000, "v": 1.15, "ease": "easeInOut" }
          ]
        }
      ]
    },
    { "id": "t_pip", "type": "video", "mutedTrack": true, "role": "overlay", "clips": [ /* 画中画/分屏 */ ] },
    { "id": "t_sfx", "type": "audio", "role": "sfx", "clips": [ /* 音效 */ ] },
    { "id": "t_bgm", "type": "audio", "role": "bgm", "clips": [
        { "id": "c_m1", "mediaId": 30, "inMs": 0, "outMs": 90000,
          "audio": { "gain": 0.35, "fadeInMs": 800, "fadeOutMs": 1200, "ducking": { "enabled": true, "threshold": 0.5 } } }
    ] },
    { "id": "t_vo", "type": "audio", "role": "voiceover", "clips": [ /* TTS/旁白 */ ] },
    { "id": "t_sub", "type": "subtitle", "clips": [ /* §5.6，或整轨引用 subtitle job 的 segments */ ] },
    { "id": "t_text", "type": "overlay", "clips": [ /* 标题/贴纸，DOM 预览 + ASS/drawtext 渲染 */ ] }
  ],
  "markers": [ { "t": 45000, "label": "高潮", "color": "#f43f5e" } ]
}
```

**操作语义约定**（服务端校验器执行，客户端同样实现）：
- 主轨 Clip 之间不允许重叠（`transitionOut.durationMs` 占位规则：转场时长从**前段尾部与后段头部各借一半**的「视觉示意」，但装配实现是独立 3s 片段插入，主轨 Clip 本身不缩短——与现网成片行为一致，预览时按「插入式」呈现）；
- 副视频轨/音频轨/文字轨 Clip 可自由重叠；同轨重叠时后加入者推开前者（ripple）或叠放（取决于吸附设置，副视频轨允许同时多个=分屏布局）；
- `inMs/outMs` 必须落在媒体探测时长内（容差 1 帧）；`speed` 改变时实际占轨时长 = `(out-in)/speed`；
- 所有时间值毫秒整数，服务端渲染时换算帧（`round(ms*fps/1000)`）。

### 5.2 媒体接入（编辑器媒体库）

| 来源 | 入口 | 说明 |
| --- | --- | --- |
| 分镜段视频 | 选集 → 勾选分镜（含未 selected） | 直接引用 `segment.video_url`，带分镜标题/序号元数据；分镜重生成后提示「源已更新，可一键刷新或保持旧版」 |
| 成片 | 选某次合成/字幕版成片 | 整片入轨，配合掐头去尾做二剪 |
| 资产库 | kind=video/audio 的资产 + 图片资产 | 视频/音频/图片均可；图片入轨时按「图片片段」处理（默认 3s，Ken Burns 动效可选，§5.4） |
| 本地上传 | 拖拽/选择 | 视频（mp4/mov/webm/mkv）、音频（mp3/wav/m4a/aac/ogg/flac）、图片（jpg/png/webp）；走现有上传落 `uploads/`，服务端 `probeMedia` 校验后建档 |
| TTS 配音 | 编辑器内「文字转语音」 | 复用现有 Voice 音色库与 TTS 能力，生成即入媒体库（`kind=tts`，计费按 TTS feature） |
| BGM 文库 | 内置曲库（部署时放 `data/bgm/` 目录 + 清单 JSON） | 按情绪/节奏标签筛选；仅存相对 URL 引用不复制文件 |

接入即触发 **proxy Job**（§7.1）：720p H.264 2Mbps faststart + 雪碧图 + 波形。用户可在代理就绪前就把 Clip 拖上轨（原始 URL 兜底预览），就绪后预览自动切换代理。

### 5.3 剪切与编排（MVP 核心）

- **入出点修剪（trim）**：时间线两端拖拽 + 检查器数值输入 + `I/O` 键标记；
- **分割（split）**：播放头处一分为二（`S` 键），帧精确（按 fps 取整）；
- **删除/波纹删除**：普通删除留空洞；波纹删除（`Shift+Del`）后段前移；
- **复制/剪切/粘贴**（`Ctrl+C/X/V`）、**多选**（框选/`Shift` 加选）与批量操作；
- **拖拽排序与跨轨移动**（拖到音频轨=只保留音频，拖回视频轨恢复）；
- **吸附与磁吸**：吸附到播放头/其他 Clip 边缘/标记点/整秒网格（可开关）；
- **静音/隐藏/锁定**：Clip 级 `mute`（不出声）、`hide`（不出画，视频轨留黑）、轨道级锁定防误操作；
- **冻结帧**：播放头处截取单帧展开为图片片段（默认 1s，可调）；
- **变速**：0.25x~4x，视频按 `setpts`、音频按 `atempo` 链（保持音调）；>2x 时人声建议自动配「仅视频变速」选项；
- **倒放**：`reverse` 滤镜（视频+音频同步倒放，长度上限 30s 防内存爆）；
- **片段音量/淡入淡出**：Clip 级 gain 与 fade 曲线；
- **标记点**：任意时间打点命名，导出不影响，协作批注锚点（§11.3）。

### 5.4 视觉调整与滤镜

**滤镜白名单**（服务端校验器只放行下列 id 与参数范围，防注入；「preset:」前缀为服务端预置组合）：

| 类别 | ffmpeg 实现 | 可调参数 |
| --- | --- | --- |
| 亮度/对比度/饱和度 | `eq` | brightness[-1,1] contrast[0,4] saturation[0,4] gamma |
| 色相旋转 | `hue` | h[-180,180] |
| 曲线调色 | `curves`（预置点集） | preset: `increase_contrast`/`vintage`/`lighter`/`darker` |
| 色彩平衡 | `colorbalance` | rs/gs/bs/rm/gm/bm/rh/gh/bh |
| 色温/色调分离 | `colortemperature`（新）/ `colorchannelmixer` | temperature/tint |
| 锐化 | `unsharp` | amount/size |
| 模糊 | `boxblur` / `gblur` | radius/sigma |
| 晕影 | `vignette` | angle |
| 去噪 | `hqdn3d` / `nlmeans` | 强度 |
| 磨皮美颜（近似） | `nlmeans`+`unsharp` 负量组合 preset | 强度 0-100 |
| 镜像/翻转 | `hflip` / `vflip` | — |
| LUT | `lut3d`（部署自带 .cube 库） | 文件名白名单 |
| Ken Burns（图片动效） | `zoompan` | 起点/终点缩放与平移、缓动 |
| 画布模糊填充（竖版套横版等） | `scale+boxblur+overlay` 组合 preset | 强度 |

**调色预设库**：服务端内置 20+ 风格（电影感暖调/冷调/赛博/黑白/褪色胶片/日系清透…），前端缩略图实时 CSS `filter` 近似预览（brightness/contrast/saturate/sepia/hue-rotate 组合映射），渲染时替换为真实 ffmpeg 滤镜栈。

**变换类**：位置/缩放/旋转/透明度/裁剪/圆角（`rotate`+`scale`+`overlay`+`geq` 圆角 or 预处理 matting），全部归一化坐标存储，渲染换算到画布像素。

### 5.5 转场（沿用「独立 3s 过渡片段」范式）

- 类型：`fade`（叠化）/`black`/`white`（闪黑闪白）/`slideL/R/U/D`（滑移）/`zoomIn`/`zoomOut`（推拉）/`blur`（虚化溶解）/`glitch`（故障风）；
- 实现：扩展现有 `generateTransitionClip(imgA, imgB, trans, outPath, aspect)`——以前段尾帧与后段首帧为蓝本，独立渲染 3s 过渡片段（音频自带 crossfade 或静音），装配时按普通段参与 concat；
- `durationMs=0` 即硬切；类型可逐对设置；「全部应用」批量操作；
- 预览：转场在客户端以「蓝本帧交叉淡入」近似呈现，草稿渲染后可见真实效果。

### 5.6 字幕与文字

1. **整轨字幕（成片级）**：直接把现有 `video_subtitle` Job 的 segments 挂为字幕轨数据源；样式取 `projects.settings.subtitle`（短边 1080 基准，未设置走回退公式），渲染复用 `segmentsToAss` + `burnSubtitles`；编辑器内可逐条改文本/时间（写回草稿，同现有两段式语义）。
2. **字幕轨手动 Clip**：单条字幕 = overlay 轨 Clip（text 类型），样式面板与项目字幕样式一致并支持覆盖（字体/字号/颜色/描边/底边距/加粗/背景条）。
3. **标题/花字**：overlay 轨文字 Clip，支持进出场动画（fade/slide/pop/打字机），渲染期映射为 ASS `\fad`/`\move` 事件。
4. **渲染实现与降级**：
   - 首选 `subtitles=` 滤镜烧 ASS（`hasAssFilter()` 探测）；
   - 无 libass 的构建（本机已知坑）：**降级方案 A** —— `drawtext` 渲染基础样式（无描边动画等高级特性，界面标注「兼容模式」）；**降级方案 B（推荐补齐）** —— 部署带 libass 的 ffmpeg 静态构建（方案附运维检查清单：`ffmpeg -filters | grep subtitles`），管理端模型配置页同级加「环境体检」红绿灯提示。
5. **外挂字幕导出**：导出同时可产出 `.srt`/`.ass` 外挂文件（不烧录版本）。

### 5.7 关键帧动画（进阶期）

- 可打轨属性：`transform.x/y/scale/rotate`、`opacity`、`audio.gain`、滤镜主参数（如 `eq.brightness`）；
- 插值：linear / easeIn / easeOut / easeInOut（服务端渲染前烘焙为逐段 `zoompan`/`overlay` 表达式或分片常量逼近——每 0.5s 一片内插值锁定，避免复杂表达式兼容问题）；
- 客户端按同套插值驱动 DOM/`<video>` transform 近似预览，草稿渲染校准。

## 6. 预览体系（两级预览）

### 6.1 客户端近似预览（0 成本，交互流畅）

- **播放器调度器**：预加载当前 Clip 与下一 Clip 的 `<video>`（代理 URL），按时间线调度播放/暂停/seek；主轨硬切即「切元素」，转场以双元素 CSS opacity/transform 过渡近似；
- **副视频轨/文字/贴纸/滤镜**：DOM 层叠加（绝对定位 + CSS transform/filter），滤镜用映射后的 CSS `filter` 近似；
- **音频**：音频轨用 `<audio>` 元素同步调度；ducking/响度归一等不可精确近似，标注「以草稿渲染为准」；
- **帧步进/精确 seek**：`requestVideoFrameCallback`（可用的浏览器）对齐帧；不可用时按 fps 估算；
- 预览画质选择：代理(720p) / 原画（网络允许时）。

### 6.2 服务端草稿渲染（精看，Job）

- `POST /editor/projects/:id/preview` → `editor_preview` Job：540p CRF30、跳过响度二遍分析、转场/滤镜全真渲染；
- **增量缓存**：渲染计划按 Clip 粒度取哈希（`mediaId+in/out/speed/filters…`），命中的段复用上次段渲染产物，只重渲脏段 + 重新装配（分钟级工程秒级出片）；
- 产物 URL 回填 `edit_renders(kind=draft)`，客户端收到（任务中心轮询/回调）后切「真预览」模式整片播放。

### 6.3 帧对齐纪律

- 全链路统一 fps/SAR/像素格式/采样率（§8.1 段渲染规格）；客户端预览时间轴以 ms 计，渲染前服务端把一切对齐到帧边界并在保存响应中回传「对齐后的 timeline」供客户端回写，杜绝「预览一处、渲染另一处」。

### 7.2 editorRender.service.js（编译器）

```
timeline JSON
  → validate(schema + 白名单 + 时间轴不变量)          // 不合法 400 带 i18n key
  → plan：
      segments[]   // 每个 Clip 一条 renderClipSegment 计划（含缓存 key）

```

## 8. 渲染管线（关键设计）

### 8.1 统一段规格（concat 无损前提）

所有 `renderClipSegment` 产物与转场片段强制一致：

```
video: h264, yuv420p, fps=工程fps, SAR=1, 尺寸=画布尺寸（含 pad/crop 后）, GOP=fps*2, closed gop
audio: aac 48kHz stereo 192k（段内仅做该 Clip 自身音频的 gain/fade/atempo 预处理，静音也保留轨）
封装: mp4 + faststart；时长精确对齐：-t 由帧数决定（round(帧数/fps)），avoid 非整数帧尾巴
```

### 8.2 两遍法总流程（final 为例）

1. 逐 Clip 段渲染（并行池）→ `seg_*.mp4`；
2. 转场片段渲染（蓝本帧 = 前段产物尾帧/后段产物首帧，`extractFrameAt`）→ `trans_*.mp4`；
3. **concat 硬切装配**（concat demuxer + `-c copy`，沿用 `concatVideos` 的逐段帧对齐校验）→ `video_only_concat.mp4`（此时音频为各段自带音频拼好的「原始音轨」）；
4. **独立混音一遍**：从时间线重建全部音频意图——视频段自带音频（带 Clip 级处理）+ 配音轨 + 音效轨 + BGM 轨（含 ducking）→ `mixdown.m4a`；若用户未做任何音频加工且仅主轨，可短路跳过（直接用 3 的音轨）；
5. mux：`ffmpeg -i concat.mp4 -i mixdown.m4a -map 0:v -map 1:a -c:v copy -c:a copy out.mp4`；
6. 导出预设封装（缩放/编码/水印 overlay/字幕烧录顺序：先烧字幕再加水印）；
7. 校验：`probeMedia` 时长差 ≤1 帧、流完整性；回写 `edit_renders`/Job result。

### 8.3 音画漂移防线（把既有踩坑固化成断言）

- 禁用一切重叠式 xfade 装配（历史方案已弃用）；
- 混音只做一遍、全部 `adelay` 精确定位（ms→采样点换算统一函数）；
- 每段渲染后 probe 校验时长，超 1 帧即失败重渲（自动一次）；
- 装配前后总时长断言；导出后再 probe 一次；
- 任何 `-ss` 快速定位都用 `-accurate_seek`（输入侧 seek）+ 输出侧 `-t` 帧数锁定。

- 路由：`/workspace/projects/:pid/editor/:editId`（键传参、params 永远尾参的既有约定）；入口：项目工作台「剪辑」页签 + 集详情「二次剪辑」按钮 + 成片卡片「去剪辑」；
- 新视图 `client/src/views/workspace/EditorView.vue` + 子组件目录 `components/editor/`：

```
EditorView
├─ EditorToolbar          保存状态/undo·redo/吸附开关/预览画质/草稿渲染/导出/版本
├─ MediaPanel（左）        Tabs: 分镜 | 资产 | 上传 | 音乐(BGM/音效) | 文字 | 贴纸 | 特效 | 转场
├─ PreviewStage（中）      播放器 + 安全区框 + 画幅切换 + 帧步进 + I/O 标记 + 变换操控手柄
├─ InspectorPanel（右）    选中对象的属性分区（变换/速度/音量/滤镜/文字/关键帧）
└─ TimelinePanel（下）     轨道头(静音/独奏/锁定) + 标尺 + 缩略图条 + 波形 + 播放头 + 缩放
```

### 10.2 交互细节

- **自动保存**：操作后防抖 3s 或失焦即 PUT；顶部常显「已保存 v12 / 保存中… / 离线」；冲突(409)弹「覆盖/另存副本」；
- **undo/redo**：命令模式栈（50 步），纯客户端；服务端版本只前进；
- **快捷键**：Space 播放暂停、J/K/L 倒放·停·进、←/→ 逐帧、Shift+←/→ 1s、I/O 入出点、S 分割、Del/Shift+Del 删除/波纹删除、Ctrl+C/X/V/Z/Y/S、M 打标记、+/- 时间线缩放、Home/End 首尾；
- **拖拽**：媒体库→时间线、跨轨拖拽、边缘修剪（cursor 变化）、轨道高度两档；
- **性能**：缩略图条 canvas 绘制（雪碧图按需切片）、波形 canvas、`requestAnimationFrame` 播放头、虚拟化长轨道（>200 Clip 时仅渲染可视窗口）。

### 10.3 移动端（≤768px）

- 布局切换为「剪映式」竖排：上=预览（16:9 区域自适应）、中=轨道条（横向滑动，单主轨+音频轨，点选片段弹出底部面板）、下=工具 Dock（剪辑/音频/文字/贴纸/滤镜/比例）；
- 修剪用双手柄滑杆替代拖拽；弹窗遵守 `min(NNpx, 94vw)` 宽度规范；PC 端零回归（双断点同现有 StoryboardEditor 做法）。

### 10.4 样式与 i18n

- 延续现代 SaaS 仪表盘 + indigo 品牌色体系；时间线暗色工作区（专业工具惯例）；
- 全部文案 `editor.*` 扁平键，9 语言齐全；`t()` 必须指向叶子字符串键；
- teleport 弹层（下拉/抽屉）样式放非 scoped 块挂自定义根类（既有坑规避）。

## 11. 权限与团队协作

### 11.1 权限 key（`perms.js` 新增两个）

| key | 控制点 |
| --- | --- |
| `editor.edit` | 保存 timeline / 媒体接入 / 草稿渲染 / AI 编辑类操作 |

owner 隐式全有；计费跟操作者（成员用自己的积分导出），与团队共享现规则一致。

### 11.2 编辑锁（准协作）

- 进入编辑器即注册锁（心跳 30s 续期，关闭页面 60s 后自动释放）；他人进入=只读模式（可批注、可另存副本），界面明示「XX 正在编辑」；
- 锁表内存态（重启即清，可接受——刷新重进即可）。

### 11.3 协作批注（进阶期）

- 时间线标记点扩展为批注（@成员 + 文案），挂在时间点或 Clip 上；列表侧栏汇总、点击跳转；
- 不做实时同步，批注通过轮询刷新（邀请中心同款 30s 轮询策略）。

## 12. 计费设计

原则：**确定性本地处理不按次收费，收敛到「导出」一次计费；AI 能力按各自 feature 单独计费。**

| 项 | feature key | 单位 | 说明 |
| --- | --- | --- | --- |
| 草稿预览渲染 | `editor_preview` | 每分钟 | 建议低价或免费（鼓励精修），命中缓存不计费 |
| 成片导出 | `editor_export` | 每分钟 × 分辨率档（720p/1080p/2K/4K 系数 1/2/4/8） | 预估=timeline 时长 × 档位；会员折扣走 `attachTierPricing` |
| 代理/缩略图/波形 | 免费 | — | 本地确定性处理 |
| TTS/ASR/字幕校正/去除字幕/高光/风格推荐 | 复用现有 feature | — | 确认页展示模型+价格，`modelConfigId` 透传 |
| GIF/音频导出 | `editor_export` 系数 0.5 | 每分钟 | — |

取消/失败退款：沿用 `withCredits` + 取消统一退款 + 崩溃孤儿退款的既有机制（导出 Job 与合成同范式）。

## 14. 性能与扩展性

- **段渲染并行池**：`min(4, cpus-1)`（对齐 `BATCH_CONCURRENT_LIMIT` 经验值），防打爆本机；
- **硬件编码可选项**：darwin `h264_videotoolbox` / Linux `h264_nvenc`（环境探测+管理端开关；4K 导出建议开启）；
- **增量渲染**：Clip 级缓存哈希 + plan_hash 整体哈希两级；
- **代理秒开**：接入即转（`-preset veryfast`，720p 单分钟视频 < 数秒）；大文件上传走分片（>200MB 提示）；
- **进度体验**：Job stage 细分（媒体准备→分段 12/38→装配→混音→封装），任务中心播报；
- **横向扩展预留**：渲染器与 Web 同进程（现状），但 `editorRender.service` 接口按「可拆独立 worker」设计（plan 为纯数据），未来可搬专用渲染机。

## 15. 安全设计

- **滤镜/参数白名单**：`filters` 数组仅放行 §5.4 表内 id 与参数区间；文字内容经长度/字符集校验后进 ASS 生成器（转义 `\N` `\h` `{}`）；
- **命令注入**：一切 ffmpeg 参数走数组；文件路径全部由 `genFilePath` 生成或 `urlToPath` 校验（拒绝对路径穿越）；
- **上传校验**：`probeMedia` 深度校验（魔数/编解码白名单/时长上限），图片对齐 4K 画质基线；
- **资源限额**：单用户并发渲染 Job=1、全局渲染并发=N（配置项）、单工程媒体数/时长上限、磁盘配额（按用户汇总 uploads+output，超限禁导出并提示）；
- **内容安全**：AI 能力沿用各 provider 审核拦截文案；导出产物不外发（仅 /files 内网相对 URL，分享走现有分享链接 24h 机制）；
- **审计**：导出/删除/恢复均留 Job/meta 痕迹（软隐藏范式）。

## 16. i18n 与无障碍

- 9 语言（zh-CN/zh-TW/en/ja/ko/es/fr/pt/…按现有清单）`editor.*` 键全覆盖；错误键走后端 i18n 解析器（Accept-Language），前端只回显；
- 时间线对比度、焦点态、键盘全操作（快捷键表内嵌帮助弹窗 `?` 键唤起）；
- 预览自动循环开关、播放速率 0.5/1/2（校对字幕场景）。

## 18. 风险与对策

| 风险 | 影响 | 对策 |
| --- | --- | --- |
| 本机 ffmpeg 无 libass（已知坑） | 字幕/花字渲染降级 | `hasAssFilter()` 探测 + drawtext 兼容模式 + 部署体检红绿灯；部署文档附静态构建清单 |
| 长工程渲染耗时 | 体验 | 段并行+增量缓存+分段进度+断点续渲+草稿先看 |
| 音画漂移回归 | 成片质量 | §8.3 断言固化：时长探针校验、装配断言、两遍法、自动化回归用例（固定样片工程） |
| 时间线复杂度爆炸 | 开发周期 | schema 分级（P1 只开主轨+音频轨字段，其余字段服务端忽略）、功能开关按阶段放量 |
| 浏览器视频解码差异（HEVC/ProRes） | 预览黑屏 | 代理统一转 H.264/AAC；不可转码的格式标注「仅可参与导出，不支持预览」 |
| 大文件上传/磁盘压力 | 稳定性 | 分片上传提示、磁盘配额、LRU 段缓存、启动孤儿清理 |
| 计费争议（渲染失败） | 客服 | 失败自动退款 + plan_hash 复渲免费 + 任务中心留痕 |

## 19. 附录

### 19.1 时间线→ffmpeg 编译示例（单 Clip 段渲染）

```
输入: seg_1307.mp4, in=1.5s, out=6.5s, speed=1.25, 滤镜 eq(saturation=1.2), 画布 1920x1080
ffmpeg -accurate_seek -ss 1.5 -t 4.0 -i seg_1307.mp4 \
  -filter_complex "[0:v]setpts=PTS/1.25,eq=saturation=1.2,\
scale=1920:1080:force_original_aspect_ratio=decrease,pad=1920:1080:(ow-iw)/2:(oh-ih)/2,\
setsar=1,fps=30,format=yuv420p[v];\
[0:a]atempo=1.25,volume=1.0,aresample=48000,aformat=channel_layouts=stereo[a]" \
  -map [v] -map [a] -c:v libx264 -crf 18 -preset medium -g 60 -c:a aac -b:a 192k \
  -movflags +faststart -video_track_timescale 15360 seg_c001.mp4
```

### 19.2 混音图示例（BGM ducking）

```
[voz][delayed_bgm] 按时间线 adelay 定位后：
[bgm][voice]sidechaincompress=threshold=0.05:ratio=8:release=400[duck];
[duck][sfx][vo]amix=inputs=3:normalize=0,loudnorm=I=-16:TP=-1.5:LRA=11[out]
```

### 19.3 API 错误键（节选，i18n flat-key）
