# AI 短剧工作室 · PC 端使用手册

> 适用对象：AI 短剧工作室网页版（PC）的普通用户。
> 顶部导航一条主线：**AI 编剧 / 项目 / 任务中心 / 展示中心 / 接单中心 / 积分中心**，右上角是邀请铃铛、积分徽章与头像菜单。
> 从一句话创意到成片发布，全程网页完成。

---

## 一、快速上手：一条完整创作动线

1. 注册 / 登录（本地账号：用户名 / 邮箱 / 手机号 + 密码）
2. **AI 编剧**四步向导：聊创意 → 生成大纲 → 分集 → 逐集细化 → 导出为项目
3. 项目工作台三步：**剧本大纲 → 资产库 → 分集视频**
4. 分镜编辑器：生成提示词 → 生成分镜视频（单镜/批量）→ 分镜检查
5. **合成全集** + 加字幕 / 在线剪辑
6. **下载成片**、生成 24 小时分享链接，或**发布到展示中心**

---

## 二、登录与账号

- 本站为**本地账号体系**：「注册」填用户名 + 密码（过一道点选验证码，注册成功即登录并送体验积分）；「登录」支持用户名 / 邮箱 / 手机号任一。忘记密码请联系站点管理员在管理后台重置。登录成功后自动回到原页面。
- **游客**可自由浏览展示中心并观看作品；其余功能点击后引导登录（登录后回到原处）。

## 三、导航布局

- **普通用户**：顶部横条导航（AI 编剧 / 项目 / 任务中心 / 展示中心 / 接单中心 / 积分中心）+ 右上角邀请铃铛（新邀请亮红点）、积分徽章、头像菜单（设置 / 退出登录）。
- **管理员**：改为左侧边栏，常用导航之外另有「系统设置」分组（模型配置、美术风格、支付管理、用户管理等，见文末）。
- **项目工作台 / 分镜编辑 / 在线剪辑**为沉浸式全屏页，自动收起导航。

## 四、展示中心

- 入口：顶部导航「展示中心」（站点首页也默认跳到这里）。游客可用。
- 浏览全站已发布短剧卡片（封面、集数、发布者、浏览量），支持**视觉风格 / 叙事类型 / 关键词**筛选与「全部 / 我发布的」切换；发布者与管理员可下架。
- 详情页：竖排剧集列表连播播放器（播完自动下一集）+ 风格/类型标签 + 播放量统计。
- **做同款**：点卡片或详情页大按钮，该作品的名称、简介、题材、风格、画幅会自动带入「AI 编剧」生成同款草稿；游客先引导登录，回来自动续起。

## 五、AI 编剧（四步向导）

- 入口：顶部导航「AI 编剧」，或展示中心「做同款」。
- 底部步骤条可回跳；右上草稿下拉可切换/删除多个剧本草稿，**自动保存**。

| 步骤 | 做什么 |
| --- | --- |
| ① 对话构思 | 选叙事题材，与 AI 流式对话打磨创意（免费、可随时停止）；满意后点「生成大纲」（计费，弹确认框） |
| ② 分集概要 | 左侧编辑总大纲，右侧逐集标题/概要；设定目标集数后「拆分并生成」（计费） |
| ③ 逐集细化 | 逐集细化或「批量细化未完成」（一次确认、一次计费）；AI 正文可继续改写 |
| ④ 导出项目 | 填项目名/题材/风格与画幅，一键「导出为项目」，自动创建项目并进入工作台 |

## 六、项目列表

- 入口：顶部导航「项目」。
- 「新建项目」弹窗：项目名、叙事类型、**视觉风格选择器**（写实/动漫两类）、画幅（9:16 / 16:9 / 1:1）；编辑态可上传封面或 **AI 生成封面**（先选出镜角色/场景/素材，再走模型+价格确认），还可填制作人/版权。
- 项目卡显示封面、画幅角标、风格名、集数与**进度条 + 阶段徽标（剧本大纲→资产库→分集视频→完成）**，点卡片或徽标直达当前阶段。
- 卡片「⋯」菜单：打开项目；所有者另有编辑 / 管理成员 / 删除；被共享成员显示「共享 · 创建者名」并有「退出项目」。

## 七、项目工作台（三步）

顶栏信息条：项目名、共享标注，以及三个快捷 chip——**画幅**（点击改比例）、**风格**（点击换风格）、**字幕设置**（字体/字号/底边距，带预览）；所有者另有「成员管理」。下方三步分段导航（完成打 ✓，自动定位到第一个未完成步骤）：

### 步骤 1 · 剧本大纲
- 导入剧本：**粘贴文本**或上传 .txt / .md / .pdf，点「AI 智能拆分」自动分集（**本地切分，零积分**）。
- 左侧分集列表 + 右侧正文预览；逐集编辑标题/正文、新增/删除分集、导出全本 .txt。

### 步骤 2 · 资产库
- 页签：**角色 / 场景 / 道具 / 素材 / 视频**，支持搜索。
- **AI 提取资产**：从剧本自动抽出角色/场景/道具（带进度条）。
- **角色创建向导**；单个/批量**生成提示词**；单个/批量 **AI 生图**（走确认弹窗）。
- 为资产上传/更换图片或视频（支持拖拽）、设置**参考图**；角色可管理**多套服饰**、**绑定音色**（弹窗内筛选 + 试听）。
- 「视频转关键帧」可从视频产出素材图。

### 步骤 3 · 分集视频
- 左侧分集列表（状态、角色/场景数）；右侧两张操作卡：**AI 提取本集要素**、**生成分镜 / 重新生成分镜**（生完进入分镜编辑器）。
- **成片区**：每集成片显示原片与字幕版/剪辑版缩略图，每张可**下载、编辑字幕/加字幕、在线剪辑、删除**。
- 顶部「**一键分享**」（生成 24 小时免登录播放链接 + 二维码）、「**发布到展示中心**」（填简介、勾选分集，含审核状态与驳回原因显示）、「**下载全集**」。

## 八、分镜编辑器

- 入口：工作台步骤 3「进入分镜」；顶部可切换其他分集。
- **三栏布局**：左侧「本镜资产」面板（从资产库添加/移除、看大图、播视频、角色音色试听）；中间分镜表（展开单镜：场景描述、视频提示词）；右侧预览窗（有视频时）或提示词窗。

**单镜操作**：
- 生成视频提示词 → **生成本镜视频**（走模型+价格确认弹窗）
- 上传本地视频替代 / 编辑（镜号、时长 2–15 秒、转场、台词、提示词）/ 删除视频
- 本镜**在线剪辑**、**AI 擦除字幕**

**底部时间轴**：
- 缩略图轨道全选/勾选分镜、‹ › 调整镜序、镜间**插入空白分镜**、设置镜间**转场特效**。

**批量操作**：
- **分镜检查**：免费体检（缺资产、时长超限、无图等警告），可一键应用修复。
- 批量生成提示词；**顺次生成视频**（串行，相邻同场景镜头自动尾帧衔接，显示 n/total 进度）；**批量并发生成**（并行，更快，可取消）。
- **合成全集**：勾选镜头按转场拼接整集，选分辨率档位后确认，显示合成进度。

## 九、在线剪辑器

- 入口：分镜编辑器或工作台成片区的剪刀按钮，独立全屏窗口。
- 播放器 + 时间线：播放/暂停、逐帧、**在播放头剪断**、删除片段；拖动片段重排、拖两侧手柄**裁剪入出点**，检查器可精确输入入点/出点；支持撤销/重做/重置/全屏。
- 「导出」弹窗：显示段数、输出分辨率（2K/4K 有提示）、时长与**积分估算**，确认后后台合成；若源是分镜或成片，导出后**自动写回替换**原视频。

## 十、任务中心

- 入口：顶部导航「任务中心」；铃铛/徽章显示进行中任务数。
- 任务表：类型、状态、进度条、消耗积分、提交时间、耗时；筛选「全部 / 进行中 / 成功 / 失败」，分页，每 2 秒自动刷新。
- **取消与退款**：排队中随时取消；运行中超过 10 分钟可取消，预扣积分自动退还。
- 成功任务点「**查看结果**」直达对应分镜编辑器或项目工作台。

## 十一、积分中心

- 入口：顶部导航「积分中心」或顶栏积分徽章。
- 余额卡（**1 元 = 10 积分**）+ **充值套餐卡**（含赠送角标）→ 微信支付弹窗（扫码/收银台）→ 到账自动刷新；充值记录可查。
- **各能力单价表**（图像 / 视频各档每秒积分）与**积分流水**（充值 / 消费 / 退款 / 结算）。

> 💡 所有 AI 生成操作共用统一的**「模型 + 价格」确认弹窗**：选模型（下拉内可见限时折扣标签）、选分辨率档位、可附参考图与补充要求，实时显示积分估算（含批量求和与单价明细），点「确认」才提交任务，取消不扣费。

## 十二、接单中心

面向发包/接单变现的悬赏广场，需登录。

- 页签：**广场 / 我发布的 / 我接的**，可只看进行中；卡片显示需求标题、时长、**每秒单价与总价**、发布者/接单人、状态。
- **发布任务单**：填标题、需求描述、时长、每秒单价、分辨率与画幅，自动算总价并显示余额；**发布即冻结积分（托管）**，余额不足会提示。
- **接单**需二次确认（防重复接单）。
- 详情页：需求说明 + 交付成片播放 + **事件时间线**（📝 发布 → 🎯 接单 → 📦 交付 → ↩️ 驳回 → ✅ 验收）。按角色操作：
  - **发布方**：验收（积分放款给接单人）/ 驳回（必填理由）/ 取消 / 申请仲裁；
  - **接单方**：交付（从自己项目成片中选一集 + 附言）/ 放弃；
  - 争议由管理员仲裁裁决。

## 十三、团队协作（邀请）

- 入口：右上角**邀请铃铛**（红点 = 待处理）。
- 收到的项目邀请列出邀请人、授予的**权限标签**（或只读）与有效期，「接受」后跳回项目立即可见，或「拒绝」。
- 项目内共享由所有者在「成员管理」弹窗操作：按邮箱/手机号查找用户、逐成员勾选**细粒度权限**（剧本编辑、资产生成、成片管理等）、移除成员、撤销待处理邀请。

## 十四、设置

- 入口：右上角头像菜单「设置」。
- 偏好：**主题**（浅色 / 深色 / 跟随系统）、**界面语言**切换。
- 账户：角色与积分展示、修改昵称、展开式**修改密码**（验证旧密码后设置新密码）。

## 十五、分享播放页

- 他人通过「一键分享」发来的链接，**免登录**直接打开：封面海报 +「播放全部」，上下滑动切集、自动连播、记忆各集进度、静音开关。
- 分享链接 **24 小时有效**，过期会明确提示（重新分享即可生成新链接）。

## 十六、管理员功能速览（仅 admin 可见，左侧栏「系统设置」分组）

| 页面 | 用途 |
| --- | --- |
| 用户管理 | 账号查询、积分调整、角色管理 |
| 模型配置 | 文本/图像/视频模型参数、分辨率、定价与折扣 |
| 模型厂商 | 上游供应商账号与渠道 |
| 美术风格 / 角色选项 | 风格与角色设定字典维护 |
| 支付管理 | 充值订单、支付渠道配置 |
| 展示审核 | 展示中心内容审核上下架 |
| 声音库 | 音色维护：筛选、新增/编辑、上传样本（≤25MB）、试听 |
| 推广管理 / 日志 / 运维 | 邀请返利、AI 提交日志、站点维护开关 |
