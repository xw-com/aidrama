# 分镜时序与运镜参考（逐秒精准控制）

## 一、标准公式

```
[x秒-x秒]: [运镜方式] + [景别] + [主体] + [核心动作] + [限制条件]
```

> 单镜头 4-15 秒，拆分为 2-3 个时间段，每个时间段描述一个连贯动作。

> 参考 镜头库

## 三、常用景别备选

| 景别 | 范围 | 适用场景 |
|------|------|----------|
| 特写 | 面部/手部 | 极致情绪 |
| 近景 | 胸部以上 | 对话、表情 |
| 中景 | 腰部以上 | 人物动作 + 环境 |
| 全景 | 全身 + 环境 | 场景交代、动作场面 |
| 远景 | 大环境 | 氛围渲染、转场 |

## 四、分镜示例

### 示例 1：雨中信封（情绪向）

```
0-2秒：固定机位，中景，男主站在雨中，低头看着手中的信封，雨水打湿头发，镜头焦点锁定信封
2-5秒：缓慢向前推进，从全景推至特写，男主缓缓抬起头，眼神从迷茫转为坚定，背景逐渐虚化
5-8秒：缓慢向后拉开，男主转身走进雨幕，身影逐渐变小，最终消失在街道尽头
```

### 示例 2：对话场景（叙事向）

```
0-3秒：固定机位，近景，女主角坐在窗边，侧脸被柔和日光照亮，微微低头翻阅旧照片
3-6秒：固定机位，近景切特写，女主角手指停在某张照片上，嘴角浮现淡淡微笑，眼眶微红
6-8秒：缓慢向前推进至特写，镜头聚焦照片中的两个人影，背景逐渐模糊为光斑
```

### 示例 3：动作场景（动态向）

```
0-2秒：斯坦尼康跟拍，全景，男主快步穿过嘈杂市场，人群自动避让，镜头紧随其后
2-5秒：水平右横移，中景，男主侧身闪过摊位，眼神锁定前方目标，步伐加快
5-8秒：缓慢向前推进至近景，男主停下脚步，深呼吸，转头看向镜头方向，眼神凌厉
```

## 五、分镜编写要点

1. **时间连续性**：各时间段必须首尾相接，覆盖完整 4-15 秒
2. **动作连贯**：上一段的结束动作是下一段的起始状态
3. **焦点明确**：每个时间段指定一个视觉焦点
4. **限制条件**：必要时附加限制（如"背景虚化""镜头焦点锁定XX"）
5. **情绪递进**：应有情绪变化弧线（如迷茫→坚定→释然）
