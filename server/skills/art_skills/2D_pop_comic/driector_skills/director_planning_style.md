# 波普美漫约束 · 波普美漫 · 技法参考

---

## 一、色调体系与画面基调

- **色调基底** — 全片以柠檬黄（C4）、波普红（C2）、电光蓝（C3）为基底撞色，整体色温明亮中性（6000-6800K），饱和度高（75-95%），呈现波普美漫的潮流俏皮感。全片保持高明度撞色基底，中性色（米白纸 C9、墨黑 C6）负责留白与轮廓分割
- **冷暖叙事对比** — 冷色（电光蓝 C3、天青蓝 C7、葡萄紫 C10）作为叙事转折的视觉信号，用于夜晚、吐槽、冷静段落局部点缀。冷暖切换应与故事弧线同步，而非随意混用
- **色盘先行原则** — 段落规划需先绑定情绪场景（日常/心动/爆点/闹剧等），再确定主色+辅色与光影方案，避免"剧情对了但情绪不对色"
- **禁用色域** — 低饱和莫兰迪色、柔和渐变、写实皮肤色与现代 CG 渲染色彩体系均与本风格不兼容

---

## 二、光影方案体系

- **光影即叙事** — 6 套光影方案对应不同情绪段落，导演规划阶段应在段落层面确定光影基调方向，而非逐镜指定
- **光源角度** — 默认正面平光 + 硬边色块阴影，拒绝写实斜侧光与柔和渐变

| 情绪段落 | 光影方向 | 色调倾向 | 适用阶段 |
|---|---|---|---|
| 都市日常 | A·明亮平光 | 柠檬黄底 + 天青蓝辅 | 全片 |
| 心动爆点 | B·放射线爆点 | 波普红 + 洋红粉 | 恋爱段 |
| 闹剧冲突 | C·对角色块分割 | 波普红 + 墨黑 | 冲突段 |
| 夜晚潮酷 | D·冷调大色块 | 葡萄紫 + 电光蓝 | 夜晚段 |
| 悲伤委屈 | E·网点加密 | 电光蓝 + 米白纸 | 低谷段 |
| 回忆/闪回 | F·粗网点仿旧印刷 | 米白纸 + 洋红粉 | 回忆段 |

- **冷暖光分配** — 高明度暖撞色（柠檬黄/波普红/橘红）贯穿全片可用；冷调（电光蓝/葡萄紫）在夜晚、转折、冷静段落使用
- **氛围方向映射** — 每场戏的氛围方向应能映射到上述光影方案（A-F）的某一方向，确保视觉一致性

---

## 三、质感方向

- **版画平面感** — 波普美漫的核心：粗黑轮廓、大色块平涂、网点铺色、硬边无渐变
- **粗黑轮廓 + 网点铺色** — 这是画面质感的锚点。不是柔和晕染，不是厚涂堆叠
- **平面不等于单调** — 本风格强调平面构成的表现力（撞色对比、网点疏密、图形爆点），通过色块节奏与梗点设计放大感染力，而非依赖立体塑造
- **俏皮不等于幼稚** — 波普美漫强调潮流艺术感（利落轮廓、讲究撞色、印刷质感），通过夸张与幽默设计放大感染力，而非依赖低幼涂鸦

---

## 四、波普都市场景空间元素

波普美漫世界观特有的场景元素及其视觉叙事功能：

- **撞色店面/大招牌/斑马线/货架展架** — 天然的框架式构图道具，制造色块分割的层次感与平面纵深
- **唱片店/咖啡馆/天台** — 青春感与梗点的天然载体，景即情：唱片店里戴上耳机 = 心动、咖啡馆卡座对坐 = 暧昧、天台吹风 = 青春烦闷
- **放射线/速度线/汗滴泪珠图形** — 留白构图的天然载体，景即情：放射线爆点 = 心动或震惊、速度线 = 追逐闹剧、汗滴图形 = 尴尬无措
- **霓虹菜单/灯箱/唱片机/点唱机** — 波普美漫的光源载体，霓虹菜单 = 复古甜腻（方案B）、灯箱 = 都市行进（方案D）、点唱机 = 心动触发
- **段落间用场景空镜过渡** — 本风格有丰富的场景资产（不同时段/天候/撞色变体），段落衔接建议用场景空镜或漫画分格硬切做情绪缓冲
- **转折点用视觉而非台词** — 优先使用画面手段（撞色突变、爆点图形、景别跳切）而非依赖对白解释

## 五、波普乐器与环境音

波普美漫世界观下的声音元素约束：

### 乐器选择

- **电风琴** — 日常/俏皮段落的核心乐器，60 年代波普质感的最强代表
- **爵士鼓刷/鼓组** — 闹剧/追逐段落，弹性节奏适合喜剧氛围
- **电贝斯** — 心动/都市段落，滑音俏皮感适合恋爱氛围
- **尤克里里/口哨** — 开场/收尾/轻松段落，轻快音色适合日常氛围
- **小号** — 爆点/得意段落，短促亮音适合戏剧化强调

### 乐器组合策略

| 情绪阶段 | 乐器组合 |
|---|---|
| 平稳/开场/收尾 | 尤克里里独奏 或 口哨 |
| 日常俏皮 | 电风琴 + 轻鼓刷 |
| 心动/浪漫 | 电贝斯滑音 + 铃鼓 |
| 闹剧/冲突/追逐 | 爵士鼓组 + 小号 |

### 波普环境音

- **典型环境音层次** — 黑胶唱片沙沙声 / 汽水气泡声 / 街边人声与车铃 / 地铁进站风声 / 转盘电话铃声 / 商店开门叮当 / 相机快门声
- **每场戏标注 1-2 个核心环境音**，帮助后续音效设计。环境音层次越丰富，波普都市场景越有沉浸感
- **留白比配乐更重要** — 关键情感瞬间（对视、告白、爆点定格）优先考虑去掉配乐，只留环境音（唱片沙沙声、汽水气泡、街边人声），让观众自己感受情绪
- **避免满配** — 全片配乐覆盖率建议不超过 50%。留白段落的"无声"与配乐段落形成呼吸感，突出俏皮节奏
