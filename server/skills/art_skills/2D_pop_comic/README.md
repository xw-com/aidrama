# 波普美漫风格说明

本风格专为"波普艺术美漫质感"题材打造，所有美术提示词、规范和生成内容均严格限定于：

- **波普都市世界观**：以波普艺术化的美式都市为背景，涵盖街头便利店、唱片店、咖啡馆、画廊展厅、地铁车厢、海滨浴场、公寓天台等，体现 Lichtenstein 式波普漫画的潮流都市感。
- **网点平涂质感**：所有角色、场景、道具均以波普美漫为标准，强调 Ben-Day 网点（halftone）、粗黑轮廓线、大色块平涂与丝网印刷质感。
- **高对比撞色美学**：在平涂基础上追求高对比撞色与硬边色块光影，画面明快、俏皮、张力外放，无渐变、无晕染。
- **情感表达**：适合展现心动、吐槽、闹剧、青春恋爱喜剧的美式漫画叙事，强调夸张而俏皮的情感表达。

## 适用范围

- 波普美漫题材的AI美术生成（角色、场景、道具、分镜等）
- 需要极致撞色网点、粗黑轮廓、大色块、潮流俏皮氛围的视觉创作

## 严禁内容

- 厚涂油画、写实水彩、照片写实
- 3D渲染、CG动画、渐变空气刷
- 低饱和莫兰迪灰调、柔和晕染色
- 细碎线稿、断线、素描排线

## 风格体验

在本风格下，您将体验到：

- 角色面容潮流化、表情夸张生动，轮廓粗黑利落，撞色服饰如海报
- 场景空间平面构成感强，网点铺色与色块分割明快，氛围俏皮有梗
- 道具、日常物品、环境细节均为波普化造型，色彩明艳，印刷质感清晰
- 分镜与画面均以网点撞色为基础，强调漫画分格与戏剧化俏皮表达

---

本风格仅适用于"波普美漫"相关项目。如需其他风格（如日式动画、厚涂美漫、3D 渲染等），请勿使用本套提示词。
