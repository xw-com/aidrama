# 波普美漫风格 - 场景图生成 · 约束手册

---

## 一、场景美学原则

1. **平面构成叙事** — 场景承载情绪与梗点，不是写实背景板
2. **色块层次** — 所有场景必须具备前/中/后景，以色块与网点区分层次
3. **版画质感** — 轮廓/网点/色块等材质表现必须清晰干净
4. **波普都市为锚** — 一切画面以波普艺术美漫为标准，拒绝写实透视与照片质感；追求波普版画特征（粗黑轮廓、Ben-Day 网点、大色块、丝网印刷）与高对比撞色光影（硬边色块阴影、放射线爆点图形）

## 三、室内场景

### 空间规范

| 维度 | 约束 | 提示词 |
|---|---|---|
| 风格 | 美式波普化房间/复古都市房间 | {风格}风格 |
| 材质 | 大色块墙面/几何地砖/塑料与木质家具 | 大色块墙面、几何地砖 |
| 色调 | 高明度撞色/双色撞色 | 撞色明快/双色撞色 |
| 纵深 | 前/中/后景以色块与网点区分层次 | 前景{元素}、中景{元素}、后景{元素} |

## 五、主视图规范

### 视图定义

> 单画面主视图，从场景中最具代表性的角度拍摄，承载空间叙事与构图重心。

| 项目 | 约束 | 提示词 |
|---|---|---|
| 视角 | 自然观察视角，构图最能体现场景主体与色块层次 | hero shot、graphic composition |
| 视点高度 | 默认人眼平视高度，招牌与橱窗场景可正面直给 | eye level（默认） |
| 构图 | 主体居中或符合三分法，前/中/后景色块层次清晰 | balanced composition |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 单画面（非拼图、非多视图、非分屏） |
| 人物 | **严禁出现任何人物、人影、人体轮廓** |
| 一致性 | 风格/色块/色调/光线统一 |
| 光线 | 平光逻辑，阴影统一为硬边色块 |
| 画面比例 | 默认 16:9（或按调用方设定） |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 场景必须有「前中后景色块层次」 |
| R2 | 室外远景必须「色块化归纳」，不得使用写实空气透视 |
| R3 | 场景图必须为「单画面主视图」，不得拼接多视图/分屏/网格 |
| R4 | 构图须能代表场景主体并展示前/中/后景层次 |
| R5 | 场景图中**严禁出现任何人物** |
| R6 | 必须包含波普关键词（Pop art American comic / Ben-Day dots / bold outlines） |
| R7 | 必须包含版画特征（粗黑轮廓、Ben-Day 网点 至少一项） |
| R8 | 必须保留丝网印刷质感与套色纹理，禁止光滑无瑕的"CG 感" |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 背景纯白/纯黑/无场景 |
| X2 | 极端天候（暴风雨/雷电/暴雪，除非剧情需要） |
| X3 | 场景无纵深/无层次 |
| X4 | 植被/天候与季节矛盾 |
| X5 | 出现任何人物、人影、人体剪影 |
| X6 | 画面被拼接成多视图/网格/分屏布局 |
| X7 | 3D 渲染/照片写实/厚涂油画质感 |
| X8 | 材质过于干净光滑、无任何印刷网点痕迹 |
| X9 | 光影出现柔和渐变、无硬边色块阴影 |
