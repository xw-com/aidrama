# 波普美漫风格 - 人物基础形象生成 · 约束手册

---

## 一、基础形象原则

1. **色块即灵魂** — 大色块平涂与粗黑轮廓塑造形体，块面干净如海报，避免渐变晕染
2. **角色为本** — 基础着装由角色描述（身份/职业/性别/场景）决定其常规着装；后续特定服化为叠加层
3. **四视图一致** — 面容/体型/发型/基础服装跨视图高度统一
4. **气质外放** — 无妆状态需体现角色气质（俏皮/张扬/元气/慵懒/酷感）

---

## 二、面容约束

> 不再固定五官特征参数，由角色描述（性别/年龄/性格/气质）驱动 AI 自由生成五官，保证人物间外观差异化。

### 通用要求

| 项目 | 约束 |
|---|---|
| 五官 | 由角色描述自然推导，不预设脸型/眼型/眉型/鼻型/唇型 |
| 风格底色 | 波普美漫插画质感（粗黑轮廓、网点铺色、硬边无渐变） |
| 气质 | 必须从角色描述提炼整体气质关键词（如俏皮/张扬/元气/酷感），并写入提示词 |
| 表情 | 中性微表情，符合角色气质 |

## 六、基础服装约束

> 基础服装由角色描述（身份/职业/性别/场景）决定其最自然的常规着装，作为该角色「日常默认态」；派对服/演出服等特殊衍生在服化衍生环节叠加。**禁止内衣打底**。

### 着装选择原则

| 角色身份 | 默认着装方向 |
|---|---|
| 学生 | 美式学院风（Polo衫/棒球夹克/百褶裙） |
| 都市白领 | 波普职业装（撞色连衣裙/亮色套装） |
| 潮流青年 | 复古波普休闲（印花T恤/牛仔/波点裙） |
| 艺术家/创作者 | 工作室穿搭（背带裤/贝雷帽/罩衫） |
| 服务业店员 | 制服化撞色工装（围裙/店员马甲） |
| 角色描述未明确 | 美式波普都市休闲装 |

### 着装统一规则

- 服装风格须与波普美漫美学一致（撞色大色块、粗黑描边、印刷质感）
- 色块简洁、大块面分布，无细碎渐变，便于后续衍生叠加
- 四视图服装款式完全一致
- 基础服装是「日常默认态」，焦点仍在面容与体态
- 严禁内衣/暴露/性化打底

## 八、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须为「素颜无妆」状态 |
| R2 | 必须根据角色描述声明合适的常规着装作为基础服装（如学生→美式学院风、白领→撞色连衣裙、潮流青年→波普休闲装）；禁止内衣打底 |
| R3 | 必须声明「无发饰、无配饰」 |
| R4 | 必须指定「米白网点纸背景 #F2EDE2」 |
| R5 | 必须指定「四视图一致性」 |
| R6 | 全身立像必须从头到脚完整展示，严禁裁切 |
| R7 | 必须指定角色身高并通过头身比换算约束全身比例（女性默认168-178cm/8-9头身超模比例，男性默认178-190cm/8-9头身健硕海报比例） |
| R8 | 人像特写必须从头顶到锁骨完整展示，严禁裁切头顶 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 内衣/暴露/性化打底；与角色描述明显不符的着装；过度复杂花纹/装饰干扰后续服化叠加 |
| X2 | 厚涂油画质感、柔和渐变皮肤 |
| X3 | 写实皮肤质感、无轮廓照片感 |
| X4 | 复杂场景背景（必须米白网点纸背景） |
| X5 | 夸张表情/动态姿势 |
| X6 | 全身立像裁切头顶或脚底，必须从头到脚完整入画 |
| X7 | 人像特写裁切头顶，必须从头顶到锁骨完整入画 |
| X8 | 忽略身高和头身比约束 |
