## 二、全局色彩盘（风格基线，不是硬锁）

> 目标：统一审美而非限制创作。除「硬约束色」外，其余颜色默认优先使用，可在合理范围内偏移。

### 色彩使用层级

| 层级 | 约束强度 | 说明 |
|---|---|---|
| L1 硬约束 | 高 | 仅锁定角色识别核心：轮廓线、肤色、主服底色的审美方向 |
| L2 软约束 | 中 | 场景色、撞色块、网点色优先参考色盘，可按镜头与剧情微调 |
| L3 例外机制 | 低 | 回忆/闹剧/特殊场景可临时突破局部色彩，但需保留整体高明度撞色逻辑 |

### 硬约束色（默认锁定）

| 色项 | 对应色 | 规则 |
|---|---|---|
| 肤色基准 | C1 奶油肤 | 默认优先，允许小幅明度/暖度微调（奶油/蜜色偏移） |
| 轮廓线基准 | C6 墨黑 | 粗黑轮廓线默认锁定，线宽均匀连贯，允许向深蓝黑轻微偏移 |

### 软约束色（推荐优先）

> C2/C3/C4/C5/C7/C8/C9/C10 为推荐色域，用于服装、装饰、背景、撞色块、环境等。可根据镜头氛围做同色相邻近调整。

### 情绪色盘使用规则

| 编号 | 规则 |
|---|---|
| E1 | 每条提示词至少指定 1 个「情绪场景」并绑定主色+辅色组合 |
| E2 | 单镜头主色不超过 2 个，避免撞色失焦变脏 |
| E3 | 情绪切换时优先调整撞色组合与色块占比，再调整网点密度 |
| E4 | 潮流向默认遵循「高明度底 + 对撞色块」：米白/柠檬黄铺底，红蓝撞色聚焦主体 |
| E5 | 若与剧情冲突，以情绪色盘优先于通用推荐色，但不得突破严禁项 |

### 色温约束

| 参数 | 值 | 说明 |
|---|---|---|
| 整体色温 | 明亮中性 6000-6800K（推荐） | 明快波普主基调 |
| 肤色色温 | 微暖 5500-6000K（推荐） | 奶油肤但平面化处理 |
| 对比度 | 极高（硬边色块） | 色块边界干净利落 |
| 饱和度 | 高 75-95%（建议区间） | 波普插画撞色浓度 |

### 容差与例外

| 项目 | 建议容差 |
|---|---|
| 色相偏移 | ±6° |
| 饱和度偏移 | ±8% |
| 明度偏移 | ±8% |

> 例外场景：回忆、闹剧、爆点镜头可使用单色专色或双色专色对撞；但禁止莫兰迪灰调与写实渐变入镜。
