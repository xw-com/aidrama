# 油画风格约束 · 油画质感写实 · 技法参考

---

## 一、色调体系与画面基调

- **色调基底** - 全片以亚麻布底（C1）、釉染肤（C2）、熟褐（C5）为基底色，整体色温偏暖（3800-4600K），饱和度中低（35-55%），呈现古典油画的醇厚与时间感
- **明暗叙事对比** - 暖色（那不勒斯黄 C7、威尼斯红 C3、焦茶金 C8）作为情感升温与关系确认的视觉信号，冷色（群青蓝 C6）用于疏离、夜色与压抑段落。明暗对照的强弱应与情绪弧线同步
- **明暗分配策略** - 日常与铺垫段落以中调为主，亲密与告白段落释放烛光暖点并加深暗部；避免全程高亮导致明暗层次塌陷
- **色盘先行原则** - 段落规划先绑定情绪场景（相遇/暧昧/告白/争执/和解等），再确定主色+辅色与光影方案，避免"剧情对了但情绪不对色"
- **禁用色域** - 高饱和荧光色、霓虹污染、现代艳丽色彩与"塑料感"画面均与本风格不兼容

## 二、光影方案体系

- **光影即叙事** - 6 套光影方案对应不同情绪段落，导演规划阶段应在段落层面确定光影基调方向，而非逐镜指定
- **光源角度** - 正给镜头默认 30°-45° 斜射（窗光/烛光的自然角度），侧给镜头加强明暗对照，塑造面颊三角光

| 光影方案 | 方案名 | 色调倾向 | 适用情绪 |
|---|---|---|---|
| A | 维米尔窗光 | 单侧窗光 + 冷暖平衡 | 日常相处、静观叙事 |
| B | 伦勃朗光 | 暖侧光 + 深邃暗部 | 心动升温、深情刻画 |
| C | 烛光单光源 | 极暖光 + 大面积暗部 | 夜话、告白、内省 |
| D | 壁炉暖光 | 漫射暖橙 + 均匀铺陈 | 家庭温情、和解 |
| E | 阴天漫射灰光 | 灰调 + 低饱和 | 低潮、压抑、回忆 |
| F | 天光/彩窗光 | 高位光 + 提亮中轴 | 肃穆、仪式、超脱时刻 |

- **冷暖光分配** - 暖光可全片使用但需分层控制；冲突/疏离段落降低暖光占比、加大暗部，避免情绪与光色冲突
- **氛围方向映射** - 每场戏氛围方向应映射到上述光影方案（A-F）的某一方向，确保视觉一致性

## 三、质感方向

- **厚涂笔触为魂** - 笔触随形体、骨相与衣纹走向排布，颜料层叠可辨；笔触是本风格的签名，不可被"高清照片感"稀释
- **画布肌理统一** - 全片共享亚麻画布底层纹理，人物与场景处于同一张"画布"上，保证质感整体性
- **肖像感人物** - 人物如古典肖像画：骨相立体、神情庄重、光位讲究；写实基底之上叠加绘画质感，解剖比例不得为画意变形
- **静物质感** - 服化道须具备静物画可信度：金属包浆、旧木纹理、天鹅绒反光、羊皮纸细节都应符合古典静物画的光影逻辑

## 四、古典场景空间元素

油画质感写实世界观特有的场景元素及其视觉叙事功能：

- **长窗/帷幔/门拱** - 天然画框式构图道具，制造空间分层与人物关系距离感，光是穿过它们的叙事者
- **烛台/壁炉/油灯** - 可移动的暖光源，光源与人物的远近即心理距离的远近；点亮与熄灭是天然的情节节拍
- **镜子/旧画/肖像画** - 时间、身份与自我的隐喻载体，适合注视、顿悟、揭幕类镜头
- **长桌/书架/画架** - 秩序与仪式感的空间锚点，承担对峙、围坐、独处等关系结构
- **麦田/河流/林径** - 情绪的外化风景，劳作、流逝与季节感的视觉容器
- **空镜过渡建议** - 烛火摇曳、尘埃光束、空椅与垂落帷幔、雨窗反光、麦浪起伏，用于段落间情绪缓冲，避免硬切
- **视觉转折建议** - 优先用画面手段承接转折：光源熄灭与点亮、明暗对照反转、由暖入冷或由暗入明；避免用对白解释情绪变化

## 五、古典乐器与环境音

油画质感写实世界观下的声音元素约束：

### 乐器选择

- **钢琴** - 日常、回忆、内心独白段落的核心乐器，古典室内乐质感
- **大提琴与弦乐** - 厚重情感的主力铺底，与油画的醇厚色调同构
- **羽管键琴/古钢琴** - 年代感与仪式感段落的风格增强器，慎用但有效
- **木管（单簧管/长笛）** - 田园、清晨、轻盈段落的色彩乐器
- **环境音优先级高** - 古典宅邸中真实环境声是沉浸感关键，配乐不应压过对白

### 乐器组合策略

| 情绪阶段 | 乐器组合 |
|---|---|
| 平稳/开场/收尾 | 钢琴独奏 或 大提琴独奏 |
| 日常推进 | 钢琴 + 弦乐轻铺底 |
| 暧昧升温/深情 | 大提琴 + 弦乐 |
| 高潮/仪式/告白 | 弦乐主导 + 管风琴式低频铺底 |
| 回忆/空镜 | 羽管键琴 或 弦乐泛音 + 环境声 |

### 古典环境音

- **典型环境音层次** - 烛芯噼啪 / 壁炉柴火 / 翻动书页 / 鹅毛笔划纸 / 雨打旧窗 / 马蹄踏石板 / 教堂钟声 / 远处人声絮语
- **每场戏标注 1-2 个核心环境音**，帮助后续音效设计。环境音层次越准确，古典宅邸的年代质感越强
- **声音留白建议** - 与画面的暗部留深同步：情绪重场戏后允许数秒仅存环境音（如烛芯声、雨声）的静默段落，让厚度沉淀后再进入下一段落
