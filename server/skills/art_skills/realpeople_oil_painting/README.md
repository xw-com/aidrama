# 油画质感写实风格说明

本风格专为"油画质感写实"题材打造，所有美术提示词、规范和生成内容均严格限定于：

- **写实人物基底**：所有角色、场景、道具均以真人写实为标准，五官、皮肤、发丝、材质保持真实的结构与比例，仅在画面质感层面叠加绘画处理。
- **古典油画质感**：整体画面呈古典油画厚涂笔触与画布肌理，颜料层叠可辨，笔触随形体与衣纹走向排布，拒绝光滑无笔触的照片直出感。
- **古典光影体系**：以伦勃朗光、维米尔式窗光、烛光与壁炉暖光为经典光位，明暗对照强烈，暗部深邃、亮部醇厚。
- **经典油画色域**：暖褐、熟褐、威尼斯红、那不勒斯黄、焦茶金等古典油画色为全片色彩基线，构图庄重稳定，人物具肖像感与静物感。
- **庄重叙事**：适合古典情感、家族往事、怀旧年代、艺术人文类故事，强调仪式感与时间的厚度。

## 适用范围

- 油画质感写实题材的AI美术生成（角色、场景、道具、分镜等）
- 需要真人写实基底、古典油画氛围与厚涂笔触质感的视觉创作

## 严禁内容

- 卡通、动漫、插画、二次元、赛璐璐风格
- 无笔触的光滑照片直出感、数码平涂板绘
- 高饱和荧光色、霓虹色、现代艳丽色彩
- 暗示性、暴露、透视等不适宜内容
- 水墨晕染、大面积留白等水墨画语言（与水墨写实风格互斥）

## 风格体验

在本风格下，您将体验到：

- 角色如古典肖像画中走出：面容写实、笔触塑造体积、肤色如釉染般醇厚温润
- 场景如古典风景写生与室内画：光自窗口与烛台斜入，暗部深邃，空间庄重静谧
- 道具如静物画中的器物：银器、陶罐、旧书、织物在暖光下呈现厚重的材质感
- 分镜与视频均以写实人物为基底，叠加油画笔触与画布肌理，叙事庄重而富有情感

---

本风格仅适用于"油画质感写实"相关项目。如需其他风格（如都市写实、水墨写实、动漫等），请勿使用本套提示词。
