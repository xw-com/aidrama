## 二、全局色彩盘（风格基线，不是硬锁）

> 目标：统一审美而非限制创作。除「硬约束色」外，其余颜色默认优先使用，可在合理范围内偏移。

### 色彩使用层级

| 层级 | 约束强度 | 说明 |
|---|---|---|
| L1 硬约束 | 高 | 仅锁定角色识别核心：肤色、发色、主服底色的审美方向 |
| L2 软约束 | 中 | 场景色、配饰色、点缀色优先参考色盘，可按镜头与剧情微调 |
| L3 例外机制 | 低 | 仪式/回忆/高潮戏可临时突破局部色彩，但需保留整体明暗对照逻辑 |

### 硬约束色（默认锁定）

| 色项 | 对应色 | 规则 |
|---|---|---|
| 肤色基准 | C2 釉染肤 | 默认优先，允许小幅明度/暖度微调 |
| 发色/瞳色基准 | C4 深褐发 | 默认优先，允许深褐/深栗轻微偏移 |

### 软约束色（推荐优先）

> C1/C3/C5/C6/C7/C8/C9/C10 为推荐色域，用于衬布、点缀、木器、冷色衣料、暖光、铜饰、背景、植被等。可根据镜头氛围做同色相邻近调整。

### 情绪色盘（导演对齐版）

| 情绪场景 | 主色 | 辅色 | 光效与对比建议 | 画面关键词 |
|---|---|---|---|---|
| 初次相遇（日常） | C7 那不勒斯黄 | C1 亚麻布底 + C6 群青蓝 | 维米尔式窗光，冷衬暖人，对比柔和 | 明净、初见、微光 |
| 心动信号（暧昧） | C2 釉染肤 | C7 那不勒斯黄 + C3 威尼斯红 | 烛光近距，伦勃朗光勾面颊，背景沉入暗部 | 靠近、心跳、醇暖 |
| 日常相处（生活） | C1 亚麻布底 | C5 熟褐 + C9 暖画灰 | 壁炉暖光漫射，明暗过渡温和 | 温厚、家常、安稳 |
| 冲突争执（压抑） | C4 深褐发 | C6 群青蓝 + C5 熟褐 | 强明暗对照，面部半没入阴影 | 对抗、沉重、割裂 |
| 重逢和解（回暖） | C7 那不勒斯黄 | C2 釉染肤 + C8 焦茶金 | 由暗转明，光自窗口铺入，暖调回归 | 释然、回温、厚实 |
| 告白/仪式（高光） | C3 威尼斯红 | C7 那不勒斯黄 + C10 橄榄深绿 | 烛光下局部提饱和（不荧光），深色衬底 | 深情、庄重、仪式感 |
| 夜晚沉思（幽深） | C6 群青蓝 | C4 深褐发 + C7 那不勒斯黄 | 单烛光源，大面积暗部留深 | 孤独、内省、静谧 |
| 回忆/闪回（做旧） | C1 亚麻布底 | C8 焦茶金 + C9 暖画灰 | 罩染式暖褐滤镜，笔触更显、明度略降 | 旧忆、泛黄、时间感 |

### 情绪色盘使用规则

| 编号 | 规则 |
|---|---|
| E1 | 每条提示词至少指定 1 个「情绪场景」并绑定主色+辅色组合 |
| E2 | 单镜头主色不超过 2 个，避免颜色叙事失焦 |
| E3 | 情绪切换时优先调整明暗光比与光源位置，再调整饱和度 |
| E4 | 油画向默认遵循「深底 + 暖光」：暗部铺底，暖光落在人物面部与关系焦点 |
| E5 | 若与剧情冲突，以情绪色盘优先于通用推荐色，但不得突破严禁项 |

### 色温约束

| 参数 | 值 | 说明 |
|---|---|---|
| 整体色温 | 偏暖 3800-4600K（推荐） | 烛光/壁炉古典基调 |
| 肤色色温 | 微暖 4000-4500K（推荐） | 釉染般温润有厚度 |
| 对比度 | 强（建议保持） | 明暗对照（Chiaroscuro）鲜明 |
| 饱和度 | 中低 35-55%（建议区间） | 古典油画沉稳色调 |

### 容差与例外

| 项目 | 建议容差 |
|---|---|
| 色相偏移 | ±8° |
| 饱和度偏移 | ±10% |
| 明度偏移 | ±12% |

> 例外场景：告白、仪式、烛光高潮镜头可使用更高饱和的威尼斯红与那不勒斯黄局部色块；但禁止荧光霓虹与高饱和现代色彩入镜。

## 三、全局约束规则

### 必守规则（所有技能继承）

| 编号 | 规则 |
|---|---|
| R1 | 必须包含「油画质感写实」风格锚定词 |
| R2 | 必须声明「厚涂笔触 + 画布肌理」 |
| R3 | 面部必须使用「古典人像笔触 + 肤色釉染温润」 |
| R4 | 发丝必须使用「笔触塑造 + 发丝分明」 |
| R5 | 纹理必须声明「颜料层叠质感 + 笔触随形体走向」 |

### 严禁项（所有技能继承）

| 编号 | 严禁内容 |
|---|---|
| X1 | 严禁「卡通/动漫/二次元/插画风」 |
| X2 | 严禁「高饱和荧光色/霓虹色」 |
| X3 | 严禁「无笔触的光滑照片直出/数码平涂板绘感」 |
| X4 | 严禁「面部变形/多指/肢体异常」倾向词 |
| X5 | 严禁「裸体/暴露/透视/暗示性描述」 |
| X6 | 严禁「水墨晕染/大面积留白等水墨画语言」（与水墨写实风格互斥） |
