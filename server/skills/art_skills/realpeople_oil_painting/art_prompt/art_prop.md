# 道具图像生成 · 油画质感写实约束手册

---

## 一、道具设计原则

1. **功能可读** - 道具用途一目了然，造型服务于功能
2. **质感极致** - 材质须以古典静物画的绘画语言呈现（厚涂笔触、画布肌理、明暗对照下的材质光泽）
3. **年代一致** - 所有道具默认符合古典/年代世界观（古董器物、静物器皿、旧书文契），现代道具仅在角色为现代设定时出现，且须做油画质感统一
4. **尺度明确** - 通过参照物或构图暗示道具真实尺寸
5. **纯道具独立展示** - 画面中只能出现道具本身，严禁出现任何人物、手部、肢体，道具不可处于被持有/佩戴/握持状态，必须以静物画陈列方式独立呈现

## 三、多角度设定图规范

### 视图定义

| 位置 | 视图 | 角度 | 要求 | 提示词 |
|---|---|---|---|---|
| 左上 | 正面图 | 正面 0° | 道具完整正面形态 | front view |
| 右上 | 侧面图 | 侧面 90° | 厚度/轮廓/结构清晰 | side view |
| 左下 | 背面图 | 背面 180° | 道具背部结构/装饰 | back view |
| 右下 | 细节特写 | 局部放大 | 材质纹理/工艺细节 | detail closeup |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 同一画面四宫格（2×2），上下左右四视角 |
| 背景 | 暖画灰 #CFC4B0（亚麻画布底色） |
| 光线 | 静物画式均匀柔光，含蓄明暗对照，无硬阴影 |
| 比例 | 每格道具占格内主体 70%+ |
| 投影 | 允许自然地面微投影 |
| 画面比例 | 建议 1:1 |

## 四、材质渲染约束

| 材质 | 渲染要求 | 提示词 |
|---|---|---|
| 做旧金属 | 包浆温润、划痕与氧化微可见 | 做旧金属、温润包浆、氧化痕迹 |
| 粗陶 | 陶土颗粒感、釉面斑驳 | 粗陶质感、釉面斑驳 |
| 玻璃 | 透光/折射含蓄、厚涂高光 | 玻璃通透、厚涂高光 |
| 旧木 | 木纹如皴、包浆温润、磨损可辨 | 旧木纹理、包浆温润 |
| 织物 | 天鹅绒/亚麻纤维质感、帷幔式褶皱 | 织物褶皱、纤维质感 |
| 蜡与果实 | 蜡质半透、果实饱满带高光点 | 蜡质半透、静物画果实质感 |

## 六、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须指定「暖画灰画布底色背景」 |
| R2 | 必须明确道具材质与工艺 |
| R3 | 道具造型必须符合古典/年代世界观（现代道具仅在角色为现代设定时出现） |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 复杂场景背景 |
| X2 | 道具与人物同画面（本环节为纯道具图） |
| X3 | 出现任何人物形象，包括全身、半身、局部（手、手指、手臂等肢体） |
| X4 | 道具处于被持有、握持、佩戴、使用中的状态 |
| X5 | 出现暗示人物存在的元素（如手持痕迹、佩戴视角、使用姿态）；无笔触的光滑照片直出感与荧光色 |
