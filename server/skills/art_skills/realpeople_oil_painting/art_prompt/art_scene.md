# 场景图生成 · 油画质感写实约束手册

---

## 一、场景美学原则

1. **空间叙事** - 场景承载情绪与叙事功能，不是纯背景板；每个空间都应像一幅可以独立成立的古典绘画
2. **层次纵深** - 所有场景必须具备前/中/后景，如古典风景画的景物递退与水平层带
3. **质感至上** - 厚涂笔触随物象排布、画布肌理可辨、颜料层叠呈现；木器/织物/金属/石墙的材质须以绘画语言重建
4. **古典光影** - 单一光源逻辑（窗光/烛光/壁炉光/天光），明暗对照强烈，暗部深邃有细节；拒绝均匀平光与现代人工光污染

| 季节 | 主色调 | 辅色调 | 提示词 |
|---|---|---|---|
| 春 | 嫩绿 + 那不勒斯黄 | 天青、鹅黄 | 春日嫩绿、暖黄新叶 |
| 夏 | 橄榄深绿 + 群青蓝 | 深绿、暖白 | 夏木浓荫、深蓝天光 |
| 秋 | 焦茶金 + 威尼斯红 | 熟褐、琥珀 | 秋日金黄、落叶赭红 |
| 冬 | 暖画灰 + 群青蓝 | 银灰、墨蓝 | 冬雪灰白、冷蓝雪光 |

## 三、室内场景

### 空间规范

| 维度 | 约束 | 提示词 |
|---|---|---|
| 风格 | 古典宅邸/画室/书房/宴会厅/教堂/乡村农舍，巴洛克/文艺复兴/荷兰黄金时代/新古典 | 古典{风格}风格室内 |
| 材质 | 木板墙/石膏线/亚麻衬布/旧木地板/黄铜烛台为主 | 木板墙、旧木地板、黄铜烛台 |
| 色调 | 暖褐金色系 + 深色木器 + 点缀色 | 暖褐金色调、熟褐木器 |
| 纵深 | 前/中/后景层次，前景衬布帷幔、远景门窗走廊 | 前景{元素}、中景{元素}、后景{元素} |
| 质感 | 厚涂笔触随物象排布、画布纹理可辨 | 厚涂笔触、画布肌理、颜料层叠 |
| 光照 | 单侧窗光（维米尔式）/烛光/壁炉光，光束中尘埃微粒可辨 | 单侧窗光、烛光暖光、尘埃微光 |
| 构图 | 三角形/对称式古典构图，视点稳定庄重 | classical composition、stable framing |
| 瑕疵感 | 木器包浆、墙面岁月痕迹、织物旧化褶皱 | 包浆光泽、岁月痕迹、织物旧化 |

### 室内类型速查

| 类型 | 核心元素 | 氛围词 |
|---|---|---|
| 古典画室 | 画架、石膏像、衬布帷幔、颜料罐 | 创作氛围、静谧专注 |
| 书房/图书室 | 书架、木案、烛台、地球仪 | 沉思氛围、知识厚度 |
| 宴会厅 | 长桌、银器、烛台成列、帷幔 | 仪式感、庄重华丽 |
| 卧室/起居室 | 四柱床、绒帘、壁炉、旧家具 | 温暖私密、旧时光 |
| 教堂/礼拜堂 | 拱顶、石柱、彩窗、长椅 | 肃穆神圣、光影恢弘 |

## 五、主视图规范

### 视图定义

> 单画面主视图，从场景中最具代表性的角度取景，承载空间叙事与构图重心。

| 项目 | 约束 | 提示词 |
|---|---|---|
| 视角 | 自然观察视角，构图最能体现场景主体与纵深 | hero shot、representative angle |
| 视点高度 | 默认人眼平视高度，特殊场景可俯/仰 | eye level（默认） |
| 构图 | 主体居中或符合三分法/古典三角形构图，前/中/后景层次清晰 | balanced classical composition |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 单画面（非拼图、非多视图、非分屏） |
| 人物 | **严禁出现任何人物、人影、人体轮廓** |
| 一致性 | 风格/材质/色调/光线统一 |
| 光线 | 单一光源逻辑，光影方向一致 |
| 画面比例 | 默认 16:9（或按调用方设定） |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 场景必须有「前中后景层次」 |
| R2 | 室外必须包含「罩染式空气感/远景暖灰递退」 |
| R3 | 场景图必须为「单画面主视图」，不得拼接多视图/分屏/网格 |
| R4 | 构图须能代表场景主体并展示前/中/后景层次 |
| R5 | 场景图中**严禁出现任何人物** |
| R6 | 必须包含油画质感关键词（oil painting realism / impasto brushstrokes / canvas texture） |
| R7 | 必须包含古典光影关键词（chiaroscuro / 单侧窗光 / 明暗对照 至少一项） |
| R8 | 材质必须带有包浆/旧化/岁月痕迹，禁止全新无瑕的"塑料感" |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 背景纯白/纯黑/无场景 |
| X2 | 极端天候（暴风雨/雷电/暴雪，除非剧情需要） |
| X3 | 场景无纵深/无层次 |
| X4 | 植被/天候与季节矛盾 |
| X5 | 出现任何人物、人影、人体剪影或人体轮廓 |
| X6 | 画面被拼接成多视图/网格/分屏布局 |
| X7 | 卡通/动漫/3D 渲染/CG/游戏引擎质感；无笔触的光滑照片直出感 |
| X8 | 材质过于干净完美、无任何使用痕迹与岁月感（避免"塑料感"） |
| X9 | 均匀平光、无明暗对照；荧光/霓虹等现代人工光污染；水墨晕染与大面积留白构图 |
