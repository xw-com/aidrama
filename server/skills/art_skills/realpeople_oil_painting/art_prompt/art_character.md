# 人物基础形象生成 · 油画质感写实约束手册

---

## 一、基础形象原则

1. **面容即灵魂** - 五官是角色唯一锚点，以古典人像笔触塑造体积与骨相
2. **角色为本** - 基础着装由角色描述（身份/职业/性别/场景）决定其常规着装；后续特定服化为叠加层
3. **四视图一致** - 面容/体型/发型/基础服装跨视图高度统一
4. **写实基底** - 五官比例与解剖结构遵循真人写实标准，绘画质感只叠加于画面表层，不得扭曲形体

---

## 二、面容约束

> 不再固定五官特征参数，由角色描述（性别/年龄/性格/气质）驱动 AI 自由生成五官，保证人物间外观差异化。

### 通用要求

| 项目 | 约束 |
|---|---|
| 五官 | 由角色描述自然推导，不预设脸型/眼型/眉型/鼻型/唇型 |
| 风格底色 | 油画质感写实、真人写实基底、古典人像笔触、画布肌理、明暗对照光影 |
| 气质 | 必须从角色描述提炼整体气质关键词（如端庄/儒雅/沉静/炽烈），并写入提示词 |
| 表情 | 中性微表情，如古典肖像定格的一瞬，符合角色气质 |

## 六、基础服装约束

> 基础服装由角色描述（身份/职业/性别/场景）决定其最自然的常规着装，作为该角色「日常默认态」；正式服饰/特殊衍生在服化衍生环节叠加。**禁止内衣打底**。古典服饰与现代服饰皆可，由角色世界观决定。

### 着装选择原则

| 角色身份 | 默认着装方向 |
|---|---|
| 古典/年代角色 | 时代服装（长裙/马甲礼服/束腰长衣等） |
| 现代角色 | 现代便装（衬衫/大衣/连衣裙），低饱和中性色 |
| 艺术家/画师 | 亚麻衬衣/工作围裙/画家罩衫 |
| 居家/休闲 | 针织衫/居家长袍/柔软便装 |
| 特殊职业 | 对应身份服装（医师/教师/神职等） |
| 角色描述未明确 | 素色亚麻/棉质常服、古典暖褐色调 |

### 着装统一规则

- 服装风格须与古典油画美学一致（衣料垂坠厚重、褶皱如古典绘画中的织物）
- 颜色限古典油画色域（暖褐/熟褐/群青/亚麻底色），无复杂花纹/装饰，便于后续衍生叠加
- 四视图服装款式完全一致
- 基础服装是「日常默认态」，焦点仍在面容与体态
- 严禁内衣/暴露/性化打底

## 八、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须为「自然状态」|
| R2 | 必须根据角色描述声明合适的常规着装作为基础服装（如古典角色->时代服装、画师->画家罩衫、现代角色->素色便装）；禁止内衣打底 |
| R3 | 必须声明「无发饰、无配饰」 |
| R4 | 必须指定「暖画灰画布底色背景」 |
| R5 | 必须指定「四视图一致性」 |
| R6 | 全身立像必须从头顶到脚底完整展示，严禁裁切 |
| R7 | 必须声明角色身高并通过头身比换算约束全身比例 |
| R8 | 人像特写必须从头顶到锁骨完整展示，严禁裁切头顶 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 内衣/暴露/性化打底；与角色描述明显不符的着装；过度复杂花纹/装饰干扰后续服化叠加 |
| X2 | 正顶硬光/正底光/彩色光 |
| X3 | 无笔触的光滑照片直出感、数码平涂板绘 |
| X4 | 复杂场景背景（必须纯画布底色） |
| X5 | 夸张表情/动态姿势 |
| X6 | 全身立像裁切头顶或脚底，必须从头到脚完整入画 |
| X7 | 人像特写裁切头顶，必须从头顶到锁骨完整入画 |
| X8 | 忽略身高和头身比约束；为追求画意而扭曲解剖比例 |
