## 二、全局色彩盘（风格基线，不是硬锁）

> 目标：统一审美而非限制创作。除「硬约束色」外，其余颜色默认优先使用，可在合理范围内偏移。

### 色彩使用层级

| 层级 | 约束强度 | 说明 |
|---|---|---|
| L1 硬约束 | 高 | 仅锁定角色识别核心：肤色、发色、主服底色的审美方向 |
| L2 软约束 | 中 | 场景色、配饰色、点缀色优先参考色盘，可按镜头与剧情微调 |
| L3 例外机制 | 低 | 回忆/高潮/特殊场景可临时突破局部色彩，但需保留整体史诗暖金深蓝逻辑 |

| 色项 | 对应色 | 规则 |

### 软约束色（推荐优先）

> C2/C3/C4/C5/C6/C8/C9/C10 为推荐色域，用于服装、装饰、背景、暖光、阴影等。可根据镜头氛围做同色相邻近调整。

### 情绪色盘使用规则

| 编号 | 规则 |
|---|---|
| E1 | 每条提示词至少指定 1 个「情绪场景」并绑定主色+辅色组合 |
| E2 | 单镜头主色不超过 2 个，避免颜色叙事失焦 |
| E3 | 情绪切换时优先调整光比与色温，再调整饱和度 |
| E4 | 史诗向默认遵循「暖金主光 + 深蓝阴影」：暖金铺光，深蓝用于阴影/夜空/冷调对比 |
| E5 | 若与剧情冲突，以情绪色盘优先于通用推荐色，但不得突破严禁项 |

### 色温约束

| 参数 | 值 | 说明 |
|---|---|---|
| 整体色温 | 暖金主调 3200-4200K（推荐） | 油画厚涂的暖金烛光主基调 |
| 肤色色温 | 微暖 4000-4600K（推荐） | 羊皮纸暖底的健康肤色 |
| 对比度 | 强（建议保持） | 戏剧明暗，暖金高光对深蓝阴影 |
| 饱和度 | 中等 55-75%（建议区间） | 古典油画的沉稳色调 |

### 容差与例外

| 项目 | 建议容差 |
|---|---|
| 色相偏移 | ±8° |
| 饱和度偏移 | ±10% |
| 明度偏移 | ±12% |

> 例外场景：魔法发光、巨龙火光、符文圣殿镜头可使用更高饱和或更冷局部色块；但禁止高饱和荧光色与赛博朋克霓虹入镜。
