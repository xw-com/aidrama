# 欧美奇幻风格 - 人物基础形象生成 · 约束手册

---

## 一、基础形象原则

1. **笔触即灵魂** — 油画厚涂笔触为角色核心，避免赛璐璐平涂与数字化锐利边缘
2. **角色为本** — 基础着装由角色描述（种族/职业/性别/场景）决定其常规中世纪幻想着装；后续特定服化为叠加层
3. **四视图一致** — 面容/体型/发型/基础服装跨视图高度统一
4. **气质庄严坚毅** — 无妆状态需体现角色气质（庄严/坚毅/沉稳/狡黠）

---

## 二、面容约束

> 不再固定五官特征参数，由角色描述（性别/年龄/性格/种族/气质）驱动 AI 自由生成五官，保证人物间外观差异化。

### 通用要求

| 项目 | 约束 |
|---|---|
| 五官 | 由角色描述自然推导，不预设脸型/眼型/眉型/鼻型/唇型 |
| 风格底色 | 欧美奇幻油画厚涂质感（暖金深蓝、笔触肌理、戏剧光影） |
| 气质 | 必须从角色描述提炼整体气质关键词（如庄严/坚毅/沉稳/狡黠），并写入提示词 |
| 表情 | 中性微表情，符合角色气质 |
| 奇幻种族 | 精灵可叠加尖耳与修长眉骨、矮人可叠加宽颌与粗壮比例、半兽人可叠加獠牙与粗骨，须在角色描述中显式声明，其余五官仍按通用要求推导 |

## 六、基础服装约束

> 基础服装由角色描述（种族/职业/性别/场景）决定其最自然的中世纪幻想着装，作为该角色「冒险默认态」；正式服饰/特殊衍生在服化衍生环节叠加。**禁止内衣打底**。

### 着装选择原则

| 角色身份 | 默认着装方向 |
|---|---|
| 骑士/战士 | 锁子甲/板甲+披风+佩剑腰带 |
| 法师/巫师 | 长袍+兜帽斗篷+符文腰带 |
| 游侠/盗贼 | 皮甲+斗篷+护臂+长靴 |
| 牧师/圣骑士 | 神职祭袍+圣徽披肩+锁甲内衬 |
| 吟游诗人 | 华丽翻领外套+羽毛帽+短剑 |
| 种族身份（精灵/矮人等） | 种族特色服饰（精灵轻纱长袍/矮人厚重皮甲） |
| 角色描述未明确 | 中世纪幻想旅行常服（束腰外衣+长裤+皮靴+斗篷） |

### 着装统一规则

- 服装风格须与欧美奇幻美学一致（暖金深蓝、油画厚涂、笔触肌理）
- 颜色中等饱和，可含纹章/简单绣饰，便于后续衍生叠加
- 四视图服装款式完全一致
- 基础服装是「冒险默认态」，焦点仍在面容与体态
- 严禁内衣/暴露/性化打底

## 八、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须为「素颜无妆」状态 |
| R2 | 必须根据角色描述声明合适的中世纪幻想着装作为基础服装（如骑士→锁甲披风、法师→长袍斗篷、游侠→皮甲斗篷）；禁止内衣打底 |
| R3 | 必须声明「无发饰、无配饰」 |
| R4 | 必须指定「羊皮纸米黄背景 #E8D9B5」 |
| R5 | 必须指定「四视图一致性」 |
| R6 | 全身立像必须从头到脚完整展示，严禁裁切 |
| R7 | 必须指定角色身高并通过头身比换算约束全身比例（女性默认160-172cm/7-7.5头身，男性默认175-190cm/7.5-8.5头身） |
| R8 | 人像特写必须从头顶到锁骨完整展示，严禁裁切头顶 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 内衣/暴露/性化打底；与角色描述明显不符的着装；过度复杂花纹/装饰干扰后续服化叠加 |
| X2 | 日系赛璐璐/二次元动漫、过饱和荧光色 |
| X3 | 过度美白至无血色、病态苍白 |
| X4 | 复杂场景背景（必须羊皮纸米黄背景） |
| X5 | 夸张Q版/卡通比例 |
| X6 | 全身立像裁切头顶或脚底，必须从头到脚完整入画 |
| X7 | 人像特写裁切头顶，必须从头顶到锁骨完整入画 |
| X8 | 忽略身高和头身比约束 |
