# 欧美奇幻风格 - 场景图生成 · 约束手册

---

## 一、场景美学原则

1. **空间叙事** — 场景承载史诗与传说叙事功能，不是纯背景板
2. **层次纵深** — 所有场景必须具备前/中/后景，杜绝扁平
3. **质感至上** — 笔触/色彩/光影等材质表现必须清晰
4. **欧美奇幻为锚** — 一切画面以欧美奇幻油画厚涂为标准，拒绝赛璐璐/3D渲染；追求油画笔触特征（厚涂肌理、混色层次）与戏剧光影（暖金主光、深蓝阴影）

## 五、主视图规范

### 视图定义

> 单画面主视图，从场景中最具代表性的角度拍摄，承载空间叙事与构图重心。

| 项目 | 约束 | 提示词 |
|---|---|---|
| 视角 | 自然观察视角，构图最能体现场景主体与纵深 | hero shot、representative angle |
| 视点高度 | 默认人眼平视高度，特殊场景可俯/仰 | eye level（默认） |
| 构图 | 主体居中或符合三分法，前/中/后景层次清晰 | balanced composition |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 单画面（非拼图、非多视图、非分屏） |
| 人物 | **严禁出现任何人物、人影、人体轮廓** |
| 一致性 | 风格/材质/色调/光线统一 |
| 光线 | 单一光源逻辑，光影方向一致 |
| 画面比例 | 默认 16:9（或按调用方设定） |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 场景必须有「前中后景层次」 |
| R2 | 室外必须包含「空气透视」 |
| R3 | 场景图必须为「单画面主视图」，不得拼接多视图/分屏/网格 |
| R4 | 构图须能代表场景主体并展示前/中/后景层次 |
| R5 | 场景图中**严禁出现任何人物** |
| R6 | 必须包含欧美奇幻关键词（western fantasy illustration / oil painting / thick impasto） |
| R7 | 必须包含笔触特征（油画厚涂、笔触肌理 至少一项） |
| R8 | 材质必须带有风化/使用痕迹，禁止全新无瑕的"CG 感" |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 背景纯白/纯黑/无场景 |
| X2 | 极端天候（暴风雨/雷电/暴雪，除非剧情需要） |
| X3 | 场景无纵深/无层次 |
| X4 | 植被/天候与季节矛盾 |
| X5 | 出现任何人物、人影、人体剪影 |
| X6 | 画面被拼接成多视图/网格/分屏布局 |
| X7 | 日系赛璐璐/3D渲染/塑料质感 |
| X8 | 材质过于干净完美、无任何风化痕迹 |
| X9 | 光照平淡均匀、无戏剧暖金深蓝光影 |
