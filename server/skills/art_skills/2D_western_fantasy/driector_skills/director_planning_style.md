# 欧美奇幻约束 · 欧美奇幻 · 技法参考

---

## 一、色调体系与画面基调

- **色调基底** — 全片以史诗暖金（C3）、深蓝（C2）、羊皮纸米黄（C1）为基底色，整体色温暖金主调（3200-4200K），饱和度中等（55-75%），呈现古典油画的厚重史诗感。全片保持暖金深蓝对比基底，局部点缀冷紫（紫罗兰 C8）与暗红（C4）增加纹章与魔法层次
- **冷暖叙事对比** — 冷色（深蓝 C2、暗夜蓝黑 C10）作为阴影/夜空/危机的视觉信号，用于夜晚或悲壮段落局部压底。冷暖切换应与故事弧线同步，而非随意混用
- **色盘先行原则** — 段落规划需先绑定情绪场景（史诗出征/城堡议政/巨龙对峙/符文圣殿等），再确定主色+辅色与光影方案，避免"剧情对了但情绪不对色"
- **禁用色域** — 高饱和荧光色、霓虹色、赛璐璐平涂色彩体系均与本风格不兼容

---

## 二、光影方案体系

- **光影即叙事** — 6 套光影方案对应不同情绪段落，导演规划阶段应在段落层面确定光影基调方向，而非逐镜指定
- **光源角度** — 默认 30-45°斜侧光，模拟自然阳光与烛光效果；魔法场景可叠加体积光束

| 情绪段落 | 光影方向 | 色调倾向 | 适用阶段 |
|---|---|---|---|
| 史诗出征 | A·逆光暖金 | 史诗暖金主导 + 深蓝阴影 | 开场/出征段 |
| 城堡议政 | B·彩窗侧光柱 | 石灰白 + 烛火橙局部 | 内政/权谋段 |
| 巨龙对峙 | C·火光冲天 | 暗红主导 + 暗夜蓝黑压底 | 高潮/战斗段 |
| 精灵秘境 | D·斑驳林光 | 森林墨绿 + 紫罗兰点缀 | 探索/神秘段 |
| 符文圣殿 | E·体积光束 | 紫罗兰主导 + 暖金辅 | 魔法/圣物段 |
| 悲壮牺牲 | F·低调逆光剪影 | 暗夜蓝黑 + 暖金余晖 | 转折/牺牲段 |

- **冷暖光分配** — 暖金光贯穿全片可用，根据场景需要灵活调整；冷色（深蓝主调）仅在夜晚、阴影或悲壮段落使用
- **氛围方向映射** — 每场戏的氛围方向应能映射到上述光影方案（A-F）的某一方向，确保视觉一致性

## 三、质感方向

- **油画厚涂史诗感** — 欧美奇幻插画的核心：笔触厚重、肌理分明、色彩混色、光影戏剧化
- **厚涂笔触 + 戏剧光影** — 这是画面质感的锚点。不是赛璐璐平涂，不是3D渲染，不是塑料质感
- **厚涂不等于粗糙** — 本风格强调油画厚涂的质感表达（笔触肌理、色彩混色、戏剧明暗），通过构图与情绪设计放大感染力，而非依赖奇观堆叠
- **戏剧不等于阴森** — 欧美奇幻强调戏剧光影的影像表达（暖金主光、深蓝阴影、体积光束），通过镜头与情绪设计放大感染力，而非依赖黑暗压抑

## 四、欧美奇幻场景空间元素

欧美奇幻特有的场景元素及其视觉叙事功能：

- **城墙/塔楼/吊桥** — 天然的框架式构图道具，制造"威权与防线"的厚重感与空间纵深
- **王座/挂毯/彩窗** — 权力叙事的天然载体，景即权：王座石阶 = 王权、挂毯纹章 = 家族史、彩窗光柱 = 神圣合法性
- **羊皮纸地图/符文卷轴** — 任务叙事的天然载体，景即命：摊开地图 = 远征召唤、符文卷轴 = 古老预言、圣物铭文 = 宿命指引
- **篝火/壁炉/烛台** — 羁绊与密谋的光源载体，篝火 = 羁绊/夜话（方案B/C）、壁炉 = 酒馆议事、烛台 = 巫师密谋
- **段落间用场景空镜过渡** — 本风格有丰富的场景资产（不同时段/天候/地貌变体），段落衔接建议用场景空镜做情绪缓冲，如荒野古道、云压城头、圣火摇曳
- **转折点用视觉而非台词** — 优先使用画面手段（光影突变、景别跳切、空镜隐喻）而非依赖对白解释

## 五、欧美奇幻乐器与环境音

欧美奇幻世界观下的声音元素约束：

### 乐器选择

- **史诗管弦交响** — 出征/战斗/高潮段落的核心乐器，最能表现欧美奇幻的恢弘与史诗
- **鲁特琴/中世纪吉他** — 酒馆/旅路/吟游段落，拨弦的温暖感适合中世纪日常
- **凯尔特风笛/爱尔兰哨笛** — 荒野/出征/悲壮段落，苍凉音色适合史诗远征
- **管风琴/唱诗** — 圣殿/王权/神圣段落，厚重音色适合庄严仪式

### 乐器组合策略

| 情绪阶段 | 乐器组合 |
|---|---|
| 平稳/开场/收尾 | 鲁特琴独奏 或 哨笛独奏 |
| 酒馆/旅路日常 | 鲁特琴 + 轻手鼓 |
| 史诗出征/战斗 | 管弦交响 + 定音鼓 |
| 圣殿/神圣 | 管风琴 + 唱诗 |

### 欧美奇幻环境音

- **典型环境音层次** — 风过荒野 / 旗帜猎猎 / 篝火噼啪 / 铁甲铿锵 / 远钟悠鸣 / 乌鸦啼叫 / 火把噼啪 / 海浪拍岸
- **每场戏标注 1-2 个核心环境音**，帮助后续音效设计。环境音层次越丰富，中世纪场景越有沉浸感
- **留白比配乐更重要** — 关键情感瞬间（远眺、抉择、牺牲）优先考虑去掉配乐，只留环境音（风声、远钟、旗帜声），让观众自己感受情绪
- **避免满配** — 全片配乐覆盖率建议不超过 50%。留白段落的"无声"与配乐段落形成呼吸感，突出史诗的厚重感
