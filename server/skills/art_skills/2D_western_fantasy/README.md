# 欧美奇幻风格说明

本风格专为"欧美油画感奇幻"题材打造，所有美术提示词、规范和生成内容均严格限定于：

- **西方中世纪幻想世界观**：以DND/魔戒系西方奇幻为舞台，涵盖中世纪城堡、巨龙巢穴、精灵森林、矮人矿坑、骑士大厅、巫师塔、羊皮纸地图与符文圣殿，体现史诗与传说的厚重感。
- **油画感厚涂质感**：所有角色、场景、道具均以西方幻想插画油画厚涂为标准，强调笔触肌理、光影层次、色彩混色与材质体积，追求古典油画的幻想插画质感。
- **史诗暖金+深蓝美学**：在厚涂基础上追求经典幻想配色，暖金主光照与深蓝阴影形成史诗对比，羊皮纸泛黄底色与符文古铜点缀，整体氛围庄严、厚重、史诗、神秘。
- **情感表达**：适合展现史诗征途、王权更迭、种族联盟、勇者屠龙、圣物追寻的西方奇幻故事，强调宿命感、庄严感与中世纪幻想的恢弘叙事。

## 适用范围

- 欧美奇幻题材的AI美术生成（角色、场景、道具、分镜等）
- 需要油画厚涂质感、史诗暖金深蓝配色、羊皮纸地图与符文元素的西方幻想视觉创作

## 严禁内容

- 日系动画赛璐璐、二次元动漫风格
- 3D渲染、CG动画、低多边形、塑料质感
- 高饱和荧光色、霓虹色、赛博朋克
- 现代都市、科幻机甲、现代服饰
- 过度明亮通透、Q版卡通、低龄向

## 风格体验

在本风格下，您将体验到：

- 角色面容写实厚重、气质庄严或坚毅，服饰、盔甲、武器均为西方中世纪幻想风格，油画笔触分明
- 场景空间层次厚重，光影戏剧化，色彩暖金与深蓝交织，氛围庄严史诗
- 道具、魔法武器、符文圣物、羊皮卷轴均为中世纪幻想造型，材质肌理清晰，古铜与宝石光泽沉稳
- 分镜与画面均以油画厚涂为基础，强调史诗叙事、戏剧光影与恢弘场面

---

本风格仅适用于"欧美奇幻"相关项目。如需其他风格（如日系奇幻冒险、暗黑奇幻、现代动画、写实插画等），请勿使用本套提示词。
