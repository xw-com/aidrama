## 一、风格基因

| 维度 | 定义 |
|---|---|
| **一级风格** | 真人时装秀场写实（Runway-Fashion Photorealism） |
| **二级风格** | 高定秀场摄影 · 冷艳锋利质感 |
| **情感基调** | 冷艳锋利 — 前卫张力、高级气场 |
| **质感锚词** | 聚光硬光、暗场低调、轮廓光分离、瓷光肌肤 |

## 二、全局色彩盘（风格基线，不是硬锁）

> 目标：统一审美而非限制创作。除「硬约束色」外，其余颜色默认优先使用，可在合理范围内偏移。

### 色彩使用层级

| 层级 | 约束强度 | 说明 |
|---|---|---|
| L1 硬约束 | 高 | 仅锁定角色识别核心：肤色、发色、礼服底色的审美方向 |
| L2 软约束 | 中 | 场景色、配饰色、光效色优先参考色盘，可按镜头与剧情微调 |
| L3 例外机制 | 低 | 前卫/概念/压轴戏可临时突破局部色彩，但需保留整体冷艳逻辑 |

### 硬约束色（默认锁定）

| 色项 | 对应色 | 规则 |
|---|---|---|
| 肤色基准 | C4 瓷光肤 | 默认优先，允许小幅明度微调 |
| 暗场底色基准 | C1 纯黑 | 秀场暗场默认纯黑铺底 |

### 软约束色（推荐优先）

> C2/C3/C5/C6/C8/C10 为推荐色域，用于聚光高光、礼服色彩、金属配饰、冷调光效、前卫礼服等。可根据镜头氛围做同色相邻近调整。

### 情绪色盘使用规则

| 编号 | 规则 |
|---|---|
| E1 | 每条提示词至少指定 1 个「情绪场景」并绑定主色+辅色组合 |
| E2 | 单镜头主色不超过 2 个，避免颜色叙事失焦 |
| E3 | 情绪切换时优先调整光比与色温，再调整饱和度 |
| E4 | 冷艳向默认遵循「暗底 + 聚光」：纯黑铺底，聚光白/烈焰红落在模特焦点 |
| E5 | 若与剧情冲突，以情绪色盘优先于通用推荐色，但不得突破严禁项 |

### 色温约束

| 参数 | 值 | 说明 |
|---|---|---|
| 整体色温 | 中性偏冷 4500-5500K（推荐） | 冷艳锋利主基调 |
| 肤色色温 | 中性 4800-5400K（推荐） | 瓷光肌肤但保留生命感 |
| 对比度 | 高（建议保持） | 聚光硬光强对比，明暗切割 |
| 饱和度 | 中低 35-55%（建议区间） | 高级冷艳色调，礼服色例外 |

### 容差与例外

| 项目 | 建议容差 |
|---|---|
| 色相偏移 | ±8° |
| 饱和度偏移 | ±10% |
| 明度偏移 | ±12% |

> 例外场景：前卫概念、压轴谢幕、金属高定镜头可使用更浓烈或更高光的局部色块；但禁止荧光糖果与梦幻柔光色彩语言入镜。

## 三、全局约束规则

### 必守规则（所有技能继承）

| 编号 | 规则 |
|---|---|
| R1 | 必须包含「真人时装秀场写实」风格锚定词 |
| R2 | 必须声明「聚光硬光 + 暗场低调」 |
| R3 | 面部必须使用「面容冷艳写实 + 瓷光肌肤」 |
| R4 | 发丝必须使用「发丝细腻渲染 + 造型发胶质感」 |
| R5 | 礼服与配饰纹理必须声明「面料与金属材质细节超清晰」 |

### 严禁项（所有技能继承）

| 编号 | 严禁内容 |
|---|---|
| X1 | 严禁「卡通/动漫/二次元/插画风」 |
| X2 | 严禁「高饱和荧光色/糖果色/梦幻柔光」 |
| X3 | 严禁「暖光唯美婚纱感/生活化休闲感」（必须明确冷艳秀场氛围） |
| X4 | 严禁「面部变形/多指/肢体异常」倾向词 |
| X5 | 严禁「过度血腥/恐怖/脏乱废墟元素」 |
| X6 | 严禁「过度美白/塑料磨皮」（须保留瓷光肌肤真实质感） |
