# 时装秀约束 · 时装秀 · 技法参考

---

## 一、色调体系与画面基调

- **暗底聚光基底** — 全片以纯黑（C1）铺底，聚光白（C2）为焦点光，香槟金（C5）/烈焰红（C3）作为高定点缀，整体呈现真人时装秀场的冷艳锋利基调。遵循「暗底 + 聚光」：纯黑铺底，聚光白/烈焰红落在模特焦点
- **聚光硬光叙事** — 聚光与明暗切割是本风格核心视觉语言，明暗分割即气场/前卫/华贵的视觉信号，而非随意打光
- **情绪先行原则** — 段落规划需先绑定情绪场景（开场/走台/前卫/金属/蓝调/谢幕等），再确定主色+辅色与光影方案，避免「情绪对但影调不对」
- **禁用柔美梦幻** — 任何柔光唯美、婚纱/生活化、高饱和荧光、梦幻柔光均与本风格不兼容

---

## 二、光影方案体系

- **聚光即气场** — 6 套光影方案对应不同叙事段落，导演规划阶段应在段落层面确定光影基调方向，而非逐镜指定
- **光源逻辑** — 默认聚光硬光 + 轮廓光分离，特殊段落用色块光/金属反光/全场亮起

| 情绪段落 | 光影方向 | 色调倾向 | 适用阶段 |
|---|---|---|---|
| 开场/亮相 | A·聚光柱硬光暗场 | 纯黑 + 聚光白 + 瓷光肤 | 开场段 |
| 走台/冷艳 | B·聚光硬光+轮廓金边 | 聚光白 + 纯黑 + 香槟金 | 展示段 |
| 前卫/张力 | C·强对比色块光 | 烈焰红 + 紫罗兰 + 纯黑 | 概念段 |
| 金属/华贵 | D·金属反光+暗场衬托 | 香槟金 + 深酒红 + 纯黑 | 高定段 |
| 蓝调/冷峻 | E·冷调聚光暗部留蓝 | 聚光蓝 + 纯黑 + 聚光白 | 冷艳段 |
| 谢幕/庄重 | F·全场亮起暖金收束 | 聚光白 + 香槟金 + 纯黑 | 收束段 |

- **明暗分配** — 暗场纯黑贯穿全片，聚光白/烈焰红作为情绪焦点点缀；谢幕（F）全场亮起暖金收束
- **氛围方向映射** — 每场戏的氛围方向应能映射到上述光影方案（A-F）的某一方向，确保视觉一致性

## 三、质感方向

- **毛孔级实拍质感** — 时装秀场的核心：面容冷艳写实、瓷光肌肤、发丝根根分明、皮肤毛孔微可见
- **高定面料极致** — 廓形结构、面料肌理、金属配饰、珠绣亮片、水晶折射，细节写实可信
- **金属镜面质感** — 金属反光、镜面倒影、灯架冷调，场景带锋利冷艳的工业精致感
- **非洁净冷艳** — 场景带灯架阴影、光斑、镜面倒影；人物锚定高定礼服，禁止休闲/婚纱元素喧宾夺主

## 四、场景空间元素

时装秀场特有的场景元素及其视觉叙事功能：

- **延伸T台/聚光柱** — 秀场标志图式，景即情：延伸T台 = 仪式通道、聚光柱 = 焦点亮相、暗场纯黑 = 冷艳衬托
- **暗场看台/虚化观众** — 旁观载体，暗场看台 = 旁观见证、虚化观众 = 聚焦T台、阶梯纵深 = 仪式感
- **后台化妆间/镜面** — 幕后载体，镜面环绕 = 静谧准备、化妆台灯 = 暖白幕后、衣架礼服 = 序曲
- **金属装置/镜面秀场** — 前卫载体，金属反光装置 = 前卫概念、镜面倒影 = 双重华贵、结构装置 = 锋利张力
- **红毯通道/酒店门廊** — 场外载体，红毯闪光灯 = 华贵聚焦、酒店暖金 = 迎宾、地标暮色 = 现代冷艳
- **段落间用场景空镜过渡** — 本风格有丰富的场景资产（不同段落/室内外变体），段落衔接建议用场景空镜做情绪缓冲（如暗场T台→后台镜面），不要硬切
- **转折点用光影而非台词** — 优先使用画面手段（聚光亮起转场/色块突变/全场亮起）而非依赖对白解释

## 五、配乐与环境音

时装秀场世界观下的声音元素约束：

### 乐器选择

- **电子合成器** — 核心：秀场走台的电子脉冲底色，冷艳锋利
- **重低音鼓点** — 走台节奏载体，每步一拍的锋利节奏
- **弦乐/钢琴** — 华贵/谢幕段落的庄重底色，弦音精致
- **环境电子音效** — 前卫/概念段落的实验色彩（克制使用）

### 乐器组合策略

| 情绪阶段 | 乐器组合 |
|---|---|
| 开场/亮相 | 电子合成器 + 重低音鼓点 |
| 走台/冷艳 | 重低音鼓点 + 电子合成器 |
| 前卫/张力 | 环境电子音效 + 电子节奏 |
| 金属/华贵 | 弦乐 + 电子合成器 |
| 蓝调/冷峻 | 电子合成器 + 钢琴冷音 |
| 谢幕/庄重 | 弦乐 + 钢琴收束 |

### 典型环境音

- **秀场环境音** — 重低音鼓点节奏/聚光灯电流声/快门连闪/看台低语/高跟鞋叩T台
- **后台环境音** — 镜面灯嗡鸣/衣架滑动/化妆品开合/对讲机调度/发胶喷雾
- **红毯环境音** — 闪光灯连闪/快门密集/人群喧响/记者呼喊
- **每场戏标注 1-2 个核心环境音**，帮助后续音效设计
- **留白即气场** — 关键瞬间（开场前暗场、回眸定格、谢幕致意）优先去掉配乐只留环境音（高跟鞋叩声、快门、聚光灯电流），寂静比满配更冷艳
- **避免满配** — 全片配乐覆盖率建议不超过 50%。留白段落的「无声」与配乐段落形成呼吸感，突出冷艳锋利
