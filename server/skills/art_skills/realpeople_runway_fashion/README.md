# 时装秀风格说明

本风格专为"高级时装秀场写实"题材打造，所有美术提示词、规范和生成内容均严格限定于：

- **高定秀场写实**：以真人时装周秀场为标准，超模走台、高定礼服、前卫设计，画面冷艳锋利、时尚张力拉满。
- **T台秀场叙事**：默认以秀场T台、聚光灯柱、看台观众、后台化妆间为舞台，聚光白+暗场黑构成标志性氛围。
- **高定时装细节**：礼服廓形/面料肌理/金属配饰/妆发造型工艺写实可信，模特身形高挑、步态凌厉。
- **秀场电影光影**：聚光灯硬光切割、暗场低调打光、轮廓光分离、冷艳金属反光，追求影视级时尚秀场纪实质感。

## 适用范围

- 时装秀场题材的AI美术生成（角色、场景、道具、分镜等）
- 需要极致冷艳、锋利前卫、时尚张力强烈的视觉创作

## 严禁内容

- 卡通、动漫、插画、二次元风格
- 暖光唯美婚纱感、生活化休闲感
- 过度血腥、恐怖、脏乱废墟元素
- 荧光糖果色、梦幻柔光滤镜

## 风格体验

在本风格下，您将体验到：

- 超模面容冷艳写实，皮肤瓷光质感，高定礼服与配饰细节极致
- 场景以秀场为主，聚光灯柱、暗场低调、T台延伸、看台虚化
- 礼服/鞋履/手包/首饰等道具工艺精细，面料金属质感分明
- 分镜与视频以走台展示为核心，秀场电影光影与时尚张力贯穿始终

---

本风格仅适用于"时装秀"相关项目。如需其他风格（如唯美婚照、动漫、警匪等），请勿使用本套提示词。
