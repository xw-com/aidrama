# 人物基础形象生成 · 时装秀约束手册

---

## 一、基础形象原则

1. **面容即灵魂** — 五官是角色唯一锚点，毛孔级精细渲染，聚光硬光下依然清晰立体、瓷光肌肤
2. **角色为本** — 超模高定礼服为默认主造型，设计师/后台工作人员等其余身份由角色描述（身份/职业/性别/场景）决定；后续特定服化为叠加层
3. **四视图一致** — 面容/体型/发型/礼服跨视图高度统一
4. **冷艳实拍** — 以真实时装秀场为锚点，聚光硬光下保留皮肤瓷光质感（毛孔/微光泽）

---

## 二、面容约束

> 不再固定五官特征参数，由角色描述（性别/年龄/性格/气质）驱动 AI 自由生成五官，保证人物间外观差异化。

### 通用要求

| 项目 | 约束 |
|---|---|
| 五官 | 由角色描述自然推导，不预设脸型/眼型/眉型/鼻型/唇型 |
| 风格底色 | 真人时装秀场、毛孔级精细渲染、冷艳电影光影、聚光硬光 |
| 气质 | 必须从角色描述提炼整体气质关键词（如冷艳/锋利/前卫/高傲），并写入提示词 |
| 表情 | 冷艳微表情：眉骨高挑、目光下垂或直视、唇线紧抿，符合角色气质 |

### 超模妆容规范（高定秀场妆）

| 项目 | 约束 | 提示词 |
|---|---|---|
| 底妆 | 无瑕瓷光肌、哑光或微光泽、精致贴肤 | 瓷光底妆、无瑕贴肤 |
| 眼妆 | 烟熏/锋利眼线/金属冷调，睫毛分明 | 锋利眼线、烟熏眼妆、睫毛分明 |
| 眉形 | 锋利高挑或干净利落 | 锋利眉形、高挑眉 |
| 唇妆 | 烈焰红/裸色/暗调，哑光质感 | 烈焰红唇、哑光质感 |
| 颊妆 | 修容立体、冷调阴影 | 立体修容、冷调阴影 |
| 高光 | 颧骨/鼻梁高光、聚光下通透 | 颧骨高光、肌肤通透 |

### 设计师/工作人员妆容规范（清透自然妆）

| 项目 | 约束 | 提示词 |
|---|---|---|
| 底妆 | 清爽自然、均匀肤色 | 清透底妆、肤色均匀 |
| 眉形 | 干净利落 | 眉形干净利落 |
| 唇部 | 润泽自然 | 唇部润泽自然 |

## 三、肤感约束

### 女性

| 露肤 | 面部/颈部/锁骨/肩部/背部/手臂，礼服设计得体 | 肩颈线条锋利、背部线条流畅 |

### 男性

| 项目 | 约束 | 提示词 |

| 光泽 | 自然哑光、清爽干净 | 皮肤自然、清爽哑光 |
| 质感 | 干净利落、可见毛孔、无油腻 | 皮肤质感真实、毛孔清晰 |

## 五、基础发型约束

> 超模以造型感盘发/利落发型为默认，发饰在衍生环节叠加；设计师以干净造型为默认。

### 女性

| 项目 | 约束 | 提示词 |
|---|---|---|
| 发色 | 自然发色（黑/深棕/金），可按高定概念染 | 自然发色、深棕/金 |
| 发长 | 及肩至及腰长发，由角色设定 | 长发及腰、及肩长发 |
| 发质 | 发丝清晰、造型发胶质感 | 发丝根根分明、发胶造型质感 |
| 造型 | 利落盘发/湿发后梳/锋利直发，碎发克制 | 利落盘发、湿发后梳、锋利直发 |

### 男性

| 项目 | 约束 | 提示词 |
|---|---|---|
| 发色 | 自然发色（黑/深棕），禁漂色 | 自然发色、黑色/深棕 |
| 发长 | 短发为主，由角色设定 | 干净短发 |
| 发质 | 发丝清晰、造型发胶质感 | 发丝根根分明、发胶造型 |
| 造型 | 利落背头/锋利短发、无发饰 | 利落背头、锋利短发 |

## 六、基础服装约束

> 基础服装默认为高定礼服体系（超模礼服），作为该角色「秀场默认态」；便装/后台服等特殊衍生在服化衍生环节叠加。**禁止内衣打底**。

### 着装选择原则

| 角色身份 | 默认着装方向 |
|---|---|
| 超模 | 高定礼服（廓形礼服/拖尾礼服/前卫结构装/金属质感装） |
| 男模 | 高定西装/前卫结构男装 |
| 设计师 | 设计师黑衣（简约黑色套装，衬托作品） |
| 造型师 | 后台黑衣工作服 |
| 看秀嘉宾 | 前卫时尚穿搭 |
| 角色描述未明确 | 超模高定礼服默认 |

### 着装统一规则

- 礼服须体现廓形结构、面料肌理、金属配饰、珠绣亮片，工艺写实可信
- 西装须挺括合身、驳头平伏、面料哑光或微光泽，剪裁锋利
- 颜色以纯黑/聚光白/烈焰红/香槟金/深酒红等高定色为主，可前卫撞色
- 四视图服装款式完全一致，廓形与拖尾形态一致
- 基础服装是「秀场默认态」，焦点仍在面容与冷艳气质
- 严禁内衣/暴露/性化打底

## 八、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须为「冷艳微表情」（眉骨高挑、目光下垂或直视、唇线紧抿）|
| R2 | 超模默认「高定礼服+造型发型」、设计师默认「黑衣套装」，其余身份按角色描述匹配；禁止内衣打底 |
| R3 | 必须声明「无额外发饰」（发饰在服化衍生环节叠加） |
| R4 | 必须指定「纯净暖象牙背景」 |
| R5 | 必须指定「四视图一致性」 |
| R6 | 全身立像必须从头顶到脚底连同礼服拖尾完整展示，严禁裁切 |
| R7 | 必须声明角色身高并通过头身比换算约束全身比例（女性默认170-182cm/8-9头身，男性默认180-190cm/8-8.5头身） |
| R8 | 人像特写必须从头顶到锁骨完整展示，严禁裁切头顶 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 内衣/暴露/性化打底；与角色描述明显不符的着装 |
| X2 | 正顶硬光/彩色光/梦幻柔光（设定图除外用均匀柔光） |
| X3 | 过度美白/塑料磨皮至无质感（须保留瓷光肌肤真实质感） |
| X4 | 复杂场景背景（必须纯暖象牙底） |
| X5 | 卡通/动漫/插画/二次元/3D渲染质感 |
| X6 | 全身立像裁切头顶、脚底或礼服拖尾，必须完整入画 |
| X7 | 人像特写裁切头顶，必须从头顶到锁骨完整入画 |
| X8 | 忽略身高和头身比约束 |
