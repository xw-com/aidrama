# 场景图生成 · 时装秀约束手册

---

## 一、场景美学原则

1. **空间叙事** — 场景承载秀场仪式与时尚张力，不是纯背景板
2. **层次纵深** — 所有场景必须具备前/中/后景，聚光硬光塑造冷艳纵深
3. **质感至上** — T台/金属/纱幔/灯架等材质表现必须清晰锋利
4. **秀场为锚** — 一切画面以真人时装秀场为标准，拒绝卡通/动漫/插画/3D/CG；追求毛孔级实拍质感（聚光硬光、暗场低调、轮廓光分离）

## 五、主视图规范

### 视图定义

> 单画面主视图，从场景中最具代表性的角度拍摄，承载空间叙事与构图重心。

| 项目 | 约束 | 提示词 |
|---|---|---|
| 视角 | 自然观察视角，构图最能体现场景主体与纵深 | hero shot、representative angle |
| 视点高度 | 默认人眼平视高度，特殊场景可俯/仰 | eye level（默认） |
| 构图 | 主体居中或符合三分法，前/中/后景层次清晰 | balanced composition |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 单画面（非拼图、非多视图、非分屏） |
| 人物 | **严禁出现任何人物、人影、人体轮廓** |
| 一致性 | 风格/材质/色调/光线统一 |
| 光线 | 单一光源逻辑，光影方向一致，聚光硬光 |
| 画面比例 | 默认 16:9（或按调用方设定） |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 场景必须有「前中后景层次」 |
| R2 | 室外必须包含「空气透视」与背景柔焦虚化 |
| R3 | 场景图必须为「单画面主视图」，不得拼接多视图/分屏/网格 |
| R4 | 构图须能代表场景主体并展示前/中/后景层次 |
| R5 | 场景图中**严禁出现任何人物** |
| R6 | 必须包含时装秀场关键词（runway-fashion photorealism / 聚光硬光 / 暗场低调） |
| R7 | 必须包含聚光特征（聚光柱/暗场低调/轮廓光分离 至少一项） |
| R8 | 材质须有金属反光与镜面倒影细节，禁止 CG 干净质感 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 背景纯白/纯黑/无场景 |
| X2 | 极端天候、脏乱废墟、恐怖元素 |
| X3 | 场景无纵深/无层次 |
| X4 | 段落/天候与剧情矛盾 |
| X5 | 出现任何人物、人影、人体剪影 |
| X6 | 画面被拼接成多视图/网格/分屏布局 |
| X7 | 卡通/动漫/插画/二次元/3D渲染/CG 风格质感 |
| X8 | 高饱和荧光色、梦幻柔光、婚纱/生活化感 |
| X9 | 光照过柔过平，无聚光硬光与暗场低调 |
