# 场景图生成 · 产品广告约束手册

---

## 一、场景美学原则

1. **舞台即叙事** — 场景是为产品搭建的材质舞台（纯色幕布/渐变幕布/台面），承载品类气质与价值暗示，不是生活背景板
2. **极简三层** — 所有舞台必须具备「主体台位/背景过渡/光位层次」三层结构，画面做减法，杜绝元素堆砌
3. **材质代言** — 台面与背景材质本身即卖点语言（大理石=奢华、亚克力=科技、水面=纯净），纹理必须清晰受控
4. **影棚实拍为锚** — 一切画面以影棚级商业静物摄影为标准，追求精准可控布光、轮廓光分离、材质高级反光，拒绝 3D 渲染/CG 动画质感

## 二、品类/氛围色调映射

| 品类/氛围 | 主色调 | 辅色调 | 提示词 |
|---|---|---|---|
| 电子数码（科技锐度） | 靛幕蓝 + 曜石深灰 | 钛银灰 | 渐变靛幕、金属冷光 |
| 美妆护肤（轻奢仪式） | 画布白 + 香槟金 | 暖瓷肌 | 纯白高调、金色高光 |
| 食品饮料（清透水感） | 玻璃青 + 画布白 | 阳光暖调 | 逆光透射、水珠凝结 |
| 酒类器皿（醇厚暗调） | 酒红丝绒 + 石墨黑 | 香槟金 | 单侧硬光、丝绒暗部 |
| 珠宝腕表（高奢精工） | 石墨黑 + 香槟金 | 钛银灰 | 束光精准、镜面倒影 |
| 家居好物（生活质感） | 影棚中灰 + 画布白 | 钛银灰 | 中灰渐变、材质铺陈 |

## 三、室内场景（影棚舞台）

### 空间规范

| 维度 | 约束 | 提示词 |
|---|---|---|
| 风格 | 纯色幕布棚/渐变幕布棚/台面舞台/微距景深台 | 影棚{舞台类型} |
| 材质 | 无缝背景纸/亚克力/大理石/岩板/水面台座 | 无缝背景、亚克力台面、大理石台面 |
| 色调 | 极简底色（画布白/影棚中灰/石墨黑）+ 品类点缀 | {品类}舞台底色、极简背景 |
| 纵深 | 主体台位/中景铺陈/背景过渡三层 | 主体台位清晰、背景过渡平滑 |
| 质感 | 台面无划痕、幕布无皱褶接缝、倒影柔和 | 台面洁净、倒影柔和 |
| 光照 | 影棚精准布光：柔光箱+束光管+轮廓光，光位可溯 | precision lighting、rim light separation |
| 镜头感 | 浅景深虚化、微距锐度、反光受控 | shallow depth of field、macro sharpness |
| 洁净度 | 无灰尘、无指纹、无水渍杂点（刻意水珠造型除外） | 洁净无瑕、无灰尘无指纹 |

### 影棚舞台类型速查

| 类型 | 核心元素 | 氛围词 |
|---|---|---|
| 纯色幕布棚 | 无缝背景纸、均匀光比 | 极简聚焦、电商主图规范 |
| 渐变幕布棚 | 中心亮四周暗、氛围渐变 | 悬念氛围、高级聚焦 |
| 亚克力台面舞台 | 半透台面、边缘透光 | 科技透亮、轻盈悬浮 |
| 大理石/岩板台面 | 纹理克制、抛光倒影 | 奢华稳重、品质背书 |
| 水面倒影台 | 静谧水面、对称倒影 | 纯净空灵、仪式感 |
| 微距景深台 | 极浅景深、背景全融化 | 工艺凝视、细节殿堂 |

## 四、室外场景（外景光台）

### 空间规范

| 维度 | 约束 | 提示词 |
|---|---|---|
| 类型 | 极简建筑立面/天台光台/海岸水面/沙石自然台 | {外景}光台，背景极简 |
| 天候 | 晴朗定向光/黄金时刻为主，杜绝浑浊阴郁 | 定向自然光、黄金时刻光线 |
| 水体 | 水面平静如镜、产品倒影对称 | 水面如镜、倒影对称 |
| 材质 | 混凝土/岩板/细沙/水面，肌理干净 | 混凝土肌理、细沙平整 |
| 空气感 | 通透干净，背景简化成面 | 空气通透、背景简化 |
| 光照 | 自然光定向 + 反光板控光，产品轮廓清晰 | 定向自然光、轮廓清晰 |
| 镜头感 | 浅景深压缩、长焦虚化、无杂乱光斑 | shallow depth of field、长焦虚化 |
| 洁净度 | 无杂物、无人群、无垃圾入镜 | 画面极简、无杂物 |

### 外景类型速查

| 类型 | 核心元素 | 氛围词 |
|---|---|---|
| 极简建筑立面 | 洁净墙面、几何线条 | 建筑感、结构美学 |
| 天台光台 | 天际线虚化、定向日光 | 开阔高级、都市格调 |
| 海岸水面 | 海天一色、平静水面 | 纯净辽阔、度假暗示 |
| 沙石自然台 | 细沙/岩石肌理、暖调光 | 自然原生、质朴高级 |

## 五、主视图规范

### 视图定义

> 单画面主视图，从舞台最具品类代表性的角度拍摄，承载材质叙事与构图重心，为产品预留明确主体台位。

| 项目 | 约束 | 提示词 |
|---|---|---|
| 视角 | 产品舞台视角，构图最能凸显台位与光位层次 | hero shot、product stage angle |
| 视点高度 | 默认略低于台面（仰衬产品），微距场景可平视 | slightly low angle（默认） |
| 构图 | 主体台位居中或三分法，台位/铺陈/背景过渡清晰 | balanced composition |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 单画面（非拼图、非多视图、非分屏） |
| 人物 | **严禁出现任何人物、人影、人体轮廓**（产品主体由道具环节单独生成，画面留出主体台位） |
| 一致性 | 风格/材质/色调/光线统一 |
| 光线 | 单一光源逻辑，光位方向一致且可溯 |
| 画面比例 | 默认 16:9（或按调用方设定） |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 舞台必须具备「台位/背景过渡/光位」三层结构 |
| R2 | 渐变背景必须「平滑无色带」，背景永远为产品让位 |
| R3 | 场景图必须为「单画面主视图」，不得拼接多视图/分屏/网格 |
| R4 | 构图须为产品预留明确主体台位（品牌材质舞台） |
| R5 | 场景图中**严禁出现任何人物与喧宾元素** |
| R6 | 必须包含影棚摄影关键词（packshot photography / studio strobe lighting / RAW photo） |
| R7 | 必须包含光位描述（rim light / precision lighting / gradient background 至少一项） |
| R8 | 材质必须洁净如新，禁止灰尘/划痕/水渍等不洁细节 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 杂乱背景/抢主体装饰/无意义道具堆砌 |
| X2 | 极端天候（外景时暴风雨/雷电/沙尘，除非剧本需要） |
| X3 | 舞台无层次/光位混乱不可溯 |
| X4 | 台面材质与品类叙事矛盾（如科技品配田园碎花） |
| X5 | 出现任何人物、人影、人体剪影或人体轮廓 |
| X6 | 画面被拼接成多视图/网格/分屏布局 |
| X7 | 3D 渲染/CG 动画/卡通/游戏引擎质感（禁用 3D render、CGI、Unreal Engine、Unity 等词） |
| X8 | 渐变背景出现色带/断层/噪点，幕布出现皱褶接缝 |
| X9 | 杂乱反光/光源入镜/光斑穿帮破坏极简舞台 |
