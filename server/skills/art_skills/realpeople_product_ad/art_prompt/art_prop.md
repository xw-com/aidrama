# 道具图像生成 · 产品广告约束手册

---

## 一、道具设计原则

1. **产品即主角** — 本环节道具=产品本身，一切构图、布光、背景都为产品价值呈现服务；产品是画面唯一视觉主体
2. **packshot 规范** — 正面完整、标识清晰可辨、无遮挡无反光遮蔽；主视角默认正面 15° 微侧（立体感）或纯正面（电商主图规范）；同系列可并列陈列但主次分明
3. **材质极致** — 玻璃折射/金属镜面/液体张力/膏体细腻等材质反光是第二主角，纹理与工艺细节必须微距级清晰
4. **洁净无瑕** — 商业修图级洁净：无指纹、无灰尘、无水渍杂点（刻意水珠造型除外），产品处于「出厂完美状态」
5. **纯道具独立展示** — 画面中只能出现产品本身（可含同系列陈列与台座），严禁出现任何人物、手部、肢体，产品不可处于被持有/佩戴/使用状态，必须以静物陈列方式独立呈现

## 三、多角度设定图规范

### 视图定义

| 位置 | 视图 | 角度 | 要求 | 提示词 |
|---|---|---|---|---|
| 左上 | 正面图 | 正面 0°（或 15° 微侧） | 产品完整正面形态、标识朝向镜头 | front view |
| 右上 | 侧面图 | 侧面 90° | 厚度/轮廓/结构清晰 | side view |
| 左下 | 背面图 | 背面 180° | 产品背部结构/工艺细节 | back view |
| 右下 | 细节特写 | 局部放大 | 材质纹理/工艺微距细节 | detail closeup、macro |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 同一画面四宫格（2×2），上下左右四视角 |
| 背景 | 纯色或渐变影棚底（画布白/影棚中灰/石墨黑，按品类选择） |
| 光线 | 柔光箱 + 轮廓光，反光受控，无杂乱光斑 |
| 比例 | 每格产品占格内主体 70%+ |
| 投影 | 允许柔和地面微投影或倒影 |
| 洁净度 | 表面无指纹、无灰尘、无水渍（刻意水珠造型除外） |
| 画面比例 | 建议 1:1 |

## 六、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须按品类指定「纯色/渐变影棚背景」 |
| R2 | 必须明确产品材质与 packshot 要点（标识朝向、无遮挡、液面水平等） |
| R3 | 必须声明「轮廓光分离 + 反光受控」 |
| R4 | 必须声明「洁净无瑕：无指纹、无灰尘、无水渍杂点」（刻意水珠造型除外） |
| R5 | 必须包含「微距细节锐利」质感描述 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 复杂生活场景背景（packshot 环节为影棚材质舞台） |
| X2 | 产品与人物同画面（本环节为纯产品图） |
| X3 | 出现任何人物形象，包括全身、半身、局部（手、手指、手臂等肢体） |
| X4 | 产品处于被持有、握持、使用中的状态 |
| X5 | 出现暗示人物存在的元素（如手持痕迹、使用姿态） |
| X6 | 产品结构变形、比例失真、标识乱码、杂乱反光穿帮 |
