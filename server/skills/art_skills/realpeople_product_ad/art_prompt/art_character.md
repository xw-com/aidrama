# 人物基础形象生成 · 产品广告约束手册

---

## 一、基础形象原则

1. **点缀不抢戏** — 人物是产品价值的人格化点缀，永远为产品让位，禁与产品争夺视觉焦点
2. **角色为本** — 基础着装由出镜身份（手部模特/佩戴模特/氛围人物）决定其素色简洁着装；后续特定服化为叠加层
3. **四视图一致** — 面容/体型/发型/基础服装跨视图高度统一
4. **最佳上镜状态** — 点缀人物默认「镜前最佳状态」：妆发干净、手部模特级肤质、姿态收敛利落

---

## 二、面容约束

> 不再固定五官特征参数，由角色描述（性别/年龄/性格/气质）驱动 AI 自由生成五官，保证人物间外观差异化。

### 通用要求

| 项目 | 约束 |
|---|---|
| 五官 | 由角色描述自然推导，不预设脸型/眼型/眉型/鼻型/唇型 |
| 风格底色 | 产品广告摄影、广告级写实质感、影棚精准布光、商业修图级洁净 |
| 气质 | 必须从角色描述提炼整体气质关键词（如清透/高级/安静/可信），并写入提示词 |
| 表情 | 中性微表情或轻微愉悦，静默陪衬为主，禁夸张表情抢产品焦点 |
| 妆容 | 妆容干净清透：底妆瓷感、眉形清爽、唇色克制，禁浓妆 |

## 三、肤感约束

### 女性

| 项目 | 约束 | 提示词 |
|---|---|---|
| 肤色 | 暖瓷感均匀、全身一致 | 暖瓷肌肤色、肤色均匀 |
| 光泽 | 瓷感缎光、非哑光非油光 | 皮肤瓷感通透、缎光均匀 |
| 质感 | 商业修图级无瑕：洁净零瑕疵，保留极微毛孔 | 商业修图级无瑕、皮肤细腻洁净 |
| 露肤 | 面部/颈部/锁骨/手部/腕部（佩戴展示需要） | 肩颈线条干净、腕部洁净 |

### 男性

| 项目 | 约束 | 提示词 |
|---|---|---|
| 肤色 | 健康均匀、哑光瓷感 | 健康肤色、质感均匀 |
| 光泽 | 清爽干净、高光克制 | 皮肤清爽、高光克制 |
| 质感 | 商业修图级无瑕、胡须刮净或修型整齐 | 商业修图级无瑕、胡须修型整齐 |

> **手部模特规范（本风格关键）**：手部出镜时必须「手部模特级肤质」— 手指修长、指节匀称、指甲修饰整洁、素色或自然甲面、腕部饰品仅限被展示产品本身。

## 五、基础发型约束

> 仅定义干净造型发型，发饰在服化衍生环节叠加；发型须利落收敛，避免发丝大面积遮挡面部与产品。

### 女性

| 项目 | 约束 | 提示词 |
|---|---|---|
| 发色 | 自然发色（黑色/深棕），禁漂色/染色 | 自然发色、深棕色 |
| 发长 | 由角色设定（中长发/长发/利落短发） | 自然长发、及肩发 |
| 发质 | 发丝清晰、柔顺有光泽 | 发丝根根分明、柔顺光泽 |
| 造型 | 干净利落：低马尾/优雅盘发/柔顺直发（束发优先，减少遮挡） | 造型干净利落、低束发 |

### 男性

| 项目 | 约束 | 提示词 |
|---|---|---|
| 发色 | 自然发色（黑色/深棕），禁漂色 | 自然发色、黑色/深棕 |
| 发长 | 短发为主，由角色设定 | 清爽短发 |
| 发质 | 发丝清晰、质感真实 | 发丝根根分明 |
| 造型 | 干净利落：清爽纹理/利落侧分 | 造型利落、清爽干净 |

## 六、基础服装约束

> 基础服装由出镜身份决定其素色简洁着装，作为该角色「点缀默认态」；着装永远为产品让位，避免亮色与花色抢夺主体。**禁止内衣打底**。

### 着装选择原则

| 出镜身份 | 默认着装方向 |
|---|---|
| 手部模特 | 素色长袖/七分袖上衣（袖口洁净），无首饰抢镜 |
| 佩戴模特（腕表/饰品） | 素色简洁装，露腕/露颈，除展示品外无其他饰品 |
| 氛围人物（局部/侧影） | 素色低饱和服装，面料垂坠有型 |
| 品牌服务人员 | 素色制服/整洁围裙，洁净如新 |
| 角色描述未明确 | 素色低饱和简洁着装，避开产品主色 |

### 着装统一规则

- 服装须为素色低饱和简洁款，无大面积图案/花纹/装饰，防止干扰产品主体
- 着装颜色须避开产品主色，形成衬托而非竞争关系
- 四视图服装款式完全一致
- 基础服装是「点缀默认态」，焦点永远在产品与材质
- 严禁内衣/暴露/性化打底

## 八、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须为「广告镜前状态」（妆发干净、手部模特级肤质） |
| R2 | 必须根据出镜身份声明素色简洁着装（手部模特→素色七分袖、佩戴模特→露腕/露颈简洁装）；禁止内衣打底 |
| R3 | 必须声明「无发饰、无配饰」（展示品类饰品除外） |
| R4 | 必须指定「影棚中灰背景」 |
| R5 | 必须指定「四视图一致性」 |
| R6 | 全身立像必须从头顶到脚底完整展示，严禁裁切 |
| R7 | 必须声明角色身高并通过头身比换算约束全身比例 |
| R8 | 人像特写必须从头顶到锁骨完整展示，严禁裁切头顶 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 内衣/暴露/性化打底；亮色花色着装抢产品主体；大面积图案干扰产品 |
| X2 | 正顶硬光/正底光/彩色光 |
| X3 | 过度磨皮至塑料脸/失真无质感 |
| X4 | 复杂场景背景（必须影棚中灰底） |
| X5 | 夸张表情/大幅度动态姿势（与产品争焦点） |
| X6 | 全身立像裁切头顶或脚底，必须从头到脚完整入画 |
| X7 | 人像特写裁切头顶，必须从头顶到锁骨完整入画 |
| X8 | 忽略身高和头身比约束 |
