# 产品广告风格说明

本风格专为"产品广告"题材打造，所有美术提示词、规范和生成内容均严格限定于：

- **产品主角叙事**：产品静物为绝对主角（packshot），极简纯色/渐变背景、影棚材质舞台、产品悬浮/舞台感构图，人物仅作点缀或无人物。
- **影棚精准布光**：以影棚级可控布光与轮廓光分离为视觉核心，玻璃折射、金属镜面、液体张力等材质高级反光即卖点表达。
- **电商海报级画质**：所有产品、场景舞台、道具均以电商主图、杂志封底级商业静物摄影为标准，微距细节、商业修图级洁净度。
- **克制高级氛围**：低饱和高级色调，光即叙事，用光位、底色与材质讲述产品价值，杜绝喧闹。

## 适用范围

- 产品广告/静物 packshot 题材的AI美术生成（产品、场景舞台、点缀人物、分镜等）
- 需要影棚精准布光、材质高级反光、极简舞台构感的视觉创作

## 严禁内容

- 卡通、动漫、插画、二次元、3D 渲染 CG 动画风
- 杂乱背景、抢主体的装饰堆砌、喧宾夺主的环境元素
- 灰尘、指纹、污渍、杂乱反光等不洁瑕疵
- 人物全身/半身入镜抢夺产品主体（点缀人物仅限手部/局部）
- 暗示性、暴露等不适宜内容

## 风格体验

在本风格下，您将体验到：

- 产品始终为画面唯一主角，packshot 正面完整、标识清晰、陈列如仪式
- 舞台极简纯粹：纯色幕布、渐变幕布、亚克力与大理石台面皆服务于材质叙事
- 玻璃的折射、金属的镜面、液体的张力被精准光位雕琢为高级质感
- 分镜与视频以商业静物级质感为基础，强调轮廓光分离与微距细节

---

本风格仅适用于"产品广告"相关项目。如需人物生活方式广告（人物与品牌场景互动叙事），请改用商业广告风格；如需其他风格（如古风、插画、动漫等），请勿使用本套提示词。
