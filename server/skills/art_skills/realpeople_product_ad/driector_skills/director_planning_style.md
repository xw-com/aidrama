# 产品广告风格约束 · 产品静物 packshot · 技法参考

---

## 一、色调体系与画面基调

- **色调基底** — 全片以画布白（C1）、影棚中灰（C9）、石墨黑（C3）构成三级舞台底色体系，底色做减法，整体饱和度中低（35-55%），呈现克制高级的静物舞台感
- **材质高光叙事** — 香槟金（C5）、钛银灰（C4）作为金属高光与工艺质感的视觉信号，只落在材质高光与勾边，不铺满画面；玻璃青（C7）专属清透液体与折射叙事
- **品类氛围分配** — 靛幕蓝（C6）用于科技发布段落，酒红丝绒（C8）+香槟金（C5）用于酒类与礼赠段落；点缀人物一律 C2 暖瓷肌，保持画面有人的温度但不抢主体
- **色盘先行原则** — 段落规划先绑定情绪场景（上市发布/轻奢开箱/清透水感/醇厚口感等），再确定舞台底色+点缀色与光位方案，避免"产品对了但舞台不对色"
- **禁用色域** — 高饱和荧光撞色、杂乱多色入镜、背景喧宾色与本风格不兼容

## 二、光影方案体系

- **光即叙事** — 6 套光影方案对应不同产品价值段落，导演规划阶段应在段落层面确定光位方向，而非逐镜指定
- **光源角度** — 轮廓光默认左右 45° 双侧勾边，主光默认 30° 柔光箱斜射；逆光透射专用于玻璃与液体品类

| 光影方案 | 方案名 | 色调倾向 | 适用情绪 |
|---|---|---|---|
| A | 高调白幕平光 | 画布白 + 顶部大柔光箱 | 电商主图、清透品类 |
| B | 暗调单侧硬光 | 石墨黑 + 黑旗控光 | 酒类、高奢、醇厚叙事 |
| C | 逆光透射 | 玻璃青透亮 + 背后束光 | 饮品、香氛、纯净感 |
| D | 轮廓双光 | 钛银灰渐变 + 双边缘光 | 数码、金属材质 |
| E | 渐变幕氛围光 | 靛幕蓝 + 束光管点缀 | 科技发布、视觉悬念 |
| F | 外景自然光台 | 香槟金暖 + 定向自然光 | 生活方式点缀段落 |

- **明暗叙事分配** — 高调（A/C）表达清透与普惠价值，暗调（B/E）表达高奢与工艺价值；明暗切换须与产品价值递进同步
- **氛围方向映射** — 每场戏氛围方向应映射到上述光影方案（A-F）的某一方向，确保视觉一致性

## 三、质感方向

- **材质反光控制** — 用柔光箱/黑旗/束光管雕琢反光形状：高光有形不死白、暗部有细节不死黑，反光是产品的第二表情
- **微距细节锐度** — 工艺凝视段落以微距景深呈现：接缝、镀层、气泡、织纹等微距细节必须锐利可信，是价值说服力的核心
- **景深焦点策略** — 焦点永远落在产品价值点（标识/材质/工艺），前后景化为纯净的虚化层次；焦点移动即价值引导
- **洁净度管理** — 商业修图级洁净是底线：无指纹、无灰尘、无水渍杂点（刻意水珠造型除外），洁净本身就是高级感的来源

## 四、影棚场景空间元素

产品广告特有的舞台元素及其视觉叙事功能：

- **幕布系统（纯色/渐变）** — 底色即品类气质：白幕=洁净普惠、黑幕=高奢醇厚、渐变=悬念氛围；幕布是画面分层的第一个工具
- **台面材质（亚克力/大理石/岩板/水面）** — 为产品价值背书：亚克力托科技感、大理石托奢华感、水面托纯净感，台面即信任状
- **液体动态（倾倒/飞溅/气泡/挂杯）** — 产品高光时刻的视觉爆点，配合高速闪光凝固，是食饮品类的黄金三秒
- **悬浮装置与倒影** — 悬浮=超现实价值暗示，倒影=对称仪式感；支撑结构不可见，投影与主体分离
- **空镜过渡建议** — 材质微距空镜（镀层/气泡/织纹）、光斑流动空镜、幕布渐变空镜用于段落衔接，保持产品呼吸感
- **视觉转折建议** — 高调→暗调的切换=价值升级叙事；环境点缀→纯舞台聚焦的收束=决策时刻；优先用光位与底色转折而非字幕解释

## 五、产品广告乐器与环境音

产品广告世界观下的声音元素约束：

### 乐器选择

- **极简电子脉冲** — 产品广告核心配乐语言，低频脉冲驱动镜头推进，克制而有科技感
- **氛围钢琴** — 高奢、礼赠、开箱仪式段落的主力，音符稀疏留白
- **弦乐轻铺** — 价值升华与品牌收尾段落的铺底，克制不煽情
- **节拍打击（clap/snap）** — 卡点剪辑的节奏工具，配合产品动态定格
- **音效优先级最高** — 产品互动音（开盖/倾倒/机械咬合）永远压过配乐，是材质可信度的听觉背书

### 乐器组合策略

| 情绪阶段 | 乐器组合 |
|---|---|
| 产品开场/悬念 | 极简电子脉冲独走 |
| 开箱仪式/轻奢 | 氛围钢琴 + 轻打击 |
| 动态高光（倾倒/旋转） | 电子脉冲 + 节拍打击 |
| 价值升华/收尾 | 弦乐轻铺 + 钢琴收束 |
| 外景生活点缀 | 木吉他轻扫 或 氛围钢琴 |

### 产品广告环境音

- **典型环境音层次** — 液体倾注声 / 冰块碰撞 / 开瓶气压声 / 包装撕膜与盒盖开合 / 金属卡扣轻响 / 机械旋钮阻尼声 / 棚拍静默底噪
- **每场戏标注 1-2 个核心产品音**，帮助后续音效设计；材质音与微距镜头一一对应时，高级感翻倍

### 留白建议

- 品牌标版/产品定妆前预留 0.5-1s 配乐静默，只留一个产品音（如开盖声）落地，让价值被听见
- 微距细节段落配乐主动退后，以近乎静默衬材质音；用一次音乐抽离再收尾，避免全程满铺
