## 二、全局色彩盘（风格基线，不是硬锁）

> 目标：统一审美而非限制创作。除「硬约束色」外，其余颜色默认优先使用，可在合理范围内偏移。

### 色彩使用层级

| 层级 | 约束强度 | 说明 |
|---|---|---|
| L1 硬约束 | 高 | 仅锁定画面识别核心：舞台底色方向、点缀人物肤色与主服底色的审美方向 |
| L2 软约束 | 中 | 材质高光色、氛围点缀色优先参考色盘，可按品类与光位微调 |
| L3 例外机制 | 低 | 节日限定/礼赠/发布高潮镜头可临时强化点缀色，但需保留极简克制逻辑 |

|---|---|---|---|

### 硬约束色（默认锁定）

| 色项 | 对应色 | 规则 |
|---|---|---|
| 肤色基准（点缀人物） | C2 暖瓷肌 | 默认优先，允许小幅明度微调 |
| 舞台底色基准 | C1 画布白 / C9 影棚中灰 / C3 石墨黑 | 单镜头底色统一，渐变须平滑无色带 |

### 软约束色（推荐优先）

> C4/C5/C6/C7/C8/C10 为推荐色域，用于材质高光、渐变幕布、器皿点缀、暗调舞台等。可根据品类与光位做同色相邻近调整。

### 情绪色盘（导演对齐版）

| 情绪场景 | 主色 | 辅色 | 光效与对比建议 | 画面关键词 |
|---|---|---|---|---|
| 上市发布（科技锐度） | C6 靛幕蓝 | C4 钛银灰 + C10 曜石深灰 | 渐变幕布 + 双边缘轮廓光 | 冷峻、精准、未来 |
| 轻奢开箱（仪式感） | C5 香槟金 | C1 画布白 + C4 钛银灰 | 高调平光 + 金色高光勾边 | 精致、尊享、克制 |
| 清透水感（饮品/护肤） | C7 玻璃青 | C1 画布白 + C2 暖瓷肌 | 逆光透射 + 水珠凝结 | 清爽、纯净、通透 |
| 醇厚口感（酒类/咖啡） | C8 酒红丝绒 | C3 石墨黑 + C5 香槟金 | 单侧硬光 + 暗部丝绒 | 醇厚、深邃、慢享 |
| 微距凝视（工艺细节） | C4 钛银灰 | C10 曜石深灰 + C5 香槟金 | 束光管精准打光 | 精密、工业、匠心 |
| 悬浮舞台（视觉奇观） | C3 石墨黑 | C5 香槟金 + C7 玻璃青 | 底光 + 轮廓双光，投影分离 | 悬浮、超现实、高级 |
| 礼赠节庆（暖意仪式） | C8 酒红丝绒 | C5 香槟金 + C2 暖瓷肌 | 暗调 + 金色点缀光 | 节庆、礼遇、暖意 |
| 手部点缀（人格温度） | C2 暖瓷肌 | C1 画布白 + C9 影棚中灰 | 柔光箱正面 + 微轮廓光 | 人的温度、可信、轻叙事 |

### 情绪色盘使用规则

| 编号 | 规则 |
|---|---|
| E1 | 每条提示词至少指定 1 个「情绪场景」并绑定主色+辅色组合 |
| E2 | 单镜头主色不超过 2 个，背景永远为产品让位 |
| E3 | 情绪切换时优先调整光位与轮廓光强度，再调整底色 |
| E4 | packshot 默认遵循「极简底 + 单点高级色」：底色做减法，高级色落在材质高光 |
| E5 | 若与品牌指定色冲突，以品牌色替代点缀色位，但不得突破严禁项 |

### 色温约束

| 参数 | 值 | 说明 |
|---|---|---|
| 整体色温 | 按品类分档：科技 5600-6500K / 食饮美妆 5000-5600K（推荐） | 冷锐或暖醇随品类叙事 |
| 肤色色温（点缀人物） | 中性微暖 5200-5600K（推荐） | 瓷感通透 |
| 对比度 | 中高（建议保持） | 轮廓与背景明确分离 |
| 饱和度 | 中低 35-55%（建议区间） | 高级克制，材质色优先 |

### 容差与例外

| 项目 | 建议容差 |
|---|---|
| 色相偏移 | ±5° |
| 饱和度偏移 | ±8% |
| 明度偏移 | ±8% |

> 例外场景：节日限定、礼赠开箱镜头可放大酒红丝绒+香槟金暖调比重；但禁止杂色入镜与背景喧宾。

## 三、全局约束规则

### 必守规则（所有技能继承）

| 编号 | 规则 |
|---|---|
| R1 | 必须包含「产品广告摄影 / packshot」风格锚定词 |
| R2 | 必须声明「影棚精准布光 + 轮廓光分离」 |
| R3 | 产品必须为画面唯一主体，点缀人物仅限手部/局部侧影 |
| R4 | 材质必须声明「高级反光：玻璃折射/金属镜面/液体张力」 |
| R5 | 画面必须声明「商业修图级洁净：无指纹、无灰尘、无水渍杂点」 |

### 严禁项（所有技能继承）

| 编号 | 严禁内容 |
|---|---|
| X1 | 严禁「卡通/动漫/二次元/插画/3D 渲染 CG 风」 |
| X2 | 严禁「杂乱背景/抢主体装饰/无意义道具堆砌」 |
| X3 | 严禁「产品结构变形/比例失真/标识乱码」 |
| X4 | 严禁「廉价塑料感/镜面穿帮/反光糊成一片」 |
| X5 | 严禁「人物全身或半身主体入镜」（点缀仅手部/局部） |
| X6 | 严禁「灰尘/指纹/污渍/杂乱光斑等不洁瑕疵」 |
