# 人物基础形象生成 · 约束手册

---

## 一、基础形象原则

1. **造型即灵魂** — 角色造型是核心锚点，少女漫画造型，柔和流畅线条
2. **底模即基础** — 基础打底服装 + 素颜，后续服化均为叠加层
3. **四视图一致** — 面容/体型/发型/基础服装跨视图高度统一
4. **少女气质** — 无妆状态仍需体现角色气质（元气/温柔/清冷/神秘）

---

## 二、面容约束

> 不再固定五官特征参数，由角色描述（性别/年龄/性格/气质）驱动 AI 自由生成五官，保证人物间外观差异化。

### 通用要求

| 项目 | 约束 |
|---|---|
| 五官 | 由角色描述自然推导，不预设脸型/眼型/眉型/鼻型/唇型 |
| 风格底色 | 少女漫画风格、闪亮星芒特效、花朵网点背景、柔粉调、清晰流畅柔和线条、大眼高光 |
| 眼部 | 大而明亮的眼，多层高光，眼神清澈有神（少女漫画标志性大眼高光） |
| 气质 | 必须从角色描述提炼整体气质关键词（如元气开朗/温柔如水/清冷孤傲/神秘迷人），并写入提示词 |
| 表情 | 中性微表情，符合角色气质 |

## 六、基础服装约束

> 基础服装无特殊约束，女性为素色校园制服（白衬衫+素色短裙），男性为素色校园制服（白衬衫+素色长裤）。正式服饰在服化衍生环节叠加。

### 女性基础服装

素色校园制服（白色衬衫 + 素色短裙），颜色以基础色为主，无花纹装饰。

### 男性基础服装

素色校园制服（白色衬衫 + 素色长裤），颜色以基础色为主，无花纹装饰。

### 着装统一规则

- 服装风格统一，确保后续服饰叠加无色彩干扰
- 除面部/手部/颈部外基本覆盖
- 四视图服装款式完全一致
- 基础服装仅为安全打底，焦点在面容与体态

## 八、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须为「素颜状态」 |
| R2 | 必须声明基础服装（女性：素色校园制服白衬衫+素色短裙；男性：素色校园制服白衬衫+素色长裤） |
| R3 | 必须声明「无发饰、无配饰」 |
| R4 | 必须指定「奶油白纯色背景」 |
| R5 | 必须指定「四视图一致性」 |
| R6 | 全身立像必须从头顶到脚底完整展示，严禁裁切 |
| R7 | 必须声明角色身高并通过头身比换算约束全身比例（女性默认 155-165cm/7-8头身，男性默认 175-185cm/7-8头身） |
| R8 | 人像特写必须从头顶到锁骨完整展示，严禁裁切头顶 |
| R9 | 必须声明「大眼高光 + 清晰流畅柔和线条」少女漫画特征 |

| 编号 | 严禁 |
|---|---|

| X2 | 正顶硬光/正底光/冷色硬光 |
| X3 | 过度美白至无血色 / 肤色发灰 |
| X4 | 复杂场景背景（必须纯色） |
