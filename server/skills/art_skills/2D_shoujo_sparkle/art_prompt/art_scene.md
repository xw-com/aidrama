# 场景图生成 · 约束手册

---

## 一、场景美学原则

1. **空间叙事** — 场景承载浪漫情绪与心动叙事功能，不是纯背景板
2. **层次纵深** — 所有场景必须具备前/中/后景，杜绝扁平
3. **梦幻质感至上** — 木质/布料/花瓣/水面等材质纹理必须超清晰，辅以柔焦梦幻氛围
4. **少女漫画为锚** — 一切画面以少女漫画手绘为标准，拒绝3D写实/CG动画质感；追求柔和流畅线条、柔焦平涂、梦幻渲染、星芒光点、花朵网点背景

## 五、主视图规范

### 视图定义

> 单画面主视图，从场景中最具代表性的角度拍摄，承载空间叙事与构图重心。

| 项目 | 约束 | 提示词 |
|---|---|---|
| 视角 | 自然观察视角，构图最能体现场景主体与纵深 | hero shot、representative angle |
| 视点高度 | 默认人眼平视高度，特殊场景可俯/仰 | eye level（默认） |
| 构图 | 主体居中或符合三分法，前/中/后景层次清晰 | balanced composition |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 单画面（非拼图、非多视图、非分屏） |
| 人物 | **严禁出现任何人物、人影、人体轮廓** |
| 一致性 | 风格/材质/色调/光线统一 |
| 光线 | 单一光源逻辑，光影方向一致 |
| 画面比例 | 默认 16:9（或按调用方设定） |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 场景必须有「前中后景层次」 |
| R2 | 室外必须包含「空气透视」与「柔焦虚化」 |
| R3 | 场景图必须为「单画面主视图」，不得拼接多视图/分屏/网格 |
| R4 | 构图须能代表场景主体并展示前/中/后景层次 |
| R5 | 场景图中**严禁出现任何人物** |
| R6 | 必须包含少女漫画关键词（shoujo manga style / soft focus / soft lines / flower tone） |
| R7 | 必须包含镜头光学特征（柔焦平涂 / 柔和线条 / 梦幻渲染 / 星芒光点） |
| R8 | 场景必须带有梦幻柔焦氛围（花瓣飘落/星芒光点/花朵网点/柔焦光晕），禁止干净冷硬的"CG 感" |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 背景纯白/纯黑/无场景 |
| X2 | 极端天候（暴风雨/雷电，除非剧情需要） |
| X3 | 场景无纵深/无层次 |
| X4 | 植被/天候与季节矛盾 |
| X5 | 出现任何人物、人影、人体剪影或人体轮廓 |
| X6 | 画面被拼接成多视图/网格/分屏布局 |
| X7 | 3D 写实/CG 动画/写实摄影/卡通游戏引擎质感（禁用 3D render、CGI、Unreal Engine、Unity 等词） |
| X8 | 场景过于冷硬干净、无任何柔焦梦幻氛围与少女漫装饰（避免"塑料 CG 感"） |
| X9 | 光照过于均匀平坦、无景深柔焦虚化、无镜头光学特征 |
| X10 | 暗黑血腥恐怖/硬核机甲/过度阴影压抑元素 |
