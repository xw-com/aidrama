# 分镜表少女漫画言情约束 · 少女漫画言情 · 技法参考

---

## 一、分镜表定位

分镜表是导演将剧本转化为镜头语言的核心工具。以下仅提供少女漫画言情风格在分镜表层面的约束规范。

---

## 二、光影与氛围

- **柔焦光影统一** — 一场戏内光影方案必须保持柔焦平涂梦幻一致性，阴影使用同色系柔和加深（禁止黑色硬阴影/过度阴影压抑），除非有明确的叙事转折（如夕阳暖金→星空逆光的时间流逝）
- **情绪色盘绑定** — 每场戏至少绑定 1 个情绪场景（如心动瞬间/校园日常/浪漫约会/梦幻星空/花海漫步/烟花祭典/忧伤独处），并在镜头组内保持主色+辅色连续性，色彩取自核心色盘（奶油白 #FBF5EE / 樱花粉 #F5C8D8 / 少女粉 #F5B8C8 / 玫瑰红 #C84A6E / 星光金 #F0D080 / 薰衣草紫 #B8A0D8 / 天空蓝 #A8C8E8 / 薄荷绿 #A8D8C0 / 玫瑰金 #E8B898 / 深莓紫 #6B4A7A）
- **光源角度规范** — 正给镜头光源默认 38.5° 斜射柔光（柔焦平涂质感），侧给镜头根据画面需要调整。描述光影时须区分正给/侧给的角度差异，光影渲染始终保持少女漫画梦幻质感
- **冷暖色调与叙事阶段匹配** — 忧伤独处/梦幻思念段落使用冷色调（薰衣草紫 + 天空蓝 + 深莓紫点缀），禁用少女粉/星光金暖光；心动瞬间/浪漫约会段落使用柔和暖调（少女粉 + 星光金 + 玫瑰红）；烟花祭典/高潮段落使用玫瑰红 + 星光金高光
- **光影转场是高级手段** — 从樱花漫射渐变到星空逆光 = 日转夜的时间流逝。在分镜表中标注光影变化点，转场过程中柔焦色块必须平滑渐变，禁止色块断层/色彩溢出
- **梦幻渲染光效** — 允许合理使用柔焦光晕、星芒光点、景深虚化、体积光等现代渲染技法，但必须保持少女漫画柔焦平涂的美学基调，禁止 3D 写实/CG 动画光效

## 三、环境动态

- **环境动态增加画面心动呼吸感** — 花瓣飘落、星芒闪烁、纱帘飘动、樱花纷飞、晚风拂发、海浪轻拍。每 3-4 个镜头至少安排一个有环境动态的镜头，避免画面"死"掉
- **少女漫画环境元素优先** — 环境动态应选用少女漫画世界观内的元素：樱花、玫瑰花瓣、星光、泡泡、羽毛、蕾丝飘带、烟花光点、晚风、海浪、萤火虫光点，禁止出现暗黑恐怖或硬核机甲元素
- **柔焦动态质感** — 环境动态元素（花瓣/星芒/水波等）必须保持柔焦平涂质感与柔和流畅线条，禁止出现 3D 粒子特效或写实流体效果
- **星芒光点为标志性动态** — 心动瞬间段落应安排星芒光点四射、集中线衬托等少女漫画标志性动态特效，强化怦然心动氛围

---

## 四、少女漫画动作节奏

- **动作柔美且带少女漫感** — 人物动作默认柔美优雅，但可在关键帧上做少女漫画夸张处理（如心动瞬间的星芒爆发、害羞时的脸颊飞红特写、回眸时的发丝飘动），转身、抬手、低头应标注"柔美/优雅"
- **服饰动态是核心画面资产** — 少女漫画服饰（百褶裙、连衣裙、缎带、蕾丝、浴衣）的飘动是天然的动态资产，可在画面描述中加入裙摆/发丝/缎带的动态，柔焦渲染下的服饰飘动应柔和线条清晰、层次分明
- **仪态约束** — 少女漫画人物的举止应符合角色气质：元气少女活泼灵动、温柔学长儒雅从容、傲娇大小姐矜持骄傲。不出现粗犷或暗黑的肢体语言。少女漫角色可在微表情上略有夸张（大眼高光、脸颊飞红、眼睛弯月），但肢体动作仍需柔美克制
- **头身比一致** — 动作设计中角色必须保持 7-8 头身的少女漫画修长唯美比例，禁止因动态姿势而破坏头身比
- **大眼高光一致性** — 所有镜头中角色眼睛必须保持大而明亮、多层高光、星芒眼神光的少女漫画标志特征，禁止写实小眼或无高光

## 五、材质与质感约束

- **柔焦平涂为锚** — 所有镜头中人物/服饰/道具/场景的渲染必须保持柔焦平涂梦幻质感，线条柔和流畅清晰，色块平滑，禁止 3D 写实/CG 动画/照片级渲染
- **服饰材质** — 雪纺 + 蕾丝 + 棉麻 + 缎面的质感用柔焦平涂表现，纹理必须超清晰，衣服质感清晰
- **道具材质** — 缎面柔光、珍珠莹润、纸张纤维、奶油糖霜晶亮、花瓣柔嫩，均以柔焦平涂 + 柔和线条呈现，禁止写实材质渲染
- **场景材质** — 原木温润、布艺柔软、花瓣柔嫩、海面波光，材质带有梦幻柔焦氛围但以少女漫画笔触呈现，禁止冷硬的"塑料 CG 感"材质

---

## 六、色彩约束

- **核心色盘锁定** — 分镜表中所有镜头的色彩必须取自核心色盘（C1-C10），色相偏移容差 ±8°，饱和度偏移 ±10%，明度偏移 ±12%
- **禁止荧光色** — 严禁高饱和死亡荧光色/霓虹色/数码感强的色彩出现
- **线条颜色** — 深莓紫或柔和深棕，禁止粗犷硬朗纯黑线条
- **阴影色** — 同色系柔和加深，禁止黑色硬阴影/过度阴影压抑
- **整体色温** — 偏暖 4500-5200K 柔粉暖调基调，对比度 35-55%，饱和度 45-65%（少女漫粉调柔和）

---

## 七、运镜禁忌

- **禁用快速运镜** — 甩镜、急推、手持晃动与少女漫画言情的柔美梦幻气质冲突，烟花祭典场景可适度加快运镜节奏但仍需保持画面柔焦清晰
- **禁用花式转场** — 划屏、旋转、百叶窗等与本风格不兼容
- **禁用写实镜头语言** — 手持摇晃/纪录片式跟拍/鱼眼镜头等与少女漫画美学冲突，破坏柔焦平涂的画面纯净感
- **禁用暗黑运镜** — 过度低角度仰拍、极端硬光剪影、压抑构图等暗黑向镜头语言与本风格不兼容
