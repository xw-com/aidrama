# 少女漫画言情约束 · 少女漫画言情 · 技法参考

---

## 一、色调体系与画面基调

- **色调基底** — 全片以核心色盘为基底：奶油白（C1 #FBF5EE）、樱花粉（C2 #F5C8D8）、少女粉（C3 #F5B8C8）、玫瑰红（C4 #C84A6E）、星光金（C5 #F0D080）、薰衣草紫（C6 #B8A0D8）、天空蓝（C7 #A8C8E8）、薄荷绿（C8 #A8D8C0）、玫瑰金（C9 #E8B898）、深莓紫（C10 #6B4A7A），整体色温偏暖（4500-5200K），饱和度中（45-65%），呈现少女漫粉调柔和的浪漫梦幻画面
- **冷暖叙事对比** — 暖色（少女粉 C3、玫瑰红 C4、星光金 C5、玫瑰金 C9）作为正向情感/心动/甜蜜的视觉信号；冷色（薰衣草紫 C6、天空蓝 C7）作为梦幻/神秘/忧伤的视觉信号。冷暖切换应与故事弧线同步，而非随意混用
- **冷暖分配策略** — 心动瞬间/浪漫约会段落使用暖色调（少女粉 + 星光金 + 玫瑰红），禁用冷色硬光；梦幻星空/忧伤独处段落使用冷色调（薰衣草紫 + 天空蓝 + 深莓紫点缀）；烟花祭典/高潮段落使用玫瑰红 + 星光金高光
- **色盘先行原则** — 段落规划需先绑定情绪场景（心动瞬间/校园日常/浪漫约会/梦幻星空/花海漫步/烟花祭典/忧伤独处等），再确定主色+辅色与光影方案，避免"剧情对了但情绪不对色"
- **禁用色域** — 高饱和死亡荧光色、霓虹数码感强色彩均与本风格不兼容。色相偏移容差 ±8°，饱和度偏移 ±10%，明度偏移 ±12%

## 二、光影方案体系

- **光影即叙事** — 7 套光影方案对应不同情绪段落，导演规划阶段应在段落层面确定光影基调方向，而非逐镜指定
- **柔焦梦幻光影为锚** — 所有光影方案必须保持柔焦平涂梦幻质感，阴影使用同色系柔和加深，禁止黑色硬阴影/过度阴影压抑，允许柔焦光晕/星芒光点/景深虚化等梦幻渲染技法
- **光源角度** — 正给镜头默认 38.5° 斜射柔光（柔焦平涂质感），侧给镜头可适当调整

| 光影方案 | 方案名 | 色调倾向 | 适用情绪 |
|---|---|---|---|
| A | 柔粉晨光 | 奶油白底 + 少女粉微暖肤光 + 樱花漫反射 | 校园日常、清新甜蜜、治愈心动 |
| B | 心动星芒 | 少女粉 + 星光金四射星芒 + 集中线衬托 | 心动瞬间、告白、怦然特化（高光时刻专用） |
| C | 暖灯柔影 | 玫瑰金暖主导 + 深莓紫柔暗部 | 咖啡厅约会、卧室亲密、暖意绵绵 |
| D | 星空逆光 | 薰衣草紫 + 天空蓝冷光 + 星芒点缀 | 星空天台、梦幻夜景、思念独处 |
| E | 樱花漫射 | 樱花粉底 + 侧光斑驳 + 花瓣飘落 | 樱花校园、春日窗光、日间静谧 |
| F | 烟花斑斓 | 玫瑰红 + 星光金高光 + 薰衣草紫暗部 | 烟花祭典、高潮华彩、盛大浪漫 |
| G | 夕阳暖金 | 玫瑰金 + 少女粉暖调 + 长影渐变 | 海边黄昏、温暖告别、暮色心动 |

- **冷暖光分配** — 暖色光（少女粉/玫瑰金/星光金）适用于正向情感/心动段落；忧伤独处/梦幻夜景段落使用冷光（薰衣草紫/天空蓝）。导演可根据叙事需要调整冷暖切换点
- **氛围方向映射** — 每场戏的氛围方向应能映射到上述光影方案（A-G）的某一方向，确保视觉一致性

## 三、质感方向

- **柔焦平涂为锚** — 少女漫画的核心：柔和流畅线条、柔焦平涂、梦幻渲染、色块平滑渐变、禁止色块断层/色彩溢出
- **柔和线条 + 浪漫分镜质感** — 这是画面质感的锚点。不是写实摄影，不是 3D CG，是少女漫画手绘加梦幻柔焦渲染的融合
- **材质少女漫化** — 所有服化道的材质必须以柔焦平涂呈现：雪纺的轻盈用平滑色块、缎面的光泽用柔和反光、珍珠的润感用内透光色块、糖霜的晶亮用星芒高光。禁止"3D 感"和"写实摄影感"
- **皮肤质感** — 粉白基调、柔焦平涂、自然光泽、通透发光、星芒高光点缀、腮红粉润。禁止哑光/死白/蜡感/油光/过曝
- **少女漫不等于扁平** — 少女漫画言情强调在柔焦平涂基础上通过梦幻光晕、景深虚化、星芒光点、花瓣飘落等手段增加空间感与浪漫电影感，而非扁平无纵深的卡通风格

## 四、少女漫画场景空间元素

少女漫画言情世界观特有的场景元素及其视觉叙事功能：

- **花朵/蕾丝/纱帘/窗帘/拱门** — 天然的框架式构图道具，制造"看不透"的层次感与浪漫空间纵深，以柔和线条呈现精致花边细节
- **樱花树/花海/星空/海边** — 留白构图的天然载体，景即情：满樱盛开 = 心动、独坐星空 = 思念、花海漫步 = 浪漫、夕阳海边 = 告别
- **星芒光点/暖灯/窗光/烟花** — 少女漫画世界的光源载体，星芒 = 心动/闪亮（方案B）、暖灯 = 暖/亲密（方案C）、窗光 = 日常/清新（方案E）、烟花 = 高潮/华彩（方案F）
- **欧式拱门/白色凉亭/摩天轮/校舍/灯塔** — 建筑元素以少女漫美学呈现，细节丰富、柔和线条清晰，材质带梦幻柔焦质感，禁止冷硬的"塑料 CG 感"
- **段落间用场景空镜过渡** — 本风格有丰富的场景资产（不同时段/天候/景别变体），段落衔接建议用场景空镜做情绪缓冲，不要硬切
- **转折点用视觉而非台词** — 优先使用画面手段（光影突变、景别跳切、空镜隐喻、星芒爆发）而非依赖对白解释
- **前中后景层次** — 所有场景必须具备前/中/后景，杜绝扁平，室外必须包含空气透视与柔焦虚化（远景柔焦梦幻）

## 五、浪漫乐器与环境音

少女漫画言情世界观下的声音元素约束：

### 乐器选择

- **钢琴** — 浪漫、心动、回忆段落的核心乐器，与心动瞬间/浪漫约会/忧伤独处氛围高度适配
- **小提琴** — 情感激荡、深情、思念段落，拉弦的悠扬感适合情绪升华
- **竖琴** — 梦幻、仙气、幻想段落，星空/花海场景的氛围点缀
- **木吉他/尤克里里** — 清新、校园、日常段落，青春心动场景的轻快节奏器
- **长笛** — 治愈、清新、田园段落，花海/欧式花园的轻盈旋律
- **八音盒** — 回忆、纯真、梦幻段落的标志性音色，少女内心独白的最佳载体
- 弦乐铺底可增加电影感但不宜喧宾夺主

### 乐器组合策略

| 情绪阶段 | 乐器组合 |
|---|---|
| 平稳/开场/收尾 | 钢琴独奏 或 钢琴 + 木吉他 |
| 心动/告白/怦然 | 八音盒 + 钢琴 + 轻铃 |
| 浪漫约会/甜蜜 | 钢琴 + 小提琴 + 木吉他 |
| 梦幻星空/幻想 | 竖琴 + 长笛 + 弦乐铺底 |
| 忧伤/思念 | 钢琴 + 小提琴（独奏） |
| 祭典/高潮/华彩 | 长笛 + 弦乐 + 轻打击乐 |
| 校园日常/清新 | 尤克里里 + 木吉他 + 口风琴 |

### 浪漫环境音

- **典型环境音层次** — 樱花飘落簌簌 / 海浪轻拍 / 风铃轻响 / 咖啡厅杯盘轻碰 / 烟花绽放 / 八音盒旋律 / 心跳怦怦 / 晚风拂过 / 星空虫鸣 / 花瓣落地 / 教室钟声
- **每场戏标注 1-2 个核心环境音**，帮助后续音效设计。环境音层次越丰富，少女漫场景越有沉浸感与心动氛围
