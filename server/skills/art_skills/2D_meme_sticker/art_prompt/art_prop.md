# 沙雕表情包风格 - 道具图像生成 · 约束手册

---

## 一、道具设计原则

1. **功能夸张** — 道具用途一目了然且常被夸张放大，造型服务于搞笑功能
2. **涂鸦质感** — 粗黑描边、色块平涂、高饱和撞色为质感核心，无写实材质
3. **表情包风格** — 所有道具符合沙雕表情包世界观，风格统一
4. **尺度夸张** — 通过夸张比例或符号化标注暗示道具搞笑尺寸
5. **纯道具独立展示** — 画面中只能出现道具本身，严禁出现任何人物、手部、肢体，道具不可处于被持有/佩戴/握持状态，必须以贴纸静物陈列方式独立呈现

## 三、多角度设定图规范

### 视图定义

| 位置 | 视图 | 角度 | 要求 | 提示词 |
|---|---|---|---|---|
| 左上 | 正面图 | 正面 0° | 道具完整正面形态 | front view |
| 右上 | 侧面图 | 侧面 90° | 厚度/轮廓/结构清晰 | side view |
| 左下 | 背面图 | 背面 180° | 道具背部结构/装饰 | back view |
| 右下 | 细节特写 | 局部放大 | 描边纹理/搞笑细节 | detail closeup |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 同一画面四宫格（2×2），上下左右四视角 |
| 背景 | 贴纸亮黄 #FFE54C |
| 光线 | 无写实光影，扁平均匀色块 |
| 比例 | 每格道具占格内主体 70%+ |
| 投影 | 允许简笔扁平微投影 |
| 画面比例 | 建议 1:1 |

## 六、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须指定「贴纸亮黄背景 #FFE54C」 |
| R2 | 必须明确道具色块材质与撞色搭配 |
| R3 | 道具造型必须符合沙雕表情包世界观风格 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 复杂场景背景 |
| X2 | 道具与人物同画面 |
| X3 | 出现任何人物形象 |
| X4 | 道具处于被持有、握持、佩戴、使用中的状态 |
