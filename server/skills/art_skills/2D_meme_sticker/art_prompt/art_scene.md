# 沙雕表情包风格 - 场景图生成 · 约束手册

---

## 一、场景美学原则

1. **扁平叙事** — 场景以扁平色块拼贴承担情绪与叙事功能，不是写实背景板
2. **撞色层次** — 所有场景必须具备前/中/后景层次，但以色块叠层而非光影透视实现
3. **涂鸦至上** — 粗黑描边、色块平涂、高饱和撞色为质感核心
4. **表情包为锚** — 一切画面以沙雕表情包涂鸦为标准，拒绝写实厚涂/3D CG/复杂透视；追求扁平贴纸描边与无厘头道具拼贴

## 五、主视图规范

### 视图定义

> 单画面主视图，从场景中最具代表性的角度拍摄，承载叙事与构图重心。

| 项目 | 约束 | 提示词 |
|---|---|---|
| 视角 | 扁平正面观察视角，构图最能体现场景主体与色块层次 | hero shot、flat front angle |
| 视点高度 | 默认正面平视，特殊场景可俯/仰 | eye level（默认） |
| 构图 | 主体居中或符合三分法，前/中/后景色块层次清晰 | balanced composition |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 单画面（非拼图、非多视图、非分屏） |
| 人物 | **严禁出现任何人物、人影、人体轮廓** |
| 一致性 | 风格/材质/色调/描边统一 |
| 光线 | 无写实光影，扁平均匀色块 |
| 画面比例 | 默认 16:9（或按调用方设定） |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 场景必须有「前中后景色块层次」 |
| R2 | 所有轮廓必须为「粗黑描边」 |
| R3 | 场景图必须为「单画面主视图」，不得拼接多视图/分屏/网格 |
| R4 | 构图须能代表场景主体并展示前/中/后景色块层次 |
| R5 | 场景图中**严禁出现任何人物** |
| R6 | 必须包含表情包关键词（meme sticker style / flat sticker / bold outline） |
| R7 | 必须包含涂鸦特征（粗黑描边、色块平涂 至少一项） |
| R8 | 光照必须为扁平均匀色块，禁止写实光影与物理透视 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 背景纯白/纯黑/无场景 |
| X2 | 写实天候与物理光影（除非剧情需要且简化为符号） |
| X3 | 场景无层次/无色块叠层 |
| X4 | 植被/天候与季节矛盾 |
| X5 | 出现任何人物、人影、人体剪影 |
| X6 | 画面被拼接成多视图/网格/分屏布局 |
| X7 | 3D渲染/CG动画/写实厚涂/复杂透视 |
| X8 | 写实材质与物理光影 |
| X9 | 写实血腥/恐怖/暗黑场景元素 |
