# 沙雕表情包风格 - 人物基础形象生成 · 约束手册

---

## 一、基础形象原则

1. **夸张即灵魂** — 大头Q版、表情放大、比例失调到喜感为角色核心，越夸张越对味
2. **角色为本** — 基础着装由角色描述（身份/职业/性别/场景）决定其常规着装；后续特定服化为叠加层
3. **四视图一致** — 面容/体型/发型/基础服装跨视图高度统一（夸张比例也须一致）
4. **荒诞气质外放** — 无妆状态需体现角色气质（呆萌/暴躁/阴阳怪气/无厘头）

---

## 二、面容约束

> 不再固定五官特征参数，由角色描述（性别/年龄/性格/气质）驱动 AI 自由生成五官，保证人物间外观差异化。但五官必须夸张化、表情包化。

### 通用要求

| 项目 | 约束 |
|---|---|
| 五官 | 由角色描述自然推导，但须夸张化放大（大眼/大嘴/粗眉），不预设具体脸型 |
| 风格底色 | 沙雕表情包扁平贴纸涂鸦质感（粗黑描边、色块平涂、高饱和撞色） |
| 气质 | 必须从角色描述提炼整体气质关键词（如呆萌/暴躁/阴阳怪气/无厘头），并写入提示词 |
| 表情 | 夸张放大表情，符合角色气质，越夸张越好 |

## 六、基础服装约束

> 基础服装由角色描述（身份/职业/性别/场景）决定其最自然的常规着装，作为该角色「日常默认态」；正式服饰/特殊衍生在服化衍生环节叠加。**禁止内衣打底**。

### 着装选择原则

| 角色身份 | 默认着装方向 |
|---|---|
| 学生 | 简化校服（色块平涂 T恤+裤/裙） |
| 上班族 | 简化职业装（衬衫+西裤，色块平涂） |
| 居家/休闲 | 简化休闲服（卫衣/T恤/睡衣，色块平涂） |
| 运动/活泼 | 简化运动套装（色块撞色） |
| 特殊职业 | 简化对应身份服装（色块平涂） |
| 角色描述未明确 | 简化日常常服（色块平涂） |

### 着装统一规则

- 服装风格须与沙雕表情包美学一致（色块平涂、粗黑描边、高饱和撞色）
- 服装造型简化为色块，无复杂花纹/写实褶皱，便于后续衍生叠加
- 四视图服装款式完全一致
- 基础服装是「日常默认态」，焦点仍在夸张面容与表情
- 严禁内衣/暴露/性化打底

## 八、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须为「素颜无妆」状态 |
| R2 | 必须根据角色描述声明合适的常规着装作为基础服装（如学生→简化校服、上班族→简化职业装、居家→简化休闲服）；禁止内衣打底 |
| R3 | 必须声明「无发饰、无配饰」 |
| R4 | 必须指定「贴纸亮黄背景 #FFE54C」 |
| R5 | 必须指定「四视图一致性」 |
| R6 | 全身立像必须从头到脚完整展示，严禁裁切 |
| R7 | 必须指定角色头身比并约束为夸张Q版比例（女性默认2-3头身，男性默认2-3.5头身） |
| R8 | 人像特写必须从头顶到锁骨完整展示，严禁裁切头顶 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 内衣/暴露/性化打底；过度复杂花纹/装饰干扰后续服化叠加 |
| X2 | 写实皮肤质感/真人比例/写实毛孔 |
| X3 | 复杂写实光影/厚涂渲染 |
| X4 | 复杂场景背景（必须贴纸亮黄背景） |
| X5 | 写实血腥/暴力/恐怖/惊悚元素 |
| X6 | 全身立像裁切头顶或脚底，必须从头到脚完整入画 |
| X7 | 人像特写裁切头顶，必须从头顶到锁骨完整入画 |
| X8 | 忽略头身比约束，回退到写实比例 |
