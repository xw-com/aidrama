## 二、全局色彩盘（风格基线，不是硬锁）

> 目标：统一审美而非限制创作。除「硬约束色」外，其余颜色默认优先使用，可在合理范围内偏移。本风格鼓励高饱和撞色，但撞色须服务于喜感表达，不得沦为杂乱无章。

### 色彩使用层级

| 层级 | 约束强度 | 说明 |
|---|---|---|
| L1 硬约束 | 高 | 仅锁定角色识别核心：肤色、发色、主服底色的审美方向 |
| L2 软约束 | 中 | 场景色、配饰色、点缀色优先参考色盘，可按镜头与剧情微调 |
| L3 例外机制 | 低 | 高潮/爆笑/特殊场景可临时突破局部色彩，但需保留整体撞色搞笑逻辑 |

|---|---|---|---|
| C1 | 贴纸黄 | #FFE54C | 主背景、表情气泡、高亮 |
| C2 | 撞色品红 | #FF3D8B | 强调、搞笑警示、嘴唇 |
| C3 | 电光蓝 | #2DD4FF | 撞色背景、冷调撞色 |
| C4 | 涂鸦黑 | #1A1A1A | 描边、五官线条、文字 |

### 硬约束色（默认锁定）

| 色项 | 对应色 | 规则 |
|---|---|---|
| 描边基准 | C4 涂鸦黑 | 默认优先，所有轮廓线必须为粗黑描边 |
| 肤色基准 | C7 贴纸肤色 | 默认优先，允许小幅明度微调，保持扁平贴纸感 |

### 软约束色（推荐优先）

> C1/C2/C3/C5/C6/C8/C9/C10 为推荐色域，用于背景、撞色、道具、气泡、阴影等。可根据镜头氛围做同色相邻近调整，鼓励两两撞色搭配。

### 情绪色盘（导演对齐版）

| 情绪场景 | 主色 | 辅色 | 光效与对比建议 | 画面关键词 |
|---|---|---|---|---|
| 爆笑/狂喜 | C1 贴纸黄 | C2 撞色品红 + C5 喜剧橙 | 高饱和撞色，无光影 | 爆笑、夸张、冲击 |
| 无语/黑线 | C8 云朵白 | C4 涂鸦黑 + C10 灰影 | 降饱和留白，黑线点缀 | 无语、冷场、尴尬 |

### 情绪色盘使用规则

| 编号 | 规则 |
|---|---|
| E1 | 每条提示词至少指定 1 个「情绪场景」并绑定主色+辅色组合 |
| E2 | 单镜头主色不超过 2 个，撞色搭配须明确主辅关系，避免杂乱 |
| E3 | 情绪切换时优先调整撞色组合与符号元素，再调整饱和度 |
| E4 | 搞笑向默认遵循「高饱和撞色 + 留白呼吸」：撞色铺主体，留白用于气泡与符号 |
| E5 | 若与剧情冲突，以情绪色盘优先于通用推荐色，但不得突破严禁项 |

### 色温约束

| 参数 | 值 | 说明 |
|---|---|---|
| 整体色温 | 中性 5500-6500K（推荐） | 高饱和贴纸中性基底 |
| 肤色色温 | 微暖 5500-6000K（推荐） | 贴纸肤色扁平自然 |
| 对比度 | 高（建议保持） | 描边与色块强对比 |
| 饱和度 | 高 80-100%（建议区间） | 表情包高饱和撞色 |

### 容差与例外

| 项目 | 建议容差 |
|---|---|
| 色相偏移 | ±12° |
| 饱和度偏移 | ±10% |
| 明度偏移 | ±8% |

> 例外场景：爆笑高潮、阴险搞事镜头可使用更极端撞色或荧光色块；但禁止写实血腥色、暗调黑暗色彩入镜。
