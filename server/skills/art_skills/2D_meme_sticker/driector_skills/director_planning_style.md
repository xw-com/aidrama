# 表情包约束 · 沙雕表情包风 · 技法参考

---

## 一、色调体系与画面基调

- **色调基底** — 全片以贴纸黄（C1）、撞色品红（C2）、电光蓝（C3）为基底色，整体色温中性（5500-6500K），饱和度高（80-100%），呈现表情包贴纸的高饱和撞色感。全片保持高饱和撞色基底，局部点缀撞色（毒液绿 C6、基佬紫 C9）增加喜感层次
- **撞色叙事对比** — 撞色组合（黄+品红、蓝+橙、绿+紫）作为情绪转折的视觉信号，用于情绪切换段落。撞色切换应与故事弧线同步，而非随意混用
- **色盘先行原则** — 段落规划需先绑定情绪场景（爆笑/无语/震惊/阴阳怪气等），再确定主色+辅色与色块氛围方案，避免"剧情对了但情绪不对色"
- **禁用色域** — 写实血腥色、暗调黑暗色、90年代做旧泛黄色、低饱和沉郁色体系均与本风格不兼容

---

## 二、光影方案体系

> 本风格无写实光影，"光影方案"实为色块氛围方案。

- **色块即叙事** — 6 套色块氛围方案对应不同情绪段落，导演规划阶段应在段落层面确定色块氛围方向，而非逐镜指定
- **氛围方向** — 默认扁平正面色块铺底，符号化背景元素（放射线/感叹号/黑线/青筋）作为情绪爆点点缀

| 情绪段落 | 色块氛围方向 | 撞色倾向 | 适用阶段 |
|---|---|---|---|
| 日常搞笑 | A·贴纸黄铺底 | 黄底 + 蓝橙撞色点缀 | 全片 |
| 爆笑高潮 | B·高饱和撞色放射 | 品红 + 喜剧橙放射线 | 爆笑段 |
| 无语冷场 | C·大面积留白 | 云朵白 + 黑线点缀 | 冷场段 |
| 震惊爆点 | D·撞色冲击 | 电光蓝 + 贴纸黄感叹号 | 爆点段 |
| 阴阳怪气 | E·紫粉斜纹 | 基佬紫 + 撞色品红斜纹 | 吐槽段 |
| 暴怒抓狂 | F·红橙火焰 | 撞色品红 + 喜剧橙火焰 | 抓狂段 |

- **撞色分配** — 高饱和撞色贯穿全片可用，根据场景需要灵活调整；留白与黑线仅在冷场或情绪低谷后使用
- **氛围方向映射** — 每场戏的氛围方向应能映射到上述色块方案（A-F）的某一方向，确保视觉一致性

## 三、质感方向

- **扁平贴纸感** — 沙雕表情包的核心：粗黑描边、色块平涂、无写实光影、无立体渲染
- **粗黑描边 + 撞色平涂** — 这是画面质感的锚点。不是渐变，不是写实光影，不是厚涂
- **夸张不等于杂乱** — 本风格强调表情包涂鸦的质感表达（粗黑描边、撞色平涂、符号化背景），通过夸张表情与荒诞道具放大感染力，而非依赖复杂特效
- **符号化是灵魂** — 放射线、感叹号、黑线、青筋、泪珠、问号等符号化元素是表情包区别于其他风格的关键，每个镜头都应安排至少一处符号化爆点

## 四、表情包场景空间元素

沙雕表情包风特有的场景元素及其视觉叙事功能：

- **气泡/对话框/符号** — 天然的喜感载体，制造"出戏入戏"的层次感与无厘头反差，表情气泡是本风格标志性符号
- **工位/沙发/工位** — 摆烂感的天然载体，景即情：工位电脑前 = 摸鱼、沙发瘫 = 摆烂、厨房翻车 = 黑暗料理
- **咖啡/零食/键盘** — 翻车喜剧的天然载体，景即情：咖啡打翻 = 震惊、零食满地 = 摆烂、键盘冒烟 = 暴怒
- **放射线/感叹号/黑线** — 表情包的光影替代载体，放射线 = 爆笑冲击、感叹号 = 震惊爆点、黑线 = 无语冷场
- **段落间用色块空镜过渡** — 本风格有丰富的场景资产（不同情绪色块变体），段落衔接建议用色块空镜做情绪缓冲，不要硬切
- **转折点用符号而非台词** — 优先使用符号化手段（感叹号突现、黑线掉落、青筋暴起）而非依赖对白解释

## 五、表情包乐器与环境音

沙雕表情包风世界观下的声音元素约束：

### 乐器选择

- **电子合成器** — 日常/搞笑/无厘头段落的核心音色，最能表现表情包的质感
- **滑稽音效（boing/弹簧音）** — 夸张/翻车/爆笑段落，滑音适合搞笑氛围
- **轻快尤克里里** — 摆烂/装傻/日常段落，轻快扫弦适合无厘头
- **8-bit 芯片音** — 震惊/爆点/暴怒段落，复古游戏音效适合爆点

### 乐器组合策略

| 情绪阶段 | 乐器/音效组合 |
|---|---|
| 平稳/开场/收尾 | 尤克里里独奏 或 8-bit 旋律 |
| 日常搞笑 | 电子合成器 + 滑稽音效 |
| 爆笑高潮 | 8-bit 芯片音 + 弹簧 boing |
| 无语冷场 | 留白 + 单音尴尬停顿 |

### 表情包环境音

- **典型环境音层次** — 键盘敲击声 / 鼠标点击 / 咖啡杯碰撞 / 电视背景音 / 手机震动 / 弹窗提示音 / 蝉鸣空调嗡嗡 / 滑稽 boing 音效
- **每场戏标注 1-2 个核心环境音**，帮助后续音效设计。环境音层次越丰富，表情包场景越有沉浸感
- **留白比配乐更重要** — 关键搞笑瞬间（冷场、尴尬停顿、灵魂出窍）优先考虑去掉配乐，只留尴尬的环境音（空调嗡嗡、远处键盘声），让观众自己感受喜感
- **避免满配** — 全片配乐覆盖率建议不超过 40%。留白段落的"无声"与配乐段落形成呼吸感，突出搞笑反差
