# 沙雕表情包风格说明

本风格专为"网络表情包/沙雕搞笑贴纸质感"题材打造，所有美术提示词、规范和生成内容均严格限定于：

- **网络表情包世界观**：以无厘头日常、网络梗、荒诞喜剧为背景，涵盖聊天框、贴纸卡面、表情气泡、夸张大头Q版角色、无厘头道具等，体现网络亚文化气息。
- **简笔涂鸦质感**：所有角色、场景、道具均以扁平贴纸描边涂鸦为标准，强调粗黑描边轮廓、色块平涂、高饱和撞色、夸张变形的大头Q版造型。
- **沙雕荒诞美学**：在涂鸦基础上追求表情包式的视觉冲击与喜剧反差，画面色调高饱和撞色，造型夸张变形，整体氛围荒诞搞笑、无厘头治愈。
- **情感表达**：适合展现搞笑、吐槽、无语、震惊、阴阳怪气、网络梗剧情，强调夸张表情与荒诞喜感下的情绪释放。

## 适用范围

- 网络表情包/沙雕搞笑贴纸题材的AI美术生成（角色、场景、道具、分镜等）
- 需要夸张变形、高饱和撞色、扁平描边涂鸦质感的视觉创作

## 严禁内容

- 写实血腥、暴力、恐怖、惊悚、暗黑
- 复杂写实光影、厚涂渲染、3D CG
- 严肃正剧、文艺沉郁、暗调治愈
- 真人写实比例、写实皮肤质感
- 复杂场景透视与写实材质

## 风格体验

在本风格下，您将体验到：

- 角色面容极度夸张、表情放大到极致，大头Q版造型，简笔涂鸦描边
- 场景扁平化色块拼贴，高饱和撞色，无厘头道具与文字气泡留位
- 道具、日常物品均为夸张变形的贴纸造型，粗黑描边，撞色平涂
- 分镜与画面均以表情包涂鸦为基底，强调喜感反差与荒诞叙事表达

本风格仅适用于"沙雕表情包/搞笑贴纸"相关项目。如需其他风格（如写实、复古、赛璐璐、文艺等），请勿使用本套提示词。
