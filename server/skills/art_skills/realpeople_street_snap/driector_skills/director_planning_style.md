# 街拍风格约束 · 时尚街拍 · 技法参考

---

## 一、色调体系与画面基调

- **色调基底** — 全片以暖灰白（C4）、水泥灰（C1）、牛仔蓝（C2）为基底色，整体色温中性偏暖（5000-6000K），饱和度中低（40-60%），呈现自然时髦的都市街拍感
- **冷暖叙事对比** — 暖色（黄金暖光 C7、焦糖棕 C5、砖红 C3）作为情感升温与关系确认的视觉信号，冷色（阴天冷蓝 C6、深炭黑 C8）用于压力、误会、疏离等段落。冷暖切换应与情绪弧线同步
- **冷暖分配策略** — 日常与通勤段落以中性/微冷为主，黄金时刻与亲密段落释放暖色；避免全程高暖导致情绪层次塌陷
- **色盘先行原则** — 段落规划先绑定情绪场景（街头偶遇/黄金时刻/阴天漫步/夜街霓虹/运动抓拍等），再确定主色+辅色与光影方案，避免"剧情对了但街拍不对色"
- **禁用色域** — 高饱和荧光色、强霓虹污染、影棚硬光、过度后期与本风格不兼容

## 二、光影方案体系

- **光影即叙事** — 6 套光影方案对应不同情绪段落，导演规划阶段应在段落层面确定光影基调方向，而非逐镜指定
- **光源角度** — 正给镜头默认 30°-45° 侧逆光（勾勒发丝与穿搭轮廓），侧给镜头根据场景与人物关系微调

| 光影方案 | 方案名 | 色调倾向 | 适用情绪 |
|---|---|---|---|
| A | 自然漫射 | 暖灰白底 + 均匀柔和光 | 日常通勤、街头偶遇、生活流叙事 |
| B | 黄金时刻侧逆光 | 黄金暖 + 局部暖光 | 升温互动、心动时刻、自信穿搭 |
| C | 阴天漫射冷光 | 阴天冷蓝 + 灰白主调 | 文艺漫步、低潮段、疏离感 |
| D | 街头点光源 | 深炭黑主导 + 暖色点缀 | 夜街霓虹、都市夜景、浪漫游走 |
| E | 商场/室内环境光 | 中性灰 + 柔和冷白 | 室内互动、理性沟通、购物场景 |
| F | 雨天漫射冷光 | 灰蓝主调 + 暖色局部 | 过渡段、低潮段、情绪段 |

- **冷暖光分配** — 暖色光可全片使用但需分层控制；冲突/疏离段落降低暖光占比，避免情绪与光色冲突
- **氛围方向映射** — 每场戏氛围方向应映射到上述光影方案（A-F）的某一方向，确保视觉一致性

## 三、质感方向

- **超清纪实感** — 都市街拍摄影核心：皮肤纹理可见、发丝根根分明、服装面料质感清晰可信
- **自然光 + 浅景深虚化** — 作为画面质感锚点。不是影棚硬光，不是重滤镜氛围化，而是可拍可落地的杂志级街拍纪实感
- **材质真实** — 服化道需具备现实可信度：风衣面料、牛仔布纹、皮革包袋、金属配饰、玻璃橱窗反射都应符合街拍实拍逻辑
- **皮肤质感** — 保留真实毛孔与细微瑕疵，控制磨皮强度，追求"真实但好看"，自然光还原生命感
- **写实不等于平淡** — 通过构图、景别、运动节奏（抓拍瞬间、运动模糊动感）放大时尚感染力，而非依赖夸张特效与过度后期

## 四、街拍场景空间元素

都市街拍世界观特有的场景元素及其视觉叙事功能：

- **斑马线/十字路口/天桥** — 天然构图引导线道具，制造空间纵深与人物关系距离感
- **橱窗/镜面/玻璃门** — 反射与框架式构图道具，制造空间分层与人物双重曝光感
- **商业街/咖啡馆外摆/地铁口** — 情绪容器：商业街偏自信时髦，咖啡馆偏治愈松弛，地铁口偏通勤节奏
- **天气与时段作为转场** — 日转夜、晴转阴、黄金时刻入夜可用于段落情绪缓冲，避免硬切
- **风吹发丝/车流动态/人流虚化** — 街拍标志动态资产，可作为情绪转折的视觉锚点
- **转折点用视觉而非解释** — 优先使用画面手段（景别突变、视线错位、街景遮挡）承接情绪转折，减少对白解释负担

## 五、街拍乐器与环境音

都市街拍世界观下的声音元素约束：

### 乐器选择

- **吉他** — 日常、街头、慢节奏浪漫段落核心乐器，最能体现街拍生活质感
- **Lo-fi/轻电子** — 年轻化、城市夜生活、节奏切换段落的风格增强器
- **钢琴** — 治愈、回忆、咖啡馆段落的有效主导
- **轻打击/手鼓** — 运动抓拍、节奏段落、动感段落的节奏增强器
- **环境音优先级高** — 街拍剧中真实城市环境声是沉浸感关键，配乐不应压过对白

### 乐器组合策略

| 情绪阶段 | 乐器组合 |
|---|---|
| 平稳/开场/收尾 | 吉他独奏 或 Lo-fi |
| 日常推进/通勤 | 吉他 + 轻打击 |
| 黄金时刻/浪漫 | 吉他 + 钢琴 |
| 运动抓拍/动感 | 轻打击 + Lo-fi |
| 夜街/转场 | Lo-fi/轻电子 + 环境声 |

### 街拍环境音

- **典型环境音层次** — 车流声 / 地铁进站提示 / 红绿灯提示音 / 咖啡机声 / 高跟鞋敲地 / 风吹树叶 / 城市远景噪声 / 雨声
- **每场戏标注 1-2 个核心环境音**，帮助后续音效设计。环境音层次越准确，街拍写实质感越强
