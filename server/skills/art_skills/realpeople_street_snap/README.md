# 时尚街拍风格说明

本风格专为"时尚街拍"题材打造，所有美术提示词、规范和生成内容均严格限定于：

- **都市街拍世界观**：以城市街道、商业区、地铁口、咖啡馆外摆、天桥、公园步道为背景，涵盖日常通勤、穿搭打卡、街头抓拍等，杜绝都市街景元素缺失。
- **真人写实摄影**：所有角色（模特、博主、路人、街拍主体）均以真人写实街拍摄影为标准，强调五官、皮肤、发丝、服装面料、配饰等极致细节与真实质感。
- **时尚杂志级纪实**：在写实基础上追求时尚街拍杂志级氛围感，画面自然光为主，城市街景背景虚化，穿搭记录感强烈，黄金时刻/阴天柔和光、运动模糊动感并存，整体氛围真实、时髦、纪实。
- **穿搭记录氛围**：适合展现自信、时髦、都市日常的时尚故事，强调人物穿搭与城市街景之间的纪实时尚表达。

## 适用范围

- 时尚街拍题材的AI美术生成（角色、场景、道具、分镜等）
- 需要极致写实、自然光、穿搭记录感氛围的视觉创作

## 严禁内容

- 卡通、动漫、插画、二次元风格
- 都市街景元素缺失、古风/古装/传统建筑
- 高饱和荧光色、影棚硬光、过度后期
- 暗示性、暴露、透视等不适宜内容

## 风格体验

在本风格下，您将体验到：

- 角色面容精致、气质自信或随性，服饰、妆容、发型均为现代都市街拍写实（时髦穿搭、风衣、牛仔、针织）
- 场景空间层次丰富，街景/建筑/招牌材质纹理超清晰，自然光与黄金时刻交织，背景虚化散景真实
- 道具、手机、咖啡杯、包袋、配饰等均为现代造型，工艺精细，材质质感极致
- 分镜与视频均以真人街拍写实为基础，强调穿搭记录、运动模糊动感与纪实时尚表达

---

本风格仅适用于"时尚街拍"相关项目。如需其他风格（如古风、插画、动漫、美食摄影等），请勿使用本套提示词。
