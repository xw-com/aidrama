## 二、全局色彩盘（风格基线，不是硬锁）

> 目标：统一审美而非限制创作。除「硬约束色」外，其余颜色默认优先使用，可在合理范围内偏移。

### 色彩使用层级

| 层级 | 约束强度 | 说明 |
|---|---|---|
| L1 硬约束 | 高 | 仅锁定服装主色、发色、肤色核心的审美方向 |
| L2 软约束 | 中 | 场景色、配饰色、点缀色优先参考色盘，可按镜头与剧情微调 |
| L3 例外机制 | 低 | 节庆/回忆/高潮戏可临时突破局部色彩，但需保留整体冷暖逻辑 |

### 硬约束色（默认锁定）

| 色项 | 对应色 | 规则 |
|---|---|---|
| 服装主色基准 | C2 牛仔蓝 + C4 暖灰白 | 默认优先，街拍穿搭核心，允许小幅明度偏移 |
| 发色/瞳色基准 | C8 深炭黑 | 默认优先，允许深棕/深褐轻微偏移 |

### 软约束色（推荐优先）

> C1/C3/C5/C6/C7/C9/C10 为推荐色域，用于街景建筑、配饰包袋、暖光、冷调阴影、军绿点缀等。可根据镜头氛围做同色相邻近调整。

### 情绪色盘（导演对齐版）

| 情绪场景 | 主色 | 辅色 | 光效与对比建议 | 画面关键词 |

### 情绪色盘使用规则

| 编号 | 规则 |
|---|---|
| E1 | 每条提示词至少指定 1 个「情绪场景」并绑定主色+辅色组合 |
| E2 | 单镜头主色不超过 2 个，避免颜色叙事失焦 |
| E3 | 情绪切换时优先调整光比与色温，再调整饱和度 |
| E4 | 街拍向默认遵循「中性底 + 暖点」：中性/冷色铺底，暖光落在人物发丝与穿搭焦点 |
| E5 | 若与剧情冲突，以情绪色盘优先于通用推荐色，但不得突破严禁项 |

### 色温约束

| 参数 | 值 | 说明 |
|---|---|---|
| 整体色温 | 中性偏暖 5000-6000K（推荐） | 自然光街拍主基调 |
| 肤色色温 | 微暖 5200-5600K（推荐） | 自然但有生命感 |
| 对比度 | 中强（建议保持） | 明暗反差鲜明但不硬 |
| 饱和度 | 中低 40-60%（建议区间） | 时尚高级色调 |

### 容差与例外

| 项目 | 建议容差 |
|---|---|
| 色相偏移 | ±8° |
| 饱和度偏移 | ±10% |
| 明度偏移 | ±12% |

> 例外场景：黄金时刻、夜街霓虹、时尚大片镜头可使用更暖或更高对比局部色块；但禁止荧光色与影棚硬光入镜。

## 三、全局约束规则

### 必守规则（所有技能继承）

| 编号 | 规则 |
|---|---|
| R1 | 必须包含「都市时尚街拍」风格锚定词 |
| R2 | 必须声明「自然光 + 城市街景虚化」 |
| R3 | 面部必须使用「面容细腻渲染 + 皮肤细腻」 |
| R4 | 发丝必须使用「根根分明 + 发丝细腻渲染」 |
| R5 | 纹理必须声明「纹理细节超清晰」 |

### 严禁项（所有技能继承）

| 编号 | 严禁内容 |
|---|---|
| X1 | 严禁「卡通/动漫/二次元/插画风」 |
| X2 | 严禁「高饱和荧光色/影棚硬光/过度后期」 |
| X3 | 严禁「都市街景缺失」（必须明确城市街道场景） |
| X4 | 严禁「面部变形/多指/肢体异常」倾向词 |
| X5 | 严禁「裸体/暴露/透视/暗示性描述」 |
| X6 | 严禁「古风/古装/汉服/传统建筑元素」 |
