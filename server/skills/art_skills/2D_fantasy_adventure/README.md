# 奇幻冒险风格说明

本风格专为"日系奇幻冒险"题材打造，所有美术提示词、规范和生成内容均严格限定于：

- **异世界大陆世界观**：以广阔奇幻大陆为舞台，涵盖古代遗迹、魔法森林、浮空岛、草原城镇、地下迷宫、龙脊山脉等，体现探索与远行的冒险气息。
- **现代赛璐璐+幻想光影**：所有角色、场景、道具均以现代日系动画赛璐璐作画为标准，线条干净利落、色块饱和明亮、光影通透具幻想感，兼具吉卜力式自然广阔感。
- **明亮探索美学**：在赛璐璐基础上追求充满空气感与阳光感的冒险氛围，色彩明快饱和，天空高远，细节丰富，整体氛围明亮、热血、向上、辽阔。
- **情感表达**：适合展现友情、勇气、成长、奇遇与羁绊的奇幻冒险故事，强调旅途感、未知感与少年心性的热血探索。

## 适用范围

- 日系奇幻冒险题材的AI美术生成（角色、场景、道具、分镜等）
- 需要明亮饱和、通透光影、广阔探索感的现代赛璐璐幻想视觉创作

## 严禁内容

- 暗黑奇幻、末世废土、克苏鲁恐怖、血腥压抑的黑暗美学
- 3D渲染、CG动画、写实厚涂、油画质感
- 低饱和灰暗色调、过曝褪色、做旧泛黄
- 过度阴影、重对比、阴森氛围、成人向内容

## 风格体验

在本风格下，您将体验到：

- 角色面容清亮、气质明朗或热血，服饰、装备、发型均为日系奇幻冒险风格，便于旅行动作
- 场景空间层次辽阔，线条干净利落，色彩明亮饱和，氛围充满阳光与空气感
- 道具、魔法器物、冒险装备均为奇幻造型，工艺精致，光泽通透
- 分镜与画面均以现代赛璐璐为基础，强调探索感、动态感与少年冒险的热血叙事

---

本风格仅适用于"奇幻冒险"相关项目。如需其他风格（如暗黑奇幻、欧美油画奇幻、现代动画、写实插画等），请勿使用本套提示词。
