# 奇幻冒险约束 · 日系奇幻冒险 · 技法参考

---

## 一、色调体系与画面基调

- **色调基底** — 全片以天空青（C1）、草原绿（C2）、冒险橙（C3）为基底色，整体色温偏暖偏亮（5200-5800K），饱和度中高（65-85%），呈现现代赛璐璐的明亮饱和探索感。全片保持明亮暖色调基底，局部点缀冷色（魔法青蓝 C5、天空青 C1）增加层次
- **冷暖叙事对比** — 冷色（魔法青蓝 C5、翡翠绿 C8）作为魔法/神秘/远景的视觉信号，用于魔法释放或危机暗涌段落局部点缀。冷暖切换应与故事弧线同步，而非随意混用
- **色盘先行原则** — 段落规划需先绑定情绪场景（出发启程/激战热血/魔法释放/遗迹探索等），再确定主色+辅色与光影方案，避免"剧情对了但情绪不对色"
- **禁用色域** — 低饱和灰暗色调、做旧泛黄、写实油画色彩体系均与本风格不兼容

---

## 二、光影方案体系

- **光影即叙事** — 6 套光影方案对应不同情绪段落，导演规划阶段应在段落层面确定光影基调方向，而非逐镜指定
- **光源角度** — 默认 30-45°斜侧光，模拟自然阳光效果；魔法场景可叠加体积光束

| 情绪段落 | 光影方向 | 色调倾向 | 适用阶段 |
|---|---|---|---|
| 出发启程 | A·通透天光 | 天空青底 + 阳光金高光 | 开场/启程段 |
| 激战热血 | B·强侧光高对比 | 冒险橙主导 + 古铜棕阴影 | 战斗段 |
| 营火休憩 | C·暖调聚焦光 | 阳光金 + 朝霞粉局部 | 休整/羁绊段 |
| 遗迹探索 | D·斑驳侧光 | 遗迹石灰 + 魔法青蓝点缀 | 探索段 |
| 魔法释放 | E·体积光束 | 魔法青蓝主导 + 翡翠绿辅 | 高潮/魔法段 |
| 危机暗涌 | F·低调冷阴影 | 古铜棕 + 魔法青蓝压低 | 危机/转折段 |

- **冷暖光分配** — 暖色调贯穿全片可用，根据场景需要灵活调整；冷色调（魔法青蓝主调）仅在魔法释放或危机暗涌时使用
- **氛围方向映射** — 每场戏的氛围方向应能映射到上述光影方案（A-F）的某一方向，确保视觉一致性

## 三、质感方向

- **赛璐璐探索感** — 现代日系动画赛璐璐的核心：线条干净利落、色块明亮饱和、光影通透分明
- **干净线稿 + 明亮上色** — 这是画面质感的锚点。不是模糊晕染，不是写实厚涂，不是油画质感
- **赛璐璐不等于简陋** — 本风格强调现代赛璐璐的质感表达（清晰线稿、明亮色块、通透光影），通过构图与情绪设计放大感染力，而非依赖复杂特效
- **通透不等于过曝** — 奇幻冒险强调明亮通透的影像表达（高远天光、饱和色彩、热血表情），通过镜头与情绪设计放大感染力，而非依赖奇观堆叠

## 四、奇幻冒险场景空间元素

日系奇幻冒险特有的场景元素及其视觉叙事功能：

- **古道/断桥/吊桥** — 天然的引导线构图道具，制造"通向未知"的纵深感与冒险召唤
- **遗迹/石柱/符文阵** — 世界观叙事的天然载体，景即史：风化石柱 = 古代文明、发光符文 = 魔法遗迹、断壁浮雕 = 失落传说
- **浮空岛/云海/瀑布** — 奇幻广度的天然载体，景即梦：浮空岛 = 自由梦想、云海翻涌 = 辽阔远方、垂落瀑布 = 壮阔奇景
- **篝火/营帐/酒馆壁炉** — 羁绊时刻的光源载体，篝火 = 温暖/羁绊（方案C）、壁炉 = 旅人歇脚、营帐 = 夜话休整
- **段落间用场景空镜过渡** — 本风格有丰富的场景资产（不同时段/天候/地貌变体），段落衔接建议用场景空镜做情绪缓冲，如古道延伸、云海流动、篝火明灭
- **转折点用视觉而非台词** — 优先使用画面手段（光影突变、景别跳切、空镜隐喻）而非依赖对白解释

## 五、奇幻冒险乐器与环境音

日系奇幻冒险世界观下的声音元素约束：

### 乐器选择

- **交响弦乐** — 出发/热血/高潮段落的核心乐器，最能表现冒险的辽阔与激昂
- **鲁特琴/木吉他** — 旅路/营火/酒馆段落，拨弦的温暖感适合旅途日常
- **民族打击乐/定音鼓** — 战斗/危机/史诗段落，鼓点驱动热血节奏
- **长笛/竖琴** — 魔法/精灵/神秘段落，清亮音色适合奇幻氛围

### 乐器组合策略

| 情绪阶段 | 乐器组合 |
|---|---|
| 平稳/开场/收尾 | 鲁特琴独奏 或 长笛独奏 |
| 旅路日常 | 木吉他 + 轻打击 |
| 热血激战 | 交响弦乐 + 定音鼓 |
| 魔法/神秘 | 竖琴 + 长笛 |

### 奇幻环境音

- **典型环境音层次** — 风过草原 / 林间鸟鸣 / 溪流潺潺 / 篝火噼啪 / 远山鹰啸 / 海浪拍岸 / 遗迹风声回响
- **每场戏标注 1-2 个核心环境音**，帮助后续音效设计。环境音层次越丰富，奇幻场景越有沉浸感
- **留白比配乐更重要** — 关键情感瞬间（远眺、对视、抉择）优先考虑去掉配乐，只留环境音（风声、鸟鸣、溪流），让观众自己感受情绪
- **避免满配** — 全片配乐覆盖率建议不超过 50%。留白段落的"无声"与配乐段落形成呼吸感，突出冒险的真实感
