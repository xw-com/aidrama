# 奇幻冒险风格 - 人物基础形象生成 · 约束手册

---

## 一、基础形象原则

1. **线条即骨架** — 干净利落的赛璐璐线条为角色核心，避免模糊晕染与数字化锐利边缘
2. **角色为本** — 基础着装由角色描述（职业/种族/性别/场景）决定其常规冒险着装；后续特定服化为叠加层
3. **四视图一致** — 面容/体型/发型/基础服装跨视图高度统一
4. **气质明朗热血** — 无妆状态需体现角色气质（热血/爽朗/沉稳/机敏）

---

## 二、面容约束

> 不再固定五官特征参数，由角色描述（性别/年龄/性格/种族/气质）驱动 AI 自由生成五官，保证人物间外观差异化。

### 通用要求

| 项目 | 约束 |
|---|---|
| 五官 | 由角色描述自然推导，不预设脸型/眼型/眉型/鼻型/唇型 |
| 风格底色 | 日系奇幻冒险赛璐璐质感（明亮饱和、干净线条、通透光影） |
| 气质 | 必须从角色描述提炼整体气质关键词（如热血/爽朗/沉稳/机敏），并写入提示词 |
| 表情 | 中性微表情，符合角色气质 |
| 奇幻种族 | 精灵可叠加尖耳、兽人可叠加兽耳/兽尾、龙裔可叠加鳞片/角，须在角色描述中显式声明，其余五官仍按通用要求推导 |

## 六、基础服装约束

> 基础服装由角色描述（职业/种族/性别/场景）决定其最自然的常规冒险着装，作为该角色「旅途默认态」；正式服饰/特殊衍生在服化衍生环节叠加。**禁止内衣打底**。

### 着装选择原则

| 角色身份 | 默认着装方向 |
|---|---|
| 剑士/战士 | 轻甲/皮甲+披风+旅行靴 |
| 法师/术士 | 法袍/兜帽斗篷+束腰带 |
| 游侠/弓手 | 翻领旅装+护臂+长靴 |
| 牧师/祭司 | 神职法衣+圣徽披肩 |
| 盗贼/斥候 | 紧身旅装+多功能腰带+短靴 |
| 种族身份（精灵/兽人等） | 种族特色旅装（精灵轻纱/兽人皮毛饰边等） |
| 角色描述未明确 | 奇幻冒险旅行常服（束腰外衣+长裤+旅行靴+披风） |

### 着装统一规则

- 服装风格须与日系奇幻冒险美学一致（明亮饱和、干净线条、赛璐璐质感）
- 颜色中高饱和，可含族徽/简单纹饰，便于后续衍生叠加
- 四视图服装款式完全一致
- 基础服装是「旅途默认态」，焦点仍在面容与体态
- 严禁内衣/暴露/性化打底

## 八、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须为「素颜无妆」状态 |
| R2 | 必须根据角色描述声明合适的常规冒险着装作为基础服装（如剑士→轻甲披风、法师→法袍斗篷、游侠→翻领旅装）；禁止内衣打底 |
| R3 | 必须声明「无发饰、无配饰」 |
| R4 | 必须指定「暖调云白背景 #F4F0E4」 |
| R5 | 必须指定「四视图一致性」 |
| R6 | 全身立像必须从头到脚完整展示，严禁裁切 |
| R7 | 必须指定角色身高并通过头身比换算约束全身比例（女性默认155-168cm/6-7头身，男性默认170-185cm/7-8头身） |
| R8 | 人像特写必须从头顶到锁骨完整展示，严禁裁切头顶 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 内衣/暴露/性化打底；与角色描述明显不符的着装；过度复杂花纹/装饰干扰后续服化叠加 |
| X2 | 暗黑奇幻/末世废土色调、低饱和灰暗 |
| X3 | 过度美白至无血色、病态苍白 |
| X4 | 复杂场景背景（必须暖色调背景） |

| X6 | 全身立像裁切头顶或脚底，必须从头到脚完整入画 |
| X7 | 人像特写裁切头顶，必须从头顶到锁骨完整入画 |
| X8 | 忽略身高和头身比约束 |
