## 二、全局色彩盘（风格基线，不是硬锁）

> 目标：统一审美而非限制创作。除「硬约束色」外，其余颜色默认优先使用，可在合理范围内偏移。

### 色彩使用层级

| 层级 | 约束强度 | 说明 |
|---|---|---|
| L1 硬约束 | 高 | 仅锁定角色识别核心：肤色、发色、主服底色的审美方向 |
| L2 软约束 | 中 | 场景色、配饰色、点缀色优先参考色盘，可按镜头与剧情微调 |
| L3 例外机制 | 低 | 回忆/高潮/特殊场景可临时突破局部色彩，但需保留整体明亮探索逻辑 |

### 情绪色盘使用规则

| 编号 | 规则 |
|---|---|
| E1 | 每条提示词至少指定 1 个「情绪场景」并绑定主色+辅色组合 |
| E2 | 单镜头主色不超过 2 个，避免颜色叙事失焦 |
| E3 | 情绪切换时优先调整光比与色温，再调整饱和度 |
| E4 | 冒险向默认遵循「明亮底 + 冷暖对比」：暖色铺底，冷色用于魔法/远景/阴影 |
| E5 | 若与剧情冲突，以情绪色盘优先于通用推荐色，但不得突破严禁项 |

### 色温约束

| 参数 | 值 | 说明 |
|---|---|---|
| 整体色温 | 偏暖偏亮 5200-5800K（推荐） | 明亮阳光的冒险主基调 |
| 肤色色温 | 微暖 5300-5600K（推荐） | 健康通透的少年感 |
| 对比度 | 中等偏强（建议保持） | 明暗层次清晰，强调光影通透感 |
| 饱和度 | 中高 65-85%（建议区间） | 现代赛璐璐的明亮饱和调 |

### 容差与例外

| 项目 | 建议容差 |
|---|---|
| 色相偏移 | ±10° |
| 饱和度偏移 | ±12% |
| 明度偏移 | ±12% |

> 例外场景：魔法释放、遗迹幽光、危机暗涌镜头可使用更冷或更高饱和局部色块；但禁止低饱和灰暗色调与做旧泛黄入镜。

## 三、全局约束规则

### 必守规则（所有技能继承）

| 编号 | 规则 |
|---|---|
| R1 | 必须包含「日系奇幻冒险风格」风格锚定词 |
| R2 | 必须声明「现代赛璐璐 + 干净利落线条」 |
| R3 | 面部必须使用「干净线条 + 明亮通透肤色」 |
| R4 | 发丝必须使用「清晰线条 + 通透高光」 |
| R5 | 光影必须声明「幻想光影 + 通透体积光」 |

### 严禁项（所有技能继承）

| 编号 | 严禁内容 |
|---|---|
| X1 | 严禁「暗黑奇幻/末世废土/克苏鲁恐怖」倾向词 |
| X2 | 严禁「3D渲染/CG动画/写实厚涂/油画质感」 |
| X3 | 严禁「低饱和灰暗色调/做旧泛黄/过曝褪色」 |
| X4 | 严禁「面部变形/比例失调/肢体异常」倾向词 |
| X5 | 严禁「过度阴影/重对比阴森/压抑黑暗」 |
| X6 | 严禁「现代都市/科幻机甲/赛博朋克元素」 |
