# 室内设计风格约束 · 室内设计 · 技法参考

---

## 一、色调体系与画面基调

- **色调基底** — 全片以暖白（C1）、橡木色（C5）、高级灰（C6）为基底色，整体色温中性偏暖（4800-5500K），饱和度中低（35-55%），呈现中性高级的空间生活感
- **冷暖叙事对比** — 暖色（窗光暖 C7、黄铜金 C3、橡木色 C5）作为情感升温与归属确认的视觉信号，冷色（雾灰蓝 C8、高级灰 C6）用于专注、冷静、过渡等段落。冷暖切换应与情绪弧线同步
- **冷暖分配策略** — 日常与阅读段落以中性/微冷为主，温暖与归家段落释放暖色；避免全程高暖导致材质层次塌陷
- **色盘先行原则** — 段落规划先绑定情绪场景（晨起居家/空间鉴赏/黄昏归家/工作阅读/软装陈列等），再确定主色+辅色与光影方案，避免"剧情对了但情绪不对色"
- **禁用色域** — 高饱和荧光色、强霓虹污染、赛博色彩与本风格不兼容

## 二、光影方案体系

- **光影即叙事** — 6 套光影方案对应不同情绪段落，导演规划阶段应在段落层面确定光影基调方向，而非逐镜指定
- **光源角度** — 正给镜头默认窗光侧射（漫射柔和），侧给镜头根据空间与人物关系微调

| 光影方案 | 方案名 | 色调倾向 | 适用情绪 |
|---|---|---|---|
| A | 窗光漫射 | 暖白底 + 均匀柔和光 | 晨起居家、日常空间叙事 |
| B | 午后斜射窗光 | 橡木暖 + 局部暖光 | 空间鉴赏、品味认同、松弛 |
| C | 黄昏归家灯光 | 窗光暖主导 + 冷蓝窗景 | 黄昏归家、温暖治愈、亲密 |
| D | 夜间点光源 | 暖点光源主导 + 暗部保留 | 夜间氛围、静谧夜居、私密 |
| E | 均匀漫射冷光 | 雾灰蓝主调 + 暖色局部 | 工作阅读、专注冷静、过渡段 |
| F | 阴天漫射冷光 | 灰蓝主调 + 暖色局部 | 低潮段、阴郁过渡、留白 |

- **冷暖光分配** — 暖光可全片使用但需分层控制；专注/冷静段落降低暖光占比，避免情绪与光色冲突
- **氛围方向映射** — 每场戏氛围方向应映射到上述光影方案（A-F）的某一方向，确保视觉一致性

## 三、质感方向

- **空间摄影质感** — 建筑杂志级核心：超广角收空间纵深，透视校正移轴保证水平垂直线，窗光平衡曝光融合保留内外细节，材质质感用侧光强调
- **强对比度 + 极致细节** — 作为画面质感锚点。不是低对比小清新，不是重滤镜氛围化，而是可拍可落地的空间纪实感
- **材质真实** — 软装需具备现实可信度：木作纹理、石材颗粒、织物编织、黄铜氧化、玻璃折射都应符合室内实拍逻辑
- **皮肤质感** — 保留真实毛孔与细微瑕疵，控制磨皮强度，追求"真实但好看"
- **写实不等于平淡** — 通过构图、景别、运动节奏放大情绪感染力，而非依赖夸张特效与过度后期

## 四、室内场景空间元素

室内设计世界观特有的场景元素及其视觉叙事功能：

- **窗框/门洞/拱形开口** — 天然框架式构图道具，制造空间分层与内外呼应，窗景即空间情绪延伸
- **沙发/岛台/书架/床** — 空间功能锚点，家具摆放直接映射角色生活状态与心理距离
- **客厅/餐厨/卧室/书房** — 情绪容器：客厅偏日常，餐厨偏烟火，卧室偏私密，书房偏理性
- **光影与时段作为转场** — 晨转午、午转黄昏、黄昏入夜可用于段落情绪缓冲，光影变化即叙事转折
- **空镜叙事为长项** — 本风格以无人空镜叙事见长，光影流动、窗帘飘动、材质质感均可承载情绪，须在规划阶段主动安排空镜过渡与视觉转折，减少对人物动作的依赖
- **转折点用视觉而非解释** — 优先使用画面手段（景别突变、光影切换、空间阻隔）承接情绪转折，减少对白解释负担

## 五、室内乐器与环境音

室内设计世界观下的声音元素约束：

### 乐器选择

- **钢琴** — 日常、温馨、回忆段落核心乐器，最能体现室内生活质感
- **环境电子/极简电子** — 现代空间、理性秩序、留白段落的风格增强器
- **吉他（民谣/古典）** — 轻松、居家、慢节奏松弛段落的有效主导
- **弦乐** — 情绪抬升与情感爆发段落的主力铺底
- **环境音优先级高** — 室内剧中真实环境声是沉浸感关键，配乐不应压过生活音景

### 乐器组合策略

| 情绪阶段 | 乐器组合 |
|---|---|
| 平稳/开场/收尾 | 钢琴独奏 或 极简电子 |
| 日常推进 | 钢琴 + 轻打击 |
| 温暖升温/归家 | 钢琴 + 弦乐 |
| 情绪爆发/冲突 | 弦乐主导 + 低频铺底 |
| 夜景/留白 | 环境电子 + 钢琴泛音 |

### 室内环境音

- **典型环境音层次** — 窗外鸟鸣 / 风穿窗帘声 / 咖啡机声 / 水壶沸声 / 键盘敲击 / 书页翻动 / 灯泡微嗡 / 空调底噪 / 雨打窗声 / 远处车流
- **每场戏标注 1-2 个核心环境音**，帮助后续音效设计。环境音层次越准确，室内空间质感越强
- **留白建议** — 空间叙事应主动安排"纯环境音无配乐"段落，让空间自身发声，强化沉浸感
