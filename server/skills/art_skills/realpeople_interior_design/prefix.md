# 全局美学基础 · 室内设计

---
必须严格、完整遵循下方全部风格约束与全局规则，并严格按提示词模板格式生成提示词；仅输出提示词正文，不得附加任何解释、说明、注释、标题或其他额外文本。
## 一、风格基因

| 维度 | 定义 |
|---|---|
| **一级风格** | 室内设计写实（Interior-Design-Photorealism） |
| **二级风格** | 建筑杂志级空间摄影 · 两点半透视校正 |
| **情感基调** | 品味向 — 满足、品味认同、生活美学 |
| **质感锚词** | 中性高级灰木色、窗光与人造光平衡、透视校正、材质温润 |

## 二、全局色彩盘（风格基线，不是硬锁）

> 目标：统一审美而非限制创作。除「硬约束色」外，其余颜色默认优先使用，可在合理范围内偏移。

### 色彩使用层级

| 层级 | 约束强度 | 说明 |
|---|---|---|
| L1 硬约束 | 高 | 仅锁定角色识别核心：肤色、发色、主服底色的审美方向 |
| L2 软约束 | 中 | 空间色、配饰色、点缀色优先参考色盘，可按镜头与剧情微调 |
| L3 例外机制 | 低 | 节庆/回忆/高潮戏可临时突破局部色彩，但需保留整体冷暖逻辑 |

| 序号 | 色名 | 色值 | 用途 |
|---|---|---|---|
| C1 | 暖白 | #F2EDE6 | 墙面、主服底色、窗帘、床品 |
| C2 | 暖米肤 | #E8D4C0 | 女性/男性肤色基准 |
| C3 | 黄铜金 | #B89B5E | 灯具五金、饰品、把手 |
| C4 | 深棕发 | #3A2E25 | 发色、眼瞳、深木家具 |
| C5 | 橡木色 | #C9A87C | 浅木地板、木家具、木梁 |
| C6 | 高级灰 | #8C8A85 | 沙发、窗帘、墙面灰调 |
| C7 | 窗光暖 | #E8C8A0 | 窗光暖调、台灯光、黄昏室内 |
| C8 | 雾灰蓝 | #7A8590 | 冷调窗帘、冷光、北欧背景 |
| C9 | 中性灰 | #E0E0E0 | 设定图背景 |
| C10 | 哑黑铁 | #2E2E2E | 工业风金属、灯具支架、框架 |

### 硬约束色（默认锁定）

| 色项 | 对应色 | 规则 |
|---|---|---|
| 肤色基准 | C2 暖米肤 | 默认优先，允许小幅明度/暖度微调，室内光下可略偏暖 |
| 发色/瞳色基准 | C4 深棕发 | 默认优先，允许深棕/深褐轻微偏移 |

### 软约束色（推荐优先）

> C1/C3/C5/C6/C7/C8/C10 为推荐色域，用于空间墙面、木作、灯具、软装、窗帘、工业金属等。可根据空间风格与镜头氛围做同色相邻近调整。

### 情绪色盘（导演对齐版）

| 情绪场景 | 主色 | 辅色 | 光效与对比建议 | 画面关键词 |
|---|---|---|---|---|
| 晨起居家（满足） | C1 暖白 | C5 橡木色 + C7 窗光暖 | 窗光漫射，中低对比，空气通透 | 温润、日常、归属 |
| 空间鉴赏（品味） | C5 橡木色 | C3 黄铜金 + C6 高级灰 | 侧光勾勒材质，中对比 | 品味、克制、高级 |
| 黄昏归家（温暖） | C7 窗光暖 | C3 黄铜金 + C1 暖白 | 暖光铺底，灯光氛围渐起 | 温暖、松弛、治愈 |
| 工作阅读（专注） | C6 高级灰 | C8 雾灰蓝 + C1 暖白 | 均匀漫射，冷调克制 | 专注、理性、宁静 |
| 软装陈列（美学） | C3 黄铜金 | C5 橡木色 + C1 暖白 | 局部点光强调质感 | 精致、陈列、美学 |
| 夜间灯光（氛围） | C7 窗光暖 | C10 哑黑铁 + C6 高级灰 | 暖点光源主导，暗部保留 | 氛围、静谧、夜居 |
| 极简留白（空灵） | C1 暖白 | C9 中性灰 + C8 雾灰蓝 | 高调漫射，弱对比 | 留白、空灵、极简 |
| 工业质感（硬朗） | C10 哑黑铁 | C5 橡木色 + C6 高级灰 | 侧光强调金属纹理 | 硬朗、工业、质感 |

### 情绪色盘使用规则

| 编号 | 规则 |
|---|---|
| E1 | 每条提示词至少指定 1 个「情绪场景」并绑定主色+辅色组合 |
| E2 | 单镜头主色不超过 2 个，避免颜色叙事失焦 |
| E3 | 情绪切换时优先调整光比与色温，再调整饱和度 |
| E4 | 室内向默认遵循「中性底 + 暖点」：中性灰木色铺底，暖光落在视觉焦点与材质高光 |
| E5 | 若与剧情冲突，以情绪色盘优先于通用推荐色，但不得突破严禁项 |

### 色温约束

| 参数 | 值 | 说明 |
|---|---|---|
| 整体色温 | 中性偏暖 4800-5500K（推荐） | 窗光与灯光平衡主基调，黄昏可升至 5500-6000K |
| 肤色色温 | 微暖 5000-5400K（推荐） | 室内光下保持暖米肤自然感 |
| 对比度 | 中等（建议保持） | 明暗反差克制，保留暗部层次 |
| 饱和度 | 中低 35-55%（建议区间） | 中性高级色调 |

### 容差与例外

| 项目 | 建议容差 |
|---|---|
| 色相偏移 | ±8° |
| 饱和度偏移 | ±10% |
| 明度偏移 | ±12% |

> 例外场景：夜间灯光、节庆软装、黄昏归家镜头可使用更暖局部色块；但禁止霓虹荧光与人造赛博色彩入镜。

## 三、全局约束规则

### 必守规则（所有技能继承）

| 编号 | 规则 |
|---|---|
| R1 | 必须包含「真人写实摄影」风格锚定词 |
| R2 | 必须声明「透视校正 + 极致细节」 |
| R3 | 面部必须使用「面容细腻渲染 + 皮肤细腻」 |
| R4 | 发丝必须使用「根根分明 + 发丝细腻渲染」 |
| R5 | 纹理必须声明「材质纹理超清晰」 |

### 严禁项（所有技能继承）

| 编号 | 严禁内容 |
|---|---|
| X1 | 严禁「卡通/动漫/二次元/插画风」 |
| X2 | 严禁「高饱和荧光色/霓虹色/赛博色彩」 |
| X3 | 严禁「空间元素缺失」（必须有真实室内空间与软装） |
| X4 | 严禁「面部变形/多指/肢体异常」倾向词 |
| X5 | 严禁「裸体/暴露/透视/暗示性描述」 |
| X6 | 严禁「透视畸变/水平垂直线不校正」 |
