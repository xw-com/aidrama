# 场景图生成 · 室内设计约束手册

---

## 一、场景美学原则

1. **建筑杂志级空间叙事** — 场景是绝对主角，承载空间风格辨识度与软装陈列美学，不是纯背景板
2. **透视严谨** — 所有场景必须遵循两点半透视校正，水平线与垂直线严格校正，杜绝透视畸变
3. **材质质感至上** — 木作/石材/织物/金属/玻璃/藤编等材质纹理必须超清晰
4. **实拍为锚** — 一切画面以真实空间摄影为标准，拒绝 3D 渲染/CG 动画质感；追求镜头光学特征（超广角景深、透视校正移轴、曝光融合、窗光平衡）与物理光照（自然窗光漫射、灯光氛围、焦散投影）

## 五、主视图规范

### 视图定义

> 单画面主视图，从空间中最具代表性的角度拍摄，承载空间叙事与构图重心。

| 项目 | 约束 | 提示词 |
|---|---|---|
| 视角 | 自然观察视角，构图最能体现空间主体与纵深 | hero shot、representative angle、architecture interior |
| 视点高度 | 默认人眼平视高度（1.5-1.6m），特殊空间可俯/仰 | eye level（默认） |
| 构图 | 主体居中或符合三分法，前/中/后景层次清晰 | balanced composition、rule of thirds |

### 两点半透视校正规则

| 项目 | 约束 |
|---|---|
| 透视模式 | 两点半透视（two-point perspective），垂直线严格保持垂直 |
| 校正方式 | 移轴镜头校正（tilt-shift），水平线与垂直线无畸变 |
| 视点 | 人眼平视高度，避免仰视/俯视导致垂直线汇聚 |
| 广角 | 超广角收空间纵深，但透视必须校正无桶形畸变 |

### 窗光规则

| 项目 | 约束 |
|---|---|
| 主光源 | 自然窗光为主，漫射柔和 |
| 平衡 | 窗光与室内灯光氛围平衡，避免窗光过曝或室内过暗 |
| 色温 | 窗光偏冷（5000-5500K），灯光偏暖（2700-3000K），冷暖对比 |
| 光束 | 可见光束粒子穿窗，体积光感 |
| 曝光融合 | HDR 曝光融合平衡高光与暗部，保留窗内外细节 |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 单画面（非拼图、非多视图、非分屏） |
| 人物 | **严禁出现任何人物、人影、人体轮廓** |
| 一致性 | 风格/材质/色调/光线统一 |
| 光线 | 单一光源逻辑，光影方向一致 |
| 画面比例 | 默认 16:9（或按调用方设定） |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 场景必须有「前中后景层次」与「空间纵深感」 |
| R2 | 必须包含「两点半透视校正」与「水平垂直线校正」 |
| R3 | 场景图必须为「单画面主视图」，不得拼接多视图/分屏/网格 |
| R4 | 构图须能代表空间主体并展示前/中/后景层次 |
| R5 | 场景图中**严禁出现任何人物** |
| R6 | 必须包含实拍摄影关键词（real photography / photorealistic / RAW photo） |
| R7 | 必须包含镜头光学特征（ultra-wide angle / tilt-shift correction / exposure fusion / lens vignette 至少一项） |
| R8 | 材质必须带有自然磨损/使用痕迹，禁止全新无瑕的"CG 感" |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 背景纯白/纯黑/无空间风格 |
| X2 | 透视畸变/水平垂直线不校正/桶形畸变 |
| X3 | 场景无纵深/无层次 |
| X4 | 软装/材质与空间风格矛盾 |
| X5 | 出现任何人物、人影、人体剪影或人体轮廓 |
| X6 | 画面被拼接成多视图/网格/分屏布局 |
| X7 | 3D 渲染/CG 动画/卡通/游戏引擎质感（禁用 3D render、CGI、Unreal Engine、Unity 等词） |
| X8 | 材质过于干净完美、无任何使用痕迹与岁月感（避免"塑料感"） |
| X9 | 光照过于均匀平坦、无窗光平衡、无景深虚化、无镜头光学特征 |
