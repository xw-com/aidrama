# 室内设计风格说明

本风格专为"室内设计"题材打造，所有美术提示词、规范和生成内容均严格限定于：

- **空间世界观**：以北欧/日式/工业/美式等真实空间风格为背景，涵盖建筑杂志级室内大片、两点半透视校正与水平垂直线校正、自然窗光与灯光氛围平衡，杜绝空间元素缺失。
- **真人写实** — 所有角色、场景、道具均以真人写实摄影为标准，强调五官、皮肤、发丝、材质等极致细节与真实质感。
- **空间纪行纪实** — 在写实基础上追求建筑杂志级氛围感，画面明暗对比克制，细节丰富，整体氛围中性高级、材质温润、窗光与人造光平衡。
- **品味氛围** — 适合展现满足、品味认同、生活美学的空间故事，强调室内空间下的软装陈列与家居材质表达。

## 适用范围

- 室内设计题材的AI美术生成（角色、场景、道具、分镜等）
- 需要极致写实、建筑杂志级空间摄影、两点半透视校正与窗光平衡氛围的视觉创作

## 严禁内容

- 卡通、动漫、插画、二次元风格
- 空间元素缺失、纯户外无室内空间叙事
- 高饱和荧光色、霓虹色、赛博色彩
- 暗示性、暴露、透视等不适宜内容

## 风格体验

在本风格下，您将体验到：

- 角色面容自然、气质品味或亲和，服饰、妆容、发型均为居家/设计师品味穿搭写实
- 场景空间透视严谨，材质纹理超清晰，氛围真实且富有空间辨识度
- 道具、灯具、餐瓷、织物、装饰摆件等均为家居软装造型，工艺精细，质感极致
- 分镜与视频均以真人写实为基础，强调空间光影叙事与软装陈列表达

---

本风格仅适用于"室内设计"相关项目。如需其他风格（如古风、插画、动漫、都市等），请勿使用本套提示词。
