## 二、全局色彩盘（风格基线，不是硬锁）

> 目标：统一审美而非限制创作。除「硬约束色」外，其余颜色默认优先使用，可在合理范围内偏移。

### 色彩使用层级

| 层级 | 约束强度 | 说明 |
|---|---|---|
| L1 硬约束 | 高 | 仅锁定角色识别核心：肤色、发色、轮廓墨线的审美方向 |
| L2 软约束 | 中 | 场景色、服饰色、纹样色优先参考色盘，可按镜头与剧情微调 |
| L3 例外机制 | 低 | 决战/怪谈/彼岸场景可临时突破局部色彩，但需保留整体套色版画逻辑 |

### 硬约束色（默认锁定）

| 色项 | 对应色 | 规则 |
|---|---|---|
| 肤色基准 | C4 米纸色 | 默认优先，平涂无渐变，允许小幅明度微调 |
| 轮廓墨线基准 | C2 墨黑 | 所有轮廓线必须为墨黑刻线，粗细均匀有力 |

### 软约束色（推荐优先）

> C1/C3/C5/C6/C7/C8/C9 为推荐色域，用于服饰、建筑、海浪、山峦、纹样等。可根据镜头氛围做同色相邻近调整。

### 情绪色盘使用规则

| 编号 | 规则 |
|---|---|
| E1 | 每条提示词至少指定 1 个「情绪场景」并绑定主色+辅色组合 |
| E2 | 单镜头主色不超过 2 个，避免颜色叙事失焦 |
| E3 | 情绪切换时优先调整色块面积与纹样密度，再调整色相 |
| E4 | 浮世向默认遵循「纸底 + 大色块」：米纸色留白铺底，浓色以块面与纹样落位 |
| E5 | 若与剧情冲突，以情绪色盘优先于通用推荐色，但不得突破严禁项 |

### 色温约束

| 参数 | 值 | 说明 |
|---|---|---|
| 整体色温 | 中性偏暖 5000-5500K（推荐） | 矿物颜料的温润版画基调 |
| 肤色色温 | 中性 5200-5600K（推荐） | 米纸色底上的温润肤色 |
| 对比度 | 中等（建议保持） | 色块边界清晰，但无明暗渐变 |
| 饱和度 | 中低 40-60%（建议区间） | 传统套色版画的沉稳色调 |

### 容差与例外

| 项目 | 建议容差 |
|---|---|
| 色相偏移 | ±8° |
| 饱和度偏移 | ±10% |
| 明度偏移 | ±12% |

> 例外场景：祭典、决战、彼岸场景可使用更浓烈或更深沉的局部色块（含晕摺渐变边缘）；但禁止写实明暗光影与荧光现代色彩语言入镜。

## 三、全局约束规则

### 必守规则（所有技能继承）

| 编号 | 规则 |
|---|---|
| R1 | 必须包含「浮世绘木刻版画风格」风格锚定词 |
| R2 | 必须声明「平面色块 + 墨线轮廓」 |
| R3 | 面部必须使用「细墨勾线 + 平涂肤色无渐变」 |
| R4 | 发丝必须使用「墨色块面 + 流畅刻线」 |
| R5 | 空间层次必须声明「以色块层叠与纹样密度表现，无写实光影」 |

### 严禁项（所有技能继承）

| 编号 | 严禁内容 |
|---|---|
| X1 | 严禁「现代日系动画风格/赛璐璐动画/新海诚风格」 |
| X2 | 严禁「3D渲染/CG动画/数字厚涂」 |
| X3 | 严禁「写实明暗光影/素描调子/大面积软渐变」 |
| X4 | 严禁「面部变形/比例失调/肢体异常」倾向词 |
| X5 | 严禁「荧光色/高饱和糖果色/霓虹色」 |
| X6 | 严禁「现代元素/现代建筑/现代服饰」 |
