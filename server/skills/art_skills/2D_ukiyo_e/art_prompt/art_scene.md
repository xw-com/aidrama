# 和风浮世绘风格 - 场景图生成 · 约束手册

---

## 一、场景美学原则

1. **平面叙事** — 场景以平面色块与纹样层次铺陈，承载市井与山水的浮世气息，不是写实空间
2. **无透视纵深** — 不用焦点透视，以前/中/后景的色块层叠与纹样密度表现层次，远处不虚化
3. **纹样至上** — 青海波、麻叶、龟甲、云纹、海浪纹等和风纹样是场景装饰核心
4. **木刻为锚** — 一切画面以江户浮世绘木刻版画为标准，拒绝现代动画/3D/CG/写实光影；追求墨线轮廓、平面色块、套色边界与纸张肌理

## 五、主视图规范

### 视图定义

> 单画面主视图，从场景中最具代表性的平面构图角度呈现，承载纹样叙事与装饰重心。

| 项目 | 约束 | 提示词 |
|---|---|---|
| 视角 | 平面装饰性构图，无焦点透视，主体居中 | flat decorative composition、ukiyo-e landscape |
| 视点高度 | 正面平视，无俯仰透视 | flat front view |
| 构图 | 主体居中或对称，前/中/后景以色块层叠 | balanced flat composition |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 单画面（非拼图、非多视图、非分屏） |
| 人物 | **严禁出现任何人物、人影、人体轮廓** |
| 一致性 | 风格/材质/色调/纹样统一 |
| 光线 | 无写实光影，平面色块铺陈 |
| 画面比例 | 默认 16:9（或按调用方设定） |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 场景必须有「前中后景色块层叠」 |
| R2 | 远景必须以色块与纹样层叠表现，**严禁空气透视虚化** |
| R3 | 场景图必须为「单画面主视图」，不得拼接多视图/分屏/网格 |
| R4 | 构图须为平面装饰性，主体居中并展示前/中/后景色块层次 |
| R5 | 场景图中**严禁出现任何人物** |
| R6 | 必须包含浮世绘关键词（ukiyo-e / woodblock print / 墨线轮廓 / 平面色块） |
| R7 | 必须包含至少 1 种和风纹样（青海波/麻叶/龟甲/云纹/海浪纹） |
| R8 | 材质必须带有木刻肌理与纸张肌理，禁止 CG 干净质感 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 背景纯白/纯黑/无场景 |
| X2 | 极端天候（暴风雨/雷电，除非剧情需要） |
| X3 | 焦点透视、空气透视虚化、写实空间纵深 |
| X4 | 植被/天候与季节矛盾 |
| X5 | 出现任何人物、人影、人体剪影 |
| X6 | 画面被拼接成多视图/网格/分屏布局 |
| X7 | 现代日系动画/3D渲染/CG/写实明暗光影 |
| X8 | 荧光色、高饱和糖果色、霓虹色 |
| X9 | 光照过于写实、有明暗渐变与软阴影 |
