# 和风浮世绘风格 - 人物基础形象生成 · 约束手册

---

## 一、基础形象原则

1. **墨线即骨架** — 所有形体以墨黑刻线勾勒，线条流畅有力、粗细均匀，无数字化锐利边缘
2. **角色为本** — 基础着装由角色描述（身份/职业/性别/场景）决定其江户样式常规着装；后续特定服化为叠加层
3. **四视图一致** — 面容/体型/发型/基础服装跨视图高度统一
4. **平面无透视** — 形体以正面或纯侧面平铺呈现，无写实透视与明暗调子，符合木刻版画平面装饰美学

---

## 二、面容约束

> 不再固定五官特征参数，由角色描述（性别/年龄/性格/气质）驱动 AI 自由生成五官，保证人物间外观差异化。

### 通用要求

| 项目 | 约束 |
|---|---|
| 五官 | 由角色描述自然推导，不预设脸型/眼型/眉型/鼻型/唇型 |
| 风格底色 | 江户浮世绘木刻版画质感（墨线勾轮廓、平面色块、套色边界、纸张肌理） |
| 气质 | 必须从角色描述提炼整体气质关键词（如净雅/凛然/市井/武勇），并写入提示词 |
| 表情 | 中性微表情，符合角色气质，含蓄克制 |
| 勾线 | 面部以细墨勾线，平涂肤色无渐变，眼/眉/唇以墨线定型 |

## 六、基础服装约束

> 基础服装由角色描述（身份/职业/性别/场景）决定其最自然的江户样式常规着装，作为该角色「日常默认态」；正式服饰/特殊衍生在服化衍生环节叠加。**禁止内衣打底**。

### 着装选择原则

| 角色身份 | 默认着装方向 |
|---|---|
| 町人/市井女子 | 江户小袖 + 腰带 |
| 武士/侍 | 纹付羽织袴 / 小袖带刀 |
| 商人/职人 | 灰色绀屋法被 + 撥拌 |
| 游女/茶屋 | 打挂/打掛小袖 + 华丽腰带 |
| 旅人/行商 | 旅装束 + 编笠 |
| 角色描述未明确 | 江户日常小袖常服 |

### 着装统一规则

- 服装风格须与浮世绘木刻版画美学一致（平面色块、墨线勾边、套色边界）
- 色彩以色盘推荐色域为主（C1/C3/C5/C6/C7/C8/C9），纹样可叠加青海波/麻叶/龟甲等和风纹样
- 四视图服装款式完全一致
- 基础服装是「日常默认态」，焦点仍在面容与体态
- 严禁内衣/暴露/性化打底

## 八、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须为「素颜无妆」状态 |
| R2 | 必须根据角色描述声明合适的江户样式常规着装作为基础服装（如町人女子→江户小袖、武士→纹付羽织袴、旅人→旅装束）；禁止内衣打底 |
| R3 | 必须声明「无发饰、无配饰」 |
| R4 | 必须指定「米纸色背景 #EFE6CE」 |
| R5 | 必须指定「四视图一致性」 |
| R6 | 全身立像必须从头到脚完整展示，严禁裁切 |
| R7 | 必须指定角色身高并通过头身比换算约束全身比例（女性默认150-160cm/6-7头身，男性默认165-175cm/6.5-7.5头身） |
| R8 | 人像特写必须从头顶到锁骨完整展示，严禁裁切头顶 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 内衣/暴露/性化打底；与角色描述明显不符的着装；过度复杂花纹干扰后续服化叠加 |
| X2 | 现代日系动画风格、3D渲染、CG动画、数字厚涂 |
| X3 | 写实明暗光影、素描调子、大面积软渐变晕染 |
| X4 | 复杂场景背景（必须米纸色背景） |
| X5 | 夸张表情/动态姿势、荧光色、高饱和糖果色 |
| X6 | 全身立像裁切头顶或脚底，必须从头到脚完整入画 |
| X7 | 人像特写裁切头顶，必须从头顶到锁骨完整入画 |
| X8 | 忽略身高和头身比约束 |
