# 和风浮世绘风格 - 道具图像生成 · 约束手册

---

## 一、道具设计原则

1. **功能可读** — 道具用途一目了然，造型服务于功能
2. **木刻质感** — 材质纹理以墨线勾边与平面色块表现，套色边界分明
3. **江户风格** — 所有道具符合江户浮世绘世界观，风格统一
4. **尺度明确** — 通过参照物或画面比例暗示道具真实尺寸
5. **纯道具独立展示** — 画面中只能出现道具本身，严禁出现任何人物、手部、肢体，道具不可处于被持有/佩戴/握持状态，必须以静物陈列方式独立呈现

## 三、多角度设定图规范

### 视图定义

| 位置 | 视图 | 角度 | 要求 | 提示词 |
|---|---|---|---|---|
| 左上 | 正面图 | 正面 0° | 道具完整正面形态 | front view |
| 右上 | 侧面图 | 侧面 90° | 厚度/轮廓/结构清晰 | side view |
| 左下 | 背面图 | 背面 180° | 道具背部结构/装饰 | back view |
| 右下 | 细节特写 | 局部放大 | 材质纹理/工艺细节 | detail closeup |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 同一画面四宫格（2×2），上下左右四视角 |
| 背景 | 米纸色 #EFE6CE |
| 光线 | 无写实光影，平面色块，无硬阴影 |
| 比例 | 每格道具占格内主体 70%+ |
| 投影 | 无写实投影，允许平面色块暗示落位 |
| 画面比例 | 建议 1:1 |

## 四、材质渲染约束

| 材质 | 渲染要求 | 提示词 |
|---|---|---|
| 钢/金属 | 平面色块、墨线勾边、无写实反光 | 钢质色块、墨线勾边 |
| 漆器 | 平涂深色块面、莳绘纹样 | 漆器平涂、莳绘纹样 |
| 木 | 纹理以刻线表现、平面色块 | 木纹刻线、平面色块 |
| 陶瓷 | 平涂色块、套色边界 | 陶瓷色块、套色边界 |
| 纸/绢 | 纤维肌理、边缘墨线 | 纸质肌理、墨线边缘 |
| 珊瑚/贝 | 平面色块、无透明折射 | 珊瑚色块、贝质平涂 |

## 六、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须指定「米纸色背景 #EFE6CE」 |
| R2 | 必须明确道具材质与工艺 |
| R3 | 道具造型必须符合江户浮世绘世界观风格 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 复杂场景背景 |
| X2 | 道具与人物同画面 |
| X3 | 出现任何人物形象 |
| X4 | 道具处于被持有、握持、佩戴、使用中的状态 |
| X5 | 出现暗示人物存在的元素 |
| X6 | 写实明暗光影、写实金属反光、3D渲染质感 |
