# 和风浮世绘风格说明

本风格专为"浮世绘木刻版画质感"题材打造，所有美术提示词、规范和生成内容均严格限定于：

- **江户浮世绘世界观**：以江户时代日本为背景，涵盖城下町街道、神社寺域、桥川港津、宿场驿站、茶屋座敷等，体现江户市井与山水的浮世气息。
- **木刻版画质感**：所有角色、场景、道具均以浮世绘木刻版画为标准，强调墨线轮廓、平面色块、套色边界与纸张肌理。
- **平面装饰美学**：在无透视的装饰性构图上追求纹样的秩序之美，海浪云纹、青海波、麻叶纹等和风纹样装点画面，整体氛围雅致、静穆、有余韵。
- **情感表达**：适合展现物哀、无常、市井悲欢与山水壮阔的故事，强调东方版画美学下的含蓄情感表达。

## 适用范围

- 和风浮世绘题材的AI美术生成（角色、场景、道具、分镜等）
- 需要极致木刻质感、平面色块构图、和风纹样韵味的视觉创作

## 严禁内容

- 现代日系动画风格、3D渲染、CG动画
- 现代元素、现代建筑、现代服饰
- 写实明暗光影、素描调子、软渐变晕染
- 荧光色、高饱和糖果色、霓虹色

## 风格体验

在本风格下，您将体验到：

- 角色面容以细墨勾线、平涂肤色呈现，气质净雅或凛然，发型服饰均为江户样式
- 场景以平面色块与纹样层次铺陈，构图装饰性强，无透视却有深远的余韵
- 道具、刀剑、簪栉、茶器、灯笼均为江户造型，木漆竹纸质感分明
- 分镜与画面均以木刻版画为基础，强调纹样叙事与留白的诗意

---

本风格仅适用于"和风浮世绘"相关项目。如需其他风格（如现代动画、CG、油画、极简插画等），请勿使用本套提示词。
