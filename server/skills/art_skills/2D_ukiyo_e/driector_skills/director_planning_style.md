# 和风浮世绘约束 · 和风浮世绘 · 技法参考

---

## 一、色调体系与画面基调

- **纸底色块基底** — 全片以米纸色（C4）铺底，墨黑（C2）勾轮廓，整体呈现江户浮世绘木刻套色版画的沉稳温润基调。遵循「米纸留白铺底，浓色以块面与纹样落位」
- **平面色块叙事** — 色块的面积与并置是本风格核心视觉语言，色块边界即叙事分割，而非写实光影塑造
- **情绪先行原则** — 段落规划需先绑定情绪场景（市井/祭典/恋慕/离别/壮阔/幽玄等），再确定主色+辅色与纹样密度，避免「情绪对但色块不对」
- **禁用写实光影** — 任何明暗渐变、软阴影、空气透视虚化、写实金属反光均与本风格不兼容

---

## 二、色块光影方案体系

- **色块即氛围** — 6 套色块方案对应不同叙事段落，导演规划阶段应在段落层面确定色块基调方向，而非逐镜指定
- **无光源逻辑** — 不区分光源角度与冷暖，以色块面积与纹样密度区分段落氛围

| 情绪段落 | 色块方向 | 主辅色 | 适用阶段 |
|---|---|---|---|
| 市井/日常 | A·米纸暖底平铺 | C5 赭石 + C4 米纸 + C8 青苔绿 | 铺垫段 |
| 恋慕/含蓄 | B·大面积留白点睛 | C3 胭脂红 + C4 米纸 + C7 山吹黄 | 升温段 |
| 祭典/热闹 | C·纹样密布红黑 | C3 胭脂红 + C7 山吹黄 + C2 墨黑 | 高潮段 |
| 离别/漂泊 | D·冷色铺陈拉远 | C9 鸦青 + C1 贝罗蓝 + C4 米纸 | 低谷段 |
| 武勇/决意 | E·硬朗色块对比 | C3 胭脂红 + C2 墨黑 + C7 山吹黄 | 对峙段 |
| 幽玄/无常 | F·墨色分层晕缘 | C2 墨黑 + C10 藤紫 + C7 山吹黄 | 超脱段 |

- **色块分配** — 米纸色底贯穿全片，浓色（胭脂/墨黑/贝罗蓝）作为情绪焦点点缀；纹样密度随情绪升温而加密
- **氛围方向映射** — 每场戏的氛围方向应能映射到上述方案（A-F）的某一方向，确保视觉一致性

---

## 三、质感方向

- **木刻套色质感** — 和风浮世绘的核心：可见墨线轮廓、平面色块、套色边界错位、纸张纤维肌理
- **纹样秩序之美** — 青海波、麻叶、龟甲、云纹、海浪纹等和风纹样以秩序化重复装点画面
- **轮廓墨线分离** — 人物与景物须以墨黑刻线从色块底中分离，线条流畅有力、粗细均匀
- **非写实非洁净** — 场景带木瓦肌理、纸张纤维、套色错位痕迹；人物锚定江户样式，禁止现代元素

## 四、场景空间元素

和风浮世绘特有的场景元素及其视觉叙事功能：

- **富士山与海浪** — 浮世绘标志性图式，景即情：富士静穆 = 崇高、神奈川冲浪 = 自然伟力、远山鸦青 = 苍凉行旅
- **城下町街道/店屋连檐** — 市井烟火载体，看板暖帘纹样化、连檐木色块面 = 繁盛生趣
- **鸟居/神社/石阶灯笼** — 朱红鸟居平面色块 = 神域边界、石阶灯笼 = 清寂禅意
- **桥川港津/舟船** — 行旅流动符号，拱桥舟船剪影 = 离别漂泊、水面云纹倒影 = 流转无常
- **障子屏风/榻榻米/灯笼** — 室内装饰载体，屏风纹样 = 雅致、灯笼暖块 = 祭典夜晚
- **段落间用场景空镜过渡** — 本风格有丰富的场景图式（不同季节/天候/室内外变体），段落衔接建议用场景空镜做情绪缓冲（如月夜名所→雪中行旅），不要硬切
- **转折点用色块而非台词** — 优先使用色块突变（暖底→冷色）、纹样密度变化、景别跳切而非依赖对白解释

## 五、配乐与环境音

和风浮世绘世界观下的声音元素约束：

### 乐器选择

- **三味线** — 核心：江户市井与游廓的标志音色，撥音清利
- **尺八** — 幽玄/禅意段落的标志音色，气息苍远
- **筝** — 雅致/恋慕段落的铺底音色，弦音清润
- **太鼓/缔太鼓** — 祭典/武勇段落的节奏色彩（祭典用热闹，武勇用沉稳）

### 乐器组合策略

| 情绪阶段 | 乐器组合 |
|---|---|
| 市井/日常 | 三味线 + 筝 |
| 恋慕/含蓄 | 筝独奏 + 尺八点缀 |
| 祭典/热闹 | 太鼓 + 三味线 + 笛 |
| 离别/漂泊 | 尺八 + 筝 |
| 武勇/决意 | 缔太鼓 + 尺八 |
| 幽玄/无常 | 尺八独奏 |

### 典型环境音

- **街道环境音** — 叫卖声/木屐叩石板/暖帘拂动/风铃声
- **室内环境音** — 障子拉合/茶器轻碰/炭火噼啪/榻榻米足音
- **自然环境音** — 水面桨声/松风/雨打瓦当/雪落无声
- **每场戏标注 1-2 个核心环境音**，帮助后续音效设计
- **留白即余韵** — 关键瞬间（离别沉默、物哀定格、决意前夜）优先去掉配乐只留环境音（风声、水声、木屐），寂静比满配更契合物哀
- **避免满配** — 全片配乐覆盖率建议不超过 45%。留白段落的「无声」与配乐段落形成呼吸感，突出雅致余韵
