# 婚纱摄影风格说明

本风格专为"婚纱摄影"题材打造，所有美术提示词、规范和生成内容均严格限定于：

- **唯美婚照质感**：以真人婚纱摄影为标准，白纱花艺与暖金柔光交织，画面通透唯美、幸福感拉满。
- **新人双人叙事**：默认新娘+新郎双人互动构图，誓言、对望、牵手、回眸等仪式化瞬间为核心镜头语言。
- **经典婚照场景**：涵盖教堂婚礼堂、草坪花园、海边沙滩、宴会厅、化妆间、酒店套房、室内棚景等婚纱摄影典型空间。
- **浪漫光影氛围**：逆光丁达尔光束、黄金时刻暖金氛围、通透水光妆容，追求影视级浪漫纪实质感。

## 适用范围

- 婚纱摄影题材的AI美术生成（角色、场景、道具、分镜等）
- 需要极致唯美、柔光浪漫、仪式感强烈的视觉创作

## 严禁内容

- 卡通、动漫、插画、二次元风格
- 高饱和荧光色、霓虹色、冷硬新闻纪实感
- 暗黑系、哥特风、恐怖婚服元素
- 暗示性、暴露、透视等不适宜内容（婚纱露出设计须优雅得体）

## 风格体验

在本风格下，您将体验到：

- 新娘面容精致、通透水光妆容，新郎挺拔绅士，纱质缎面与珠绣细节极致
- 场景花艺饱满、光束柔和，逆光丁达尔与暖金氛围交织，仪式感浓郁
- 头纱、捧花、婚戒、喜帖等道具工艺精细，质感唯美
- 分镜与视频以新人互动为核心，幸福感与浪漫氛围贯穿始终

---

本风格仅适用于"婚纱摄影"相关项目。如需其他风格（如古风、插画、动漫、现代等），请勿使用本套提示词。
