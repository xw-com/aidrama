# 人物基础形象生成 · 婚纱摄影约束手册

---

## 一、基础形象原则

1. **面容即灵魂** — 五官是角色唯一锚点，毛孔级精细渲染，柔光下依然清晰立体
2. **角色为本** — 新娘婚纱/新郎西装为默认主造型，伴娘伴郎等其余身份由角色描述（身份/关系/场景）决定；后续特定服化为叠加层
3. **四视图一致** — 面容/体型/发型/礼服跨视图高度统一
4. **唯美实拍** — 以真实婚纱摄影为锚点，柔光下保留皮肤通透水光质感（毛孔/微光泽）

---

## 二、面容约束

> 不再固定五官特征参数，由角色描述（性别/年龄/性格/气质）驱动 AI 自由生成五官，保证人物间外观差异化。

### 通用要求

| 项目 | 约束 |
|---|---|
| 五官 | 由角色描述自然推导，不预设脸型/眼型/眉型/鼻型/唇型 |
| 风格底色 | 真人婚纱摄影、毛孔级精细渲染、唯美柔光、自然光影 |
| 气质 | 必须从角色描述提炼整体气质关键词（如温婉/明媚/端庄/绅士），并写入提示词 |
| 表情 | 幸福微表情：嘴角轻扬、眼底笑意，符合角色气质 |

## 六、基础服装约束

> 基础服装默认为婚纱礼服体系（新娘婚纱+新郎西装），作为该角色「婚照默认态」；晚礼服/便装等特殊衍生在服化衍生环节叠加。**禁止内衣打底**。

### 着装选择原则

| 角色身份 | 默认着装方向 |
|---|---|
| 新娘 | 婚纱礼服（A 字裙/鱼尾裙/蓬蓬裙/缎面拖尾） |
| 新郎 | 西装礼服（深色套西/浅色礼服/马甲三件套） |
| 伴娘 | 伴娘纱裙（樱花粉/鼠尾草绿低饱和） |
| 伴郎 | 伴郎西装（同新郎色系、细节简化） |
| 花童 | 花童小纱裙 / 小西装 |
| 角色描述未明确 | 新娘婚纱 + 新郎西装默认双人礼服 |

### 着装统一规则

- 婚纱须体现纱质层次、缎面光泽、蕾丝刺绣与珠绣细节，工艺写实可信
- 西装须挺括合身、驳头平伏、面料哑光或微光泽，剪裁绅士
- 颜色以象牙白/香槟金/深灰蓝等低饱和色为主，无喧宾夺主的复杂印花
- 四视图服装款式完全一致，裙摆与拖尾形态一致
- 基础服装是「婚照默认态」，焦点仍在面容与幸福感
- 严禁内衣/暴露/性化打底

## 八、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须为「幸福微表情」（嘴角轻扬、眼底笑意）|
| R2 | 新娘默认「婚纱礼服+仪式盘发」、新郎默认「西装礼服」，其余身份按角色描述匹配对应礼服；禁止内衣打底 |
| R3 | 必须声明「无额外发饰」（头纱在服化衍生环节叠加） |
| R4 | 必须指定「纯净暖灰白背景」 |
| R5 | 必须指定「四视图一致性」 |
| R6 | 全身立像必须从头顶到脚底连同裙摆拖尾完整展示，严禁裁切 |
| R7 | 必须声明角色身高并通过头身比换算约束全身比例 |
| R8 | 人像特写必须从头顶到锁骨完整展示，严禁裁切头顶 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 内衣/暴露/性化打底；与角色描述明显不符的着装；喧宾夺主的复杂印花装饰 |
| X2 | 正顶硬光/正底光/彩色光 |
| X3 | 过度美白/过度磨皮至无质感（须保留通透水光肌） |
| X4 | 复杂场景背景（必须纯暖灰白底） |
| X5 | 哭崩/愤怒等破坏唯美氛围的夸张表情与动态姿势 |
| X6 | 全身立像裁切头顶、脚底或裙摆拖尾，必须完整入画 |
| X7 | 人像特写裁切头顶，必须从头顶到锁骨完整入画 |
| X8 | 忽略身高和头身比约束 |
