# 场景图生成 · 婚纱摄影约束手册

---

## 一、场景美学原则

1. **空间叙事** — 场景承载仪式感与浪漫叙事功能，不是纯背景板
2. **层次纵深** — 所有场景必须具备前/中/后景，柔光浅景深虚化背景突出主体氛围
3. **质感至上** — 花艺/纱幔/光束/建筑等材质表现必须清晰唯美
4. **婚照为锚** — 一切画面以真人婚纱摄影为标准，拒绝卡通/动漫/插画/3D/CG；追求毛孔级实拍质感（柔光、通透水光、暖金浪漫光影）

## 三、室内场景

### 空间规范

| 维度 | 约束 | 提示词 |
|---|---|---|
| 风格 | 婚礼堂/宴会厅/化妆间/酒店套房/室内棚景 | {风格}风格、婚纱摄影场景 |
| 材质 | 纱幔/花艺/木质/水晶/金属为主 | 纱幔、花艺、水晶吊灯 |
| 色调 | 暖柔底色 + 香槟金点缀 | 暖灰白底、香槟金点缀 |
| 纵深 | 前/中/后景层次，背景柔焦虚化 | 前景{元素}、中景{元素}、后景虚化 |
| 质感 | 纱质通透、花艺饱满、光束柔和 | 纱质通透、花艺饱满 |
| 光照 | 柔光+丁达尔光束+暖金氛围 | 柔光、丁达尔光束、暖金氛围 |
| 瑕疵感 | 场景整洁唯美，可有自然花影光斑 | 花影光斑、自然氛围 |

### 室内类型速查

| 类型 | 核心元素 | 氛围词 |
|---|---|---|
| 教堂婚礼堂 | 长椅/彩窗/圣坛/拱门 | 神圣、肃穆、见证 |

| 化妆间 | 梳妆台/镜光/头纱 | 期待、纯净、仪式序曲 |
| 酒店套房 | 大床/纱幔/落地窗 | 私密、唯美、柔光 |
| 室内棚景 | 纯色背景/花墙/纱幔 | 干净、聚焦、唯美 |

## 五、主视图规范

### 视图定义

> 单画面主视图，从场景中最具代表性的角度拍摄，承载空间叙事与构图重心。

| 项目 | 约束 | 提示词 |
|---|---|---|
| 视角 | 自然观察视角，构图最能体现场景主体与纵深 | hero shot、representative angle |
| 视点高度 | 默认人眼平视高度，特殊场景可俯/仰 | eye level（默认） |
| 构图 | 主体居中或符合三分法，前/中/后景层次清晰 | balanced composition |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 单画面（非拼图、非多视图、非分屏） |
| 人物 | **严禁出现任何人物、人影、人体轮廓** |
| 一致性 | 风格/材质/色调/光线统一 |
| 光线 | 单一光源逻辑，光影方向一致，柔光唯美 |
| 画面比例 | 默认 16:9（或按调用方设定） |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 场景必须有「前中后景层次」 |
| R2 | 室外必须包含「空气透视」与背景柔焦虚化 |
| R3 | 场景图必须为「单画面主视图」，不得拼接多视图/分屏/网格 |
| R4 | 构图须能代表场景主体并展示前/中/后景层次 |
| R5 | 场景图中**严禁出现任何人物** |
| R6 | 必须包含婚纱摄影关键词（bridal photorealism / 柔光唯美 / 暖金浪漫） |
| R7 | 必须包含柔光特征（丁达尔光束/暖金氛围/通透水光 至少一项） |
| R8 | 材质须有纱质通透与花艺饱满的纹理细节，禁止 CG 干净质感 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 背景纯白/纯黑/无场景 |
| X2 | 极端天候（暴风雨/雷电，除非剧情需要） |
| X3 | 场景无纵深/无层次 |
| X4 | 植被/天候与季节矛盾 |
| X5 | 出现任何人物、人影、人体剪影 |
| X6 | 画面被拼接成多视图/网格/分屏布局 |
| X7 | 卡通/动漫/插画/二次元/3D渲染/CG 风格质感 |
| X8 | 高饱和荧光色、霓虹色、冷硬新闻纪实感 |
| X9 | 光照过硬/过平，无柔光唯美氛围 |
