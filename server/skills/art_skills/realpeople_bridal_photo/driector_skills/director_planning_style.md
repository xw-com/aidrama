# 婚纱摄影约束 · 婚纱摄影 · 技法参考

---

## 一、色调体系与画面基调

- **暖柔金调基底** — 全片以暖灰白（C9）铺底，象牙白（C1）纱质为主，香槟金（C5）/暮金琥珀（C7）作为暖金焦点，整体呈现真人婚纱摄影的唯美浪漫基调。遵循「柔底 + 金点」：柔和底色铺陈，暖金落在新人互动焦点
- **柔光唯美叙事** — 柔光与暖金是本风格核心视觉语言，光束与高光即幸福感的视觉信号，而非随意打光
- **情绪先行原则** — 段落规划需先绑定情绪场景（备婚/心动/誓言/戒指/嬉戏/暮色等），再确定主色+辅色与光影方案，避免「情绪对但影调不对」
- **禁用冷硬纪实** — 任何冷硬新闻纪实、高饱和荧光、霓虹、暗黑哥特均与本风格不兼容

---

## 二、光影方案体系

- **柔光即幸福** — 6 套光影方案对应不同叙事段落，导演规划阶段应在段落层面确定光影基调方向，而非逐镜指定
- **光源逻辑** — 默认柔光主光 + 轮廓金边，逆光段落用丁达尔光束与暖金逆光

| 情绪段落 | 光影方向 | 色调倾向 | 适用阶段 |
|---|---|---|---|
| 备婚/期待 | A·侧柔窗光 | 暖灰白 + 香槟金 + 樱花粉 | 铺垫段 |
| 心动/First Look | B·逆光轮廓+面部柔光 | 象牙白 + 暮金琥珀 + 樱花粉 | 升温段 |
| 誓言/庄重 | C·侧柔主光+轮廓金边 | 香槟金 + 象牙白 + 暖灰白 | 仪式段 |
| 戒指/高光 | D·局部高光聚焦手部 | 暮金琥珀 + 香槟金 + 象牙白 | 高潮段 |
| 嬉戏/雀跃 | E·自然日光+花瓣逆光 | 鼠尾草绿 + 象牙白 + 樱花粉 | 欢腾段 |
| 暮色/隽永 | F·黄金时刻逆光 | 暮金琥珀 + 天青蓝 + 象牙白 | 收束段 |

- **明暗分配** — 暖柔底色贯穿全片，暖金高光作为情绪焦点点缀；戒指高光（D）仅在交换戒指等高潮瞬间聚焦使用
- **氛围方向映射** — 每场戏的氛围方向应能映射到上述光影方案（A-F）的某一方向，确保视觉一致性

## 三、质感方向

- **毛孔级实拍质感** — 婚纱摄影的核心：面容细腻渲染、通透水光肌、发丝根根分明、皮肤毛孔微可见
- **纱缎纹理极致** — 纱质通透层次、缎面微光泽、蕾丝刺绣立体、珠绣细节清晰
- **花艺饱满通透** — 花瓣通透、叶材层次分明、花艺饱满自然
- **非洁净柔美** — 场景带光斑、花瓣飞舞、海风扬纱等自然氛围；人物锚定婚纱礼服，禁止现代休闲喧宾夺主

---

## 四、场景空间元素

婚纱摄影特有的场景元素及其视觉叙事功能：

- **花艺拱门/花墙** — 仪式感载体，景即情：拱门 framing = 见证、花墙背景 = 唯美聚焦、花瓣飞舞 = 雀跃
- **教堂彩窗/圣坛** — 神圣庄重载体，彩窗光束丁达尔 = 神圣见证、圣坛 = 仪式核心
- **海边/沙滩/海风** — 浪漫静谧载体，海面天青蓝 = 辽阔、海风扬纱 = 流动浪漫、暮色逆光 = 隽永
- **纱幔/水晶灯/落地窗** — 室内柔光载体，纱幔漫射 = 柔美、水晶灯暖光 = 华丽、落地窗柔光 = 唯美
- **草坪/树阵/庄园** — 自然典雅载体，草坪鼠尾草绿 = 轻盈、树阵 = 典雅、庄园城堡 = 童话华贵
- **段落间用场景空镜过渡** — 本风格有丰富的场景资产（不同时段/室内外/季节变体），段落衔接建议用场景空镜做情绪缓冲（如教堂彩窗→海边暮色），不要硬切
- **转折点用光影而非台词** — 优先使用画面手段（光影突变/景别跳切/逆光转场）而非依赖对白解释

## 五、配乐与环境音

婚纱摄影世界观下的声音元素约束：

### 乐器选择

- **钢琴** — 核心：独奏钢琴铺底，温柔浪漫的主色调
- **弦乐四重奏** — 仪式/誓言段落的庄重底色，弦音深情
- **竖琴** — 神圣/梦幻段落的点缀色彩，琶音晶莹
- **原声吉他/木吉他** — 户外/嬉戏段落的轻盈色彩（克制使用）

### 乐器组合策略

| 情绪阶段 | 乐器组合 |
|---|---|
| 备婚/期待 | 钢琴 + 竖琴点缀 |
| 心动/First Look | 钢琴独奏 + 弦乐渐入 |
| 誓言/庄重 | 弦乐四重奏 + 钢琴 |
| 戒指/高光 | 竖琴 + 钢琴高音区 |
| 嬉戏/雀跃 | 原声吉他 + 钢琴 |
| 暮色/隽永 | 弦乐 + 钢琴收束 |

### 典型环境音

- **室外环境音** — 海浪轻拍/海风拂纱/鸟鸣/花瓣落地/草坪足音
- **室内环境音** — 纱幔轻拂/水晶灯微响/镜光环境/烛火噼啪
- **教堂环境音** — 彩窗风声/空旷回响/管风琴余韵
- **每场戏标注 1-2 个核心环境音**，帮助后续音效设计
- **留白即深情** — 关键瞬间（誓言沉默、回眸定格、交换戒指）优先去掉配乐只留环境音（海风、呼吸、纱幔声），寂静比满配更动人
- **避免满配** — 全片配乐覆盖率建议不超过 50%。留白段落的「无声」与配乐段落形成呼吸感，突出幸福浪漫
