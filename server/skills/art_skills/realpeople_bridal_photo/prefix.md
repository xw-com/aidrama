## 一、风格基因

| 维度 | 定义 |
|---|---|
| **一级风格** | 真人婚纱摄影（Bridal-Photorealism） |
| **二级风格** | 唯美婚照摄影 · 影视级浪漫质感 |
| **情感基调** | 幸福向 — 甜蜜绽放、仪式庄重 |
| **质感锚词** | 柔光唯美、通透水光、暖金浪漫 |

## 二、全局色彩盘（风格基线，不是硬锁）

> 目标：统一审美而非限制创作。除「硬约束色」外，其余颜色默认优先使用，可在合理范围内偏移。

### 色彩使用层级

| 层级 | 约束强度 | 说明 |
|---|---|---|
| L1 硬约束 | 高 | 仅锁定角色识别核心：肤色、发色、主纱/西装底色的审美方向 |
| L2 软约束 | 中 | 场景色、花艺色、点缀色优先参考色盘，可按镜头与剧情微调 |
| L3 例外机制 | 低 | 晚宴/回忆/高潮戏可临时突破局部色彩，但需保留整体暖柔逻辑 |

### 硬约束色（默认锁定）

| 色项 | 对应色 | 规则 |
|---|---|---|
| 肤色基准 | C2 暖瓷肤 | 默认优先，允许小幅明度/暖度微调 |
| 发色/瞳色基准 | C4 栗棕发 | 默认优先，允许栗棕/深褐轻微偏移 |

### 软约束色（推荐优先）

> C1/C3/C5/C6/C7/C8/C9/C10 为推荐色域，用于婚纱礼服、花艺装饰、场景背景、暖金光效、天空海面、木质家具等。可根据镜头氛围做同色相邻近调整。

### 情绪色盘使用规则

| 编号 | 规则 |
|---|---|
| E1 | 每条提示词至少指定 1 个「情绪场景」并绑定主色+辅色组合 |
| E2 | 单镜头主色不超过 2 个，避免颜色叙事失焦 |
| E3 | 情绪切换时优先调整光比与色温，再调整饱和度 |
| E4 | 幸福向默认遵循「柔底 + 金点」：柔和底色铺陈，暖金落在新人互动焦点 |
| E5 | 若与剧情冲突，以情绪色盘优先于通用推荐色，但不得突破严禁项 |

### 色温约束

| 参数 | 值 | 说明 |
|---|---|---|
| 整体色温 | 偏暖 4800-5500K（推荐） | 唯美浪漫主基调 |
| 肤色色温 | 微暖 4800-5300K（推荐） | 通透水光但有生命感 |
| 对比度 | 柔和中等（建议保持） | 明暗过渡圆润，高光柔美 |
| 饱和度 | 中低 35-55%（建议区间） | 高级唯美色调 |

### 容差与例外

| 项目 | 建议容差 |
|---|---|
| 色相偏移 | ±8° |
| 饱和度偏移 | ±10% |
| 明度偏移 | ±12% |

> 例外场景：晚宴派对、暮色逆光、情绪高潮镜头可使用更暖金或高光溢出的局部色块；但禁止霓虹荧光与冷硬纪实色彩语言入镜。

## 三、全局约束规则

### 必守规则（所有技能继承）

| 编号 | 规则 |
|---|---|
| R1 | 必须包含「真人婚纱摄影」风格锚定词 |
| R2 | 必须声明「柔光唯美 + 极致细节」 |
| R3 | 面部必须使用「面容细腻渲染 + 通透水光肌」 |
| R4 | 发丝必须使用「根根分明 + 发丝细腻渲染」 |
| R5 | 纱质与花艺纹理必须声明「纹理细节超清晰」 |

### 严禁项（所有技能继承）

| 编号 | 严禁内容 |
|---|---|
| X1 | 严禁「卡通/动漫/二次元/插画风」 |
| X2 | 严禁「高饱和荧光色/霓虹色」 |
| X3 | 严禁「冷硬新闻纪实风」（必须明确唯美婚照氛围） |
| X4 | 严禁「面部变形/多指/肢体异常」倾向词 |
| X5 | 严禁「裸体/暴露/透视/暗示性描述」（婚纱露出设计须优雅得体） |
| X6 | 严禁「暗黑系/哥特/恐怖婚服元素」 |
