# 热血战斗风格 - 人物基础形象生成 · 约束手册

---

## 一、基础形象原则

1. **张力即灵魂** — 锐利线稿与阴影二分为角色核心，站姿自带蓄力感，避免松垮软塌
2. **角色为本** — 基础着装由角色描述（身份/职业/性别/场景）决定其常规着装；后续特定服化为叠加层
3. **四视图一致** — 面容/体型/发型/基础服装跨视图高度统一
4. **气质锐利昂扬** — 无妆状态需体现角色气质（坚毅/狂傲/沉静/热血）

---

## 二、面容约束

> 不再固定五官特征参数，由角色描述（性别/年龄/性格/气质）驱动 AI 自由生成五官，保证人物间外观差异化。

### 通用要求

| 项目 | 约束 |
|---|---|
| 五官 | 由角色描述自然推导，不预设脸型/眼型/眉型/鼻型/唇型 |
| 风格底色 | 现代热血战斗动画 2D 赛璐璐质感（锐利线条、阴影二分、高对比） |
| 气质 | 必须从角色描述提炼整体气质关键词（如坚毅/狂傲/沉静/热血），并写入提示词 |
| 表情 | 中性微表情偏锐利，眼神有神，符合角色气质 |

## 六、基础服装约束

> 基础服装由角色描述（身份/职业/性别/场景）决定其最自然的常规着装，作为该角色「日常默认态」；战斗服/形态变化在服化衍生环节叠加。**禁止内衣打底**。

### 着装选择原则

| 角色身份 | 默认着装方向 |
|---|---|
| 学生 | 现代校服 / 学院制服（战斗改良细节） |
| 武斗者/格斗家 | 便于活动的武道服 / 训练服 |
| 异能者/超能力者 | 现代便装 + 轻量战术元素 |
| 竞技选手 | 队服 / 竞技护具便装态 |
| 特殊职业 | 对应身份服装（军警/雇佣兵/医疗等） |
| 角色描述未明确 | 现代战斗风日常常服 |

### 着装统一规则

- 服装风格须与现代热血战斗动画美学一致（锐利剪裁、高对比、作画质感）
- 色彩高对比但主色不超过 2 种，无复杂花纹，便于后续战斗服衍生叠加
- 四视图服装款式完全一致
- 基础服装是「日常默认态」，焦点仍在面容与体态
- 严禁内衣/暴露/性化打底

## 八、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须为「素颜无妆」状态 |
| R2 | 必须根据角色描述声明合适的常规着装作为基础服装（如学生→现代校服、武斗者→武道训练服、异能者→战术便装）；禁止内衣打底 |
| R3 | 必须声明「无发饰、无配饰」 |
| R4 | 必须指定「中性冷灰白背景 #EFF1F4」 |
| R5 | 必须指定「四视图一致性」 |
| R6 | 全身立像必须从头到脚完整展示，严禁裁切 |
| R7 | 必须指定角色身高并通过头身比换算约束全身比例（女性默认155-168cm/6.5-7头身，男性默认172-185cm/7-8头身） |
| R8 | 人像特写必须从头顶到锁骨完整展示，严禁裁切头顶 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 内衣/暴露/性化打底；与角色描述明显不符的着装；过度复杂花纹/装饰干扰后续服化叠加 |
| X2 | 黑白漫画网点、印刷网纹、漫画分格框 |
| X3 | 数字化锐利过度至生硬CG感、低饱和褪色 |
| X4 | 复杂场景背景（必须中性冷灰白背景） |
| X5 | 夸张崩坏表情/战斗动态姿势（设定图须保持站立默认态） |
| X6 | 全身立像裁切头顶或脚底，必须从头到脚完整入画 |
| X7 | 人像特写裁切头顶，必须从头顶到锁骨完整入画 |
| X8 | 忽略身高和头身比约束 |
