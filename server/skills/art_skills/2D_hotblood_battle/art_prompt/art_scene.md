# 热血战斗风格 - 场景图生成 · 约束手册

---

## 一、场景美学原则

1. **战场即叙事** — 场景承载对决与成长功能，破坏痕迹、战损细节都是"已经打过/即将开打"的视觉台词
2. **层次纵深** — 所有场景必须具备前/中/后景，杜绝扁平；构图须为高速动作预留视线通道
3. **质感至上** — 线条/色彩/光影等材质表现必须清晰，能量特效与环境材质须可辨
4. **战斗作画为锚** — 一切画面以现代热血战斗动画为标准，拒绝3D写实/黑白漫画网点；追求赛璐璐线条特征（锐利线稿、阴影二分）与战斗演出特征（高对比明暗、能量光效、透视张力）

## 五、主视图规范

### 视图定义

> 单画面主视图，从战场中最具代表性与张力的角度拍摄，承载空间叙事与构图重心。

| 项目 | 约束 | 提示词 |
|---|---|---|
| 视角 | 广角低机位或高机位俯瞰，构图最能体现场战规模与冲击纵深 | dynamic wide angle、low angle establishing shot |
| 视点高度 | 默认低角度仰视强化压迫，或俯瞰呈现战场全貌 | low angle（默认）/ bird eye |
| 构图 | 主体居中或三分法，前/中/后景层次清晰，视线通道开阔 | balanced composition、open sightline |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 单画面（非拼图、非多视图、非分屏） |
| 人物 | **严禁出现任何人物、人影、人体轮廓** |
| 一致性 | 风格/材质/色调/光线统一 |
| 光线 | 主光方向明确，能量光效方向与主光逻辑一致 |
| 画面比例 | 默认 16:9（或按调用方设定） |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 场景必须有「前中后景层次」 |
| R2 | 室外必须包含「空气透视」与定向光逻辑 |
| R3 | 场景图必须为「单画面主视图」，不得拼接多视图/分屏/网格 |
| R4 | 构图须体现战场张力（广角透视/视线通道/规模感）并展示前/中/后景层次 |
| R5 | 场景图中**严禁出现任何人物** |
| R6 | 必须包含战斗动画关键词（battle anime style / high contrast / cel shading） |
| R7 | 必须包含线条特征（锐利线条、阴影二分 至少一项） |
| R8 | 材质必须带战损痕迹（裂纹/灼痕/沟壑），禁止崭新无瑕的空场地 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 背景纯白/纯黑/无场景 |
| X2 | 阴郁灰暗低对比、恐怖猎奇氛围 |
| X3 | 场景无纵深/无层次/无明暗二分 |
| X4 | 黑白漫画网点、印刷网纹、漫画分格框 |
| X5 | 出现任何人物、人影、人体剪影 |
| X6 | 画面被拼接成多视图/网格/分屏布局 |
| X7 | 3D 写实渲染/真人实拍质感/水彩晕染 |
| X8 | 材质干净完美、无任何战斗痕迹的空旷场地 |
| X9 | 血腥残虐痕迹（血泊/残肢等直观暴力符号） |
