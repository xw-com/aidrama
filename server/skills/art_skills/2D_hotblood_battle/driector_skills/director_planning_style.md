# 热血战斗约束 · 热血战斗动画 · 技法参考

---

## 一、色调体系与画面基调

- **色调基底** — 全片以燃焰橙（C1）、热血红（C2）、电光蓝（C3）、曜石黑（C5）为基底色，整体色温中性偏亮（5500-6000K），饱和度高（75-95%），呈现现代战斗动画的高燃质感。全片保持高对比色彩基底，暗部用曜石黑（C5）与钢铁灰（C7）压住画面，亮部用爆闪黄（C4）与纯净白（C6）拉开明暗
- **冷暖叙事对比** — 电光蓝（C3）与能量青（C8）作为冷系能量与冷静蓄势的视觉信号，与燃焰橙（C1）、热血红（C2）的暖系爆发形成对撞。冷暖切换应与攻防节奏同步（蓄势冷→爆发暖），而非随意混用
- **色盘先行原则** — 段落规划需先绑定情绪场景（蓄势对峙/热血觉醒/必杀释放/胜利余烬等），再确定主色+辅色与光影方案，避免"剧情对了但情绪不对色"
- **禁用色域** — 低饱和褪色、阴郁灰暗、水彩柔和色系均与本风格不兼容

## 二、光影方案体系

- **光影即演出** — 6 套光影方案对应不同战斗段落，导演规划阶段应在段落层面确定光影基调方向，而非逐镜指定
- **光源角度** — 默认 30-45° 硬侧光或强逆光，阴影二分硬切；爆发时刻允许人物自发光取代环境光源

| 情绪段落 | 光影方向 | 色调倾向 | 适用阶段 |
|---|---|---|---|
| 日常/备战 | A·明朗顶光 | 电光蓝 + 纯净白，高调干净 | 日常/羁绊段 |
| 对峙蓄势 | B·强逆光剪影 | 曜石黑主调 + 爆闪黄边光 | 开战前 |
| 交锋高速 | C·侧逆光+速度光轨 | 燃焰橙 + 电光蓝交替 | 交战段 |
| 必杀爆发 | D·冲击帧白闪 | 爆闪黄 + 纯净白瞬间拉满 | 高潮段 |
| 强敌威压 | E·低明度暗紫辉光 | 暗渊紫 + 曜石黑 | 危机/绝境段 |
| 异空间/终局 | F·辐射天幕光 | 能量青 + 暗渊紫环境光 | 终局段 |

- **冷暖光分配** — 暖调（燃焰橙/热血红）用于爆发与逆袭段落，冷调（电光蓝/能量青）用于蓄势、预判与高速交锋段；必杀白闪（D）不分冷暖，直接以明度碾压
- **氛围方向映射** — 每场戏的氛围方向应能映射到上述光影方案（A-F）的某一方向，确保视觉一致性

## 三、质感方向

- **赛璐璐战斗纪实感** — 现代热血战斗动画的核心：锐利线稿、阴影二分硬切、高对比明暗、高饱和色彩
- **锐利线稿 + 硬边阴影** — 这是画面质感的锚点。不是柔和渐变，不是黑白网点漫画，也不是3D写实渲染
- **特效是演出语言** — 速度线、集中线、冲击帧、能量爆气不是装饰而是节拍器：速度线=高速、集中线=聚焦、白闪=冲击峰值，按动作节拍投放而非满屏滥用
- **高燃不等于糊爆** — 本风格强调"炸得有层次"（前景人物锐利、中景特效辉光、背景压暗衬亮），通过明暗对比与特效层级放大燃感，而非全画面糊成一团光

## 四、热血战斗场景空间元素

现代热血战斗动画特有的场景元素及其视觉叙事功能：

- **竞技场/擂台/结界** — 天然的仪式化对决容器，制造"此地为战场"的界域感，景即誓：防护结界亮起 = 开战、擂台划痕 = 往昔激战、旗帜翻卷 = 荣誉在肩
- **废墟/弹坑/断壁** — 战斗烈度的可视化记录，景即证：悬浮碎块 = 力量余波、光柱穿尘 = 神圣决战、切面钢筋 = 战斗的代价
- **能量湍流/扭曲天幕/符文地面** — 异空间战场的法则异质感，景即境：无重力碎屑 = 法则崩坏、辐射穹顶 = 终局舞台
- **观众席/看板/战术屏** — 见证者视角的载体，看台人浪 = 呐喊应援、战术屏冷光 = 备战指挥、场馆看板 = 舞台感
- **段落间用战场空镜过渡** — 本风格有丰富的场景资产（不同时段/战况/异变变体），段落衔接建议用战场空镜做情绪缓冲（如：硝烟散去的擂台空镜→下一场开战），不要硬切
- **转折点用视觉而非台词** — 优先使用画面手段（觉醒白闪、光影方案骤变、爆气冲天、静默定格）而非依赖对白解释

## 五、热血战斗乐器与环境音

现代热血战斗动画世界观下的声音元素约束：

### 乐器选择

- **管弦齐奏（弦乐+铜管）** — 决战与逆袭段落的核心配置，铜管号角一响即是"翻盘宣言"
- **电吉他/失真riff** — 交战高速段落的节奏引擎，驱动感最强的攻击性音色
- **太鼓/打击乐群** — 蓄势与重击段落的节拍核心，鼓点即拳点
- **合成器脉冲/贝斯铺底** — 异空间与现代竞技段的低频驱动，科技感与紧张感并存
- **尺八/三味线（和风点缀）** — 招式吟唱与奥义释放的东方气口，一音定肃杀

### 乐器组合策略

| 情绪阶段 | 乐器组合 |
|---|---|
| 平稳/开场/收尾 | 钢琴 + 弦乐轻铺底 |
| 蓄势/对峙 | 太鼓低频 + 合成器脉冲渐强 |
| 交战高速 | 电吉他riff + 打击乐群 |
| 必杀/觉醒 | 全管弦齐奏 + 铜管号角（前接骤静） |

### 战斗环境音

- **典型环境音层次** — 气浪爆鸣 / 金属交击 / 碎石崩落 / 能量嗡鸣 / 观众呐喊声浪 / 疾风风压 / 脚步踏地闷响
- **每场戏标注 1-2 个核心环境音**，帮助后续音效设计。环境音与打击音分层越清晰，战斗越有"拳拳到肉"的质感
- **骤静是必杀的前奏** — 必杀释放前优先做 0.5-1s 骤静（只留呼吸/心跳/能量蓄积嗡鸣），随后音乐全奏砸下，落差即燃点
- **避免满配** — 全片配乐覆盖率建议不超过 70%，日常与备战段落留呼吸；但交战高潮段允许全覆盖强驱动
