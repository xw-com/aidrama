# 热血战斗风格说明

本风格专为"热血战斗动画"题材打造，所有美术提示词、规范和生成内容均严格限定于：

- **现代战斗动画演出**：以现代热血战斗动画作画为锚，涵盖速度线/集中线、冲击帧、能量光效与爆气、招式释放演出、夸张透视与动态张力。
- **赛璐璐战斗作画质感**：所有角色、场景、道具均以现代二维战斗动画为标准，锐利线稿、阴影二分、高对比强烈明暗、能量特效自发光。
- **高燃战斗美学**：高饱和燃系色彩、白闪冲击帧、招式轨迹与气浪特效，追求"燃"的视觉冲击与作画张力。
- **战场世界观**：以竞技场、废墟都市、异空间战场为核心舞台，涵盖武斗大会、异能对决、团队阻击等题材。

## 适用范围

- 热血战斗动画题材的AI美术生成（角色、场景、道具、分镜等）
- 需要速度线冲击帧、能量爆气、高对比作画张力的视觉创作

## 严禁内容

- 写实摄影、3D写实渲染、真人实拍质感
- 黑白漫画网点、印刷网纹、漫画分格框（本风格为彩色动画作画）
- 低对比灰暗阴郁、恐怖猎奇氛围
- 柔和治愈水彩、低饱和褪色调
- 血腥残虐特写（战斗张力靠演出特效，不靠血腥）

## 风格体验

在本风格下，您将体验到：

- 角色造型锐利挺拔，战斗服护甲精致，肌肉张力与动态姿势并存
- 场景充满战场氛围，竞技场、废墟与异空间细节丰富，能量光效与气浪渲染炸裂
- 道具器物考究，能量兵器与护甲材质质感清晰，高对比色彩统一
- 分镜与画面强调速度线冲击帧、招式释放演出与高燃作画张力

---

本风格仅适用于"热血战斗"相关项目。如需其他风格（如治愈、恐怖、漫画网点等），请勿使用本套提示词。
