## 二、全局色彩盘（风格基线，不是硬锁）

> 目标：统一审美而非限制创作。除「硬约束色」外，其余颜色默认优先使用，可在合理范围内偏移。

### 色彩使用层级

| 层级 | 约束强度 | 说明 |
|---|---|---|
| L1 硬约束 | 高 | 仅锁定角色识别核心：肤色、发色、主服底色的审美方向 |
| L2 软约束 | 中 | 战场色、能量特效色、点缀色优先参考色盘，可按招式与战况微调 |
| L3 例外机制 | 低 | 必杀爆发/觉醒/白闪帧可临时突破局部色彩，但需保留高对比逻辑 |

### 硬约束色（默认锁定）

| 色项 | 对应色 | 规则 |
|---|---|---|
| 肤色基准 | 健康微暖肤色（近 C4 调和） | 默认优先，允许明度随光影二分拉差 |
| 发色/瞳色基准 | 不限色域，但须高饱和高对比 | 默认优先，允许彩色发色（燃系惯例） |

### 软约束色（推荐优先）

> C1/C2/C3/C5/C7/C8/C9/C10 为推荐色域，用于战袍、护甲、特效、战场、环境等。可根据招式属性做同色相邻近调整。

### 情绪色盘使用规则

| 编号 | 规则 |
|---|---|
| E1 | 每条提示词至少指定 1 个「情绪场景」并绑定主色+辅色组合 |
| E2 | 单镜头主色不超过 2 个（冲击帧白闪除外），避免颜色叙事失焦 |
| E3 | 情绪切换时优先调整光比与特效强度，再调整色相 |
| E4 | 燃系默认遵循「高对比 + 能量点亮」：阴影二分铺底，能量色只用于光源与特效 |
| E5 | 若与剧情冲突，以情绪色盘优先于通用推荐色，但不得突破严禁项 |

### 色温约束

| 参数 | 值 | 说明 |
|---|---|---|
| 整体色温 | 中性偏亮 5500-6000K（推荐） | 高燃清爽主基调，爆发段允许强偏移 |
| 肤色色温 | 微暖 5400-5800K（推荐） | 健康有血性 |
| 对比度 | 高（建议保持） | 阴影二分，明暗硬切 |
| 饱和度 | 高 75-95%（建议区间） | 现代战斗动画燃系色调 |

### 容差与例外

| 项目 | 建议容差 |
|---|---|
| 色相偏移 | ±12° |
| 饱和度偏移 | ±12% |
| 明度偏移 | ±15% |

> 例外场景：必杀爆发、觉醒白闪、异空间镜头可瞬间拉满明度与饱和（冲击帧演出）；但禁止整段低对比灰暗或全程高曝发白。
