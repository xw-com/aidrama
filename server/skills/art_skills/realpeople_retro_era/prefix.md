## 二、摄影机语法（替代"渲染引擎"）

> 真人年代怀旧不依赖渲染管线。画面品质取决于摄影机的选择、镜头的性格、年代光源的调度。以下为"摄影机语法"核心参数。

### 2.1 画幅与格式

| 参数 | 基准值 | 美学意图 |
|---|---|---|
| 影像格式 | 35mm胶片质感 / 全画幅数字摄影模拟胶片 | 浅景深能力、自然的暗角过渡、80/90年代胶片的颗粒结构与微偏暖的色偏 |
| 色彩科学 | 怀旧电影色彩科学（参考《漫长的季节》《山海情》《人世间》年代调性） | 肤色还原自然偏暖、高光滚降柔和、暗部不压死且有层次，整体微暖微旧但不泛黄失真 |

### 2.2 镜头性格

| 焦段 | 叙事性格 | 典型应用 |
|---|---|---|
| 24-28mm（广角） | 环境吞噬人物、空间壮阔感、车间与集体的宏大 | 车间全景、家属院空镜、厂区大门、绿皮车厢全貌 |
| 35mm（小广角） | 主观视点、身临其境、纪实感 | 筒子楼走廊跟随、胡同行走、车厢内对话、百货柜台前 |
| 50mm（标准） | 人眼等价、客观注视、不美化不扭曲 | 人物肖像、劳模特写、双人对话、邻里情感凝视 |
| 85mm（中长焦） | 压缩空间、拉近情感距离、背景虚化突出人物 | 年代面孔特写、车间远端注视、街对面望见 |
| 135mm+（长焦） | 极端压缩、窥视感、将人物从环境中剥离 | 厂区远眺、车窗内远去的月台、个体在集体中的孤独 |

| 手法 | 视觉心理 | 使用场景 |
|---|---|---|
| 固定机位 | 冷静、观察、让时间自己说话 | 车间日常、筒子楼对话、空镜留白 |
| 手持微晃 | 在场感、呼吸感、年代纪实 | 情绪波动、胡同行走、绿皮车厢内的晃动跟随 |

## 四、全局约束规则

### 4.1 影像真实性约束（必守）

| 编号 | 规则 |
|---|---|
| P1 | 必须以「真人摄影 / 真人实拍 / 真人电影剧照」为生成锚——画面必须读作"摄影机拍下的"，而非"计算机生成的" |
| P2 | 必须指定一个具体的年代光源逻辑：这场戏的光从哪里来？（车间天窗/钨丝灯泡/日光灯管/胡同夕照/灶火）光源方向、色温、软硬须自洽 |
| P3 | 必须保留人物皮肤的真实质感——毛孔、细纹、痣、日晒色差、自然肤色不均——杜绝塑料磨皮与AI感假面 |
| P4 | 发丝必须呈现年代发型的自然状态——麻花辫的毛躁碎发、齐耳短发的自然走向、分头的发际线、烫发的蓬松——杜绝建模感整齐发块与假发套边界 |
| P5 | 服饰必须体现"穿过/劳作过"的痕迹——的确良领口的微黄汗渍、绿军装肘部的磨白、工装的机油印、海魂衫的洗涤松垮——杜绝全新样板衣感 |
| P6 | 场景必须有"被使用过"的年代证据——搪瓷缸的磕瓷、机床的油污、墙皮剥落、水泥地磨损、标语褪色——杜绝样板间与影楼道具 |
| P7 | 人物必须处于自然年代体态——真实的站姿（重心偏一侧）、劳作后的微驼、拘谨的双手、憨厚或爽朗的表情——杜绝网红摆拍与现代pose |
| P8 | 必须指定一个具体的 80/90 年代中国市井空间——拒绝"generic retro"或任何无国别无年代标识的架空场景 |

### 4.4 风格越界判定

> 当你生成的画面出现以下任一信号，说明已经偏离真人年代怀旧风格：

| 越界信号 | 说明 |
|---|---|
| 人物皮肤像硅胶 | 磨皮过度，失去真人质感——立即停用"光滑""完美肌肤"类词汇 |
| 出现现代元素 | 手机/品牌Logo/现代发型/当代服饰——回到年代符号锚定，强化"1980-1990年代"声明 |
| 光源来源不明 | 画面亮但说不清光从哪来——补全年代光源逻辑，拒绝"全局均匀亮" |
| 画面像民国或古装 | 出现旗袍洋行/汉服古建——强化"80/90年代市井"与"区别民国"声明 |
| 场景过于干净/做旧过度 | 影楼样板或刻意做旧——回归真实年代使用痕迹，不要泛黄滤镜 |
| 人物像网红摆拍 | 现代pose/网红表情——给一个年代人自然的拘谨或憨厚体态 |
| 色彩像廉价怀旧滤镜 | 一刀切泛黄——回归年代光源色温驱动，不要"怀旧滤镜套用" |
