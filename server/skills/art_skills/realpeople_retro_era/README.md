本手册专为"真人年代怀旧"题材视觉创作打造，所有美术提示词、视觉规范和生成内容严格限定于真人实拍级年代怀旧影视美学体系，聚焦 1980–1990 年代中国市井生活。

## 一、风格核心定义

**真人年代怀旧**是以**真人影视摄影美学**为基准、以**1980–1990 年代中国市井生活**为核心的视觉风格体系。其核心特征为：

- **真人写实摄影质感**：以真人影视级摄影为锚点，画面呈现真实人物的皮肤纹理、毛发细节、微表情与肢体语言，杜绝3D建模感、CG渲染感、手绘感
- **年代怀旧世界观**：所有场景严格限定于 80–90 年代中国市井空间——国营大厂车间、筒子楼走廊与公用厨房、绿皮火车车厢、老胡同与家属院、国营百货商店、录像厅、新华书店、厂区子弟学校、工人文化宫等真实年代生活场景
- **电影级摄影语言**：以院线级真人年代电影摄影为基准，强调钨丝灯、车间天窗、日光灯等年代光源的有机调度、构图叙事的专业性、景深与焦点的情绪表达、色彩分级的电影感
- **年代人文温度感**：在保持专业影像品质的前提下，强调搪瓷缸、二八大杠、缝纫机、收音机、磁带、暖水瓶、粮票布票等年代符号承载的市井烟火气与人与人之间真实的情感连接

### 创作理念与核心价值

本手册的核心创作理念为 **"岁月即质感"**：

1. **年代质感的审美回归**：在AI生成影像日趋同质化的当下，80/90年代中国市井以其不可替代的岁月痕迹，成为最具情感穿透力的视觉语言。的确良衬衫的挺括、搪瓷缸磕掉的白瓷、暖水瓶外壳的磨痕、绿皮车厢的皮革吊环——这些被时间打磨过的真实细节，构成了一种3D渲染无法复刻的审美深度。

2. **年代的叙事容器**：80/90年代是中国人记忆深处最温暖的叙事空间。筒子楼走廊里飘出的各家饭菜香、车间机床的轰鸣、绿皮车厢里瓜子花生的市井对话、家属院大喇叭的广播、新华书店玻璃柜台里的连环画——年代空间本身就是一个巨大的叙事容器，等待被挖掘。

3. **人本主义的视觉立场**：本手册坚持以"人"为核心。无论车间多么宏大、光影多么动人，最终回归到人物的劳作状态与内心世界——厂矿工人的憨厚、返城知青的迷茫、个体户倒爷的精明、子弟学校学生的青涩。

4. **电影与年代日常的临界点**：寻求"电影的精致"与"年代的真实"之间的微妙平衡——画面足够美、足够专业、有电影感，但不过度精致而失去生活年代感；人物足够真实、足够生动，但不过度随意而失去审美品质。

**核心价值：**

- 为AI视觉创作者提供一套系统化、可复用的真人年代怀旧题材提示词方法论
- 建立从概念到成品的标准化视觉创作管线
- 降低真人年代怀旧题材AI视觉创作的技术门槛与试错成本
- 填补当前AI视觉创作领域"真人年代怀旧题材系统化方法论"的空白

## 四、关键视觉元素

### 4.1 人物视觉元素

真人年代怀旧题材的人物视觉以**"真实个体、年代气质"**为核心：

- **面容标准**：真人肌肤质感，五官自然，妆容符合年代审美且不过度修饰（雪花膏/蛤蜊油级别的朴素护肤，无现代彩妆）。支持多元年代面容类型——朴实憨厚、爽朗泼辣、文静腼腆、精明干练、憨厚质朴等
- **发型标准**：80/90年代真实发型，发丝自然质感，杜绝假发感与僵硬造型。支持麻花辫、齐耳短发、分头、烫发（烟花烫/锡纸烫）、海魂头、运动头等多种年代发型
- **服饰标准**：80/90年代真实着装体系——的确良衬衫、绿军装、海魂衫、蓝灰工装、碎花衬衫、喇叭裤、健美裤、工装背带裤、劳保服等。面料纹理清晰（的确良的挺括微透、棉布的厚实、帆布的粗粝），有穿着与劳作痕迹
- **表情与体态**：微表情真实细腻（眼神、嘴角、眉宇），肢体语言自然不做作，呈现年代人特有的拘谨、憨厚或爽朗，杜绝现代摆拍感与网红表情

## 五、严禁内容（优先级最高）

本风格严格排除以下内容类型，确保视觉体系纯净统一：

1. **非真人质感**：3D渲染/CG建模/次世代游戏引擎/动画风格/手绘插画/水彩油画/二次元/Voxel/低多边形等一切非真人实拍影像质感
2. **非80/90年代世界观**：当代智能手机/现代都市/民国（区别republic_era，无旗袍洋行租界）/古风/古装/传统中式古建/仙侠/玄幻/武侠/宫廷/赛博朋克/科幻未来/星际太空/西方奇幻/中世纪等非80/90年代中国市井背景
3. **非80/90年代中国语境**：明显非年代特征的建筑、服饰、标识、人物造型（如智能手机、当代品牌、现代发型、2020年代服饰）
4. **技术质量缺陷**：低分辨率/模糊/噪点/变形/畸形肢体/五官扭曲/比例失调/抠图感/塑料感/过度磨皮/假面感
5. **审美倾向违规**：过度高饱和/死亡荧光色/廉价滤镜感/过度HDR/脏乱差画面/刻意阴间色调
6. **内容合规红线**：暴露/低俗/暗示性/暴力血腥/违法内容/歧视性表达/政治敏感元素

## 七、使用说明

### 提示词使用原则

1. **前缀先行**：所有生成内容必须首先加载"前缀提示词"中的全局风格锚定段，锁定真人年代怀旧写实质感基线
2. **专项叠加**：在全局前缀基础上，按需叠加角色/场景/道具/分镜专项提示词
3. **负面必加**：每次生成必须附带"负面提示词"，规避伪影与风格偏差
4. **迭代优化**：建议首轮生成后根据效果对专项提示词做微调，而非修改全局前缀
5. **平台适配**：本手册提示词优先适配Doubao-Seedream（生图）与Doubao-Seedance（视频生成），部分提示词可能需根据平台特性微调
