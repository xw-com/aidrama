# 真人年代怀旧道具图像生成 · 约束手册

---

## 一、道具设计原则

> 真人年代怀旧的道具不是"被建模的物体"，而是"被年代人使用过的物品"——它在某只劳作的手里待过、在某张掉漆的桌上放过、在某个军挎包里装过。摄影机拍下的是它此刻带着岁月痕迹的样子。

1. **物品即叙事** — 每一件年代道具都是一个微型的叙事容器。搪瓷缸磕掉的白瓷暗示用了多少年、暖水瓶外壳的磨痕暗示反复打水、磁带的卷带痕迹暗示被反复听过、二八大杠车架的掉漆暗示风里雨里的通勤
2. **使用痕迹与岁月优先于完美品相** — 真人年代怀旧的道具必须有"被年代人用过、用过很多年"的证据。全新的、刚出厂的、样板级别的道具一律不出现（除非剧情是"刚买的"）
3. **80/90年代中国市井真实物品** — 道具必须是 80/90 年代中国市井生活中真实存在的物品：搪瓷缸/搪瓷盆（带磕瓷）、二八大杠自行车（飞鸽/永久/凤凰牌）、缝纫机（蝴蝶/飞人牌）、收音机（红灯牌）、录音机与磁带、暖水瓶、铝饭盒、粮票布票、的确良/绿军装、黑白/彩电、雪花膏/蛤蜊油——拒绝无国别无年代标识的架空物品
4. **材质即真实** — 不是PBR参数渲染出的材质，而是摄影机拍下的年代真实材质行为：搪瓷的釉面与磕瓷露铁、铝饭盒的氧化哑光、铸铁机床的油污、橡胶暖水瓶塞的磨损、磁带塑料的注塑纹理
5. **单视图静物摄影** — 道具以单张静物产品摄影方式独立呈现，非多角度建模展示，非2×2四宫格

## 三、单视图静物摄影规范

> 真人年代怀旧道具仅需单张静物产品摄影，非多角度建模展示。以下为单视图摄影的完整规范。

### 画面构成

| 项目 | 摄影要求 |
|---|---|
| 道具呈现 | 道具居中或偏三分线位置独立陈列，完整入画，无裁切 |
| 背景 | 素灰无缝背景纸 #B0B0B0（哑光），或年代真实台面（掉漆木桌/水泥台面/绿皮桌面/搪瓷台面），根据道具属性选择。无多余物体、无装饰、无现代文字 |
| 光线 | 自然窗光或单灯柔光。窗光45°侧入（明亮柔和带自然阴影）、或钨丝灯泡暖黄光（2400-2800K，年代道具适配）、或柔光箱顶+侧补（产品摄影级均匀光线）。光影柔和、方向明确、无硬阴影 |
| 景深 | 浅景深（f/2.8-f/5.6），道具主体清晰锐利，前后微虚化突出主体 |
| 投影 | 道具底部与承载面之间的自然接触阴影——真实的而非抠图或悬浮。阴影柔软、方向与主光源一致 |
| 画面比例 | 建议 1:1 正方形或 4:3，适配单件道具展示 |

### 道具状态准则

| 维度 | 要求 |
|---|---|
| 使用痕迹 | 必须有"被年代人使用过多年"的视觉证据——非全新未拆封、非样板品相 |
| 年代辨识度 | 80/90年代中文标识/年代品牌（飞鸽/永久/蝴蝶/红灯/双菱/上海牌）/年代式样/年代包装——拒绝无国别无年代架空物品 |
| 材质真实感 | 非渲染质感——是摄影机拍下的年代真实材料行为（光的反射、漫射、透射、磨损、氧化） |
| 尺度感 | 通过材质纹理密度、工艺细节暗示实物尺寸，无需参照物 |

| 编号 | 规则 |
|---|---|
| R1 | 必须是「单张静物摄影」——单视图、非多角度、非2×2四宫格、非建模展示 |

| R3 | 必须指定光源逻辑——窗光或钨丝灯泡暖黄光或柔光箱，光影方向明确、投影自然 |

| R8 | 必须声明「1980-1990年代中国市井」年代与世界观锚定 |
