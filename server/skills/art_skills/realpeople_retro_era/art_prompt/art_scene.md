# 真人年代怀旧场景图像生成 · 约束手册

---

## 一、场景美学原则

> 真人年代怀旧的场景不是"被建模的空间"，而是"被摄影机选中的 80/90 年代真实场所"。没有渲染引擎、没有贴图、没有体积光参数——只有实际存在的年代光源（车间天窗、钨丝灯泡、日光灯管）、真实的年代材料、以及中国市井的年代日常。

1. **空间即叙事** — 一个空无一人的车间不是"空的"，是刚下早班。一把歪放的工具、一杯没喝完的搪瓷缸水、机床区还亮着的局部灯——空间自己会讲故事
2. **真实的年代光源，不是渲染的光** — 场景的光只有一个来源：实际的天光（通过车间天窗、窗户、门洞）、实际的年代灯光（钨丝灯泡、日光灯管、灶火、煤球炉火）。光的色温和方向必须在物理上说得通
3. **被使用过的年代空间** — 真实的年代场景不整洁。机床有油污铁屑、筒子楼走廊堆满杂物、搪瓷有磕瓷、墙皮剥落、水泥地磨损。一个完全没有岁月痕迹的空间是影楼样板，不是真人年代怀旧
4. **80/90年代中国市井的真实场所** — 场景必须有年代中文标识、年代特征（标语、宣传画、毛主席像、大喇叭、绿皮、搪瓷、的确良布帘）。这不是"generic retro"，这是"80/90年代中国市井的一个具体角落"
5. **单视图全景全貌** — 一张照片装下整个场地的完整信息。广角或标准焦段，全景深，正面展示空间的全貌与纵深——不是四视图分割，不是多角度拼贴

## 五、单视图全景摄影规范

> 真人年代怀旧场景仅需**单张**全景摄影——一张照片装下整个空间的完整信息。不是2×2四视图，不是多角度拼接。

### 画面构成

| 项目 | 摄影要求 |
|---|---|
| 空间呈现 | 单张照片完整呈现场景的空间全貌。使用24-28mm广角或35mm，全场地的纵深、宽度、高度在一张画面中全部可见 |
| 构图 | 全景深大景别——前景（机床/桌椅/门框/煤炉/自行车）形成天然画框→中景是场地主体→后景向空间纵深或窗外/走廊尽头延伸 |
| 景深 | 全景深 f/8-f/11，从前到后全部清晰。这不是人像摄影——场景的每一个角落都应该能被看见 |
| 人物 | **严禁出现任何人物、人影、人体轮廓。** 场景是空的——但这种"空"有叙事：刚下早班/即将开场/人去楼空/年代日常的静止瞬间 |
| 比例 | 建议 16:9 或 3:2 宽幅——匹配全景空间展示的横向视觉习惯 |
| 色彩 | 由实际年代光源的色温驱动，不套滤镜。色彩科学参考怀旧年代电影色调（微暖微旧但不泛黄失真） |

### 空的场景如何叙事

| "空"的类型 | 画面线索 | 叙事暗示 |
|---|---|---|
| 刚下早班 | 机床区局部灯还亮、工具没归位、搪瓷缸还有半杯水、地面铁屑未扫 | 刚才工人在这里，现在下班了 |
| 即将开场 | 课桌椅摆好、黑板擦干净、粉笔摆好、值日表更新、广播刚响过 | 有人马上要来上课，现在是开始前的静止 |
| 人去楼空 | 搬走后的空宿舍、墙上挂钩和挂历痕迹、地面积尘的轮廓、留下的一只搪瓷缸 | 曾经有人住过，现在已经搬走了 |
| 日常的静止 | 筒子楼走廊的炉灶上锅还温着、公用厨房水龙头滴水、自行车靠墙、晾晒的衣物 | 生活的常态、只是此刻没有人入镜 |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须是**单张**全景摄影——单视图、非2×2四视图、非多角度、非turnaround |
| R2 | 必须使用广角镜头（24-28mm）或标准焦段（35mm），全景深 f/8-f/11，完整空间纵深 |
| R3 | 光源必须可追溯——年代自然光（车间天窗/窗户）的方向与时刻匹配、年代人工光源（钨丝灯/日光灯/灶火/煤球炉火）的位置和色温合理 |
| R4 | 场景必须有前/中/后景空间层次，前景画框→中景主体→后景延伸 |
| R5 | 必须有 80/90 年代中国市井辨识度——年代中文标识（标语/招牌/宣传画）/年代建筑风格/年代符号（绿皮/搪瓷/大喇叭/毛主席像） |
| R6 | 必须有年代使用痕迹——墙皮剥落/水泥地磨损/机床油污/搪瓷磕瓷、非样板间非全新非效果图非影楼 |
| R7 | **严禁出现任何人物、人影、人体轮廓、剪影** |
| R8 | 必须声明"真人实拍摄影 + 非3D渲染非CG"核心锚定 |
| R9 | 必须声明「1980-1990年代中国市井」年代与世界观锚定 |
