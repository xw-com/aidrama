# 分镜提示词 · 真人年代怀旧 · 风格专属技法

---

## 适用范围

本 Skill 专用于**真人年代怀旧**风格的分镜提示词生成，适配厂矿劳作、筒子楼邻里、知青返城、个体闯荡、怀旧温情、年代青春等 80/90 年代中国市井真人实拍影视题材的分镜创作。

## 一、摄影机前的年代情绪——面孔、眼神、微表情

> 真人年代怀旧的情绪不来自"义体光效"或"渲染参数"，而来自年代人在摄影机前的真实微表情。以下映射面向摄影机捕捉真实年代人物的方式。

| 情绪输入 | 面容描述 | 眼神描述 | 微表情补充 |
|---|---|---|---|
| 憨厚 / 朴实 | 神情自然不紧绷，面部线条放松 | 眼神笃定朴实不躲闪，注视沉稳 | 嘴角自然平直微抿，下颌微收，憨厚克制 |
| 奋进 / 坚定 | 面部线条清晰，下颌微抬 | 眼神笔直向前，有劳模式的坚定 | 下巴微收或微抬，表情果敢但不张扬 |
| 文静 / 腼腆 | 眉眼舒展含蓄，面部柔和 | 眼神含蓄温润，注视略带羞涩 | 嘴角自然平直，可能低头后抬眼，文静克制 |
| 爽朗 / 泼辣 | 眉眼舒展生动，面部有热络 | 眼神明亮有神采，注视直接不躲闪 | 嘴角自然上扬像随时要开口，面颊微红 |
| 忧伤 / 落寞 | 眉眼低垂，面部肌肉松弛 | 目光涣散失焦，望向搪瓷缸或窗外 | 嘴角自然下沉，表情怅然，不刻意 |
| 沧桑 / 厚实 | 眼角鱼尾纹深刻，面部整体厚重 | 目光深邃有阅历，注视沉稳 | 法令纹明显，表情厚重，可能的抽烟痕迹 |
| 惊讶 / 触动 | 眼尾微抬，眉毛自然上扬 | 眼神骤然聚焦，瞳孔微扩 | 嘴角微启，表情鲜活不夸张 |
| 沉思 / 内省 | 神情淡然，眼部周围肌肉放松 | 目光放远失焦，像在看但不在看 | 表情平静，可能单手摩挲搪瓷缸边缘 |
| 喜悦 / 鲜活 | 眼角出现自然笑纹，眼型微弯 | 眼神明亮有光，眼角有笑意 | 嘴角上扬，面颊微红，年代人克制的鲜活 |
| 疲惫 / 倦怠 | 眼窝微陷，面部整体松弛 | 目光朦胧，眼皮微沉 | 眉眼低垂，可能的汗渍与油污，表情松弛 |
| 精明 / 闯荡 | 眉眼灵动，面部线条利落 | 眼神锐利有光，带打量与机敏 | 嘴角似笑非笑，下颌微抬，市井精明 |
| 迷茫 / 转折 | 眉眼低垂或游移，面部松弛 | 目光涣散，像在寻找方向 | 嘴角微启，表情怅然，时代的迷惘 |

## 四、摄影机语法——镜头选择与运动

### 4.1 焦段选择

| 焦段 | 叙事性格 | 适用场景 |
|---|---|---|
| 24-28mm广角 | 环境包围人物，集体壮阔感，车间与时代的宏大 | 车间空镜、厂区俯瞰、筒子楼走廊、家属院全景 |
| 35mm小广角 | 主观视点，身临其境的纪实感，人与年代环境共存 | 筒子楼跟随、胡同行走、车厢对话、百货柜台前 |
| 50mm标准 | 人眼等价，客观中立的注视，最诚实的镜头 | 人物肖像、劳模特写、双人对话、邻里情感凝视 |
| 85mm中长焦 | 压缩空间，拉近情感距离，背景虚化突出人物 | 年代面孔特写、车间远端注视、胡同对面望见 |
| 135mm+长焦 | 将人物从环境中剥离，极端的注视或窥视 | 厂区远眺、车窗内远去月台、集体中的个体孤独 |

### 4.2 景别选择

| 景别 | 取景范围 | 叙事功能 |
|---|---|---|
| 大特写 | 眼睛/嘴唇/手指/搪瓷缸/劳模奖章/磁带 | 情绪爆发点、关键信息揭示、年代细节聚焦 |
| 近景 | 头顶至胸部以上 | 人物情感、对话反应、年代面孔的微表情 |
| 中近景 | 头顶至腰部 | 人物互动、劳作手势、年代动作的身体语言 |
| 中景 | 头顶至膝盖上下 | 人物与车间/筒子楼/车厢的初级关系 |
| 全景 | 人物全身+部分年代环境 | 人物在车间/广场/车厢的位置、行动路线 |
| 大全景/空镜 | 空间全貌，人物极小或无人物 | 空间叙事、情绪缓冲、高烟囱与厂区的隐喻留白 |

### 4.3 摄影机运动

| 运动方式 | 视觉心理 | 使用场景 |
|---|---|---|
| 固定 | 冷静观察，让时间自己说话 | 车间日常、筒子楼对话、空镜留白 |
| 手持微晃 | 在场感，呼吸感，年代纪实 | 情绪波动、胡同行走、绿皮车厢内的晃动跟随 |
| 稳定器流动 | 优雅的年代漫游，诗意 | 重要场景过渡、人物登场、厂区空间展示 |
| 缓推 | 注意力逐渐聚焦、情绪趋近 | 对话升温、真相逼近、情感推进 |
| 缓拉 | 拉开距离、揭示全貌、情绪抽离 | 离别、章节收束、厂区全景揭示 |
| 跟拍 | 与人物同行、主观陪同 | 胡同行走、绿皮车过道、追踪 |
| 摇镜 | 视线转移、空间关系交代 | 人物视线引导、车间机床与标语的关系 |

## 五、固定风格锚定词

**摄影锚定（必选）：**

真人实拍摄影，真人电影剧照，1980-1990年代中国市井，电影级摄影，年代光源调度（钨丝灯泡/车间天窗/日光灯管/灶火/煤球炉火），真实色彩科学

**人物质感（含人物镜头时必选）：**

真人写实摄影质感，真实皮肤纹理毛孔可见含日晒色差，不磨皮不硅胶脸，年代发型自然质感（麻花辫/齐耳短发/分头/烫发）有碎发，年代面料纹理可见（的确良挺括/绿军装粗粝/海魂衫条纹）有穿着与劳作褶皱，年代自然微表情，真实年代肢体语言

**场景质感（含场景镜头时必选）：**

真人实拍年代场景摄影，真实年代建筑材质与岁月痕迹（搪瓷磕瓷/墙皮剥落/机床油污铁屑/水泥地磨损/标语褪色），年代光源方向明确可追溯，大气透视自然，非影楼样板非效果图

**参考图一致性锚定（参考图模式必选）：**

保持人物造型、面容、年代发型、年代服饰与参考图完全一致，保持场景风格与参考图一致，保持年代光影色彩基调统一，所有镜头呈现为同一人物的连续摄影记录

**风格收尾（固定）：**

真人写实摄影，1980-1990年代中国市井电影质感，电影级摄影画面，非3D非渲染非CG

**画质锁定词：**

## 六、美学禁止项

以下词汇/风格不得出现于输出提示词中：

- ❌ 3D渲染 / 3D建模 / CG / UE引擎 / Blender / PBR材质 / 次世代建模 / 体积光 / 环境光遮蔽 / 光线追踪
- ❌ 2D手绘 / 插画 / 动画 / 二次元 / 漫画 / Q版 / 低多边形
- ❌ 写实摄影（英文禁止 photorealistic / realistic photography——真人年代怀旧是"真人实拍摄影"live-action cinematic photography，不是"拟真渲染"）
- ❌ 过度磨皮 / 塑料假面 / 零毛孔 / 硅胶脸 / 蜡像感 / AI感平滑 / 网红磨皮滤镜
- ❌ 当代智能手机 / 现代都市 / 民国（旗袍洋行租界）/ 古风 / 古装 / 汉服 / 仙侠 / 武侠 / 宫廷 / 古代建筑 / 赛博朋克 / 科幻 / 西方奇幻 / 中世纪
- ❌ 现代彩妆 / 烟熏妆 / 假睫毛 / 美瞳 / 现代修容 / 现代美甲 / 现代染发挑染
- ❌ 人体结构错误 / 肢体畸形 / 面部崩坏 / 比例失调
- ❌ 高饱和荧光色 / 霓虹溢色 / 廉价怀旧泛黄滤镜 / 现代网红滤镜调色
- ❌ 非年代标识的架空场景 / 全现代标识 / 现代品牌
