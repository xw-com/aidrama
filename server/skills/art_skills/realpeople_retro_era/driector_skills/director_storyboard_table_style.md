## 一、分镜表定位

分镜表是导演将剧本转化为镜头语言的核心工具。本约束面向 Seedance 2.0 视频生成，所有光影、动作、空间描述均采用模型可执行的具象语言。不做抽象的情感概括，不写模型看不懂的渲染参数。

## 三、光影与氛围——Seedance 2.0 年代物理光源描述

### 3.1 同场戏光影统一

一场戏内不应出现两种以上核心光影方案，除非有叙事驱动的光源变化（如有人打开钨丝灯、下班从车间走到胡同、从绿皮车走到站台）。光源变化必须在分镜表中标注触发事件。

### 3.2 光源语句法（每个镜头必须包含）
[光源] 主光：{年代光源类型}，{方向}，{色温值K}，{软硬}
[光源] 辅光/环境光：{年代光源类型}，{方向}，{色温值K}
[光比] 约1:{X}

### 3.4 冷暖色调与叙事阶段

- **冷光主导**（5000K+）：车间劳作、绿皮车漂泊、百货秩序、录像厅隐秘、悬疑对峙、蓝调过渡
- **暖光主导**（1800-3500K）：筒子楼温情、胡同归家、居家日常、金色时刻、灶火煤球炉火段落
- **冷暖共存**：过渡时刻（蓝调时刻+初亮钨丝灯）、深夜心事（暖钨丝+冷屏光）、时代转折（车间冷+室内暖）
- **光源变化 = 叙事信号**：车间天光从冷白渐变至黄昏暖金=下班归家；从车间冷白走到胡同黄昏暖金下=场景与情绪的切换；绿皮车日光灯冷白到站台黄昏暖金=到家的情绪信号

### 3.5 Seedance 2.0 光影适配要点

- 色温数字帮助模型校准白平衡倾向：`钨丝灯泡约2600K` 优于 `暖光`
- 光比数字帮助模型建立明暗意识：`光比约1:4` 优于 `柔和的阴影`
- 光源必须有明确来源：`车间高窗天窗天光从上方漫射` 优于 `顶光`
- 环境光的反射路径描述：`机床金属与机油微反光` 优于 `金属反光`

每 3-4 个镜头至少安排一个有环境动态的镜头。静态对话戏也不例外——至少有一个镜头里车间天窗的粉尘光束在缓慢飘移、公用厨房灶火的火苗在跳动、绿皮车窗外的田野在飞掠。

### 4.3 Seedance 2.0 环境动态描述规范

- 动态必须有具体轨迹和速度：`灶火火苗跳动约2-3cm，每秒约3次不规则跳动` 优于 `火在动`
- 光源动态与空间光源逻辑一致：`云朵遮住自然光时，车间天窗天光面积缩小约30%，持续约3秒后恢复`
- 禁止无来源的动态：没有煤球炉=没有烟。室内没有开窗=没有风。绿皮车没启动=没有铁轨震动

### 5.1 动作描述铁律

所有人物动作必须描述：**轨迹 + 速度/时长 + 身体部位协调 + 对周围年代物体的影响**。

### 5.3 动作节奏与叙事场景

- **日常叙事/文戏**：动作沉稳克制，每个微动作标注时长和轨迹。节奏舒缓——不是慢，是"不赶"，符合年代人节奏
- **情绪波动场景**：动作幅度和速度略微增加。人物可能在对话中不自觉地加快摩挲搪瓷缸的频率、呼吸带动肩膀起伏更明显
- **冲突场景**：动作干脆利落，但仍有物理轨迹。推搡须具体到"右手推在对方左肩前方，对方重心向后偏移约20cm，撞翻身后的搪瓷盆，盆中水洒在水泥地"
- 禁止：无叙事理由的快速动作堆砌、无物理逻辑的瞬移、"做了个手势"等含糊描述

### 5.4 服饰动态

年代服饰的动态是画面的天然资产——不是"布料模拟参数"，而是"绿军装下摆被车间穿堂风吹起约15度角""军挎包肩带随蹬自行车动作上下微颤约2cm""麻花辫随转身甩到胸前约0.5秒"。在分镜表画面描述中标注年代服饰的动态细节。

## 六、空间逻辑具象化——Seedance 2.0 空间坐标系统

### 6.1 每镜头必须声明的空间信息
水平位置：画面左/中/右，或画面左侧三分之一处
纵深位置：距镜头{数值}米，前景/中景/背景
人物与场景的关系：距{固定物}{数值}米（如"距机床0.3米"）
（若双人以上）人物A与B的相对距离和朝向
### 6.2 站位衔接示例
【片段A尾部】
A站在车间机床前，距机床约0.3米，面朝机床，位于画面中央偏左，距镜头约4米。
车间高窗天窗天光从上方漫射，斜入光斑落在机床区。
A右手持搪瓷缸于胸前，缸口距嘴唇约15cm，缸口有热气。

【片段B开头】
A的搪瓷缸刚从嘴边下降约10cm，缸仍在胸前位置。A仍站在机床前（位置未变）。
车间天窗天光角度已略微西移，斜入光斑从机床区移向地面约30cm。
A的工装肘部磨白与机油印清晰可见。
### 6.3 空间变化必须具象

| 抽象（禁止） | Seedance 2.0 具象 |
|---|---|
| 他走近了 | A从画面背景（距镜头约5米、车间铁门位置）向镜头方向匀速行走4步（约3米），停在距镜头约2米处——耗时约4秒 |
| 两人面对面 | A位于画面中央偏左（距镜头约3米），B位于画面中央偏右（距镜头约3米），两人面对面，相距约0.8米，中间是公用厨房炉灶 |
| 从车间到胡同 | A从车间内（距镜头约3米）走向车间铁门，推开铁门（门向内旋转约80度发出吱呀声），右脚跨过门槛，进入厂区道路——厂区黄昏暖金光瞬间取代车间冷白天光 |

## 七、运镜规范——Seedance 2.0 摄影机运动

### 7.1 允许的运镜

| 运镜 | Seedance 2.0 描述 | 适用场景 |
|---|---|---|
| 固定 | 摄影机固定不动，画面静止 | 车间对话、筒子楼日常、空镜留白、情绪凝视 |
| 手持微晃 | 摄影机有轻微不规则晃动（幅度约±2cm），模拟手持拍摄的呼吸感 | 情绪波动、胡同行走、绿皮车厢内的晃动跟随 |
| 稳定器流动 | 摄影机平滑匀速移动，无晃动 | 厂区漫游、人物登场、空间展示、过渡 |
| 缓推 | 摄影机向主体缓慢推进，推进速率约每秒0.3米 | 情绪升温、真相逼近、注意力聚焦 |
| 缓拉 | 摄影机向后缓慢拉远，拉远速率约每秒0.3米 | 离别、收束、揭示车间全貌 |
| 跟拍 | 摄影机与人物保持约2米距离同步移动 | 胡同行走跟随、绿皮车过道追踪、自行车通勤 |
| 摇镜 | 摄影机原地水平/垂直旋转 | 视线转移、车间机床与标语的关系交代 |

### 7.2 禁用运镜

- 无叙事目的的快速甩镜、急推急拉（推拉速率超过每秒1米）
- 超过3秒的剧烈手持晃动（除非主观受击/眩晕/绿皮车颠簸叙事）
- 无逻辑花式转场——划屏、旋转、百叶窗、翻页等特效转场
- 摄影机无理由的360度旋转

### 7.3 真人年代怀旧运镜哲学

- 固定机位是第一选择——让观众看到真实年代人在真实年代空间里自然地存在
- 手持微晃在情绪段落与绿皮车/胡同行走段落使用——但晃动幅度不超过电影纪实风格的常规范围
- 运动镜头的起幅和落幅必须平稳，运动过程匀速——禁止突然加速或急停

| 转场 | 视觉执行 | 叙事功能 |
|---|---|---|
| 硬切 | 直接切换 | 同场戏内镜头切换（默认） |
| 光影匹配转场 | 两个场景在相近年代光影逻辑下切换 | 时间流逝、平行叙事。例：A处车间的天窗天光 → B处筒子楼走廊的窗光 |
| 空间匹配转场 | 两个空间在构图或元素上呼应 | 场景跳转。例：车间铁门关上的瞬间 → 筒子楼单元门打开的瞬间 |
| 空镜过渡 | 插入场景空镜（3-5秒） | 情绪缓冲、章节划分、时间流逝暗示（高烟囱冒烟、空车间机床、绿皮车窗外田野） |
| 焦点转场 | 前镜焦点从主体移至背景，后镜从模糊背景中逐渐聚焦主体 | 空间切换、注意力的转移 |

### 8.2 禁止的转场

- 纯视觉特效转场（翻页、划屏、百叶窗、马赛克）
- 无叙事逻辑的旋转/缩放转场
- 同一场戏内使用超过两种转场方式

## 十一、空镜使用规范

### 11.1 空镜不是"没东西拍"

空镜是年代情绪容器。每个空镜必须有叙事目的和具体的视觉内容：

| 空镜类型 | 叙事目的 | 示例 |
|---|---|---|
| 场景建立 | 新年代空间首次出现——让观众看清楚这是什么地方 | 国营厂车间大全景：机床排列、天窗天光、铁屑机油、墙上标语 |
| 情绪缓冲 | 高情绪段落后的喘息 | 筒子楼公用厨房灶火火苗跳动，约2-3cm每秒3次 |
| 时间流逝 | 暗示时间过去了 | 同一扇车间天窗的天光从清晨冷蓝渐变至黄昏暖金 |
| 隐喻留白 | 以年代物代情 | 工具台上半杯没喝完的搪瓷缸水，缸口有热气，把手有磕瓷 |
| 转场衔接 | 前后两个空间的自然过渡 | 厂区高烟囱冒烟——前一场车间，下一场是胡同黄昏 |

### 11.2 空镜 Seedance 2.0 描述规范

空镜也必须遵循年代光源+质感+动态的描述铁律：
车间高窗天窗天光从上方漫射（约5500-6500K冷白偏蓝），穿过空气中粉尘形成可见光束，
粉尘缓慢飘移约每秒5-10cm下沉，机床区金属反光随车间震动微颤，
约5秒后光束变暗——一朵云挡住了天窗天光。
机床表面有油污与铁屑，工具台上搪瓷缸杯口边缘有3处磕瓷露铁黑点。
