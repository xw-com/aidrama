# 都市现代写实风格说明

本风格专为"都市现代写实"题材打造，所有美术提示词、规范和生成内容均严格限定于：

- **现代世界观**：以现代都市生活流为背景，涵盖 CBD 玻璃幕墙街区、地铁通勤、共享办公、精品公寓、连锁咖啡馆等，杜绝现代元素缺失。
- **真人写实**：所有角色、场景、道具均以真人写实摄影为标准，强调五官、皮肤、发丝、材质等极致细节与真实质感。
- **自然光纪实**：在写实基础上以自然光纪实质感与现代时尚感为锚，蓝灰都市基调配暖色点缀，画面干净利落、层次分明，整体氛围高效、克制、快节奏。
- **快节奏生活氛围**：适合展现通勤、职场、独居、社交切换的现代都市生活故事，强调都市速度之下的人情温度。

## 适用范围

- 都市现代写实题材的AI美术生成（角色、场景、道具、分镜等）
- 需要极致写实、蓝灰时尚质感、现代都市生活流氛围的视觉创作

## 严禁内容

- 卡通、动漫、插画、二次元风格
- 现代元素缺失、古风/古装/传统建筑
- 高饱和荧光色、霓虹赛博撞色
- 暗示性、暴露、透视等不适宜内容

## 风格体验

在本风格下，您将体验到：

- 角色面容精致、气质干练或松弛，服饰、妆容、发型均为现代通勤与时尚写实
- 场景空间层次丰富，玻璃幕墙、金属、石材纹理超清晰，氛围真实且富有通勤节奏感
- 道具、手机、电脑、通勤包等均为现代造型，工艺精细，质感极致
- 分镜与视频均以真人写实为基础，强调快节奏生活流叙事与情感表达
