# 场景图生成 · 都市现代写实约束手册

---

## 一、场景美学原则

1. **空间叙事** — 场景承载情绪与叙事功能（通勤节奏/职场秩序/独居松弛），不是纯背景板
2. **层次纵深** — 所有场景必须具备前/中/后景，杜绝扁平
3. **质感至上** — 玻璃幕墙/金属/石材/混凝土/皮革等材质纹理必须超清晰
4. **实拍为锚** — 一切画面以真实摄影为标准，拒绝 3D 渲染/CG 动画质感；追求镜头光学特征（景深虚化、镜头暗角、色散微痕）与物理光照（天光漫射、幕墙反射、屏幕冷光、体积光）

| 冬 | 石墨灰 + 冷白 | 银灰、深海军蓝 | 冬日灰白、冷蓝夜幕 |

## 三、室内场景

### 空间规范

| 维度 | 约束 | 提示词 |
|---|---|---|
| 风格 | CBD 写字楼/共享办公/精品公寓/咖啡馆，现代简约/极简/轻工业风 | 现代{风格}风格 |
| 材质 | 石材/玻璃/金属/木材/皮革为主 | 石材地面、玻璃隔断、金属框架 |
| 色调 | 低饱和蓝灰 + 米白 + 暖点缀 | 蓝灰基调、米白、暖点缀 |
| 纵深 | 前/中/后景层次 | 前景{元素}、中景{元素}、后景{元素} |
| 质感 | 石纹/金属拉丝/皮革纹理可辨 | 纹理清晰、质感写实 |
| 光照 | 天光漫射+幕墙反射为主（屏幕冷光/轨道灯补充），光线干净利落，可见光束粒子、焦散投影 | 天光漫射、幕墙反射光、屏幕冷光 |
| 镜头感 | 浅景深虚化前后景、微镜头暗角、自然色温偏移 | shallow depth of field、lens vignette、natural color cast |
| 瑕疵感 | 地面有磨痕、玻璃有指纹微痕、桌面有使用痕迹 | 使用痕迹、石材磨痕、自然磨损 |

### 室内类型速查

| 类型 | 核心元素 | 氛围词 |
|---|---|---|
| CBD 写字楼大堂 | 石材地面、玻璃闸机、导视牌 | 冷峻开阔、商务秩序 |
| 共享办公空间 | 开放工位、白板、绿植、咖啡角 | 年轻高效、松弛协作 |
| 精品公寓 | 岛台、落地窗、皮质沙发、吧椅 | 精致现代、独居生活感 |
| 连锁咖啡馆 | 吧台、咖啡机、原木桌、幕墙玻璃 | 都市日常、快节奏喘息 |
| 会议室/洽谈室 | 玻璃隔断、长条桌、面板灯 | 理性克制、商务对峙 |

## 五、主视图规范

### 视图定义

> 单画面主视图，从场景中最具代表性的角度拍摄，承载空间叙事与构图重心。

| 项目 | 约束 | 提示词 |
|---|---|---|
| 视角 | 自然观察视角，构图最能体现场景主体与纵深 | hero shot、representative angle |
| 视点高度 | 默认人眼平视高度，特殊场景可俯/仰 | eye level（默认） |
| 构图 | 主体居中或符合三分法，前/中/后景层次清晰 | balanced composition |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 单画面（非拼图、非多视图、非分屏） |
| 人物 | **严禁出现任何人物、人影、人体轮廓** |
| 一致性 | 风格/材质/色调/光线统一 |
| 光线 | 单一光源逻辑，光影方向一致 |
| 画面比例 | 默认 16:9（或按调用方设定） |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 场景必须有「前中后景层次」 |
| R2 | 室外必须包含「空气透视」 |
| R3 | 场景图必须为「单画面主视图」，不得拼接多视图/分屏/网格 |
| R4 | 构图须能代表场景主体并展示前/中/后景层次 |
| R5 | 场景图中**严禁出现任何人物** |
| R6 | 必须包含实拍摄影关键词（real photography / photorealistic / RAW photo） |
| R7 | 必须包含镜头光学特征（shallow depth of field / lens vignette / bokeh 至少一项） |
| R8 | 材质必须带有自然磨损/使用痕迹，禁止全新无瑕的"CG 感" |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 背景纯白/纯黑/无场景 |
| X2 | 极端天候（暴风雨/雷电/暴雪，除非剧情需要） |
| X3 | 场景无纵深/无层次 |
| X4 | 植被/天候与季节矛盾 |
| X5 | 出现任何人物、人影、人体剪影或人体轮廓 |
| X6 | 画面被拼接成多视图/网格/分屏布局 |
| X7 | 3D 渲染/CG 动画/卡通/游戏引擎质感（禁用 3D render、CGI、Unreal Engine、Unity 等词） |
| X8 | 材质过于干净完美、无任何使用痕迹与通勤感（避免"塑料感"） |
| X9 | 光照过于均匀平坦、无景深虚化、无镜头光学特征 |
