# 都市现代写实风格约束 · 技法参考

---

## 一、色调体系与画面基调

- **色调基底** — 全片以云雾白（C1）、暖调肤色（C2）、都会蓝灰（C3）、石墨灰（C5）为基底色，整体色温中性偏冷（5000-5600K），饱和度低至中低（35-55%），呈现干净利落的现代都市生活感
- **冷暖叙事对比** — 暖色（琥珀暖橙 C7、浅驼杏 C10）作为情感升温与生活回归的视觉信号，冷色（都会蓝灰 C3、深海军蓝 C6）用于通勤、职场、压力、疏离等段落。冷暖切换应与情绪弧线同步
- **冷暖分配策略** — 通勤与办公段落以蓝灰冷调为主，咖啡馆与居家段落释放暖色；暖色克制使用，避免全程偏暖导致都市感与情绪层次塌陷
- **色盘先行原则** — 段落规划先绑定情绪场景（通勤/偶遇/加班/冲突/回暖等），再确定主色+辅色与光影方案，避免"剧情对了但情绪不对色"
- **禁用色域** — 高饱和荧光色、霓虹赛博污染、浓艳撞色与本风格不兼容


---

## 二、光影方案体系

- **光影即叙事** — 6 套光影方案对应不同情绪段落，导演规划阶段应在段落层面确定光影基调方向，而非逐镜指定
- **光源角度** — 正给镜头默认 45° 斜侧天光（干净利落），情绪镜头转逆光/半逆光勾勒轮廓

| 光影方案 | 方案名 | 色调倾向 | 适用情绪 |
|---|---|---|---|
| A | 晨光漫射 | 蓝灰底 + 均匀天光 | 晨间通勤、生活流开场 |
| B | 幕墙反射柔光 | 蓝灰 + 高光冷白 | 日间办公、商务推进 |
| C | 顶光+屏幕冷光 | 石墨灰 + 冷白 | 深夜加班、理性克制 |
| D | 单点暖光 | 琥珀暖橙主导 + 深海军蓝背景 | 夜归独处、温情释放 |
| E | 车灯流动光 | 冷色流动 + 暖点点缀 | 晚高峰、都市节奏 |
| F | 阴雨漫射 | 灰蓝主调 + 暖砂局部 | 低潮段、过渡段 |

- **冷暖光分配** — 暖色光可全片使用但需分层控制；冲突/疏离段落降低暖光占比，避免情绪与光色冲突
- **氛围方向映射** — 每场戏氛围方向应映射到上述光影方案（A-F）的某一方向，确保视觉一致性

## 三、质感方向

- **超清纪实质感** — 真人写实摄影核心：皮肤纹理可见、发丝根根分明、材质细节清晰可信
- **自然光纪实 + 现代时尚感** — 作为画面质感锚点。不是柔光梦幻大片，不是霓虹夜景风，而是可落地实拍的现代都市纪实感
- **焦段与景深** — 35mm 纪实跟拍、50mm 客观肖像、85mm 压缩特写；浅景深虚化人流与幕墙，制造都市中的"焦点隔离"
- **材质真实** — 服化道需具备现实可信度：西装面料、幕墙玻璃反射、石材地面、金属器件、电子屏幕高光都应符合都市实拍逻辑
- **皮肤质感** — 保留真实毛孔与细微瑕疵，控制磨皮强度，追求"真实但好看"

## 四、都市现代场景空间元素

都市现代生活流特有的场景元素及其视觉叙事功能：

- **玻璃幕墙/幕墙反射** — CBD 的天然镜面，提供双重构图与人物镜像，制造虚实分层与都市体量感
- **地铁/闸机/电梯/写字楼走廊** — 快节奏载体，通勤与停顿的切换可直接映射角色心理状态
- **共享办公/会议室/咖啡角** — 职场情绪容器：工位偏协作，会议室偏对峙，咖啡角偏喘息与偶遇
- **精品公寓/岛台/落地窗** — 独居生活感的锚点，用于松弛段落与夜归独处
- **空镜过渡建议** — 幕墙反光流动、地铁隧道频闪、咖啡机蒸汽、电梯数字跳动，可作为段落呼吸口与时间流逝暗示
- **视觉转折建议** — 优先使用画面手段（景别突变、幕墙镜像错位、人流虚化与静立对比）承接情绪转折，减少对白解释负担

## 五、都市现代乐器与环境音

都市现代生活流下的声音元素约束：

### 乐器选择

- **钢琴** — 日常、独处、回忆段落核心乐器，最能体现都市生活质感
- **轻电子/Lo-fi** — 年轻化、通勤流、办公推进段落的节奏底色
- **吉他** — 周末松弛、咖啡馆、轻快段落的有效主导
- **弦乐** — 情绪抬升与冲突爆发段落的主力铺底
- **合成器 Pad** — 城市夜景、转折段落的氛围铺底
- **环境音优先级高** — 都市剧中真实环境声是沉浸感关键，配乐不应压过对白

### 乐器组合策略

| 情绪阶段 | 乐器组合 |
|---|---|
| 平稳/开场/收尾 | 钢琴独奏 或 轻电子底 |
| 通勤/日常推进 | 轻电子 + 轻打击 |
| 暧昧升温/浪漫 | 钢琴 + 弦乐 |
| 冲突/爆发 | 弦乐主导 + 低频铺底 |
| 夜景/转场 | Lo-fi/轻电子 + 环境声 |

### 都市现代环境音

- **典型环境音层次** — 地铁进站与提示音 / 闸机滴声 / 电梯到层提示 / 键盘敲击 / 咖啡机蒸汽 / 车流与鸣笛 / 空调新风底噪 / 手机消息提示音
- **每场戏标注 1-2 个核心环境音**，帮助后续音效设计。环境音层次越准确，都市现代生活质感越强
- **留白建议** — 快节奏风格中也需呼吸：冲突后保留 1-2 秒纯环境音再进配乐，避免情绪连续轰炸
