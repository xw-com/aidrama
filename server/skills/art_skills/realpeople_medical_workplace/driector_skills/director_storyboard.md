# 分镜提示词 · 真人医疗职场 · 风格专属技法

---

## 适用范围

本 Skill 专用于**真人医疗职场**风格的分镜提示词生成，适配医疗剧情、急救危急、手术专注、病房治愈、医患温情、职业坚守等真人实拍医疗影视题材的分镜创作。

---

## 一、摄影机前的情绪——面孔、眼神、微表情

> 真人医疗职场的情绪不来自"义体光效"或"渲染参数"，而来自真实医护在摄影机前的微表情，以及口罩上方那双被凝视的眼睛。以下映射面向摄影机捕捉真实医护的方式。

| 情绪输入 | 面容描述 | 眼神描述 | 微表情补充 |
|---|---|---|---|
| 专注 / 沉稳 | 口罩上方眉骨轻绷，面部线条自然不紧绷 | 眼神笃定，注视手术野/病人不移开 | 眼睛微收窄，额头可能有手术帽勒痕，气场沉稳专业 |
| 疲惫 / 倦怠 | 眼窝微陷，面部整体松弛，眼下暗沉明显 | 目光朦胧，眼皮微沉，仍努力聚焦 | 眉眼低垂，可能的黑眼圈，口罩压痕明显，表情松弛 |
| 温柔 / 安抚 | 口罩上方眉目舒展，面部柔和 | 眼神温润专注，像在认真听病人说哪里不舒服 | 眼角可能微弯（口罩下的微笑感），有温度但不夸张 |
| 紧张 / 戒备（青涩） | 口罩上方眉骨微绷，面部有克制的小幅度活动 | 眼神发亮但带一丝紧绷，瞳孔有光但游移 | 第一次进手术室/第一次单独值班的紧绷，呼吸略浅 |
| 紧迫 / 决断（急诊） | 面部线条微微绷紧，下颌收紧，不夸张 | 眼神锐利沉稳，注视有力，随时准备决策 | 表情克制紧绷，身体语言前倾，动作干脆利落 |
| 惊讶 / 触动 | 眼尾微抬，眉毛自然上扬 | 眼神骤然聚焦，瞳孔微扩 | 口罩上方眼睛睁大，表情鲜活不夸张 |
| 沉思 / 诊断 | 神情淡然，眼部周围肌肉放松 | 目光放远失焦，像在看监护仪但不在看 | 表情平静，可能单手托腮或持病历轻点 |
| 坚守 / 坚毅 | 面部线条厚重，下颌微抬 | 眼神笔直向前，不回避不躲闪 | 下巴微收或微抬，表情果敢但不夸张，沧桑里的仁心 |
| 悲悯 / 无力 | 眉眼低垂，面部肌肉松弛 | 目光涣散失焦，望向窗外或病人 | 嘴角自然下沉（口罩下），表情怅然，对生命的无力感 |
| 释然 / 希望 | 眼角出现自然笑纹，眼型微弯 | 眼神明亮有光，眼角有笑意牵动 | 口罩上方眼睛弯起（口罩下的微笑），面颊微动 |

## 二、摄影机前的光——医疗光源逻辑与氛围

### 2.1 医疗专业光源

| 光源 | 光源行为 | 色温与色调 | 空间氛围 |
|---|---|---|---|
| 无影灯 | 手术台正上方垂直下泄、均匀无影、显色性极高、不锈钢器械冷反光 | 5000-6000K冷白均匀 | 手术专注、生死博弈、无菌冷静 |
| 日光灯管（走廊/门诊/病房日间） | 顶光均匀、略有频闪感、地面光泽反光 | 4000-5000K冷白顶光 | 秩序运转、日常诊疗、职场克制 |
| 病房夜灯 | 床头低位照明、暖黄柔和低照度、不打扰病人、配合窗外冷蓝月色 | 约2700K暖黄 | 深夜守护、温柔治愈、安静 |
| 监护仪/呼吸机屏幕 | 冷蓝绿点阵光、波形与数字发光、映在人物一侧脸颊 | 约6500K冷蓝 | 重症守望、理性克制、24小时不间断 |
| 急诊冷调主光 | 冷白偏蓝、混入警示灯与监护光、平车反光 | 4500-5500K冷调 | 紧迫危急、命悬一线、高压张力 |
| 值班室台灯 | 单点暖黄孤岛式照明、电脑屏冷光补面、大范围暗部 | 2800-3000K暖黄 | 疲惫坚守、脆弱私密、一个人的时刻 |
| 晨光（清晨开诊） | 窗外晨光斜入+门诊日光灯、明亮通透 | 5000-5500K中性偏冷通透 | 希望、新生、一天的秩序开始 |

## 四、摄影机语法——镜头选择与运动

### 4.1 焦段选择

| 焦段 | 叙事性格 | 适用场景 |
|---|---|---|
| 24-28mm广角 | 空间包围人物、秩序的压迫感、医院宏大与个体渺小 | 手术室大全景、急诊大厅、长走廊纵深、门诊大厅空镜 |
| 35mm小广角 | 主观视点，身临其境的纪实感，人与环境共存 | 查房跟随、医护走动、护士站交接班、医患对话 |
| 50mm标准 | 人眼等价，客观中立的注视，最诚实的镜头 | 医护肖像、医患对话、情感凝视 |
| 85mm中长焦 | 压缩空间，拉近情感距离，背景虚化突出人物 | 口罩上方眼神特写、缝合手指特写、监护数字特写 |
| 135mm+长焦 | 将人物从环境中剥离，极端的注视或窥视 | 走廊尽头远眺的医生、手术室观察窗外的注视 |

### 4.2 景别选择

| 景别 | 取景范围 | 叙事功能 |
|---|---|---|
| 大特写 | 眼睛/口罩压痕/手指/器械细节 | 情绪爆发点、关键操作、感官聚焦 |
| 近景 | 头顶至胸部以上 | 医护情感、对话反应、口罩上方眼神 |
| 中近景 | 头顶至腰部 | 医护互动、操作动作、查房中的身体语言 |
| 中景 | 头顶至膝盖上下 | 医护团队、查房小组、多人同框 |
| 全景 | 人物全身+部分环境 | 医护在空间中的位置、抢救现场全貌 |
| 大全景/空镜 | 空间全貌，人物极小或无人物 | 空间叙事、情绪缓冲、无影灯下空手术台 |

### 4.3 摄影机运动

| 运动方式 | 视觉心理 | 使用场景 |
|---|---|---|
| 固定 | 冷静观察，让生命自己说话 | 日常诊疗、医患对话、监护凝视、空镜留白 |
| 手持微晃 | 在场感，呼吸感，紧迫的主观介入 | 急救抢救、医护小跑、情绪波动、抢救推车跟随 |
| 稳定器流动 | 优雅的查房漫游，诗意 | 查房长镜头、医生登场、走廊推移 |
| 缓推 | 注意力逐渐聚焦、情绪趋近 | 对话升温、诊断逼近、注意力聚焦 |
| 缓拉 | 拉开距离、揭示全貌、情绪抽离 | 离别（病人离世）、章节收束、揭示抢救全貌 |
| 跟拍 | 与医护同行、主观陪同 | 查房行走、推平车追踪、医护日常跟随 |
| 摇镜 | 视线转移、空间关系交代 | 医生视线引导（病人↔监护仪）、空间关系 |

## 五、固定风格锚定词

**摄影锚定（必选）：**

真人实拍摄影，真人电影剧照，当代中国医院医疗职场，电影级摄影，无影灯/日光灯/夜灯专业光源调度，真实色彩科学

**人物质感（含人物镜头时必选）：**

真人写实摄影质感，真实医护皮肤纹理毛孔可见与职业痕迹（口罩压痕/手术帽勒痕/夜班疲态），不磨皮不硅胶脸，发丝自然质感有碎发（束发/手术帽下被压扁的鬓角），医护服饰面料纹理可见有穿着洗涤褶皱（白大褂/洗手衣/手术衣），自然微表情，真实职业体态

**场景质感（含场景镜头时必选）：**

真人实拍医疗职市场景摄影，真实医疗材质与使用痕迹（不锈钢器械消毒膜/医白墙面消毒水渍/光泽地胶磨损），光源方向明确可追溯（无影灯/日光灯/夜灯/监护屏），大气透视自然，非样板医院非效果图

**参考图一致性锚定（参考图模式必选）：**

保持医护造型、面容、发型、服饰与参考图完全一致，保持场景风格与参考图一致，保持医疗光影色彩基调统一，所有镜头呈现为同一医护的连续摄影记录

**风格收尾（固定）：**

真人写实摄影，当代中国医疗职场电影质感，电影级摄影画面，非3D非渲染非CG

**画质锁定词：**

模式A（中文）——默认：
真人摄影高清画质，电影级画面质感，画面无字幕、无水印、无标题叠字、无UI元素

模式A（中文）——画内文字场景（画面中含科室牌/病历/药品标签/叫号屏等道具文字时）：
真人摄影高清画质，电影级画面质感，画面无字幕、无水印、无标题叠字、无UI元素，科室牌/病历/药品标签/叫号屏等场景道具上的文字清晰可辨

模式B（英文）——默认：
live-action cinematic photography, real human medical staff skin texture, contemporary Chinese hospital, cinematic color science, surgical lamp/fluorescent/night lamp practical lighting, high detail, no subtitles, no captions, no watermark, no title overlay, no UI elements

模式B（英文）——画内文字场景：

## 六、美学禁止项

以下词汇/风格不得出现于输出提示词中：

- ❌ 3D渲染 / 3D建模 / CG / UE引擎 / Blender / PBR材质 / 次世代建模 / 体积光 / 环境光遮蔽 / 光线追踪
- ❌ 2D手绘 / 插画 / 动画 / 二次元 / 漫画 / Q版 / 低多边形
- ❌ 写实摄影（英文禁止 photorealistic / realistic photography——真人医疗职场是"真人实拍摄影"live-action cinematic photography，不是"拟真渲染"）
- ❌ 过度磨皮 / 塑料假面 / 零毛孔 / 硅胶脸 / 蜡像感 / AI感平滑
- ❌ 古风 / 古装 / 汉服 / 仙侠 / 武侠 / 民国 / 宫廷 / 校园 / 豪门奢华 / 市井烟火居家 / 赛博朋克 / 科幻机甲 / 西方奇幻 / 中世纪
- ❌ 人体结构错误 / 肢体畸形 / 面部崩坏 / 比例失调
- ❌ 高饱和荧光色 / 霓虹溢色 / 廉价滤镜感 / 血腥过度渲染
- ❌ 非中国当代医院的架空场景 / 无中文标识的 generic hospital
- ❌ 浓妆 / 红唇 / 美甲 / 垂坠耳环（违反医护职业真实）
