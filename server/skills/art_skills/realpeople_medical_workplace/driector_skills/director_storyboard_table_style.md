## 一、分镜表定位

分镜表是导演将剧本转化为镜头语言的核心工具。本约束面向 Seedance 2.0 视频生成，所有光影、动作、空间描述均采用模型可执行的具象语言。不做抽象的情感概括，不写模型看不懂的渲染参数。

## 三、光影与氛围——Seedance 2.0 物理光源描述

### 3.1 同场戏光影统一

一场戏内不应出现两种以上核心光影方案，除非有叙事驱动的光源变化（如手术结束关闭无影灯、从手术室走到走廊、夜晚病房只留夜灯）。光源变化必须在分镜表中标注触发事件。

### 3.2 光源语句法（每个镜头必须包含）
[光源] 主光：{医疗光源类型——无影灯/日光灯/夜灯/监护屏}，{方向}，{色温值K}，{软硬}
[光源] 辅光/环境光：{光源类型}，{方向}，{色温值K}
[光比] 约1:{X}
### 3.3 情绪 → 光源矩阵

| 情绪 | 光源配方（Seedance 2.0 可直接填入） | 视觉关键词 |
|---|---|---|
| 手术专注 | 无影灯冷白主光（5000-6000K）从手术台正上方垂直下泄，环境辅助光。光比约1:2 | 冷白均匀无影、器械冷反光 |
| 日常诊疗 | 走廊/门诊日光灯冷白顶光（4000-5000K），日间窗光补面。光比约1:2.5 | 中性偏冷、秩序运转 |
| 病房守护 | 病房夜灯暖黄主光（约2700K），窗外冷蓝月色对冲，监护波形微光。光比约1:4 | 暖调包裹、治愈陪伴 |
| 急救危急 | 急诊冷调主光（4500-5500K），警示灯/监护仪光点缀，平车反光。光比约1:6 | 冷调高张力、紧迫 |
| 重症守望 | 监护仪/呼吸机屏幕冷蓝光（约6500K）主导，环境沉入暗部，仪器指示光。光比约1:8 | 极冷调、理性克制 |
| 深夜值班 | 值班室台灯暖黄单点光源（2800-3000K），电脑屏冷光补面，大范围暗部。光比约1:8 | 暖光孤岛、疲惫私密 |
| 希望治愈 | 清晨自然光+日光灯（5000-5500K）明亮通透，窗外晨光斜入。光比约1:1.5 | 高调通透、希望新生 |
| 紧张对峙 | 冷暖光对冲（无影灯冷白+室内暖灯/窗外冷蓝+夜灯暖黄）。光比约1:8 | 大光比、伦理冲突 |

### 3.4 冷暖色调与叙事阶段

- **冷光主导**（4500K+）：手术专注、急诊危急、重症监护、职场克制、深夜走廊
- **暖光主导**（2700-3000K）：病房守护、深夜值班、温情节拍、希望治愈
- **冷暖共存**：过渡时刻（手术室冷白→病房夜灯暖）、夜班（冷走廊+暖值班室）
- **光源变化 = 叙事信号**：手术结束无影灯从全亮到关闭=一场博弈的终结；从急诊冷调走到病房夜灯暖黄=从危急切到守护；监护仪波形从规律到不规则=病情恶化

### 3.5 Seedance 2.0 光影适配要点

- 色温数字帮助模型校准白平衡倾向：`色温约5500K无影灯冷白` 优于 `手术室亮光`
- 光比数字帮助模型建立明暗意识：`光比约1:8监护仪蓝光主导` 优于 `昏暗的ICU`
- 医疗光源必须有明确来源：`无影灯从手术台正上方垂直下泄` 优于 `顶光`
- 监护屏光的映照路径描述：`监护仪冷蓝光映在病人右脸颊` 优于 `脸上有蓝光`

## 四、环境动态——让画面呼吸

### 4.1 动态密度

每 3-4 个镜头至少安排一个有环境动态的镜头。静态对话戏也不例外——至少有一个镜头里监护仪的波形在跳动、输液袋里的药液在缓慢滴落、窗帘被空调风轻吹。

### 4.2 医疗环境动态元素（Seedance 2.0 可执行）

| 场景 | 可描述的环境动态 |
|---|---|
| 手术室 | 无影灯光斑稳定但器械冷反光随医护动作移动、监护仪波形规律跳动（约每0.8秒一次QRS）、麻醉机送气囊规律起伏、手术室空气中的微尘在无影灯光束中飘动 |
| 急诊抢救大厅 | 监护仪数字与波形快速变化、警示灯偶闪、输液袋药液滴落（约每秒一滴）、医护快速走动带起衣摆、平车被推行时轮子滚动声 |
| 病房 | 输液袋药液缓慢滴落、监护仪波形规律跳动（日间）、窗帘被空调风轻鼓约10cm后回落（约2秒周期）、床头柜水杯水面微晃、窗外光线随云朵移动明暗变化 |
| ICU | 多台监护仪波形各自规律跳动、呼吸机送气节律（约每3秒一次）、输液泵指示灯闪烁、报警光偶闪、空气中的安静（仅低频嗡鸣） |
| 办公室/值班室 | 电脑屏幕光映在天花板、台灯光斑稳定、键盘敲击时屏幕内容变化、窗外光线随时间变化、空调低鸣 |
| 走廊/门诊 | 日光灯管微弱频闪、推车轮子在地胶上滚动、自动门开合、叫号屏幕数字跳动、远处医护脚步声由远及近 |

### 4.3 Seedance 2.0 环境动态描述规范

- 动态必须有具体轨迹和速度：`监护仪波形规律跳动，约每0.8秒一次QRS波` 优于 `监护仪在动`
- 光源动态与空间光源逻辑一致：`无影灯被调整时，冷白光斑从垂直变为偏左斜照约30度，持续约2秒`
- 禁止无来源的动态：监护仪报警必须有病情触发逻辑、手术器械的移动必须有操作者

## 五、人物动作节奏——Seedance 2.0 物理逻辑具象化

### 5.1 动作描述铁律

所有医护动作必须描述：**轨迹 + 速度/时长 + 身体部位协调 + 对周围物体/病人的影响**。

### 5.2 医护日常动作具象库

| 动作 | Seedance 2.0 可执行描述 |
|---|---|
| 戴听诊器 | 双手将听诊器耳管轻轻分开约5cm，将耳管挂入双耳，胸件（听头）贴在病人胸前左锁骨中线位置，食指与中指轻按胸件，凝神倾听约5秒——全程约7秒 |
| 查房记录 | 左手持病历夹于胸前，右手持笔在医嘱单相应栏位书写，笔尖与纸面接触发出轻微沙沙声，视线在病人与病历间切换，全程约4秒 |
| 推抢救平车 | 双手握住平车床头推杆，身体前倾约15度，步伐加快至每秒约两步，平车轮子在光泽地胶上快速滚动发出急促声响，平车沿走廊向抢救室方向直行约8米，全程约5秒 |
| 调整无影灯 | 右手握住无影灯手柄，向下拉约20cm并将灯头向手术野左上方旋转约30度，冷白光斑（约5500K）从垂直变为偏左斜照，光斑中心精准落在切口区域——全程约2秒 |
| 看监护仪 | 头向右转约45度，视线从病人面部移至床旁监护仪屏幕，绿色QRS波形规律跳动，心率数字76次/分（中文界面），注视约2秒后转回 |
| 手消毒 | 双手挤约3ml手消液于掌心，双手掌心相对互搓约5次，左手掌心覆盖右手背交叉搓洗再换手，指尖在掌心旋转搓洗，全程约30秒，皮肤呈现消毒后的湿润光泽 |
| 静脉注射 | 左手在病人前臂扎紧止血带，右手取注射器，食指轻弹注射器排出空气，针头以约15度角刺入静脉，回抽见血后推注药液，全程约8秒 |
| 推门进入病房 | 右手握住门把手向下转动约30度，向内推开门约70度角，身体随门进入，右脚先跨过门槛，白大褂下摆随转身摆动——全程约2秒 |
| 交接班 | 两名护士在护士站站立相对，一人手持交接班记录本，手指在记录上逐项指过，另一人点头确认，视线在记录与电脑间切换——全程约6秒 |
| 安抚家属 | 医生面对家属，身体微微前倾约10度，右手轻抬约15度做安抚手势，口罩上方的眼睛温润专注，嘴唇在口罩下微动（说话），家属点头——全程约4秒 |

### 5.3 动作节奏与叙事场景

- **日常诊疗/文戏**：动作沉稳克制，每个微动作标注时长和轨迹。节奏舒缓——不是慢，是"专业不慌"
- **急救/手术段落**：动作干脆利落但仍有物理轨迹。抢救操作须具体到"双手按压胸骨中下1/3交界处，垂直下压约5cm，频率约每分钟100次"
- **情绪波动场景**：动作幅度和速度略微变化。疲惫的医生可能扶额、揉眼、靠墙；紧张的规培生可能手指敲击、呼吸加快
- 禁止：无叙事理由的快速动作堆砌、无物理逻辑的瞬移、"做了个操作"等含糊描述

### 5.4 服饰动态

医护服饰的动态是画面的天然资产——不是"布料模拟参数"，而是"白大褂下摆随快走摆动约15度角""手术帽边缘被汗水浸湿变深约2cm""护士服袖口在记录时上移露出腕部手表"。在分镜表画面描述中标注服饰的动态细节。

## 六、空间逻辑具象化——Seedance 2.0 空间坐标系统

### 6.1 每镜头必须声明的空间信息
水平位置：画面左/中/右，或画面左侧三分之一处
纵深位置：距镜头{数值}米，前景/中景/背景
人物与医疗固定物的关系：距{病床/器械台/护士站/监护仪}{数值}米
（若双人以上）医护A与B/医护与病人的相对距离和朝向
### 6.2 站位衔接示例
【片段A尾部】
主刀医生站在手术台右侧，距台沿约0.3米，面向手术野，位于画面中央偏右，距镜头约3米。
无影灯冷白光（约5500K）从正上方垂直下泄。
主刀右手执笔式持手术刀在切口位置，刀刃与皮肤约45度。

【片段B开头】
主刀的右手刚从手术刀上移开，器械护士递上止血钳，主刀接过。
主刀仍站在手术台右侧（位置未变）。
监护仪波形规律跳动（约每0.8秒一次），心率数字76次/分。
### 6.3 空间变化必须具象

| 抽象（禁止） | Seedance 2.0 具象 |
|---|---|
| 她走近病床 | A从画面背景（距镜头约5米、病房门口位置）向镜头方向匀速行走4步（约3米），停在病床右侧距床沿约0.3米处——耗时约4秒 |
| 两人面对面 | 主刀A位于画面中央偏左（距镜头约3米，手术台右侧），一助B位于画面中央偏右（距镜头约3米，手术台左侧），两人面对面隔手术台相望，相距约1.2米 |
| 从手术室到走廊 | 主刀从手术台右侧（距镜头约3米）走向手术室门，推开门（门向外旋转约80度），右脚跨出门槛，进入走廊——走廊日光灯冷白光（约4500K）瞬间取代手术室无影灯冷白光（约5500K），光质从均匀无影变为顶光带阴影 |

## 七、运镜规范——Seedance 2.0 摄影机运动

### 7.1 允许的运镜

| 运镜 | Seedance 2.0 描述 | 适用场景 |
|---|---|---|
| 固定 | 摄影机固定不动，画面静止 | 日常诊疗、医患对话、监护凝视、空镜留白 |
| 手持微晃 | 摄影机有轻微不规则晃动（幅度约±2cm），模拟手持拍摄的呼吸感 | 急救抢救、医护小跑、情绪波动、主观视角 |
| 稳定器流动 | 摄影机平滑匀速移动，无晃动 | 查房长镜头、医生登场、走廊推移、空间展示 |
| 缓推 | 摄影机向主体缓慢推进，推进速率约每秒0.3米 | 情绪升温、诊断逼近、注意力聚焦 |
| 缓拉 | 摄影机向后缓慢拉远，拉远速率约每秒0.3米 | 离别（病人离世）、章节收束、揭示抢救全貌 |
| 跟拍 | 摄影机与医护保持约2米距离同步移动 | 查房行走、推平车追踪、医护跟随 |
| 摇镜 | 摄影机原地水平/垂直旋转 | 视线转移（病人↔监护仪）、空间关系交代 |

### 7.2 禁用运镜

- 无叙事目的的快速甩镜、急推急拉（推拉速率超过每秒1米）——除非抢救段落的主观紧迫
- 超过3秒的剧烈手持晃动（除非抢救/眩晕叙事）
- 无逻辑花式转场——划屏、旋转、百叶窗、翻页等特效转场
- 摄影机无理由的360度旋转

### 7.3 真人医疗职场运镜哲学

- 固定机位是第一选择——让观众看到真实的医护在真实医院空间里专业地存在
- 手持微晃在急救/抢救段落使用——但晃动幅度不超过电影纪实风格的常规范围
- 运动镜头的起幅和落幅必须平稳，运动过程匀速——禁止突然加速或急停

## 八、转场规范

### 8.1 允许的转场方式

| 转场 | 视觉执行 | 叙事功能 |
|---|---|---|
| 硬切 | 直接切换 | 同场戏内镜头切换（默认） |
| 光影匹配转场 | 两个场景在相近医疗光影逻辑下切换 | 时间流逝、平行叙事。例：A处手术室无影灯冷白 → B处手术室无影灯冷白 |
| 空间匹配转场 | 两个空间在构图或元素上呼应 | 场景跳转。例：手术室门关上的瞬间 → 病房门打开的瞬间 |
| 空镜过渡 | 插入场景空镜（3-5秒） | 情绪缓冲、章节划分、时间流逝暗示（如无影灯下空手术台→监护仪独自跳动） |
| 焦点转场 | 前镜焦点从主体移至背景（监护仪），后镜从模糊背景中逐渐聚焦主体（医生） | 空间切换、注意力的转移 |

### 8.2 禁止的转场

- 纯视觉特效转场（翻页、划屏、百叶窗、马赛克）
- 无叙事逻辑的旋转/缩放转场
- 同一场戏内使用超过两种转场方式

## 十一、空镜使用规范

### 11.1 空镜不是"没东西拍"

空镜是情绪容器。每个空镜必须有叙事目的和具体的视觉内容：

| 空镜类型 | 叙事目的 | 示例 |
|---|---|---|
| 场景建立 | 新医疗空间首次出现——让观众看清楚这是什么地方 | 手术室大全景：无影灯、手术床、器械台、麻醉机 |
| 情绪缓冲 | 高情绪段落后的喘息（如抢救后） | 监护仪屏幕的波形从急剧变为规律，约5秒 |
| 时间流逝 | 暗示时间过去了 | 同一扇病房窗外的天色从午后变蓝调时刻 |
| 隐喻留白 | 以物代情 | 无影灯下空手术台，器械台已收拾（一台手术刚结束） |
| 转场衔接 | 前后两个空间的自然过渡 | 长走廊日光灯——前一场的手术室，下一场是病房 |

### 11.2 空镜 Seedance 2.0 描述规范

空镜也必须遵循光源+质感+动态的描述铁律：
监护仪屏幕的绿色QRS波形规律跳动（约每0.8秒一次），心率数字稳定在76次/分（中文界面），
冷蓝光（约6500K）映在半暗的ICU墙面上，
呼吸机送气囊规律起伏（约每3秒一次），
画面中无人，只有生命仪器的光与节律——约5秒的静止，
墙面医白有消毒水渍与使用痕迹，不锈钢床栏有冷反光。
