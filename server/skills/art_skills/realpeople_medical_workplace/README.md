## 一、风格核心定义

**真人医疗职场**是以**真人影视摄影美学**为基准、以**当代中国医院/医疗职场**为核心的视觉风格体系。其核心特征为：

- **真人写实摄影质感**：以真人影视级摄影为锚点，画面呈现真实医护人员的皮肤纹理、毛发细节、白大褂与洗手衣的织物特征、不锈钢医疗材质的金属反光，杜绝3D建模感、CG渲染感、手绘感
- **当代中国医疗世界观**：所有场景严格限定于当代中国医院空间——手术室（无影灯）、急诊抢救大厅、普通病房、ICU重症监护、医生办公室/值班室、医院长走廊、门诊/挂号大厅、检验科/影像科、护士站等真实医疗职场场景
- **电影级摄影语言**：以院线级医疗题材影视摄影为基准，强调无影灯/日光灯/夜灯的专业光源调度、构图叙事的专业性、景深与焦点的情绪表达、色彩分级的电影感
- **医疗职场人文温度感**：在保持专业影像品质的前提下，强调医护人员的职业坚守、医患之间的真实情感连接、生死瞬间的审美提炼

### 创作理念与核心价值

本手册的核心创作理念为 **"专业即力量，真实即温度"**：

1. **真实感的审美回归**：在AI生成影像日趋泛滥的当下，真人写实质感以其不可替代的真实力量，成为最具情感穿透力的视觉语言。医护人员被口罩压出红痕的面颊、手术帽下被汗水浸湿的鬓发、白大褂被反复洗涤后的微微泛旧、不锈钢器械上的消毒水膜——这些真实细节构成了一种生命质感，是3D渲染无法复刻的审美深度。

2. **医疗空间的叙事容器**：当代中国医院是中国人最熟悉的"生死叙事空间"。手术室的无影灯承载着生与死的博弈，急诊大厅的平车回响着命悬一线的紧迫，病房的夜灯下守着家属的疲惫与希望，值班室的一盏台灯是深夜医生的孤岛——医疗空间本身就是一个巨大的叙事容器，等待被挖掘。

3. **人本主义的视觉立场**：本手册坚持以"人"为核心——尤其是"作为职业人的医护者"。无论场景多么专业、器械多么精密，最终回归到人物的职业状态与内心世界。每一帧画面都是一次对生命的注视、对坚守者的凝视。

4. **专业与日常的临界点**：寻求"医疗的专业感"与"职场的真实感"之间的微妙平衡——画面足够专业、有医疗现场感，但不过度渲染血腥恐怖；人物足够真实、足够生动，但保留职业者的尊严与克制。

**核心价值：**

- 为AI视觉创作者提供一套系统化、可复用的真人医疗职场题材提示词方法论
- 建立从概念到成品的标准化视觉创作管线

## 四、关键视觉元素

### 4.1 人物视觉元素

真人医疗职场题材的人物视觉以**"真实个体、职业气质"**为核心：

- **面容标准**：真人肌肤质感，五官自然立体，呈现医护职业痕迹——口罩压痕、手术帽勒痕、眼下疲态与暗沉、消毒后的皮肤干燥。支持多元面容类型——沉稳专业、温柔耐心、干练果决、青涩紧张、疲惫坚守等
- **发型标准**：医护职业发型——女性多为利落束发（低马尾/盘发/手术帽下束起）、男性多为利落短发；手术/无菌操作场景须以手术帽完全包裹头发。发丝自然质感，杜绝假发感与僵硬造型
- **服饰标准**：当代中国医院职业着装体系——白大褂（长/短款）、洗手衣（手术绿/蓝色分体衣）、手术衣（无菌一次性或布制）、护士服（粉色/淡蓝/白色分体或连体）、防护服（隔离衣/防护服）。反复洗涤后的微微泛旧与穿着褶皱
- **表情与体态**：微表情真实细腻（专注的眼神、疲惫的眉眼、安抚的微笑、紧绷的下颌），肢体语言符合职业习惯（双手插兜的白大褂、交叠抱胸、低头记录的姿势），杜绝僵硬摆拍感
- **人物气质维度**：沉稳专业 / 温柔耐心 / 干练果决 / 青涩紧张 / 疲惫坚守 / 严厉威严 / 权威从容

### 4.2 场景视觉元素

- **手术室（无影灯）**：无影灯冷白光主照明、手术床+器械台、麻醉机+监护仪、洗手区、不锈钢墙面、手术绿洗手衣、无菌单——一切围绕"无菌、专注、生死"的手术室核心
- **急诊抢救大厅**：抢救平车、除颤仪、急救药车、心电监护、输液架、呼叫铃声、明亮冷调日光灯、医护人员快速走动——忙乱、紧迫、命悬一线的急诊现场
- **普通病房**：病床+床头柜+输液架、床头呼叫器、氧气接口、窗帘隔断、阳光从窗户洒入、家属陪护椅——日常病房的秩序与温情
- **ICU重症监护**：密集的监护仪+呼吸机+输液泵、生命体征报警光、床边操作空间、隔离帘、冷蓝仪器光主导——理性、克制、24小时不间断的守护
- **医生办公室/值班室**：电脑+病历系统、办公桌+一摞病历夹、值班床+折叠被、台灯+暖光、白大褂挂在门后——医生的非战斗区域，疲惫与决策的场所
- **医院长走廊**：日光灯冷白顶光、地面光泽反光、病房门牌、扶手、护士站中段、推车与轮椅往来、消毒水气息——医院最经典的过渡空间
- **门诊/挂号大厅**：挂号窗口、叫号屏幕、候诊椅、自助机、导诊台、人流穿梭——医院最公共、最日常的空间
- **检验科/影像科**：检验仪器、试管架、CT/MRI设备、阅片灯箱、铅玻璃、暗房光环境——医疗的"技术后台"
- **护士站**：环形/长条护理台、病历车、医嘱电脑、药品柜、呼叫系统、白板排班——护士的核心指挥所

### 4.3 道具与细节元素

- **医护服饰**：白大褂/洗手衣/手术衣/护士服、胸牌/工牌（中文医院+科室+姓名）、手术帽/圆帽、口罩（外科/KN95）、手套（乳胶/丁腈）、防护服/隔离衣

- **医疗设备**：无影灯/手术灯、心电监护仪/除颤仪/呼吸机/输液泵/注射泵、移动X光、超声——仪器指示灯与屏幕光是医院特有的"光源叙事"
- **病历文书**：病历夹/处方笺/医嘱单/检验报告/知情同意书/交接班记录——纸面与中文医疗术语
- **耗材与输液**：输液架/输液袋/注射器/纱布/绷带/棉签/胶布/导联线——医疗现场的"细节密度"
- **转运设备**：医用推车/抢救平车/轮椅/担架——医院空间的"流动元素"

## 五、严禁内容（优先级最高）

本风格严格排除以下内容类型，确保视觉体系纯净统一：

1. **非真人质感**：3D渲染/CG建模/次世代游戏引擎/动画风格/手绘插画/水彩油画/二次元/Voxel/低多边形等一切非真人实拍影像质感
2. **非医疗职场世界观**：古风/古装/传统中式古建/仙侠/玄幻/武侠/民国/宫廷/校园/豪门奢华/市井烟火居家/赛博朋克/科幻机甲/西方奇幻/中世纪等非当代中国医疗职场背景
3. **非当代中国医疗语境**：明显非中国医院特征的建筑、标识、设备、人物造型（如欧美式私立医院、日式诊所等）

## 七、使用说明

### 提示词使用原则

1. **前缀先行**：所有生成内容必须首先加载"前缀提示词"中的全局风格锚定段，锁定真人医疗职场写实质感基线
2. **专项叠加**：在全局前缀基础上，按需叠加角色/场景/道具/分镜专项提示词
3. **负面必加**：每次生成必须附带"负面提示词"，规避伪影与风格偏差
4. **迭代优化**：建议首轮生成后根据效果对专项提示词做微调，而非修改全局前缀
5. **平台适配**：本手册提示词优先适配Doubao-Seedream（生图）与Doubao-Seedance（视频生成），部分提示词可能需根据平台特性微调
