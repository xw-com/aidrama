## 四、全局约束规则

### 4.1 影像真实性约束（必守）

| 编号 | 规则 |
|---|---|
| P1 | 必须以「真人摄影 / 真人实拍 / 真人电影剧照」为生成锚——画面必须读作"摄影机拍下的"，而非"计算机生成的" |
| P2 | 必须指定一个具体的光源逻辑：这场戏的光从哪里来？（无影灯/日光灯/夜灯/窗光/监护仪屏）光源方向、色温、软硬须自洽 |
| P3 | 必须保留医护人物皮肤的真实质感——毛孔、细纹、口罩压痕、手术帽勒痕、消毒后的干燥、眼下疲态暗沉——杜绝塑料磨皮与AI感假面 |
| P4 | 发丝必须呈现自然状态——束发被帽子压出的碎发、手术帽下被汗水浸湿的鬓角、洗手后凌乱的额前碎发——杜绝建模感整齐发块 |
| P5 | 服饰必须体现"穿过/洗过"的痕迹——白大褂洗涤后的微旧与褶皱、洗手衣的针织纹理与松紧带勒痕、手术衣的无纺布质感——杜绝全新样板衣感 |
| P6 | 场景必须有"被使用过"的证据——器械台有消毒水膜、墙面有使用痕迹、地面有光泽磨损、桌面有病历散落——杜绝样板医院 |
| P7 | 医护人物必须处于职业体态——查房时双手插兜的白大褂、低头记录的姿势、抢救时前倾的身体、问诊时专注的注视——杜绝模特式摆拍 |
| P8 | 必须指定一个具体的当代中国医院空间——拒绝"generic hospital"或任何无国别标识的架空医院，须有中文医院标识/中文科室牌/中文病历 |
