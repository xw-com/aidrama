# 真人医疗职场道具图像生成 · 约束手册

---

## 一、道具设计原则

> 真人医疗职场的道具不是"被建模的物体"，而是"被使用过的医疗物品"——它在某位医生手里待过、在某张器械台上摆过、在某次抢救中用过。摄影机拍下的是它的此刻。

1. **物品即叙事** — 每一件医疗道具都是一个微型的叙事容器。听诊器耳管的磨损暗示用过千百次、手术器械上的消毒膜暗示刚从无菌包取出、病历夹的折角暗示被反复翻阅、监护仪屏幕的波形暗示生命还在跳动
2. **使用痕迹优先于完美品相** — 真人医疗职场的道具必须有"被用过"的证据。全新的、刚拆封的、样板级别的医疗器械一律不出现（除非剧情本身需要"开封"瞬间）
3. **中国当代医院真实物品** — 道具必须是中国医院真实存在的物品：中文药品标签、中文病历、中文科室标识、国产品牌或常见进口品牌医疗器械——拒绝无国别的架空物品
4. **材质即真实** — 不是PBR参数渲染出的材质，而是摄影机拍下的真实材质行为：不锈钢器械的冷光与消毒膜、白大褂棉质的微皱、无纺布手术衣的纹理、塑料注射器的注塑质感
5. **单视图静物摄影** — 道具以单张静物产品摄影方式独立呈现，非多角度建模展示，非2×2四宫格

## 三、单视图静物摄影规范

> 真人医疗职场道具仅需单张静物产品摄影，非多角度建模展示。以下为单视图摄影的完整规范。

### 画面构成

| 项目 | 摄影要求 |
|---|---|
| 道具呈现 | 道具居中或偏三分线位置独立陈列，完整入画，无裁切 |
| 背景 | 素灰无缝背景纸 #B0B0B0（哑光），或医白台面/不锈钢操作台面，根据道具属性选择。无多余物体、无装饰、无文字 |
| 光线 | 自然窗光或单灯柔光。窗光45°侧入（明亮柔和带自然阴影）、或柔光箱顶+侧补（产品摄影级均匀光线）。光影柔和、方向明确、无硬阴影 |
| 景深 | 浅景深（f/2.8-f/5.6），道具主体清晰锐利，前后微虚化突出主体 |
| 投影 | 道具底部与承载面之间的自然接触阴影——真实的而非抠图或悬浮。阴影柔软、方向与主光源一致 |
| 画面比例 | 建议 1:1 正方形或 4:3，适配单件道具展示 |

### 道具状态准则

| 维度 | 要求 |
|---|---|
| 使用痕迹 | 必须有"被使用过"的视觉证据——非全新未拆封、非样板品相（除非剧情需要"开封"瞬间） |
| 中国辨识度 | 中文标识/中文药品标签/中文病历/中文科室牌/当代中国医院常见品牌——拒绝无国别架空物品 |
| 材质真实感 | 非渲染质感——是摄影机拍下的真实材料行为（光的反射、漫射、透射） |
| 专业洁净感 | 医疗道具须呈现"已消毒/待用"的专业洁净感——非恐怖血腥，非过度渲染 |
| 尺度感 | 通过材质纹理密度、工艺细节暗示实物尺寸，无需参照物 |

## 六、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须是「单张静物摄影」——单视图、非多角度、非2×2四宫格、非建模展示 |
| R2 | 必须指定「素灰背景纸 #B0B0B0」或「医白台面/不锈钢操作台面」等真实桌面，禁止复杂场景 |
| R3 | 必须指定光源逻辑——窗光或柔光箱，光影方向明确、投影自然 |
| R4 | 道具必须有「使用痕迹」——非全新、非样板品相、非未拆封（除非剧情本身需要"开封"瞬间） |
| R5 | 道具必须具备中国当代医院辨识度——中文标识/中文药品标签/中文病历/中文科室牌 |
| R6 | 必须声明「实物产品摄影 + 非3D渲染非CG」核心锚定 |
| R7 | 材质必须描述为摄影机下的真实表现，而非渲染参数 |
