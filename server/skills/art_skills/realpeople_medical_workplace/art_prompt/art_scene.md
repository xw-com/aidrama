# 真人医疗职市场景图像生成 · 约束手册

---

## 一、场景美学原则

> 真人医疗职场的场景不是"被建模的空间"，而是"被摄影机选中的真实医院场所"。没有渲染引擎、没有贴图、没有体积光参数——只有实际存在的专业光源（无影灯/日光灯/夜灯）、真实的医疗材料、以及中国医院的日常。

1. **空间即叙事** — 一个空无一人的手术室不是"空的"，是刚做完一台手术。一把歪放的轮椅、一张还没收的器械台、监护仪上还跳动的波形——空间自己会讲故事
2. **真实的专业光源，不是渲染的光** — 场景的光来源明确：手术室无影灯冷白（5000-6000K）、走廊/门诊日光灯管（4000-5000K）、病房日光灯+窗光、病房夜灯暖黄（2700K）、监护仪屏幕冷蓝（约6500K）。光的色温和方向必须在物理上说得通
3. **被使用过的空间** — 真实的医院场景有使用痕迹——器械台有消毒水膜、地面有光泽磨损、墙面有使用痕迹、不锈钢有划痕与指纹。一个完全没有使用痕迹的空间是样板医院，不是真人医疗职场
4. **中国当代医院的真实场所** — 场景必须有中文医院标识、中国医院特征（中文科室牌、中文药品标签、中文病历、医保标识）。这不是"generic hospital"，这是"当代中国医院的一个具体角落"
5. **单视图全景全貌** — 一张照片装下整个场地的完整信息。广角或标准焦段，全景深，正面展示空间的全貌与纵深——不是四视图分割，不是多角度拼贴

## 二、时段与光源——医疗专业光的导演

> 真人医疗职场的场景光，首先由医疗专业光源和时段决定。以下是真实光源在医院不同区域、不同时段的摄影行为。

| 区域 | 时段 | 光的行为 | 场景氛围词 |
|---|---|---|---|
| 手术室 | 全天（无窗或独立照明） | 无影灯冷白5000-6000K均匀无影光、不锈钢器械冷反光、墙面手术绿洗手衣 | 冷静专注、生死博弈、专业沉静 |
| 急诊抢救大厅 | 全天24小时 | 冷调主光4500-5500K、混入监护仪/平车警示光、永远明亮 | 紧迫危急、高压张力、命悬一线 |
| 走廊/门诊 | 日间 | 日光灯管4000-5000K冷白顶光、配合窗外自然光、地面光泽反光 | 秩序运转、日常诊疗、专业克制 |
| 走廊/门诊 | 夜间 | 日光灯管4000-5000K冷白、空旷走廊、孤寂冷调 | 夜班静谧、孤岛式照明、深夜坚守 |
| 普通病房 | 日间 | 病房日光灯4500-5500K+窗外自然光、明亮通透 | 治愈陪伴、日常秩序、温暖 |

## 三、室内场景

### 空间摄影规范

| 维度 | 摄影要求 | 提示词 |
|---|---|---|
| 风格 | 真实的中国当代医院室内空间——不是效果图、不是样板医院、不是渲染。是有使用痕迹的真实医院场所 | 真实的中国当代医院{空间类型}、真人实拍摄影、非效果图非样板医院 |

## 五、单视图全景摄影规范

> 真人医疗职市场景仅需**单张**全景摄影——一张照片装下整个空间的完整信息。不是2×2四视图，不是多角度拼接。

### 画面构成

| 项目 | 摄影要求 |
|---|---|
| 空间呈现 | 单张照片完整呈现场景的空间全貌。使用24-28mm广角或35mm，全场地的纵深、宽度、高度在一张画面中全部可见 |
| 构图 | 全景深大景别——前景（器械台/输液架/门框/窗帘/护栏）形成天然画框→中景是场地主体→后景向空间纵深或走廊尽头/窗外延伸 |
| 景深 | 全景深 f/8-f/11，从前到后全部清晰。这不是人像摄影——场景的每一个角落都应该能被看见 |
| 人物 | **严禁出现任何人物、人影、人体轮廓。** 场景是空的——但这种"空"有叙事：刚做完一台手术/即将开始抢救/人去楼空/夜班的静止瞬间 |
| 比例 | 建议 16:9 或 3:2 宽幅——匹配全景空间展示的横向视觉习惯 |
| 色彩 | 由实际医疗光源的色温驱动，不套滤镜。色彩科学参考ARRI Alexa/Sony Venice电影色调 |

### 空的场景如何叙事

| "空"的类型 | 画面线索 | 叙事暗示 |
|---|---|---|
| 刚做完手术 | 无影灯还亮着、器械台还没收、无菌单掀开一角、地面有消毒水膜 | 刚结束一台手术，现在空了 |
| 即将开始抢救 | 抢救平车就位、除颤仪已开机、急救药车推进、监护仪待机 | 有人马上要被推来，现在是开始前的静止 |
| 人去楼空 | 已停用的病房、墙上挂钩和病历夹留下的痕迹、地面磨损的轮廓 | 曾经有人住过，现在已经腾退 |
| 日常的静止 | 病房床头柜上没喝完的水、办公室还没关的电脑、值班室皱着的被角 | 生活的常态、只是此刻没有人入镜 |
| 夜班的场所 | 空荡的走廊只有日光灯亮着、护士站只有一盏台灯、ICU监护仪独自跳动 | 医院睡着了、但生命监护还醒着 |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须是**单张**全景摄影——单视图、非2×2四视图、非多角度、非turnaround |
| R2 | 必须使用广角镜头（24-28mm）或标准焦段（35mm），全景深 f/8-f/11，完整空间纵深 |
| R3 | 光源必须可追溯——专业医疗光源（无影灯/日光灯/夜灯/监护屏）的方向与色温合理自洽 |
| R4 | 场景必须有前/中/后景空间层次，前景画框→中景主体→后景延伸 |
| R5 | 必须有中国当代医院辨识度——中文科室牌/中文病历/中文药品标签/医保标识 |
| R6 | 必须有使用痕迹——器械台消毒水膜/地面光泽磨损/墙面痕迹/不锈钢划痕、非样板医院非全新非效果图 |
| R7 | **严禁出现任何人物、人影、人体轮廓、剪影** |
| R8 | 必须声明"真人实拍摄影 + 非3D渲染非CG"核心锚定 |
