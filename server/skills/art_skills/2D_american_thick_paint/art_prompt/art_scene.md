# 美漫厚涂风格 - 场景图生成 · 约束手册

---

## 一、场景美学原则

1. **体积叙事** — 场景承载冲突与力量感，不是纯背景板
2. **厚重纵深** — 所有场景必须具备前/中/后景，杜绝扁平
3. **材质至上** — 笔触/色彩/光影等材质表现必须清晰厚重
4. **美漫都市为锚** — 一切画面以美式漫画厚涂插画为标准，拒绝 3D 渲染与照片写实；追求厚涂笔触特征（可见笔痕、颜料堆叠、粗犷肌理）与戏剧化体积光影（硬光明暗截断、轮廓光、体积光束）

## 五、主视图规范

### 视图定义

> 单画面主视图，从场景中最具代表性的角度拍摄，承载空间叙事与构图重心。

| 项目 | 约束 | 提示词 |
|---|---|---|
| 视角 | 人眼平视或低机位仰视，构图最能体现场景体量与纵深 | hero shot、dramatic angle |
| 视点高度 | 默认人眼平视高度，地标与冲突场景可低机位仰拍 | eye level（默认）、low angle |
| 构图 | 主体居中或符合三分法，前/中/后景层次清晰 | balanced composition |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 单画面（非拼图、非多视图、非分屏） |
| 人物 | **严禁出现任何人物、人影、人体轮廓** |
| 一致性 | 风格/材质/色调/光线统一 |
| 光线 | 单一光源逻辑，光影方向一致 |
| 画面比例 | 默认 16:9（或按调用方设定） |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 场景必须有「前中后景层次」 |
| R2 | 室外必须包含「大气透视」 |
| R3 | 场景图必须为「单画面主视图」，不得拼接多视图/分屏/网格 |
| R4 | 构图须能代表场景主体并展示前/中/后景层次 |
| R5 | 场景图中**严禁出现任何人物** |
| R6 | 必须包含美漫厚涂关键词（American comic thick paint / impasto / dramatic lighting） |
| R7 | 必须包含笔触特征（厚涂笔触、雕塑感块面 至少一项） |
| R8 | 材质必须带有使用痕迹，禁止全新无瑕的"CG 感" |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 背景纯白/纯黑/无场景 |
| X2 | 极端天候（暴风雨/雷电/暴雪，除非剧情需要） |
| X3 | 场景无纵深/无层次 |
| X4 | 建筑/植被材质与季节或城市气候矛盾 |
| X5 | 出现任何人物、人影、人体剪影 |
| X6 | 画面被拼接成多视图/网格/分屏布局 |
| X7 | 3D 渲染/照片写实/日系动画质感 |
| X8 | 材质过于干净完美、无任何使用痕迹 |
| X9 | 光照过于均匀平坦、无戏剧化明暗截断 |
