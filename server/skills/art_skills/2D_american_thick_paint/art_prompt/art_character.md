# 美漫厚涂风格 - 人物基础形象生成 · 约束手册

---

## 一、基础形象原则

1. **体积即灵魂** — 厚涂块面与笔触方向塑造形体，结构如雕塑，避免轻薄平贴
2. **角色为本** — 基础着装由角色描述（身份/职业/性别/场景）决定其常规着装；后续特定服化为叠加层
3. **四视图一致** — 面容/体型/发型/基础服装跨视图高度统一
4. **气质外化** — 无妆状态需体现角色气质（坚毅/威压/沉稳/锋利）

---

## 二、面容约束

> 不再固定五官特征参数，由角色描述（性别/年龄/性格/气质）驱动 AI 自由生成五官，保证人物间外观差异化。

### 通用要求

| 项目 | 约束 |
|---|---|
| 五官 | 由角色描述自然推导，不预设脸型/眼型/眉型/鼻型/唇型 |
| 风格底色 | 美漫厚涂插画质感（雕塑感块面、可见笔触、戏剧光塑形） |
| 气质 | 必须从角色描述提炼整体气质关键词（如坚毅/威压/沉稳/锋利），并写入提示词 |
| 表情 | 中性微表情，符合角色气质 |

## 六、基础服装约束

> 基础服装由角色描述（身份/职业/性别/场景）决定其最自然的常规着装，作为该角色「日常默认态」；战衣/装甲等特殊衍生在服化衍生环节叠加。**禁止内衣打底**。

### 着装选择原则

| 角色身份 | 默认着装方向 |
|---|---|
| 英雄/义警 | 战术便装（工装夹克/连帽衫/作战裤） |
| 警探/特工 | 风衣/西装/皮夹克 |
| 记者/媒体人 | 都市职业装（衬衫+西裤/风衣） |
| 科研/医护 | 工装马甲/白大褂/实验便装 |
| 市民/学生 | 美式休闲装（牛仔/T恤/连帽衫） |
| 角色描述未明确 | 美式都市机能风常服 |

### 着装统一规则

- 服装风格须与美漫厚涂美学一致（硬朗廓形、中高饱和、厚涂质感）
- 色彩对比明确、大块面分布，无细碎花纹，便于后续衍生叠加
- 四视图服装款式完全一致
- 基础服装是「日常默认态」，焦点仍在面容与体态
- 严禁内衣/暴露/性化打底

## 八、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须为「素颜无妆」状态 |
| R2 | 必须根据角色描述声明合适的常规着装作为基础服装（如义警→战术便装、警探→风衣/皮夹克、市民→美式休闲装）；禁止内衣打底 |
| R3 | 必须声明「无发饰、无配饰」 |
| R4 | 必须指定「冷调石墨灰背景 #54575F」 |
| R5 | 必须指定「四视图一致性」 |
| R6 | 全身立像必须从头到脚完整展示，严禁裁切 |
| R7 | 必须指定角色身高并通过头身比换算约束全身比例（女性默认168-178cm/7.5-8.5头身超模比例，男性默认180-195cm/8-9头身健硕英雄比例） |
| R8 | 人像特写必须从头顶到锁骨完整展示，严禁裁切头顶 |

|---|---|

| X2 | 赛璐璐平涂、日系动画质感 |
| X3 | 粉嫩透明肤色、无结构平板脸 |
| X4 | 复杂场景背景（必须石墨灰背景） |

| X7 | 人像特写裁切头顶，必须从头顶到锁骨完整入画 |
| X8 | 忽略身高和头身比约束 |
