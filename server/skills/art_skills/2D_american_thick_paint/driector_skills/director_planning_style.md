# 美漫厚涂约束 · 美漫厚涂 · 技法参考

---

## 一、色调体系与画面基调

- **色调基底** — 全片以玄黑（C4）、钢蓝（C3）、猩红（C2）为基底色，整体色温中性偏冷（5500-6200K），饱和度中高（60-80%），呈现美式漫画厚涂插画的硬朗史诗感。全片保持厚重明暗基底，暖色（琥珀金 C7、铜肤 C1）在高潮段落集中释放
- **冷暖叙事对比** — 暖色（琥珀金 C7、猩红 C2）作为情绪爆发的视觉信号，用于登场、觉醒、决战、凯旋段落局部强化。冷暖切换应与故事弧线同步，而非随意混用
- **色盘先行原则** — 段落规划需先绑定情绪场景（对峙/登场/濒危/凯旋等），再确定主色+辅色与光影方案，避免"剧情对了但情绪不对色"
- **禁用色域** — 粉嫩马卡龙色、水彩透明色系、日系低饱和灰调均与本风格不兼容

---

## 二、光影方案体系

- **光影即叙事** — 6 套光影方案对应不同情绪段落，导演规划阶段应在段落层面确定光影基调方向，而非逐镜指定
- **光源角度** — 默认 45°斜侧硬光，明暗截断强烈，模拟戏剧舞台光效果

| 情绪段落 | 光影方向 | 色调倾向 | 适用阶段 |
|---|---|---|---|
| 街头日常 | A·自然硬光 | 暖砂底 + 均匀日光 | 全片 |
| 对峙紧张 | B·硬侧光对切 | 猩红 + 玄黑 + 电弧青 | 冲突段 |
| 英雄登场 | C·底光+轮廓光 | 琥珀金主导 + 铬银 | 登场段 |
| 濒危绝望 | D·低调打光 | 玄黑主调 + 枪灰 | 低谷段 |
| 反击觉醒 | E·逆光爆发 | 琥珀金 + 猩红 + 电弧青 | 高潮段 |
| 雨夜追击 | F·冷调主光+湿面反射 | 钢蓝 + 铬银 + 玄黑 | 追逐/夜晚段 |

- **冷暖光分配** — 冷调（钢蓝 C3、玄黑 C4）铺底贯穿全片；暖调（琥珀金 C7、猩红 C2）集中用于情绪爆发与情感释放段落
- **氛围方向映射** — 每场戏的氛围方向应能映射到上述光影方案（A-F）的某一方向，确保视觉一致性

## 三、质感方向

- **厚涂雕塑感** — 美式漫画厚涂插画的核心：impasto 笔触堆叠、可见笔痕、颜料肌理、块面塑形
- **粗犷肌理 + 戏剧光** — 这是画面质感的锚点。不是平滑渐变，不是照片写实
- **厚重不等于脏乱** — 本风格强调暗部厚重、亮部饱和的体积表达（笔触堆叠、雕塑块面、硬光截断），通过构图与冲突设计放大感染力，而非依赖凌乱笔触
- **粗犷不等于潦草** — 美漫厚涂强调笔意的控制力（结构准确、块面清晰、光影分明），通过张力与节奏设计放大感染力，而非依赖糊乱涂抹

## 四、美漫都市场景空间元素

美漫厚涂世界观特有的场景元素及其视觉叙事功能：

- **天台护栏/消防铁梯/高架立柱** — 天然的框架式构图道具，制造压迫式层次感与空间纵深
- **摩天楼/街巷/港口** — 力量对抗的天然载体，景即情：天台俯瞰灯海 = 孤独使命、雨夜街巷湿反光 = 危机潜伏、港口仓库对峙 = 宿命决战
- **雨幕/蒸汽/粉尘/翻飞报纸** — 体积光与空气感的天然载体，景即情：雨幕霓虹 = 冷峻（方案F）、蒸汽升腾 = 蛰伏、粉尘光柱 = 神圣降临（方案C）
- **火光/探照灯/霓虹招牌** — 美漫厚涂的光源载体，火光 = 觉醒/爆发（方案E）、探照灯 = 搜捕/威压（方案B）、霓虹 = 夜晚都市（方案F）
- **段落间用场景空镜过渡** — 本风格有丰富的场景资产（不同时段/天候/天气变体），段落衔接建议用场景空镜做情绪缓冲，不要硬切
- **转折点用视觉而非台词** — 优先使用画面手段（光影突变、景别跳切、空镜隐喻）而非依赖对白解释

## 五、美漫乐器与环境音

美漫厚涂世界观下的声音元素约束：

### 乐器选择

- **铜管组（小号/长号）** — 英雄登场/凯旋段落的核心乐器，最能表现美漫史诗的崇高感
- **电吉他** — 追击/对峙/觉醒段落，失真音墙适合硬核氛围
- **鼓组/定音鼓** — 冲突升级/决战段落，重锤节奏适合力量表达
- **弦乐铺底** — 悲怆/哀悼/回忆段落，低音弦震适合沉重情绪

### 乐器组合策略

| 情绪阶段 | 乐器组合 |
|---|---|
| 平稳/开场/收尾 | 弦乐长音铺底 或 钢琴独奏 |
| 日常/调查 | 钢琴 + 轻鼓刷 |
| 冲突/追击 | 电吉他 + 鼓组 |
| 决战/觉醒/凯旋 | 铜管 + 定音鼓 + 弦乐 |

### 美漫环境音

- **典型环境音层次** — 都市车流 / 远处警笛 / 雨点打铁皮 / 港口汽笛 / 金属撞击 / 直升机螺旋桨 / 风声呼啸
- **每场戏标注 1-2 个核心环境音**，帮助后续音效设计。环境音层次越丰富，美式都市场景越有沉浸感
- **留白比配乐更重要** — 关键情感瞬间（抉择、牺牲、摘下面具）优先考虑去掉配乐，只留环境音（风声、雨声、远处警笛），让观众自己感受情绪
- **避免满配** — 全片配乐覆盖率建议不超过 60%。留白段落的"无声"与配乐段落形成呼吸感，突出史诗张力
