# 美漫厚涂风格说明

本风格专为"美式漫画厚涂插画质感"题材打造，所有美术提示词、规范和生成内容均严格限定于：

- **美漫都市世界观**：以现代美式都市为背景，涵盖摩天楼天台、雨夜街巷、警局、实验室、港口仓库、英雄据点等，体现 Marvel/DC 系概念插画的都市史诗感。
- **厚涂笔触质感**：所有角色、场景、道具均以美漫厚涂插画为标准，强调 impasto 厚涂笔触、粗犷肌理堆叠、可见笔痕与颜料厚度。
- **戏剧体积美学**：在厚涂基础上追求戏剧化体积光影，强调人物与建筑的雕塑感块面，暗部厚重、亮部饱和，画面张力强烈。
- **情感表达**：适合展现英雄、对抗、救赎、热血的美式漫画叙事，强调西式画法下的力量感与戏剧性情感表达。

## 适用范围

- 美漫厚涂题材的AI美术生成（角色、场景、道具、分镜等）
- 需要极致厚涂质感、粗犷肌理、戏剧光影、硬核史诗氛围的视觉创作

## 严禁内容

- 日式动画风格、赛璐璐平涂、二次元大眼比例
- 3D渲染、CG动画、照片写实
- 粉嫩马卡龙色、水彩透明感、扁平矢量
- 平淡大平光、无阴影、软弱轻飘质感

## 风格体验

在本风格下，您将体验到：

- 角色面容结构硬朗、气质坚毅或威压，体型健硕、肌肉块面如雕塑，服饰廓形利落
- 场景空间厚重纵深，材质粗粝真实，氛围浓烈且富有电影张力
- 道具、武器、装备均为美漫工业造型，锻造厚重，磨损与使用感清晰
- 分镜与画面均以厚涂笔触为基础，强调戏剧光与叙事张力

---

本风格仅适用于"美漫厚涂"相关项目。如需其他风格（如日式动画、波普漫画、3D 渲染等），请勿使用本套提示词。
