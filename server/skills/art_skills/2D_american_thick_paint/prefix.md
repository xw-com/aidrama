## 二、全局色彩盘（风格基线，不是硬锁）

> 目标：统一审美而非限制创作。除「硬约束色」外，其余颜色默认优先使用，可在合理范围内偏移。

### 色彩使用层级

| 层级 | 约束强度 | 说明 |
|---|---|---|
| L1 硬约束 | 高 | 仅锁定角色识别核心：肤色、暗部基调、主服底色的审美方向 |
| L2 软约束 | 中 | 场景色、装备色、特效色优先参考色盘，可按镜头与剧情微调 |
| L3 例外机制 | 低 | 战斗/爆发/特殊场景可临时突破局部色彩，但需保留整体厚重明暗逻辑 |

| 色项 | 对应色 | 规则 |

### 情绪色盘使用规则

| 编号 | 规则 |
|---|---|
| E1 | 每条提示词至少指定 1 个「情绪场景」并绑定主色+辅色组合 |
| E2 | 单镜头主色不超过 2 个，避免颜色叙事失焦 |
| E3 | 情绪切换时优先调整光比与明暗截断，再调整饱和度 |
| E4 | 史诗向默认遵循「重暗部 + 高光提饱和」：暗部铺底，亮部集中提亮提饱和 |
| E5 | 若与剧情冲突，以情绪色盘优先于通用推荐色，但不得突破严禁项 |

### 色温约束

| 参数 | 值 | 说明 |
|---|---|---|
| 整体色温 | 中性偏冷 5500-6200K（推荐） | 硬朗戏剧主基调 |
| 肤色色温 | 微暖 5000-5600K（推荐） | 铜肤但有生命感 |
| 对比度 | 高（建议保持） | 明暗截断强烈，雕塑感块面 |
| 饱和度 | 中高 60-80%（建议区间） | 暗部厚重、亮部饱和的美漫插画色调 |

### 容差与例外

| 项目 | 建议容差 |
|---|---|
| 色相偏移 | ±10° |
| 饱和度偏移 | ±12% |
| 明度偏移 | ±10% |

> 例外场景：战斗、爆发、觉醒镜头可局部提高光饱和与锐度；但禁止粉嫩糖果色与日系透明水彩感入镜。
