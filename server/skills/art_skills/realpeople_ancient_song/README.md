## 一、风格核心定义

**真人宋朝写实**是以**真人影视摄影美学**为基准、以**宋代（北宋/南宋）雅致文人审美**为核心视觉舞台的风格体系。其核心特征为：

- **真人写实摄影质感**：以真人影视级摄影为锚点，画面呈现真实人物的皮肤纹理、毛发细节、宋制丝绸罗纱的轻盈垂坠、宋代木构建筑的温润材质、微表情与肢体语言，杜绝3D建模感、CG渲染感、手绘感与二次元动漫感
- **宋代雅致世界观**：所有场景严格限定于宋代生活空间——汴京/临安市井（《清明上河图》的繁华市井）、茶肆酒楼、瓦子勾栏、文人书斋、宋代园林、西湖山水、书院讲堂；建筑以宋代木构（斗拱、悬山/歇山顶、青瓦素木、格子门窗）为准
- **电影级摄影语言**：以院线级真人古装影视摄影为基准，强调自然天光与烛火茶汤之光的有机调度、构图叙事的专业性、景深与焦点的情绪表达、色彩分级的电影感
- **宋代文人雅致厚重感**：在保持专业影像品质的前提下，强调"雅、简、淡、静"的宋人审美——宋瓷的温润如玉、文人四艺（焚香、点茶、挂画、插花）的清雅、瘦金体的锋芒、宋画山水的水墨意境

### 创作理念与核心价值

本手册的核心创作理念为 **"雅淡之中，烟火之上"**：

1. **真实感的审美回归**：真人肌肤的纹理、宋瓷釉面的开片与莹润、茶汤的氤氲热气、书斋窗纸上漏下的天光——这些真实细节构成了一种宋人独有的生命质感与生活气韵，是3D渲染无法复刻的审美深度。

2. **宋人的市井与书斋**：宋代是最具"生活气"的朝代。汴京虹桥上的繁华市井、茶肆里点茶分茶的从容、书斋中焚香展卷的清雅、西湖边的诗酒风流——宋代空间本身就是一个雅俗共赏、烟火与清欢并存的叙事容器。

3. **雅淡即视觉**：宋代的色彩尚"雅"尚"淡"——天青为汝窑之色、月白为宋瓷之色、茶褐为点茶之色、墨青为山水之色。本手册坚持以宋代美学驱动色彩与造型，反对浓艳与繁复，与盛唐的浓丽、明清的富丽形成鲜明对照。

4. **克制写实即品格**：本风格为"真人写实宋风"，不是仙侠法术，不是动漫玄幻。一切光影、材质、人物以写实克制为底色——文人的风骨落在眉宇与衣袂间，不落在魔法光效上；市井的烟火落在茶汤与市声里，不落在特效里。

**核心价值：**

- 为AI视觉创作者提供一套系统化、可复用的真人宋代题材提示词方法论
- 建立从概念到成品的标准化视觉创作管线
- 降低真人宋代题材AI视觉创作的技术门槛与试错成本
- 填补当前AI视觉创作领域"真人写实宋代系统化方法论"的空白

## 三、视觉风格定位

### 3.1 整体风格定位

**"电影级真人写实宋韵美学"**

以宋代生活为叙事舞台，以真人影视摄影为技术锚点，追求院线级古装电影（《梦华录》一脉的宋代烟火与雅致）的画面品质与审美高度。整体风格在"宋韵雅致"与"市井烟火"之间寻找黄金平衡——画面清雅但有温度，真实但不随意，审美在线但不空洞。

### 3.2 影像质感层级

| 质感维度 | 定位标准 |
|---|---|
| **皮肤质感** | 真人摄影级，可见自然的皮肤纹理、毛孔、细纹、淡妆与皮肤融合（宋代崇尚淡妆素雅），杜绝过度磨皮与塑料感 |
| **毛发质感** | 真实发髻/发辫/冠巾下发丝根缕分明，鬓发碎发自然，簪钗步摇有垂坠与微动感，杜绝僵硬假发与建模发块 |
| **服饰质感** | 罗纱/丝绸/缂丝的轻盈光泽与垂坠、褙子抹胸衫裙的瘦长修身层级、衣纹随身体动态与重力的自然垂坠，宋制以素雅织物为主 |
| **环境质感** | 宋代木构的斗拱梁枋、格子门窗的温润木纹、青瓦的白头与积尘、宋瓷釉面的开片与莹润、书案上展卷的宋版书——宋人生活的岁月质感 |
| **光影质感** | 格子窗天光与茶汤烛火暖光的有机调度，柔和漫射为主，杜绝生硬反差与不自然噪点，追求电影级色彩科学 |

## 四、关键视觉元素

### 4.1 人物视觉元素

真人宋朝写实的人物视觉以**"宋衣瘦长、文人清骨"**为核心：

- **面容标准**：真人肌肤质感，五官自然，宋代崇尚淡妆素雅（薄施脂粉、淡扫蛾眉），与皮肤融合。支持多元面容类型——清雅文秀、温婉柔顺、端庄持重、清灵少女、刚烈独立等
- **发型标准**：真实宋制发髻/冠巾——女性高髻盘发、低髻、双鬟、堕马髻、簪花戴钗；男性文人幅巾、东坡巾、纶巾、束发加冠。鬓发碎发自然，杜绝假发感
- **服饰标准**：宋代着装体系——女性褙子（对襟、瘦长修身）配抹胸与衫裙、对襟长衫；男性文人直裰、襕衫、鹤氅，配幅巾/东坡巾。罗纱/丝绸/缂丝面料轻盈垂坠，纹样素雅
- **体态标准**：清瘦文雅——宋人审美尚"瘦"尚"清"，身形清隽挺拔，举止从容克制，杜绝浮夸与现代随意体态
- **人物气质维度**：清雅文秀 / 温婉柔顺 / 端庄持重 / 清灵灵动 / 儒雅温润 / 刚毅深沉 / 风流倜傥 / 老成持重

### 4.2 场景视觉元素

- **汴京/临安市井**：虹桥、酒楼茶肆、瓦子勾栏、沿街商铺、幌子酒旆、舟车骡马——《清明上河图》式的繁华市井烟火
- **茶肆酒楼**：茶汤灶台、点茶器具、茶客桌椅、酒幌、临街格子窗、市井百态
- **文人书斋**：书案、文房四宝、宋版书、宋画挂轴、香炉、宋瓷清供、格子窗天光——文人精神世界
- **宋代园林**：太湖石、竹林、曲水流觞、茅亭、回廊、花木（梅兰竹菊）、水景——宋人园林意趣
- **西湖山水**：湖光山色、断桥苏堤、画舫、远山如黛、烟雨朦胧——南宋临安的诗意
- **书院讲堂**：太学/书院、书案列席、经史典籍、讲学场景——宋代文教之盛

### 4.3 道具与细节元素

- **宋瓷雅器**：汝窑天青釉（温润如玉、开片）、官窑、定窑白瓷、钧窑（窑变紫红斑）、建盏（兔毫/油滴）——宋代美学之冠
- **文人四艺**：焚香（香炉/香篆/香合）、点茶（茶盏/茶筅/茶托/汤瓶/建盏）、挂画（宋画立轴/绢本）、插花（宋式瓶花/清供）
- **文房清供**：端砚、徽墨、湖笔、澄心堂纸、瘦金体书法、宋版书（蝴蝶装/线装）、笔架山、镇纸、水盂
- **服饰配件**：褙子玉扣、抹胸系带、巾笄、玉簪、罗帕、团扇（宋绢扇）、香囊、玉佩、绦环
- **市井器物**：酒幌、灯笼、算盘、铜钱串、食盒、瓷碗汤勺、担挑货物

## 五、严禁内容（优先级最高）

本风格严格排除以下内容类型，确保视觉体系纯净统一：

1. **非真人质感**：3D渲染/CG建模/次世代游戏引擎/动画风格/手绘插画/水彩油画/二次元/Voxel/低多边形/赛璐璐等一切非真人实拍影像质感
2. **非宋代世界观**：现代当代都市/民国/西方/和风日式/赛博朋克/科幻未来/星际太空等非中国古代背景
3. **跨朝代混搭（本风格最高红线之一）**：严禁混入唐代浓艳（高饱和唐三彩/浓妆艳抹/丰腴体态）、明清元素（明清硬山黄琉璃/旗装马褂/花盆底）、清代旗装（钿子/剃发垂辫/朝服补子）——本风格锚定宋代，宋制服饰/建筑/器物须严格准确
4. **仙侠法术与玄幻特效**：法术光效/真气流转/御剑飞行/玄幻粒子/灵力光环等一切玄幻CG特效（本风格为写实克制宋风，宋人的"玄"靠意境不靠特效）
5. **非中国语境**：明显非中国古代特征的建筑、服饰、人物造型（如和服、韩服、欧式、哥特等）
6. **技术质量缺陷**：低分辨率/模糊/噪点/变形/畸形肢体/五官扭曲/比例失调/抠图感/塑料感/过度磨皮
7. **审美倾向违规**：高饱和荧光色/死亡荧光色/廉价滤镜感/过度HDR/刻意阴间色调/二次元平涂（本风格尚"雅淡"，高饱和浓艳为最大审美违规）
8. **内容合规红线**：暴露/低俗/暗示性/暴力血腥/违法内容/歧视性表达/政治敏感元素
