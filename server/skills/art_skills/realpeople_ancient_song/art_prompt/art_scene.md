# 真人宋朝写实场景图像生成 · 约束手册

---

## 一、场景美学原则

> 真人宋朝写实的场景不是"被建模的布景"，而是"被摄影机选中的真实宋人空间"。没有渲染引擎、没有贴图、没有体积光参数——只有实际存在的格子窗天光与茶汤烛火、真实的青瓦素木与宋瓷雅器、以及宋人生活的岁月与烟火。

1. **空间即生活** — 一座空无一人的书斋不是"空的"，是主人暂离之后。书案上展开未合的宋版书、香炉里青烟未绝、茶盏余温——空间自己会讲宋人雅俗的故事
2. **真实的光，不是渲染的光** — 场景的光只有一个来源：实际的日光（通过格子门窗、庭院）、实际的灯火（烛台、纱灯、茶汤灶火）。光的色温和方向必须在物理上说得通
3. **被岁月使用过的宋代空间** — 真实的宋代生活空间不崭新。木构梁枋有包浆、青瓦有积尘与白头、宋瓷釉面有使用痕、书案有展卷翻阅的磨损、市井店铺有烟火熏痕——一个完全没有岁月痕迹的空间是横店的样板布景，不是真实宋人生活
4. **中国宋代的真实场所** — 场景必须有明确的中国宋代辨识度（宋代木构斗拱、青瓦素木、格子门窗、太湖石园林、宋瓷清供、市井酒幌）。这不是"generic ancient"，这是"中国宋代的一个具体角落"
5. **单视图全景全貌** — 一张照片装下整座书斋/市井/园林的完整信息。广角或标准焦段，全景深，正面展示空间的全貌与纵深——不是四视图分割，不是多角度拼贴

## 五、单视图全景摄影规范

> 真人宋朝写实场景仅需**单张**全景摄影——一张照片装下整座书斋/市井/园林的完整信息。不是2×2四视图，不是多角度拼接。

### 画面构成

| 项目 | 摄影要求 |
|---|---|
| 空间呈现 | 单张照片完整呈现场景的空间全貌。使用24-28mm广角或35mm，全场地的纵深、宽度、高度在一张画面中全部可见 |
| 构图 | 全景深大景别——前景（格子门窗/梁柱/纱帐/书案/栏杆/花木/酒幌）形成天然画框→中景是书斋/市井/园林主体→后景向空间纵深或后堂/天空/远山延伸 |
| 景深 | 全景深 f/8-f/11，从前到后全部清晰。这不是人像摄影——场景的每一个角落都应该能被看见 |
| 人物 | **严禁出现任何人物、人影、人体轮廓。** 场景是空的——但这种"空"有叙事：主人暂离/即将开市/人去斋空/宋人生活的静止瞬间 |
| 比例 | 建议 16:9 或 3:2 宽幅——匹配全景空间展示的横向视觉习惯 |
| 色彩 | 由实际光源的色温驱动，不套滤镜，低饱和雅淡为主。色彩科学参考ARRI Alexa/Sony Venice电影色调 |

### 空的场景如何叙事

| "空"的类型 | 画面线索 | 叙事暗示 |
|---|---|---|
| 主人暂离 | 书案上展开未合的宋版书、香炉青烟未绝、茶盏余温、椅凳微移 | 刚才书斋有人，现在暂离了 |
| 即将开市 | 店铺门板刚卸、幌子刚挂、灶火刚生、桌凳摆齐 | 茶肆马上开张，此刻是开场前的准备 |
| 人去斋空 | 搬迁后的空斋、墙上挂过画的钉痕、地面积尘的轮廓、断了的香火 | 曾经有人住过，现在离去/贬谪/变故 |
| 生活的静止 | 木床纱帐半垂、妆台铜镜映空榻、茶盏余温、窗外庭光打在地砖 | 起居的常态，只是此刻无人入镜 |
| 深夜的空间 | 空荡的回廊只有纱灯亮着、书斋窗纸透出一团暖光、月下的空庭院 | 市井睡着了，但宋人空间还醒着 |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须是**单张**全景摄影——单视图、非2×2四视图、非多角度、非turnaround |
