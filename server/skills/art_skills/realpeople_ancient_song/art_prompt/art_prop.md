# 真人宋朝写实道具图像生成 · 约束手册

---

## 一、道具设计原则

> 真人宋朝写实的道具不是"被建模的物件"，而是"被宋人用过、被岁月盘过的雅器"——它在文人手里待过、在书案上供过、在点茶击拂中被茶筅搅过。摄影机拍下的是它的此刻。

1. **器物即雅趣与生活** — 每一件道具都是一个微型的宋人叙事容器。建盏里未饮尽的茶汤余乳暗示刚刚点过茶、宋版书翻开的折页暗示主人读到一半、香炉里袅袅青烟暗示焚香未绝
2. **使用痕迹优先于完美品相** — 真人宋朝写实的道具必须有"被用过、被岁月盘过"的证据。全新出厂、样板级别的道具一律不出现
3. **中国宋代真实器物** — 道具必须是中国宋代真实存在的器物：宋瓷（汝窑/官窑/定窑/钧窑/建盏）、文房四宝、点茶器具、宋画挂轴、宋版书、香炉——拒绝无国别架空物品
4. **材质即真实** — 不是PBR参数渲染出的材质，而是摄影机拍下的真实材质行为：汝窑天青釉的温润如玉与开片、建盏黑釉的兔毫结晶、端砚的细腻锋芒、澄心堂纸的纤维、宋画绢本的泛黄
5. **单视图静物摄影** — 道具以单张静物产品摄影方式独立呈现，非多角度建模展示，非2×2四宫格

## 三、单视图静物摄影规范

> 真人宋朝写实道具仅需单张静物产品摄影，非多角度建模展示。以下为单视图摄影的完整规范。

### 画面构成

| 项目 | 摄影要求 |
|---|---|
| 道具呈现 | 道具居中或偏三分线位置独立陈列，完整入画，无裁切 |
| 背景 | 素灰无缝背景纸 #B0B0B0（哑光），或深木桌面/米白绢布台面，根据道具属性选择。无多余物体、无装饰、无文字（道具本身的题字除外，如宋版书/药帖/瘦金体书法） |
| 光线 | 自然柔光或单灯柔光。格子窗光45°侧入（明亮柔和带自然阴影）、或柔光箱顶+侧补（产品摄影级均匀光线）。光影柔和、方向明确、无硬阴影 |
| 景深 | 浅景深（f/2.8-f/5.6），道具主体清晰锐利，前后微虚化突出主体 |
| 投影 | 道具底部与承载面之间的自然接触阴影——真实的而非抠图或悬浮。阴影柔软、方向与主光源一致 |
| 画面比例 | 建议 1:1 正方形或 4:3，适配单件道具展示 |

### 道具状态准则

| 维度 | 要求 |
|---|---|
| 使用痕迹 | 必须有"被用过、被岁月盘过"的视觉证据——非全新未启用、非样板品相 |
| 中国宋代辨识度 | 宋代器物形制/中文（如宋版书/药帖/瘦金体）/宋代工艺——拒绝无国别架空物品 |
| 材质真实感 | 非渲染质感——是摄影机拍下的真实材料行为（光的反射、漫射、透射） |
| 雅器等级感 | 文人清供须有合乎身份的工艺等级（汝窑天青开片、建盏兔毫结晶、端砚细腻锋芒） |
| 尺度感 | 通过材质纹理密度、工艺细节暗示实物尺寸，无需参照物 |
