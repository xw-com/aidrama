# 分镜表真人宋朝写实约束 · 真人实拍宋韵 · 技法参考

## 一、分镜表定位

分镜表是导演将剧本转化为镜头语言的核心工具。本约束面向 Seedance 2.0 视频生成，所有光影、动作、空间描述均采用模型可执行的具象语言。不做抽象的情感概括，不写模型看不懂的渲染参数。

## 三、光影与氛围——Seedance 2.0 物理光源描述

### 3.1 同场戏光影统一

一场戏内不应出现两种以上核心光影方案，除非有叙事驱动的光源变化（如有人吹灭烛火、日落后天光暗于烛火、从书斋走到市井）。光源变化必须在分镜表中标注触发事件。

### 3.2 光源语句法（每个镜头必须包含）
[光源] 主光：{光源类型——格子窗天光/烛火/月光/纱灯/茶汤灶火}，{方向}，{色温值K}，{软硬}
[光源] 辅光/环境光：{光源类型}，{方向}，{色温值K}
[光比] 约1:{X}
### 3.3 情绪 → 光源矩阵

| 情绪 | 光源配方（Seedance 2.0 可直接填入） | 视觉关键词 |
|---|---|---|

| 茶席雅趣 | 茶肆/书斋烛火暖橙主光（2200-2800K），纱灯透暖，暗部宋瓷罗纱反光。光比约1:4 | 暖调包裹、点茶、雅致 |

### 3.4 冷暖色调与叙事阶段

- **冷光主导**（5000K+）：书斋清思、月夜孤寂、西湖诗意、紧张压抑
- **暖光主导**（2200-3500K）：茶席雅趣、烛火私密、市井繁华、临安夕照
- **冷暖共存**：过渡时刻（蓝调时刻+初亮灯火）、月夜书窗（月光+孤灯）、紧张暗涌（烛火暖+格子窗冷）
- **光源变化 = 命运信号**：格子窗外天光从日间冷白渐变至黄昏暖金=时间流逝；从书斋烛火暖走到月下冷=命运的坠落

### 3.5 Seedance 2.0 光影适配要点

- 色温数字帮助模型校准白平衡倾向：`色温约2500K烛火暖橙` 优于 `暖光`
- 光比数字帮助模型建立明暗意识：`光比约1:4` 优于 `柔和的阴影`
- 光源必须有明确来源：`从画面右侧高位格子窗漫射斜入` 优于 `柔光`
- 环境光的反射路径描述：`书案宋版书反射烛火暖光` 优于 `桌面有暖色反光`

## 四、环境动态——让画面呼吸

### 4.1 动态密度

每 3-4 个镜头至少安排一个有环境动态的镜头。静态书斋戏也不例外——至少有一个镜头里烛火在摇曳、罗纱帷帐被穿堂风轻拂、远处更鼓传来。

### 4.2 宋人环境动态元素（Seedance 2.0 可执行）

| 场景 | 可描述的环境动态 |
|---|---|
| 书斋 | 罗纱帷帐被穿堂风轻鼓约10cm后回落（约2秒周期）、烛火明灭摇曳、香炉青烟袅袅升起、格子窗光斑随天光微移、窗外花木影子在书案缓慢移动、铜漏滴水 |
| 茶肆酒楼 | 茶汤灶火蒸汽升腾、酒幌布随风摆动约15cm、茶客低语、瓷盏轻碰声、远处跑堂吆喝、临街窗光变化 |
| 市井 | 酒幌茶旆随风摆动、行人骡马往来、舟船橹声、铜钱叮当、叫卖声此起彼伏、远处炊烟袅袅 |
| 园林 | 竹林花木叶片簌簌晃动、远处画眉/黄鹂鸣叫、花瓣偶有飘落、水景潺潺涟漪、檐马叮当作响 |
| 西湖 | 湖面水波粼粼、画舫乌篷轻摇、远处渔歌、鸥鹭掠水、烟雨朦胧飘洒、桃柳夹岸沾雨 |
| 回廊 | 格子窗光斑随天光角度缓慢移动、远处纱灯随穿堂风微晃、脚步声在长廊回响由远及近、廊柱明暗切割随人物穿行变化 |
| 月夜 | 烛火摇曳、更鼓由远及近传来二/三更声、月光下花木影子缓慢移动、虫鸣（秋蛩）、风过格子窗轻鸣 |

### 4.3 Seedance 2.0 环境动态描述规范

- 动态必须有具体轨迹和速度：`烛火每秒约2-3次微幅明灭摇曳` 优于 `烛火在动`
- 光源动态与空间光源逻辑一致：`云朵遮住日头时，格子窗光斑缩小约40%，持续约3秒后恢复`
- 禁止无来源的动态：没有风=罗纱帷帐不动。门窗紧闭=没有穿堂风

所有人物动作必须描述：**轨迹 + 速度/时长 + 身体部位协调 + 服饰连带动态 + 对周围物体的影响**。

### 5.3 动作节奏与叙事场景

- **文戏/书斋雅事**：动作沉稳克制，每个微动作标注时长和轨迹。节奏舒缓——不是慢，是"宋人的不急"
- **情绪波动**：动作幅度和速度略微变化。人物可能在对话中不自觉地加快团扇摆动频率、呼吸带动肩膀起伏更明显
- **冲突场景**：动作干脆利落，但仍有物理轨迹。推搡/摔物须具体到"右手推在对方左肩前方，对方重心向后偏移约20cm，褙子下摆剧烈摆动"
- 禁止：无叙事理由的快速动作堆砌、无物理逻辑的瞬移、"施了一礼"等含糊描述

### 5.4 服饰动态

真人宋朝写实的服饰动态是画面的天然资产——不是"布料模拟参数"，而是"褙子下摆随敛衽前倾自然垂坠""直裰袖口起身时带回约10cm""簪钗步摇随头部微动垂坠微动约2秒渐止""罗纱帷帐被穿堂风鼓起约15cm"。在分镜表画面描述中标注服饰与首饰的动态细节。

## 六、空间逻辑具象化——Seedance 2.0 空间坐标系统

### 6.1 每镜头必须声明的空间信息
水平位置：画面左/中/右，或画面左侧三分之一处
纵深位置：距镜头{数值}米，前景/中景/背景
人物与场景的关系：距{固定物——书案/拔步床/格子窗/园林太湖石/茶灶}{数值}米
（若双人以上）人物A与B的相对距离和朝向
### 6.2 站位衔接示例
【片段A尾部】
A女眷立于书斋书案前，距案约0.5米，面朝宋画挂轴，位于画面中央偏右，距镜头约4米。
书斋格子窗天光从画面右侧高位柔和漫射斜入（约5000-5500K冷白）。
A右手轻抚团扇骨柄，团扇距面颊约15cm。

【片段B开头】
A的右手刚将团扇收回约10cm，玉簪仍在原位置附近反光。A仍立于书案前（位置未变）。
格子窗外天色已从午后转为黄昏——窗外暖金透入，书斋烛火已亮（约2500K暖橙）。
纱灯已亮（画面右后侧），透暖光照在A的右后侧肩背。

### 6.3 空间变化必须具象

| 抽象（禁止） | Seedance 2.0 具象 |
|---|---|
| 她走近了 | A从画面背景（距镜头约5米、书斋门位置）向镜头方向缓步走来4步（约3米），绣履落地有轻微触地声，停在距镜头约2米处——耗时约4秒 |

| 从书斋到园林 | A从书斋（距镜头约3米）走向格子门，推开格子门（门向内旋转约80度，木棂反光一闪），跨过门槛进入园林——园林天光瞬间取代书斋烛火暖光 |

## 七、运镜规范——Seedance 2.0 摄影机运动

### 7.1 允许的运镜

| 运镜 | Seedance 2.0 描述 | 适用场景 |
|---|---|---|
| 固定 | 摄影机固定不动，画面静止 | 书斋展卷、茶席点茶、对话、空斋留白、情绪凝视 |
| 手持微晃 | 摄影机有轻微不规则晃动（幅度约±2cm），模拟手持拍摄的呼吸感 | 市井穿行、情绪波动、主观视角 |
| 稳定器流动 | 摄影机平滑匀速移动，无晃动 | 回廊纵深、人物登场、市井穿行、空间展示 |
| 缓推 | 摄影机向主体缓慢推进，推进速率约每秒0.3米 | 情绪升温、真相逼近、注意力聚焦 |
| 缓拉 | 摄影机向后缓慢拉远，拉远速率约每秒0.3米 | 离别、收束、揭示全貌 |
| 跟拍 | 摄影机与人物保持约2米距离同步移动 | 回廊穿行、市井行走跟随、园林闲步 |
| 摇镜 | 摄影机原地水平/垂直旋转 | 视线转移、市井纵深关系交代 |

### 7.2 禁用运镜

- 无叙事目的的快速甩镜、急推急拉（推拉速率超过每秒1米）
- 超过3秒的剧烈手持晃动（除非主观受击/眩晕/兵乱叙事）
- 无逻辑花式转场——划屏、旋转、百叶窗、翻页等特效转场
- 摄影机无理由的360度旋转

### 7.3 真人宋朝写实运镜哲学

- 固定机位是书斋与雅事的第一选择——让观众看到宋人在空间里自然存在
- 手持微晃在情绪段落使用——但晃动幅度不超过电影纪实风格的常规范围
- 稳定器流动用于回廊纵深与人物登场——宋人生活的从容诗
- 运动镜头的起幅和落幅必须平稳，运动过程匀速——禁止突然加速或急停

## 八、转场规范

### 8.1 允许的转场方式

| 转场 | 视觉执行 | 叙事功能 |
|---|---|---|
| 硬切 | 直接切换 | 同场戏内镜头切换（默认） |
| 光影匹配转场 | 两个场景在相近光影逻辑下切换 | 时间流逝、平行叙事。例：A处烛火 → B处烛火 |
| 空间匹配转场 | 两个空间在构图或元素上呼应 | 场景跳转。例：书案宋画的山水 → 园林真山真水 |
| 空镜过渡 | 插入场景空镜（3-5秒） | 情绪缓冲、章节划分、时间流逝暗示（如市井黄昏→月夜书斋） |
| 焦点转场 | 前镜焦点从主体移至背景，后镜从模糊背景中逐渐聚焦主体 | 空间切换、注意力的转移 |

### 8.2 禁止的转场

- 纯视觉特效转场（翻页、划屏、百叶窗、马赛克、水墨化开）
- 无叙事逻辑的旋转/缩放转场

## 十一、空镜使用规范

### 11.1 空镜不是"没东西拍"

空镜是情绪容器。每个空镜必须有叙事目的和具体的视觉内容：

| 空镜类型 | 叙事目的 | 示例 |
|---|---|---|
| 场景建立 | 新空间首次出现——让观众看清楚这是什么宋人空间 | 书斋大全景：书案、文房四宝、宋画挂轴、宋瓷清供、格子窗天光 |
| 情绪缓冲 | 高情绪段落后的喘息 | 格子窗外月光沿罗纱帷帐滑下，速度约每秒2cm |
| 时间流逝 | 暗示时间过去了 | 同一格子窗外的天光从午后冷白渐变至黄昏暖金再至月夜冷蓝 |
| 隐喻留白 | 以物代情 | 书案上半残的烛台，烛泪凝结，烛火明灭；或展卷未合的宋版书 |
| 转场衔接 | 前后两个空间的自然过渡 | 回廊格子窗——前一场书斋，下一场园林 |

### 11.2 空镜 Seedance 2.0 描述规范

空镜也必须遵循光源+质感+动态的描述铁律：书斋格子窗天光从画面右侧高位柔和漫射斜入（约5000-5500K冷白），
在空荡荡的书案宋瓷清供上镀一层清雅冷光，宋瓷天青釉面温润反光映出空书案，
烛火每秒约2-3次微幅明灭，罗纱帷帐被穿堂风鼓起约10cm后回落，
书案紫檀木有包浆，宋版书展卷泛黄书口磨损。
