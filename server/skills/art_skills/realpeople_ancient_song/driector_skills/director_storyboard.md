## 适用范围

本 Skill 专用于**真人宋朝写实**风格的分镜提示词生成，适配宋风文雅、市井烟火、文人雅集、茶事离愁、园林闲适、月夜孤思等真人实拍宋代影视题材的分镜创作。

## 一、摄影机前的情绪——面孔、眼神、微表情

> 真人宋朝写实的情绪不来自"法术光效"或"渲染参数"，而来自真人演员在摄影机前的微表情与宋制礼法之下的眼神。宋人审美尚"雅淡克制"，表情更内敛。以下映射面向摄影机捕捉真实宋人的方式。

| 情绪输入 | 面容描述 | 眼神描述 | 微表情补充 |
|---|---|---|---|
| 清雅 / 文秀 | 神情清朗，面部线条清隽不紧绷，下颌微收 | 眼神清亮有书卷气，沉静深远，不张扬 | 唇线平直，下颌微收，气度从容如水 |
| 隐忍 / 克制 | 眉眼不抬，面部肌肉收敛 | 目光低垂或平直不游移，将情绪压在眼底 | 嘴角自然平直，呼吸极轻，全身只有眼皮微动 |
| 温婉 / 柔顺 | 眉目舒展，面部柔和 | 眼神温润专注，像在认真听对方说话 | 嘴角自然含一丝温意，不是笑，是有温度 |
| 端庄 / 持重 | 神情端凝，面部线条端正不紧绷 | 眼神沉稳平直，注视时从容不迫 | 唇线平直，下颌微收，持重而不失柔和 |
| 刚毅 / 坚定 | 面部线条清晰，下颌微抬 | 眼神笔直向前，不回避不躲闪 | 下巴微收或微抬，表情果敢但不凶悍 |
| 惊动 / 触动 | 眼尾微抬，眉峰微动 | 眼神骤然聚焦，瞳孔微扩 | 嘴角微启，眉下眼神鲜活一瞬 |
| 沉思 / 内省 | 神情淡然，眼部周围肌肉放松 | 目光放远失焦，像在看但不在看 | 表情平静，可能单手持罗帕或玉簪轻抵唇角 |
| 哀怨 / 离愁 | 眉宇微蹙，眼睑低垂 | 目光含愁含水，望向窗外月色或落叶 | 嘴角自然下沉，眼尾有未落之泪的微光 |
| 喜悦 / 鲜活 | 眼角出现自然笑纹，眼型微弯 | 眼神明亮有光，眼角有笑意牵动 | 嘴角上扬，面颊微红，表情生动但不夸张 |
| 慌乱 / 惊惧 | 眉峰上挑，面色微白 | 眼神涣散游移，瞳孔收缩 | 嘴唇微颤，呼吸带动肩膀起伏明显 |
| 风流 / 倜傥 | 眉眼含情，面部微带笑意 | 眼神流转有光，眼尾微挑带韵 | 嘴角含一丝玩味，团扇或酒盏在手 |

## 四、摄影机语法——镜头选择与运动

### 4.1 焦段选择

| 焦段 | 叙事性格 | 适用场景 |
|---|---|---|
| 24-28mm广角 | 市井铺陈、园林山水开阔、宋人生活的广度 | 市井大全景、虹桥码头、园林全景、山水远景 |
| 35mm小广角 | 主观视点，身临其境的宋人生活纪实感 | 书斋穿行、茶肆对话、市井跟随、园林闲步 |
| 50mm标准 | 人眼等价，客观中立的注视，最诚实的镜头 | 人物肖像、双人对话、文人凝视 |
| 85mm中长焦 | 压缩空间，拉近情感距离，宋瓷与衣纹细节突出 | 特写、簪钗步摇、茶筅击拂、烛火下的面容 |
| 135mm+长焦 | 将人物从市井山水中剥离，极端的注视或窥视 | 月下远眺、长廊尽头注视、命运的距离感 |

### 4.2 景别选择

| 景别 | 取景范围 | 叙事功能 |
|---|---|---|
| 大特写 | 眼睛/嘴唇/玉簪/茶筅/毛笔落墨/瓷釉开片 | 情绪爆发点、关键信息揭示、感官聚焦 |
| 近景 | 头顶至胸部以上 | 人物情感、对话反应、淡妆眉眼微表情 |
| 中近景 | 头顶至腰部 | 人物互动、敛衽/奉茶/展卷/作揖手势 |
| 中景 | 头顶至膝盖上下 | 人物与空间初级关系、多人同框 |
| 全景 | 人物全身+部分场景 | 人物在空间中的位置、行动路线、褙子/直裰全貌 |
| 大全景/空镜 | 市井/园林全貌，人物极小或无人物 | 空间叙事、情绪缓冲、隐喻留白 |

### 4.3 摄影机运动

| 运动方式 | 视觉心理 | 使用场景 |
|---|---|---|
| 固定 | 从容静观，让时间自己说话 | 书斋展卷、茶席点茶、对话、空斋留白 |
| 手持微晃 | 在场感，呼吸感，主观介入 | 市井穿行、冲突波动、情绪波动 |
| 稳定器流动 | 优雅的回廊市井纵深，宋人生活的诗 | 人物登场、回廊纵深跟拍、市井穿行 |
| 缓推 | 注意力逐渐聚焦、情绪趋近 | 对话升温、真相逼近、情感推进 |
| 缓拉 | 拉开距离、揭示全貌、情绪抽离 | 离别、章节收束、空间展示 |
| 跟拍 | 与人物同行、主观陪同 | 回廊穿行、市井行走、园林闲步 |
| 摇镜 | 视线转移、空间关系交代 | 人物视线引导、市井纵深关系 |

## 六、美学禁止项

以下词汇/风格不得出现于输出提示词中：

- ❌ 3D渲染 / 3D建模 / CG / UE引擎 / Blender / PBR材质 / 次世代建模 / 体积光 / 环境光遮蔽 / 光线追踪
- ❌ 2D手绘 / 插画 / 动画 / 二次元 / 漫画 / Q版 / 赛璐璐 / 低多边形
- ❌ 写实摄影（英文禁止 photorealistic / realistic photography——本风格是"真人实拍摄影"live-action cinematic photography，不是"拟真渲染"）
- ❌ 过度磨皮 / 塑料假面 / 零毛孔 / 硅胶脸 / 蜡像感 / AI感平滑 / 妆容像贴图
- ❌ 仙侠法术 / 玄幻特效 / 真气流转 / 御剑飞行 / 法术光效 / 灵力光环 / 水墨法术特效
- ❌ 现代当代都市 / 民国 / 西方 / 和风日式 / 赛博朋克 / 科幻 / 西方奇幻 / 中世纪
- ❌ 跨朝代混搭：唐代浓艳（唐三彩浓色/浓妆艳抹/丰腴体态）/ 明清元素（黄琉璃硬山宫殿/旗装马褂）/ 清代旗装（钿子/花盆底/剃发垂辫/朝服补子/点翠头面/护甲/朝珠）
- ❌ 平面印花冒充刺绣 / 平面金线
- ❌ 人体结构错误 / 肢体畸形 / 面部崩坏 / 比例失调
- ❌ 高饱和荧光色 / 霓虹溢色 / 廉价滤镜感 / 二次元平涂 / 唐三彩浓艳色 / 明清珐琅彩浓彩
- ❌ 非中国宋代的架空场景 / 西式城堡 / 日式城堡 / 明清紫禁城式宫殿 / 无辨识度的 generic ancient
