## 一、色调体系与画面基调

- **色调基底** — 全片以天青（汝窑青 #6B8E7F）、月白（#D8DDE0）、茶褐（#6B4E3A）、墨青（#2F3E45）为基底色，辅以定窑白（#E8E4DA）、建盏黑（#1A1A1A）、竹青（#5E7A5E）、绢黄（#C9B98A）。整体色温分日间中性偏冷（格子窗天光5000-6000K柔和漫射）、夜间烛火暖橙主导（2200-2800K）+ 月光冷蓝（6500-7500K）。**饱和度低（35-55%）**，呈现"雅淡但不灰败"的克制宋韵色调——色彩来自宋韵雅色与实际光源，不来自后期调色，与盛唐浓艳、明清富丽形成鲜明对照
- **宋韵雅色即色盘** — 不以"主色/辅色"配对，而是以宋代美学与光源色温驱动画面色彩。天青为宋瓷之色（书斋/雅器）、月白为宋瓷素色（褙子/清雅人物）、茶褐为点茶之色（茶肆/常服）、墨青为山水之色（书斋深色/夜色）、建盏黑为深沉点缀（茶席核心）——尚"雅、简、淡、静"
- **冷暖叙事对照** — 暖光（市井斜阳暖金/茶肆烛火/纱灯笼火）用于市井繁华、茶席温情、对饮密谈、烛影私密段落；冷光（格子窗天光/月光/烟雨漫射）用于书斋清思、月夜孤寂、离愁哀怨、山水留白段落。关键转场可通过光源色温切换（如纱灯被风吹灭→月光从格子窗切入）来暗示情绪转向
- **光源先行原则** — 段落规划先确定"光从哪儿来、什么色温"（格子窗天光/烛火/月色/纱灯），再确定画面色调。避免"这个镜头颜色好看但光源说不通"
- **禁用色域** — 高饱和荧光色、廉价滤镜调色（如青橙预设/茶色预设）、CG金光溢色、霓虹色、二次元平涂、非真实光源产生的异常色偏、法术玄幻色、唐三彩浓艳色、明清珐琅彩浓彩——本风格尚"雅淡"，高饱和浓艳为最大审美违规

## 三、质感方向——摄影机前的真实宋韵

> 真人宋朝写实质感的唯一标尺：摄影机拍到的材质行为，不是渲染引擎生成的材质参数。

- **皮肤质感** — 毛孔可见、T区自然出油反光、颧骨处自然泛红、眼周微暗、宋代淡妆（薄施脂粉/淡扫蛾眉）与皮肤融合——真实皮肤的"活着"的证据。Seedance 2.0 提示词用"visible skin pores, natural skin texture, not airbrushed，宋代淡妆与皮肤融合，真实皮肤质感"替代 3D 项目的"次表面散射/SSS"
- **发髻冠巾质感** — 宋制高髻盘发/低髻真实结构、幅巾东坡巾裹首、鬓发碎发自然、发缕聚合分离、簪花玉簪步摇垂坠微动、烛火/天光逆光下发丝半透明暖色轮廓。Seedance 2.0 用"real Song-style coiled hair structure, scholar's silk cap and headscarf, flyaway hair strands, gently swaying hairpin, backlit hair rim light"替代"物理级发丝模拟"
- **宋制罗纱服饰质感** — 罗纱/丝绸/缂丝的轻盈光泽垂坠、褙子抹胸衫裙的瘦长修身层级、衣纹随身体动态与重力的自然垂坠、领襟层叠。Seedance 2.0 用"sheer silk beizi overlay, slim elongated Song silhouette, fabric drape with body movement, layered Song robe, lived-in costume"
- **宋代场景材质** — 木构梁枋的包浆、青瓦的积尘白头、格子窗棂的岁月、白墙的斑驳水痕、宋瓷釉面的开片与使用痕、书案的展卷磨损。Seedance 2.0 用"weathered Song timber beams with patina, dust-collected blue-grey tiles, crackled Song celadon glaze, real aged Song living surfaces, not showroom clean"

## 四、真人宋朝写实场景空间元素

中国宋代特有的场景元素及其在 Seedance 2.0 视频中的视觉叙事功能：

- **格子门窗/格子窗** — 宋代书斋与厅堂最核心的构图与光影道具。格子窗即光源入口——天光的方向和色温决定整个室内的光影逻辑。格子窗棂制造"宋韵雅致"的标志光影（方格光斑漏在书案地砖）。Seedance 2.0 中重点描述"daylight diffusing through lattice window of the study at specific angle"以帮助模型理解光源方向
- **青瓦素木/白墙/斗拱** — 宋代建筑的空间骨架。青瓦素木 = 宋人的雅致与素朴；白墙斑驳 = 岁月的痕迹；斗拱梁枋 = 宋代木构的工艺之美。Seedance 2.0 中场景必须明确"blue-grey tile roof with weathered white wall"或"Song timber frame with bracket set"等可被模型执行的光学描述
- **烛火/纱灯/茶汤灶火/月光** — 宋人世界的核心光源叙事载体。烛火暖橙（2200-2800K）= 书斋的体温与夜读；纱灯笼火透暖 = 市井夜市与灯会；茶汤灶火 = 茶肆的烟火气；月光冷蓝（6500-7500K）= 月夜书窗或离愁哀怨
- **书斋/茶肆市井/园林/西湖** — 宋代生活的四种叙事容器。书斋的文房清供与展卷 = 文人精神世界；茶肆酒楼的点茶幌子与人烟 = 宋代市井繁华（清明上河图）；园林的太湖石花木 = 文人雅致意趣；西湖的山水烟雨 = 南宋临安的诗意
- **段落间用场景空镜过渡** — 空镜为情绪缓冲，不用硬切。同一空间在不同时段/天气的空镜（如市井黄昏→月夜书斋）可暗示时间流逝。Seedance 2.0 中空镜需指定光源逻辑，空斋也有情绪
- **转折点用视觉而非台词** — 光影突变（纱灯被风吹灭→月光从格子窗切入）、景别跳切（中景→大特写）、空间转场（书斋→市井）、焦点漂移（从书案展卷的宋版书→背后的暗处）——由摄影机完成叙事

## 五、真人宋朝写实配乐与环境音

### 5.1 配乐乐器选择

真人宋朝写实配乐以民族乐器为主、弦乐铺底为辅、打击乐节制使用，追求"不抢戏的宋韵雅乐存在感"：

- **古琴** — 宋代文人第一乐器，文戏、独处、书斋、月夜独思的核心乐器。单音留白或稀疏泛音的最佳状态——琴韵之间的静默和音本身同样重要
- **笛/箫** — 园林、庭院、月夜、离愁的抒情主线。箫的苍凉适合离别哀怨，笛的明亮适合庭院闲适与少年意气
- **琵琶** — 市井繁华、紧张、对峙的情绪推动。轮指/扫弦适合市井鼎沸与冲突段落；琵琶也是宋代市井瓦子勾栏的代表乐器
- **筝** — 闺阁、茶席、雅集、温婉段落的抒情主线。音色清亮适合宋韵雅致
- **编钟/雅乐编磬** — 朝堂典礼、祭祀、大典、雅乐的礼乐之声。庄重肃穆，仅在大典礼段落使用，不滥用于市井
- **二胡/板胡** — 哀愁、凄凉、离别的情绪主奏。二胡的苍凉适合离愁/贬谪/远行段落
- **埙** — 古朴苍远，适合山水空灵、怀古追远段落
- **弦乐组（西式铺底）** — 情感积蓄与命运感段落的铺底。中低音区温暖铺底，高音区用于情绪高点的轻触即收
- **大鼓/建鼓** — 典礼、战争、气势段落的力量基底。节制使用，过则成戏
- **电子氛围 Pad** — 悬疑、暗涌、命运铺垫段落的低频铺底。克制使用，作为底层存在
- 慎用：大型交响全奏、重金属失真、高能电子舞曲、过度的国风电音beat——这些会让宋韵变成"配乐在演戏"

### 5.2 配乐组合策略

| 情绪阶段 | 乐器组合 |
|---|---|
| 书斋清思/文房雅事 | 古琴+箫点缀 |
| 茶席点茶/雅集清谈 | 筝+笛+轻弦乐 |
| 市井繁华/虹桥晨昏 | 琵琶+笛+轻打击+弦乐铺底 |
| 园林闲适/庭院 | 笛+筝+轻琵琶 |
| 离愁哀怨/月夜 | 箫+二胡+古琴泛音 |
| 紧张对峙/暗涌 | 琵琶轮指+电子Pad低频+节制鼓点 |
| 命运转折/远行 | 二胡+弦乐组渐强+埙收束 |
| 月夜独思/对月 | 古琴稀疏单音+箫点缀 |
| 大典礼/祭祀 | 编钟+雅乐编磬+大鼓+弦乐 |
| 结尾/余韵 | 古琴/箫单音渐疏 → 环境音独奏 |

### 5.3 真人宋朝写实环境音

> 环境音是宋代场景的"听觉材质"，决定了空间的沉浸感。每场戏标注 1-2 个核心环境音。

**核心环境音层次：**
- **书斋环境音**：翻书展卷声/毛笔触纸沙沙/香炉青烟哔剥/烛火微响/格子窗风过窗棂的轻鸣/远处市声隐约
- **市井环境音**：人声鼎沸/叫卖声/骡马蹄声/舟船橹声/酒幌布响/铜钱叮当/茶肆灶火蒸汽
- **茶肆环境音**：茶筅击拂茶汤的沙沙声/汤瓶注水声/茶客低语/跑堂吆喝/瓷盏轻碰
- **园林环境音**：风过竹林/花叶簌簌/鸟鸣（黄鹂/画眉/杜鹃）/水景潺潺/檐马叮当/远处笛声
- **西湖环境音**：水波拍舷/橹声欸乃/远处渔歌/鸥鹭鸣叫/风过桃柳
- **月夜环境音**：更鼓由远及近/烛火哔剥/铜漏滴水/虫鸣（秋蛩）/风过格子窗
- **静默也是一种环境音**：深夜书斋只有烛火哔剥与铜漏——这种"声音的缺失"本身就是叙事

音效设计哲学：
- 环境音不是贴上去的，是宋代场景自带的声音
- 关键时刻"抽掉"环境音比"加入"特效更能制造情绪冲击（如离别人远去时的骤然寂静）
- 环境音的变化可以暗示空间转换——从市井鼎沸走进书斋寂静，声音突然"变干净了"

## 七、全局叙事约束

- **空镜即情绪** — 每个叙事段落之间建议用场景空镜（同一空间在不同光线下）做情绪缓冲。空镜不是"没东西拍"，是"让观众喘口气"
- **光的连续性与变化** — 同一空间内在日间段落的天光角度应随时间连续变化。如果一场书斋戏跨越了半个时辰，格子窗光斑的面积应该移动了一些——Seedance 2.0 能理解这种"合理的不完全一致"
- **人物光源一致性** — 同一镜头内所有人物的面部光源方向必须统一。如果主光从格子窗右侧来，所有人的右脸都应该是亮面
- **服制连续性** — 同一场景内人物的褙子/直裰/衫裙、发髻冠巾、首饰在所有镜头中必须完全一致——不得无故换装
- **避免"过度导演"** — 真人宋朝写实追求"被摄影机捕获的宋人生活"，不是"被编剧安排的桥段"。允许画面中有不可控的宋韵细节（烛火摇曳、罗纱轻拂、花瓣飘落、簪钗微动）
- **静默的价值** — 不必每个镜头都填满动作和台词。一个3秒的静止特写——人物只是呼吸、眨眼、罗帕微动——往往比任何台词都更有力
