# 人物基础形象生成 · 时尚大片约束手册

---

## 一、基础形象原则

1. **骨相即灵魂** - 面部结构与轮廓光是角色唯一锚点，毛孔级精细渲染，高级脸优先于甜美脸
2. **角色为本** - 基础着装由角色描述（身份/职业/性别/造型定位）决定其常规造型；后续特定服化为叠加层
3. **四视图一致** - 面容/体型/发型/基础服装跨视图高度统一
4. **大片实拍** - 以真实超模摄影为锚点，保留皮肤真实质感（毛孔/微小瑕疵），姿态舒展、镜头感克制

---

## 二、面容约束

> 不再固定五官特征参数，由角色描述（性别/年龄/性格/气质）驱动 AI 自由生成五官，保证人物间外观差异化。

### 通用要求

| 项目 | 约束 |
|---|---|
| 五官 | 由角色描述自然推导，不预设脸型/眼型/眉型/鼻型/唇型，但整体须呈高级脸审美（骨相清晰、下颌线利落） |
| 风格底色 | 真人写实摄影、影棚硬光、骨相立体渲染、毛孔级精细渲染、写实材质 |
| 气质 | 必须从角色描述提炼整体气质关键词（如高冷/锋利/慵懒/清冷/强势），并写入提示词 |
| 表情 | 中性微表情 + 镜头感凝视，符合角色气质 |

## 六、基础服装约束

> 基础服装由角色描述（身份/职业/性别/造型定位）决定其最自然的常规造型，作为该角色「大片默认态」；礼服/主题造型在服化衍生环节叠加。**禁止内衣打底**，时尚风格必须强调高定/成衣质感。

### 着装选择原则

| 角色身份 | 默认着装方向 |
|---|---|
| 超模/大片主角 | 高定礼服 或 廓形感成衣套装 |
| 主编/设计师 | 设计师时装（结构感外套/利落套装） |
| 模特新秀 | 极简成衣（纯色连衣裙/修身西装） |
| 名流/富豪 | 高定正装/晚宴装 |
| 幕后职业（化妆师/公关等） | 全黑工作装束（利落黑衣） |
| 角色描述未明确 | 黑/白/灰纯色成衣，高定剪裁质感 |

### 着装统一规则

- 服装风格须与高级时装大片美学一致（纯色系、结构剪裁、面料垂坠）
- 强调高定/成衣质感：面料垂坠感、剪裁利落、廓形清晰
- 颜色以黑白灰纯色为主，无复杂花纹/装饰，便于后续衍生叠加
- 四视图服装款式完全一致
- 基础服装是「大片默认态」，焦点仍在面容与体态
- 严禁内衣/暴露/性化打底

## 八、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须为「大片默认态」造型，禁止内衣打底 |
| R2 | 必须根据角色描述声明合适的高定/成衣着装作为基础服装（如超模->高定礼服、主编->设计师时装、幕后->全黑工作装束）；必须强调高定/成衣质感 |
| R3 | 必须声明「无发饰、无配饰」 |
| R4 | 必须指定「纯净燕麦灰背景」 |
| R5 | 必须指定「四视图一致性」 |
| R6 | 全身立像必须从头顶到脚底完整展示，严禁裁切 |
| R7 | 必须声明角色身高并通过头身比换算约束全身比例，体型须符合模特身形规范 |
| R8 | 人像特写必须从头顶到锁骨完整展示，严禁裁切头顶 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 内衣/暴露/性化打底；与角色描述明显不符的着装；复杂花纹/装饰干扰后续服化叠加 |
| X2 | 正顶硬光/正底光/彩色光 |
| X3 | 过度美白/过度磨皮至无质感；甜美网红妆感 |
| X4 | 复杂场景背景（必须纯燕麦灰底） |
| X5 | 夸张表情/动态姿势（四视图须为大片站姿） |
| X6 | 全身立像裁切头顶或脚底，必须从头到脚完整入画 |
| X7 | 人像特写裁切头顶，必须从头顶到锁骨完整入画 |
| X8 | 忽略身高、头身比与模特身形约束 |
