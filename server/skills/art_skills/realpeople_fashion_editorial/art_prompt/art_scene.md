# 场景图生成 · 时尚大片约束手册

---

## 一、场景美学原则

1. **布景即概念** - 场景是整组大片的概念载体，影棚幕布与极简布景本身即叙事语言，不是纯背景板
2. **层次纵深** - 所有场景必须具备前/中/后景（幕布褶皱/主体布景/背景光晕），杜绝扁平
3. **质感至上** - 幕布织物/地胶/金属灯架/镜面/大理石等材质纹理必须超清晰
4. **实拍为锚** - 一切画面以真实摄影为标准，拒绝 3D 渲染/CG 动画质感；追求镜头光学特征（大光圈虚化、镜头暗角、色散微痕）与摄影布光逻辑（单灯硬光、轮廓光、剪影光比）

---

## 二、季节色调映射

> 时尚大片以主题季度（春夏/秋冬系列）替代自然季节概念，色调服务系列主题。

| 季节 | 主色调 | 辅色调 | 提示词 |
|---|---|---|---|
| 春夏系列 | 象牙白 + 正红 | 银灰、燕麦灰 | 春夏大片、白幕高调、正红点缀 |
| 秋冬系列 | 墨黑 + 勃艮第 | 香槟金、炭灰 | 秋冬大片、暗调幕布、金饰提亮 |
| 高定系列 | 香槟金 + 象牙白 | 银灰、深灰 | 高定大片、暖金光晕、白幕刺绣 |
| 概念系列 | 深灰 + 炭灰 | 墨黑、银灰 | 概念大片、灰幕阵列、冷峻极简 |

## 三、室内场景

### 空间规范

| 维度 | 约束 | 提示词 |
|---|---|---|
| 风格 | 专业影棚/秀场/后台/试衣间，极简或纯色布景，戏剧化布光 | 摄影影棚、纯色幕布、editorial set design |
| 材质 | 幕布织物/地胶/金属灯架/镜面/大理石为主 | 无缝背景幕布、反光地胶、金属灯架 |
| 色调 | 墨黑/象牙白/深灰幕布 + 单一点缀色 | 暗调布景、单色幕布、克制点缀 |
| 纵深 | 前/中/后景层次 | 前景{元素}、中景{布景主体}、后景{幕布光晕} |
| 质感 | 幕布褶皱/地胶反光/金属拉丝/镜面映射可辨 | 幕布自然垂褶、地胶反光、镜面质感 |
| 光照 | 单灯硬光为主（聚光/束光筒/蜂窝罩），光比大，可见光束粒子与幕布光晕渐变 | dramatic studio lighting、hard key light、single spotlight、beam light |
| 镜头感 | 大光圈虚化、微镜头暗角、冷调色偏 | shallow depth of field、lens vignette、cool color grade |
| 布景痕迹 | 幕布有自然垂褶与暗角、地胶有走位磨损、灯架线缆入画感 | 布景真实感、走位痕迹、摄影棚细节 |

### 室内类型速查

| 类型 | 核心元素 | 氛围词 |
|---|---|---|
| 影棚黑幕区 | 无缝黑幕、束光筒灯位、地胶 | 戏剧压迫、暗调雕塑 |
| 影棚白幕/色纸区 | 无缝白幕、色纸背景、大柔光箱 | 高调纯净、概念极简 |
| 秀场T台 | 伸展台、顶部阵列灯、两侧观众席虚化 | 秩序威压、荣耀仪式 |
| 后台化妆间 | 化妆镜灯泡阵列、化妆台、挂衣架 | 紧张备战、真实后台 |
| 试衣间/挂衣廊 | 服装挂杆、高定礼服、全身镜 | 待选张力、奢华密集 |

## 五、主视图规范

### 视图定义

> 单画面主视图，从布景/外景地最具代表性的机位拍摄，承载整组大片的概念重心与构图张力。

| 项目 | 约束 | 提示词 |
|---|---|---|
| 视角 | 概念主视觉机位，构图最能体现布景主体与空间纵深 | hero shot、editorial set wide shot |
| 视点高度 | 默认平视或微仰（强化空间气场），特殊场景可俯 | eye level（默认）、low angle |
| 构图 | 主体居中或强对称/三分法，前/中/后景层次清晰 | balanced composition、symmetrical composition |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 单画面（非拼图、非多视图、非分屏） |
| 人物 | **严禁出现任何人物、人影、人体轮廓** |
| 一致性 | 风格/材质/色调/光线统一 |
| 光线 | 单一光源逻辑，光影方向一致，光比明确 |
| 画面比例 | 默认 16:9（或按调用方设定） |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 场景必须有「前中后景层次」 |
| R2 | 室外必须包含「空气透视」 |
| R3 | 场景图必须为「单画面主视图」，不得拼接多视图/分屏/网格 |
| R4 | 构图须能代表布景/外景地主体并展示前/中/后景层次 |
| R5 | 场景图中**严禁出现任何人物** |
| R6 | 必须包含实拍摄影关键词（real photography / photorealistic / RAW photo） |
| R7 | 必须包含镜头光学特征（shallow depth of field / lens vignette / bokeh 至少一项）与戏剧布光关键词（hard key light / spotlight 至少一项） |
| R8 | 材质必须带有真实布景痕迹（幕布垂褶/走位磨损/混凝土风化），禁止全新无瑕的"CG 感" |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 背景杂乱无概念（大片布景必须概念统一） |
| X2 | 极端天候（暴风雨/雷电/暴雪，除非剧情需要） |
| X3 | 场景无纵深/无层次 |
| X4 | 自然元素与系列主题矛盾 |
| X5 | 出现任何人物、人影、人体剪影或人体轮廓 |
| X6 | 画面被拼接成多视图/网格/分屏布局 |
| X7 | 3D 渲染/CG 动画/卡通/游戏引擎质感（禁用 3D render、CGI、Unreal Engine、Unity 等词） |
| X8 | 材质过于干净完美、无任何布景痕迹与使用感（避免"塑料感"） |
| X9 | 光照过于均匀平坦、无光比、无镜头光学特征 |
