# 时尚大片风格说明

本风格专为"时尚大片"题材打造，所有美术提示词、规范和生成内容均严格限定于：

- **高定大片世界观**：以高级时装大片（Vogue / Harper's Bazaar 封面级 editorial）为标杆，涵盖影棚纯色幕布、秀场、后台等戏剧化空间，杜绝日常随拍感。
- **真人写实**：所有角色、场景、道具均以真人写实摄影为标准，强调骨相、皮肤、发丝、高定面料等极致细节与真实质感。
- **影棚戏剧光影**：单灯硬光、蝴蝶光、伦勃朗光与戏剧性剪影构成画面骨架，明暗对比极强，人物如雕塑般被光塑形。
- **高级冷艳氛围**：适合展现气场、张力、孤傲与蜕变感的时尚叙事，强调超模姿态与高级脸的镜头表现力。

## 适用范围

- 时尚大片题材的AI美术生成（角色、场景、道具、分镜等）
- 需要影棚戏剧化光影、高定质感、封面级构图张力的视觉创作

## 严禁内容

- 卡通、动漫、插画、二次元风格
- 日常随拍感、旅游照感、手机随手拍质感
- 高饱和荧光色、糖果色、甜腻少女色系
- 暗示性、暴露、透视等不适宜内容

## 风格体验

在本风格下，您将体验到：

- 角色面容高级、骨相立体，妆发造型为大片级高定水准
- 场景以影棚纯色幕布与极简布景为主，光影雕塑感极强
- 道具以箱包、鞋履、珠宝配饰、美妆产品为核心，工艺细节极致
- 分镜与视频均以真人写实为基础，强调姿态张力与时尚叙事表达

---

本风格仅适用于"时尚大片"相关项目。如需其他风格（如古风、插画、动漫、都市写实等），请勿使用本套提示词。
