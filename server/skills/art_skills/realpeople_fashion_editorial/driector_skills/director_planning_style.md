# 大片风格约束 · 时尚大片 · 技法参考

---

## 一、色调体系与画面基调

- **色调基底** - 全片以墨黑（C4）、象牙白（C1）、深灰（C6）为基底色，整体色温中性偏冷（5000-5500K），饱和度低-中（30-50%），呈现暗调雕塑感的封面级影棚美学
- **点缀叙事对比** - 正红（C3）与香槟金（C5）作为关键帧的视觉爆点：正红用于蜕变、对峙与高光定格，香槟金用于加冕、谢幕与荣耀时刻；点缀色全片克制使用，一帧一焦点
- **冷暖分配策略** - 暗底亮人是核心策略：墨黑/炭灰铺底，光只落在人物面容与造型轮廓上；暖色仅在高光段落释放，避免全程高暖导致张力稀释
- **色盘先行原则** - 段落规划先绑定情绪场景（定场气场/张力对峙/脆弱卸防/蜕变重生/高光谢幕等），再确定主色+辅色与光影方案，避免"剧情对了但情绪不对色"
- **禁用色域** - 高饱和荧光色、糖果色、甜腻少女色系与本风格不兼容

## 二、光影方案体系

- **光影即雕塑** - 6 套光影方案对应不同情绪段落，导演规划阶段应在段落层面确定光影基调方向，而非逐镜指定
- **光源角度** - 影棚主灯默认 45° 斜上硬光（蝴蝶光位），外景硬光顺侧 30°-45°；侧给镜头根据人物关系微调光比

| 光影方案 | 方案名 | 色调倾向 | 适用情绪 |
|---|---|---|---|
| A | 单灯硬光雕塑 | 墨黑底 + 极强光比 | 定场气场、封面定格 |
| B | 蝴蝶光正面 | 冷调肤 + 背景压暗 | 暧昧凝视、人物特写 |
| C | 伦勃朗硬侧光 | 深灰底 + 面部明暗分割 | 对峙、锋芒、脆弱卸防 |
| D | 逆光剪影 | 象牙白/暖金轮廓 + 主体沉黑 | 蜕变重生、悬念转场 |
| E | 顶光阵列（秀场） | 冷暖交织 + 纵深光束 | 群像阵列、仪式威压 |
| F | 漫射软光高调 | 象牙白底 + 柔和均匀 | 概念极简、清冷松弛 |

- **冷暖光分配** - 暖金光（香槟金 C5）仅用于荣耀与升温段落；冲突/卸防段落保持冷调硬光，避免情绪与光色冲突
- **氛围方向映射** - 每场戏氛围方向应映射到上述光影方案（A-F）的某一方向，确保视觉一致性

## 三、质感方向

- **中画幅人像质感** - 以 85mm 以上中长焦人像镜头为视觉基准：面部透视平实、背景压缩、主体如雕塑般突出
- **大光圈浅景深** - 焦点永远钉在面容与造型细节上，背景幕布化为色块与光晕，杜绝全画面清晰的光板感
- **细腻胶片颗粒** - 轻微胶片颗粒维持"真实照片"属性，宽动态范围保留暗部层次，黑要黑得进去、亮要亮得克制
- **面料即肌理** - 缎面流光、皮革油润、纱层透叠等高定面料质感是画面肌理核心，皮肤保留毛孔与雾面妆感，拒绝塑料皮肤

## 四、大片场景空间元素

时尚大片世界观特有的场景元素及其视觉叙事功能：

- **无缝幕布（黑/白/色纸）** - 概念容器：黑幕承载压迫与气场，白幕承载纯净与概念，色纸呼应系列主题色
- **束光筒光束与地胶反光** - 影棚光线的仪式感符号，光束粒子与地面反光可作空镜过渡语言
- **化妆镜灯泡阵列** - 后台叙事核心：镜像带来分裂与审视，灯泡阵列暖光与影棚冷硬光形成情绪对照
- **伸展台与观众席虚化** - 秩序与被注视的权力关系载体，T 台纵深直接映射人物弧光的走向
- **混凝土立面与空旷地平线（外景）** - 人物如立于雕塑之中，天光硬朗衬托面料的柔软，用于段落间的视觉呼吸
- **空镜过渡建议** - 幕布褶皱特写、珠宝静物微距、灯架亮灭、裙摆扫过地胶的残影，皆可作高级转场；转折点优先用光比突变与幕布换色承接，而非对白解释

## 五、大片乐器与环境音

时尚大片世界观下的声音元素约束：

### 乐器选择

- **电子/合成器** - 定场与气场段落核心音色，低频脉冲直接对应画面张力
- **浩室（House）/律动电子** - 秀场、后台备战、快剪蒙太奇段落的主导节奏
- **弦乐简约（极简主义弦乐）** - 情绪抬升、蜕变与加冕段落的主力铺底
- **钢琴单音** - 脆弱卸防、内省独白段落的留白乐器
- **环境音优先级高** - 影棚与秀场的真实环境声是沉浸感关键，配乐不应压过脚步与呼吸

### 乐器组合策略

| 情绪阶段 | 乐器组合 |
|---|---|
| 平稳/开场/收尾 | 钢琴单音 或 弦乐简约长音 |
| 定场气场/封面定格 | 电子低频脉冲 + 合成器铺底 |
| 蜕变/快剪蒙太奇 | 浩室律动 + 弦乐推进 |
| 情绪爆发/加冕 | 弦乐主导 + 电子低频铺底 |
| 脆弱卸防/内省 | 钢琴独奏 + 环境声留白 |

### 大片环境音

- **典型环境音层次** - 快门连拍声 / 高跟鞋走位于地胶 / 幕布布料摩擦 / 反光板与灯架调整声 / 后台嘈杂人声 / 秀场低频音响震动 / 空调与镇流器底噪
- **每场戏标注 1-2 个核心环境音**，帮助后续音效设计。环境音层次越准确，大片实拍质感越强
- **留白建议** - 定格帧与封面式构图的收尾处配乐骤停、只留一声快门，是本风格的标志性声音设计；内省段落允许 2-3 秒纯环境音留白
