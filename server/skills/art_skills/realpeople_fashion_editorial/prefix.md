## 二、全局色彩盘（风格基线，不是硬锁）

> 目标：统一审美而非限制创作。除「硬约束色」外，其余颜色默认优先使用，可在合理范围内偏移。

### 色彩使用层级

| 层级 | 约束强度 | 说明 |
|---|---|---|
| L1 硬约束 | 高 | 仅锁定角色识别核心：肤色、发色、主服底色的审美方向 |
| L2 软约束 | 中 | 幕布色、配饰色、点缀色优先参考色盘，可按镜头与剧情微调 |
| L3 例外机制 | 低 | 概念大片/高潮定格/主题封面可临时突破局部色彩，但需保留整体明暗雕塑逻辑 |

### 硬约束色（默认锁定）

| 色项 | 对应色 | 规则 |
|---|---|---|
| 肤色基准 | C2 冷调肤 | 默认优先，允许小幅明度/冷度微调 |
| 发色/瞳色基准 | C4 墨黑 | 默认优先，允许墨黑/深褐/造型漂色轻微偏移（需角色描述支持） |

### 软约束色（推荐优先）

> C1/C3/C5/C6/C7/C8/C9/C10 为推荐色域，用于幕布、礼服、珠宝、暖金光晕、银饰、暗部层次等。可根据大片主题做同色相邻近调整。

### 情绪色盘（导演对齐版）

### 情绪色盘使用规则

| 编号 | 规则 |
|---|---|
| E1 | 每条提示词至少指定 1 个「情绪场景」并绑定主色+辅色组合 |
| E2 | 单镜头主色不超过 2 个，避免颜色叙事失焦 |
| E3 | 情绪切换时优先调整光比与光位，再调整饱和度 |
| E4 | 大片向默认遵循「暗底 + 亮人」：暗色铺底，光与高饱和只落在人物与造型焦点 |
| E5 | 若与剧情冲突，以情绪色盘优先于通用推荐色，但不得突破严禁项 |

### 色温约束

| 参数 | 值 | 说明 |
|---|---|---|
| 整体色温 | 中性偏冷 5000-5500K（推荐） | 影棚大片冷静克制主基调 |
| 肤色色温 | 微冷 5000-5400K（推荐） | 冷调但有血色与生命感 |
| 对比度 | 极强（建议保持） | 明暗反差呈雕塑感 |
| 饱和度 | 低-中 30-50%（建议区间） | 高级时装克制色调 |

### 容差与例外

| 项目 | 建议容差 |
|---|---|
| 色相偏移 | ±8° |
| 饱和度偏移 | ±10% |
| 明度偏移 | ±12% |

> 例外场景：红毯定格、概念封面、情绪高潮镜头可使用正红或香槟金大面积色块；但禁止荧光糖果色与甜腻少女色系入镜。

## 三、全局约束规则

### 必守规则（所有技能继承）

| 编号 | 规则 |
|---|---|
| R1 | 必须包含「真人写实摄影」风格锚定词 |
| R2 | 必须声明「单灯硬光 + 戏剧性明暗对比」 |
| R3 | 面部必须使用「骨相立体渲染 + 皮肤细腻」 |
| R4 | 发丝必须使用「根根分明 + 发丝细腻渲染」 |
| R5 | 纹理必须声明「高定面料纹理超清晰」 |

### 严禁项（所有技能继承）

| 编号 | 严禁内容 |
|---|---|
| X1 | 严禁「卡通/动漫/二次元/插画风」 |
| X2 | 严禁「高饱和荧光色/糖果色/甜腻少女色系」 |
| X3 | 严禁「大片造型语言缺失」（必须明确戏剧布光与高定造型） |
| X4 | 严禁「面部变形/多指/肢体异常」倾向词 |
| X5 | 严禁「裸体/暴露/透视/暗示性描述」 |
| X6 | 严禁「古风/古装/汉服/日常随拍感」 |
