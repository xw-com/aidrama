# 场景图生成 · 约束手册

---

## 一、场景美学原则

1. **空间叙事** — 场景承载情绪与叙事功能，不是纯背景板；舰桥暗示指挥权、格纳库暗示备战、废墟暗示战火
2. **层次纵深** — 所有场景必须具备前/中/后景，杜绝扁平
3. **质感至上** — 钛银装甲、钢灰金属、全息光、推进尾焰等材质纹理必须超清晰
4. **二次元为锚** — 一切画面以机甲科幻二次元为标准，拒绝3D写实/CG动画质感；追求干净线条、赛璐璐平涂、能量光效

## 五、主视图规范

### 视图定义

> 单画面主视图，从场景中最具代表性的角度拍摄，承载空间叙事与构图重心。

| 项目 | 约束 | 提示词 |
|---|---|---|
| 视角 | 自然观察视角，构图最能体现场景主体与纵深 | hero shot、representative angle |
| 视点高度 | 默认人眼平视高度，特殊场景可俯/仰 | eye level（默认） |
| 构图 | 主体居中或符合三分法，前/中/后景层次清晰 | balanced composition |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 单画面（非拼图、非多视图、非分屏） |
| 人物 | **严禁出现任何人物、人影、人体轮廓**（机甲在本场景资产中也严禁出现，机甲属道具/角色资产） |
| 一致性 | 风格/材质/色调/光线统一 |
| 光线 | 单一光源逻辑，光影方向一致 |
| 画面比例 | 默认 16:9（或按调用方设定） |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 场景必须有「前中后景层次」 |
| R2 | 舱外必须包含「空气透视/空间纵深」 |
| R3 | 场景图必须为「单画面主视图」，不得拼接多视图/分屏/网格 |
| R4 | 构图须能代表场景主体并展示前/中/后景层次 |
| R5 | 场景图中**严禁出现任何人物**，也严禁出现机甲（机甲属道具/角色资产） |
| R6 | 必须包含机甲科幻二次元关键词（mecha sci-fi anime / cel shading / clean linework） |
| R7 | 必须包含镜头光学特征（赛璐璐平涂 / 干净线条 / 能量光效） |
| R8 | 材质必须带有战损/磨损/烧蚀痕迹，禁止全新无瑕的"塑料感" |
| R9 | 必须包含 @ImageX_{场景名} 锚点 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 背景纯白/纯黑/无场景 |
| X2 | 传统东方古韵画风/古典东方建筑/写意传统氛围混入 |
| X3 | 场景无纵深/无层次 |
| X4 | 植被/天候与战区设定矛盾（如废墟都市出现古典东方园林） |
| X5 | 出现任何人物、人影、人体剪影或人体轮廓，以及机甲 |
| X6 | 画面被拼接成多视图/网格/分屏布局 |
| X7 | 3D 写实/CG 动画/卡通/游戏引擎质感（禁用 3D render、CGI、Unreal Engine、Unity 等词作为风格声明） |
| X8 | 材质过于干净完美、无任何战损与使用痕迹（避免"塑料感"） |
| X9 | 光照过于均匀平坦、无景深虚化、无镜头光学特征 |
