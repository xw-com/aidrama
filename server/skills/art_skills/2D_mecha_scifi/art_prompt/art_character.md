# 人物基础形象生成 · 约束手册

---

## 一、基础形象原则

1. **造型即灵魂** — 角色造型是核心锚点，机甲科幻二次元造型，线条干净利落
2. **底模即基础** — 基础驾驶服 / 紧身飞行服 + 素颜，后续装备均为叠加层
3. **四视图一致** — 面容/体型/发型/基础服装跨视图高度统一
4. **科幻气质** — 无妆状态仍需体现角色气质（冷峻果决/沉稳指挥/神秘异星/灵动少年）

---

## 二、面容约束

> 不再固定五官特征参数，由角色描述（性别/年龄/性格/气质/驾驶员类型）驱动 AI 自由生成五官，保证人物间外观差异化。机甲科幻题材允许发色 / 瞳色多样化（异星、AI、改造人均可），由角色描述推导。

### 通用要求

| 项目 | 约束 |
|---|---|
| 五官 | 由角色描述自然推导，不预设脸型/眼型/眉型/鼻型/唇型 |
| 风格底色 | 机甲科幻二次元、赛璐璐平涂、干净利落线条、能量光效、硬核机械审美 |
| 气质 | 必须从角色描述提炼整体气质关键词（如冷峻果决/沉稳威严/神秘疏离/灵动热血），并写入提示词 |
| 表情 | 中性微表情，符合驾驶员气质 |

## 五、基础发型约束

> 机甲科幻题材不锁定单一发色（异星/改造/AI 均允许彩色发色），发色与造型由角色描述推导；仅定义"自然发型"，发饰与头盔在服化衍生环节叠加。

### 女性

| 项目 | 约束 | 提示词 |
|---|---|---|
| 发色 | 由角色描述推导（如银白/能量蓝/异星粉/墨黑均可） | {发色}长发、发丝清晰 |
| 发长 | 由角色描述推导，默认中长至长发 | 中长发/长发 |
| 发质 | 干净利落线条、发丝清晰 | 干净线条、清晰发丝 |
| 造型 | 自然散发、无发饰 | 长发自然散落、无发饰 |

### 男性

| 项目 | 约束 | 提示词 |
|---|---|---|
| 发色 | 由角色描述推导（如银白/深空黑/能量紫均可） | {发色}短发/中长发、发丝清晰 |
| 发长 | 短发或中长发 | 利落短发/中长发 |
| 发质 | 干净利落线条、发丝清晰 | 干净线条、清晰发丝 |
| 造型 | 自然短发或束发，无头饰 | 自然短发/后束短发 |

## 六、基础服装约束

> 基础服装无特殊约束，统一为素色基础驾驶紧身服（plug suit / 飞行服打底），无装甲、无装备、无徽记。正式驾驶服 / 战术装备在服化衍生环节叠加。

### 女性基础服装

素色基础驾驶紧身服，钛银或深空黑底色为主，无装备挂点、无徽记。

### 男性基础服装

素色基础驾驶紧身服，钛银或深空黑底色为主，无装备挂点、无徽记。

### 着装统一规则

- 服装风格统一，确保后续装备叠加无色彩干扰
- 除面部/手部/颈部外基本覆盖（紧身服覆盖躯干四肢）
- 四视图服装款式完全一致
- 基础服装仅为安全打底，焦点在面容与体态

## 八、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须为「素颜状态」 |
| R2 | 必须声明基础服装（素色基础驾驶紧身服，无装备挂点无徽记） |
| R3 | 必须声明「无发饰、无配饰、无装备」 |
| R4 | 必须指定「深空黑纯色背景」 |
| R5 | 必须指定「四视图一致性」 |
| R6 | 全身立像必须从头顶到脚底完整展示，严禁裁切 |
| R7 | 必须声明角色身高并通过头身比换算约束全身比例（女性默认 158-170cm/6-7头身，男性默认 172-185cm/6-7头身） |
| R8 | 人像特写必须从头顶到锁骨完整展示，严禁裁切头顶 |
| R9 | 必须包含 @ImageX_{角色名} 锚点 |
