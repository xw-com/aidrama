## 二、全局色彩盘（风格基线）

### 色彩使用层级

| 层级 | 约束强度 | 说明 |
|---|---|---|
| L1 硬约束 | 高 | 机甲科幻色基线、二次元配色、能量发光描边 |
| L2 软约束 | 中 | 战区色、装甲色、能量发射色可按情绪微调 |
| L3 例外机制 | 低 | 特殊场景/高光时刻可临时突破局部色彩 |

### 硬约束色（默认锁定）

| 色项 | 对应色 | 规则 |
|---|---|---|
| 整体色调 | 机甲科幻色 + 二次元配色 | 禁止高饱和荧光色（能量发射器高光除外） |
| 线条颜色 | 深空黑或钢灰 | 禁止纯黑粗线条 |
| 阴影 | 同色系加深 | 禁止黑色硬阴影 |
| 赛璐璐色块 | 平滑渐变 | 禁止色块断层/色彩溢出 |

### 色温约束

| 参数 | 值 | 说明 |
|---|---|---|
| 整体色温 | 偏冷 6500-8000K（太空主基调，推荐） | 战场冷调主基调 |
| 对比度 | 中高 55-75%（建议区间） | 硬核机械层次感 |
| 饱和度 | 中 45-65%（建议区间） | 能量发射色局部高饱和，整体克制 |

### 容差与例外

| 项目 | 建议容差 |
|---|---|
| 色相偏移 | ±8° |
| 饱和度偏移 | ±10% |
| 明度偏移 | ±12% |

## 三、全局约束规则

### 必守规则（所有技能继承）

| 编号 | 规则 |
|---|---|
| R1 | 必须包含「机甲科幻二次元」风格锚定词 |
| R2 | 必须声明「赛璐璐平涂 + 干净利落线条」 |
| R3 | 必须声明「装甲分件线 / 机械刻线 + 能量发光描边」 |
| R4 | 必须声明「硬核机械设计 + 电影质感」 |
| R5 | 必须声明「机甲科幻二次元电影风格」 |

### 严禁项（所有技能继承）

| 编号 | 严禁内容 |
|---|---|
| X1 | 严禁「写实摄影/3D 写实 CG 渲染/照片级真实感」（禁用 3D render、CGI、Unreal Engine、Unity 等词作为风格声明） |
| X2 | 严禁「传统东方古韵画风/古典东方服饰画风/写意传统画」（本风格独立，禁与其他画风混血） |
| X3 | 严禁「魔法玄幻/西方中世纪/蒸汽朋克」混入 |
| X4 | 严禁「粗劣线条/模糊画质/低精度/塑料感无瑕材质」 |
| X5 | 严禁「色彩混乱/风格不统一/审美崩坏」 |
