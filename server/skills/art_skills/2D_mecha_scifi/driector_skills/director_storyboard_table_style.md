# 分镜表机甲科幻约束 · 机甲科幻风格 · 技法参考

---

## 一、分镜表定位

分镜表是导演将剧本转化为镜头语言的核心工具。以下仅提供机甲科幻风格在分镜表层面的约束规范。

---

## 二、光影与氛围

- **赛璐璐光影统一** — 一场戏内光影方案必须保持赛璐璐平涂一致性，阴影使用同色系加深（禁止黑色硬阴影），除非有明确的叙事转折（如全息舱光熄灭→警报红闪）
- **情绪色盘绑定** — 每场戏至少绑定 1 个情绪场景（出击巡航/决战高潮/孤独深空/机甲觉醒/都市日常/战后残骸），并在镜头组内保持主色+辅色连续性，色彩取自核心色盘（钛银 #A8B0B8 / 能量蓝 #2E8BD0 / 警示橙 #E8650C / 深空黑 #16181E / 霓虹青 #3ED8C8 / 能量紫 #8A4AE0 / 钢灰 #4A5058 / 警报红 #D32F2F / 等离子白 #EAF6FF / 焦土棕 #6B4A2E）
- **光源角度规范** — 正给镜头光源默认 38.5° 斜射柔光（赛璐璐平涂质感），侧给镜头根据画面需要调整。能量发射器与推进尾焰须带镜头光晕与发光描边，描述光影时须区分正给/侧给的角度差异
- **冷暖色调与叙事阶段匹配** — 深空巡航/孤独对峙段落使用冷色调（钛银 + 深空黑 + 能量蓝），禁用警示橙暖光；决战高潮/战损危机段落使用警示橙 + 警报红暖光；机甲觉醒段落使用能量紫 + 能量蓝辉光
- **光影转场是高级手段** — 从全息舱光渐变到警报红闪 = 巡航转入危机。在分镜表中标注光影变化点，转场过程中赛璐璐色块必须平滑渐变，禁止色块断层/色彩溢出
- **动画光效** — 允许合理使用体积光（volumetric light）、景深虚化、镜头光晕（lens flare）、发光描边等动画技法，但必须保持机甲科幻二次元赛璐璐平涂的美学基调，禁止 3D 写实/CG 动画光效

---

## 三、环境动态

- **环境动态增加画面呼吸感** — 推进尾焰流动、能量节点闪烁、全息数据流滚动、警报灯闪烁、星尘漂浮、碎片缓动、烟柱升腾。每 3-4 个镜头至少安排一个有环境动态的镜头，避免画面"死"掉
- **机甲科幻环境元素优先** — 环境动态应选用本世界观内的元素：能量光束交错、推进尾焰、全息数据流、警报闪烁、漂浮残骸、电弧迸射、星尘漂浮、火花迸溅，禁止出现古典东方画风/魔法元素
- **赛璐璐动态质感** — 环境动态元素（尾焰/光束/全息/碎片等）必须保持赛璐璐平涂质感与干净线条，能量元素用发光描边呈现，禁止出现 3D 粒子特效或写实流体效果

---

## 四、机甲与人物动作节奏

- **机甲动作有重量感** — 人形机甲的步伐、举臂、转身默认沉稳厚重，每步带金属踏地震动与微尘，禁止轻飘飘无重量感的运动。机甲步行约 1-1.5 步/秒，奔跑时带速度模糊（speed blur）与姿态喷口修正
- **推进器点火有过程** — 推进尾焰点火须分阶段：喷口预热微光 → 等离子白核心成型 → 暖橙尾焰喷射 → 加速位移，单次点火时长建议 0.8-1.2 秒，尾焰用暖橙渐变 + 等离子白核心 + 发光描边
- **光束射击有蓄放** — 光束步枪发射须有蓄能（能量节点亮起 0.2-0.4 秒）→ 发射（等离子白光束 + 镜头光晕 + 速度线）→ 余热（枪管散热口蒸汽 0.3 秒）的节奏，光束用等离子白核心 + 能量蓝外缘 + 发光描边
- **能量光剑拔收有光** — 能量光剑拔出时能量紫/蓝辉光渐亮 + 发光描边扩散（0.3-0.5 秒），挥动时带能量残影与速度线，收剑时辉光渐熄
- **人物动作干练带动画感** — 驾驶员动作默认干练利落，但可在关键帧做二次元夸张处理（觉醒时瞳孔能量辉光、决胜时眼神锁定特写），敬礼、转身、抬头应标注"干练/果决"
- **驾驶服动态** — 驾驶服的反光条、接口走线、磁吸挂点在动作中是天然的动态资产，可在画面描述中加入接口节点闪烁、反光条流光，赛璐璐渲染下应线条清晰、层次分明
- **头身比一致** — 动作设计中角色必须保持 6-7 头身的二次元科幻比例，机甲必须保持设定的头身/比例（通常 9-12 头身以上的人形机甲比例），禁止因动态姿势而破坏比例

---

## 五、材质与质感约束

- **赛璐璐平涂为锚** — 所有镜头中人物/驾驶服/机甲/道具/场景的渲染必须保持赛璐璐平涂质感，线条干净清晰，色块平滑，禁止 3D 写实/CG 动画/照片级渲染
- **机甲材质** — 钛银合金装甲 + 钢灰骨架 + 能量蓝关节的质感用赛璐璐平涂表现，分件线/散热栅口/推进喷口纹理必须超清晰，关节带能量辉光
- **道具材质** — 钛银枪身、能量晶体、等离子核心、全息光体，均以赛璐璐平涂 + 干净线条 + 发光描边呈现，禁止写实材质渲染
- **场景材质** — 装甲有战损划痕、面板有油渍磨损、地面前有刮痕，材质带有使用感但以机甲科幻赛璐璐笔触呈现，禁止"塑料感"的全新无瑕材质

---

## 六、色彩约束

- **核心色盘锁定** — 分镜表中所有镜头的色彩必须取自核心色盘（C1-C10），色相偏移容差 ±8°，饱和度偏移 ±10%，明度偏移 ±12%
- **能量色例外** — 能量发射器、光束、推进尾焰、全息屏允许局部高饱和发光（能量蓝/能量紫/警示橙/等离子白），这是本风格的能量张力来源，不计入整体饱和度上限
- **禁止荧光滥用** — 整体画面严禁滥用高饱和荧光色，能量色仅用于发光节点与光束本体
- **线条颜色** — 深空黑或钢灰，禁止纯黑粗线条
- **阴影色** — 同色系加深，禁止黑色硬阴影
- **整体色温** — 偏冷 6500-8000K 太空主基调，对比度 55-75%，饱和度 45-65%（能量色局部高饱和例外）

---

## 七、运镜与转场禁忌

- **禁用破坏重量感的运镜** — 轻飘甩镜、手持摇晃、纪录片式跟拍与机甲的厚重质感冲突，决战场景可适度加快运镜节奏但仍需保持画面清晰
- **禁用花式转场** — 划屏、旋转、百叶窗、翻页等与本硬核风格不兼容
- **禁用写实镜头语言** — 鱼眼镜头、过度广角畸变、手持摇晃 Vlog 风格与二次元美学冲突，破坏赛璐璐平涂的画面纯净感
- **转场优先匹配机甲物理** — 推荐用动作匹配（机甲抬臂→光束发射）、光影匹配（全息舱光→警报红闪）、元素匹配（推进尾焰→爆炸火光）等硬核物理转场，避免无逻辑硬切
