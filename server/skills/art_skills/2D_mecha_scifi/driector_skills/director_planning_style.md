# 机甲科幻约束 · 机甲科幻风格 · 技法参考

---

## 一、色调体系与画面基调

- **色调基底** — 全片以核心色盘为基底：钛银（C1 #A8B0B8）、能量蓝（C2 #2E8BD0）、警示橙（C3 #E8650C）、深空黑（C4 #16181E）、霓虹青（C5 #3ED8C8）、能量紫（C6 #8A4AE0）、钢灰（C7 #4A5058）、警报红（C8 #D32F2F）、等离子白（C9 #EAF6FF）、焦土棕（C10 #6B4A2E），整体色温偏冷（6500-8000K 太空主基调），饱和度中（45-65%），呈现机甲科幻硬核冷峻的画面
- **冷暖叙事对比** — 冷色（钛银 C1、深空黑 C4、能量蓝 C2、霓虹青 C5、钢灰 C7）作为巡航/孤寂/精密的视觉信号；暖色（警示橙 C3、警报红 C8、焦土棕 C10）作为战斗/危机/战损的视觉信号。冷暖切换应与故事弧线同步，而非随意混用
- **冷暖分配策略** — 深空巡航/孤独对峙段落使用冷色调（钛银 + 深空黑 + 能量蓝），禁用警示橙暖光；决战高潮/战损危机段落使用警示橙 + 警报红暖光；机甲觉醒/能量觉醒段落使用能量紫 + 能量蓝辉光
- **色盘先行原则** — 段落规划需先绑定情绪场景（出击巡航/决战高潮/孤独深空/机甲觉醒/都市日常/战后残骸），再确定主色+辅色与光影方案，避免"剧情对了但情绪不对色"
- **禁用色域** — 高饱和荧光色（能量发射器高光除外）、与机甲科幻不兼容的传统东方古韵/写意传统/古典东方色域均排除。色相偏移容差 ±8°，饱和度偏移 ±10%，明度偏移 ±12%

## 二、光影方案体系

- **光影即叙事** — 7 套光影方案对应不同情绪段落，导演规划阶段应在段落层面确定光影基调方向，而非逐镜指定
- **赛璐璐光影为锚** — 所有光影方案必须保持赛璐璐平涂质感，阴影使用同色系加深，禁止黑色硬阴影，允许体积光/景深虚化/镜头光晕等动画技法
- **光源角度** — 正给镜头默认 38.5° 斜射柔光（赛璐璐平涂质感），侧给镜头可适当调整；能量发射器与推进尾焰需带镜头光晕与发光描边

| 光影方案 | 方案名 | 色调倾向 | 适用情绪 |
|---|---|---|---|
| A | 全息舱光 | 钛银 + 能量蓝 + 霓虹青辉光 | 出击巡航、驾驶舱内、人机对话、日常精密 |
| B | 推进尾焰 | 警示橙暖光 + 深空黑 | 出击起飞、加速冲刺、机甲升空 |
| C | 警报红闪 | 警报红 + 深空黑（~3000K 闪烁） | 战斗警报、舰船受损、危机时刻 |
| D | 星光冷调 | 钛银 + 深空黑 + 能量蓝轮廓光（~8000K） | 深空巡航、轨道、孤独对峙 |
| E | 能量觉醒 | 能量紫 + 能量蓝辉光 + 发光描边 | 机甲觉醒、新机启动、能量力场展开 |
| F | 战火焦土 | 警示橙 + 焦土棕 + 烟尘漫射 | 废墟都市、地面战场、战后萧瑟 |
| G | 屏幕高亮 | 等离子白 + 霓虹青（~6500K） | 舰桥指挥、全息战术台、AI 交互 |

- **冷暖光分配** — 暖色光（警示橙/警报红/焦土棕）适用于战斗/危机段落；深空巡航/孤独段落一律冷光（能量蓝/霓虹青/钛银轮廓光）。导演可根据叙事需要调整冷暖切换点
- **氛围方向映射** — 每场戏的氛围方向应能映射到上述光影方案（A-G）的某一方向，确保视觉一致性

## 三、质感方向

- **赛璐璐平涂为锚** — 机甲科幻二次元的核心：干净利落线条、赛璐璐平涂、能量光效渲染、色块平滑渐变、禁止色块断层/色彩溢出
- **干净线条 + 电影质感** — 这是画面质感的锚点。不是写实摄影，不是 3D CG，是二次元动画渲染加机甲科幻美学的融合
- **机械二次元化** — 所有道具机甲的材质必须以赛璐璐平涂呈现：钛银装甲的反光用平滑色块、能量节点的辉光用发光描边、推进尾焰用暖橙渐变。禁止"3D 感"和"写实摄影感"
- **皮肤质感** — 自然肤色、赛璐璐平涂、自然光泽、柔和质感、能量内透光（战斗态启用）。禁止哑光/死白/蜡感/油光/过曝/写实皮肤纹理
- **二次元不等于扁平** — 机甲科幻强调在赛璐璐平涂基础上通过光影层次、景深虚化、体积光、发光描边等手段增加空间感与电影感，而非扁平无纵深的卡通风格

## 四、机甲科幻场景空间元素

机甲科幻世界观特有的场景元素及其视觉叙事功能：

- **全息操控屏/战术台/舷窗/投影网格** — 天然的框架式构图道具，制造科技纵深与信息密度感，以赛璐璐线条呈现清晰数据流与网格
- **格纳库/维修机械臂/脚手架/巨型机甲停泊** — 体量对比的天然载体，机甲与机械臂的尺寸差 = 工业力量感，赛璐璐线条呈现清晰刻线与关节
- **推进尾焰/光束/警报灯/全息广告牌** — 机甲科幻世界的光源载体，尾焰 = 暖/动力（方案B）、警报灯 = 冷/危机（方案C）、全息屏 = 精密/指挥（方案G）、广告牌 = 赛博/市井（都市场景）
- **钛银装甲板/分件线/散热栅口/暴露线缆/残骸碎片** — 机械元素以硬核美学呈现，细节丰富、赛璐璐线条清晰，材质带战损/磨损/烧蚀感，禁止全新无瑕的"塑料感"
- **段落间用场景空镜过渡** — 本风格有丰富的场景资产（不同时段/星况/景别变体），段落衔接建议用太空空镜或舰内空镜做情绪缓冲，不要硬切
- **转折点用视觉而非台词** — 优先使用画面手段（警报闪烁、机甲觉醒辉光、景别跳切、能量溢光）而非依赖对白解释
- **前中后景层次** — 所有场景必须具备前/中/后景，杜绝扁平，舱外必须包含空气透视/空间纵深（远景星云/残骸虚化）

## 五、配乐合成器与环境音

机甲科幻世界观下的声音元素约束：

### 配乐选择（合成器 + 管弦）

- **合成器铺底（synth pad）** — 太空氛围、深空巡航、舰内日常的核心音色，与星光冷调/全息舱光高度适配
- **铜管主旋律（brass fanfare）** — 机甲出击、决战高潮、热血段落，嘹亮铜管适合英雄主题
- **女声吟唱 / 拉丁合唱** — 史诗觉醒、神秘异星、能量觉醒段落，空灵人声适合宏大意境
- **弦乐快弓（string ostinato）** — 紧张、急促、追逐段落的推动器，战斗场景的节奏引擎
- **电子节拍 / 工业打击** — 战斗、突击、机甲对决的节奏基础，不建议长时间独占
- 管弦 + 合成的混合编制可增加电影感但不宜喧宾夺主

### 配乐组合策略

| 情绪阶段 | 配乐组合 |
|---|---|
| 平稳/巡航/收尾 | 合成器铺底独奏 或 合成器 + 弦乐长音 |
| 深空/孤寂/辽远 | 合成器 pad + 空灵女声吟唱 |
| 紧张渐浓 | 弦乐快弓 + 电子节拍 |
| 出击/热血/英雄 | 铜管主旋律 + 弦乐 + 工业打击 |
| 觉醒/史诗/异星 | 拉丁合唱 + 铜管 + 合成器铺底 |
| 都市/日常/市井 | 轻电子节拍 + 合成器旋律 |
| 危机/警报/决战 | 工业打击 + 铜管齐鸣 + 弦乐急促 |

### 机甲科幻环境音

- **典型环境音层次** — 机械嗡鸣 / 推进器轰鸣 / 警报蜂鸣 / 能量充能嗡声 / 无线电杂音 / 全息屏嗡响 / 舱内空调低鸣 / 舷窗真空静谧 / 星体背景辐射 / 步行机甲金属踏地 / 火花迸溅
- **每场戏标注 1-2 个核心环境音**，帮助后续音效设计。环境音层次越丰富，机甲科幻场景越有沉浸感
