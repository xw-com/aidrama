# 机甲科幻风格说明

本风格专为"机甲科幻"题材打造，所有美术提示词、规范和生成内容均严格限定于：

- **机甲科幻二次元动画**：以巨型人形机甲、太空舰队、未来战场为核心背景的二次元动画风格，承袭高达、EVA、超时空要塞、机动警察一脉
- **硬核机械设计**：精细的装甲分件线、散热栅口、关节液压结构、能量发射器、推进器尾焰，机械细节考究可信
- **2D 赛璐璐渲染**：干净利落的线条、赛璐璐平涂硬阴影、网点高光、能量发光描边，纯二次元动画质感
- **深空战场美学**：宇宙星海、废墟都市、赛博都市、轨道空间站等未来战场空间，冷峻硬朗的氛围张力
- **能量光效张力**：光束、光剑、全息屏、警报闪烁等能量元素以发光描边与体积光呈现，画面极具科技冲击力
- **机甲科幻电影质感**：电影级构图、硬光对比、动态张力、机甲对决的重量感与速度感

## 适用范围

- 机甲科幻题材的 AI 美术生成（角色、场景、道具、机甲、分镜等）
- 需要硬核机械设计、能量光效、赛璐璐动画质感的视觉创作
- 机甲动画、太空歌剧、科幻游戏美术、概念设计、机设插画

## 严禁内容

- 传统东方古韵画风 / 写实摄影 / 3D 写实 CG 渲染
- 魔法玄幻 / 西方中世纪 / 蒸汽朋克混入
- 3D 渲染术语作为风格声明（如 3D render、CGI、Unreal Engine、Unity 等）
- 粗劣线条 / 模糊画质 / 低精度建模 / 塑料感无瑕材质
- 色彩混乱 / 风格不统一 / 审美崩坏

## 风格体验

在本风格下，您将体验到：

- 角色造型二次元比例，驾驶服 / 紧身飞行服精致，线条干净利落
- 机甲作为"角色"独立成图，装甲刻线、关节、推进器细节考究，能量发光描边
- 场景充满科技纵深，舰桥全息、格纳库机械臂、废墟残骸层次丰富
- 道具器物硬核可信，金属钛银、能量蓝光辉、光束发光描边，色彩对比鲜明
- 分镜与渲染均强调电影质感、机甲重量感、能量光效张力、赛璐璐动画技法
