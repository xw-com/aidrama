本手册的核心创作理念为 **"大唐气象，真人骨血"**：

1. **真实感的审美回归**：在AI生成影像日趋泛滥的当下，真人写实质感以其不可替代的真实力量，成为最具情感穿透力的视觉语言。真人肌肤的纹理、罗纱帔帛的飘举、灯烛下摇曳的光影、唐式木柱上的漆皮剥落——这些真实细节构成了一种生命质感与岁月质感，是3D渲染无法复刻的审美深度。

4. **写实克制即品格**：本风格为"真人写实唐代"，不是仙侠法术，不是动漫玄幻。一切光影、材质、人物以写实克制为底色——大唐的恢宏落在木构斗拱与丰腴端丽的体态上，不落在魔法光效上；仕女的浓丽落在花钿面靥与石榴红罗裙上，不落在玄幻粒子上。

4. **仙侠法术与玄幻特效**：法术光效/真气流转/御剑飞行/玄幻粒子/灵力光环/水墨法术特效等一切玄幻CG特效（本风格为写实克制唐代，大唐的"奇"靠气象不靠特效）
5. **非中国唐代语境**：明显非唐代特征的建筑、服饰、人物造型（如和服、韩服、欧式宫廷、哥特等）
6. **技术质量缺陷**：低分辨率/模糊/噪点/变形/畸形肢体/五官扭曲/比例失调/抠图感/塑料感/过度磨皮/假面感

## 七、使用说明

### 提示词使用原则

1. **前缀先行**：所有生成内容必须首先加载"前缀提示词"中的全局风格锚定段，锁定真人唐代写实质感基线
2. **专项叠加**：在全局前缀基础上，按需叠加角色/场景/道具/分镜专项提示词
3. **负面必加**：每次生成必须附带"负面提示词"，尤其须明确规避**清代元素与跨朝代混搭**
4. **迭代优化**：建议首轮生成后根据效果对专项提示词做微调，而非修改全局前缀
5. **平台适配**：本手册提示词优先适配Doubao-Seedream（生图）与Doubao-Seedance（视频生成），部分提示词可能需根据平台特性微调

### 历史准确性自检

每次生成前，创作者须自检以下唐代锚点是否成立：
- 女性是否为**丰腴端丽**体态（盛唐审美），而非清瘦？
- 女性服饰是否为**齐胸襦裙 + 半臂 + 帔帛**，而非旗装/马面裙/立领袄裙？
- 男性是否戴**幞头**穿**圆领袍**，而非剃发垂辫/马褂？
- 建筑是否为**唐式木构**（斗拱硕大/出檐深远/鸱吻/朱柱/直棂窗），而非明清黄琉璃格局？
- 器物是否为唐代典型（唐三彩/海兽葡萄镜/鎏金银器），而非明清器物？
