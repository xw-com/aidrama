## 一、分镜表定位

分镜表是导演将剧本转化为镜头语言的核心工具。本约束面向 Seedance 2.0 视频生成，所有光影、动作、空间描述均采用模型可执行的具象语言。不做抽象的情感概括，不写模型看不懂的渲染参数。**严格锚定唐代服制、建筑、器物，杜绝跨朝代混搭。**

## 三、光影与氛围——Seedance 2.0 物理光源描述

### 3.1 同场戏光影统一

一场戏内不应出现两种以上核心光影方案，除非有叙事驱动的光源变化（如有人吹灭灯笼、日落后天光暗于烛火、从殿内走到庭院）。光源变化必须在分镜表中标注触发事件。

### 3.2 光源语句法（每个镜头必须包含）
[光源] 主光：{光源类型——直棂窗天光/灯笼烛火/月光/绢纱灯笼}，{方向}，{色温值K}，{软硬}
[光源] 辅光/环境光：{光源类型}，{方向}，{色温值K}
[光比] 约1:{X}
### 3.3 情绪 → 光源矩阵

| 情绪 | 光源配方（Seedance 2.0 可直接填入） | 视觉关键词 |
|---|---|---|
| 朝堂恢宏 | 殿内直棂窗/高侧窗天光主光（4500-5500K）从斗拱方向斜下，金箔赭黄反光辅亮。光比约1:3 | 金红交织、肃穆、万国来朝 |
| 曲江闲适 | 庭院自然天光漫射（5500-6500K），花木漏影，朱柱暖反射。光比约1:2 | 通透、低反差、清新 |
| 夜宴华灯 | 灯笼烛火暖橙主光（2200-2800K），绢纱灯笼透光，暗部织锦金线反光。光比约1:4 | 暖调包裹、烛影华贵 |

### 3.4 冷暖色调与叙事阶段

- **冷光主导**（5000K+）：朝堂清明、孤寂凄清、月夜、对峙压抑
- **暖光主导**（2200-3500K）：夜宴温情、灯烛私密、朱柱夕照、大典册封的金红
- **冷暖共存**：过渡时刻（蓝调时刻+初亮灯笼）、佛寺（天光+烛火）、对峙（烛火暖+直棂冷）
- **光源变化 = 命运信号**：殿窗外天光从日间冷白渐变至黄昏暖金=时间流逝；从殿内烛火暖走到月下庭院=命运的坠落

### 3.5 Seedance 2.0 光影适配要点

- 色温数字帮助模型校准白平衡倾向：`色温约2500K灯笼暖橙` 优于 `暖光`
- 光比数字帮助模型建立明暗意识：`光比约1:4` 优于 `柔和的阴影`
- 光源必须有明确来源：`从画面左侧低位灯笼斜入` 优于 `侧光`
- 环境光的反射路径描述：`青砖地墁反射烛火暖光` 优于 `地面有暖色反光`

## 四、环境动态——让画面呼吸

### 4.1 动态密度

每 3-4 个镜头至少安排一个有环境动态的镜头。静态朝堂戏也不例外——至少有一个镜头里烛火在摇曳、帷幔被穿堂风轻拂、远处更鼓传来。

### 4.2 唐代环境动态元素（Seedance 2.0 可执行）

| 场景 | 可描述的环境动态 |
|---|---|
| 殿内（居室/书斋） | 帷幔被穿堂风轻鼓约10cm后回落（约2秒周期）、烛火明灭摇曳、香炉青烟袅袅升起、窗外花木影子在地砖上随天光微移、铜漏滴水 |
| 庭院（唐式庭院/曲江） | 花木叶片簌簌晃动、远处坊人执物缓步走过、牡丹花瓣偶有飘落、檐马叮当作响、曲江水波微澜 |
| 廊庑 | 直棂光斑随天光角度缓慢移动、远处灯笼随穿堂风微晃、脚步声在廊庑回响由远及近、廊柱明暗切割随人物穿行变化 |
| 朝堂 | 香炉香烟袅袅升腾、赭黄帷幔极轻微摆动、远处内侍肃立不动、金箔在烛火/天光下明灭反光 |
| 坊市 | 驼铃叮当、胡商叫卖声、骆驼缓步、幌子幔帐随风摆动、灯笼暖光透过飘尘 |
| 深夜长安 | 灯笼烛火摇曳、更鼓由远及近传来声、月光下花木影子在地砖缓慢移动 |

### 4.3 Seedance 2.0 环境动态描述规范

- 动态必须有具体轨迹和速度：`烛火每秒约2-3次微幅明灭摇曳` 优于 `烛火在动`
- 光源动态与空间光源逻辑一致：`云朵遮住日头时，直棂光斑缩小约40%，持续约3秒后恢复`
- 禁止无来源的动态：没有风=帷幔不动。门窗紧闭=没有穿堂风

## 五、人物动作节奏——Seedance 2.0 物理逻辑具象化

### 5.1 动作描述铁律

所有人物动作必须描述：**轨迹 + 速度/时长 + 身体部位协调 + 服饰连带动态 + 对周围物体的影响**。

### 5.2 唐代日常动作具象库

| 动作 | Seedance 2.0 可执行描述 |
|---|---|
| 敛衽礼（女） | 双手交叠于腹前（右手在外），身体缓慢前倾约30度，头微低，帔帛随前倾自然前垂约15cm，全程约2秒，起身时衣袖自然垂落带回约10cm，步摇花钗随之晃动约1秒渐止 |
| 跪拜（大礼） | 双膝跪于青砖地墁，双手前撑扶地，头低垂至手背附近，圆领袍/襦裙下摆铺开约40cm，全程约3秒，起身时膝盖处衣袍有明显褶痕 |
| 叉手礼（男女通用，唐典型） | 左手紧握右手拇指，左手在外，双手拱于胸前，微躬身约15度，头微颔，全程约1.5秒——唐代最典型的日常礼 |
| 转身回望 | 向右缓慢旋转约90度，高髻随之微动，步摇花钗随之垂坠晃动约2秒渐止，帔帛随转身飘举约20cm，视线从窗外移至殿门方向 |
| 奉茶 | 双手捧银杯托盘，从胸前高度平稳递出约30cm，银杯微晃，蒸汽从杯口缓缓升起，全程约3秒 |
| 曲江漫步 | 在汉白玉小径缓步前行，步速约每秒一步，翘头履落地有轻微叩击声，牡丹花瓣偶有飘落擦过帔帛 |
| 朱批文书 | 右手持朱笔，笔尖蘸朱砂，在纸本文书上落下笔锋，朱砂墨迹微洇，左手轻按文书边缘，全程约2秒一画 |
| 拨弄烛火 | 右手持铜挑针，挑拨烛芯约0.5cm，烛火明灭一次后复亮，全程约1.5秒，步摇反光一闪 |
| 持团扇掩面 | 右手持唐绢团扇骨柄，团扇从腰侧抬起至面颊右侧约15cm处，扇面微倾约20度遮掩下半面，丝穗垂坠晃动约1秒 |
| 抚琵琶 | 怀抱梨形曲项琵琶横抱，右手持拨子拨弦后离弦约2cm，左手按相品位微移，弦振可见，全程约2秒一音 |
| 接告身文书 | 双膝跪地，双手高举过头接纸本告身，身体前倾约20度，头微抬注视文书，全程约3秒 |
| 打马球 | 骑马持杖，马球杖缠绳端头挥击马球约向前30度，身体随挥杖侧倾约15度，马匹缓步，全程约2秒 |

### 5.3 动作节奏与叙事场景

- **文戏/朝堂礼法**：动作沉稳克制，每个微动作标注时长和轨迹。节奏舒缓——不是慢，是"合乎礼法的不急"
- **情绪波动**：动作幅度和速度略微变化。人物可能在对话中不自觉地加快步摇轻叩的频率、呼吸带动肩膀起伏更明显
- **冲突场景**：动作干脆利落，但仍有物理轨迹。推搡/摔物须具体到"右手推在对方左肩前方，对方重心向后偏移约20cm，高髻步摇晃动剧烈"
- 禁止：无叙事理由的快速动作堆砌、无物理逻辑的瞬移、"施了一礼"等含糊描述

### 5.4 服饰动态

真人唐朝写实的服饰动态是画面的天然资产——不是"布料模拟参数"，而是"齐胸襦裙下摆随敛衽前倾自然垂坠""圆领袍衣袖起身时带回约10cm""步摇花钗随头部微动垂坠晃动约2秒渐止""帔帛随转身飘举约20cm""帷幔被穿堂风鼓起约15cm"。在分镜表画面描述中标注服饰与首饰的动态细节。

## 六、空间逻辑具象化——Seedance 2.0 空间坐标系统

### 6.1 每镜头必须声明的空间信息
水平位置：画面左/中/右，或画面左侧三分之一处
纵深位置：距镜头{数值}米，前景/中景/背景
人物与场景的关系：距{固定物——御榻/屏风/直棂窗/宫门/廊柱}{数值}米
（若双人以上）人物A与B的相对距离和朝向
### 6.2 站位衔接示例
【片段A尾部】
A仕女身着石榴红齐胸襦裙立于唐式居室榻前，距榻约0.5米，面朝帷幔，位于画面中央偏右，距镜头约4米。
室内灯笼烛火从画面左侧低位照入（约2500K暖橙）。
A右手轻抚帷幔边沿，步摇距幔面约2cm。

【片段B开头】
A的右手刚从帷幔收回约10cm，步摇仍在原位置附近。A仍站在榻前（位置未变）。
殿窗外天色已从黄昏转为蓝调时刻——天空深蓝紫透直棂窗，室内灯笼已为主光源（约2500K暖橙）。
绢纱灯笼已亮（画面右后侧），透柔光照在A的右后侧肩背与帔帛。

### 6.3 空间变化必须具象

| 抽象（禁止） | Seedance 2.0 具象 |
|---|---|
| 她走近了 | A从画面背景（距镜头约5米、殿门位置）向镜头方向缓步走来4步（约3米），翘头履落地有轻微叩击声，停在距镜头约2米处——耗时约4秒 |
| 君臣对峙 | 帝位于御榻前居中（距镜头约6米），臣跪于丹陛下距帝位约5米，两人面朝彼此，臣双手交叠于腹前 |
| 从居室到廊庑 | A从居室（距镜头约3米）走向殿门，推开朱红木门（门向内旋转约80度，门钉反光一闪），跨过门槛进入廊庑——廊庑直棂窗天光瞬间取代居室烛火暖光 |

## 七、运镜规范——Seedance 2.0 摄影机运动

### 7.1 允许的运镜

| 运镜 | Seedance 2.0 描述 | 适用场景 |
|---|---|---|
| 固定 | 摄影机固定不动，画面静止 | 朝堂礼法、典礼、对话、空殿留白、情绪凝视 |
| 手持微晃 | 摄影机有轻微不规则晃动（幅度约±2cm），模拟手持拍摄的呼吸感 | 暗涌、跟踪密会、情绪波动、主观视角 |
| 稳定器流动 | 摄影机平滑匀速移动，无晃动 | 廊庑纵深、人物登场、册封大典、空间展示 |
| 缓推 | 摄影机向主体缓慢推进，推进速率约每秒0.3米 | 情绪升温、真相逼近、注意力聚焦 |
| 缓拉 | 摄影机向后缓慢拉远，拉远速率约每秒0.3米 | 离别、收束、揭示全貌 |
| 跟拍 | 摄影机与人物保持约2米距离同步移动 | 廊庑穿行、坊市行走跟随 |
| 摇镜 | 摄影机原地水平/垂直旋转 | 视线转移、殿宇纵深关系交代 |

### 7.2 禁用运镜

- 无叙事目的的快速甩镜、急推急拉（推拉速率超过每秒1米）
- 超过3秒的剧烈手持晃动（除非主观受击/眩晕/宫变叙事）
- 无逻辑花式转场——划屏、旋转、百叶窗、翻页等特效转场
- 摄影机无理由的360度旋转

### 7.3 真人唐朝写实运镜哲学

- 固定机位是朝堂与典礼的第一选择——让观众看到唐人在礼法空间里自然存在
- 手持微晃在冲突段落使用——但晃动幅度不超过电影纪实风格的常规范围
- 稳定器流动用于廊庑纵深与人物登场——大唐的仪式诗
- 运动镜头的起幅和落幅必须平稳，运动过程匀速——禁止突然加速或急停

## 八、转场规范

### 8.1 允许的转场方式

| 转场 | 视觉执行 | 叙事功能 |
|---|---|---|
| 硬切 | 直接切换 | 同场戏内镜头切换（默认） |
| 光影匹配转场 | 两个场景在相近光影逻辑下切换 | 时间流逝、平行叙事。例：A处灯笼烛火 → B处灯笼烛火 |
| 空间匹配转场 | 两个空间在构图或元素上呼应 | 场景跳转。例：含元殿御榻的赭黄 → 居室赭黄帷幔 |
| 空镜过渡 | 插入场景空镜（3-5秒） | 情绪缓冲、章节划分、时间流逝暗示（如黄昏坊门→月夜庭院） |
| 焦点转场 | 前镜焦点从主体移至背景，后镜从模糊背景中逐渐聚焦主体 | 空间切换、注意力的转移 |

### 8.2 禁止的转场

- 纯视觉特效转场（翻页、划屏、百叶窗、马赛克、水墨化开）
- 无叙事逻辑的旋转/缩放转场
- 同一场戏内使用超过两种转场方式

## 九、音画同步规划（Seedance 2.0 专属）

### 9.1 环境音标注规范

每场戏标注 1-2 个核心环境音，写在分镜表的环境音列：

| 场景 | 建议环境音 |

## 十一、空镜使用规范

### 11.1 空镜不是"没东西拍"

空镜是情绪容器。每个空镜必须有叙事目的和具体的视觉内容：

| 空镜类型 | 叙事目的 | 示例 |
|---|---|---|
| 场景建立 | 新空间首次出现——让观众看清楚这是什么唐代场所 | 含元殿大全景：朱柱列阵、硕大斗拱、鸱吻、御榻、丹陛、帷幔 |
| 情绪缓冲 | 高情绪段落后的喘息 | 直棂窗外月光沿帷幔滑下，速度约每秒2cm |
| 时间流逝 | 暗示时间过去了 | 同一直棂窗外的天光从午后湛蓝渐变至黄昏暖金再至月夜冷蓝 |
| 隐喻留白 | 以物代情 | 妆台上半残的烛台，烛泪凝结，烛火明灭；或铜镜海兽葡萄纹的特写 |
| 转场衔接 | 前后两个空间的自然过渡 | 廊庑直棂窗——前一场居室，下一场庭院 |

### 11.2 空镜 Seedance 2.0 描述规范

空镜也必须遵循光源+质感+动态的描述铁律：唐式居室内灯笼烛火从画面左侧低位斜入（约2500K暖橙），
在空荡荡的妆台铜镜（海兽葡萄镜）上镀一层暖金，铜镜映出空榻帷幔，
烛火每秒约2-3次微幅明灭，帷幔被穿堂风鼓起约10cm后回落，
妆台木构有包浆，漆奁朱漆边角磨损。
