## 一、道具设计原则

> 真人唐朝写实的道具不是"被建模的物件"，而是"被唐人用过、被岁月盘过的器物"——它在仕女鬓边插过、在御案上供过、在朱批文书上压过。摄影机拍下的是它的此刻。**严格锚定唐代器物形制，杜绝明清及跨朝代器物混入。**

1. **器物即气象与命运** — 每一件道具都是一个微型的盛唐叙事容器。未干的朱砂暗示刚颁告身、银杯上的细微划痕暗示昨夜豪饮、香毘里残留的香灰暗示已被冷落多日
2. **使用痕迹优先于完美品相** — 真人唐朝写实的道具必须有"被用过、被岁月盘过"的证据。全新出厂、样板级别的道具一律不出现
3. **中国唐代真实器物** — 道具必须是中国唐代真实存在的器物：唐三彩、鎏金银壶、海兽葡萄镜、卷草纹/宝相花纹器物、鎏金银香囊（香毘）、步摇花钗头面、玉带、琵琶、胡瓶——拒绝无国别架空物品，拒绝明清器物
4. **材质即真实** — 不是PBR参数渲染出的材质，而是摄影机拍下的真实材质行为：唐罗织锦金线的凸起反光、鎏金银器的氧化哑光与暖金反光、唐三彩釉的铅光、铜镜的铅锡光与铜绿、玉带銙的温润油性
5. **单视图静物摄影** — 道具以单张静物产品摄影方式独立呈现，非多角度建模展示，非2×2四宫格

## 三、单视图静物摄影规范

> 真人唐朝写实道具仅需单张静物产品摄影，非多角度建模展示。以下为单视图摄影的完整规范。

### 画面构成

| 项目 | 摄影要求 |
|---|---|
| 道具呈现 | 道具居中或偏三分线位置独立陈列，完整入画，无裁切 |
| 背景 | 素灰无缝背景纸 #B0B0B0（哑光），或深木桌面/米白绢纱台面，根据道具属性选择。无多余物体、无装饰、无文字（道具本身的题字除外，如文书/告身） |
| 光线 | 自然柔光或单灯柔光。窗光/直棂窗光45°侧入（明亮柔和带自然阴影）、或柔光箱顶+侧补（产品摄影级均匀光线）。光影柔和、方向明确、无硬阴影 |
| 景深 | 浅景深（f/2.8-f/5.6），道具主体清晰锐利，前后微虚化突出主体 |
| 投影 | 道具底部与承载面之间的自然接触阴影——真实的而非抠图或悬浮。阴影柔软、方向与主光源一致 |
| 画面比例 | 建议 1:1 正方形或 4:3，适配单件道具展示 |

### 道具状态准则

| 维度 | 要求 |
|---|---|
| 使用痕迹 | 必须有"被用过、被岁月盘过"的视觉证据——非全新未启用、非样板品相 |
| 唐代辨识度 | 唐代器物形制/中文（如文书/告身）/唐代工艺（唐三彩/鎏金/海兽葡萄镜）——拒绝无国别架空物品，拒绝明清器物 |
| 材质真实感 | 非渲染质感——是摄影机拍下的真实材料行为（光的反射、漫射、透射） |
| 礼制等级感 | 礼制重器须有合乎身份的工艺等级（帝王赭黄圆领袍、玉带按品级、金累丝头面） |
| 尺度感 | 通过材质纹理密度、工艺细节暗示实物尺寸，无需参照物 |
