# 真人唐朝写实场景图像生成 · 约束手册

---

## 一、场景美学原则

> 真人唐朝写实的场景不是"被建模的宫殿"，而是"被摄影机选中的真实唐代空间"。没有渲染引擎、没有贴图、没有体积光参数——只有实际存在的天光与灯烛、真实的朱柱灰瓦与金箔木构、以及唐代建筑深远的出檐与硕大的斗拱。**严格锚定唐代建筑形制，区别于后世明清的黄琉璃朱墙格局。**

1. **空间即气象** — 一座空无一人的含元殿不是"空的"，是退朝之后。丹陛上的烛泪未干、屏风帷幔微动、奏案文书未合——空间自己会讲大唐的故事
2. **真实的光，不是渲染的光** — 场景的光只有一个来源：实际的日光（通过直棂窗、宫门、廊庑）、实际的灯火（灯笼、烛台、廊灯）。光的色温和方向必须在物理上说得通
3. **被岁月使用过的唐代建筑** — 真实的唐式木构不崭新。朱柱有漆皮剥落、斗拱有积尘、鸱吻有苔痕、土朱墙有雨痕、灰瓦有苔藓、莲柱础有包浆——一个完全没有岁月痕迹的唐式建筑是横店样板布景，不是真实唐代
4. **中国唐代的真实场所** — 场景必须有明确的唐代辨识度（朱红柱、灰瓦/青瓦、硕大斗拱、深远出檐、鸱吻、直棂窗、莲柱础、土朱墙、屏风帷幔）。**唐代以灰瓦/青瓦为主，非后世明清的黄琉璃瓦群**；建筑为木构，斗拱硕大、出檐深远、屋顶坡度缓和——这不是"generic palace"，这是"中国唐代的一个具体角落"
5. **单视图全景全貌** — 一张照片装下整座殿/院/坊的完整信息。广角或标准焦段，全景深，正面展示空间的全貌与纵深——不是四视图分割，不是多角度拼贴

## 五、单视图全景摄影规范

> 真人唐朝写实场景仅需**单张**全景摄影——一张照片装下整座殿/院/坊的完整信息。不是2×2四视图，不是多角度拼接。

### 画面构成

| 项目 | 摄影要求 |
|---|---|
| 空间呈现 | 单张照片完整呈现场景的空间全貌。使用24-28mm广角或35mm，全场地的纵深、宽度、高度在一张画面中全部可见 |
| 构图 | 全景深大景别——前景（朱柱/廊庑/帷幔/灯笼/屏风/花木/直棂窗）形成天然画框→中景是殿宇/院落主体→后景向空间纵深或后殿/天空延伸 |
| 景深 | 全景深 f/8-f/11，从前到后全部清晰。这不是人像摄影——场景的每一个角落都应该能被看见 |
| 人物 | **严禁出现任何人物、人影、人体轮廓。** 场景是空的——但这种"空"有叙事：退朝之后/即将大典/人去殿空/庭院的静止瞬间 |
| 比例 | 建议 16:9 或 3:2 宽幅——匹配全景空间展示的横向视觉习惯 |
| 色彩 | 由实际光源的色温驱动，不套滤镜。色彩科学参考ARRI Alexa/Sony Venice电影色调 |

### 空的场景如何叙事

| "空"的类型 | 画面线索 | 叙事暗示 |
|---|---|---|
| 退朝之后 | 御榻帷幔微皱、丹陛上烛泪未干、奏案文书未合、地墁有靴印 | 刚才朝堂有人，现在散了 |
| 即将大典 | 仪仗陈设齐整、灯笼全亮、香炉香烟未起、帷幔拉平 | 大典马上开始，此刻是开场前的肃静 |
| 人去殿空 | 搬迁后的空殿、墙上挂过画屏的钉痕、地面积尘的轮廓、断了的香火 | 曾经有人住过，现在被废/迁/抄 |
| 庭院的静止 | 屏风帷幔半垂、铜镜妆台映空榻、茶盏余温、直棂窗光打在地砖 | 起居的常态，只是此刻无人入镜 |
| 深夜的长安 | 空荡的廊庑只有灯笼亮着、内室窗纸透出一团暖光、月下的空庭院 | 宵禁之后，长安睡着了，但建筑还醒着 |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须是**单张**全景摄影——单视图、非2×2四视图、非多角度、非turnaround |
| R2 | 必须使用广角镜头（24-28mm）或标准焦段（35mm），全景深 f/8-f/11，完整空间纵深 |
| R3 | 光源必须可追溯——自然光的方向与时刻匹配、灯烛灯笼的位置和色温合理 |
| R4 | 场景必须有前/中/后景空间层次，前景画框→中景主体→后景延伸 |
| R5 | 必须有中国唐代辨识度——朱红柱/灰瓦青瓦/硕大斗拱/深远出檐/鸱吻/直棂窗/莲柱础/土朱墙/屏风帷幔 |
| R6 | **建筑必须为唐式木构**——硕大斗拱层叠、深远出檐、鸱吻、朱柱、缓坡屋顶、直棂窗、莲柱础、灰瓦青瓦；严禁明清黄琉璃瓦群与红墙金顶格局 |
| R7 | 必须有岁月痕迹——朱柱漆皮剥落/斗拱积尘/土朱墙雨痕/灰瓦苔痕/金箔氧化/木构包浆、非样板殿非全新非效果图 |
| R8 | **严禁出现任何人物、人影、人体轮廓、剪影** |
| R9 | 必须声明"真人实拍摄影 + 非3D渲染非CG"核心锚定 |

|---|---|
