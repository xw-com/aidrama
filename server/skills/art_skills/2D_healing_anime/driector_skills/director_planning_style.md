# 治愈系动漫约束 · 治愈系动漫 · 技法参考

---

## 一、色调体系与画面基调

- **色调基底** — 全片以奶白（C1）、嫩叶绿（C3）、杏仁暖（C5）为基底色，雾霭蓝（C2）作远景与空气层，整体色温中性微暖（5200-5600K），饱和度低（35-55%），呈现水彩般通透松弛的治愈日常感
- **冷暖叙事呼吸** — 雾霭蓝（C2）与青灰蓝（C9）仅用于雨天、夜晚与远景雾霭，作为情绪留白层；暖色（杏仁暖 C5、暮云粉 C7）留给食物、黄昏与陪伴段落。冷暖交替形成"呼吸感"，而非冲突对比
- **色盘先行原则** — 段落规划需先绑定情绪场景（日常呼吸/午后小憩/雨天湿润/黄昏归途等），再确定主色+辅色与光影方案，避免"剧情对了但情绪不对色"
- **禁用色域** — 高饱和荧光色、霓虹色、厚重油画暗调、写实CG色彩体系均与本风格不兼容

---

## 二、光影方案体系

- **光影即呼吸** — 6 套光影方案对应不同情绪段落，导演规划阶段应在段落层面确定光影基调方向，而非逐镜指定
- **光源角度** — 默认高位漫射或 30-45°柔侧光，模拟自然柔光效果

| 情绪段落 | 光影方向 | 色调倾向 | 适用阶段 |
|---|---|---|---|
| 日常呼吸感 | A·空气感漫射 | 奶白底 + 均匀柔光 | 全片 |
| 清晨苏醒 | B·薄雾斜射晨光 | 浅藤黄 + 雾霭蓝远山 | 开场/晨间段 |
| 烘焙/室内温暖 | C·暖灯窗光 | 杏仁暖主导 + 薄荷奶绿点缀 | 面包店/厨房段 |
| 雨天静谧 | D·雨雾漫射冷光 | 青灰蓝主调 + 奶白提亮 | 雨天/独处段 |
| 黄昏归途 | E·暖金渐层逆光 | 暮云粉 + 杏仁暖过渡 | 黄昏段 |
| 夜晚安眠 | F·月色冷蓝+暖灯一点 | 雾霭蓝主调 + 杏仁暖局部 | 夜晚段 |

- **冷暖光分配** — 暖色（杏仁暖/暮云粉）贯穿全片可用；冷色（雾霭蓝/青灰蓝）仅在雨天、夜晚与远景雾霭使用，作留白层
- **氛围方向映射** — 每场戏的氛围方向应能映射到上述光影方案（A-F）的某一方向，确保视觉一致性

## 三、质感方向

- **水彩通透感** — 治愈系动画的核心：色彩像水彩一样轻盈叠透，色块边缘柔和呼吸
- **轻盈干净线稿 + 低饱和粉彩** — 这是画面质感的锚点。不是厚重油画，不是写实CG渲染
- **柔光不等于模糊** — 空气感柔光通过光斑、雾化、微尘实现层次，细节依然清晰可辨
- **慢节奏不等于静态** — 通过环境动态（蒸汽、叶隙光斑、猫尾轻摆）让画面持续呼吸，而非依赖运镜炫技

## 四、治愈场景空间元素

治愈系动漫特有的场景元素及其视觉叙事功能：

- **橱窗/窗台/纱帘** — 天然的柔光过滤器，制造光斑与朦胧层次，是"空气感"的视觉来源
- **面包店/老宅/花房** — 治愈感的天然载体，景即情：出炉蒸汽 = 温暖、花房绿意 = 生机、老宅木纹 = 岁月安稳
- **猫咪/绿植/餐桌** — 陪伴与生活的三角：猫 = 无言陪伴、绿植 = 时间流逝、餐桌 = 温暖具象化
- **单线电车/铁轨/坡道** — 小镇节奏的视觉载体：铁轨延伸 = 远方、坡道缓行 = 慢节奏生活
- **段落间用场景空镜过渡** — 天空延时、植物特写、猫咪打盹等空镜做情绪缓冲，不要硬切
- **转折点用视觉而非台词** — 优先使用画面手段（雨过放晴、季节首帧、光斑重新洒落）而非对白解释

## 五、治愈系乐器与环境音

治愈系动漫世界观下的声音元素约束：

### 乐器选择

- **木吉他（指弹）** — 日常/散步/劳作段落的核心乐器，最能表现治愈系的松弛质感
- **钢琴** — 回忆/感动/夜晚段落的情感支柱，音色干净克制
- **口琴/口风琴** — 乡野/旅途/清晨段落，气息感强，自带小镇味道
- **拇指琴/八音盒** — 小确幸/童趣/入眠段落，音色轻盈通透

### 乐器组合策略

| 情绪阶段 | 乐器组合 |
|---|---|
| 平稳/开场/收尾 | 口琴独奏 或 拇指琴独奏 |
| 日常呼吸感 | 木吉他指弹 + 钢琴轻音 |
| 温暖陪伴/感动 | 钢琴 + 口琴 |
| 雨天/夜晚安眠 | 八音盒 + 环境垫音 |

### 治愈系环境音

- **典型环境音层次** — 面包出炉的气鸣与烤箱滴答 / 风穿过树叶与晾衣绳 / 猫咪呼噜与轻跳窗台 / 虫鸣蛙叫与远处溪流 / 单线电车驶过铁轨 / 水壶沸腾与陶瓷轻碰 / 市集远处人声 / 雨滴檐廊
- **每场戏标注 1-2 个核心环境音**，帮助后续音效设计。环境音层次越丰富，治愈场景越有沉浸感
- **留白比配乐更重要** — 关键情感瞬间（对视、发呆、入睡、雨停）优先考虑去掉配乐，只留环境音（风声、虫鸣、炉火声），让观众自己感受情绪
- **避免满配** — 全片配乐覆盖率建议不超过 40%。留白段落的"无声"与配乐段落形成呼吸感，突出治愈节奏
