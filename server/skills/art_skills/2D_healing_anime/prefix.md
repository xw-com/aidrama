## 二、全局色彩盘（风格基线，不是硬锁）

> 目标：统一审美而非限制创作。除「硬约束色」外，其余颜色默认优先使用，可在合理范围内偏移。

### 色彩使用层级

| 层级 | 约束强度 | 说明 |
|---|---|---|
| L1 硬约束 | 高 | 仅锁定角色识别核心：肤色、发色、主服底色的审美方向 |
| L2 软约束 | 中 | 场景色、器物色、点缀色优先参考色盘，可按镜头与季节微调 |
| L3 例外机制 | 低 | 雨天/黄昏/回忆等特殊场景可临时突破局部色彩，但需保留整体通透柔和逻辑 |

### 硬约束色（默认锁定）

| 色项 | 对应色 | 规则 |
|---|---|---|
| 肤色基准 | C1 奶白 | 默认优先，允许小幅明度微调，保持通透粉彩感 |
| 发色/瞳色基准 | C4 亚麻棕 | 默认优先，允许亚麻/栗色/暖灰轻微偏移 |

### 软约束色（推荐优先）

> C2/C3/C5/C6/C7/C8/C9/C10 为推荐色域，用于服装、器物、背景、植被、暖光等。可根据季节与镜头氛围做同色相邻近调整。

### 情绪色盘（导演对齐版）

| 情绪场景 | 主色 | 辅色 | 光效与对比建议 | 画面关键词 |
|---|---|---|---|---|
| 日常呼吸感 | C1 奶白 | C3 嫩叶绿 + C6 薄荷奶绿 | 均匀柔光，低对比 | 平静、松弛、洁净 |
| 清晨苏醒 | C8 浅藤黄 | C1 奶白 + C2 雾霭蓝 | 斜射晨光，薄雾柔化 | 清新、微凉、希望 |
| 午后小憩 | C5 杏仁暖 | C1 奶白 + C10 淡暖褐 | 光斑洒落，暖调弥漫 | 慵懒、安全、困意 |
| 雨天湿润 | C9 青灰蓝 | C2 雾霭蓝 + C1 奶白 | 漫射冷光，低饱和低对比 | 静谧、湿润、独处 |
| 陪伴温暖 | C5 杏仁暖 | C7 暮云粉 + C3 嫩叶绿 | 近景暖光，轻轮廓光 | 猫咪、烘焙、相视 |
| 黄昏归途 | C7 暮云粉 | C5 杏仁暖 + C9 青灰蓝 | 逆光渐层，天色渐暖渐冷 | 归家、满足、微怅 |
| 季节流转 | C3 嫩叶绿 | C7 暮云粉 + C8 浅藤黄 | 季节主色渐变，通透叠色 | 新绿、樱色、麦浪 |
| 夜晚安眠 | C2 雾霭蓝 | C9 青灰蓝 + C5 杏仁暖局部 | 冷调为主，暖灯一点 | 安眠、月色、守护 |

### 情绪色盘使用规则

| 编号 | 规则 |
|---|---|
| E1 | 每条提示词至少指定 1 个「情绪场景」并绑定主色+辅色组合 |
| E2 | 单镜头主色不超过 2 个，避免颜色叙事失焦 |
| E3 | 情绪切换时优先调整光比与空气感（雾化/光斑），再调整饱和度 |
| E4 | 治愈向默认遵循「亮底 + 柔冷点缀」：奶白与暖色铺底，雾蓝仅用于远景与阴影 |
| E5 | 若与剧情冲突，以情绪色盘优先于通用推荐色，但不得突破严禁项 |

### 色温约束

| 参数 | 值 | 说明 |
|---|---|---|
| 整体色温 | 中性微暖 5200-5600K（推荐） | 明亮通透的日常主基调 |
| 肤色色温 | 微暖 5200-5600K（推荐） | 奶白通透且有生命感 |
| 对比度 | 低（建议保持） | 柔光弥散，明暗过渡平缓 |
| 饱和度 | 低 35-55%（建议区间） | 低饱和粉彩高级色调 |

### 容差与例外

| 项目 | 建议容差 |
|---|---|
| 色相偏移 | ±8° |
| 饱和度偏移 | ±10% |
| 明度偏移 | ±12% |

> 例外场景：黄昏、烘焙暖光、回忆镜头可使用更暖的局部色块；但禁止高饱和荧光色与厚重油画质感入镜。

## 三、全局约束规则

### 必守规则（所有技能继承）

| 编号 | 规则 |
|---|---|
| R1 | 必须包含「治愈系动漫风格」风格锚定词 |
| R2 | 必须声明「空气感柔光 + 低饱和粉彩上色」 |
| R3 | 面部必须使用「干净柔和线条 + 通透粉彩肤色」 |
| R4 | 发丝必须使用「柔软轻盈线条 + 水彩般通透质感」 |
| R5 | 光影必须声明「柔光弥散 + 光斑/雾化氛围层次」 |

### 严禁项（所有技能继承）

| 编号 | 严禁内容 |
|---|---|
| X1 | 严禁「写实摄影/真人实拍/3D写实渲染/CG动画质感」 |
| X2 | 严禁「高饱和荧光色/霓虹色/厚重油画笔触」 |
| X3 | 严禁「暗黑血腥/惊悚悬疑/激烈冲突场景」 |
| X4 | 严禁「面部变形/比例失调/肢体异常」倾向词 |
| X5 | 严禁「硬阴影/重对比/暗调压抑」 |
| X6 | 严禁「快节奏炫技元素/强冲突戏剧张力描述」 |
