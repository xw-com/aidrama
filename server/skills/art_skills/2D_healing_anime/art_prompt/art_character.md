# 治愈系动漫风格 - 人物基础形象生成 · 约束手册

---

## 一、基础形象原则

1. **松弛即灵魂** — 面容与体态以"松弛温软"为核心，避免紧绷锐利的数字化边缘
2. **角色为本** — 基础着装由角色描述（身份/职业/性别/场景）决定其常规着装；后续特定服化为叠加层
3. **四视图一致** — 面容/体型/发型/基础服装跨视图高度统一
4. **温暖亲和** — 无妆状态需体现角色气质（温软/松弛/干净/沉静）

---

## 二、面容约束

> 不再固定五官特征参数，由角色描述（性别/年龄/性格/气质）驱动 AI 自由生成五官，保证人物间外观差异化。

### 通用要求

| 项目 | 约束 |
|---|---|
| 五官 | 由角色描述自然推导，不预设脸型/眼型/眉型/鼻型/唇型 |
| 风格底色 | 现代治愈系动画水彩通透质感（低饱和粉彩、轻盈线条、柔和色块） |
| 气质 | 必须从角色描述提炼整体气质关键词（如温软/松弛/干净/沉静），并写入提示词 |
| 表情 | 中性微表情，嘴角松弛，符合角色气质 |

## 六、基础服装约束

> 基础服装由角色描述（身份/职业/性别/场景）决定其最自然的常规着装，作为该角色「日常默认态」；正式服饰/特殊衍生在服化衍生环节叠加。**禁止内衣打底**。

### 着装选择原则

| 角色身份 | 默认着装方向 |
|---|---|
| 面包店/咖啡店主理人 | 棉麻工作服 + 围裙 |
| 花店/园艺相关 | 园艺围裙 + 便装卸货装 |
| 学生 | 现代西式校服（西服外套+裙/裤） |
| 乡村/居家生活者 | 棉麻连衣裙 / 针织开衫 |
| 自由职业/手作者 | 宽松针织 + 棉麻长裤 |
| 角色描述未明确 | 治愈系棉麻日常常服 |

### 着装统一规则

- 服装风格须与治愈系日常美学一致（棉麻、针织、围裙等温润材质、低饱和粉彩色）
- 颜色低饱和粉彩，无复杂花纹/装饰，便于后续衍生叠加
- 四视图服装款式完全一致
- 基础服装是「日常默认态」，焦点仍在面容与体态
- 严禁内衣/暴露/性化打底

## 八、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须为「素颜无妆」状态 |
| R2 | 必须根据角色描述声明合适的常规着装作为基础服装（如面包店主理人→棉麻围裙工作服、学生→现代校服、居家→针织休闲服）；禁止内衣打底 |
| R3 | 必须声明「无发饰、无配饰」 |
| R4 | 必须指定「奶油米白背景 #F7F3EA」 |
| R5 | 必须指定「四视图一致性」 |
| R6 | 全身立像必须从头到脚完整展示，严禁裁切 |
| R7 | 必须指定角色身高并通过头身比换算约束全身比例（女性默认155-165cm/5.5-6.5头身，男性默认168-178cm/6-7头身） |
| R8 | 人像特写必须从头顶到锁骨完整展示，严禁裁切头顶 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 内衣/暴露/性化打底；与角色描述明显不符的着装；过度复杂花纹/装饰干扰后续服化叠加 |
| X2 | 数字化锐利边缘、高饱和浓艳色彩 |
| X3 | 过度美白至无血色 |
| X4 | 复杂场景背景（必须奶油米白纯色背景） |
| X5 | 夸张表情/动态姿势 |
| X6 | 全身立像裁切头顶或脚底，必须从头到脚完整入画 |
| X7 | 人像特写裁切头顶，必须从头顶到锁骨完整入画 |
| X8 | 忽略身高和头身比约束 |
