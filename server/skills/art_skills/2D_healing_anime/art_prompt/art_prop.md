# 治愈系动漫风格 - 道具图像生成 · 约束手册

---

## 一、道具设计原则

1. **温度可读** — 道具须带有生活温度与手作痕迹，让人一眼感到"被用心使用过"
2. **质感极致** — 材质纹理必须清晰可辨（木质/藤编/陶土/棉麻/烘焙/玻璃）
3. **日常为锚** — 所有道具符合治愈系日常世界观（烘焙/绿植/手作器物），风格统一
4. **尺度明确** — 通过参照物或标注暗示道具真实尺寸
5. **纯道具独立展示** — 画面中只能出现道具本身，严禁出现任何人物、手部、肢体，道具不可处于被持有/佩戴/握持状态，必须以静物陈列方式独立呈现

## 三、多角度设定图规范

### 视图定义

| 位置 | 视图 | 角度 | 要求 | 提示词 |
|---|---|---|---|---|
| 左上 | 正面图 | 正面 0° | 道具完整正面形态 | front view |
| 右上 | 侧面图 | 侧面 90° | 厚度/轮廓/结构清晰 | side view |
| 左下 | 背面图 | 背面 180° | 道具背部结构/细节 | back view |
| 右下 | 细节特写 | 局部放大 | 材质纹理/手作细节 | detail closeup |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 同一画面四宫格（2×2），上下左右四视角 |
| 背景 | 奶油米白 #F7F3EA |
| 光线 | 空气感柔光，均匀柔光，无硬阴影 |
| 比例 | 每格道具占格内主体 70%+ |
| 投影 | 允许自然地面微投影 |
| 画面比例 | 建议 1:1 |

## 六、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须指定「奶油米白背景 #F7F3EA」 |
| R2 | 必须明确道具材质与手作工艺 |
| R3 | 道具造型必须符合治愈系日常世界观风格 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 复杂场景背景 |
| X2 | 道具与人物同画面 |
| X3 | 出现任何人物形象 |
| X4 | 道具处于被持有、握持、佩戴、使用中的状态 |
| X5 | 出现暗示人物存在的元素 |
