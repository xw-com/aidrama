# 治愈系动漫风格 - 场景图生成 · 约束手册

---

## 一、场景美学原则

1. **空气叙事** — 场景以「空气感」为核心，光斑、蒸汽、雾霭与漂浮微尘让空间"会呼吸"
2. **层次纵深** — 所有场景必须具备前/中/后景，远景以雾霭蓝柔化过渡，杜绝扁平
3. **质感至上** — 水彩通透上色、低饱和粉彩色调等材质表现必须清晰
4. **治愈日常为锚** — 一切画面以现代治愈系日常动画为标准，拒绝写实渲染与3D CG；追求轻盈干净线条与柔光弥散（光斑、雾化、微尘）

## 五、主视图规范

### 视图定义

> 单画面主视图，从场景中最具代表性的角度拍摄，承载空间叙事与构图重心。

| 项目 | 约束 | 提示词 |
|---|---|---|
| 视角 | 自然观察视角，构图最能体现场景主体与纵深 | hero shot、representative angle |
| 视点高度 | 默认人眼平视高度，特殊场景可俯/仰 | eye level（默认） |
| 构图 | 主体居中或符合三分法，前/中/后景层次清晰 | balanced composition |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 单画面（非拼图、非多视图、非分屏） |
| 人物 | **严禁出现任何人物、人影、人体轮廓** |
| 一致性 | 风格/材质/色调/光线统一 |
| 光线 | 单一光源逻辑，光影方向一致 |
| 画面比例 | 默认 16:9（或按调用方设定） |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 场景必须有「前中后景层次」 |
| R2 | 室外必须包含「空气透视 + 远景雾霭柔化」 |
| R3 | 场景图必须为「单画面主视图」，不得拼接多视图/分屏/网格 |
| R4 | 构图须能代表场景主体并展示前/中/后景层次 |
| R5 | 场景图中**严禁出现任何人物** |
| R6 | 必须包含治愈系关键词（modern healing anime style / watercolor-like / pastel） |
| R7 | 必须包含通透特征（水彩通透上色、空气感柔光 至少一项） |
| R8 | 材质必须带有手作痕迹/使用感，禁止全新无瑕的"CG 感" |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 背景纯白/纯黑/无场景 |
| X2 | 极端天候（暴风雨/雷电/暴雪，除非剧情需要） |
| X3 | 场景无纵深/无层次 |
| X4 | 植被/天候与季节矛盾 |
| X5 | 出现任何人物、人影、人体剪影 |
| X6 | 画面被拼接成多视图/网格/分屏布局 |
| X7 | 3D 渲染/写实摄影/CG 动画质感 |
| X8 | 材质过于干净完美、无任何手作痕迹 |
| X9 | 光照硬朗、强对比硬阴影，无柔光弥散 |
