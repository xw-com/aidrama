# 治愈系动漫风格说明

本风格专为"现代治愈系日常动画质感"题材打造，所有美术提示词、规范和生成内容均严格限定于：

- **治愈系世界观**：以现代治愈系日常为背景，涵盖面包店、花房、乡野小镇、单线电车、木造老宅等，体现空气感慢生活气息。
- **水彩通透质感**：所有角色、场景、道具均以现代治愈系动画为标准，强调低饱和粉彩上色、水彩般的通透叠色、空气感柔光层次。
- **治愈日常美学**：在柔光画面上追求呼吸感氛围，色调明亮通透，细节温和，整体氛围松弛、温暖、被治愈。
- **情感表达**：适合展现平静、温暖、陪伴系的故事，强调"无事发生却也动人"的日常诗意。

## 适用范围

- 治愈系日常动画题材的AI美术生成（角色、场景、道具、分镜等）
- 需要空气感柔光、低饱和粉彩、水彩通透上色的视觉创作

## 严禁内容

- 写实摄影、真人实拍、3D渲染、CG动画质感
- 高饱和荧光色、霓虹色、厚重油画笔触
- 暗黑血腥、惊悚悬疑、激烈冲突内容
- 快节奏炫技运镜、强对比硬阴影

## 风格体验

在本风格下，您将体验到：

- 角色面容干净温柔、气质松弛，服饰以棉麻、围裙、针织等温暖日常材质为主
- 场景空气感充足，光斑、蒸汽、雾霭与微尘营造"会呼吸"的空间
- 道具以烘焙、绿植、陶器、手作器物为主，手作痕迹与生活温度并存
- 分镜与画面以柔光慢节奏为基础，强调留白、静观与情绪治愈

---

本风格仅适用于"治愈系动漫"相关项目。如需其他风格（如恋爱动画、少女漫画、少年热血、写实摄影等），请勿使用本套提示词。
