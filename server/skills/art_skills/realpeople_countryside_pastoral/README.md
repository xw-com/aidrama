## 一、风格核心定义

**真人乡村田园**是以**真人影视摄影美学**为基准、以**当代中国乡村田园生活**为核心的视觉风格体系。其核心特征为：

- **真人写实摄影质感**：以真人影视级摄影为锚点，画面呈现真实人物的皮肤纹理、毛发细节、微表情与肢体语言，真实还原泥土、砖瓦、面料、作物的物理质感，杜绝3D建模感、CG渲染感、手绘感
- **当代乡村田园世界观**：所有场景严格限定于当代中国乡村/新农村空间——农家砖瓦院落、青砖土墙、堂屋灶间、稻田菜地、竹林溪流、晒谷场、乡间土路、村口老树、乡镇集市、村小学校、土砖老屋等真实乡村生活场景
- **电影级摄影语言**：以院线级真人电影摄影为基准，强调自然天光与灶火/灯火的人工光有机调度、构图叙事的专业性、景深与焦点的情绪表达、色彩分级的电影感
- **乡村人文温度感**：在保持专业影像品质的前提下，强调乡村生活的烟火气、土地与人的真实情感连接、劳作与节气的日常审美提炼

### 创作理念与核心价值

本手册的核心创作理念为 **"土地即根脉"**：

1. **真实感的审美回归**：在AI生成影像日趋泛滥的当下，真人写实质感以其不可替代的真实力量，成为最具情感穿透力的视觉语言。被日晒的小麦色皮肤、皲裂的茧手、被汗浸透的粗布衣领、灶火映红的脸庞、晨雾里起伏的稻浪——这些真实细节构成了一种扎根土地的生命质感，是3D渲染无法复刻的审美深度。

2. **乡村的叙事容器**：当代中国乡村是最具中国底色的叙事空间。堂屋灶间升起的炊烟承载着几代人的生活，田埂上的脚印记录着春种秋收，村口老树下听见了乡音与乡愁，晒谷场上的玉米辣椒晾晒着日子的颜色——乡村空间本身就是一个巨大的叙事容器，等待被挖掘。

3. **人本主义的视觉立场**：本手册坚持以"人"为核心。无论场景多么开阔、光影多么绚丽，最终回归到人物的情感状态与内心世界。每一帧画面都是一次对土地与人的注视。

4. **电影与日常的临界点**：寻求"电影的精致"与"乡土的真实"之间的微妙平衡——画面足够美、足够专业、有电影感，但不过度精致而失去泥土感；人物足够真实、足够生动，但不过度随意而失去审美品质。

**核心价值：**

- 为AI视觉创作者提供一套系统化、可复用的真人乡村田园题材提示词方法论
- 建立从概念到成品的标准化视觉创作管线
- 降低真人乡村田园题材AI视觉创作的技术门槛与试错成本
- 填补当前AI视觉创作领域"真人乡村田园题材系统化方法论"的空白

## 三、视觉风格定位

### 3.1 整体风格定位

**"电影级真人写实乡村田园美学"**

以当代中国乡村田园为叙事舞台，以真人影视摄影为技术锚点，追求院线级乡村电影的画面品质与审美高度。整体风格在"电影感"与"泥土感"之间寻找黄金平衡——画面精致但不空洞，真实但不粗糙，审美在线但不炫技。

### 3.2 影像质感层级

| 质感维度 | 定位标准 |
|---|---|
| **皮肤质感** | 真人摄影级，可见自然的皮肤纹理、毛孔、细纹、晒痕、茧纹，杜绝过度磨皮与塑料感 |
| **毛发质感** | 发丝根根分明，自然蓬松或被风吹乱，受光面与背光面层次清晰，杜绝僵硬发块 |
| **衣物质感** | 面料纹理可辨（棉麻的粗织肌理、粗布的厚实、灯芯绒的棱纹、的确良的光滑），褶皱符合劳作动态与重力 |
| **环境质感** | 土墙有风化与裂纹、瓦面有青苔与落叶、木门有使用包浆、地面有踩踏磨损，杜绝"全新道具感" |
| **光影质感** | 自然天光与灶火灯火有机调度，杜绝生硬的反差与不自然的噪点，追求电影级色彩科学 |

## 四、关键视觉元素

### 4.1 人物视觉元素

真人乡村田园题材的人物视觉以**"真实个体、乡土气质"**为核心：

- **面容标准**：真人肌肤质感，五官自然，皮肤偏暖/日晒小麦色，有劳作痕迹（晒痕、茧手、皲裂）。支持多元乡土气质——朴实憨厚、勤劳爽朗、沧桑内敛、羞涩质朴、返乡青年的清亮
- **发型标准**：自然不造作的乡村发型，发丝自然质感，杜绝假发感与造作造型。女性自然垂落/低马尾/辫子/随意盘发，男性利落短发/板寸/微分碎盖
- **服饰标准**：当代乡村日常着装体系——粗布对襟/棉布衬衫/旧夹克/工装裤/胶鞋布鞋/碎花罩衫/围裙。面料纹理清晰（棉麻粗织、的确良、灯芯绒），有劳作磨损与洗涤褪色
- **表情与体态**：微表情真实细腻（眼神、嘴角、眉宇），肢体语言自然不做作，劳作后的真实体态，杜绝僵硬摆拍感与过度戏剧化表情
- **人物气质维度**：朴实憨厚 / 勤劳爽朗 / 沧桑内敛 / 羞涩质朴 / 返乡清亮 / 乡野童真 / 老成持重

### 4.2 场景视觉元素

- **农家院落（堂屋/灶间/厢房）**：青砖土墙、瓦顶、堂屋八仙桌与条案、灶间柴火灶与大铁锅、厢房木板床与花被子——院墙的青苔、土墙的裂纹、门槛的磨痕、晾晒的作物
- **稻田菜地**：起伏的稻浪、田埂小路、菜地的垄沟与架豆、水田的倒影、远处的山影——四季作物状态分明
- **乡间土路与田埂**：泥土路面的车辙与脚印、路边的野草与野花、田埂的窄道、远处的村庄轮廓
- **村口老树与晒谷场**：巨大的老樟树/老榕/老槐、树下的石凳石碾、晒谷场的水泥/三合土地面、晾晒的玉米辣椒花生
- **村小学校操场**：红砖教学楼、水泥操场、旗杆、简易篮球架、墙上的标语、孩子们的跑道
- **乡镇集市**：搭棚的摊位、塑料布与编织袋、赶集的乡亲、蔬菜瓜果家禽、手写的价格牌
- **土砖老屋**：夯土墙、木梁结构、小木窗、青瓦或石棉瓦、屋前的柴垛与农具
- **竹林溪边**：成片的竹影、溪水卵石、洗衣的石板、漫射的林间光、清凉湿润
- **小卖部/卫生室**：老式玻璃柜台、货架的日用杂货、挂着的零食袋；卫生室的白墙、简易诊桌、输液架

### 4.3 道具与细节元素

- **农具道具**：锄头、镰刀、犁、扁担、箩筐、簸箕、风车、打谷机、水桶——有使用包浆与泥土痕迹
- **生活器物**：搪瓷缸、搪瓷盆、咸菜坛、腌菜缸、铁锅、柴火灶、风箱、煤油灯、手电——充满年代感与使用痕迹
- **时代符号道具**：蓑衣斗笠、二八大杠自行车、编织筐、草帽、扁担水桶、铝饭盒、军绿色水壶——承载乡村记忆
- **晾晒作物**：玉米棒、红辣椒、花生、柿饼、咸菜——挂满屋檐与晒场，色彩饱满
- **光影道具**：柴火灶、煤油灯、白炽灯泡、手电光束——乡村叙事中的氛围制造者
- **情感符号道具**：老照片、家书、汇款单、车票、针线笸箩、孩子的奖状——承载乡愁的小物件

## 五、严禁内容（优先级最高）

本风格严格排除以下内容类型，确保视觉体系纯净统一：

1. **非真人质感**：3D渲染/CG建模/次世代游戏引擎/动画风格/手绘插画/水彩油画/二次元/Voxel/低多边形等一切非真人实拍影像质感
2. **非乡村田园世界观**：古风/古装/仙侠/武侠/宫廷/民国/赛博朋克/科幻未来/星际太空/西方奇幻/中世纪等非当代乡村田园背景；高楼都市/CBD/现代写字楼等与乡村田园无关的精致都市符号
3. **非当代中国乡村语境**：明显非中国乡村特征的建筑、标识、人物造型（如日式田园、欧式农庄、和服、韩屋等）
4. **技术质量缺陷**：低分辨率/模糊/噪点/变形/畸形肢体/五官扭曲/比例失调/抠图感/塑料感/过度磨皮/假面感
5. **审美倾向违规**：过度高饱和/死亡荧光色/廉价滤镜感/过度HDR/脏乱差画面/刻意阴间色调
6. **内容合规红线**：暴露/低俗/暗示性/暴力血腥/违法内容/歧视性表达/政治敏感元素

## 七、使用说明

### 提示词使用原则

1. **前缀先行**：所有生成内容必须首先加载"前缀提示词"中的全局风格锚定段，锁定真人乡村田园写实质感基线
2. **专项叠加**：在全局前缀基础上，按需叠加角色/场景/道具/分镜专项提示词
3. **负面必加**：每次生成必须附带"负面提示词"，规避伪影与风格偏差
4. **迭代优化**：建议首轮生成后根据效果对专项提示词做微调，而非修改全局前缀
5. **平台适配**：本手册提示词优先适配Doubao-Seedream（生图）与Doubao-Seedance（视频生成），部分提示词可能需根据平台特性微调
