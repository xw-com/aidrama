## 二、摄影机语法（替代"渲染引擎"）

> 真人乡村田园不依赖渲染管线。画面品质取决于摄影机的选择、镜头的性格、光线的调度。以下为"摄影机语法"核心参数。

### 2.1 画幅与格式

| 参数 | 基准值 | 美学意图 |
|---|---|---|
| 影像格式 | 35mm胶片质感 / 全画幅数字摄影 | 浅景深能力、自然的暗角过渡、微妙的颗粒结构，承载乡村的温度与颗粒感 |
| 色彩科学 | ARRI Alexa / Sony Venice 类电影色彩科学 | 肤色（含日晒小麦色）还原自然、高光滚降柔和、暗部不压死且有层次 |

### 2.2 镜头性格

| 焦段 | 叙事性格 | 典型应用 |
|---|---|---|
| 24-28mm（广角） | 土地吞没人物、田野的辽阔、个体在乡野中的渺小与扎根 | 乡村空镜、稻浪全景、村庄与远山的关系 |
| 35mm（小广角） | 主观视点、身临其境、纪实感 | 院落跟随、田间劳作、灶间对话、村道行走 |
| 50mm（标准） | 人眼等价、客观注视、不美化不扭曲 | 人物肖像、双人对话、情感凝视 |
| 85mm（中长焦） | 压缩空间、拉近情感距离、背景虚化突出人物 | 特写、远处田埂上望见、村口老树下远远凝视 |
| 135mm+（长焦） | 极端压缩、窥视感、将人物从田野中剥离 | 隔着院墙的注视、远眺归途、情绪的物理距离 |

### 2.3 机位与运动

| 手法 | 视觉心理 | 使用场景 |
|---|---|---|
| 固定机位 | 冷静、观察、让土地与时间自己说话 | 日常场景、院落对话、炊烟空镜留白 |
| 手持微晃 | 在场感、呼吸感、主观介入 | 情绪波动、田间行走、灶间跟随 |
| 斯坦尼康/稳定器 | 优雅流动、乡野漫游的诗意 | 重要场景过渡、人物登场、村道与田野展示 |
| 俯拍 | 命运感、渺小、大地纹理的几何美 | 田野俯瞰、晒谷场俯视、归途回望 |
| 仰拍 | 老树与人物的力量感、崇高 | 村口老树的伟岸、人物的力量感 |
| 焦点偏移（Rack Focus） | 注意力的转移、关系的改变 | 人物对视时焦点的游移、揭示隐藏信息 |

## 三、乡村田园色谱——光与材料的真实色彩

> 真人乡村田园的色彩来自中国乡村真实的光与材料，不是引擎色板。以下色盘提取自：泥土路与田埂的暖黄、青砖土墙的岁月、灶火与煤油灯的暖橙、稻田与竹林的青绿、瓦顶与远山的灰青。

### 3.1 乡村光源色谱

| 光源 | 色温（K） | 光色描述 | 乡野场域 |
|---|---|---|---|
| 晨光（日出后1h） | 3500-4500 | 低角度暖白漫射，穿过薄雾与晨炊烟气扩散 | 薄雾中的稻浪、田埂上扛锄的农人、菜地的露水 |
| 上午天光 | 5000-5500 | 冷白清澈，阴影清晰，作物与土墙材质感最强 | 院落、晒谷场、田间劳作的日间默认光 |
| 正午顶光 | 5500-6500 | 冷硬强光，阴影短而浓重——乡野烈日下需谨慎使用 | 裸露的田野、空旷的晒场——慎用，易压平质感 |
| 金色时刻（日落前1h） | 2600-3200 | 最珍贵的暖调，长阴影，稻浪与瓦面镀上金边 | 一切温情与丰收、归家段落的首选光源 |
| 蓝调时刻（日落后20min） | 8000-10000 | 天空呈深邃蓝紫，村庄灯火尚弱于天光，冷谧诗意 | 归途、过渡、内心独白、尾声 |
| 灶火/柴火灶 | 2000-2600 | 标志性的暖橙红，乡村夜晚与灶间的体温 | 灶间做饭、年夜团圆、火塘夜话、炊烟升腾 |
| 煤油灯/烛火 | 1800-2200 | 极暖的跳动点光源，照亮一隅，老屋的夜晚 | 老屋幽光、停电夜晚、怀旧记忆 |
| 白炽灯泡（老式） | 2700-3000 | 暖黄、稍显昏暗，乡村室内的常用夜光 | 堂屋、厢房、小卖部、卫生室的夜晚 |
| 村口路灯/院灯 | 3000-4000 | 暖白或微黄，村口与院落的夜间标识 | 暮色归途、村口等候、院落夜晚 |
| 手电光束 | 4000-5000 | 移动的冷白点光源，光束穿过夜雾产生体积效果 | 夜间走村道、巡田、找寻 |
| 篝火/烧秸秆火光 | 2000-2400 | 跳动的暖橙火光，照亮围坐的人脸 | 秋收烧秸秆、火塘围坐、节庆烟火 |

## 四、全局约束规则

### 4.1 影像真实性约束（必守）

| 编号 | 规则 |
|---|---|
| P1 | 必须以「真人摄影 / 真人实拍 / 真人电影剧照」为生成锚——画面必须读作"摄影机拍下的"，而非"计算机生成的" |
| P2 | 必须指定一个具体的光源逻辑：这场戏的光从哪里来？（天光/灶火/灯火/窗光）光源方向、色温、软硬须自洽 |
| P3 | 必须保留人物皮肤的真实质感——晒痕、毛孔、细纹、茧手、皲裂——杜绝塑料磨皮与AI感假面 |
| P4 | 发丝必须呈现自然状态——被风吹乱、被汗贴在额头、扎起后散落的碎发——杜绝建模感整齐发块 |
| P5 | 服饰必须体现"穿过/劳作过"的痕迹——棉麻粗布的磨损、洗涤褪色、领口变形、裤脚泥点——杜绝全新样板衣感 |
| P6 | 场景必须有"被使用过/被岁月侵蚀过"的证据——土墙裂纹、瓦缝杂草、门槛磨痕、晒场积灰——杜绝影视城样板 |
| P7 | 人物必须处于自然体态——真实的站姿（重心偏一侧）、劳作后的微弯、不刻意的表情——日常的手部与农活动作 |
| P8 | 必须指定一个具体的当代中国乡村田园空间——拒绝"generic countryside"或任何无国别标识的架空田园 |

### 4.2 摄影品质约束（必守）

| 编号 | 规则 |
|---|---|
| Q1 | 必须声明一种摄影机的"在场方式"：固定注视 / 手持呼吸 / 稳定器流动 / 长焦窥视 |
| Q2 | 景深必须具有叙事意图——浅景深突出情绪、深景深强调土地田野、焦点偏移引导注意力 |

### 4.4 风格越界判定

> 当你生成的画面出现以下任一信号，说明已经偏离真人乡村田园风格：

| 越界信号 | 说明 |
|---|---|
| 人物皮肤像硅胶 | 磨皮过度，失去真人质感——立即停用"光滑""完美肌肤"类词汇 |
| 光源来源不明 | 画面亮但说不清光从哪来——补全光源逻辑，拒绝"全局均匀亮" |
| 乡村失去中国辨识度 | 场景像日式田园或欧式农庄——加入土砖老屋、对联门神、搪瓷缸、二八大杠等明确的中国乡村符号 |

| 人物站姿像模特 | 体态僵硬对称——给一个自然的身体重心偏移、劳作后的微弯 |
| 色彩像滤镜APP | 色调统一但廉价——回归光源色温驱动，不要"滤镜套用" |
