# 真人乡村田园场景图像生成 · 约束手册

---

## 一、场景美学原则

> 真人乡村田园的场景不是"被建模的空间"，而是"被摄影机选中的真实乡野地点"。没有渲染引擎、没有贴图、没有体积光参数——只有实际存在的天光、真实的土地材料、被岁月与劳作打磨过的中国乡村日常。

1. **空间即叙事** — 一个空无一人的堂屋不是"空的"，是刚放下碗筷。一把靠在墙上的锄头、灶膛里未灭的余烬、堂屋条案上的搪瓷缸——空间自己会讲故事
2. **真实的光，不是渲染的光** — 场景的光只有一个来源：实际的天光（通过门窗、院落）、实际的火光与人造光（柴火灶、煤油灯、白炽灯泡、村口路灯）。光的色温和方向必须在物理上说得通
3. **被使用过、被岁月侵蚀过的空间** — 真实的乡村场景不整洁。土墙有裂纹、瓦缝长草、地面有踩踏磨损、门槛磨出凹槽。一个完全没有生活痕迹的空间是影视城样板，不是真人乡村田园
4. **中国当代乡村的真实场所** — 场景必须有中文标识、中国乡村特征（对联门神、搪瓷缸、二八大杠、晒秋作物、特定建筑样式）。这不是"generic countryside"，这是"当代中国乡村的一个具体角落"
5. **单视图全景全貌** — 一张照片装下整个场地的完整信息。广角或标准焦段，全景深，正面展示空间的全貌与纵深——不是四视图分割，不是多角度拼贴

## 二、季节与时刻——自然光的导演

> 真人乡村田园场景的光，首先由季节和时刻决定。以下是真实光源在四个季节、五个时段的摄影行为。

| 春 | 正午 11:00-13:00 | 日光近乎垂直、阴影短、作物与土墙材质清晰、光线偏冷白 | 春日明亮、菜花金黄、田野通透 |
| 春 | 午后 14:00-16:00 | 日光偏西、暖调渐强、斜光穿过屋檐与树枝形成光斑 | 春日午后、慵懒温暖、院落光斑 |

## 三、室内场景

| 维度 | 摄影要求 | 提示词 |

| 光源逻辑 | 必须有明确的光源来源——门窗光是哪个方向、火光/灯是哪一盏。光的方向和色温必须自洽 | {门窗光方向}自然天光为主、{灶火/灯火/白炽灯}为辅、光的方向明确可追溯 |
| 空间层次 | 单张全景照片必须呈现前/中/后景——前景（门框/木柱/家具边缘）形成画框感、中景是空间主体、后景是空间延伸（另一间房/门外院落/堂屋后门） | 前景{画框元素}、中景{空间主体}、后景{空间延伸}、广角镜头捕捉完整空间纵深 |

## 五、单视图全景摄影规范

> 真人乡村田园场景仅需**单张**全景摄影——一张照片装下整个空间的完整信息。不是2×2四视图，不是多角度拼接。

### 画面构成

| 项目 | 摄影要求 |
|---|---|
| 空间呈现 | 单张照片完整呈现场景的空间全貌。使用24-28mm广角或35mm，全场地的纵深、宽度、高度在一张画面中全部可见 |
| 构图 | 全景深大景别——前景（门框/木柱/家具/作物/树干）形成天然画框→中景是场地主体→后景向空间纵深或门外/远山延伸 |
| 景深 | 全景深 f/8-f/11，从前到后全部清晰。这不是人像摄影——场景的每一个角落都应该能被看见 |
| 人物 | **严禁出现任何人物、人影、人体轮廓。** 场景是空的——但这种"空"有叙事：刚放下农具/即将开饭/人去屋空/日常的静止瞬间 |
| 比例 | 建议 16:9 或 3:2 宽幅——匹配全景空间展示的横向视觉习惯 |
| 色彩 | 由实际光源的色温驱动，不套滤镜。色彩科学参考ARRI Alexa/Sony Venice电影色调 |

### 空的场景如何叙事

| "空"的类型 | 画面线索 | 叙事暗示 |
|---|---|---|
| 刚收工 | 锄头靠在墙上有泥土、灶膛有余烬、桌上摆着未盛的碗筷 | 刚才有人在这里，现在去了别处 |
| 即将开饭 | 八仙桌摆好碗筷、铁锅里冒着热气、条凳整齐、堂屋后门半开 | 有人马上要来吃饭，现在是开饭前的静止 |
| 人去屋空 | 老屋搬空后的角落、墙上挂过照片的痕迹、地面积灰的家具轮廓 | 曾经有人住过，现在已经离开 |
| 日常的静止 | 灶台上锅在煮、围裙搭在凳上、堂屋门半开、阳光打在八仙桌上 | 生活的常态、只是此刻没有人入镜 |
| 闲暇的场所 | 晒谷场空着、村口老树下石凳空着、村小操场的旗杆、午后的菜地 | 阳光下的停顿、土地在歇一口气 |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
