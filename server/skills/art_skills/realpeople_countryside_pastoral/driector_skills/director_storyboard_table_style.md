# 分镜表真人乡村田园约束 · 真人实拍乡村田园 · 技法参考

## 一、分镜表定位

分镜表是导演将剧本转化为镜头语言的核心工具。本约束面向 Seedance 2.0 视频生成，所有光影、动作、空间描述均采用模型可执行的具象语言。不做抽象的情感概括，不写模型看不懂的渲染参数。

## 三、光影与氛围——Seedance 2.0 物理光源描述

### 3.1 同场戏光影统一

一场戏内不应出现两种以上核心光影方案，除非有叙事驱动的光源变化（如有人点亮煤油灯、日出后天光亮过灶火、从堂屋走到院落）。光源变化必须在分镜表中标注触发事件。

### 3.2 光源语句法（每个镜头必须包含）
[光源] 主光：{光源类型}，{方向}，{色温值K}，{软硬}
[光源] 辅光/环境光：{光源类型}，{方向}，{色温值K}
[光比] 约1:{X}
### 3.3 情绪 → 光源矩阵

| 情绪 | 光源配方（Seedance 2.0 可直接填入） | 视觉关键词 |
|---|---|---|
| 田园日常 | 院落天光漫射主光（5000-5500K）从上方入射，屋檐投阴影。光比约1:2 | 中性偏暖，材质清晰 |
| 灶间烟火 | 柴火灶/煤油灯暖光主光源（2200-2600K），暗部保留物体轮廓，蒸汽炊烟升腾。光比约1:5 | 暖调包裹、亲情 |
| 黄昏丰收 | 金色时刻低角度暖光（2600-3200K）穿过屋檐与树梢，稻浪镀金。光比约1:4 | 暖金主导、喜悦 |
| 雨后沉思 | 湿泥路反射天光冷基底（6000K）+ 云间透暖日光斑（4500K），作物挂水珠。光比约1:4 | 冷暖共存、清新 |
| 老屋怀旧 | 天井/高窗单一束天光（5500K冷白），大范围暗部，尘埃游走。光比约1:8 | 沧桑、被封存的记忆 |
| 暮色离别 | 蓝调天空漫射（8000-10000K）+ 村口暖路灯（3000K）+ 远山剪影。光比约1:5 | 冷暖告别、诗意 |
| 乡野悬疑 | 侧方硬光（冷白天光5000K或煤油灯暖2000K）单光源，大光比，暗部深但有微弱轮廓。光比约1:8 | 压抑、不确定 |
| 童真治愈 | 充足自然漫射（5000-5500K），天空光+地面反射补光。光比约1:1.5 | 高调通透、希望 |
| 深夜私密 | 单一暖光源——灶火余烬/煤油灯/白炽灯（2200-3000K）形成孤岛式照明，面部一侧亮一侧暗。光比约1:8 | 极简光源、私密 |

### 3.4 冷暖色调与叙事阶段

- **冷光主导**（5000K+）：田园克制、乡野悬疑、清冷独处、雨后沉思
- **暖光主导**（2000-3500K）：灶间亲情、丰收烟火、黄昏归家、金色时刻
- **冷暖共存**：过渡时刻（蓝调时刻+初亮村口暖灯）、雨后（冷环境+暖日光斑）、暮色（冷天+暖灯）
- **光源变化 = 叙事信号**：堂屋门外天空从日间冷白渐变至黄昏暖金=时间流逝；从田间冷白天光走到灶火暖橙下=场景与情绪的切换

### 3.5 Seedance 2.0 光影适配要点

- 色温数字帮助模型校准白平衡倾向：`色温约2400K灶火` 优于 `暖光`
- 光比数字帮助模型建立明暗意识：`光比约1:5` 优于 `柔和的阴影`
- 光源必须有明确来源：`从画面左侧灶膛跃动` 优于 `侧光`
- 环境光的反射路径描述：`湿泥路反射天光` 优于 `地面有冷色反光`

## 四、环境动态——让画面呼吸

### 4.1 动态密度

每 3-4 个镜头至少安排一个有环境动态的镜头。静态对话戏也不例外——至少有一个镜头里院落的晾晒作物在动、灶间的蒸汽在升腾、窗外的稻浪在起伏。

### 4.2 乡村环境动态元素（Seedance 2.0 可执行）

| 场景 | 可描述的环境动态 |
|---|---|
| 院落 | 屋檐下晾晒的辣椒串被风吹起约15度后回落（约2秒周期）、母鸡在院坝踱步啄食、墙头晒太阳的猫伸懒腰、远处炊烟从邻居家屋顶缓缓升起 |
| 灶间 | 铁锅口蒸汽缓缓上升约50cm后散开、灶膛火苗跳动明暗交替、风箱呼哧拉动时火苗窜高、墙面被火光映得明暗变化 |
| 田野 | 稻浪随风起伏约每秒2-3次微幅摆动、田埂边的草叶簌簌晃动、远处田里有人弯腰劳作的剪影、布谷鸟叫声中叶片抖动 |
| 村道 | 路边树叶被风吹动、远处一辆拖拉机突突驶过扬起薄尘、电线杆上麻雀起落、村口的狗懒洋洋起身走开 |
| 集市 | 摊主反复整理蔬菜摆放、远处有人挑着扁担走过、塑料布被风吹得鼓起、讨价还价时手势起伏 |
| 老屋 | 天井漏下的光束中尘埃缓慢游走、蛛网在角落微微颤动、木梁上的旧物落细灰、窗外竹影随风摇曳投在土墙上 |
| 雨天 | 雨丝斜斜落下、屋檐滴水成线、院积水泛涟漪、瓦面水流如小瀑、作物叶片被雨点打得微颤 |

### 4.3 Seedance 2.0 环境动态描述规范

- 动态必须有具体轨迹和速度：`稻浪被风吹动，每秒约2-3次微幅起伏` 优于 `稻浪在动`
- 光源动态与空间光源逻辑一致：`云朵遮住太阳时，院落天光面积缩小约40%，光斑变暗，持续约3秒后恢复`
- 禁止无来源的动态：没有风=晾晒作物不动。灶膛没火=没有火光跳动

## 五、人物动作节奏——Seedance 2.0 物理逻辑具象化

### 5.1 动作描述铁律

所有人物动作必须描述：**轨迹 + 速度/时长 + 身体部位协调 + 对周围物体的影响**。

### 5.2 乡村日常动作具象库

| 动作 | Seedance 2.0 可执行描述 |
|---|---|
| 挑起扁担 | 双手握扁担两端，膝盖微屈，肩部下沉让扁担中部落在右肩，两桶水随起身轻微晃动，扁担吱呀作响，起身全程约2秒，站直后停顿0.5秒 |
| 烧火做饭 | 右手抓一把干柴塞入灶膛约20cm深，左手拉动风箱约30cm行程，火苗从暗红窜至亮橙（色温升至约2400K），火光映亮下半脸，蒸汽从铁锅口升起约50cm |
| 田间锄地 | 双手一上一下握锄柄，举高至肩部约1.4米，向前约30度角挥下，锄刃入土约10cm发出闷响，向后拉约20cm翻起一块湿土，全程约1.5秒一个循环 |
| 择菜 | 坐矮凳上身体微前倾，左手握一把豆角，右手拇食指掐去豆角两头，掐下的筋丝随手丢脚边，约每2秒处理一根 |
| 端碗盛饭 | 左手扶粗瓷碗，右手执木饭勺舀起米饭约8分满，手腕翻转将米饭扣入碗中，饭勺在碗沿轻刮一下——全程约2秒 |
| 门槛坐下 | 身体微侧，右手扶门框，臀部落在门槛上，背靠门框，双脚自然伸出门外——全程约1.5秒 |
| 推门进入 | 右手握住木门铁环向内拉动约70度角，身体随门进入，右脚先跨过门槛约20cm高，门轴吱呀响——全程约2秒 |
| 戴草帽 | 右手从墙上取下麦秸草帽，举过头顶约30cm，向下扣在头上，双手轻压帽檐调整角度——全程约2秒 |
| 雨中行走 | 在湿泥路上缓步走，步速约每秒一步，每步踩下时鞋底与泥水接触发出啪嗒声溅起小水花，水洼反射天空在脚下晃动 |
| 拥抱 | A向前迈出约0.5米，双臂环绕B的肩背，双手在B背部轻拍两下，面部贴近B的耳侧，保持约3秒 |

### 5.3 动作节奏与叙事场景

- **日常叙事/文戏**：动作沉稳克制，每个微动作标注时长和轨迹。节奏舒缓——不是慢，是"不赶"
- **情绪波动场景**：动作幅度和速度略微增加。人物可能在择菜时加快掐豆角、擦汗时力度加大、呼吸带动肩膀起伏更明显
- **劳作/冲突场景**：动作干脆有力，但仍有物理轨迹。锄地/砍柴须具体到"锄刃入土约10cm发出闷响"；推搡须"右手推在对方左肩前方，对方重心向后偏移约20cm"
- 禁止：无叙事理由的快速动作堆砌、无物理逻辑的瞬移、"做了个手势"等含糊描述

### 5.4 服饰动态

真人乡村服饰的动态是画面的天然资产——不是"布料模拟参数"，而是"围裙下摆被风吹起约15度角""碎花罩衫的袖口因择菜动作上下移动""草帽被一阵风掀起一角后被人按下"。在分镜表画面描述中标注服饰的动态细节。

## 六、空间逻辑具象化——Seedance 2.0 空间坐标系统

### 6.1 每镜头必须声明的空间信息
水平位置：画面左/中/右，或画面左侧三分之一处
纵深位置：距镜头{数值}米，前景/中景/背景
人物与场景的关系：距{固定物}{数值}米
（若双人以上）人物A与B的相对距离和朝向
### 6.2 站位衔接示例
【片段A尾部】
A站在灶间柴火灶前，距灶台约0.5米，面朝灶台，位于画面中央偏右，距镜头约3米。
灶膛火苗从画面左侧跃动，A右手持锅铲在铁锅中翻炒。
蒸汽从锅口升起约40cm。

【片段B开头】
A的锅铲刚从铁锅中抬起约10cm，仍在手中。A仍站在柴火灶前（位置未变）。
窗外天色已转为蓝调时刻——天空深蓝紫，堂屋白炽灯已亮起。
灶膛火光减弱（柴将燃尽），火光在A脸上的面积缩小。

### 6.3 空间变化必须具象

| 抽象（禁止） | Seedance 2.0 具象 |
|---|---|
| 她走近了 | A从堂屋后门（距镜头约5米）向镜头方向匀速走4步（约3米），停在距镜头约2米的八仙桌旁——耗时约4秒 |
| 两人面对面 | A位于画面中央偏左（距镜头约3米），B位于画面中央偏右（距镜头约3米），两人隔八仙桌面对面，相距约1.2米 |
| 从灶间到院落 | A从灶间（距镜头约3米）走向院门，推开木门（门向外旋转约80度），右脚跨过门槛约20cm，进入院落——院落天光瞬间取代灶间暖橙火光 |

## 七、运镜规范——Seedance 2.0 摄影机运动

### 7.1 允许的运镜

| 运镜 | Seedance 2.0 描述 | 适用场景 |
|---|---|---|
| 固定 | 摄影机固定不动，画面静止 | 对话、日常、空镜留白、情绪凝视 |
| 手持微晃 | 摄影机有轻微不规则晃动（幅度约±2cm），模拟手持拍摄的呼吸感 | 情绪波动、田间行走、灶间跟随、主观视角 |
| 稳定器流动 | 摄影机平滑匀速移动，无晃动 | 乡野漫游、人物登场、村道田野展示、过渡 |
| 缓推 | 摄影机向主体缓慢推进，推进速率约每秒0.3米 | 情绪升温、真相逼近、注意力聚焦 |
| 缓拉 | 摄影机向后缓慢拉远，拉远速率约每秒0.3米 | 离别、收束、揭示全貌、归家远景 |
| 跟拍 | 摄影机与人物保持约2米距离同步移动 | 村道行走、田间跟随、归途 |
| 摇镜 | 摄影机原地水平/垂直旋转 | 视线转移、院落到田地的空间关系 |

### 7.2 禁用运镜

- 无叙事目的的快速甩镜、急推急拉（推拉速率超过每秒1米）
- 超过3秒的剧烈手持晃动（除非主观受击/眩晕叙事）
- 无逻辑花式转场——划屏、旋转、百叶窗、翻页等特效转场
- 摄影机无理由的360度旋转

### 7.3 真人乡村田园运镜哲学

- 固定机位是第一选择——让观众看到真实的人在真实土地里自然地存在
- 手持微晃在情绪段落使用——但晃动幅度不超过电影纪实风格的常规范围
- 运动镜头的起幅和落幅必须平稳，运动过程匀速——禁止突然加速或急停

## 八、转场规范

### 8.1 允许的转场方式

| 转场 | 视觉执行 | 叙事功能 |
|---|---|---|
| 硬切 | 直接切换 | 同场戏内镜头切换（默认） |
| 光影匹配转场 | 两个场景在相近光影逻辑下切换 | 时间流逝、平行叙事。例：A处灶火 → B处灶火 |
| 空间匹配转场 | 两个空间在构图或元素上呼应 | 场景跳转。例：堂屋门推开 → 院落门推开 |
| 空镜过渡 | 插入场景空镜（3-5秒） | 情绪缓冲、章节划分、时间流逝暗示 |
| 焦点转场 | 前镜焦点从主体移至背景，后镜从模糊背景中逐渐聚焦主体 | 空间切换、注意力的转移 |

### 8.2 禁止的转场

- 纯视觉特效转场（翻页、划屏、百叶窗、马赛克）
- 无叙事逻辑的旋转/缩放转场
- 同一场戏内使用超过两种转场方式

- `t=2s` 锅铲与铁锅碰撞的轻响——翻炒的节奏
- `t=5s` 木门推开时门轴吱呀声——人物进入堂屋，院落鸟声被门隔绝瞬间变小
- `t=8s` 院外远处传来拖拉机突突声——人物抬头望向院门约1秒

## 十一、空镜使用规范

### 11.1 空镜不是"没东西拍"

空镜是情绪容器。每个空镜必须有叙事目的和具体的视觉内容：

| 空镜类型 | 叙事目的 | 示例 |
|---|---|---|
| 场景建立 | 新空间首次出现——让观众看清楚这是什么地方 | 农家院落大全景：院墙、堂屋大门、晾晒作物、鸡鸭 |
| 情绪缓冲 | 高情绪段落后的喘息 | 屋檐滴水沿瓦面滑落，速度约每秒20cm |
| 时间流逝 | 暗示时间过去了 | 同一片稻田从晨雾青绿渐变至黄昏金黄 |
| 隐喻留白 | 以物代情 | 灶台上铁锅里冒着热气，旁边搭着围裙，人不在 |
| 转场衔接 | 前后两个空间的自然过渡 | 村口老树——前一场是院落，下一场是村道 |

### 11.2 空镜 Seedance 2.0 描述规范

空镜也必须遵循光源+质感+动态的描述铁律：午后院落天光从上方漫射（约5000K），屋檐投下整齐阴影落在土院地面，
晾晒的辣椒串被风吹起约15度后回落（约2秒周期），远处炊烟从邻居家屋顶缓缓升起约1米高后散开。
土院地面有车辙与鸡爪印，墙根有青苔。
