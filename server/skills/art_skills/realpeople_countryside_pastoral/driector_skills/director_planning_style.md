# 真人乡村田园约束 · 真人实拍乡村田园 · 技法参考

## 一、色调体系与画面基调

- **色调基底** — 全片以米白（#EDE6D3）、泥土黄（#B89B6B）、瓦灰（#6E6A63）为基底色。整体色温分日间中性偏暖（5000-5800K）、夜间冷暖共存（灶火/灯火暖2200-3000K + 冷环境6000-8000K）。饱和度中低（35-55%），呈现"电影感但不滤镜感"的克制乡土色调——色彩来自实际光源与土地，不来自后期调色
- **光源即色盘** — 不以"主色/辅色"配对，而是以光源的色温和方向来驱动画面色彩。晨光3500-4500K（暖白漫射）、正午5000-6500K（冷白清透）、金色时刻2600-3200K（暖金）、蓝调时刻8000-10000K（深蓝紫）、灶火2000-2600K（暖橙红）、煤油灯1800-2200K（极暖跳动）
- **冷暖叙事对照** — 暖光（晨光/夕照/灶火/煤油灯/白炽灯）用于温情、亲情、丰收、烟火段落；冷光（正午天光/阴雨漫射/蓝调时刻）用于克制、思念、孤独、悬疑段落。关键转场可通过光源色温切换来暗示情绪转向
- **光源先行原则** — 段落规划先确定"光从哪儿来、什么色温"，再确定画面色调。避免"这个镜头颜色好看但光源说不通"
- **禁用色域** — 高饱和荧光色、廉价滤镜调色（如青橙预设/复古暖黄预设）、CG溢色、非真实光源产生的异常色偏

## 二、光影方案体系

- **光影即叙事** — 7 套光影方案对应不同情绪段落。导演规划阶段在段落层面确定光影基调方向，而非逐镜指定。每套方案必须指定"光的来源 + 色温 + 光比"，确保可被 Seedance 2.0 物理模拟
- **实拍摄影光影特征** — 自然天光的门窗与院落调度、实用光源（灶火/煤油灯/白炽灯泡/村口路灯）、环境反射（湿泥路/水田/水面）、手持摄影的微晃呼吸感、景深变化引导注意力——为真人乡村田园风格的核心光影手段

| 方案 | 方案名 | 光源配方 | 光比 | 适用情绪 |
|---|---|---|---|---|
| A | 晨雾田垄 | 晨光低角度45°斜入（3800-4200K暖白）+ 薄雾漫射 + 环境天光5500K补光 | 1:2.5 中低反差 | 清晨劳作、新生希望、静谧蓄势、田园的开场 |
| B | 午后院落 | 院落上方天光漫射（5000-5500K），屋檐投下整齐阴影，光斑落土院 | 1:2 低反差 | 日常松弛、邻里闲话、慵懒时光、乡村日间默认 |
| C | 灶火暖烟 | 柴火灶/煤油灯暖调主光（2200-2600K暖橙），蒸汽烟气升腾，暗部保留细节 | 1:5 暖调包裹 | 灶间烟火、亲情团圆、年节温情、深夜私密 |
| D | 黄昏稻浪 | 金色时刻低角度暖光（2600-3200K）穿过屋檐与树梢，稻浪与作物镀金，长阴影 | 1:4 暖金主导 | 丰收喜悦、归家时刻、温情回忆、土地的高光 |
| E | 雨后泥路 | 雨后湿泥路反射天光（冷基底6000K环境）+ 云间透出的暖日光（4500K光斑） | 1:4 冷暖共存 | 沉思清新、情绪洗涤、转折新生、雨后的呼吸 |
| F | 老屋天井幽光 | 天井/高窗漏下的单一束天光（5500K冷白），照亮堂屋一隅，其余沉入暗部，尘埃在光束中游走 | 1:8 大光比 | 怀旧沧桑、内心独白、岁月沉淀、被封存的记忆 |
| G | 暮色村口 | 日落后天空深蓝紫漫射（8000-10000K）+ 村口初亮暖路灯（3000K）+ 远山剪影 | 1:5 冷主暖点 | 归途离别、诗意留白、尾声收束、冷暖告别 |

- **冷暖光分配** — 暖色光（晨光/夕照/灶火/煤油灯/白炽灯）适用于温情亲情、丰收烟火、归家段落；冷色光（正午天光/阴雨漫射/蓝调/天井冷光）适用于克制思念、悬疑对峙、清冷独处段落。冷暖切换点即叙事转折点
- **氛围方向映射** — 每场戏的氛围方向应能映射到上述光影方案（A-G）的某一方向。如叙事需要混合方案（如E+G），需明确主导光源
- **Seedance 2.0 光影适配要点**：光源名称可被AI理解（"灶火映亮人脸"优于"暖色体积光"）。光比数字帮助模型建立明暗意识。多光源场景须明确主光+辅光+环境光的层级

## 三、质感方向——摄影机前的真实乡野世界

> 真人乡村田园质感的唯一标尺：摄影机拍到的材质行为，不是渲染引擎生成的材质参数。

- **皮肤质感** — 晒痕、毛孔可见、T区自然出油、面颊日晒泛红、茧手与皲裂——真实皮肤"被土地与劳作养过"的证据。Seedance 2.0 提示词用"sun-weathered skin, visible pores, callused hands, natural skin texture, not airbrushed，真实乡村皮肤质感"替代 3D 项目的"次表面散射/SSS"
- **发丝质感** — 碎发被风吹散在额前颈后、发缕自然聚散、逆光下头发边缘呈半透明暖色轮廓、被汗贴在额头或被风吹乱的自然状态。Seedance 2.0 用"flyaway hair strands, natural hair movement, backlit hair rim light, wind-blown hair"替代"物理级发丝模拟"
- **衣料质感** — 棉麻粗布的粗织肌理、的确良的光滑、灯芯绒的棱纹、旧夹克的褪色与磨损、围裙的油渍泥点。衣服有"被穿过/劳作过"的证据。Seedance 2.0 用"coarse cotton-linen texture, faded worn fabric, lived-in work clothing, natural fabric drape"
- **建筑材质** — 土墙的风化裂纹、青砖的苔痕与泛碱、灰瓦缝隙的杂草、木梁的虫眼与包浆、门槛的磨痕。Seedance 2.0 用"weathered rammed earth wall, mossy grey tile roof, worn wooden beams, real rural surfaces, not showroom clean"
- **岁月质感至上** — 材质不可过于干净完美。生活与岁月痕迹（土墙裂纹、瓦缝杂草、晒场积灰、门槛磨凹）不是缺陷，是空间叙事的基础。禁止"影视城样板"和"无痕效果图"
- **Seedance 2.0 质感适配要点**：避免 "PBR材质""物理级渲染""8K贴图" 等CG术语。改用 "real texture, natural material surface, visible wear and weathering marks, not CGI"。当描述轻微瑕疵时用 "subtle" 而非 "micro-detail" 等建模术语

## 四、真人乡村田园场景空间元素

当代中国乡村特有的场景元素及其在 Seedance 2.0 视频中的视觉叙事功能：

- **院落/堂屋大门/门窗** — 乡村最核心的构图与光影道具。门即光源与视线入口——门光的方向和色温决定堂屋与院内的光影逻辑。堂屋大门的对联门神、半开的木门、贴着窗花的木窗，制造"内与外、家与土地"的多层空间。Seedance 2.0 中重点描述"daylight entering through the courtyard door at specific angle"以帮助模型理解光源方向
- **田埂/土路/稻田/远山** — 室外场景的空间骨架。空旷的田埂 = 辽阔与孤独，起伏的稻浪 = 时节与生机，远山轮廓 = 山那边的世界。Seedance 2.0 中田野场景必须明确"golden rice waves in afternoon light"或"wet mud road reflecting sky after rain"等可被模型执行的光学描述
- **灶火/煤油灯/白炽灯/村口路灯** — 乡村世界的核心光源叙事载体。灶火暖橙（2000-2600K）= 家的温度与炊烟；煤油灯极暖跳动（1800-2200K）= 老屋的夜与怀旧；白炽灯泡暖黄（2700-3000K）= 堂屋与厢房的夜；村口路灯（3000-4000K）= 归途的标识与等候
- **堂屋/灶间/厢房/院坝/土砖老屋** — 乡村建筑的五种叙事容器。堂屋的八仙桌与条案 = 家族中心；灶间的柴火灶与油烟 = 烟火核心；厢房的花被子与木床 = 私密温馨；院坝的晾晒与农具 = 日常劳作；土砖老屋的夯土墙 = 几代人的沧桑记忆
- **段落间用场景空镜过渡** — 空镜为情绪缓冲，不用硬切。同一空间在不同时段/天气的空镜（如晨雾稻田→黄昏稻田）可暗示时间流逝。Seedance 2.0 中空镜需指定光源逻辑，空镜也有情绪
- **转折点用视觉而非台词** — 光影突变（云遮住太阳→院落突然变暗）、景别跳切（中景→大特写）、空间转场（堂屋→门外田埂）、焦点漂移——由摄影机完成叙事

## 五、真人乡村田园配乐与环境音

### 5.1 配乐乐器选择

真人乡村田园配乐以原声民族乐器为主、电子元素克制为辅，追求"不抢戏的乡土存在感"：

- **竹笛/梆笛** — 田园辽阔、晨雾田垄、稻浪起伏段落的核心乐器。悠长的气息线条自带"风吹过田野"的辽阔
- **古筝/古琴** — 内敛克制、怀旧思念、老屋幽光段落的底色。单音留白比密集旋律更有力量——慎用，避免滑向古风
- **二胡** — 沧桑思念、留守独白、归途离别的情绪载体。如泣如诉的弓弦线条，但克制使用，不滥用悲情
- **木吉他** — 返乡青年、现代田园日常、清新治愈段落的底色。指弹或轻扫和弦，自带"午后院落"的温度
- **钢琴** — 温情细腻、家庭团圆、孩童段落的核心乐器。单音重复或稀疏和弦，音符之间的沉默同样重要
- **口琴/手风琴** — 乡镇集市、赶集热闹、年节烟火段落的点睛乐器。局部出现即叙事信号
- **弦乐组** — 情感积蓄与释放段落的推动力。中低音区铺底，高音区用于情绪高点的轻触即收
- **乡土打击（木鱼/梆子/锣鼓）** — 年节、庙会、集市、丰收庆典段落的节奏点。仅在需要乡土节庆感时出现
- **电子氛围 Pad** — 悬疑、时间流逝、远山朦胧段落的低频铺底。作为"可以被忽略但拿走就不对"的底层存在
- 慎用：大型管弦乐团全奏、重金属失真、高能电子舞曲、过度中国风编曲——这些会让乡村田园变成"配乐在演戏"或滑向古风

### 5.2 配乐组合策略

| 情绪阶段 | 乐器组合 |
|---|---|
| 平稳开场/田园晨景 | 竹笛独奏 或 木吉他 + 极轻电子Pad |
| 温情日常/灶间烟火 | 钢琴 + 木吉他 + 轻弦乐铺底 |
| 返乡清新/田园治愈 | 木吉他 + 竹笛点缀 + 钢琴 |
| 沧桑思念/留守独白 | 二胡独奏 或 二胡 + 钢琴稀疏单音 |
| 丰收喜悦/年节庆典 | 竹笛 + 木吉他 + 乡土打击轻点 + 弦乐 |
| 情绪转折/命运时刻 | 弦乐组渐强 + 钢琴收束 |
| 集市热闹/赶集烟火 | 手风琴/口琴 + 木吉他 + 乡土打击 |
| 怀旧幽光/老屋记忆 | 古琴/古筝稀疏单音 + 弦乐低音铺底（克制，避免古风） |
| 结尾/余韵归途 | 竹笛单音渐疏 → 环境音独奏 |

### 5.3 真人乡村田园环境音

> 环境音是真人乡村田园场景的"听觉材质"，决定了土地的沉浸感。每场戏标注 1-2 个核心环境音。

**核心环境音层次：**
- **院落/室内环境音**：柴火灶噼啪/风箱呼哧/铁锅翻炒/母鸡咯咯/狗吠远/堂屋挂钟走动/风吹门帘/水缸舀水/八仙桌上碗筷轻碰
- **田野/室外环境音**：稻浪沙沙/蛙鸣/蝉鸣/布谷鸟叫/风吹竹林/远处拖拉机突突/溪水潺潺/锄头入土的闷响/扁担吱呀
- **过渡环境音**：村小上下课铃声/村口广播/集市人声嘈杂/拖拉机/摩托进村/远处鞭炮
- **静默也是一种环境音**：深夜老屋只有挂钟的滴答与灶膛余烬的偶尔爆响、雪夜田野连风都安静——这种"声音的缺失"本身就是叙事

音效设计哲学：
- 环境音不是贴上去的，是土地与场景自带的声音
- 关键时刻"抽掉"环境音比"加入"特效更能制造情绪冲击
- 环境音的变化可以暗示空间转换——从嘈杂集市走进安静院落，声音突然"变干净了"

### 6.5 空间逻辑具象化（真人乡村田园专属）

**空间坐标定义标准：**
- **水平位置**：画面左侧三分之一处 / 画面中央 / 画面右侧，或相对于场景固定物（"距堂屋大门1米"）
- **纵深位置**：前景（距镜头1-2米）/ 中景（距镜头3-5米）/ 背景 / 远山远景
- **人物之间**：相对距离与朝向（"A与B在八仙桌两侧面对面，相距约1.2米，A略偏左，B略偏右"）
- **人与空间关系**：相对于场景固定物的距离和方向

**站位衔接示例：**

## 七、全局叙事约束

- **空镜即情绪** — 每个叙事段落之间建议用场景空镜（同一空间在不同光线下）做情绪缓冲。空镜不是"没东西拍"，是"让观众喘口气"
- **光的连续性与变化** — 同一空间内在日间段落的天光角度应随时间连续变化。如果一场对话戏跨越了半小时，门窗光的入射位置应该移动了一些——Seedance 2.0 能理解这种"合理的不完全一致"
- **人物光源一致性** — 同一镜头内所有人物的面部光源方向必须统一。如果主光从左侧来，所有人的左脸都应该是亮面
- **避免"过度导演"** — 真人乡村田园追求"被摄影机捕获的乡土生活"，不是"被编剧安排的情节"。允许画面中有不可控的日常细节（风吹动晾晒的作物、一只踱步的母鸡、远处传来的拖拉机声）
- **静默的价值** — 不必每个镜头都填满动作和台词。一个3秒的静止特写——人物只是呼吸、眨眼、望向远山——往往比任何台词都更有力
