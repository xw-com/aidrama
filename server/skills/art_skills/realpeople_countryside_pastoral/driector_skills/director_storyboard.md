# 分镜提示词 · 真人乡村田园 · 风格专属技法

---

## 适用范围

本 Skill 专用于**真人乡村田园**风格的分镜提示词生成，适配乡村剧情、返乡成长、乡土悬疑、丰收喜悦、留守温情、田园治愈等真人实拍影视题材的分镜创作。

---

## 一、摄影机前的情绪——面孔、眼神、微表情

> 真人乡村田园的情绪不来自"义体光效"或"渲染参数"，而来自真人演员在摄影机前的微表情。以下映射面向摄影机捕捉真实乡野人物的方式。

| 情绪输入 | 面容描述 | 眼神描述 | 微表情补充 |
|---|---|---|---|
| 憨厚 / 朴实 | 神情放松，面部线条柔和自然 | 眼神温润直率，不躲闪不游移 | 嘴角自然微扬露憨笑，眼尾笑纹，可能擦汗 |
| 沧桑 / 隐忍 | 眉眼低垂，面部肌肉松弛有岁月痕 | 目光深沉内敛，望向远处田地或地面 | 嘴角自然下沉，法令纹深刻，表情克制 |
| 爽朗 / 泼辣 | 眉眼舒展，面部红润有光 | 眼神明亮直接，笑起来有光 | 笑时露齿响亮，可能边说边择菜/比划 |
| 羞涩 / 腼腆 | 面颊微红，面部微低 | 目光游移下垂，偶尔抬眼一瞥 | 嘴角抿住想笑又忍住，可能拨弄衣角 |
| 思念 / 留守 | 眉眼低垂，面部松弛倦怠 | 目光放远失焦，望向村口或远山 | 表情平静下的怅然，可能摩挲手里旧物 |
| 喜悦 / 丰收 | 眼角笑纹深刻，面部明亮 | 眼神发亮有光，眼角有笑意 | 嘴角上扬露齿，面颊红润，擦汗带笑 |
| 疲惫 / 劳作后 | 眼窝微陷，面部松弛有汗痕 | 目光朦胧，眼皮微沉 | 眉眼低垂，用搭肩毛巾擦汗，呼吸起伏 |
| 期待 / 返乡 | 眉眼微扬，面部有克制的小幅度活动 | 眼神发亮，瞳孔有光 | 嘴角微微上扬，压抑的笑意，可能踮脚张望 |
| 决绝 / 离乡 | 面部线条清晰，下颌微抬 | 眼神笔直向前，不回避 | 下巴微收，喉结微动，表情果敢克制 |
| 警觉 / 乡野悬疑 | 面部线条微微绷紧 | 眼神锐利扫视，注视有力 | 身体语言防御，可能手持煤油灯/手电 |

## 二、摄影机前的光——光源逻辑与氛围

### 2.1 自然光时刻

| 时刻 | 光源行为 | 色温与色调 | 空间氛围 |
|---|---|---|---|
| 清晨 | 低角度暖白晨光，穿过薄雾与晨炊；田间稻浪沾露；院落刚被照亮 | 3500-4500K暖白，空气微冷湿润 | 静谧未醒、晨雾田垄、一切尚未开始 |
| 上午 | 天光升高，冷白清澈，阴影锐利；作物与土墙材质清晰；院落与田野明亮 | 5000-5500K中性偏冷 | 秩序建立、日常劳作、高效清晰 |
| 正午 | 顶光或近乎顶光，阴影短而浓重——乡野烈日下需谨慎使用 | 5500-6500K冷调 | 暂停感、午歇空隙、烈日下的停顿 |
| 午后 | 日光偏西，暖调渐强，斜光穿过屋檐/竹林/窗形成长阴影和光斑 | 4000-5000K渐暖 | 慵懒、时间变慢、午后光斑的最长一段 |
| 金色时刻 | 极低角度暖金漫射，长阴影到极致，稻浪与瓦面镀上金边 | 2600-3200K极暖 | 转瞬即逝的珍贵、丰收与归家段落的唯一光源 |
| 蓝调时刻 | 太阳沉入远山后，天空深蓝紫，自然光极暗极冷，村口路灯与窗光刚刚亮起 | 8000-10000K天空+暖点人工光 | 过渡、诗意、白天已尽夜晚尚未接管 |
| 深夜 | 仅靠人工光源——灶火余烬、煤油灯、白炽灯泡、村口路灯。大部分区域沉入暗部 | 暖光源1800-3000K / 冷环境6000K+ | 孤独或私密、世界安静了 |

### 2.2 情绪光影

| 情绪基调 | 光线配方 | 摄影约束 |
|---|---|---|
| 田园日常 | 院落天光漫射（5000-5500K），屋檐投下整齐阴影，光斑落土院 | 光比适中约1:2，保留作物与土墙质感 |
| 灶间烟火 | 柴火灶/煤油灯暖调主光（2200-2600K），蒸汽炊烟升腾，暗部保留细节 | 暖调包裹，单点暖光源为主，人脸被火光映亮 |
| 黄昏丰收 | 金色时刻低角度暖光（2600-3200K），穿过屋檐与树梢，稻浪镀金 | 暖金主导，长阴影拉过田埂，光比约1:4 |
| 雨后沉思 | 雨后湿泥路反射天光（冷基底6000K环境+暖4500K光斑），作物挂水珠 | 冷暖共存，低饱和，湿润清透 |
| 老屋怀旧 | 天井/高窗单一束天光（5500K冷白），大范围暗部，尘埃游走 | 大光比1:8，单点冷光沉入暖暗，沧桑感 |
| 暮色离别 | 蓝调天空（8000K深蓝紫）+ 村口暖路灯（3000K）+ 远山剪影 | 冷暖告别，光比约1:5冷主暖点 |
| 乡野悬疑 | 硬光侧打（冷白天光5000K或煤油灯暖2000K），深阴影，冷暖对冲 | 大光比1:8以上，硬光勾勒轮廓，暗部压深但有细节 |
| 童真治愈 | 充足自然漫射（5000-5500K），天空光+地面反射补光，通透清新 | 低反差高调，通透清新，浅景深柔化背景 |

## 四、摄影机语法——镜头选择与运动

### 4.1 焦段选择

| 焦段 | 叙事性格 | 适用场景 |
|---|---|---|
| 24-28mm广角 | 土地包围人物，田野辽阔，个体在乡土中的渺小与扎根 | 乡村空镜、稻田全景、村庄与远山、归途俯瞰 |
| 35mm小广角 | 主观视点，身临其境的纪实感，人与土地共存 | 院落跟随、田间劳作、灶间对话、村道行走 |
| 50mm标准 | 人眼等价，客观中立的注视，最诚实的镜头 | 人物肖像、双人对话、情感凝视 |
| 85mm中长焦 | 压缩空间，拉近情感距离，背景虚化突出人物 | 特写、田埂上远远望见、村口老树下凝视 |
| 135mm+长焦 | 将人物从田野中剥离，极端的注视或窥视 | 隔着院墙的注视、远眺归途、叙事的距离感 |

### 4.2 景别选择

| 景别 | 取景范围 | 叙事功能 |
|---|---|---|
| 大特写 | 眼睛/嘴唇/茧手/作物细节 | 情绪爆发点、关键信息揭示、感官聚焦 |
| 近景 | 头顶至胸部以上 | 人物情感、对话反应、面部晒痕与微表情 |
| 中近景 | 头顶至腰部 | 人物互动、劳作手势（择菜/盛饭/挥锄） |
| 中景 | 头顶至膝盖上下 | 人物与院落/田地的初级关系、多人同框 |
| 全景 | 人物全身+部分环境 | 人物在土地中的位置、劳作路线 |
| 大全景/空镜 | 空间全貌，人物极小或无人物 | 空间叙事、情绪缓冲、隐喻留白 |

### 4.3 摄影机运动

| 运动方式 | 视觉心理 | 使用场景 |
|---|---|---|
| 固定 | 冷静观察，让土地与时间自己说话 | 日常场景、院落对话、炊烟空镜留白 |
| 手持微晃 | 在场感，呼吸感，主观介入 | 情绪波动、田间行走、灶间亲密跟随 |
| 稳定器流动 | 优雅的乡野漫游，诗意 | 重要场景过渡、人物登场、村道与田野展示 |
| 缓推 | 注意力逐渐聚焦、情绪趋近 | 对话升温、真相逼近、情感推进 |
| 缓拉 | 拉开距离、揭示全貌、情绪抽离 | 离别、章节收束、土地展示 |
| 跟拍 | 与人物同行、主观陪同 | 村道行走、田间跟随、归途 |
| 摇镜 | 视线转移、空间关系交代 | 人物视线引导、院落到田地的关系 |

## 五、固定风格锚定词

**摄影锚定（必选）：**

真人实拍摄影，真人电影剧照，当代中国乡村田园，电影级摄影，自然天光与灶火灯火调度，真实色彩科学

**人物质感（含人物镜头时必选）：**

真人写实摄影质感，真实皮肤晒痕毛孔可见，茧手与劳作痕迹，不磨皮不硅胶脸，发丝自然质感有碎发，服饰棉麻粗织面料有穿着磨损褶皱，自然微表情，真实肢体语言

**场景质感（含场景镜头时必选）：**

真人实拍乡村场景摄影，真实土墙青砖瓦面与岁月痕迹（裂纹/苔痕/杂草/磨痕），光源方向明确可追溯，大气透视与炊烟自然，非影视城样板非效果图

**参考图一致性锚定（参考图模式必选）：**

保持人物造型、面容、发型、服饰与参考图完全一致，保持场景风格与参考图一致，保持光影色彩基调统一，所有镜头呈现为同一人物的连续摄影记录

**风格收尾（固定）：**

真人写实摄影，当代中国乡村田园电影质感，电影级摄影画面，非3D非渲染非CG

**画质锁定词：**

模式A（中文）——默认：
真人摄影高清画质，电影级画面质感，画面无字幕、无水印、无标题叠字、无UI元素

模式A（中文）——画内文字场景（画面中含对联/标语/招牌/课本/奖状等道具文字时）：

## 六、美学禁止项

以下词汇/风格不得出现于输出提示词中：

- ❌ 3D渲染 / 3D建模 / CG / UE引擎 / Blender / PBR材质 / 次世代建模 / 体积光 / 环境光遮蔽 / 光线追踪
- ❌ 2D手绘 / 插画 / 动画 / 二次元 / 漫画 / Q版 / 低多边形
- ❌ 写实摄影（英文禁止 photorealistic / realistic photography——真人乡村田园是"真人实拍摄影"live-action cinematic photography，不是"拟真渲染"）
- ❌ 过度磨皮 / 塑料假面 / 零毛孔 / 硅胶脸 / 蜡像感 / AI感平滑
- ❌ 古风 / 古装 / 汉服 / 仙侠 / 武侠 / 宫廷 / 民国 / 赛博朋克 / 科幻 / 高楼都市 / 西方奇幻 / 中世纪 / 日式田园 / 欧式农庄
- ❌ 人体结构错误 / 肢体畸形 / 面部崩坏 / 比例失调
- ❌ 高饱和荧光色 / 霓虹溢色 / 廉价滤镜感
- ❌ 非中国当代乡村的架空场景 / 无中文标识的 generic countryside
