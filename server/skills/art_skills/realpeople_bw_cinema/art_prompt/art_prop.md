# 道具图像生成 · 黑白电影约束手册

---

## 一、道具设计原则

1. **功能可读** - 道具用途一目了然，造型服务于功能与悬念
2. **质感极致** - 材质纹理必须清晰可辨（金属/皮革/毛呢/玻璃/纸张），黑白影调下靠反光与灰阶塑造立体感
3. **年代一致** - 所有道具必须符合 40-50 年代黑色电影世界观，禁止现代元素
4. **尺度明确** - 通过参照物或标注暗示道具真实尺寸
5. **纯道具独立展示** - 画面中只能出现道具本身，严禁出现任何人物、手部、肢体，道具不可处于被持有/佩戴/握持状态，必须以静物陈列方式独立呈现

## 三、多角度设定图规范

### 视图定义

| 位置 | 视图 | 角度 | 要求 | 提示词 |
|---|---|---|---|---|
| 左上 | 正面图 | 正面 0° | 道具完整正面形态 | front view |
| 右上 | 侧面图 | 侧面 90° | 厚度/轮廓/结构清晰 | side view |
| 左下 | 背面图 | 背面 180° | 道具背部结构/装饰 | back view |
| 右下 | 细节特写 | 局部放大 | 材质纹理/工艺细节 | detail closeup |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 同一画面四宫格（2×2），上下左右四视角 |
| 背景 | 纯净画布灰 #DCDCDC，从上至下轻微明度渐变 |
| 光线 | 单源侧光+柔补光，无杂乱阴影，轻微暗角 |
| 比例 | 每格道具占格内主体 70%+ |
| 投影 | 允许锐利自然的地面投影（noir 式有形阴影） |
| 画面比例 | 建议 1:1 |

## 六、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须指定「纯净画布灰背景」 |
| R2 | 必须明确道具材质与年代工艺 |
| R3 | 道具造型必须符合 40-50 年代黑色电影世界观 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 复杂场景背景 |
| X2 | 道具与人物同画面（本环节为纯道具图） |
| X3 | 出现任何人物形象，包括全身、半身、局部（手、手指、手臂等肢体） |
| X4 | 道具处于被持有、握持、佩戴、使用中的状态 |
| X5 | 现代物品/现代工业设计（智能手机、电子表、塑料打火机、现代枪械造型） |
