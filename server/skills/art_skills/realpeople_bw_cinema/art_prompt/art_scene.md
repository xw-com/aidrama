# 场景图生成 · 黑白电影约束手册

---

## 一、场景美学原则

1. **光影即叙事** - 场景承载宿命与悬念，明暗分割就是剧作结构；光与影各占一半的 noir 构图优先
2. **层次纵深** - 所有场景必须具备前/中/后景，且以灰阶明暗区分层次（前暗后亮或前亮后暗），杜绝扁平
3. **质感至上** - 水泥/湿沥青/砖墙/百叶窗/毛玻璃/烟雾等材质必须超清晰，反差分明
4. **黑白为锚** - 一切画面以经典黑白电影摄影为标准，拒绝彩色与数码锐利；追求单源硬光、高反差明暗、百叶窗光条、剪影轮廓、雨夜反光与银盐颗粒

## 三、室内场景

### 空间规范

| 维度 | 约束 | 提示词 |
|---|---|---|
| 风格 | 百叶窗办公室/noir 侦探社/爵士酒吧/警局审讯室/酒店套房/法庭 | 40-50 年代{场景}风格 |
| 材质 | 水泥/砖墙/木百叶/毛玻璃/皮革/黄铜/大理石 | 百叶窗、毛玻璃门、黄铜配件 |
| 色调 | 炭黑+珍珠灰高反差分布，深灰铺底 | 高反差黑白、明暗分割 |
| 纵深 | 前/中/后景以明暗区分层次 | 前景阴影、中景主体、远景亮部 |
| 质感 | 烟雾缭绕/桌面划痕/皮革磨光/玻璃指纹可辨 | 烟雾层次、使用痕迹 |
| 光照 | 单源硬光（台灯/百叶窗光条/顶光），光束穿尘，阴影边界锐利 | 单源硬光、光条切割、顶光压顶 |
| 镜头感 | 深景深（noir 偏好纵深清晰）、边缘暗角、银盐颗粒 | deep depth of field、vignette、film grain |
| 瑕疵感 | 烟灰缸满溢、桌面污渍、墙面水渍 | 烟灰缸、水渍痕迹、颓败细节 |

## 五、主视图规范

### 视图定义

> 单画面主视图，从场景中最具代表性的角度拍摄，承载空间叙事与构图重心。

| 项目 | 约束 | 提示词 |
|---|---|---|
| 视角 | 宿命感构图优先：低机位仰拍/高机位俯瞰/纵深灭点线 | hero shot、dramatic angle |
| 视点高度 | 默认人眼平视高度，重点场景强烈建议低仰/高俯 | low angle / high angle |
| 构图 | 明暗各半或光条分割画面，前/中/后景灰阶分离 | chiaroscuro composition |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 单画面（非拼图、非多视图、非分屏） |
| 人物 | **严禁出现任何人物、人影、人体轮廓** |
| 一致性 | 风格/灰阶/光影方向统一 |
| 光线 | 单一光源逻辑，光影方向一致，阴影边界清晰 |
| 画面比例 | 默认 16:9（或按调用方设定） |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 场景必须有「前中后景层次」且以明暗灰阶区分 |
| R2 | 室外必须包含「烟雾/雨雾空气透视」 |
| R3 | 场景图必须为「单画面主视图」，不得拼接多视图/分屏/网格 |
| R4 | 构图须能代表场景主体并体现宿命感光影结构 |
| R5 | 场景图中**严禁出现任何人物** |
| R6 | 必须包含黑白电影关键词（black and white / monochrome / film noir 至少一项） |
| R7 | 必须包含高反差光影特征（chiaroscuro / 单源硬光 / 光条 / 剪影 至少一项） |
| R8 | 材质必须带有年代使用痕迹与颓败感，禁止崭新无瑕的"数码感" |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 背景纯白/纯黑无场景（除非刻意的剪影构图） |
| X2 | 任何彩色元素、彩色霓虹、彩色滤镜（画面必须纯黑白） |
| X3 | 场景无纵深/无层次 |
| X4 | 现代都市元素（玻璃幕墙/LED 屏/现代车辆/现代路牌） |
| X5 | 出现任何人物、人影、人体剪影或人体轮廓 |
| X6 | 画面被拼接成多视图/网格/分屏布局 |
| X7 | 数码锐利/HDR/CG 渲染质感（禁用 3D render、CGI、digital sharpening、vivid colors 等词） |
| X8 | 光照均匀平坦、阴影模糊无边界（noir 阴影必须锐利有形） |
| X9 | 现代光源（LED 冷白光、智能屏光）入镜 |
