# 人物基础形象生成 · 黑白电影约束手册

---

## 一、基础形象原则

1. **面容即灵魂** - 五官是角色唯一锚点，影调层次级细腻渲染
2. **角色为本** - 基础着装由角色描述（身份/职业/性别/场景）决定其常规着装；后续特定服化为叠加层
3. **四视图一致** - 面容/体型/发型/基础服装跨视图高度统一
4. **影调塑形** - 以真实黑白电影摄影为锚点，五官立体感由光影灰阶塑造，皮肤保留银盐颗粒质感
5. **好莱坞气质** - 妆发造型默认锚定 40-50 年代经典好莱坞审美，杜绝现代感

---

## 二、面容约束

> 不再固定五官特征参数，由角色描述（性别/年龄/性格/气质）驱动 AI 自由生成五官，保证人物间外观差异化。黑白影像下面部立体感依赖影调层次而非色彩。

### 通用要求

| 项目 | 约束 |
|---|---|
| 五官 | 由角色描述自然推导，不预设脸型/眼型/眉型/鼻型/唇型 |
| 风格底色 | 黑白电影摄影、film noir、影调层次塑形、银盐颗粒、单源硬光或柔光 |
| 气质 | 必须从角色描述提炼整体气质关键词（如冷峻/优雅/世故/坚毅），并写入提示词 |
| 表情 | 中性微表情，符合角色气质，带 noir 式的克制与城府 |

## 六、基础服装约束

> 基础服装由角色描述（身份/职业/性别/场景）决定其最自然的常规着装，作为该角色「日常默认态」；正式服饰/特殊衍生在服化衍生环节叠加。**禁止内衣打底**。

### 着装选择原则

| 角色身份 | 默认着装方向 |
|---|---|
| 私家侦探/警探 | 风衣/呢子大衣+礼帽+西装三件套 |
| 黑帮/毒枭爪牙 | 宽驳头条纹西装/皮大衣+礼帽 |
| 歌女/夜总会歌手 | 缎面晚礼服/亮片裙+长手套+披肩 |
| 警务/公务人员 | 制服/素色西装+软毡帽 |
| 上流淑女/名媛 | 垫肩收腰套裙/裙装+小帽/珍珠配饰 |
| 记者/打字员 | 衬衫+铅笔裙/马甲背心 |
| 角色描述未明确 | 40-50 年代常服，深灰/中灰/珍珠灰低对比灰阶 |

### 着装统一规则

- 服装风格须与 40-50 年代好莱坞黑白摄影美学一致（呢料、缎面、丝绸、垫肩剪裁）
- 灰阶分布明确：浅色服饰承接高光、深色服饰沉入阴影，避免与背景灰阶同层级粘连
- 四视图服装款式完全一致
- 基础服装是「日常默认态」，焦点仍在面容与体态
- 严禁内衣/暴露/性化打底
