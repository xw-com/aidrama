# 黑白电影风格说明

本风格专为"黑白电影"题材打造，所有美术提示词、规范和生成内容均严格限定于：

- **黑白影像语言**：以黑白单色（monochrome）摄影为基准，画面呈现丰富的黑白灰阶层次、film noir 式高反差明暗（chiaroscuro）、百叶窗光影、雨夜街道倒影与烟雾缭绕等经典黑色电影视觉符号。
- **真人写实**：所有角色、场景、道具均以真人黑白电影摄影为标准，强调影调层次、轮廓光、皮肤灰阶质感与老电影胶片的银盐颗粒。
- **40-50 年代好莱坞氛围**：妆发服饰、场景空间、道具器物均锚定 40-50 年代经典好莱坞与黑色电影语境，杜绝现代元素。
- **宿命感叙事**：适合展现悬疑、罪案、宿命纠缠、乱世情缘类故事，强调光影即命运的电影语言。

## 适用范围

- 黑白电影题材的AI美术生成（角色、场景、道具、分镜等）
- 需要高反差黑白光影、noir 氛围、经典好莱坞质感的视觉创作

## 严禁内容

- 卡通、动漫、插画、二次元风格
- 任何彩色元素、彩色滤镜、现代数码单反质感
- 现代智能设备、现代服饰发型
- 暗示性、暴露、透视等不适宜内容

## 风格体验

在本风格下，您将体验到：

- 角色面容以影调层次塑形，40-50 年代好莱坞式妆发与正装造型，轮廓光勾勒侧影
- 场景空间笼罩高反差明暗分割，百叶窗光条、雨夜湿街倒影、烟雾与顶光切割画面
- 道具、左轮手枪、礼帽风衣、打字机、怀表香烟等均为年代造型，金属铬银反光锐利
- 分镜与视频均以黑白电影摄影为基础，强调宿命感构图与光影叙事表达

---

本风格仅适用于"黑白电影"相关项目。如需其他风格（如古风、插画、动漫、现代彩色等），请勿使用本套提示词。
