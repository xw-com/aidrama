# 黑白电影约束 · 黑白电影 · 技法参考

---

## 一、灰阶色调体系与画面基调

- **灰阶基底** — 全片以中灰（C5）、深灰（C6）、炭黑（C4）为基底灰阶，整体严格黑白单色（monochrome），无任何彩色信息与色偏滤镜，呈现 40-50 年代经典黑白电影的银盐质感。全片保持「黑占画面、白做人眼」：大面积深灰/炭黑铺底，银白（C1）/浅灰肤（C2）落在情绪焦点
- **chiaroscuro 明暗叙事** — 高反差明暗是本风格核心视觉语言，明暗分割即善恶/宿命/真相的视觉信号，而非随意打光
- **灰阶先行原则** — 段落规划需先绑定情绪场景（周旋/暧昧/罪案/对峙/诀别/真相等），再确定主灰阶+辅灰阶与光影方案，避免"情绪对但影调不对"
- **禁用色域** — 任何彩色元素、彩色滤镜、局部调色、泛黄/泛褐复古色调均与本风格不兼容

---

## 二、光影方案体系

- **光影即命运** — 6 套光影方案对应不同叙事段落，导演规划阶段应在段落层面确定光影基调方向，而非逐镜指定
- **光源角度** — 默认单源硬光 + 30-45°斜侧，模拟老电影聚光灯效果；特殊场景用顶光/百叶窗光条/逆光剪影

| 情绪段落 | 光影方向 | 灰阶倾向 | 适用阶段 |
|---|---|---|---|
| 周旋/日常 | A·中光比侧光 | 中灰底 + 轮廓光柔和 | 铺垫段 |
| 暧昧/私语 | B·面部渐亮 | 浅灰肤 + 背景沉黑 | 升温段 |
| 罪案/冷峻 | C·硬光强对比 | 沥青灰 + 铬银反光 | 罪案段 |
| 对峙/审问 | D·顶光/百叶窗条 | 深灰 + 银白切割面部 | 对峙段 |
| 诀别/宿命 | E·低调打光 | 炭黑 + 银白落眼 | 低谷段 |
| 真相/高潮 | F·强对比白闪 | 银白过曝 + 炭黑底 | 高潮段 |

- **明暗分配** — 深灰/炭黑基调贯穿全片，银白/浅灰肤作为情绪焦点点缀；白闪（F）仅在真相揭露等高潮瞬间短暂使用
- **氛围方向映射** — 每场戏的氛围方向应能映射到上述光影方案（A-F）的某一方向，确保视觉一致性

## 三、质感方向

- **银盐颗粒感** — 黑白电影的核心：可见银盐颗粒、老电影胶片质感、非数码锐利
- **灰阶层次丰富** — 从炭黑到银白至少 5 级可辨过渡，忌二值化非黑即白
- **轮廓光分离** — 人物须有轮廓光将发丝/肩线从深灰背景中分离，避免糊成一团
- **非洁净感与年代感** — 场景带烟雾、雨雾、湿街反光、使用痕迹；人物妆发服饰锚定 40-50 年代好莱坞，禁止现代元素

---

## 四、场景空间元素

黑白电影特有的场景元素及其视觉叙事功能：

- **百叶窗/门框/走廊** — 天然的明暗切割道具，百叶窗光条切割面部 = 道德灰色/被困，门框走廊纵深 = 未知与宿命
- **雨夜街道/湿地反光** — noir 标志性场景，景即情：雨夜独行 = 孤影、湿地铬银反光 = 双重世界、长影拉伸 = 不祥
- **烟雾/蒸汽/雾气** — 空气介质与明暗塑造工具，烟雾漫射 = 密谋/迷离、井盖蒸汽 = 阴冷、晨雾 = 朦胧回忆
- **台灯/路灯/顶光** — 单源点光载体，台灯点光 = 私语、路灯顶光 = 孤立审视、审讯顶光 = 压迫
- **爵士酒吧/码头/公寓** — noir 经典空间，景即情：酒吧烟雾 = 周旋、码头铁皮漏光 = 亡命、老公寓百叶窗 = 私密
- **段落间用场景空镜过渡** — 本风格有丰富的场景资产（不同时段/天气/室内外变体），段落衔接建议用场景空镜做情绪缓冲（如雨夜街景→黎明湿街），不要硬切
- **转折点用视觉而非台词** — 优先使用画面手段（白闪转场/光影突变/景别跳切）而非依赖对白解释

## 五、配乐与环境音

黑白电影世界观下的声音元素约束：

### 乐器选择

- **钢琴** — 核心：独奏钢琴铺底，忧郁克制的 noir 主色调
- **萨克斯** — 爵士酒吧/暧昧段落的标志音色，慵懒沙哑
- **低音提琴** — 紧张/罪案段落的脉冲底色，拨弦制造不安
- **小号/铜管** — 宿命/高潮段落的点睛色彩（克制使用）

### 乐器组合策略

| 情绪阶段 | 乐器组合 |
|---|---|
| 周旋/铺垫 | 钢琴 + 低音提琴拨弦 |
| 暧昧/私语 | 萨克斯 + 钢琴 |
| 罪案/冷峻 | 低音提琴 + 钢琴不协和音 |
| 对峙/审问 | 低音提琴脉冲 + 铜管短促 |
| 诀别/宿命 | 钢琴独奏 |
| 真相/高潮 | 铜管 + 弦乐骤强 |

### 典型环境音

- **街道环境音** — 雨打沥青/远处车驶过/电车叮当/霓虹招牌嗡鸣（无彩色）/脚步回响
- **室内环境音** — 打火机咔嗒/烟灰掉落/酒杯轻碰/百叶窗拉绳/打字机敲击/座钟摆动
- **酒吧环境音** — 爵士背景乐/杯盏人声/钢琴角落/冰块撞击
- **每场戏标注 1-2 个核心环境音**，帮助后续音效设计
- **留白即张力** — 关键瞬间（对峙沉默、真相前夜、诀别）优先去掉配乐只留环境音（雨声、脚步、打火机），寂静比满配更震撼
- **避免满配** — 全片配乐覆盖率建议不超过 45%。留白段落的"无声"与配乐段落形成呼吸感，突出宿命张力
