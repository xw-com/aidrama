## 二、全局色彩盘（灰阶层级体系，风格基线，不是硬锁）

> 目标：统一审美而非限制创作。黑白电影不存在彩色，色彩盘以「灰阶层级」表达画面明暗结构；除「硬约束灰阶」外，其余层级默认优先使用，可在合理范围内偏移。

### 色彩使用层级

| 层级 | 约束强度 | 说明 |
|---|---|---|
| L1 硬约束 | 高 | 仅锁定角色识别核心：肤色灰阶映射、发色灰阶、主服明度的审美方向 |
| L2 软约束 | 中 | 场景明暗结构、服饰灰阶、道具反光优先参考灰阶盘，可按镜头与剧情微调 |
| L3 例外机制 | 低 | 梦境/闪回/高潮戏可临时突破常规光比（如全剪影、过曝白闪），但需保留黑白单色逻辑 |

| 序号 | 灰阶名 | 色值 | 用途 |
|---|---|---|---|
| C1 | 银白 | #EFEFEF | 高光、白衬衫、雾气、窗纸 |
| C2 | 浅灰肤 | #B8B2AC | 女性/男性肤色灰阶基准（中浅灰映射） |
| C3 | 珍珠灰 | #D6D2CC | 女性浅色服饰、蕾丝、丝绸 |
| C4 | 炭黑 | #161513 | 发色、眼瞳、燕尾服、深夜部 |
| C5 | 中灰 | #8C8884 | 街道水泥、毛呢西装、墙面 |
| C6 | 深灰 | #3C3936 | 阴影部、风衣大衣、夜色 |
| C7 | 烟灰 | #A6A19B | 烟雾、雨雾、空气透视 |

| C10 | 沥青灰 | #262523 | 湿路面、影子、夜幕底色 |

### 硬约束灰阶（默认锁定）

| 灰阶项 | 对应灰阶 | 规则 |
|---|---|---|
| 肤色基准 | C2 浅灰肤 | 默认中浅灰映射，允许小幅明度微调；影调层次塑形，严禁死白/死黑糊脸 |
| 发色/瞳色基准 | C4 炭黑 | 默认优先，允许深灰/炭黑轻微偏移，配轮廓光分离发丝与背景 |

### 软约束灰阶（推荐优先）

> C1/C3/C5/C6/C7/C8/C10 为推荐灰阶域，用于高光、服饰、阴影、烟雾、金属、夜色等。可根据镜头氛围做相邻明度调整。

### 情绪色盘（导演对齐版 · 灰阶明暗映射）

| 情绪场景 | 主灰阶 | 辅灰阶 | 光效与对比建议 | 画面关键词 |
|---|---|---|---|---|
| 初遇试探（日常） | C5 中灰 | C2 浅灰肤 + C1 银白 | 中光比，轮廓光柔和，阴影克制 | 周旋、克制、暗流 |
| 暧昧靠近（升温） | C2 浅灰肤 | C1 银白 + C6 深灰 | 面部主光渐亮，背景渐暗，光比拉大 | 亲密、私语、微光 |
| 罪案现场（冷峻） | C10 沥青灰 | C6 深灰 + C8 铬银 | 硬光强对比，影子长而利落 | 阴冷、证据、谜团 |
| 对峙审问（高压） | C6 深灰 | C4 炭黑 + C1 银白 | 顶光或百叶窗光条切割面部 | 压迫、明暗分割 |
| 亡命追逐（紧张） | C10 沥青灰 | C7 烟灰 + C1 银白 | 逆光剪影+湿街反光，动态模糊克制 | 夜奔、雨夜、倒影 |
| 诀别宿命（低谷） | C4 炭黑 | C6 深灰 + C10 沥青灰 | 低调打光，面部半隐于阴影 | 宿命、诀别、沉默 |
| 真相揭露（高潮） | C1 银白 | C2 浅灰肤 + C4 炭黑 | 强对比单源硬光，过曝白闪可作转场 | 震撼、摊牌、白热 |
| 回忆闪回（柔化） | C7 烟灰 | C1 银白 + C5 中灰 | 降低光比，雾化柔光，颗粒加重 | 迷雾、旧忆、朦胧 |

### 情绪色盘使用规则

| 编号 | 规则 |
|---|---|
| E1 | 每条提示词至少指定 1 个「情绪场景」并绑定主灰阶+辅灰阶组合 |
| E2 | 单镜头主导灰阶不超过 2 个层级，避免影调叙事失焦 |
| E3 | 情绪切换时优先调整光比与光位，再调整灰阶明度分布 |
| E4 | 黑白电影默认遵循「黑占画面、白做人眼」：大面积深灰/炭黑铺底，银白/浅灰肤落在情绪焦点 |
| E5 | 若与剧情冲突，以情绪灰阶盘优先于通用推荐灰阶，但不得突破严禁项 |

### 色温约束

| 参数 | 值 | 说明 |
|---|---|---|
| 整体色彩 | 严格黑白单色 monochrome | 全片零彩色信息，无色偏滤镜 |
| 肤色映射 | 中浅灰（C2 方向） | 影调层次塑形，保留皮肤灰阶过渡 |
| 对比度 | 高（建议保持） | chiaroscuro 明暗强对比，黑要沉、白要透 |
| 灰阶层次 | 丰富（建议保持） | 从炭黑到银白至少 5 级可辨过渡，忌二值化 |

### 容差与例外

| 项目 | 建议容差 |
|---|---|
| 灰阶明度偏移 | ±10% |
| 对比度偏移 | ±15% |
| 颗粒密度偏移 | ±15% |

> 例外场景：梦境、死前闪回、真相白闪镜头可使用极端影调（全剪影/过曝）；但任何情况下禁止彩色信息入镜。

## 三、全局约束规则

### 必守规则（所有技能继承）

| 编号 | 规则 |
|---|---|
| R1 | 必须包含「黑白单色 monochrome / film noir」风格锚定词 |
| R2 | 必须声明「高反差明暗 chiaroscuro + 灰阶层次丰富」 |
| R3 | 面部必须使用「影调层次塑形 + 面容细腻渲染」，保留灰阶肤感 |
| R4 | 发丝必须使用「根根分明 + 轮廓光分离」，炭黑发色配银边高光 |
| R5 | 画面须体现「银盐颗粒 + 老电影胶片质感」 |

### 严禁项（所有技能继承）

| 编号 | 严禁内容 |
|---|---|
| X1 | 严禁「卡通/动漫/二次元/插画风」 |
| X2 | 严禁「任何彩色元素/彩色滤镜/局部调色」（全画必须黑白单色） |
| X3 | 严禁「现代智能设备/现代服饰发型/现代都市元素」 |
| X4 | 严禁「面部变形/多指/肢体异常」倾向词 |
| X5 | 严禁「裸体/暴露/透视/暗示性描述」 |
| X6 | 严禁「数码锐利感/HDR/无颗粒数码质感/赛博霓虹元素」 |
