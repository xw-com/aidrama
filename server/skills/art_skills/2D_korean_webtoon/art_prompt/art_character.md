# 韩漫风格 - 人物基础形象生成 · 约束手册

---

## 一、基础形象原则

1. **线稿即骨架** — 干净锐利线稿为角色核心，线条粗细节奏分明，避免毛边断线
2. **角色为本** — 基础着装由角色描述（身份/职业/性别/场景）决定其常规着装；后续特定服化为叠加层
3. **四视图一致** — 面容/体型/发型/基础服装跨视图高度统一
4. **气质都市时尚** — 无妆状态需体现角色气质（清冷/温柔/干练/奶凶）

---

## 二、面容约束

> 不再固定五官特征参数，由角色描述（性别/年龄/性格/气质）驱动 AI 自由生成五官，保证人物间外观差异化。

### 通用要求

| 项目 | 约束 |
|---|---|
| 五官 | 由角色描述自然推导，不预设脸型/眼型/眉型/鼻型/唇型 |
| 风格底色 | 韩漫 Webtoon 质感（干净线稿、清透上色、五官立体、小脸轮廓） |
| 气质 | 必须从角色描述提炼整体气质关键词（如清冷/温柔/干练/奶凶），并写入提示词 |
| 表情 | 中性微表情，符合角色气质 |

## 六、基础服装约束

> 基础服装由角色描述（身份/职业/性别/场景）决定其最自然的常规着装，作为该角色「日常默认态」；正式服饰/特殊衍生在服化衍生环节叠加。**禁止内衣打底**。

### 着装选择原则

| 角色身份 | 默认着装方向 |
|---|---|
| 学生 | 韩系西装式校服 / 学院制服 |
| 上班族 | 韩系通勤装（西装外套+衬衫+西裤/半裙） |
| 财阀/精英 | 定制西装 / 长风衣 / 大衣 |
| 居家/休闲 | 针织开衫/卫衣/休闲套装 |
| 特殊职业 | 对应身份服装（医生/律师/主厨等） |
| 角色描述未明确 | 韩系都市时尚日常穿搭 |

### 着装统一规则

- 服装风格须与韩漫都市美学一致（莫兰迪配色、利落剪裁、精致质感）
- 色彩低饱和高级，无复杂花纹/装饰，便于后续衍生叠加
- 四视图服装款式完全一致
- 基础服装是「日常默认态」，焦点仍在面容与体态
- 严禁内衣/暴露/性化打底

## 八、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须为「素颜无妆」状态 |
| R2 | 必须根据角色描述声明合适的常规着装作为基础服装（如学生→韩系西装校服、上班族→通勤西装、精英→长风衣）；禁止内衣打底 |
| R3 | 必须声明「无发饰、无配饰」 |
| R4 | 必须指定「暖米白背景 #F7F5F1」 |
| R5 | 必须指定「四视图一致性」 |
| R6 | 全身立像必须从头到脚完整展示，严禁裁切 |
| R7 | 必须指定角色身高并通过头身比换算约束全身比例（女性默认160-170cm/7-7.5头身，男性默认178-188cm/8-9头身） |
| R8 | 人像特写必须从头顶到锁骨完整展示，严禁裁切头顶 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 内衣/暴露/性化打底；与角色描述明显不符的着装；过度复杂花纹/装饰干扰后续服化叠加 |
| X2 | 毛边断线、厚重笔触、脏色污渍感 |
| X3 | 过度美白至无血色 |
| X4 | 复杂场景背景（必须暖米白背景） |
| X5 | 夸张表情/动态姿势 |
| X6 | 全身立像裁切头顶或脚底，必须从头到脚完整入画 |
| X7 | 人像特写裁切头顶，必须从头顶到锁骨完整入画 |
| X8 | 忽略身高和头身比约束 |
