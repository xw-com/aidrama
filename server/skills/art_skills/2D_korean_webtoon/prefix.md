| 维度 | 定义 |

## 二、全局色彩盘（风格基线，不是硬锁）

> 目标：统一审美而非限制创作。除「硬约束色」外，其余颜色默认优先使用，可在合理范围内偏移。

### 色彩使用层级

| 层级 | 约束强度 | 说明 |
|---|---|---|
| L1 硬约束 | 高 | 仅锁定角色识别核心：肤色、发色、主服底色的审美方向 |
| L2 软约束 | 中 | 场景色、配饰色、点缀色优先参考色盘，可按镜头与剧情微调 |
| L3 例外机制 | 低 | 告白/重逢/闪回场景可临时突破局部色彩，但需保留整体清透灰调逻辑 |

### 硬约束色（默认锁定）

| 色项 | 对应色 | 规则 |
|---|---|---|
| 肤色基准 | C1 奶油肤 | 默认优先，允许小幅明度/冷暖微调 |
| 发色/瞳色基准 | C4 炭墨 | 默认优先，允许黑/深棕/灰棕系轻微偏移 |

### 软约束色（推荐优先）

> C2/C3/C5/C6/C7/C8/C9/C10 为推荐色域，用于服装、装饰、背景、光效、环境等。可根据镜头氛围做同色相邻近调整。

### 情绪色盘使用规则

| 编号 | 规则 |
|---|---|
| E1 | 每条提示词至少指定 1 个「情绪场景」并绑定主色+辅色组合 |
| E2 | 单镜头主色不超过 2 个，避免颜色叙事失焦 |
| E3 | 情绪切换时优先调整光比与色温，再调整饱和度 |
| E4 | 言情向默认遵循「灰底 + 柔和亮部」：高级灰铺底，柔亮色用于人物面部与情绪高光 |
| E5 | 若与剧情冲突，以情绪色盘优先于通用推荐色，但不得突破严禁项 |

### 色温约束

| 参数 | 值 | 说明 |
|---|---|---|
| 整体色温 | 中性偏柔 5000-5800K（推荐） | 都市清透主基调 |
| 肤色色温 | 柔白透粉 5200-5600K（推荐） | 白皙通透而有血色 |
| 对比度 | 中低（建议保持） | 明暗过渡柔和，不硬碰 |
| 饱和度 | 中低 40-60%（建议区间） | 莫兰迪高级灰色域 |

### 容差与例外

| 项目 | 建议容差 |
|---|---|
| 色相偏移 | ±8° |
| 饱和度偏移 | ±10% |
| 明度偏移 | ±12% |

> 例外场景：告白、重逢、心动高潮镜头可使用更柔焦或更高亮度的局部色块；但禁止高饱和荧光色与厚重油彩感入镜。

## 三、全局约束规则

### 必守规则（所有技能继承）

| 编号 | 规则 |
|---|---|
| R1 | 必须包含「韩漫风格」风格锚定词 |
| R2 | 必须声明「干净线稿 + 清透数码上色」 |
| R3 | 面部必须使用「精致五官线条 + 清透肤色」 |
| R4 | 发丝必须使用「流畅发束线条 + 柔和高光」 |
| R5 | 光影必须声明「柔和渐变光影 + 高级灰色域」 |

### 严禁项（所有技能继承）

| 编号 | 严禁内容 |
|---|---|
| X1 | 严禁「3D渲染/写实照片/厚涂油画」 |
| X2 | 严禁「高饱和荧光色/霓虹撞色/重油彩笔触」 |
| X3 | 严禁「复古网点印刷/做旧噪点/粗糙颗粒」 |
| X4 | 严禁「面部变形/比例失调/肢体异常」倾向词 |
| X5 | 严禁「日漫大眼Q版/夸张变形/热血漫画分格」 |
| X6 | 严禁「暗黑猎奇/恐怖血腥向元素」 |
