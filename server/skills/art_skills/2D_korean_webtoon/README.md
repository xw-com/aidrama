# 韩漫风格说明

本风格专为"韩式网页漫画（Webtoon）"题材打造，所有美术提示词、规范和生成内容均严格限定于：

- **现代都市世界观**：以当代韩国都市为背景，涵盖咖啡厅、写字楼、豪华公寓、江边步道、商圈街头等，体现精致的都市时尚气息。
- **清透数码质感**：所有角色、场景、道具均以韩式 Webtoon 数码上色为标准，强调干净锐利的线稿、清透通透的色彩、柔和的渐变光影。
- **高级灰美学**：大面积高级灰与莫兰迪都市色铺底，点缀清雅柔亮色，画面干净、通透、富有空气感。
- **偶像剧氛围**：追求都市言情与偶像剧般的情感张力，适合心动、暗恋、误会、双向奔赴的浪漫叙事。

## 适用范围

- 韩漫风格题材的AI美术生成（角色、场景、道具、分镜等）
- 需要清透上色、干净线稿、莫兰迪都市色、偶像剧氛围的视觉创作

## 严禁内容

- 3D渲染、厚涂油画、写实照片感
- 高饱和荧光色、霓虹撞色、重油彩笔触
- 复古网点印刷、做旧噪点、粗糙颗粒
- 暗黑猎奇、恐怖血腥、成人向内容

## 风格体验

在本风格下，您将体验到：

- 角色面容精致时尚、气质清冷或温柔，五官立体、身材比例修长，服饰、发型均为韩系都市时尚风格
- 场景空间干净通透，灰调高级，光影柔和，氛围克制且富有情感
- 道具、时尚单品、生活器物均为精致都市造型，质感细腻，品味高级
- 分镜与画面均以柔和渐变光影与留白构图为基础，强调情感流动与偶像剧式心动瞬间

---

本风格仅适用于"韩漫风格"相关项目。如需其他风格（如赛璐璐日漫、厚涂写实、水彩等），请勿使用本套提示词。
