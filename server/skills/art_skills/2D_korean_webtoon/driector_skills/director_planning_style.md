# 韩漫约束 · 韩漫风格 · 技法参考

---

## 一、色调体系与画面基调

- **色调基底** — 全片以暖米白（C6）、高级灰（C9）、雾霾蓝（C3）为基底色，整体色温中性偏柔（5000-5800K），饱和度中低（40-60%），呈现韩漫 Webtoon 的清透高级感。全片保持莫兰迪灰调基底，局部点缀柔亮色（干玫瑰 C2、焦糖驼 C7）提亮情绪高光
- **冷暖叙事对比** — 冷色（雾霾蓝 C3、藏青蓝 C10）作为误会/离别/职场段落的视觉信号，暖色（焦糖驼 C7、干玫瑰 C2）用于心动/告白/重逢段落。冷暖切换应与感情线同步，而非随意混用
- **色盘先行原则** — 段落规划需先绑定情绪场景（日常/心动/误会/重逢等），再确定主色+辅色与光影方案，避免"剧情对了但情绪不对色"
- **禁用色域** — 高饱和荧光色、霓虹撞色、厚重油彩色系均与本风格不兼容

---

## 二、光影方案体系

- **光影即叙事** — 6 套光影方案对应不同情绪段落，导演规划阶段应在段落层面确定光影基调方向，而非逐镜指定
- **光源角度** — 默认正面 45° 柔和漫射，光比小、过渡缓，避免硬边阴影

| 情绪段落 | 光影方向 | 色调倾向 | 适用阶段 |
|---|---|---|---|
| 治愈日常 | A·柔匀自然光 | 暖米白底 + 均匀柔亮 | 全片 |
| 心动暧昧 | B·柔焦暖光 | 藕荷紫 + 干玫瑰局部 | 升温段 |
| 职场/都市 | C·阴天漫射 | 高级灰 + 雾霾蓝 | 职场/通勤段 |
| 告白高光 | D·暖调聚焦 | 焦糖驼主导 + 背景压暗 | 告白/甜蜜段 |
| 夜晚都市 | E·人工柔光 | 藏青蓝 + 冷暖混光点彩 | 夜晚段 |
| 误会/离别 | F·冷灰逆光 | 高级灰 + 藏青蓝剪影 | 虐心/转折段 |

- **冷暖光分配** — 灰调贯穿全片可用，根据场景需要灵活调整；柔暖光（焦糖驼/干玫瑰）集中用于心动脉段，冷调（雾霾蓝/藏青蓝）用于误会、离别与夜晚段落
- **氛围方向映射** — 每场戏的氛围方向应能映射到上述光影方案（A-F）的某一方向，确保视觉一致性

## 三、质感方向

- **清透数码感** — 韩漫 Webtoon 的核心：线稿干净、色面清透、渐变柔和
- **干净线稿 + 柔和渐变** — 这是画面质感的锚点。不是网点印刷，不是厚涂油画，更不是写实照片
- **高级灰不等于灰暗** — 莫兰迪色靠明度与灰度的克制搭配呈现高级感，画面仍须清亮通透、有空气感
- **偶像剧不等于狗血** — 情感张力靠光影留白与微表情设计放大，而非夸张动作与浓烈色彩

## 四、韩漫都市场景空间元素

韩漫 Webtoon 特有的场景元素及其视觉叙事功能：

- **落地窗/玻璃幕墙/橱窗** — 天然的框架与反射构图道具，制造都市纵深与"隔窗相望"的情感距离
- **咖啡厅/江边/天台** — 言情叙事的天然载体，景即情：咖啡厅落地窗 = 等待与心事、江边夜景灯点 = 告白与治愈、天台夜风 = 秘密与释怀
- **樱花道/银杏道/雨幕** — 留白构图的天然载体，景即情：樱花纷落 = 心动、银杏金驼 = 温柔陪伴、雨中共伞 = 靠近与守护
- **店招灯箱/江面灯点/城市灯海** — 夜景柔光的来源，虚化成光斑即是偶像剧氛围本身
- **段落间用场景空镜过渡** — 本风格有丰富的场景资产（不同时段/天候/季节变体），段落衔接建议用空镜 + 光斑虚化做情绪缓冲，不要硬切
- **转折点用视觉而非台词** — 优先使用画面手段（冷暖光切换、逆光剪影、景别跳切、空镜隐喻）而非依赖对白解释

## 五、韩漫乐器与环境音

韩漫 Webtoon 世界观下的声音元素约束：

### 乐器选择

- **钢琴** — 心动/深情/回忆段落的核心乐器，最能表现韩漫言情的细腻质感
- **原声吉他** — 日常/治愈/轻快段落，指弹的清透感适合都市日常
- **弦乐铺底** — 情感升华/虐心/离别段落，拉弦的绵长感适合情绪推进
- **爵士三重奏** — 咖啡厅/夜晚都市段落，慵懒质感适合微醺氛围

### 乐器组合策略

| 情绪阶段 | 乐器组合 |
|---|---|
| 平稳/开场/收尾 | 钢琴独奏 或 氛围铺底单音色 |
| 日常治愈 | 原声吉他 + 轻打击乐 |
| 心动升温 | 钢琴 + 弦乐 |
| 夜晚都市 | 爵士三重奏 或 氛围电子铺底 |
| 虐心/离别 | 弦乐 + 钢琴 |

### 韩漫都市环境音

- **典型环境音层次** — 咖啡机蒸汽声 / 江水拍岸与游船汽笛 / 城市车流底噪 / 地铁报站与轨道声 / 风铃与店门叮咚 / 雨滴打伞面 / 高跟鞋与皮鞋脚步声
- **每场戏标注 1-2 个核心环境音**，帮助后续音效设计。环境音层次越丰富，都市场景越有沉浸感
- **留白比配乐更重要** — 关键情感瞬间（对视、擦肩、转身）优先考虑去掉配乐，只留环境音（雨声、江水声、车流声），让观众自己感受情绪
- **避免满配** — 全片配乐覆盖率建议不超过 50%。留白段落的"无声"与配乐段落形成呼吸感，突出心动落点
