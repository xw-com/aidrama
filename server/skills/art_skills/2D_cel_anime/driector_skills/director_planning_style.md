# 赛璐璐日漫约束 · 现代赛璐璐日漫 · 技法参考

---

## 一、色调体系与画面基调

- **色调基底** — 全片以荧白（C6）、电光蓝（C3）、樱雪粉（C10）为基底色，整体色温中性偏亮（5500-6500K），饱和度高（80-95%），呈现现代 TV 动画主视觉的明快锐利感。全片保持亮底高饱和基底，局部点缀重色（焰红 C2、深空灰 C9）用于阴影、轮廓与情绪冲击
- **冷暖叙事对比** — 冷色（电光蓝 C3、靛夜蓝 C4、薄藤紫 C5）作为夜晚都会、对决与情绪转折的视觉信号，用于夜景段落或情绪转折点局部强化。冷暖切换应与故事弧线同步，而非随意混用
- **色盘先行原则** — 段落规划需先绑定情绪场景（日常/心动/对决/觉醒等），再确定主色+辅色与光影方案，避免"剧情对了但情绪不对色"
- **禁用色域** — 灰暗低饱和色、整体脏色调、大面积莫兰迪灰均与本风格不兼容

---

## 二、光影方案体系

- **光影即叙事** — 6 套光影方案对应不同情绪段落，导演规划阶段应在段落层面确定光影基调方向，而非逐镜指定
- **光源角度** — 默认高位 30-45° 斜侧光，二分阴影干脆、明暗边界清晰锐利

| 情绪段落 | 光影方向 | 色调倾向 | 适用阶段 |
|---|---|---|---|
| 日常明快 | A·高位自然光 | 荧白底 + 均匀明亮光 | 全片 |
| 心动糖分 | B·柔暖侧光 | 樱雪粉 + 琥珀金局部 | 升温段 |
| 燃向对决 | C·强对比顶光 | 焰红 + 深空灰硬阴影 | 战斗/对决段 |
| 黄昏抒情 | D·逆光金边 | 琥珀金主导 + 靛夜蓝背景 | 抒情/惜别段 |
| 夜晚都会 | E·人工光源点彩 | 薄藤紫 + 电光蓝点彩 | 夜晚段 |
| 觉醒/异能 | F·底光+侧光强对比 | 电光蓝 + 焰红能量光 | 高潮/觉醒段 |

- **冷暖光分配** — 亮色（荧白/琥珀金）贯穿全片可用，根据场景需要灵活调整；重色（深空灰/靛夜蓝）仅用于阴影、轮廓线与夜景段落
- **氛围方向映射** — 每场戏的氛围方向应能映射到上述光影方案（A-F）的某一方向，确保视觉一致性

## 三、质感方向

- **二分赛璐璐感** — 现代日漫赛璐璐的核心：描线锐利干净、色块分明、阴影二分干脆利落
- **锐利线稿 + 干净色块** — 这是画面质感的锚点。不是厚涂涂抹，不是水彩晕染，更不是 3D 渲染
- **二分不等于廉价** — 本风格强调现代 TV 动画主视觉的完成度（高饱和色域、高光留白、锐利轮廓），通过演出设计与情绪张力放大感染力，而非依赖复杂特效
- **明快不等于刺眼** — 高饱和不靠滤镜堆砌，靠色块明度关系与光影边界设计呈现干净透亮的画面

## 四、现代日漫场景空间元素

现代赛璐璐日漫特有的场景元素及其视觉叙事功能：

- **教室/天台/河堤** — 青春感的天然载体，景即情：教室窗格光斑 = 日常、天台铁丝网后的天空 = 自由与呐喊、黄昏河堤坡道 = 放学与治愈
- **都市街道/便利店/电车站** — 现代都市律动的载体，景即情：路口信号灯 = 命运交错、深夜便利店灯箱 = 都市慰藉、电车站台 = 相遇与送别
- **电线/招牌/玻璃幕墙** — 都会上空的线条分割与锐利反光，制造几何构图、速度感与画面纵深
- **樱吹雪/光斑/风** — 留白构图的天然载体，景即情：樱吹雪 = 心动、窗格光斑流动 = 时间流逝、逆光风起 = 情绪转折
- **段落间用场景空镜过渡** — 本风格有丰富的场景资产（不同时段/天候/季节变体），段落衔接建议用场景空镜做情绪缓冲，不要硬切
- **转折点用视觉而非台词** — 优先使用画面手段（光影突变、景别跳切、色温骤变、空镜隐喻）而非依赖对白解释

## 五、现代日漫乐器与环境音

现代赛璐璐日漫世界观下的声音元素约束：

### 乐器选择

- **电子合成器** — 日常/都市流动段落的核心音色，轻快节拍最贴合现代动画的都市感
- **电吉他** — 燃向/对决/觉醒段落，失真音墙适合热血爆发与冲刺
- **钢琴** — 心动/抒情/回忆段落，干净琴音适合情绪落点
- **弦乐铺底** — 情感升华/离别/高潮段落，拉弦的推进感适合情绪翻涌

### 乐器组合策略

| 情绪阶段 | 乐器组合 |
|---|---|
| 平稳/开场/收尾 | 钢琴独奏 或 电子合成器单音色铺底 |
| 日常明快 | 电子合成器 + 轻快鼓点 |
| 心动/抒情 | 钢琴 + 弦乐 |
| 燃向对决/觉醒 | 电吉他 + 鼓组 + 弦乐齐奏 |

### 现代都市环境音

- **典型环境音层次** — 电车驶过与轨道声 / 便利店自动门提示音 / 信号灯滴答与车流 / 操场哨声与喧闹 / 蝉鸣与风扇转动 / 雨打雨棚与伞面 / 键盘敲击与手机震动
- **每场戏标注 1-2 个核心环境音**，帮助后续音效设计。环境音层次越丰富，现代都市场景越有沉浸感
- **留白比配乐更重要** — 关键情感瞬间（对视、回头、告白前的沉默）优先考虑去掉配乐，只留环境音（电车声、风声、蝉鸣），让观众自己感受情绪
- **避免满配** — 全片配乐覆盖率建议不超过 50%。留白段落的"无声"与配乐段落形成呼吸感，突出情绪落点
