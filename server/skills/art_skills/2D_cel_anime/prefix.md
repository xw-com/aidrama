## 二、全局色彩盘（风格基线，不是硬锁）

> 目标：统一审美而非限制创作。除「硬约束色」外，其余颜色默认优先使用，可在合理范围内偏移。

### 色彩使用层级

| 层级 | 约束强度 | 说明 |
|---|---|---|
| L1 硬约束 | 高 | 仅锁定角色识别核心：肤色、发色、主服底色的审美方向 |
| L2 软约束 | 中 | 场景色、配饰色、点缀色优先参考色盘，可按镜头与剧情微调 |
| L3 例外机制 | 低 | 战斗/觉醒/异能场景可临时突破局部色彩，但需保留整体明快高饱和逻辑 |

### 硬约束色（默认锁定）

| 色项 | 对应色 | 规则 |
|---|---|---|
| 肤色基准 | C1 透亮肤 | 默认优先，允许小幅明度/冷暖微调 |
| 发色/瞳色基准 | C4 靛夜蓝 | 默认优先，允许深蓝/深褐/黑色系轻微偏移 |

### 软约束色（推荐优先）

> C2/C3/C5/C6/C7/C8/C10 为推荐色域，用于服装、装饰、背景、光效、环境等。可根据镜头氛围做同色相邻近调整。

### 情绪色盘使用规则

| 编号 | 规则 |
|---|---|
| E1 | 每条提示词至少指定 1 个「情绪场景」并绑定主色+辅色组合 |
| E2 | 单镜头主色不超过 2 个，避免颜色叙事失焦 |
| E3 | 情绪切换时优先调整光比与色温，再调整饱和度 |
| E4 | 明快向默认遵循「亮底 + 高光锐利」：亮色铺底，重色仅用于阴影与轮廓 |
| E5 | 若与剧情冲突，以情绪色盘优先于通用推荐色，但不得突破严禁项 |

### 色温约束

| 参数 | 值 | 说明 |
|---|---|---|
| 整体色温 | 中性偏亮 5500-6500K（推荐） | 明快清爽主基调 |
| 肤色色温 | 透亮中性 5800-6200K（推荐） | 白皙透亮且有血色 |
| 对比度 | 高（建议保持） | 二分阴影干脆，明暗边界清晰 |
| 饱和度 | 高 80-95%（建议区间） | 现代日漫高饱和主视觉色域 |

### 容差与例外

| 项目 | 建议容差 |
|---|---|
| 色相偏移 | ±10° |
| 饱和度偏移 | ±8% |
| 明度偏移 | ±10% |

> 例外场景：战斗、觉醒、异能爆发镜头可使用更高饱和或更强对比的局部色块；但禁止灰暗脏色调与写实摄影色彩语言入镜。

## 三、全局约束规则

| 编号 | 规则 |
