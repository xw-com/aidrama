# 赛璐璐日漫风格说明

本风格专为"现代赛璐璐日漫画风"题材打造，所有美术提示词、规范和生成内容均严格限定于：

- **现代日漫世界观**：以现代都市与校园生活为背景，涵盖教室、公寓、都市街道、电车站、便利店等，体现鲜明的现代生活气息。
- **赛璐璐动画质感**：所有角色、场景、道具均以现代日漫赛璐璐动画为标准，强调锐利干净的描线、干脆的二分阴影、高饱和明快的色彩。
- **动画主视觉美学**：在赛璐璐基础上追求 TV 动画与轻小说插画般的完成度，画面干净透亮、色块分明，整体氛围明快、锐利、富有青春张力。
- **情感表达**：适合展现热血、心动、成长、奇幻冒险的现代日漫故事，强调青春感与情绪张力。

## 适用范围

- 现代赛璐璐日漫题材的AI美术生成（角色、场景、道具、分镜等）
- 需要锐利描线、二分硬阴影、高饱和色彩、动画主视觉质感的视觉创作

## 严禁内容

- 3D渲染、CG材质、写实摄影感
- 厚涂油画、水彩晕染、颗粒噪点肌理
- 灰暗低饱和、整体脏色调
- 暗黑猎奇、恐怖向、成人向内容

## 风格体验

在本风格下，您将体验到：

- 角色面容精致锐利、气质明快或飒爽，服饰、发型均为现代日漫风格
- 场景空间干净利落，色块明快，光影干脆，氛围清爽且富有青春感
- 道具、日常物品、环境细节均为现代造型，细节锐利，质感干净
- 分镜与画面均以赛璐璐二分光影为基础，强调演出张力与情感表达

---

本风格仅适用于"赛璐璐日漫风"相关项目。如需其他风格（如复古手绘、写实、厚涂、韩漫等），请勿使用本套提示词。
