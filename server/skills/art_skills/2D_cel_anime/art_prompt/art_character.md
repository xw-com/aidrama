# 现代赛璐璐日漫风 - 人物基础形象生成 · 约束手册

---

## 一、基础形象原则

1. **线稿即灵魂** — 锐利干净描线为角色核心，避免毛边、断线与涂抹感
2. **角色为本** — 基础着装由角色描述（身份/职业/性别/场景）决定其常规着装；后续特定服化为叠加层
3. **四视图一致** — 面容/体型/发型/基础服装跨视图高度统一
4. **气质锐利明快** — 无妆状态需体现角色气质（飒爽/元气/清冷/腹黑）

---

## 二、面容约束

> 不再固定五官特征参数，由角色描述（性别/年龄/性格/气质）驱动 AI 自由生成五官，保证人物间外观差异化。

### 通用要求

| 项目 | 约束 |
|---|---|
| 五官 | 由角色描述自然推导，不预设脸型/眼型/眉型/鼻型/唇型 |
| 风格底色 | 现代赛璐璐日漫质感（锐利线稿、二分阴影、高饱和明快色） |
| 气质 | 必须从角色描述提炼整体气质关键词（如飒爽/元气/清冷/腹黑），并写入提示词 |
| 表情 | 中性微表情，符合角色气质 |

## 六、基础服装约束

> 基础服装由角色描述（身份/职业/性别/场景）决定其最自然的常规着装，作为该角色「日常默认态」；正式服饰/特殊衍生在服化衍生环节叠加。**禁止内衣打底**。

### 着装选择原则

| 角色身份 | 默认着装方向 |
|---|---|
| 学生 | 现代西式校服 / 学院制服 |
| 上班族 | 现代通勤装（衬衫+西裤/裙装） |
| 居家/休闲 | 现代休闲服（连帽卫衣/T恤/针织开衫） |
| 运动/活泼 | 运动套装 / 球衣 / 校队队服 |
| 特殊职业 | 对应身份服装（医生/警察/教师等） |
| 角色描述未明确 | 现代都市日常常服 |

### 着装统一规则

- 服装风格须与现代赛璐璐日漫美学一致（明快配色、利落剪裁、干净色块）
- 色彩明快干净，无复杂花纹/装饰，便于后续衍生叠加
- 四视图服装款式完全一致
- 基础服装是「日常默认态」，焦点仍在面容与体态
- 严禁内衣/暴露/性化打底

## 八、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须为「素颜无妆」状态 |
| R2 | 必须根据角色描述声明合适的常规着装作为基础服装（如学生→现代校服、上班族→通勤装、居家→现代休闲服）；禁止内衣打底 |
| R3 | 必须声明「无发饰、无配饰」 |
| R4 | 必须指定「浅冷灰背景 #F4F6FA」 |
| R5 | 必须指定「四视图一致性」 |
| R6 | 全身立像必须从头到脚完整展示，严禁裁切 |
| R7 | 必须指定角色身高并通过头身比换算约束全身比例（女性默认155-165cm/6.5-7头身，男性默认172-182cm/7-7.5头身） |
| R8 | 人像特写必须从头顶到锁骨完整展示，严禁裁切头顶 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 内衣/暴露/性化打底；与角色描述明显不符的着装；过度复杂花纹/装饰干扰后续服化叠加 |
| X2 | 毛边断线、灰暗脏色、厚涂涂抹感 |
| X3 | 过度美白至无血色 |
| X4 | 复杂场景背景（必须浅冷灰背景） |
| X5 | 夸张表情/动态姿势 |
| X6 | 全身立像裁切头顶或脚底，必须从头到脚完整入画 |
| X7 | 人像特写裁切头顶，必须从头顶到锁骨完整入画 |
| X8 | 忽略身高和头身比约束 |
