## 一、风格核心定义

**真人商战豪门写实**是以**真人影视摄影美学**为基准、以**当代顶奢商战与豪门世家**为核心的视觉风格体系。其核心特征为：

- **真人写实摄影质感**：以真人影视级摄影为锚点，画面呈现真实人物的皮肤纹理、毛发细节、微表情与肢体语言，高定面料的垂坠与光泽、奢华建筑材质的厚重与反光，杜绝3D建模感、CG渲染感、手绘感
- **当代顶奢商战豪门世界观**：所有场景严格限定于当代顶奢权力与财富空间——CBD顶层CEO办公室、董事会会议室、海景/山景豪宅客厅与主卧、私人会所、宴会晚宴厅、高尔夫球场、私人酒窖、游艇甲板、私人停机坪、艺术画廊与收藏室
- **电影级摄影语言**：以院线级真人电影摄影为基准，强调自然光与奢华人工光（水晶吊灯、氛围灯、城市夜景灯）的有机调度、构图叙事的专业性、景深与焦点的情绪表达、色彩分级的电影感
- **顶奢质感与权力温度**：在保持专业影像品质的前提下，强调高定西装的挺括、晚礼服的流转、名表珠宝的微光、红酒雪茄的氤氲、豪门世家的人物气场与权谋温度

### 创作理念与核心价值

本手册的核心创作理念为 **"奢华即真实，权力即凝视"**：

1. **真实感的奢华回归**：在AI生成影像日趋泛滥的当下，真人写实质感以其不可替代的真实力量，成为最具情感穿透力的视觉语言。真实皮肤的光泽与毛孔、高定面料在身体上的自然垂坠、水晶吊灯在红酒杯壁的折射光斑、雪茄烟雾在落地窗逆光中的流转——这些真实细节构成了一种3D渲染无法复刻的奢华生命质感。

2. **权力空间的叙事容器**：顶层办公室的落地窗承载着权力的俯瞰，董事会的长桌回荡着博弈的冷峻，豪宅客厅的水晶吊灯下掩藏着世家的秘密，游艇甲板的风里有浮华与孤独——顶奢商战空间本身就是一个巨大的权力叙事容器，等待被挖掘。

3. **精英主义的视觉立场**：本手册坚持以"人"为核心。无论场景多么奢华、光影多么绚丽，最终回归到人物的权谋气场、城府深度、欲望挣扎与内心世界。每一帧画面都是一次对权力与人性的注视。

4. **电影与奢华的临界点**：寻求"电影的精致"与"奢华的真实"之间的微妙平衡——画面足够美、足够专业、有电影感，但不过度浮华而失去真实质感；人物足够精致、足够有气场，但不过度磨皮而失去真人皮肤的生命感。

**核心价值：**

- 为AI视觉创作者提供一套系统化、可复用的真人商战豪门题材提示词方法论
- 建立从概念到成品的标准化视觉创作管线
- 降低真人商战豪门题材AI视觉创作的技术门槛与试错成本

## 四、关键视觉元素

### 4.1 人物视觉元素

真人商战豪门题材的人物视觉以**"顶奢精英、世家气场"**为核心：

- **面容标准**：真人肌肤质感，五官自然立体且精致，妆容符合顶奢审美但保留真实皮肤质感。支持多元面容类型——强势冷峻、优雅贵气、精明干练、温婉隐忍、阳光名媛等
- **发型标准**：当代顶奢精英定制发型，发丝自然质感与造型纹理并存，杜绝假发感与僵硬造型。支持低盘发/优雅卷发/利落短发/侧分油头/定制商务短发等多种精英发型
- **服饰标准**：当代顶奢精英着装体系——高定商务正装（西装三件套、定制衬衫、领带/领结）、晚装礼服（晚礼服、燕尾服、高定连衣裙）、奢华日常（羊绒大衣、高定针织、设计师单品）。面料纹理清晰，剪裁挺括有型，褶皱符合身体动态
- **表情与体态**：微表情真实细腻（眼神的威压、嘴角的城府、眉宇的隐忍），肢体语言克制而有气场，杜绝僵硬摆拍感与过度戏剧化表情

## 五、严禁内容（优先级最高）

本风格严格排除以下内容类型，确保视觉体系纯净统一：

1. **非真人质感**：3D渲染/CG建模/次世代游戏引擎/动画风格/手绘插画/水彩油画/二次元/Voxel/低多边形等一切非真人实拍影像质感
2. **非顶奢商战豪门世界观**：古风/古装/宫廷/仙侠/玄幻/武侠/民国/西方奇幻/中世纪/赛博朋克/科幻未来/星际太空/机甲等非当代顶奢背景
3. **非顶奢/廉价元素**：市井烟火/普通民居/老小区/菜市场/便利店/夜市排档/出租屋/乡村田园/校园/工厂车间等明显非顶奢场景与元素
4. **非当代语境**：明显非当代特征的建筑、服饰、道具（如古装、民国服饰、和服等）
5. **技术质量缺陷**：低分辨率/模糊/噪点/变形/畸形肢体/五官扭曲/比例失调/抠图感/塑料感/过度磨皮/假面感
6. **审美倾向违规**：过度高饱和/死亡荧光色/廉价滤镜感/过度HDR/塑料质感/明显廉价非顶奢元素
7. **内容合规红线**：暴露/低俗/暗示性/暴力血腥/违法内容/歧视性表达/政治敏感元素

## 七、使用说明

### 提示词使用原则

1. **前缀先行**：所有生成内容必须首先加载"前缀提示词"中的全局风格锚定段，锁定真人商战豪门写实质感基线
2. **专项叠加**：在全局前缀基础上，按需叠加角色/场景/道具/分镜专项提示词
3. **负面必加**：每次生成必须附带"负面提示词"，规避伪影与风格偏差
4. **迭代优化**：建议首轮生成后根据效果对专项提示词做微调，而非修改全局前缀
5. **平台适配**：本手册提示词优先适配Doubao-Seedream（生图）与Doubao-Seedance（视频生成），部分提示词可能需根据平台特性微调
