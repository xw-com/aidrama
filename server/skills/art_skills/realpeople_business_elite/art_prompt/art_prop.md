# 真人商战豪门道具图像生成 · 约束手册

---

## 一、道具设计原则

> 真人商战豪门的道具不是"被建模的物体"，而是"被使用过的顶奢物品"——它在某个总裁手里待过、在某张胡桃木桌上放过、在某个真皮公文包里装过。摄影机拍下的是它的此刻。

1. **物品即权谋** — 每一件道具都是一个微型的权力叙事容器。红酒杯壁的挂杯暗示刚才有人在品鉴、名表表带的弯折暗示戴了很久、合同上的签字暗示一场博弈刚刚落幕
2. **使用痕迹优先于全新品相** — 真人商战豪门的道具必须有"被用过"的证据。开过瓶的红酒、有手温痕迹的名表、有包浆的真皮公文包、有签字的合同——杜绝未拆封的样品
3. **当代顶奢商战豪门真实物品** — 道具必须是顶奢世界中真实存在的物品：奢华腕表、高定钢笔、水晶高脚杯、真皮公文包、中文合同/股权文件、艺术藏品——拒绝无质感的架空物品与廉价仿品
4. **材质即奢华** — 不是PBR参数渲染出的材质，而是摄影机拍下的真实奢华材质行为：贵金属的厚重反光、水晶的真实折射、真皮的自然毛孔、丝绸的光泽流转
5. **单视图静物摄影** — 道具以单张奢华静物产品摄影方式独立呈现，非多角度建模展示，非2×2四宫格

## 三、单视图静物摄影规范

> 真人商战豪门道具仅需单张奢华静物产品摄影，非多角度建模展示。以下为单视图摄影的完整规范。

### 画面构成

| 项目 | 摄影要求 |
|---|---|
| 道具呈现 | 道具居中或偏三分线位置独立陈列，完整入画，无裁切 |
| 背景 | 素灰无缝背景纸 #B0B0B0（哑光），或胡桃木桌面/大理石台面/真皮台面（根据道具属性选择顶奢承载面）。无多余物体、无装饰、无文字 |
| 光线 | 自然窗光或单灯柔光。窗光45°侧入（明亮柔和带自然阴影）、或柔光箱顶+侧补（奢华产品摄影级均匀光线）。光影柔和、方向明确、能凸显奢华材质的折射与反光 |
| 景深 | 浅景深（f/2.8-f/5.6），道具主体清晰锐利，前后微虚化突出主体 |
| 投影 | 道具底部与承载面之间的自然接触阴影——真实的而非抠图或悬浮。阴影柔软、方向与主光源一致 |
| 画面比例 | 建议 1:1 正方形或 4:3，适配单件奢华道具展示 |

### 道具状态准则

| 维度 | 要求 |
|---|---|
| 使用痕迹 | 必须有"被使用过"的视觉证据——非全新未拆封、非样品品相 |
| 顶奢辨识度 | 中文标识/顶奢工艺/奢华材质/当代商战豪门日常——拒绝无质感架空物品与廉价仿品 |
| 材质真实感 | 非渲染质感——是摄影机拍下的真实奢华材料行为（贵金属反光、水晶折射、真皮毛孔、丝绸光泽） |
| 尺度感 | 通过材质纹理密度、工艺细节暗示实物尺寸与奢华程度，无需参照物 |

## 六、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须是「单张奢华静物摄影」——单视图、非多角度、非2×2四宫格、非建模展示 |
| R2 | 必须指定「素灰背景纸 #B0B0B0」或「胡桃木桌面/大理石台面/真皮台面」等真实顶奢承载面，禁止复杂场景 |
