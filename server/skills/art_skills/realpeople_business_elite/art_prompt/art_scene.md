# 真人商战豪门场景图像生成 · 约束手册

---

## 一、场景美学原则

> 真人商战豪门的场景不是"被建模的空间"，而是"被摄影机选中的真实顶奢场所"。没有渲染引擎、没有贴图、没有体积光参数——只有实际存在的奢华光、真实的顶奢材料、以及当代商战豪门世界的真实。

1. **空间即权力** — 一个空无一人的CEO办公室不是"空的"，是权力的暂停。一张胡桃木办公大桌、一杯未喝完的威士忌、落地窗外仍在运转的城市——空间自己会讲述权力的故事
2. **真实的光，不是渲染的光** — 场景的光只有一个来源：实际的城市天光（通过落地窗）、实际的奢华人工光（水晶吊灯、壁灯、氛围灯、城市夜景灯）。光的色温和方向必须在物理上说得通
3. **被使用过的奢华空间** — 真实的顶奢场景不是样板间。桌上有翻开的文件、酒柜里有开过瓶的红酒、真皮沙发有自然包浆、大理石有自然纹理——一个完全没有使用痕迹的空间是售楼处的样板间，不是真人商战豪门
4. **当代顶奢商战豪门的真实场所** — 场景必须有顶奢辨识度（落地窗城市天际线、水晶吊灯、胡桃木护墙、大理石、真皮、艺术藏品）。这不是"generic luxury"，这是"当代顶奢商战豪门的一个具体权力角落"
5. **单视图全景全貌** — 一张照片装下整个奢华空间的完整信息。广角或标准焦段，全景深，正面展示空间的全貌与纵深——不是四视图分割，不是多角度拼贴

## 五、单视图全景摄影规范

> 真人商战豪门场景仅需**单张**全景摄影——一张照片装下整个奢华空间的完整信息。不是2×2四视图，不是多角度拼接。

### 画面构成

| 项目 | 摄影要求 |
|---|---|
| 空间呈现 | 单张照片完整呈现场景的奢华空间全貌。使用24-28mm广角或35mm，全场地的纵深、宽度、高度在一张画面中全部可见 |
| 构图 | 全景深大景别——前景（落地窗框/真皮沙发边缘/办公桌角/护栏/树木）形成天然画框→中景是奢华场地主体→后景向空间纵深或落地窗外城市天际线延伸 |
| 景深 | 全景深 f/8-f/11，从前到后全部清晰。这不是人像摄影——奢华场景的每一个角落都应该能被看见 |
| 人物 | **严禁出现任何人物、人影、人体轮廓。** 场景是空的——但这种"空"有权力叙事：刚散会/即将开场/人去楼空/权力的暂停瞬间 |
| 比例 | 建议 16:9 或 3:2 宽幅——匹配全景奢华空间展示的横向视觉习惯 |
| 色彩 | 由实际光源的色温驱动，不套滤镜。色彩科学参考ARRI Alexa/Sony Venice电影色调 |

### 空的场景如何叙事

| "空"的类型 | 画面线索 | 叙事暗示 |
|---|---|---|
| 刚散会 | 会议桌上文件未收、矿泉水剩半瓶、椅子未推回原位、白板上字迹未擦 | 刚才有人在这里博弈，现在散了 |
| 即将开场 | 椅子摆好、桌面整洁、水晶杯具已摆好、鲜花已布置、烛光已点 | 有人马上要来，现在是盛宴前的静止 |
| 人去楼空 | 落地窗城市依旧运转、办公桌上文件已收走、酒杯已空、只剩城市灯海 | 权力的暂停、独留空间的余韵 |
| 权力的静止 | 落地窗外的城市天际线、办公桌上未喝完的威士忌、真皮沙发的自然包浆、水晶摆件的反光 | 权力的常态、只是此刻没有人入镜 |
| 深夜的奢华场所 | 空荡的宴会厅只有水晶吊灯亮着、酒窖的暖点光、CEO办公室落地窗外的城市灯海 | 城市睡着了、但权力空间还醒着 |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须是**单张**全景摄影——单视图、非2×2四视图、非多角度、非turnaround |
| R2 | 必须使用广角镜头（24-28mm）或标准焦段（35mm），全景深 f/8-f/11，完整奢华空间纵深 |
| R3 | 光源必须可追溯——自然光的方向与时刻匹配、奢华人工光源的位置和色温合理 |
| R4 | 场景必须有前/中/后景空间层次，前景画框→中景主体→后景延伸 |
| R5 | 必须有当代顶奢商战豪门辨识度——落地窗城市天际线/水晶吊灯/胡桃木/大理石/真皮/艺术藏品等顶奢符号 |
| R6 | 必须有真实奢华材质厚重感——大理石纹理反光/胡桃木包浆/真皮毛孔/水晶折射/金属奢华光泽，非塑料非廉价非样板间 |
| R7 | **严禁出现任何人物、人影、人体轮廓、剪影** |
| R8 | 必须声明"真人实拍摄影 + 非3D渲染非CG"核心锚定 |
