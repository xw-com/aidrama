## 一、摄影机前的权谋情绪——面孔、眼神、微表情

> 真人商战豪门的情绪不来自"义体光效"或"渲染参数"，而来自真人演员在摄影机前的微表情。以下映射面向摄影机捕捉权贵人物的方式。

| 情绪输入 | 面容描述 | 眼神描述 | 微表情补充 |
|---|---|---|---|
| 强势 / 威压 | 面部线条利落紧致，下颌微收 | 眼神笃定有力，直视不躲闪 | 嘴角平直微抿，下颌微收，气场沉稳的掌控感 |
| 城府 / 算计 | 神情淡然，面部肌肉松弛克制 | 目光深邃难以捉摸，似在评估一切 | 嘴角平直不轻易上扬，眼底有隐而不露的算计 |
| 冷峻 / 戒备 | 面部线条微微绷紧，不夸张 | 眼神锐利克制，注视有力但不张扬 | 下颌收紧，表情克制，身体语言防御 |
| 优雅 / 从容 | 眉目舒展，面部柔和精致 | 眼神温润从容，不卑不亢 | 嘴角自然微扬，教养式的得体，世家贵气 |
| 惊讶 / 触动 | 眼尾微抬，眉毛自然上扬 | 眼神骤然聚焦，瞳孔微扩 | 嘴角微启，表情鲜活但不失克制 |
| 沉思 / 权谋 | 神情淡然，眼部周围肌肉放松 | 目光放远失焦，像在看但不在看 | 表情平静，可能单手持威士忌杯或手指轻点桌面 |
| 得意 / 嘴角藏笑 | 眼角出现极淡笑纹，眼型微弯 | 眼神含光，眼底有压抑的胜券在握 | 嘴角微扬后即收，压抑的得意不外露 |
| 疲惫 / 倦怠（卸下权谋） | 眼窝微陷，面部整体松弛 | 目光朦胧，眼皮微沉 | 眉眼低垂，松开领带/解袖扣，卸下权谋后的真实 |
| 隐忍 / 压抑 | 面部线条绷紧但克制 | 眼神有压抑的情绪，注视沉稳 | 下颌紧咬后放松，手部可能有微弱的握拳/松开 |
| 决绝 / 破釜 | 面部线条清晰，下颌微抬 | 眼神笔直向前，不回避不躲闪 | 下巴微收或微抬，表情果敢坚定，权谋的最后一击 |

## 二、摄影机前的光——光源逻辑与氛围

### 2.1 自然光时刻

| 时刻 | 光源行为 | 色温与色调 | 空间氛围 |
|---|---|---|---|
| 清晨 | 低角度暖白日光，穿透落地窗斜入CEO办公室/豪宅客厅；海景豪宅晨光越过海平面 | 3500-4500K暖白，空气微冷 | 权力苏醒、晨光镀金、尚未运转的豪门静谧 |

## 四、摄影机语法——镜头选择与运动

### 4.1 焦段选择

| 焦段 | 叙事性格 | 适用场景 |
|---|---|---|
| 24-28mm广角 | 奢华空间包围人物、权力空间的宏大、城市天际线的俯瞰 | CEO办公室空镜、宴会厅全貌、豪宅客厅、城市俯瞰 |
| 35mm小广角 | 环境肖像、人物在权力空间中的位置 | 办公室对话、走廊行进、空间中的人物关系 |
| 50mm标准 | 人眼等价，客观中立的注视，最诚实的镜头 | 人物肖像、双人对话、权谋凝视 |
| 85mm中长焦 | 压缩空间，拉近权谋距离，背景虚化突出人物气场 | 特写、对峙对话、宴会中的注视 |
| 135mm+长焦 | 极端压缩，窥视感，将人物从奢华环境中剥离 | 宴会中隔离的个体、远眺、权谋的距离感 |

### 4.2 景别选择

| 景别 | 取景范围 | 叙事功能 |
|---|---|---|
| 大特写 | 眼睛/嘴唇/手指/名表/签字笔/红酒挂杯 | 权谋爆发点、关键信息揭示、感官聚焦 |
| 近景 | 头顶至胸部以上 | 人物情感、对话反应、面部权谋微表情 |
| 中近景 | 头顶至腰部 | 人物互动、举杯/递文件手势、对话中的身体语言 |
| 中景 | 头顶至膝盖上下 | 人物与奢华空间的初级关系、多人同框 |
| 全景 | 人物全身+部分奢华环境 | 人物在权力空间中的位置、行动路线 |
| 大全景/空镜 | 奢华空间全貌，人物极小或无人物 | 空间叙事、情绪缓冲、隐喻留白 |

### 4.3 摄影机运动

| 运动方式 | 视觉心理 | 使用场景 |
|---|---|---|
| 固定 | 冷静威压的注视，让权谋自己说话 | 对话、办公室博弈、空镜留白 |
| 缓推 | 真相逼近、压力累积、注意力聚焦 | 权谋对峙、秘密揭露、情绪升温 |
| 稳定器流动 | 优雅流动，奢华空间的诗意展示 | 人物登场、豪宅/会所空间展示、过渡 |
| 缓拉 | 拉开距离、揭示全貌、情绪抽离 | 离别、章节收束、权力空间展示 |
| 跟拍 | 与人物同行、陪同感 | 走廊行进、商务座驾、城市行走 |
| 摇镜 | 视线转移、空间关系交代 | 人物视线引导、空间与空间的关系 |

## 五、固定风格锚定词

**摄影锚定（必选）：**

真人实拍摄影，真人电影剧照，当代顶奢商战豪门，电影级摄影，自然光与奢华人工光调度，真实色彩科学

**人物质感（含人物镜头时必选）：**

真人写实摄影质感，真实皮肤纹理毛孔可见（精致妆容之下），不磨皮不硅胶脸，定制发型纹理有碎发，高定面料纹理可见有穿着褶皱，权谋微表情，真实肢体语言

**场景质感（含场景镜头时必选）：**

真人实拍顶奢场景摄影，真实奢华材质厚重感（大理石纹理反光/胡桃木包浆/真皮毛孔/水晶折射/金属奢华光泽），光源方向明确可追溯，大气透视自然，非样板间非塑料非廉价

**参考图一致性锚定（参考图模式必选）：**

保持人物造型、面容、发型、高定服饰与参考图完全一致，保持奢华场景风格与参考图一致，保持光影色彩基调统一，所有镜头呈现为同一人物的连续摄影记录

**风格收尾（固定）：**

真人写实摄影，当代顶奢商战豪门电影质感，电影级摄影画面，非3D非渲染非CG

**画质锁定词：**

模式A（中文）——默认：
真人摄影高清画质，电影级画面质感，画面无字幕、无水印、无标题叠字、无UI元素

模式A（中文）——画内文字场景（画面中含合同/文件/支票/招牌/屏幕等道具文字时）：
真人摄影高清画质，电影级画面质感，画面无字幕、无水印、无标题叠字、无UI元素，合同/支票/文件/招牌/屏幕等场景道具上的中文文字清晰可辨

## 六、美学禁止项

以下词汇/风格不得出现于输出提示词中：

- ❌ 3D渲染 / 3D建模 / CG / UE引擎 / Blender / PBR材质 / 次世代建模 / 体积光 / 环境光遮蔽 / 光线追踪
- ❌ 2D手绘 / 插画 / 动画 / 二次元 / 漫画 / Q版 / 低多边形
- ❌ 写实摄影（英文禁止 photorealistic / realistic photography——真人商战豪门是"真人实拍摄影"live-action cinematic photography，不是"拟真渲染"）
- ❌ 过度磨皮 / 塑料假面 / 零毛孔 / 硅胶脸 / 蜡像感 / AI感平滑
- ❌ 古风 / 古装 / 汉服 / 宫廷 / 仙侠 / 武侠 / 民国 / 赛博朋克 / 科幻 / 机甲 / 西方奇幻 / 中世纪
- ❌ 市井烟火 / 普通民居 / 老小区 / 菜市场 / 便利店 / 夜市排档 / 出租屋 / 校园 / 乡村田园 / 工厂
- ❌ 塑料质感 / 廉价仿品 / 假奢华 / 非顶奢元素
- ❌ 人体结构错误 / 肢体畸形 / 面部崩坏 / 比例失调
- ❌ 高饱和荧光色 / 霓虹溢色 / 廉价滤镜感
- ❌ 非当代顶奢商战豪门的架空场景 / 无质感的 generic luxury
