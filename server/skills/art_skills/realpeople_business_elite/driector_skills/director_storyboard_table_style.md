# 分镜表真人商战豪门约束 · 真人实拍顶奢商战豪门 · 技法参考

---

## 一、分镜表定位

分镜表是导演将剧本转化为镜头语言的核心工具。本约束面向 Seedance 2.0 视频生成，所有光影、动作、空间描述均采用模型可执行的具象语言。不做抽象的情感概括，不写模型看不懂的渲染参数。

---

## 三、光影与氛围——Seedance 2.0 物理光源描述

### 3.1 同场戏光影统一

一场戏内不应出现两种以上核心光影方案，除非有叙事驱动的光源变化（如有人打开壁灯、日落天光亮过室内灯、从CEO办公室走到雨夜街道）。光源变化必须在分镜表中标注触发事件。

### 3.2 光源语句法（每个镜头必须包含）
[光源] 主光：{光源类型}，{方向}，{色温值K}，{软硬}
[光源] 辅光/环境光：{光源类型}，{方向}，{色温值K}
[光比] 约1:{X}
### 3.3 情绪 → 光源矩阵

| 情绪 | 光源配方（Seedance 2.0 可直接填入） | 视觉关键词 |
|---|---|---|
| 商务权谋 | 落地窗冷白主光（5000-5500K）从落地窗方向侧入，屏幕冷光（6500K）补面。光比约1:3 | 中性偏冷，材质清晰 |
| 权力高光 | 落地窗午后暖金光45°侧入（3000-3500K），城市天光5500K环境补光。光比约1:3 | 鎏金、威严、登顶 |
| 豪门宴会 | 水晶吊灯奢华暖光主光（2700-3000K）+ 桌烛点光（2200-2500K）。光比约1:3多层 | 华贵、多层光斑、浮华 |
| 私密密谋 | 暖色壁灯主光（2700-3200K），暗部保留物体轮廓。光比约1:8 | 暖调孤岛、私密权谋 |
| 雨夜抉择 | 湿街面反射城市霓虹（冷基底6000K + 暖2800K光斑），车窗/落地窗雨痕散射。光比约1:6 | 冷暖共存、命运孤独 |
| 悬疑对峙 | 侧方硬光（董事会议顶冷白4800K或落地窗冷光）单光源，大光比约1:8。光比约1:8 | 压抑、博弈、不确定 |
| 奢享浮华 | 户外自然日光（5500-6000K），海面/水面反光漫射补光。光比约1:2 | 高调通透、浮华 |
| 深夜卸下 | 单一奢华暖光源（壁灯/落地窗外城市灯2800-3200K）形成孤岛式照明。光比约1:8 | 极简光源、私密脆弱 |

### 3.4 冷暖色调与叙事阶段

- **冷光主导**（5000K+）：商务权谋、董事会博弈、冷峻对峙、雨夜
- **暖光主导**（2700-3500K）：权力高光、豪门宴会、私密密谋、世家温情、金色时刻
- **冷暖共存**：过渡时刻（蓝调时刻+初亮吊灯）、雨夜（冷环境+暖光斑）、车内密谈（暖氛围灯+冷车外街景）
- **光源变化 = 权谋信号**：落地窗外天空从日间冷白渐变至傍晚暖金=时间流逝与权谋推进；从CEO办公室冷白走到雨夜车内暖光=场景与权谋情绪的切换

### 3.5 Seedance 2.0 光影适配要点

- 色温数字帮助模型校准白平衡倾向：`色温约3000K暖金` 优于 `暖光`
- 光比数字帮助模型建立明暗意识：`光比约1:8` 优于 `低调暗调`
- 光源必须有明确来源：`从画面右侧落地窗45°斜入` 优于 `侧光`
- 环境光的反射路径描述：`湿街面反射城市霓虹冷暖光斑` 优于 `地面有冷暖反光`

## 四、环境动态——让权谋画面呼吸

### 4.1 动态密度

每 3-4 个镜头至少安排一个有环境动态的镜头。静态对话戏也不例外——至少有一个镜头里雪茄烟雾在升腾、红酒液面在轻微晃动、落地窗外远处有车流灯光扫过。

### 4.2 商战豪门环境动态元素（Seedance 2.0 可执行）

| 场景 | 可描述的环境动态 |
|---|---|
| CEO办公室 | 落地窗外远处城市车流灯光偶尔扫过天花板、雪茄烟雾在落地窗逆光中缓慢上升、威士忌杯里冰块极缓慢融化产生的细微气泡、真皮座椅的轻微吱呀 |
| 董事会会议室 | 投影大屏的画面微弱闪烁、百叶窗条纹光影随窗外光线角度缓慢移动、中央空调出风口纸张的轻微颤动、名表机芯的微弱嘀嗒 |
| 豪宅客厅 | 水晶吊灯水晶挂件被空调气流吹动微响、落地窗外海面/城市灯光的明灭、羊毛地毯纤维被脚步压下后的缓慢回弹、艺术藏品的静谧 |
| 私人会所/酒窖 | 雪茄尖端红点光的微弱明灭、壁灯火焰的轻微跳动（若有烛火）、酒窖中红酒瓶身的微弱反光变化、暖色点光的静谧 |
| 宴会厅 | 水晶吊灯的多层光斑随吊灯微晃而流动、桌烛火焰的轻微跳动、水晶杯碰撞的微响、鲜花花瓣的静止 |
| 游艇甲板/高尔夫 | 海浪拍打游艇甲板的节奏、游艇马达的低鸣、海风吹动衣摆约15度角、高尔夫球杆击球的瞬间 |
| 商务座驾内饰 | 车窗外街景/雨痕的流动、车内氛围灯的稳定暖光、真皮座椅的轻微形变、车过颠簸时杯中液体的晃动 |
| 雨夜奢华街道 | 雨打落地窗/车窗和路面、湿街面反射的城市霓虹随车流经过而流动、远处偶尔驶过的车灯在湿街面拉出光带 |

### 4.3 Seedance 2.0 环境动态描述规范

- 动态必须有具体轨迹和速度：`雪茄烟雾缓慢上升约每秒10cm，呈半透明蓝灰色` 优于 `烟雾缭绕`
- 光源动态与空间光源逻辑一致：`云朵遮住太阳时，落地窗光面积缩小约40%，持续约3秒后恢复`
- 禁止无来源的动态：没有风吹=水晶挂件不动。室内没有开窗=没有风

## 五、人物动作节奏——Seedance 2.0 物理逻辑具象化

### 5.1 动作描述铁律

所有人物动作必须描述：**轨迹 + 速度/时长 + 身体部位协调 + 对周围奢华物体的影响**。

### 5.2 商战豪门日常动作具象库

| 动作 | Seedance 2.0 可执行描述 |
|---|---|
| 起身离桌 | 双手撑住真皮办公椅扶手，膝盖向前移动，0.5秒后身体重心前移至双脚，再1秒后站直，站直后整理西装下摆停顿约0.5秒——全程约2秒 |
| 转头望落地窗 | 头缓慢向右旋转约45度，视线从桌面合同移至落地窗外城市天际线，旋转过程约1秒，到位后目光停在远处约1秒 |
| 品鉴威士忌 | 右手持水晶威士忌杯，杯口靠近嘴唇，倾斜杯子约15度，琥珀色液体接触上唇，小口啜饮约1秒，杯子下降回原位约1秒 |
| 举杯致意 | 右手持水晶高脚杯杯柄，杯身倾斜约20度，红酒液面沿杯壁回流形成挂杯，杯口缓慢向对方致意，全程约2秒 |
| 走向落地窗 | 从真皮办公椅起身（约2秒），向画面右侧落地窗匀速行走约4步（约3米距离，耗时约3秒），停在距落地窗约0.5米处 |
| 签字落笔 | 右手持镀金钢笔，笔尖接触合同文件纸面，手腕带动笔尖书写约3个汉字，落笔后钢笔缓慢抬起——全程约3秒，纸面留下钢笔墨迹 |
| 整理西装/袖扣 | 右手整理西装下摆，随后手指轻触左袖袖扣确认位置，双肩向后微展让西装贴合肩部——全程约3秒 |
| 解领带/松袖扣（卸下权谋） | 右手伸至颈间，手指勾住领带结缓慢向下拉松约3cm，随后左手解开盘扣——全程约4秒，颈部明显放松 |
| 递文件/合同 | 右手持合同文件夹从胸前高度向前伸出约40cm，文件正面朝向对方，左手轻扶文件下沿——全程约1.5秒 |
| 凝视对峙 | A与B隔董事会长桌对坐，A身体前倾约10度，双手交叠于桌面，目光直视B的眼睛不眨约3秒 |

### 5.3 动作节奏与叙事场景

- **日常权谋/文戏**：动作沉稳克制，每个微动作标注时长和轨迹。节奏舒缓——不是慢，是"权力的从容"
- **情绪波动场景**：动作幅度和速度略微增加。人物可能在对话中不自觉地握紧手中的水晶杯、呼吸带动肩膀起伏更明显
- **冲突场景**：动作干脆利落，但仍有物理轨迹。推搡/拍桌须具体到"右手拍在胡桃木桌面，桌面震动让水晶杯轻响，对方重心向后偏移约20cm"
- 禁止：无叙事理由的快速动作堆砌、无物理逻辑的瞬移、"做了个手势"等含糊描述

### 5.4 服饰动态

高定服饰的动态是画面的天然资产——不是"布料模拟参数"，而是"西装下摆被转身带动约15度角""晚礼服裙摆随步伐左右轻摆约10cm""真丝领带随身体前倾自然垂落"。在分镜表画面描述中标注高定服饰的动态细节。

## 六、空间逻辑具象化——Seedance 2.0 空间坐标系统

### 6.1 每镜头必须声明的空间信息
水平位置：画面左/中/右，或画面左侧三分之一处
纵深位置：距镜头{数值}米，前景/中景/背景
人物与场景的关系：距{固定物}{数值}米（"距落地窗1米"、"董事会长桌主位"）
（若双人以上）人物A与B的相对距离和朝向
### 6.2 站位衔接示例
【片段A尾部】
A站在CEO办公室落地窗前，距落地窗约0.5米，面朝窗外城市天际线，位于画面中央偏右，距镜头约4米。
午后落地窗暖金光从画面右侧斜入（约3200K）。
A右手持水晶威士忌杯于胸前，杯子距嘴唇约15cm。

【片段B开头】
A的水晶威士忌杯刚从嘴边下降约10cm，杯子仍在胸前位置。A仍站在落地窗前（位置未变）。
窗外天色已转为蓝调时刻——天空深蓝紫，城市建筑轮廓灯与夜景灯已亮起。
室内壁灯已开（画面左侧边桌），暖黄光（约3000K）照在A的左侧脸颊。
### 6.3 空间变化必须具象

| 抽象（禁止） | Seedance 2.0 具象 |
|---|---|
| 他走近了 | A从画面背景（距镜头约5米、办公室门口位置）向镜头方向匀速行走4步（约3米），停在距镜头约2米的真皮沙发前——耗时约4秒 |
| 两人对坐对峙 | A位于画面中央偏左（距镜头约3米），B位于画面中央偏右（距镜头约3米），两人隔董事会长桌对坐，相距约2.5米 |
| 从办公室到雨夜车内 | A从CEO办公室（距镜头约3米）走向门口，推开胡桃木门（门向内旋转约80度），右脚跨出门槛，切至下一镜头：商务座驾后排，雨夜车窗外霓虹模糊，车内氛围灯暖光（约2800K）照亮A侧脸 |

## 七、运镜规范——Seedance 2.0 摄影机运动

### 7.1 允许的运镜

| 运镜 | Seedance 2.0 描述 | 适用场景 |
|---|---|---|
| 固定 | 摄影机固定不动，画面静止 | 对话、办公室博弈、空镜留白、权谋凝视 |
| 缓推 | 摄影机向主体缓慢推进，推进速率约每秒0.3米 | 权谋升温、真相逼近、压力累积、注意力聚焦 |
| 稳定器流动 | 摄影机平滑匀速移动，无晃动 | 人物登场、奢华空间展示、过渡、豪宅漫游 |
| 缓拉 | 摄影机向后缓慢拉远，拉远速率约每秒0.3米 | 离别、收束、揭示权力空间全貌 |
| 跟拍 | 摄影机与人物保持约2米距离同步移动 | 走廊行进、商务座驾、城市行走 |
| 摇镜 | 摄影机原地水平/垂直旋转 | 视线转移、空间关系交代 |

### 7.2 禁用运镜

- 无叙事目的的快速甩镜、急推急拉（推拉速率超过每秒1米）
- 超过3秒的剧烈手持晃动（除非受击/眩晕叙事）
- 无逻辑花式转场——划屏、旋转、百叶窗、翻页等特效转场
- 摄影机无理由的360度旋转

### 7.3 真人商战豪门运镜哲学

- 固定机位与缓推是第一选择——让观众看到真实的权贵人物在真实奢华空间里自然存在
- 缓推在权谋段落使用——压力的累积与真相的逼近
- 运动镜头的起幅和落幅必须平稳，运动过程匀速——禁止突然加速或急停

## 八、转场规范

### 8.1 允许的转场方式

| 转场 | 视觉执行 | 叙事功能 |
|---|---|---|
| 硬切 | 直接切换 | 同场戏内镜头切换（默认） |
| 光影匹配转场 | 两个场景在相近光影逻辑下切换 | 时间流逝、平行权谋叙事。例：A处落地窗外晨光 → B处落地窗外晨光 |
| 空间匹配转场 | 两个奢华空间在构图或元素上呼应 | 场景跳转。例：CEO办公室门关上的瞬间 → 豪宅客厅门打开的瞬间 |
| 空镜过渡 | 插入奢华场景空镜（3-5秒） | 情绪缓冲、章节划分、时间流逝暗示 |
| 焦点转场 | 前镜焦点从主体移至背景，后镜从模糊背景中逐渐聚焦主体 | 空间切换、权谋注意力的转移 |

### 8.2 禁止的转场

- 纯视觉特效转场（翻页、划屏、百叶窗、马赛克）
- 无叙事逻辑的旋转/缩放转场
- 同一场戏内使用超过两种转场方式

## 九、音画同步规划（Seedance 2.0 专属）

### 9.1 环境音标注规范

每场戏标注 1-2 个核心环境音，写在分镜表的环境音列：

| 场景 | 建议环境音 |
|---|---|

## 十一、空镜使用规范

### 11.1 空镜不是"没东西拍"

空镜是权谋情绪容器。每个空镜必须有叙事目的和具体的奢华视觉内容：

| 空镜类型 | 叙事目的 | 示例 |
|---|---|---|
| 场景建立 | 新奢华空间首次出现——让观众看清楚这是什么权力场所 | CEO办公室大全景：胡桃木办公桌、落地窗、城市天际线、真皮沙发 |
| 情绪缓冲 | 高权谋段落后的喘息 | 落地窗外雨滴沿玻璃滑落，速度约每秒2cm，远处城市霓虹模糊 |
| 时间流逝 | 暗示时间过去了 | 同一扇落地窗外的天空从午后湛蓝渐变至蓝调深紫，城市灯逐渐亮起 |
| 隐喻留白 | 以奢华物代权谋情 | 胡桃木桌上未喝完的威士忌，杯壁有挂杯，旁边放着未签字的合同 |
| 转场衔接 | 前后两个奢华空间的自然过渡 | 水晶吊灯特写——前一场的宴会厅，下一场是私人酒窖 |

### 11.2 空镜 Seedance 2.0 描述规范

空镜也必须遵循光源+质感+动态的描述铁律：午后落地窗暖金光从右侧斜入（约3200K），在空荡荡的董事会长桌上投下百叶窗的条纹光斑，
光斑随窗外云朵移动而缓慢变化宽度和位置，约5秒后完全变暗——一朵云挡住了太阳。
胡桃木长桌有细微划痕和会议留下的水杯圈痕，真皮高背椅排列整齐。
