# Q版SD萌系风格说明

本风格专为"Q版SD萌系"题材打造，所有美术提示词、规范和生成内容均严格限定于：

- **Q版SD手绘动画**：以二头身三头身萌系美学为锚的Q版手绘动画风格，涵盖萌系日常、糖果世界等题材
- **治愈可爱美学**：圆润柔和线条与夸张可爱表情结合，治愈感与萌系时尚感并存
- **贴纸平涂渲染技法**：贴纸/印章式平涂上色与明亮低阴影技术，圆润饱满结合数字渲染
- **糖果世界萌系意境**：糖果屋、云朵乐园、甜品王国等治愈氛围、留白构图、明亮深远的萌系美学表达
- **圆润笔触**：圆润柔和的线条、饱满的细节、精致的角色与场景设计
- **Q版SD萌系电影质感**：治愈级构图、明亮光影层次、动态张力、情绪氛围

## 适用范围

- Q版SD萌系题材的AI美术生成（角色、场景、道具、分镜等）
- 需要治愈可爱美学、贴纸平涂渲染、糖果世界意境的视觉创作
- Q版动画、游戏美术、表情包设计、概念设计、插画创作

## 严禁内容

- 写实人体比例/3D写实渲染
- 暗黑血腥/哥特/恐怖风格
- 硬核机甲/赛博朋克/过度成人化元素
- 锐利硬朗线条/复杂写实光影重阴影/低精度
- 高对比压抑/色彩混乱/风格不统一/审美崩坏
