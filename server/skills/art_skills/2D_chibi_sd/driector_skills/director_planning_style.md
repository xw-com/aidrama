# Q版SD萌系约束 · Q版SD萌系 · 技法参考

---

## 一、色调体系与画面基调

- **色调基底** — 全片以核心色盘为基底：奶白（C1 #FBF5EE）、薄荷（C2 #A8E0C8）、樱花粉（C3 #F5B8C8）、粉蓝（C4 #A8C8E8）、鹅黄（C5 #F0D89A）、可可棕（C6 #6B4F3A）、蜜桃橙（C7 #F5B080）、奶油黄（C8 #F5E0A0）、薰衣草（C9 #C8B0E0）、莓果紫（C10 #B88AC8），整体色温偏暖（5200-6000K），饱和度中（50-65%），呈现萌系糖果色盘饱满的治愈可爱画面
- **冷暖叙事对比** — 暖色（樱花粉 C3、蜜桃橙 C7、奶油黄 C8、鹅黄 C5）作为正向情感/甜蜜/庆典的视觉信号；冷色（粉蓝 C4、薰衣草 C9、薄荷 C2）作为梦幻/空灵/静谧的视觉信号。本风格整体明亮高调，冷暖切换应与故事弧线同步，但冷暖对比始终柔和，不出现高对比压抑
- **冷暖分配策略** — 派对庆典/甜蜜互动段落使用暖色调（樱花粉 + 奶油黄 + 蜜桃橙）；云朵梦幻/星夜安睡段落使用柔和冷调（粉蓝 + 薰衣草 + 奶白）；花园活力/萌系日常段落使用薄荷 + 鹅黄清新暖调
- **色盘先行原则** — 段落规划需先绑定情绪场景（萌系日常/糖果甜蜜/派对庆典/云朵梦幻/花园活力/星夜温馨等），再确定主色+辅色与光影方案，避免"剧情对了但情绪不对色"
- **禁用色域** — 高饱和荧光色、霓虹色、数码感强色彩、高对比压抑色调均与本风格不兼容。色相偏移容差 ±8°，饱和度偏移 ±10%，明度偏移 ±12%

## 二、光影方案体系

- **光影即叙事** — 7 套光影方案对应不同情绪段落，导演规划阶段应在段落层面确定光影基调方向，而非逐镜指定
- **贴纸光影为锚** — 所有光影方案必须保持贴纸平涂质感，阴影使用同色系柔和加深，禁止黑色硬阴影、复杂写实重阴影，允许柔和景深虚化等明亮渲染技法
- **光源角度** — 正给镜头默认 38.5° 斜射明亮柔光（贴纸平涂质感），侧给镜头可适当调整

| 光影方案 | 方案名 | 色调倾向 | 适用情绪 |
|---|---|---|---|
| A | 明亮柔光 | 奶白底 + 奶油黄暖肤光 | 萌系日常、温馨甜蜜、治愈清新 |
| B | 糖果光泽 | 樱花粉 + 鹅黄贴纸光泽 | 糖果甜蜜、心动约会、惊艳登场 |
| C | 暖灯柔影 | 蜜桃橙暖主导 + 莓果紫柔和暗部 | 夜间温馨、亲密升温、暖意绵绵 |
| D | 星光柔辉 | 薰衣草 + 粉蓝冷光 + 鹅黄星点 | 星夜安睡、思念独处、宁静清冷 |
| E | 窗光透亮 | 奶白底 + 侧光柔和斑驳 | 温馨室内、学园日常、日间静谧 |
| F | 派对华辉 | 蜜桃橙 + 鹅黄高光 + 莓果紫星闪 | 派对庆典、生日盛大、正式欢乐 |
| G | 云朵柔光 | 粉蓝 + 奶白均匀柔光 + 薰衣草点缀 | 云朵梦幻、空灵意境、轻盈治愈 |

- **冷暖光分配** — 暖色光（蜜桃橙/奶油黄/樱花粉）适用于正向情感/甜蜜/庆典段落；星夜安睡/云朵梦幻段落使用柔和冷光。导演可根据叙事需要调整冷暖切换点，但整体保持明亮高调
- **氛围方向映射** — 每场戏的氛围方向应能映射到上述光影方案（A-G）的某一方向，确保视觉一致性

## 三、质感方向

- **贴纸平涂为锚** — Q版SD萌系的核心：圆润柔和线条、贴纸平涂、明亮低阴影渲染、色块平滑均匀、禁止色块断层/色彩溢出
- **圆润柔和线条 + 治愈质感** — 这是画面质感的锚点。不是写实摄影，不是 3D CG，是Q版手绘贴纸平涂加萌系美学的融合
- **材质萌系化** — 所有服化道的材质必须以贴纸平涂呈现：糖果的晶莹光泽用平滑色块、绒毛的柔软用柔和漫反射色块、木质的圆润用柔和色泽色块。禁止"3D 感"和"写实摄影感"
- **皮肤质感** — 奶白粉嫩基调、贴纸平涂、柔和光泽、明亮质感、圆形腮红、皮肤柔和透亮。禁止哑光/死白/蜡感/油光/复杂写实重阴影/过曝
- **Q版不等于扁平** — Q版SD萌系强调在贴纸平涂基础上通过柔和光影层次、景深虚化、明亮高调等手段增加空间感与治愈感，而非扁平无纵深的低幼卡通风格

## 四、Q版SD萌系场景空间元素

Q版糖果世界观特有的场景元素及其视觉叙事功能：

- **糖果屋/云朵塔/像素小屋/圆润家具** — 天然的萌系构图道具，制造圆润饱满的层次感与空间纵深，以贴纸平涂呈现精致糖果细节
- **花园/樱花树/薄荷草地/糖果花** — 留白构图的天然载体，景即情：满园花开 = 治愈、独坐星空 = 安睡、花瓣飘落 = 浪漫、云朵飘动 = 梦幻空灵
- **星星灯/暖灯/窗光/星点光** — Q版世界的光源载体，星星灯 = 暖/温馨（方案C/E）、星点光 = 冷/静谧（方案D）、暖灯 = 夜间/温馨（方案C）、窗光 = 日常/静谧（方案E）
- **糖果屋村/甜品王国/云朵乐园/像素小镇** — 建筑元素以萌系美学呈现，圆润饱满、贴纸线条清晰，材质带圆润使用痕迹/柔和包浆感，禁止全新无瑕的"塑料感"
- **段落间用场景空镜过渡** — 本风格有丰富的场景资产（不同时段/天候/景别变体），段落衔接建议用场景空镜做情绪缓冲，不要硬切
- **转折点用视觉而非台词** — 优先使用画面手段（光影柔和突变、景别跳切、空镜隐喻）而非依赖对白解释
- **前中后景层次** — 所有场景必须具备前/中/后景，杜绝扁平，室外必须包含空气透视（远景柔和）

## 五、萌系乐器与环境音

Q版糖果世界观下的声音元素约束：

### 乐器选择

- **木琴/马林巴** — 治愈、清新、灵动段落的核心乐器，与萌系日常/花园活力氛围高度适配
- **尤克里里** — 轻快、活泼、元气段落，拨弦的明亮感适合甜蜜互动
- **口风琴/口琴** — 温馨、怀旧、思念段落，柔和音色适合星夜安睡
- **铃铛/小风铃** — 灵动、梦幻、治愈段落的点缀，与云朵梦幻/糖果甜蜜氛围适配
- **合成器 pad/音乐盒** — 梦幻、空灵、童话段落，铺底增加治愈感与童话氛围
- 轻打击（沙锤/手鼓）可增加派对节奏感但不宜喧宾夺主

### 乐器组合策略

| 情绪阶段 | 乐器组合 |
|---|---|
| 平稳/开场/收尾 | 音乐盒独奏 或 木琴 + 铃铛 |
| 梦幻/空灵/意境 | 合成器 pad + 木琴 + 小风铃 |
| 治愈渐浓 | 口风琴 + 木琴 |
| 甜蜜互动/心动 | 尤克里里 + 音乐盒 |
| 派对/庆典/盛大 | 尤克里里 + 手鼓 + 木琴 + 铃铛 |
| 萌系日常/元气 | 尤克里里 + 木琴 |
| 星夜安睡/温馨 | 口琴 + 音乐盒 + 合成器 pad |

### 萌系环境音

- **典型环境音层次** — 花瓣飘落 / 糖浆潺潺 / 风过花树 / 糖果店叮当 / 星夜虫鸣 / 布料柔软摩擦 / 小风铃轻响 / 棉花云轻飘 / 萤火虫光点微响 / 小气泡啵啵
- **每场戏标注 1-2 个核心环境音**，帮助后续音效设计。环境音层次越丰富，Q版糖果场景越有沉浸感
