# 分镜表Q版SD萌系约束 · Q版SD萌系 · 技法参考

---

## 一、分镜表定位

分镜表是导演将剧本转化为镜头语言的核心工具。以下仅提供Q版SD萌系风格在分镜表层面的约束规范。

---

## 二、光影与氛围

- **贴纸光影统一** — 一场戏内光影方案必须保持贴纸平涂一致性，阴影使用同色系柔和加深（禁止黑色硬阴影、复杂写实重阴影），除非有明确的叙事转折（如暖灯熄灭→星光柔辉）
- **情绪色盘绑定** — 每场戏至少绑定 1 个情绪场景（如萌系日常/糖果甜蜜/派对庆典/云朵梦幻/花园活力/星夜温馨），并在镜头组内保持主色+辅色连续性，色彩取自核心色盘（奶白 #FBF5EE / 薄荷 #A8E0C8 / 樱花粉 #F5B8C8 / 粉蓝 #A8C8E8 / 鹅黄 #F0D89A / 可可棕 #6B4F3A / 蜜桃橙 #F5B080 / 奶油黄 #F5E0A0 / 薰衣草 #C8B0E0 / 莓果紫 #B88AC8）
- **光源角度规范** — 正给镜头光源默认 38.5° 斜射明亮柔光（贴纸平涂质感），侧给镜头根据画面需要调整。描述光影时须区分正给/侧给的角度差异，光影渲染始终保持Q版萌系贴纸质感
- **冷暖色调与叙事阶段匹配** — 星夜安睡/云朵梦幻段落使用柔和冷色调（粉蓝 + 薰衣草 + 奶白），禁用蜜桃橙/奶油黄强暖光；萌系日常/花园活力段落使用柔和暖调（奶白 + 樱花粉 + 鹅黄）；派对庆典段落使用蜜桃橙 + 鹅黄高光
- **光影转场是高级手段** — 从窗光透亮渐变到暖灯柔影 = 日转夜的时间流逝。在分镜表中标注光影变化点，转场过程中贴纸色块必须平滑渐变，禁止色块断层/色彩溢出
- **明亮渲染光效** — 允许合理使用柔和景深虚化、明亮高光、贴纸光泽等明亮渲染技法，但必须保持Q版SD萌系贴纸平涂的美学基调，禁止 3D 写实/CG 动画光效、复杂写实重阴影

---

## 三、环境动态

- **环境动态增加画面呼吸感** — 花瓣飘落、糖浆流淌、云朵轻飘、糖果闪烁、毛绒玩偶轻晃。每 3-4 个镜头至少安排一个有环境动态的镜头，避免画面"死"掉
- **Q版萌系环境元素优先** — 环境动态应选用Q版糖果世界观内的元素：花瓣、糖霜、轻烟、糖浆、风过花树、星星灯闪烁、云朵流动、萤火虫光点、小气泡啵啵，禁止出现写实成人化元素
- **贴纸动态质感** — 环境动态元素（花瓣/糖霜/云朵等）必须保持贴纸平涂质感与圆润柔和线条，禁止出现 3D 粒子特效或写实流体效果

---

## 四、Q版SD萌系动作节奏

- **动作萌系且带治愈感** — 人物动作默认轻快活泼，可在关键帧上做Q版夸张处理（如开心时的蹦跳、惊讶时的呆萌定格、委屈时的嘟嘴），起身、转身、抬手应标注"轻快/萌系"
- **服饰动态是核心画面资产** — Q版萌系服饰（蓬松裙摆、小斗篷、飘带、呆毛）的轻晃是天然的动态资产，可在画面描述中加入裙摆/飘带/呆毛的动态，贴纸渲染下的服饰动态应圆润柔和、层次分明
- **仪态约束** — Q版萌系人物的举止应符合治愈可爱气质：动作轻快圆润、举手投足呆萌活泼、不出现成人化的肢体语言（如冷峻、凌厉、性感）。Q版角色可在夸张表情上做萌系处理（眼睛弯月、圆腮红、嘴巴小O），肢体动作保持圆润克制
- **头身比一致** — 动作设计中角色必须保持 2-3 头身的Q版萌系比例，禁止因动态姿势而破坏头身比或回到写实人体比例

---

## 五、材质与质感约束

- **贴纸平涂为锚** — 所有镜头中人物/服饰/道具/场景的渲染必须保持贴纸平涂质感，线条圆润柔和清晰，色块平滑，禁止 3D 写实/CG 动画/照片级渲染
- **服饰材质** — 柔软棉 + 蕾丝 + 蓬松纱的质感用贴纸平涂表现，纹理必须超清晰，衣服质感清晰
- **道具材质** — 糖果晶莹光泽、绒毛柔和漫反射、木纹圆润、塑料圆润光泽，均以贴纸平涂 + 圆润柔和线条呈现，禁止写实材质渲染
- **场景材质** — 圆润边角、贴纸纹理、布料柔和褶皱、糖果轻微融化痕迹，材质带有治愈使用感但以Q版萌系笔触呈现，禁止"塑料感"的全新无瑕材质

---

## 六、色彩约束

- **核心色盘锁定** — 分镜表中所有镜头的色彩必须取自核心色盘（C1-C10），色相偏移容差 ±8°，饱和度偏移 ±10%，明度偏移 ±12%
- **禁止荧光色** — 严禁高饱和荧光色/霓虹色/数码感强的色彩出现
- **线条颜色** — 可可棕或深暖棕，禁止纯黑粗线条、锐利硬朗线条
- **阴影色** — 同色系柔和加深，禁止黑色硬阴影、复杂写实重阴影
- **整体色温** — 偏暖 5200-6000K 明亮治愈基调，对比度 30-50%（柔和明亮避免压抑），饱和度 50-65%（萌系色盘柔和饱满）

---

## 七、运镜禁忌

- **禁用压抑快速运镜** — 甩镜、急推、手持晃动与Q版SD萌系的治愈可爱气质冲突，派对庆典场景可适度加快运镜节奏但仍需保持画面柔和明亮
- **禁用花式转场** — 划屏、旋转、百叶窗等与本风格不兼容
- **禁用写实镜头语言** — 手持摇晃/纪录片式跟拍/鱼眼镜头等与Q版萌系美学冲突，破坏贴纸平涂的画面纯净感
- **禁用高对比压抑光影** — 硬光黑影、恐怖明暗对比与治愈明亮基调冲突
