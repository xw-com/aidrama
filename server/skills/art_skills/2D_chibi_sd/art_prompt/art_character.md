# 人物基础形象生成 · 约束手册

---

## 一、基础形象原则

1. **造型即灵魂** — 角色造型是核心锚点，Q版SD萌系造型，圆润柔和线条
2. **底模即基础** — 基础打底服装 + 素颜，后续服化均为叠加层
3. **四视图一致** — 面容/体型/发型/基础服装跨视图高度统一
4. **萌系气质** — 无妆状态仍需体现角色气质（治愈/呆萌/元气/软萌）

---

## 二、面容约束

> 不再固定五官特征参数，由角色描述（性别/年龄/性格/气质）驱动 AI 自由生成五官，保证人物间外观差异化。但所有面容必须服从Q版SD符号化五官美学。

### 通用要求

| 项目 | 约束 |
|---|---|
| 五官 | 由角色描述自然推导，但必须为Q版符号化五官：圆脸大眼小嘴、眼睛占面部比例夸张放大 |
| 风格底色 | Q版SD风格、贴纸平涂、圆润柔和线条、明亮低阴影、治愈明亮 |
| 气质 | 必须从角色描述提炼整体气质关键词（如治愈软萌/元气活泼/呆萌天然/乖巧可爱），并写入提示词 |
| 表情 | 夸张可爱的萌系微表情（开心/惊讶/委屈/呆萌），符合角色气质 |

### Q版五官符号化约束

| 部位 | 约束 | 提示词 |
|---|---|---|
| 脸型 | 圆润饱满、婴儿肥、小下巴 | round face、chubby cheeks、cute round face |
| 眼睛 | 超大眼睛、占面部1/3以上、水汪汪、高光闪亮 | big sparkly eyes、huge cute eyes、glistening eyes |
| 嘴巴 | 极小、樱桃小嘴、符号化 | tiny mouth、small cute mouth |
| 腮红 | 柔和粉色腮红、贴纸式圆形腮红 | soft pink blush、cute round blush stickers |
| 眉毛 | 极简符号化、淡而柔和 | simple soft eyebrows |

## 六、基础服装约束

> 基础服装无特殊约束，女性为素色萌系迷你连衣裙，男性为素色萌系小套装。正式服饰在服化衍生环节叠加。

### 女性基础服装

素色萌系迷你连衣裙，颜色以基础奶白/樱花粉为主，无花纹装饰，圆润剪裁。

### 男性基础服装

素色萌系小套装（小上衣+小短裤），颜色以基础奶白/粉蓝为主，无花纹装饰，圆润剪裁。

### 着装统一规则

- 服装风格统一，确保后续服饰叠加无色彩干扰
- Q版服装整体迷你、圆润、剪裁柔和
- 四视图服装款式完全一致
- 基础服装仅为安全打底，焦点在面容与Q版比例

## 八、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须为「素颜状态」 |
| R2 | 必须声明基础服装（女性：素色萌系迷你连衣裙；男性：素色萌系小套装） |
| R3 | 必须声明「无发饰、无配饰」 |
| R4 | 必须指定「奶白纯色背景」 |
| R5 | 必须指定「四视图一致性」 |
| R6 | 全身立像必须从头顶到脚底完整展示，严禁裁切 |
| R7 | 必须声明Q版头身比（二头身至三头身，2-3 heads tall proportion）并通过大头小身约束全身比例 |
| R8 | 人像特写必须从头顶到锁骨完整展示，严禁裁切头顶 |
| R9 | 五官必须为Q版符号化（圆脸大眼小嘴、超大眼睛占面部1/3以上） |
