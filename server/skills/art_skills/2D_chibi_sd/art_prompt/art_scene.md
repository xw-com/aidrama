# 场景图生成 · 约束手册

---

## 一、场景美学原则

1. **空间叙事** — 场景承载情绪与叙事功能，不是纯背景板
2. **层次纵深** — 所有场景必须具备前/中/后景，杜绝扁平
3. **质感至上** — 糖果/绒毛/木质/塑料/贴纸等材质纹理必须超清晰
4. **Q版萌系为锚** — 一切画面以Q版SD萌系为标准，拒绝3D写实/CG动画质感；追求圆润柔和线条、贴纸平涂、明亮低阴影

## 三、室内场景

### 空间规范

| 维度 | 约束 | 提示词 |
|---|---|---|
| 风格 | 萌系迷你房间/糖果屋/温馨小屋/像素房间 | 萌系{风格}房间 |
| 材质 | 木质迷你家具为主、布料/绒毛/塑料为辅 | 圆润迷你家具、柔软布艺、毛绒装饰 |
| 色调 | 萌系糖果色调 + 奶白墙面 + 樱花粉装饰 | 暖糖果色调、温馨陈设 |
| 纵深 | 前/中/后景层次 | 前景{元素}、中景{元素}、后景{元素} |
| 质感 | 木纹/布料垂感/糖果光泽可辨 | 纹理清晰、质感细腻 |
| 光照 | 明亮自然光源为主（窗光/暖灯），柔和明亮光影 | 自然光漫射、暖灯柔和、明亮光影 |
| 镜头感 | 贴纸平涂虚化前后景、圆润线条清晰 | sticker shading wash, soft round lines |
| 瑕疵感 | 圆润边角、贴纸纹理、布料柔和褶皱、玩偶轻微压扁 | 圆润使用痕迹、柔和褶皱、玩偶蓬松 |

| 类型 | 核心元素 | 氛围词 |
|---|---|---|
| 温馨卧室 | 小床、毛绒玩偶、星星灯、小书架 | 温馨私密、柔软治愈 |
| 糖果厨房 | 迷你灶台、甜品道具、糖果罐、马卡龙 | 糖果气息、甜蜜日常 |

| 玩具房 | 玩偶架、积木、小帐篷、贴纸墙 | 童趣盎然、萌系缤纷 |
| 学园教室 | 小课桌、黑板、贴纸公告栏、小书包 | 学园清新、元气日常 |

## 四、室外场景

### 空间规范

| 维度 | 约束 | 提示词 |
|---|---|---|
| 类型 | 糖果屋/云朵乐园/像素小镇/甜品王国/花园草地 | {场景}，{季节}，{时间} |
| 天候 | 晴/薄云/微风/糖霜雪/花瓣雨 | 晴空万里、糖霜飘落 |
| 植被 | 樱花树/薄荷草/糖果花/棉花云/果树（须符合季节） | 樱花盛开、薄荷草地 |

## 五、主视图规范

### 视图定义

> 单画面主视图，从场景中最具代表性的角度拍摄，承载空间叙事与构图重心。

| 项目 | 约束 | 提示词 |
|---|---|---|
| 视角 | 自然观察视角，构图最能体现场景主体与纵深 | hero shot、representative angle |
| 视点高度 | 默认人眼平视高度，特殊场景可俯/仰 | eye level（默认） |
| 构图 | 主体居中或符合三分法，前/中/后景层次清晰 | balanced composition |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 单画面（非拼图、非多视图、非分屏） |
| 人物 | **严禁出现任何人物、人影、人体轮廓** |
| 一致性 | 风格/材质/色调/光线统一 |
| 光线 | 单一光源逻辑，光影方向一致 |
| 画面比例 | 默认 16:9（或按调用方设定） |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 场景必须有「前中后景层次」 |
| R2 | 室外必须包含「空气透视」 |
| R3 | 场景图必须为「单画面主视图」，不得拼接多视图/分屏/网格 |
| R4 | 构图须能代表场景主体并展示前/中/后景层次 |
| R5 | 场景图中**严禁出现任何人物** |
| R6 | 必须包含Q版SD萌系关键词（chibi SD style / sticker shading / soft round lines） |
| R7 | 必须包含镜头光学特征（贴纸平涂 / 圆润柔和线条 / 明亮低阴影渲染） |
| R8 | 材质必须带有圆润使用痕迹/柔和岁月感，禁止全新无瑕的"塑料感" |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 背景纯白/纯黑/无场景 |
| X2 | 极端天候（暴风雨/雷电/恐怖暴雪，除非剧情需要） |
| X3 | 场景无纵深/无层次 |
| X4 | 植被/天候与季节矛盾 |
| X5 | 出现任何人物、人影、人体剪影或人体轮廓 |
| X6 | 画面被拼接成多视图/网格/分屏布局 |
| X7 | 3D 写实/CG 动画/硬核机甲/游戏引擎质感（禁用 3D render、CGI、Unreal Engine、Unity 等词） |
| X8 | 暗黑血腥/恐怖/锐利硬朗线条/复杂写实重阴影 |
| X9 | 材质过于干净完美、无任何使用痕迹与治愈感（避免"塑料感"） |
| X10 | 光照过于高对比压抑、无景深虚化、无镜头光学特征 |
