# 道具图像生成 · 约束手册

---

## 一、道具设计原则

1. **功能可读** — 道具用途一目了然，造型服务于功能，剪影清晰友好
2. **质感极致** — 材质纹理必须清晰可辨（魔法水晶/木质/糖果釉/金属/布料），圆润倒角
3. **卡通一致** — 所有道具必须符合欧美卡通世界观，圆润亲和、禁止写实锐利
4. **尺度明确** — 通过参照物或标注暗示道具真实尺寸
5. **纯道具独立展示** — 画面中只能出现道具本身，严禁出现任何人物、手部、肢体，道具不可处于被持有/佩戴/握持状态，必须以静物陈列方式独立呈现

## 三、多角度设定图规范

### 视图定义

| 位置 | 视图 | 角度 | 要求 | 提示词 |
|---|---|---|---|---|
| 左上 | 正面图 | 正面 0° | 道具完整正面形态 | front view |
| 右上 | 侧面图 | 侧面 90° | 厚度/轮廓/结构清晰 | side view |
| 左下 | 背面图 | 背面 180° | 道具背部结构/装饰 | back view |
| 右下 | 细节特写 | 局部放大 | 材质纹理/工艺细节 | detail closeup |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 同一画面四宫格（2×2），上下左右四视角 |
| 背景 | 奶油纯色 #F5E8C8 |
| 光线 | 柔和全局光（GI），均匀柔光，无硬阴影 |
| 比例 | 每格道具占格内主体 70%+ |
| 投影 | 允许自然地面柔和接触阴影 |
| 画面比例 | 建议 1:1 |

## 六、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须指定「奶油纯色背景」 |
| R2 | 必须明确道具材质与工艺（圆润倒角） |
| R3 | 道具造型必须符合欧美卡通世界观，圆润友好 |
| R4 | 必须声明「圆润倒角 + glossy friendly materials」卡通质感锚定 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 复杂场景背景 |
| X2 | 道具与人物同画面（本环节为纯道具图） |
| X3 | 出现任何人物形象，包括全身、半身、局部（手、手指、手臂等肢体） |
| X4 | 道具处于被持有、握持、佩戴、使用中的状态 |
| X5 | 出现暗示人物存在的元素（如手持痕迹、佩戴视角、使用姿态） |
| X6 | 写实锐利的金属/锋利尖角造型（破坏卡通友好感） |
| X7 | 中式古典/东方古典/东方古韵道具造型元素 |
