# 人物基础形象生成 · 约束手册

---

## 一、基础形象原则

1. **造型即灵魂** — 角色造型是核心锚点，3D欧美卡通造型，圆润饱满、轮廓友好、剪影清晰
2. **底模即基础** — 基础打底服装 + 素颜，后续服化均为叠加层
3. **四视图一致** — 面容/体型/发型/基础服装跨视图高度统一
4. **亲和气质** — 无妆状态仍需体现角色气质（勇敢/活泼/呆萌/威严诙谐）
5. **吸引力原则** — 剪影可读、比例夸张可爱、大眼睛灵动传神，遵循 Disney 十二原则之 Appeal

---

## 二、面容约束

> 不再固定五官特征参数，由角色描述（性别/年龄/性格/气质）驱动 AI 自由生成五官，保证人物间外观差异化。

### 通用要求

| 项目 | 约束 |
|---|---|
| 五官 | 由角色描述自然推导，不预设脸型/眼型/眉型/鼻型/唇型 |
| 眼睛 | 大眼睛（占面部比例显著放大）、瞳孔清澈通透、高光饱满有神，是角色表情核心载体 |
| 风格底色 | 3D欧美卡通渲染、高精度建模、表面散射皮肤（SSS）、柔和全局光照 |
| 气质 | 必须从角色描述提炼整体气质关键词（如勇敢机灵/呆萌搞笑/威严诙谐），并写入提示词 |
| 表情 | 中性微表情，符合角色气质，嘴角弧度自然友好 |

## 四、体型约束

> 欧美卡通比例强调夸张可爱与剪影可读，头身比小于写实，头部偏大、四肢圆润。

| 身高 | 由角色设定指定，默认范围 110-165cm | {身高}cm tall、{身高描述如：small brave kid / cute young girl} |

## 六、基础服装约束

> 基础服装无特殊约束，女性为素色卡通日常裙装，男性为素色卡通日常上衣裤装。正式服饰在服化衍生环节叠加。

### 女性基础服装

素色卡通日常连衣裙或上衣短裙，颜色以基础友好色为主，无花纹装饰，圆润友好剪裁。

### 男性基础服装

素色卡通日常上衣与裤装，颜色以基础友好色为主，无花纹装饰，圆润友好剪裁。

### 着装统一规则

- 服装风格统一，确保后续服饰叠加无色彩干扰
- 除面部/手部/颈部外基本覆盖
- 四视图服装款式完全一致
- 基础服装仅为安全打底，焦点在面容与体态
- 服装倒角圆润、无锐利尖角，体现友好亲和

## 八、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须为「素颜状态」 |
| R2 | 必须声明基础服装（女性：素色卡通日常连衣裙；男性：素色卡通日常上衣裤装） |
| R3 | 必须声明「无发饰、无配饰」 |
| R4 | 必须指定「奶油纯色背景」 |
| R5 | 必须指定「四视图一致性」 |
| R6 | 全身立像必须从头顶到脚底完整展示，严禁裁切 |
| R7 | 必须声明角色身高并通过夸张头身比换算约束全身比例（儿童/萌系默认 110-165cm/3-5头身，英雄/男性默认 150-185cm/4-6头身） |
| R8 | 人像特写必须从头顶到锁骨完整展示，严禁裁切头顶 |
| R9 | 必须声明「大眼睛 + 表面散射皮肤SSS + 圆润倒角」卡通锚定 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 基础服装以外的任何服装/配饰/妆容 |
| X2 | 单一硬光正顶光/正底光/刺眼冷色光 |
| X3 | 写实摄影肤色 / 真实毛孔质感（破坏卡通感） |
| X4 | 复杂场景背景（必须纯色） |
| X5 | 扁平2D/赛璐璐/无3D体积感 |
| X6 | 全身立像裁切头顶或脚底，必须从头到脚完整入画 |
| X7 | 人像特写裁切头顶，必须从头顶到锁骨完整入画 |
| X8 | 忽略身高和头身比约束，身高必须明确声明并通过夸张头身比换算体现全身比例 |
| X9 | 中式古典/东方古典/东方古韵/写意画造型元素 |
| X10 | 刺眼荧光色发色或服饰色 |
