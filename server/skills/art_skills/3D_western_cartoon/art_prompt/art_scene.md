# 场景图生成 · 约束手册

---

## 一、场景美学原则

1. **空间叙事** — 场景承载情绪与叙事功能，不是纯背景板，每处细节都在讲故事
2. **层次纵深** — 所有场景必须具备前/中/后景，杜绝扁平
3. **圆润亲和** — 建筑/家具/道具造型圆润倒角、剪影友好，体现卡通吸引力原则
4. **3D为锚** — 一切画面以3D卡通渲染为标准，拒绝平面贴图/扁平2D/廉价CG感；追求柔和全局光照（GI）、表面散射、景深虚化、梦幻光晕等电影级渲染效果
5. **友好明亮** — 色彩饱满温暖、光影柔和明亮，营造温暖希望的童话氛围

## 五、主视图规范

### 视图定义

> 单画面主视图，从场景中最具代表性的角度拍摄，承载空间叙事与构图重心。

| 项目 | 约束 | 提示词 |
|---|---|---|
| 视角 | 自然观察视角，构图最能体现场景主体与纵深 | hero shot、representative angle |
| 视点高度 | 默认人眼平视高度，特殊场景可俯/仰 | eye level（默认） |
| 构图 | 主体居中或符合三分法，前/中/后景层次清晰 | balanced composition |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 单画面（非拼图、非多视图、非分屏） |
| 人物 | **严禁出现任何人物、人影、人体轮廓** |
| 一致性 | 风格/材质/色调/光线统一 |
| 光线 | 单一光源逻辑，光影方向一致 |
| 画面比例 | 默认 16:9（或按调用方设定） |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 场景必须有「前中后景层次」 |
| R2 | 室外必须包含「空气透视」与「梦幻光晕」 |
| R3 | 场景图必须为「单画面主视图」，不得拼接多视图/分屏/网格 |
| R4 | 构图须能代表场景主体并展示前/中/后景层次 |
| R5 | 场景图中**严禁出现任何人物** |
| R6 | 必须包含3D卡通渲染关键词（3D cartoon render / soft global illumination / SSS） |
| R7 | 必须包含镜头光学特征（depth of field / lens vignette / bokeh 至少一项） |
| R8 | 造型必须圆润友好、倒角圆润，禁止尖锐锐利剪影（避免廉价"CG感"与恐怖感） |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 背景纯白/纯黑/无场景 |
| X2 | 极端恐怖天候（血色雷暴/暗黑风暴/恐怖迷雾，除非剧情需要且保持卡通化） |
| X3 | 场景无纵深/无层次 |
| X4 | 植被/天候与季节矛盾 |
| X5 | 出现任何人物、人影、人体剪影或人体轮廓 |
| X6 | 画面被拼接成多视图/网格/分屏布局 |
| X7 | 低精度建模/粗糙贴图/廉价塑料质感（禁用 low-poly、rough modeling 等词） |
| X8 | 写实摄影质感/照片级真实建筑（破坏卡通感） |
| X9 | 光照过于恐怖阴暗/恐怖硬阴影/惊悚光影 |
| X10 | 中式古典/东方古典/东方古韵/写意画建筑元素 |
