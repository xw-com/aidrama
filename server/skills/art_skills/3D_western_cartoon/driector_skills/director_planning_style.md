# 3D欧美卡通约束 · 3D欧美卡通 · 技法参考

---

## 一、色调体系与画面基调

- **色调基底** — 全片以奶油（W1）、天蓝（W2）、草绿（W3）、暖橘（W4）为基底色，整体色温偏暖（3800-5000K），饱和度中高（60-80%），呈现欧美卡通友好明亮的温暖希望色调
- **情绪色盘驱动** — 六套情绪色盘（冒险启程/童话梦幻/欢乐嬉戏/魔法奇遇/反派对峙/派对庆典）对应不同叙事段落，色盘切换应与故事弧线同步
- **冷暖叙事对比** — 暖色（暖橘 W4、阳光金 W9、暖红 W5、奶油 W1）作为叙事主调，用于冒险、温情、欢腾段落；冷色（深紫 W6、星夜蓝 W10）仅用于反派对峙、神秘魔法、夜晚段落，且始终保持卡通化、不滑向恐怖
- **色盘先行原则** — 段落规划需先绑定情绪场景（冒险启程/童话梦幻/欢乐嬉戏/魔法奇遇/反派对峙/派对庆典等），再确定主色+辅色与光影方案，避免"剧情对了但情绪不对色"
- **禁用色域** — 高饱和刺眼荧光色、恐怖暗黑色域、霓虹数码色均与本风格不兼容

## 二、光影方案体系

- **光影即叙事** — 7 套光影方案对应不同情绪段落，导演规划阶段应在段落层面确定光影基调方向，而非逐镜指定
- **3D卡通渲染光影特征** — 柔和全局光照（GI）、表面散射皮肤（SSS）、梦幻光晕、景深虚化为欧美卡通风格的核心光影手段，所有光影方案均须体现高精度卡通物理材质渲染质感

| 光影方案 | 方案名 | 色调倾向 | 适用情绪 |
|---|---|---|---|
| A | 黄金时刻暖光 | 暖橘 + 阳光金高光 + 奶油底（~3800K） | 冒险启程、英雄时刻、温暖希望、主角亮相 |
| B | 明亮日光 | 天蓝 + 草绿 + 奶油底 + 明亮高光 | 户外探险、欢乐嬉戏、明亮日常、嬉戏追逐 |
| C | 梦幻柔光 | 奶油 + 天蓝柔光 + 柔和接触阴影 | 童话相遇、温情时刻、魔法初现、纯真治愈 |
| D | 魔法彩光 | 深紫 + 阳光金魔法光 + 暖橘点缀 + 丁达尔神光 | 魔法施展、奇幻时刻、学院探险、宝藏开启 |
| E | 反派舞台光 | 深紫 + 暖红 + 戏剧硬光对比（卡通化、不恐怖） | 反派出场、对峙冲突、戏剧高潮、诙谐危险 |
| F | 节日彩灯暖光 | 暖橘 + 暖红 + 阳光金 + 彩灯暖光（~2800K） | 派对庆典、烟花欢腾、盛大结尾、加冕舞会 |
| G | 星夜柔光 | 星夜蓝 + 奶油月光 + 暖橘窗光点缀 | 夜晚温情、睡前故事、思念独处、月夜童话 |

- **冷暖光分配** — 暖色光（黄金时刻/明亮日光/节日彩灯）适用于冒险、温情、欢腾段落；冷色光（魔法彩光/反派舞台光/星夜柔光）适用于魔法、对峙、夜晚段落。导演可根据叙事需要调整冷暖切换点，但反派与夜晚段落必须保持卡通化、禁止滑向恐怖暗黑
- **氛围方向映射** — 每场戏的氛围方向应能映射到上述光影方案（A-G）的某一方向，确保视觉一致性

## 三、质感方向

- **3D卡通渲染为锚** — 欧美卡通的核心：高精度建模、表面散射皮肤（SSS）、柔和全局光照（GI）、圆润倒角、大眼睛夸张表情、梦幻光晕、景深虚化，呈现电影级3D卡通渲染画面
- **SSS皮肤至上** — 所有角色的皮肤必须通过表面散射（Subsurface Scattering）可信通透：儿童脸颊苹果肌的红润内透、长辈的暖白亲和、公主的通透光泽。禁止写实毛孔/照片级皮肤
- **圆润倒角与友好材质** — 服化道造型必须圆润友好：服装的圆润领口与蓬松层次、家具的圆润倒角、建筑的圆润屋顶、道具的圆润边角。禁止尖锐锐利剪影与廉价塑料感
- **柔和全局光与梦幻光晕** — 柔和GI是欧美卡通画面的灵魂：所有场景必须有柔和全局光照与梦幻光晕，黄金时刻暖光为默认参考；室外场景必须有空气透视，魔法场景增加丁达尔神光与发光粒子
- **友好"做旧"质感** — 材质不可过于干净到"塑料感"，但也不能写实老化：木面有圆润使用痕迹、玩具有可爱划痕、布料有蓬松褶皱、糖果有晶莹糖釉。禁止廉价"塑料感"与写实"破败感"
- **卡通不等于廉价** — 欧美卡通强调电影级质感与温度感，通过SSS皮肤、柔和GI、圆润倒角、友好色彩传达温暖希望，而非依赖粗糙低多边形

## 四、欧美卡通场景空间元素

欧美卡通世界观特有的场景元素及其视觉叙事功能：

- **歪斜小屋/圆润尖塔/糖果栅栏** — 天然的童话视觉符号，制造"故事书翻开"的代入感与童趣剪影。3D渲染中圆润倒角与糖果釉光泽是画面亮点
- **巨型花朵/发光蘑菇/精灵萤火** — 奇幻氛围的天然载体，景即情：满树繁花 = 治愈希望、萤火飞舞 = 神奇冒险、糖果飘香 = 欢腾甜蜜。3D场景中发光元素的体积光与魔法粒子尤为重要
- **魔法灯/星月窗/彩虹桥** — 欧美卡通世界的光源与通路载体，魔法灯 = 暖/奇幻（方案D）、星月窗 = 冷/梦幻（方案G）、彩虹桥 = 希望/转折（方案C）。3D渲染中光源的梦幻光晕与SSS材质反射是关键
- **蓬松云朵/星辰穹顶/水晶塔** — 卡通世界的标志性元素，3D建模需体现蓬松轻盈与晶莹剔透，材质需有梦幻光晕
- **段落间用场景空镜过渡** — 本风格有丰富的场景资产（不同时段/天候/季节变体），段落衔接建议用场景空镜（如飘过的蓬松云朵、彩虹渐现、星光闪烁）做情绪缓冲，不要硬切
- **转折点用视觉而非台词** — 优先使用画面手段（光影从反派舞台光E切到黄金时刻A、景别跳切、魔法粒子爆发）而非依赖对白解释

## 五、欧美卡通乐器与环境音

欧美卡通世界观下的声音元素约束：

### 乐器选择

- **尤克里里/木吉他** — 温暖、治愈、嬉戏段落的核心乐器，最能表现友好明亮与日常温情
- **钢琴/音乐盒** — 情感、思念、梦幻段落，清澈音色适合情绪铺垫
- **铜管小号/圆号** — 英雄启程、冒险主题、主角亮相段落的标志音色，辉煌嘹亮
- **马林巴/木琴** — 喜剧、呆萌、搞怪段落的点缀，跳跃音色适合诙谐节奏
- **口哨/拨弦pizzicato** — 欢快、调皮、潜行偷吃段落，轻盈跳跃
- **合成器铺底/钟铃** — 魔法、奇幻、精灵段落，梦幻空灵
- **管弦乐团tutti** — 高潮、决战、盛大结尾段落，电影级史诗感，慎用但一用即燃
- 弦乐铺底可增加电影感但不宜喧宾夺主

### 乐器组合策略

| 情绪阶段 | 乐器组合 |
|---|---|
| 平稳/开场/收尾 | 尤克里里独奏 或 木吉他 + 口哨 |
| 童话梦幻/治愈 | 音乐盒 + 钢琴 + 钟铃 |
| 冒险启程/英雄亮相 | 铜管小号 + 圆号 + 弦乐 |
| 魔法奇遇/精灵 | 合成器铺底 + 钟铃 + 竖琴 |
| 喜剧呆萌/搞怪 | 马林巴 + 拨弦pizzicato + 口哨 |
| 高潮决战/盛大结尾 | 管弦乐团tutti + 铜管 + 打击乐 |
| 反派对峙/诙谐危险 | 低音管 + 定音鼓 + 蓄势拨弦 |
| 温情夜晚/睡前 | 钢琴 + 音乐盒 + 轻弦乐 |

### 欧美卡通环境音

- **典型环境音层次** — 鸟鸣啁啾 / 风铃轻响 / 魔法叮咚 / 糖纸沙沙 / 雪地咯吱 / 礼花噼啪 / 海浪轻拍 / 树叶沙沙 / 人群欢笑 / 钟声悠扬 / 精灵咯咯笑 / 布料窸窣
- **每场戏标注 1-2 个核心环境音**，帮助后续音效设计。环境音层次越丰富，卡通场景越有沉浸感与童趣
