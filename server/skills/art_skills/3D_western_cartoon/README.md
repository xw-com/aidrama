# 3D欧美卡通风格说明

本风格专为"3D欧美卡通"题材打造，所有美术提示词、规范和生成内容均严格限定于：

- **3D卡通渲染**：以皮克斯/迪士尼/照明/梦工厂式的三维卡通渲染技术呈现，涵盖夸张可爱的造型比例、圆润饱满的剪影、友好亲和的角色设计
- **3D卡通质感**：高精度建模、表面散射皮肤（SSS）、柔和全局光照（GI）、光泽友好材质、圆润倒角、细节清晰可辨
- **友好明亮色彩**：暖橘、天蓝、草绿、奶油、阳光金等友好明亮色盘，色彩饱满温暖、和谐明快
- **温暖希望氛围**：明亮乐观、温暖治愈、充满童趣与冒险精神、大眼睛夸张表情、吸引力（Appeal）原则
- **卡通人物造型**：3D卡通建模、夸张可爱比例、大头小身、大眼睛灵动、服饰圆润友好
- **电影级卡通光影**：柔和全局光、温暖黄金时刻光、柔和接触阴影、梦幻光晕、景深虚化等电影级渲染效果

## 适用范围

- 3D欧美卡通题材的AI美术生成（角色、场景、道具、分镜等）
- 需要3D卡通渲染质感、友好明亮色彩、温暖希望氛围的视觉创作
- 动画电影、儿童向短剧、合家欢冒险、奇幻童话、萌宠喜剧等应用场景

## 严禁内容

- 写实摄影/照片级真实感（必须为3D卡通渲染，而非真实摄影）
- 扁平2D/赛璐璐/纯手绘动画/无3D体积感的二维风格
- 中式古典、东方古典建筑、东方传统纹样、写意画等东方古典元素
- 恐怖/血腥/暗黑恐怖光影/过度惊悚的视觉表现
- 低多边形/粗糙建模/廉价塑料感/贴图模糊
- 赛博朋克/硬科幻/废土末日等冷硬风格

## 风格体验

在本风格下，您将体验到：

- 角色造型可爱亲和，3D建模圆润饱满，表面散射皮肤通透，大眼睛灵动传神，表情夸张生动
- 场景明亮温暖，色彩友好饱满，圆润倒角随处可见，柔和全局光与梦幻光晕营造童话氛围
- 道具器物圆润可爱，材质光泽友好，色彩明快统一
- 分镜与渲染均强调3D卡通质感、温暖希望基调、电影级柔和光影
