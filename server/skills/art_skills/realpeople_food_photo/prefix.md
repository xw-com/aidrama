## 二、全局色彩盘（风格基线，不是硬锁）

> 目标：统一审美而非限制创作。除「硬约束色」外，其余颜色默认优先使用，可在合理范围内偏移。

### 色彩使用层级

| 层级 | 约束强度 | 说明 |
|---|---|---|
| L1 硬约束 | 高 | 仅锁定食材主色、酱汁光泽色、餐具底色的审美方向 |
| L2 软约束 | 中 | 场景色、配饰色、点缀色优先参考色盘，可按镜头与剧情微调 |
| L3 例外机制 | 低 | 节庆/回忆/高潮戏可临时突破局部色彩，但需保留整体暖调逻辑 |

### 硬约束色（默认锁定）

| 色项 | 对应色 | 规则 |
|---|---|---|
| 食材主色基准 | C2 焦糖棕 + C7 蛋黄暖 | 默认优先，暖调食欲感核心，允许小幅明度偏移 |
| 酱汁光泽基准 | C2 焦糖棕 | 默认优先，允许深浅焦糖轻微偏移 |
| 餐具底色基准 | C1 奶白瓷 | 默认优先，允许米白/暖白轻微偏移 |

### 软约束色（推荐优先）

> C3/C4/C5/C6/C8/C9/C10 为推荐色域，用于食材点缀、桌面、冷光反差、金属厨具、草本香料等。可根据镜头氛围做同色相邻近调整。

### 情绪色盘（导演对齐版）

| 情绪场景 | 主色 | 辅色 | 光效与对比建议 | 画面关键词 |
|---|---|---|---|---|
| 新鲜出炉（高光） | C7 蛋黄暖 | C2 焦糖棕 + C1 奶白瓷 | 暖光主导，强调蒸汽与光泽，局部高光不过曝 | 诱人、热气、食欲 |
| 精致摆盘（日常） | C1 奶白瓷 | C4 抹茶绿 + C10 橄榄绿 | 柔和侧光，低对比突出质感，点缀色克制 | 精致、克制、杂志感 |
| 家常温暖（治愈） | C2 焦糖棕 | C7 蛋黄暖 + C5 木纹褐 | 暖光铺底，木质桌面温润，整体饱和适中 | 温暖、家常、治愈 |
| 街头小吃（烟火） | C3 番茄红 | C2 焦糖棕 + C8 不锈钢银 | 暖光 + 局部冷反差，烟火气强对比 | 烟火、市井、热闹 |
| 甜品时刻（甜蜜） | C7 蛋黄暖 | C1 奶白瓷 + C4 抹茶绿 | 柔和暖光，浅景深糖霜质感，低饱和精致 | 甜蜜、细腻、梦幻 |
| 烹饪过程（动感） | C2 焦糖棕 | C3 番茄红 + C8 不锈钢银 | 侧逆光火光，强对比油花飞溅，动态瞬间 | 动感、火光、专业 |
| 早餐晨光（清新） | C6 窗光冷白 | C7 蛋黄暖 + C1 奶白瓷 | 窗光漫射为主，暖点局部，清新通透 | 清新、晨光、舒展 |
| 夜市烟火（都市） | C2 焦糖棕 | C3 番茄红 + C8 不锈钢银 | 暖光源主导，暗部保留，市井灯光散景 | 夜市、烟火、氛围 |

### 情绪色盘使用规则

| 编号 | 规则 |
|---|---|
| E1 | 每条提示词至少指定 1 个「情绪场景」并绑定主色+辅色组合 |
| E2 | 单镜头主色不超过 2 个，避免颜色叙事失焦 |
| E3 | 情绪切换时优先调整光比与色温，再调整饱和度 |
| E4 | 食欲向默认遵循「暖底 + 冷点」：暖色铺底，冷光落在食材边缘勾勒质感 |
| E5 | 若与剧情冲突，以情绪色盘优先于通用推荐色，但不得突破严禁项 |

### 色温约束

| 参数 | 值 | 说明 |
|---|---|---|
| 整体色温 | 偏暖 3200-4500K（推荐） | 温暖食欲主基调 |
| 食材色温 | 微暖 3500-4500K（推荐） | 暖调还原食材本色 |
| 对比度 | 中强（建议保持） | 光泽与质感反差鲜明 |
| 饱和度 | 中高 55-75%（建议区间） | 食欲感饱满色调 |

### 容差与例外

| 项目 | 建议容差 |
|---|---|
| 色相偏移 | ±8° |
| 饱和度偏移 | ±10% |
| 明度偏移 | ±12% |

> 例外场景：甜品、夜市、烹饪火光镜头可使用更暖或更高饱和局部色块；但禁止霓虹荧光与冷蓝主调入镜。

## 三、全局约束规则

### 必守规则（所有技能继承）

| 编号 | 规则 |
|---|---|
| R1 | 必须包含「商业美食摄影」风格锚定词 |
| R2 | 必须声明「暖色调 + 微距浅景深」 |
| R3 | 食材必须使用「食材质感清晰 + 酱汁光泽」 |
| R4 | 蒸汽/新鲜感必须使用「热气蒸腾 + 新鲜质感」 |
| R5 | 纹理必须声明「纹理细节超清晰」 |

### 严禁项（所有技能继承）

| 编号 | 严禁内容 |
|---|---|
| X1 | 严禁「卡通/动漫/二次元/插画风」 |
| X2 | 严禁「高饱和荧光色/霓虹色/冷蓝主调」 |
| X3 | 严禁「美食场景缺失」（必须明确餐厅/厨房/餐桌场景） |
| X4 | 严禁「食材变形/餐具异常/肢体异常」倾向词 |
| X5 | 严禁「裸体/暴露/透视/暗示性描述」 |
| X6 | 严禁「古风/古装/汉服/传统建筑元素」 |
