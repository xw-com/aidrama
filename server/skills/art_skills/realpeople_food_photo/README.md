# 美食摄影风格说明

本风格专为"美食摄影"题材打造，所有美术提示词、规范和生成内容均严格限定于：

- **商业美食世界观**：以餐厅厨房、美食市集、家常餐桌、街头小吃摊为背景，涵盖中餐、西餐、甜品、烘焙、饮品等，杜绝现代美食场景缺失。
- **真人写实摄影**：所有角色（厨师、食客、主持人、烘焙师）、场景、道具均以真人写实摄影为标准，强调五官、皮肤、发丝、食材质感、餐具材质等极致细节与真实质感。
- **美食杂志级纪实**：在写实基础上追求商业美食摄影级氛围感，画面暖色调饱满，食材质感超清晰，酱汁光泽诱人，蒸汽新鲜感扑面，整体氛围温暖、诱人、食欲感强烈。
- **食欲氛围**：适合展现温暖、治愈、新鲜的美食故事，强调食物与人之间的情感表达与生活温度。

## 适用范围

- 美食摄影题材的AI美术生成（角色、场景、道具、分镜等）
- 需要极致写实、细腻质感、暖调食欲感氛围的视觉创作

## 严禁内容

- 卡通、动漫、插画、二次元风格
- 现代美食元素缺失、古风/古装/传统建筑
- 高饱和荧光色、霓虹色、冷蓝主调
- 暗示性、暴露、透视等不适宜内容

## 风格体验

在本风格下，您将体验到：

- 角色面容精致、气质温暖或干练，服饰、妆容、发型均为现代美食场景写实（厨师服、围裙、便装）
- 场景空间层次丰富，厨房/餐厅/市集材质纹理超清晰，暖光与窗光交织，氛围真实且富有食欲感
- 道具、餐具、食材、厨具等均为现代造型，工艺精细，食材质感与酱汁光泽极致诱人
- 分镜与视频均以真人写实为基础，强调食物特写、蒸汽新鲜感与叙事情感表达

---

本风格仅适用于"美食摄影"相关项目。如需其他风格（如古风、插画、动漫、都市纪实等），请勿使用本套提示词。
