# 美食风格约束 · 美食摄影 · 技法参考

---

## 一、色调体系与画面基调

- **色调基底** — 全片以奶白瓷（C1）、焦糖棕（C2）、蛋黄暖（C7）为基底色，整体色温偏暖（3200-4500K），饱和度中高（55-75%），呈现温暖诱人的食欲感
- **冷暖叙事对比** — 暖色（焦糖棕 C2、蛋黄暖 C7、番茄红 C3）作为食欲升温与关系确认的视觉信号，冷色（窗光冷白 C6）用于压力、误会、疏离等段落及食材边缘勾勒。冷暖切换应与情绪弧线同步
- **冷暖分配策略** — 烹饪与用餐段落以暖调为主，冲突/独处段落降低暖光占比、引入冷白反差；避免全程高暖导致食欲层次塌陷
- **色盘先行原则** — 段落规划先绑定情绪场景（新鲜出炉/精致摆盘/家常温暖/街头小吃/甜品时刻/烹饪过程等），再确定主色+辅色与光影方案，避免"剧情对了但食欲不对色"
- **禁用色域** — 高饱和荧光色、强霓虹污染、冷蓝主调、过度赛博色彩与本风格不兼容

## 二、光影方案体系

- **光影即叙事** — 6 套光影方案对应不同情绪段落，导演规划阶段应在段落层面确定光影基调方向，而非逐镜指定
- **光源角度** — 正给镜头默认 30°-45° 斜射（侧逆光为主，突出食材质感），侧给镜头根据场景与食物关系微调

| 光影方案 | 方案名 | 色调倾向 | 适用情绪 |
|---|---|---|---|
| A | 窗光漫射 | 奶白底 + 均匀柔和光 | 早餐晨光、精致摆盘、日常流叙事 |
| B | 暖调侧逆光 | 蛋黄暖 + 局部暖光 | 新鲜出炉、家常温暖、用餐松弛 |
| C | 顶光环境混合 | 中性暖 + 柔和冷白 | 专业厨房、烹饪节奏、理性操作 |
| D | 炉火点光源 | 焦糖棕主导 + 暗部冷反差 | 夜市烟火、烹饪动感、亲密推进 |
| E | 灯串暖光晕光 | 暖色背景 + 冷点点缀 | 市集夜景、甜品时刻、浪漫游走 |
| F | 阴天漫射冷光 | 灰白主调 + 暖色局部 | 过渡段、低潮段、反思段 |

- **冷暖光分配** — 暖色光可全片使用但需分层控制；冲突/疏离段落降低暖光占比，避免情绪与光色冲突
- **氛围方向映射** — 每场戏氛围方向应映射到上述光影方案（A-F）的某一方向，确保视觉一致性

## 三、质感方向

- **超清食欲感** — 商业美食摄影核心：食材肌理可见、酱汁光泽诱人、蒸汽体积光真实、餐具釉面细腻
- **暖色调 + 微距浅景深** — 作为画面质感锚点。不是冷调小清新，不是重滤镜氛围化，而是可拍可落地的杂志级美食纪实感
- **材质真实** — 服化道与食材需具备现实可信度：陶瓷釉面、不锈钢反光、木质砧板刀痕、食材汁水、油脂光泽都应符合美食实拍逻辑
- **皮肤质感** — 保留真实毛孔与细微瑕疵，控制磨皮强度，追求"真实但好看"，暖调肤色还原生命感
- **写实不等于平淡** — 通过构图、景别（俯拍/45°特写/微距）、运动节奏放大食欲感染力，而非依赖夸张特效与过度后期

## 四、美食场景空间元素

美食世界观特有的场景元素及其视觉叙事功能：

- **中岛/砧板/灶台** — 天然构图重心道具，制造操作动线与人物专注感，刀工与火候可直接映射角色心理状态
- **窗光/暖光吊灯/炉火** — 食欲氛围容器：窗光偏清新摆盘，吊灯偏温馨家常，炉火偏烟火动感
- **蒸汽/油烟/酱汁淋落** — 动态质感资产，蒸汽升腾=新鲜出炉，酱汁淋落=精致收尾，可作为情绪转折的视觉锚点
- **餐桌/餐具陈设/食材陈列** — 关系容器：家庭餐桌偏治愈，餐厅大堂偏精致，市集摊位偏烟火
- **天气与时段作为转场** — 晨光入厨房、午后备餐、黄昏出餐、夜市开张可用于段落情绪缓冲，避免硬切
- **转折点用视觉而非解释** — 优先使用画面手段（食材特写突入、火光明灭、蒸汽遮掩）承接情绪转折，减少对白解释负担

## 五、美食乐器与环境音

美食世界观下的声音元素约束：

### 乐器选择

- **吉他** — 日常、温馨、家常段落核心乐器，最能体现美食生活质感
- **钢琴** — 精致摆盘、回忆、治愈段落的有效主导
- **轻打击/手鼓** — 烟火市井、街头小吃、热闹段落的节奏增强器
- **口琴/手风琴** — 市集、夜市、地方风味段落的风格化点缀
- **环境音优先级高** — 美食剧中真实烹饪/用餐环境声是沉浸感关键，配乐不应压过食物与对白

### 乐器组合策略

| 情绪阶段 | 乐器组合 |
|---|---|
| 平稳/开场/收尾 | 吉他独奏 或 钢琴独奏 |
| 日常推进/家常 | 吉他 + 轻打击 |
| 精致摆盘/治愈 | 钢琴 + 弦乐铺底 |
| 烟火市井/热闹 | 手鼓 + 口琴 + 环境声 |
| 夜市/转场 | 轻电子/Lofi + 环境声 |

### 美食环境音

- **典型环境音层次** — 切菜砧板声 / 油锅滋啦 / 水流冲洗 / 蒸汽嘶嘶 / 碗碟轻碰 / 咖啡机萃取 / 炉火呼呼 / 市集人声底噪
- **每场戏标注 1-2 个核心环境音**，帮助后续音效设计。环境音层次越准确，美食写实质感越强
