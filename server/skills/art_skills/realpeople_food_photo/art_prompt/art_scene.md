# 场景图生成 · 美食摄影约束手册

---

## 一、场景美学原则

1. **空间叙事** — 场景承载食欲与叙事功能，不是纯背景板
2. **层次纵深** — 所有场景必须具备前/中/后景，杜绝扁平
3. **质感至上** — 木质台面/陶瓷餐具/不锈钢厨具/食材纹理必须超清晰
4. **实拍为锚** — 一切画面以真实美食摄影为标准，拒绝 3D 渲染/CG 动画质感；追求镜头光学特征（微距浅景深、镜头暗角、焦外散景）与物理光照（自然窗光漫射、侧逆光、蒸汽体积光、焦散光泽）

## 三、室内场景

### 空间规范

| 维度 | 约束 | 提示词 |
|---|---|---|
| 风格 | 专业厨房/开放式厨房/餐厅大堂/咖啡厅/甜品店/家宴厨房，现代简约/工业风/日式食堂风 | 美食{风格}风格 |
| 材质 | 不锈钢/木质台面/陶瓷/玻璃/大理石为主 | 不锈钢台面、木纹砧板、陶瓷餐具 |
| 色调 | 暖调中性色 + 焦糖棕 + 点缀色 | 暖调中性色、焦糖棕、点缀色 |
| 纵深 | 前/中/后景层次 | 前景{元素}、中景{元素}、后景{元素} |
| 质感 | 木纹/金属拉丝/陶瓷釉面/食材纹理可辨 | 纹理清晰、质感写实 |
| 光照 | 自然窗光为主（侧逆光/漫射），暖光吊灯点缀，可见蒸汽体积光、酱汁焦散光泽 | 自然窗光漫射、侧逆光、蒸汽体积光 |
| 镜头感 | 微距浅景深虚化前后景、镜头暗角、暖色温偏移、散景光斑 | macro shallow depth of field、lens vignette、warm color cast、bokeh |
| 瑕疵感 | 台面有使用痕迹、刀具磨损、砧板刀痕、餐具水渍 | 使用痕迹、砧板刀痕、自然磨损 |

### 室内类型速查

| 类型 | 核心元素 | 氛围词 |
|---|---|---|
| 专业厨房 | 灶台、不锈钢台、厨具架、烟机 | 专业高效、烟火气 |
| 开放式厨房 | 中岛、砧板、调料瓶、暖光吊灯 | 温馨互动、生活感 |
| 餐厅大堂 | 餐桌椅、餐具陈列、暖光、绿植 | 精致典雅、用餐氛围 |
| 咖啡厅/甜品店 | 吧台、咖啡机、甜品柜、展示橱窗 | 轻松惬意、文艺氛围 |
| 家宴厨房 | 家用灶台、餐桌、锅具、食材篮 | 温暖家常、治愈感 |
| 烘焙工坊 | 烤箱、面粉台、模具架、冷却架 | 甜蜜香气、手作感 |

## 五、主视图规范

### 视图定义

> 单画面主视图，从场景中最具代表性的角度拍摄，承载空间叙事与构图重心。

| 项目 | 约束 | 提示词 |
|---|---|---|
| 视角 | 自然观察视角，构图最能体现场景主体与纵深（俯拍或 45°特写为美食场景标志视角） | hero shot、representative angle、overhead or 45-degree food photography |
| 视点高度 | 默认人眼平视或 45°俯视，美食特写可近垂直俯拍 | eye level（默认）或 45-degree overhead |
| 构图 | 主体居中或符合三分法，前/中/后景层次清晰 | balanced composition |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 单画面（非拼图、非多视图、非分屏） |
| 人物 | **严禁出现任何人物、人影、人体轮廓** |
| 一致性 | 风格/材质/色调/光线统一 |
| 光线 | 单一光源逻辑，光影方向一致 |
| 画面比例 | 默认 16:9（或按调用方设定） |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 场景必须有「前中后景层次」 |
| R2 | 室外必须包含「空气透视」 |
| R3 | 场景图必须为「单画面主视图」，不得拼接多视图/分屏/网格 |
| R4 | 构图须能代表场景主体并展示前/中/后景层次 |
| R5 | 场景图中**严禁出现任何人物** |
| R6 | 必须包含实拍美食摄影关键词（real food photography / photorealistic / RAW photo） |
| R7 | 必须包含镜头光学特征（macro shallow depth of field / lens vignette / bokeh 至少一项） |
| R8 | 材质必须带有自然磨损/使用痕迹，禁止全新无瑕的"CG 感" |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 背景纯白/纯黑/无场景 |
| X2 | 极端天候（暴风雨/雷电/暴雪，除非剧情需要） |
| X3 | 场景无纵深/无层次 |
| X4 | 植被/食材与季节矛盾 |
| X5 | 出现任何人物、人影、人体剪影或人体轮廓 |
| X6 | 画面被拼接成多视图/网格/分屏布局 |
| X7 | 3D 渲染/CG 动画/卡通/游戏引擎质感（禁用 3D render、CGI、Unreal Engine、Unity 等词） |
| X8 | 材质过于干净完美、无任何使用痕迹与烟火感（避免"塑料感"） |
| X9 | 光照过于均匀平坦、无景深虚化、无镜头光学特征、无蒸汽体积光 |
