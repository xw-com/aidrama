# 复古胶片风格说明

本风格专为"复古胶片"题材打造，所有美术提示词、规范和生成内容均严格限定于：

- **胶片介质质感**：以柯达金（Kodak Gold）/波特拉（Portra）胶片色彩科学为基准，画面呈现可见胶片颗粒、卤化银质感、暖调肤色与青绿阴影分离、漏光与暗角等真实胶片特征。
- **真人写实**：所有角色、场景、道具均以真人胶片摄影为标准，强调皮肤颗粒感、发丝柔光、材质年代纹理等真实细节。
- **80-90 年代氛围**：妆发服饰、生活场景、道具器物均限定于 80-90 年代老式生活语境，杜绝现代数码元素。
- **忆旧温柔情绪**：适合展现怀旧、重逢、青涩爱恋、旧日时光类故事，强调时光滤镜下的温柔回望。

## 适用范围

- 复古胶片题材的AI美术生成（角色、场景、道具、分镜等）
- 需要胶片颗粒质感、暖调怀旧氛围、年代生活气息的视觉创作

## 严禁内容

- 卡通、动漫、插画、二次元风格
- 数码锐利感、HDR、现代数码单反质感、现代智能设备
- 高饱和荧光色、霓虹赛博色彩
- 暗示性、暴露、透视等不适宜内容

## 风格体验

在本风格下，您将体验到：

- 角色面容带胶片暖肤与细颗粒质感，妆容发型均为 80-90 年代年代感造型
- 场景空间笼罩暖金黄与青绿阴影的胶片色分离，漏光与暗角自然入镜
- 道具、胶片相机、磁带、老爷车、打字机等均为年代造型，磨损质感真实
- 分镜与视频均以胶片摄影为基础，强调忆旧情绪与时光叙事表达

---

本风格仅适用于"复古胶片"相关项目。如需其他风格（如古风、插画、动漫、现代数码等），请勿使用本套提示词。
