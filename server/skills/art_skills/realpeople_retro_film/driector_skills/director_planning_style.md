# 复古胶片风格约束 · 复古胶片 · 技法参考

---

## 一、色调体系与画面基调

- **色调基底** - 全片以柯达金暖肤（C2）、米黄纸白（C1）、青绿阴影（C6）为基底色，整体色温偏暖（4500-5500K），饱和度中等（45-65%），呈现泛黄温软的旧日时光感
- **胶片分离逻辑** - 暖调肤色与青绿阴影分离（C2 暖肤 vs C6 青绿阴影）是本风格的色彩签名：人物永远偏暖，暗部永远偏青绿，冷暖分离承担情绪与空间层次
- **冷暖叙事对比** - 暖色（落日琥珀 C7、蜜桃橘 C3）用于忆旧、重逢、心动段落，青绿灰调（C6、C5 灰橄榄）用于失落、隔阂、离别段落。冷暖切换应与情绪弧线同步
- **色盘先行原则** - 段落规划先绑定情绪场景（忆旧/心动/离别/回忆闪回/迪厅高光等），再确定主色+辅色与光影方案，避免"剧情对了但情绪不对色"
- **禁用色域** - 高饱和荧光色、数码荧光蓝、LED 冷白光、霓虹赛博色彩与本风格不兼容

## 二、光影方案体系

- **光影即叙事** - 6 套光影方案对应不同情绪段落，导演规划阶段应在段落层面确定光影基调方向，而非逐镜指定
- **光源角度** - 正给镜头默认 30° 斜射（暖调柔和），侧给镜头根据场景与人物关系微调

| 光影方案 | 方案名 | 色调倾向 | 适用情绪 |
|---|---|---|---|
| A | 晨昏泛黄漫射 | 米黄纸白底 + 均匀柔光 | 旧日日常、生活流叙事 |
| B | 钨丝灯暖点光 | 暖黄主调 + 青绿暗部 | 夜谈、私语、居家温情 |
| C | 黄昏金色逆光 | 落日琥珀主导 + 晕光柔化 | 心动升温、离别送行 |
| D | 树影斑驳日光 | 灰橄榄 + 米黄光斑 | 巷弄漫步、午后闲适 |
| E | 迪厅灯球光斑 | 暖主光 + 彩色光斑点缀 | 舞厅高光、情绪释放 |
| F | 雨后青绿湿调 | 青绿阴影主导 + 暖点残光 | 低潮段、隔阂与错过 |

- **冷暖光分配** - 暖光可全片使用但需分层控制；失落/隔阂段落降低暖光占比、让青绿阴影接管画面，避免情绪与光色冲突
- **氛围方向映射** - 每场戏氛围方向应映射到上述光影方案（A-F）的某一方向，确保视觉一致性

## 三、质感方向

- **胶片颗粒** - 可见但不粗粝的 35mm 颗粒是本风格的介质签名，全片颗粒密度须统一，禁止数码无噪点画面
- **色偏与晕光** - 柯达金式暖肤色偏、高光 halation 晕染、暗角与轻微漏光共同构成"时光滤镜"；漏光须克制，不可喧宾夺主
- **宽容度质感** - 胶片宽容度的柔和高光滚降与厚实暗部（暗部偏青绿而非死黑），拒绝数码 HDR 式的通透与锐利
- **材质真实** - 服化道需具备年代可信度：的确良衬衫、针织毛衣、搪瓷、藤编、老式车漆、镀铬件都应符合 80-90 年代生活实拍逻辑

## 四、年代场景空间元素

复古胶片世界观特有的场景元素及其视觉叙事功能：

- **老街/巷弄/骑楼** - 天然纵深载体，斑驳砖墙与褪色招牌暗示岁月流逝，适合相遇与错过
- **胶片相机/照相馆** - "定格"母题的核心道具：取景、按下快门、冲洗照片可直接映射凝视与记忆
- **绿皮火车/老车站/铁路道口** - 离别与远方的时间符号，蒸汽与站台灯天然带怀旧滤镜
- **录像带店/迪厅/露天电影院** - 年代文化容器：录像带店偏试探与文艺，迪厅偏释放与心动，露天影院偏集体记忆
- **天气与时段作为转场** - 黄昏入夜、雨后放晴、泛黄回忆闪回可用于段落情绪缓冲，回忆段整体褪色+颗粒加重即"时光跳切"
- **转折点用视觉而非解释** - 优先使用画面手段（一张旧照片入镜、灯球光斑停转、取景器虚实切换）承接情绪转折，减少对白解释负担

## 五、年代乐器与环境音

复古胶片世界观下的声音元素约束：

### 乐器选择

- **合成器流行（Synth-Pop）** - 80 年代标识音色，霓虹灯球与青春律动段落的核心
- **老歌金曲（翻唱/原创怀旧曲）** - 抒情段落主力，卡带播放的"沙沙底噪"本身就是叙事音
- **爵士（慢爵士/融合爵士）** - 歌舞厅、夜色私语、成年角色情感段落的气质担当
- **口琴/木吉他** - 乡间、站台、遗憾与远方段落的民谣质感
- **弦乐** - 情绪爆发与命运转折段落的铺底
- **环境音优先级高** - 胶片质感的沉浸关键在介质噪声与环境声，配乐不应压过对白

### 乐器组合策略

| 情绪阶段 | 乐器组合 |
|---|---|
| 平稳/开场/收尾 | 木吉他独奏 或 钢琴+磁带底噪 |
| 日常推进 | 口琴 + 轻打击 |
| 心动升温/浪漫 | 老歌金曲风格主旋律 + 弦乐 |
| 迪厅/情绪释放 | 合成器流行 + 动感贝斯 |
| 离别/遗憾 | 弦乐主导 + 口琴残响 |

### 典型环境音

- **典型环境音层次** - 磁带卡座运转声 / 胶片过片与快门声 / 钨丝灯电流嗡鸣 / 老式电视雪花噪点声 / 绿皮火车哐当声 / 蝉鸣与蒲扇风声 / 雨打瓦檐声 / 街坊收音机广播声
- **每场戏标注 1-2 个核心环境音**，帮助后续音效设计。环境音层次越准确，年代沉浸感越强

### 留白建议

- 回忆闪回段落可只保留磁带底噪与单一乐器独奏，抽掉环境音制造"时间真空"感
- 关键情绪定格（如快门按下瞬间）前后各留 0.5-1s 声音空白，让画面颗粒自己说话
