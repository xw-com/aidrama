### 硬约束色（默认锁定）

| 色项 | 对应色 | 规则 |
|---|---|---|
| 肤色基准 | C2 暖肤金 | 默认柯达金暖肤方向，允许小幅明度微调，严禁冷白/数码粉白 |
| 发色/瞳色基准 | C4 墨棕发 | 默认优先，允许深棕/深褐轻微偏移，禁亮色漂染 |

### 软约束色（推荐优先）

> C1/C3/C5/C6/C7/C8/C10 为推荐色域，用于服饰、装饰、背景、暖光、老金属、砖墙等。可根据镜头氛围做同色相邻近调整。

### 情绪色盘使用规则

| 编号 | 规则 |
|---|---|
| E1 | 每条提示词至少指定 1 个「情绪场景」并绑定主色+辅色组合 |
| E2 | 单镜头主色不超过 2 个，避免颜色叙事失焦 |
| E3 | 情绪切换时优先调整光比与色温，再调整饱和度 |
| E4 | 复古胶片默认遵循「暖肤 + 青绿阴影」：肤色永远偏暖，阴影永远偏青绿，二者分离是胶片色彩科学的标志 |
| E5 | 若与剧情冲突，以情绪色盘优先于通用推荐色，但不得突破严禁项 |

### 色温约束

| 参数 | 值 | 说明 |
|---|---|---|
| 整体色温 | 偏暖 4500-5500K（推荐） | 钨丝灯与夕照主导的年代暖调 |
| 肤色色温 | 微暖 4600-5300K（推荐） | 柯达金暖肤，健康但不惨白 |
| 对比度 | 中等（建议保持） | 明暗反差柔和，宽容度大，高光滚降柔和 |
| 饱和度 | 中等 45-65%（建议区间） | 暖色饱和、冷色低饱和的胶片式不平衡 |

### 容差与例外

| 项目 | 建议容差 |
|---|---|
| 色相偏移 | ±10° |
| 饱和度偏移 | ±12% |
| 明度偏移 | ±12% |

> 例外场景：迪厅、回忆高潮、漏光镜头可出现更大局部偏色与光斑；但禁止数码荧光色与现代屏幕蓝光污染入镜。

## 三、全局约束规则

### 必守规则（所有技能继承）

| 编号 | 规则 |
|---|---|
| R1 | 必须包含「复古胶片摄影」风格锚定词（Kodak Gold / Portra film 色彩科学） |
| R2 | 必须声明「可见胶片颗粒 + 卤化银质感」 |
| R3 | 面部必须使用「胶片暖肤 + 面容细腻渲染」，保留颗粒肤感 |
| R4 | 发丝必须使用「根根分明 + 柔光发际」，带胶片柔光晕 |
| R5 | 画面须体现「暖调肤色与青绿阴影分离」的胶片色彩特征 |

### 严禁项（所有技能继承）

| 编号 | 严禁内容 |
|---|---|
| X1 | 严禁「卡通/动漫/二次元/插画风」 |
| X2 | 严禁「数码锐利感/HDR/现代数码单反质感/数码荧光色」 |
| X3 | 严禁「现代智能设备/液晶屏/LED 冷白光」（手机、平板、智能手表等） |
| X4 | 严禁「面部变形/多指/肢体异常」倾向词 |
| X5 | 严禁「裸体/暴露/透视/暗示性描述」 |
| X6 | 严禁「21 世纪现代时尚元素」（现代潮牌、现代发型、玻璃幕墙极简空间） |
