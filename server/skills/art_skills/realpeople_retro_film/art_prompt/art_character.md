# 人物基础形象生成 · 复古胶片约束手册

---

## 一、基础形象原则

1. **面容即灵魂** - 五官是角色唯一锚点，胶片颗粒级细腻渲染
2. **角色为本** - 基础着装由角色描述（身份/职业/性别/场景）决定其常规着装；后续特定服化为叠加层
3. **四视图一致** - 面容/体型/发型/基础服装跨视图高度统一
4. **胶片质感** - 以真实胶片摄影为锚点，肤色带柯达金暖调，皮肤保留颗粒与微小瑕疵
5. **年代气质** - 妆发造型默认锚定 80-90 年代审美，杜绝现代网红感

---

## 二、面容约束

> 不再固定五官特征参数，由角色描述（性别/年龄/性格/气质）驱动 AI 自由生成五官，保证人物间外观差异化。

### 通用要求

| 项目 | 约束 |
|---|---|
| 五官 | 由角色描述自然推导，不预设脸型/眼型/眉型/鼻型/唇型 |
| 风格底色 | 复古胶片摄影、柯达金暖肤、颗粒肤感、卤化银质感、柔和中辨度 |
| 气质 | 必须从角色描述提炼整体气质关键词（如温婉/飒爽/木讷/明艳），并写入提示词 |
| 表情 | 中性微表情，符合角色气质，带年代式的含蓄感 |

## 五、基础发型约束

> 仅定义自然散发/简单束发，发饰在服化衍生环节叠加。发型须带年代感，杜绝现代网红烫染造型。

### 女性

| 项目 | 约束 | 提示词 |
|---|---|---|
| 发色 | 自然发色（黑色/深棕），禁漂色/染色 | 自然发色、深棕色 |
| 发长 | 及肩/及腰中长发为主，由角色设定 | 中长发、及肩微卷 |
| 发质 | 发丝清晰、带胶片柔光晕 | 发丝根根分明、柔光发际 |
| 造型 | 80 年代吹高刘海/大波浪卷、90 年代直发披肩/低马尾/麻花辫 | 八十年代吹卷刘海、九十年代披肩直发 |

### 男性

| 项目 | 约束 | 提示词 |
|---|---|---|
| 发色 | 自然发色（黑色/深棕），禁漂色 | 自然发色、黑色/深棕 |
| 发长 | 短中发为主，由角色设定 | 短发、蓬松中发 |
| 发质 | 发丝清晰、带蓬松感 | 发丝根根分明、蓬松 |
| 造型 | 80 年代油头背梳/蓬松吹高、90 年代三七分/齐耳短发 | 八十年代背梳油头、九十年代三七分短发 |

## 六、基础服装约束

> 基础服装由角色描述（身份/职业/性别/场景）决定其最自然的常规着装，作为该角色「日常默认态」；正式服饰/特殊衍生在服化衍生环节叠加。**禁止内衣打底**。

### 着装选择原则

| 角色身份 | 默认着装方向 |
|---|---|
| 学生 | 80-90 年代校服 / 运动套装 / 白衬衫背带裙 |
| 上班族 | 垫肩西装/衬衫西裤/一步裙（职业年代装） |
| 居家/休闲 | 针织毛衣/的确良衬衫/灯芯绒裤/碎花连衣裙 |
| 文艺/约会 | 碎花裙/牛仔外套/高腰牛仔裤/喇叭裤 |
| 特殊职业 | 对应身份年代服装（国营厂工人/音像店店员/司机等） |
| 角色描述未明确 | 年代常服、米黄/灰橄榄/砖红褐低饱和胶片色 |

### 着装统一规则

- 服装风格须与 80-90 年代胶片摄影美学一致（垫肩轮廓、高腰线、天然面料）
- 颜色取低饱和胶片色，无现代印花/大 logo，便于后续衍生叠加
- 四视图服装款式完全一致
- 基础服装是「日常默认态」，焦点仍在面容与体态
- 严禁内衣/暴露/性化打底

## 八、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须为「自然状态」|
| R2 | 必须根据角色描述声明合适的年代常规着装作为基础服装；禁止内衣打底 |
| R3 | 必须声明「无发饰、无配饰」 |
| R4 | 必须指定「纯净奶油灰背景」 |
| R5 | 必须指定「四视图一致性」 |
| R6 | 全身立像必须从头顶到脚底完整展示，严禁裁切 |
| R7 | 必须声明角色身高并通过头身比换算约束全身比例 |
| R8 | 人像特写必须从头顶到锁骨完整展示，严禁裁切头顶 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 内衣/暴露/性化打底；现代潮牌/现代发型/现代妆容 |
| X2 | 正顶硬光/正底光/彩色光 |
| X3 | 数码锐利磨皮/无颗粒的数码肤感 |
| X4 | 复杂场景背景（必须奶油灰纯底） |
