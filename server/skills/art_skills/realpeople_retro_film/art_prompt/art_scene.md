# 场景图生成 · 复古胶片约束手册

---

## 一、场景美学原则

1. **空间叙事** - 场景承载情绪与叙事功能，不是纯背景板
2. **层次纵深** - 所有场景必须具备前/中/后景，杜绝扁平
3. **质感至上** - 水泥/砖墙/木窗框/老瓷砖/布料等材质纹理必须超清晰
4. **胶片为锚** - 一切画面以真实胶片摄影为标准，拒绝数码锐利/CG 质感；追求胶片光学特征（可见颗粒、轻微漏光、边缘暗角、高光晕光）与年代光照（钨丝灯、白炽灯、日光灯管的暖黄光）

## 三、室内场景

### 空间规范

| 维度 | 约束 | 提示词 |
|---|---|---|
| 风格 | 老式住宅/国营单位/录像带店/迪厅/老式照相馆/供销社 | 80-90 年代{场景}风格 |
| 材质 | 砖墙/水泥/木窗框/老瓷砖/花布/搪瓷为主 | 红砖墙面、木框玻璃窗、老式花砖 |
| 色调 | 米黄纸白 + 灰橄榄 + 砖红褐点缀 | 年代暖调、砖红点缀 |
| 纵深 | 前/中/后景层次 | 前景{元素}、中景{元素}、后景{元素} |
| 质感 | 墙皮剥落/木纹磨损/花布褪色可辨 | 墙皮斑驳、使用痕迹、褪色 |
| 光照 | 钨丝灯/白炽台灯/日光灯管暖黄光，光线柔和，可见光束灰尘粒子 | 钨丝灯暖光、灯光穿窗、尘埃微粒 |
| 镜头感 | 中浅景深、可见胶片颗粒、边缘暗角、轻微漏光 | film grain、vignette、light leak、halation |
| 瑕疵感 | 墙面年久泛黄、地面磨损、家具掉漆 | 年久泛黄、掉漆磨损、岁月痕迹 |

### 室内类型速查

| 类型 | 核心元素 | 氛围词 |
|---|---|---|
| 老式住宅 | 搪瓷缸、缝纫机、木柜、挂历 | 生活气息、年代温情 |
| 国营单位办公室 | 木桌、算盘、搪瓷杯、暖水瓶 | 制度感、旧日秩序 |
| 录像带店 | 货架录像带、海报墙、柜台电视 | 街角文化、市井文艺 |
| 迪厅/歌舞厅 | 灯球、彩灯串、格地板、卡座 | 律动感、灯球光斑 |
| 老式照相馆 | 布景幕布、老相机、台灯、木凳 | 仪式感、定格记忆 |
| 筒子楼走廊 | 公用灶台、走廊杂物、声控灯 | 烟火气、邻里时代 |

## 五、主视图规范

### 视图定义

> 单画面主视图，从场景中最具代表性的角度拍摄，承载空间叙事与构图重心。

| 项目 | 约束 | 提示词 |
|---|---|---|
| 视角 | 自然观察视角，构图最能体现场景主体与纵深 | hero shot、representative angle |
| 视点高度 | 默认人眼平视高度，特殊场景可俯/仰 | eye level（默认） |
| 构图 | 主体居中或符合三分法，前/中/后景层次清晰 | balanced composition |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 单画面（非拼图、非多视图、非分屏） |
| 人物 | **严禁出现任何人物、人影、人体轮廓** |
| 一致性 | 风格/材质/色调/光线统一 |
| 光线 | 单一光源逻辑，光影方向一致 |
| 画面比例 | 默认 16:9（或按调用方设定） |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 场景必须有「前中后景层次」 |
| R2 | 室外必须包含「空气透视」 |
| R3 | 场景图必须为「单画面主视图」，不得拼接多视图/分屏/网格 |
| R4 | 构图须能代表场景主体并展示前/中/后景层次 |
| R5 | 场景图中**严禁出现任何人物** |
| R6 | 必须包含胶片摄影关键词（film / Kodak / 35mm 至少一项） |
| R7 | 必须包含胶片光学特征（film grain / vignette / light leak / halation 至少一项） |
| R8 | 材质必须带有年久磨损/岁月痕迹，禁止崭新无瑕的"数码感" |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 背景纯白/纯黑/无场景 |
| X2 | 极端天候（暴风雨/雷电/暴雪，除非剧情需要） |
| X3 | 场景无纵深/无层次 |
| X4 | 现代都市元素（玻璃幕墙/现代商圈/LED 大屏/共享单车） |
| X5 | 出现任何人物、人影、人体剪影或人体轮廓 |
| X6 | 画面被拼接成多视图/网格/分屏布局 |
| X7 | 数码锐利/HDR/CG 渲染质感（禁用 3D render、CGI、digital sharpening 等词） |
| X8 | 材质过于干净完美、无任何年代使用痕迹 |
| X9 | 现代光源（LED 冷白光、智能屏光、霓虹赛博灯效）入镜 |
