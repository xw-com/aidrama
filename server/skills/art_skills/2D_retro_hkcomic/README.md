# 复古港漫风格说明

本风格专为"复古港漫风格"题材打造，所有美术提示词、规范和生成内容均严格限定于：

- **港式武侠漫画**：以 1970s-90s 香港武侠漫画（黄玉郎《龙虎门》《中华英雄》、马荣成《风云》）为根基，硬派江湖、刀光剑影、热血对决
- **粗黑墨线美学**：粗重钢笔轮廓线、笔锋凌厉，线条即骨骼，结构靠线撑起
- **平涂高饱和色块**：硬边平涂上色、明暗硬切，色块饱满浓烈，拒绝柔和渐变
- **速度线与集中线**：放射状集中线、速度线、冲击星芒，画面自带爆裂张力
- **斗气气势特效**：内力气劲、斗气爆裂、网点贴影，夸张的肌肉与表情张力
- **强戏剧硬光**：底光/顶光制造压迫，高对比高饱和，闪电冷白与火光暖橙交错

## 适用范围

- 港式武侠漫画题材的 AI 美术生成（角色、场景、道具、分镜等）
- 需要硬派港漫美学、粗黑墨线、平涂高饱和、速度线气势特效的视觉创作
- 武侠漫画、江湖热血、概念设计、插画创作、动画分镜

## 严禁内容

- 写实摄影/3D 写实 CG 渲染/照片级真实感
- 柔美柔焦柔光式的柔和水润插画气质
- 日漫少女柔焦/低对比柔光唯美
- 任何 CG 渲染术语（PBR/SSR/AO/次世代/体积光）
- 粗劣线条/模糊画质/低精度建模
- 色彩混乱/风格不统一/审美崩坏

## 风格体验

在本风格下，您将体验到：

- 角色造型夸张硬朗，粗黑轮廓线撑起结构，肌肉线条分明，表情张力爆裂
- 场景充满江湖肃杀与戏剧冲突，强戏剧硬光制造压迫，明暗硬切
- 道具器物粗犷有力，兵器锋芒毕露，材质以平涂色块与硬边阴影呈现
- 分镜与渲染均强调冲击帧、速度线、斗气爆裂、高对比爆裂张力
