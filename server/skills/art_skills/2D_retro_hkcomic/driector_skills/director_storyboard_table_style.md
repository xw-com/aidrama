# 分镜表复古港漫约束 · 复古港漫风格 · 技法参考

---

## 一、分镜表定位

分镜表是导演将剧本转化为镜头语言的核心工具。以下仅提供复古港漫风格（1970s-90s 港式武侠漫画）在分镜表层面的约束规范。

---

## 二、光影与氛围

- **硬光硬切统一** — 一场戏内光影方案必须保持强戏剧硬光一致性，阴影使用同色系加深硬边切（明暗硬切高对比，禁止柔光均匀照明），除非有明确的叙事转折（如闪电骤亮→月夜冷辉）
- **情绪色盘绑定** — 每场戏至少绑定 1 个情绪场景（热血爆击/邪派压境/江湖豪气/雷霆决战/火海炼狱/深渊孤绝），并在镜头组内保持主色+辅色连续性，色彩取自核心色盘（港漫红 #C8202A / 金黄 #E8B020 / 墨蓝 #1E3A5A / 铜绿 #3A6A5A / 墨黑 #1A1A1A / 肉色 #E0B080 / 银白 #E8E8E0 / 暗赭 #6A2820 / 紫黑 #2A1A3A / 灰青 #4A5A6A）
- **光源角度规范** — 正给镜头光源默认高位 45° 斜射硬光（高对比硬阴影），底光/顶光用于压迫主体。描述光影时须标注色温（火光 2000K / 闪电 6500K / 月光 4100K / 烈日 5500K）与光比（建议 1:4–1:9），明暗硬切始终保持港漫质感
- **冷暖色调与叙事阶段匹配** — 邪派压境/深渊孤绝段落使用冷色调（紫黑 + 墨蓝 + 灰青），禁用港漫红/金黄暖光；热血爆击/江湖豪气段落使用爆裂暖调（港漫红 + 金黄 + 暗赭）；雷霆决战段落冷白闪电与血色暖红交错
- **光影转场是高级手段** — 从烈日硬光硬切到雷霆冷电 = 白昼转入夜战雷暴。在分镜表中标注光影变化点，转场过程中须用硬切/impact frame，禁止柔滑渐变
- **港漫硬光光效** — 允许合理使用集中线、速度线、轮廓硬光、网点贴影等港漫画法增加戏剧张力，但必须保持粗黑墨线 + 平涂高饱和的美学基调，禁止体积光等 CG 渲染光效

---

## 三、环境动态

- **环境动态增加爆裂张力** — 速度线放射、集中线定格、斗气爆裂、披风猎猎、发丝狂舞、碎片飞溅、火星飞舞、雨丝横斜。每 2-3 个镜头至少安排一个有环境动态或 impact frame 的镜头，避免画面"死"掉
- **港漫环境元素优先** — 环境动态应选用港漫江湖世界观内的元素：速度线、集中线、斗气气劲、披风发丝飞扬、碎石火星飞溅、闪电雨幕、火焰跳动、战旗猎猎、瓦砾崩塌，禁止出现现代元素
- **2D 手绘动态质感** — 环境动态元素（速度线/斗气/碎片等）必须保持粗黑墨线 + 平涂色块 + 网点贴影的港漫手绘质感，禁止出现 3D 粒子特效或写实流体效果

---

## 四、复古港漫动作节奏

- **动作夸张且带爆裂感** — 人物动作默认凌厉爆裂，关键帧做港漫夸张处理（如绝招收招的 impact frame 定格、出拳的速度线残影、怒目圆睁的特写硬切），出拳、挥刀、转身应标注"凌厉/爆裂/蓄势"
- **披风发丝肌肉是核心画面资产** — 港漫披风（猎猎飞扬）、发丝（狂野散乱）、肌肉（充血青筋）的动态是天然的爆裂资产，可在画面描述中加入披风/发丝/肌肉的动态，平涂渲染下的飘动应粗黑轮廓清晰、层次硬朗
- **仪态约束** — 港漫人物的举止应符合硬派江湖气质：动作大开大合、招式凌厉爆裂、蓄势与爆发对比强烈。反派可阴柔诡异，正派可豪迈刚猛，不出现现代化的肢体语言（如耸肩、摊手）
- **头身比一致** — 动作设计中角色必须保持男性 8-9 头身、女性 7-8 头身的港漫夸张比例，禁止因动态姿势而破坏头身比
- **impact frame 定格** — 关键招式命中/绝招收招建议使用 impact frame 定格 + 集中线放射 + 特写硬切，这是港漫动作节奏的灵魂

---

## 五、材质与质感约束

- **粗黑墨线 + 平涂为锚** — 所有镜头中人物/服饰/道具/场景的渲染必须保持粗黑墨线轮廓 + 平涂高饱和色块质感，线条粗重硬朗，色块饱满，硬边阴影明暗硬切，禁止 3D 写实/CG 渲染/照片级渲染
- **服饰材质** — 皮革 + 金属甲片 + 布料的质感用平涂硬边表现，纹理必须超清晰，战甲护甲质感硬朗分明
- **道具材质** — 金属冷光泽战损划痕、玉质通透、木纹粗犷、青铜铜绿锈迹，均以粗黑轮廓 + 平涂硬边呈现，禁止写实材质渲染
- **场景材质** — 木面有刀痕、石壁有裂缝风化、金属有战损、布料有撕裂，材质带有战损岁月感但以港漫笔触呈现，禁止"塑料感"的全新无瑕材质

---

## 六、色彩约束

- **核心色盘锁定** — 分镜表中所有镜头的色彩必须取自核心色盘（C1-C10），色相偏移容差 ±8°，饱和度偏移 ±10%，明度偏移 ±12%
- **禁止荧光色** — 严禁高饱和荧光霓虹数码色出现
- **线条颜色** — 墨黑 #1A1A1A 粗黑轮廓，必须粗黑硬边轮廓线
- **阴影色** — 同色系加深硬边切，禁止柔光渐变阴影
- **整体色温** — 戏剧化两极（火光暖橙 2000K / 闪电冷白 6500K），对比度高 65-85%，饱和度高 65-80%（港漫平涂色块饱满浓烈）

---

## 七、运镜禁忌

- **禁用过度平滑柔滑的滑轨长镜** — 与港漫爆裂硬切的气质冲突，本风格鼓励急推急拉、冲击 zoom、impact frame 定格、对角线冲击构图以强化张力
- **禁用写实纪录片手持摇晃** — 手持摇晃/纪录片式跟拍/鱼眼畸变等与 2D 港漫美学冲突，破坏粗黑墨线 + 平涂色块的画面纯净感
- **禁用过度频繁无意义的甩镜** — 导致画面混乱可读性差，甩镜应服务于爆裂节拍且有节制使用
- **禁用花式柔滑转场** — 划屏柔滑、旋转叠化、百叶窗等柔滑转场与本风格不兼容，段落衔接建议用速度线冲击帧/集中线定格/特写硬切
