# 复古港漫约束 · 复古港漫风格 · 技法参考

---

## 一、色调体系与画面基调

- **色调基底** — 全片以核心色盘为基底：港漫红（C1 #C8202A）、金黄（C2 #E8B020）、墨蓝（C3 #1E3A5A）、铜绿（C4 #3A6A5A）、墨黑（C5 #1A1A1A）、肉色（C6 #E0B080）、银白（C7 #E8E8E0）、暗赭（C8 #6A2820）、紫黑（C9 #2A1A3A）、灰青（C10 #4A5A6A），整体色温两极戏剧化（火光暖橙 2000K / 闪电冷白 6500K），饱和度高（65-80%），呈现港漫平涂色块饱满浓烈的硬派江湖画面
- **冷暖叙事对比** — 暖色（港漫红 C1、金黄 C2、暗赭 C8、肉色 C6）作为热血/爆裂/豪气的视觉信号；冷色（墨蓝 C3、墨黑 C5、紫黑 C9、灰青 C10）作为肃杀/邪派/孤绝的视觉信号。冷暖切换应与故事弧线同步，而非随意混用
- **冷暖分配策略** — 邪派压境/深渊孤绝段落使用冷色调（紫黑 + 墨蓝 + 灰青），禁用港漫红/金黄暖光；热血爆击/江湖豪气段落使用爆裂暖调（港漫红 + 金黄 + 暗赭）；雷霆决战段落使用银白闪电冷光与港漫红血色交错
- **色盘先行原则** — 段落规划需先绑定情绪场景（热血爆击/邪派压境/江湖豪气/雷霆决战/火海炼狱/深渊孤绝等），再确定主色+辅色与光影方案，避免"剧情对了但情绪不对色"
- **禁用色域** — 高饱和荧光霓虹数码色、柔美柔光柔润色均与本风格不兼容。色相偏移容差 ±8°，饱和度偏移 ±10%，明度偏移 ±12%

## 二、光影方案体系

- **光影即叙事** — 7 套光影方案对应不同情绪段落，导演规划阶段应在段落层面确定光影基调方向，而非逐镜指定
- **硬光硬切为锚** — 所有光影方案必须保持强戏剧硬光质感，阴影使用同色系加深硬边切，明暗硬切高对比，禁止柔光均匀照明，禁止体积光等 CG 渲染光效
- **光源角度** — 正给镜头默认高位 45° 斜射硬光（高对比硬阴影），底光/顶光用于压迫主体，侧给镜头可适当调整

| 光影方案 | 方案名 | 色温/光比 | 适用情绪 |
|---|---|---|---|
| A | 烈日硬光 | 5500K / 光比 1:4 / 硬边短影 | 热血白昼、武林大会、江湖亮相 |
| B | 火海冲天 | 2000K 暖橙 / 光比 1:6 / 底光跳动闪烁 | 火海炼狱、客栈火并、惨烈悲壮 |
| C | 雷霆冷电 | 6500K 冷白 / 光比 1:8 / 瞬时全亮→骤暗 | 雷雨夜决战、绝招爆发、惊天动地 |
| D | 月夜冷辉 | 4100K / 光比 1:5 / 硬边明暗切 | 山崖夜战、孤胆独行、肃杀冷冽 |
| E | 邪派底光 | 3000K 偏紫 / 光比 1:7 / 底光压迫 | 反派登场、魔头现世、阴森邪恶 |
| F | 金殿华辉 | 3200K 金黄 / 光比 1:3 / 顶光对称庄严 | 皇城金殿、册封大典、皇权威压 |
| G | 斗气爆光 | 蓝紫能量光 变温 / 光比 1:9 / 由内向外爆裂 | 内力爆发、绝招收招、斗气冲天 |

- **冷暖光分配** — 暖色光（火光暖橙/金黄/港漫红）适用于热血/爆裂段落；邪派压境/孤绝段落一律冷光（紫黑/墨蓝）。雷霆决战段落冷白闪电与血色暖红交错，导演可根据叙事需要调整冷暖切换点
- **氛围方向映射** — 每场戏的氛围方向应能映射到上述光影方案（A-G）的某一方向，确保视觉一致性

## 三、质感方向

- **粗黑墨线为锚** — 复古港漫的核心：粗黑钢笔轮廓线、笔锋粗重、线条即骨骼结构，禁止细软线条
- **平涂高饱和 + 硬边阴影** — 这是画面质感的锚点。平涂色块饱满浓烈，阴影同色系加深硬边切，明暗硬切高对比。不是写实摄影，不是 3D CG，是 1970s-90s 港式武侠漫画手绘渲染
- **速度线集中线 + 网点贴影** — 放射状集中线、速度线、冲击星芒是港漫画面张力来源；网点贴影用于过渡阴影与质感层次，禁止 3D 粒子/写实流体
- **斗气势势特效** — 内力气劲、斗气爆裂、罡气罩等气势特效以平涂能量色块 + 集中线呈现，是港漫灵魂技法
- **皮肤质感** — 肉色基调 C6、平涂色块、硬边阴影、肌肉块状分明。禁止哑光/柔焦/柔光/柔润插画质感
- **夸张不等于崩坏** — 复古港漫强调夸张肌肉、夸张表情张力、夸张动作幅度，但造型结构严谨、粗黑轮廓清晰，绝非粗劣变形

## 四、复古港漫场景空间元素

港漫江湖世界观特有的场景元素及其视觉叙事功能：

- **飞扬披风/发丝/绷带/速度线** — 天然的动感张力载体，制造"随时爆裂"的动态感与画面冲击力，披风猎猎 = 蓄势待发、发丝狂舞 = 力量外放、速度线 = 极速冲击
- **险峻山崖/火海/雷雨/断壁残垣** — 戏剧冲突的天然舞台，景即势：孤崖绝顶 = 决绝孤高、火海冲天 = 惨烈悲壮、雷雨夜战 = 惊天动地、断壁残垣 = 战后苍凉
- **火把/闪电/斗气/火光** — 港漫世界的光源载体，火把 = 暖橙/阴森（方案B/E）、闪电 = 冷白/惊天（方案C）、斗气 = 能量爆裂（方案G）、火光 = 暖橙/炼狱（方案B）
- **龙形雕饰/麒麟图腾/擂台/匾额/兵器架** — 江湖武林元素以港漫美学呈现，粗黑轮廓清晰、图腾浮雕硬朗，材质带战损刀痕/风化痕迹，禁止全新无瑕的"塑料感"
- **段落间用冲击帧过渡** — 本风格的段落衔接建议用速度线冲击帧/集中线定格/特写硬切做张力缓冲，而非柔滑渐变
- **转折点用视觉而非台词** — 优先使用画面手段（光影硬切、景别跳切、impact frame定格、斗气爆裂）而非依赖对白解释
- **前中后景层次 + 留黑纵深** — 所有场景必须具备前/中/后景与留黑，杜绝扁平，室外必须包含空气透视（远山压暗）

## 五、港漫配乐与环境音

港漫江湖世界观下的声音元素约束：

### 乐器选择

- **大鼓（战鼓）** — 战斗、对决、蓄势段落的核心节奏器，密集鼓点推动爆裂节奏，与武侠对决高度适配
- **铜锣** — 惊天撞击、转折爆点、登场震撼，一击即震场，慎用但一用即核弹
- **唢呐** — 情感爆发、悲壮赴死、命运转折段落，高亢穿透力适合绝招收招
- **二胡** — 悲壮、苍凉、孤胆段落，拉弦的苍凉感适合英雄末路与江湖悲歌
- **古筝** — 开场定调 / 平稳段落 / 华丽登场，与战鼓搭配使用
- **电吉他（硬派摇滚 solo）** — 现代港漫动画化的灵魂配器，失真 solo 适配爆裂绝招与热血冲顶，强化硬派气质
- 交响弦乐铺底可增加电影感但不宜喧宾夺主

### 乐器组合策略

| 情绪阶段 | 乐器组合 |
|---|---|
| 平稳/开场/收尾 | 古筝独奏 或 古筝 + 二胡 |
| 江湖豪气/亮相 | 古筝 + 战鼓点缀 |
| 蓄势/对决前 | 战鼓密集 + 弦乐衬底 |
| 绝招爆发/热血冲顶 | 电吉他失真 solo + 战鼓 + 铜锣 |
| 悲壮赴死/英雄末路 | 唢呐独奏 或 唢呐 + 二胡 |
| 邪派登场/阴森 | 低频弦乐 + 铜锣闷击 + 不协和音 |
| 皇城/大典/盛大 | 编钟 + 古筝 + 弦乐铺底 |

### 港漫环境音

- **典型环境音层次** — 雷鸣炸响 / 狂风呼啸 / 兵刃交击铮鸣 / 拳风破空 / 斗气轰爆 / 火把噼啪 / 瓦砾崩塌 / 披风猎猎 / 雨夜滂沱 / 木构嘎吱 / 战旗猎猎
- **每场戏标注 1-2 个核心环境音**，帮助后续音效设计。环境音层次越丰富，港漫江湖场景越有沉浸感与爆裂张力
