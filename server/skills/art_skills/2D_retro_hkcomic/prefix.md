### 硬约束色（默认锁定）

| 色项 | 对应色 | 规则 |
|---|---|---|
| 整体色调 | 港漫核心色 + 平涂高饱和 | 禁止高饱和荧光霓虹数码色 |
| 线条颜色 | 墨黑 #1A1A1A 粗黑轮廓 | 必须粗黑硬边轮廓线，禁止细软线 |
| 阴影 | 同色系加深硬边切 | 禁止柔和渐变阴影，必须明暗硬切 |
| 平涂色块 | 硬边平涂、色块饱满 | 禁止色块溢出/断层不清 |
