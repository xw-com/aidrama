# 道具图像生成 · 约束手册

---

## 一、道具设计原则

1. **功能可读** — 道具用途一目了然，造型服务于江湖功能与戏剧象征
2. **质感极致** — 材质纹理必须以粗黑轮廓与平涂硬边清晰可辨（金属/玉石/木/布/纸/青铜/能量）
3. **年代一致** — 所有道具必须符合港漫江湖武林世界观，禁止现代元素
4. **尺度明确** — 通过参照物或标注暗示道具真实尺寸（兵器尤为厚重夸张）
5. **纯道具独立展示** — 画面中只能出现道具本身，严禁出现任何人物、手部、肢体，道具不可处于被持有/佩戴/握持状态，必须以静物陈列方式独立呈现

## 三、多角度设定图规范

### 视图定义

| 位置 | 视图 | 角度 | 要求 | 提示词 |
|---|---|---|---|---|
| 左上 | 正面图 | 正面 0° | 道具完整正面形态 | front view |
| 右上 | 侧面图 | 侧面 90° | 厚度/轮廓/结构清晰 | side view |
| 左下 | 背面图 | 背面 180° | 道具背部结构/装饰 | back view |
| 右下 | 细节特写 | 局部放大 | 材质纹理/工艺细节 | detail closeup |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 同一画面四宫格（2×2），上下左右四视角 |
| 背景 | 银灰纯色 #E8E8E0 |
| 光线 | 单侧硬光主光，强调材质硬边阴影，明暗硬切 |
| 比例 | 每格道具占格内主体 70%+ |
| 投影 | 允许硬边地面投影 |
| 画面比例 | 建议 1:1 |

## 六、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须指定「银灰纯色背景」 |
| R2 | 必须明确道具材质与工艺 |
| R3 | 道具造型必须符合港漫江湖武林世界观 |
| R4 | 必须为「四宫格」布局：正面 + 侧面 + 背面 + 特写 |
| R5 | 必须包含「复古港漫 + 粗黑轮廓 + 平涂硬边」关键词 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 复杂场景背景 |
| X2 | 道具与人物同画面（本环节为纯道具图） |
| X3 | 出现任何人物形象，包括全身、半身、局部（手、手指、手臂等肢体） |
| X4 | 道具处于被持有、握持、佩戴、使用中的状态 |
| X5 | 出现暗示人物存在的元素（如手持痕迹、佩戴视角、使用姿态） |
| X6 | 现代元素出现在港漫道具中 |
| X7 | 柔光均匀照明（必须单侧硬光明暗硬切） |
