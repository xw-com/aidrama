# 场景图生成 · 约束手册

---

## 一、场景美学原则

1. **戏剧承载** — 场景承载江湖冲突与戏剧张力，不是纯背景板，每一处场景都是对决舞台
2. **层次纵深** — 所有场景必须具备前/中/后景，杜绝扁平，用留黑与硬光制造压迫纵深
3. **质感至上** — 石壁/木构/金属/火焰等材质纹理必须以粗黑轮廓与平涂硬边清晰呈现
4. **港漫为锚** — 一切画面以复古港漫为标准，拒绝 3D 写实/CG 渲染；追求粗黑墨线、平涂高饱和色块、硬边阴影、速度线气势

## 五、主视图规范

### 视图定义

> 单画面主视图，从场景中最具代表性的角度拍摄，承载戏剧冲突与构图重心。港漫多用低仰/俯瞰的戏剧角度。

| 项目 | 约束 | 提示词 |
|---|---|---|
| 视角 | 戏剧低仰或俯瞰视角，构图最能承载对决张力与纵深 | hero shot、dramatic low angle |
| 视点高度 | 默认人眼平视或低位仰望（强调压迫）/ 高位俯瞰（强调布局） | eye level / low angle / bird's eye view |
| 构图 | 主体居中或对角线冲击构图，前/中/后景层次清晰 | dramatic composition、bold composition |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 单画面（非拼图、非多视图、非分屏） |
| 人物 | **严禁出现任何人物、人影、人体轮廓** |
| 一致性 | 风格/材质/色调/光线统一 |
| 光线 | 单一戏剧硬光源逻辑，光影方向一致，明暗硬切 |
| 画面比例 | 默认 16:9（或按调用方设定） |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 场景必须有「前中后景层次 + 留黑纵深」 |
| R2 | 室外必须包含「空气透视」与远景压暗 |
| R3 | 场景图必须为「单画面主视图」，不得拼接多视图/分屏/网格 |
| R4 | 构图须能承载戏剧冲突并展示前/中/后景层次 |
| R5 | 场景图中**严禁出现任何人物** |
| R6 | 必须包含复古港漫关键词（Hong Kong comic / bold ink outlines / flat saturated colors） |
| R7 | 必须包含港漫渲染特征（粗黑墨线 / 平涂色块 / 硬边阴影 / 速度线集中线） |
| R8 | 材质必须带有战损/刀痕/风化/岁月痕迹，禁止全新无瑕的"塑料感" |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 背景纯白/纯黑/无场景 |
| X2 | 柔光均匀平坦照明（必须戏剧硬光高对比明暗硬切） |
| X3 | 场景无纵深/无层次 |
| X4 | 氛围与色调矛盾（火海配冷蓝主光等） |
| X5 | 出现任何人物、人影、人体剪影或人体轮廓 |
| X6 | 画面被拼接成多视图/网格/分屏布局 |
| X7 | 3D 写实/CG 渲染/柔焦柔光/柔润插画质感（禁用 3D render、CGI、PBR、SSR、AO、体积光、次世代等词） |
| X8 | 材质过于干净完美、无任何战损痕迹与岁月感（避免"塑料感"） |
| X9 | 光照柔和均匀、无硬边阴影、无高对比戏剧光 |
