# 人物基础形象生成 · 约束手册

---

## 一、基础形象原则

1. **造型即灵魂** — 角色造型是核心锚点，港漫夸张硬朗造型，粗黑轮廓线撑起结构
2. **底模即基础** — 基础打底服装 + 素颜，后续服化均为叠加层
3. **四视图一致** — 面容/体型/发型/基础服装跨视图高度统一
4. **硬派气质** — 无妆状态仍需体现角色气质（刚猛/阴鸷/豪迈/飒爽）
5. **粗黑轮廓为骨** — 一切形体由粗黑墨线轮廓定义，线条即结构

---

## 二、面容约束

> 不再固定五官特征参数，由角色描述（性别/年龄/性格/气质）驱动 AI 自由生成五官，保证人物间外观差异化。港漫面容强调夸张表情张力与硬朗线条。

### 通用要求

| 项目 | 约束 |
|---|---|
| 五官 | 由角色描述自然推导，不预设脸型/眼型/眉型/鼻型/唇型 |
| 风格底色 | 复古港漫、1970s-90s 港式武侠漫画、粗黑墨线轮廓、平涂高饱和色块、硬边阴影 |
| 气质 | 必须从角色描述提炼整体气质关键词（如刚猛霸烈/阴鸷邪魅/豪迈义气/飒爽英气），并写入提示词 |
| 表情 | 中性偏硬朗的微表情，眉眼自带英气或戾气，符合角色气质 |
| 线条 | 五官由粗黑墨线勾勒，眉锋凌厉、眼神锐利，硬边轮廓清晰 |

## 六、基础服装约束

> 基础服装为素色劲装打底，女性为素色束身劲装，男性为素色武服。正式战甲华服在服化衍生环节叠加。

### 女性基础服装

素色束身劲装，颜色以基础色（肉色/灰青/墨蓝）为主，无花纹装饰，便于行动。

### 男性基础服装

素色武服或赤膊缠绷带，颜色以基础色（肉色/灰青/墨蓝）为主，无花纹装饰。

### 着装统一规则

- 服装风格统一，确保后续战甲服饰叠加无色彩干扰
- 女性劲装露出手臂腿部线条，男性可赤膊展示肌肉
- 四视图服装款式完全一致
- 基础服装仅为安全打底，焦点在面容、体型与肌肉线条

## 八、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须为「素颜状态」 |
| R2 | 必须声明基础服装（女性：素色束身劲装；男性：素色武服或赤膊缠绷带） |
| R3 | 必须声明「无发饰、无配饰」 |
| R4 | 必须指定「银灰纯色背景」 |
| R5 | 必须指定「四视图一致性」 |
| R6 | 全身立像必须从头顶到脚底完整展示，严禁裁切 |
| R7 | 必须声明角色身高并通过头身比换算约束全身比例（女性默认 165-175cm/7-8头身，男性默认 180-195cm/8-9头身） |
| R8 | 人像特写必须从头顶到锁骨完整展示，严禁裁切头顶 |
| R9 | 必须使用「粗黑墨线轮廓 + 平涂高饱和色块 + 硬边阴影」港漫核心技法 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 基础服装以外的任何服装/配饰/妆容 |
| X2 | 柔光均匀照明/低对比柔光（必须硬光高对比明暗硬切） |
| X3 | 柔美柔焦柔光气质/柔和水润插画式柔和质感 |
| X4 | 复杂场景背景（必须纯色） |
| X5 | 夸张动态姿势（基础形象为自然站立） |
| X6 | 全身立像裁切头顶或脚底，必须从头到脚完整入画 |
| X7 | 人像特写裁切头顶，必须从头顶到锁骨完整入画 |
| X8 | 忽略身高和头身比约束，身高必须明确声明并通过头身比换算体现全身比例 |
| X9 | 细软线条/写实摄影/3D CG 渲染/PBR/SSR/AO/体积光等 CG 术语 |
