# 二维水彩绘本动画风格说明

本风格专为"二维水彩绘本动画"题材打造，所有美术提示词、规范和生成内容均严格限定于：

- **手绘水彩绘本动画**：以手绘水彩绘本/童话故事书质感为锚的治愈童话视觉体系，涵盖童话森林、绘本小镇、云朵花园等题材
- **绘本童话美学**：水彩透明晕染、颜料边缘水迹、纸张纤维纹理、大量留白意境、柔和淡彩、童真治愈
- **手绘水彩渲染技法**：柔和淡褐色细线、块面水彩上色、水彩晕染透明感，区别于死板平涂与锐利赛璐璐
- **治愈童话**：圆润柔和五官、清澈大眼、纯真温柔好奇气质，水彩手绘发丝
- **柔和线条**：清晰柔和的淡褐色细线、淡彩块面、水彩晕染、纸张质感
- **水彩绘本电影质感**：电影级构图、水彩光晕层次、治愈氛围、情绪意境

## 适用范围

- 水彩绘本童话题材的AI美术生成（角色、场景、道具、分镜等）
- 需要手绘水彩质感、绘本插画风格、治愈童话意境的视觉创作
- 童话动画、绘本游戏美术、概念设计、插画创作

## 严禁内容

- 3D渲染/CG/UE/Blender/PBR材质写实渲染
- 写实摄影/真人实拍/照片级真实感
- 硬朗锐利黑线/高对比度阴影
