# 二维水彩绘本动画约束 · 二维水彩绘本动画 · 技法参考

---

## 一、色调体系与画面基调

- **色调基底** — 全片以核心色盘为基底：水彩粉（C1 #F2C9C9）、天青（C2 #A8C8D8）、鹅黄（C3 #F0D89A）、薄荷绿（C4 #A8C8A8）、米白纸（C5 #F5F0E6）、淡紫（C6 #C9B8D8）、暖橙（C7 #E8B080）、雾灰（C8 #B8B8C0），整体色温偏暖（5200-6000K），饱和度中低（40-60%），呈现水彩淡彩通透的治愈童话画面
- **冷暖叙事对比** — 暖色（水彩粉 C1、鹅黄 C3、暖橙 C7）作为正向情感/温馨/治愈的视觉信号；冷色（天青 C2、淡紫 C6、雾灰 C8）作为宁静/梦境/思念的视觉信号。冷暖切换应与故事弧线同步，而非随意混用
- **冷暖分配策略** — 月夜童话/思念独处段落使用冷色调（天青 + 淡紫 + 米白纸），禁用暖橙/鹅黄暖光；花园午后/窗光暖室段落使用柔和暖调（米白纸 + 水彩粉 + 鹅黄 + 暖橙）；黄昏晕染段落使用暖橙 + 淡紫水彩渐变
- **色盘先行原则** — 段落规划需先绑定情绪场景（森林清晨/花园午后/黄昏晕染/月夜童话/窗光暖室/精灵魔法/雨后彩虹等），再确定主色+辅色与光影方案，避免"剧情对了但情绪不对色"
- **禁用色域** — 高饱和荧光色、霓虹色、数码感强色彩均与本风格不兼容。色相偏移容差 ±8°，饱和度偏移 ±10%，明度偏移 ±12%

## 二、光影方案体系

- **光影即叙事** — 7 套光影方案对应不同情绪段落，导演规划阶段应在段落层面确定光影基调方向，而非逐镜指定
- **水彩光影为锚** — 所有光影方案必须保持水彩晕染质感，阴影使用同色系水彩晕染加深，禁止黑色硬阴影，允许体积光晕/景深虚化等柔和渲染技法
- **光源角度** — 正给镜头默认 38.5° 斜射柔光（水彩晕染质感），侧给镜头可适当调整

| 光影方案 | 方案名 | 色调倾向 | 适用情绪 |
|---|---|---|---|
| A | 晨雾森林 | 薄荷绿 + 米白纸底 + 水彩粉微暖肤光 | 森林清晨、治愈清新、初遇启程 |
| B | 午后花园暖光 | 米白纸 + 水彩粉 + 鹅黄 + 暖橙边缘光 | 花园午后、温馨甜蜜、治愈日常 |
| C | 黄昏晕染 | 暖橙主导 + 淡紫渐变 + 雾灰柔暗部 | 黄昏告别、浪漫升温、暖意绵绵 |
| D | 月夜淡蓝 | 天青 + 米白纸冷光 + 淡紫微暖点缀 | 月夜童话、思念独处、宁静清冷 |
| E | 窗光童话暖 | 米白纸底 + 暖橙侧光斑驳 + 鹅黄点缀 | 室内日常、绘本书房、童趣安心 |
| F | 彩虹雨后 | 薄荷绿 + 天青 + 水彩粉 + 鹅黄通透漫射 | 雨后希望、清新治愈、释然重生 |
| G | 星光精灵光 | 淡紫 + 水彩粉 + 鹅黄点点星光 + 通透光晕 | 精灵魔法、梦境奇妙、心愿仪式 |

- **冷暖光分配** — 暖色光（暖橙/鹅黄/水彩粉）适用于正向情感/温馨段落；月夜童话/梦境段落可冷光为主，但本风格整体偏暖治愈，冷光段落应保留柔和暖光点缀。导演可根据叙事需要调整冷暖切换点
- **氛围方向映射** — 每场戏的氛围方向应能映射到上述光影方案（A-G）的某一方向，确保视觉一致性

## 三、质感方向

- **水彩晕染为锚** — 二维水彩绘本动画的核心：淡褐细线、水彩晕染、纸张纹理、柔和淡彩、色块透明晕染渐变，禁止色块断层/死板平涂/色彩溢出
- **手绘水彩 + 治愈质感** — 这是画面质感的锚点。不是写实摄影，不是 3D CG，不是锐利赛璐璐，是手绘水彩绘本动画加治愈童话美学的融合
- **材质水彩化** — 所有服化道的材质必须以水彩晕染呈现：棉麻的柔软用透明色块、木质的温润用晕染色阶、玻璃的通透用淡彩折射、纸张的纤维用可见纹理。禁止"3D 感"和"写实摄影感"
- **皮肤质感** — 粉白水彩基调、水彩晕染、自然柔润、柔和质感、内透水彩光感、皮肤通透泛粉。禁止哑光/死白/蜡感/油光/过曝
- **水彩不等于扁平** — 二维水彩绘本动画强调在水彩晕染基础上通过光影层次、景深虚化、水彩光晕等手段增加空间感与治愈氛围，而非扁平无纵深的卡通风格

## 四、水彩绘本场景空间元素

水彩童话世界观特有的场景元素及其视觉叙事功能：

- **纸张留白/水彩晕染/淡彩渐变** — 天然的意境构图手法，制造"看得见呼吸"的治愈层次与留白意境，以水彩晕染呈现温柔过渡
- **童话森林/花田/云朵/星空** — 留白构图的天然载体，景即情：满花田 = 治愈喜悦、独坐月下 = 思念、蒲公英飞舞 = 启程、云朵花园 = 梦幻自由
- **窗光/星光灯/烛火/月光** — 童话世界的光源载体，窗光 = 暖/安心（方案E）、月色 = 冷/思念（方案D）、星光灯 = 梦幻/童趣（方案G）、烛火 = 暖/私密（方案C）
- **绘本小镇木屋/风车磨坊/小桥/糖果屋/栅栏** — 建筑元素以绘本美学呈现，圆润柔和、淡褐细线清晰，材质带自然手作/温柔岁月感，禁止全新无瑕的"塑料感"
- **段落间用场景空镜过渡** — 本风格有丰富的场景资产（不同时段/天候/景别变体），段落衔接建议用场景空镜做情绪缓冲，不要硬切
- **转折点用视觉而非台词** — 优先使用画面手段（光影突变、景别跳切、空镜隐喻）而非依赖对白解释
- **前中后景层次 + 留白** — 所有场景必须具备前/中/后景 + 大量留白意境，杜绝扁平，室外必须包含空气透视（远山水彩晕染）

## 五、童话乐器与环境音

水彩童话世界观下的声音元素约束：

### 乐器选择

- **钢琴（柔音/童话音色）** — 治愈、日常、温馨段落的核心乐器，与花园午后/森林清晨氛围高度适配
- **木吉他/尤克里里** — 旅人、启程、探索段落的轻快乐器，适合纸船河流/风车磨坊/旅途场景
- **竖琴/钢片琴** — 梦境、精灵、魔法段落，晶莹剔透的音色适合星光精灵光氛围
- **长笛/竹笛** — 童话森林、清晨鸟鸣、自然治愈段落，与晨雾森林氛围高度适配
- **弦乐（柔弦铺底）** — 情感渐浓、思念、告别段落，温柔拉弦适合黄昏晕染/月夜淡蓝
- **八音盒** — 童真、回忆、心愿仪式段落，与星光精灵光/心愿瓶氛围高度适配
- 弦乐铺底可增加电影感但不宜喧宾夺主

### 乐器组合策略

| 情绪阶段 | 乐器组合 |
|---|---|
| 平稳/开场/收尾 | 钢琴独奏 或 钢琴 + 长笛 |
| 森林清晨/治愈日常 | 长笛 + 钢琴 + 轻铃 |
| 旅途/探索/启程 | 尤克里里 + 木吉他 + 轻打击 |
| 梦境/精灵/魔法 | 八音盒 + 竖琴 + 钢片琴 |
| 思念/告别渐浓 | 弦乐铺底 + 钢琴 + 长笛 |
| 情绪高潮/心愿达成 | 弦乐 + 八音盒 + 钢琴 + 轻合唱 |
| 节庆/舞会/盛大 | 弦乐 + 木管 + 轻打击 + 钢琴铺底 |

### 童话环境音

- **典型环境音层次** — 鸟鸣啁啾 / 溪水潺潺 / 风过花田 / 风铃轻响 / 萤火虫光点微响 / 纸张翻动 / 烛火噼啪 / 蒲公英飞舞 / 星光呢喃 / 八音盒余韵
- **每场戏标注 1-2 个核心环境音**，帮助后续音效设计。环境音层次越丰富，童话场景越有沉浸感
