# 分镜表二维水彩绘本动画约束 · 二维水彩绘本动画 · 技法参考

---

## 一、分镜表定位

分镜表是导演将剧本转化为镜头语言的核心工具。以下仅提供二维水彩绘本动画风格在分镜表层面的约束规范。

---

## 二、光影与氛围

- **水彩光影统一** — 一场戏内光影方案必须保持水彩晕染一致性，阴影使用同色系水彩晕染加深（禁止黑色硬阴影），除非有明确的叙事转折（如星光灯熄灭→月光淡蓝）
- **情绪色盘绑定** — 每场戏至少绑定 1 个情绪场景（如森林清晨/花园午后/黄昏晕染/月夜童话/窗光童话暖/精灵魔法/雨后彩虹），并在镜头组内保持主色+辅色连续性，色彩取自核心色盘（水彩粉 #F2C9C9 / 天青 #A8C8D8 / 鹅黄 #F0D89A / 薄荷绿 #A8C8A8 / 米白纸 #F5F0E6 / 淡紫 #C9B8D8 / 暖橙 #E8B080 / 雾灰 #B8B8C0）
- **光源角度规范** — 正给镜头光源默认 38.5° 斜射柔光（水彩晕染质感），侧给镜头根据画面需要调整。描述光影时须区分正给/侧给的角度差异，光影渲染始终保持手绘水彩质感
- **冷暖色调与叙事阶段匹配** — 月夜童话/忧伤哀婉段落使用冷色调（天青 + 淡紫 + 雾灰），但保留柔和暖光点缀；森林清晨/花园午后段落使用柔和暖调（米白纸 + 水彩粉 + 鹅黄 + 暖橙）；黄昏晕染段落使用暖橙 + 淡紫水彩渐变
- **光影转场是高级手段** — 从窗光童话暖渐变到月夜淡蓝 = 日转夜的时间流逝。在分镜表中标注光影变化点，转场过程中水彩色块必须平滑晕染渐变，禁止色块断层/色彩溢出
- **水彩光效** — 允许合理使用水彩体积光晕（watercolor light glow）、景深虚化、轮廓柔光等柔和渲染技法，但必须保持二维水彩绘本动画的手绘水彩美学基调，禁止 3D 写实/CG 动画光效

---

## 三、环境动态

- **环境动态增加画面呼吸感** — 花瓣飘落、蒲公英飞舞、水波荡漾、纱帘飘动、裙摆飘逸、萤火虫光点。每 3-4 个镜头至少安排一个有环境动态的镜头，避免画面"死"掉
- **水彩绘本环境元素优先** — 环境动态应选用童话世界观内的元素：落花、蒲公英、轻雾、流水、风过花田、烛火摇曳、云朵流动、萤火虫光点、星光闪烁、纸船漂浮，禁止出现现代元素
- **水彩动态质感** — 环境动态元素（花瓣/雾气/水波等）必须保持水彩晕染质感与淡褐细线，禁止出现 3D 粒子特效或写实流体效果

---

## 四、二维水彩绘本动画动作节奏

- **动作优雅且带童话感** — 人物动作默认缓慢温柔，可在关键帧上做童话夸张处理（如少女回眸时的发丝飘动、精灵魔法时的光晕扩散），起身、转身、抬手应标注"缓慢/温柔/治愈"
- **服饰动态是核心画面资产** — 水彩绘本服饰（连衣裙裙摆、披风、缎带、薄纱）的飘动是天然的动态资产，可在画面描述中加入裙摆/披风/缎带的动态，水彩渲染下的服饰飘动应淡褐细线清晰、层次分明
- **仪态约束** — 水彩绘本人物的举止应符合童话气质：行走轻柔、举手投足纯真温柔、不出现现代化的肢体语言（如耸肩、摊手）。绘本角色可在微表情上略有童话夸张（眼睛弯月、脸颊泛粉），但肢体动作仍需温柔克制
- **头身比一致** — 动作设计中角色必须保持 5-6 头身的童话绘本圆润比例，禁止因动态姿势而破坏头身比

---

## 五、材质与质感约束

- **水彩晕染为锚** — 所有镜头中人物/服饰/道具/场景的渲染必须保持水彩晕染质感，淡褐细线柔和清晰，色块透明晕染，禁止 3D 写实/CG 动画/照片级渲染
- **服饰材质** — 棉麻 + 蕾丝 + 薄纱 + 缎带的质感用水彩晕染表现，纹理必须超清晰，衣服水彩质感清晰
- **道具材质** — 木质温润、陶瓷釉面、玻璃通透、纸纤维可见，均以水彩晕染 + 淡褐细线呈现，禁止写实材质渲染
- **场景材质** — 木面有手作痕迹、石面有青苔、布料有自然褶皱，材质带有温柔岁月感但以水彩绘本笔触呈现，禁止"塑料感"的全新无瑕材质

---

## 六、色彩约束

- **核心色盘锁定** — 分镜表中所有镜头的色彩必须取自核心色盘（C1-C8），色相偏移容差 ±8°，饱和度偏移 ±10%，明度偏移 ±12%
- **禁止荧光色** — 严禁高饱和荧光色/霓虹色/数码感强的色彩出现
- **线条颜色** — 柔和淡褐色细线，禁止锐利纯黑粗线条
- **阴影色** — 同色系水彩晕染加深，禁止黑色硬阴影
- **整体色温** — 偏暖 5200-6000K 治愈暖光基调，对比度 35-55%，饱和度 40-60%（水彩淡彩通透）

---

## 七、运镜禁忌

- **禁用快速运镜** — 甩镜、急推、手持晃动与二维水彩绘本动画的治愈温柔气质冲突，梦境/精灵魔法场景可适度使用柔焦推移但仍需保持画面清晰柔和
- **禁用花式转场** — 划屏、旋转、百叶窗等与本风格不兼容
- **禁用写实镜头语言** — 手持摇晃/纪录片式跟拍/鱼眼镜头等与水彩绘本美学冲突，破坏手绘水彩晕染的画面纯净感
