# 人物基础形象生成 · 约束手册

---

## 一、基础形象原则

1. **造型即灵魂** — 角色造型是核心锚点，水彩绘本造型，圆润柔和线条
2. **底模即基础** — 基础打底服装 + 素颜，后续服化均为叠加层
3. **四视图一致** — 面容/体型/发型/基础服装跨视图高度统一
4. **童话气质** — 无妆状态仍需体现角色气质（治愈/纯真/温柔/好奇）

---

## 二、面容约束

> 不再固定五官特征参数，由角色描述（性别/年龄/性格/气质）驱动 AI 自由生成五官，保证人物间外观差异化。

### 通用要求

| 项目 | 约束 |
|---|---|
| 五官 | 由角色描述自然推导，圆润柔和五官、清澈大眼，不预设脸型/眼型/眉型/鼻型/唇型 |
| 风格底色 | 手绘水彩绘本、治愈童话美学、水彩晕染、柔和淡褐细线、纸张纹理 |
| 气质 | 必须从角色描述提炼整体气质关键词（如治愈纯真/温柔好奇/灵动俏皮），并写入提示词 |
| 表情 | 中性微表情，符合角色气质，童真柔和 |

### 人物原型矩阵

| 原型 | 面容/气质关键词 | 适用 |
|---|---|---|
| 童话少女 | 圆润柔和五官、清澈大眼、治愈纯真、温柔好奇 | 主角、少女向叙事 |
| 童话少年 | 圆润清秀五官、明亮眼神、纯真勇敢、温暖少年感 | 主角、少年向叙事 |
| 动物伙伴（兔子/小鹿/猫头鹰/小狐） | 圆润拟人化五官、灵动大眼、纯真陪伴、毛茸质感 | 陪伴角色、童话精灵向 |
| 森林精灵 | 尖耳柔美五官、通透灵动眼、空灵治愈、淡彩光晕 | 魔法/精灵叙事 |
| 绘本旅人 | 柔和沉静五官、清澈好奇眼、温文治愈、旅途气质 | 旅人/探索叙事 |
| 魔法师少年 | 圆润英气五官、明亮坚定眼、纯真果敢、魔法光晕 | 魔法/冒险叙事 |

## 六、基础服装约束

> 基础服装无特殊约束，女性为素色水彩绘本连衣裙/罩衫，男性为素色水彩绘本衬衫+背心/罩衫。正式服饰在服化衍生环节叠加。

### 女性基础服装

素色水彩绘本连衣裙，颜色以基础淡彩为主，无花纹装饰。

### 男性基础服装

素色水彩绘本衬衫与背心，颜色以基础淡彩为主，无花纹装饰。

### 着装统一规则

- 服装风格统一，确保后续服饰叠加无色彩干扰
- 除面部/手部/颈部外基本覆盖
- 四视图服装款式完全一致
- 基础服装仅为安全打底，焦点在面容与体态
- 服装上色为水彩晕染色块，禁死板平涂/锐利边缘

## 八、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须为「素颜状态」 |
| R2 | 必须声明基础服装（女性：素色水彩绘本连衣裙；男性：素色水彩绘本衬衫与背心） |
| R3 | 必须声明「无发饰、无配饰」 |
| R4 | 必须指定「米白纸纯色背景带纸张纤维纹理」 |
| R5 | 必须指定「四视图一致性」 |
| R6 | 全身立像必须从头顶到脚底完整展示，严禁裁切 |
| R7 | 必须声明角色身高并通过头身比换算约束全身比例（女性默认 150-165cm/5-6头身，男性默认 160-175cm/5-6头身） |
| R8 | 人像特写必须从头顶到锁骨完整展示，严禁裁切头顶 |
| R9 | 必须包含「手绘水彩质感 + 水彩晕染透明感 + 纸张纹理」风格锚定词 |
| R10 | 线条必须为「柔和淡褐细线」，禁锐利黑线 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 基础服装以外的任何服装/配饰/妆容 |
| X2 | 正顶硬光/正底光/冷色硬光/重对比阴影 |
| X3 | 过度美白至无血色 / 肤色发灰 |
| X4 | 复杂场景背景（必须纯色纸张底） |
| X5 | 夸张表情/激烈动态姿势 |
| X6 | 全身立像裁切头顶或脚底，必须从头到脚完整入画 |
| X7 | 人像特写裁切头顶，必须从头顶到锁骨完整入画 |
| X8 | 忽略身高和头身比约束，身高必须明确声明并通过头身比换算体现全身比例 |
| X9 | 锐利纯黑线条、死板平涂、3D/CG/写实摄影质感 |
| X10 | 荧光色发色/霓虹色/古风国潮水墨/赛博朋克机甲元素 |
