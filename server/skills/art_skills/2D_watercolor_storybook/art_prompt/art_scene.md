# 场景图生成 · 约束手册

---

## 一、场景美学原则

1. **空间叙事** — 场景承载治愈与童话叙事功能，不是纯背景板
2. **层次纵深** — 所有场景必须具备前/中/后景 + 大量留白意境，杜绝扁平
3. **质感至上** — 水彩纸张纤维、颜料水迹边缘、木纹/布料/水面等材质必须以水彩晕染呈现
4. **水彩绘本为锚** — 一切画面以二维水彩绘本动画为标准，拒绝3D写实/CG动画/照片质感；追求水彩晕染、淡褐细线、纸张纹理、柔和淡彩

## 三、室内场景

### 空间规范

| 维度 | 约束 | 提示词 |
|---|---|---|
| 风格 | 童话小屋/绘本书房/糖果屋/阁楼卧室/树屋内饰 | 童话{类型}风格内饰 |
| 材质 | 木质为主、棉麻布艺/陶瓷/纸艺为辅 | 木地板、棉麻窗帘、陶瓷小物、纸艺装饰 |
| 色调 | 水彩淡彩色调 + 米白纸墙面 + 暖橙木漆 | 暖木色调、绘本质感陈设 |
| 纵深 | 前/中/后景层次 + 留白意境 | 前景{元素}、中景{元素}、后景{元素}、留白意境 |
| 质感 | 木纹/布料垂感/陶瓷光泽以水彩晕染可辨 | 水彩纹理清晰、晕染质感细腻 |
| 光照 | 自然光源为主（窗光/烛光/星光灯），柔和漫射 | 自然光漫射、烛光柔和、水彩光晕 |
| 镜头感 | 水彩晕染虚化前后景、淡褐细线清晰 | watercolor wash, soft brown lines |
| 瑕疵感 | 木面有使用痕迹、陶器有手作不规整、布料有自然褶皱 | 手作痕迹、自然磨损、布料自然垂褶 |

| 类型 | 核心元素 | 氛围词 |

| 童话小屋卧室 | 木床、棉被、纱帘、小窗、星光灯 | 温馨私密、纸页静谧 |
| 绘本书房 | 书架、绘本、画框、摇椅、台灯 | 幽静治愈、墨香纸韵 |
| 糖果屋 | 糖果装饰、饼干墙、糖霜、小炉灶 | 童趣甜蜜、暖意融融 |
| 树屋内饰 | 木梯、藤蔓、小窗、麻绳、软垫 | 自然童趣、温馨栖居 |
| 阁楼星空 | 老虎窗、星光灯、望远镜、软毯 | 梦幻静谧、星河入梦 |

## 五、主视图规范

### 视图定义

> 单画面主视图，从场景中最具代表性的角度拍摄，承载空间叙事与构图重心。

| 项目 | 约束 | 提示词 |
|---|---|---|
| 视角 | 自然观察视角，构图最能体现场景主体与纵深 | hero shot、representative angle |
| 视点高度 | 默认人眼平视高度，特殊场景可俯/仰 | eye level（默认） |
| 构图 | 主体居中或符合三分法，前/中/后景层次清晰，留白意境 | balanced composition、negative space |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 单画面（非拼图、非多视图、非分屏） |
| 人物 | **严禁出现任何人物、人影、人体轮廓** |
| 一致性 | 风格/材质/色调/光线统一 |
| 光线 | 单一光源逻辑，水彩光影方向一致 |
| 画面比例 | 默认 16:9（或按调用方设定） |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 场景必须有「前中后景层次 + 留白意境」 |
| R2 | 室外必须包含「空气透视水彩晕染」 |
| R3 | 场景图必须为「单画面主视图」，不得拼接多视图/分屏/网格 |
| R4 | 构图须能代表场景主体并展示前/中/后景层次 |
| R5 | 场景图中**严禁出现任何人物** |
| R6 | 必须包含水彩绘本关键词（hand-painted watercolor / storybook illustration / soft brown lines） |
| R7 | 必须包含镜头光学特征（水彩晕染 / 淡褐细线 / 纸张纹理） |
| R8 | 材质必须带有手作痕迹/自然磨损，禁止全新无瑕的"CG 感"/"塑料感" |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 背景纯白/纯黑/无场景 |
| X2 | 极端天候（暴风雨/雷电/暴雪，除非剧情需要） |
| X3 | 场景无纵深/无层次/无留白 |
| X4 | 植被/天候与季节矛盾 |
| X5 | 出现任何人物、人影、人体剪影或人体轮廓 |
| X6 | 画面被拼接成多视图/网格/分屏布局 |
| X7 | 3D 写实/CG 动画/卡通/游戏引擎质感（禁用 3D render、CGI、Unreal Engine、Unity、Blender、PBR 等词） |
| X8 | 材质过于干净完美、无任何使用痕迹与手作感（避免"塑料感"） |
| X9 | 光照过于均匀平坦、无景深虚化、无水彩晕染层次 |
| X10 | 锐利纯黑线条、重对比阴影、高饱和荧光霓虹色 |
| X11 | 古风国潮水墨/赛博朋克机甲/暗黑暴力元素（破坏童话纯净） |
