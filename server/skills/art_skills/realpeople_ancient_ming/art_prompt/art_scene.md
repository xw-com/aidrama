# 真人明朝写实场景图像生成 · 约束手册

---

## 一、场景美学原则

> 真人明朝写实的场景不是"被建模的古代布景"，而是"被摄影机选中的真实明代空间"。没有渲染引擎、没有贴图、没有体积光参数——只有实际存在的天光与烛火、真实的青砖黛瓦与黄花梨紫檀、以及明代社会的岁月与礼法。

1. **空间即社会** — 一座空无一人的江南园林不是"空的"，是主人离席之后。黄花梨书案上的墨迹未干、罗汉床上的靠垫微皱、折扇未合——空间自己会讲士大夫、商贾与市井的故事
2. **真实的光，不是渲染的光** — 场景的光只有一个来源：实际的日光（通过漏窗、天井、厅窗）、实际的灯火（烛台、油灯、廊灯）。光的色温和方向必须在物理上说得通
3. **被岁月使用过的明代** — 真实的明代空间不崭新。青砖有磨损与雨痕、黛瓦有积苔、白墙有水渍斑驳、黄花梨有鬼脸纹与包浆、紫檀有开裂、朱漆有剥落——一个完全没有岁月痕迹的空间是横店的样板布景，不是真实明代
4. **明代社会的真实场所** — 场景必须有明确的明代辨识度（马面裙、补子、明式家具、青花瓷、漏窗、马头墙、白墙黛瓦、贡院号舍、明代市肆）。这不是"generic ancient chinese"，这是"明代社会的一个具体角落"
5. **单视图全景全貌** — 一张照片装下整座园/院/堂/肆的完整信息。广角或标准焦段，全景深，正面展示空间的全貌与纵深——不是四视图分割，不是多角度拼贴

## 五、单视图全景摄影规范

> 真人明朝写实场景仅需**单张**全景摄影——一张照片装下整座园/院/堂/肆的完整信息。不是2×2四视图，不是多角度拼接。

### 画面构成

| 项目 | 摄影要求 |
|---|---|
| 空间呈现 | 单张照片完整呈现场景的空间全貌。使用24-28mm广角或35mm，全场地的纵深、宽度、高度在一张画面中全部可见 |
| 构图 | 全景深大景别——前景（门/梁柱/纱帐/漏窗/家具/花木/马头墙）形成天然画框→中景是厅堂/园林/市肆主体→后景向空间纵深或后堂/天空延伸 |
| 景深 | 全景深 f/8-f/11，从前到后全部清晰。这不是人像摄影——场景的每一个角落都应该能被看见 |
| 人物 | **严禁出现任何人物、人影、人体轮廓。** 场景是空的——但这种"空"有叙事：主人离席之后/即将开市/人去院空/明代的静止瞬间 |
| 比例 | 建议 16:9 或 3:2 宽幅——匹配全景空间展示的横向视觉习惯 |
| 色彩 | 由实际光源的色温驱动，不套滤镜。色彩科学参考ARRI Alexa/Sony Venice电影色调 |

### 空的场景如何叙事

| "空"的类型 | 画面线索 | 叙事暗示 |
|---|---|---|
| 主人离席 | 黄花梨书案上墨迹未干、折扇未合、罗汉床靠垫微皱、茶盏余温 | 刚才有人，现在离席了 |
| 即将开市 | 市肆铺面门板半卸、幌子刚挂、酒坛码齐、无人 | 市肆即将开张，此刻是开市前的肃静 |
| 人去院空 | 搬迁后的空园、墙上挂过中堂的钉痕、地面积尘的轮廓、断了的香火 | 曾经有人住过，现在被废/迁/抄 |
| 明代的静止 | 架子床纱帐半垂、妆台铜镜映空床、茶盏余温、天井光打在青砖地 | 起居的常态，只是此刻无人入镜 |
| 深夜的厅堂 | 空荡的曲廊只有灯火亮着、书斋窗纸透出一团暖光、月下的空园林 | 院落睡着了，但明代空间还醒着 |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须是**单张**全景摄影——单视图、非2×2四视图、非多角度、非turnaround |
| R2 | 必须使用广角镜头（24-28mm）或标准焦段（35mm），全景深 f/8-f/11，完整空间纵深 |
| R3 | 光源必须可追溯——自然光的方向与时刻匹配、烛火灯火的位置和色温合理 |
| R4 | 场景必须有前/中/后景空间层次，前景画框→中景主体→后景延伸 |
| R5 | 必须有明代辨识度——漏窗/马头墙白墙黛瓦/明式家具/青花瓷/紫禁城朱墙黄瓦/贡院号舍/明代市肆 |
| R6 | 必须有岁月痕迹——青砖磨损/黛瓦积苔/白墙水渍/黄花梨包浆/朱漆剥落、非样板殿非全新非效果图 |
| R7 | **严禁出现任何人物、人影、人体轮廓、剪影** |
| R8 | 必须声明"真人实拍摄影 + 非3D渲染非CG"核心锚定 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 严禁「3D渲染 / 3D建模 / CG / UE引擎 / Blender / PBR材质 / 体积光 / AO」等一切CG术语 |
| X2 | 严禁「2D手绘 / 插画 / 动画 / 二次元 / 赛璐璐」等非摄影媒介 |
| X3 | 严禁「四视图 / 2×2网格 / 多角度 / turnaround / orthographic view / blueprint」——仅单张 |
| X4 | 严禁「现代都市/民国/西方/和风日式/仙侠法术/赛博朋克/科幻/西方奇幻/异世界」等非明代场景 |
| X5 | 严禁「清代元素——朱墙黄瓦配旗装马褂、牌坊配顶戴花翎、剃发垂辫人物」等清朝场景特征 |
| X6 | 严禁「唐宋建筑与陈设混搭——唐制斗拱配唐服、宋制褙子配宋式家具」当明代 |
| X7 | 严禁「无明代辨识度的架空古代 / 西式城堡 / 日式城堡 / generic ancient palace」 |
| X8 | 严禁「出现任何人物/人影/人体轮廓/剪影/肢体」 |
| X9 | 严禁「样板殿/横店崭新布景/全新无痕/完美品相/无岁月痕迹/法术光效」的场景 |
| X10 | 严禁「光源来源不明/全局均匀照明/无方向的光/法术发光」 |
| X11 | 严禁「过曝死白/暗部死黑/无景深/画面扁平」 |
| X12 | 严禁「水印 / 文字 / LOGO / 签名 / 边框 / AI生成痕迹」 |
