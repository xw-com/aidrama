# 真人明朝写实道具图像生成 · 约束手册

---

## 一、道具设计原则

> 真人明朝写实的道具不是"被建模的物件"，而是"被明代人用过、被岁月盘过的器物"——它在士子手里待过、在黄花梨案上供过、在朱批公文上压过。摄影机拍下的是它的此刻。

1. **器物即礼法与命运** — 每一件道具都是一个微型的明代叙事容器。圣旨上未干的朱砂暗示刚刚颁旨、补子的金线磨损暗示官员久历朝堂、书斋的墨锭磨去大半暗示士子寒窗多日
2. **使用痕迹优先于完美品相** — 真人明朝写实的道具必须有"被用过、被岁月盘过"的证据。全新出厂、样板级别的道具一律不出现
3. **明代社会真实器物** — 道具必须是明代社会中真实存在的器物：明式家具（黄花梨/紫檀）、永宣青花瓷、剔红漆器、文房四宝（徽墨/端砚/宣纸/湖笔）、补子乌纱帽、金簪头面、折扇——拒绝无朝代架空物品，拒绝清代器物
4. **材质即真实** — 不是PBR参数渲染出的材质，而是摄影机拍下的真实材质行为：黄花梨的鬼脸纹与温润包浆、紫檀的牛毛纹、青花瓷的釉下钴蓝、剔红漆器的堆雕层次、宣纸的纤维
5. **单视图静物摄影** — 道具以单张静物产品摄影方式独立呈现，非多角度建模展示，非2×2四宫格

## 三、单视图静物摄影规范

> 真人明朝写实道具仅需单张静物产品摄影，非多角度建模展示。以下为单视图摄影的完整规范。

### 画面构成

| 项目 | 摄影要求 |
|---|---|
| 道具呈现 | 道具居中或偏三分线位置独立陈列，完整入画，无裁切 |
| 背景 | 素灰无缝背景纸 #B0B0B0（哑光），或黄花梨木桌面/深紫檀台面/米白绫绢台面/粗棉布台面，根据道具属性选择。无多余物体、无装饰、无文字（道具本身的题字除外，如圣旨/家书/药帖/墨锭款识） |
| 光线 | 自然柔光或单灯柔光。窗光/天井光45°侧入（明亮柔和带自然阴影）、或柔光箱顶+侧补（产品摄影级均匀光线）。光影柔和、方向明确、无硬阴影 |
| 景深 | 浅景深（f/2.8-f/5.6），道具主体清晰锐利，前后微虚化突出主体 |
| 投影 | 道具底部与承载面之间的自然接触阴影——真实的而非抠图或悬浮。阴影柔软、方向与主光源一致 |
| 画面比例 | 建议 1:1 正方形或 4:3，适配单件道具展示 |

### 道具状态准则

| 维度 | 要求 |
|---|---|
| 使用痕迹 | 必须有"被用过、被岁月盘过"的视觉证据——非全新未启用、非样板品相 |
| 明代辨识度 | 明代器物形制/中文（如家书/圣旨/药帖/墨锭款识）/明代工艺——拒绝无朝代架空物品，拒绝清代器物 |
| 材质真实感 | 非渲染质感——是摄影机拍下的真实材料行为（光的反射、漫射、透射） |
| 服制等级感 | 礼制器物须有合乎身份的工艺等级（补子文禽武兽按品级、乌纱帽展角、玉带玉板按品级） |
| 尺度感 | 通过材质纹理密度、工艺细节暗示实物尺寸，无需参照物 |

## 六、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须是「单张静物摄影」——单视图、非多角度、非2×2四宫格、非建模展示 |
| R2 | 必须指定「素灰背景纸 #B0B0B0」或「黄花梨木桌面/深紫檀台面/米白绫绢台面」等真实明代承载面，禁止复杂场景 |
| R3 | 必须指定光源逻辑——天井光/窗光或柔光箱，光影方向明确、投影自然 |
| R4 | 道具必须有「使用痕迹/岁月痕迹」——非全新、非样板品相、非未启用 |
| R5 | 道具必须具备明代辨识度——明代器物形制/中文/明代工艺/按身份礼制等级 |
| R6 | 必须声明「实物产品摄影 + 非3D渲染非CG」核心锚定 |
| R7 | 材质必须描述为摄影机下的真实表现，而非渲染参数；刺绣须凸起非平面印花；黄花梨须有鬼脸纹包浆；青花须有釉下钴蓝 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 严禁「3D渲染 / 3D建模 / CG / UE引擎 / Blender / PBR材质」等一切CG术语 |
| X2 | 严禁「2D手绘 / 插画 / 动画 / 二次元 / 赛璐璐」等非摄影媒介 |
| X3 | 严禁「多角度 / 四视图 / 2×2网格 / 正交视图 / turnaround / blueprint」——仅单张 |
| X4 | 严禁「全新未启用 / 样板品相 / 无使用痕迹 / 完美品相 / 平面印花冒充刺绣」的道具 |
| X5 | 严禁「清代器物——旗装顶戴花翎、花盆底鞋、朝珠、钿子、清式广作家具」等清朝物品 |
| X6 | 严禁「唐宋器物混搭——唐三彩、宋汝窑、宋式家具」当明代 |

| X11 | 严禁「悬浮/抠图白底/无投影/无承载面」——物品必须放在真实表面上 |
