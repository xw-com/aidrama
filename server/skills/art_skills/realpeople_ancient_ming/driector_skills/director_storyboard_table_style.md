## 一、分镜表定位

分镜表是导演将剧本转化为镜头语言的核心工具。本约束面向 Seedance 2.0 视频生成，所有光影、动作、空间描述均采用模型可执行的具象语言。不做抽象的情感概括，不写模型看不懂的渲染参数。严格锚定明代（1368-1644），明制服饰、明式家具、青花瓷漆器、江南园林徽派建筑。

## 三、光影与氛围——Seedance 2.0 物理光源描述

### 3.1 同场戏光影统一

一场戏内不应出现两种以上核心光影方案，除非有叙事驱动的光源变化（如有人吹灭烛火、日落后天光暗于烛火、从厅堂走到园林）。光源变化必须在分镜表中标注触发事件。

### 3.2 光源语句法（每个镜头必须包含）
[光源] 主光：{光源类型——天井/厅窗天光/烛台油灯/月光/红纱灯}，{方向}，{色温值K}，{软硬}
[光源] 辅光/环境光：{光源类型}，{方向}，{色温值K}
[光比] 约1:{X}

### 3.4 冷暖色调与叙事阶段

- **冷光主导**（5000K+）：朝堂清明、月夜孤寂、寒窗压抑、悬疑克制
- **暖光主导**（2200-3500K）：书斋温情、烛影私密、青砖夕照、大典册封的金红
- **冷暖共存**：过渡时刻（蓝调时刻+初亮灯火）、书斋（月光+残烛）、对峙（烛火暖+漏窗冷）
- **光源变化 = 命运信号**：厅窗外天光从日间冷白渐变至黄昏暖金=时间流逝；从厅堂烛火暖走到月下青砖=命运的坠落

### 3.5 Seedance 2.0 光影适配要点

- 色温数字帮助模型校准白平衡倾向：`色温约2500K烛火暖橙` 优于 `暖光`
- 光比数字帮助模型建立明暗意识：`光比约1:4` 优于 `柔和的阴影`
- 光源必须有明确来源：`从画面左侧低位烛台斜入` 优于 `侧光`
- 环境光的反射路径描述：`青砖地反射烛火暖光` 优于 `地面有暖色反光`

- 禁止无来源的动态：没有风=纱帐不动。门窗紧闭=没有穿堂风

### 5.3 动作节奏与叙事场景

- **文戏/朝堂礼法**：动作沉稳克制，每个微动作标注时长和轨迹。节奏舒缓——不是慢，是"合乎明代礼法的不急"
- **情绪波动**：动作幅度和速度略微变化。人物可能在对话中不自觉地加快折扇开合的频率、呼吸带动肩膀起伏更明显
- **冲突场景**：动作干脆利落，但仍有物理轨迹。推搡/摔物须具体到"右手推在对方左肩前方，对方重心向后偏移约20cm，狄髻头面晃动剧烈"
- 禁止：无叙事理由的快速动作堆砌、无物理逻辑的瞬移、"施了一礼"等含糊描述

### 5.4 服饰动态

真人明朝写实的服饰动态是画面的天然资产——不是"布料模拟参数"，而是"马面裙褶皱随万福礼前倾自然垂坠""圆领袍衣袖起身时带回约10cm""狄髻金挑心随头部微动轻微晃动约1秒渐止""纱帐被穿堂风鼓起约15cm"。在分镜表画面描述中标注服饰与首饰的动态细节。

## 六、空间逻辑具象化——Seedance 2.0 空间坐标系统

### 6.1 每镜头必须声明的空间信息
水平位置：画面左/中/右，或画面左侧三分之一处
纵深位置：距镜头{数值}米，前景/中景/背景

### 6.2 站位衔接示例
【片段A尾部】
A闺秀站在徽派厅堂黄花梨罗汉床前，距床约0.5米，面朝床帐，位于画面中央偏右，距镜头约4米。
厅堂烛台油灯从画面左侧低位照入（约2500K暖橙）。
A右手轻抚纱帐边沿，金挑心距帐面约2cm。

【片段B开头】
A的右手刚从纱帐收回约10cm，金挑心仍在原位置附近。A仍站在罗汉床前（位置未变）。
厅窗外天色已从黄昏转为蓝调时刻——天空深蓝紫透窗，厅堂烛台已为主光源（约2500K暖橙）。
红纱灯已亮（画面右后侧），透红光照在A的右后侧肩背。

## 七、运镜规范——Seedance 2.0 摄影机运动

### 7.1 允许的运镜

| 运镜 | Seedance 2.0 描述 | 适用场景 |
|---|---|---|
| 固定 | 摄影机固定不动，画面静止 | 朝堂礼法、典礼、对话、空园留白、情绪凝视 |
| 手持微晃 | 摄影机有轻微不规则晃动（幅度约±2cm），模拟手持拍摄的呼吸感 | 暗涌、跟踪密会、情绪波动、市井喧闹 |
| 稳定器流动 | 摄影机平滑匀速移动，无晃动 | 曲廊纵深、人物登场、册封大典、空间展示 |
| 缓推 | 摄影机向主体缓慢推进，推进速率约每秒0.3米 | 情绪升温、真相逼近、注意力聚焦 |
| 缓拉 | 摄影机向后缓慢拉远，拉远速率约每秒0.3米 | 离别、收束、揭示全貌 |
| 跟拍 | 摄影机与人物保持约2米距离同步移动 | 曲廊穿行、市肆行走、园林跟随 |
| 摇镜 | 摄影机原地水平/垂直旋转 | 视线转移、厅堂纵深关系交代 |

### 7.2 禁用运镜

- 无叙事目的的快速甩镜、急推急拉（推拉速率超过每秒1米）
- 超过3秒的剧烈手持晃动（除非主观受击/眩晕/动乱叙事）
- 无逻辑花式转场——划屏、旋转、百叶窗、翻页等特效转场
- 摄影机无理由的360度旋转

### 7.3 真人明朝写实运镜哲学

- 固定机位是朝堂与典礼的第一选择——让观众看到明代人在礼法空间里自然存在
- 手持微晃在紧张段落使用——但晃动幅度不超过电影纪实风格的常规范围
- 稳定器流动用于曲廊纵深与人物登场——明代园林的仪式诗
- 运动镜头的起幅和落幅必须平稳，运动过程匀速——禁止突然加速或急停

## 八、转场规范

### 8.1 允许的转场方式

| 转场 | 视觉执行 | 叙事功能 |
|---|---|---|
| 硬切 | 直接切换 | 同场戏内镜头切换（默认） |
| 光影匹配转场 | 两个场景在相近光影逻辑下切换 | 时间流逝、平行叙事。例：A处烛火 → B处烛火 |
| 空间匹配转场 | 两个空间在构图或元素上呼应 | 场景跳转。例：宝座的明黄 → 厅堂明黄幔帐 |
| 空镜过渡 | 插入场景空镜（3-5秒） | 情绪缓冲、章节划分、时间流逝暗示（如黄昏马头墙→月夜黛瓦） |
| 焦点转场 | 前镜焦点从主体移至背景，后镜从模糊背景中逐渐聚焦主体 | 空间切换、注意力的转移 |

### 8.2 禁止的转场

- 纯视觉特效转场（翻页、划屏、百叶窗、马赛克、水墨化开）
- 无叙事逻辑的旋转/缩放转场
- 同一场戏内使用超过两种转场方式

## 十一、空镜使用规范

### 11.1 空镜不是"没东西拍"

空镜是情绪容器。每个空镜必须有叙事目的和具体的视觉内容：

| 空镜类型 | 叙事目的 | 示例 |
|---|---|---|
| 场景建立 | 新空间首次出现——让观众看清楚这是什么明代空间 | 紫禁城三大殿大全景：盘龙柱、藻井、宝座、丹陛、明黄幔帐 |
| 情绪缓冲 | 高情绪段落后的喘息 | 漏窗外月光沿纱帐滑下，速度约每秒2cm |
| 时间流逝 | 暗示时间过去了 | 同一厅窗外的天光从午后湛蓝渐变至黄昏暖金再至月夜冷蓝 |
| 隐喻留白 | 以物代情 | 黄花梨书案上半残的烛台，烛泪凝结，烛火明灭 |
| 转场衔接 | 前后两个空间的自然过渡 | 曲廊漏窗——前一场厅堂，下一场园林 |

### 11.2 空镜 Seedance 2.0 描述规范

空镜也必须遵循光源+质感+动态的描述铁律：厅堂烛台油灯从画面左侧低位斜入（约2500K暖橙），
在空荡荡的妆台铜镜上镀一层暖金，铜镜映出空罗汉床纱帐，
烛火每秒约2-3次微幅明灭，纱帐被穿堂风鼓起约10cm后回落，
妆台黄花梨木有鬼脸纹包浆，首饰盒朱漆边角磨损。

## 十二、分镜表质量自检清单

每场戏的分镜表完成后，导演逐项自检：

| 检查项 | 通过标准 |
|---|---|
