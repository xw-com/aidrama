# 分镜提示词 · 真人明朝写实 · 风格专属技法

## 适用范围

本 Skill 专用于**真人明朝写实**风格的分镜提示词生成，适配明代朝堂权谋、士人风骨、闺秀命妇、市井烟火、园林雅集、科举功名、锦衣卫江湖等真人实拍明代影视题材的分镜创作。严格锚定明代（1368-1644），明制服饰（袄裙马面裙/圆领袍补子/曳撒直裰）、明式家具（黄花梨/紫檀）、青花瓷漆器、江南园林、徽派马头墙、紫禁城初建、科举贡院、明代市肆。

## 一、摄影机前的情绪——面孔、眼神、微表情

> 真人明朝写实的情绪不来自"法术光效"或"渲染参数"，而来自真人演员在摄影机前的微表情与明代礼法之下的眼神。以下映射面向摄影机捕捉真实明代人的方式。

| 情绪输入 | 面容描述 | 眼神描述 | 微表情补充 |
|---|---|---|---|
| 威仪 / 沉稳 | 神情端凝，面部线条端正不紧绷，下颌微收 | 眼神深邃不怒自威，俯瞰式注视，喜怒难测 | 唇线平直，下颌微收，气场如山 |
| 隐忍 / 克制 | 眉眼不抬，面部肌肉收敛 | 目光低垂或平直不游移，将情绪压在眼底 | 嘴角自然平直，呼吸极轻，全身只有眼皮微动 |
| 温婉 / 柔顺 | 眉目舒展，面部柔和 | 眼神温润专注，像在认真听对方说话 | 嘴角自然含一丝温意，不是笑，是有温度 |
| 市井精明 | 面部线条微绷，藏锋于笑 | 眼神锐利有光，眼尾上挑，注视时不躲闪 | 嘴角微扬似笑非笑，算盘珠子般精明 |
| 清冷 / 孤傲 | 眉眼疏淡，面部不苟 | 眼神疏离冷意，眼尾微挑，自带距离感 | 唇形小巧微抿，下颌线紧致 |
| 惊动 / 触动 | 眼尾微抬，眉峰微动 | 眼神骤然聚焦，瞳孔微扩 | 嘴角微启，蛾眉下眼神鲜活一瞬 |
| 沉思 / 内省 | 神情淡然，眼部周围肌肉放松 | 目光放远失焦，像在看但不在看 | 表情平静，可能单手持折扇或玉佩轻抵唇角 |
| 哀怨 / 凄清 | 眉宇微蹙，眼睑低垂 | 目光含怨含水，望向窗外月色或落叶 | 嘴角自然下沉，眼尾有未落之泪的微光 |
| 喜悦 / 鲜活 | 眼角出现自然笑纹，眼型微弯 | 眼神明亮有光，眼角有笑意牵动 | 嘴角上扬，面颊微红，表情生动但不夸张 |
| 决绝 / 坚定 | 面部线条清晰，下颌微抬 | 眼神笔直向前，不回避不躲闪 | 下巴微收或微抬，表情果敢但不凶悍 |
| 寒窗孤苦 | 面色微白，眉宇微蹙 | 目光专注但疲倦，眼底有熬夜的青影 | 嘴唇微干，手指有墨渍，呼吸带动肩膀起伏 |

## 四、摄影机语法——镜头选择与运动

### 4.1 焦段选择

| 焦段 | 叙事性格 | 适用场景 |
|---|---|---|
| 24-28mm广角 | 空间吞噬人物，殿宇与园林威压，明代宏大与个体渺小 | 朝堂大全景、紫禁城广场、园林全貌、市肆长街、贡院号舍 |
| 35mm小广角 | 主观视点，身临其境的礼法纪实感，人与明代社会共存 | 曲廊穿行、书斋对话、园林跟随、市肆行走 |
| 50mm标准 | 人眼等价，客观中立的注视，最诚实的镜头 | 人物肖像、双人对话、补子凝视 |
| 85mm中长焦 | 压缩空间，拉近情感距离，丝绸补子与狄髻头面细节突出 | 特写、金簪头面、笔锋墨迹、烛火下的面容 |
| 135mm+长焦 | 将人物从青砖黛瓦中剥离，极端的注视或窥视 | 马头墙后远眺、长廊尽头的注视、命运的距离感 |

### 4.2 景别选择

| 景别 | 取景范围 | 叙事功能 |
|---|---|---|
| 大特写 | 眼睛/嘴唇/金簪/折扇/朱笔/墨迹/补子金线 | 情绪爆发点、关键信息揭示、感官聚焦 |
| 近景 | 头顶至胸部以上 | 人物情感、对话反应、蛾眉点唇微表情 |
| 中近景 | 头顶至腰部 | 人物互动、作揖/奉茶/递简手势 |
| 中景 | 头顶至膝盖上下 | 人物与厅堂园林的初级关系、多人同框 |
| 全景 | 人物全身+部分场景 | 人物在空间中的位置、行动路线、袄裙马面裙/圆领袍全貌 |
| 大全景/空镜 | 场景全貌，人物极小或无人物 | 空间叙事、情绪缓冲、隐喻留白 |

### 4.3 摄影机运动

| 运动方式 | 视觉心理 | 使用场景 |
|---|---|---|
| 固定 | 礼法庄严，让时间自己说话 | 朝堂、典礼、对话、空园留白 |
| 手持微晃 | 暗涌在场感，呼吸感，主观介入 | 冲突、跟踪密会、情绪波动、市井喧闹 |
| 稳定器流动 | 优雅的曲廊纵深，园林的仪式诗 | 人物登场、曲廊纵深跟拍、册封大典 |
| 缓推 | 注意力逐渐聚焦、情绪趋近 | 对话升温、真相逼近、情感推进 |
| 缓拉 | 拉开距离、揭示全貌、情绪抽离 | 离别、章节收束、空间展示 |
| 跟拍 | 与人物同行、主观陪同 | 曲廊穿行、市肆行走、园林跟随 |
| 摇镜 | 视线转移、空间关系交代 | 人物视线引导、厅堂纵深关系 |

## 五、固定风格锚定词

**摄影锚定（必选）：**

真人实拍摄影，真人电影剧照，明代社会，电影级摄影，自然天光与烛火油灯调度，真实色彩科学

**人物质感（含人物镜头时必选）：**

真人写实摄影质感，真实皮肤纹理毛孔可见，明代妆容与皮肤融合，不磨皮不硅胶脸，女性狄髻头面/男性束发网巾乌纱帽真实发质有鬓发碎发，丝绸袄裙马面裙圆领袍补子金线刺绣凸起反光有衣摆褶皱，明代礼法体态，克制微表情

**场景质感（含场景镜头时必选）：**

真人实拍明代场景摄影，真实材质和岁月痕迹（青砖磨损/黛瓦积苔/白墙水渍/黄花梨鬼脸纹包浆/朱漆剥落），光源方向明确可追溯，大气透视自然，非样板布景非效果图

保持人物造型、面容、狄髻头面/束发网巾乌纱帽、袄裙马面裙圆领袍首饰与参考图完全一致，保持场景风格与参考图一致，保持光影色彩基调统一，所有镜头呈现为同一人物的连续摄影记录

真人写实摄影，明代社会电影质感，电影级摄影画面，非3D非渲染非CG

## 六、美学禁止项

以下词汇/风格不得出现于输出提示词中：

- ❌ 3D渲染 / 3D建模 / CG / UE引擎 / Blender / PBR材质 / 次世代建模 / 体积光 / 环境光遮蔽 / 光线追踪
- ❌ 2D手绘 / 插画 / 动画 / 二次元 / 漫画 / Q版 / 赛璐璐 / 低多边形
- ❌ 写实摄影（英文禁止 photorealistic / realistic photography——本风格是"真人实拍摄影"live-action cinematic photography，不是"拟真渲染"）
- ❌ 过度磨皮 / 塑料假面 / 零毛孔 / 硅胶脸 / 蜡像感 / AI感平滑 / 妆容像贴图
- ❌ **清代元素——旗装/旗袍、花盆底鞋、马蹄袖、钿子/旗头/两把头、剃发垂辫/阴阳头、顶戴花翎、马褂、朝珠**（那是清朝不是明朝）
- ❌ **唐宋元素混搭——唐制齐胸襦裙、唐圆领翻领袍、宋制褙子**当明代
- ❌ 仙侠法术 / 玄幻特效 / 真气流转 / 御剑飞行 / 法术光效 / 灵力光环 / 水墨法术特效
- ❌ 现代当代都市 / 民国 / 西方 / 和风日式 / 赛博朋克 / 科幻 / 西方奇幻 / 中世纪
- ❌ 平面印花冒充刺绣 / 平面金线
- ❌ 人体结构错误 / 肢体畸形 / 面部崩坏 / 比例失调
- ❌ 高饱和荧光色 / 霓虹溢色 / 廉价滤镜感 / 二次元平涂
- ❌ 无明代辨识度的架空古代 / 西式城堡 / 日式城堡 / generic ancient palace
