本手册的核心创作理念为 **"衣冠正经，烟火可亲"**：

4. **克制写实即品格**：本风格为"真人写实明代"，不是仙侠法术，不是动漫玄幻。一切光影、材质、人物以写实克制为底色——士子的抱负落在眉宇与笔锋上，不落在魔法光效上；市井的冷暖藏在青砖巷弄里，不藏在特效里。

- **发型标准**：女性真实狄髻/高髻/堕马髻，配头面（金簪、银脚簪、掩鬓、挑心、顶簪）；男性束发戴网巾，其上加乌纱帽/方巾/幞头/六合一统帽。杜绝假发感与僵硬造型

2. **非明代/非中国古代世界观**：现代当代都市/民国/西方/和风日式/赛博朋克/科幻未来/星际太空等非明代社会背景
3. **跨朝代混搭（历史红线）**：**严禁混入清代元素**（旗装/旗袍、花盆底鞋、马蹄袖、钿子/旗头、剃发垂辫/阴阳头、顶戴花翎、马褂）——那是清朝不是明朝；**严禁混入唐宋元素**（唐制齐胸襦裙、唐圆领袍翻领、宋制褙子）当明代；**严禁混入仙侠/架空**。明代就是明代，服制建筑器物必须锚定明代
4. **仙侠法术与玄幻特效**：法术光效/真气流转/御剑飞行/玄幻粒子/灵力光环/水墨法术特效等一切玄幻CG特效（本风格为写实克制明代，"玄"靠氛围不靠特效）
5. **违反明代服制**：明代人物穿清代旗装、女子穿马蹄袖花盆底、男子剃发垂辫、补子错配品级、明显违反明代服制的造型
6. **技术质量缺陷**：低分辨率/模糊/噪点/变形/畸形肢体/五官扭曲/比例失调/抠图感/塑料感/过度磨皮/假面感
7. **审美倾向违规**：过度高饱和/死亡荧光色/廉价滤镜感/过度HDR/脏乱差画面/刻意阴间色调/二次元平涂
8. **内容合规红线**：暴露/低俗/暗示性/暴力血腥/违法内容/歧视性表达/政治敏感元素
9. **水印文字**：水印/文字/签名/LOGO/边框/UI元素/生成工具痕迹

## 六、使用说明

### 提示词使用原则

1. **前缀先行**：所有生成内容必须首先加载"前缀提示词"中的全局风格锚定段，锁定真人明代写实质感基线
2. **专项叠加**：在全局前缀基础上，按需叠加角色/场景/道具/分镜专项提示词
3. **负面必加**：每次生成必须附带"负面提示词"，规避伪影与风格偏差（尤其规避清代/唐宋混搭）
4. **迭代优化**：建议首轮生成后根据效果对专项提示词做微调，而非修改全局前缀
5. **平台适配**：本手册提示词优先适配Doubao-Seedream（生图）与Doubao-Seedance（视频生成），部分提示词可能需根据平台特性微调
