# 真人古风明艳写实场景图像生成 · 约束手册

---

## 一、场景美学原则

> 真人古风明艳写实的场景不是"被建模的殿堂"，而是"被摄影机选中的真实华贵空间"。没有渲染引擎、没有贴图、没有体积光参数——只有实际存在的天光与华灯、真实的朱柱金漆与织金帷幔、以及华贵空间深处的岁月与繁华。

1. **空间即华贵** — 一座空无一人的殿堂不是"空的"，是华礼之前或散朝之后。织金帷幔垂坠、华灯齐燃未点、龙椅上织金褥垫微皱——空间自己会讲盛世与华贵的故事
2. **真实的光，不是渲染的光** — 场景的光只有一个来源：实际的日光（通过殿窗、宫门、漏窗）、实际的华灯（宫灯、灯笼、烛台、廊灯）。光的色温和方向必须在物理上说得通
3. **被岁月盘过的华贵** — 真实的华贵空间不崭新。朱柱金漆有剥落与包浆、织金帷幔有厚重垂坠、金箔有氧化、青砖金砖有磨损、檀木有开裂包浆——一个完全没有岁月痕迹的殿堂是样板布景，不是真实华贵
4. **明艳浓郁的色彩分级** — 场景色彩必须明艳华贵：朱红漆柱、织金帷幔、翠竹朱墙、金箔彩绘、青花瓷彩——色彩饱和浓郁、金碧辉煌，但来自真实材质的真色彩，不来自后期荧光滤镜
5. **中国古代华贵空间** — 场景必须有明确的中国古代华贵辨识度（朱柱金漆殿堂、织金帷幔、锦绣屏风、宫灯、彩绘雕梁、富贵庭院）。这不是"generic palace"，这是"中国古代华贵空间的一个具体角落"
6. **单视图全景全貌** — 一张照片装下整座殿/院/廊的完整信息。广角或标准焦段，全景深，正面展示空间的全貌与纵深——不是四视图分割，不是多角度拼贴

## 五、单视图全景摄影规范

> 真人古风明艳写实场景仅需**单张**全景摄影——一张照片装下整座殿/院/廊的完整信息。不是2×2四视图，不是多角度拼接。

### 画面构成

| 项目 | 摄影要求 |
|---|---|
| 空间呈现 | 单张照片完整呈现场景的空间全貌。使用24-28mm广角或35mm，全场地的纵深、宽度、高度在一张画面中全部可见 |
| 构图 | 全景深大景别——前景（华门/朱柱/纱帐/宫灯/栏杆/花木/漏窗）形成天然画框→中景是殿堂/院落主体→后景向空间纵深或后殿/天空延伸 |
| 景深 | 全景深 f/8-f/11，从前到后全部清晰。这不是人像摄影——场景的每一个角落都应该能被看见 |
| 人物 | **严禁出现任何人物、人影、人体轮廓。** 场景是空的——但这种"空"有叙事：华礼之前/散朝之后/人去殿空/华堂的静止瞬间 |
| 比例 | 建议 16:9 或 3:2 宽幅——匹配全景空间展示的横向视觉习惯 |
| 色彩 | 由实际光源的色温驱动 + 明艳浓郁的色彩分级，不套荧光滤镜。色彩科学参考ARRI Alexa/Sony Venice电影色调，色彩饱和度偏华贵浓郁 |

### 空的场景如何叙事

| "空"的类型 | 画面线索 | 叙事暗示 |
|---|---|---|
| 华礼之前 | 仪仗陈设齐整、华灯全亮、香炉香烟未起、织金帷幔拉平 | 华礼马上开始，此刻是开场前的华贵肃静 |
| 散朝之后 | 龙椅上织金褥垫微皱、丹陛上烛泪未干、奏折未合、地墁有靴印 | 刚才殿堂有人，现在散了 |
| 人去殿空 | 搬迁后的空殿、墙上挂过匾的钉痕、地面积尘的轮廓、断了的香火 | 曾经有人住过，现在被废/迁/抄 |
| 华堂的静止 | 拔步床织金纱帐半垂、妆台铜镜映空榻、茶盏余温、窗外庭光打在金砖地墁 | 起居的华贵常态，只是此刻无人入镜 |
| 深夜的华堂 | 空荡的回廊只有华灯亮着、寝殿窗纸透出一团暖光、月下的空庭院 | 华堂睡着了，但华灯还醒着 |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须是**单张**全景摄影——单视图、非2×2四视图、非多角度、非turnaround |
| R2 | 必须使用广角镜头（24-28mm）或标准焦段（35mm），全景深 f/8-f/11，完整空间纵深 |
