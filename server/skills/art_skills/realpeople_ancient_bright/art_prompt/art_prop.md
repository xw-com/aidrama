## 一、道具设计原则

> 真人古风明艳写实的道具不是"被建模的物件"，而是"被华服中人用过、被岁月盘过的华贵器物"——它在贵妇手里待过、在龙案上供过、在锦绣匣中珍藏过。摄影机拍下的是它浓郁华贵的此刻。

1. **器物即华贵与命运** — 每一件道具都是一个微型的华贵叙事容器。圣旨上未干的朱砂暗示刚刚颁旨、织金团扇上的磨损暗示主人常用、华灯的烟熏痕暗示长夜未熄
2. **使用痕迹优先于完美品相** — 真人古风明艳写实的道具必须有"被用过、被岁月盘过"的证据。全新出厂、样板级别的道具一律不出现
3. **中国古代华贵真实器物** — 道具必须是中国古代真实存在的华贵器物：织金团扇、点翠金钗、青花粉彩瓷、鎏金香炉、绫本华笺、和田玉佩、缂丝锦盒——拒绝无国别架空物品
4. **材质即真实** — 不是PBR参数渲染出的材质，而是摄影机拍下的真实材质行为：织金线的凸起反光、金箔的氧化哑光、鎏金青铜的包浆铜绿、和田玉的温润油性、瓷器的釉光
5. **明艳浓郁的色彩** — 道具色彩必须明艳华贵：朱红漆器、明黄织金、翠玉宝石、宝蓝青花、绛紫绫绢、金箔赤金——浓郁华贵的真色彩，非荧光非廉价
6. **单视图静物摄影** — 道具以单张静物产品摄影方式独立呈现，非多角度建模展示，非2×2四宫格

## 三、单视图静物摄影规范

> 真人古风明艳写实道具仅需单张静物产品摄影，非多角度建模展示。以下为单视图摄影的完整规范。

### 画面构成

| 项目 | 摄影要求 |
|---|---|
| 道具呈现 | 道具居中或偏三分线位置独立陈列，完整入画，无裁切 |
| 背景 | 素灰无缝背景纸 #B0B0B0（哑光），或深檀木桌面/米白绫绢台面/织金锦缎台面，根据道具属性选择。无多余物体、无装饰、无文字（道具本身的题字除外，如圣旨/华笺/匾额） |
| 光线 | 自然柔光或单灯柔光。窗光/殿窗光45°侧入（明亮柔和带自然阴影）、或柔光箱顶+侧补（产品摄影级均匀光线）。光影柔和、方向明确、无硬阴影 |
| 景深 | 浅景深（f/2.8-f/5.6），道具主体清晰锐利，前后微虚化突出主体 |
| 投影 | 道具底部与承载面之间的自然接触阴影——真实的而非抠图或悬浮。阴影柔软、方向与主光源一致 |
| 画面比例 | 建议 1:1 正方形或 4:3，适配单件道具展示 |

### 道具状态准则

| 维度 | 要求 |
|---|---|
| 使用痕迹 | 必须有"被用过、被岁月盘过"的视觉证据——非全新未启用、非样板品相 |
| 中国华贵辨识度 | 华贵器物形制/中文（如圣旨/华笺/匾额）/中国华贵工艺——拒绝无国别架空物品 |
| 材质真实感 | 非渲染质感——是摄影机拍下的真实材料行为（光的反射、漫射、透射） |
| 色彩明艳华贵 | 道具色彩取自朱红/明黄/翠绿/宝蓝/绛紫/金箔华贵色盘，浓郁华贵真色彩，非荧光非廉价 |
| 服制等级感 | 华贵礼器须有合乎身份的工艺等级（龙袍织金九龙、凤冠金累丝点翠嵌珠、金印螭纽） |
| 尺度感 | 通过材质纹理密度、工艺细节暗示实物尺寸，无需参照物 |

## 六、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须是「单张静物摄影」——单视图、非多角度、非2×2四宫格、非建模展示 |
| R2 | 必须指定「素灰背景纸 #B0B0B0」或「深檀木桌面/米白绫绢台面/织金锦缎台面」等真实华贵承载面，禁止复杂场景 |
| R3 | 必须指定光源逻辑——殿窗光或柔光箱，光影方向明确、投影自然 |
| R4 | 道具必须有「使用痕迹/御用痕迹/岁月痕迹」——非全新、非样板品相、非未启用 |
| R5 | 道具必须具备中国古代华贵辨识度——华贵形制/中文/中国华贵工艺/按身份礼制等级 |
| R6 | 必须声明「实物产品摄影 + 非3D渲染非CG」核心锚定 |
| R7 | 材质必须描述为摄影机下的真实表现，而非渲染参数；织金刺绣须凸起非平面印花 |
| R8 | 色彩必须明艳华贵——取自朱红/明黄/翠绿/宝蓝/绛紫/金箔华贵色盘的真色彩 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 严禁「3D渲染 / 3D建模 / CG / UE引擎 / Blender / PBR材质」等一切CG术语 |
| X2 | 严禁「2D手绘 / 插画 / 动画 / 二次元 / 赛璐璐」等非摄影媒介 |
| X3 | 严禁「多角度 / 四视图 / 2×2网格 / 正交视图 / turnaround / blueprint」——仅单张 |
| X4 | 严禁「全新未启用 / 样板品相 / 无使用痕迹 / 完美品相 / 平面印花冒充刺绣」的道具 |
| X5 | 严禁「现代都市/民国/西方宫廷/和风日式/仙侠法术/赛博朋克/科幻/西方奇幻/架空」等非中国古代物品 |
| X6 | 严禁「无中国华贵辨识度的架空物品 / 西式器物 / 日式器物」 |
| X7 | 严禁「出现人物/手部/手指/肢体」 |
| X8 | 严禁「道具被持有/握持/佩戴/使用中/与人物互动」的状态 |
| X9 | 严禁「悬浮/抠图白底/无投影/无承载面」——物品必须放在真实表面上 |
| X10 | 严禁「法术发光/灵力光效/玄幻粒子/能量光」——真实器物不会发光 |
| X11 | 严禁「荧光色/霓虹溢色/死亡芭比粉/电子合成色/廉价滤镜感/二次元平涂」——明艳≠廉价荧光 |
| X12 | 严禁「水印 / 文字 / LOGO / 签名 / 边框 / AI生成痕迹」（道具本身题字如圣旨/华笺/匾额除外） |
