## 一、风格核心定义

**真人古风明艳写实**是以**真人影视摄影美学**为基准、以**中国古代（可跨朝代华服）**为核心视觉舞台、以**明艳高饱和浓郁华贵的色彩分级**为灵魂的风格体系。它与项目内已有的克制低饱和「真人古风写实」形成鲜明对照——同属真人摄影血统，但追求盛唐式浓烈华贵、金碧辉煌的富贵美感。

其核心特征为：

- **真人写实摄影质感**：以真人影视级摄影为锚点，画面呈现真实人物的皮肤纹理、毛发细节、织金锦缎的光泽垂坠、朱柱殿堂的岁月材质、浓丽妆容与华服的繁复细节，杜绝3D建模感、CG渲染感、手绘感与二次元动漫感
- **明艳高饱和的色彩基因**：色彩浓郁华贵、富丽堂皇——朱红、明黄、翠绿、宝蓝、绛紫、金箔构成盛唐式浓烈华贵的色盘。色彩饱和度高但不廉价、不荧光，是真实丝绸矿物染料、金箔宝石、织金织锦呈现的真色彩
- **跨朝代华服世界观**：不限单一朝代，可融合唐宋明清各代华服元素——齐胸襦裙、大袖衫、马面裙、旗装、龙袍、霞帔。核心是「中国古代华服的富贵美感」，而非某一朝服制的考据
- **电影级摄影语言**：以院线级真人古装电影摄影为基准，自然天光与灯火（宫灯/烛火/灯笼）的有机调度、构图叙事的专业性、景深与焦点的情绪表达，但色彩分级偏饱和浓郁、金碧辉煌
- **浓丽华贵的妆容器物**：妆容浓丽（花钿、面靥、阔眉/蛾翅眉、点唇、斜红）；器物华丽（织金织锦、彩绘雕梁、金漆朱柱、宫灯锦绣帷幔）

### 创作理念与核心价值

本手册的核心创作理念为 **"金碧之下，华贵之上"**：

1. **明艳即品格**：明艳高饱和≠廉价荧光。本风格的色彩来自真实材质——丝绸的矿物植物染料（朱砂、石青、石绿、藤黄）、金箔宝石的折射、织金线的反光。这是一种浓郁华贵、富丽堂皇的真色彩，盛唐壁画与宋代院体花鸟的色彩浓度是其审美高度

2. **华服即叙事**：跨朝代的华服不是"乱穿"，而是"取其华贵"。齐胸襦裙的飘逸、大袖衫的雍容、马面裙的端庄、旗装的繁复、龙袍的至高——本手册以华服的富贵美感驱动造型，而非单一朝代的服制考据

3. **色彩即情绪**：明艳的色彩本身即是情绪放大器。朱红是喜庆与权柄、明黄是至尊与荣耀、翠绿是生机与富贵、宝蓝是深沉与华贵、绛紫是神秘与尊崇、金箔是辉煌与高光

4. **克制写实为底，明艳为神**：本风格是"真人写实"的明艳版——光影、材质、人物以写实摄影为底色（真实肌肤、真实丝绸、真实宫殿材质），色彩分级偏浓郁饱和、金碧辉煌。是写实的华贵，不是动漫的艳俗

## 五、使用说明

### 提示词使用原则

1. **前缀先行**：所有生成内容必须首先加载"前缀提示词"中的全局风格锚定段，锁定真人实拍+明艳高饱和基线
2. **专项叠加**：在全局前缀基础上，按需叠加角色/场景/道具/分镜专项提示词
3. **负面必加**：每次生成必须附带"负面提示词"，规避伪影、CG感、荧光色与风格偏差
4. **明艳校准**：明艳高饱和的达成依赖"真实丝绸矿物染料/金箔宝石/织金线反光"的真色彩描述，而非"高饱和/鲜艳/滤镜"等空泛词——明艳是材质与色彩分级的真实结果，不是后期拉饱和
5. **平台适配**：本手册提示词优先适配Doubao-Seedream（生图）与Doubao-Seedance（视频生成），部分提示词可能需根据平台特性微调
