## 一、分镜表定位

分镜表是导演将剧本转化为镜头语言的核心工具。本约束面向 Seedance 2.0 视频生成，所有光影、动作、空间描述均采用模型可执行的具象语言。不做抽象的情感概括，不写模型看不懂的渲染参数。色彩基调为明艳浓郁华贵——以朱红/明黄/翠绿/宝蓝/绛紫/金箔华贵色盘驱动，明艳≠荧光。

## 三、光影与氛围——Seedance 2.0 物理光源描述

### 3.1 同场戏光影统一

一场戏内不应出现两种以上核心光影方案，除非有叙事驱动的光源变化（如有人吹灭华灯、日落后天光暗于烛火、从殿内走到庭院）。光源变化必须在分镜表中标注触发事件。

[光源] 辅光/环境光：{光源类型}，{方向}，{色温值K}
[光比] 约1:{X}

### 3.5 Seedance 2.0 光影适配要点

- 色温数字帮助模型校准白平衡倾向：`色温约2500K华灯暖橙` 优于 `暖光`
- 光比数字帮助模型建立明暗意识：`光比约1:4` 优于 `柔和的阴影`
- 光源必须有明确来源：`从画面左侧低位华灯斜入` 优于 `侧光`
- 环境光的反射路径描述：`金砖地墁反射华灯暖光` 优于 `地面有暖色反光`
- 明艳色彩用真色彩材质描述：`朱红织金锦缎矿物染料真色彩` 优于 `高饱和红色`

## 四、环境动态——让画面呼吸

### 4.1 动态密度

每 3-4 个镜头至少安排一个有环境动态的镜头。静态殿堂戏也不例外——至少有一个镜头里华灯在摇曳、织金纱帐被穿堂风轻拂、远处钟鼓传来。

### 4.2 华贵环境动态元素（Seedance 2.0 可执行）

| 场景 | 可描述的环境动态 |
|---|---|
| 殿内（寝殿/书房） | 织金纱帐被穿堂风轻鼓约10cm后回落（约2秒周期）、华灯烛火明灭摇曳、香炉青烟袅袅升起、窗外花木影子在地砖上随天光微移、铜漏滴水 |
| 庭院（富贵花园） | 花木叶片簌簌晃动、远处仆从执物缓步走过、牡丹花瓣偶有飘落、铜缸水面微澜、檐马叮当作响 |
| 回廊 | 漏窗光斑随天光角度缓慢移动、远处华灯随穿堂风微晃、脚步声在长廊回响由远及近、廊柱明暗切割随人物穿行变化 |
| 殿堂 | 香炉香烟袅袅升腾、织金帷幔极轻微摆动、远处侍从肃立不动、金箔在华灯/天光下明灭反光 |

| 深夜华堂 | 华灯烛火摇曳、更鼓由远及近传来二/三更声、月光下花木影子在地砖缓慢移动 |

### 4.3 Seedance 2.0 环境动态描述规范

- 动态必须有具体轨迹和速度：`华灯烛火每秒约2-3次微幅明灭摇曳` 优于 `烛火在动`
- 光源动态与空间光源逻辑一致：`云朵遮住日头时，漏窗光斑缩小约40%，持续约3秒后恢复`
- 禁止无来源的动态：没有风=纱帐不动。门窗紧闭=没有穿堂风

### 5.3 动作节奏与叙事场景

- **文戏/殿堂礼数**：动作沉稳克制，每个微动作标注时长和轨迹。节奏舒缓——不是慢，是"合乎礼数的不急"
- **华贵情绪波动**：动作幅度和速度略微变化。人物可能在对话中不自觉地加快护甲轻叩的频率、呼吸带动肩膀起伏更明显
- **冲突场景**：动作干脆利落，但仍有物理轨迹。推搡/摔物须具体到"右手推在对方左肩前方，对方重心向后偏移约20cm，高髻步摇晃动剧烈"
- 禁止：无叙事理由的快速动作堆砌、无物理逻辑的瞬移、"施了一礼"等含糊描述

### 5.4 服饰动态

真人古风明艳写实的服饰动态是画面的天然资产——不是"布料模拟参数"，而是"马面裙马面随屈膝微动""大袖衫衣袖起身时带回约10cm""金钗步摇流苏随头部微动垂坠晃动约2秒渐止""织金纱帐被穿堂风鼓起约15cm"。在分镜表画面描述中标注服饰与首饰的动态细节。

## 六、空间逻辑具象化——Seedance 2.0 空间坐标系统

### 6.1 每镜头必须声明的空间信息
水平位置：画面左/中/右，或画面左侧三分之一处
纵深位置：距镜头{数值}米，前景/中景/背景
人物与场景的关系：距{固定物——龙椅/拔步床/漏窗/华门/朱柱}{数值}米
（若双人以上）人物A与B的相对距离和朝向

### 6.2 站位衔接示例
【片段A尾部】
A华服女子站在寝殿拔步床前，距床约0.5米，面朝织金纱帐，位于画面中央偏右，距镜头约4米。
寝殿华灯烛火从画面左侧低位照入（约2500K暖橙）。
A右手轻抚织金纱帐边沿，护甲距帐面约2cm。

【片段B开头】
A的右手刚从纱帐收回约10cm，护甲仍在原位置附近。A仍站在拔步床前（位置未变）。
殿窗外天色已从黄昏转为蓝调时刻——天空深蓝紫透窗，寝殿华灯已为主光源（约2500K暖橙）。
红纱灯笼已亮（画面右后侧），透红光照在A的右后侧肩背。

### 6.3 空间变化必须具象

| 抽象（禁止） | Seedance 2.0 具象 |
|---|---|
| 她走近了 | A从画面背景（距镜头约5米、殿门位置）向镜头方向缓步走来4步（约3米），绣鞋落地有轻微叩击声，停在距镜头约2米处——耗时约4秒 |

## 七、运镜规范——Seedance 2.0 摄影机运动

### 7.1 允许的运镜

| 运镜 | Seedance 2.0 描述 | 适用场景 |
|---|---|---|
| 固定 | 摄影机固定不动，画面静止 | 殿堂礼数、典礼、对话、空殿留白、情绪凝视 |
| 手持微晃 | 摄影机有轻微不规则晃动（幅度约±2cm），模拟手持拍摄的呼吸感 | 暗涌、跟踪密会、情绪波动、主观视角 |
| 稳定器流动 | 摄影机平滑匀速移动，无晃动 | 回廊纵深、人物登场、华礼大典、空间展示 |
| 缓推 | 摄影机向主体缓慢推进，推进速率约每秒0.3米 | 情绪升温、真相逼近、注意力聚焦 |
| 缓拉 | 摄影机向后缓慢拉远，拉远速率约每秒0.3米 | 离别、收束、揭示全貌 |
| 跟拍 | 摄影机与人物保持约2米距离同步移动 | 回廊穿行、华贵场景行走跟随 |
| 摇镜 | 摄影机原地水平/垂直旋转 | 视线转移、殿堂纵深关系交代 |

### 7.2 禁用运镜

- 无叙事目的的快速甩镜、急推急拉（推拉速率超过每秒1米）
- 超过3秒的剧烈手持晃动（除非主观受击/眩晕/宫变叙事）
- 无逻辑花式转场——划屏、旋转、百叶窗、翻页等特效转场
- 摄影机无理由的360度旋转

### 7.3 真人古风明艳写实运镜哲学

- 固定机位是殿堂与典礼的第一选择——让观众看到华服中人在华贵空间里自然存在
- 手持微晃在冲突段落使用——但晃动幅度不超过电影纪实风格的常规范围
- 稳定器流动用于回廊纵深与人物登场——华贵的仪式诗
- 运动镜头的起幅和落幅必须平稳，运动过程匀速——禁止突然加速或急停

## 八、转场规范

### 8.1 允许的转场方式

| 转场 | 视觉执行 | 叙事功能 |
|---|---|---|
| 硬切 | 直接切换 | 同场戏内镜头切换（默认） |
| 光影匹配转场 | 两个场景在相近光影逻辑下切换 | 时间流逝、平行叙事。例：A处华灯烛火 → B处华灯烛火 |
| 空间匹配转场 | 两个空间在构图或元素上呼应 | 场景跳转。例：殿堂龙椅的明黄织金 → 寝殿明黄织金帷幔 |
| 色彩匹配转场 | 两个场景在主色上呼应 | 色彩叙事。例：朱红华服 → 朱红华墙 → 朱红华灯 |
| 空镜过渡 | 插入场景空镜（3-5秒） | 情绪缓冲、章节划分、时间流逝暗示（如黄昏华门→月夜华墙） |
| 焦点转场 | 前镜焦点从主体移至背景，后镜从模糊背景中逐渐聚焦主体 | 空间切换、注意力的转移 |

### 8.2 禁止的转场

- 纯视觉特效转场（翻页、划屏、百叶窗、马赛克、水墨化开）
- 无叙事逻辑的旋转/缩放转场
- 同一场戏内使用超过两种转场方式

## 十一、空镜使用规范

### 11.1 空镜不是"没东西拍"

空镜是情绪容器。每个空镜必须有叙事目的和具体的视觉内容：

| 空镜类型 | 叙事目的 | 示例 |
|---|---|---|
| 场景建立 | 新空间首次出现——让观众看清楚这是什么华贵场所 | 朱柱殿堂大全景：朱柱金漆、彩绘雕梁藻井、龙椅、丹陛、织金帷幔、华灯 |
| 情绪缓冲 | 高情绪段落后的喘息 | 漏窗外月光沿织金纱帐滑下，速度约每秒2cm |
| 时间流逝 | 暗示时间过去了 | 同一殿窗外的天光从午后湛蓝渐变至黄昏暖金再至月夜冷蓝，华灯从点到亮 |
| 隐喻留白 | 以物代情 | 妆台上半残的华烛台，烛泪凝结，烛火明灭，金钗反光一闪 |
| 色彩叙事 | 以华贵色彩推进情绪 | 朱红华服挂架→朱红华墙→朱红华灯，色彩呼应 |
| 转场衔接 | 前后两个空间的自然过渡 | 回廊漏窗——前一场寝殿，下一场富贵庭院 |

### 11.2 空镜 Seedance 2.0 描述规范

空镜也必须遵循光源+质感+动态+色彩的描述铁律：
寝殿华灯烛火从画面左侧低位斜入（约2500K暖橙），
在空荡荡的妆台铜镜上镀一层暖金，铜镜映出空拔步床织金纱帐，
华灯烛火每秒约2-3次微幅明灭，织金纱帐被穿堂风鼓起约10cm后回落，
妆台紫檀木有包浆，护甲盒朱漆织金边角磨损，
色彩明艳华贵——朱红漆盒、明黄织金、金箔反光。
