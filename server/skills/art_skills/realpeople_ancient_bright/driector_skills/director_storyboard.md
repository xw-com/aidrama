## 四、摄影机语法——镜头选择与运动

### 4.1 焦段选择

| 焦段 | 叙事性格 | 适用场景 |
|---|---|---|
| 24-28mm广角 | 殿堂吞噬人物，华贵威压，盛世宏大与个体华美 | 殿堂大全景、华门甬道、华贵庭院、长廊纵深 |
| 35mm小广角 | 主观视点，身临其境的华贵纪实感，人与华贵场景共存 | 回廊穿行、寝殿对话、庭园跟随 |
| 50mm标准 | 人眼等价，客观中立的注视，最诚实的镜头 | 人物肖像、双人对话、华服凝视 |
| 85mm中长焦 | 压缩空间，拉近情感距离，织金线与金钗细节突出 | 特写、金钗步摇流苏、护甲、华灯下的面容 |
| 135mm+长焦 | 将人物从锦绣华堂中剥离，极端的注视或窥视 | 长廊尽头注视、华墙后远眺、命运的距离感 |

### 4.2 景别选择

| 景别 | 取景范围 | 叙事功能 |
|---|---|---|
| 大特写 | 眼睛/嘴唇/护甲/金钗/花钿/朱笔/织金线 | 情绪爆发点、关键信息揭示、感官聚焦 |
| 近景 | 头顶至胸部以上 | 人物情感、对话反应、浓丽妆容微表情 |
| 中近景 | 头顶至腰部 | 人物互动、敛衽/奉茶/执团扇手势、玉带织金 |
| 中景 | 头顶至膝盖上下 | 人物与殿堂的初级关系、多人同框 |
| 全景 | 人物全身+部分殿堂 | 人物在空间中的位置、行动路线、华服全貌（齐胸襦裙/马面裙/大袖衫层层叠搭） |
| 大全景/空镜 | 殿堂全貌，人物极小或无人物 | 空间叙事、情绪缓冲、隐喻留白 |

### 4.3 摄影机运动

| 运动方式 | 视觉心理 | 使用场景 |
|---|---|---|
| 固定 | 华贵礼数庄严，让色彩自己说话 | 殿堂、典礼、对话、空殿留白 |
| 手持微晃 | 在场感、情绪暗涌、主观介入 | 冲突、跟踪密会、情绪波动 |
| 稳定器流动 | 优雅的回廊纵深，华贵的仪式诗 | 人物登场、回廊纵深跟拍、华礼大典 |
| 缓推 | 注意力逐渐聚焦、情绪趋近 | 对话升温、真相逼近、情感推进 |
| 缓拉 | 拉开距离、揭示全貌、情绪抽离 | 离别、章节收束、空间展示 |
| 跟拍 | 与人物同行、主观陪同 | 回廊穿行、华贵场景行走跟随 |
| 摇镜 | 视线转移、空间关系交代 | 人物视线引导、殿堂纵深关系 |

## 五、固定风格锚定词

**摄影锚定（必选）：**

真人实拍摄影，真人电影剧照，中国古代华贵场景，跨朝代华服，电影级摄影，华灯烛火与自然天光调度，明艳浓郁华贵色彩分级，真实色彩科学

**人物质感（含人物镜头时必选）：**

真人写实摄影质感，真实皮肤纹理毛孔可见，浓丽古装妆容（花钿/面靥/阔眉/点唇）与皮肤融合，不磨皮不硅胶脸，高髻/旗头真实发质有鬓发碎发，织金华服织金线凸起反光有衣摆褶皱，礼数体态，华贵雍容微表情

**场景质感（含场景镜头时必选）：**

真人实拍华贵场景摄影，真实殿堂材质和岁月痕迹（朱柱金漆剥落/织金帷幔厚重/金箔氧化/金砖磨损/檀木包浆），光源方向明确可追溯，明艳浓郁华贵色彩，大气透视自然，非样板殿非效果图

**参考图一致性锚定（参考图模式必选）：**

保持人物造型、面容、高髻/旗头、华服首饰与参考图完全一致，保持场景风格与参考图一致，保持光影色彩基调统一（明艳华贵），所有镜头呈现为同一人物的连续摄影记录

**风格收尾（固定）：**

真人写实摄影，中国古代华贵电影质感，明艳浓郁华贵色彩分级，电影级摄影画面，非3D非渲染非CG

## 六、美学禁止项

以下词汇/风格不得出现于输出提示词中：

- ❌ 3D渲染 / 3D建模 / CG / UE引擎 / Blender / PBR材质 / 次世代建模 / 体积光 / 环境光遮蔽 / 光线追踪
- ❌ 2D手绘 / 插画 / 动画 / 二次元 / 漫画 / Q版 / 赛璐璐 / 低多边形
- ❌ 写实摄影（英文禁止 photorealistic / realistic photography——本风格是"真人实拍摄影"live-action cinematic photography，不是"拟真渲染"）
- ❌ 过度磨皮 / 塑料假面 / 零毛孔 / 硅胶脸 / 蜡像感 / AI感平滑 / 妆容像贴图
- ❌ 仙侠法术 / 玄幻特效 / 真气流转 / 御剑飞行 / 法术光效 / 灵力光环 / 水墨法术特效
- ❌ 现代当代都市 / 民国 / 西方宫廷 / 和风日式 / 赛博朋克 / 科幻 / 西方奇幻 / 中世纪
- ❌ 平面印花冒充刺绣 / 平面金线
- ❌ 人体结构错误 / 肢体畸形 / 面部崩坏 / 比例失调
- ❌ 荧光色 / 霓虹溢色 / 死亡芭比粉 / 电子合成色 / 廉价滤镜感 / 二次元平涂（明艳≠廉价荧光）
- ❌ 莫兰迪低饱和 / 寡淡灰败 / 过度去饱和（本风格为明艳华贵，非克制低饱和）
- ❌ 非中国华贵的架空场景 / 西式城堡 / 日式城堡 / 无辨识度的 generic palace
