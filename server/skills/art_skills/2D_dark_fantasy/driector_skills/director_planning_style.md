# 暗黑奇幻二次元约束 · 二维暗黑奇幻 · 技法参考

---

## 一、色调体系与画面基调

- **色调基底** — 全片以核心色盘为基底：月白（C1 #C8C8D8）、暗夜紫（C2 #2A2440）、血红（C3 #7A1E2A）、灰蓝（C4 #4A5868）、暗金（C5 #8A6E2E）、墨黑（C6 #1A1A22）、锈红（C7 #6A2820）、深绿（C8 #2A4030）、骨白（C9 #D8D0C0）、幽光紫（C10 #5A3A7A），整体色温偏冷（4200-5000K），饱和度中低（35-55%），呈现低明度高对比的暗黑奇幻画面
- **冷暖叙事对比** — 暖色（血红 C3、暗金 C5、锈红 C7）作为血月/仪式/狂乱的视觉信号；冷色（暗夜紫 C2、灰蓝 C4、墨黑 C6、深绿 C8）作为孤寂/死寂/幽冥的视觉信号。冷暖切换应与故事弧线同步，而非随意混用
- **冷暖分配策略** — 墓园死寂/暗森林秘段落使用冷色调（暗夜紫 + 灰蓝 + 深绿 + 墨黑），禁用血红/暗金暖光；古堡幽宴/月夜悲咏段落使用暗夜紫 + 暗金 + 月白冷调点缀；血月狂乱/篝火仪式段落使用血红 + 锈红 + 暗金高光
- **色盘先行原则** — 段落规划需先绑定情绪场景（古堡幽宴/血月狂乱/魔法幽冥/墓园死寂/暗森林秘/月夜悲咏等），再确定主色+辅色与光影方案，避免"剧情对了但情绪不对色"
- **禁用色域** — 高饱和荧光色、霓虹色、粉嫩萌色、数码感强色彩均与本风格不兼容。色相偏移容差 ±8°，饱和度偏移 ±10%，明度偏移 ±12%

## 二、光影方案体系

- **光影即叙事** — 7 套光影方案对应不同情绪段落，导演规划阶段应在段落层面确定光影基调方向，而非逐镜指定
- **赛璐璐光影为锚** — 所有光影方案必须保持赛璐璐平涂质感，阴影使用同色系加深、厚重低明度，禁止黑色硬阴影，允许体积光/景深虚化/魔法自发光等哥特渲染技法
- **光源角度** — 正给镜头默认 38.5° 斜射冷柔光（赛璐璐平涂质感），侧给镜头可适当调整

| 光影方案 | 方案名 | 色调倾向 | 适用情绪 |
|---|---|---|---|
| A | 血月荒原 | 血红月光 + 锈红荒原，墨黑剪影 | 血月狂乱、嗜血对决、诅咒爆发 |
| B | 烛火古堡 | 暗金烛光暖橙 + 墨黑暗部 | 古堡内部、密谈暗影、华美阴郁 |
| C | 魔法幽光 | 幽光紫 + 深绿药剂光，自发光阵法 | 施法、阵法激活、魔法高潮 |
| D | 彩窗投影 | 月白 + 血红/暗金投影，暗夜紫暗部 | 废弃教堂、神圣诅咒、庄严诡异 |
| E | 月夜墓园 | 灰蓝月光 + 骨白，冷调低对比 | 死寂、追忆、亡灵、孤寂清冷 |
| F | 篝火仪式 | 锈红火光 + 墨黑剪影，逆光群像 | 群集仪式、献祭、命运转折 |
| G | 幽冥逆光 | 幽光紫轮廓光 + 墨黑剪影，38.5°侧逆射冷光 | 恶魔登场、逆光剪影、高潮震慑 |

- **冷暖光分配** — 暖色光（暗金烛光/血红月/锈红篝火）适用于狂乱/华美/仪式段落；墓园死寂/暗森林段落一律冷光。导演可根据叙事需要调整冷暖切换点
- **氛围方向映射** — 每场戏的氛围方向应能映射到上述光影方案（A-G）的某一方向，确保视觉一致性

## 三、质感方向

- **赛璐璐平涂为锚** — 暗黑奇幻二次元的核心：精致冷峻线条、赛璐璐平涂、哥特手绘渲染、色块平滑渐变、禁止色块断层/色彩溢出
- **精致冷峻线条 + 电影质感** — 这是画面质感的锚点。不是写实摄影，不是 3D CG，是二次元日式动画渲染加暗黑奇幻哥特美学的融合
- **材质二次元化** — 所有服化道的材质必须以赛璐璐平涂呈现：丝绒的暗光用平滑色块、暗银的反光用冷光泽线条、血宝石的幽光用内透光色块。禁止"3D 感"和"写实摄影感"
- **皮肤质感** — 苍白基调、赛璐璐平涂、冷光自然、柔和质感、冷光内透、皮肤通透冷光。禁止哑光/死白/蜡感/油光/粉嫩腮红/过曝
- **二次元不等于扁平** — 二维暗黑奇幻强调在赛璐璐平涂基础上通过厚重光影层次、景深虚化、魔法自发光、体积光等手段增加空间感与电影感，而非扁平无纵深的卡通风格

## 四、暗黑奇幻场景空间元素

暗黑奇幻世界观特有的场景元素及其视觉叙事功能：

- **彩窗/穹顶/高耸拱门/飞扶壁** — 天然的框架式构图道具，制造"看不透"的层次感与空间纵深，以赛璐璐线条呈现繁复哥特纹饰细节
- **暗黑森林/枯木/荆棘/迷雾/血月** — 留白构图的天然载体，景即情：满庭荆棘 = 诅咒、独坐雾中 = 孤寂、枯叶纷飞 = 死寂、迷雾缥缈 = 幽冥未知
- **烛火/血月/彩窗光/魔法幽光** — 暗黑世界的光源载体，烛光 = 暖/华美阴郁（方案B）、血月 = 狂乱/嗜血（方案A）、彩窗光 = 神圣诅咒（方案D）、魔法幽光 = 诡谲超然（方案C）
- **哥特尖塔/暗石古堡/彩窗玻璃/暗银烛台** — 建筑元素以哥特美学呈现，繁复纹饰丰富、赛璐璐线条清晰，材质带自然风化/岁月包浆感，禁止全新无瑕的"塑料感"
- **段落间用场景空镜过渡** — 本风格有丰富的场景资产（不同时段/天候/景别变体），段落衔接建议用场景空镜做情绪缓冲，不要硬切
- **转折点用视觉而非台词** — 优先使用画面手段（光影突变、景别跳切、空镜隐喻）而非依赖对白解释
- **前中后景层次** — 所有场景必须具备前/中/后景，杜绝扁平，室外必须包含空气透视（远塔如墨）

## 五、暗黑奇幻乐器与环境音

暗黑奇幻世界观下的声音元素约束：

### 乐器选择

- **管风琴** — 庄严、神圣、诡异段落的核心乐器，与教堂/典祭/古堡大厅氛围高度适配
- **大提琴** — 深沉悲痛、孤寂思念段落，低音的呜咽感适合情绪压抑
- **小提琴** — 紧张、癫狂、诡谲段落的点缀，群弓不协和音适合疯狂与嗜血
- **女声咏叹/唱诗班** — 哥特神圣/空灵诡异段落，与管风琴搭配制造震慑与咏叹
- **丧钟/钟铃** — 情感波动剧烈段落（死亡、命运转折、典祭高潮），慎用但一用即震慑
- 钢琴独奏可增加孤寂电影感但不宜喧宾夺主

### 乐器组合策略

| 情绪阶段 | 乐器组合 |
|---|---|
| 平稳/开场/收尾 | 钢琴独奏 或 钢琴 + 大提琴 |
| 古堡/幽宴/阴郁 | 大提琴 + 女声咏叹 + 弦乐铺底 |
| 悲怆渐浓 | 大提琴 + 小提琴低音 |
| 情绪爆发/命运转折 | 丧钟独奏 或 管风琴 + 唱诗班 |
| 紧张/癫狂/嗜血 | 小提琴群弓 + 鼓点 + 弦乐衬底 |
| 魔法/幽冥/诡谲 | 女声咏叹 + 钟铃 + 合成铺底 |
| 典祭/盛宴/庄严 | 管风琴 + 唱诗班 + 弦乐铺底 |

### 暗黑奇幻环境音

- **典型环境音层次** — 风过钟楼 / 烛火噼啪 / 乌鸦夜枭啼叫 / 远处狼嚎 / 锁链拖拽 / 低语呢喃 / 雨打彩窗 / 石阶脚步回响 / 怀表滴答 / 落叶枯草窸窣
- **每场戏标注 1-2 个核心环境音**，帮助后续音效设计。环境音层次越丰富，暗黑奇幻场景越有沉浸感
