# 分镜表暗黑奇幻二次元约束 · 二维暗黑奇幻 · 技法参考

---

## 一、分镜表定位

分镜表是导演将剧本转化为镜头语言的核心工具。以下仅提供二维暗黑奇幻风格在分镜表层面的约束规范。

---

## 二、光影与氛围

- **赛璐璐光影统一** — 一场戏内光影方案必须保持赛璐璐平涂一致性，阴影使用同色系加深、厚重低明度（禁止黑色硬阴影），除非有明确的叙事转折（如烛光熄灭→月光冷辉、血月升起→血红逆光）
- **情绪色盘绑定** — 每场戏至少绑定 1 个情绪场景（如古堡幽宴/血月狂乱/魔法幽冥/墓园死寂/暗森林秘/月夜悲咏），并在镜头组内保持主色+辅色连续性，色彩取自核心色盘（月白 #C8C8D8 / 暗夜紫 #2A2440 / 血红 #7A1E2A / 灰蓝 #4A5868 / 暗金 #8A6E2E / 墨黑 #1A1A22 / 锈红 #6A2820 / 深绿 #2A4030 / 骨白 #D8D0C0 / 幽光紫 #5A3A7A）
- **光源角度规范** — 正给镜头光源默认 38.5° 斜射冷柔光（赛璐璐平涂质感），侧给镜头根据画面需要调整。描述光影时须区分正给/侧给的角度差异，光影渲染始终保持日式动画哥特质感
- **冷暖色调与叙事阶段匹配** — 墓园死寂/暗森林秘段落使用冷色调（暗夜紫 + 灰蓝 + 深绿 + 墨黑），禁用血红/暗金暖光；古堡幽宴/月夜悲咏段落使用暗夜紫 + 暗金 + 月白冷调点缀；血月狂乱/篝火仪式段落使用血红 + 锈红 + 暗金高光
- **光影转场是高级手段** — 从彩窗投影渐变到烛火古堡 = 日转夜的时间流逝、从月光冷辉突变到血月逆光 = 命运转折。在分镜表中标注光影变化点，转场过程中赛璐璐色块必须平滑渐变，禁止色块断层/色彩溢出
- **哥特渲染光效** — 允许合理使用体积光（volumetric light）、景深虚化、轮廓光、魔法自发光等现代渲染技法，但必须保持暗黑奇幻二次元赛璐璐平涂的美学基调，禁止 3D 写实/CG 动画光效

---

## 三、环境动态

- **环境动态增加画面呼吸感** — 烛火摇曳、迷雾流动、枯叶飘落、丝绒帷幕飘动、荆棘蔓延。每 3-4 个镜头至少安排一个有环境动态的镜头，避免画面"死"掉
- **暗黑奇幻环境元素优先** — 环境动态应选用暗黑奇幻世界观内的元素：枯叶、灰烬、迷雾、烛火摇曳、魔法幽光流动、荆棘蔓延、血雨、乌鸦掠影、彩窗光斑游移，禁止出现现代元素
- **赛璐璐动态质感** — 环境动态元素（灰烬/迷雾/烛火等）必须保持赛璐璐平涂质感与精致冷峻线条，禁止出现 3D 粒子特效或写实流体效果

---

## 四、暗黑奇幻二次元动作节奏

- **动作冷峻且带动画感** — 人物动作默认冷峻克制、缓慢阴郁，但可在关键帧上做二次元夸张处理（如堕落骑士挥剑时的凌厉线条、魔女回眸时的发丝飘动、吸血鬼展翅时的剪影张力），起身、转身、抬手应标注"冷峻/克制"
- **服饰动态是核心画面资产** — 暗黑奇幻服饰（斗篷、披风、蕾丝长裙、丝绒帷幕、锁链飘带）的飘动是天然的动态资产，可在画面描述中加入斗篷/裙摆/锁链的动态，赛璐璐渲染下的服饰飘动应线条精致、繁复层次分明
- **仪态约束** — 暗黑奇幻人物的举止应符合冷峻气质：行走稳缓、举手投足阴郁克制、不出现现代化的肢体语言（如耸肩、摊手）。二次元角色可在微表情上略有夸张（眼神锐利、嘴角冷挑），但肢体动作仍需哥特克制
- **头身比一致** — 动作设计中角色必须保持 6-7 头身的二次元哥特比例，禁止因动态姿势而破坏头身比

---

## 五、材质与质感约束

- **赛璐璐平涂为锚** — 所有镜头中人物/服饰/道具/场景的渲染必须保持赛璐璐平涂质感，线条精致冷峻清晰，色块平滑，禁止 3D 写实/CG 动画/照片级渲染
- **服饰材质** — 丝绒 + 蕾丝 + 暗银刺绣 + 暗金纹饰的质感用赛璐璐平涂表现，纹理必须超清晰，衣服质感清晰
- **道具材质** — 暗银冷光泽、血宝石幽光、骨纹温润、暗木纹清晰，均以赛璐璐平涂 + 精致冷峻线条呈现，禁止写实材质渲染
- **场景材质** — 石面有风化纹、墙面包浆、丝绒有自然褶皱、彩窗玻璃有暗纹，材质带有岁月感但以暗黑奇幻二次元笔触呈现，禁止"塑料感"的全新无瑕材质

---

## 六、色彩约束

- **核心色盘锁定** — 分镜表中所有镜头的色彩必须取自核心色盘（C1-C10），色相偏移容差 ±8°，饱和度偏移 ±10%，明度偏移 ±12%
- **禁止荧光粉嫩色** — 严禁高饱和荧光色/霓虹色/少女粉嫩色/数码感强的色彩出现
- **线条颜色** — 墨黑或深紫，禁止纯黑粗线条
- **阴影色** — 同色系加深、厚重低明度，禁止黑色硬阴影
- **整体色温** — 偏冷 4200-5000K 暗黑冷调基调，对比度 55-75%（高对比），饱和度 35-55%（低明度暗黑色盘）

---

## 七、运镜禁忌

- **禁用快速运镜** — 甩镜、急推、手持晃动与二维暗黑奇幻的冷峻阴郁气质冲突，血月狂乱/对决场景可适度加快运镜节奏但仍需保持画面清晰
- **禁用花式转场** — 划屏、旋转、百叶窗等与本风格不兼容
- **禁用写实镜头语言** — 手持摇晃/纪录片式跟拍/鱼眼镜头等与二次元美学冲突，破坏赛璐璐平涂的画面纯净感
