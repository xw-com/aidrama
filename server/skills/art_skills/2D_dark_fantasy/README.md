# 二维暗黑奇幻风格说明

本风格专为"二维暗黑奇幻"题材打造，所有美术提示词、规范和生成内容均严格限定于：

- **暗黑奇幻二次元**：以暗黑奇幻/哥特二次元美学为背景的手绘动画风格，涵盖吸血鬼、魔女、亡灵、诅咒等题材
- **哥特华丽美学**：哥特建筑、繁复纹饰、厚重阴影、高对比低明度，古典华丽与神秘阴郁并存
- **日式动画渲染技法**：现代日式动画的上色与光影技术，赛璐璐平涂结合数字渲染
- **神秘魔法氛围**：魔法幽光、血月冷辉、彩窗投影、烛火摇曳的神秘意境表达
- **精致冷峻线条**：繁复精致的线条、冷峻凌厉的笔触、华丽而阴郁的角色与场景设计
- **暗黑奇幻电影质感**：电影级构图、厚重光影层次、动态张力、压抑氛围

## 适用范围

- 暗黑奇幻题材的AI美术生成（角色、场景、道具、分镜等）
- 需要哥特美学、暗黑奇幻渲染、神秘魔法氛围的视觉创作
- 暗黑奇幻动画、游戏美术、概念设计、插画创作

## 严禁内容

- 明亮治愈萌系/少女粉嫩/甜系可爱
- 完全写实摄影/3D写实渲染/真人实拍
- 现代日常都市/赛博机甲/科幻元素
- 3D卡通圆润/Q版可爱/扁平low-poly
- 高饱和荧光粉嫩/霓虹数码感强
- 粗劣线条/模糊画质/低精度建模
- 色彩混乱/风格不统一/审美崩坏

## 风格体验

在本风格下，您将体验到：

- 角色造型二次元比例，繁复哥特服饰精致，线条冷峻凌厉
- 场景充满神秘氛围，哥特建筑细节丰富，厚重光影渲染精致
- 道具器物考究，材质质感清晰，暗黑华彩和谐统一
- 分镜与渲染均强调电影质感、哥特华丽审美、暗黑奇幻手绘技法
