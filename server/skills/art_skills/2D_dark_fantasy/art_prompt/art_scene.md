# 场景图生成 · 约束手册

---

## 一、场景美学原则

1. **空间叙事** — 场景承载情绪与叙事功能，不是纯背景板
2. **层次纵深** — 所有场景必须具备前/中/后景，杜绝扁平
3. **质感至上** — 石质/木质/丝绒/彩窗玻璃/水面等材质纹理必须超清晰
4. **二次元为锚** — 一切画面以暗黑奇幻二次元为标准，拒绝3D写实/CG动画质感；追求精致冷峻线条、赛璐璐平涂、哥特手绘渲染

## 三、室内场景

### 空间规范

| 维度 | 约束 | 提示词 |
|---|---|---|
| 风格 | 哥特古堡/废弃教堂/魔法图书馆/地下墓穴 | 哥特{类型}风格 |
| 材质 | 石质为主、暗银/木/丝绒/彩窗玻璃为辅 | 石质穹顶、暗银烛台、彩窗投影 |
| 色调 | 暗黑奇幻色调 + 月白冷光 + 血红丝绒 | 冷石色调、暗华陈设 |
| 纵深 | 前/中/后景层次 | 前景{元素}、中景{元素}、后景{元素} |
| 质感 | 石纹/丝绒垂感/彩窗玻璃可辨 | 纹理清晰、质感细腻 |
| 光照 | 烛火/彩窗投影/魔法幽光为主，厚重光影 | 烛光摇曳、彩窗投影、魔法幽光、厚重光影 |
| 镜头感 | 赛璐璐平涂虚化前后景、精致线条 | cel shading wash, clear lines |
| 瑕疵感 | 石面有风化纹、丝绒有自然褶皱、蛛网尘封 | 岁月痕迹、风化石纹、丝绒自然垂褶、尘封蛛网 |

## 四、室外场景

## 五、主视图规范

### 视图定义

> 单画面主视图，从场景中最具代表性的角度拍摄，承载空间叙事与构图重心。

| 项目 | 约束 | 提示词 |
|---|---|---|
| 视角 | 自然观察视角，构图最能体现场景主体与纵深 | hero shot、representative angle |
| 视点高度 | 默认人眼平视高度，特殊场景可俯/仰 | eye level（默认） |
| 构图 | 主体居中或符合三分法，前/中/后景层次清晰 | balanced composition |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 单画面（非拼图、非多视图、非分屏） |
| 人物 | **严禁出现任何人物、人影、人体轮廓** |
| 一致性 | 风格/材质/色调/光线统一 |
| 光线 | 单一光源逻辑，光影方向一致 |
| 画面比例 | 默认 16:9（或按调用方设定） |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 场景必须有「前中后景层次」 |
| R2 | 室外必须包含「空气透视」 |
| R3 | 场景图必须为「单画面主视图」，不得拼接多视图/分屏/网格 |
| R4 | 构图须能代表场景主体并展示前/中/后景层次 |
| R5 | 场景图中**严禁出现任何人物** |
| R6 | 必须包含暗黑奇幻二次元关键词（dark fantasy anime / cel shading / fine cold brushstrokes） |
| R7 | 必须包含镜头光学特征（赛璐璐平涂 / 精致冷峻线条 / 哥特渲染） |
| R8 | 材质必须带有自然风化/岁月痕迹，禁止全新无瑕的"CG 感" |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 背景纯白/纯黑/无场景 |
| X2 | 极端天候（暴风雨/雷电/暴雪，除非剧情需要） |
| X3 | 场景无纵深/无层次 |
| X4 | 植被/天候与季节矛盾 |
| X5 | 出现任何人物、人影、人体剪影或人体轮廓 |
| X6 | 画面被拼接成多视图/网格/分屏布局 |
| X7 | 3D 写实/CG 动画/卡通/游戏引擎质感（禁用 3D render、CGI、Unreal Engine、Unity 等词） |
| X8 | 材质过于干净完美、无任何使用痕迹与岁月感（避免"塑料感"） |
| X9 | 光照过于均匀平坦、无景深虚化、无镜头光学特征 |
| X10 | 明亮治愈/少女粉嫩/萌系色调破坏暗黑奇幻氛围 |
