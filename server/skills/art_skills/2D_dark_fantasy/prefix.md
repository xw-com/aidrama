### 硬约束色（默认锁定）

| 色项 | 对应色 | 规则 |
|---|---|---|
| 整体色调 | 暗黑奇幻色 + 低明度动漫配色 | 禁止高饱和荧光色/粉嫩色 |
| 线条颜色 | 墨黑或深紫 | 禁止纯黑粗线条 |
| 阴影 | 同色系加深、厚重低明度 | 禁止黑色硬阴影 |
| 赛璐璐色块 | 平滑渐变、高对比 | 禁止色块断层/色彩溢出 |

| 参数 | 值 | 说明 |
|---|---|---|
| 整体色温 | 偏冷 4200-5000K（推荐） | 暗黑冷调主基调 |

| 饱和度 | 中低 35-55%（建议区间） | 低明度暗黑色盘 |
