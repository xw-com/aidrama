本手册专为"真人家庭生活"题材视觉创作打造，所有美术提示词、视觉规范和生成内容严格限定于真人实拍级家庭生活/家居日常影视美学体系。

## 一、风格核心定义

**真人家庭生活写实**是以**真人影视摄影美学**为基准、以**当代中国家庭生活/家居日常**为核心的视觉风格体系。其核心特征为：

- **真人写实摄影质感**：以真人影视级摄影为锚点，画面呈现真实人物不同年龄的皮肤纹理（婴幼儿细嫩、成人毛孔、长辈皱纹）、毛发细节、微表情与肢体语言，杜绝3D建模感、CG渲染感、手绘感
- **当代中国家庭世界观**：所有场景严格限定于当代中国家庭的温馨私密空间——客厅、家庭餐厅、开放式厨房、主卧次卧、儿童房、阳台、玄关、小区花园楼下等真实家居日常场景
- **电影级摄影语言**：以院线级家庭题材真人电影摄影为基准，强调居家窗光与暖吊灯/夜灯的有机调度、构图叙事的专业性、景深与焦点的情绪表达、色彩分级的电影感
- **家庭日常温度感**：在保持专业影像品质的前提下，强调家庭生活的烟火气、家人之间真实温情的情感连接、日常瞬间的审美提炼——一桌饭菜、一盏夜灯、一双拖鞋、一张全家福

### 创作理念与核心价值

本手册的核心创作理念为 **"平凡即深情"**：

1. **日常瞬间的史诗感**：家庭生活的伟大恰恰藏在最平凡的瞬间里。灶台上升腾的蒸汽、餐桌边围坐的一家人、孩子趴在地板上玩积木、奶奶在阳台浇花、深夜夫妻在客厅低声交谈——这些被反复发生的日常，才是中国人最深处的情感叙事。

2. **家即叙事容器**：当代中国家庭是最私人也最普世的叙事空间。客厅的沙发承载了几代人的团圆，厨房的灶火从未真正熄灭，儿童房贴满的身高刻度、冰箱上越积越多的磁贴、玄关那盏总不关的小灯——家本身就是一个巨大的情感容器，每一处磨损都是时间的签名。

3. **多代同框的在场感**：家庭生活题材的独有魅力在于"老幼共处"。孩童的细嫩肌肤与长辈的皱纹在同框对话，父母操劳的体态与子女天真的眼神互相映照——这种跨越年龄的真实在场，是其他题材无法替代的生命质感。

4. **电影与日常的临界点**：寻求"电影的精致"与"家的真实"之间的微妙平衡——画面足够美、足够专业、有电影感，但不过度精致而失去生活感；家人足够真实、足够生动，但不过度随意而失去审美品质。家不是样板间，但家也值得被认真凝视。

**核心价值：**

- 为AI视觉创作者提供一套系统化、可复用的真人家庭生活题材提示词方法论
- 建立从概念到成品的标准化视觉创作管线
- 降低真人家庭生活题材AI视觉创作的技术门槛与试错成本
- 填补当前AI视觉创作领域"真人家庭生活题材系统化方法论"的空白

## 三、视觉风格定位

### 3.1 整体风格定位

**"电影级真人写实家庭生活美学"**

以当代中国家庭日常为叙事舞台，以真人影视摄影为技术锚点，追求院线级家庭题材电影的画面品质与审美高度。整体风格在"电影感"与"家的生活感"之间寻找黄金平衡——画面精致但不空洞，真实但不随意，温暖但不甜腻，审美在线但不炫技。

## 四、关键视觉元素

### 4.1 人物视觉元素

真人家庭生活题材的人物视觉以**"真实家人、跨越年龄"**为核心：

- **面容标准**：真人肌肤质感，五官自然立体，呈现不同年龄的真实肤况——婴幼儿细嫩通透、孩童胶原蛋白饱满、成人毛孔细纹、长辈皱纹老年斑，妆容以"洗过脸的原生状态"为主。支持多元气质类型——温柔慈爱、操持烟火、严苛操心、叛逆青春期、天真童真、唠叨市井等
- **发型标准**：当代中国家庭日常发型，居家随意舒适——母亲在家随意扎起的低马尾/丸子头、父亲的居家短发微乱、长辈的盘发或灰白短发、孩童的马尾/童发、青少年的随意造型。发丝自然质感，杜绝假发感与僵硬造型
- **服饰标准**：当代中国家庭日常家居着装体系——家居棉麻套装、针织睡衣、围裙隔热手套、亲子装、长辈家常服、孩童家居/童装、青少年T恤短裤。面料以棉麻针织为主，纹理清晰，褶皱自然，有洗涤穿过的痕迹
- **表情与体态**：微表情真实细腻（眼神、嘴角、眉宇），肢体语言自然不做作——母亲俯身哄娃、父亲瘫坐沙发、长辈拄腰站立、孩子满地乱爬。杜绝僵硬摆拍感与过度戏剧化表情
- **人物气质维度**：温柔慈爱 / 操持烟火 / 严苛操心 / 唠叨市井 / 叛逆青春期 / 天真童真 / 疲惫但温暖 / 新婚甜蜜

### 4.2 场景视觉元素

- **客厅**：布艺沙发+茶几、电视柜+电视、单人椅、地毯、抱枕毛毯、绿植盆栽、全家福照片墙、窗帘——窗光洒入的温暖感、茶几上散落的遥控器和水果盘、沙发上有坐过的凹陷痕迹
- **家庭餐厅/餐桌**：餐桌+餐椅、餐边柜、上方吊灯、餐具碗碟、桌上的菜和饭——烟火气是这里的灵魂，一顿刚吃到一半的饭、桌边围坐的家人
- **开放式厨房**：橱柜+中岛/操作台、灶台+油烟机、冰箱（贴满冰箱贴）、水槽、挂钩上的锅铲围裙——家的运转中心，灶火蒸汽、备菜的真实痕迹
- **主卧**：双人床+床品、衣柜、梳妆台、床头柜+台灯、窗帘——私密休憩空间，床头灯的暖光、随意搭在床尾的睡衣
- **次卧/儿童房**：单人床/儿童床、书桌+椅、玩具/绘本/积木、身高刻度墙贴、童趣配色——孩子的世界，散落的玩具、墙上贴的画
- **阳台**：绿植盆栽、晾晒衣物、休闲椅+小桌、地垫——半户外的呼吸空间，阳光透过绿植的光斑、被风吹动的晾晒衣物
- **玄关**：鞋柜+散落的拖鞋、挂衣钩、穿衣镜、钥匙托盘、感应小灯——家的入口与出口，生活进出的痕迹
- **小区花园/楼下**：长椅、儿童游乐设施（滑梯/摇马）、绿化带、步道、单元门——家的外延，邻里日常、傍晚遛弯、孩子奔跑

- **儿童道具**：玩具/绘本/积木、毛绒玩偶、儿童画、奶嘴、小书包、学步车——童真符号
- **居家生活道具**：抱枕毛毯、拖鞋、洗衣篮/晾衣架、绿植盆栽、家庭医药箱、遥控器、台灯夜灯——日常肌理
- **光影道具**：吊灯、台灯、夜灯、蜡烛/生日蜡烛、窗光、灶火——家庭题材的氛围制造者
- **季节与节日元素**：春节春联红包、中秋月饼、生日蛋糕蜡烛、夏夜凉席西瓜、冬至饺子——节令增强家庭叙事的时间维度

## 五、严禁内容（优先级最高）

本风格严格排除以下内容类型，确保视觉体系纯净统一：

1. **非真人质感**：3D渲染/CG建模/次世代游戏引擎/动画风格/手绘插画/水彩油画/二次元/Voxel/低多边形等一切非真人实拍影像质感
2. **非家庭生活世界观**：古风/古装/传统中式古建/仙侠/玄幻/武侠/宫廷/民国/西方奇幻/中世纪/赛博朋克/科幻未来/机甲/星际太空等非当代家庭日常背景
3. **非家庭空间**：职场CBD写字楼办公室、校园教室、豪门奢华宫殿式宅邸、商业酒店式样板间、明显非家庭家居的公共空间（区别于家庭温馨私密）
4. **非当代中国语境**：明显非中国家庭特征的建筑、家居、标识、人物造型（如和式榻榻米、韩式地炕、纯欧式别墅等无中国家庭辨识度的空间）
5. **技术质量缺陷**：低分辨率/模糊/噪点/变形/畸形肢体/五官扭曲/比例失调/抠图感/塑料感/过度磨皮/假面感
6. **审美倾向违规**：过度高饱和/死亡荧光色/廉价滤镜感/过度HDR/脏乱差画面/刻意阴间色调/过度甜腻假温馨
7. **内容合规红线**：暴露/低俗/暗示性/暴力血腥/违法内容/歧视性表达/政治敏感元素

## 七、使用说明

### 提示词使用原则

1. **前缀先行**：所有生成内容必须首先加载"前缀提示词"中的全局风格锚定段，锁定真人家庭生活写实质感基线
2. **专项叠加**：在全局前缀基础上，按需叠加角色/场景/道具/分镜专项提示词
3. **负面必加**：每次生成必须附带"负面提示词"，规避伪影与风格偏差
4. **迭代优化**：建议首轮生成后根据效果对专项提示词做微调，而非修改全局前缀
5. **平台适配**：本手册提示词优先适配Doubao-Seedream（生图）与Doubao-Seedance（视频生成），部分提示词可能需根据平台特性微调
