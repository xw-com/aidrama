## 四、全局约束规则

### 4.1 影像真实性约束（必守）

| 编号 | 规则 |
|---|---|
| P1 | 必须以「真人摄影 / 真人实拍 / 真人电影剧照」为生成锚——画面必须读作"摄影机拍下的"，而非"计算机生成的" |
| P2 | 必须指定一个具体的光源逻辑：这场戏的光从哪里来？（窗/吊灯/夜灯/灶火/烛光）光源方向、色温、软硬须自洽 |
| P3 | 必须保留人物不同年龄的真实皮肤质感——婴幼儿细嫩通透、成人毛孔细纹、长辈皱纹老年斑——杜绝塑料磨皮与AI感假面 |
| P4 | 发丝必须呈现自然居家状态——随意束起的碎发、睡前微乱的头发、长辈灰白发的真实质地——杜绝建模感整齐发块 |
| P5 | 家居服饰必须体现"穿过/洗过"的痕迹——棉麻自然褶皱、针织起球、睡衣领口松垮、围裙上的油渍——杜绝全新样板衣感 |
| P6 | 家居空间必须有"被住过"的证据——茶几散落的物品、墙面钉子孔与贴纸残留、沙发坐过的凹陷、冰箱贴越积越多——杜绝样板间 |
| P7 | 人物必须处于家庭日常的自然体态——母亲俯身、父亲瘫坐、孩子满地爬、长辈拄腰——非摆拍对称 |
| P8 | 必须指定一个具体的当代中国家庭空间——拒绝"generic home"或任何无国别/无家居辨识度的架空空间 |

### 4.4 风格越界判定

> 当你生成的画面出现以下任一信号，说明已经偏离真人家庭生活写实风格：
