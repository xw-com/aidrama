# 真人家庭生活场景图像生成 · 约束手册

---

## 一、场景美学原则

> 真人家庭生活写实的场景不是"被建模的空间"，而是"被摄影机选中的一个住过很久的家"。没有渲染引擎、没有贴图、没有体积光参数——只有实际存在的居家光、真实的家居材料、以及一个中国家庭的日常痕迹。

1. **家即叙事** — 一个空无一人的客厅不是"空的"，是一家人刚吃完饭。沙发上的凹陷、茶几上没收的碗、电视还开着、阳台上还在晾的衣服——空间自己会讲故事
2. **真实的光，不是渲染的光** — 场景的光只有一个来源：实际的居家日光（通过窗户、阳台门）、实际的居家灯光（客厅顶灯、餐厅吊灯、卧室台灯、夜灯、灶火）。光的色温和方向必须在物理上说得通
3. **被住过很久的空间** — 真实的家不整洁。沙发有坐过的凹陷、茶几有水渍圈痕、墙上有孩子的涂鸦和贴纸、冰箱贴越积越多、儿童房玩具散落。一个完全没有生活痕迹的空间是样板间，不是家
4. **中国当代家庭的真实场所** — 场景必须有中国家庭特征（中式餐具、国产品牌电器、春联、中文冰箱贴、中国居民楼的窗与阳台）。这不是"generic home"，这是"当代中国家庭的一个具体角落"
5. **单视图全景全貌** — 一张照片装下整个家居空间的完整信息。广角或标准焦段，全景深，正面展示空间的全貌与纵深——不是四视图分割，不是多角度拼贴

## 三、室内场景

### 空间摄影规范

| 维度 | 摄影要求 | 提示词 |
|---|---|---|
| 风格 | 真实的中国当代家庭室内空间——不是效果图、不是样板间、不是渲染。是有生活痕迹的真实家居 | 真实的中国当代家庭{空间类型}、真人实拍摄影、非效果图非样板间 |
| 光源逻辑 | 必须有明确的光源来源——客厅窗光是哪个方向的窗、餐厅吊灯、卧室夜灯。光的方向和色温必须自洽 | {窗光方向}自然光为主、{居家灯具光源}为辅、光的方向明确可追溯 |
| 空间层次 | 单张全景照片必须呈现前/中/后景——前景（门框/沙发边缘/窗帘）形成画框感、中景是空间主体、后景是空间延伸（另一个房间/窗外/走廊/阳台） | 前景{画框元素}、中景{空间主体}、后景{空间延伸}、广角镜头捕捉完整空间纵深 |
| 材质与表面 | 墙面有居住痕迹（孩子的贴纸/钉子孔/身高刻度）、地面有正常磨损、家具表面有使用包浆、沙发有坐过的凹陷——一切材质呈现在摄影机下，非渲染 | 真实墙面居住痕迹、地面正常磨损、家具使用包浆、沙发凹陷、非全新非样板间 |
| 镜头选择 | 24-28mm广角——装下整个家居空间的广度、前景到后景的纵深全部清晰（全景深 f/8-f/11）、轻微桶形畸变增加空间感 | 广角24-28mm、全景深f/8-f/11、空间纵深完整、轻微透视增加空间感 |

## 五、单视图全景摄影规范

> 真人家庭生活写实场景仅需**单张**全景摄影——一张照片装下整个家居空间的完整信息。不是2×2四视图，不是多角度拼接。

### 画面构成

| 项目 | 摄影要求 |
|---|---|
| 空间呈现 | 单张照片完整呈现场景的空间全貌。使用24-28mm广角或35mm，全场地的纵深、宽度、高度在一张画面中全部可见 |
| 构图 | 全景深大景别——前景（门框/家具/窗帘/绿植）形成天然画框→中景是场地主体→后景向空间纵深或窗外/阳台/另一个房间延伸 |
| 景深 | 全景深 f/8-f/11，从前到后全部清晰。这不是人像摄影——家居的每一个角落都应该能被看见 |
| 人物 | **严禁出现任何人物、人影、人体轮廓。** 场景是空的——但这种"空"有叙事：刚吃完饭/即将起床/人去屋空/日常的静止瞬间 |
| 比例 | 建议 16:9 或 3:2 宽幅——匹配全景空间展示的横向视觉习惯 |
| 色彩 | 由实际居家光源的色温驱动，不套滤镜。色彩科学参考ARRI Alexa/Sony Venice电影色调 |

### 空的场景如何叙事

| "空"的类型 | 画面线索 | 叙事暗示 |
|---|---|---|
| 刚吃完饭 | 餐桌还没收、碗碟还在、剩菜剩饭、椅子没推回、茶几上有水果皮 | 刚才一家人在这吃饭，现在离开了 |
| 即将开饭 | 餐桌摆好碗筷、菜在锅里、吊灯已开、椅子拉开、饭已盛好 | 有人马上要来吃饭，现在是开饭前的静止 |
| 人去屋空 | 搬家后的空房间、墙上挂钩和钉子留下的痕迹、地面积尘的轮廓、留下的旧全家福 | 曾经有人住过，现在搬走了 |
| 日常的静止 | 沙发上的毛毯随意搭着、茶几上的遥控器和半杯水、阳台还在晾的衣服、儿童房散落的玩具 | 生活的常态，只是此刻没有人入镜 |
| 深夜的家 | 客厅只有电视光、卧室只有夜灯、餐厅吊灯关了、玄关感应灯为晚归人留着 | 家睡着了，但为某个人留了一盏灯 |
| 清晨未醒 | 窗帘透进晨光、厨房还没开火、餐椅整齐、卧室床铺凌乱、整体静谧 | 一切还没开始，家还在沉睡 |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须是**单张**全景摄影——单视图、非2×2四视图、非多角度、非turnaround |
