# 真人家庭生活道具图像生成 · 约束手册

---

## 一、道具设计原则

> 真人家庭生活写实的道具不是"被建模的物体"，而是"被一家人用过、用了很多年的物品"——它在某个家人的手里待过、在餐桌上放过、在孩子嘴里咬过、在灶台上熏过。摄影机拍下的是它的此刻。

1. **物品即家庭叙事** — 每一件道具都是一个微型的家庭叙事容器。围裙上的油渍暗示刚做完一顿饭、奶瓶的磨损暗示用了很久、全家福相框的落尘暗示摆在电视柜很久、孩子绘本的翻旧暗示被反复读过
2. **使用与岁月痕迹优先于完美品相** — 家庭道具必须有"被用过/用了很多年"的证据。全新的、刚拆封的、样板级别的道具一律不出现——除非剧情需要"刚买的新东西"
3. **中国当代家庭真实物品** — 道具必须是中国家庭生活中真实存在的物品：中式碗筷、国产品牌小家电、中文标签、中国式外卖/超市包装、春节春联红包——拒绝无国别的架空物品
4. **材质即真实** — 不是PBR参数渲染出的材质，而是摄影机拍下的真实材质行为：原木的自然纹理与磕碰、陶瓷的釉面与划痕、棉麻的编织与起球、不锈钢的反射与指纹
5. **单视图静物摄影** — 道具以单张静物产品摄影方式独立呈现，非多角度建模展示，非2×2四宫格

## 三、单视图静物摄影规范

> 真人家庭生活写实道具仅需单张静物产品摄影，非多角度建模展示。以下为单视图摄影的完整规范。

### 画面构成

| 项目 | 摄影要求 |
|---|---|
| 道具呈现 | 道具居中或偏三分线位置独立陈列，完整入画，无裁切 |
| 背景 | 素灰无缝背景纸 #B0B0B0（哑光），或真实家居台面（浅木纹餐桌/米白台面/厨房操作台大理石）根据道具属性选择。无多余物体、无装饰、无文字 |
| 光线 | 自然居家窗光或单灯柔光。窗光45°侧入（明亮柔和带自然阴影）、或柔光箱顶+侧补（产品摄影级均匀光线）、或餐桌吊灯暖光（餐具类道具）。光影柔和、方向明确、无硬阴影 |
| 景深 | 浅景深（f/2.8-f/5.6），道具主体清晰锐利，前后微虚化突出主体 |
| 投影 | 道具底部与承载面之间的自然接触阴影——真实的而非抠图或悬浮。阴影柔软、方向与主光源一致 |
| 画面比例 | 建议 1:1 正方形或 4:3，适配单件道具展示 |

### 道具状态准则

| 维度 | 要求 |
|---|---|
| 使用痕迹 | 必须有"被使用过"的视觉证据——非全新未拆封、非样板品相 |
| 中国辨识度 | 中文标识/中国品牌/中式器皿/当代中国家庭日常——拒绝无国别架空物品 |
| 材质真实感 | 非渲染质感——是摄影机拍下的真实材料行为（光的反射、漫射、透射） |
| 家庭温度感 | 道具有"被一家人用过"的个性——非冷冰冰的商品照 |
| 尺度感 | 通过材质纹理密度、工艺细节暗示实物尺寸，无需参照物 |

## 六、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须是「单张静物摄影」——单视图、非多角度、非2×2四宫格、非建模展示 |
