# 真人家庭生活人物基础形象生成 · 约束手册

## 一、选角逻辑——摄影机前的一家人

> 3D角色的起点是"建一个模型"；真人家庭生活写实的起点是"选一个家的人站在摄影机前"。家庭题材的独特在于年龄跨度的真实——同一画面里可能同时存在婴幼儿、孩童、青少年、父母、长辈。以下原则从选角和拍摄出发，不从建模出发。

1. **面孔即岁月** — 一张家庭题材的脸就是一部被时间写下的故事。不追求"完美的五官"，而追求"值得被注视的五官"——长辈皱纹里藏的笑、孩子胶原蛋白的饱满、母亲眼角的细纹、父亲疲惫却温暖的眉眼——每个年龄都有不可替代的真实
2. **素人感优先于明星感** — 家庭叙事需要的是"看起来像你家客厅里会坐着的人"，而非"杂志封面走下来的人"。居家洗过脸的原生状态优先于精致妆造
3. **体态说真话** — 真实的家庭体态不是对称的——母亲抱娃时重心偏一侧、父亲瘫坐沙发歪向一边、长辈拄腰站立、孩子满地乱爬。杜绝模特式对称站姿
4. **同一人物跨角度可辨认** — 正面/侧面/背面/特写四角度必须呈现为同一个人的摄影记录，而非四个相似的人。核心识别点：颌骨轮廓、鼻梁转折、耳廓形状、发际线走向、年龄肤质特征
5. **年龄跨度是核心资产** — 婴幼儿、孩童、青少年、成人、长辈各有真实肤质/发质/体态。禁止用"年龄模糊的中年人"模糊处理家庭身份
