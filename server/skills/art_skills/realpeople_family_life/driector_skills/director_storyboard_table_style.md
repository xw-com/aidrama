## 一、分镜表定位

分镜表是导演将剧本转化为镜头语言的核心工具。本约束面向 Seedance 2.0 视频生成，所有光影、动作、空间描述均采用模型可执行的具象语言。不做抽象的家庭情感概括，不写模型看不懂的渲染参数。

## 三、光影与氛围——Seedance 2.0 物理光源描述

### 3.1 同场戏光影统一

一场戏内不应出现两种以上核心光影方案，除非有叙事驱动的光源变化（如有人打开餐厅吊灯、清晨天光亮过夜灯、从客厅走到阳台）。光源变化必须在分镜表中标注触发事件。

### 3.2 光源语句法（每个镜头必须包含）
[光源] 主光：{光源类型}，{方向}，{色温值K}，{软硬}
[光源] 辅光/环境光：{光源类型}，{方向}，{色温值K}
[光比] 约1:{X}
### 3.3 情绪 → 光源矩阵

| 情绪 | 光源配方（Seedance 2.0 可直接填入） | 视觉关键词 |
|---|---|---|
| 日常起居 | 客厅窗光漫射主光（5000-5500K）从落地窗方向侧入，纱帘柔化。光比约1:1.5 | 中性偏暖，通透治愈 |
| 围坐用餐 | 餐桌吊灯暖光主光源（2700-3000K），饭菜与面部被暖色包裹，四周稍暗保留轮廓。光比约1:4 | 暖调包裹、团圆烟火 |
| 亲子陪伴 | 客厅窗光或阳台日光漫射（5000-5500K），明亮柔和，地面反射补光。光比约1:1.5 | 高调通透、柔软生机 |
| 下厨烟火 | 厨房顶灯冷白（4000-5000K）+ 灶火跳动暖橙点光（1800-2200K）+ 操作台暖白补光。光比约1:4 | 暖点冷底、热气腾腾 |
| 长辈温情 | 午后窗光暖侧光（4000-4500K）+ 室内台灯暖补（3000K）。光比约1:3 | 暖调厚重、岁月沉稳 |
| 深夜私语 | 单一卧室夜灯暖柔光（2200-2700K），大面积留暗。光比约1:6 | 极简暖光源、私密脆弱 |
| 家庭矛盾 | 阴天窗光冷调侧打（5500-6500K）+ 深阴影 + 电视冷光局部对冲。光比约1:8 | 冷调压抑、张力 |
| 烛光仪式 | 蛋糕蜡烛1800-2000K为唯一光源，人脸极暖包裹，四周沉暗。光比约1:8 | 极暖极低反差、仪式感 |
| 送别离家 | 玄关暖感应灯（3000K）+ 门外清晨冷光（4500K）逆光剪影。光比约1:5冷暖共存 | 冷暖告别、不舍与希望 |

### 3.4 冷暖色调与叙事阶段

- **冷光主导**（5500K+）：家庭矛盾、压抑独处、阴天日常、雨后
- **暖光主导**（1800-3500K）：围坐用餐、亲子陪伴、下厨烟火、长辈温情、深夜私语、烛光仪式、清晨
- **冷暖共存**：送别离家（玄关暖+门外冷）、夜晚客厅（吊灯暖+屏幕冷）、雨夜（窗外冷+室内暖）
- **光源变化 = 家庭叙事信号**：从客厅窗光（日间冷白）转至餐厅吊灯（傍晚暖橙）= 时间流逝进入晚饭；从餐厅吊灯（暖团圆）转至卧室夜灯（暖私密）= 一天进入尾声；灶火开关 = 做饭开始/结束

### 3.5 Seedance 2.0 光影适配要点

- 色温数字帮助模型校准白平衡倾向：`色温约3000K吊灯暖光` 优于 `餐厅暖光`
- 光比数字帮助模型建立明暗意识：`光比约1:4` 优于 `柔和的暖色阴影`
- 光源必须有明确来源：`餐桌正上方吊灯` 优于 `顶部暖光`
- 环境光的反射路径描述：`锅底反射灶火跳动暖橙光` 优于 `锅底有暖色反光`

## 四、环境动态——让家庭画面呼吸

### 4.1 动态密度

每 3-4 个镜头至少安排一个有环境动态的镜头。静态家庭对话戏也不例外——至少有一个镜头里灶台的蒸汽在升腾、窗帘被微风吹动、孩子的玩具在晃、婴儿在蹬腿。

### 4.2 家庭环境动态元素（Seedance 2.0 可执行）

| 场景 | 可描述的环境动态 |
|---|---|
| 客厅 | 窗帘被微风轻鼓约10cm后回落（约2秒周期）、电视画面在远处闪烁、茶几上水杯水面微微晃动、沙发凹陷缓慢回弹、绿植叶片被空调吹动 |
| 厨房 | 灶台蒸汽缓缓升起并扩散、锅底油渍滋滋冒泡、油烟机运转的低频震动、冰箱偶尔发出"咕噜"气泡声、调料瓶被灶火震动微颤 |
| 餐厅 | 饭菜蒸汽缓缓升起、吊灯轻微晃动导致光影微变、桌面上筷子被碰动滚了一下、窗外光线随云朵移动而明暗变化 |
| 卧室 | 床头台灯光晕稳定、窗帘被缝隙风吹动、床头柜水杯水面微晃、窗外偶尔车灯扫过天花板、婴儿胸口随呼吸起伏 |
| 阳台 | 晾晒衣物被风吹动、绿植叶片簌簌、远处小区有人走过、阳台门半开被风轻推、晾衣架金属碰撞轻响 |
| 儿童房 | 玩具被孩子碰动、积木倒塌、绘本被翻页、风铃被风吹响、小夜灯稳定光晕 |
| 玄关 | 感应灯在人经过时亮起、门外楼道偶尔的脚步声、穿衣镜轻微反射变化、鞋柜上钥匙被放下 |
| 小区楼下 | 行道树叶片簌簌、远处孩子在游乐区嬉闹、电动车缓慢驶过、单元门反复开合、傍晚路灯渐亮 |

### 4.3 Seedance 2.0 环境动态描述规范

- 动态必须有具体轨迹和速度：`蒸汽以约每秒10cm速度上升并扩散` 优于 `蒸汽在升`
- 光源动态与空间光源逻辑一致：`云朵遮住太阳时，客厅窗光面积缩小约40%，持续约3秒后恢复`
- 禁止无来源的动态：没有开窗=没有风吹窗帘。灶台没开火=没有蒸汽

## 五、人物动作节奏——Seedance 2.0 物理逻辑具象化

### 5.1 动作描述铁律

所有家人动作必须描述：**轨迹 + 速度/时长 + 身体部位协调 + 对周围物体的影响**。

### 5.2 家庭日常动作具象库

| 动作 | Seedance 2.0 可执行描述 |
|---|---|
| 夹菜 | 右手持竹筷，筷尖从盘中夹起一块菜，手臂向画面左侧移动约30cm，将菜放入对方碗中，筷尖松开——全程约2秒，菜落入碗中带起轻微汤汁 |
| 盛饭 | 右手持饭勺从电饭煲中舀起米饭，手臂抬起转向碗方向，将米饭倒入碗中至大半满，饭勺轻拍一下饭面——全程约3秒 |
| 喝汤 | 双手端起汤碗至嘴边，碗口倾斜约20度，嘴唇接触碗沿，小口啜饮约1秒，碗下降回桌面约1秒 |
| 哄娃入睡 | 母亲坐在床边，右手轻拍婴儿背部，拍击频率约每秒1次，幅度约上下5cm，身体微微前倾，嘴里轻声哼唱——持续约5秒 |
| 抱孩子 | 母亲弯腰双手穿过孩子腋下，将孩子抱起至胸前，左手托臀右手扶背，孩子双腿环住母亲腰部——全程约2秒 |
| 端菜上桌 | 母亲双手端着砂锅隔热手套，从厨房方向走向餐桌约3步（约2米，耗时2秒），将砂锅放在餐桌中央，锅底与桌面接触发出沉闷一声，随即升起蒸汽 |
| 晨起做饭 | 母亲在操作台前，左手扶锅，右手拧开灶火开关，火苗从蓝转橙跳动起来，她将鸡蛋磕入锅中，发出滋啦一声，蛋白迅速凝固变白——全程约4秒 |
| 瘫坐沙发 | 父亲身体前倾微屈膝，臀部陷入沙发，背部自然靠向沙发背，沙发凹陷随之下压约5cm，双腿随意伸出——全程约1.5秒 |
| 推门回家 | 右手握住门把手向下转动约30度，向内推开门约70度角，身体随门进入，右脚先跨过门槛，随手关门——全程约2秒，玄关感应灯亮起 |
| 给老人夹菜 | 母亲站起或前倾，持筷从盘中夹菜，手臂移动至长辈碗中（约40cm距离），轻放——全程约2.5秒，动作比给孩子夹菜更克制恭敬 |
| 看全家福 | 人物走近电视柜/墙面，目光停留在全家福照片上，身体微前倾，可能伸出手指轻触相框——持续约3秒，神情怀旧 |
| 吹蜡烛 | 人物双手撑在桌沿，身体前倾，深吸一口气，嘴部收圆对准蜡烛，用力吹气，火苗依次熄灭，升起一缕青烟——全程约2秒 |

### 5.3 动作节奏与家庭叙事场景

- **日常叙事/家庭文戏**：动作沉稳克制，每个微动作标注时长和轨迹。节奏舒缓——不是慢，是"家的节奏"
- **亲子场景**：动作幅度活泼，但不失温柔。母亲的动作多为俯身、抚摸、轻拍，孩子的动作多为随意、笨拙、活泼
- **家庭冲突场景**：动作干脆但仍有物理轨迹。摔碗/推搡须具体到"右手将碗摔在餐桌上，碗里的汤汁溅出约20cm，碗底撞击桌面发出清脆一声"
- **长辈场景**：动作缓慢稳重，可能有颤抖。长辈的站起/坐下/转身都标注得更慢（约比成人慢1.5倍）
- 禁止：无叙事理由的快速动作堆砌、无物理逻辑的瞬移、"做了个家务"等含糊描述

### 5.4 服饰与织物动态

真人家庭服饰的动态是画面的天然资产——不是"布料模拟参数"，而是"围裙下摆被转身带起约15度角""睡衣袖口因盛饭动作滑至肘部""孩子被抱起时小睡衣下摆上移露出肚子""毛毯从沙发边缘垂落一角"。在分镜表画面描述中标注家居服饰与织物的动态细节。

## 六、空间逻辑具象化——Seedance 2.0 空间坐标系统

### 6.1 每镜头必须声明的空间信息
水平位置：画面左/中/右，或画面左侧三分之一处
纵深位置：距镜头{数值}米，前景/中景/背景
人物与家居的关系：距{固定家具}{数值}米
（若双人以上）家人之间的相对距离和朝向
### 6.2 站位衔接示例
【片段A尾部】
母亲站在灶台前，距操作台约0.3米，面朝灶台，位于画面中央偏左，距镜头约4米。
灶火正旺，火光映在母亲右脸。
母亲右手持锅铲，刚将炒好的菜盛入盘中。

【片段B开头】
母亲的右手刚从锅铲上移开，盘子在操作台上。母亲仍站在灶台前（位置未变）。
灶火已关，但锅底仍有余温升起蒸汽。
画面右侧的餐厅方向传来家人入座的声音——母亲转头看向餐厅约1秒。

### 6.3 空间变化必须具象

| 抽象（禁止） | Seedance 2.0 具象 |
|---|---|
| 母亲走过来 | 母亲从厨房方向（距镜头约5米、灶台位置）向镜头方向匀速行走4步（约3米），停在距镜头约2米的餐桌前——耗时约4秒 |
| 一家人围坐 | 父亲位于画面中央偏左（距镜头约3米），母亲位于画面右侧（距镜头约3米），孩子位于画面中央（距镜头约3.5米），三人围坐餐桌三方，相距约0.8米 |
| 从客厅到卧室 | 母亲从客厅沙发（距镜头约3米）起身，走向画面右侧卧室门，推开门（门向内旋转约80度），右脚跨过门槛进入卧室——卧室夜灯2200-2700K暖光瞬间取代客厅台灯3000K暖光 |

## 七、运镜规范——Seedance 2.0 摄影机运动

### 7.1 允许的运镜

| 运镜 | Seedance 2.0 描述 | 适用场景 |
|---|---|---|
| 固定 | 摄影机固定不动，画面静止 | 餐桌对话、客厅日常、空镜留白、哄睡凝视 |
| 手持微晃 | 摄影机有轻微不规则晃动（幅度约±2cm），模拟手持拍摄的呼吸感 | 哄娃、厨房忙碌、情绪波动、家庭争吵、跟随孩子 |
| 稳定器流动 | 摄影机平滑匀速移动，无晃动 | 从玄关走到客厅、端菜到餐桌、家居空间展示、家人登场 |
| 缓推 | 摄影机向主体缓慢推进，推进速率约每秒0.3米 | 饭桌对话升温、哄睡、烛光时刻、情感逼近 |
| 缓拉 | 摄影机向后缓慢拉远，拉远速率约每秒0.3米 | 家人入睡后离开卧室、章节收束、揭示家居全貌 |
| 跟拍 | 摄影机与家人保持约2米距离同步移动 | 厨房到餐厅端菜、归家走进家门、小区遛弯 |
| 摇镜 | 摄影机原地水平/垂直旋转 | 扫过全家福照片墙、从灶台摇到餐桌、孩子视线引导 |

### 7.2 禁用运镜

- 无叙事目的的快速甩镜、急推急拉（推拉速率超过每秒1米）
- 超过3秒的剧烈手持晃动（除非家庭争吵/受击/眩晕叙事）
- 无逻辑花式转场——划屏、旋转、百叶窗、翻页等特效转场
- 摄影机无理由的360度旋转

### 7.3 真人家庭生活写实运镜哲学

- 固定机位是第一选择——让观众看到真实的家人在真实的家里自然地存在
- 手持微晃在情绪段落使用——但晃动幅度不超过电影纪实风格的常规范围
- 运动镜头的起幅和落幅必须平稳，运动过程匀速——禁止突然加速或急停
- 家里孩子/婴幼儿在场时，手持微晃更能传达"在场感"与"陪伴感"

## 八、转场规范

### 8.1 允许的转场方式

| 转场 | 视觉执行 | 叙事功能 |
|---|---|---|
| 硬切 | 直接切换 | 同场戏内镜头切换（默认） |
| 光影匹配转场 | 两个场景在相近居家光影逻辑下切换 | 时间流逝、平行叙事。例：A处餐桌吊灯暖光 → B处清晨厨房窗光（一顿饭到第二天早晨） |
| 空间匹配转场 | 两个家居空间在构图或元素上呼应 | 场景跳转。例：关上自家门的瞬间 → 打开父母家门的瞬间 |
| 家居空镜过渡 | 插入家居空镜（3-5秒） | 情绪缓冲、章节划分、时间流逝暗示（深夜玄关灯→清晨灶台） |
| 焦点转场 | 前镜焦点从家人移至家居物品，后镜从模糊物品中逐渐聚焦家人 | 空间切换、注意力转移（焦点从孩子移至全家福，再从全家福聚焦长辈） |

### 8.2 禁止的转场

- 纯视觉特效转场（翻页、划屏、百叶窗、马赛克）
- 无叙事逻辑的旋转/缩放转场
- 同一场戏内使用超过两种转场方式

## 十一、家居空镜使用规范

### 11.1 空镜不是"没东西拍"

家居空镜是家庭情绪容器。每个空镜必须有叙事目的和具体的视觉内容：

| 空镜类型 | 叙事目的 | 示例 |
|---|---|---|
| 家居建立 | 新空间首次出现——让观众看清楚这是家里的什么地方 | 客厅大全景：沙发茶几电视、全家福墙、阳台门 |
| 情绪缓冲 | 高情绪段落后的喘息 | 深夜玄关那盏为晚归人留的感应灯，灯泡微微发热 |
| 时间流逝 | 暗示时间过去了 | 同一扇窗外的光从清晨暖白渐变至黄昏暖橙 |
| 隐喻留白 | 以物代情 | 餐桌上一桌没动过的饭菜渐渐变凉，蒸汽减少 |
| 转场衔接 | 前后两个家庭空间的自然过渡 | 玄关的感应灯——前一场是归家，下一场是卧室夜话 |

### 11.2 家居空镜 Seedance 2.0 描述规范

空镜也必须遵循光源+质感+动态的描述铁律：餐桌正上方吊灯散发2700-3000K暖橙黄光照亮一桌家常菜，
饭菜的蒸汽以约每秒10cm速度缓缓升起并扩散，
茶杯水面因桌面轻微震动泛起细微涟漪——
餐桌中央的砂锅底部真实熏黑，碗碟有真实使用划痕，桌面有水渍圈痕。
画面右侧的餐椅没推回，暗示刚有人离开。
