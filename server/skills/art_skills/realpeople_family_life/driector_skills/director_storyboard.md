## 适用范围

本 Skill 专用于**真人家庭生活写实**风格的分镜提示词生成，适配家庭伦理、亲情日常、围坐用餐、亲子陪伴、长辈温情、夫妻私语、生日仪式、送别归家等真人实拍家庭题材的分镜创作。

## 一、摄影机前的情绪——面孔、眼神、微表情

> 真人家庭生活写实的情绪不来自"义体光效"或"渲染参数"，而来自真人家人的微表情——而且要体现不同年龄的差异。以下映射面向摄影机捕捉真实家人面孔的方式。

| 情绪输入 | 面容描述 | 眼神描述 | 微表情补充 |
|---|---|---|---|
| 温柔 / 慈爱 | 眉目舒展，面部柔和，看孩子时整张脸都柔软 | 眼神温润专注，像在认真看孩子吃饭 | 嘴角自然微扬，不是笑，是有温度的注视 |
| 操劳 / 疲惫 | 眼窝微陷，面部整体松弛，可能有黑眼圈 | 目光朦胧，眼皮微沉，但仍有温度 | 眉眼低垂，嘴角下垂，但眼神并未冷漠 |
| 唠叨 / 关切 | 面部线条微微绷紧，嘴唇微动像在说话 | 眼神锐利带操心，注视有力 | 嘴部动作多，眉头微蹙，关切里的挑剔 |
| 严厉 / 操心 | 面部线条清晰绷紧，下颌微收 | 眼神笔直有力，不回避 | 下巴收紧，表情克制，威严里的爱 |
| 叛逆 / 不耐 | 眉头微蹙，嘴角微撇，眼神躲闪 | 目光斜视或下垂，偶有对抗性对视 | 嘴唇抿紧，可能翻白眼，少年特有的抵抗 |
| 童真 / 好奇 | 眼睛睁大圆润，面部胶原蛋白饱满 | 眼神清澈直接，瞳孔大而亮 | 嘴巴微张，可能流口水（婴幼儿），表情鲜活 |
| 喜悦 / 温暖 | 眼角出现自然笑纹，眼型微弯 | 眼神明亮有光，眼角有笑意 | 嘴角上扬，面颊微红，全家团聚的暖意 |
| 沉思 / 怀旧 | 神情淡然，眼部周围肌肉放松 | 目光放远失焦，像在看全家福发呆 | 表情平静，可能单手托腮或抚摸旧物 |
| 委屈 / 隐忍 | 眉眼低垂，面部肌肉松弛下垂 | 目光湿润但回避对视，眼眶微红 | 嘴角紧抿，可能咬唇，倔强里的脆弱 |
| 决绝 / 担当 | 面部线条清晰，下颌微抬 | 眼神笔直向前，有承担感 | 下巴微收或微抬，表情果敢，家人的脊梁 |

## 二、摄影机前的光——居家光源逻辑与氛围

### 2.1 自然居家光时刻

| 时刻 | 光源行为 | 色温与色调 | 空间氛围 |
|---|---|---|---|
| 清晨 | 低角度暖白日光穿过窗帘斜入室内；阳台日光刚越过对面楼顶、长阴影 | 3500-4500K暖白，空气微冷 | 静谧未醒、晨雾清冽、家刚苏醒 |

## 四、摄影机语法——镜头选择与运动

### 4.1 焦段选择

| 焦段 | 叙事性格 | 适用场景 |
|---|---|---|
| 24-28mm广角 | 家的完整呈现、空间包裹感、家人共处全貌 | 客厅全景、餐桌围坐、家居空镜 |
| 35mm小广角 | 主观视点，身临其境，家的日常纪实 | 厨房跟随、客厅对话、亲子互动 |
| 50mm标准 | 人眼等价，客观中立的注视，最诚实的镜头 | 家人肖像、餐桌对话、情感凝视 |
| 85mm中长焦 | 压缩空间，拉近情感距离，背景虚化突出家人 | 哄睡特写、烛光映脸、长辈手部特写 |
| 135mm+长焦 | 将人物从家居中剥离，极端的注视 | 阳台远眺、卧室门口偷听视角、情绪的距离感 |

### 4.2 景别选择

| 景别 | 取景范围 | 叙事功能 |
|---|---|---|
| 大特写 | 眼睛/嘴唇/手指/家庭物品细节 | 情绪爆发点、家庭情感揭示、感官聚焦（孩子睫毛/长辈皱纹/烛光映眼） |
| 近景 | 头顶至胸部以上 | 家人情感、对话反应、面部微表情 |
| 中近景 | 头顶至腰部 | 家人互动（夹菜/喂饭/抚摸）、手势动作 |
| 中景 | 头顶至膝盖上下 | 家人围坐、餐桌关系、客厅对话、亲子游戏 |
| 全景 | 家人全身+部分家居 | 家人在空间中的位置、家居全貌、行动 |
| 大全景/空镜 | 家居全貌，家人极小或无人物 | 家居叙事、情绪缓冲、留白（灶台蒸汽/夜灯/全家福） |

### 4.3 摄影机运动

| 运动方式 | 视觉心理 | 使用场景 |
|---|---|---|
| 固定 | 冷静观察，让家庭日常自己说话 | 餐桌对话、客厅日常、空镜留白、情感凝视 |
| 手持微晃 | 在场感，呼吸感，家庭纪实的主观介入 | 哄娃、厨房忙碌、情绪波动、争吵 |
| 稳定器流动 | 优雅流动，跟随家人穿行家中 | 从玄关走到客厅、人物登场、家居空间展示 |
| 缓推 | 注意力逐渐聚焦、情感趋近 | 对话升温、哄睡、烛光时刻 |
| 缓拉 | 拉开距离、揭示家居全貌、情绪抽离 | 章节收束、深夜离开卧室、家人入睡后 |
| 跟拍 | 与家人同行、主观陪同 | 厨房到餐厅端菜、归家走进家门 |
| 摇镜 | 视线转移、家居关系交代 | 扫过全家福照片墙、从灶台摇到餐桌 |

## 五、固定风格锚定词

**摄影锚定（必选）：**

真人实拍摄影，真人电影剧照，当代中国家庭生活家居，电影级摄影，居家窗光与暖吊灯/夜灯/灶火/烛光调度，真实色彩科学

**人物质感（含人物镜头时必选）：**

真人写实摄影质感，真实不同年龄皮肤纹理（婴幼儿细嫩/孩童饱满/青春期痘印/成人毛孔细纹/长辈皱纹老年斑），不磨皮不硅胶脸不硅胶娃娃，居家随意发型有碎发，家居棉麻针织面料纹理可见有穿着洗涤褶皱，自然微表情，真实家庭日常肢体语言

**场景质感（含场景镜头时必选）：**

真人实拍家庭家居场景摄影，真实家居材质和居住痕迹（沙发凹陷/茶几水渍/墙面贴纸钉孔/冰箱贴/儿童玩具散落/绿植黄尖），光源方向明确可追溯，大气透视自然，非样板间非效果图

**参考图一致性锚定（参考图模式必选）：**

保持人物造型、面容、发型、家居服饰与参考图完全一致，保持场景风格与参考图一致，保持光影色彩基调统一，所有镜头呈现为同一家人的连续摄影记录

**风格收尾（固定）：**

真人写实摄影，当代中国家庭生活电影质感，电影级摄影画面，非3D非渲染非CG

**画质锁定词：**

## 六、美学禁止项

以下词汇/风格不得出现于输出提示词中：

- ❌ 3D渲染 / 3D建模 / CG / UE引擎 / Blender / PBR材质 / 次世代建模 / 体积光 / 环境光遮蔽 / 光线追踪
- ❌ 2D手绘 / 插画 / 动画 / 二次元 / 漫画 / Q版 / 低多边形
- ❌ 写实摄影（英文禁止 photorealistic / realistic photography——真人家庭生活写实是"真人实拍摄影"live-action cinematic photography，不是"拟真渲染"）
- ❌ 过度磨皮 / 塑料假面 / 零毛孔 / 硅胶脸 / 蜡像感 / AI感平滑 / 婴幼儿硅胶娃娃感
- ❌ 古风 / 古装 / 汉服 / 仙侠 / 武侠 / 宫廷 / 民国 / 赛博朋克 / 科幻 / 机甲 / 西方奇幻 / 中世纪
- ❌ 职场CBD写字楼办公室 / 校园 / 豪门奢华宫殿宅邸 / 酒店式样板间 / 明显非家庭家居空间
- ❌ 人体结构错误 / 肢体畸形 / 面部崩坏 / 比例失调 / 婴幼儿成人化比例
- ❌ 高饱和荧光色 / 霓虹溢色 / 廉价滤镜感 / 过度甜腻假温馨色调
- ❌ 非中国当代家庭的架空家居 / 无中文辨识度的 generic home
