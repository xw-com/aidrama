## 一、风格基因

| 维度 | 定义 |
|---|---|
| **一级风格** | 全身时尚（Fashion-Photorealism） |

## 二、全局色彩盘（风格基线，不是硬锁）

> 目标：统一审美而非限制创作。除「硬约束色」外，其余颜色默认优先使用，可在合理范围内偏移。

### 色彩使用层级

| 层级 | 约束强度 | 说明 |
|---|---|---|
| L1 硬约束 | 高 | 仅锁定角色识别核心：肤色、发色、主服底色的审美方向 |
| L2 软约束 | 中 | 场景色、配饰色、点缀色优先参考色盘，可按镜头与剧情微调 |
| L3 例外机制 | 低 | 秀场/高定/旅拍高潮戏可临时突破局部色彩，但需保留整体冷暖逻辑 |

| C4 | 深棕发 | #3A2E25 | 发色、眼瞳 |

### 硬约束色（默认锁定）

| 色项 | 对应色 | 规则 |
|---|---|---|
| 肤色基准 | C2 暖白肤 | 默认优先，允许小幅明度/暖度微调 |
| 发色/瞳色基准 | C4 深棕发 | 默认优先，允许深棕/深褐轻微偏移 |

### 软约束色（推荐优先）

> C1/C3/C5/C6/C7/C8/C10 为推荐色域，用于服饰、配饰、背景、暖光、饰品、时尚黑等。可根据穿搭造型与镜头氛围做同色相邻近调整。

### 情绪色盘（导演对齐版）

| 情绪场景 | 主色 | 辅色 | 光效与对比建议 | 画面关键词 |
|---|---|---|---|---|
| 自信出场（高光） | C10 墨黑 | C7 金色暖光 + C8 香槟金 | 暖光镀边，强对比剪影，全身构图 | 锋利、气场、自信 |
| 慵懒松弛（日常） | C1 米杏 | C5 驼色 + C2 暖白肤 | 漫射柔光，低对比暖调，背景虚化 | 松弛、随性、惬意 |
| 锋利气场（冷调） | C6 雾霾蓝 | C10 墨黑 + C9 中性灰 | 冷调主导，硬侧光，明暗分割 | 冷峻、摩登、距离 |
| 街拍随性（自然） | C6 雾霾蓝 | C1 米杏 + C2 暖白肤 | 自然光漫射，中性偏暖，浅景深 | 自然、街头、日常 |
| 秀场高光（辉煌） | C8 香槟金 | C7 金色暖光 + C10 墨黑 | 局部高饱和，金属反光，强光高亮 | 辉煌、华丽、舞台 |
| 旅拍浪漫（暖调） | C7 金色暖光 | C1 米杏 + C5 驼色 | 黄金时刻逆光，暖调铺满，光斑散景 | 浪漫、温暖、远方 |

| 暗调摩登（低沉） | C10 墨黑 | C6 雾霾蓝 + C8 香槟金 | 低调打光，暗部留存，局部金属点缀 | 神秘、高级、沉稳 |

### 情绪色盘使用规则

| 编号 | 规则 |
|---|---|
| E1 | 每条提示词至少指定 1 个「情绪场景」并绑定主色+辅色组合 |
| E2 | 单镜头主色不超过 2 个，避免颜色叙事失焦 |
| E3 | 情绪切换时优先调整光比与色温，再调整饱和度 |
| E4 | 时尚向默认遵循「中性底 + 暖光点」：中性色铺底，暖光落在人物轮廓与穿搭焦点 |
| E5 | 若与剧情冲突，以情绪色盘优先于通用推荐色，但不得突破严禁项 |

### 色温约束

| 参数 | 值 | 说明 |
|---|---|---|
| 整体色温 | 偏暖 5200-6000K（推荐） | 时尚暖调主基调 |
| 肤色色温 | 微暖 5200-5600K（推荐） | 暖白但有生命感 |
| 对比度 | 中强（建议保持） | 明暗反差鲜明但不硬 |
| 饱和度 | 中低 40-55%（建议区间） | 时尚高级色调 |

### 容差与例外

| 项目 | 建议容差 |
|---|---|
| 色相偏移 | ±8° |
| 饱和度偏移 | ±10% |
| 明度偏移 | ±12% |

> 例外场景：秀场、高定、黄金时刻镜头可使用更暖或更高饱和局部色块；但禁止霓虹荧光与卡通色彩语言入镜。

## 三、全局约束规则

### 必守规则（所有技能继承）

| 编号 | 规则 |
|---|---|
| R1 | 必须包含「真人写实摄影」风格锚定词 |
| R2 | 必须声明「全身构图 + 穿搭层次」 |
| R3 | 面部必须使用「面容细腻渲染 + 皮肤细腻」 |
| R4 | 发丝必须使用「根根分明 + 发丝细腻渲染」 |
| R5 | 纹理必须声明「身材比例 + 穿搭质感 + 纹理细节超清晰」 |

### 严禁项（所有技能继承）

| 编号 | 严禁内容 |
|---|---|
| X1 | 严禁「卡通/动漫/二次元/插画风」 |
| X2 | 严禁「高饱和荧光色/霓虹色」 |
| X3 | 严禁「时尚元素缺失」（必须明确时尚穿搭场景） |
| X4 | 严禁「面部变形/多指/肢体异常」倾向词 |
| X5 | 严禁「裸体/暴露/透视/暗示性描述」 |
| X6 | 严禁「古风/古装/汉服/传统建筑元素」 |
