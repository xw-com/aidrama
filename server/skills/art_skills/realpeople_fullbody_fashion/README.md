# 全身时尚风格说明

本风格专为"全身时尚"题材打造，所有美术提示词、规范和生成内容均严格限定于：

- **时尚世界观**：以全身时尚穿搭为背景，涵盖都市街头、广场、秀场、旅拍地、穿搭背景等，杜绝时尚场景元素缺失。
- **真人写实**：所有角色、场景、道具均以真人写实摄影为标准，强调身材比例、头身比、穿搭层次、配饰材质等极致细节与真实质感。
- **时尚纪实**：在写实基础上追求时尚杂志级氛围感，全身构图展示穿搭、黄金时刻自然光、背景虚化，整体氛围自信松弛、时尚大片感十足。
- **穿搭情绪**：适合展现自信、慵懒、锋利、松弛等时尚造型情绪表达，强调全身构图下的身材比例与穿搭展示。

## 适用范围

- 全身时尚题材的AI美术生成（角色、场景、道具、分镜等）
- 需要极致写实、全身穿搭展示、身材比例、街拍自然光氛围的视觉创作

## 严禁内容

- 卡通、动漫、插画、二次元风格
- 时尚元素缺失、古风/古装/传统建筑
- 高饱和荧光色、霓虹色
- 暗示性、暴露、透视等不适宜内容

## 风格体验

在本风格下，您将体验到：

- 角色身材比例优越、头身比出众，时尚造型、配饰、发型均为全身时尚写实
- 场景空间层次丰富，街头/广场/旅拍背景虚化超清晰，氛围真实且富有时尚大片感
- 道具、手包、鞋履、配饰、穿搭道具等均为时尚造型，工艺精细，质感极致
- 分镜与视频均以真人写实为基础，强调全身构图与穿搭展示表达

---

本风格仅适用于"全身时尚"相关项目。如需其他风格（如古风、插画、动漫、都市等），请勿使用本套提示词。
