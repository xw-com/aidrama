# 场景图生成 · 全身时尚约束手册

---

## 一、场景美学原则

1. **空间叙事** — 场景承载时尚情绪与叙事功能，不是纯背景板
2. **层次纵深** — 所有场景必须具备前/中/后景，杜绝扁平
3. **质感至上** — 建筑立面/石材地面/金属栏杆/绿植等材质纹理必须超清晰
4. **实拍为锚** — 一切画面以真实时尚摄影为标准，拒绝 3D 渲染/CG 动画质感；追求镜头光学特征（浅景深虚化、黄金时刻光斑、镜头暗角、色散微痕）与物理光照（自然光漫射、逆光镀边、体积光）

## 三、室内场景

### 空间规范

| 维度 | 约束 | 提示词 |
|---|---|---|
| 风格 | 秀场/买手店/艺术空间/酒店大堂/时尚工作室，现代简约/极简/工业风 | 现代{风格}风格时尚空间 |
| 材质 | 大理石/金属/玻璃/混凝土/木质为主 | 大理石地面、金属结构、玻璃幕墙 |
| 色调 | 中性高级色 + 暖光点缀 + 时尚黑 | 中性高级色、暖光点缀、时尚黑 |
| 纵深 | 前/中/后景层次 | 前景{元素}、中景{元素}、后景{元素} |
| 质感 | 石材纹/金属拉丝/玻璃通透可辨 | 纹理清晰、质感写实 |
| 光照 | 自然光源与人工光混合（窗光/射灯/氛围灯），光线漫射柔和，可见光束粒子、焦散投影 | 自然光漫射、射灯聚焦、光束穿窗 |
| 镜头感 | 浅景深虚化前后景、微镜头暗角、自然色温偏移、光斑散景 | shallow depth of field、lens vignette、natural color cast、bokeh |
| 瑕疵感 | 地面有使用痕迹、金属有氧化、石材有自然纹理 | 使用痕迹、自然纹理、材质真实 |

### 室内类型速查

| 类型 | 核心元素 | 氛围词 |
|---|---|---|
| 秀场T台 | T台、灯光架、看台、背景幕墙 | 华丽舞台、聚焦高光 |
| 买手店/精品店 | 陈列架、服装展示、镜面、灯光 | 精致质感、时尚陈列 |
| 艺术空间 | 白墙、艺术品、射灯、地面 | 极简高级、艺术氛围 |
| 酒店大堂 | 大理石地面、吊灯、沙发、前台 | 奢华静谧、高级氛围 |
| 时尚工作室 | 镜墙、衣架、灯光、道具 | 创作氛围、专业时尚 |

## 五、主视图规范

### 视图定义

> 单画面主视图，从场景中最具代表性的角度拍摄，承载时尚空间叙事与构图重心。

| 项目 | 约束 | 提示词 |
|---|---|---|
| 视角 | 自然观察视角，构图最能体现场景主体与纵深 | hero shot、representative angle |
| 视点高度 | 默认人眼平视高度，特殊场景可俯/仰 | eye level（默认） |
| 构图 | 主体居中或符合三分法，前/中/后景层次清晰 | balanced composition |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 单画面（非拼图、非多视图、非分屏） |
| 人物 | **严禁出现任何人物、人影、人体轮廓** |
| 一致性 | 风格/材质/色调/光线统一 |
| 光线 | 单一光源逻辑，光影方向一致 |
| 画面比例 | 默认 16:9（或按调用方设定） |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 场景必须有「前中后景层次」 |
| R2 | 室外必须包含「空气透视」 |
| R3 | 场景图必须为「单画面主视图」，不得拼接多视图/分屏/网格 |
| R4 | 构图须能代表场景主体并展示前/中/后景层次 |
| R5 | 场景图中**严禁出现任何人物** |
| R6 | 必须包含实拍摄影关键词（real photography / photorealistic / RAW photo） |
| R7 | 必须包含镜头光学特征（shallow depth of field / lens vignette / bokeh 至少一项） |
| R8 | 材质必须带有自然纹理/使用痕迹，禁止全新无瑕的"CG 感" |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 背景纯白/纯黑/无场景 |
| X2 | 极端天候（暴风雨/雷电/暴雪，除非剧情需要） |
| X3 | 场景无纵深/无层次 |
| X4 | 植被/天候与季节矛盾 |
| X5 | 出现任何人物、人影、人体剪影或人体轮廓 |
| X6 | 画面被拼接成多视图/网格/分屏布局 |
| X7 | 3D 渲染/CG 动画/卡通/游戏引擎质感（禁用 3D render、CGI、Unreal Engine、Unity 等词） |
| X8 | 材质过于干净完美、无任何使用痕迹与岁月感（避免"塑料感"） |
| X9 | 光照过于均匀平坦、无景深虚化、无镜头光学特征 |
