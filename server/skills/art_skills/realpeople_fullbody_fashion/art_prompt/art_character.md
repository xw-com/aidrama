# 人物基础形象生成 · 全身时尚约束手册

---

## 一、基础形象原则

1. **身材即灵魂** — 身材比例与头身比是角色唯一锚点，全身级精细渲染
2. **角色为本** — 基础穿搭由角色描述（身份/风格/性别/场景）决定其常规造型；后续特定服化为叠加层
3. **四视图一致** — 面容/体型/发型/基础服装跨视图高度统一
4. **时尚真实** — 无妆状态仍需体现角色气质（自信/慵懒/锋利/松弛）
5. **实拍摄影** — 以真实时尚摄影为锚点，保留皮肤真实质感（毛孔/微小瑕疵）

---

## 二、面容约束

> 不再固定五官特征参数，由角色描述（性别/年龄/风格/气质）驱动 AI 自由生成五官，保证时尚人物间外观差异化。

### 通用要求

| 项目 | 约束 |
|---|---|
| 五官 | 由角色描述自然推导，不预设脸型/眼型/眉型/鼻型/唇型 |
| 风格底色 | 真人写实摄影、时尚杂志级精细渲染、写实材质、街拍自然光影 |
| 气质 | 必须从角色描述提炼整体气质关键词（如自信/慵懒/锋利/松弛），并写入提示词 |
| 表情 | 中性微表情，符合时尚气质，可带自信/松弛感 |

## 六、基础服装约束

> 基础服装由角色描述（身份/风格/性别/场景）决定其最自然的常规全身穿搭，作为该角色「日常默认态」；正式造型/特殊衍生在服化衍生环节叠加。**禁止内衣打底**。

### 着装选择原则

| 角色身份 | 默认着装方向 |
|---|---|
| 街拍潮人 | 都市时髦穿搭（外套+内搭+裤装/裙装+鞋履） |
| 职场时尚 | 时尚通勤装（西装/衬衫+裤装+皮鞋） |
| 旅拍休闲 | 休闲时尚穿搭（风衣/针织+牛仔裤+休闲鞋） |
| 秀场模特 | 时尚造型装（设计师款全身造型） |
| 日常穿搭 | 都市基础穿搭（上衣+下装+鞋履+配饰层次） |
| 角色描述未明确 | 时尚常服、中性高级色调 |

### 着装统一规则

- 服装风格须与全身时尚摄影美学一致（高级色调、写实材质、穿搭层次）
- 颜色中性高级色，无复杂花纹/装饰，便于后续衍生叠加
- 四视图服装款式完全一致
- 基础服装是「日常默认态」，焦点仍在身材比例与穿搭展示
- 严禁内衣/暴露/性化打底

## 八、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须为「时尚状态」|
| R2 | 必须根据角色描述声明合适的常规全身穿搭作为基础服装（如街拍潮人→都市时髦穿搭、职场时尚→时尚通勤装、旅拍休闲→休闲时尚穿搭）；禁止内衣打底 |
| R3 | 必须声明「无发饰、无配饰」 |
| R4 | 必须指定「纯净中性灰背景」 |
| R5 | 必须指定「四视图一致性」 |
| R6 | 全身立像必须从头顶到脚底完整展示，严禁裁切 |
| R7 | 必须声明角色身高并通过头身比换算约束全身比例 |
| R8 | 人像特写必须从头顶到锁骨完整展示，严禁裁切头顶 |
| R9 | 皮肤必须保留真实质感，不可过度磨皮；身材比例与穿搭层次必须可辨 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 内衣/暴露/性化打底；与角色描述明显不符的着装；过度复杂花纹/装饰干扰后续服化叠加 |
| X2 | 正顶硬光/正底光/彩色光 |
| X3 | 过度美白/过度磨皮至无质感 |
| X4 | 复杂场景背景（必须纯灰底） |
| X5 | 夸张表情/非时尚动态姿势 |
| X6 | 全身立像裁切头顶或脚底，必须从头到脚完整入画 |
| X7 | 人像特写裁切头顶，必须从头顶到锁骨完整入画 |
| X8 | 忽略身高和头身比约束；忽略身材比例与穿搭展示约束 |
