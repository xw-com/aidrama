# 时尚风格约束 · 全身时尚 · 技法参考

---

## 一、色调体系与画面基调

- **色调基底** — 全片以米杏（C1）、暖白肤（C2）、驼色（C5）为基底色，整体色温偏暖（5200-6000K），饱和度中低（40-55%），呈现温暖高级的时尚大片感
- **冷暖叙事对比** — 暖色（金色暖光 C7、香槟金 C8、玫瑰豆沙 C3）作为自信/浪漫/高光的视觉信号，冷色（雾霾蓝 C6、墨黑 C10）用于锋利/疏离/摩登等段落。冷暖切换应与时尚情绪弧线同步
- **冷暖分配策略** — 日常与街拍段落以中性/微暖为主，秀场与锋利气场段落释放冷调与高对比；避免全程高暖导致情绪层次塌陷
- **色盘先行原则** — 段落规划先绑定情绪场景（自信出场/慵懒松弛/锋利气场/旅拍浪漫等），再确定主色+辅色与光影方案，避免"剧情对了但情绪不对色"
- **禁用色域** — 高饱和荧光色、强霓虹污染、过度赛博色彩与本风格不兼容

## 二、光影方案体系

- **光影即叙事** — 6 套光影方案对应不同时尚情绪段落，导演规划阶段应在段落层面确定光影基调方向，而非逐镜指定
- **光源角度** — 正给镜头默认 30° 斜射（较柔和），侧给镜头根据场景与人物关系微调

| 光影方案 | 方案名 | 色调倾向 | 适用情绪 |
|---|---|---|---|
| A | 自然漫射 | 米杏底 + 均匀柔和光 | 日常穿搭、街拍随性 |
| B | 黄金时刻逆光 | 金色暖主导 + 暖光镀边 | 旅拍浪漫、温暖高光 |
| C | 硬侧光聚焦 | 健康肤暖 + 局部硬光 | 自信气场、锋利造型 |
| D | 阴天漫射冷光 | 灰蓝主调 + 暖色局部 | 慵懒松弛、低调日常 |
| E | 秀场射灯 | 香槟金主导 + 暗部留存 | 秀场高光、华丽舞台 |
| F | 冷调逆光剪影 | 墨黑主导 + 雾霾蓝背景 | 暗调摩登、神秘疏离 |

- **冷暖光分配** — 暖色光可全片使用但需分层控制；锋利/疏离段落降低暖光占比，避免情绪与光色冲突
- **氛围方向映射** — 每场戏氛围方向应映射到上述光影方案（A-F）的某一方向，确保视觉一致性

## 三、质感方向

- **时尚摄影质感** — 真人写实摄影核心：全身构图展示穿搭、穿搭层次分明、身材比例与头身比出众
- **强对比度 + 极致细节** — 作为画面质感锚点。不是低对比小清新，不是重滤镜氛围化，而是可拍可落地的时尚大片感
- **材质真实** — 服化道需具备现实可信度：风衣面料垂坠、皮革包袋纹理、鞋履光泽、金属配饰反光、丝绸光泽都应符合时尚实拍逻辑
- **皮肤质感** — 保留真实毛孔与细微瑕疵，控制磨皮强度，追求"真实但高级"

## 四、时尚场景空间元素

时尚世界观特有的场景元素及其视觉叙事功能：

- **建筑立面/橱窗/镜面** — 天然框架式构图道具，制造空间分层与时尚反射感
- **街头/广场/旅拍地** — 时尚节奏载体，步态展示与背景虚化的切换可直接映射角色气质
- **秀场/买手店/艺术空间** — 情绪容器：秀场偏华丽聚焦，买手店偏精致陈列，艺术空间偏极简高级
- **天气与时段作为转场** — 日转夜、晴转阴、黄金时刻入夜可用于段落情绪缓冲，避免硬切
- **转折点用视觉而非解释** — 优先使用画面手段（全身构图切换、景别突变、背景虚实转换）承接情绪转折，减少对白解释负担

## 五、时尚乐器与环境音

时尚世界观下的声音元素约束：

### 乐器选择

- **电子/环境时尚音** — 自信出场、街拍节奏、秀场段落核心风格，最能体现时尚摩登感
- **钢琴** — 温馨、回忆、浪漫段落核心乐器，能体现时尚生活质感
- **弦乐** — 情绪抬升与华丽高光段落的主力铺底
- **Lo-fi/轻电子** — 慵懒松弛、城市生活、节奏切换段落的风格增强器
- **环境音优先级高** — 时尚剧中真实街拍环境声是沉浸感关键，配乐不应压过步态与衣料声

### 乐器组合策略

| 情绪阶段 | 乐器组合 |
|---|---|
| 平稳/开场/收尾 | 钢琴独奏 或 Lo-fi 轻铺 |
| 日常推进 | 电子节奏 + 轻打击 |
| 自信/气场 | 电子节奏 + 低频铺底 |
| 华丽/秀场 | 弦乐主导 + 电子节奏 |
| 浪漫/温暖 | 钢琴 + 弦乐 |

### 时尚环境音

- **典型环境音层次** — 高跟鞋踩地声 / 街道车流声 / 橱窗音乐 / 喷泉水声 / 风吹衣摆声 / 快门声 / 城市远景噪声 / 秀场观众低语
- **每场戏标注 1-2 个核心环境音**，帮助后续音效设计。环境音层次越准确，时尚临场感越强
