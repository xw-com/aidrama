## 一、风格核心定义

**真人校园青春**是以**真人影视摄影美学**为基准、以**当代中国校园（高中/大学）**为核心的视觉风格体系。其核心特征为：

- **真人写实摄影质感**：以真人影视级摄影为锚点，画面呈现真实青春人物的皮肤纹理、自然发型、微表情与肢体语言，校服面料的褶皱、校园建筑的岁月痕迹——杜绝3D建模感、CG渲染感、手绘感
- **当代校园世界观**：所有场景严格限定于当代中国校园空间——教室、阶梯教室、图书馆自习室、操场跑道、宿舍上下铺、食堂、林荫道、天台、社团活动室、校园小卖部、实验室等真实校园生活场景
- **电影级摄影语言**：以院线级青春电影摄影为基准，强调自然光与日光灯的有机调度、构图叙事的专业性、景深与焦点的情绪表达、色彩分级的电影感
- **青春人文温度感**：在保持专业影像品质的前提下，强调校园生活的呼吸感、少年少女之间真实的情感连接、青春日常瞬间的审美提炼

### 创作理念与核心价值

本手册的核心创作理念为 **"青春即真实"**：

1. **真实感的审美回归**：在AI生成影像日趋泛滥的当下，真人写实质感以其不可替代的真实力量，成为最具情感穿透力的视觉语言。少女脸庞的绒毛与细纹、少年额头的青春痘印、校服洗过多次的柔软褶皱、阳光穿过碎发在课桌上投下的金边——这些真实细节构成了一种生命质感，是3D渲染无法复刻的审美深度。

2. **校园的叙事容器**：当代中国校园是最具共情力的叙事空间。教室的黑板擦过一半还留着板书、操场的跑道被夕阳镀上暖橙、图书馆台灯下的侧脸、宿舍熄灯后的手机微光、林荫道上单车掠过的风——校园空间本身就是一个巨大的青春叙事容器，等待被挖掘。

3. **人本主义的视觉立场**：本手册坚持以"人"为核心。无论场景多么熟悉、光影多么绚丽，最终回归到人物的情感状态与内心世界。每一帧画面都是一次对青春的注视。

4. **电影与日常的临界点**：寻求"电影的精致"与"校园的真实"之间的微妙平衡——画面足够美、足够专业、有电影感，但不过度精致而失去学生气；人物足够真实、足够生动，但不过度随意而失去审美品质。

**核心价值：**

- 为AI视觉创作者提供一套系统化、可复用的真人校园青春题材提示词方法论
- 建立从概念到成品的标准化视觉创作管线
- 降低真人校园题材AI视觉创作的技术门槛与试错成本
- 填补当前AI视觉创作领域"真人校园青春题材系统化方法论"的空白

## 三、视觉风格定位

### 3.1 整体风格定位

**"电影级真人写实校园青春美学"**

以当代中国校园为叙事舞台，以真人影视摄影为技术锚点，追求院线级青春电影的画面品质与审美高度。整体风格在"电影感"与"学生气"之间寻找黄金平衡——画面精致但不空洞，真实但不随意，审美在线但不炫技。

### 3.2 影像质感层级

| 质感维度 | 定位标准 |
|---|---|
| **皮肤质感** | 真人摄影级，可见青春皮肤的真实纹理——绒毛、细纹、青春期痘印、自然肤色不均，杜绝过度磨皮与塑料感 |

## 四、关键视觉元素

### 4.1 人物视觉元素

真人校园青春题材的人物视觉以**"真实少年、校园气质"**为核心：

- **面容标准**：真人青春肌肤质感，五官自然立体，妆容为素颜或极淡学生妆，不过度修饰。支持多元青春面容类型——清冷学霸、元气阳光、温柔文艺、热血运动、内向羞涩、叛逆不羁等
- **发型标准**：当代校园发型（受校规约束的真实学生发型），发丝自然质感，杜绝假发感与僵硬造型。支持女生马尾/丸子头/短发/披肩发、男生碎盖/短发/寸头等多种校园发型
- **服饰标准**：当代校园着装体系——运动校服套装（拉链外套+长裤）、制服校服（衬衫+西裤/百褶裙+领带/领结）、日常学生穿搭（卫衣/T恤/牛仔）、社团服装、体育课运动服。面料纹理清晰，校徽与年级标识可见，褶皱自然
- **表情与体态**：微表情真实细腻（眼神、嘴角、眉宇），肢体语言自然不做作，杜绝僵硬摆拍感与过度戏剧化表情
- **人物气质维度**：清冷学霸 / 元气阳光 / 温柔文艺 / 热血运动 / 内向羞涩 / 叛逆不羁 / 乖巧听话 / 文静秀气

### 4.2 场景视觉元素

- **教室**：整齐或略显散乱的课桌椅、黑板与粉笔灰、讲台、墙上成绩单/班规/学习园地、窗光与日光灯、课桌上的涂鸦刻字——教室是青春最日常的容器
- **图书馆自习室**：排列的书架、长桌与台灯、自习隔间、安静的氛围、翻旧的书页、窗外天光——静谧与专注的代名词
- **操场跑道与看台**：红色塑胶跑道、绿色人工草坪、看台台阶、体育器材、午后阳光下的长阴影——热血与张扬的舞台
- **宿舍上下铺**：双层铁架床、床帘、桌面台灯、衣物挂钩、洗漱用品、贴满海报的墙面、熄灯后的手机光——私密与青春的巢穴
- **食堂**：长桌长凳、餐盘餐具、菜品窗口、排队人流、暖调日光灯——烟火气的青春公共空间
- **林荫道**：两侧高大行道树（梧桐/银杏/樱花/香樟）、斑驳光影、单车停放、路过的学生——心动与邂逅的走廊
- **教学楼天台**：水泥地面、护栏、城市/校园天际线、夕阳——心事独白与青春告别的高处
- **社团活动室/实验室**：桌椅堆叠、社团道具（乐器/画具/球类）、实验台与器皿——兴趣与成长的小天地
- **校园小卖部**：货架零食饮料、冷柜、暖光、小窗——课间十分钟的快乐源泉

### 4.3 道具与细节元素

- **学习道具**：课本与教辅（封面有中文科目名）、笔记本（翻旧有手写笔记）、便利贴、签字笔与荧光笔、橡皮、圆规尺子、书包（双肩包为主）、准考证、奖状、成绩单

- **季节与校园元素**：春日樱花飘落/柳絮、夏日蝉鸣/雷阵雨、秋日银杏金黄、冬日呵气/校园初雪——季节感增强校园叙事的时间维度

## 五、严禁内容（优先级最高）

本风格严格排除以下内容类型，确保视觉体系纯净统一：

1. **非真人质感**：3D渲染/CG建模/次世代游戏引擎/动画风格/手绘插画/水彩油画/二次元/Voxel/低多边形等一切非真人实拍影像质感
2. **非校园世界观**：古风/古装/宫廷/传统中式古建/仙侠/玄幻/武侠/民国/职场成人都市CBD/乡村田园/西方奇幻/中世纪/赛博朋克/科幻未来/星际太空等一切非当代校园背景
3. **非当代中国语境**：明显非中国校园特征的建筑、校服、标识、人物造型（如日式水手服JK、韩式校服、欧美高中等非中国校园符号）
4. **技术质量缺陷**：低分辨率/模糊/噪点/变形/畸形肢体/五官扭曲/比例失调/抠图感/塑料感/过度磨皮/假面感
5. **审美倾向违规**：过度高饱和/死亡荧光色/廉价滤镜感/过度HDR/脏乱差画面/刻意阴间色调
6. **内容合规红线**：暴露/低俗/暗示性/暴力血腥/违法内容/歧视性表达/政治敏感元素

## 七、使用说明

### 提示词使用原则

1. **前缀先行**：所有生成内容必须首先加载"前缀提示词"中的全局风格锚定段，锁定真人校园青春写实质感基线
2. **专项叠加**：在全局前缀基础上，按需叠加角色/场景/道具/分镜专项提示词
3. **负面必加**：每次生成必须附带"负面提示词"，规避伪影与风格偏差
4. **迭代优化**：建议首轮生成后根据效果对专项提示词做微调，而非修改全局前缀
5. **平台适配**：本手册提示词优先适配Doubao-Seedream（生图）与Doubao-Seedance（视频生成），部分提示词可能需根据平台特性微调
