# 分镜提示词 · 真人校园青春 · 风格专属技法

---

## 适用范围

本 Skill 专用于**真人校园青春**风格的分镜提示词生成，适配校园日常、暗恋心动、操场热血、社团成长、毕业离别、宿舍夜话等真人实拍青春影视题材的分镜创作。

## 一、摄影机前的情绪——面孔、眼神、微表情

> 真人校园青春的情绪不来自"义体光效"或"渲染参数"，而来自真实少年少女在摄影机前的微表情。以下映射面向摄影机捕捉真实青春面孔的方式。

| 情绪输入 | 面容描述 | 眼神描述 | 微表情补充 |
|---|---|---|---|
| 专注 / 沉静 | 神情专注，面部放松不紧绷 | 眼神聚焦书本或板书，偶尔眨眼 | 嘴唇微抿或轻咬笔帽，可能托腮或拨发 |
| 暗恋 / 心动 | 眉眼微抬，面颊自然泛红 | 眼神偷偷望向TA，被发现后立刻闪开 | 嘴角不自觉微扬，手指无意识卷书页角 |
| 害羞 / 局促 | 面颊迅速泛红，面部微绷 | 眼神躲闪下垂，抬眼时清澈一瞬 | 嘴唇轻抿，可能咬下唇，手指攥紧衣角或笔 |
| 阳光 / 明朗 | 眼角出现自然笑纹，面部舒展 | 眼神明亮有光，眼角有笑意牵动 | 嘴角上扬露齿，面颊微红，表情生动不夸张 |
| 忧伤 / 落寞 | 眉眼低垂，面部肌肉松弛 | 目光涣散失焦，望向窗外或桌面 | 嘴角自然下沉，表情怅然，不刻意 |
| 冷淡 / 疏离 | 眉眼平直，面部线条偏冷 | 眼神清淡不聚焦，看向远方 | 唇线平直，下颌微收，气场疏离克制 |
| 热血 / 张扬 | 眉眼上扬，面部潮红（运动后） | 眼神锐利有光，注视有力 | 嘴角咧开，可能喘气，额头有汗 |
| 叛逆 / 桀骜 | 眉峰微挑，下颌微抬 | 眼神带不服与挑衅，注视直接 | 嘴角玩味微扬，可能嚼口香糖 |
| 期待 / 憧憬 | 眉眼微扬，面部有克制的小幅度活动 | 眼神发亮，瞳孔有光 | 嘴角微微上扬，面部有压抑的笑意 |
| 决绝 / 坚定 | 面部线条清晰，下颌微抬 | 眼神笔直向前，不回避不躲闪 | 下巴微收或微抬，表情果敢但不凶悍 |
| 疲惫 / 倦怠 | 眼窝微陷，面部整体松弛 | 目光朦胧，眼皮微沉 | 眉眼低垂，可能的黑眼圈，表情松弛 |
| 温柔 / 治愈 | 眉目舒展，面部柔和 | 眼神温润专注，像在认真听对方说话 | 嘴角自然微扬，不是笑，是有温度 |

## 二、摄影机前的光——光源逻辑与氛围

### 2.1 自然光时刻

| 时刻 | 光源行为 | 色温与色调 | 空间氛围 |
|---|---|---|---|
| 清晨早自习 | 低角度暖白日光，通过教室窗斜入；走廊阳光刚越过教学楼 | 3500-4500K暖白，空气微冷 | 静谧未醒、晨雾清冽、一天刚开始 |
| 上午课堂 | 日光升高，冷白清澈，阴影柔和；教室窗光面积最大；日光灯辅助 | 5000-6000K中性偏冷 | 秩序建立、日常运转、课堂清晰 |
| 正午 | 顶光或近乎顶光，阴影短而浓重；室外操场材质反光强 | 5500-6500K冷调 | 暂停感、午间空隙、午休空荡校园 |
| 午后 | 日光偏西，暖调渐强，斜光穿过教室窗或行道树形成长阴影和光斑 | 4000-5000K渐暖 | 慵懒、时间变慢、青春缓慢、午后诗意 |
| 金色时刻 | 极低角度暖金漫射，长阴影到极致，一切表面镀上金边 | 2800-3500K极暖 | 转瞬即逝的青春珍贵、心动回忆段落的唯一光源 |
| 蓝调时刻 | 太阳沉入地平线后，天空深蓝紫，自然光极暗极冷，日光灯/路灯刚刚亮起 | 8000-10000K天空+暖点人工光 | 过渡、诗意、晚自习前、心事萌动 |
| 晚自习 | 日光灯管冷白主光，窗外夜色深蓝，专注或孤独 | 日光灯5500-6500K / 窗外8000K+ | 备考、内省、专注或孤独、深夜奋斗 |
| 深夜 | 仅靠人工光源——宿舍小夜灯、台灯、手机屏光、校园路灯。大部分区域沉入暗部 | 暖点光源2800-3200K | 私密或心事、世界安静了 |

### 2.2 情绪光影

| 情绪基调 | 光线配方 | 摄影约束 |
|---|---|---|
| 教室日常 | 教室窗外天光漫射主光（5000-6000K）+ 日光灯辅助（4000-5500K），明亮通透 | 光比适中约1:2，保留空间纵深，窗框光影层次 |
| 午后慵懒 | 教室窗斜光（4000-5000K）+ 长阴影光斑穿过课桌，窗帘柔化 | 暖调渐强，斜光制造光斑，慵懒通透 |
| 暗恋心动 | 林荫道夕阳逆光（2800-3500K）穿过树叶，发丝镀金边，浅景深 | 逆光轮廓光，浅景深突出人物，光斑跳跃 |
| 图书馆静谧 | 台灯暖橙主光（2800-3200K），书架间幽暗有层次 | 暖调包裹，单点暖光源为主，暗部温暖有细节 |
| 操场热血 | 午后斜阳暖橙（3500-4500K），跑道红高饱和，长阴影 | 暖调主导，高饱和，光影分明，运动张扬 |
| 晚自习清寂 | 日光灯管冷白主光（5500-6500K）+ 窗外夜色深蓝（8000K+） | 冷调，光比约1:5，冷清专注或孤独 |
| 天台告别 | 低角度夕照暖金（2800-3500K）+ 蓝调天空过渡（8000-10000K） | 冷暖共存，光比约1:4，天空橙红渐变 |
| 宿舍夜话 | 单一小夜灯/手机屏光暖点（2800-3500K），大面积暗部 | 极简光源，孤岛式照明，光比约1:8，私密脆弱 |
| 冲突对峙 | 侧方硬光（窗光冷白或日光灯）+ 深阴影 + 冷暖对冲 | 大光比1:8以上，硬光勾勒轮廓，暗部压深但有细节 |

## 四、摄影机语法——镜头选择与运动

### 4.1 焦段选择

| 焦段 | 叙事性格 | 适用场景 |
|---|---|---|
| 24-28mm广角 | 环境包围人物，校园空间感，少年在天地间的渺小与希望 | 教室空镜、操场全景、林荫道纵深 |
| 35mm小广角 | 主观视点，身临其境的纪实感，少年与校园共存 | 课间走廊跟随、同桌对话、放学路上 |
| 50mm标准 | 人眼等价，客观中立的注视，最诚实的镜头 | 人物肖像、同桌对话、暗恋凝视 |
| 85mm中长焦 | 压缩空间，拉近情感距离，背景虚化突出人物 | 特写、偷偷注视、教室后排望向TA |
| 135mm+长焦 | 将人物从人群中剥离，极端的注视或窥视 | 教室里隔着一排排座位望向TA、毕业典礼远眺 |

### 4.2 景别选择

| 景别 | 取景范围 | 叙事功能 |
|---|---|---|
| 大特写 | 眼睛/嘴唇/手指/物件细节（笔尖/纸条/泪） | 情绪爆发点、关键信息揭示、感官聚焦 |
| 近景 | 头顶至胸部以上 | 人物情感、对话反应、面部微表情 |
| 中近景 | 头顶至腰部 | 人物互动、手势动作（递纸条/递奶茶）、对话中的身体语言 |
| 中景 | 头顶至膝盖上下 | 人物与空间的初级关系、多人同框 |
| 全景 | 人物全身+部分环境 | 人物在空间中的位置、行动路线 |
| 大全景/空镜 | 空间全貌，人物极小或无人物 | 空间叙事、情绪缓冲、隐喻留白 |

### 4.3 摄影机运动

| 运动方式 | 视觉心理 | 使用场景 |
|---|---|---|
| 固定 | 冷静观察，让青春自己说话 | 教室日常、自习、空镜留白 |
| 手持微晃 | 在场感，呼吸感，少年主观介入 | 课间追逐、走廊奔跑、情绪波动 |
| 稳定器流动 | 优雅的校园漫游，诗意 | 放学路上、林荫道、人物登场 |
| 缓推 | 注意力逐渐聚焦、情绪趋近 | 暗恋升温、心动逼近、注意力聚焦 |
| 缓拉 | 拉开距离、揭示全貌、情绪抽离 | 离别、毕业收束、空间展示 |
| 跟拍 | 与人物同行、主观陪同 | 放学行走、校园追踪、日常跟随 |
| 摇镜 | 视线转移、空间关系交代 | 视线引导（从黑板转向TA）、空间关系 |

## 五、固定风格锚定词

**摄影锚定（必选）：**

真人实拍摄影，真人电影剧照，当代中国校园，电影级摄影，自然光与日光灯调度，真实色彩科学

**人物质感（含人物镜头时必选）：**

真人写实摄影质感，真实青春皮肤纹理绒毛痘印可见，不磨皮不硅胶脸，发丝自然质感有碎发，校服面料纹理可见有穿着褶皱，自然少年微表情，真实肢体语言

**场景质感（含场景镜头时必选）：**

真人实拍校园场景摄影，真实校园建筑材质与学生痕迹（课桌涂鸦/粉笔灰/跑道磨损/墙面张贴），光源方向明确可追溯，大气透视自然，非样板学校非效果图

**参考图一致性锚定（参考图模式必选）：**

保持人物造型、面容、发型、校服与参考图完全一致，保持场景风格与参考图一致，保持光影色彩基调统一，所有镜头呈现为同一人物的连续摄影记录

**风格收尾（固定）：**

真人写实摄影，当代中国校园电影质感，电影级摄影画面，非3D非渲染非CG

**画质锁定词：**

## 六、美学禁止项

以下词汇/风格不得出现于输出提示词中：

- ❌ 3D渲染 / 3D建模 / CG / UE引擎 / Blender / PBR材质 / 次世代建模 / 体积光 / 环境光遮蔽 / 光线追踪
- ❌ 2D手绘 / 插画 / 动画 / 二次元 / 漫画 / Q版 / 低多边形
- ❌ 写实摄影（英文禁止 photorealistic / realistic photography——真人校园青春是"真人实拍摄影"live-action cinematic photography，不是"拟真渲染"）
- ❌ 过度磨皮 / 塑料假面 / 零毛孔 / 硅胶脸 / 蜡像感 / AI感平滑
- ❌ 古风 / 古装 / 汉服 / 宫廷 / 仙侠 / 武侠 / 民国 / 职场成人都市 / 乡村田园 / 赛博朋克 / 科幻 / 西方奇幻 / 中世纪
- ❌ 非中国校园符号——日式水手服JK / 韩式校服 / 欧美高中 / 架空异国校园
- ❌ 人体结构错误 / 肢体畸形 / 面部崩坏 / 比例失调 / 成人化浓妆
- ❌ 高饱和荧光色 / 霓虹溢色 / 廉价滤镜感 / 死亡芭比粉
- ❌ 非中国当代校园的架空场景 / 无中文标识的 generic school
