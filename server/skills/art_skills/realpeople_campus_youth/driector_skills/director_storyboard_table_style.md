# 分镜表真人校园青春约束 · 真人实拍校园青春 · 技法参考

## 一、分镜表定位

分镜表是导演将剧本转化为镜头语言的核心工具。本约束面向 Seedance 2.0 视频生成，所有光影、动作、空间描述均采用模型可执行的具象语言。不做抽象的情感概括，不写模型看不懂的渲染参数。

> 真人校园青春分镜表中所有描述必须遵守以下翻译原则——将"导演意图"翻译为"AI可执行的物理指令"。

## 三、光影与氛围——Seedance 2.0 物理光源描述

### 3.1 同场戏光影统一

一场戏内不应出现两种以上核心光影方案，除非有叙事驱动的光源变化（如有人打开台灯、上课铃后日光灯全亮、从教室走到天台）。光源变化必须在分镜表中标注触发事件。

### 3.2 光源语句法（每个镜头必须包含）
[光源] 主光：{光源类型}，{方向}，{色温值K}，{软硬}
[光源] 辅光/环境光：{光源类型}，{方向}，{色温值K}
[光比] 约1:{X}
### 3.3 情绪 → 光源矩阵

| 情绪 | 光源配方（Seedance 2.0 可直接填入） | 视觉关键词 |
|---|---|---|
| 教室日常 | 教室窗外天光漫射主光（5000-6000K）+ 日光灯辅助（4000-5500K）。光比约1:2 | 明亮通透、秩序日常 |
| 午后慵懒 | 教室窗斜光（4000-5000K）穿过窗与课桌形成长阴影光斑，窗帘柔化。光比约1:3 | 暖调渐强、光斑、慵懒 |
| 暗恋心动 | 林荫道夕阳逆光（2800-3500K暖金）穿过树叶，发丝镀金边，浅景深。光比约1:3 | 逆光轮廓、金边、心动 |
| 图书馆静谧 | 台灯暖橙主光（2800-3200K），书架间幽暗暗部保留书脊轮廓。光比约1:4 | 暖调包裹、静谧专注 |
| 操场热血 | 午后斜阳暖橙（3500-4500K）+ 跑道红高饱和，长阴影。光比约1:3 | 暖调高饱和、张扬热血 |
| 晚自习清寂 | 日光灯管冷白主光（5500-6500K）+ 窗外夜色深蓝（8000K+）。光比约1:5 | 冷调清寂、专注孤独 |
| 天台告别 | 低角度夕照暖金（2800-3500K）+ 蓝调天空过渡（8000-10000K）。光比约1:4 | 冷暖共存、橙红天空、离别 |
| 宿舍夜话 | 单一小夜灯/手机屏光暖点（2800-3500K），大面积暗部沉入深暗。光比约1:8 | 孤岛式照明、私密脆弱 |
| 冲突对峙 | 侧方硬窗光或日光灯（冷白5000-5500K）单光源，大光比约1:8，暗部深但有微弱轮廓 | 压抑、不确定、少年意气 |

### 3.4 冷暖色调与叙事阶段

- **冷光主导**（5000K+）：教室日常、晚自习备考、清寂独处、离别前夜
- **暖光主导**（2800-3500K）：暗恋心动、操场热血、图书馆静谧、金色时刻、宿舍夜话
- **冷暖共存**：天台告别（夕照暖金+蓝调天空）、晚自习（日光灯冷白+窗外深蓝）
- **光源变化 = 叙事信号**：窗外天空从午后暖白渐变至傍晚暖金=时间流逝；从教室日光灯冷白走到天台夕阳暖金=场景与情绪的切换；熄灯后日光灯灭→宿舍只剩小夜灯=私密时刻的开始

### 3.5 Seedance 2.0 光影适配要点

- 色温数字帮助模型校准白平衡倾向：`色温约3200K` 优于 `暖光`
- 光比数字帮助模型建立明暗意识：`光比约1:4` 优于 `柔和的阴影`
- 光源必须有明确来源：`从画面左侧教室窗45°斜入` 优于 `侧光`
- 环境光的反射路径描述：`红色跑道反射暖橙光到少年脸上` 优于 `脸上有暖色反光`

## 四、环境动态——让画面呼吸

### 4.1 动态密度

每 3-4 个镜头至少安排一个有环境动态的镜头。静态对话戏也不例外——至少有一个镜头里窗外的树叶在动、粉笔灰在斜光中飞舞、窗帘被微风吹动。

### 4.2 校园环境动态元素（Seedance 2.0 可执行）

| 场景 | 可描述的环境动态 |
|---|---|
| 教室 | 窗帘被微风轻鼓约10cm后回落（约2秒周期）、粉笔灰在斜射阳光中飘落、课桌上方日光灯管的极微弱闪烁、窗外操场远处有人跑过、讲台上老师的粉笔写字声 |
| 走廊 | 课间人群流动的低语与脚步、宣传栏纸张被风掀起一角、远处有人开关教室门、阳光穿过走廊窗在地面的光斑随时间缓慢移动 |
| 图书馆自习室 | 极轻的翻书声、空调出风口纸张被吹动、台灯光线被人经过时短暂遮挡、窗外云朵移动使室内明暗变化 |
| 操场 | 行道树叶片簌簌晃动、远处有人投篮球碰篮筐的声响、跑道边矿泉水瓶被风吹倒、午后阳光的角度随时间变化拉长影子 |
| 林荫道 | 树叶光斑在地面与校服上跳跃、落叶/樱花飘落的可见轨迹、单车从画面经过的轻响、夕阳逆光穿过树叶的光束变化 |
| 宿舍 | 上下铺铁架床翻身时的吱呀、走廊水房的水声、远处熄灯铃、手机屏幕在被窝里透出的微光晃动、风扇/空调的嗡鸣 |
| 天台 | 风声持续、远处城市/校园的微弱嗡鸣、晾衣绳衣物的飘动、天空中云朵缓慢移动、夕阳色温随时间渐变 |

### 4.3 Seedance 2.0 环境动态描述规范

- 动态必须有具体轨迹和速度：`树叶被风吹动，每秒约2-3次微幅晃动` 优于 `树在动`
- 光源动态与空间光源逻辑一致：`云朵遮住太阳时，教室窗光面积缩小约40%，持续约3秒后恢复`
- 禁止无来源的动态：室内没有开窗=没有风吹动窗帘。晚自习课间=走廊有人走动

## 五、人物动作节奏——Seedance 2.0 物理逻辑具象化

### 5.1 动作描述铁律

所有人物动作必须描述：**轨迹 + 速度/时长 + 身体部位协调 + 对周围物体的影响**。

### 5.2 校园日常动作具象库

| 动作 | Seedance 2.0 可执行描述 |
|---|---|
| 起立回答 | 双手撑住课桌边缘，椅子向后微移约10cm，膝盖伸直，0.5秒后身体站直，全程约1.5秒，站直后停顿约0.5秒看向老师 |
| 传纸条 | 右手将折好的纸条（约5cm宽）从课桌下方推向右侧同桌桌面，纸条滑过约30cm距离，同桌手指捏住——全程约1秒 |
| 转头看TA | 头缓慢向右旋转约30度，视线从黑板/课本移至斜前方那个人的侧脸，旋转过程约1秒，到位后瞳孔轻微聚焦停留约1秒 |
| 喝水 | 右手拿起课桌上的保温杯，杯口靠近嘴唇，仰头约15度，小口啜饮约1秒，杯口离开嘴唇后嘴角有一滴水珠——全程约2秒 |
| 投篮 | 双手持篮球于胸前，膝盖微屈蓄力，双臂上举将球推出，篮球沿抛物线飞向篮筐约3米，球碰篮筐——全程约1.5秒 |
| 翻书 | 右手拇指与食指捏住书页右下角，向左翻转约180度，纸页划过空气发出轻响，新页面停住——全程约0.8秒 |
| 放下笔 | 右手将笔从书写位置抬起约5cm，水平移动至笔记本上方，笔身横放，手指松开——全程约1秒 |
| 写板书 | 老师右手持粉笔在黑板书写，粉笔与黑板接触发出"吱吱"声，粉笔灰从字迹处落下，每写一个字约1秒 |
| 单车骑过 | 单车从画面左侧匀速骑过，速度约每秒3米，车轮碾过落叶，校服外套下摆被风吹起约20度，书包带在背后轻晃——经过画面约2秒 |
| 拥抱 | A向前迈出约0.5米，双臂环绕B的肩背，双手在B背部轻轻交叠，面部贴近B的耳侧，保持约3秒 |

### 5.3 动作节奏与叙事场景

- **日常叙事/文戏**：动作沉稳克制，每个微动作标注时长和轨迹。节奏舒缓——不是慢，是"不赶"（自习、课堂、走廊对话）
- **暗恋/心动场景**：动作细微含蓄。眼神偷望的来回、手指无意识的小动作（卷书页角/转笔/拨发）、面颊的泛红——用微动作传递情绪
- **操场/热血场景**：动作干脆利落有力量感，但仍有物理轨迹。运动动作须具体到"持篮球起跳，校服下摆扬起约30度"
- **冲突场景**：动作干脆，但仍有物理轨迹。推搡须具体到"右手推在对方左肩前方，对方重心向后偏移约20cm"
- 禁止：无叙事理由的快速动作堆砌、无物理逻辑的瞬移、"做了个手势"等含糊描述

### 5.4 服饰动态

真人校园校服的动态是画面的天然资产——不是"布料模拟参数"，而是"校服拉链外套的下摆被风吹起约20度角""马尾随跑步节奏左右轻摆约15cm""百褶裙摆随步伐轻摆""校服袖口挽起露出内搭"。在分镜表画面描述中标注服饰的动态细节。

## 六、空间逻辑具象化——Seedance 2.0 空间坐标系统

### 6.1 每镜头必须声明的空间信息
水平位置：画面左/中/右，或画面左侧三分之一处，或"靠窗倒数第二排"
纵深位置：距镜头{数值}米，前景/中景/背景
人物与场景的关系：距{固定物}{数值}米（距讲台/距窗/距黑板）
（若双人以上）人物A与B的相对距离和朝向
### 6.2 站位衔接示例
【片段A尾部】
A坐在靠窗倒数第二排的课桌前，距窗户约0.5米，侧脸朝窗，位于画面中央偏右，距镜头约3米。
午后阳光从画面右侧教室窗斜入（约4500K暖白）。
A右手持签字笔，笔尖距笔记本约2cm，正在书写。

【片段B开头】
A的右手刚从笔上松开，笔横放在笔记本上（位置变化约5cm）。A仍坐在原位（座位未变）。
窗外天色已从午后转为金色时刻——阳光色温暖化至约3200K，发丝边缘镀上金边。
黑板右侧的高考倒计时数字被夕阳镀上暖金边。
### 6.3 空间变化必须具象

| 抽象（禁止） | Seedance 2.0 具象 |
|---|---|
| 她走近TA | A从画面背景（距镜头约5米、教室后门位置）向镜头方向匀速行走4步（约3米），停在距TA约0.5米处——耗时约4秒 |
| 同桌面对面 | A位于画面中央偏左（距镜头约3米），B位于画面中央偏右（距镜头约3米），两人同桌，A在左B在右，相距约0.6米，A侧身约45度朝B |
| 从教室到天台 | A从教室（距镜头约3米）起身，走出教室后门，经过走廊楼梯（约耗时8秒），推开天台铁门（门向外开启约90度），右脚跨出门槛，进入天台——天台夕阳暖金光瞬间取代教室日光灯冷白光 |

## 七、运镜规范——Seedance 2.0 摄影机运动

### 7.1 允许的运镜

| 运镜 | Seedance 2.0 描述 | 适用场景 |
|---|---|---|
| 固定 | 摄影机固定不动，画面静止 | 教室对话、自习、空镜留白、情绪凝视 |
| 手持微晃 | 摄影机有轻微不规则晃动（幅度约±2cm），模拟手持拍摄的呼吸感 | 课间追逐、走廊奔跑、情绪波动、暗恋主观视角 |
| 稳定器流动 | 摄影机平滑匀速移动，无晃动 | 放学路上、林荫道、人物登场、校园漫游 |
| 缓推 | 摄影机向主体缓慢推进，推进速率约每秒0.3米 | 暗恋升温、心动逼近、注意力聚焦 |
| 缓拉 | 摄影机向后缓慢拉远，拉远速率约每秒0.3米 | 离别、毕业收束、揭示全貌 |
| 跟拍 | 摄影机与人物保持约2米距离同步移动 | 放学行走、校园追踪、林荫道跟随 |
| 摇镜 | 摄影机原地水平/垂直旋转 | 视线转移（从黑板转向TA）、空间关系交代 |

### 7.2 禁用运镜

- 无叙事目的的快速甩镜、急推急拉（推拉速率超过每秒1米）
- 超过3秒的剧烈手持晃动（除非主观受击/眩晕/奔跑叙事）
- 无逻辑花式转场——划屏、旋转、百叶窗、翻页等特效转场
- 摄影机无理由的360度旋转

### 7.3 真人校园青春运镜哲学

- 固定机位是第一选择——让观众看到真实的少年在真实校园里自然地存在
- 手持微晃在情绪段落使用——但晃动幅度不超过电影纪实风格的常规范围
- 运动镜头的起幅和落幅必须平稳，运动过程匀速——禁止突然加速或急停

## 八、转场规范

### 8.1 允许的转场方式

| 转场 | 视觉执行 | 叙事功能 |
|---|---|---|
| 硬切 | 直接切换 | 同场戏内镜头切换（默认） |
| 光影匹配转场 | 两个场景在相近光影逻辑下切换 | 时间流逝、平行叙事。例：A处教室窗的午后光 → B处林荫道的午后光 |
| 空间匹配转场 | 两个空间在构图或元素上呼应 | 场景跳转。例：教室门关上的瞬间 → 宿舍门推开的瞬间 |
| 空镜过渡 | 插入场景空镜（3-5秒） | 情绪缓冲、章节划分、时间流逝暗示 |
| 焦点转场 | 前镜焦点从主体移至背景，后镜从模糊背景中逐渐聚焦主体 | 空间切换、注意力的转移 |
| 声音转场 | 上下课铃/广播/环境音先行进入，画面随后切换 | 校园时间标识、强情绪转场 |

### 8.2 禁止的转场

- 纯视觉特效转场（翻页、划屏、百叶窗、马赛克）
- 无叙事逻辑的旋转/缩放转场
- 同一场戏内使用超过两种转场方式

## 九、音画同步规划（Seedance 2.0 专属）

### 9.1 环境音标注规范

每场戏标注 1-2 个核心环境音，写在分镜表的环境音列：

## 十一、空镜使用规范

### 11.1 空镜不是"没东西拍"

空镜是情绪容器。每个空镜必须有叙事目的和具体的视觉内容：

| 空镜类型 | 叙事目的 | 示例 |
|---|---|---|
| 场景建立 | 新空间首次出现——让观众看清楚这是什么校园角落 | 教室大全景：课桌排列、黑板、窗光、窗外操场 |
| 情绪缓冲 | 高情绪段落后的喘息 | 窗外樱花在风中飘落，速度约每秒一片经过画面 |
| 时间流逝 | 暗示时间过去了 | 同一扇教室窗外的天空从午后湛蓝渐变至金色时刻暖橙 |
| 隐喻留白 | 以物代情 | 课桌上摊开的笔记本，写满TA的名字，笔横放在上面 |
| 转场衔接 | 前后两个校园空间的自然过渡 | 走廊的日光灯管——前一场的教室，下一场是操场 |

### 11.2 空镜 Seedance 2.0 描述规范

空镜也必须遵循光源+质感+动态的描述铁律：午后窗光从右侧教室窗45°斜入（约4500K暖白），在空荡荡的课桌桌面上投下窗框光斑，
光斑随窗外云朵移动而缓慢变化宽度和位置，约5秒后完全变暗——一朵云挡住了太阳。
课桌桌面有历届学生刻的涂鸦与圆珠笔印记，桌角堆着翻旧的课本。

## 十二、分镜表质量自检清单

每场戏的分镜表完成后，导演逐项自检：

| 检查项 | 通过标准 |
|---|---|
| 光源可追溯 | 每个镜头能回答"光从哪儿来、什么色温"——窗光/日光灯/台灯/夕阳 |
| 动作可执行 | 每个动作有轨迹、时长、身体部位 |
| 空间可定位 | 每个镜头标注了人物的水平和纵深位置，及与课桌/窗/黑板的距离 |
| 站位移接 | 相邻镜头的同一个人位置/姿态可衔接 |
| 环境有动态 | 每3-4个镜头至少1个有校园环境动态（粉笔灰/窗帘/落叶/光斑移动） |
| 语气不空泛 | 无"她很美""气氛很好""很青春"等不可执行描述 |
| CG术语清零 | 无PBR/SSR/AO/体积光/次世代等CG词汇 |
| 校园元素到位 | 有中国校园辨识度——中文板书/校徽/校服/中文成绩单/课桌涂鸦 |
