# 真人校园青春场景图像生成 · 约束手册

---

## 一、场景美学原则

> 真人校园青春的场景不是"被建模的空间"，而是"被摄影机选中的真实校园角落"。没有渲染引擎、没有贴图、没有体积光参数——只有实际存在的日光（穿过教室窗）、实际的灯光（日光灯管/台灯）、以及中国校园的日常。

1. **空间即叙事** — 一间空无一人的教室不是"空的"，是刚下课。黑板上没擦净的板书、课桌上摊开的课本、椅背上挂着校服、地面掉落的粉笔头——空间自己会讲青春的故事
2. **真实的光，不是渲染的光** — 场景的光只有一个来源：实际的日光（通过教室窗、走廊窗）、实际的灯光（日光灯管、台灯、路灯）。光的色温和方向必须在物理上说得通
3. **被使用过的空间** — 真实的校园不整洁。课桌有涂鸦刻字、墙面有张贴痕迹、跑道有磨损、黑板有粉笔灰残留。一个完全没有学生痕迹的空间是样板学校，不是真人校园青春
4. **中国当代校园的真实场所** — 场景必须有中文标识、中国校园特征（中文成绩单/班规/校训/校徽/中文课本）。这不是"generic school"，这是"当代中国校园的一个具体角落"
5. **单视图全景全貌** — 一张照片装下整个场地的完整信息。广角或标准焦段，全景深，正面展示空间的全貌与纵深——不是四视图分割，不是多角度拼贴

## 二、季节与时刻——自然光的导演

> 真人校园青春场景的光，首先由季节和时刻决定。以下是真实光源在四个季节、五个时段的摄影行为。

| 季节 | 时段 | 光的行为 | 场景氛围词 |
|---|---|---|---|
| 春 | 清晨 6:00-8:00 | 低角度暖白日光、空气中有薄雾的漫射、教学楼表面柔和、樱花/新绿初绽 | 通透清冽、晨雾未散、早自习的安静、新学期 |
| 春 | 正午 11:00-13:00 | 日光近乎垂直、阴影短、建筑表面材质清晰、光线偏冷白 | 明亮清爽、春暖花开、课间操场 |
| 春 | 午后 14:00-16:00 | 日光偏西、暖调逐渐增强、斜光穿过窗和樱花树形成光斑 | 慵懒温暖、午后光影、林荫道心动 |
| 春 | 金色时刻 17:00-18:30 | 暖金低角度光、长阴影、一切表面镀金边、樱花在夕阳中飞舞 | 金色春光、放学路上、青春温柔 |
| 春 | 夜晚 19:00-次日 | 校园路灯为主、宿舍楼灯光为辅、晚自习教室日光灯 | 春夜微凉、晚自习窗光、夜色温柔 |
| 夏 | 清晨 5:00-7:00 | 极早的暖光、空气清澈、长阴影、校园尚未完全醒来 | 夏日晨光、空气清澈、早读前 |
| 夏 | 正午 11:00-14:00 | 顶光强、阴影浓重短促、跑道反光强烈、蝉鸣午后的寂静 | 盛夏烈日、浓荫蔽日、午休空荡校园 |

| 秋 | 清晨 6:30-8:00 | 清冷暖白日光、空气干燥通透、可能薄雾、银杏金黄枝叶 | 秋高气爽、晨光清冽、开学季金黄 |

## 三、室内场景

### 空间摄影规范

| 维度 | 摄影要求 | 提示词 |
|---|---|---|
| 风格 | 真实的中国当代校园室内空间——不是效果图、不是样板学校、不是渲染。是有学生生活痕迹的真实校园 | 真实的中国当代校园{空间类型}、真人实拍摄影、非效果图非样板间 |
| 光源逻辑 | 必须有明确的光源来源——教室窗光是哪个方向的窗、日光灯是否全亮、台灯在哪张桌上。光的方向和色温必须自洽 | {窗光方向}自然天光为主、{日光灯/台灯}为辅、光的方向明确可追溯 |
| 空间层次 | 单张全景照片必须呈现前/中/后景——前景（门框/课桌边缘/窗帘/书架）形成画框感、中景是空间主体、后景是空间延伸（窗外操场/走廊尽头/另一排书架） | 前景{画框元素}、中景{空间主体}、后景{空间延伸}、广角镜头捕捉完整空间纵深 |
| 材质与表面 | 课桌有涂鸦刻字与圆珠笔印记、墙面有张贴痕迹与污渍、黑板有粉笔灰与半擦板书、地面有自然磨损——一切材质呈现在摄影机下，非渲染 | 课桌涂鸦刻字、墙面张贴痕迹、黑板粉笔灰残留、地面磨损、非全新非样板学校 |
| 镜头选择 | 24-28mm广角——装下整个空间的广度、前景到后景的纵深全部清晰（全景深 f/8-f/11）、轻微桶形畸变增加空间感 | 广角24-28mm、全景深f/8-f/11、空间纵深完整、轻微透视增加空间感 |

## 五、单视图全景摄影规范

> 真人校园青春场景仅需**单张**全景摄影——一张照片装下整个空间的完整信息。不是2×2四视图，不是多角度拼接。

### 画面构成

| 项目 | 摄影要求 |
|---|---|
| 空间呈现 | 单张照片完整呈现场景的空间全貌。使用24-28mm广角或35mm，全场地的纵深、宽度、高度在一张画面中全部可见 |
| 构图 | 全景深大景别——前景（门框/课桌/护栏/树木/窗框）形成天然画框→中景是场地主体→后景向空间纵深或窗外/天际线延伸 |
| 景深 | 全景深 f/8-f/11，从前到后全部清晰。这不是人像摄影——场景的每一个角落都应该能被看见 |
| 人物 | **严禁出现任何人物、人影、人体轮廓。** 场景是空的——但这种"空"有叙事：刚下课/即将上课/晚自习前/人去楼空/日常的静止瞬间 |
| 比例 | 建议 16:9 或 3:2 宽幅——匹配全景空间展示的横向视觉习惯 |
| 色彩 | 由实际光源的色温驱动，不套滤镜。色彩科学参考ARRI Alexa/Sony Venice电影色调 |

### 空的场景如何叙事

| "空"的类型 | 画面线索 | 叙事暗示 |
|---|---|---|
| 刚下课 | 黑板上没擦净的板书、课桌上摊开的课本、椅背上挂着校服、地面掉落的粉笔头 | 刚才这里满座学生，现在都走了 |
| 即将上课 | 课桌椅整齐、黑板擦干净只剩日期、讲台放着教案、窗外阳光打在第一排 | 马上要上课，现在是开始前的静止 |
| 人去楼空 | 毕业后的空教室、课桌上残留的涂鸦刻字、墙上揭掉海报的痕迹、地面积尘的轮廓 | 曾经有人在这里读书，现在已经毕业了 |
| 日常的静止 | 课桌上摊着的笔记本与笔、窗台上的盆栽、窗外操场的光打在地板上 | 校园的常态、只是此刻没有人入镜 |
| 晚自习前/后 | 教室日光灯已亮但无人、或熄灯后只剩窗外月色、黑板上的倒计时 | 备考的紧张、或一天结束的安静 |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须是**单张**全景摄影——单视图、非2×2四视图、非多角度、非turnaround |
| R2 | 必须使用广角镜头（24-28mm）或标准焦段（35mm），全景深 f/8-f/11，完整空间纵深 |
| R3 | 光源必须可追溯——自然光的方向与时刻匹配、日光灯/台灯/路灯的位置和色温合理 |
| R4 | 场景必须有前/中/后景空间层次，前景画框→中景主体→后景延伸 |
| R5 | 必须有中国当代校园辨识度——中文成绩单/班规/校训/校徽/中文课本/中国校园建筑 |
| R6 | 必须有学生使用痕迹——课桌涂鸦/墙面张贴痕迹/跑道磨损/黑板粉笔灰、非样板学校非全新非效果图 |
| R7 | **严禁出现任何人物、人影、人体轮廓、剪影** |
| R8 | 必须声明"真人实拍摄影 + 非3D渲染非CG"核心锚定 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 严禁「3D渲染 / 3D建模 / CG / UE引擎 / Blender / PBR材质 / 体积光 / AO」等一切CG术语 |
| X2 | 严禁「2D手绘 / 插画 / 动画 / 二次元」等非摄影媒介 |
| X3 | 严禁「四视图 / 2×2网格 / 多角度 / turnaround / orthographic view / blueprint」——仅单张 |
| X4 | 严禁「古风/古代/宫廷/仙侠/武侠/民国/职场成人/乡村田园/赛博朋克/科幻/西方奇幻/异世界」等非校园场景 |
| X5 | 严禁「无中国辨识度的架空校园 / 日式JK校园 / 韩式校园 / 欧美高中 / 全英文标识」 |
| X6 | 严禁「出现任何人物/人影/人体轮廓/剪影/肢体」 |
| X7 | 严禁「样板学校/售楼处式效果图/全新无痕/完美品相/无学生痕迹」的场景 |
| X8 | 严禁「光源来源不明/全局均匀照明/无方向的光」 |
| X9 | 严禁「过曝死白/暗部死黑/无景深/画面扁平」 |
| X10 | 严禁「水印 / 文字 / LOGO / 签名 / 边框 / AI生成痕迹」 |
