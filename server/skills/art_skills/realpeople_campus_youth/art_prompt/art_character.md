# 真人校园青春人物基础形象生成 · 约束手册

## 一、选角逻辑——摄影机前的少年

> 3D角色的起点是"建一个模型"；真人校园青春的起点是"选一个少年/少女站在摄影机前"。以下原则不从建模出发，而从选角和拍摄出发。

1. **面孔即青春** — 一张少年的脸就是一部尚未写完的青春故事。真人校园青春不追求"完美的五官"，而追求"值得被注视的青春面孔"——有辨识度的不对称、有故事感的微瑕疵（青春痘印/小痣/绒毛）、能被摄影机凝视的面孔
2. **学生感优先于明星感** — 校园叙事需要的是"看起来像你同班同学的人"，而非"看起来像刚从杂志封面走下来的人"。素颜状态下的真实青春面容优先于精致妆造
3. **体态说真话** — 真实的少年站姿不是对称的——重心偏一条腿、肩膀微斜、可能还带着一点学生式的含胸或懒散。杜绝模特式对称站姿和军人式立正体态
4. **同一人物跨角度可辨认** — 正面/侧面/背面/特写四角度必须呈现为同一个人的摄影记录，而非四个相似的人。核心识别点：颌骨轮廓、鼻梁转折、耳廓形状、发际线走向

## 七、基础服装——被穿过的那件校服

> 真人校园青春的基础服装不是"打底款"，而是"挂在课桌椅背上、穿过一整个学期、有身体记忆的那件校服"。

### 女性基础服装

中国当代校园基础校服：运动校服套装（拉链外套+长裤，藏蓝/红白/灰白拼色，涤纶面料，校徽刺绣于胸口）或 制服校服（白色衬衫+藏蓝百褶裙/西裤+领结/领带+西装外套，校徽于左胸）。面料可见自然纹理（涤纶的光泽与柔软、棉质衬衫的微皱、百褶裙的压褶痕迹）。校服有"穿过"的痕迹：袖口磨损、膝盖处拉伸纹理、领口微变形、洗过多次的柔软。无时尚品牌标识（除校徽/年级标识外），无装饰性设计。

### 男性基础服装

中国当代校园基础校服：运动校服套装（拉链外套+长裤，藏蓝/红白/灰白拼色，涤纶面料，校徽刺绣于胸口）或 制服校服（白色衬衫+藏蓝西裤+领带+西装外套，校徽于左胸）。面料可见自然纹理（涤纶的光泽与柔软、棉质衬衫的微皱、西裤膝盖处的拉伸纹理）。校服有"穿过"的痕迹：袖口磨损、膝盖处鼓包、领口微变形、洗过多次的柔软。无时尚品牌标识（除校徽/年级标识外），无装饰性设计。

### 着装统一规则

- 基础服装是真实的中国当代校园校服——运动校服套装或制服校服，是学生身份的核心标识
- 校服有"穿过"的痕迹：洗过多次的柔软、袖口/领口/膝盖处磨损、有学生的身体记忆
- 覆盖范围：除面部/颈部/手部外基本覆盖，校园合规着装覆盖度，无过度裸露
- 四角度服装款式、颜色、质地完全一致，呈现为同一件校服在不同角度下的摄影记录
