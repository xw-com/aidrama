## 二、摄影机语法（替代"渲染引擎"）

> 真人校园青春不依赖渲染管线。画面品质取决于摄影机的选择、镜头的性格、光线的调度。以下为"摄影机语法"核心参数。

### 2.1 画幅与格式

| 参数 | 基准值 | 美学意图 |
|---|---|---|
| 影像格式 | 35mm胶片质感 / 全画幅数字摄影 | 浅景深能力、自然的暗角过渡、微妙的颗粒结构——青春题材的胶片感尤其珍贵 |
| 色彩科学 | ARRI Alexa / Sony Venice 类电影色彩科学 | 青春肤色还原自然、高光滚降柔和、暗部不压死且有层次 |

### 2.2 镜头性格

| 焦段 | 叙事性格 | 典型应用 |
|---|---|---|
| 24-28mm（广角） | 环境包围人物、校园空间感、少年在天地间的渺小与希望 | 教室空镜、操场全景、林荫道纵深的校园 |
| 35mm（小广角） | 主观视点、身临其境、纪实感 | 课间走廊跟随、同桌对话、放学路上 |
| 50mm（标准） | 人眼等价、客观注视、不美化不扭曲 | 人物肖像、同桌对话、暗恋凝视 |
| 85mm（中长焦） | 压缩空间、拉近情感距离、背景虚化突出人物 | 特写、偷偷注视、操场对面远远望见那个TA |
| 135mm+（长焦） | 极端压缩、窥视感、将人物从人群中剥离 | 教室里隔着一排排座位望向TA、毕业典礼远眺 |

### 2.3 机位与运动

| 手法 | 视觉心理 | 使用场景 |
|---|---|---|
| 固定机位 | 冷静、观察、让青春自己说话 | 教室日常、自习、空镜留白 |
| 手持微晃 | 在场感、呼吸感、少年视角的主观介入 | 课间追逐、走廊奔跑、情绪波动 |
| 斯坦尼康/稳定器 | 优雅流动、校园漫游的诗意 | 放学路上、林荫道、人物登场 |
| 俯拍 | 命运感、渺小、回忆视角 | 校园俯瞰、毕业回望、堆满课桌的教室 |
| 仰拍 | 崇高或青春的英雄感 | 操场跳跃、天台仰望天空、少年力量感 |
| 焦点偏移（Rack Focus） | 注意力的转移、关系的改变 | 同桌对视时焦点的游移、揭示隐藏的心事 |

## 三、校园色谱——光与材料的真实色彩

> 真人校园青春的色彩来自中国校园真实的光与材料，不是引擎色板。以下色盘提取自：教室日光灯与窗外天光、操场跑道的塑胶红、黑板未擦净的粉笔灰、林荫道斑驳的树影、宿舍熄灯后的小夜灯。

| 光源 | 色温（K） | 光色描述 | 校园场域 |

| 教室上午天光 | 5500-6000 | 冷白清澈，窗外天光为主、日光灯辅助，阴影柔和 | 教室日常、上午的课、窗光打在课桌上 |
| 正午顶光 | 6000-6500 | 冷硬强光，阴影短而浓重，人物眼眶/下颌出现深影 | 操场正午、食堂、午间空荡的校园——需谨慎使用 |

## 四、全局约束规则

### 4.1 影像真实性约束（必守）

| 编号 | 规则 |
|---|---|
| P1 | 必须以「真人摄影 / 真人实拍 / 真人电影剧照」为生成锚——画面必须读作"摄影机拍下的"，而非"计算机生成的" |
| P2 | 必须指定一个具体的光源逻辑：这场戏的光从哪里来？（窗/日光灯/台灯/天光/夕阳）光源方向、色温、软硬须自洽 |
| P3 | 必须保留人物青春皮肤的真实质感——绒毛、细纹、青春期痘印、痣、自然肤色不均——杜绝塑料磨皮与AI感假面 |
| P4 | 发丝必须呈现自然状态——被风吹乱、扎起后散落的碎发、运动后贴在额前的湿发、逆光中的碎金色轮廓——杜绝建模感整齐发块 |
| P5 | 校服/服饰必须体现"穿过"的痕迹——洗过多次的柔软、面料褶皱、领口变形、膝盖/手肘拉伸纹理——杜绝全新出厂样板衣感 |
| P6 | 场景必须有"被使用过"的证据——黑板粉笔灰、课桌涂鸦刻字、跑道磨损、墙面张贴痕迹——杜绝样板学校 |
| P7 | 人物必须处于自然体态——真实的站姿（重心偏一侧）、不刻意的少年表情（非全脸对称笑容）、日常的学生动作 |
| P8 | 必须指定一个具体的当代中国校园空间——拒绝"generic school"或任何无国别标识的架空校园 |

### 4.2 摄影品质约束（必守）

| 编号 | 规则 |
|---|---|
| Q1 | 必须声明一种摄影机的"在场方式"：固定注视 / 手持呼吸 / 稳定器流动 / 长焦窥视 |
| Q2 | 景深必须具有叙事意图——浅景深突出情绪、深景深强调环境、焦点偏移引导注意力 |
| Q3 | 高光不得过曝死白，暗部不得死黑无层次——保留高光滚落和阴影细节是电影感的基础 |

### 4.4 风格越界判定

> 当你生成的画面出现以下任一信号，说明已经偏离真人校园青春风格：

| 越界信号 | 说明 |
|---|---|
| 少年皮肤像硅胶 | 磨皮过度，失去青春质感——立即停用"光滑""完美肌肤"类词汇，加入绒毛/细纹/痘印 |
