## 四、全局约束规则

### 4.1 影像真实性约束（必守）

| 编号 | 规则 |
|---|---|
| P1 | 必须以「真人摄影 / 真人实拍 / 真人电影剧照」为生成锚——画面必须读作"摄影机拍下的"，而非"计算机生成的" |
| P2 | 必须指定一个具体的光源逻辑：这场戏的光从哪里来？（窗/煤油灯/钨丝灯/霓虹/天空）光源方向、色温、软硬须自洽 |
| P3 | 必须保留人物皮肤的真实质感——毛孔、细纹、痣、自然肤色不均——杜绝塑料磨皮与AI感假面 |
| P4 | 发丝必须呈现自然状态——手推波纹有发油光与碎发、长辫有自然毛躁、被风吹乱、被雨打湿——杜绝建模感整齐发块 |
| P5 | 服饰必须体现"穿过"的痕迹——丝绸自然垂坠与褶皱、织锦缎光泽受光、棉布起皱、领口自然变形——杜绝全新样板衣感 |

| P7 | 人物必须处于自然体态——真实的站姿（重心偏一侧）、不刻意的表情（非全脸对称笑容）、符合年代礼仪的手部动作 |
| P8 | 必须指定一个具体的民国年代中国空间——老上海外滩、石库门弄堂、洋行公馆、百乐门、火车站、教会学校等——拒绝"generic period"或任何无国别标识的架空年代 |
