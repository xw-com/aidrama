# 真人民国年代场景图像生成 · 约束手册

---

## 一、场景美学原则

> 真人民国年代写实的场景不是"被建模的影视城"，而是"被摄影机选中的民国真实场所"。没有渲染引擎、没有贴图、没有体积光参数——只有民国年代实际存在的光、真实的材料、以及那个时代中国城市的日常。

1. **空间即叙事** — 一个空无一人的公馆客厅不是"空的"，是刚送完客。一把歪放的太师椅、一盏未熄的铜台灯、留声机上还转着的唱片——空间自己会讲故事
2. **真实的光，不是渲染的光** — 场景的光只有一个来源：实际的日光（通过天井、高窗、百叶门）、实际的实用光源（煤油灯、钨丝吊灯、铜台灯、霓虹招牌、舞厅灯球）。光的色温和方向必须在物理上说得通
3. **被使用过的空间** — 真实的民国场景不整洁。青砖墙有水渍与青苔、木楼梯有踩踏磨损、月份牌有泛黄卷翘、煤油灯罩有烟熏、地面水磨石有污渍。一个完全没有岁月痕迹的空间是影视城刚搭好的样板，不是真人民国年代写实
4. **民国年代中国的真实场所** — 场景必须有民国年代中国特征（青砖石库门、外滩新古典建筑、月份牌、煤油灯、留声机、有轨电车、黄包车、中文招牌与洋文行号）。这不是"generic period"，这是"民国年代中国的一个具体角落"
5. **单视图全景全貌** — 一张照片装下整个场地的完整信息。广角或标准焦段，全景深，正面展示空间的全貌与纵深——不是四视图分割，不是多角度拼贴

## 五、单视图全景摄影规范

> 真人民国年代写实场景仅需**单张**全景摄影——一张照片装下整个空间的完整信息。不是2×2四视图，不是多角度拼接。

### 画面构成

| 项目 | 摄影要求 |
|---|---|
| 空间呈现 | 单张照片完整呈现场景的空间全貌。使用24-28mm广角或35mm，全场地的纵深、宽度、高度在一张画面中全部可见 |
| 构图 | 全景深大景别——前景（门框/屏风/太师椅/铜台灯/晾衣竹竿/窗框）形成天然画框→中景是场地主体→后景向空间纵深或窗外/天际线延伸 |
| 景深 | 全景深 f/8-f/11，从前到后全部清晰。这不是人像摄影——场景的每一个角落都应该能被看见 |
| 人物 | **严禁出现任何人物、人影、人体轮廓。** 场景是空的——但这种"空"有叙事：刚送完客/即将开场/人去楼空/日常的静止瞬间 |
| 比例 | 建议 16:9 或 3:2 宽幅——匹配全景空间展示的横向视觉习惯 |
| 色彩 | 由实际光源的色温驱动，不套滤镜。色彩科学参考ARRI Alexa/Sony Venice电影色调，整体略偏暖黄年代底色 |

### 空的场景如何叙事

| "空"的类型 | 画面线索 | 叙事暗示 |
|---|---|---|
| 刚送完客 | 太师椅没推回原位、茶几上留一盏未熄的铜台灯、留声机唱片还在转、茶杯里茶半凉 | 刚才有人在这里，现在走了 |
| 即将开场 | 椅子摆好、桌面整洁、煤油灯已点亮、月份牌已挂好、留声机待播 | 有人马上要来，现在是开始前的静止 |
| 人去楼空 | 搬离后的公馆、墙上挂画留下的印记、月份牌停在旧日期、地面积尘的轮廓、蛛网 | 曾经有人住过，现在已经走了 |
| 日常的静止 | 沙发上的绸缎披肩随意搭着、书桌上摊开的家书、窗外斜光打在水磨石地面 | 生活的常态、只是此刻没有人入镜 |
| 深夜的场所 | 空荡的弄堂只有煤油街灯亮着、报馆排版间的孤灯、月台上最后一盏信号灯 | 城市睡着了、但空间还醒着 |
| 乱世痕迹 | 一扇打碎的花窗、倒地的太师椅、散落的家书、未熄的煤油灯 | 刚发生过什么、逃难或搜查 |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须是**单张**全景摄影——单视图、非2×2四视图、非多角度、非turnaround |
| R2 | 必须使用广角镜头（24-28mm）或标准焦段（35mm），全景深 f/8-f/11，完整空间纵深 |
| R3 | 光源必须可追溯——自然光的方向与时刻匹配、实用光源（煤油灯/钨丝灯/霓虹）的位置和色温合理 |
| R4 | 场景必须有前/中/后景空间层次，前景画框→中景主体→后景延伸 |
| R5 | 必须有民国年代中国辨识度——青砖石库门/月份牌/煤油灯/留声机/中文招牌洋文行号/外滩建筑 |
| R6 | 必须有岁月痕迹——青砖水渍/木楼梯磨损/月份牌泛黄/煤油灯罩烟熏/水磨石污渍、非影视城样板非全新非效果图 |
| R7 | **严禁出现任何人物、人影、人体轮廓、剪影** |
| R8 | 必须声明"真人实拍摄影 + 非3D渲染非CG"核心锚定 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 严禁「3D渲染 / 3D建模 / CG / UE引擎 / Blender / PBR材质 / 体积光 / AO」等一切CG术语 |
| X2 | 严禁「2D手绘 / 插画 / 动画 / 二次元 / 国风水彩插画」等非摄影媒介 |
| X3 | 严禁「四视图 / 2×2网格 / 多角度 / turnaround / orthographic view / blueprint」——仅单张 |
| X4 | 严禁「现代当代都市/古风古代/仙侠/武侠/宫廷/赛博朋克/科幻/西方奇幻/异世界」等非民国年代场景 |
| X5 | 严禁「无民国年代辨识度的架空年代场景 / 现代穿帮元素（智能手机/现代汽车/现代招牌/现代服饰）」 |
| X6 | 严禁「出现任何人物/人影/人体轮廓/剪影/肢体」 |
| X7 | 严禁「影视城刚搭好的样板景/售楼处效果图/全新无痕/完美品相/无岁月痕迹」的场景 |
| X8 | 严禁「光源来源不明/全局均匀照明/无方向的光」 |
| X9 | 严禁「过曝死白/暗部死黑/无景深/画面扁平」 |
| X10 | 严禁「现代水印 / 现代文字 / LOGO / 签名 / 边框 / AI生成痕迹」（画面中年代招牌/月份牌/站牌等道具文字除外） |
