# 真人民国年代道具图像生成 · 约束手册

---

## 一、道具设计原则

> 真人民国年代写实的道具不是"被建模的器物"，而是"被使用过的民国物品"——它在某个名媛手里待过、在某张红木桌上放过、在某件马褂口袋里装过。摄影机拍下的是它的此刻。

1. **物品即叙事** — 每一件道具都是一个微型的叙事容器。怀表表壳的氧化暗示用了许多年、月份牌的卷翘暗示翻阅过无数次、煤油灯罩的烟熏暗示点亮过许多个夜晚
2. **使用痕迹优先于完美品相** — 真人民国年代写实的道具必须有"被用过"的证据。全新出厂的、刚拆封的、样板级别的道具一律不出现
3. **民国年代中国真实物品** — 道具必须是民国年代中国真实存在的器物：银元/法币、月份牌、留声机与黑胶唱片、煤油灯、铜台灯、拨盘电话、钢笔信笺、旗袍盘扣、玉佩——拒绝无年代辨识度的架空物品
4. **材质即真实** — 不是PBR参数渲染出的材质，而是摄影机拍下的真实材质行为：黄铜的氧化包浆、丝绸的光泽、青花的釉面、纸制品的吸光、老玻璃的微绿断面
5. **单视图静物摄影** — 道具以单张静物产品摄影方式独立呈现，非多角度建模展示，非2×2四宫格

## 三、单视图静物摄影规范

> 真人民国年代写实道具仅需单张静物产品摄影，非多角度建模展示。以下为单视图摄影的完整规范。

### 画面构成

| 项目 | 摄影要求 |
|---|---|
| 道具呈现 | 道具居中或偏三分线位置独立陈列，完整入画，无裁切 |
| 背景 | 米白宣纸色无缝背景纸 #EDE6D3（哑光，带轻微纸纹），或深色硬木桌面（红木/胡桃木本色），根据道具属性选择。无多余物体、无装饰、无现代文字 |
| 光线 | 自然窗光或单灯柔光，色温略偏暖（约3800-4200K）。窗光45°侧入（明亮柔和带自然阴影）、或柔光箱顶+侧补（产品摄影级均匀光线）。光影柔和、方向明确、无硬阴影 |
| 景深 | 浅景深（f/2.8-f/5.6），道具主体清晰锐利，前后微虚化突出主体 |
| 投影 | 道具底部与承载面之间的自然接触阴影——真实的而非抠图或悬浮。阴影柔软、方向与主光源一致 |
| 画面比例 | 建议 1:1 正方形或 4:3，适配单件道具展示 |

### 道具状态准则

| 维度 | 要求 |
|---|---|
| 使用痕迹 | 必须有"被使用过"的视觉证据——非全新未拆封、非样板品相 |
| 年代辨识度 | 中文标识/民国招牌/月份牌美人图/银元法币/民国器物造型——拒绝无年代辨识度的架空物品 |
| 材质真实感 | 非渲染质感——是摄影机拍下的真实材料行为（光的反射、漫射、透射、氧化） |
| 尺度感 | 通过材质纹理密度、工艺细节暗示实物尺寸，无需参照物 |

## 六、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须是「单张静物摄影」——单视图、非多角度、非2×2四宫格、非建模展示 |
| R2 | 必须指定「米白宣纸色背景纸 #EDE6D3」或「深色硬木桌面（红木/胡桃木本色）」等真实承载面，禁止复杂场景 |
| R3 | 必须指定光源逻辑——窗光或柔光箱（色温约3800-4200K偏暖），光影方向明确、投影自然 |
| R4 | 道具必须有「使用痕迹」——非全新、非样板品相、非未拆封 |
| R5 | 道具必须具备民国年代中国辨识度——中文招牌/月份牌/银元法币/民国器物造型 |
| R6 | 必须声明「实物产品摄影 + 非3D渲染非CG」核心锚定 |
| R7 | 材质必须描述为摄影机下的真实表现（氧化/包浆/泛黄/磨损），而非渲染参数 |
