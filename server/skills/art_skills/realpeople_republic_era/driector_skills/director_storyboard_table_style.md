## 一、分镜表定位

分镜表是导演将剧本转化为镜头语言的核心工具。本约束面向 Seedance 2.0 视频生成，所有光影、动作、空间描述均采用模型可执行的具象语言。不做抽象的情感概括，不写模型看不懂的渲染参数。

## 三、光影与氛围——Seedance 2.0 物理光源描述

### 3.1 同场戏光影统一

一场戏内不应出现两种以上核心光影方案，除非有叙事驱动的光源变化（如有人点亮煤油灯、鎏金时刻后天光暗过室内灯、从公馆走到外滩）。光源变化必须在分镜表中标注触发事件。

### 3.2 光源语句法（每个镜头必须包含）
[光源] 主光：{光源类型}，{方向}，{色温值K}，{软硬}（火光/钨丝灯须注明"火苗微颤/灯丝微颤"）
[光源] 辅光/环境光：{光源类型}，{方向}，{色温值K}
[光比] 约1:{X}

### 3.4 冷暖色调与叙事阶段

- **冷光主导**（5000K+）：名媛清冷（部分）、悬疑紧张、清冷独处、雨夜月台
- **暖光主导**（2200-3500K）：温情亲密、市井烟火、鎏金高光、舞厅浮华、书桌密谈
- **冷暖共存**：过渡时刻（蓝调时刻+初亮煤油/钨丝灯）、雨夜（冷环境+暖光斑）、舞厅（灯球冷暖光斑）
- **光源变化 = 叙事信号**：窗外天空从日间冷白渐变至鎏金暖金=时间流逝；从公馆煤油暖光走到雨夜黛蓝街灯下=场景与情绪的切换；点亮煤油灯=夜幕降临/密谈开始

### 3.5 Seedance 2.0 光影适配要点

- 色温数字帮助模型校准白平衡倾向：`色温约2400K煤油火光` 优于 `暖光`
- 光比数字帮助模型建立明暗意识：`光比约1:4` 优于 `柔和的阴影`
- 光源必须有明确来源：`从画面右侧百叶窗45°斜入` 优于 `侧光`
- 火光/钨丝灯须注明动态：`煤油灯火苗微颤` / `钨丝灯丝微颤`——以区别于CG静态光
- 环境光的反射路径描述：`湿石板路反射街灯暖黄光斑` 优于 `地面有暖色反光`

## 四、环境动态——让画面呼吸

### 4.1 动态密度

每 3-4 个镜头至少安排一个有环境动态的镜头。静态对话戏也不例外——至少有一个镜头里百叶窗光斑在移动、青花瓷茶杯口的热气在升腾、丝绒窗帘被微风鼓动。

| 石库门弄堂 | 晾衣竹竿上的衣物被风吹动、煤炉生烟袅袅升起、远处有黄包车叮当驶过、小贩叫卖声传来、晾衣水滴落青砖地 |

### 4.3 Seedance 2.0 环境动态描述规范

- 动态必须有具体轨迹和速度：`煤油灯火苗每秒约2-3次微颤` 优于 `灯在动`
- 光源动态与空间光源逻辑一致：`云朵遮住太阳时，百叶窗光斑缩小约40%，持续约3秒后恢复`
- 禁止无来源的动态：没有风吹=丝绒窗帘不动。室内没有开窗=没有风。煤油灯未点燃=没有火苗

## 五、人物动作节奏——Seedance 2.0 物理逻辑具象化

### 5.1 动作描述铁律

所有人物动作必须描述：**轨迹 + 速度/时长 + 身体部位协调 + 服饰动态 + 对周围物体的影响**。

### 5.2 民国年代日常动作具象库

| 动作 | Seedance 2.0 可执行描述 |
|---|---|
| 起身离太师椅 | 双手撑住太师椅扶手，膝盖向前移动，0.5秒后身体重心前移至双脚，再1秒后站直，旗袍下摆自然垂落——全程约2秒，站直后停顿约0.5秒 |
| 转头望向百叶窗外 | 头缓慢向右旋转约30度，视线从桌上的家书移至百叶窗外，旋转过程约1秒，到位后目光停在远处约1秒 |
| 端茶递客 | 右手持青花瓷茶壶壶柄，壶嘴倾斜约30度，深红茶水注入青花瓷杯，液面从杯底上升至杯身三分之二处，全程约3秒，蒸汽从杯口缓缓升起 |
| 走向窗前 | 从太师椅起身（约2秒），向画面右侧百叶窗匀速行走约4步（约3米距离，耗时约3秒），旗袍下摆随步伐左右轻摆约10cm，停在距窗约0.5米处 |
| 落座 | 身体前倾微屈膝，臀部接触太师椅椅面，红木椅面下压约1cm，背部自然靠向椅背，旗袍后摆自然铺开——全程约1.5秒 |
| 放下茶杯 | 右手持青花瓷杯从胸前高度下降至红木茶几，杯底与红木茶几接触发出轻微碰撞声，手指从杯身松开——全程约1秒 |

| 看怀表 | 右手从马褂口袋取出黄铜怀表（约6cm直径），拇指轻按表盖弹簧扣，表盖弹开，眼睛微眯聚焦表盘——全程约3秒 |
| 撑油纸伞 | 左手持油纸伞柄从身侧抬起举过头顶，右手将伞面推开的竹条撑骨依次撑开，伞面水珠抖落，油纸伞面完全撑开——全程约4秒 |
| 拥抱 | A向前迈出约0.5米，双臂环绕B的肩背，双手在B背部轻轻交叠，旗袍袖口贴合B的西装肩线，面部贴近B的耳侧，保持约3秒 |

### 5.3 动作节奏与叙事场景

- **日常叙事/文戏**：动作沉稳克制，每个微动作标注时长和轨迹。节奏舒缓——不是慢，是"不赶"
- **情绪波动场景**：动作幅度和速度略微增加。人物可能在对话中不自觉地加快摩挲玉镯的频率、呼吸带动旗袍立领下的肩膀起伏更明显
- **冲突场景**：动作干脆利落，但仍有物理轨迹。推搡/抓握须具体到"右手推在对方左肩前方，对方重心向后偏移约20cm，马褂领口被扯歪"
- 禁止：无叙事理由的快速动作堆砌、无物理逻辑的瞬移、"做了个手势"等含糊描述

### 5.4 服饰动态

民国服饰的动态是画面的天然资产——不是"布料模拟参数"，而是"旗袍下摆被转身带起约20度角""长衫下摆踩到微尘""织锦缎袖口随端茶动作垂落""油纸伞面被风吹歪约15度"。在分镜表画面描述中标注服饰的动态细节。

## 六、空间逻辑具象化——Seedance 2.0 空间坐标系统

### 6.1 每镜头必须声明的空间信息
水平位置：画面左/中/右，或画面左侧三分之一处
纵深位置：距镜头{数值}米，前景/中景/背景

（若双人以上）人物A与B的相对距离和朝向
### 6.2 站位衔接示例
【片段A尾部】
旗袍名媛A立于公馆百叶窗前，距窗约0.5米，面朝窗外，位于画面中央偏右，距镜头约4米。
窗外为午后鎏金时刻的外滩天际线，阳光从画面右侧百叶窗斜入。
A右手持青花瓷茶杯于胸前，杯子距嘴唇约15cm。
旗袍下摆自然垂落，立领贴合颈线。

【片段B开头】
A的青花瓷茶杯刚从嘴边下降约10cm，杯子仍在胸前位置。A仍立于百叶窗前（位置未变）。
窗外天色已转为蓝调时刻——天空深蓝紫，外滩建筑轮廓灯与街灯已亮起。
室内铜台灯已开（画面左侧红木书桌），暖白偏黄光（约2800K）照在A的左侧脸颊。

## 七、运镜规范——Seedance 2.0 摄影机运动

### 7.1 允许的运镜

| 运镜 | Seedance 2.0 描述 | 适用场景 |
|---|---|---|
| 固定 | 摄影机固定不动，画面静止 | 公馆对话、书桌独白、空镜留白、情绪凝视 |
| 手持微晃 | 摄影机有轻微不规则晃动（幅度约±2cm），模拟手持拍摄的呼吸感 | 情绪波动、弄堂奔走、月台离别跟随、主观视角 |
| 稳定器流动 | 摄影机平滑匀速移动，无晃动 | 洋场漫游、舞厅穿梭、人物登场、空间展示 |
| 缓推 | 摄影机向主体缓慢推进，推进速率约每秒0.3米 | 情绪升温、真相逼近、注意力聚焦 |
| 缓拉 | 摄影机向后缓慢拉远，拉远速率约每秒0.3米 | 离别、收束、揭示全貌 |
| 跟拍 | 摄影机与人物保持约2米距离同步移动 | 弄堂行走、月台跟随、黄包车追踪 |
| 摇镜 | 摄影机原地水平/垂直旋转 | 视线转移、舞厅环视、月台扫视 |

### 7.2 禁用运镜

- 无叙事目的的快速甩镜、急推急拉（推拉速率超过每秒1米）
- 超过3秒的剧烈手持晃动（除非主观受击/眩晕/逃乱叙事）
- 无逻辑花式转场——划屏、旋转、百叶窗、翻页等特效转场
- 摄影机无理由的360度旋转

### 7.3 真人民国年代写实运镜哲学

- 固定机位是第一选择——让观众看到真实的人在真实的民国空间里自然地存在
- 手持微晃在情绪段落使用——但晃动幅度不超过电影纪实风格的常规范围
- 运动镜头的起幅和落幅必须平稳，运动过程匀速——禁止突然加速或急停

## 八、转场规范

### 8.1 允许的转场方式

| 转场 | 视觉执行 | 叙事功能 |
|---|---|---|
| 硬切 | 直接切换 | 同场戏内镜头切换（默认） |
| 光影匹配转场 | 两个场景在相近光影逻辑下切换 | 时间流逝、平行叙事。例：A处百叶窗鎏金光 → B处弄堂鎏金光 |
| 空间匹配转场 | 两个空间在构图或元素上呼应 | 场景跳转。例：公馆门关上的瞬间 → 月台门打开的瞬间 |
| 空镜过渡 | 插入场景空镜（3-5秒） | 情绪缓冲、章节划分、时间流逝暗示 |
| 焦点转场 | 前镜焦点从主体移至背景，后镜从模糊背景中逐渐聚焦主体 | 空间切换、注意力的转移 |
| 声音转场 | 前场声音延续到后场画面（如留声机唱片沙沙声、钟声） | 情绪延续、隐喻连接 |

### 8.2 禁止的转场

- 纯视觉特效转场（翻页、划屏、百叶窗、马赛克）
- 无叙事逻辑的旋转/缩放转场
- 同一场戏内使用超过两种转场方式

## 十一、空镜使用规范

### 11.1 空镜不是"没东西拍"

空镜是情绪容器。每个空镜必须有叙事目的和具体的视觉内容：

| 空镜类型 | 叙事目的 | 示例 |
|---|---|---|
| 场景建立 | 新空间首次出现——让观众看清楚这是什么地方 | 公馆客厅大全景：太师椅、百叶窗、留声机、红木茶几、月份牌 |
| 情绪缓冲 | 高情绪段落后的喘息 | 花窗玻璃上雨滴沿裂痕滑落，速度约每秒2cm |
| 时间流逝 | 暗示时间过去了 | 同一扇百叶窗外的天空从午后湛蓝渐变至蓝调深紫 |
| 隐喻留白 | 以物代情 | 红木茶几上半杯没喝完的茶，杯口有胭脂印 |
| 转场衔接 | 前后两个空间的自然过渡 | 公馆走廊的铜台灯——前一场的客厅，下一场是书房 |
| 年代符号 | 强化年代沉浸 | 月份牌上的民国美人图与日期、留声机转动的黑胶唱片、外滩钟楼 |

### 11.2 空镜 Seedance 2.0 描述规范

空镜也必须遵循光源+质感+动态的描述铁律：午后鎏金光从画面右侧百叶窗45°斜入（约3200K），在空荡荡的红木会议桌上投下百叶窗的条纹光斑，
光斑随窗外云朵移动而缓慢变化宽度和位置，约5秒后完全变暗——一朵云挡住了太阳。
红木桌面有细微划痕和茶杯圈痕，铜台灯有氧化包浆。
