## 四、摄影机语法——镜头选择与运动

### 4.1 焦段选择

| 焦段 | 叙事性格 | 适用场景 |
|---|---|---|
| 24-28mm广角 | 时代吞噬人物，乱世空间疏离感，十里洋场宏大与个体渺小 | 外滩空镜、月台离散、舞厅全景、弄堂纵深 |
| 35mm小广角 | 主观视点，身临其境的纪实感，人与时代环境共存 | 弄堂行走、公馆对话、黄包车穿行 |
| 50mm标准 | 人眼等价，客观中立的注视，最诚实的镜头 | 人物肖像、双人对话、旗袍名媛凝视 |
| 85mm中长焦 | 压缩空间，拉近情感距离，背景虚化突出人物 | 特写、隔街远望、留声机旁的歌女 |
| 135mm+长焦 | 将人物从乱世中剥离，极端的注视或窥视 | 外滩中隔离的个体、远眺、叙事的距离感 |

### 4.2 景别选择

| 景别 | 取景范围 | 叙事功能 |
|---|---|---|
| 大特写 | 眼睛/嘴唇/手指/旗袍盘扣/怀表链/钢笔尖 | 情绪爆发点、关键信息揭示、感官聚焦 |
| 近景 | 头顶至胸部以上 | 人物情感、对话反应、面部微表情 |
| 中近景 | 头顶至腰部 | 人物互动、手势动作、对话中的身体语言 |
| 中景 | 头顶至膝盖上下 | 人物与空间的初级关系、多人同框 |
| 全景 | 人物全身+部分环境 | 人物在空间中的位置、旗袍/长衫全貌 |
| 大全景/空镜 | 空间全貌，人物极小或无人物 | 空间叙事、情绪缓冲、隐喻留白 |

### 4.3 摄影机运动

| 运动方式 | 视觉心理 | 使用场景 |
|---|---|---|
| 固定 | 冷静观察，让时间自己说话 | 公馆对话、书桌独白、空镜留白 |
| 手持微晃 | 在场感，呼吸感，主观介入 | 情绪波动、弄堂奔走、月台离别跟随 |
| 稳定器流动 | 优雅的洋场漫游，诗意 | 百乐门登场、舞厅穿梭、外滩过渡 |
| 缓推 | 注意力逐渐聚焦、情绪趋近 | 对话升温、真相逼近、情感推进 |
| 缓拉 | 拉开距离、揭示全貌、情绪抽离 | 离别、章节收束、空间展示 |
| 跟拍 | 与人物同行、主观陪同 | 弄堂行走、月台跟随、城市追踪 |
| 摇镜 | 视线转移、空间关系交代 | 人物视线引导、舞厅环视、月台扫视 |

## 五、固定风格锚定词

**摄影锚定（必选）：**

真人实拍摄影，真人电影剧照，1920s–1940s 民国年代中国，电影级摄影，自然光与实用光源（煤油灯/钨丝灯/霓虹）调度，真实色彩科学

**人物质感（含人物镜头时必选）：**

真人写实摄影质感，真实皮肤纹理毛孔可见，不磨皮不硅胶脸，年代薄粉之下仍见真人皮肤，发丝自然质感有碎发（手推波纹/油头/盘发），服饰面料纹理可见有穿着褶皱（丝绸/织锦缎/棉布/呢绒），自然微表情，符合年代礼仪的真实肢体语言

**场景质感（含场景镜头时必选）：**

真人实拍民国年代场景摄影，真实年代材质和岁月痕迹（青砖水渍/木楼梯磨损/月份牌泛黄/煤油灯罩烟熏/水磨石污渍），光源方向明确可追溯，大气透视自然，略偏暖黄年代底色，非影视城样板非效果图

保持人物造型、面容、发型、服饰与参考图完全一致，保持场景风格与参考图一致，保持光影色彩基调统一，所有镜头呈现为同一人物的连续摄影记录

## 六、美学禁止项

以下词汇/风格不得出现于输出提示词中：

- ❌ 3D渲染 / 3D建模 / CG / UE引擎 / Blender / PBR材质 / 次世代建模 / 体积光 / 环境光遮蔽 / 光线追踪
- ❌ 2D手绘 / 插画 / 动画 / 二次元 / 漫画 / Q版 / 低多边形 / 国风水彩插画
- ❌ 写实摄影（英文禁止 photorealistic / realistic photography——真人民国年代写实是"真人实拍摄影"live-action cinematic photography，不是"拟真渲染"）
- ❌ 过度磨皮 / 塑料假面 / 零毛孔 / 硅胶脸 / 蜡像感 / AI感平滑
- ❌ 现代当代都市 / 古风古装汉服 / 仙侠 / 武侠 / 宫廷 / 赛博朋克 / 科幻 / 机甲 / 西方奇幻 / 中世纪
- ❌ 现代穿帮元素：智能手机、现代汽车、现代品牌、现代发型、现代服装、现代建筑等
- ❌ 人体结构错误 / 肢体畸形 / 面部崩坏 / 比例失调
- ❌ 高饱和荧光色 / 霓虹溢色泛滥 / 廉价复古滤镜感（如做旧棕褐/茶色预设）
- ❌ 非民国年代中国的架空场景 / 无年代辨识度的 generic period
