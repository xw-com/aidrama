# 真人民国年代题材视觉手册 · 风格说明

本手册专为"真人民国年代写实"题材视觉创作打造，所有美术提示词、视觉规范和生成内容严格限定于真人实拍级民国年代（1920s–1940s 中国）影视美学体系。

## 一、风格核心定义

**真人民国年代写实**是以**真人影视摄影美学**为基准、以**民国年代（1920s–1940s）中国**为核心的视觉风格体系。其核心特征为：

- **真人写实摄影质感**：以真人影视级摄影为锚点，画面呈现真实人物的皮肤纹理、毛发细节、微表情与肢体语言，杜绝3D建模感、CG渲染感、手绘感
- **民国年代世界观**：所有场景严格限定于民国年代中国空间——老上海租界外滩、石库门弄堂、洋行公馆、百乐门舞厅、火车站月台、教会学校、报馆、老式药房；时代符号如旗袍马褂、长衫、黄包车、电车、留声机、月份牌、煤油灯
- **电影级摄影语言**：以院线级年代真人电影摄影为基准，强调自然光与实用光源（煤油灯、钨丝灯、霓虹）的有机调度、构图叙事的专业性、景深与焦点的情绪表达、色彩分级的电影感
- **年代人文厚度感**：在保持专业影像品质的前提下，强调民国年代的生活质感、面料与建筑材质的岁月痕迹、乱世浮生中的真实人情温度

### 创作理念与核心价值

本手册的核心创作理念为 **"真实即力量"**：

1. **真实感的审美回归**：在AI生成影像日趋泛滥的当下，真人写实质感以其不可替代的真实力量，成为最具情感穿透力的视觉语言。肌肤的纹理、眼神的温度、丝绸的褶皱、煤油灯穿过发丝的碎影——这些真实细节构成了一种生命质感，是3D渲染无法复刻的审美深度。

2. **民国年代的叙事容器**：民国年代是中国影像最具戏剧张力的叙事空间之一。外滩十里洋场的浮华、石库门弄堂的市井、百乐门的灯红酒绿、火车站月台的离散、报馆里的家国——民国空间本身就是一个巨大的叙事容器，等待被挖掘。

3. **人本主义的视觉立场**：本手册坚持以"人"为核心。无论时代多么动荡、光影多么绚丽，最终回归到人物的情感状态与内心世界。每一帧画面都是一次对乱世之中人性的注视。

4. **电影与年代的真实平衡**：寻求"电影的精致"与"年代的真实"之间的微妙平衡——画面足够美、足够专业、有电影感，但不过度精致而失去年代厚重感；人物足够真实、足够生动，但不过度随意而失去审美品质。

**核心价值：**

- 为AI视觉创作者提供一套系统化、可复用的真人民国年代题材提示词方法论
- 建立从概念到成品的标准化视觉创作管线
- 降低真人民国年代题材AI视觉创作的技术门槛与试错成本
- 填补当前AI视觉创作领域"真人民国年代题材系统化方法论"的空白

## 三、视觉风格定位

### 3.1 整体风格定位

**"电影级真人写民国年代美学"**

以民国年代中国为叙事舞台，以真人影视摄影为技术锚点，追求院线级年代电影的画面品质与审美高度。整体风格在"电影感"与"年代厚重感"之间寻找黄金平衡——画面精致但不空洞，真实但不随意，审美在线但不炫技。

### 3.2 影像质感层级

| 质感维度 | 定位标准 |
|---|---|
| **皮肤质感** | 真人摄影级，可见自然的皮肤纹理、毛孔、细纹、痣斑，杜绝过度磨皮与塑料感 |
| **毛发质感** | 发丝根根分明，自然蓬松或垂落，受光面与背光面层次清晰，杜绝僵硬发块；手推波纹、低盘发、长辫须呈现真实的发油光与碎发 |
| **衣物质感** | 面料纹理可辨（丝绸的光泽垂坠、棉布的肌理、呢绒的绒感、织锦缎的纹路、毛料的厚实），褶皱符合身体动态与重力；旗袍的盘扣、马褂的对襟、长衫的下摆皆有真实垂坠 |
| **环境质感** | 石库门砖墙有岁月水渍、木楼梯有踩踏磨损、月份牌有泛黄卷翘、煤油灯罩有烟熏痕迹，杜绝"全新道具感" |
| **光影质感** | 自然光与实用光源（煤油灯、钨丝灯、霓虹）有机调度，杜绝生硬的反差与不自然的噪点，追求电影级色彩科学 |

## 四、关键视觉元素

### 4.1 人物视觉元素

真人民国年代题材的人物视觉以**"真实个体、年代气质"**为核心：

- **面容标准**：真人肌肤质感，五官自然立体，妆容符合民国年代审美（柳叶眉、复古红唇、细挑眼线）且不过度现代修饰。支持多元面容类型——清冷名媛、温婉闺秀、干练女学生、沧桑军阀、热血文人、世故买办等
- **发型标准**：民国年代典型发式，发丝自然质感，杜绝假发感与僵硬造型。女性：手推波纹、低盘发、及肩卷、长辫、双麻花；男性：三七/中分油头、平头、军帽、礼帽
- **服饰标准**：民国年代着装体系——旗袍（立领盘扣、织锦缎、素色棉布）、马褂、长衫、中山装、学生装、军阀军装、西装三件套、洋裙、歌女舞台装。面料纹理清晰，褶皱自然
- **表情与体态**：微表情真实细腻（眼神、嘴角、眉宇），肢体语言符合年代礼仪与角色身份，杜绝现代T台感与过度戏剧化表情
- **人物气质维度**：清冷高门 / 温婉闺秀 / 干练新女性 / 热血爱国 / 沧桑世故 / 浮华迷离 / 市井质朴 / 文人风骨

- **外滩十里洋场**：汇丰银行等新古典主义建筑、江海关钟楼、外白渡桥、黄浦江轮船烟囱、霓虹招牌、有轨电车、黄包车——洋场繁华天际线

- **教会学校**：拱形窗、木质课桌、黑板、十字架、长廊、校服、拉丁文课本——新旧交汇的教育空间

## 五、严禁内容（优先级最高）

本风格严格排除以下内容类型，确保视觉体系纯净统一：

1. **非真人质感**：3D渲染/CG建模/次世代游戏引擎/动画风格/手绘插画/水彩油画/二次元/Voxel/低多边形等一切非真人实拍影像质感
2. **非民国年代世界观**：现代当代都市、古风/古装/仙侠/武侠/宫廷、赛博朋克/科幻/机甲、西方奇幻/中世纪、星际太空等非民国年代背景
3. **非民国年代语境**：明显非民国年代特征的建筑、街道、标识、人物造型（如智能手机、现代汽车、当代发型等明显穿帮元素）
4. **技术质量缺陷**：低分辨率/模糊/噪点/变形/畸形肢体/五官扭曲/比例失调/抠图感/塑料感/过度磨皮/假面感
5. **审美倾向违规**：过度高饱和/死亡荧光色/廉价滤镜感/过度HDR/脏乱差画面/刻意阴间色调
6. **内容合规红线**：暴露/低俗/暗示性/暴力血腥/违法内容/歧视性表达/政治敏感元素

## 七、使用说明

### 提示词使用原则

1. **前缀先行**：所有生成内容必须首先加载"前缀提示词"中的全局风格锚定段，锁定真人民国写实质感基线
2. **专项叠加**：在全局前缀基础上，按需叠加角色/场景/道具/分镜专项提示词
3. **负面必加**：每次生成必须附带"负面提示词"，规避伪影与风格偏差
4. **迭代优化**：建议首轮生成后根据效果对专项提示词做微调，而非修改全局前缀
5. **平台适配**：本手册提示词优先适配Doubao-Seedream（生图）与Doubao-Seedance（视频生成），部分提示词可能需根据平台特性微调
