# 分镜表水墨动画约束 · 水墨动画风格 · 技法参考

---

## 一、分镜表定位

分镜表是导演将剧本转化为镜头语言的核心工具。以下仅提供水墨动画风格在分镜表层面的约束规范。

---

## 二、墨色光影与氛围

- **墨色光影统一** — 一场戏内墨色方案（A 宣纸清透 / B 烟雨氤氲 / C 晨雾透光 / D 月色淡墨 / E 雪霁空明 / F 焦墨点睛 / G 朱砂落款）必须保持一致，墨色浓淡即明暗（禁止黑色硬阴影、禁止CG式硬光直射），除非有明确的叙事转折（如晨雾 C 渐变为月色 D = 日转夜）
- **情绪墨色绑定** — 每场戏至少绑定 1 个情绪场景（文人雅集/隐逸山林/牧笛田园/烟雨江南/禅意古寺/侠客寒林/悲戚离别等），并在镜头组内保持主墨色+辅墨色连续性，墨色取自核心墨盘（焦墨黑 #2A2A2A / 浓墨 #4A4A4A / 淡墨灰 #8A8A8A / 宣纸白 #F2EDE0 / 朱砂印 #A83232 / 青绿点缀 #6E8A6A）
- **墨色浓淡角度规范** — 正给镜头默认留白受光 + 淡墨晕影，侧给镜头根据画面需要调整墨色浓淡方向。描述光影时须区分正给/侧给的角度差异，墨色浓淡过渡始终保持手绘水墨笔意
- **浓淡叙事与阶段匹配** — 文人雅集/牧笛田园段落使用淡墨为主（淡墨 + 宣纸白 + 大面积留白）；侠客寒林/悲戚离别段落使用焦墨 + 枯笔飞白 + 大面积虚；禅意古寺段落使用淡墨 + 留白晨雾；烟雨江南段落使用湿润淡墨晕染 + 留白雨雾。朱砂红仅在大婚/落款/封印处极小面积出现
- **墨色转场是高级手段** — 从晨雾 C 渐变到月色 D = 日转夜的时间流逝；从宣纸清透 A 渐变到焦墨点睛 F = 情绪由淡转浓。在分镜表中标注墨色变化点，转场过程中墨色必须晕化平滑渐变，禁止色块断层
- **手绘水墨光效** — 允许合理使用水墨晕化虚化、空气透视（近浓远淡）、景深墨色过渡等水墨技法，但必须保持手绘水墨笔意的美学基调，禁止 3D 写实/CG 渲染光效（3D写实渲染、CG动画渲染、照片级真实感等非水墨光效一律禁用）

---

## 三、环境动态

- **环境动态增加画面呼吸感** — 云雾流动、水波荡漾、墨色晕化、衣袂飘逸、落叶飘零、雪片飘落、鹤影掠空。每 3-4 个镜头至少安排一个有环境动态的镜头，避免画面"死"掉
- **水墨环境元素优先** — 环境动态应选用水墨世界观内的元素：流云、烟雨、墨晕、涟漪、落叶、飞絮、飘雪、鹤唳、烛火摇曳、纱帐轻飘，禁止出现现代元素
- **水墨动态质感** — 环境动态元素（云雾/水波/墨晕等）必须保持手绘水墨笔意与皴擦点染质感，运动须"水墨晕化"式渐进（如墨色在宣纸上洇开），禁止 3D 粒子特效或写实流体效果
- **留白会"呼吸"** — 留白区域并非死寂，运镜时留白可随视角微微流动（如云雾在留白处缓缓漫开），增强气韵生动感

---

## 四、水墨动作节奏

- **动作优雅且带笔意** — 人物动作默认缓慢优雅、含蓄内敛，如笔锋提按般有起收。文人/仕女/老僧起身、转身、抬手应标注"缓慢/优雅/含蓄"；侠客可在关键帧做焦墨枯笔式的凌厉处理（如挥剑的飞白残影）
- **服饰动态是核心画面资产** — 水墨服饰（宽袖、裙摆、披帛、飘带）的飘动是天然的动态资产，可在画面描述中加入衣袂/裙摆/飘带的动态，水墨渲染下的服饰飘动应以行云流水描呈现、线条清晰、墨色浓淡分明
- **泼墨发动态** — 水墨人物的头发以泼墨成块呈现，回眸/行走时泼墨发的飞白飘动是水墨动画的标志性动态，可重点标注
- **仪态约束** — 水墨人物的举止应符合古典文人气质：行走稳缓、举手投足含蓄内敛、不出现现代化的肢体语言（如耸肩、摊手）。可在微表情上以焦墨眉眼微调表达情绪，但肢体动作仍需古典克制
- **头身比一致** — 动作设计中角色必须保持 6-7 头身的水墨古典比例，禁止因动态姿势而破坏头身比
- **减笔写意原则** — 远景人物可用减笔写意（几笔点出形神），近景人物须笔意完整。动作幅度越大越要减笔，避免线条堆积破坏气韵

---

## 五、材质与质感约束

- **手绘水墨笔意为锚** — 所有镜头中人物/服饰/道具/场景的渲染必须保持手绘水墨笔意，焦墨勾骨、浓墨成块、淡墨晕肉、皴擦点染、留白意境，禁止 3D 写实/CG 动画/照片级渲染/平涂卡通
- **服饰材质** — 丝绸/纱/麻以衣纹描法（行云流水描/铁线描/减笔描）表现，纹理必须超清晰，衣纹线条清晰，墨色浓淡分明
- **道具材质** — 木竹用皴擦、玉石用淡墨晕润留白、瓷用留白温润、金属用焦墨枯笔勾轮廓，均以手绘水墨笔意呈现，禁止写实材质渲染
- **场景材质** — 山石用皴法（披麻/斧劈/雨点/米点）、树木用点叶/点苔、木面有皴擦岁月痕、石面有苔点斑驳，材质带有岁月感但以水墨笔意呈现，禁止"塑料感"的全新无瑕材质
- **宣纸纤维质感** — 所有画面底层带宣纸纤维质感纹理，增强手绘水墨的物质真实感

---

## 六、色彩约束

- **核心墨盘锁定** — 分镜表中所有镜头的色彩必须取自核心墨盘（C1-C6），黑白灰墨色为绝对主体（画面占比 ≥ 95%），宣纸底色色相偏移容差 ±5°、明度偏移 ±8%，墨色浓淡偏移容差 ±1 级
- **点缀色克制** — 朱砂印 C5 与青绿点缀 C6 全画面占比严禁超过 3%，单点缀 ≤ 1%。朱砂仅用于落款印章、大婚点唇、信物封印；青绿仅用于苔点、远树、竹叶
- **禁止全彩** — 严禁全彩浓艳画面/高饱和彩色插画/平涂卡通色块/荧光色/霓虹色出现
- **线条颜色** — 焦墨黑 #2A2A2A，须有飞白与枯润变化，禁止纯黑僵硬描边
- **阴影色** — 墨色浓淡过渡（浓墨/重墨），禁止黑色硬阴影
- **整体色温** — 漫射天光偏中性 5800-6200K，对比度中低 35-55%，饱和度极低 5-15%，留白比例 30-50%

---

## 七、运镜禁忌

- **禁用快速运镜** — 甩镜、急推、手持晃动与水墨动画的优雅诗意冲突。水墨动画首选长卷式横移（如卷轴展开）、缓推、缓拉、慢摇。侠客对决场景可适度加快运镜节奏但仍需保持画面清晰
- **禁用花式转场** — 划屏、旋转、百叶窗等与本风格不兼容。水墨转场应使用墨色晕化、留白流转、淡墨渐隐等"水墨式"转场
- **禁用写实镜头语言** — 手持摇晃/纪录片式跟拍/鱼眼镜头等与水墨美学冲突，破坏手绘笔意的画面纯净感
- **禁用CG镜头光效** — 镜头光晕、镜头畸变等CG镜头语言一律禁用，保持宣纸般的纯净画面

---

## 八、转场禁忌

- **禁用硬切对撞** — 两个高墨色浓度镜头直接硬切会破坏气韵，应通过留白空镜或淡墨渐隐缓冲
- **禁用彩色渐变转场** — 水墨转场只能用墨色浓淡渐变（淡入淡出、墨晕扩散、留白渐显），禁用彩色叠化/闪光转场
- **推荐转场手段** — 墨色晕化转场（墨色如宣纸洇开）、留白流转转场（一片留白渐显新场景）、长卷横移转场（镜头横移如展开新画卷）、空镜过渡（飞鹤/孤舟/云雾等水墨空镜做情绪缓冲）、朱砂落款转场（段落收尾以朱砂印章式定格转入下一段）
