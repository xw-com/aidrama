# 水墨动画约束 · 水墨动画风格 · 技法参考

---

## 一、墨色体系与画面基调

- **墨色基底** — 全片以核心墨盘为基底：焦墨黑（C1 #2A2A2A）、浓墨（C2 #4A4A4A）、淡墨灰（C3 #8A8A8A）、宣纸白（C4 #F2EDE0）、朱砂印（C5 #A83232）、青绿点缀（C6 #6E8A6A）。整体以黑白灰墨色为绝对主体（画面占比 ≥ 95%），整体色温偏中性漫射天光（5800-6200K），饱和度极低（5-15%），呈现文人画清雅淡远的水墨画面
- **墨分五色叙事** — 焦（C1）→ 浓（C2）→ 重（C1 与 C2 过渡）→ 淡（C3）→ 清（C3 极薄晕近宣纸白）。五色构成全部"明暗层级"，对应其他风格的高光、中间调、阴影。墨色浓淡的切换应与故事弧线同步：情节沉郁则墨色浓重、情节清远则墨色淡润、情节爆发则焦墨点睛
- **浓淡分配策略** — 文人雅集/田园牧歌段落使用淡墨为主（淡墨 + 宣纸白 + 大面积留白）；烟雨江南/竹林清幽段落使用湿润淡墨晕染 + 留白雨雾；侠客寒林/悲戚离别段落使用焦墨 + 枯笔飞白 + 大面积虚；禅意古寺段落使用淡墨 + 留白晨雾 + 极简笔墨；雪山寒林段落使用大面积留白 + 淡墨寒林
- **墨色先行原则** — 段落规划需先绑定情绪场景（文人雅集/隐逸山林/牧笛田园/烟雨江南/禅意古寺/侠客寒林/悲戚离别等），再确定主墨色+辅墨色与留白比例，避免"剧情对了但墨色不对"
- **点缀色克制原则** — 朱砂印 C5 与青绿点缀 C6 全画面占比严禁超过 3%，单点缀 ≤ 1%。朱砂仅用于落款印章、大婚典礼点唇、信物封印、极小面积点睛；青绿仅用于苔点、远树、竹叶极小点缀。禁止彩色铺满、禁止全彩画面
- **禁用色域** — 高饱和荧光色、霓虹色、重彩画、平涂卡通色块均与本风格不兼容。宣纸底色色相偏移容差 ±5°、明度偏移 ±8%，墨色浓淡偏移容差 ±1 级

## 二、墨色光影方案体系

> **核心准则**：水墨风格"光影即墨色浓淡"，不存在彩色冷暖光。光 = 留白与淡墨，影 = 浓墨与焦墨。下列 7 套方案以"墨色浓度+留白比例+晕染干湿"定义画面基调。

- **墨色光影即叙事** — 7 套墨色光影方案对应不同情绪段落，导演规划阶段应在段落层面确定墨色基调方向，而非逐镜指定
- **手绘笔意为锚** — 所有方案必须保持水墨动画笔意，焦墨勾骨、浓墨成块、淡墨晕肉、留白为光，禁止黑色硬阴影、禁止CG式硬光直射
- **光源逻辑** — 漫射天光为唯一光源逻辑（~6000K），正给镜头默认留白受光 + 淡墨晕影，侧给镜头可适当调整墨色浓淡方向

| 墨色光影方案 | 方案名 | 墨色配置 | 留白比例 | 适用情绪 |
|---|---|---|---|---|
| A | 宣纸清透 | 淡墨 C3 为主 + 宣纸白 C4 大面积 | 40-50% | 文人雅集、田园牧歌、少女天真、日常温馨 |
| B | 烟雨氤氲 | 淡墨 C3 湿润晕染 + 浓墨 C2 远树 + 留白雨雾 | 45-55% | 烟雨江南、竹林清幽、湿润朦胧、思念惆怅 |
| C | 晨雾透光 | 淡墨 C3 + 浓墨 C2 近景 + 大面积留白晨雾 | 40-50% | 山水长卷、古寺晨钟、禅意出世、空灵意境 |
| D | 月色淡墨 | 浓墨 C2 成块 + 留白为月光水面 + 淡墨晕月辉 | 25-35% | 月夜思念、独处孤寂、宁静清冷、出世禅定 |
| E | 雪霁空明 | 大面积留白 C4 为雪 + 淡墨 C3 寒林枯枝 | 55-65% | 雪山寒林、凛冽孤绝、侠客独行、悲壮苍凉 |
| F | 焦墨点睛 | 焦墨 C1 + 浓墨 C2 + 枯笔飞白 + 留白极简 | 15-25% | 戏剧点睛、侠客对决、命运转折、凛冽刚劲 |
| G | 朱砂落款 | 任一方案为底 + 朱砂印 C5 极小面积落款/点唇/封印 | 沿用底方案 | 收尾落款、大婚典礼、信物封印、高潮留红 |

- **方案组合策略** — 一场戏默认锁定单一墨色方案，仅在叙事转折处切换（如文人雅集 A → 离别 E、烟雨 B → 月夜 D）。方案切换须通过墨色晕化渐变过渡，禁止生硬跳切
- **氛围方向映射** — 每场戏的氛围方向应能映射到上述方案（A-G）的某一方向，确保全片墨色基调一致
- **朱砂落款 G 为收尾专用** — 朱砂红绝不在常规镜头大面积出现，仅在段落收尾、信物封印、大婚点唇处作为"印章"式点睛

## 三、质感方向

- **手绘水墨笔意为锚** — 水墨动画风格的核心：毛笔飞白、皴擦点染、焦浓重淡清五色晕染、留白意境、气韵生动。墨色晕染过渡平滑，禁止色块断层
- **毛笔笔触 + 水墨电影质感** — 这是画面质感的锚点。不是写实摄影，不是 3D CG，不是平涂卡通，是二维手绘水墨动画加宣纸质感的融合
- **材质水墨化** — 所有服化道的材质必须以水墨笔法呈现：丝绸的飘逸用行云流水描、木质的纹理用皴擦、玉石的润感用淡墨晕染留白、金属的冷质用焦墨枯笔勾轮廓。禁止"3D 感"和"写实摄影感"
- **墨肉质感** — 淡墨晕染面部为墨肉、宣纸白留出高光、焦墨细线勾五官、笔意呼吸、留白通透。禁止彩色肤色/腮红/唇色（朱砂点唇除外）
- **水墨不等于扁平** — 水墨动画强调通过墨色浓淡五级、留白意境、皴擦点染、空气透视（近浓远淡）等手段增加空间感与电影感，而非无层次的简笔涂鸦
- **宣纸纤维质感** — 所有画面底层带宣纸纤维质感纹理，增强手绘水墨的物质真实感

## 四、水墨场景空间元素

水墨世界观特有的场景元素及其视觉叙事功能：

- **留白即叙事** — 留白是水墨风格的核心语言：留白即云、即雾、即水、即天、即雪、即气韵。满庭留白 = 空灵出世、独坐留白 = 孤寂、大雪留白 = 凛冽悲壮、晨雾留白 = 禅意清寂
- **山水长卷构图** — 三远法（高远/深远/平远）是水墨场景的天然构图语言，段落衔接建议用长卷式横移运镜，如卷轴徐徐展开
- **皴法即质感** — 山石用披麻皴/斧劈皴/雨点皴/米点皴，树叶用点叶法/点苔法。皴法的选择本身就是叙事（斧劈显刚劲侠客、披麻显温润山水、米点显江南烟雨）
- **水墨环境载体** — 飞鹤 = 仙逸/出尘、荷花 = 清雅/禅意、孤舟 = 隐逸/渔翁、古松 = 苍劲/文骨、残荷 = 萧索/秋意、新竹 = 清幽/气节
- **段落间用墨色晕化过渡** — 本风格有丰富的墨色方案（A-G），段落衔接建议用墨色晕化/留白流转做情绪缓冲，不要硬切。长卷式横移 + 墨色晕化是水墨动画的标志性转场
- **转折点用笔墨而非台词** — 优先使用画面手段（墨色突变焦墨点睛、皴法从披麻转斧劈、留白比例骤变、朱砂落款收尾）而非依赖对白解释
- **前中后景墨色层次** — 所有场景必须具备前/中/后景墨色层次（近焦浓、远清淡），室外必须包含空气透视（远山如黛、远景淡墨虚化）

## 五、古风乐器与环境音

水墨世界观下的声音元素约束：

### 乐器选择

- **古琴** — 水墨动画的灵魂乐器，开场定调 / 平稳段落 / 禅意意境 / 文人雅集，与箫搭配使用，散音泛音皆宜
- **箫（洞箫）** — 凄凉、孤寂、清远、出世段落的核心乐器，与月夜诗意/隐逸山林/禅意古寺氛围高度适配
- **笛（竹笛）** — 牧笛田园、天真烂漫段落，清亮悠扬，牧童主题首选
- **二胡** — 情感深沉、悲戚、思念段落，拉弦的哭腔感适合情绪沉淀与爆发
- **编钟/磬** — 古寺晨钟、庄严禅定段落，钟磬声与留白意境绝配，慎用但一用即定禅意
- **琵琶** — 紧张、急促段落的点缀，侠客对决场景的节奏推动器，不作主导
- 埙/古筝可作氛围铺底但不宜喧宾夺主

### 乐器组合策略

| 情绪阶段 | 乐器组合 |
|---|---|
| 平稳/开场/收尾 | 古琴独奏 或 古琴 + 箫 |
| 文人雅集/书斋 | 古琴 + 箫 + 轻磬 |
| 牧笛田园/天真 | 竹笛独奏 或 竹笛 + 古筝 |
| 禅意/古寺/出世 | 编钟/磬 + 古琴 + 箫 |
| 烟雨江南/思念 | 箫 + 古筝 + 轻雨声 |
| 悲戚渐浓 | 箫 + 二胡 |
| 情绪爆发/命运转折 | 二胡独奏 或 二胡 + 琵琶点缀 |
| 紧张/侠客对决 | 琵琶点缀 + 鼓点 + 弦乐衬底 |
| 月夜独处/孤寂 | 古琴泛音 + 箫 + 虫鸣 |

### 水墨环境音

- **典型环境音层次** — 风过竹林 / 溪水潺潺 / 晨钟暮鼓 / 雨打荷叶 / 雪落寒枝 / 渔歌远唱 / 牧笛回响 / 鹤唳长空 / 虫鸣夜露 / 涛声远壑 / 笔墨纸砚轻响（书斋）/ 茶汤注盏
- **留白处的"静"也是声音** — 水墨风格的留白段落可配极简环境音（一声远钟、一缕虫鸣、一滴水），以"静"显"境"，每场戏标注 1-2 个核心环境音。环境音越简练，水墨意境越浓
