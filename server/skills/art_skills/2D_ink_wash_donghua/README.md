# 水墨动画风格说明

本风格专为「水墨动画」题材打造，承袭上海美术电影制片厂水墨动画体系（《小蝌蚪找妈妈》《山水情》《牧笛》）的视觉文脉，所有美术提示词、规范和生成内容均严格限定于：

- **水墨动画**：以传统中国水墨画为语言根基的二维手绘动画风格，焦墨、浓墨、淡墨层层晕染，宣纸纤维质感为底
- **墨分五色**：焦、浓、重、淡、清五级墨色构成画面层次与"光感"，墨色浓淡即明暗，墨色干湿即质感
- **留白与气韵**：计白当黑，留白即云、即水、即雾、即天，气韵生动是最高准则
- **克制点缀**：画面以黑白灰为绝对主体，朱砂印章红与青绿仅在落款/题跋/极少数神采点睛处出现
- **手绘笔意**：毛笔飞白、皴擦点染、枯润相济，保留笔锋呼吸，绝非矢量描边或CG渲染
- **水墨电影质感**：长卷式构图、留白意境、虚淡远景、虚实相生，追求诗意与文学性

## 适用范围

- 水墨动画题材的AI美术生成（角色、场景、道具、分镜等）
- 需要水墨意境、文人画审美、传统动画笔意的视觉创作
- 山水田园、文人隐逸、禅意古韵、江南烟雨类短剧的视觉开发
- 国画长卷式叙事、水墨动画短片、概念美术、文学性插画创作

## 严禁内容

- 全彩写实摄影 / 3D写实渲染 / 照片级真实感
- 重彩画 / 高饱和彩色插画 / 平涂卡通色块
- 赛博朋克 / 科幻 / 西方奇幻 / 哥特等非东方水墨语境
- 矢量描边 / 扁平无笔意 / 塑料光泽 / 现代UI插画风
- 粗劣抖动线条 / 模糊画质 / 低精度生成
- 任何CG写实渲染（3D写实/CG动画渲染/照片级真实感等）

## 风格体验

在本风格下，您将体验到：

- 角色以水墨线描造型登场，焦墨勾骨、淡墨晕肉，留白处皆是气韵，举手投足自带诗意
- 场景如山水长卷徐徐展开，远山淡墨、近石浓墨、云雾留白，墨色浓淡即天光晨昏
- 道具器物以皴擦点染呈现，竹木有节、宣纸有纹、瓷砚有润，墨韵中见质感
- 分镜与渲染强调"墨色即光影"，景别即墨色层次，转场即墨色晕化，整片如一卷会呼吸的水墨画
