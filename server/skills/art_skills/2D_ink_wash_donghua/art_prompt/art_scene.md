# 水墨场景图生成 · 约束手册

---

## 一、场景美学原则

1. **留白即叙事** — 留白不是空，而是云、是雾、是水、是天、是气韵流动的所在，承载情绪与意境
2. **墨色即远近** — 近景焦浓、中景浓重、远景清淡，墨色浓淡五级构成全部空间纵深，杜绝扁平
3. **皴法即质感** — 山石用皴（披麻/斧劈/雨点/米点），树叶用点（点叶/点苔），笔法服务于材质
4. **手绘水墨为锚** — 一切画面以二维手绘水墨动画为标准，拒绝3D写实/CG渲染/平涂卡通；追求毛笔飞白、晕染呼吸、宣纸纤维质感

## 五、主视图规范

### 视图定义

> 单画面主视图，从场景中最具代表性的角度呈现，承载空间叙事与构图重心。水墨场景主视图常取"长卷式"或"三远法"（高远/深远/平远）构图。

| 项目 | 约束 | 提示词 |
|---|---|---|
| 视角 | 自然观察视角，三远法构图最能体现水墨意境 | hero shot、three-distance composition |
| 视点高度 | 默认人眼平视高度，山水长卷可取平远/高远 | eye level（默认）、level distance |
| 构图 | 主体居中或符合留白构图法，前/中/后景墨色层次清晰 | balanced composition with negative space |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 单画面（非拼图、非多视图、非分屏） |
| 人物 | **严禁出现任何人物、人影、人体轮廓** |
| 一致性 | 墨色浓淡层级/皴法笔法/笔意风格统一 |
| 光线（墨色） | 墨色浓淡即光影逻辑，浓淡过渡方向一致 |
| 画面比例 | 默认 16:9（或按调用方设定） |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 场景必须有「前中后景墨色层次」（近焦浓、远清淡） |
| R2 | 室外必须包含「留白为云雾/水面」与「空气透视」 |
| R3 | 场景图必须为「单画面主视图」，不得拼接多视图/分屏/网格 |
| R4 | 构图须能代表场景主体并展示前/中/后景墨色层次（三远法） |
| R5 | 场景图中**严禁出现任何人物** |
| R6 | 必须包含水墨动画关键词（Chinese ink-wash animation / ink wash / xuan paper / negative space） |
| R7 | 必须包含笔法光学特征（毛笔飞白 / 皴擦点染 / 墨色浓淡即光影） |
| R8 | 材质必须带有皴擦/苔点/岁月痕迹，禁止全新无瑕的"CG 感"或"塑料感" |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 背景纯白/纯黑无场景（纯白必须有宣纸纤维质感与皴擦痕迹） |
| X2 | 极端天候的写实暴风（暴风雨/雷电写实描绘，除非剧情需要；水墨以留白与淡墨写风雨） |
| X3 | 场景无纵深/无墨色层次/扁平 |
| X4 | 植被/天候与季节矛盾 |
| X5 | 出现任何人物、人影、人体剪影或人体轮廓 |
| X6 | 画面被拼接成多视图/网格/分屏布局 |
| X7 | 3D 写实/CG 渲染/卡通平涂/游戏引擎质感（禁用 3D写实渲染、CG动画渲染、照片级真实感、矢量描边、塑料光泽等非水墨质感） |
| X8 | 全彩浓艳画面/高饱和彩色插画（必须以黑白灰墨色为主体） |
| X9 | 光照过于均匀平坦或硬直射、无景深晕化、无笔意光学特征 |
