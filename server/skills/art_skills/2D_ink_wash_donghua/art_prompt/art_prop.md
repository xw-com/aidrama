# 水墨道具图像生成 · 约束手册

---

## 一、道具设计原则

1. **功能可读** — 道具用途一目了然，造型服务于功能，以最少的笔墨点明物象（减笔写意）
2. **墨韵极致** — 材质纹理必须以墨色浓淡、皴擦点染、留白清晰可辨（木/玉/瓷/布/纸/竹）
3. **年代一致** — 所有道具必须符合古风水墨世界观，禁止现代元素
4. **尺度明确** — 通过参照物或标注暗示道具真实尺寸
5. **纯道具独立展示** — 画面中只能出现道具本身，严禁出现任何人物、手部、肢体，道具不可处于被持有/佩戴/握持状态，必须以静物陈列方式独立呈现
6. **惜墨如金** — 水墨道具以黑白灰墨色为主体，朱砂/青绿仅在关键道具落款或点睛处极小面积出现

## 三、多角度设定图规范

### 视图定义

| 位置 | 视图 | 角度 | 要求 | 提示词 |
|---|---|---|---|---|
| 左上 | 正面图 | 正面 0° | 道具完整正面形态 | front view |
| 右上 | 侧面图 | 侧面 90° | 厚度/轮廓/结构清晰 | side view |
| 左下 | 背面图 | 背面 180° | 道具背部结构/装饰 | back view |
| 右下 | 细节特写 | 局部放大 | 皴法纹理/笔意细节 | detail closeup |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 同一画面四宫格（2×2），上下左右四视角 |
| 背景 | 宣纸白纯色 #F2EDE0 带宣纸纤维质感 |
| 光线（墨色） | 焦墨勾骨、浓墨成块、淡墨晕肉，墨色浓淡即明暗，无硬阴影无直射 |
| 比例 | 每格道具占格内主体 70%+ |
| 投影 | 允许淡墨极薄地面微投影 |
| 画面比例 | 建议 1:1 |

## 六、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须指定「宣纸白纯色背景 #F2EDE0 带宣纸纤维质感」 |
| R2 | 必须明确道具材质与对应皴法/笔法 |
| R3 | 道具造型必须符合古风水墨世界观，禁现代元素 |
| R4 | 必须为「四宫格」布局：正面 + 侧面 + 背面 + 特写 |
| R5 | 必须包含「水墨动画 + 焦浓重淡清五色晕染 + 宣纸留白」关键词 |
| R6 | 必须以黑白灰墨色为主体，朱砂/青绿点缀全画面占比 ≤ 3% |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 复杂场景背景（必须宣纸白纯色） |
| X2 | 道具与人物同画面（本环节为纯道具图） |
| X3 | 出现任何人物形象，包括全身、半身、局部（手、手指、手臂等肢体） |
| X4 | 道具处于被持有、握持、佩戴、使用中的状态 |
| X5 | 出现暗示人物存在的元素（如手持痕迹、佩戴视角、使用姿态） |
| X6 | 现代元素出现在古风水墨道具中 |
| X7 | 全彩浓艳画面/高饱和彩色插画/平涂卡通色块（必须黑白灰墨色为主体） |
| X8 | 3D 写实/CG 渲染/矢量描边/塑料光泽（禁用 3D写实渲染、CG动画渲染、照片级真实感等非水墨质感） |
