## 一、风格基因

| 维度 | 定义 |
|---|---|
| **一级风格** | 水墨动画风格（Chinese Ink-wash Animation） |
| **二级风格** | 二维手绘水墨 · 焦浓重淡清五色晕染 + 宣纸留白 |
| **情感基调** | 诗意空灵、文人清雅、气韵生动、虚实相生 |
| **质感锚词** | 毛笔飞白、墨色晕染、宣纸纤维、留白意境、墨分五色 |

## 二、全局色彩盘（风格基线）

### 色彩使用层级

| 层级 | 约束强度 | 说明 |
|---|---|---|
| L1 硬约束 | 高 | 以黑白灰墨色为绝对主体，禁全彩、禁重彩画 |
| L2 软约束 | 中 | 墨色浓淡（焦/浓/重/淡/清）可按情绪与景深微调 |
| L3 例外机制 | 低 | 朱砂印、青绿点缀仅在落款/点睛/特定叙事处极小面积出现 |

### 核心色盘

| 序号 | 色名 | 色值 | 用途 |
|---|---|---|---|
| C1 | 焦墨黑 | #2A2A2A | 主轮廓、近景结构、点睛枯笔 |
| C2 | 浓墨 | #4A4A4A | 主要形体、中景墨块、衣纹主线 |
| C3 | 淡墨灰 | #8A8A8A | 远景晕染、衣纹次线、雾气过渡 |
| C4 | 宣纸白 | #F2EDE0 | 纸基底色、留白、天空、水面、云雾 |
| C5 | 朱砂印 | #A83232 | 印章落款、极小面积点睛（唇/印/朱砂痣） |
| C6 | 青绿点缀 | #6E8A6A | 极小面积点缀（竹叶/苔点/远树） |

> **墨分五色执行口径**：焦（C1）→ 浓（C2）→ 重（C1 与 C2 之间过渡墨块）→ 淡（C3）→ 清（C3 极薄晕染近宣纸白）。五色构成画面的全部"明暗层级"，对应其他风格的高光与阴影。

### 硬约束色（默认锁定）

| 色项 | 对应色 | 规则 |
|---|---|---|
| 整体色调 | 黑白灰墨色 | 禁止全彩、禁止重彩画、禁止平涂卡通色块 |
| 线条颜色 | 焦墨黑 #2A2A2A | 禁止纯黑僵硬描边，须有飞白与枯润变化 |
| 明暗 | 墨色浓淡（焦浓重淡清） | 禁止黑白硬对比，须以晕染过渡 |
| 点缀色 | 朱砂印 / 青绿 | 极小面积、低频出现，禁止彩色铺满 |

### 情绪色盘

> 水墨风格"情绪"由墨色浓淡与留白比例表达，而非彩色冷暖。

| 情绪场景 | 主墨色 | 辅墨色 | 留白与点缀建议 | 画面关键词 |
|---|---|---|---|---|
| 文人雅集 | 浓墨 C2 + 淡墨 C3 | 焦墨 C1 勾骨 | 大面积留白，青绿苔点 | 清雅、疏朗、书卷 |
| 隐逸山林 | 淡墨 C3 + 浓墨 C2 | 焦墨 C1 树石 | 留白为云雾，宣纸白为主 | 空灵、淡远、出世 |
| 牧笛田园 | 淡墨 C3 + 宣纸白 C4 | 浓墨 C2 水牛 | 青绿点缀草地，极淡 | 天真、牧歌、田园 |
| 烟雨江南 | 淡墨 C3 + 清墨 | 浓墨 C2 远树 | 留白为雨雾，墨色湿润 | 烟雨、朦胧、湿润 |
| 禅意古寺 | 浓墨 C2 + 淡墨 C3 | 焦墨 C1 飞檐 | 留白为晨雾，朱砂极小印 | 清寂、禅定、晨钟 |
| 侠客寒林 | 焦墨 C1 + 浓墨 C2 | 淡墨 C3 远山 | 留白为雪，枯笔飞白 | 凛冽、孤绝、清刚 |
| 悲戚离别 | 淡墨 C3 + 清墨 | 焦墨 C1 残笔 | 大面积留白，墨色干涩 | 苍凉、萧索、留白 |

### 色温约束

| 参数 | 值 | 说明 |
|---|---|---|
| 整体色温 | 漫射天光偏中性 5800-6200K（推荐） | 模拟自然漫射光，无强直射 |
| 对比度 | 中低 35-55%（建议区间） | 墨色晕染过渡为主，避免硬对比 |
| 饱和度 | 极低 5-15%（建议区间） | 黑白灰为主，彩色为极小点缀 |
| 留白比例 | 画面 30-50% 留白（建议区间） | 计白当黑，留白即气韵 |

### 容差与例外

| 项目 | 建议容差 |
|---|---|
| 墨色浓淡偏移 | ±1 级（如浓墨可偏重墨或淡墨） |
| 宣纸底色偏移 | 色相 ±5°、明度 ±8% |
| 点缀色面积占比 | 全画面 ≤ 3%，单点缀 ≤ 1% |

## 三、全局约束规则

### 必守规则（所有技能继承）

| 编号 | 规则 |
|---|---|
| R1 | 必须包含「水墨动画」风格锚定词 |
| R2 | 必须声明「焦浓重淡清五色晕染 + 宣纸留白」 |
| R3 | 必须声明「毛笔飞白 + 手绘笔意 + 气韵生动」 |
| R4 | 必须声明「二维手绘水墨 + 长卷构图 + 留白意境」 |
| R5 | 必须声明「水墨动画电影质感 + 墨色即光影」 |

### 严禁项（所有技能继承）

| 编号 | 严禁内容 |
|---|---|
| X1 | 严禁「写实摄影 / 3D写实渲染 / 照片级真实感」 |
| X2 | 严禁「重彩画 / 高饱和彩色插画 / 平涂卡通色块 / 全彩」 |
| X3 | 严禁「CG写实渲染」——3D写实渲染、CG动画渲染、照片级真实感、矢量描边、塑料光泽等非水墨质感一律禁用 |
| X4 | 严禁「矢量描边 / 扁平无笔意 / 塑料光泽 / 现代UI插画风」 |
| X5 | 严禁「粗劣抖动线条 / 模糊画质 / 低精度生成 / 色彩混乱」 |
