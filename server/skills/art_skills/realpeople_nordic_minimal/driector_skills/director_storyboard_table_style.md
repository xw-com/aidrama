## 一、分镜表定位

分镜表是导演将剧本转化为镜头语言的核心工具。本约束面向 Seedance 2.0 视频生成，所有光影、动作、空间描述均采用模型可执行的具象语言。不做抽象的情感概括，不写模型看不懂的渲染参数。北欧美学以柔和漫射、低对比、严格低饱和、克制留白为核心。

## 三、光影与氛围——Seedance 2.0 物理光源描述

### 3.1 同场戏光影统一

一场戏内不应出现两种以上核心光影方案，除非有叙事驱动的光源变化（如有人开了台灯、从日间大窗光走到夜间夜灯、从客厅走到卧室）。光源变化必须在分镜表中标注触发事件。北欧极简光比整体偏低（柔和低对比）。

### 3.2 光源语句法（每个镜头必须包含）
[光源] 主光：{光源类型——大窗漫射/薄纱晨光/暖白台灯/雪日冷光}，{方向}，{色温值K}，{软硬——北欧极简以柔和漫射为主}
[光源] 辅光/环境光：{光源类型}，{方向}，{色温值K}
[光比] 约1:{X}（北欧极简整体偏低反差1:1.5-1:4）

### 3.4 冷暖色调与叙事阶段

- **冷光主导**（5500K+）：起居日常的通透克制、雪日静谧、独处沉思、过渡诗意
- **暖光主导**（2700-3500K）：阅读独处、厨房烟火、黄昏松弛、深夜私语
- **冷暖共存**：过渡时刻（蓝调时刻+初亮台灯）、雪日（冷漫射+暖灯点）、冲突（冷窗光+暖台灯）
- **光源变化 = 时间/心境信号**：窗外大窗光从午后偏暖（4500K）渐变至黄昏暖金（3500K）= 时间流逝；从日间大窗漫射走到夜间夜灯暖光=一天将尽

### 3.5 Seedance 2.0 光影适配要点

- 色温数字帮助模型校准白平衡倾向：`色温约5500K大窗柔和漫射` 优于 `柔光`
- 光比数字帮助模型建立明暗意识：`光比约1:2低反差` 优于 `柔和的阴影`
- 光源必须有明确来源：`从画面右侧大窗柔和漫射斜入` 优于 `柔光`
- 强调柔和漫射特性：`阴影边缘模糊` `低对比` `白墙二次反射柔化` 优于笼统的 `柔光`
- 环境光的反射路径描述：`原木茶几反射漫射光` 优于 `桌面有反光`

## 四、环境动态——让画面呼吸

### 4.1 动态密度

每 3-4 个镜头至少安排一个有环境动态的镜头。静态生活戏也不例外——至少有一个镜头里绿植叶片轻晃、蒸汽缓缓升起、纱帘被穿堂风轻拂、远处鸟鸣传来。北欧极简的动态以"微弱、克制、自然"为特征。

### 4.2 北欧极简环境动态元素（Seedance 2.0 可执行）

| 场景 | 可描述的环境动态 |
|---|---|
| 客厅 | 绿植叶片被空调风轻拂约2cm后回正（约2秒周期）、亚麻纱帘被穿堂风鼓起约10cm后回落（约3秒周期）、茶几上陶瓷杯口蒸汽缓缓升起约5cm后飘散、窗外远处鸟鸣隐约传来 |
| 厨房 | 手冲咖啡的滴滤声、壶水沸腾的轻响、原木砧板上的切菜声、陶瓷餐具轻碰、蒸汽从锅口升腾、窗外阳光随云层移动微弱明暗变化 |
| 书房 | 书页翻动的纸张声、台灯的电流嗡鸣、黑胶唱机的低转、窗外远处车流、笔尖触纸 |

### 4.3 Seedance 2.0 环境动态描述规范

- 动态必须有具体轨迹和速度：`蒸汽每秒约1缕缓缓升起约5cm后飘散` 优于 `咖啡冒着热气`
- 光源动态与空间光源逻辑一致：`云层遮住日光时，大窗漫射光减弱约30%，持续约3秒后恢复`
- 禁止无来源的动态：没有风=纱帘不动。门窗紧闭=没有穿堂风
- 北欧极简动态以"微弱、克制、自然"为核心——不可有夸张剧烈的动态

所有人物动作必须描述：**轨迹 + 速度/时长 + 身体部位协调 + 服饰连带动态 + 对周围物体的影响**。北欧生活方式动作以"松弛、缓慢、日常、不刻意"为节奏基调。

### 5.3 动作节奏与叙事场景

- **起居日常/阅读独处**：动作松弛缓慢克制，每个微动作标注时长和轨迹。节奏舒缓——不是慢，是"生活方式的不急"
- **厨房烟火**：动作有生活节奏感。备餐/手冲/切菜须具体到轨迹与声音连带，但保持松弛不慌乱
- **情绪波动**：动作幅度和速度略微变化。人物可能在独处时放慢手部动作、呼吸带动肩膀起伏更明显
- **冲突场景**：动作干脆但仍有物理轨迹。推搡/摔物须具体到"右手推在对方左肩前方，对方重心向后偏移约20cm，亚麻衣物随动作剧烈摆动"——但北欧极简冲突仍保持克制，不夸张暴力
- 禁止：无叙事理由的快速动作堆砌、无物理逻辑的瞬移、"喝了一口"等含糊描述

### 5.4 服饰动态

真人北欧极简写实的服饰动态是画面的天然资产——不是"布料模拟参数"，而是"亚麻衬衫随抬手自然上移约3cm""粗针毛衣随身体前倾自然垂坠""亚麻家居服随步伐自然摆动""纱帘被穿堂风鼓起约10cm"。在分镜表画面描述中标注亚麻/棉麻/针织服饰的动态细节。

### 6.1 每镜头必须声明的空间信息
水平位置：画面左/中/右，或画面左侧三分之一处
纵深位置：距镜头{数值}米，前景/中景/背景

### 6.2 站位衔接示例
【片段A尾部】
A女性身着燕麦色亚麻衬衫坐在白墙客厅原木沙发左侧，距茶几约0.5米，面向茶几，位于画面中央偏左，距镜头约3米。

【片段B开头】
A的右手刚把马克杯放回原木茶几，杯底距茶几边缘约10cm。A仍坐在沙发左侧（位置未变）。

## 七、运镜规范——Seedance 2.0 摄影机运动

### 7.1 允许的运镜

| 运镜 | Seedance 2.0 描述 | 适用场景 |
|---|---|---|
| 固定 | 摄影机固定不动，画面静止 | 日常场景、对话、空镜留白、静物凝视、生活观察 |
| 手持微晃 | 摄影机有轻微不规则晃动（幅度约±1.5cm），模拟手持拍摄的呼吸感 | 厨房忙碌、情绪波动、跟随行走、生活纪实 |
| 稳定器流动 | 摄影机平滑匀速移动，无晃动 | 空间过渡、人物登场、家居漫游、极简空间展示 |
| 缓推 | 摄影机向主体缓慢推进，推进速率约每秒0.3米 | 情绪升温、注意力聚焦、真相逼近 |
| 缓拉 | 摄影机向后缓慢拉远，拉远速率约每秒0.3米 | 收束、空间揭示、留白展开 |
| 跟拍 | 摄影机与人物保持约2米距离同步移动 | 穿行极简空间、行走跟随 |
| 摇镜 | 摄影机原地水平/垂直旋转 | 视线转移、空间纵深关系交代 |

### 7.2 禁用运镜

- 无叙事目的的快速甩镜、急推急拉（推拉速率超过每秒1米）——北欧极简追求克制观察，不追求视觉刺激
- 超过3秒的剧烈手持晃动（除非主观受击/眩晕/意外叙事）
- 无逻辑花式转场——划屏、旋转、百叶窗、翻页等特效转场
- 摄影机无理由的360度旋转
- 任何破坏"克制观察"美学的炫技运镜

### 7.3 真人北欧极简写实运镜哲学

- 固定机位是日常起居与独处场景的第一选择——让观众看到生活者在极简空间里自然存在
- 手持微晃在生活纪实段落使用——但晃动幅度极轻微（±1.5cm），不破坏克制美感
- 稳定器流动用于穿行极简空间与人物登场——极简空间的仪式诗
- 运动镜头的起幅和落幅必须平稳，运动过程匀速——禁止突然加速或急停

## 八、转场规范

### 8.1 允许的转场方式

| 转场 | 视觉执行 | 叙事功能 |
|---|---|---|
| 硬切 | 直接切换 | 同场戏内镜头切换（默认） |
| 光影匹配转场 | 两个场景在相近光影逻辑下切换 | 时间流逝、平行叙事。例：A处大窗漫射光 → B处大窗漫射光 |
| 空间匹配转场 | 两个空间在构图或元素上呼应 | 场景跳转。例：客厅原木茶几 → 厨房原木砧板 |
| 空镜过渡 | 插入场景空镜（3-5秒） | 情绪缓冲、章节划分、时间流逝暗示（如黄昏客厅→夜灯卧室） |
| 焦点转场 | 前镜焦点从主体移至背景，后镜从模糊背景中逐渐聚焦主体 | 空间切换、注意力的转移 |

### 8.2 禁止的转场

- 纯视觉特效转场（翻页、划屏、百叶窗、马赛克、水墨化开）
- 无叙事逻辑的旋转/缩放转场
- 同一场戏内使用超过两种转场方式

## 十一、空镜使用规范

### 11.1 空镜不是"没东西拍"

空镜是情绪容器。北欧极简的空镜是留白诗意的核心载体——每个空镜必须有叙事目的和具体的视觉内容：

| 空镜类型 | 叙事目的 | 示例 |
|---|---|---|
| 场景建立 | 新空间首次出现——让观众看清楚这是什么极简空间 | 白墙客厅大全景：沙发、茶几、绿植、落地窗、极简装饰画 |
| 情绪缓冲 | 高情绪段落后的喘息 | 原木茶几上陶瓷杯口的蒸汽缓缓升起，速度约每秒1缕 |
| 时间流逝 | 暗示时间过去了 | 同一落地窗外的天光从午后偏暖渐变至黄昏暖金再至夜灯暖白 |
| 隐喻留白 | 以物代情 | 阅读角暖白台灯下翻开的极简书，书页被穿堂风轻翻约5cm |
| 转场衔接 | 前后两个空间的自然过渡 | 厨房中岛上的手冲咖啡器具——前一场客厅，下一场厨房 |

### 11.2 空镜 Seedance 2.0 描述规范

空镜也必须遵循光源+质感+动态的描述铁律：原木茶几上陶瓷马克杯口蒸汽缓缓升起，
大窗柔和漫射自然光从画面右侧斜入（约5500K），白纱帘柔化，白墙二次反射，
在原木天然纹理与亚麻桌布上铺开均匀柔光，
蒸汽每秒约1缕升起约5cm后向右侧飘散，
茶几旁绿植叶片被空调风轻拂约2cm后回正，
原木茶几有使用包浆，亚麻抱枕有柔软褶皱。

## 十二、分镜表质量自检清单

每场戏的分镜表完成后，导演逐项自检：

| 检查项 | 通过标准 |
|---|---|
| 光源可追溯 | 每个镜头能回答"光从哪儿来、什么色温"（大窗漫射/薄纱晨光/暖白台灯/雪日冷光） |
| 光比柔和 | 光比整体偏低（1:1.5-1:4），无硬光无强反差，阴影边缘模糊 |
| 动作可执行 | 每个动作有轨迹、时长、身体部位、松弛体态、服饰连带 |
| 空间可定位 | 每个镜头标注了人物的水平和纵深位置、与固定物关系 |
| 站位移接 | 相邻镜头的同一个人位置/姿态/服饰动态可衔接 |
| 环境有动态 | 每3-4个镜头至少1个有环境动态（蒸汽/纱帘/绿植/光斑微移） |
| 语气不空泛 | 无"她很松弛""气氛很安静"等不可执行描述 |
| CG术语清零 | 无PBR/SSR/AO/体积光/次世代等CG词汇 |
| 低饱和锁定 | 严格低饱和（25-45%），无高饱和无明艳无荧光色 |
| 繁复装饰清零 | 无华丽陈设/金碧辉煌/巴洛克/繁复花纹/堆砌装饰 |
| 服装妆容一致 | 同场戏人物服装/发型/自然妆容在所有镜头完全一致 |
| @reference完整 | 角色/场景/核心道具都标注了锚定引用 |
