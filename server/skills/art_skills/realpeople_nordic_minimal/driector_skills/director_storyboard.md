# 分镜提示词 · 真人北欧极简写实 · 风格专属技法

---

## 适用范围

本 Skill 专用于**真人北欧极简写实**风格的分镜提示词生成，适配现代北欧极简主义（Scandinavian / Japandi）生活方式、家居日常、咖啡时光、阅读独处、绿植生活、雪日静谧等真人实拍生活方式题材的分镜创作。

## 一、摄影机前的情绪——面孔、眼神、微表情

> 真人北欧极简写实的情绪不来自"法术光效"或"渲染参数"，而来自真人演员在摄影机前的松弛微表情与自然眼神。以下映射面向摄影机捕捉真实现代生活者的方式。所有情绪表达克制自然，不刻意不浮夸。

| 情绪输入 | 面容描述 | 眼神描述 | 微表情补充 |
|---|---|---|---|
| 松弛 / 宁静 | 神情舒展，面部线条放松不紧绷，下颌微收 | 眼神平静温和，注视时像在看远处又不执着 | 嘴角自然平直放松，呼吸自然，全身松弛 |
| 专注 / 内敛 | 眉眼微聚，面部肌肉自然专注 | 目光沉稳聚焦，像在看书或手中的物 | 嘴唇自然微抿，手部有细微动作（翻页/捧杯） |
| 温暖 / 柔和 | 眉目舒展，面部柔和 | 眼神温和有光，像在认真听对方说话 | 嘴角自然含一丝温意，不是笑，是有温度 |
| 文艺 / 清冷 | 眉眼疏淡，面部不苟 | 眼神清冷有距离感但不冷漠，像在想远处的事 | 唇形自然微抿，下颌线放松 |
| 安静 / 独立 | 神情淡然，眼部周围肌肉放松 | 目光放远失焦，像在看但不在看 | 表情平静，可能单手持杯或手扶桌沿 |
| 惊动 / 触动 | 眼尾微抬，眉峰微动 | 眼神骤然聚焦，瞳孔微扩 | 嘴角微启，眼神鲜活一瞬 |
| 沉思 / 内省 | 神情淡然，面部放松 | 目光放远，像在想什么 | 表情平静，可能手指无意识摩挲杯沿 |
| 喜悦 / 鲜活 | 眼角出现自然笑纹，眼型微弯 | 眼神明亮有光，眼角有笑意牵动 | 嘴角自然上扬，表情生动但克制不夸张 |
| 决绝 / 坚定 | 面部线条清晰，下颌微抬 | 眼神平静向前，不回避不躲闪 | 下巴微收或微抬，表情沉稳 |
| 疲惫 / 卸下 | 眉眼微垂，面部松弛 | 目光柔和但带着倦意 | 嘴角自然下沉，呼吸带动肩膀起伏 |

## 二、摄影机前的光——光源逻辑与氛围

### 2.1 大窗漫射光与生活灯光时刻

| 时刻 | 光源行为 | 色温与色调 | 空间氛围 |
|---|---|---|---|
| 清晨 | 低角度暖白晨光，穿过薄纱窗帘斜入室内；白墙柔和苏醒 | 4000-5000K暖白，薄雾漫射 | 静默开始、家刚醒来、一切尚未开始 |
| 上午 | 大窗漫射为主，白纱帘柔化，阴影边缘模糊；原木纹理清晰 | 5000-6000K中性偏冷 | 生活秩序、起居日常、克制通透 |
| 正午 | 多云漫射为主，无强阴影，室内均匀柔和；白墙二次反射 | 5500-6500K中性 | 暂停感、午间休憩、留白呼吸的顶点 |
| 午后 | 日光偏西，斜光穿过绿植形成柔和光斑，长柔和阴影 | 4000-5000K渐暖 | 慵懒、时间变慢、午后松弛 |
| 黄昏 | 极低角度暖金漫射，原木与白墙镀暖边，长柔和阴影 | 3000-4000K极暖克制 | 转瞬即逝的暖、归家松弛、一天将尽 |
| 蓝调时刻 | 太阳沉入地平线后，天空深蓝紫，暖白台灯已亮 | 8000-10000K天空 + 暖点台灯 | 过渡、诗意、白天已尽夜晚尚未接管 |
| 深夜 | 仅靠暖白台灯/夜灯——阅读角、床头。窗外可能雪夜冷蓝 | 暖光源2700-3000K / 冷窗光6500-7500K | 私密或独处、夜晚的安静 |
| 雪日 | 雪天均匀冷白漫射，无强影，室内暖灯点亮冷暖共存 | 6500-7500K冷白 + 2700K暖点 | 北欧冬日、静谧、通透的冷 |

| 情绪基调 | 光线配方 | 摄影约束 |

## 四、摄影机语法——镜头选择与运动

### 4.1 焦段选择

| 焦段 | 叙事性格 | 适用场景 |
|---|---|---|
| 24-28mm广角 | 极简空间呼吸、留白全貌、人与家居共存 | 客厅大全景、餐厅全貌、极简空间展示、雪景森林 |
| 35mm小广角 | 主观视点、身临其境的生活方式纪实感 | 厨房跟随、客厅对话、咖啡馆随行 |
| 50mm标准 | 人眼等价、客观中立的注视、最诚实的镜头——北欧生活方式首选 | 人物肖像、双人对话、日常凝视 |
| 85mm中长焦 | 压缩空间、拉近情感距离、亚麻与原木细节突出 | 特写、材质质感、松弛神态、窗边侧光人像 |
| 135mm+长焦 | 极端压缩、窥视感、将人物从留白中剥离 | 窗边远眺、门口偷拍视角、情绪的物理距离 |

### 4.2 景别选择

| 景别 | 取景范围 | 叙事功能 |
|---|---|---|
| 大特写 | 亚麻纹理/原木木纹/陶瓷釉面/绿植叶尖/手捧杯沿/翻书的手 | 材质质感、关键细节、感官聚焦 |
| 近景 | 头顶至胸部以上 | 人物情感、松弛神态、自然裸妆微表情 |
| 中近景 | 头顶至腰部 | 人物互动、手部动作（捧杯/翻书/浇花） |
| 中景 | 头顶至膝盖上下 | 人物与极简空间的初级关系、多人同框 |
| 全景 | 人物全身+部分空间 | 人物在空间中的位置、行动路线、着装全貌 |
| 大全景/空镜 | 极简空间全貌，人物极小或无人物 | 留白叙事、情绪缓冲、隐喻诗意 |

### 4.3 摄影机运动

| 运动方式 | 视觉心理 | 使用场景 |
|---|---|---|
| 固定 | 冷静、观察、让生活方式的静默自己说话 | 日常场景、对话、空镜留白、静物凝视 |
| 手持微晃 | 在场感、呼吸感、生活纪实的主观介入 | 厨房忙碌、情绪波动、跟随行走 |
| 稳定器流动 | 优雅流动、穿行极简空间的诗意 | 空间过渡、人物登场、家居漫游 |
| 缓推 | 注意力逐渐聚焦、情绪趋近 | 对话升温、真相逼近、注意力聚焦 |
| 缓拉 | 拉开距离、揭示全貌、情绪抽离 | 收束、空间展示、留白展开 |
| 跟拍 | 与人物同行、主观陪同 | 穿行极简空间、行走跟随 |
| 摇镜 | 视线转移、空间关系交代 | 人物视线引导、空间纵深关系 |

## 五、固定风格锚定词

**摄影锚定（必选）：**

真人实拍摄影，真人电影剧照，现代北欧极简生活方式，电影级摄影，大窗柔和漫射自然光与暖白台灯调度，真实色彩科学，严格低饱和

**人物质感（含人物镜头时必选）：**

真人写实摄影质感，真实皮肤纹理毛孔可见，自然裸妆或素颜与皮肤融合，不磨皮不硅胶脸，现代自然发型有鬓发碎发，亚麻/棉麻/粗针毛衣真实肌理褶皱有衣物垂坠，松弛自然体态，克制微表情

**场景质感（含场景镜头时必选）：**

真人实拍北欧极简家居场景摄影，真实自然材质和留白克制（白墙干净留白/原木桦木橡木天然浅色纹理/亚麻棉麻柔软褶皱/陶瓷哑光釉面/绿植鲜活），光源方向明确可追溯柔和漫射，低对比柔和，严格低饱和，非样板间非效果图非繁复装饰

**参考图一致性锚定（参考图模式必选）：**

保持人物造型、面容、发型、服装、自然妆容与参考图完全一致，保持场景风格与参考图一致，保持光影色彩基调统一，所有镜头呈现为同一人物的连续摄影记录

**风格收尾（固定）：**

真人写实摄影，现代北欧极简生活方式电影质感，电影级摄影画面，低对比柔和色调，严格低饱和，非3D非渲染非CG

## 六、美学禁止项

以下词汇/风格不得出现于输出提示词中：

- ❌ 3D渲染 / 3D建模 / CG / UE引擎 / Blender / PBR材质 / 次世代建模 / 体积光 / 环境光遮蔽 / 光线追踪
- ❌ 2D手绘 / 插画 / 动画 / 二次元 / 漫画 / Q版 / 赛璐璐 / 低多边形
- ❌ 写实摄影（英文禁止 photorealistic / realistic photography——本风格是"真人实拍摄影"live-action cinematic photography，不是"拟真渲染"）
- ❌ 过度磨皮 / 塑料假面 / 零毛孔 / 硅胶脸 / 蜡像感 / AI感平滑 / 现代浓妆 / 烟熏妆 / 红唇 / 假睫毛 / 美瞳
- ❌ 模特对称摆拍 / 走秀pose / 刻意戏剧化表情
- ❌ 古风 / 古装 / 汉服 / 宫廷 / 民国 / 和风传统 / 仙侠 / 武侠 / 赛博朋克 / 科幻 / 西方奇幻 / 中世纪
- ❌ 高饱和荧光色 / 霓虹溢色 / 明艳对比色 / 死亡芭比粉 / 廉价滤镜感 / 二次元平涂
- ❌ 棚拍硬光 / 聚光灯 / 强反差阴影 / 锐利高光 / 过曝死白
- ❌ 繁复华丽装饰 / 金碧辉煌 / 巴洛克 / 洛可可 / 繁复雕花 / 大量装饰品堆砌 / 极繁主义 / 花纹繁复壁纸
- ❌ 样板间 / 售楼处效果图 / 全新无痕 / 完美品相 / 杂物堆砌脏乱差
- ❌ 人体结构错误 / 肢体畸形 / 面部崩坏 / 比例失调
