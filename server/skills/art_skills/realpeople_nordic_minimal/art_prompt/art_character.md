## 一、选角逻辑——摄影机前的现代生活者

> 3D角色的起点是"建一个模型"；真人北欧极简写实的起点是"选一个真实生活的人，穿上素色亚麻或粗针毛衣，站进大窗柔和漫射光里的白墙客厅"。以下原则不从建模出发，而从选角和生活方式实拍出发。

1. **面孔即生活** — 一张脸就是一段被认真生活的日常。本风格不追求"完美无瑕的五官"或"偶像感"，而追求"值得被生活方式摄影机凝视的真实面孔"——有辨识度的不对称、有故事感的微瑕疵、能承载松弛或专注的真实面孔
2. **真人气韵优先于精致感** — 北欧生活方式叙事需要的是"看起来真的住在这里、这样生活的人"，而非"刚从杂志封面走下来的模特"。骨相、皮相、神态都要真，自然裸妆为辅，松弛不摆拍是底色
3. **松弛体态说真话** — 真实生活者的站姿不是对称的——重心自然偏移、肩背放松、手部有日常动作（捧杯/插兜/撩发）、眼神不刻意。杜绝模特式对称站姿和刻意摆拍
4. **同一人物跨角度可辨认** — 正面/侧面/背面/特写四角度必须呈现为同一个人的摄影记录，而非四个相似的人。核心识别点：颌骨轮廓、鼻梁转折、耳廓形状、发际线走向、眉骨结构
