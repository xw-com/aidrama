# 真人北欧极简写实道具图像生成 · 约束手册

## 一、道具设计原则

> 真人北欧极简写实的道具不是"被建模的物件"，而是"被生活者用过、被自然材质塑造的器物"——它在亚麻桌布上待过、在原木茶几上供过、在咖啡时光里被捧过。摄影机拍下的是它的此刻。北欧极简的道具以自然材质、克制造型、素色哑光为核心。

1. **器物即生活方式** — 每一件道具都是一个微型的北欧生活叙事容器。半杯喝过的咖啡暗示刚放下书走开、翻开的极简书暗示阅读被打断、绿植叶尖的水珠暗示刚浇过——克制的器物承载克制的生活
2. **使用痕迹优先于完美品相** — 真人北欧极简写实的道具必须有"被用过、被生活过"的证据。全新出厂、样板级别的道具一律不出现
3. **自然材质即真实** — 不是PBR参数渲染出的材质，而是摄影机拍下的真实自然材质行为：亚麻的柔软褶皱、原木的天然浅色纹理、陶瓷的哑光釉面、羊毛的蓬松、绿植的鲜活
4. **克制造型即品格** — 北欧极简道具造型简洁、几何干净、无繁复花纹、无华丽装饰、素色哑光为主。Less is more，器物之美在于材质与造型本身，不在于装饰堆砌
5. **单视图静物摄影** — 道具以单张静物产品摄影方式独立呈现，非多角度建模展示，非2×2四宫格

## 三、单视图静物摄影规范

> 真人北欧极简写实道具仅需单张静物产品摄影，非多角度建模展示。以下为单视图摄影的完整规范。

### 画面构成

| 项目 | 摄影要求 |
|---|---|
| 道具呈现 | 道具居中或偏三分线位置独立陈列，完整入画，无裁切 |
| 背景 | 浅灰/米白无缝背景纸 #D8D4CC（哑光），或浅原木桌面/亚麻布台面，根据道具属性选择。无多余物体、无繁复装饰、无文字（道具本身的标识除外，如书脊/黑胶标签） |
| 光线 | 大窗漫射自然光或单灯柔光。大窗漫射光45°侧入（明亮柔和带自然软阴影）、或柔光箱顶+侧补（产品摄影级均匀光线）。光影柔和、方向明确、无硬阴影——北欧极简以柔和漫射为主 |
| 景深 | 浅景深（f/2.8-f/5.6），道具主体清晰锐利，前后微虚化突出主体 |
| 投影 | 道具底部与承载面之间的自然接触阴影——柔软、低对比、方向与主光源一致。真实的而非抠图或悬浮 |
| 画面比例 | 建议 1:1 正方形或 4:3，适配单件道具展示 |

### 道具状态准则

| 维度 | 要求 |
|---|---|
| 使用痕迹 | 必须有"被用过、被生活过"的视觉证据——非全新未启用、非样板品相 |
| 北欧极简辨识度 | 自然材质（亚麻/原木/陶瓷/绿植）/ 素色哑光 / 极简几何造型——拒绝繁复华丽，拒绝无辨识度的架空物品 |
| 材质真实感 | 非渲染质感——是摄影机拍下的真实自然材料行为（光的反射、漫射、透射） |
| 克制造型感 | 道具须有北欧极简的克制造型——简洁几何、无繁复花纹、无华丽装饰、素色哑光为主 |
| 尺度感 | 通过材质纹理密度、自然细节暗示实物尺寸，无需参照物 |

## 六、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须是「单张静物摄影」——单视图、非多角度、非2×2四宫格、非建模展示 |
| R2 | 必须指定「浅灰米白背景纸 #D8D4CC」或「浅原木桌面/亚麻布台面」等真实北欧极简承载面，禁止复杂场景与繁复装饰背景 |
| R3 | 必须指定光源逻辑——大窗漫射光或柔光箱，光影方向明确、投影自然柔和、低对比 |
