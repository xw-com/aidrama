# 真人北欧极简写实场景图像生成 · 约束手册

---

## 一、场景美学原则

> 真人北欧极简写实的场景不是"被建模的空间"，而是"被摄影机选中的一个被认真生活的极简角落"。没有渲染引擎、没有贴图、没有体积光参数——只有实际存在的大窗柔和漫射自然光、真实的白墙与原木、亚麻棉麻与绿植、以及北欧生活方式的克制留白。

1. **留白即叙事** — 一个空无一人的白墙客厅不是"空的"，是刚放下书走开。茶几上翻开的书、半杯咖啡、沙发上的亚麻抱枕有坐过的凹陷、阳台还在晾的亚麻布——空间自己会讲北欧生活方式的故事
2. **真实的光，不是渲染的光** — 场景的光只有一个来源：实际的自然光（通过大窗、落地窗、薄纱窗帘）、实际的生活灯光（暖白台灯、极简吊灯、夜灯）。光的色温和方向必须在物理上说得通。北欧极简以柔和漫射为主，严禁硬光与强反差
3. **被生活过但不堆砌的空间** — 真实的北欧极简家居有克制的"被生活过"的证据——一本翻开的书、一杯喝了一半的咖啡、绿植有自然状态——但绝不杂物堆砌。Less is more，留白是主角
4. **现代北欧极简的真实场所** — 场景必须有明确的北欧极简辨识度（白墙、原木、亚麻、绿植、大窗柔和漫射光、几何简洁、大量留白）。这不是"generic home"，这是"现代北欧极简生活的一个具体角落"
5. **单视图全景全貌** — 一张照片装下整个极简空间的完整信息。广角或标准焦段，全景深，正面展示空间的全貌与纵深——不是四视图分割，不是多角度拼贴

## 二、季节与时刻——大窗漫射光的导演

> 真人北欧极简写实场景的光，首先由季节和时刻决定。北欧多云漫射光是本风格的标志光。以下是真实光源在四个季节、五个时段的摄影行为。

| 季节 | 时段 | 光的行为 | 场景氛围词 |
|---|---|---|---|
| 春 | 清晨 | 低角度暖白晨光穿过薄纱窗帘、空气中有薄雾漫射、白墙与原木柔和苏醒 | 春晨苏醒、薄纱晨光、静默开始 |
| 春 | 正午 | 多云漫射为主、大窗光面积最大、白墙二次反射、阴影边缘模糊 | 春日通透、窗明几净、留白呼吸 |
| 春 | 午后 | 日光偏西、斜光穿过绿植形成柔和光斑、长柔和阴影 | 慵懒温暖、午后小憩、春日融融 |
| 春 | 黄昏 | 暖金低角度漫射穿过窗、原木镀暖边、长柔和阴影 | 金色春暮、归家时刻、克制暖意 |
| 春 | 夜晚 | 暖白台灯/极简吊灯为主、卧室夜灯、冷暖居家光共存 | 春夜静谧、灯下独处、夜色温柔 |
| 夏 | 清晨 | 极早的清亮晨光、空气清澈、白纱帘透光、家尚未完全醒来 | 夏日清晨、空气清澈、家最静的时刻 |
| 夏 | 正午 | 多云漫射为主、窗帘半拉柔化强光、室内通透柔和 | 盛夏午间、帘后清凉、午睡时刻 |
| 夏 | 午后 | 日光偏西、阳台绿植浓荫、柔和光斑、凉席质感 | 午后慵懒、绿荫清凉、暑气中的家 |
| 夏 | 黄昏 | 极暖调低角度漫射、长柔和阴影、原木与白墙镀上暖橙金 | 夏日黄昏、归家松弛、金色漫溢 |
| 夏 | 夜晚 | 暖白吊灯/台灯为主、卧室夜灯、绿植在夜灯下剪影 | 夏夜静谧、灯下独处、夜深安静 |
| 秋 | 清晨 | 清冷暖白日光、空气干燥通透、可能薄雾、阳台绿植渐变色 | 秋高气爽、晨光清冽、秋日家居 |
| 秋 | 正午 | 多云漫射、光线干净通透、阴影柔和、原木纹理最清晰 | 秋日明净、天高云淡、家居清澈 |
| 秋 | 午后 | 偏暖漫射、阳台绿植投影、燕麦色织物更柔软 | 秋日午后、温暖静谧、收获季节的家 |
| 秋 | 黄昏 | 极暖金橙漫射、长柔和阴影、家居染上秋色 | 熔金秋暮、归家围坐、克制温暖 |
| 秋 | 夜晚 | 入夜早、暖白吊灯+台灯为主、卧室夜灯 | 秋夜静谧、灯下独处、冷暖交织 |
| 冬 | 清晨 | 低角度冷白晨光、可能薄雾、雪天漫射、家裹着暖意 | 冬日清晨、清冷晨雾、家最暖的地方 |
| 冬 | 正午 | 雪天均匀冷白漫射（6500-7500K）、全天最柔、无强影、窗帘拉开 | 冬日暖阳、雪日漫射、家中宁静 |
| 冬 | 午后 | 漫射衰减柔和、阴影模糊、光偏冷、室内暖灯早燃 | 冬日午后、室内暖光、天色渐沉 |
| 冬 | 黄昏 | 短暂的暖调、低角度斜光、窗外可能积雪、室内暖灯与冷窗光共存 | 冬日残阳、最后一抹暖、归家时刻 |

## 三、室内场景——北欧极简家居

### 空间摄影规范

| 维度 | 摄影要求 | 提示词 |
|---|---|---|
| 风格 | 真实的现代北欧极简室内空间——不是效果图、不是样板间、不是渲染。是被认真生活但克制留白的空间 | 真实的现代北欧极简{空间类型}、真人实拍摄影、非效果图非样板间 |

## 五、单视图全景摄影规范

> 真人北欧极简写实场景仅需**单张**全景摄影——一张照片装下整个极简空间的完整信息。不是2×2四视图，不是多角度拼接。

### 画面构成

| 项目 | 摄影要求 |
|---|---|
| 空间呈现 | 单张照片完整呈现场景的空间全貌。使用24-28mm广角或35mm，全场地的纵深、宽度、高度在一张画面中全部可见 |
| 构图 | 全景深大景别——前景（门框/家具边缘/窗帘/绿植）形成天然画框→中景是空间主体→后景向空间纵深或窗外/阳台/另一个房间延伸。**大量留白是构图核心** |
| 景深 | 全景深 f/8-f/11，从前到后全部清晰。极简空间的每一个角落都应该能被看见 |
| 人物 | **严禁出现任何人物、人影、人体轮廓。** 场景是空的——但这种"空"有叙事：刚放下书走开/即将开餐/日常的静止瞬间/生活者在别处 |
| 比例 | 建议 16:9 或 3:2 宽幅——匹配极简全景空间展示的横向视觉习惯 |
| 色彩 | 由实际光源的色温驱动，严格低饱和（25-45%），不套滤镜。色彩科学参考ARRI Alexa/Sony Venice电影色调 |

### 空的场景如何叙事

| "空"的类型 | 画面线索 | 叙事暗示 |
|---|---|---|
| 刚放下书走开 | 茶几上翻开的书、半杯喝过的咖啡、沙发亚麻抱枕有坐过的凹陷、阅读角台灯还亮着 | 刚才有人在这读书，现在走开了 |
| 即将开餐 | 原木餐桌摆好陶瓷餐具、面包水果已上桌、极简吊灯已开、椅子拉开 | 有人马上要来用餐，现在是开餐前的静止 |
| 人去屋空 | 搬迁后的极简房间、墙上挂钩留下的痕迹、地面尘轮廓、留下的旧绿植 | 曾经有人住过，现在搬走了 |
| 日常的静止 | 沙发上随意搭着的针织衫、茶几上的书和水杯、阳台还在晾的亚麻布、绿植自然状态 | 生活的常态，只是此刻没有人入镜 |
| 深夜的家 | 客厅只有阅读角台灯亮、卧室只有夜灯、厨房暗着、窗外深蓝夜色 | 家睡着了，但留了一盏灯 |
| 清晨未醒 | 薄纱窗帘透进晨光、厨房还没开火、餐椅整齐、卧室床品微乱、整体静谧 | 一切还没开始，家还在沉睡 |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须是**单张**全景摄影——单视图、非2×2四视图、非多角度、非turnaround |
| R2 | 必须使用广角镜头（24-28mm）或标准焦段（35mm），全景深 f/8-f/11，完整空间纵深 |
| R3 | 光源必须可追溯——大窗/落地窗漫射自然光的方向与时刻匹配、暖白台灯/极简吊灯的位置和色温合理，以柔和漫射为主 |
| R4 | 场景必须有前/中/后景空间层次，前景画框→中景主体→后景延伸，**大量留白是构图核心** |
| R5 | 必须有现代北欧极简辨识度——白墙留白/原木（桦木/橡木）/亚麻棉麻/绿植/大窗柔和漫射光/几何简洁 |
| R6 | 必须有自然材质真实质感——白墙/原木天然纹理/亚麻柔软褶皱/陶瓷哑光釉/绿植鲜活、非样板间非效果图非繁复装饰 |
| R7 | **严禁出现任何人物、人影、人体轮廓、剪影** |
| R8 | 必须声明"真人实拍摄影 + 非3D渲染非CG"核心锚定 |
| R9 | 必须严格低饱和（25-45%），色彩来自自然材质与漫射光，非高饱和非明艳 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 严禁「3D渲染 / 3D建模 / CG / UE引擎 / Blender / PBR材质 / 体积光 / AO」等一切CG术语 |
| X2 | 严禁「2D手绘 / 插画 / 动画 / 二次元 / 赛璐璐」等非摄影媒介 |
| X3 | 严禁「四视图 / 2×2网格 / 多角度 / turnaround / orthographic view / blueprint」——仅单张 |
| X4 | 严禁「古风/古装/汉服/宫廷/民国/和风传统/仙侠/武侠/赛博朋克/科幻/机甲/西方奇幻/中世纪/异世界」等非现代北欧极简场景 |
| X5 | 严禁「繁复华丽装饰/金碧辉煌/巴洛克/洛可可/繁复雕花/大量装饰品堆砌/极繁主义/花纹繁复壁纸」——北欧极简为 Less is more |
| X6 | 严禁「高饱和荧光色/霓虹溢色/明艳对比色/死亡芭比粉/电子合成色/廉价滤镜感」——严格低饱和 |
| X7 | 严禁「棚拍硬光/聚光灯/强反差阴影/锐利高光/过曝死白」——本风格为大窗柔和漫射、低对比克制 |
| X8 | 严禁「样板间/售楼处效果图/全新无痕/完美品相/无生活痕迹」与「杂物堆砌脏乱差」——克制留白有生活痕迹但不堆砌 |
| X9 | 严禁「光源来源不明/全局均匀照明/无方向的光/硬光强反差」 |
| X10 | 严禁「出现任何人物/人影/人体轮廓/剪影/肢体」 |
| X11 | 严禁「过曝死白/暗部死黑/无景深/画面扁平」 |
| X12 | 严禁「水印 / 文字 / LOGO / 签名 / 边框 / AI生成痕迹」 |
