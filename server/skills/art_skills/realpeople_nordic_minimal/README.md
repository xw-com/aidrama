### 创作理念与核心价值

本手册的核心创作理念为 **"少即是多，光即是静"（Less is more, light is calm）**：

1. **留白即叙事**：北欧极简的伟大恰恰藏在"少"里。一面白墙、一束大窗漫射光、一盆绿植、一只亚麻抱枕、一本翻开的书——克制不是空洞，是把生活的注意力归还给光、材质与人本身。每一处留白都是有意的呼吸。

2. **自然材质即品格**：北欧极简不靠装饰堆砌，而靠材质说话。桦木的浅色纹理、橡木的温润、亚麻的柔软褶皱、陶瓷的哑光釉面、羊毛毯的蓬松、绿植的鲜活——这些真实材质在摄影机下的行为，是3D渲染无法复刻的审美深度。

3. **光即静默的诗**：北欧极简的灵魂是大窗柔和漫射自然光。低角度的北欧日光穿过薄纱窗帘，在白墙与原木上铺开一层柔软的漫射，阴影边缘模糊、对比克制——这种光本身就是一种生活态度：不张扬，不喧哗，让空间自己安静下来。

4. **克制写实即生活方式**：本风格为"真人写实北欧生活方式"，不是样板间，不是广告片。人物穿素色亚麻衬衫、粗针毛衣、中性色家居服，化自然裸妆，神态松弛，不刻意摆拍——一切光影、材质、人物以真实克制为底色。美学参考 Kinfolk 杂志、Norm Architects、宜家（IKEA）生活方式、H&M Home、MUJI 无印良品的克制感。

## 三、视觉风格定位

### 3.1 整体风格定位

**"电影级真人写实北欧极简生活方式美学"**

以现代北欧极简家居/生活方式为叙事舞台，以真人影视摄影为技术锚点，追求院线级生活方式/家居题材摄影的画面品质与审美高度。整体风格在"电影感"与"生活的克制真实"之间寻找黄金平衡——画面精致但不堆砌，真实但不随意，留白但不空洞，审美在线但不炫技。

## 七、使用说明

### 提示词使用原则

1. **前缀先行**：所有生成内容必须首先加载"前缀提示词"中的全局风格锚定段，锁定真人北欧极简写实质感基线
2. **专项叠加**：在全局前缀基础上，按需叠加角色/场景/道具/分镜专项提示词
3. **负面必加**：每次生成必须附带"负面提示词"，规避伪影与风格偏差
4. **迭代优化**：建议首轮生成后根据效果对专项提示词做微调，而非修改全局前缀
5. **平台适配**：本手册提示词优先适配Doubao-Seedream（生图）与Doubao-Seedance（视频生成），部分提示词可能需根据平台特性微调
