# 人物基础形象生成 · 赛博朋克写实约束手册

---

## 一、基础形象原则

1. **面容即灵魂** — 五官是角色唯一锚点，毛孔级精细渲染，霓虹环境色只作反射映肤，不覆盖皮肤底色
2. **角色为本** — 基础着装由角色描述（身份/职业/性别/场景）决定其常规着装；义体改造与特殊装备为后续叠加层
3. **四视图一致** — 面容/体型/发型/基础服装跨视图高度统一
4. **实拍夜景摄影** — 以真实夜景人像摄影为锚点，保留皮肤真实质感（毛孔/微小瑕疵/皮脂与雨水反光），拒绝舞台假光

---

## 二、面容约束

> 不再固定五官特征参数，由角色描述（性别/年龄/性格/气质）驱动 AI 自由生成五官，保证人物间外观差异化。

### 通用要求

| 项目 | 约束 |
|---|---|
| 五官 | 由角色描述自然推导，不预设脸型/眼型/眉型/鼻型/唇型 |
| 风格底色 | 真人写实摄影、夜景高反差、毛孔级精细渲染、写实材质、霓虹环境反光 |
| 气质 | 必须从角色描述提炼整体气质关键词（如锋利/疲惫/冷酷/桀骜/麻木），并写入提示词 |
| 表情 | 中性微表情，符合角色气质 |

### 男性

### 女性

| 项目 | 约束 | 提示词 |

## 六、基础服装约束

> 基础服装由角色描述（身份/职业/性别/场景）决定其最自然的常规着装，作为该角色「日常默认态」；外露义体、战术装备、礼服在服化衍生环节叠加。**禁止内衣打底**。

### 着装选择原则

| 角色身份 | 默认着装方向 |
|---|---|
| 街头浪人/底层游民 | 机能风：防水冲锋夹克、破洞针织、束绳工装裤 |
| 黑客/数据贩子 | 连帽衫 + 多口袋马甲、合体战术内搭、便携终端腕带 |
| 企业精英/塔楼阶层 | 暗色修身西装、光泽混纺面料、隐形科技配饰 |
| 义体医师/技师 | 工装围裙、机械吊带、防静电手套、工具腰包 |
| 佣兵/保安/打手 | 战术背心、局部护甲、磁扣风衣 |
| 夜店/乐队从业者 | 反光面料、PVC 混纺、宽肩廓形外套 |
| 角色描述未明确 | 暗色机能常服、低饱和底色 + 一处霓虹点缀 |

### 着装统一规则

- 服装风格须与赛博朋克写实摄影美学一致（科技面料、机能剪裁、哑光为主 + 局部反光）
- 颜色低饱和深色为主，至多一处霓虹点缀色，无复杂花纹/装饰，便于后续衍生叠加
- 面料须有现实可信细节：防水涂层反光、磨损铆钉、拉链齿痕、缝线走线
- 四视图服装款式完全一致
- 基础服装是「日常默认态」，焦点仍在面容与体态；外露义体改造默认不画，角色描述明确时仅保留轻微接驳口细节
- 严禁内衣/暴露/性化打底

## 八、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须为「自然状态」|
| R2 | 必须根据角色描述声明合适的常规着装作为基础服装（如黑客→连帽衫马甲、企业精英→暗色修身西装、佣兵→战术背心）；禁止内衣打底 |
| R3 | 必须声明「无发饰、无配饰」 |
| R4 | 必须指定「纯净深空灰背景」 |
| R5 | 必须指定「四视图一致性」 |
| R6 | 全身立像必须从头顶到脚底完整展示，严禁裁切 |
| R7 | 必须声明角色身高并通过头身比换算约束全身比例 |
| R8 | 人像特写必须从头顶到锁骨完整展示，严禁裁切头顶 |
| R9 | 皮肤必须保留真实质感，不可过度磨皮；霓虹只作环境映色，不得覆盖皮肤底色 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 内衣/暴露/性化打底；与角色描述明显不符的着装；过度复杂花纹/装饰干扰后续服化叠加 |
| X2 | 正顶硬光/正底光；整片彩色泛光灯墙 |
| X3 | 过度美白/过度磨皮至无质感 |
| X4 | 复杂场景背景（必须纯深灰底） |
| X5 | 夸张表情/动态姿势 |
| X6 | 全身立像裁切头顶或脚底，必须从头到脚完整入画 |
| X7 | 人像特写裁切头顶，必须从头顶到锁骨完整入画 |
| X8 | 忽略身高和头身比约束；外露义体改造喧宾夺主（基础态默认不画） |
