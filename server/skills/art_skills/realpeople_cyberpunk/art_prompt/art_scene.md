# 场景图生成 · 赛博朋克写实约束手册

---

## 一、场景美学原则

1. **空间叙事** — 场景承载情绪与叙事功能，不是纯背景板；霓虹密度与阶层落差本身就是叙事
2. **层次纵深** — 所有场景必须具备前/中/后景，杜绝扁平；招牌层、行人层、车流层错位排布
3. **质感至上** — 湿沥青/锈蚀金属/全息膜/塑料棚布/混凝土等材质纹理必须超清晰
4. **实拍为锚** — 一切画面以真实夜景摄影为标准，拒绝 3D 渲染/CG 动画质感；追求镜头光学特征（景深虚化、镜头暗角、霓虹光晕衍射、色散微痕）与物理光照（湿地镜面反射、蒸汽体积光、焦散投影）

## 五、主视图规范

### 视图定义

> 单画面主视图，从场景中最具代表性的角度拍摄，承载空间叙事与构图重心。

| 项目 | 约束 | 提示词 |
|---|---|---|
| 视角 | 自然观察视角，构图最能体现场景主体与纵深 | hero shot、representative angle |
| 视点高度 | 默认人眼平视高度，特殊场景可俯/仰 | eye level（默认） |
| 构图 | 主体居中或符合三分法，前/中/后景层次清晰 | balanced composition |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 单画面（非拼图、非多视图、非分屏） |
| 人物 | **严禁出现任何人物、人影、人体轮廓** |
| 一致性 | 风格/材质/色调/光线统一 |
| 光线 | 光源逻辑一致，霓虹主次分明，暗部保留可辨层次 |
| 画面比例 | 默认 16:9（或按调用方设定） |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 场景必须有「前中后景层次」 |
| R2 | 室外必须包含「雨雾空气透视」与「远景霓虹晕染」 |
| R3 | 场景图必须为「单画面主视图」，不得拼接多视图/分屏/网格 |
| R4 | 构图须能代表场景主体并展示前/中/后景层次 |
| R5 | 场景图中**严禁出现任何人物** |
| R6 | 必须包含实拍摄影关键词（real photography / photorealistic / RAW photo） |
| R7 | 必须包含镜头光学特征（shallow depth of field / neon bokeh / lens vignette 至少一项） |
| R8 | 材质必须带有锈蚀/油污/磨损等使用痕迹，霓虹须有明暗主次，禁止荧光过曝糊成一片色雾 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 背景纯白/纯黑/无场景 |
| X2 | 极端天候（台风/雷电大作/冰暴，除非剧情需要） |
| X3 | 场景无纵深/无层次 |
| X4 | 全息/科技元素与雨夜都市世界观矛盾（禁止魔法/仙术/蒸汽朋克主体） |
| X5 | 出现任何人物、人影、人体剪影或人体轮廓 |
| X6 | 画面被拼接成多视图/网格/分屏布局 |
| X7 | 3D 渲染/CG 动画/卡通/游戏引擎质感（禁用 3D render、CGI、Unreal Engine、Unity 等词） |
| X8 | 材质过于干净完美、无任何使用痕迹与岁月感（避免"塑料感"）；过度锈蚀成废土风也禁止 |
| X9 | 光照过于均匀平坦、无景深虚化、无镜头光学特征；荧光过曝整片失焦 |
