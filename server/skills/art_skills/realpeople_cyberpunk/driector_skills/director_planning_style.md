# 赛博风格约束 · 赛博朋克写实 · 技法参考

---

## 一、色调体系与画面基调

- **色调基底** — 全片以夜幕蓝黑（C1）、沥青蓝灰（C10）、深空灰（C9）为基底色，整体色温冷色基底（3800-4500K），饱和度中高（55-75%，暗部低饱和），呈现冷峻迷离的雨夜都市感
- **霓虹叙事对比** — 霓虹色（品红霓虹 C3、霓虹青 C4、电紫 C5、酸性黄 C6）作为欲望、诱惑与资本力量的视觉信号，钨丝暖橙（C7）与冷调肤（C2）留给人物情感与人性时刻。霓虹与暖光的切换应与情绪弧线同步
- **冷暖分配策略** — 街头/工作/麻木段落以冷青紫为主，亲密/觉醒/救赎段落释放暖橙；避免全程高密度霓虹导致视觉疲劳与情绪层次塌陷
- **色盘先行原则** — 段落规划先绑定情绪场景（独行/相遇/对峙/觉醒/沉沦等），再确定主色+辅色与光影方案，避免"剧情对了但情绪不对色"
- **禁用色域** — 糖果粉彩、明亮田园色、高饱和荧光糊成一片的失焦色雾与本风格不兼容

## 二、光影方案体系

- **光影即叙事** — 6 套光影方案对应不同情绪段落，导演规划阶段应在段落层面确定光影基调方向，而非逐镜指定
- **光源角度** — 正给镜头默认 30° 斜射（较柔和），侧给镜头根据场景与人物关系微调；霓虹光源须有主次，禁止均质泛光

| 光影方案 | 方案名 | 色调倾向 | 适用情绪 |
|---|---|---|---|
| A | 雨夜漫射 | 沥青蓝灰底 + 均匀湿地反光 | 日常独行、街头生活流叙事 |
| B | 品红侧光 | 品红霓虹 + 面部映色 | 暧昧试探、欲望靠近 |
| C | 屏幕青光 | 霓虹青主导 + 深空灰背景 | 数据作业、专注冷峻 |
| D | 全息高峰辉光 | 电紫+霓虹青密集 + 体积雾 | 都市沉浸、喧嚣迷失 |
| E | 暖橙点光源 | 钨丝暖橙主导 + 冷蓝背景 | 觉醒救赎、人性回温 |
| F | 顶光硬切 | 冷白硬光 + 大暗部分割 | 对峙压迫、危机冲突 |

- **冷暖光分配** — 霓虹光可全片使用但需分层控制；冲突/疏离段落降低暖光占比，避免情绪与光色冲突
- **氛围方向映射** — 每场戏氛围方向应映射到上述光影方案（A-F）的某一方向，确保视觉一致性

## 三、质感方向

- **超清纪实感** — 真人写实摄影核心：皮肤纹理可见、发丝根根分明、雨水挂珠与皮脂反光可信
- **夜景高反差 + 极致细节** — 作为画面质感锚点。不是均质亮场，也不是糊成一片的霓虹色雾，而是暗部有层次、高光有节制的电影级夜景
- **材质真实** — 服化道需具备现实可信度：科技面料涂层反光、义体金属拉丝、湿地镜面、塑料棚布、锈蚀管线都应符合雨夜都市实拍逻辑
- **皮肤质感** — 保留真实毛孔与细微瑕疵，霓虹环境色只作映肤不覆盖底色，控制磨皮强度，追求"真实但好看"
- **写实不等于平淡** — 通过景别压缩、倒影构图、光束切割空间放大情绪感染力，而非依赖光效堆砌

## 四、赛博场景空间元素

赛博朋克世界观特有的场景元素及其视觉叙事功能：

- **叠层招牌/全息广告/玻璃幕墙** — 天然的前景遮挡与色彩滤镜，制造空间分层；广告内容可直接讽刺或呼应角色处境
- **雨夜街道/积水/天台/轨道** — 都市节奏与阶层落差载体：积水倒影用于自我审视，天台边缘用于抉择时刻，轨道光带用于速度与逃离
- **义体诊所/地下酒吧/胶囊公寓/企业塔楼** — 情绪容器：诊所偏身份焦虑，酒吧偏欲望交易，胶囊公寓偏孤独喘息，塔楼偏权力冷感
- **雾气、蒸汽与光束作为转场** — 车灯扫过、全息广告切换、蒸汽涌起遮画、霓虹熄灭与亮起可用于段落情绪缓冲，避免硬切
- **转折点用视觉而非解释** — 优先使用画面手段（倒影破碎、镜面分离、灯光骤灭、瞳孔义眼亮起）承接情绪转折，减少对白解释负担

## 五、赛博乐器与环境音

赛博朋克世界观下的声音元素约束：

### 乐器选择

- **合成器浪潮（Synthwave）** — 日常、夜行、都市游荡段落核心配器，最能体现霓虹都市质感
- **工业电子（Industrial Electronic）** — 压迫、追逐、冲突段落的有效主导，机械节拍强化危机感
- **暗黑氛围（Dark Ambient）** — 麻木、疏离、底层挣扎段落的铺底底色
- **低频贝斯/鼓机** — 地下酒吧、夜生活、情绪抬升段落的节奏引擎
- **孤音钢琴/暖声合成器** — 觉醒、救赎、人性时刻的稀缺暖色，与冷底配器形成反差
- **环境音优先级高** — 赛博都市剧中真实环境声是沉浸感关键，配乐不应压过对白

### 乐器组合策略

| 情绪阶段 | 乐器组合 |
|---|---|
| 平稳/开场/收尾 | 暗黑氛围铺底 或 合成器浪潮独走 |
| 日常推进 | 合成器浪潮 + 鼓机轻拍 |
| 暧昧升温/欲望 | 合成器浪潮 + 暖声合成器旋律 |
| 追逐/冲突/危机 | 工业电子主导 + 低频贝斯 |
| 觉醒/救赎/收束 | 孤音钢琴 + 弦乐化合成器 |

### 赛博环境音

- **典型环境音层次** — 持续雨声 / 电流嗡鸣 / 全息广告循环播报 / 磁悬浮列车呼啸 / 服务器风扇底噪 / 人群多语言杂语 / 远处警笛 / 摊贩油烟滋响
- **每场戏标注 1-2 个核心环境音**，帮助后续音效设计。环境音层次越准确，赛博都市质感越强
- **留白建议** — 觉醒与抉择时刻可抽掉全部配乐，只留雨声与呼吸声，让"城市噪音的消失"成为情绪事件
