## 二、全局色彩盘（风格基线，不是硬锁）

> 目标：统一审美而非限制创作。除「硬约束色」外，其余颜色默认优先使用，可在合理范围内偏移。霓虹色是本风格核心语言，允许出现，但只作为光源与反射存在，禁止荧光过曝糊成一片色雾。

### 色彩使用层级

| 层级 | 约束强度 | 说明 |
|---|---|---|
| L1 硬约束 | 高 | 仅锁定角色识别核心：肤色、发色、主服底色的审美方向 |
| L2 软约束 | 中 | 场景色、霓虹点缀色、配饰色优先参考色盘，可按镜头与剧情微调 |
| L3 例外机制 | 低 | 追逐/觉醒/赛博空间高潮戏可临时增强霓虹密度，但需保留暗部层次 |

### 硬约束色（默认锁定）

| 色项 | 对应色 | 规则 |
|---|---|---|
| 肤色基准 | C2 冷调肤 | 默认优先，允许霓虹环境色映在皮肤但底色不变 |
| 发色/瞳色基准 | C1 夜幕蓝黑 | 默认深黑/深棕，角色设定明确时允许 C3/C4/C5 霓虹挑染或全染 |

### 软约束色（推荐优先）

> C3/C4/C5/C6/C7/C8/C9/C10 为推荐色域，用于霓虹招牌、全息投影、义体金属、街面湿反光等。可根据镜头氛围做同色相邻近调整。

### 情绪色盘（导演对齐版）

### 情绪色盘使用规则

| 编号 | 规则 |
|---|---|
| E1 | 每条提示词至少指定 1 个「情绪场景」并绑定主色+辅色组合 |
| E2 | 单镜头霓虹主色不超过 2 个，避免颜色叙事失焦 |
| E3 | 情绪切换时优先调整光比与霓虹密度，再调整饱和度 |
| E4 | 赛博朋克默认遵循「夜底 + 霓光落点」：暗色铺底，霓虹只落在光源可见处与人物边缘，不淹没面部底色 |
| E5 | 若与剧情冲突，以情绪色盘优先于通用推荐色，但不得突破严禁项 |

### 色温约束

| 参数 | 值 | 说明 |
|---|---|---|
| 整体色温 | 冷色基底 3800-4500K（推荐） | 雨夜都市主基调，霓虹光源可局部大跨度混色 |
| 肤色色温 | 中性偏冷 4800-5200K（推荐） | 允许环境映色，但皮肤底色保持真实 |
| 对比度 | 极强（建议保持） | 夜景高反差，明暗分割鲜明 |
| 饱和度 | 中高 55-75%（建议区间） | 霓虹区域局部可更高，暗部保持低饱和 |

### 容差与例外

| 项目 | 建议容差 |
|---|---|
| 色相偏移 | ±10° |
| 饱和度偏移 | ±12% |
| 明度偏移 | ±15% |

> 例外场景：追逐、觉醒、赛博空间镜头可增强局部霓虹密度与饱和；但禁止荧光过曝、整片失焦色雾，暗部必须保有可辨层次。

## 三、全局约束规则

### 必守规则（所有技能继承）

| 编号 | 规则 |
|---|---|
| R1 | 必须包含「真人写实摄影」风格锚定词 |
| R2 | 必须声明「夜景高反差 + 极致细节」 |
| R3 | 面部必须使用「面容细腻渲染 + 皮肤细腻」并允许霓虹环境色映肤 |
| R4 | 发丝必须使用「根根分明 + 发丝细腻渲染」，霓虹边缘光下轮廓清晰 |
| R5 | 纹理必须声明「纹理细节超清晰」，并至少含一项风格质感词（湿地反光/全息辉光/体积雾气/金属拉丝） |

### 严禁项（所有技能继承）

| 编号 | 严禁内容 |
|---|---|
| X1 | 严禁「卡通/动漫/二次元/插画风」 |
| X2 | 严禁「荧光过曝/整片失焦色雾/纯装饰性滤镜光斑」（霓虹光源本身允许） |
| X3 | 严禁「未来元素缺失」（必须明确赛博都市环境与科技细节） |
| X4 | 严禁「面部变形/多指/肢体异常」倾向词 |
| X5 | 严禁「裸体/暴露/透视/暗示性描述」 |
| X6 | 严禁「古风/古装/汉服/传统建筑主体」（中文/日文霓虹招牌属赛博都市画内元素，不属古风） |
