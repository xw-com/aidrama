# 赛博朋克写实风格说明

本风格专为"赛博朋克写实"题材打造，所有美术提示词、规范和生成内容均严格限定于：

- **未来世界观**：以 Blade Runner 式雨夜都市为背景，涵盖霓虹商业街、义体诊所、地下酒吧、胶囊公寓、企业塔楼等，杜绝未来元素缺失。
- **真人写实**：所有角色、场景、道具均以真人写实摄影为标准，强调五官、皮肤、发丝、材质等极致细节与真实质感。
- **赛博都市纪实**：在写实基础上追求影视级夜景氛围，画面明暗反差极强，霓虹与湿地反光层次丰富，整体氛围冷峻、迷离、"高科技低生活"。
- **暗夜张力**：适合展现疏离、抗争、欲望、救赎的赛博都市故事，强调雨夜霓虹下的情感表达。

## 适用范围

- 赛博朋克真人题材的AI美术生成（角色、场景、道具、分镜等）
- 需要极致写实、夜景高反差、霓虹氛围的视觉创作

## 严禁内容

- 卡通、动漫、插画、二次元风格
- 未来元素缺失、古风/古装/传统建筑主体
- 荧光过曝、整片失焦色雾、纯装饰性滤镜光斑
- 暗示性、暴露、透视等不适宜内容

## 风格体验

在本风格下，您将体验到：

- 角色面容精致、气质锋利或疲惫，服饰、妆容、发型均为赛博机能写实，可含义体改造细节
- 场景空间层次丰富，全息广告、中文/日文招牌、蒸汽与湿地反光纹理超清晰
- 道具、义体组件、全息终端、科技武器均为未来造型，工艺精细，质感极致
- 分镜与视频均以真人写实夜景为基础，强调叙事与情感表达

---

本风格仅适用于"赛博朋克写实"相关项目。如需其他风格（如古风、都市现代、插画、动漫等），请勿使用本套提示词。
