# 少年热血漫画约束 · 少年热血漫画 · 技法参考

---

## 一、色调体系与画面基调

- **色调基底** — 全片以核心色盘为基底：烈焰橙（C1 #E8650C）、热血红（C2 #C82828）、天空蓝（C3 #2E8BD0）、热血黄（C4 #F0C020）、墨黑（C5 #1A1A1A）、钛白（C6 #F0F0F0）、钢灰（C7 #6A7080）、能量绿（C8 #3ED870）、战损铜（C9 #8A5A2A）、紫电（C10 #7B3DB5），整体色温偏暖（4500-5200K），饱和度中高（60-75%），呈现热血战斗色盘强烈饱满的燃系画面
- **冷暖叙事对比** — 暖色（烈焰橙 C1、热血红 C2、热血黄 C4）作为热血/觉醒/爆发的视觉信号；冷色（天空蓝 C3、墨黑 C5、钢灰 C7）作为冷静蓄势/对峙肃杀的视觉信号；紫电 C10 与能量绿 C8 作为异能/必杀技的特殊能量信号。冷暖切换应与战斗弧线同步，而非随意混用
- **冷暖分配策略** — 热血觉醒/必杀爆发段落使用暖色调（烈焰橙 + 热血红 + 热血黄高光）；宿命对决/反派降临段落使用冷调对峙（墨黑 + 钢灰 + 紫电暗辉），禁用暖橙柔光；修炼成长段落使用冷静蓄势（天空蓝 + 钢灰 + 晨光）
- **色盘先行原则** — 段落规划需先绑定战斗情绪场景（热血觉醒/宿命对决/必杀爆发/兄弟羁绊/反派降临/修炼成长/战场末日等），再确定主色+辅色与光影方案，避免"剧情对了但情绪不对色"
- **禁用色域** — 柔和少女粉嫩色、水彩治愈低饱和色、暗黑低明度压抑全程色调均与本风格不兼容。色相偏移容差 ±10°，饱和度偏移 ±12%，明度偏移 ±15%

## 二、光影方案体系

- **光影即叙事** — 7 套光影方案对应不同战斗情绪段落，导演规划阶段应在段落层面确定光影基调方向，而非逐镜指定
- **热血漫光影为锚** — 所有光影方案必须保持锐利墨线 + 网点排线 + 高对比的漫画手绘质感，允许速度线集中线、能量气焰自发光、爆炸火光、闪电等燃系光效，禁止柔和少女柔光/水彩晕染
- **光源角度** — 正给镜头默认 38.5° 斜射硬光（高对比漫画质感），侧给镜头与战斗动作镜头可强化逆光轮廓与速度线

| 光影方案 | 方案名 | 色调倾向 | 适用情绪 |
|---|---|---|---|
| A | 速度线冲击 | 钛白底 + 烈焰橙/热血黄集中线 | 热血觉醒、突破极限、冲刺突进 |
| B | 能量气焰自发光 | 能量绿/热血黄气焰 + 钛白核心 | 必杀技蓄力、能量爆发、变身觉醒 |
| C | 爆炸火光 | 烈焰橙 + 热血红火光 + 墨黑暗部 | 战场破坏、技能碰撞、爆裂轰击 |
| D | 强逆光对峙 | 钛白逆光 + 墨黑剪影 | 宿敌登场、对峙博弈、决战前夕 |
| E | 必杀技爆发（特化） | 热血黄 + 钛白爆光 + 能量绿气焰 + 满屏集中线 | 终极奥义、最强必杀、高潮爆发 |
| F | 雷电交加 | 紫电 + 钛白闪光照亮 | 雷系技能、异能量释放、天罚降临 |
| G | 冷静蓄势 | 天空蓝 + 钢灰冷光 | 修炼独处、战略思考、回忆沉淀 |

- **冷暖光分配** — 暖色光（烈焰橙/热血红/热血黄）适用于热血觉醒/爆发段落；宿命对决/反派降临段落使用强逆光对峙（D）+ 紫电暗辉（F），冷调为主。导演可根据叙事需要调整冷暖切换点
- **氛围方向映射** — 每场戏的氛围方向应能映射到上述光影方案（A-G）的某一方向，确保视觉一致性。必杀技高潮段落应直接绑定方案 E（必杀技爆发特化）

## 三、质感方向

- **锐利墨线 + 网点排涂为锚** — 少年热血漫画的核心：粗黑墨线勾边、网点排线铺底、局部强彩、高对比，禁止色块断层/色彩溢出/细弱发丝线条
- **锐利动态线条 + 能量气焰** — 这是画面质感的锚点。不是写实摄影，不是 3D CG，是 2D 手绘漫画渲染加热血战斗美学的融合，速度线集中线与能量气焰自发光是标志性质感
- **材质漫画化** — 所有服化道的材质必须以热血漫笔触呈现：金属的反光用冷光泽硬线、能量核心的自发光用强彩高光+集中线辐射、肌肉的张力用墨线分块+网点排线。禁止"3D 感"和"写实摄影感"
- **皮肤质感** — 健康古铜/坚毅肤色、锐利墨线勾边、肌肉分块清晰、汗水高光、能量气焰环境光反射。禁止柔嫩少女肤质/惨白无血色/水彩晕染
- **热血漫不等于杂乱** — 少年热血漫画强调在粗黑墨线基础上通过速度线集中线、能量气焰、夸张透视、景深虚化等手段强化动态张力与电影感，而非杂乱无章的特效堆砌

## 四、少年热血场景空间元素

热血战斗世界观特有的场景元素及其视觉叙事功能：

- **断壁残垣/弹坑焦土/碎石残骸/残旗** — 战场废墟的天然构图道具，制造惨烈感与纵深感，以战损刮痕+焦黑墨线呈现战斗痕迹
- **竞技场擂台/能量护栏/聚光灯/观众席** — 武斗竞技的载体，擂台 = 燃/万众瞩目，聚光灯 = 焦点/对决（方案A），能量护栏 = 危险/张力
- **熔岩流/火山口/焦石/热浪** — 火山决战场的光源载体与危险信号，熔岩火光 = 爆炸火光（方案C），热浪扭曲空气 = 张力/生死搏杀
- **瀑布/山崖/修炼台/古松** — 修炼山的载体，瀑布飞流 = 坚毅磨砺，山崖晨光 = 冷静蓄势（方案G）
- **能量气焰/速度线集中线/闪电/血月** — 热血世界的戏剧光源与能量载体，速度线 = 冲刺/突破（方案A）、能量气焰 = 必杀蓄力（方案B）、闪电 = 雷系/天罚（方案F）、血月 = 压迫/不祥
- **段落间用场景空镜过渡** — 本风格有丰富的战场资产（不同时段/天候/景别变体），段落衔接建议用战场空镜做情绪缓冲，配合速度线或能量气焰做燃系转场，不要硬切
- **转折点用视觉而非台词** — 优先使用画面手段（光影突变、必杀技爆发、景别跳切、空镜隐喻）而非依赖对白解释
- **前中后景层次与夸张透视** — 所有场景必须具备前/中/后景与夸张透视，杜绝扁平，室外必须包含空气透视（远景硝烟/能量气焰弥漫）

## 五、热血漫配器与环境音

热血战斗世界观下的声音元素约束：

### 配器选择

- **电吉他（失真/重金属）** — 热血觉醒、突破极限、战斗爆发的核心乐器，与速度线冲击（方案A）/必杀爆发（方案E）高度适配
- **交响史诗（铜管+弦乐群）** — 宿命对决、史诗决战、终极奥义段落，铜管的英雄感适合情绪顶点
- **太鼓/和太鼓** — 战斗节奏推动器、必杀技蓄力的心跳节拍，与能量气焰自发光（方案B）适配
- **电子合成器** — 能量爆发、异能量释放、机械改造/未来都市段落，与能量气焰/紫电闪（方案B/F）适配
- **重型鼓点（双踩/blast beat）** — 高强度激战、苦战鏖战段落，节奏推动器
- **人声合唱（史诗合唱）** — 终极奥义、最强必杀、兄弟羁绊顶点，慎用但一用即核弹
- 弦乐铺底可增加电影感但不宜喧宾夺主

### 配器组合策略

| 情绪阶段 | 配器组合 |
|---|---|
| 集结/备战/开场 | 电子合成铺底 + 太鼓心跳 |
| 热血觉醒/突破 | 电吉他失真主奏 + 重型鼓点 |
| 必杀蓄力/能量爆发 | 太鼓渐强 + 电子合成 + 弦乐上扬 |
| 必杀爆发/终极奥义 | 电吉他 + 交响史诗铜管 + 史诗合唱 |
| 宿命对峙/决战前夕 | 交响弦乐低音 + 太鼓低频 + 寂静留白 |
| 反派降临/危机 | 电子合成低频 + 不和谐铜管 + 重型鼓点 |
| 兄弟羁绊/希望 | 交响弦乐温暖 + 钢琴 + 电吉他清音 |
| 修炼/独处/回忆 | 钢琴独奏 或 笛子 + 弦乐衬底 |

### 热血战斗环境音

- **典型环境音层次** — 爆炸轰鸣 / 金属碰撞铮响 / 能量气焰翻涌嘶吼 / 碎石坠落 / 雷电轰鸣 / 风沙咆哮 / 巨剑破空呼啸 / 战场烈火噼啪 / 警报蜂鸣 / 心跳加速 / 战损崩裂
- **每场戏标注 1-2 个核心环境音**，帮助后续音效设计。环境音层次越丰富，热血战场越有沉浸感与燃系张力
