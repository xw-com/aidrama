# 分镜表少年热血漫画约束 · 少年热血漫画 · 技法参考

---

## 一、分镜表定位

分镜表是导演将剧本转化为镜头语言的核心工具。以下仅提供少年热血漫画风格在分镜表层面的约束规范。

---

## 二、光影与氛围

- **燃系光影统一** — 一场戏内光影方案必须保持热血漫手绘质感一致性，阴影使用墨黑网点/同色系加深（禁止水彩柔和晕染阴影），除非有明确的叙事转折（如必杀技爆发→速度线满屏）
- **情绪色盘绑定** — 每场戏至少绑定 1 个战斗情绪场景（热血觉醒/宿命对决/必杀爆发/兄弟羁绊/反派降临/修炼成长/战场末日），并在镜头组内保持主色+辅色连续性，色彩取自核心色盘（烈焰橙 #E8650C / 热血红 #C82828 / 天空蓝 #2E8BD0 / 热血黄 #F0C020 / 墨黑 #1A1A1A / 钛白 #F0F0F0 / 钢灰 #6A7080 / 能量绿 #3ED870 / 战损铜 #8A5A2A / 紫电 #7B3DB5）
- **光源角度规范** — 正给镜头光源默认 38.5° 斜射硬光（高对比漫画质感），战斗动作镜头可强化逆光轮廓与速度线。描述光影时须区分正给/战斗动作的角度差异，光影渲染始终保持热血漫手绘质感
- **冷暖色调与战斗阶段匹配** — 热血觉醒/必杀爆发段落使用暖色调（烈焰橙 + 热血红 + 热血黄高光），禁用冷蓝柔光；宿命对决/反派降临段落使用冷调对峙（墨黑 + 钢灰 + 紫电暗辉）；修炼成长段落使用冷静蓄势（天空蓝 + 钢灰 + 晨光）
- **光影转场是高级手段** — 从冷静蓄势（晨光蓝）渐变到必杀技爆发（热血黄+钛白爆光）= 觉醒突破的能量升腾。在分镜表中标注光影变化点，转场过程中速度线集中线必须从无到满屏渐变，禁止突兀断层
- **燃系光效** — 允许合理使用速度线集中线、能量气焰自发光、爆炸火光、闪电、运动模糊、体积光等燃系光效与渲染技法，但必须保持少年热血漫画锐利墨线+网点排线的美学基调，禁止 3D 写实/CG 动画光效

---

## 三、环境动态

- **环境动态增加画面燃系张力** — 速度线集中线、能量气焰翻涌、碎石飞溅、披风翻飞、爆炸冲击波、闪电频闪、硝烟翻滚。每 2-3 个镜头至少安排一个有环境动态的镜头，避免画面"死"掉
- **热血漫环境元素优先** — 环境动态应选用热血战斗世界观内的元素：速度线、集中线、能量气焰、爆炸冲击波、碎石飞溅、披风翻飞、闪电、血月、硝烟、能量纹路蔓延，禁止出现柔美治愈元素（樱花飘/治愈暖阳/萌系光点）
- **漫画动态质感** — 环境动态元素（速度线/能量气焰/碎石等）必须保持锐利墨线+网点排线质感，禁止出现 3D 粒子特效或写实流体效果

---

## 四、少年热血动作节奏

- **动作凌厉且带燃系张力** — 人物动作默认凌厉干脆、动态张力强，可在关键帧上做燃系夸张处理（如必杀技爆发的满屏集中线、冲刺时的速度线拖尾、挥拳时的动态模糊），出拳、挥剑、冲刺应标注"凌厉/燃系张力"
- **披风战袍动态是核心画面资产** — 热血漫战袍披风（长披风、战带、飘带、发丝）的翻飞是天然的动态资产，可在画面描述中加入披风/战带/发丝的动态，热血漫渲染下的战袍翻飞应锐利墨线清晰、动态张力强
- **战斗仪态约束** — 热血人物的举止应符合战斗气质：战斗姿态稳健、出拳挥剑凌厉有力、不出现柔美化的肢体语言（如少女式扭捏）。二次元角色可在表情上燃系夸张（怒目圆睁、嘴角狂笑、青筋暴起），但战斗动作仍需干脆凌厉
- **夸张透视与动态张力** — 动作设计中应充分利用夸张透视（如挥拳近大远小、必杀技仰视压迫感），强化燃系动态张力
- **头身比一致** — 动作设计中角色必须保持 7-8 头身的热血漫夸张比例，禁止因动态姿势而破坏头身比，禁止 Q版可爱比例

---

## 五、材质与质感约束

- **锐利墨线 + 网点排涂为锚** — 所有镜头中人物/战袍/护甲/武器/战场的渲染必须保持锐利墨线勾边 + 网点排线质感，线条粗黑清晰，色块高对比，禁止 3D 写实/CG 动画/照片级渲染
- **战袍护甲材质** — 金属甲片 + 皮革束带 + 能量纹路的质感用热血漫笔触表现，纹理必须超清晰，战甲质感清晰
- **武器道具材质** — 金属冷光泽、能量晶体自发光、皮革战斗磨损，均以锐利墨线 + 网点排线 + 能量气焰呈现，禁止写实材质渲染
- **战场材质** — 战损断壁、刮痕凹陷、烟尘焦痕、碎石残骸，材质带有战场战损感但以少年热血漫笔触呈现，禁止"塑料感"的全新无瑕材质

---

## 六、色彩约束

- **核心色盘锁定** — 分镜表中所有镜头的色彩必须取自核心色盘（C1-C10），色相偏移容差 ±10°，饱和度偏移 ±12%，明度偏移 ±15%
- **禁用柔美色** — 严禁柔和少女粉嫩色/水彩治愈低饱和色/暗黑低明度压抑全程色调出现
- **线条颜色** — 墨黑粗线为主，禁止细弱发丝线条
- **阴影色** — 墨黑网点/同色系加深，禁止水彩柔和晕染阴影
- **整体色温** — 偏暖 4500-5200K 热血主基调，对比度 65-85%，饱和度 60-75%（热血色盘强烈饱满）

---

## 七、运镜禁忌

- **禁用过度柔缓运镜** — 过度缓慢优雅的运镜与少年热血漫画的燃系张力冲突，战斗场景应保持动态运镜节奏（可适度使用急推、甩镜强化冲击感），但仍需保持画面锐利清晰
- **禁用花式转场** — 划屏、百叶窗、旋转等花哨转场与本风格不兼容；燃系转场应使用速度线冲屏、能量气焰吞没、白光爆切等热血漫语言
- **禁用写实镜头语言** — 手持摇晃/纪录片式跟拍/鱼眼镜头等写实手法与热血漫美学冲突，破坏锐利墨线+网点排线的画面纯净感
- **禁用柔美化处理** — 柔光镜/梦幻光晕/少女系柔焦等与热血战斗气质完全冲突，禁止使用
