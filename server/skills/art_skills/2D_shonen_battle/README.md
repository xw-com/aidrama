# 少年热血漫画风格说明

本风格专为"少年热血漫画"题材打造，所有美术提示词、规范和生成内容均严格限定于：

- **少年热血战斗漫画**：以少年热血战斗漫画美学为锚的燃系动态视觉体系，涵盖武斗竞技、异世界战斗、机甲对战、修炼成长等题材
- **燃系手绘美学**：锐利动态粗黑线条、速度线/集中线、能量气焰特效、夸张透视与动态张力，黑白漫画网点与局部强彩色结合
- **少年漫手绘渲染技法**：手绘网点铺底、墨线勾边、局部强彩、能量气焰自发光，漫画分镜与动态张力并重
- **战斗张力**：硬朗肌肉、坚毅/狂气眼神、伤疤战损、夸张动态姿势、战袍披风翻飞
- **锐利笔触**：粗黑墨线、网点排线、速度线集中线、能量光效，精致的角色与场景设计
- **少年热血电影质感**：电影级构图、高对比硬光、动态张力、情绪氛围

## 适用范围

- 少年热血漫画题材的AI美术生成（角色、场景、道具、分镜等）
- 需要燃系动态、手绘漫画质感、战斗张力的视觉创作
- 热血动漫、游戏美术、概念设计、插画创作

## 严禁内容

- 完全写实摄影/3D写实渲染/真人实拍
- 柔和少女粉嫩/水彩治愈/治愈系清新
- 暗黑低明度压抑/恐怖血腥过度
- 扁平low-poly/3D卡通圆润/Q版可爱
- 粗劣线条/模糊画质/低精度建模
- 色彩混乱/风格不统一/审美崩坏

## 风格体验

在本风格下，您将体验到：

- 角色造型锐利挺拔，战袍护甲精致，粗黑墨线动态张力强
- 场景充满战斗氛围，战场废墟与竞技场细节丰富，速度线与能量气焰渲染炸裂
- 道具器物考究，能量武器与护甲材质质感清晰，色彩对比强烈统一
- 分镜与渲染均强调燃系动态、少年热血美学、漫画手绘与电影质感
