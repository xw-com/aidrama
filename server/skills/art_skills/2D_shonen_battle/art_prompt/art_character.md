# 人物基础形象生成 · 约束手册

---

## 一、基础形象原则

1. **造型即灵魂** — 角色造型是核心锚点，少年热血漫画造型，锐利动态粗黑线条
2. **底模即基础** — 基础打底战袍 + 素颜，后续服化均为叠加层
3. **四视图一致** — 面容/体型/发型/基础战袍跨视图高度统一
4. **战斗气质** — 无妆状态仍需体现角色战斗气质（热血/狂气/坚毅/冷酷）
5. **肌肉张力** — 默认战斗体态，肌肉线条与动态张力是热血漫角色根基

---

## 二、面容约束

> 不再固定五官特征参数，由角色描述（性别/年龄/性格/原型/气质）驱动 AI 自由生成五官，保证人物间外观差异化。

### 通用要求

| 项目 | 约束 |
|---|---|
| 五官 | 由角色描述自然推导，不预设脸型/眼型/眉型/鼻型/唇型 |
| 风格底色 | 少年热血漫画风格、锐利动态线条、速度线集中线、能量气焰特效、燃系分镜、高对比、夸张透视 |
| 气质 | 必须从角色描述提炼整体气质关键词（如热血坚毅/狂气桀骜/冷静凌厉/宗师沉稳），并写入提示词 |
| 眼神 | 坚毅或狂气眼神，锐利有神，符合角色战斗气质 |
| 伤疤 | 可按角色原型添加标志性伤疤（如十字疤/眼角疤/颧骨疤），写入提示词 |
| 表情 | 中性战斗微表情，符合角色气质 |

### 人物原型与五官特征

| 原型 | 典型五官特征 | 眼神气质 |
|---|---|---|
| 热血主角 | 锐利五官、剑眉星目、嘴角坚毅 | 坚毅炽热、目光向前 |
| 宿敌/劲敌 | 凌厉五官、眉峰锋利、薄唇 | 狂气桀骜、目光锐利 |
| 师父/宗师 | 沉稳五官、眉目深邃、留须（可选） | 深沉睿智、目光悠远 |
| 伙伴 | 爽朗五官、浓眉大眼 | 真诚明亮、目光灵动 |
| 反派BOSS | 锐利阴鸷五官、窄眼、高颧骨 | 阴鸷压迫、目光冰冷 |
| 机械改造人 | 锐利五官、机械义眼/焊疤 | 冷酷机械、目光锋利 |
| 剑士/格斗家 | 凌厉五官、刀削面庞、紧抿唇 | 凌厉专注、目光如刀 |

| 肤色 | 健康古铜/坚毅肤色、全身均匀、肌肉张力强 | 古铜肤色、健康质感、肌肉线条清晰、少年热血漫肤色 |

## 六、基础服装约束

> 基础服装无特殊约束，默认为基础战袍/战斗服打底。正式战袍护甲在服化衍生环节叠加。

### 男性基础服装

素色基础战袍/战斗服，颜色以基础色为主，无纹章装饰，覆盖躯干。

### 女性基础服装

素色基础战斗服/战袍，颜色以基础色为主，无纹章装饰，覆盖躯干。

### 着装统一规则

- 服装风格统一，确保后续战袍护甲叠加无色彩干扰
- 战斗服为安全打底，焦点在面容、肌肉张力与战斗体态
- 四视图服装款式完全一致
- 基础服装仅为安全打底，正式战甲/披风/护具在衍生环节叠加

## 八、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须为「素颜状态」 |
| R2 | 必须声明基础服装（男性：素色基础战袍/战斗服；女性：素色基础战斗服） |
| R3 | 必须声明「无发饰、无配饰、无护甲」 |
| R4 | 必须指定「钛白纯色背景」 |
| R5 | 必须指定「四视图一致性」 |
| R6 | 全身立像必须从头顶到脚底完整展示，严禁裁切 |
| R7 | 必须声明角色身高并通过头身比换算约束全身比例（男性默认 175-190cm/7-8头身，女性默认 165-180cm/7-8头身） |
| R8 | 人像特写必须从头顶到锁骨完整展示，严禁裁切头顶 |
