# 场景图生成 · 约束手册

---

## 一、场景美学原则

1. **空间叙事** — 场景承载战斗情绪与叙事功能，不是纯背景板；战场废墟即惨烈、竞技场即燃、修炼山即坚毅
2. **层次纵深** — 所有场景必须具备前/中/后景，杜绝扁平；热血漫强调夸张透视与纵深感
3. **质感至上** — 断壁残垣/金属装甲/岩浆/能量纹路等材质纹理必须超清晰
4. **热血漫手绘为锚** — 一切画面以少年热血手绘漫画为标准，拒绝3D写实/CG动画质感；追求锐利墨线、网点排线、速度线集中线、能量气焰、高对比

## 五、主视图规范

### 视图定义

> 单画面主视图，从场景中最具代表性的角度拍摄，承载战斗空间叙事与构图重心。

| 项目 | 约束 | 提示词 |
|---|---|---|
| 视角 | 夸张透视视角，构图最能体现战场主体与纵深张力 | hero shot、dramatic perspective |
| 视点高度 | 默认人眼平视或低位仰视强调压迫感，特殊场景可俯瞰 | eye level（默认）/ low angle |
| 构图 | 主体居中或符合三分法，前/中/后景层次清晰、夸张透视 | dramatic composition |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 单画面（非拼图、非多视图、非分屏） |
| 人物 | **严禁出现任何人物、人影、人体轮廓** |
| 一致性 | 风格/材质/色调/光线统一 |
| 光线 | 单一主光源逻辑 + 戏剧光源（能量气焰/爆炸/闪电），光影方向一致 |
| 画面比例 | 默认 16:9（或按调用方设定） |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 场景必须有「前中后景层次」+「夸张透视」 |
| R2 | 室外必须包含「空气透视」（硝烟/能量气焰/远景模糊） |
| R3 | 场景图必须为「单画面主视图」，不得拼接多视图/分屏/网格 |
| R4 | 构图须能代表战场主体并展示前/中/后景层次与夸张透视 |
| R5 | 场景图中**严禁出现任何人物** |
| R6 | 必须包含少年热血漫画关键词（shonen battle manga / speed lines / energy aura） |
| R7 | 必须包含镜头光学特征（锐利墨线 / 网点排线 / 速度线集中线 / 高对比） |
| R8 | 材质必须带有战损痕迹/战场残骸，禁止全新无瑕的"CG 感" |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 背景纯白/纯黑/无场景 |
| X2 | 柔和治愈天候（粉嫩樱花飘/治愈暖阳），除非剧情需要 |
| X3 | 场景无纵深/无层次/无夸张透视 |
| X4 | 植被/天候与战场情境矛盾 |
| X5 | 出现任何人物、人影、人体剪影或人体轮廓 |
| X6 | 画面被拼接成多视图/网格/分屏布局 |
| X7 | 3D 写实/CG 动画/Q版卡通/游戏引擎质感（禁用 3D render、CGI、Unreal Engine、Unity 等词） |
| X8 | 材质过于干净完美、无任何战损痕迹与战场感（避免"塑料感"） |
| X9 | 光照柔和平坦、低对比、无戏剧光源、无景深虚化 |
