# 分镜提示词 · 真人纪实摄影 · 风格专属技法

---

## 适用范围

本 Skill 专用于**真人纪实摄影**风格的分镜提示词生成，适配人文纪实、社会观察、市井烟火、劳作记录、乡土人文、少数民族纪实等真人抓拍纪实题材的分镜创作。严格区别于"真人都市影像/时尚街拍"——本风格是粗粝真实的社会人文纪实。

## 一、摄影机抓拍的情绪——风霜面孔、真实眼神、不修饰的微表情

> 真人纪实摄影的情绪不来自"戏剧化光影"或"摆拍姿势"，而来自真实普通人在社会现场被35mm人文定焦抓拍到的自然神态。以下映射面向摄影机抓拍真实普通人的方式。所有情绪均为零化妆、零修饰、自然抓拍状态。

| 情绪输入 | 面容描述 | 眼神描述 | 微表情补充 |
|---|---|---|---|
| 沧桑 / 沉静 | 面部沟壑纵横，皮肤松弛，皱纹深陷，嘴角自然微下垂 | 眼神浑浊但有光，看过世事的沉静与隐忍，不躲闪也不迎合 | 眼睑微垂，呼吸极轻，老年斑与晒痕清晰，零化妆 |
| 疲惫 / 坚忍 | 面部线条紧绷又松弛并存，嘴角下沉，皮肤有汗渍灰尘 | 眼神疲惫但有力，是劳作者撑过一天的坚韧 | 额头鬓角碎发被汗贴住，T区出油反光，嘴唇干裂 |
| 坚毅 / 专注 | 面部线条硬朗，下颌有力，皮肤紧实不松弛 | 眼神坚毅专注，常因强光眯起，注视有力不躲闪 | 眉头微聚，嘴唇紧抿，皮肤古铜日晒色有灰尘 |
| 纯真 / 好奇（孩童） | 脸庞小巧圆润，骨骼未长开，面颊日晒红晕或有脏污 | 眼睛大而明亮清澈，黑白分明，纯粹直接的好奇注视 | 嘴唇微张，可能有鼻涕痕迹，头发凌乱 |
| 市井 / 精明 | 面部轮廓精明利落，嘴角带市井的精到 | 眼神精亮，扫视顾客与货品，讨价还价时活络 | 嘴角微扬似笑非笑，皮肤粗糙有色斑，零化妆 |
| 劳作 / 专注 | 面部因专注而凝定，下颌微收，皮肤有汗渍油污 | 眼神专注低垂注视手中活计，抬眼时笃定有力 | 眉头微聚，呼吸带劳作节奏，手部动作不停 |
| 喜悦 / 鲜活（偶发） | 眼角出现自然笑纹，面颊微红 | 眼神明亮有光，眼角有笑意牵动 | 嘴角自然上扬——这是偶然的笑，不是摆拍的笑 |
| 思念 / 出神 | 神情淡然，眼部周围肌肉放松 | 目光放远失焦，像在看但不在看 | 表情平静，可能手持搪瓷缸或工具发呆 |
| 惊动 / 触动（看镜头） | 眼尾微抬，眉峰微动 | 眼神骤然聚焦镜头——偶然的对视，非安排 | 嘴角微启，这一瞬的对视是纪实摄影的高光 |
| 羞涩 / 躲闪（孩童） | 面颊微红，嘴角含笑又抿起 | 眼神闪烁，看了镜头又迅速躲开 | 低头或转头，手不知所措——真实的羞涩 |

## 二、摄影机抓拍的光——现场自然光源逻辑与氛围

### 2.1 现场自然光时刻

| 时刻 | 光源行为 | 色温与色调 | 现场氛围 |
|---|---|---|---|
| 清晨 | 低角度暖白晨光，穿过集市顶棚/街巷/薄雾斜入；蒸汽与晨炊烟气扩散 | 4000-5000K暖白，空气微冷湿润 | 一天的起点、出摊出工、烟火初起 |
| 上午 | 日光升高，冷白清澈，阴影清晰；现场材质感最强 | 5000-6000K中性偏冷 | 运转中的市井、劳作展开 |
| 正午 | 顶光或近乎顶光，硬阴影短而浓——真实"难看的光" | 5500-6500K冷硬 | 暴晒的硬度、劳作的重量 |
| 午后 | 日光偏西，暖调渐增，长影穿过街巷 | 4000-5000K渐暖 | 时间变慢、市井延续 |
| 黄昏 | 极低角度暖金光，长影到极致，一切镀金边 | 2800-3200K极暖 | 归途温情、收摊收工、一天收束 |
| 蓝调时刻 | 太阳沉入地平线后，天空深蓝紫，街灯/室内灯初亮但弱于天光 | 8000-10000K天空+暖点灯火 | 过渡、诗意、白天已尽 |
| 夜晚 | 街灯/室内灯/灶火/夜市灯为主，大暗部，点光源 | 暖光源2000-3000K / 冷环境 | 夜市烟火、村庄夜、归途孤灯 |

### 2.2 情绪光影（现场自然光，无任何布光）

| 情绪基调 | 光线配方 | 摄影约束 |
|---|---|---|
| 清晨市集烟火 | 清晨日光45°斜入（4000-5000K暖白）+ 薄雾漫射 + 顶棚斑驳光斑 | 光比约1:2.5，无补光，胶片颗粒 |
| 正午劳作硬度 | 正午顶光（5500-6500K冷白）+ 硬阴影 + 强对比 | 光比约1:5硬反差，真实"难看的光"，无补光 |
| 室内市井日常 | 室内白炽/荧光灯（3000-4000K）+ 门窗漏入天光，明暗对比 | 光比约1:4，实用光源为主 |
| 黄昏归途温情 | 金色时刻低角度暖光（2800-3200K）+ 长影 + 镀金轮廓 | 光比约1:4暖金主导，无补光 |
| 阴雨沉郁 | 阴雨均匀冷灰漫射（6500-7500K）+ 湿地面反射 + 水洼倒影 | 光比约1:2低反差，湿润质感 |
| 夜市/灶间亲情 | 街灯/灶火/煤油灯（2000-3000K暖橙）点光源 + 大暗部 | 光比约1:8点暖沉暗，极简光源 |
| 黑白纪实提纯 | 去色，银盐灰阶（Tri-X高反差/Plus-X细腻） | 灰阶层次，胶片颗粒 |

## 四、摄影机语法——人文定焦镜头与抓拍运动

### 4.1 焦段选择（人文定焦为王）

| 焦段 | 叙事性格 | 适用场景 |
|---|---|---|
| 28mm（广角人文） | 现场吞噬人物、社会现场的宏大、近距离介入感 | 集市全景、工地全景、庙会人群、街巷纵深 |
| **35mm（人文之眼，首选）** | 纪实摄影的标志焦段、主观视点、身临其境、人与现场共存 | 街头抓拍、集市人物、劳作瞬间、决定性时刻 |
| 50mm（标准人文） | 人眼等价、客观注视、不夸大不扭曲 | 人物肖像、市井对视、孩童凝视、环境人像 |
| 85mm（中长焦） | 压缩空间、远距离抓拍不打扰——谨慎使用 | 远处抓拍、手部特写、不被打扰的瞬间 |

### 4.2 景别选择

| 景别 | 取景范围 | 叙事功能 |
|---|---|---|
| 特写 | 手/眼/脸/关键器物/风霜细节 | 风霜证据、关键信息、感官聚焦 |
| 近景 | 头顶至胸部以上 | 人物神态、市井对视、抓拍反应 |
| 中近景 | 头顶至腰部 | 人物与摊位/工具的互动 |
| 中景 | 头顶至膝盖上下 | 人在现场中、决定性瞬间、市井关系 |
| 全景 | 人物全身+部分现场 | 人物在空间中的位置、劳作全貌 |
| 大全景/空镜 | 现场全貌，人物极小或无 | 社会现场叙事、情绪缓冲、时代切片 |

### 4.3 摄影机运动（手持抓拍美学）

| 运动方式 | 视觉心理 | 使用场景 |
|---|---|---|
| **手持抓拍（核心）** | 在场感、呼吸感、偶发性、决定性瞬间捕获 | 几乎所有街头/市井/劳作抓拍 |
| 固定机位 | 冷静观察、让现场自己说话 | 场景空镜、大全景、社会观察 |
| 平视眼平取景 | 与被摄者平等的注视、尊重 | 人物肖像、面对面抓拍 |
| 低角度（蹲下） | 孩童视角、仰视的力量、地面纹理 | 孩童、劳作低位、积水倒影 |
| 高角度俯拍 | 上帝视角、社会现场的几何 | 集市俯瞰、人群图案、田野几何 |
| 缓慢跟拍 | 与人物同步行走、主观陪同 | 街巷行走、市集穿行 |
| 摇镜 | 视线转移、现场关系交代 | 人物视线引导、现场扫视 |

## 五、固定风格锚定词

**摄影锚定（必选）：**

真人纪实摄影，人文纪实抓拍，当代中国社会现场，35mm人文定焦镜头，手持抓拍，仅现场自然光无棚拍布光，35mm胶片颗粒质感，低饱和真实色温

**人物质感（含人物镜头时必选）：**

真实普通人，真实风霜皮肤质感（晒痕/皱纹/毛孔/汗渍/老年斑），零化妆零修饰不磨皮，真实凌乱发型（被风塑造/被汗贴住），褪色磨损衣着（补丁/油渍/泥点/起球），真实抓拍体态（劳作重心偏一侧/非摆拍），自然神态非看镜头微笑

**场景质感（含场景镜头时必选）：**

真实社会现场，真实生活痕迹与时代质感（湿漉地面/斑驳墙皮/积灰/油污/晾晒物/电线），现场自然光源方向明确可追溯，中文招牌/电动车/蛇皮袋等中国当代辨识度，胶片颗粒，非影视城非样板非全新

**参考图一致性锚定（参考图模式必选）：**

保持人物面容、风霜特征、发型、衣着磨损与参考图完全一致，保持场景风格与参考图一致，保持光影色彩基调统一，所有镜头呈现为同一人物的连续纪实抓拍记录

**风格收尾（固定）：**

真人纪实摄影，人文纪实新闻摄影质感，35mm人文定焦，胶片颗粒，非3D非渲染非CG非棚拍非摆拍

## 六、美学禁止项

以下词汇/风格不得出现于输出提示词中：

- ❌ 3D渲染 / 3D建模 / CG / UE引擎 / Blender / PBR材质 / 次世代建模 / 体积光 / 环境光遮蔽 / 光线追踪
- ❌ 2D手绘 / 插画 / 动画 / 二次元 / 漫画 / Q版 / 赛璐璐 / 低多边形
- ❌ 棚拍 / 影棚 / 柔光箱 / 补光板 / 反光板 / 闪光灯 / 三点布光 / 美人碟 / 中灰无缝背景纸
- ❌ 摆拍 / 模特pose / 时尚街拍 / 穿搭lookbook / 走秀 / 看镜头微笑摆拍
- ❌ 戏剧化电影光 / 电影感调色 / 青橙调色（teal-orange）/ 体积光束 / 镜头光晕炫光 / 电影剧照感
- ❌ 过度后期滤镜 / HDR堆叠 / 高饱和 / 荧光色 / 霓虹溢色 / 廉价滤镜APP质感 / 网红色调
- ❌ 过度磨皮 / 塑料假面 / 零毛孔 / 硅胶脸 / 蜡像感 / AI感平滑 / 精致妆容 / 粉底口红修容 / 网红脸
- ❌ 全新样板衣 / 时尚穿搭 / 精致造型 / 时装周 / 奢侈品牌质感
- ❌ 影视城样板布景 / 横店 / 全新无痕 / 过度干净空净 / 样板间 / 无生活痕迹
- ❌ 商业人像的极端虚化 / bokeh overload / 极浅景深（纪实摄影须交代环境）
- ❌ 科幻 / 赛博朋克 / 星际 / 古风古装 / 仙侠 / 武侠 / 西方奇幻 / 中世纪 / 民国影视
- ❌ 人体结构错误 / 肢体畸形 / 面部崩坏 / 比例失调
- ❌ 写实摄影（英文注意：本风格是"人文纪实抓拍"documentary candid photography，避免被理解为"商业realistic photography"）
