# 分镜表真人纪实摄影约束 · 人文纪实新闻摄影 · 技法参考

## 一、分镜表定位

分镜表是导演将剧本转化为镜头语言的核心工具。本约束面向 Seedance 2.0 视频生成，所有光影、动作、空间描述均采用模型可执行的具象语言。不做抽象的情感概括，不写模型看不懂的渲染参数。真人纪实摄影分镜表的最高准则：**所有画面读作"摄影机在真实社会现场抓拍下的"，而非"棚拍摆拍的"或"计算机生成的"**。

## 三、光影与氛围——Seedance 2.0 现场自然光源描述

### 3.1 同场戏光影统一

一场戏内不应出现两种以上核心光影方案，除非有叙事驱动的光源变化（如从清晨走到正午、从室外走进室内菜市场、从晴天转到阴雨）。光源变化必须在分镜表中标注触发事件。**所有光影严格只用现场自然光，无任何布光补光反光板。**

### 3.2 光源语句法（每个镜头必须包含）
[光源] 主光：{光源类型——日光/天光/白炽灯/荧光灯/街灯/灶火}，{方向}，{色温值K}，{软硬}
[光源] 辅光/环境光：{光源类型}（如门窗漏光/湿地反射/天空漫射），{方向}，{色温值K}
[光比] 约1:{X}
[布光声明] 仅现场自然光，无人工布光、无补光、无反光板

### 3.3 情绪 → 现场光源矩阵

| 情绪/现场 | 光源配方（Seedance 2.0 可直接填入） | 视觉关键词 |
|---|---|---|
| 清晨市集烟火 | 清晨日光45°斜入（4000-5000K暖白）穿过顶棚/薄雾，斑驳光斑，环境天光5500K补。光比约1:2.5 | 烟火、一天的起点、无布光 |
| 正午劳作硬度 | 正午顶光（5500-6500K冷白）硬阴影短而浓，强对比。光比约1:5 | 暴晒、劳作的硬度、真实难看的光 |
| 室内市井日常 | 室内白炽/荧光灯（3000-4000K暖黄或冷白偏绿）+ 门窗漏入天光，明暗对比。光比约1:4 | 烟火潮湿、市井真实、实用光源 |
| 黄昏归途温情 | 金色时刻低角度暖光（2800-3200K）穿过屋檐街巷，长影，镀金边。光比约1:4暖金主导 | 温情、归家、一天收束 |
| 阴雨沉郁 | 阴雨均匀冷灰漫射（6500-7500K）+ 湿地反射 + 水洼倒影。光比约1:2低反差 | 沉郁、真实、被雨洗过 |
| 夜市/灶间亲情 | 街灯/灶火/煤油灯（2000-3000K暖橙）点光源 + 大暗部。光比约1:8点暖沉暗 | 夜市烟火、亲情、极简点光源 |
| 黑白纪实提纯 | 去色，银盐灰阶（Tri-X高反差/Plus-X细腻），保留胶片颗粒 | 去色提纯、形式感、Magnum |

### 3.4 冷暖色调与叙事阶段

- **冷光主导**（5000K+）：正午劳作、阴雨沉郁、社会观察、市井克制
- **暖光主导**（2800-4000K）：清晨烟火、黄昏归途、市井温情、夜市灶间
- **冷暖共存**：蓝调时刻（天空冷+街灯暖）、阴雨中的室内（窗外冷灰+室内白炽暖）
- **光源变化 = 情绪信号**：从清晨暖白走到正午冷硬=劳作的推进；从晴天暖金转到阴雨冷灰=情绪的沉坠

### 3.5 Seedance 2.0 光影适配要点

- 色温数字帮助模型校准白平衡倾向：`色温约4500K清晨暖白日光` 优于 `自然光`
- 光比数字帮助模型建立明暗意识：`光比约1:5正午硬光` 优于 `强烈的阴影`
- 光源必须有明确来源与路径：`从画面右侧穿过顶棚缝隙斜入` 优于 `侧光`
- **始终声明"仅现场自然光，无人工布光"**：这是纪实摄影与棚拍/电影剧照的根本分界
- 环境光的反射路径描述：`湿漉漉水泥地反射白炽灯暖光` 优于 `地面有暖色反光`

## 四、环境动态——让真实现场呼吸

### 4.1 动态密度

每 3-4 个镜头至少安排一个有环境动态的镜头。纪实现场永远在动——至少有一个镜头里蒸汽在升、塑料布在飘、人群在穿行、孩童在跑、机械在响。

### 4.2 真实社会现场环境动态元素（Seedance 2.0 可执行）

| 场景 | 可描述的环境动态 |
|---|---|
| 集市/菜市场 | 褪色塑料布顶棚被风鼓起约20cm后啪嗒落下（约3秒周期）、蒸汽从早点摊升起、三轮车穿行扬尘、远处摊贩叫卖、顾客讨价还价的手势、电子秤滴滴响 |
| 工地 | 塔吊缓慢旋转（约每秒5度）、钢筋碰撞声、扬尘在光柱中飘浮、远处电焊火花闪烁、安全网随风轻鼓、工人搬运的水泥袋晃动 |
| 田间 | 稻浪/麦浪随风起伏（约每秒2-3次）、远处拖拉机轰鸣驶过、鸟掠过田埂、锄头入土扬起尘土、汗水滴落入土 |
| 工厂车间 | 机器运转的规律震动、传送带匀速移动、金属零件碰撞、荧光灯电流嗡鸣、工人手的重复动作、油污反光闪烁 |
| 老街巷 | 电动车穿行、晾晒衣裳随风摆动、空调外机嗡鸣滴水、远处孩童嬉闹、行人脚步、小卖部广播 |
| 码头 | 渔船随浪轻微起伏、缆绳绷紧放松、海鸥掠过、装卸工搬运节奏、集装箱反射阳光闪烁、水波拍岸 |
| 室内/堂屋 | 白炽灯微微闪烁、搪瓷缸冒蒸汽、窗外行人影掠过、苍蝇飞舞、老挂钟摆动滴答、电视雪花 |
| 雨天现场 | 雨滴打在塑料布顶棚（约每秒多次）、雨水从顶棚缝隙滴落形成水帘、地面水洼泛涟漪、行人撑伞抖水、屋檐滴水 |

### 4.3 Seedance 2.0 环境动态描述规范

- 动态必须有具体轨迹和速度：`蒸汽从早点摊蒸笼升起约30cm后散开` 优于 `蒸汽在升`
- 光源动态与现场光源逻辑一致：`云朵遮住太阳时，顶棚光斑缩小约40%，持续约3秒后恢复`
- 禁止无来源的动态：没有风=塑料布不动。室内=没有扬尘
- **禁止摆拍式动态**：人物的环境动态必须是"正在发生的"，不是"被安排的"

## 五、人物动作节奏——Seedance 2.0 物理逻辑具象化

### 5.1 动作描述铁律

所有人物动作必须描述：**轨迹 + 速度/时长 + 身体部位协调 + 衣着/汗水连带动态 + 对周围物体的影响**。所有动作必须是真实生活/劳作中的自然动作，**非摆拍、非为镜头表演**。

### 5.2 真实生活劳作动作具象库

| 动作 | Seedance 2.0 可执行描述 |
|---|---|
| 卖菜称重 | 双手在电子秤上熟练拨弄蔬菜，左手扶秤右手调整，身体微前倾专注，每隔约2秒抬头扫一眼顾客，秤显示数字后报出价格，全程自然抓拍状态，约4-5秒一个完整周期 |
| 擦汗 | 右手抬起用搭在肩上的旧毛巾擦拭额头汗珠，毛巾在额头停留约1秒后甩回肩上，毛巾有污渍磨损——非摆拍，是劳作中真实的擦汗，约2秒 |
| 锄地 | 双手握锄头木柄，举过头顶约30cm后落下入土，身体随动作前倾后仰，每秒约一锄，汗珠从额头滑落，呼吸可见——真实劳作的节奏 |
| 搬运水泥袋 | 双手抱起水泥袋（约25kg），身体微蹲后站起扛上肩，腰部发力可见，工装后背汗渍扩大，稳步走向堆放点约5米——劳作的重量，约6秒 |
| 孩童奔跑 | 孩童从画面右侧跑入，步速约每秒两步，书包随跑动上下晃动，鞋底扬起尘土，跑过积水时溅起水花，回头看一眼镜头后跑远——偶发性抓拍 |
| 喝水歇息 | 左手拿起搪瓷缸（缸壁有茶垢），送到嘴边仰头喝水约2秒，喉结滚动，水从嘴角淌下一道，放下缸时叹一口气——午休的真实瞬间 |
| 整理蔬菜 | 双手把堆积的蔬菜分拣摆放，左手抓起一把右手码齐，剔除烂叶扔到摊下，身体微前倾，约每秒一个动作循环——出摊准备 |
| 工地焊接 | 半蹲，右手持焊枪，左手扶钢筋，焊枪火花闪烁约每秒数次，面罩下眼神专注，工装有焊渣烫痕——专注劳作 |
| 缝纫/手艺 | 坐于缝纫机/工作台前，双手引导布料/工件，脚踏踏板规律踩动，低头专注，每秒约一个动作周期——手艺的节奏 |
| 蹲坐歇息 | 双手抱膝蹲在墙根/摊位后，背靠墙，嘴角叼烟或手持搪瓷缸，眼神放空望向街巷——午休或疲惫的真实姿态 |

### 5.3 动作节奏与叙事场景

- **日常/劳作**：动作沉稳真实，每个动作标注时长和轨迹。节奏是真实生活的节奏——不快不慢，是"正在做这件事"
- **市井交易**：动作熟练活络，摊贩的手势快而准，眼神扫视顾客，是市井生存的本能
- **孩童段落**：动作偶发不可控，奔跑、嬉闹、突然停下——抓拍的是"孩子不知道被拍"的真实
- **冲突/辛苦段落**：动作干脆或沉重，但仍有物理轨迹。搬运的重、锄地的力、擦汗的累——须具体到身体的发力与汗水的连带
- 禁止：无叙事理由的摆拍动作堆砌、看镜头微笑、模特pose、"为了镜头而做"的任何动作

### 5.4 衣着与汗水动态

真人纪实摄影的衣着与汗水动态是画面的天然资产——不是"布料模拟参数"，而是"工装后背汗渍随劳作扩大""棉袄下摆随弯腰自然垂坠""碎发被汗贴在额头鬓角""擦汗时毛巾的污渍磨损可见""围裙的油渍在动作中反光"。在分镜表画面描述中标注衣着与汗水的动态细节。

## 六、空间逻辑具象化——Seedance 2.0 空间坐标系统

### 6.1 每镜头必须声明的空间信息
水平位置：画面左/中/右，或画面左侧三分之一处
纵深位置：距镜头{数值}米，前景/中景/背景
人物与场景的关系：距{固定物——摊位/脚手架/田埂/灶台/课桌}{数值}米
（若双人以上）人物A与B的相对距离和朝向

### 6.2 站位衔接示例
【片段A尾部】
老摊贩站在自己菜摊后方，距摊约0.3米，面朝顾客，位于画面中央偏右，距镜头约3.5米。
双手在电子秤上称蔬菜，身体微前倾。
清晨日光从画面右侧45°穿过顶棚斜入（约4500K暖白）。

【片段B开头】
老摊贩仍站在菜摊后（位置未变），右手刚把称好的蔬菜递给顾客约30cm。
现场天光已从清晨暖白转为上午冷白，顶棚光斑向右移动了约30cm。
远处一个顾客走近摊位约1米。

### 6.3 空间变化必须具象

| 抽象（禁止） | Seedance 2.0 具象 |
|---|---|
| 他走过来了 | 老摊贩从摊位后（距镜头约3.5米）绕过摊位走到摊前（约1.5米），步速约每秒一步，解放鞋底磨平可见，停在距顾客约1米处——耗时约3秒 |
| 摊贩和顾客 | 摊贩位于摊后（距镜头约3.5米），顾客位于摊前（距镜头约2.5米），两人面朝彼此，相距约1.5米，中间隔着菜摊 |
| 从市场走到街上 | 老人从菜市场内（距镜头约4米、摊位间）缓步走向市场出口，跨过湿漉漉的水泥地（脚下水花可见），走出褪色塑料布顶棚的光区进入街巷日光——顶棚斑驳光被均匀街光取代 |

## 七、运镜规范——Seedance 2.0 摄影机运动（手持抓拍美学）

### 7.1 允许的运镜

| 运镜 | Seedance 2.0 描述 | 适用场景 |
|---|---|---|
| **手持抓拍（核心）** | 摄影机有轻微不规则晃动（幅度约±2-3cm），模拟手持35mm人文定焦的呼吸感与在场感 | 几乎所有街头/市井/劳作抓拍——纪实摄影的第一手法 |
| 固定机位 | 摄影机固定不动，画面静止，客观观察 | 场景空镜、大全景、社会现场记录、长焦偷拍 |
| 平视眼平取景 | 摄影机位于人眼高度，与被摄者平视，平等注视 | 人物肖像、面对面抓拍——纪实的伦理高度 |
| 低角度（蹲下） | 摄影机降至约0.8-1米高度，仰视或平视低处 | 孩童、劳作低位、积水倒影、地面纹理 |
| 高角度俯拍 | 摄影机升高至约2.5-3米以上，俯瞰现场 | 集市俯瞰、人群图案、田野几何、社会现场的几何 |
| 缓慢跟拍 | 摄影机与人物保持约2-2.5米距离同步移动，手持呼吸感 | 街巷行走、市集穿行、归途跟随 |
| 摇镜 | 摄影机原地水平/垂直旋转，手持微晃 | 视线转移、现场扫视、人物视线引导 |

### 7.2 禁用运镜

- **影棚式稳定器过度流动**（除非叙事需要，纪实以手持为主）——过度光滑的稳定器运动是商业片语言
- 无叙事目的的快速甩镜、急推急拉（推拉速率超过每秒1米）
- 超过3秒的剧烈手持晃动（除非主观受击/眩晕叙事）
- 无逻辑花式转场——划屏、旋转、百叶窗、翻页等特效转场
- 摄影机无理由的360度旋转
- 商业MV式的快速剪辑与节奏化运镜

### 7.3 真人纪实摄影运镜哲学

- **手持抓拍是纪实摄影的第一选择**——让观众感受到"摄影机正在现场"，呼吸感与偶发性是真实感的来源
- 固定机位用于空镜与社会全景——让观众看到现场在自然运转
- 平视眼平取景是纪实的伦理高度——与被摄者平等，不仰视美化也不俯视猎奇
- 低角度用于孩童——蹲下到孩子的视线高度，是尊重
- 运动镜头的起幅和落幅允许轻微的不平稳——这是手持抓拍的证据，不是缺陷
- **35mm/50mm人文定焦是默认焦段**——禁止商业变焦语言

## 八、转场规范

### 8.1 允许的转场方式

| 转场 | 视觉执行 | 叙事功能 |
|---|---|---|
| 硬切 | 直接切换 | 同场戏内镜头切换（默认） |
| 光影匹配转场 | 两个场景在相近现场光影下切换 | 时间流逝、平行叙事。例：A处清晨日光 → B处清晨日光 |
| 空间匹配转场 | 两个空间在构图或元素上呼应 | 场景跳转。例：菜市场的堆积蔬果 → 田间待收的作物 |
| 空镜过渡 | 插入场景空镜（3-5秒） | 情绪缓冲、章节划分、时间流逝暗示（如清晨集市→黄昏收摊） |
| 焦点转场 | 前镜焦点从主体移至背景，后镜从模糊背景中逐渐聚焦主体 | 空间切换、注意力的转移 |
| 声音先行转场 | 下一场景的环境音在前一镜尾提前进入 | 空间预示、时间过渡 |

### 8.2 禁止的转场

- 纯视觉特效转场（翻页、划屏、百叶窗、马赛克、水墨化开、光效溶解）
- 无叙事逻辑的旋转/缩放转场
- 商业广告式的快剪节奏转场
- 同一场戏内使用超过两种转场方式

## 十一、空镜使用规范

### 11.1 空镜不是"没东西拍"

空镜是情绪容器与时代切片。每个空镜必须有叙事目的和具体的视觉内容：

| 空镜类型 | 叙事目的 | 示例 |
|---|---|---|
| 场景建立 | 新现场首次出现——让观众看清楚这是什么社会现场 | 清晨菜市场全景：褪色顶棚、蛇皮袋摊位、湿地面、蒸汽 |
| 情绪缓冲 | 高情绪段落后的喘息 | 收摊后散落菜叶的湿地面，水洼倒映着街灯 |
| 时间流逝 | 暗示时间过去了 | 同一集市场景：清晨未开市→正午喧闹→黄昏收摊 |
| 时代切片 | 以物/以景代情，传递时代质感 | 斑驳墙上褪色的标语、电线杆上的小广告、晾晒的衣裳 |
| 隐喻留白 | 以现场细节隐喻人物命运 | 磨平的解放鞋底、补丁摞补丁的工装、积水的泥路 |
| 转场衔接 | 前后两个现场的自然过渡 | 街巷空镜——前一场集市，下一场工地 |

### 11.2 空镜 Seedance 2.0 描述规范

空镜也必须遵循光源+质感+动态+胶片颗粒的描述铁律：清晨日光从画面右侧45°穿过褪色塑料布顶棚斜入（约4500K暖白），
在湿漉漉水泥地形成斑驳光斑，无任何人工布光，
顶棚被风鼓起约20cm后啪嗒落下（约3秒周期），
蒸汽从早点摊升起约30cm后散开，
远处三轮车穿行扬尘在光柱中飘浮，
地面有散落的菜叶与水洼倒影，
35mm胶片颗粒质感，低饱和真实色温。
