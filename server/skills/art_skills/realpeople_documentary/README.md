# 真人纪实摄影视觉手册 · 风格说明

本手册专为"真人纪实摄影"题材视觉创作打造，所有美术提示词、视觉规范和生成内容严格限定于真人实拍级人文纪实/新闻摄影美学体系。

## 一、风格核心定义

**真人纪实摄影**是以**人文纪实新闻摄影美学**为基准、以**真实社会生活现场**为核心视觉舞台的风格体系。其核心特征为：

- **纪实抓拍摄影质感**：以真人纪实摄影机为唯一成像媒介，画面呈现真实普通人被自然光抓拍到的此刻——皮肤的风霜、汗渍与尘土、粗布衣着的磨损、市井现场的粗粝材质、不加修饰的瞬间神态。允许并欢迎胶片颗粒、环境灰、轻微脱焦与构图不完美。杜绝3D建模感、CG渲染感、棚拍柔光、摆拍样板感、后期滤镜感与戏剧化电影光
- **真实社会生活世界观**：所有场景严格限定于真实社会现场——乡村集市、菜市场、建筑工地、老街巷、田间地头、工厂车间、乡村学校、庙会、码头、火车站、城中村、手工作坊。不是影视城，不是样板布景，是真实在运转的社会现场
- **纪实新闻摄影语言**：以35mm/50mm人文定焦为标志焦段，手持抓拍、环境自然光、决定性瞬间。不依赖布光、不依赖稳定器、不依赖后期调色。摄影机是"在场的旁观者"，而非"导演"
- **人本身即核心**：本风格关注"人本身"——劳动者的手、孩童的眼、老人的脸、市井的烟火。真实普通人是主角：老农、建筑工人、菜贩、孩童、手艺人、少数民族、拾荒者、渔民。满脸风霜、真实衣着、自然神态、绝不修饰

### 创作理念与核心价值

本手册的核心创作理念为 **"决定性瞬间里，看见人的此刻"**：

1. **真实即美学**：在AI生成影像日趋精致泛滥的当下，纪实摄影的粗粝真实具有不可替代的力量。劳动妇女额头被汗贴住的碎发、老农掌心皲裂的纹路、集市上被日光晒褪色的塑料布、工地扬尘里逆光飞舞的颗粒——这些真实细节构成了一种时代质感与生命厚度，是任何精致渲染都无法复刻的。

2. **现场即叙事**：一个真实的菜市场、一段正在施工的工地、一场庙会的喧嚣——纪实摄影不"搭建"场景，而是"进入"场景。真实社会现场本身就是一个充满生活痕迹与时代信息的叙事容器。

3. **决定性瞬间**：追随布列松——摄影的价值在于在 fraction of a second 里，recognize 一个事件的意义，以及赋予这个事件以恰当的几何形式。老农抬头的瞬间、孩童奔跑过市集的瞬间、工人擦汗的瞬间——抓拍的是"正在发生"，不是"被安排发生"。

4. **克制即品格**：本风格为"真人纪实人文"，不是时尚街拍，不是电影剧照。没有戏剧化的明暗、没有青橙调色、没有梦幻虚化、没有摆拍的姿势。一切以真实、克制、不干预为底色——粗粝真实是最高美学。

**核心价值：**

- 为AI视觉创作者提供一套系统化、可复用的真人纪实人文题材提示词方法论
- 建立从概念到成品的标准化视觉创作管线
- 填补当前AI视觉创作领域"真人纪实系统化方法论"的空白
- 严格区别于项目内"真人都市影像/时尚街拍"——本风格是粗粝真实的社会人文纪实，关注人本身与时代现场，而非时尚穿搭与精致街拍

## 三、视觉风格定位

### 3.1 整体风格定位

**"粗粝真实的社会人文纪实美学"**

以真实社会现场为舞台，以人文纪实新闻摄影为技术锚点，追求布列松「决定性瞬间」、吕楠/解海龙中国人文纪实、玛格南图片社(Magnum)、侯登科一脉的画面品质与审美高度。整体风格在"真实粗粝"与"人文厚度"之间寻找平衡——画面真实但不随意，有颗粒但不脏乱，关注人本身而非炫技。

### 3.2 影像质感层级

| 质感维度 | 定位标准 |
|---|---|
| **皮肤质感** | 纪实摄影级，可见风霜、晒痕、毛孔、汗渍、尘土、皲裂、皱纹、老年斑、雀斑、痘印——真实劳动者/市井人的皮肤证据，杜绝一切磨皮与皮肤修饰 |
| **衣着质感** | 棉麻工装的磨损、褪色、补丁、油渍、泥点；旧夹克的起球、领口变形；民族服饰的真实织物质地；杜绝全新样板衣感与时尚精致 |
| **环境质感** | 菜市场湿漉的地面、工地的扬尘与钢筋、老街的斑驳墙皮、田间的泥土与茬秆、工厂的油污机器——真实社会现场的粗粝材质与生活痕迹 |
| **颗粒质感** | 35mm胶片颗粒为默认美学（Kodak Tri-X/Tri-X黑白、Kodak Gold/Portra彩色胶片质感），允许并欢迎粗糙颗粒、轻微噪点、环境灰——这是纪实摄影的签名感 |
| **光影质感** | 纯环境自然光——日光、天光、街灯、灶火、室内白炽灯。无补光、无反光板、无柔光箱。光的方向与色温由现场决定，不由摄影师控制 |

### 3.3 色彩体系

**色彩哲学：真实低戏剧性、胶片质感、自然色温**

| 特征 | 定位 |
|---|---|
| **饱和度** | 中低（35-55%）——真实世界的色彩不饱和。晒褪色的塑料布、灰扑扑的水泥、土黄的泥墙——低饱和是真实，高饱和是滤镜 |
| **色温** | 由现场自然光决定。晨昏暖、正午冷、室内白炽灯暖黄、阴天冷灰——不统一、不修正，保留现场色温的"不完美" |
| **对比度** | 中等偏低，胶片质感的对比——黑色不死黑、白色不死白，中间调丰富，暗部与高光都有层次 |
| **色偏** | 允许胶片特有的轻微色偏（柯达暖偏、富士绿偏、黑白银盐的中性灰），这是胶片美学的签名 |

**情绪色盘矩阵（真实社会现场的色温情绪）**

| 情绪/现场类型 | 色温走向 | 视觉关键词 |
|---|---|---|
| 清晨集市出摊 | 晨光暖白（4000-5000K）+ 薄雾漫射 | 通透、烟火、一天的起点 |
| 正午工地/田间 | 冷白顶光（5500-6500K）+ 强阴影 | 暴晒、汗水、劳作的硬度 |
| 菜市场室内 | 白炽灯/荧光暖黄（3000-4000K）+ 湿地面反射 | 烟火、潮湿、市井真实 |
| 黄昏老街/归途 | 金色时刻暖橙（2800-3200K）+ 长影 | 温情、归家、一天收束 |
| 阴雨街巷 | 阴天冷灰漫射（6500-7500K）+ 湿地面 | 沉郁、真实、被雨洗过 |
| 灶火/火塘夜话 | 柴火/煤油灯暖橙（2000-2600K） | 温度、亲情、被火光照亮 |
| 黑白纪实（可选） | 银盐黑白灰阶 | 去色提纯、形式感、经典Magnum |

### 3.4 光影体系

真人纪实摄影的光影以**"现场有什么光就用什么光"**为核心原则——不布光、不补光、不修饰：

| 光影方案 | 方案名 | 光影特征 | 适用现场 |
|---|---|---|---|
| A | 清晨烟火 | 日出后低角度暖白漫射光（4000-5000K）、薄雾、晨炊烟气 | 清晨集市、田间出工、菜场早市 |
| B | 正午劳作 | 正午顶光或高角度日光（5500-6500K）、硬阴影、强对比 | 工地、田间、晒场、码头 |
| C | 室内实用光 | 室内白炽灯/荧光灯（3000-4000K）+ 门窗漏入天光、明暗对比 | 菜市场、作坊、乡村学校、堂屋 |
| D | 黄昏金光 | 日落前金色时刻（2800-3200K）、长阴影、镀金轮廓 | 老街、归途、田埂、收工 |
| E | 阴雨漫射 | 阴天/雨天均匀冷灰漫射（6500-7500K）、湿地面反射 | 雨天街巷、潮湿市场、泥泞田间 |
| F | 夜间人工光 | 路灯/灶火/煤油灯/篝火（2000-3000K）点光源、大暗部 | 庙会夜、灶间、村口、火塘 |
| G | 黑白银盐 | 去色，黑白胶片灰阶（Tri-X高反差/Plus-X细腻） | 任意现场的人文纪实提纯 |

## 四、关键视觉元素

### 4.1 人物视觉元素

- **面容标准**：真实普通人的脸——风霜、晒痕、皱纹、老年斑、雀斑、痘印、汗渍、尘土。五官自然不修饰，无精致妆容、无粉底、无口红、无修容。支持多元面孔类型——饱经风霜的老农、黝黑坚毅的工人、眼神明亮的孩童、市井精明的摊贩、沧桑的手艺人、特征鲜明的少数民族面孔
- **衣着标准**：真实衣着——工装/棉袄/旧夹克/褪色T恤/民族服饰/校服/围裙/胶鞋/布鞋/解放鞋。褪色、磨损、补丁、油渍、泥点是真实证据。绝非时尚穿搭、绝非精致新衣
- **发饰标准**：自然发型——被风吹乱的头发、被汗贴在额头的碎发、凌乱的发髻、花白稀疏的老年发、孩童的天然乱发。无造型、无发胶、无精致打理
- **表情与体态**：自然神态——劳作的专注、疲惫的喘息、孩童的纯粹、老人的沉静、市井的精明、偶然的笑。非摆拍、非模特姿势。重心偏一侧的劳作站姿、蹲坐的休息、奔跑的动势
- **人物气质维度**：饱经风霜 / 坚毅沉默 / 纯真明亮 / 市井精明 / 沧桑沉静 / 劳作的疲惫与尊严 / 少数民族的质朴

### 4.2 场景视觉元素

- **乡村集市/菜市场**：塑料布顶棚、湿漉水泥地、堆积的蔬果、电子秤、蛇皮袋、三轮车、讨价还价的人群——市井烟火的现场
- **建筑工地**：脚手架、塔吊、钢筋、水泥浆、安全帽、扬尘、安全网——现代建设的硬现场
- **田间地头**：稻茬、田埂、沟渠、塑料大棚、拖拉机、锄头扁担、远山——农耕的现场
- **老街巷/城中村**：斑驳墙皮、电线、晾衣绳、空调外机、电动车、小卖部、贴满广告的电线杆——市井生活的纹理
- **工厂车间**：油污机器、流水线、工装工人、安全标识、金属零件——制造的现场
- **乡村学校**：旧课桌、黑板、粉笔、窗户破损、孩子、操场、国旗——教育与未来
- **庙会/集市节庆**：人群、旗帜、小吃摊、戏台、香火、喧闹——民俗的现场
- **码头/火车站**：集装箱、渔船、缆绳、行囊、候车人群、铁轨——流动与聚散

### 4.3 道具与细节元素

- **劳作工具**：锄头/镰刀/扁担/铁锹/箩筐/蛇皮袋/安全帽/扳手/焊枪/渔网——被手握过千万次的器物
- **生活器物**：搪瓷缸/军用水壶/老式保温瓶/塑料凳/马扎/蒲扇/旧毛巾/解放鞋——市井日常的真实物
- **食物与炊具**：铁锅/柴灶/蒸笼/铝饭盒/塑料袋装的食物/瓷碗/筷子——市井饮食
- **时代物件**：老式收音机/大哥大/搪瓷盆/二八大杠/老挂历/奖状/毛主席像——时代的痕迹

### 4.4 镜头语言元素

| 景别 | 叙事功能 | 纪实特征 |
|---|---|---|
| 特写 | 风霜细节、手、眼、关键器物 | 老农的手、孩童的眼、劳动者的汗、皲裂的脚 |

## 五、严禁内容（优先级最高）

本风格严格排除以下内容类型，确保视觉体系纯净统一：

1. **非真人质感**：3D渲染/CG建模/次世代游戏引擎/动画风格/手绘插画/水彩油画/二次元/Voxel/低多边形/赛璐璐等一切非真人实拍影像质感
2. **棚拍/摆拍/时尚街拍**：影棚柔光/补光板/反光板/模特pose/时尚穿搭/精致妆容/精致街拍——本风格严格区别于"真人都市影像"的时尚街拍路线
3. **戏剧化电影光与后期滤镜**：电影级布光/青橙调色/电影感调色/HDR过度堆叠/滤镜APP质感/高饱和/霓虹/荧光色——本风格是真实低戏剧性的纪实
4. **精致空净的样板场景**：影视城样板布景、全新无痕的场景、过度干净的画面、样板间——本风格需要真实生活痕迹与时代质感
5. **模特/演员感的人物**：精致妆容、完美皮肤、时尚造型、摆拍姿势、对称僵笑、网红脸——本风格是真实普通人
6. **技术质量缺陷**：低分辨率/严重模糊（非美学脱焦）/畸形肢体/五官扭曲/比例失调/抠图感（纪实允许轻微脱焦与颗粒，但不允许结构性崩坏）
7. **非真实社会现场**：架空场景/科幻/仙侠/古风古装/西方奇幻/民国影视——本风格限定真实当代社会现场
8. **内容合规红线**：暴露/低俗/暗示性/暴力血腥/违法内容/歧视性表达/政治敏感元素。人文纪实须以尊严为本，杜绝猎奇与消费苦难

## 七、使用说明

### 提示词使用原则

1. **前缀先行**：所有生成内容必须首先加载"前缀提示词"中的全局风格锚定段，锁定真人纪实摄影质感基线
2. **专项叠加**：在全局前缀基础上，按需叠加角色/场景/道具/分镜专项提示词
3. **负面必加**：每次生成必须附带"负面提示词"，规避伪影与风格偏差（尤其规避棚拍柔光、时尚街拍、电影戏剧光）
4. **真实优先**：当"精致好看"与"真实粗粝"冲突时，永远选择真实粗粝——这是纪实摄影的最高准则
5. **平台适配**：本手册提示词优先适配Doubao-Seedream（生图）与Doubao-Seedance（视频生成），部分提示词可能需根据平台特性微调
