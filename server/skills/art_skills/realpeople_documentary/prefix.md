## 二、摄影机语法（替代"渲染引擎"）

> 真人纪实摄影不依赖渲染管线，也拒绝棚拍布光与后期滤镜。画面品质取决于摄影机的选择、人文定焦镜头的性格、现场自然光的调度、以及对决定性瞬间的抓取。以下为"摄影机语法"核心参数。

### 2.1 画幅与格式

| 参数 | 基准值 | 美学意图 |
|---|---|---|
| 影像格式 | **35mm胶片质感（首选）** / 全画幅数字摄影（旁轴/单反/无反） | 35mm人文纪实是本风格的灵魂画幅；胶片颗粒是纪实摄影的签名。允许Tri-X黑白胶片、Kodak Gold/Portra/Ektar、Ilford等胶片质感 |
| 色彩科学 | **胶片色彩科学**（柯达暖、富士绿、银盐灰）优先于数字干净色彩 | 纪实摄影偏好胶片的有机色彩与颗粒，而非数字摄影的干净锐利。色彩还原真实、低饱和、保留现场色温的"不完美" |
| 颗粒 | **35mm胶片颗粒必选**——细腻到粗糙不等，是纪实摄影的美学签名 | 胶片颗粒不是噪声缺陷，是真实感与时代质感的来源。Tri-X的粗颗粒、Portra的细腻颗粒均可 |

### 2.2 镜头性格——人文定焦为王

> 纪实摄影的标志是**定焦镜头**（prime lens），尤以35mm/50mm人文焦段为核心。变焦镜头属于商业摄影，不属于纪实人文。所有画面应指定一个具体的人文定焦焦段。

| 焦段 | 叙事性格 | 典型应用 |
|---|---|---|
| **28mm（广角人文）** | 环境吞噬人物、社会现场的宏大与个体的渺小、近距离介入感 | 集市全景、工地全景、庙会人群、街巷纵深 |
| **35mm（人文之眼，首选）** | 纪实摄影的标志焦段、主观视点、身临其境、人与环境共存——布列松/Magnum的常用焦段 | 街头抓拍、集市人物、劳作瞬间、决定性时刻 |
| **50mm（标准人文）** | 人眼等价、客观注视、不夸大不扭曲——卡帕/寇德卡的常用焦段 | 人物肖像、市井对视、孩童凝视、环境人像 |
| 85mm（中长焦） | 压缩空间、远距离抓拍不打扰、细节突出——谨慎使用，避免变成商业肖像 | 远处抓拍、手部特写、不被打扰的瞬间 |
| 135mm+（长焦） | 极端压缩、远距离偷拍感——纪实摄影中较少使用，易丢失环境 | 偶用于远处人群中的个体剥离 |

### 2.3 机位与运动——手持抓拍美学

| 手法 | 视觉心理 | 使用场景 |
|---|---|---|
| **手持抓拍（核心手法）** | 在场感、呼吸感、偶发性、决定性瞬间的捕获——纪实摄影的第一手法 | 几乎所有街头/市井/劳作抓拍场景 |
| 固定机位 | 冷静观察、让现场自己说话、社会全景的客观记录 | 场景空镜、大全景、长焦偷拍 |
| 平视眼平取景 | 与被摄者平等的注视、尊重——纪实的伦理高度 | 人物肖像、面对面抓拍 |
| 腰平/低角度 | 孩童视角、仰视的力量感、地面的纹理 | 孩童、劳作的低位、积水倒影 |
| 高角度俯拍 | 上帝视角、社会现场的几何、人群的图案 | 集市俯瞰、人群图案、田野几何 |
| 焦点偏移 | 注意力的转移——纪实摄影中少用，因抓拍通常单次对焦 | 偶用于环境人像的前后景关系 |

### 2.4 决定性瞬间——纪实摄影的灵魂

> 追随布列松："在几分之一秒内，同时认识一个事件的意义，以及赋予它以恰当几何形式的那种精确关系。" 纪实摄影不是拍"人在那里"，而是拍"那个瞬间"。以下为决定性瞬间的抓拍准则：

| 准则 | 说明 |
|---|---|
| 抓拍而非摆拍 | 被摄者不知道/不在意被拍，呈现最自然的状态。绝不指挥"看这里""笑一个" |
| 几何与时机 | 画面中人物位置、动势、背景几何在某一瞬间形成最佳构成——这就是按快门的时刻 |
| 动作的中段 | 抓拍动作的中段而非起止——老农抬头的瞬间、孩童奔跑中途、摊贩称重的手势 |
| 眼神的偶然 | 被摄者与镜头的眼神接触是偶然而非安排——那一瞬的对视是纪实摄影的高光 |
| 允许不完美 | 轻微脱焦、构图偏移、运动模糊——这些"不完美"是真实抓拍的证据，不是缺陷 |

## 三、社会现场色谱——光与材料的真实色彩

> 真人纪实摄影的色彩来自真实社会现场的光与材料，不是引擎色板，也不是后期滤镜。以下色盘提取自：晒褪色的塑料布、湿漉漉的水泥地、土黄的泥墙、油污的机器、灶火的暖橙、阴雨的冷灰。

## 四、全局约束规则

### 4.1 影像真实性约束（必守）

| 编号 | 规则 |
|---|---|
| P1 | 必须以「真人纪实摄影 / 真人实拍 / 人文新闻摄影 / 抓拍」为生成锚——画面必须读作"摄影机在现场抓拍下的真实瞬间"，而非"计算机生成的"或"棚拍摆拍的" |
| P2 | 必须指定一个具体的**现场自然光源**逻辑：这场戏的光从哪里来？（日光/天光/街灯/灶火/室内白炽灯/荧光灯）光源方向、色温须自洽，**严禁布光、补光、反光板、柔光箱** |
| P3 | 必须保留人物皮肤的**真实风霜质感**——晒痕、毛孔、汗渍、尘土、皱纹、老年斑、雀斑、痘印、皲裂——杜绝一切磨皮、皮肤修饰、精致妆容、粉底口红 |
| P4 | 发丝必须呈现**自然凌乱状态**——被风吹散、被汗贴在额头、花白稀疏、孩童乱发——杜绝造型、发胶、精致打理 |
| P5 | 服饰必须体现**穿用过/劳作过**的痕迹——褪色、磨损、补丁、油渍、泥点、领口变形——杜绝全新样板衣感、时尚穿搭、精致造型 |
| P6 | 场景必须有**真实生活痕迹与时代质感**——湿漉地面、斑驳墙皮、积灰、油污、晾晒物、电线——杜绝样板布景、影视城、过度干净空净的画面 |
| P7 | 人物必须处于**自然抓拍体态**——真实劳作站姿（重心偏一侧）、蹲坐休息、奔跑动势、专注劳作——**杜绝模特摆拍姿势、时尚pose、对称僵笑** |
| P8 | 必须指定一个具体的**真实社会生活现场**——拒绝"generic street"或任何无国别标识的架空场景。场景须有中国当代社会现场的辨识度 |

| 越界信号 | 说明 |
