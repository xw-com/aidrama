# 真人纪实摄影场景图像生成 · 约束手册

---

## 一、场景美学原则

> 真人纪实摄影的场景不是"被搭建的布景"，而是"被摄影机进入的真实社会现场"。没有渲染引擎、没有影棚、没有布光、没有道具陈设——只有实际存在的社会生活现场、现场的自然光、以及真实的生活痕迹与时代质感。

1. **现场即时代** — 一个真实的菜市场、一段正在施工的工地、一条老街——这些空间本身就是时代切片。墙上的标语、褪色的招牌、积水的路面、晾晒的衣裳，每一个细节都在讲述当下的社会真实
2. **现场的自然光，不是布光** — 场景的光只有一个来源：实际的日光、天光、街灯、室内白炽灯/荧光灯。光的色温和方向必须在物理上说得通，**绝不补光、不布光、不加反光板**
3. **被生活使用过的现场** — 真实的社会现场不干净。菜市场地面湿漉漉有菜叶、工地扬尘有钢筋、老街墙皮斑驳有电线、田间有茬秆与泥——一个过度干净空净的场景是影视城样板，不是真实现场
4. **真实当代中国社会现场** — 场景必须有明确的中国当代社会辨识度（中文招牌、电动车、蛇皮袋、塑料凳、晾晒方式、特定建筑形态）。这不是"generic street"，这是"中国当代社会的一个具体角落"
5. **单视图全景全貌** — 一张照片装下整个现场的完整信息。35mm人文定焦或28mm广角，全景深或适中景深，客观记录现场的全貌与纵深——不是四视图分割，不是多角度拼贴

## 二、时段与天气——现场光的纪实导演

> 真人纪实摄影场景的光，首先由时段和天气决定。以下是真实现场光源在不同时段、天气的纪实摄影行为。

| 时段 | 光的行为 | 现场氛围词 |
|---|---|---|
| 清晨（日出后1-2h） | 低角度暖白晨光斜入、薄雾漫射、晨炊/市集蒸汽、长影、空气湿润通透 | 清晨烟火、一天的起点、出摊出工、薄雾中的现场 |
| 上午 | 日光升高、冷白清澈、阴影清晰、材质感最强——纪实摄影的"标准日光" | 上午的市井、运转中的现场、秩序与劳作 |
| 正午 | 顶光或近乎顶光、硬阴影短而浓、暴晒感——纪实摄影可接受这种"难看的光"，因为它真实 | 正午暴晒、工地的硬度、田间的烈日 |
| 午后 | 日光偏西、暖调渐增、长影穿过街巷、漏光斑驳 | 午后的市井、时间变慢、慵懒与延续 |
| 黄昏 | 极低角度暖金光、长影到极致、一切镀金边——人文纪实的温情时段 | 黄昏归途、收摊收工、一天收束的暖 |
| 蓝调时刻 | 太阳沉入地平线后、天空深蓝紫、街灯/室内灯初亮但弱于天光 | 过渡、归途夜色、诗意收尾 |
| 夜晚 | 街灯/室内灯/灶火为主光源、大暗部、点光源——夜市的烟火 | 夜市烟火、村庄夜、归途孤灯 |

| 天气 | 光的行为 | 现场氛围词 |
|---|---|---|
| 晴天 | 强方向光、硬阴影、高对比、材质清晰 | 暴晒、明亮、阴影的几何 |
| 多云 | 柔和方向光、阴影柔和、材质仍清晰——纪实摄影的理想光况 | 均匀、柔和、舒适 |
| 阴天 | 冷灰均匀漫射、无强阴影、湿润质感——纪实摄影的常见光况 | 沉郁、真实、被灰光笼罩 |
| 雨中/雨后 | 湿地面反射天光与灯光、水洼倒影、雨幕散射、空气清新 | 洗涤、倒影、泥泞的真实 |
| 雾/霾 | 大气透视增强、远景虚化、空气有厚度、颗粒感 | 朦胧、距离、时代的空气 |

## 三、市井交易现场——集市/菜市场/庙会

### 空间摄影规范

| 维度 | 摄影要求 | 提示词 |
|---|---|---|
| 风格 | 真实的中国当代市井交易现场——不是布景、不是影视城、不是渲染。是有烟火气与生活痕迹的真实现场 | 真实的中国当代{市场类型}、人文纪实摄影、非布景非影视城 |
| 光源逻辑 | 必须有明确的现场光源——室外集市：日光/天光（方向与时段匹配）；室内菜市场：白炽灯/荧光灯（色温暖黄或冷白偏绿）+ 门窗漏入天光。光的方向和色温必须自洽 | {现场光源——日光/天光/白炽灯/荧光灯}为主、光的方向明确可追溯、无补光 |
| 空间层次 | 单张全景照片必须呈现前/中/后景——前景（摊位/货架/人群/顶棚柱）形成现场感、中景是交易主体（摊位全貌）、后景是现场延伸（其他摊位/街巷纵深） | 前景{摊位元素}、中景{交易主体}、后景{市场纵深}、人文定焦捕捉完整现场 |
| 材质与表面 | 塑料布顶棚晒褪色、湿漉漉水泥地、堆积蔬果、蛇皮袋、电子秤、塑料凳——一切材质呈现在摄影机下的真实粗糙，非渲染非样板 | 晒褪色塑料布顶棚、湿漉水泥地、堆积蔬果蛇皮袋、电子秤塑料凳、真实粗糙材质 |
| 镜头选择 | 28mm广角（现场全景）或35mm人文定焦（人眼感），全景深 f/8-f/11 或适中 f/5.6-f/8，画面包含完整现场纵深 | 28mm广角/35mm人文定焦、全景深、完整现场纵深、单张全景 |

### 市井类型速查

| 类型 | 核心元素 | 氛围词 |
|---|---|---|
| 乡村集市 | 褪色彩钢瓦/塑料布顶棚、蛇皮袋摊位、堆积蔬果、电子秤、三轮车、讨价还价人群、扬尘 | 乡镇烟火、集日喧闹、最基层的市井 |
| 城市菜市场 | 湿漉漉水泥地、鲜肉水产摊、悬挂的肉类、塑料筐、白炽灯/荧光灯、摊贩与顾客 | 城市烟火、潮湿真实、一日三餐的源头 |

## 六、单视图全景摄影规范

> 真人纪实摄影场景仅需**单张**全景摄影——一张照片装下整个现场的完整信息。不是2×2四视图，不是多角度拼接。

### 画面构成

| 项目 | 摄影要求 |
|---|---|
| 空间呈现 | 单张照片完整呈现场景的现场全貌。使用28mm广角或35mm人文定焦，全场地的纵深、宽度、高度在一张画面中全部可见 |
| 构图 | 全景深大景别——前景（摊位/工具/晾晒物/人物/车辆）形成天然现场感→中景是现场主体→后景向街巷/田野/纵深延伸 |
| 景深 | 全景深 f/8-f/11（环境交代完整）或适中 f/5.6-f/8（主体清晰背景可辨），纪实摄影通常需要交代环境，**绝非商业人像的极端虚化** |
| 人物 | **场景中可包含真实生活/劳作中的人**——摊贩、工人、行人、孩童，处于自然抓拍状态（非摆拍）。也可为空场（收摊后/清晨未开市/午休空寂） |
| 比例 | 建议 3:2（35mm经典）或 16:9 宽幅——匹配纪实摄影的画幅习惯 |
| 色彩 | 低饱和、胶片质感、由现场光源色温驱动，**不套滤镜、不做电影调色** |
| 颗粒 | **35mm胶片颗粒**——Tri-X/Kodak Gold/Portra质感，纪实摄影的签名感 |

### 场景如何叙事

| 场景状态 | 画面线索 | 叙事暗示 |
|---|---|---|
| 清晨未开市 | 折叠摊位未展开、覆盖防雨布、地面湿漉、零星摊贩在摆放 | 一天即将开始，此刻是开场前的蓄势 |
| 喧闹运转中 | 人群交易、蒸汽升腾、讨价还价、三轮车穿行 | 现场正在发生，烟火最盛 |
| 收摊收工后 | 散落的菜叶纸屑、空摊位、积水倒影、夕阳余晖 | 一天结束了，现场安静下来 |
| 正午空寂 | 摊主午休、阴影短、暴晒的空场 | 正午的暂停，最硬的光 |
| 雨中冷清 | 撑伞的零星行人、湿地面倒影、防雨布覆盖、冷灰光 | 雨天的沉郁，市井的另一面 |

## 八、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须是**单张**全景摄影——单视图、非2×2四视图、非多角度、非turnaround |
| R2 | 必须使用人文定焦镜头（28mm/35mm）或广角（24-28mm），全景深 f/8-f/11 或适中 f/5.6-f/8，完整现场纵深 |
| R3 | 光源必须是**现场自然光**——日光/天光/街灯/白炽灯/荧光灯，方向与时段/天气匹配。**严禁布光、补光、反光板、柔光箱** |
| R4 | 场景必须有前/中/后景空间层次，前景现场物件→中景主体→后景延伸 |
| R5 | 必须有中国当代社会现场辨识度——中文招牌/电动车/蛇皮袋/塑料凳/晾晒/对联等真实社会符号 |
| R6 | 必须有真实生活痕迹与时代质感——晒褪色/湿漉/斑驳/油污/积灰/晾晒物/电线，非样板非影视城非全新 |
