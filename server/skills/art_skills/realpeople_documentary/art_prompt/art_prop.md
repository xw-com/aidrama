# 真人纪实摄影道具图像生成 · 约束手册

---

## 一、道具设计原则

> 真人纪实摄影的道具不是"被陈设的精致物件"，而是"被真实生活用旧了、被手握过千万次、被岁月盘过"的真实生活器物——它在劳动者手里待过、在灶台上熏过、在田间日晒雨淋过。摄影机拍下的是它的此刻，带着全部的使用痕迹与时代质感。

1. **器物即时代** — 每一件道具都是一个微型的时代叙事容器。搪瓷缸掉漆的豁口暗示用了多少年、解放鞋磨平的鞋底暗示走过多少路、老收音机的旋钮油腻暗示被听过多少个黄昏——器物自己会讲普通人的故事
2. **使用痕迹优先于完美品相** — 真人纪实摄影的道具必须有"被用过、被磨过、被岁月盘过"的证据。全新出厂、精致品相、样板级别的道具一律不出现——这是纪实，不是产品广告
3. **中国当代真实生活器物** — 道具必须是中国当代社会中真实存在的生活/劳作器物：锄头、扁担、搪瓷缸、军用水壶、解放鞋、二八大杠、老式保温瓶、蛇皮袋——拒绝无国别架空物品、拒绝精致陈设
4. **材质即真实** — 不是PBR参数渲染出的材质，而是摄影机拍下的真实材质行为：搪瓷的掉漆与磕碰、铁器的锈与油污、木器的包浆与开裂、塑料的褪色与发黄
5. **单视图纪实静物摄影** — 道具以单张纪实静物摄影方式独立呈现，**在真实环境表面上**（木桌/水泥地/灶台/田埂），非多角度建模展示，非2×2四宫格，**非素灰背景纸产品摄影**

## 三、单视图纪实静物摄影规范

> 真人纪实摄影道具仅需单张纪实静物摄影，**在真实环境表面上**拍摄，非多角度建模展示，**非素灰背景纸产品摄影**（那是商业广告，不是纪实）。以下为单视图纪实静物的完整规范。

### 画面构成

| 项目 | 摄影要求 |
|---|---|
| 道具呈现 | 道具居中或偏三分线位置独立陈列，完整入画，无裁切 |
| 背景/承载面 | **真实环境表面**——旧木桌/灶台/水泥地/田埂土地/布面/报纸，根据道具属性选择。背景为真实环境的轻微虚化（同色系现场），**绝非素灰无缝背景纸**。无刻意装饰 |
| 光线 | **现场自然光**——窗光/门光/天光45°侧入（柔和带自然阴影）、或室内白炽灯/荧光灯实用光。**无柔光箱、无反光板、无补光、无影棚灯**。光影方向明确、投影自然 |
| 景深 | 适中景深（f/4-f/8），道具主体清晰，前后微虚化保留环境交代——绝非商业产品的极端浅景深 |
| 投影 | 道具底部与承载面之间的自然接触阴影——真实的而非抠图或悬浮。阴影柔软、方向与现场光源一致 |
| 颗粒 | **35mm胶片颗粒**——Tri-X/Kodak Gold/Portra质感 |
| 画面比例 | 建议 3:2（35mm经典）或 1:1 正方形，适配单件道具展示 |

### 道具状态准则

| 维度 | 要求 |
|---|---|
| 使用痕迹 | 必须有"被用过、被岁月盘过"的视觉证据——非全新、非样板品相、非未启用 |
| 中国当代辨识度 | 中国当代社会真实生活/劳作器物形制/中文（如招牌/挂历/奖状）——拒绝无国别架空物品、拒绝精致陈设 |
| 材质真实感 | 非渲染质感——是摄影机拍下的真实材料行为（光的反射、漫射、透射、磨损） |
| 时代质感 | 器物须承载时代信息——褪色、锈迹、油污、磨损、旧化是叙事的基础 |
| 尺度感 | 通过材质纹理密度、磨损细节暗示实物尺寸，无需参照物 |

## 六、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须是「单张纪实静物摄影」——单视图、非多角度、非2×2四宫格、非建模展示 |
| R2 | 必须指定「真实环境承载面」（旧木桌/灶台/水泥地/田埂/布面/报纸），**禁止素灰无缝背景纸与商业产品摄影背景** |
| R3 | 必须指定「现场自然光」（窗光门光/白炽灯/荧光灯），光影方向明确、投影自然，**禁止柔光箱/反光板/补光/影棚灯** |
| R4 | 道具必须有「使用痕迹/磨损痕迹/岁月旧化」——非全新、非样板品相、非未启用 |
| R5 | 道具必须具备中国当代社会辨识度——真实生活/劳作器物形制/中文——拒绝无国别架空物品与精致陈设 |
| R6 | 必须声明「纪实静物摄影 + 非3D渲染非CG非棚拍非产品广告」核心锚定 |
| R7 | 材质必须描述为摄影机下的真实磨损表现，而非渲染参数 |
| R8 | 必须声明「35mm胶片颗粒质感 + 低饱和真实色温」 |
