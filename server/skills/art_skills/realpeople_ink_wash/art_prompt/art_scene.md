# 场景图生成 · 水墨写实约束手册

---

## 一、场景美学原则

1. **留白即语言** - 以白当黑，画面留白不少于三分之一；留白是云、是水、是雾、是呼吸，不是空无
2. **层次纵深** - 所有场景必须具备前/中/后景，墨色近浓远淡，层层递退，远景化入空白
3. **质感至上** - 宣纸纹理可辨、皴擦点染笔意含蓄、干湿浓淡变化丰富；山石如皴、水纹如描、粉墙如留白
4. **意境叙事** - 空景如诗，物象简而不空；题跋位留白布局（画面边角预留空白如题跋之位），但画面中不出现任何真实文字

## 二、季节色调映射

| 季节 | 主色调 | 辅色调 | 提示词 |
|---|---|---|---|
| 春 | 淡青 + 苍青 | 花青、浅赭 | 春山淡青、新枝浅绿 |
| 夏 | 浓墨 + 苍青 | 花青、留白 | 夏木浓荫、墨叶沉沉 |
| 秋 | 赭石 + 淡墨灰 | 米灰、枯笔 | 秋山赭黄、枯笔疏林 |
| 冬 | 留白 + 淡墨灰 | 银灰、焦墨点 | 冬雪留白、寒林焦墨 |

## 三、室内场景

### 空间规范

| 维度 | 约束 | 提示词 |
|---|---|---|
| 风格 | 江南庭院/书斋/茶室/禅房/水榭，中式素雅陈设 | 中式{空间}素雅陈设 |
| 材质 | 木格窗/宣纸窗/原木家具/素麻织物/陶器为主 | 木格窗、纸窗柔光、原木家具 |
| 色调 | 素雅淡彩 + 原木色 + 墨色点缀 | 素雅色调、青淡设色 |
| 纵深 | 前/中/后景层次，墨色近浓远淡 | 前景{元素}、中景{元素}、后景{元素} |
| 质感 | 宣纸纹理、木纹如皴、织物素净 | 皴擦笔意、宣纸质感 |
| 光照 | 柔和天光透过纸窗漫射，无强光，光影如淡墨晕染 | 纸窗漫射天光、淡墨光影 |

| 瑕疵感 | 木器包浆、纸窗微皱、陶器开片、器物简旧 | 包浆温润、器物简旧 |

## 五、主视图规范

### 视图定义

> 单画面主视图，从场景中最具代表性的角度取景，承载空间叙事与构图重心。

| 项目 | 约束 | 提示词 |
|---|---|---|
| 视角 | 自然观察视角，构图最能体现留白呼吸与场景主体 | hero shot、representative angle |
| 视点高度 | 默认人眼平视高度，特殊场景可俯/仰 | eye level（默认） |
| 构图 | 边角取景或三分法，主体偏置，留白过半，前/中/后景层次清晰 | balanced composition with negative space |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 单画面（非拼图、非多视图、非分屏） |
| 人物 | **严禁出现任何人物、人影、人体轮廓** |
| 一致性 | 风格/材质/色调/光线统一 |
| 光线 | 单一光源逻辑，光影方向一致 |
| 画面比例 | 默认 16:9（或按调用方设定） |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 场景必须有「前中后景层次」，墨色近浓远淡 |
| R2 | 室外必须包含「近浓远淡/远山化入空白」的墨色递退 |
| R3 | 场景图必须为「单画面主视图」，不得拼接多视图/分屏/网格 |
| R4 | 构图须能体现留白呼吸（留白不少于三分之一）与场景主体 |
| R5 | 场景图中**严禁出现任何人物** |
| R6 | 必须包含水墨质感关键词（ink wash realism / xuan paper / five shades of ink） |
| R7 | 必须包含留白构图关键词（negative space / 大面积留白 / 以白当黑 至少一项） |
| R8 | 材质必须带有包浆/苔痕/岁月痕迹，禁止全新无瑕的"塑料感" |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 背景纯白无场景层次/纯黑/无场景 |
| X2 | 极端天候（暴风雨/雷电/暴雪，除非剧情需要） |
| X3 | 场景无纵深/无层次/满构图无留白 |
| X4 | 植被/天候与季节矛盾 |
| X5 | 出现任何人物、人影、人体剪影或人体轮廓 |
| X6 | 画面被拼接成多视图/网格/分屏布局 |
| X7 | 卡通/动漫/3D 渲染/CG 质感；2D 水墨动画/水墨漫画/纯手绘插画风 |
| X8 | 高饱和浓彩/荧光/霓虹；油彩厚涂与画布肌理等油画语言 |
| X9 | 画面出现任何真实文字（题跋、对联、匾额、印章款识一律以留白代替）；光照出现硬阴影强明暗 |
