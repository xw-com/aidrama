# 人物基础形象生成 · 水墨写实约束手册

---

## 一、基础形象原则

1. **面容即灵魂** - 五官是角色唯一锚点，面部以留白提神、淡墨皴擦塑形
2. **角色为本** - 基础着装由角色描述（身份/职业/性别/场景）决定其常规着装；后续特定服化为叠加层
3. **四视图一致** - 面容/体型/发型/基础服装跨视图高度统一
4. **写实基底** - 五官比例与解剖结构遵循真人写实标准，水墨质感只叠加于画面表层，不得扭曲形体、不得滑向 2D 水墨动画

---

## 二、面容约束

> 不再固定五官特征参数，由角色描述（性别/年龄/性格/气质）驱动 AI 自由生成五官，保证人物间外观差异化。

### 通用要求

| 项目 | 约束 |
|---|---|
| 五官 | 由角色描述自然推导，不预设脸型/眼型/眉型/鼻型/唇型 |
| 风格底色 | 水墨写实、真人写实基底、写意皴擦笔意、宣纸纹理、墨色浓淡干湿 |
| 气质 | 必须从角色描述提炼整体气质关键词（如清雅/疏淡/温润/凛然），并写入提示词 |
| 表情 | 中性微表情，如水墨人物定格的一瞬，符合角色气质 |

## 六、基础服装约束

> 基础服装由角色描述（身份/职业/性别/场景）决定其最自然的常规着装，作为该角色「日常默认态」；正式服饰/特殊衍生在服化衍生环节叠加。**禁止内衣打底**。素色衣袂为本风格统一规则：衣料素净、褶皱如墨线勾勒、设色青淡。

### 着装选择原则

| 角色身份 | 默认着装方向 |
|---|---|
| 古风/传统角色 | 素色衣袂（长衫/襦裙/道袍等，水墨晕染质感） |
| 现代角色 | 现代素色便装（棉麻衬衫/素色连衣裙，低饱和） |
| 文人/学者 | 棉麻长衫/素色衬衫 |
| 居家/休闲 | 素色家居便服 |
| 特殊职业 | 对应身份服装（素色低饱和处理） |
| 角色描述未明确 | 素色棉麻常服、青灰/花青色调 |

### 着装统一规则

- 服装风格须与水墨美学一致：素色为主、衣袂垂坠、褶皱如墨线勾勒、设色青淡
- 颜色限淡彩（花青/赭石/苍青/灰调），无繁复花纹/装饰，便于后续衍生叠加
- 四视图服装款式完全一致
- 基础服装是「日常默认态」，焦点仍在面容与体态
- 严禁内衣/暴露/性化打底

## 八、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须为「自然状态」|
| R2 | 必须根据角色描述声明合适的常规着装作为基础服装（如古风角色->素色衣袂、文人->棉麻长衫、现代角色->素色便装）；禁止内衣打底 |
| R3 | 必须声明「无发饰、无配饰」 |
| R4 | 必须指定「茶白宣纸底色背景」 |
| R5 | 必须指定「四视图一致性」 |
| R6 | 全身立像必须从头顶到脚底完整展示，严禁裁切 |
| R7 | 必须声明角色身高并通过头身比换算约束全身比例 |
| R8 | 人像特写必须从头顶到锁骨完整展示，严禁裁切头顶 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 内衣/暴露/性化打底；与角色描述明显不符的着装；过度复杂花纹/装饰干扰后续服化叠加 |
| X2 | 正顶硬光/正底光/彩色光 |
| X3 | 2D 水墨动画/水墨漫画/纯手绘插画风；为追求画意而扭曲解剖比例 |
| X4 | 复杂场景背景（必须纯宣纸底色） |
| X5 | 夸张表情/动态姿势 |
| X6 | 全身立像裁切头顶或脚底，必须从头到脚完整入画 |
| X7 | 人像特写裁切头顶，必须从头顶到锁骨完整入画 |
| X8 | 忽略身高和头身比约束；画面出现任何真实文字（题跋/印章/款识一律不得出现） |
