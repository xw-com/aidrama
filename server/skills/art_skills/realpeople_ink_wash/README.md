# 水墨写实风格说明

本风格专为"水墨写实"题材打造，所有美术提示词、规范和生成内容均严格限定于：

- **写实人物基底**：所有角色、场景、道具均以真人写实为标准，五官、皮肤、发丝、材质保持真实的结构与比例，仅在画面质感层面叠加水墨处理；绝非 2D 水墨动画或水墨漫画。
- **水墨写意质感**：整体画面呈墨分五色（焦浓重淡清）的浓淡干湿变化、写意皴擦笔意与宣纸纹理，墨色塑形、笔触含蓄。
- **大面积留白构图**：以白当黑，画面留白即呼吸；题跋位留白布局，但画面中不出现任何真实文字。
- **青淡设色点缀**：墨为主色，花青、赭石、苍青等青淡设色仅作点睛，朱磦一点用于高光时刻。
- **烟雨意境叙事**：适合山水烟雨、江南庭院、文人情感、古意今情类故事，强调含蓄悠远的东方诗性表达。

## 适用范围

- 水墨写实题材的AI美术生成（角色、场景、道具、分镜等）
- 需要真人写实基底、水墨写意质感与留白意境的视觉创作

## 严禁内容

- 卡通、动漫、插画、二次元、赛璐璐风格
- 2D 水墨动画/水墨漫画/纯手绘插画风（必须为写实基底+水墨质感叠加）
- 高饱和浓彩、荧光色、霓虹色
- 暗示性、暴露、透视等不适宜内容
- 油彩厚涂、画布肌理等油画语言（与油画质感写实风格互斥）
- 画面出现任何真实文字（题跋、对联、印章款识、书本文字一律以留白代替）

## 风格体验

在本风格下，您将体验到：

- 角色如立于宣纸之上：面容写实、淡赭肤色温润、面部留白提神、发丝如墨色晕染
- 场景如水墨山水与庭院小写：烟雨空蒙、白墙黛瓦、近浓远淡、大面积留白构图
- 道具如文人清供：笔墨纸砚、素陶茶器、油纸伞、折扇以皴擦点染呈现素雅质感
- 分镜与视频均以写实人物为基底，叠加墨色浓淡与宣纸肌理，叙事含蓄而有诗性

---

本风格仅适用于"水墨写实"相关项目。如需其他风格（如都市写实、油画质感写实、动漫等），请勿使用本套提示词。
