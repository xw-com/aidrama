# 水墨风格约束 · 水墨写实 · 技法参考

---

## 一、色调体系与画面基调

- **墨色体系为轴** - 全片以墨分五色（焦浓重淡清）为色彩主轴，宣纸白（C1）为呼吸底色，整体色温中性偏冷（6000-6800K），饱和度低（15-35%），呈现素净清朗的水墨意境
- **墨色叙事对比** - 浓墨（C4）用于冲突、决绝、力量段落，淡墨灰（C5）与留白用于疏离、追忆、释然段落；墨的浓淡即是情绪的深浅，应与情绪弧线同步
- **设色点睛策略** - 日常与铺垫段落以纯墨与灰调为主，心动与高光段落释放淡彩（花青 C6、苍青 C8），朱磦点（C3）全片仅留给最重要的一次情绪点睛；避免全程设色导致水墨语言稀释
- **留白先行原则** - 段落规划先绑定情绪场景（初见/暧昧/争执/和解/顿悟等），再确定墨色浓淡、留白面积与设色方案，避免"剧情对了但意境不对墨"
- **禁用色域** - 高饱和浓彩、荧光色、霓虹污染与油画式暖褐金色调均与本风格不兼容

## 二、光影方案体系

- **光影即叙事** - 6 套光影方案对应不同情绪段落，导演规划阶段应在段落层面确定光影基调方向，而非逐镜指定
- **光源角度** - 以漫射天光为默认光源，无硬影；正给镜头默认正面漫射+侧后方淡淡轮廓，侧给镜头以墨色浓淡区分层次

| 光影方案 | 方案名 | 色调倾向 | 适用情绪 |
|---|---|---|---|
| A | 素白漫射 | 留白主导 + 极淡墨影 | 日常、静观叙事 |
| B | 湿墨晕染 | 灰调湿墨 + 空气感 | 烟雨、思念、朦胧 |
| C | 焦墨浓影 | 浓墨对比 + 深色轮廓 | 冲突、压抑、决绝 |
| D | 淡彩点睛 | 素底 + 朱磦/花青一点 | 心动、高光、点睛 |
| E | 月夜墨色 | 冷灰深墨 + 烛火一点 | 夜话、孤寂、内省 |
| F | 留白空境 | 大面积留白 + 物象极简 | 顿悟、超脱、空镜转场 |

- **浓淡分配** - 浓墨可全片使用但需克制；冲突段落拉大浓淡反差，释然段落收拢墨色放宽留白，避免情绪与墨色脱节
- **氛围方向映射** - 每场戏氛围方向应映射到上述光影方案（A-F）的某一方向，确保视觉一致性

## 三、质感方向

- **墨分五色为魂** - 焦浓重淡清的层次变化是本风格的签名；每一画面都应能说清"最浓的墨在哪里、留白在哪里"
- **宣纸肌理统一** - 全片共享宣纸底层纹理，人物与场景如绘于同一张纸上，保证质感整体性；写实基底不变形，水墨只叠加于质感层
- **皴擦点染笔意** - 山石如皴、水纹如描、苔点如缀、发丝如晕；笔触含蓄服务于物象，不做无意义的笔触炫技
- **留白即构图** - 留白不少于三分之一，以白当黑；留白是云是水是雾是心境，构图永远为留白留出呼吸之位

## 四、水墨场景空间元素

水墨写实世界观特有的场景元素及其视觉叙事功能：

- **纸窗/月洞门/曲廊/帘幕** - 框景与"隔而不断"的东方空间语言，制造层叠透景与人物关系距离感
- **水面/雾气/远山** - 留白与虚实的核心载体；水天一色的空白处即情绪的余韵
- **石阶/苔痕/古桥/粉墙** - 时间沉淀的痕迹，承担岁月、故人、旧事等记忆叙事
- **油纸伞/扁舟/灯笼/烛火** - 点睛道具与情绪外化：伞下是独处，舟上是漂泊，灯与烛是人间一点暖
- **空镜过渡建议** - 雨滴水面的涟漪、雾中远山渐隐、竹影横斜、檐角滴水、飞鸟掠过空白，用于段落间情绪缓冲，避免硬切
- **视觉转折建议** - 优先用画面手段承接转折：墨色由浓转淡、由湿转干、留白面积突变、朱磦点出现或褪去；避免用对白解释情绪变化

## 五、水墨乐器与环境音

水墨写实世界观下的声音元素约束：

### 乐器选择

- **古琴** - 核心：留白、呼吸、文人风骨，最能承载水墨意境的乐器
- **箫/笛** - 悠远、思念、烟雨空蒙段落的主导音色
- **中国打击乐（鼓/木鱼/磬）** - 顿点、节奏转折与禅意段落的骨架
- **弦乐淡铺底** - 情绪弥散段落克制使用，音量永远从属于民族乐器
- **环境音优先级高** - 水墨世界中真实环境声是意境关键，配乐不应压过对白

### 乐器组合策略

| 情绪阶段 | 乐器组合 |
|---|---|
| 平稳/开场/收尾 | 古琴独奏 |
| 日常推进 | 古琴 + 轻打击（木鱼/磬点） |
| 思念/烟雨 | 箫独奏 或 古琴 + 箫 |
| 冲突/决绝 | 中国大鼓 + 低频铺底 |
| 空镜/顿悟/转场 | 磬声余韵 + 环境声（近无声） |

### 水墨环境音

- **典型环境音层次** - 雨打芭蕉 / 檐角滴水 / 风过竹林 / 水面桨声 / 茶汤注杯 / 纸页翻动 / 远处寺钟 / 空谷鸟鸣
- **每场戏标注 1-2 个核心环境音**，帮助后续音效设计。环境音层次越准确，烟雨庭院的意境质感越强
- **声音留白建议** - 声音留白与画面留白同步：空镜与顿悟段落允许数秒近无声，只留一个环境音；对白之后留一息呼吸，再起乐声，如墨迹将干未干
