## 二、全局色彩盘（风格基线，不是硬锁）

> 目标：统一审美而非限制创作。除「硬约束色」外，其余颜色默认优先使用，可在合理范围内偏移。

### 色彩使用层级

| 层级 | 约束强度 | 说明 |
|---|---|---|
| L1 硬约束 | 高 | 仅锁定角色识别核心：肤色、发色、主服底色的审美方向 |
| L2 软约束 | 中 | 场景色、配饰色、点缀色优先参考色盘，可按镜头与剧情微调 |
| L3 例外机制 | 低 | 高潮/顿悟/点睛戏可临时突破局部设色，但需保留整体墨色主导逻辑 |

| 序号 | 色名 | 色值 | 用途 |
|---|---|---|---|
| C1 | 宣纸白 | #F2EDE3 | 留白基底、纸窗、白墙、雾气 |
| C2 | 淡赭肤 | #E4D3BC | 女性/男性肤色基准 |
| C3 | 朱磦点 | #B5493A | 点睛色、唇色、烛火、灯笼 |
| C4 | 浓墨 | #2B2B2B | 发色、眼瞳、墨线、焦墨 |
| C5 | 淡墨灰 | #8C8C86 | 远山、衣纹、灰面过渡 |
| C6 | 花青 | #4A6670 | 衣料、天色、水面设色 |
| C7 | 赭石 | #A5765A | 木器、坡石、暖点缀 |
| C8 | 苍青 | #6B7F6A | 植被、苔点、淡彩 |
| C9 | 茶白 | #EDE7DA | 设定图背景、软装基底 |
| C10 | 米灰 | #D9D2C2 | 织物、纸窗、室内灰面 |

### 硬约束色（默认锁定）

| 色项 | 对应色 | 规则 |
|---|---|---|
| 肤色基准 | C2 淡赭肤 | 默认优先，允许小幅明度微调，禁艳彩妆感 |
| 发色/瞳色基准 | C4 浓墨 | 默认优先，允许浓墨/深墨轻微偏移 |

### 软约束色（推荐优先）

> C1/C3/C5/C6/C7/C8/C9/C10 为推荐色域，用于留白、点睛、衣纹、天色、木器、植被、背景、织物等。可根据镜头氛围做同色相邻近调整；设色永远从属于墨色。

### 情绪色盘（导演对齐版）

| 情绪场景 | 主色 | 辅色 | 光效与对比建议 | 画面关键词 |
|---|---|---|---|---|
| 初次相遇（日常） | C1 宣纸白 | C6 花青 + C5 淡墨灰 | 淡墨铺底、人物微设色，留白过半 | 初见、清朗、纸墨微香 |
| 心动信号（暧昧） | C2 淡赭肤 | C3 朱磦点 + C8 苍青 | 人物淡彩微升温，背景墨色减淡留白 | 微澜、含蓄、欲说还休 |
| 日常相处（生活） | C9 茶白 | C7 赭石 + C5 淡墨灰 | 墨色温润，干笔皴擦质感 | 淡泊、家常、清简烟火 |
| 冲突争执（压抑） | C4 浓墨 | C5 淡墨灰 + C6 花青 | 焦墨重笔，浓淡反差拉大 | 凝重、对峙、风雨欲来 |
| 重逢和解（回暖） | C1 宣纸白 | C8 苍青 + C2 淡赭肤 | 淡墨转湿墨晕染，留白渐宽 | 释然、云开、烟波平静 |
| 告白/高光（浓情） | C3 朱磦点 | C6 花青 + C2 淡赭肤 | 唯一允许的浓彩点缀，墨底衬朱 | 深情、点睛、惊鸿一瞥 |
| 烟雨沉思（幽远） | C6 花青 | C5 淡墨灰 + C1 宣纸白 | 湿墨晕染，远景化入空白 | 迷离、悠远、山水无言 |
| 回忆/闪回（褪色） | C1 宣纸白 | C9 茶白 + C5 淡墨灰 | 旧墨褪色感，淡到将尽 | 追忆、氤氲、似水流年 |

### 情绪色盘使用规则

| 编号 | 规则 |
|---|---|
| E1 | 每条提示词至少指定 1 个「情绪场景」并绑定主色+辅色组合 |
| E2 | 单镜头主色不超过 2 个，点彩不超过 1 处，避免颜色叙事失焦 |
| E3 | 情绪切换时优先调整墨色浓淡与留白面积，再调整设色 |
| E4 | 水墨向默认遵循「墨底留白 + 淡彩点睛」：墨色塑形，留白呼吸，彩色只落在情绪焦点 |
| E5 | 若与剧情冲突，以情绪色盘优先于通用推荐色，但不得突破严禁项 |

### 色温约束

| 参数 | 值 | 说明 |
|---|---|---|
| 整体色温 | 中性偏冷 6000-6800K（推荐） | 素净清朗的水墨基调 |
| 肤色色温 | 中性 5500-6200K（推荐） | 淡赭温润不艳 |
| 对比度 | 中（建议保持） | 以墨色浓淡过渡为主，非强明暗 |
| 饱和度 | 低 15-35%（建议区间） | 墨为主、淡彩为辅 |

### 容差与例外

| 项目 | 建议容差 |
|---|---|
| 色相偏移 | ±8° |
| 饱和度偏移 | ±10% |
| 明度偏移 | ±12% |

> 例外场景：告白、点睛、高光镜头可将朱磦点 C3 提至较高饱和作为唯一浓彩；但禁止大面积浓彩与高饱和现代色彩入镜。

## 三、全局约束规则

### 必守规则（所有技能继承）

| 编号 | 规则 |
|---|---|
| R1 | 必须包含「水墨写实」风格锚定词 |
| R2 | 必须声明「墨分五色 + 宣纸纹理」 |
| R3 | 面部必须使用「写意皴擦笔意 + 面部留白提神」 |
| R4 | 发丝必须使用「墨色笔触晕染 + 发丝可辨」 |
| R5 | 纹理必须声明「宣纸纹理 + 墨色浓淡干湿变化」 |

### 严禁项（所有技能继承）

| 编号 | 严禁内容 |
|---|---|
| X1 | 严禁「卡通/动漫/二次元/赛璐璐」 |
| X2 | 严禁「高饱和浓彩/荧光色/霓虹色」 |
| X3 | 严禁「2D 水墨动画/水墨漫画/纯手绘插画风」（必须为写实人物基底+水墨质感叠加） |
| X4 | 严禁「面部变形/多指/肢体异常」倾向词 |
| X5 | 严禁「裸体/暴露/透视/暗示性描述」 |
| X6 | 严禁「油彩厚涂/画布肌理等油画语言」（与油画质感写实风格互斥） |
