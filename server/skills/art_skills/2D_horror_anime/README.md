# 恐怖动漫风格说明

本风格专为"日式恐怖动漫"题材打造，所有美术提示词、规范和生成内容均严格限定于：

- **日式恐怖世界观**：以都市怪谈、旧宅废墟、深夜街道、校园七不思议为背景，涵盖旧公寓、废弃医院、神社后山、隧道巷弄等异质空间。
- **阴翳动画质感**：所有角色、场景、道具均以日式恐怖动画为标准，强调大面积阴翳阴影、硬朗清晰线稿、低饱和惨色调。
- **心理恐怖美学**：以诡异视角、失衡构图、大面积负空间压迫制造不安感，追求"看不见的恐怖"与氛围铺陈，而非直观惊吓。
- **克制的惊悚表达**：以心理恐怖/氛围恐怖为内容安全边界，恐怖感来自暗示、留白与光影错位，禁止过度血腥猎奇描述。

## 适用范围

- 日式恐怖动漫题材的AI美术生成（角色、场景、道具、分镜等）
- 需要阴翳阴影、诡异构图、心理恐怖氛围的视觉创作

## 严禁内容

- 过度血腥、猎奇、残虐、尸体特写等直观恐怖描述（以心理恐怖/氛围恐怖为界）
- 现代明亮动画风格、3D渲染、CG动画、写实摄影质感
- 高饱和糖果色、萌系可爱化处理、Q版变形
- 鬼怪过度具象化、跳吓式猎奇演出、成人向内容

## 风格体验

在本风格下，您将体验到：

- 角色面容清冷、气质敏感脆弱或阴郁沉默，服饰暗色低调，均为日式恐怖动漫风格
- 场景阴翳纵深，走廊、废墟、深夜街巷层次丰富，负空间压迫感强烈
- 道具、旧物、诅咒物造型古旧，锈蚀霉斑质感细腻，暗示性叙事强
- 分镜与画面以阴翳光影与诡异构图制造心理不安，强调暗示而非展示

---

本风格仅适用于"恐怖动漫"相关项目。如需其他风格（如治愈、热血、写实、CG等），请勿使用本套提示词。
