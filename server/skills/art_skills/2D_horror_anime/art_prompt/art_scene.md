# 恐怖动漫风格 - 场景图生成 · 约束手册

---

## 一、场景美学原则

1. **空间即威胁** — 场景本身承载压迫与不安，不是纯背景板；纵深尽头、门缝、转角都是叙事伏笔
2. **层次纵深** — 所有场景必须具备前/中/后景，且至少一层被阴翳吞噬，杜绝扁平
3. **质感至上** — 线条/色彩/光影等材质表现必须清晰，陈旧破损细节须可辨
4. **阴翳为锚** — 一切画面以日式恐怖动漫为标准，拒绝现代CG/3D渲染；追求手绘线条特征（硬朗线条、块面阴翳）与诡异构图（失衡视角、大面积负空间、非常规取景）

| 类型 | 核心元素 | 氛围词 |

## 五、主视图规范

### 视图定义

> 单画面主视图，从场景中最具不安感与代表性的角度拍摄，承载空间叙事与构图重心。

| 项目 | 约束 | 提示词 |
|---|---|---|
| 视角 | 非常规观察视角（低角度仰视/略倾斜俯视/正对纵深），构图最能制造不安感 | unsettling angle、low angle、forced perspective |
| 视点高度 | 默认人眼高度或低于人眼，制造压迫 | low eye level（默认） |
| 构图 | 主体偏置或置于纵深尽头，负空间占比 40%+，前/中/后景层次清晰 | off-center composition、large negative space |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 单画面（非拼图、非多视图、非分屏） |
| 人物 | **严禁出现任何人物、人影、人体轮廓** |
| 一致性 | 风格/材质/色调/光线统一 |
| 光线 | 单一光源逻辑，光影方向一致 |
| 画面比例 | 默认 16:9（或按调用方设定） |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 场景必须有「前中后景层次」，且至少一层没入阴翳 |
| R2 | 室外必须包含「空气透视」与孤立光源逻辑 |
| R3 | 场景图必须为「单画面主视图」，不得拼接多视图/分屏/网格 |
| R4 | 构图须体现不安感（失衡取景/纵深尽头/负空间压迫）并展示前/中/后景层次 |
| R5 | 场景图中**严禁出现任何人物** |
| R6 | 必须包含恐怖动漫关键词（Japanese horror anime style / dark shadows / desaturated） |
| R7 | 必须包含线条特征（硬朗线条、阴翳块面 至少一项） |
| R8 | 材质必须带有霉斑/锈迹/积灰等陈旧痕迹，禁止崭新无瑕的"CG 感" |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 背景纯白/纯灰无场景 |
| X2 | 明亮晴空/万里无云的清爽白昼 |
| X3 | 场景无纵深/无层次/无阴翳 |
| X4 | 植被茂盛鲜绿、天候与时段氛围矛盾 |
| X5 | 出现任何人物、人影、人体剪影 |
| X6 | 画面被拼接成多视图/网格/分屏布局 |
| X7 | 3D 渲染/CG 动画/现代明亮风格质感 |
| X8 | 材质过于干净完美、无任何陈旧痕迹 |
| X9 | 血腥猎奇元素（血泊/残肢/尸体痕迹等直观恐怖符号） |
