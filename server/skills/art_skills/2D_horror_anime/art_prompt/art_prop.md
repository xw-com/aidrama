# 恐怖动漫风格 - 道具图像生成 · 约束手册

---

## 一、道具设计原则

1. **暗示可读** — 道具的叙事暗示力优先（来历/执念/禁忌），造型服务于"背后有故事"
2. **质感极致** — 材质纹理必须清晰可辨（锈金属/旧木/斑驳陶瓷/褪色布纸/浑浊玻璃）
3. **年代风格** — 所有道具符合日式恐怖世界观，旧物美学统一，禁止崭新量产感
4. **尺度明确** — 通过参照物或标注暗示道具真实尺寸
5. **纯道具独立展示** — 画面中只能出现道具本身，严禁出现任何人物、手部、肢体，道具不可处于被持有/佩戴/握持状态，必须以静物陈列方式独立呈现

## 三、多角度设定图规范

### 视图定义

| 位置 | 视图 | 角度 | 要求 | 提示词 |
|---|---|---|---|---|
| 左上 | 正面图 | 正面 0° | 道具完整正面形态 | front view |
| 右上 | 侧面图 | 侧面 90° | 厚度/轮廓/结构清晰 | side view |
| 左下 | 背面图 | 背面 180° | 道具背部结构/磨损 | back view |
| 右下 | 细节特写 | 局部放大 | 材质纹理/做旧痕迹细节 | detail closeup |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 同一画面四宫格（2×2），上下左右四视角 |
| 背景 | 冷灰白 #C9CFC4 |
| 光线 | 柔和顶部冷光，均匀柔光，轻微单侧阴影保留阴翳气质 |
| 比例 | 每格道具占格内主体 70%+ |
| 投影 | 允许自然地面微投影 |
| 画面比例 | 建议 1:1 |

## 六、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须指定「冷灰白背景 #C9CFC4」 |
| R2 | 必须明确道具材质与做旧程度 |
| R3 | 道具造型必须符合日式恐怖世界观风格，诅咒物/信物须带来历暗示痕迹 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 复杂场景背景 |
| X2 | 道具与人物同画面 |
| X3 | 出现任何人物形象 |
| X4 | 道具处于被持有、握持、佩戴、使用中的状态 |
| X5 | 出现暗示人物存在的元素 |
| X6 | 崭新量产感、高饱和鲜艳配色 |
| X7 | 血腥猎奇元素（血渍/残肢/人体组织等直观恐怖符号） |
