# 恐怖动漫风格 - 人物基础形象生成 · 约束手册

---

## 一、基础形象原则

1. **阴翳即灵魂** — 大面积阴影与惨白对比为角色核心，避免均匀明亮打光
2. **角色为本** — 基础着装由角色描述（身份/职业/性别/场景）决定其常规着装；后续特定服化为叠加层
3. **四视图一致** — 面容/体型/发型/基础服装跨视图高度统一
4. **气质阴郁克制** — 无妆状态需体现角色气质（阴郁/敏感/麻木/清冷）

---

## 二、面容约束

> 不再固定五官特征参数，由角色描述（性别/年龄/性格/气质）驱动 AI 自由生成五官，保证人物间外观差异化。

### 通用要求

| 项目 | 约束 |
|---|---|
| 五官 | 由角色描述自然推导，不预设脸型/眼型/眉型/鼻型/唇型 |
| 风格底色 | 日式恐怖动漫 2D 赛璐璐质感（硬朗线条、阴翳阴影、低饱和惨色） |
| 气质 | 必须从角色描述提炼整体气质关键词（如阴郁/敏感/麻木/清冷），并写入提示词 |
| 表情 | 中性微表情偏紧绷，眼神略带戒备，符合角色气质 |

## 六、基础服装约束

> 基础服装由角色描述（身份/职业/性别/场景）决定其最自然的常规着装，作为该角色「日常默认态」；正式服饰/特殊衍生在服化衍生环节叠加。**禁止内衣打底**。

### 着装选择原则

| 角色身份 | 默认着装方向 |
|---|---|
| 学生 | 深色旧式校服 / 暗色学院制服 |
| 上班族 | 暗色通勤装（衬衫+裤装/裙装） |
| 居家/休闲 | 旧式家居服（针织开衫/长裙/居家套装） |
| 灵异相关者 | 对应身份装束（巫女服/神官装/除灵师装束等） |
| 特殊职业 | 对应身份服装（医生/警察/记者等） |
| 角色描述未明确 | 暗色系日常常服 |

### 着装统一规则

- 服装风格须与日式恐怖动漫美学一致（暗色低调、低饱和、手绘质感）
- 颜色低饱和，无复杂花纹/装饰，便于后续衍生叠加
- 四视图服装款式完全一致
- 基础服装是「日常默认态」，焦点仍在面容与体态
- 严禁内衣/暴露/性化打底

## 八、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须为「素颜无妆」状态 |
| R2 | 必须根据角色描述声明合适的常规着装作为基础服装（如学生→深色旧式校服、上班族→暗色通勤装、居家→旧式家居服）；禁止内衣打底 |
| R3 | 必须声明「无发饰、无配饰」 |
| R4 | 必须指定「冷灰白背景 #C9CFC4」 |
| R5 | 必须指定「四视图一致性」 |
| R6 | 全身立像必须从头到脚完整展示，严禁裁切 |
| R7 | 必须指定角色身高并通过头身比换算约束全身比例（女性默认150-163cm/5.5-6头身，男性默认168-178cm/6.5-7.5头身） |
| R8 | 人像特写必须从头顶到锁骨完整展示，严禁裁切头顶 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 内衣/暴露/性化打底；与角色描述明显不符的着装；过度复杂花纹/装饰干扰后续服化叠加 |
| X2 | 数字化锐利边缘、高饱和鲜艳色彩 |
| X3 | 过度美白至蜡像假人感（惨白须保留生命感） |
| X4 | 复杂场景背景（必须冷灰白背景） |
| X5 | 惊吓表情/恐怖妆效/鬼化特征（设定图须保持日常默认态） |
| X6 | 全身立像裁切头顶或脚底，必须从头到脚完整入画 |
| X7 | 人像特写裁切头顶，必须从头顶到锁骨完整入画 |
| X8 | 忽略身高和头身比约束 |
