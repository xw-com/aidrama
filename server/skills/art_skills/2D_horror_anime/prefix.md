## 二、全局色彩盘（风格基线，不是硬锁）

> 目标：统一审美而非限制创作。除「硬约束色」外，其余颜色默认优先使用，可在合理范围内偏移。

### 色彩使用层级

| 层级 | 约束强度 | 说明 |
|---|---|---|
| L1 硬约束 | 高 | 仅锁定角色识别核心：肤色、发色、主服底色的审美方向 |
| L2 软约束 | 中 | 场景色、道具色、阴影色优先参考色盘，可按镜头与剧情微调 |
| L3 例外机制 | 低 | 惊惧/异变/高潮场景可临时突破局部色彩，但需保留整体阴翳逻辑 |

### 硬约束色（默认锁定）

| 色项 | 对应色 | 规则 |
|---|---|---|
| 肤色基准 | C1 惨白 | 默认优先，允许冷调失血感微调 |
| 发色/瞳色基准 | C5 墨黑 / C4 灰蓝系 | 默认优先，允许深黑/暗褐轻微偏移 |

### 软约束色（推荐优先）

> C2/C3/C6/C7/C8/C9/C10 为推荐色域，用于服装、道具、背景、阴影、环境等。可根据镜头氛围做同色相邻近调整。

### 情绪色盘（导演对齐版）

| 情绪场景 | 主色 | 辅色 | 光效与对比建议 | 画面关键词 |
|---|---|---|---|---|

| 违和渐显 | C8 病黄 | C6 霉绿 + C5 墨黑 | 老灯昏黄，暗部吞噬 | 异样、察觉、不安 |
| 惊惧瞬间 | C3 暗红 | C5 墨黑 + C1 惨白 | 骤亮骤暗，强明暗差 | 心悸、屏息、定格 |
| 深夜独行 | C4 灰蓝 | C5 墨黑 + C7 冷白 | 月光冷调，大面积死黑 | 孤立、警觉、寒意 |
| 废墟探索 | C6 霉绿 | C9 锈棕 + C2 暗绿 | 散射天光，霉斑色主导 | 荒废、锈蚀、往事 |
| 诡异平静 | C1 惨白 | C7 冷白 + C10 深紫 | 无影平光，曝光过白 | 假平静、诡谲、倒错 |

### 情绪色盘使用规则

| 编号 | 规则 |
|---|---|
| E1 | 每条提示词至少指定 1 个「情绪场景」并绑定主色+辅色组合 |
| E2 | 单镜头主色不超过 2 个，避免颜色叙事失焦 |
| E3 | 情绪切换时优先调整明暗光比与阴影面积，再调整色温 |
| E4 | 恐怖向默认遵循「冷底 + 暗色吞噬」：冷色铺底，死黑用于阴影与负空间，惨白仅作骤亮对比 |
| E5 | 若与剧情冲突，以情绪色盘优先于通用推荐色，但不得突破严禁项 |

### 色温约束

| 参数 | 值 | 说明 |
|---|---|---|
| 整体色温 | 偏冷 6500-7200K（推荐） | 阴郁压抑主基调 |
| 肤色色温 | 冷调 6200-6800K（推荐） | 惨白但有生命感 |
| 对比度 | 高（建议保持） | 死黑与惨白强明暗层次 |
| 饱和度 | 低 20-40%（建议区间） | 高级惨淡恐怖色调 |

### 容差与例外

| 项目 | 建议容差 |
|---|---|
| 色相偏移 | ±10° |
| 饱和度偏移 | ±8% |
| 明度偏移 | ±8% |

> 例外场景：惊惧、异变、真相揭露镜头可使用局部暗红与骤亮惨白增强冲击；但禁止高饱和荧光色与滥用刺目红浆色，恐怖感靠阴影与构图而非血腥浓度。
