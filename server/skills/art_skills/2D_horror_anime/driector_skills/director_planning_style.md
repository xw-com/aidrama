# 恐怖动漫约束 · 日式恐怖动漫 · 技法参考

---

## 一、色调体系与画面基调

- **色调基底** — 全片以惨白（C1）、灰蓝（C4）、墨黑（C5）为基底色，整体色温偏冷（6500-7200K），饱和度低（20-40%），呈现日式恐怖动漫的阴郁压抑感。全片保持低饱和冷调基底，局部点缀病黄（C8）、暗红（C3）增加不安层次
- **暗色叙事对比** — 暗红（C3）与深紫（C10）作为异变与禁忌的视觉信号，仅用于违和渐显、真相揭露等关键节点局部点缀。暗色入侵应与怪谈揭示节奏同步，而非随意混用
- **色盘先行原则** — 段落规划需先绑定情绪场景（日常潜流/违和渐显/惊惧瞬间/逃出生天等），再确定主色+辅色与光影方案，避免"剧情对了但情绪不对色"
- **禁用色域** — 高饱和糖果色、荧光色、明亮暖甜治愈色彩体系均与本风格不兼容

---

## 二、光影方案体系

- **光影即恐怖** — 6 套光影方案对应不同恐怖段落，导演规划阶段应在段落层面确定光影基调方向，而非逐镜指定
- **光源角度** — 默认单一弱光源低位侧给或顶给，光锥之外全部沉入死黑；禁止均匀多向补光

| 情绪段落 | 光影方向 | 色调倾向 | 适用阶段 |
|---|---|---|---|
| 日常潜流 | A·惨白平光 | 冷白底 + 均匀无影 | 开场铺垫 |
| 违和渐显 | B·病黄点光 | 病黄灯泡 + 暗部吞噬 | 异样察觉段 |
| 深夜独行 | C·月光冷调 | 灰蓝主调 + 大面积死黑 | 深夜探索段 |
| 探索揭示 | D·手电/烛光 | 单点游移光 + 全黑包围 | 废墟/旧宅段 |
| 惊惧爆发 | E·骤亮骤暗 | 惨白闪 + 暗红沉底 | 惊惧高潮段 |
| 真相揭露 | F·暗红沉底 | 暗红主调 + 轮廓湮灭 | 禁忌揭示段 |

- **冷暖光分配** — 冷调惨白贯穿全片可用；病黄暖点光仅作孤立光源（路灯/灯泡/烛火）使用，形成"暖光更衬四周黑"的反差
- **氛围方向映射** — 每场戏的氛围方向应能映射到上述光影方案（A-F）的某一方向，确保视觉一致性

## 三、质感方向

- **阴翳纪实感** — 日式恐怖动画的核心：大面积阴翳、硬朗线条、块面阴影二分、低饱和惨色
- **清晰线稿 + 阴影吞噬** — 这是画面质感的锚点。不是模糊黑暗看不清，不是现代CG渲染；暗部仍有形状，亮部仍有细节
- **阴翳不等于黑图** — 本风格强调"阴影有形"的恐怖表达（负空间压迫、影子错位、光锥边界），通过藏与露的设计放大不安感，而非依赖全画面糊黑
- **手绘不等于粗糙** — 日式恐怖动漫强调手绘质感的影像表达（单一光源、诡异构图、克制造型），通过视角与留白设计放大心理恐怖，而非依赖直观惊吓

## 四、日式恐怖场景空间元素

日式恐怖动漫特有的场景元素及其视觉叙事功能：

- **走廊/门缝/楼梯间** — 天然的纵深引导道具，制造"尽头有什么"的期待与压迫，景即惧：走廊尽头微光 = 未知、门缝漏光 = 窥视、下行楼梯 = 坠入
- **旧公寓/废墟/废弃学校** — 怪谈的天然载体，景即事：积灰课桌 = 往事残留、废弃病床 = 禁忌、剥落墙皮 = 时间停滞
- **雾/雨幕/浮尘** — 留白与遮蔽构图的天然载体，景即恐：雾中轮廓 = 认知边界、雨夜孤灯 = 孤立、光锥浮尘 = 空间实在感
- **路灯/月光/烛光手电** — 恐怖动漫的光源载体，路灯 = 孤岛（方案B）、月光 = 冷寂（方案C）、手电烛光 = 脆弱安全区（方案D）
- **段落间用场景空镜过渡** — 本风格有丰富的场景资产（不同时段/天候/异变变体），段落衔接建议用空镜做情绪缓冲（如：走廊空镜→门缝特写→房间内），不要硬切
- **转折点用视觉而非台词** — 优先使用画面手段（骤亮骤暗、影子错位、构图失衡、空镜隐喻）而非依赖对白解释

## 五、日式恐怖乐器与环境音

日式恐怖动漫世界观下的声音元素约束：

### 乐器选择

- **走音八音盒/音乐盒** — 诡异平静/回忆扭曲段落的核心乐器，童谣质感倒错最制造不安
- **水琴（waterphone）** — 惊惧渐近段落的标志性音色，金属泛音的颤感自带寒意
- **预置钢琴/弱音钢琴** — 日常潜流/违和渐显段落，走音单音适合"不对劲"的氛围
- **弦乐不谐和弦/泛音** — 不安渐强/真相揭露段落，细密的高频揉弦压迫感最强
- **环境低频（drone）** — 全片底噪层，低频嗡鸣暗示"场"的存在，音量随危险 proximity 递增

### 乐器组合策略

| 情绪阶段 | 乐器组合 |
|---|---|
| 平稳/开场/收尾 | 走音八音盒独奏 或 环境低频铺底 |
| 日常潜流/铺垫 | 弱音钢琴 + 环境音 |
| 不安渐强/逼近 | 弦乐不谐和弦 + 低频渐强 |
| 惊惧爆发/揭示 | 骤静 → 水琴 + 弦乐重击 |

### 日式恐怖环境音

- **典型环境音层次** — 电流嗡鸣 / 水管滴水 / 木地板吱呀 / 远处犬吠 / 乌鸦啼叫 / 风穿走廊 / 时钟摆动 / 电视雪花声
- **每场戏标注 1-2 个核心环境音**，帮助后续音效设计。环境音层次越"日常"，异常音插入时越有惊惧反差
- **骤静比配乐更重要** — 关键恐怖瞬间（回头、开门、对视）优先考虑抽掉全部声音只留一个微小音（滴水/心跳/呼吸），"突然的安静"是最强的恐怖音效
- **避免满配** — 全片配乐覆盖率建议不超过 40%。留白段落的"无声"与配乐段落形成呼吸感，放大心理恐怖的克制美学
