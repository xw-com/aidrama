# 场景图生成 · 暗黑哥特写实约束手册

---

## 一、场景美学原则

1. **空间叙事** — 场景承载情绪与叙事功能，不是纯背景板；烛光位置与阴影吞噬范围本身就是叙事
2. **层次纵深** — 所有场景必须具备前/中/后景，杜绝扁平；廊柱、拱门、石碑形成天然纵深序列
3. **质感至上** — 风化石墙/深色木饰/天鹅绒/黄铜/彩窗玻璃等材质纹理必须超清晰
4. **实拍为锚** — 一切画面以真实低照度摄影为标准，拒绝 3D 渲染/CG 动画质感；追求镜头光学特征（浅景深虚化、镜头暗角、烛光光晕、色散微痕）与物理光照（烛焰摇曳、月光漫射、雾气体积光、焦散投影），呈现古典油画式明暗对照

## 五、主视图规范

### 视图定义

> 单画面主视图，从场景中最具代表性的角度拍摄，承载空间叙事与构图重心。

| 项目 | 约束 | 提示词 |
|---|---|---|
| 视角 | 自然观察视角，构图最能体现场景主体与纵深 | hero shot、representative angle |
| 视点高度 | 默认人眼平视高度，特殊场景可俯/仰 | eye level（默认） |
| 构图 | 主体居中或符合三分法，前/中/后景层次清晰 | balanced composition |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 单画面（非拼图、非多视图、非分屏） |
| 人物 | **严禁出现任何人物、人影、人体轮廓** |
| 一致性 | 风格/材质/色调/光线统一 |
| 光线 | 烛光或月光单一主导光源逻辑，光影方向一致，暗部保有层次 |
| 画面比例 | 默认 16:9（或按调用方设定） |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 场景必须有「前中后景层次」 |
| R2 | 室外必须包含「雾气空气透视」与「远景剪影溶形」 |
| R3 | 场景图必须为「单画面主视图」，不得拼接多视图/分屏/网格 |
| R4 | 构图须能代表场景主体并展示前/中/后景层次 |
| R5 | 场景图中**严禁出现任何人物** |
| R6 | 必须包含实拍摄影关键词（real photography / photorealistic / RAW photo） |
| R7 | 必须包含镜头光学特征（shallow depth of field / lens vignette / candlelight glow 至少一项） |
| R8 | 材质必须带有风化/龟裂/锈蚀/尘封等岁月痕迹，光源须单一主导逻辑，暗部保有可辨层次 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 背景纯白/纯黑/无场景 |
| X2 | 极端天候（雷暴电光密集/飓风，除非剧情需要） |
| X3 | 场景无纵深/无层次 |
| X4 | 植被繁盛翠绿/天候明亮明媚与衰败暗黑基调矛盾 |
| X5 | 出现任何人物、人影、人体剪影或人体轮廓 |
| X6 | 画面被拼接成多视图/网格/分屏布局 |
| X7 | 3D 渲染/CG 动画/卡通/游戏引擎质感（禁用 3D render、CGI、Unreal Engine、Unity 等词） |
| X8 | 材质过于干净完美、无任何风化与岁月感（避免"影楼布景感"）；现代建材/现代家具 |
| X9 | 光照过于均匀平坦、无景深虚化、无镜头光学特征；高饱和荧光/霓虹/糖果色 |
