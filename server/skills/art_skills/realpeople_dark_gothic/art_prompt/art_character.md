# 人物基础形象生成 · 暗黑哥特写实约束手册

---

## 一、基础形象原则

1. **面容即灵魂** — 五官是角色唯一锚点，毛孔级精细渲染，烛光只作暖染，不覆盖苍白肤底色与血色
2. **角色为本** — 基础着装由角色描述（身份/职业/性别/场景）决定其常规着装；丧服面纱、仪式正装与饰品为后续叠加层
3. **四视图一致** — 面容/体型/发型/基础服装跨视图高度统一
4. **实拍烛光摄影** — 以真实烛光人像摄影为锚点，保留皮肤真实质感（毛孔/微小瑕疵/苍白中的血色），拒绝舞台假光

---

## 二、面容约束

> 不再固定五官特征参数，由角色描述（性别/年龄/性格/气质）驱动 AI 自由生成五官，保证人物间外观差异化。

### 通用要求

| 项目 | 约束 |
|---|---|
| 五官 | 由角色描述自然推导，不预设脸型/眼型/眉型/鼻型/唇型 |
| 风格底色 | 真人写实摄影、明暗对照、毛孔级精细渲染、写实材质、烛光单源逻辑 |
| 气质 | 必须从角色描述提炼整体气质关键词（如阴郁/高贵/清冷/哀婉/诡秘），并写入提示词 |
| 表情 | 中性微表情，符合角色气质 |

## 五、基础发型约束

> 仅定义自然散发/古典束发，发饰与丧帽面纱在服化衍生环节叠加。

### 女性

| 项目 | 约束 | 提示词 |
|---|---|---|
| 发色 | 默认乌黑/深棕，角色设定明确时允许暗红挑染，禁浅金亮彩 | 乌黑长发、暗红挑染（按角色设定） |
| 发长 | 及腰长卷发或长直发，由角色设定 | 及腰长卷发、乌黑长发 |
| 发质 | 发丝清晰、烛光下高光呈暖金发丝光 | 发丝根根分明、暖金发丝光 |
| 造型 | 自然披卷/古典低髻/侧编发，基础态无发饰 | 古典长发、无发饰 |

### 男性

| 项目 | 约束 | 提示词 |
|---|---|---|
| 发色 | 默认乌黑/深棕，禁漂染亮色 | 乌黑短发、深棕发色 |
| 发长 | 短发后梳/中长微卷/及领长发，由角色设定 | 后梳短发、中长微卷 |
| 发质 | 发丝清晰、湿润或粉感真实 | 发丝根根分明 |
| 造型 | 严谨后梳/自然微卷/半束，基础态无发饰 | 古典发型、无发饰 |

### 妆容规则

- 女性默认素颜自然态；角色描述明确时允许苍白底妆 + 血红唇色（C3）+ 深色眼影，但须保留皮肤真实质感与毛孔
- 男性默认无妆；角色描述明确时允许苍白粉感或病态倦容

## 六、基础服装约束

> 基础服装由角色描述（身份/职业/性别/场景）决定其最自然的常规着装，作为该角色「日常默认态」；丧服面纱、仪式华服、斗篷在服化衍生环节叠加。**禁止内衣打底**。

### 着装选择原则

| 角色身份 | 默认着装方向 |
|---|---|
| 贵族小姐/庄园女主人 | 维多利亚深色长裙：高领蕾丝、束腰裙撑、天鹅绒披肩 |
| 贵族少爷/庄园主 | 维多利亚正装三件套：立领礼服外套、马甲、怀表链、深色领结 |
| 遗孀/服丧者 | 全黑丧服裙装、黑蕾丝手套、黑呢斗篷 |
| 神职人员/修女 | 黑色长袍、念珠、木质十字架 |
| 家庭教师/医师 | 深色高领长裙 / 三件套外套 + 怀表与皮箱 |
| 侍从/管家 | 深色制服、白手套、立扣马甲 |
| 角色描述未明确 | 深色维多利亚常服：骨白衬衫 + 墨黑长裙/礼服外套 |

### 着装统一规则

- 服装风格须与暗黑哥特写实摄影美学一致（维多利亚剪裁、天鹅绒/蕾丝/呢料/绸缎等写实材质）
- 颜色以墨黑/深棕/暗红/骨白为主，深红与古金只作点缀，无大面积亮色，便于后续衍生叠加
- 蕾丝领口与薄纱须有衬里，不透肤；十字架、怀表、戒指等饰品基础态默认不画
- 四视图服装款式完全一致
- 基础服装是「日常默认态」，焦点仍在面容与体态
- 严禁内衣/暴露/性化打底

## 八、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须为「自然状态」|
| R2 | 必须根据角色描述声明合适的常规着装作为基础服装（如贵族小姐→维多利亚深色长裙、庄园主→立领礼服三件套、遗孀→全黑丧服）；禁止内衣打底 |
| R3 | 必须声明「无发饰、无配饰」 |
| R4 | 必须指定「纯净石墨深灰背景」 |
| R5 | 必须指定「四视图一致性」 |
| R6 | 全身立像必须从头顶到脚底完整展示，严禁裁切 |
| R7 | 必须声明角色身高并通过头身比换算约束全身比例 |
| R8 | 人像特写必须从头顶到锁骨完整展示，严禁裁切头顶 |
| R9 | 皮肤必须保留真实质感，不可过度磨皮；苍白须保留血色，禁尸白/瓷偶化 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 内衣/暴露/性化打底；无衬里透视蕾丝；与角色描述明显不符的着装；过度复杂装饰干扰后续服化叠加 |
| X2 | 正顶硬光/正底光/彩色泛光 |
| X3 | 过度美白至尸白瓷偶质感/过度磨皮至无质感 |
| X4 | 复杂场景背景（必须纯深灰底） |
| X5 | 夸张表情/动态姿势 |
| X6 | 全身立像裁切头顶或脚底，必须从头到脚完整入画 |
| X7 | 人像特写裁切头顶，必须从头顶到锁骨完整入画 |
| X8 | 忽略身高和头身比约束；现代服饰/现代发型/亮彩染发 |
