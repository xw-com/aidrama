## 二、全局色彩盘（风格基线，不是硬锁）

> 目标：统一审美而非限制创作。除「硬约束色」外，其余颜色默认优先使用，可在合理范围内偏移。暗黑高反差与深红黑金是该风格核心，允许强烈的明暗分割，但暗部必须保有可辨层次。

### 色彩使用层级

| 层级 | 约束强度 | 说明 |
|---|---|---|
| L1 硬约束 | 高 | 仅锁定角色识别核心：肤色、发色、主服底色的审美方向 |
| L2 软约束 | 中 | 场景色、烛光色、配饰色优先参考色盘，可按镜头与剧情微调 |
| L3 例外机制 | 低 | 仪式/死亡/情感爆发戏可临时强化血红与烛金，但需保留暗部层次 |

### 硬约束色（默认锁定）

| 色项 | 对应色 | 规则 |
|---|---|---|
| 肤色基准 | C2 象牙白肤 | 默认苍白偏冷但保留血色与毛孔，禁尸白/瓷偶化，允许烛光暖染 |
| 发色/瞳色基准 | C9 乌木棕黑 | 默认乌黑/深棕，角色设定明确时允许暗红挑染，禁浅金亮彩 |

### 软约束色（推荐优先）

> C3/C4/C5/C6/C7/C8/C10 为推荐色域，用于烛光、鎏金饰品、蕾丝衬衫、雾气、月光、铁石构件等。可根据镜头氛围做同色相邻近调整。

### 情绪色盘使用规则

| 编号 | 规则 |
|---|---|
| E1 | 每条提示词至少指定 1 个「情绪场景」并绑定主色+辅色组合 |
| E2 | 单镜头暖光源不超过一个主导色相（烛琥珀或冷月蓝二选一为主），避免颜色叙事失焦 |
| E3 | 情绪切换时优先调整光比与光源（烛光↔月光），再调整饱和度 |
| E4 | 哥特向默认遵循「暗底 + 烛光点」：大面积暗部托底，暖光只落在面部、手部与关系焦点，血红只作一点 |
| E5 | 若与剧情冲突，以情绪色盘优先于通用推荐色，但不得突破严禁项 |

### 色温约束

| 参数 | 值 | 说明 |
|---|---|---|
| 整体色温 | 烛光暖 2600-3400K 与月光冷 4500-5000K 双源对照（推荐） | 古典明暗对照主基调 |
| 肤色色温 | 微暖 3200-3600K（推荐） | 烛光下苍白肤仍保留血色与生命感 |
| 对比度 | 极强（建议保持） | 明暗对照法（Chiaroscuro），暗部厚重有层次 |
| 饱和度 | 低 25-45%（建议区间） | 血红/古金点缀可局部更高，整体克制 |

### 容差与例外

| 项目 | 建议容差 |
|---|---|
| 色相偏移 | ±8° |
| 饱和度偏移 | ±10% |
| 明度偏移 | ±12% |

> 例外场景：仪式高潮、血色瞬间、情感爆发镜头可强化血红与烛金的局部饱和；但禁止荧光、糖果色、明亮粉彩，暗部必须保有可辨层次。

## 三、全局约束规则

### 必守规则（所有技能继承）

| 编号 | 规则 |
|---|---|
| R1 | 必须包含「真人写实摄影」风格锚定词 |
| R2 | 必须声明「古典油画式明暗（明暗对照）+ 极致细节」 |
| R3 | 面部必须使用「面容细腻渲染 + 皮肤细腻」，苍白有血色、禁尸白瓷偶化 |
| R4 | 发丝必须使用「根根分明 + 发丝细腻渲染」，烛光下高光呈暖金发丝光 |
| R5 | 纹理必须声明「纹理细节超清晰」，并至少含一项风格质感词（烛光晕染/雾气弥漫/天鹅绒织纹/石墙风化） |

### 严禁项（所有技能继承）

| 编号 | 严禁内容 |
|---|---|
| X1 | 严禁「卡通/动漫/二次元/插画风」 |
| X2 | 严禁「高饱和荧光色/霓虹色/糖果粉彩色」 |
| X3 | 严禁「哥特元素缺失」（必须有烛光/古堡/维多利亚服饰等明确哥特符号） |
| X4 | 严禁「面部变形/多指/肢体异常」倾向词 |
| X5 | 严禁「裸体/暴露/透视/暗示性描述」（蕾丝须有衬里不透） |
| X6 | 严禁「现代科技元素/未来科幻元素」（手机/汽车/LED屏/霓虹灯/义体等） |
