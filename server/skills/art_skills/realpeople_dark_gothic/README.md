# 暗黑哥特写实风格说明

本风格专为"暗黑哥特写实"题材打造，所有美术提示词、规范和生成内容均严格限定于：

- **哥特世界观**：以维多利亚时代暗黑哥特为背景，涵盖古堡厅堂、烛光教堂、雾气墓园、闺房书房等，杜绝哥特元素缺失与现代科技元素。
- **真人写实**：所有角色、场景、道具均以真人写实摄影为标准，强调五官、皮肤、发丝、材质等极致细节与真实质感。
- **古典油画式纪实**：在写实基础上追求古典明暗对照（Chiaroscuro）的油画光影，烛光与月光双源对照，暗部厚重、高光克制、深红黑金暗色调。
- **暗黑浪漫氛围**：适合展现压抑、渴望、宿命、爱欲与死亡的哥特故事，强调暗夜烛光下的情感表达。

## 适用范围

- 暗黑哥特真人题材的AI美术生成（角色、场景、道具、分镜等）
- 需要极致写实、烛光暗调、古典油画式明暗的视觉创作

## 严禁内容

- 卡通、动漫、插画、二次元风格
- 现代科技元素（手机/汽车/LED屏等）、未来科幻元素
- 高饱和荧光色、霓虹色、明亮粉彩糖果色
- 暗示性、暴露、透视等不适宜内容

## 风格体验

在本风格下，您将体验到：

- 角色面容苍白精致、气质阴郁或高贵，服饰、妆容、发型均为维多利亚哥特写实，可含蕾丝与十字架饰品
- 场景空间层次丰富，烛光教堂、雾气墓园、古堡石墙材质纹理超清晰，明暗对照强烈
- 道具、银器、烛台、古书、棺钉等均为古典工艺造型，做旧精细，质感极致
- 分镜与视频均以真人写实烛光夜景为基础，强调叙事与情感表达

---

本风格仅适用于"暗黑哥特写实"相关项目。如需其他风格（如都市现代、赛博朋克、插画、动漫等），请勿使用本套提示词。
