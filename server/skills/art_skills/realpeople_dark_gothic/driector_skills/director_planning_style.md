# 暗黑哥特风格约束 · 暗黑哥特写实 · 技法参考

---

## 一、色调体系与画面基调

- **色调基底** — 全片以墨黑（C1）、石墨深灰（C10）、乌木棕黑（C9）为基底色，整体呈烛光暖（2600-3400K）与月光冷（4500-5000K）双源对照，饱和度低（25-45%，血红/古金点缀局部更高），呈现深红黑金的暗黑浪漫基调
- **冷暖叙事对比** — 烛光琥珀（C4）、古金（C5）与血红（C3）作为爱欲、生命与危险的视觉信号，冷月蓝（C8）、雾紫灰（C7）用于死亡、宿命、疏离等段落。烛光与月光的切换应与情绪弧线同步
- **冷暖分配策略** — 压抑/丧仪/夜探段落以冷月雾灰为主，亲密/回忆/反抗段落释放烛光暖金；避免全程死黑导致情绪层次塌陷，暗部必须保有可辨层次
- **色盘先行原则** — 段落规划先绑定情绪场景（暗厅初遇/暧昧试探/仪式静默/悲恸丧失/亲密沉沦等），再确定主色+辅色与光影方案，避免"剧情对了但情绪不对色"
- **禁用色域** — 高饱和荧光色、霓虹色、明亮粉彩糖果色与本风格不兼容

## 二、光影方案体系

- **光影即叙事** — 6 套光影方案对应不同情绪段落，导演规划阶段应在段落层面确定光影基调方向，而非逐镜指定
- **光源角度** — 正给镜头默认 30° 斜射烛光（较柔和），侧给镜头根据场景与人物关系微调；光源须单一主导逻辑，烛阵只作纵深点缀

| 光影方案 | 方案名 | 色调倾向 | 适用情绪 |
|---|---|---|---|
| A | 烛光点光源 | 烛光琥珀 + 大暗部包裹 | 私密对话、暗厅初遇 |
| B | 壁炉暖辉 | 烛光琥珀主导 + 骨白反光 | 家庭聚集、回忆讲述 |
| C | 彩窗昼光 | 冷灰天光 + 血红/古金色斑 | 日常仪式、压抑忏悔 |
| D | 月光漫射 | 冷月蓝主导 + 雾紫灰 | 墓园哀思、夜半游荡 |
| E | 电光劈照 | 冷白瞬闪 + 墨黑对切 | 惊惧揭秘、诅咒爆发 |
| F | 单烛硬光 | 烛金一点 + 四周墨黑 | 地窖探秘、疯狂独白 |

- **冷暖光分配** — 烛光可全片使用但需分层控制；死亡/告别段落降低暖光占比，让冷月接管，避免情绪与光色冲突
- **氛围方向映射** — 每场戏氛围方向应映射到上述光影方案（A-F）的某一方向，确保视觉一致性

## 三、质感方向

- **超清纪实感** — 真人写实摄影核心：皮肤纹理可见、发丝根根分明、烛光暖染与苍白血色可信
- **明暗对照 + 极致细节** — 作为画面质感锚点。不是均质灰暗，也不是纯黑糊死，而是古典油画式的"亮部有形、暗部有层"的 Chiaroscuro
- **材质真实** — 服化道需具备时代可信度：天鹅绒吸光、蕾丝镂空、风化石墙、黄铜做旧、旧玻气泡都应符合低照度实拍逻辑
- **皮肤质感** — 保留真实毛孔与细微瑕疵，苍白须有血色与暖染层次，控制磨皮强度，追求"苍白但活着"
- **写实不等于平淡** — 通过明暗分割构图、剪影、倒影与镜像放大情绪感染力，而非依赖恐怖特效与廉价惊吓

## 四、哥特场景空间元素

暗黑哥特世界观特有的场景元素及其视觉叙事功能：

- **烛台/彩窗/拱门/廊柱** — 天然的明暗切割与框架式构图道具；彩窗色斑可直接暗示罪与赎，拱门纵列制造宿命长廊感
- **古堡旋梯/长廊/地窖/墓园小径** — 宿命与秘密的载体：旋梯用于阶层与欲望缠绕，地窖用于真相封存，墓园用于告别与诅咒
- **镜子/肖像画/梳妆台** — 自我与家族的凝视装置：镜中倒影用于自我审视与分裂暗示，祖先肖像用于家族凝视与血脉压迫
- **雾气、烛焰与钟声作为转场** — 烛焰熄灭入黑、雾气漫过画面、月隐云出、远处丧钟余响可用于段落情绪缓冲，避免硬切
- **转折点用视觉而非解释** — 优先使用画面手段（烛火骤灭、镜面裂缝、画像眼睛的阴影、十字架倒影）承接情绪转折，减少对白解释负担

## 五、哥特乐器与环境音

暗黑哥特世界观下的声音元素约束：

### 乐器选择

- **管风琴** — 仪式、教堂、宿命段落核心乐器，低频轰鸣最能撑起古堡与教堂的空间敬畏
- **暗黑室内乐（弦乐四重奏）** — 压抑、哀恸、暗流涌动段落的主力铺底
- **圣咏/人声吟唱** — 仪式肃穆与超自然暗示段落的无词人声底色
- **大提琴独奏** — 悲恸、告别、孤独独白段落的主导声部
- **羽管键琴/古钢琴** — 时代质感锚点，用于回忆闪回与庄园日常段落
- **环境音优先级高** — 哥特剧中烛焰、风声、钟声等环境声是沉浸感关键，配乐不应压过对白

### 乐器组合策略

| 情绪阶段 | 乐器组合 |
|---|---|
| 平稳/开场/收尾 | 羽管键琴独奏 或 大提琴独奏 |
| 日常推进 | 暗黑室内乐 + 羽管键琴 |
| 暧昧升温/爱欲 | 大提琴 + 弦乐渐入 |
| 仪式/惊惧/爆发 | 管风琴主导 + 圣咏人声 |
| 哀悼/告别/收束 | 大提琴 + 弦乐四重奏 |

### 哥特环境音

- **典型环境音层次** — 烛芯噼啪 / 风穿彩窗呜咽 / 乌鸦啼叫 / 管风琴残响 / 钟楼远钟 / 木地板与旋梯吱呀 / 雨打石板 / 壁炉柴爆 / 地窖滴水
- **每场戏标注 1-2 个核心环境音**，帮助后续音效设计。环境音层次越准确，哥特古堡质感越强
- **留白建议** — 揭秘与死亡时刻可抽掉全部配乐，只留烛芯噼啪与呼吸声，让"寂静本身"成为恐惧与悲怆的放大器
