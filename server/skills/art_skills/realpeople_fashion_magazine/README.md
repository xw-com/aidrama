# 时尚杂志风格说明

本风格专为"时尚杂志"题材打造，所有美术提示词、规范和生成内容均严格限定于：

- **杂志专题世界观**：以时尚杂志内页专题（editorial story 叙事组图）为标杆，涵盖都市外景、精品酒店、美术馆、咖啡馆、买手店等专题取景地，杜绝棚拍硬大片感与日常随拍感。
- **真人写实**：所有角色、场景、道具均以真人写实摄影为标准，强调五官、皮肤、发丝、成衣面料等极致细节与真实质感，肤色追求印刷级通透。
- **自然光叙事**：自然漫射光、窗光、反光板补光构成画面骨架，光影通透柔和，画面如杂志专题页般具有故事感与排版留白。
- **都市精英氛围**：适合展现都市精英的职场、社交、情感与蜕变叙事，强调造型专题换装与人物在场景中的故事感。

## 适用范围

- 时尚杂志题材的AI美术生成（角色、场景、道具、分镜等）
- 需要杂志专题故事感、印刷级通透质感、都市外景叙事的视觉创作

## 严禁内容

- 卡通、动漫、插画、二次元风格
- 影棚硬光大片感、旅游照感、手机随手拍质感
- 高饱和荧光色、霓虹色
- 暗示性、暴露、透视等不适宜内容

## 风格体验

在本风格下，您将体验到：

- 角色面容通透、气质知性或锋利，妆发造型为杂志专题级换装水准
- 场景以都市外景与精致室内为主，自然光通透，构图具有排版留白感
- 道具以箱包、鞋履、眼镜刊物、香氛配饰为核心，工艺细节精致
- 分镜与视频均以真人写实为基础，强调专题组图叙事与情感表达

---

本风格仅适用于"时尚杂志"相关项目。如需其他风格（如古风、插画、动漫、影棚大片等），请勿使用本套提示词。
