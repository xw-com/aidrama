## 二、全局色彩盘（风格基线，不是硬锁）

> 目标：统一审美而非限制创作。除「硬约束色」外，其余颜色默认优先使用，可在合理范围内偏移。

### 色彩使用层级

| 层级 | 约束强度 | 说明 |
|---|---|---|
| L1 硬约束 | 高 | 仅锁定角色识别核心：肤色、发色、主服底色的审美方向 |
| L2 软约束 | 中 | 场景色、配饰色、点缀色优先参考色盘，可按镜头与剧情微调 |
| L3 例外机制 | 低 | 专题高潮/封面定格/回忆插叙可临时突破局部色彩，但需保留整体通透逻辑 |

| 序号 | 色名 | 色值 | 用途 |
|---|---|---|---|
| C1 | 晨雾白 | #F4F2ED | 杂志留白、墙面、浅色造型 |
| C2 | 通透肤 | #F0E0D0 | 女性/男性肤色基准 |
| C3 | 裸粉 | #E7C9B8 | 唇色、腮红、柔和点缀 |
| C4 | 深栗发 | #4A3327 | 发色、眼瞳 |
| C5 | 雾霾蓝 | #A8B8C2 | 外景天空、衬衫、玻璃反射 |
| C6 | 橄榄绿 | #8A8B6E | 植被、军旅风造型、皮质点缀 |
| C7 | 暖沙 | #D6C3A3 | 外景石墙、风衣、针织 |
| C8 | 酒红 | #7C3A44 | 深色造型、丝绒、晚装点缀 |

### 硬约束色（默认锁定）

| 色项 | 对应色 | 规则 |
|---|---|---|
| 肤色基准 | C2 通透肤 | 默认优先，允许小幅明度/暖度微调，须保持印刷级通透 |
| 发色/瞳色基准 | C4 深栗发 | 默认优先，允许深栗/深褐/造型挑染轻微偏移（需角色描述支持） |

### 软约束色（推荐优先）

> C1/C3/C5/C6/C7/C8/C9/C10 为推荐色域，用于杂志留白、成衣造型、外景天空、植被、石墙、皮具等。可根据专题主题做同色相邻近调整。

### 情绪色盘（导演对齐版）

| 情绪场景 | 主色 | 辅色 | 光效与对比建议 | 画面关键词 |
|---|---|---|---|---|
| 初遇街拍（日常） | C7 暖沙 | C5 雾霾蓝 + C1 晨雾白 | 晨光漫射，肤色通透，背景低饱和 | 偶遇、轻盈、都市晨光 |
| 怦然心动（升温） | C3 裸粉 | C7 暖沙 + C2 通透肤 | 窗光侧逆提亮，肤温微升 | 柔和、靠近、心动 |
| 职场锋芒（对峙） | C10 石墨黑 | C9 浅灰 + C5 雾霾蓝 | 阴天漫射冷光，明暗克制但有切面 | 专业、锋利、距离 |
| 换装蜕变（转折） | C8 酒红 | C1 晨雾白 + C10 石墨黑 | 由灰调渐入暖调，轮廓光收束 | 蜕变、自信、专题感 |
| 社交派对（高光） | C8 酒红 | C6 橄榄绿 + C3 裸粉 | 暖点光源 + 深色背景，允许局部提饱和 | 精英、觥筹、都市夜 |
| 独处省思（低谷） | C5 雾霾蓝 | C9 浅灰 + C1 晨雾白 | 灰调漫射，留白增大，人物缩小入景 | 疏离、留白、沉思 |
| 回忆插叙（柔和化） | C7 暖沙 | C3 裸粉 + C6 橄榄绿 | 低饱和暖化，微雾感但不朦胧滤镜 | 旧忆、温柔、真实 |
| 封面定格（收尾） | C1 晨雾白 | C2 通透肤 + C10 石墨黑 | 均匀通透主光 + 大面积留白 | 定格、刊首、故事收束 |

### 情绪色盘使用规则

| 编号 | 规则 |
|---|---|
| E1 | 每条提示词至少指定 1 个「情绪场景」并绑定主色+辅色组合 |
| E2 | 单镜头主色不超过 2 个，避免颜色叙事失焦 |
| E3 | 情绪切换时优先调整光源方向与色温，再调整饱和度 |
| E4 | 杂志向默认遵循「通透底 + 故事点」：低饱和通透铺底，情绪焦点落在人物关系与造型细节 |
| E5 | 若与剧情冲突，以情绪色盘优先于通用推荐色，但不得突破严禁项 |

### 色温约束

| 参数 | 值 | 说明 |
|---|---|---|
| 整体色温 | 中性偏暖 5300-5800K（推荐） | 印刷级通透主基调 |
| 肤色色温 | 微暖 5200-5600K（推荐） | 通透但有血色与生命感 |
| 对比度 | 中强（建议保持） | 明暗有层次但不压黑 |
| 饱和度 | 中低 35-55%（建议区间） | 杂志印刷高级色调 |

### 容差与例外

| 项目 | 建议容差 |
|---|---|
| 色相偏移 | ±8° |
| 饱和度偏移 | ±10% |
| 明度偏移 | ±12% |

> 例外场景：派对、封面定格、情绪高潮镜头可使用酒红或暖沙局部色块；但禁止霓虹荧光色与影棚硬光大片感入镜。

## 三、全局约束规则

### 必守规则（所有技能继承）

| 编号 | 规则 |
|---|---|
| R1 | 必须包含「真人写实摄影」风格锚定词 |
| R2 | 必须声明「自然漫射光 + 印刷级通透质感」 |
| R3 | 面部必须使用「面容细腻渲染 + 皮肤通透」 |
| R4 | 发丝必须使用「根根分明 + 发丝细腻渲染」 |
| R5 | 纹理必须声明「成衣面料纹理超清晰」 |

### 严禁项（所有技能继承）

| 编号 | 严禁内容 |
|---|---|
| X1 | 严禁「卡通/动漫/二次元/插画风」 |
| X2 | 严禁「高饱和荧光色/霓虹色」 |
| X3 | 严禁「都市专题取景缺失」（必须明确杂志专题场景语言） |
| X4 | 严禁「面部变形/多指/肢体异常」倾向词 |
| X5 | 严禁「裸体/暴露/透视/暗示性描述」 |
| X6 | 严禁「古风/古装/汉服/影棚硬光大片感」 |
