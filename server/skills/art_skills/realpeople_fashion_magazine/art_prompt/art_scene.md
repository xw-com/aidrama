# 场景图生成 · 时尚杂志约束手册

---

## 一、场景美学原则

1. **取景即叙事** - 场景是专题故事的取景地，美术馆、酒店、街角皆承载人物故事，不是纯背景板
2. **层次纵深** - 所有场景必须具备前/中/后景，构图须为人物与文字排版预留呼吸位
3. **质感至上** - 大理石/水磨石/黄铜/玻璃/织物/石材等材质纹理必须超清晰
4. **实拍为锚** - 一切画面以真实摄影为标准，拒绝 3D 渲染/CG 动画质感；追求镜头光学特征（自然景深、空气透视、微色散）与自然光摄影逻辑（窗光漫射、反光板补光、黄金时段外景）

## 三、室内场景

### 空间规范

| 维度 | 约束 | 提示词 |
|---|---|---|
| 风格 | 美术馆/精品酒店/咖啡馆/买手店/ Loft 公寓，现代雅致/复古学院/极简主义 | {风格}空间，magazine editorial location |

## 五、主视图规范

### 视图定义

> 单画面主视图，从取景地最具代表性的机位拍摄，承载专题故事的空间语境与排版留白。

| 项目 | 约束 | 提示词 |
|---|---|---|
| 视角 | 专题主视觉机位，构图最能体现取景地气质与空间纵深 | hero shot、editorial location wide shot |
| 视点高度 | 默认人眼平视高度，街拍场景可微仰/微俯 | eye level（默认） |
| 构图 | 主体居中或符合三分法，须预留排版呼吸位，前/中/后景层次清晰 | balanced composition、negative space |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 单画面（非拼图、非多视图、非分屏） |
| 人物 | **严禁出现任何人物、人影、人体轮廓** |
| 一致性 | 风格/材质/色调/光线统一 |
| 光线 | 单一光源逻辑，光影方向一致，通透不压黑 |
| 画面比例 | 默认 16:9（或按调用方设定） |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 场景必须有「前中后景层次」 |
| R2 | 室外必须包含「空气透视」 |
| R3 | 场景图必须为「单画面主视图」，不得拼接多视图/分屏/网格 |
| R4 | 构图须能代表取景地气质并展示前/中/后景层次，预留排版呼吸位 |
| R5 | 场景图中**严禁出现任何人物** |
| R6 | 必须包含实拍摄影关键词（real photography / photorealistic / RAW photo） |
| R7 | 必须包含镜头光学特征（natural depth of field / soft vignette / bokeh 至少一项）与自然光关键词（窗光漫射/黄金时段光线 至少一项） |
| R8 | 材质必须带有岁月磨痕/使用痕迹，禁止全新无瑕的"CG 感" |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 背景纯白/纯黑/无场景 |
| X2 | 极端天候（暴风雨/雷电/暴雪，除非剧情需要） |
| X3 | 场景无纵深/无层次 |
| X4 | 植被/天候与季节矛盾 |
| X5 | 出现任何人物、人影、人体剪影或人体轮廓 |
| X6 | 画面被拼接成多视图/网格/分屏布局 |
| X7 | 3D 渲染/CG 动画/卡通/游戏引擎质感（禁用 3D render、CGI、Unreal Engine、Unity 等词） |
| X8 | 材质过于干净完美、无任何使用痕迹与岁月感（避免"塑料感"） |
| X9 | 光照过于均匀平坦、影棚硬光大片感、无景深虚化与自然光逻辑 |
