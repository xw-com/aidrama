# 人物基础形象生成 · 时尚杂志约束手册

---

## 一、基础形象原则

1. **通透即灵魂** - 印刷级通透肤色与自然神态是角色唯一锚点，毛孔级精细渲染
2. **角色为本** - 基础着装由角色描述（身份/职业/性别/造型专题）决定其常规造型；后续换装专题为叠加层
3. **四视图一致** - 面容/体型/发型/基础服装跨视图高度统一
4. **杂志实拍** - 以真实杂志专题摄影为锚点，保留皮肤真实质感（毛孔/微小瑕疵），姿态自然、神态有故事感

---

## 二、面容约束

> 不再固定五官特征参数，由角色描述（性别/年龄/性格/气质）驱动 AI 自由生成五官，保证人物间外观差异化。

### 通用要求

| 项目 | 约束 |
|---|---|
| 五官 | 由角色描述自然推导，不预设脸型/眼型/眉型/鼻型/唇型，整体须呈杂志专题审美（耐看、有辨识度、上相） |
| 风格底色 | 真人写实摄影、自然漫射光、面容细腻渲染、毛孔级精细渲染、印刷级通透质感 |
| 气质 | 必须从角色描述提炼整体气质关键词（如知性/干练/文艺/松弛），并写入提示词 |
| 表情 | 中性微表情 + 自然神态，符合角色气质与专题故事感 |

## 六、基础服装约束

> 基础服装由角色描述（身份/职业/性别/造型专题）决定其最自然的常规造型，作为该角色「杂志默认态」；专题换装在服化衍生环节叠加。**禁止内衣打底**，时尚风格必须强调成衣质感与造型专题感。

### 着装选择原则

| 角色身份 | 默认着装方向 |
|---|---|
| 杂志主编/时装编辑 | 时装编辑造型（利落外套+阔腿裤/半裙） |
| 都市白领/精英 | 通勤高级成衣（西装外套/衬衫+直筒裤） |
| 模特/艺人 | 专题换装造型（风衣/针织裙/设计感成衣） |
| 文艺/创作者 | 松弛文艺造型（针织+伞裙/亚麻套装） |
| 社交名流 | 精致社交装（小礼服/丝质套装） |
| 角色描述未明确 | 中性低饱和成衣（风衣/衬衫/针织），杂志质感 |

### 着装统一规则

- 服装风格须与杂志专题摄影美学一致（低饱和高级色、成衣剪裁、面料自然垂感）
- 强调成衣质感：面料垂感、细节剪裁、层次搭配清晰可辨
- 颜色低饱和高级色，无复杂花纹/装饰，便于后续换装专题叠加
- 四视图服装款式完全一致
- 基础服装是「杂志默认态」，焦点仍在面容与神态
- 严禁内衣/暴露/性化打底

## 八、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须为「杂志默认态」造型，禁止内衣打底 |
| R2 | 必须根据角色描述声明合适的成衣造型作为基础服装（如编辑->时装编辑造型、白领->通勤高级成衣、创作者->松弛文艺造型）；必须强调成衣质感 |
| R3 | 必须声明「无发饰、无配饰」 |
| R4 | 必须指定「纯净浅灰背景」 |
| R5 | 必须指定「四视图一致性」 |
| R6 | 全身立像必须从头顶到脚底完整展示，严禁裁切 |
| R7 | 必须声明角色身高并通过头身比换算约束全身比例，体型须符合杂志模特规范 |
| R8 | 人像特写必须从头顶到锁骨完整展示，严禁裁切头顶 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 内衣/暴露/性化打底；与角色描述明显不符的着装；复杂花纹/装饰干扰后续换装叠加 |
| X2 | 正顶硬光/正底光/彩色光；影棚硬光大片感 |
| X3 | 过度美白/过度磨皮至无质感；浓重网红妆感 |
| X4 | 复杂场景背景（必须纯浅灰底） |
| X5 | 夸张表情/动态姿势（四视图须为自然站姿） |
| X6 | 全身立像裁切头顶或脚底，必须从头到脚完整入画 |
| X7 | 人像特写裁切头顶，必须从头顶到锁骨完整入画 |
| X8 | 忽略身高、头身比与杂志模特身形约束 |
