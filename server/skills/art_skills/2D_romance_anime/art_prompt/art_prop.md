# 恋爱动漫风格 - 道具图像生成 · 约束手册

---

## 一、道具设计原则

1. **心意可读** — 道具须承载恋爱心意（赠礼/信物/约定），造型服务于情感表达
2. **质感极致** — 材质纹理必须清晰可辨（巧克力/缎带/纸品/金属/亚克力）
3. **现代为锚** — 所有道具符合现代恋爱世界观（校园/都市/祭典），风格统一
4. **尺度明确** — 通过参照物或标注暗示道具真实尺寸
5. **纯道具独立展示** — 画面中只能出现道具本身，严禁出现任何人物、手部、肢体，道具不可处于被持有/佩戴/握持状态，必须以静物陈列方式独立呈现

## 三、多角度设定图规范

### 视图定义

| 位置 | 视图 | 角度 | 要求 | 提示词 |
|---|---|---|---|---|
| 左上 | 正面图 | 正面 0° | 道具完整正面形态 | front view |
| 右上 | 侧面图 | 侧面 90° | 厚度/轮廓/结构清晰 | side view |
| 左下 | 背面图 | 背面 180° | 道具背部结构/装饰 | back view |
| 右下 | 细节特写 | 局部放大 | 材质纹理/工艺细节 | detail closeup |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 同一画面四宫格（2×2），上下左右四视角 |
| 背景 | 淡粉米白 #FBF2F0 |
| 光线 | 明亮柔光，均匀柔光，无硬阴影 |
| 比例 | 每格道具占格内主体 70%+ |
| 投影 | 允许自然地面微投影 |
| 画面比例 | 建议 1:1 |

## 六、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须指定「淡粉米白背景 #FBF2F0」 |
| R2 | 必须明确道具材质与工艺 |
| R3 | 道具造型必须符合现代恋爱世界观风格 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 复杂场景背景 |
| X2 | 道具与人物同画面 |
| X3 | 出现任何人物形象 |
| X4 | 道具处于被持有、握持、佩戴、使用中的状态 |
| X5 | 出现暗示人物存在的元素 |
