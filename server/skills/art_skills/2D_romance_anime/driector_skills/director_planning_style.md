# 恋爱动漫约束 · 现代恋爱动画 · 技法参考

---

## 一、色调体系与画面基调

- **色调基底** — 全片以奶油白（C1）、心动粉（C2）、青空蓝（C3）为基底色，整体色温偏暖微甜（5200-5600K），饱和度中高（60-80%），呈现现代恋爱动画的清透明亮感。全片保持粉蓝奶油基底，局部以晚霞紫（C6）与窗光金（C5）增加浪漫层次
- **心动演出色调** — 心动演出时以 C2 心动粉与 C5 窗光金爆发式提亮（背景炸白、光晕扩散），与日常段落的清爽低调形成情绪反差
- **色盘先行原则** — 段落规划需先绑定情绪场景（日常/心动/告白/误会等），再确定主色+辅色与心动演出方案，避免"情绪对但色不对"
- **禁用色域** — 高饱和荧光色、霓虹色、暗黑重口色、复古网点纸色均与本风格不兼容

---

## 二、光影方案体系

- **光影即心动** — 6 套光影方案对应不同恋爱段落，导演规划阶段应在段落层面确定光影基调方向，而非逐镜指定
- **光源角度** — 默认 30-45°斜侧光 + 柔和漫射，模拟自然光效果；心动演出时可用逆光轮廓光强化

| 情绪段落 | 光影方向 | 色调倾向 | 适用阶段 |
|---|---|---|---|
| 日常清爽 | A·均匀漫射 | 青空蓝底 + 均匀柔光 | 全片 |
| 怦然心动 | B·逆光柔焦 | 心动粉 + 窗光金轮廓光 | 心动段 |
| 暧昧靠近 | C·浅景深侧光 | 奶油白 + 窗光金微暖 | 暧昧段 |
| 告白高光 | D·背景炸白 | 窗光金主爆 + 心动粉散点 | 告白段 |
| 误会低落 | E·降饱和侧光 | 制服藏蓝底 + 色温偏冷 | 误会/别扭段 |
| 黄昏浪漫 | F·逆光暖调 | 晚霞紫 + 窗光金 + 心动粉 | 约会/祭典段 |

- **冷暖光分配** — 清爽暖调（A/B/C/D/F）贯穿全片，冷调（E 误会段）仅在情绪低落段落短暂使用
- **氛围方向映射** — 每场戏的氛围方向应能映射到上述光影方案（A-F）的某一方向，确保视觉一致性

---

## 三、质感方向

- **干净赛璐璐感** — 现代恋爱动画的核心：色块清晰、线条流畅、双层阴影与细腻高光
- **清秀线条 + 明快上色** — 画面质感的锚点。不是模糊晕染，不是复古网点，不是厚重厚涂
- **心动演出即特效** — 飘花、光晕、背景炸白、逆光轮廓、升格慢动作是本风格独有的视觉语言，而非依赖复杂CG特效
- **透明感与空气感** — 恋爱动画追求画面的通透与轻盈，而非写实厚重或暗黑纵深

---

## 四、场景空间元素

现代恋爱动画特有的场景元素及其视觉叙事功能：

- **教室/天台/走廊** — 青春恋爱的核心舞台，景即情：教室窗边逆光 = 心动、天台围栏黄昏 = 告白、走廊转角偶遇 = 暧昧
- **樱花道/祭典/烟花** — 心动演出的天然载体，景即情：樱花飘落 = 怦然、祭典灯火 = 甜蜜、烟花升空 = 告白高光
- **甜品店/车站/河堤** — 约会与等待的场景，景即情：甜品店对坐 = 甜蜜、车站月台挥手 = 离别、河堤并肩 = 释然
- **雨中/伞下/雪夜** — 恋爱经典意象，景即情：共撑一伞 = 靠近、雨中追赶 = 急切、初雪约定 = 承诺
- **段落间用场景空镜过渡** — 本风格有丰富的场景资产（不同时段/天气/季节变体），段落衔接建议用场景空镜做情绪缓冲（如放学路渐暗→车站灯亮），不要硬切
- **转折点用视觉而非台词** — 优先使用画面手段（心动演出爆发/光影突变/景别跳切）而非依赖对白解释

## 五、乐器与环境音

现代恋爱动画世界观下的声音元素约束：

### 乐器选择

- **钢琴** — 日常/心动/回忆段落的核心乐器，最能表现恋爱动画的甜蜜与感伤
- **原声吉他** — 轻松/阳光/户外段落，清亮拨弦适合青春氛围
- **弦乐铺底** — 告白/离别/情感升华段落，拉弦的细腻感适合情绪过渡
- **钟琴/风铃** — 心动演出/梦幻时刻，清脆音色适合怦然瞬间

### 乐器组合策略

| 情绪阶段 | 乐器组合 |
|---|---|
| 日常清爽 | 钢琴 + 轻吉他 |
| 怦然心动 | 钟琴 + 弦乐轻铺 |
| 告白高光 | 弦乐 + 钢琴 + 钟琴 |
| 误会低落 | 钢琴独奏 |
| 约会甜蜜 | 吉他 + 钢琴 |
| 离别感伤 | 弦乐 + 钢琴 |

### 典型环境音

- **校园环境音** — 上课铃声/走廊脚步/操场喧闹/蝉鸣/风吹树叶
- **都市环境音** — 电车轨道声/信号灯提示/自动门/咖啡机/雨打伞面
- **祭典环境音** — 太鼓远处/人群笑闹/射击摊/烟花升空/风铃摇响
- **每场戏标注 1-2 个核心环境音**，帮助后续音效设计
- **留白比配乐更重要** — 关键心动瞬间（对视、告白、初吻）优先考虑去掉配乐，只留环境音（风声、远处电车、心跳暗示），让观众自己感受情绪
- **避免满配** — 全片配乐覆盖率建议不超过. 50%。留9留白段落的"无声"与配乐段落形成呼吸感，突出真实情感
