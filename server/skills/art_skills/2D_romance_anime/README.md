# 恋爱动漫风格说明

本风格专为"现代恋爱动画质感"题材打造，所有美术提示词、规范和生成内容均严格限定于：

- **现代恋爱世界观**：以现代校园与都市恋爱为背景，涵盖教室、天台、樱花街道、咖啡甜品店、祭典烟花、车站月台等，体现青春恋爱舞台感。
- **现代赛璐璐质感**：所有角色、场景、道具均以现代恋爱动画为标准，强调干净色块、清秀线条、双层阴影与细腻高光。
- **心动演出美学**：以飘花、光晕、背景炸白、逆光对视等心动演出特效放大情感瞬间，粉蓝奶油色调清透明亮。
- **情感表达**：适合展现怦然心动、暧昧拉扯、告白、误会与和好等现代恋爱故事，强调双人关系构图与情绪张力。

## 适用范围

- 现代恋爱动画题材的AI美术生成（角色、场景、道具、分镜等）
- 需要心动演出特效、粉蓝奶油色调、双人互动构图的视觉创作

## 严禁内容

- 写实摄影、真人实拍、3D写实渲染、CG动画质感
- 高饱和荧光色、霓虹色、暗黑重口色彩
- 暗黑血腥、恐怖惊悚、成人向内容
- 少女漫网点纸质感、90年代复古赛璐璐粗粝感

## 风格体验

在本风格下，您将体验到：

- 角色面容清秀、气质清爽或元气，校服与便装均为现代恋爱动画风格
- 场景构图预留双人站位与对视轴线，天色通透、逆光唯美
- 道具以巧克力、情书、透明伞、拍立得等恋爱信物为主，精致细腻
- 分镜与画面以心动演出为基础，飘花、光晕与升格慢动作放大怦然瞬间

---

本风格仅适用于"恋爱动漫"相关项目。如需其他风格（如治愈系日常、少女漫画网点、少年热血、写实摄影等），请勿使用本套提示词。
