## 二、全局色彩盘（风格基线，不是硬锁）

> 目标：统一审美而非限制创作。除「硬约束色」外，其余颜色默认优先使用，可在合理范围内偏移。

### 色彩使用层级

| 层级 | 约束强度 | 说明 |
|---|---|---|
| L1 硬约束 | 高 | 仅锁定角色识别核心：肤色、发色、主服底色的审美方向 |
| L2 软约束 | 中 | 场景色、道具色、演出特效色优先参考色盘，可按镜头与情绪微调 |
| L3 例外机制 | 低 | 烟花/告白/误会等高潮场景可临时突破局部色彩，但需保留整体清透逻辑 |

### 硬约束色（默认锁定）

| 色项 | 对应色 | 规则 |
|---|---|---|
| 肤色基准 | C1 奶油白 | 默认优先，允许小幅明度微调，保持清透红润感 |
| 发色/瞳色基准 | C8 可可棕 | 默认优先，允许可可/栗棕/深棕轻微偏移 |

### 软约束色（推荐优先）

> C2/C3/C4/C5/C6/C7/C9/C10 为推荐色域，用于服装、道具、背景、演出特效、夜色等。可根据情绪阶段做同色相邻近调整。

### 情绪色盘使用规则

| 编号 | 规则 |
|---|---|
| E1 | 每条提示词至少指定 1 个「情绪场景」并绑定主色+辅色组合 |
| E2 | 单镜头主色不超过 2 个，避免颜色叙事失焦 |
| E3 | 情绪切换时优先调整光效（逆光/炸白/冷调）与色温，再调整饱和度 |
| E4 | 恋爱向默认遵循「清透底 + 心动暖」：奶油白与青空蓝铺底，心动粉/窗光金留给情感高光 |
| E5 | 若与剧情冲突，以情绪色盘优先于通用推荐色，但不得突破严禁项 |

### 色温约束

| 参数 | 值 | 说明 |
|---|---|---|
| 整体色温 | 中性偏亮 5300-5700K（推荐） | 清透明亮的青春主基调 |
| 肤色色温 | 微暖 5200-5600K（推荐） | 奶油白皙且红润有生气 |
| 对比度 | 中等（建议保持） | 色块干净，阴影克制 |
| 饱和度 | 中 55-70%（建议区间） | 现代恋爱动画柔亮色调 |

### 容差与例外

| 项目 | 建议容差 |
|---|---|
| 色相偏移 | ±8° |
| 饱和度偏移 | ±10% |
| 明度偏移 | ±12% |

> 例外场景：烟花、告白、黄昏等高潮镜头可使用更高饱和的局部色块与光效；但禁止高饱和荧光色与暗黑重口色彩入镜。
