# 魔法少女动画风格 - 人物基础形象生成 · 约束手册

---

## 一、基础形象原则

1. **闪耀即灵魂** — 星形高光与亮粉粒子为角色核心气质，避免灰哑哑的哑光处理
2. **角色为本** — 基础着装由角色描述（身份/职业/性别/场景）决定其常规着装；魔法战服为后续衍生叠加层
3. **四视图一致** — 面容/体型/发型/基础服装跨视图高度统一
4. **甜度默认在线** — 无妆状态需体现角色气质（元气/温柔/神秘/清冷）

---

## 二、面容约束

> 不再固定五官特征参数，由角色描述（性别/年龄/性格/气质）驱动 AI 自由生成五官，保证人物间外观差异化。

### 通用要求

| 项目 | 约束 |
|---|---|
| 五官 | 由角色描述自然推导，不预设脸型/眼型/眉型/鼻型/唇型；风格默认眼睛偏大偏清澈 |
| 风格底色 | 魔法少女动画手绘质感（糖果高饱和、清晰线条、星形高光、柔和光泽） |
| 气质 | 必须从角色描述提炼整体气质关键词（如元气/温柔/神秘/清冷），并写入提示词 |
| 表情 | 中性微表情带甜度，符合角色气质 |

## 六、基础服装约束

> 基础服装由角色描述（身份/职业/性别/场景）决定其最自然的常规着装，作为该角色「日常默认态」；魔法战服/变身服/礼服在服化衍生环节叠加。**禁止内衣打底**。

### 着装选择原则

| 角色身份 | 默认着装方向 |
|---|---|
| 学生 | 现代校园制服 / 学院风连衣裙 |
| 魔法使/见习生 | 日常魔法装（连衣裙+小斗篷/短披风） |
| 居家/休闲 | 可爱家居服（针织连衣裙/卫衣裙） |
| 偶像/演出者 | 舞台演出裙装 / 打歌服 |
| 特殊职业 | 对应身份服装（魔女店主/占卜师/骑士见习等） |
| 角色描述未明确 | 糖果色系少女日常常服 |

### 着装统一规则

- 服装风格须与魔法少女动画美学一致（糖果亮色、轻盈材质、手绘质感）
- 颜色明快，无复杂战服结构/徽章纹章，便于后续战服衍生叠加
- 四视图服装款式完全一致
- 基础服装是「日常默认态」，焦点仍在面容与体态
- 严禁内衣/暴露/性化打底

## 八、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须为「素颜无妆」状态 |
| R2 | 必须根据角色描述声明合适的常规着装作为基础服装（如学生→校园制服、魔法使→日常魔法装、居家→可爱家居服）；禁止内衣打底 |
| R3 | 必须声明「无发饰、无配饰」 |
| R4 | 必须指定「梦幻淡粉背景 #FFF0F6」 |
| R5 | 必须指定「四视图一致性」 |
| R6 | 全身立像必须从头到脚完整展示，严禁裁切 |
| R7 | 必须指定角色身高并通过头身比换算约束全身比例（女性默认150-160cm/5.5-6.5头身，男性默认170-180cm/6.5-7.5头身） |
| R8 | 人像特写必须从头顶到锁骨完整展示，严禁裁切头顶 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 内衣/暴露/性化打底；与角色描述明显不符的着装；过度复杂战服结构/纹章干扰后续战服叠加 |
| X2 | 数字化锐利边缘、灰暗低饱和色彩 |
| X3 | 过度美白至无血色、病态苍白 |
| X4 | 复杂场景背景（必须梦幻淡粉背景） |
| X5 | 夸张表情/剧烈动态姿势 |
| X6 | 全身立像裁切头顶或脚底，必须从头到脚完整入画 |
| X7 | 人像特写裁切头顶，必须从头顶到锁骨完整入画 |
| X8 | 忽略身高和头身比约束 |
