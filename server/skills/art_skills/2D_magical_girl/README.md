# 魔法少女风风格说明

本风格专为"魔法少女动画质感"题材打造，所有美术提示词、规范和生成内容均严格限定于：

- **魔法少女世界观**：以现代都市与魔法异空间交织为背景，涵盖校园、街道、甜品屋、星空天台、变身异空间、魔法结界等，体现少女日常与魔法奇遇的双重质感。
- **闪亮手绘质感**：所有角色、场景、道具均以经典魔法少女动画为标准，强调清晰线条、糖果色高饱和上色、星形高光与亮粉粒子特效。
- **梦幻闪耀美学**：在高饱和糖果粉紫基调上追求变身演出式的华丽光效，画面明亮璀璨，整体氛围梦幻、元气、充满希望。
- **情感表达**：适合展现友情、羁绊、觉醒与守护的故事，强调少女成长弧线下的热血与治愈并存的情感表达。

## 适用范围

- 魔法少女动画题材的AI美术生成（角色、场景、道具、分镜等）
- 需要极致闪耀质感、糖果高饱和色彩、梦幻魔法氛围的视觉创作

## 严禁内容

- 写实画风、厚涂油画、灰暗低饱和画风
- 3D渲染、CG动画、写实摄影感
- 阴郁黑暗系、恐怖猎奇、成人向内容
- 现代职场写实服饰、日常灰调服装

## 风格体验

在本风格下，您将体验到：

- 角色面容甜美、气质元气或神秘，大眼星光高光，发丝飘逸闪亮，服饰均为华丽的魔法少女风格
- 场景空间层次丰富，糖果色铺陈，星光粒子常驻，氛围梦幻且富有奇迹感
- 道具、魔杖、变身器、徽章均为闪亮魔法造型，宝石璀璨，光效华丽
- 分镜与画面均以闪耀手绘为基础，强调变身演出与情感爆发

本风格仅适用于"魔法少女动画"相关项目。如需其他风格（如写实插画、CG、水墨、浮世绘等），请勿使用本套提示词。
