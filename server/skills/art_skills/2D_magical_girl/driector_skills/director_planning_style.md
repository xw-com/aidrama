# 魔法少女约束 · 魔法少女风 · 技法参考

---

## 一、色调体系与画面基调

- **色调基底** — 全片以糖果粉（C1）、星光紫（C2）、亮金（C10）为基底色，整体色温中性偏亮（6000-6500K），饱和度高（75-90%），呈现魔法少女动画的梦幻闪耀感。全片保持糖果高饱和亮调基底，局部点缀深蓝（C9 银河深蓝）用于反派与夜空衬底
- **冷暖叙事对比** — 深蓝（C9）与灰紫作为叙事转折的视觉信号，用于反派结界、黑化或低谷段落局部压暗。明暗切换应与故事弧线同步，而非随意混用
- **色盘先行原则** — 段落规划需先绑定情绪场景（日常可爱/变身高光/决战时刻/希望觉醒等），再确定主色+辅色与光影方案，避免"剧情对了但情绪不对色"
- **禁用色域** — 灰暗低饱和色系、写实油画色彩体系、荧光脏浊的赛博色均与本风格不兼容

---

## 二、光影方案体系

- **光影即叙事** — 6 套光影方案对应不同情绪段落，导演规划阶段应在段落层面确定光影基调方向，而非逐镜指定
- **光源角度** — 默认正面高位光 + 侧后轮廓光，日常场景 30-45°斜侧光；变身与决战允许中心爆发光

| 情绪段落 | 光影方向 | 色调倾向 | 适用阶段 |
|---|---|---|---|
| 日常可爱 | A·均匀亮调漫射 | 糖果粉底 + 奶黄高光 | 全片 |
| 元气活泼 | B·明亮顶光 | 柠檬奶黄 + 糖果粉点缀 | 校园/日常段 |
| 变身高光 | C·中心爆发光 | 亮金光核 + 星光紫环绕 | 变身段 |
| 决战时刻 | D·高对比逆光 | 玫瑰红 + 亮金对撞 | 战斗高潮段 |
| 夜晚星空 | E·星光冷调 | 梦幻蓝紫 + 亮色点缀 | 夜晚/独处段 |
| 反派结界 | F·暗紫底光 | 银河深蓝主导 + 冷紫裂纹 | 敌对段 |

- **冷暖光分配** — 亮调光（A/B/C）贯穿全片可用，根据场景需要灵活调整；暗调光（F）仅在反派、黑化或低谷段落使用，且人物面部保留可读微光
- **氛围方向映射** — 每场戏的氛围方向应能映射到上述光影方案（A-F）的某一方向，确保视觉一致性

## 三、质感方向

- **闪耀纪实感** — 魔法少女动画的核心：星形高光、亮粉粒子、糖果高饱和平涂、光效层次分明
- **清晰线稿 + 糖果上色** — 这是画面质感的锚点。不是灰哑哑的写实厚涂，不是3D渲染光泽
- **高饱和不等于刺眼** — 本风格强调糖果色的明快感表达（干净色块、柔和粉紫渐变、璀璨高光），通过构图与情绪设计放大感染力，而非堆砌荧光
- **粒子有节制** — 星光粒子与亮粉特效服务于情绪节点（变身/觉醒/释放），日常段落仅做微星尘点缀，避免全片"特效疲劳"

## 四、魔法少女场景空间元素

魔法少女动画特有的场景元素及其视觉叙事功能：

- **魔法阵/光带/镜面碎片** — 天然的旋转构图道具，制造"包裹感"的仪式层次与变身演出张力
- **天台/教室/甜品屋** — 少女日常感的天然载体，景即情：天台星空 = 憧憬、教室窗边阳光 = 青春、甜品屋暖光 = 治愈日常
- **星光/极光/光之雨** — 留白构图的天然载体，景即情：漫天星光 = 羁绊、极光流转 = 奇迹、光之雨落下 = 觉醒前夕
- **结界/异空间/云上圣域** — 魔法世界的空间载体，结界 = 危机（方案F）、异空间 = 变身仪式（方案C）、云上圣域 = 希望彼岸
- **段落间用场景空镜过渡** — 本风格有丰富的场景资产（不同时段/天候/光效变体），段落衔接建议用场景空镜做情绪缓冲，不要硬切
- **转折点用视觉而非台词** — 优先使用画面手段（光效突变、粒子爆发、星图闪烁）而非依赖对白解释

## 五、魔法少女乐器与环境音

魔法少女动画世界观下的声音元素约束：

### 乐器选择

- **钢片琴/音乐盒** — 变身/回忆/梦幻段落的核心乐器，清脆音色最能表现魔法闪耀质感
- **电子合成器** — 日常/战斗段落的节奏基底，明快脉冲适合元气氛围
- **弦乐铺底** — 觉醒/决战/情感升华段落，拉弦的张力适合情绪爆发
- **小号/圆号** — 希望觉醒与胜利时刻，铜管辉煌感放大奇迹降临
- **竖琴/铃鼓** — 魔法释放与粒子飘散段落，琶音与碎响对应星光音效

### 乐器组合策略

| 情绪阶段 | 乐器组合 |
|---|---|
| 平稳/开场/收尾 | 钢片琴独奏 或 音乐盒独奏 |
| 日常温馨 | 电子合成器 + 轻铃鼓 |
| 情绪升华/决战 | 弦乐 + 小号 |
| 变身/觉醒 | 音乐盒渐强 + 弦乐 + 铜管 |

### 魔法少女环境音

- **典型环境音层次** — 星光叮咚音 / 风铃轻响 / 便利店门铃 / 上课下课铃 / 夜晚虫鸣 / 城市远景车流 / 魔法爆发嗡鸣 / 心跳声
- **每场戏标注 1-2 个核心环境音**，帮助后续音效设计。环境音层次越丰富，双重世界（日常+魔法）越有沉浸感
- **留白比配乐更重要** — 关键情感瞬间（对视、初次变身前的凝滞、告别）优先考虑去掉配乐，只留环境音（风声、心跳、虫鸣），让观众自己感受情绪
- **避免满配** — 全片配乐覆盖率建议不超过 50%。留白段落的"无声"与配乐段落形成呼吸感，突出奇迹降临时的爆发
