## 二、全局色彩盘（风格基线，不是硬锁）

> 目标：统一审美而非限制创作。除「硬约束色」外，其余颜色默认优先使用，可在合理范围内偏移。

### 色彩使用层级

| 层级 | 约束强度 | 说明 |
|---|---|---|
| L1 硬约束 | 高 | 仅锁定角色识别核心：肤色、发色、主服底色的审美方向 |
| L2 软约束 | 中 | 场景色、配饰色、魔法光效色优先参考色盘，可按镜头与剧情微调 |
| L3 例外机制 | 低 | 反派结界/黑化/决战高潮可临时突破局部色彩，但需保留整体闪亮逻辑 |

### 硬约束色（默认锁定）

| 色项 | 对应色 | 规则 |
|---|---|---|
| 肤色基准 | C4 蜜桃肤 | 默认优先，允许小幅明度/粉度微调 |
| 发色/瞳色基准 | C1/C2/C6/C10 亮彩系 | 发色默认糖果亮彩（粉/金/紫/蓝），瞳孔必须带星形高光 |

### 软约束色（推荐优先）

> C2/C3/C5/C7/C8/C9 为推荐色域，用于魔法阵、缎带、背景、光效、结界等。可根据镜头氛围做同色相邻近调整。

### 情绪色盘使用规则

| 编号 | 规则 |
|---|---|
| E1 | 每条提示词至少指定 1 个「情绪场景」并绑定主色+辅色组合 |
| E2 | 单镜头主色不超过 2 个，避免颜色叙事失焦 |
| E3 | 情绪切换时优先调整光效密度与明度，再调整色相 |
| E4 | 闪耀向默认遵循「亮底 + 暗衬」：糖果亮色铺底，深蓝仅用于反派与夜空 |
| E5 | 若与剧情冲突，以情绪色盘优先于通用推荐色，但不得突破严禁项 |

### 色温约束

| 参数 | 值 | 说明 |
|---|---|---|
| 整体色温 | 中性偏亮 6000-6500K（推荐） | 梦幻闪耀主基调 |
| 肤色色温 | 微粉 5800-6200K（推荐） | 蜜桃感且有生命气息 |
| 对比度 | 中等偏高（建议保持） | 高光璀璨，但不失细节 |
| 饱和度 | 高 75-90%（建议区间） | 糖果高饱和魔法少女色调 |

### 容差与例外

| 项目 | 建议容差 |
|---|---|
| 色相偏移 | ±8° |
| 饱和度偏移 | ±10% |
| 明度偏移 | ±12% |

> 例外场景：变身、决战、黑化镜头可使用更高饱和或更深暗部局部色块；但禁止灰暗低饱和整体画风与写实色彩语言入镜。
