# 人物基础形象生成 · 警匪动作写实约束手册

---

## 一、基础形象原则

1. **面容即灵魂** — 五官是角色唯一锚点，毛孔级精细渲染，硬光下依然清晰立体、皮肤粗粝真实
2. **角色为本** — 警员制服/战术装、匪徒便装/黑衣为默认主造型，其余身份由角色描述（身份/职业/性别/场景）决定；后续特定服化为叠加层
3. **四视图一致** — 面容/体型/发型/装备跨视图高度统一
4. **冷硬实拍** — 以真实警匪动作影视为锚点，硬光下保留皮肤粗粝质感（毛孔/汗渍/尘灰）

---

## 二、面容约束

> 不再固定五官特征参数，由角色描述（性别/年龄/性格/气质）驱动 AI 自由生成五官，保证人物间外观差异化。

### 通用要求

| 项目 | 约束 |
|---|---|
| 五官 | 由角色描述自然推导，不预设脸型/眼型/眉型/鼻型/唇型 |
| 风格底色 | 真人警匪动作写实、毛孔级精细渲染、冷硬电影光影、硬光强对比 |
| 气质 | 必须从角色描述提炼整体气质关键词（如冷峻/果决/狠厉/沉稳），并写入提示词 |
| 表情 | 冷硬微表情：眉骨压低、目光锐利、唇线紧抿，符合角色气质 |

### 警员形象规范

| 项目 | 约束 | 提示词 |
|---|---|---|
| 神态 | 冷峻果决、目光警觉 | 冷峻神态、目光警觉 |
| 面容 | 饱经风霜、皮肤粗粝、可有胡茬/疤痕 | 皮肤粗粝、胡茬、疤痕细节 |
| 妆容 | 无妆/淡妆自然，禁美化磨皮 | 素颜自然、无美化磨皮 |

### 匪徒形象规范

| 项目 | 约束 | 提示词 |
|---|---|---|
| 神态 | 狠厉阴鸷、目光凶戾 | 狠厉神态、目光凶戾 |
| 面容 | 粗粝真实、可有纹身/疤痕/刀疤 | 皮肤粗粝、纹身、刀疤 |
| 妆容 | 无妆自然，禁美化 | 素颜自然、无美化 |

## 六、基础服装约束

> 基础服装默认为警员制服/战术装或匪徒便装/黑衣体系，作为该角色「默认态」；卧底/伪装等特殊衍生在服化衍生环节叠加。**禁止内衣打底**。

### 着装选择原则

| 角色身份 | 默认着装方向 |
|---|---|
| 巡警/刑警 | 警服制服（警蓝衬衫+战术裤+警徽） |
| 特警/突击 | 战术装备（防弹背心+战术头盔+护具） |
| 卧底/便衣 | 便衣夹克+深色裤装 |
| 匪徒/黑帮 | 黑色便装/皮衣/帽衫 |
| 线人/平民 | 日常便服 |
| 角色描述未明确 | 警员制服/匪徒黑衣默认 |

### 着装统一规则

- 警服须体现面料质感、警徽臂章、战术挂件，工艺写实可信
- 战术装备须体现防弹背心纹路、弹匣袋、枪套、护膝，细节写实
- 颜色以警蓝/沥青黑/战术卡其/灰水泥为主，无喧宾夺主的复杂印花
- 四视图服装款式完全一致，装备挂载位置一致
- 基础服装是「默认态」，焦点仍在面容与冷峻气质
- 严禁内衣/暴露/性化打底

## 八、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须为「冷硬微表情」（眉骨压低、目光锐利、唇线紧抿）|
| R2 | 警员默认「制服/战术装」、匪徒默认「黑衣便装」，其余身份按角色描述匹配；禁止内衣打底 |
| R3 | 必须声明「无发饰」（战术发饰在服化衍生环节叠加） |
| R4 | 必须指定「纯净钢银白背景」 |
| R5 | 必须指定「四视图一致性」 |
| R6 | 全身立像必须从头顶到脚底连同装备完整展示，严禁裁切 |
| R7 | 必须声明角色身高并通过头身比换算约束全身比例 |
| R8 | 人像特写必须从头顶到锁骨完整展示，严禁裁切头顶 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 内衣/暴露/性化打底；与角色描述明显不符的着装 |
| X2 | 正顶硬光/彩色光/梦幻柔光（设定图除外用均匀柔光） |
| X3 | 过度美白/塑料磨皮至无质感（须保留皮肤粗粝真实） |
| X4 | 复杂场景背景（必须纯钢银白底） |
| X5 | 卡通/动漫/插画/二次元/3D渲染质感 |
| X6 | 全身立像裁切头顶、脚底或装备，必须完整入画 |
| X7 | 人像特写裁切头顶，必须从头顶到锁骨完整入画 |
| X8 | 忽略身高和头身比约束 |
