# 警匪动作写实约束 · 警匪动作写实 · 技法参考

---

## 一、色调体系与画面基调

- **暗底冷调基底** — 全片以沥青黑（C1）铺底，警蓝（C2）/冷青夜（C8）为冷调主色，钠灯琥珀（C6）/警示红（C3）作为点光焦点，整体呈现真人警匪动作影视的冷硬紧绷基调。遵循「暗底 + 点光」：沥青黑铺底，琥珀/红蓝点光落在对峙焦点
- **硬光强对比叙事** — 硬光与明暗分割是本风格核心视觉语言，明暗切割即善恶/危机/对峙的视觉信号，而非随意打光
- **情绪先行原则** — 段落规划需先绑定情绪场景（潜伏/对峙/追击/审讯/火拼/收网等），再确定主色+辅色与光影方案，避免「情绪对但影调不对」
- **禁用柔美梦幻** — 任何柔光唯美、婚纱/时尚、高饱和荧光、霓虹梦幻均与本风格不兼容

---

## 二、光影方案体系

- **硬光即张力** — 6 套光影方案对应不同叙事段落，导演规划阶段应在段落层面确定光影基调方向，而非逐镜指定
- **光源逻辑** — 默认硬光强对比 + 30-45°斜侧，特殊场景用顶光/警灯红蓝/钠灯逆光

| 情绪段落 | 光影方向 | 色调倾向 | 适用阶段 |
|---|---|---|---|
| 潜伏/巡逻 | A·低调打光+冷调底 | 沥青黑 + 冷青夜 + 钠灯琥珀 | 铺垫段 |
| 对峙/一触 | B·警灯红蓝切割面部 | 警示红 + 警蓝 + 沥青黑 | 危机段 |
| 追击/急切 | C·钠灯侧逆光+湿地反光 | 沥青黑 + 钢银白 + 钠灯琥珀 | 紧张段 |
| 审讯/博弈 | D·顶光直射半明半暗 | 警蓝 + 灰水泥 + 自然肤 | 冷峻段 |
| 火拼/高潮 | E·爆破暖光+枪口火光 | 警示红 + 钠灯琥珀 + 锈血红 | 高潮段 |
| 收网/肃冷 | F·蓝调时刻冷光薄雾 | 冷青夜 + 沥青黑 + 钢银白 | 收束段 |

- **明暗分配** — 暗调冷底贯穿全片，琥珀/红蓝点光作为情绪焦点点缀；火拼接 E 段短暂爆裂暖光
- **氛围方向映射** — 每场戏的氛围方向应能映射到上述光影方案（A-F）的某一方向，确保视觉一致性

## 三、质感方向

- **毛孔级实拍质感** — 警匪写实的核心：面容冷峻写实、皮肤粗粝真实、毛孔清晰、汗渍尘灰、无塑料磨皮
- **战术装备质感** — 防弹背心纹路、枪械金属哑光、弹匣袋缝线、护具磨损，细节写实可信
- **环境粗粝质感** — 水泥墙面、锈蚀钢铁、湿地反光、碎玻璃、弹痕涂鸦，场景带使用与战斗痕迹
- **非洁净冷硬** — 场景带雨雾、烟雾、油污、锈迹；人物锚定战术装备，禁止时尚/婚纱元素喧宾夺主

## 四、场景空间元素

警匪动作写实特有的场景元素及其视觉叙事功能：

- **雨夜巷口/湿地反光** — 标志性场景，景即情：雨夜独行 = 孤影潜伏、湿地铬银反光 = 双重世界、长影拉伸 = 不祥危机
- **警灯红蓝/钠灯琥珀** — 光源载体，警灯红蓝切割 = 对峙一触、钠灯琥珀光柱 = 冷夜暖点、应急灯绿光 = 危机逼仄
- **废弃仓库/厂房/车库** — 火拼伏击空间，景即情：仓库木箱 = 潜伏伏击、厂房铁梁 = 荒冷对峙、车库水泥柱 = 追击逼仄
- **审讯室/铁桌顶光** — 博弈空间，顶光直射 = 压迫审讯、半明半暗 = 心理博弈
- **码头货柜/工地废墟** — 亡命火拼空间，集装箱铁冷 = 走私亡命、脚手架废墟 = 爆破火拼
- **段落间用场景空镜过渡** — 本风格有丰富的场景资产（不同时段/天候/室内外变体），段落衔接建议用场景空镜做情绪缓冲（如雨夜巷口→黎明收网），不要硬切
- **转折点用光影而非台词** — 优先使用画面手段（警灯闪烁转场/光影突变/枪口火光硬切）而非依赖对白解释

## 五、配乐与环境音

警匪动作写实世界观下的声音元素约束：

### 乐器选择

- **合成器低音脉冲** — 核心：紧张/追击段落的脉冲底色，制造不安与压迫
- **打击乐/定音鼓** — 对峙/火拼段落的节奏色彩，沉重击打
- **大提琴/弦乐** — 悲壮/收网段落的低沉底色，弦音压抑
- **电子失真音效** — 火拼/高潮段落的爆裂色彩（克制使用）

### 乐器组合策略

| 情绪阶段 | 乐器组合 |
|---|---|
| 潜伏/巡逻 | 合成器低音脉冲 + 环境音 |
| 对峙/一触 | 打击乐 + 合成器脉冲 |
| 追击/急切 | 合成器低音 + 电子节奏 |
| 审讯/博弈 | 大提琴独奏 + 寂静 |
| 火拼/高潮 | 打击乐 + 电子失真 + 弦乐骤强 |
| 收网/肃冷 | 大提琴 + 钢琴收束 |

### 典型环境音

- **街道环境音** — 警笛远近/雨打沥青/车驶飞驰/脚步回响/霓虹招牌嗡鸣
- **室内环境音** — 枪械上膛咔嗒/对讲机电流声/铁门闭合/弹壳落地/呼吸急促
- **火拼环境音** — 枪口爆响/玻璃碎裂/金属撞击/烟雾弥漫/呼喊杂乱
- **每场戏标注 1-2 个核心环境音**，帮助后续音效设计
- **留白即压迫** — 关键瞬间（对峙沉默、审讯停顿、决绝赴险前夜）优先去掉配乐只留环境音（呼吸、雨声、枪械咔嗒），寂静比满配更紧绷
- **避免满配** — 全片配乐覆盖率建议不超过 50%。留白段落的「无声」与配乐段落形成呼吸感，突出对峙张力
