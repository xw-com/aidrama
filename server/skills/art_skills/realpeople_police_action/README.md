# 警匪动作写实风格说明

本风格专为"警匪动作影视写实"题材打造，所有美术提示词、规范和生成内容均严格限定于：

- **硬核警匪写实**：以真人警匪动作影视为标准，特警战术、刑侦缉凶、街头火拼、对峙追逐，画面冷硬紧绷、戏剧张力拉满。
- **都市夜场叙事**：默认以都市夜景/废弃工业/巷战楼宇为舞台，警灯红蓝交替、雨夜湿地反光、钠灯琥珀光柱构成标志性氛围。
- **战术装备细节**：警服/战术背心/防弹头盔/枪械/手铐/对讲机等装备工艺写实可信，人物身手矫健、神色冷峻。
- **冷硬电影光影**：硬光强对比、警灯红蓝切割、雨夜湿地铬银反光、低调打光与轮廓光分离，追求影视级动作纪实质感。

## 适用范围

- 警匪动作题材的AI美术生成（角色、场景、道具、分镜等）
- 需要极致硬核、冷硬紧绷、戏剧张力强烈的视觉创作

## 严禁内容

- 卡通、动漫、插画、二次元风格
- 柔光唯美、婚纱/时尚杂志感
- 过度血腥猎奇、解剖级暴力展示（动作张力靠构图与光影，不靠血腥堆砌）
- 荧光糖果色、梦幻滤镜

## 风格体验

在本风格下，您将体验到：

- 警员/匪徒面容冷峻写实，皮肤粗粝质感，战术装备与枪械细节极致
- 场景以都市夜场为主，警灯红蓝交替、雨夜湿地反光、废弃工业冷调
- 枪械/手铐/对讲机/警车等道具工艺精细，金属质感分明
- 分镜与视频以对峙追逐为核心，冷硬电影光影与动作张力贯穿始终

---

本风格仅适用于"警匪动作写实"相关项目。如需其他风格（如唯美婚照、动漫、时尚等），请勿使用本套提示词。
