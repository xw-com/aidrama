## 一、风格基因

| 维度 | 定义 |
|---|---|
| **一级风格** | 真人警匪动作写实（Police-Action Photorealism） |
| **二级风格** | 硬核动作影视 · 冷紧戏剧质感 |
| **情感基调** | 冷硬紧绷 — 对峙张力、生死时速 |
| **质感锚词** | 硬光强对比、警灯红蓝、雨夜湿地反光、战术装备质感 |

## 二、全局色彩盘（风格基线，不是硬锁）

> 目标：统一审美而非限制创作。除「硬约束色」外，其余颜色默认优先使用，可在合理范围内偏移。

### 色彩使用层级

| 层级 | 约束强度 | 说明 |
|---|---|---|
| L1 硬约束 | 高 | 仅锁定角色识别核心：肤色、发色、制服/战术装底色的审美方向 |
| L2 软约束 | 中 | 场景色、装备色、光效色优先参考色盘，可按镜头与剧情微调 |
| L3 例外机制 | 低 | 火拼/爆破/高潮戏可临时突破局部色彩，但需保留整体冷硬逻辑 |

### 硬约束色（默认锁定）

| 色项 | 对应色 | 规则 |
|---|---|---|
| 肤色基准 | C4 自然肤 | 默认优先，允许小幅明度/冷暖微调 |
| 制服底色基准 | C2 警蓝 / C1 沥青黑 | 警员制服默认警蓝/黑，匪徒默认黑/灰 |

### 软约束色（推荐优先）

> C3/C5/C6/C7/C8/C10 为推荐色域，用于警灯光效、建筑场景、战术装备、夜空玻璃、锈迹血迹等。可根据镜头氛围做同色相邻近调整。

### 情绪色盘使用规则

| 编号 | 规则 |
|---|---|
| E1 | 每条提示词至少指定 1 个「情绪场景」并绑定主色+辅色组合 |
| E2 | 单镜头主色不超过 2 个，避免颜色叙事失焦 |
| E3 | 情绪切换时优先调整光比与色温，再调整饱和度 |
| E4 | 冷硬向默认遵循「暗底 + 点光」：沥青黑铺底，琥珀/红蓝点光落在对峙焦点 |
| E5 | 若与剧情冲突，以情绪色盘优先于通用推荐色，但不得突破严禁项 |

### 色温约束

| 参数 | 值 | 说明 |
|---|---|---|
| 整体色温 | 偏冷 3200-4500K（推荐） | 冷硬动作影视主基调 |
| 肤色色温 | 中性偏冷 4000-4800K（推荐） | 冷光下保留生命感 |
| 对比度 | 高（建议保持） | 明暗强对比，硬光长影 |
| 饱和度 | 中低 30-50%（建议区间） | 冷硬高级色调，警灯红蓝例外 |

### 容差与例外

| 项目 | 建议容差 |
|---|---|
| 色相偏移 | ±8° |
| 饱和度偏移 | ±10% |
| 明度偏移 | ±12% |

> 例外场景：火拼爆破、警灯对峙、情绪高潮镜头可使用更浓烈的局部色块（暖光爆裂/红蓝强闪）；但禁止霓虹荧光与梦幻柔光色彩语言入镜。

## 三、全局约束规则

### 必守规则（所有技能继承）

| 编号 | 规则 |
|---|---|
| R1 | 必须包含「真人警匪动作写实」风格锚定词 |
| R2 | 必须声明「硬光强对比 + 冷硬电影光影」 |
| R3 | 面部必须使用「面容冷峻写实 + 皮肤粗粝质感」 |
| R4 | 发丝必须使用「发丝细腻渲染 + 真实发质」 |
| R5 | 装备与枪械纹理必须声明「金属与战术材质细节超清晰」 |

### 严禁项（所有技能继承）

| 编号 | 严禁内容 |
|---|---|
| X1 | 严禁「卡通/动漫/二次元/插画风」 |
| X2 | 严禁「高饱和荧光色/霓虹梦幻色/柔光唯美」 |
| X3 | 严禁「婚纱/时尚杂志/治愈系氛围」（必须明确冷硬动作氛围） |
| X4 | 严禁「面部变形/多指/肢体异常」倾向词 |
| X5 | 严禁「解剖级血腥猎奇/过度暴力展示」（动作张力靠构图与光影，不靠血腥堆砌） |
| X6 | 严禁「过度美白/塑料磨皮」（须保留皮肤粗粝真实质感） |
