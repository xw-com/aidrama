# 真人古装宫廷写实场景图像生成 · 约束手册

---

## 一、场景美学原则

> 真人古装宫廷写实的场景不是"被建模的宫殿"，而是"被摄影机选中的真实宫廷"。没有渲染引擎、没有贴图、没有体积光参数——只有实际存在的天光与宫烛、真实的朱墙黄瓦与金箔檀木、以及宫廷深处的岁月与礼法。

1. **空间即权柄** — 一座空无一人的金銮殿不是"空的"，是退朝之后。龙椅上的明黄褥垫微皱、丹陛上的烛泪未干、奏折未合——空间自己会讲朝堂与后宫的故事
2. **真实的光，不是渲染的光** — 场景的光只有一个来源：实际的日光（通过殿窗、宫门、漏窗）、实际的灯火（宫灯、烛台、廊灯）。光的色温和方向必须在物理上说得通
3. **被岁月使用过的宫殿** — 真实的宫廷不崭新。朱墙有剥落与雨痕、琉璃瓦有积尘、金箔有氧化、青砖有磨损、檀木有开裂包浆——一个完全没有岁月痕迹的宫殿是横店的样板布景，不是真实宫廷
4. **中国古代宫廷的真实场所** — 场景必须有明确的中国宫廷辨识度（朱红宫墙、黄琉璃瓦、彩绘梁枋、漏窗、宫灯、铜缸、汉白玉栏杆）。这不是"generic palace"，这是"中国古代宫廷的一个具体角落"
5. **单视图全景全貌** — 一张照片装下整座殿/院/廊的完整信息。广角或标准焦段，全景深，正面展示空间的全貌与纵深——不是四视图分割，不是多角度拼贴

## 五、单视图全景摄影规范

> 真人古装宫廷写实场景仅需**单张**全景摄影——一张照片装下整座殿/院/廊的完整信息。不是2×2四视图，不是多角度拼接。

### 画面构成

| 项目 | 摄影要求 |
|---|---|
| 空间呈现 | 单张照片完整呈现场景的空间全貌。使用24-28mm广角或35mm，全场地的纵深、宽度、高度在一张画面中全部可见 |
| 构图 | 全景深大景别——前景（宫门/梁柱/纱帐/宫灯/栏杆/花木/漏窗）形成天然画框→中景是殿宇/院落主体→后景向空间纵深或后殿/天空延伸 |
| 景深 | 全景深 f/8-f/11，从前到后全部清晰。这不是人像摄影——场景的每一个角落都应该能被看见 |
| 人物 | **严禁出现任何人物、人影、人体轮廓。** 场景是空的——但这种"空"有叙事：退朝之后/即将大典/人去殿空/宫闱的静止瞬间 |
| 比例 | 建议 16:9 或 3:2 宽幅——匹配全景空间展示的横向视觉习惯 |
| 色彩 | 由实际光源的色温驱动，不套滤镜。色彩科学参考ARRI Alexa/Sony Venice电影色调 |

### 空的场景如何叙事

| "空"的类型 | 画面线索 | 叙事暗示 |
|---|---|---|
| 退朝之后 | 龙椅上明黄褥垫微皱、丹陛上烛泪未干、奏折未合、地墁有靴印 | 刚才朝堂有人，现在散了 |
| 即将大典 | 仪仗陈设齐整、宫灯全亮、香炉香烟未起、明黄幔帐拉平 | 大典马上开始，此刻是开场前的肃静 |
| 人去殿空 | 搬迁后的空殿、墙上挂过匾的钉痕、地面积尘的轮廓、断了的香火 | 曾经有人住过，现在被废/迁/抄 |
| 宫闱的静止 | 拔步床纱帐半垂、妆台铜镜映空榻、茶盏余温、窗外庭光打在地砖 | 起居的常态，只是此刻无人入镜 |
| 深夜的宫殿 | 空荡的回廊只有宫灯亮着、寝宫窗纸透出一团暖光、月下的空庭院 | 宫睡着了，但宫殿还醒着 |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须是**单张**全景摄影——单视图、非2×2四视图、非多角度、非turnaround |
| R2 | 必须使用广角镜头（24-28mm）或标准焦段（35mm），全景深 f/8-f/11，完整空间纵深 |
| R3 | 光源必须可追溯——自然光的方向与时刻匹配、宫烛宫灯的位置和色温合理 |
| R4 | 场景必须有前/中/后景空间层次，前景画框→中景主体→后景延伸 |
| R5 | 必须有中国古代宫廷辨识度——朱红宫墙/黄琉璃瓦/彩绘梁枋/漏窗/宫灯/汉白玉栏杆 |
| R6 | 必须有岁月痕迹——朱墙剥落/琉璃积尘/青砖磨损/金箔氧化/檀木包浆、非样板殿非全新非效果图 |
| R7 | **严禁出现任何人物、人影、人体轮廓、剪影** |
| R8 | 必须声明"真人实拍摄影 + 非3D渲染非CG"核心锚定 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 严禁「3D渲染 / 3D建模 / CG / UE引擎 / Blender / PBR材质 / 体积光 / AO」等一切CG术语 |
| X2 | 严禁「2D手绘 / 插画 / 动画 / 二次元 / 赛璐璐」等非摄影媒介 |
| X3 | 严禁「四视图 / 2×2网格 / 多角度 / turnaround / orthographic view / blueprint」——仅单张 |
| X4 | 严禁「现代都市/民国/西方宫廷/和风日式/仙侠法术/赛博朋克/科幻/西方奇幻/异世界」等非中国古代宫廷场景 |
| X5 | 严禁「无中国宫廷辨识度的架空宫殿 / 西式城堡 / 日式城堡」 |
| X6 | 严禁「出现任何人物/人影/人体轮廓/剪影/肢体」 |
| X7 | 严禁「样板殿/横店崭新布景/全新无痕/完美品相/无岁月痕迹/法术光效」的场景 |
| X8 | 严禁「光源来源不明/全局均匀照明/无方向的光/法术发光」 |
| X9 | 严禁「过曝死白/暗部死黑/无景深/画面扁平」 |
| X10 | 严禁「水印 / 文字 / LOGO / 签名 / 边框 / AI生成痕迹」 |
