## 一、风格核心定义

**真人古装宫廷写实**是以**真人影视摄影美学**为基准、以**中国古代宫廷（清宫/宫斗题材）**为核心视觉舞台的风格体系。其核心特征为：

- **真人写实摄影质感**：以真人影视级摄影为锚点，画面呈现真实人物的皮肤纹理、毛发细节、丝绸华服的光泽垂坠、宫殿建筑的岁月材质、微表情与肢体语言，杜绝3D建模感、CG渲染感、手绘感与二次元动漫感
- **古代宫廷世界观**：所有场景严格限定于中国古代宫廷空间——金銮殿/太和殿、后宫庭院与御花园、东西六宫寝宫、朱红宫墙与黄琉璃瓦、彩绘回廊与漏窗、御书房、冷宫、浣衣局、库房珍宝阁、宫门甬道
- **电影级摄影语言**：以院线级真人古装电影摄影为基准，强调宫灯烛火与自然天光的有机调度、构图叙事的专业性、景深与焦点的情绪表达、色彩分级的电影感
- **宫廷人文厚重感**：在保持专业影像品质的前提下，强调宫廷礼制的庄严、朱墙黄瓦的礼法色序、丝绸与金箔的真实物质感、深宫人物之间的隐忍情感连接

### 创作理念与核心价值

本手册的核心创作理念为 **"礼法之下，肉身之上"**：

1. **真实感的审美回归**：在AI生成影像日趋泛滥的当下，真人写实质感以其不可替代的真实力量，成为最具情感穿透力的视觉语言。真人肌肤的纹理、丝绸上的金线、宫灯下摇曳的烛影、朱红宫墙上的雨痕与剥落——这些真实细节构成了一种生命质感与岁月质感，是3D渲染无法复刻的审美深度。

2. **宫廷的叙事容器**：中国古代宫廷是最具戏剧张力的叙事空间。金銮殿的龙椅承载天下权柄，东西六宫的寝宫回荡着嫔妃的算计与哀愁，冷宫的蛛网与朱墙的剥落讲述着被遗忘的人——宫廷空间本身就是一个等级森严、暗流涌动的叙事容器。

3. **礼法即视觉**：宫廷的色彩有礼法秩序——明黄为帝王之色、朱红为宫墙之色、石青与绛紫为臣工命妇之色。本手册坚持以真实宫规服制驱动色彩与造型，反对架空与随意混搭。

4. **克制写实即品格**：本风格为"真人写实宫廷"，不是仙侠法术，不是动漫玄幻。一切光影、材质、人物以写实克制为底色——宫斗的狠辣藏在眼神里，不藏在特效里；帝王的威仪落在肩背与朝服上，不落在魔法光效上。

**核心价值：**

- 为AI视觉创作者提供一套系统化、可复用的真人古装宫廷题材提示词方法论
- 建立从概念到成品的标准化视觉创作管线
- 降低真人古装宫廷题材AI视觉创作的技术门槛与试错成本
- 填补当前AI视觉创作领域"真人写实宫廷系统化方法论"的空白

## 四、关键视觉元素

### 4.1 人物视觉元素

真人古装宫廷题材的人物视觉以**"礼法衣冠、真人骨血"**为核心：

- **面容标准**：真人肌肤质感，五官自然立体，古装妆容（花钿、点唇、远山黛、面靥）与皮肤融合不过度浓艳。支持多元面容类型——端庄威仪、清冷孤傲、温婉柔顺、狠辣凌厉、隐忍克制、天真烂漫等
- **发型标准**：真实古装发髻/旗头/盘发，鬓发碎发自然，杜绝假发感与僵硬造型。支持旗头钿子、高髻盘发、两把头、堕马髻、点翠头面、步摇流苏等多种宫廷发型
- **服饰标准**：古代宫廷着装体系——朝服（大典）、吉服（节日）、常服（日常）、行服（出行）、便服（私密）。朝服石青外褂配龙纹补子、吉服明黄或绛紫、常服素雅，丝绸/缂丝/锦缎面料纹理清晰，金线刺绣凸起反光，衣摆褶皱符合身体动态与重力
- **表情与体态**：微表情真实细腻（眼神、嘴角、眉宇、下颌的细微收放），肢体语言符合宫廷礼制（敛衽、万福、跪拜、躬身），杜绝僵硬摆拍感与浮夸戏剧化表情
- **人物气质维度**：威仪天成 / 端庄贤淑 / 清冷孤傲 / 温婉柔顺 / 狠辣凌厉 / 隐忍深沉 / 天真烂漫 / 老成持重

## 五、严禁内容（优先级最高）

本风格严格排除以下内容类型，确保视觉体系纯净统一：

1. **非真人质感**：3D渲染/CG建模/次世代游戏引擎/动画风格/手绘插画/水彩油画/二次元/Voxel/低多边形/赛璐璐等一切非真人实拍影像质感
2. **非古代宫廷世界观**：现代当代都市/民国/西方宫廷/和风日式/赛博朋克/科幻未来/星际太空等非中国古代宫廷背景
3. **仙侠法术与玄幻特效**：法术光效/真气流转/御剑飞行/玄幻粒子/灵力光环/水墨法术特效等一切玄幻CG特效（本风格为写实克制宫廷，宫廷中的"玄"靠氛围不靠特效）
4. **违反宫规服制**：龙袍乱穿、嫔妃越制、朝服错配、明显违反清代（或剧中设定朝代）服制礼法的造型
5. **非中国宫廷语境**：明显非中国古代宫廷特征的建筑、服饰、人物造型（如和服、韩服、欧式宫廷、哥特等）
6. **技术质量缺陷**：低分辨率/模糊/噪点/变形/畸形肢体/五官扭曲/比例失调/抠图感/塑料感/过度磨皮/假面感
7. **审美倾向违规**：过度高饱和/死亡荧光色/廉价滤镜感/过度HDR/脏乱差画面/刻意阴间色调/二次元平涂
8. **内容合规红线**：暴露/低俗/暗示性/暴力血腥/违法内容/歧视性表达/政治敏感元素

## 七、使用说明

### 提示词使用原则

1. **前缀先行**：所有生成内容必须首先加载"前缀提示词"中的全局风格锚定段，锁定真人古装宫廷写实质感基线
2. **专项叠加**：在全局前缀基础上，按需叠加角色/场景/道具/分镜专项提示词
3. **负面必加**：每次生成必须附带"负面提示词"，规避伪影与风格偏差
4. **迭代优化**：建议首轮生成后根据效果对专项提示词做微调，而非修改全局前缀
5. **平台适配**：本手册提示词优先适配Doubao-Seedream（生图）与Doubao-Seedance（视频生成），部分提示词可能需根据平台特性微调
