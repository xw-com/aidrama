## 一、摄影机前的情绪——面孔、眼神、微表情

> 真人古装宫廷写实的情绪不来自"法术光效"或"渲染参数"，而来自真人演员在摄影机前的微表情与礼法之下的眼神。以下映射面向摄影机捕捉真实宫中人的方式。

| 情绪输入 | 面容描述 | 眼神描述 | 微表情补充 |
|---|---|---|---|
| 威仪 / 沉稳 | 神情端凝，面部线条端正不紧绷，下颌微收 | 眼神深邃不怒自威，俯瞰式注视，喜怒难测 | 唇线平直，下颌微收，气场如山 |
| 隐忍 / 克制 | 眉眼不抬，面部肌肉收敛 | 目光低垂或平直不游移，将情绪压在眼底 | 嘴角自然平直，呼吸极轻，全身只有眼皮微动 |
| 温婉 / 柔顺 | 眉目舒展，面部柔和 | 眼神温润专注，像在认真听对方说话 | 嘴角自然含一丝温意，不是笑，是有温度 |
| 狠辣 / 凌厉 | 面部线条微绷，藏锋于笑 | 眼神锐利有寒意，眼尾上挑，注视时不躲闪 | 嘴角微扬似笑非笑，护甲轻叩有声 |
| 清冷 / 孤傲 | 眉眼疏淡，面部不苟 | 眼神疏离冷意，眼尾微挑，自带距离感 | 唇形小巧微抿，下颌线紧致 |
| 惊动 / 触动 | 眼尾微抬，眉峰微动 | 眼神骤然聚焦，瞳孔微扩 | 嘴角微启，花钿下眼神鲜活一瞬 |
| 沉思 / 内省 | 神情淡然，眼部周围肌肉放松 | 目光放远失焦，像在看但不在看 | 表情平静，可能单手持宫绢或护甲轻抵唇角 |
| 哀怨 / 凄清 | 眉宇微蹙，眼睑低垂 | 目光含怨含水，望向窗外月色或落叶 | 嘴角自然下沉，眼尾有未落之泪的微光 |
| 喜悦 / 鲜活 | 眼角出现自然笑纹，眼型微弯 | 眼神明亮有光，眼角有笑意牵动 | 嘴角上扬，面颊微红，表情生动但不夸张 |
| 决绝 / 坚定 | 面部线条清晰，下颌微抬 | 眼神笔直向前，不回避不躲闪 | 下巴微收或微抬，表情果敢但不凶悍 |
| 恐惧 / 慌乱 | 眉峰上挑，面色微白 | 眼神涣散游移，瞳孔收缩 | 嘴唇微颤，呼吸带动肩膀起伏明显 |

## 二、摄影机前的光——光源逻辑与氛围

### 2.1 宫中天光与灯火时刻

| 时刻 | 光源行为 | 色温与色调 | 空间氛围 |
|---|---|---|---|
| 清晨 | 低角度暖白晨光，通过殿窗/宫门斜入殿内；庭院飞檐投下长影、宫烟袅袅 | 3500-4500K暖白，空气微冷 | 肃穆初启、宫门刚启、一切尚未开始 |

## 四、摄影机语法——镜头选择与运动

### 4.1 焦段选择

| 焦段 | 叙事性格 | 适用场景 |
|---|---|---|
| 24-28mm广角 | 宫殿吞噬人物，殿宇威压，宫廷宏大与个体渺小 | 朝堂大全景、宫门甬道、冷宫空寂、宫墙深院 |
| 35mm小广角 | 主观视点，身临其境的礼法纪实感，人与宫廷共存 | 回廊穿行、寝宫对话、御花园跟随 |
| 50mm标准 | 人眼等价，客观中立的注视，最诚实的镜头 | 人物肖像、双人对话、朝服凝视 |
| 85mm中长焦 | 压缩空间，拉近情感距离，丝绸朝服与步摇细节突出 | 特写、步摇流苏、护甲、烛火下的面容 |
| 135mm+长焦 | 将人物从朱墙黄瓦中剥离，极端的注视或窥视 | 长廊尽头注视、宫墙后远眺、命运的距离感 |

### 4.2 景别选择

| 景别 | 取景范围 | 叙事功能 |
|---|---|---|
| 大特写 | 眼睛/嘴唇/护甲/步摇/朱笔/玉玺钤印 | 情绪爆发点、关键信息揭示、感官聚焦 |
| 近景 | 头顶至胸部以上 | 人物情感、对话反应、花钿点唇微表情 |
| 中近景 | 头顶至腰部 | 人物互动、敛衽/奉茶/递折手势 |
| 中景 | 头顶至膝盖上下 | 人物与殿宇的初级关系、多人同框 |
| 全景 | 人物全身+部分殿宇 | 人物在空间中的位置、行动路线、朝服全貌 |
| 大全景/空镜 | 宫殿全貌，人物极小或无人物 | 空间叙事、情绪缓冲、隐喻留白 |

### 4.3 摄影机运动

| 运动方式 | 视觉心理 | 使用场景 |
|---|---|---|
| 固定 | 礼法庄严，让时间自己说话 | 朝堂、典礼、对话、空殿留白 |
| 手持微晃 | 暗涌在场感，宫斗呼吸感，主观介入 | 宫斗冲突、跟踪密会、情绪波动 |
| 稳定器流动 | 优雅的回廊纵深，宫廷的仪式诗 | 人物登场、回廊纵深跟拍、册封大典 |
| 缓推 | 注意力逐渐聚焦、情绪趋近 | 对话升温、真相逼近、情感推进 |
| 缓拉 | 拉开距离、揭示全貌、情绪抽离 | 离别、章节收束、空间展示 |
| 跟拍 | 与人物同行、主观陪同 | 回廊穿行、宫中行走、朝堂跟随 |
| 摇镜 | 视线转移、空间关系交代 | 人物视线引导、殿宇纵深关系 |

## 五、固定风格锚定词

**摄影锚定（必选）：**

真人实拍摄影，真人电影剧照，中国古代宫廷，电影级摄影，宫灯烛火与自然天光调度，真实色彩科学

**人物质感（含人物镜头时必选）：**

真人写实摄影质感，真实皮肤纹理毛孔可见，古装妆容与皮肤融合，不磨皮不硅胶脸，旗头钿子/发髻真实发质有鬓发碎发，丝绸朝服金线刺绣凸起反光有衣摆褶皱，礼法体态，克制微表情

**场景质感（含场景镜头时必选）：**

真人实拍宫廷场景摄影，真实宫殿材质和岁月痕迹（朱墙剥落/琉璃积尘/金箔氧化/青砖磨损/檀木包浆），光源方向明确可追溯，大气透视自然，非样板殿非效果图

**参考图一致性锚定（参考图模式必选）：**

保持人物造型、面容、旗头发髻、朝服首饰与参考图完全一致，保持场景风格与参考图一致，保持光影色彩基调统一，所有镜头呈现为同一人物的连续摄影记录

**风格收尾（固定）：**

真人写实摄影，中国古代宫廷电影质感，电影级摄影画面，非3D非渲染非CG

## 六、美学禁止项

以下词汇/风格不得出现于输出提示词中：

- ❌ 3D渲染 / 3D建模 / CG / UE引擎 / Blender / PBR材质 / 次世代建模 / 体积光 / 环境光遮蔽 / 光线追踪
- ❌ 2D手绘 / 插画 / 动画 / 二次元 / 漫画 / Q版 / 赛璐璐 / 低多边形
- ❌ 写实摄影（英文禁止 photorealistic / realistic photography——本风格是"真人实拍摄影"live-action cinematic photography，不是"拟真渲染"）
- ❌ 过度磨皮 / 塑料假面 / 零毛孔 / 硅胶脸 / 蜡像感 / AI感平滑 / 妆容像贴图
- ❌ 仙侠法术 / 玄幻特效 / 真气流转 / 御剑飞行 / 法术光效 / 灵力光环 / 水墨法术特效
- ❌ 现代当代都市 / 民国 / 西方宫廷 / 和风日式 / 赛博朋克 / 科幻 / 西方奇幻 / 中世纪
- ❌ 平面印花冒充刺绣 / 平面金线
- ❌ 人体结构错误 / 肢体畸形 / 面部崩坏 / 比例失调
- ❌ 高饱和荧光色 / 霓虹溢色 / 廉价滤镜感 / 二次元平涂
- ❌ 非中国宫廷的架空场景 / 西式城堡 / 日式城堡 / 无辨识度的 generic palace
