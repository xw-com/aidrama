# 校园动漫约束 · 现代校园动漫 · 技法参考

---

## 一、色调体系与画面基调

- **色调基底** — 全片以通透肤色（C1）、天空白（C2）、阳光金（C3）为基底色，整体色温中性偏暖（5500-6000K），饱和度中等（60-75%），呈现现代赛璐璐动画的明亮通透感。全片保持清新明亮色调基底，局部点缀暖光（阳光金 C3、樱草粉 C5）与冷调（透明蓝阴影 C10）增加层次
- **冷暖叙事对比** — 冷色（天空白 C2、透明蓝阴影 C10）作为叙事转折的视觉信号，用于雨天或情绪低谷段落局部点缀。冷暖切换应与故事弧线同步，而非随意混用
- **色盘先行原则** — 段落规划需先绑定情绪场景（日常/心动/黄昏/雨天等），再确定主色+辅色与光影方案，避免"剧情对了但情绪不对色"
- **禁用色域** — 高饱和荧光色、霓虹色、90年代做旧泛黄色、暗调黑暗色彩体系均与本风格不兼容

---

## 二、光影方案体系

- **光影即叙事** — 6 套光影方案对应不同情绪段落，导演规划阶段应在段落层面确定光影基调方向，而非逐镜指定
- **光源角度** — 默认 30-45°斜侧光，模拟自然光效果，强调通透空气感

| 情绪段落 | 光影方向 | 色调倾向 | 适用阶段 |
|---|---|---|---|
| 日常校园 | A·明亮漫射 | 天空白底 + 通透柔光 | 全片 |
| 心动瞬间 | B·暖调侧光 | 樱草粉 + 阳光金局部 | 升温段 |
| 天台/午休 | C·顶光+环境光 | 天空白 + 草坪绿 | 开阔段 |
| 黄昏放学 | D·逆光暖调 | 阳光金主导 + 薄暮紫背景 | 甜蜜段 |
| 雨天走廊 | E·漫射冷光 | 透明蓝阴影主调 + 暖色局部点缀 | 忧郁段 |
| 夜晚校园 | F·路灯暖光 | 校园海军蓝主调 + 暖光点缀 | 夜晚段 |

- **冷暖光分配** — 明亮暖色调贯穿全片可用，根据场景需要灵活调整；冷色调（透明蓝阴影主调）仅在雨天、夜晚或情绪低谷后使用
- **氛围方向映射** — 每场戏的氛围方向应能映射到上述光影方案（A-F）的某一方向，确保视觉一致性

---

## 三、质感方向

- **赛璐璐通透感** — 现代数字赛璐璐动画的核心：线条通透流畅、上色清新均匀、光影空气感分明
- **清晰线稿 + 通透上色** — 这是画面质感的锚点。不是胶片颗粒，不是90年代做旧，不是写实厚涂
- **通透不等于寡淡** — 本风格强调现代赛璐璐的质感表达（通透线稿、清新上色、空气感光影），通过构图与情绪设计放大感染力，而非依赖复杂特效
- **空气感是灵魂** — 玻璃反光、尘埃光柱、耀斑光晕、远景浅化等空气感元素是校园动漫区别于其他风格的关键，每个镜头都应安排至少一处空气感细节

## 四、校园场景空间元素

现代校园动漫特有的场景元素及其视觉叙事功能：

- **窗框/门框/走廊** — 天然的框架式构图道具，制造"看不透"的层次感与空间纵深，窗格光斑是本风格标志性符号
- **教室/天台/放学路** — 青春感的天然载体，景即情：教室窗边阳光 = 青春日常、天台开阔天空 = 自由向往、黄昏放学路 = 怀念成长
- **樱花/银杏/雨幕** — 留白构图的天然载体，景即情：满树樱花 = 心动、银杏落叶 = 时光流逝、雨中走廊 = 思念
- **夕阳/天光/路灯** — 校园动漫的光源载体，夕阳 = 暖/怀念（方案D）、天光 = 明亮日常（方案A/C）、路灯 = 夜晚静谧（方案F）
- **段落间用场景空镜过渡** — 本风格有丰富的场景资产（不同时段/天候/天气变体），段落衔接建议用场景空镜做情绪缓冲，不要硬切
- **转折点用视觉而非台词** — 优先使用画面手段（光影突变、景别跳切、空镜隐喻）而非依赖对白解释

## 五、校园动漫乐器与环境音

现代校园动漫世界观下的声音元素约束：

### 乐器选择

- **钢琴** — 日常/温馨/回忆段落的核心乐器，最能表现校园动漫的质感
- **吉他** — 轻松/浪漫/放学路段落，扫弦的清新感适合青春氛围
- **轻弦乐铺底** — 情感升华/离别段落，拉弦的细腻感适合情绪过渡
- **口风琴/尤克里里** — 社团/活泼/回忆段落，轻快音色适合青春日常

### 乐器组合策略

| 情绪阶段 | 乐器组合 |
|---|---|
| 平稳/开场/收尾 | 钢琴独奏 或 口风琴独奏 |
| 日常温馨 | 钢琴 + 轻吉他 |
| 情绪升华/浪漫 | 弦乐 + 钢琴 |
| 活泼/社团 | 尤克里里 + 吉他 |

### 校园环境音

- **典型环境音层次** — 教室翻书声 / 走廊脚步回声 / 操场远处喧闹 / 风吹过树叶 / 上课铃声 / 电车驶过 / 蝉鸣鸟叫 / 雨打窗玻璃
- **每场戏标注 1-2 个核心环境音**，帮助后续音效设计。环境音层次越丰富，校园场景越有沉浸感
- **留白比配乐更重要** — 关键情感瞬间（对视、转身、离别）优先考虑去掉配乐，只留环境音（风声、铃声、脚步声），让观众自己感受情绪
- **避免满配** — 全片配乐覆盖率建议不超过 50%。留白段落的"无声"与配乐段落形成呼吸感，突出真实情感
