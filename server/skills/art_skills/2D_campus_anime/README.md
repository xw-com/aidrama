# 校园动漫风格说明

本风格专为"现代校园日常动画质感"题材打造，所有美术提示词、规范和生成内容均严格限定于：

- **现代校园世界观**：以当代校园日常为背景，涵盖教室、走廊、天台、社团室、图书馆、放学路、便利店、电车站等，体现青春校园生活气息。
- **现代赛璐璐质感**：所有角色、场景、道具均以现代数字赛璐璐动画为标准，强调通透光影、空气感氛围、明亮清新的色彩层次。
- **青春治愈美学**：在赛璐璐基础上追求空气感氛围与电影感光线，画面色调明亮通透，细节丰富，整体氛围清新治愈、青春温暖。
- **情感表达**：适合展现青春友情、朦胧恋爱、校园成长故事，强调光与空气感下的少年少女情感表达。

## 适用范围

- 现代校园动漫题材的AI美术生成（角色、场景、道具、分镜等）
- 需要极致空气感光影、清新通透氛围、青春治愈气质的视觉创作

## 严禁内容

- 90年代复古手绘质感、胶片颗粒、做旧泛黄
- 3D渲染、CG动画、写实厚涂
- 暗黑成人向、血腥暴力、恐怖惊悚
- 高饱和荧光色、霓虹赛博、赛博朋克
- 重阴影、暗调、过度对比

## 风格体验

在本风格下，您将体验到：

- 角色面容清透、气质明亮或温柔，服饰、发型均为现代校园日常风格
- 场景空间通透、空气感强烈，窗光、天光、夕阳光形成清新光影层次
- 道具、日常物品、校园器具均为现代造型，质感清透，工艺精致
- 分镜与画面均以现代赛璐璐为基底，强调光、空气与青春叙事表达

---

本风格仅适用于"现代校园动漫"相关项目。如需其他风格（如90年代复古、CG、插画、写实等），请勿使用本套提示词。
