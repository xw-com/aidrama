# 现代校园动漫风格 - 人物基础形象生成 · 约束手册

---

## 一、基础形象原则

1. **通透即灵魂** — 数字赛璐璐质感与空气感光影为角色核心，追求明亮清透的现代动画质感
2. **角色为本** — 基础着装由角色描述（身份/职业/性别/场景）决定其常规着装；后续特定服化为叠加层
3. **四视图一致** — 面容/体型/发型/基础服装跨视图高度统一
4. **青春气质克制** — 无妆状态需体现角色气质（明朗/温柔/安静/活力）

---

## 二、面容约束

> 不再固定五官特征参数，由角色描述（性别/年龄/性格/气质）驱动 AI 自由生成五官，保证人物间外观差异化。

### 通用要求

| 项目 | 约束 |
|---|---|
| 五官 | 由角色描述自然推导，不预设脸型/眼型/眉型/鼻型/唇型 |
| 风格底色 | 现代校园动漫数字赛璐璐质感（通透光影、清新色彩、空气感高光） |
| 气质 | 必须从角色描述提炼整体气质关键词（如明朗/温柔/安静/活力），并写入提示词 |
| 表情 | 中性微表情，符合角色气质 |

## 六、基础服装约束

> 基础服装由角色描述（身份/职业/性别/场景）决定其最自然的常规着装，作为该角色「日常默认态」；正式服饰/特殊衍生在服化衍生环节叠加。**禁止内衣打底**。

### 着装选择原则

| 角色身份 | 默认着装方向 |
|---|---|
| 中学/高校学生 | 现代校服（西装制服/水手服/运动校服） |
| 大学生 | 休闲学院风（衬衫+针织开衫/T恤+牛仔裤） |
| 居家/休闲 | 现代休闲服（卫衣/T恤/棉质家居服） |
| 运动/活泼 | 运动套装 / 校服运动款 |
| 教师/职员 | 现代职业便装（衬衫+西裤/半裙） |
| 角色描述未明确 | 现代校园日常常服 |

### 着装统一规则

- 服装风格须与现代校园动漫美学一致（清新色彩、通透质感、空气感光影）
- 颜色清新明亮，无复杂花纹/装饰，便于后续衍生叠加
- 四视图服装款式完全一致
- 基础服装是「日常默认态」，焦点仍在面容与体态
- 严禁内衣/暴露/性化打底

## 八、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须为「素颜无妆」状态 |
| R2 | 必须根据角色描述声明合适的常规着装作为基础服装（如学生→现代校服、大学生→学院风休闲、居家→现代休闲服）；禁止内衣打底 |
| R3 | 必须声明「无发饰、无配饰」 |
| R4 | 必须指定「通透浅蓝白背景 #EAF4FB」 |
| R5 | 必须指定「四视图一致性」 |
| R6 | 全身立像必须从头到脚完整展示，严禁裁切 |
| R7 | 必须指定角色身高并通过头身比换算约束全身比例（女性默认155-165cm/6.5-7头身，男性默认170-180cm/7-7.5头身） |
| R8 | 人像特写必须从头顶到锁骨完整展示，严禁裁切头顶 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 内衣/暴露/性化打底；与角色描述明显不符的着装；过度复杂花纹/装饰干扰后续服化叠加 |
| X2 | 90年代复古质感、胶片颗粒、做旧泛黄 |
| X3 | 过度美白至无血色或厚涂写实肤感 |
| X4 | 复杂场景背景（必须通透浅蓝白背景） |
| X5 | 夸张变形表情/Q版比例/动态姿势 |
| X6 | 全身立像裁切头顶或脚底，必须从头到脚完整入画 |
| X7 | 人像特写裁切头顶，必须从头顶到锁骨完整入画 |
| X8 | 忽略身高和头身比约束 |
