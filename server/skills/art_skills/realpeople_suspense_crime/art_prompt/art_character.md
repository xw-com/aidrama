# 真人悬疑刑侦人物基础形象生成 · 约束手册

## 一、选角逻辑——摄影机前的刑侦里的人

> 3D角色的起点是"建一个模型"；真人悬疑刑侦的起点是"选一个被疲惫、压力、秘密、执念打磨过的人站在摄影机前"。以下原则不从建模出发，而从选角和拍摄出发。

1. **面孔即案情** — 一张脸就是一份未被结案的卷宗。悬疑刑侦不追求"完美的五官"，而追求"值得被审讯室顶灯凝视的五官"——有故事感的眼袋、有秘密的回避眼神、有压力的紧绷嘴角、有熬过夜的暗沉
2. **疲态即真实** — 刑侦叙事需要的是"看起来像三天没睡的刑警"、"像被生活逼到墙角的嫌疑人"。疲态是本风格最重要的真实证据：眼袋、暗沉、胡茬青影、冷白或暗沉的肤色、眼周微暗——这些不是缺陷，是"这个人活在案件里"的证明
3. **体态说真话** — 真实的站姿不是对称的——疲惫的塌肩、戒备的微缩、审讯时的前倾、被抓捕时的僵硬。杜绝模特式对称站姿和军人式立正体态
4. **同一人物跨角度可辨认** — 正面/侧面/背面/特写四角度必须呈现为同一个人的摄影记录，而非四个相似的人。核心识别点：颌骨轮廓、鼻梁转折、耳廓形状、发际线走向、胡茬分布
