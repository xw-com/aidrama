# 真人悬疑刑侦道具图像生成 · 约束手册

---

## 一、道具设计原则

> 真人悬疑刑侦的道具不是"被建模的物体"，而是"被使用过、承载过案情、被某人佩戴或翻阅过的物品"——它在某个刑警腰间挂过、在某个审讯桌上放过、在某个证物袋里封过。摄影机拍下的是它的此刻。

1. **物品即案情** — 每一件道具都是一个微型的案情容器。手铐的划痕暗示反复使用、卷宗的折角暗示被反复翻阅、咖啡杯的烟灰暗示又一个不眠之夜、警官证的磨损暗示多年执勤
2. **使用痕迹优先于完美品相** — 真人悬疑刑侦的道具必须有"被用过"的证据。全新的、刚拆封的、样板级别的道具一律不出现——警用装备有执勤磨损、卷宗纸张有翻阅痕迹、不锈钢有氧化划痕
3. **中国当代刑侦真实物品** — 道具必须是中国刑侦工作中真实存在的物品：中文警官证、中国警徽、中文卷宗档案、中国式证物袋、中文路牌、中国警用对讲机——拒绝无国别的架空警用物品、拒绝美剧式道具
4. **材质即真实** — 不是PBR参数渲染出的材质，而是摄影机拍下的真实材质行为：不锈钢的冷反光与划痕、金属戒具的氧化、卷宗纸张的泛黄纤维、塑料证物袋的透明折痕
5. **单视图静物摄影** — 道具以单张静物产品摄影方式独立呈现，非多角度建模展示，非2×2四宫格

## 三、单视图静物摄影规范

> 真人悬疑刑侦道具仅需单张静物产品摄影，非多角度建模展示。以下为单视图摄影的完整规范。

### 画面构成

| 项目 | 摄影要求 |
|---|---|
| 道具呈现 | 道具居中或偏三分线位置独立陈列，完整入画，无裁切 |
| 背景 | 素灰无缝背景纸 #B0B0B0（哑光），或深灰台面/不锈钢台面/深色桌面（暗调静物，与悬疑基调匹配），根据道具属性选择。无多余物体、无装饰、无文字（除道具自带中文标识） |
| 光线 | 单灯柔光或顶灯硬光（与悬疑基调匹配）。柔光箱顶+侧补（产品摄影级均匀光线）、或单顶灯硬光下压（强悬疑感，致敬审讯室光）。光影方向明确，金属有冷反光，暗部压深但有层次 |
| 景深 | 浅景深（f/2.8-f/5.6），道具主体清晰锐利，前后微虚化突出主体 |
| 投影 | 道具底部与承载面之间的自然接触阴影——真实的而非抠图或悬浮。阴影方向与主光源一致，金属道具的投影冷硬 |
| 画面比例 | 建议 1:1 正方形或 4:3，适配单件道具展示 |

### 道具状态准则

| 维度 | 要求 |
|---|---|
| 使用痕迹 | 必须有"被执勤/办案使用过"的视觉证据——非全新未拆封、非样板品相 |
| 中国辨识度 | 中文标识（警官证/卷宗/警戒带/车牌/检验报告）、中国警徽、中国警用装备——拒绝无国别架空警用物品 |
| 材质真实感 | 非渲染质感——是摄影机拍下的真实材料行为（光的反射、漫射、金属氧化、纸张泛黄） |
| 克制专业 | 涉及血迹/死亡/伤痕的道具须克制、专业、去情绪化呈现——非恐怖片式渲染 |
| 尺度感 | 通过材质纹理密度、工艺细节暗示实物尺寸，无需参照物 |

| R1 | 必须是「单张静物摄影」——单视图、非多角度、非2×2四宫格、非建模展示 |
| R2 | 必须指定「素灰背景纸 #B0B0B0」或「深灰/不锈钢台面」等真实暗调桌面，禁止复杂场景 |
| R3 | 必须指定光源逻辑——柔光箱或顶灯硬光，光影方向明确、投影自然、与悬疑基调匹配 |
| R4 | 道具必须有「执勤/办案使用痕迹」——非全新、非样板品相、非未拆封 |
| R5 | 道具必须具备中国当代刑侦辨识度——中文标识/中国警徽/中国警用装备/中文卷宗 |
| R6 | 必须声明「实物产品摄影 + 非3D渲染非CG」核心锚定 |
| R7 | 材质必须描述为摄影机下的真实表现，而非渲染参数 |
| R8 | 涉及血迹/死亡/伤痕的道具必须「克制专业、去情绪化」呈现，非恐怖片式渲染 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 严禁「3D渲染 / 3D建模 / CG / UE引擎 / Blender / PBR材质」等一切CG术语 |
| X2 | 严禁「2D手绘 / 插画 / 动画 / 二次元」等非摄影媒介 |
| X3 | 严禁「多角度 / 四视图 / 2×2网格 / 正交视图 / turnaround / blueprint」——仅单张 |
| X4 | 严禁「全新未拆封 / 样板品相 / 无使用痕迹 / 完美品相」的道具 |
| X5 | 严禁「古风/古代/仙侠/武侠/民国/赛博朋克/科幻/校园/豪门奢华/西方奇幻/架空」等非悬疑刑侦物品 |
| X6 | 严禁「无中国辨识度的架空警用物品 / 全英文标识 / 美剧式警用道具」 |
| X7 | 严禁「出现人物/手部/手指/肢体」 |

| X11 | 严禁「水印 / 文字 / LOGO / 签名 / 边框 / AI生成痕迹」（道具自带中文标识除外） |
