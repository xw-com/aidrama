# 真人悬疑刑侦场景图像生成 · 约束手册

---

## 一、场景美学原则

> 真人悬疑刑侦的场景不是"被建模的空间"，而是"被摄影机选中的、发生过或即将发生案件的场所"。没有渲染引擎、没有贴图、没有体积光参数——只有实际存在的光、真实的混凝土与不锈钢、以及中国刑侦空间的冷峻日常。

1. **空间即案卷** — 一个空无一人的审讯室不是"空的"，是刚结束一场审讯。桌上还没收走的纸杯、椅子的斜角、单向玻璃后的暗影——空间自己会讲案情
2. **真实的光，不是渲染的光** — 场景的光只有一个来源：实际的顶灯（审讯室/解剖室/监控室）、实际的街灯与手电（室外夜间）、实际的自然光（厂房天窗/车库高窗）。光的色温和方向必须在物理上说得通，且必须服从低调暗调基调
3. **被使用过/被案件发生过** — 真实的刑侦场景不整洁。审讯室墙面有磨损、警局工位堆满卷宗与烟灰缸、案发现场拉起警戒带留下凌乱、废弃厂房积灰积水。一个完全没有痕迹的空间是样板间，不是刑侦现场
4. **中国当代刑侦的真实场所** — 场景必须有中文标识、中国刑侦特征（警徽/警官证/中文卷宗/中国式警局布局/中文路牌）。这不是"generic crime scene"，这是"当代中国刑侦的一个具体角落"
5. **单视图全景全貌** — 一张照片装下整个场地的完整信息。广角或标准焦段，全景深，正面展示空间的全貌与纵深——不是四视图分割，不是多角度拼贴

## 二、时刻与光线方案——光源即审讯者

> 真人悬疑刑侦场景的光，首先由时刻和光线方案共同决定。审讯室、解剖室、监控室的光几乎不随自然时刻变化——它们被人工光源定义；而室外现场、废弃厂房、雨夜街巷则受自然时刻与天气强烈影响。以下是真实光源在关键光线方案与时刻下的摄影行为。

| 光线方案 | 时刻/条件 | 光的行为 | 场景氛围词 |
|---|---|---|---|
| A 审讯硬光 | 审讯室（任意时刻） | 单顶灯冷白5000-5500K垂直下压硬光，光斑只覆盖桌椅区，四周压暗至全黑，光比1:8极端高反差 | 压迫、对峙、真相逼近、半张脸的阴影 |
| B 雨夜街灯 | 雨夜/雨后夜间 | 湿路面反射街灯暖光斑2800K，冷蓝环境漫射6000K，雨幕散射，警灯红蓝偶尔扫过 | 孤独、压抑、街灯下的孤立身影 |
| C 手电探光 | 暗巷/废弃厂房/夜间现场 | 单束手电硬光穿透黑暗，光束在浮尘/雨雾中可见体积感，照亮区之外全黑 | 紧张、未知、搜索、潜入 |
| D 监控屏冷光 | 监控室/技侦（任意时刻） | 多块监控屏冷蓝白5500-6500K为主光源，幽暗环境，屏光映在值守脸与控制台 | 窥视、技术侦查、屏幕面光 |
| E 无影灯解剖 | 解剖室/检验室（任意时刻） | 无影灯冷白5500-6500K顶光均匀无阴影，不锈钢台面冷反光，环境去情绪化 | 客观、专业、冷静、不锈钢冷反光 |
| F 暗巷钠灯 | 老旧暗巷/城中村夜间 | 单点老旧钠灯2000-2200K暖橙黄，光斑有限范围之外全黑，四周沉入深暗 | 危险、潜伏、线人接头、未知 |
| G 废弃厂天窗 | 废弃厂房（日间） | 脏污天窗透下漫射日光5500-6500K，光柱穿过浮尘形成可见光束，地面斑驳积水反光 | 空旷、回响、藏匿现场、命案抛尸 |
| 日间天光（辅助） | 案发现场日间/警局日间 | 日光从窗/门斜入，冷白清澈，阴影锐利，材质清晰——但整体仍偏冷峻去饱和 | 秩序建立、勘查进行、客观记录 |
| 荧光灯管（辅助） | 警局走廊/车库/停尸房（任意时刻） | 荧光灯管冷白4000-5000K偏青，可能有频闪感，工业冷峻 | 冷硬、孤寂、回响、专业冷静 |
| 深夜孤岛（辅助） | 警局深夜/单工位深夜 | 仅一盏台灯/屏幕光/手电的单一光源，大部分区域沉入暗部 | 孤独、私密、不眠不休、执拗 |

## 五、单视图全景摄影规范

> 真人悬疑刑侦场景仅需**单张**全景摄影——一张照片装下整个空间的完整信息。不是2×2四视图，不是多角度拼接。

### 画面构成

| 项目 | 摄影要求 |
|---|---|
| 空间呈现 | 单张照片完整呈现场景的空间全貌。使用24-28mm广角或35mm，全场地的纵深、宽度、高度在一张画面中全部可见 |
| 构图 | 全景深大景别——前景（门框/桌沿/铁栅/警戒带）形成天然画框→中景是场地主体→后景向空间纵深或单向玻璃/走廊/窗外延伸 |
| 景深 | 全景深 f/8-f/11，从前到后全部清晰。这不是人像摄影——场景的每一个角落都应该能被看见，暗部要"黑得有内容" |
| 人物 | **严禁出现任何人物、人影、人体轮廓。** 场景是空的——但这种"空"有案情叙事：刚结束审讯/即将勘查/案发后的封锁/熬夜办公的间歇 |
| 比例 | 建议 16:9 或 2.39:1 宽幅——匹配悬疑题材的横向压迫视觉习惯 |
| 色彩 | 由实际光源的色温驱动，不套滤镜。整体冷峻去饱和，暗部压深。色彩科学参考ARRI Alexa/Sony Venice电影色调，略偏冷调 |

### 空的场景如何叙事

| "空"的类型 | 画面线索 | 叙事暗示 |
|---|---|---|
| 刚结束审讯 | 审讯桌上的纸杯没收走、椅子斜角、单向玻璃后的暗影、顶灯还亮 | 刚才一场审讯结束，嫌疑人被带走 |
| 即将勘查 | 勘查箱就位、编号牌备好、警戒带刚拉好、相机三脚架支起 | 有人马上要进入现场，现在是封锁后的静止 |
| 案发后封锁 | 凌乱的现场痕迹、警戒带围起、编号物证、手电光束 | 这里发生过案件，正在等待勘查 |
| 熬夜办公的间歇 | 工位上堆满卷宗、烟灰缸堆满烟蒂、咖啡杯凉透、白板线索图写满、屏幕还亮 | 刑警熬了一夜刚离开工位 |
| 深夜的场所 | 空荡走廊只有荧光灯亮着、监控室屏光闪烁、地下车库回响 | 城市与警局都半睡着，但工作没停 |
