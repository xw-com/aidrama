# 分镜提示词 · 真人悬疑刑侦 · 风格专属技法

---

## 适用范围

本 Skill 专用于**真人悬疑刑侦**风格的分镜提示词生成，适配悬疑、犯罪、刑侦、法医、缉毒、反黑等真人实拍影视题材的分镜创作。

## 一、摄影机前的情绪——面孔、眼神、微表情（疲态在场）

> 真人悬疑刑侦的情绪不来自"义体光效"或"渲染参数"，而来自真人演员在摄影机前被压力、疲惫、秘密、执念刻画出的微表情。以下映射面向摄影机捕捉真实刑侦人物的方式。

| 情绪输入 | 面容描述 | 眼神描述 | 微表情补充 |
|---|---|---|---|
| 沉稳 / 老练 | 神情沉稳，面部线条自然不紧绷，可见疲态 | 眼神笃定深邃，直视前方不飘忽，有阅历的洞察 | 唇线平直，下颌微收，气场克制；可能有烟灰抖落 |
| 戒备 / 警觉 | 面部线条微微绷紧，不夸张 | 眼神锐利扫视，余光观察四周 | 下颌收紧，身体微缩成防御姿态，手部接近腰间 |
| 阴鸷 / 算计 | 面部冷硬，嘴角可能有极细微冷笑 | 眼神阴冷深沉，注视时让人不安 | 下颌微抬，表情克制，偶尔喉结滚动 |
| 紧张 / 心虚 | 面部僵硬微泛白或冒油 | 眼神躲闪不定，频繁回避直视 | 嘴角紧抿下垂，额间薄汗，手指不自觉摩挲 |
| 疲惫 / 倦怠 | 眼窝深陷带眼袋，面部整体松弛暗沉 | 目光朦胧，眼皮微沉，血丝眼 | 眉眼低垂，明显黑眼圈，可能夹着烟的手在抖 |
| 压迫 / 施压 | 面部线条清晰有力，下颌微抬 | 眼神笔直锐利，不回避地盯住对方 | 嘴角紧抿，身体前倾，气场下压 |
| 正义 / 执拗 | 面部紧绷有克制，眉宇紧锁 | 眼神坚定发亮，直视不躲 | 下颌微抬，唇微抿，身体挺直 |
| 惊触 / 动摇 | 眼尾微抬，眉毛自然上扬 | 眼神骤然聚焦，瞳孔微扩 | 嘴角微启，呼吸停顿半拍 |
| 决绝 / 果断 | 面部线条清晰，下颌微收 | 眼神笔直向前，不回避不躲闪 | 下巴微收或微抬，表情果敢 |
| 恐惧 / 崩溃 | 面部惨白肌肉失控 | 目光涣散失焦，瞳孔骤扩 | 嘴角颤抖，呼吸急促，可能伴随眼泪 |

## 四、摄影机语法——镜头选择与运动

### 4.1 焦段选择

| 焦段 | 叙事性格 | 适用场景 |
|---|---|---|
| 24-28mm广角 | 空间包围人物、压迫与渺小、幽闭窒息 | 审讯室全景、案发现场全貌、废弃厂房、嫌疑人被包围 |
| 35mm小广角 | 主观视点、临场纪实感、对峙的在场 | 审讯对话、抓捕现场、街头跟踪、室内搜查 |
| 50mm标准 | 人眼等价、审讯者的客观凝视 | 人物肖像、审讯近景、双人对话、线索凝视 |
| 85mm中长焦 | 压缩空间、窥视感、半张脸沉阴影的特写 | 审讯特写、嫌疑人面部、单向玻璃窥视、街对面盯梢 |
| 135mm+长焦 | 极端压缩、追踪感、将人物从黑暗剥离 | 远距离盯梢、长焦跟踪、心理距离的物理化 |

### 4.2 景别选择

| 景别 | 取景范围 | 叙事功能 |
|---|---|---|
| 大特写 | 眼睛/嘴唇/手指/手铐咔合/证物细节 | 情绪爆发点、关键证据揭示、感官聚焦 |
| 近景 | 头顶至胸部以上 | 审讯博弈、情感反应、半张脸的阴影 |
| 中近景 | 头顶至腰部 | 对峙互动、手铐/警官证/对讲机入画 |
| 中景 | 头顶至膝盖上下 | 审讯桌两侧对峙、案发现场人物站位 |
| 全景 | 人物全身+部分环境 | 空间压迫、人物被包围/孤寂 |
| 大全景/空镜 | 空间全貌，人物极小或无 | 空间案情叙事、情绪缓冲、隐喻留白 |

### 4.3 摄影机运动

| 运动方式 | 视觉心理 | 使用场景 |
|---|---|---|
| 固定 | 冷静凝视、审讯者的不动、压迫累积 | 审讯室、案发现场、空镜留白、线索凝视 |
| 手持微晃 | 在场感、紧张不安、临场感 | 抓捕行动、搜查、情绪波动、街头跟踪 |
| 缓慢推进 | 真相逼近、施压、心理压缩 | 审讯升温、关键证物揭示、嫌疑人崩溃 |
| 缓慢拉远 | 揭示全貌、抽离、孤立放大 | 离开案发现场、章节收束、人物被黑暗吞没 |
| 跟拍 | 与人物同行、追踪主观陪同 | 街头盯梢、暗巷追击、夜间蹲守 |
| 摇镜 | 视线转移、空间关系交代 | 审讯者扫视、白板线索图巡视 |

## 五、固定风格锚定词

**摄影锚定（必选）：**

真人实拍摄影，真人电影剧照，当代中国悬疑刑侦，电影级摄影，低调暗调高反差光源调度，真实色彩科学，冷峻去饱和

**人物质感（含人物镜头时必选）：**

真人写实摄影质感，真实皮肤疲态（眼袋/暗沉/胡茬），毛孔可见，不磨皮不硅胶脸，发丝被汗雨打湿有碎发，便装制服面料纹理可见有穿着褶皱，自然微表情，真实肢体语言

**场景质感（含场景镜头时必选）：**

真人实拍悬疑刑侦场景摄影，真实混凝土墙面水渍裂缝/不锈钢氧化划痕/软包墙面磨损，光源方向明确可追溯（审讯顶灯/街灯/手电/屏光），低调暗调，非样板间非效果图

**参考图一致性锚定（参考图模式必选）：**

保持人物造型、面容、发型、服饰与参考图完全一致，保持场景风格与参考图一致，保持光影色彩基调统一，所有镜头呈现为同一人物的连续摄影记录

**风格收尾（固定）：**

真人写实摄影，当代中国悬疑刑侦电影质感，电影级摄影画面，非3D非渲染非CG

**画质锁定词：**

模式A（中文）——默认：
真人摄影高清画质，电影级画面质感，低调暗调高反差，画面无字幕、无水印、无标题叠字、无UI元素

模式A（中文）——画内文字场景（画面中含警官证/卷宗/警戒带/路牌/屏幕等道具文字时）：
真人摄影高清画质，电影级画面质感，低调暗调高反差，画面无字幕、无水印、无标题叠字、无UI元素，警官证/卷宗/警戒带/路牌/屏幕等场景道具上的中文清晰可辨

模式B（英文）——默认：
live-action cinematic photography, real human skin texture with eye bags and stubble, contemporary Chinese criminal investigation, cinematic color science, low-key dark tone with high-contrast lighting, desaturated cool palette, high detail, no subtitles, no captions, no watermark, no title overlay, no UI elements

## 六、美学禁止项

以下词汇/风格不得出现于输出提示词中：

- ❌ 3D渲染 / 3D建模 / CG / UE引擎 / Blender / PBR材质 / 次世代建模 / 体积光 / 环境光遮蔽 / 光线追踪
- ❌ 2D手绘 / 插画 / 动画 / 二次元 / 漫画 / Q版 / 低多边形
- ❌ 写实摄影（英文禁止 photorealistic / realistic photography——真人悬疑刑侦是"真人实拍摄影"live-action cinematic photography，不是"拟真渲染"）
- ❌ 过度磨皮 / 塑料假面 / 零毛孔 / 硅胶脸 / 蜡像感 / AI感平滑 / 精神饱满妆容精致
- ❌ 古风 / 古装 / 汉服 / 仙侠 / 武侠 / 民国 / 宫廷 / 赛博朋克 / 科幻 / 机甲 / 校园 / 豪门奢华 / 西方奇幻 / 中世纪
- ❌ 明亮高调治愈调 / 廉价恐怖片蓝绿调 / 高饱和荧光色 / 霓虹溢色 / 廉价滤镜感
- ❌ 渲染性血腥 / 恐怖惊悚剥削 / 尸体特写 / 恶心器官展示 / 廉价恐怖片调色
- ❌ 人体结构错误 / 肢体畸形 / 面部崩坏 / 比例失调
- ❌ 非中国当代刑侦的架空犯罪场景 / 无中文标识的 generic crime scene / 美剧式警用道具
