## 一、分镜表定位

分镜表是导演将剧本转化为镜头语言的核心工具。本约束面向 Seedance 2.0 视频生成，所有光影、动作、空间描述均采用模型可执行的具象语言。不做抽象的情感概括，不写模型看不懂的渲染参数。

## 三、光影与氛围——Seedance 2.0 物理光源描述

### 3.1 同场戏光影统一

一场戏内不应出现两种以上核心光影方案，除非有叙事驱动的光源变化（如审讯者关掉顶灯只剩屏光、从室内走到雨夜室外、日出后天窗光亮过厂房灯）。光源变化必须在分镜表中标注触发事件。

### 3.2 光源语句法（每个镜头必须包含）
[光源] 主光：{光源类型——审讯顶灯/无影灯/监控屏/钠灯/手电/街灯/天窗}，{方向}，{色温值K}，{软硬}
[光源] 辅光/环境光：{光源类型或无辅光}，{方向}，{色温值K}
[光比] 约1:{X}
### 3.3 情绪 → 光源矩阵

| 情绪 | 光源配方（Seedance 2.0 可直接填入） | 视觉关键词 |
|---|---|---|
| 审讯对峙 | 单顶灯冷白硬光（5000-5500K）垂直下压，无辅光，四周墙壁压暗至全黑。光比约1:8 | 压迫、半张脸阴影、真相逼近 |
| 雨夜追查 | 湿路面反射街灯暖光斑（2800K）+ 冷蓝环境漫射（6000K），雨幕散射，警灯红蓝偶尔扫过。光比约1:6 | 冷暖共存、孤独压抑 |
| 暗巷潜伏 | 单点钠灯暖橙黄（2000-2200K）有限光斑，光斑外全黑。光比约1:8 | 危险未知、孤光沉暗 |
| 现场勘查 | 手电/勘查灯冷白硬光束（5500-6500K）+ 警戒带橙黄反光点缀。光比约1:10 | 移动硬光、搜索紧张 |
| 监控窥视 | 多块监控屏冷蓝白（5500-6500K）为主光源，幽暗环境。光比约1:5 | 屏光映脸、窥视技侦 |
| 法医冷静 | 无影灯冷白均匀（5500-6500K）顶光无阴影，不锈钢台冷反光。光比约1:1.5 | 客观去情绪、专业理性 |
| 熬夜办公 | 屏幕冷蓝（6500K）+ 台灯/咖啡杯暖点（2800-3200K）。光比约1:4 | 冷主暖点、疲惫执拗 |
| 抓捕行动 | 警灯红蓝交替旋转扫过（红约2500K/蓝约6500K）+ 手电冷白硬光。光比约1:8 | 红蓝交替、紧张爆发 |

### 3.4 冷暖色调与叙事阶段

- **冷光主导**（5000K+）：审讯对峙、法医冷静、监控窥视、雨夜、熬夜办公
- **暖光主导**（2000-3500K）：暗巷潜伏、线人接头、深夜独处的人性瞬间
- **冷暖共存**：雨夜街灯（冷环境+暖光斑）、废弃厂（冷光柱+暖积水反光）、抓捕（红蓝交替）
- **光源变化 = 案情信号**：审讯者关掉顶灯→只剩屏光暗示施压升级；从审讯室冷白走到雨夜街灯→场景与案情的切换；天窗光从午后变暗→废弃厂时间流逝
- **整体去饱和冷调**：后期去饱和、暗部压深、肤色保留但偏冷——这是悬疑刑侦的色调基底

### 3.5 Seedance 2.0 光影适配要点

- 色温数字帮助模型校准白平衡倾向：`色温约5200K冷白硬光` 优于 `审讯室硬光`
- 光比数字帮助模型建立明暗意识：`光比约1:8极端高反差` 优于 `强烈的明暗对比`
- 光源必须有明确来源与方向：`审讯室头顶单灯垂直下压` 优于 `顶光`
- 单源环境须明确"无辅光/四周压暗"：`光斑外墙壁压暗至全黑，无辅光` 优于 `周围暗`

## 四、环境动态——让画面呼吸（即使压抑也有呼吸）

### 4.1 动态密度

每 3-4 个镜头至少安排一个有环境动态的镜头。即使审讯室的压抑静态戏也不例外——至少有一个镜头里顶灯有电流的微弱闪烁、烟灰缸上一缕烟在升、单向玻璃后有微弱动静。

### 4.2 刑侦环境动态元素（Seedance 2.0 可执行）

| 场景 | 可描述的环境动态 |
|---|---|
| 审讯室 | 顶灯电流的微弱光斑抖动、烟灰缸上一缕烟缓缓上升打转、单向玻璃后偶尔有暗影微动、铁桌水杯水面因桌面震动产生细微涟漪 |
| 警局办公区 | 屏幕保护程序切换、打印机吐出纸张、白板上便签一角卷起、烟灰缸烟蒂还在冒一缕烟、咖啡杯口热气升腾（若未凉透） |
| 监控室 | 多块监控屏画面交替闪烁变化、某块屏突然出现异常画面、键盘指示灯闪烁、值守人员的咖啡杯 |
| 雨夜街巷 | 湿路面被车轮碾过激起水花、雨丝在街灯下斜向下落、钠灯光斑在风中微晃、远处警灯红蓝旋转扫过墙面、积水被脚步踩溅涟漪 |
| 暗巷 | 钠灯电流嗡鸣伴随光斑微弱抖动、远处野猫叫、墙角杂草被风吹动、积水偶尔滴落 |
| 废弃厂房 | 天窗光柱随云朵移动而明暗变化、浮尘在光柱中飘动、屋顶偶尔有碎屑掉落、积水表面因震动起涟漪 |
| 法医解剖室 | 无影灯冷光稳定、器械盘上器械被轻挪、洗手水龙头偶尔滴水、通风系统的低频嗡鸣 |
| 地下车库 | 荧光灯管偶尔频闪一下、远处偶尔有车灯扫过、承重柱后偶尔有脚步回响 |

### 4.3 Seedance 2.0 环境动态描述规范

- 动态必须有具体轨迹和速度：`雨丝在街灯下以约每秒2米的速度斜向下落` 优于 `下雨`
- 光源动态与空间光源逻辑一致：`警灯旋转时红蓝光以约每秒1次的频率交替扫过墙面，每次扫过约0.5秒`
- 禁止无来源的动态：室内无开窗=无风吹动文件；审讯室顶灯=不应有窗外光变化

## 五、人物动作节奏——Seedance 2.0 物理逻辑具象化

### 5.1 动作描述铁律

所有人物动作必须描述：**轨迹 + 速度/时长 + 身体部位协调 + 对周围物体的影响**。

### 5.2 刑侦动作具象库

| 动作 | Seedance 2.0 可执行描述 |
|---|---|
| 拍桌施压 | 右手抬起约30cm，掌心向下猛击铁桌面，手掌与金属接触发出闷响，桌面水杯里的水轻微晃动，嫌疑人身体不自觉后缩约5cm——全程约0.5秒 |
| 回避眼神 | 视线从审讯者眼睛移开，先落向桌面卷宗，再下移至交握的双手，喉结明显滚动，整个过程约1.5秒，到位后停顿约1秒才再次抬眼 |
| 喝咖啡（熬夜） | 右手从桌面拿起凉透的咖啡纸杯，杯口靠近嘴唇，倾斜杯子约15度，小口啜饮约1秒，眉头因苦涩微皱，杯子下降回桌面约1秒——全程约3秒 |
| 走向审讯桌 | 从门口起身（约2秒），向画面右侧铁桌匀速行走约3步（约2米距离，耗时约2秒），停在距桌约0.5米处，双手撑桌 |
| 戴手铐 | 嫌疑人双手缓慢背至身后，刑警左手握住其左腕压低，右手将手铐铐环卡入手腕，金属咔合声清脆，嫌疑人肩膀不自觉一缩——全程约2秒 |
| 翻阅卷宗 | 右手食指沾唾液，捏住卷宗页角翻起约90度，纸张纤维翻动声，目光在页面从左至右扫视，眉头逐渐皱紧，约3秒后停下，食指点在某行文字 |
| 手电探照 | 右手握手电筒举起约与肩同高，拇指按下开关，冷白硬光束刺破黑暗，光束缓慢从左向右扫过空间约90度，浮尘在光束中可见——全程约3秒 |
| 点烟（疲惫） | 从烟盒抽出一根烟叼在唇间，左手护火，右手按打火机，火苗在指尖跳动约1秒，深吸一口，烟头明暗一次，烟雾从鼻口缓缓呼出——全程约4秒 |
| 抓捕按倒 | 刑警从嫌疑人身后约2米处加速冲近，双手抓住嫌疑人双肩向后按压，嫌疑人膝盖弯曲跪倒，刑警膝盖压住其背部，双手将其双手拧至背后——全程约2秒 |
| 看监控 | 值守人员坐在操作台前，上身微前倾，目光在多块屏幕间从左至右扫视，右手偶尔移动鼠标，屏幕冷蓝光映在脸上，咖啡杯在手边——静止状态约3秒 |

### 5.3 动作节奏与叙事场景

- **审讯文戏/心理博弈**：动作沉稳克制，每个微动作标注时长和轨迹。节奏压抑——不是慢，是"对峙中的静止比动作更有力"
- **线索推理/办公戏**：动作沉稳有疲态，翻卷宗、看屏幕、记笔记的重复节奏，体现熬夜办案的真实
- **蹲守追踪戏**：动作缓慢谨慎，标注步速和与目标的距离，手持摄影的紧张微晃
- **抓捕冲突戏**：动作干脆利落，但仍有物理轨迹。控制/按倒须具体到"双手抓肩、膝压背部、双手拧背"
- 禁止：无叙事理由的快速动作堆砌、无物理逻辑的瞬移、"做了个手势"等含糊描述

### 5.4 服饰动态

真人刑侦服饰的动态是画面的天然资产——不是"布料模拟参数"，而是"皮夹克下摆被转身带起约15度角""警服领口因前倾微敞""手铐链条在按倒时晃动发出金属声""被雨淋湿贴在身上的衬衫"。在分镜表画面描述中标注服饰的动态细节。

## 六、空间逻辑具象化——Seedance 2.0 空间坐标系统

### 6.1 每镜头必须声明的空间信息
水平位置：画面左/中/右，或画面左侧三分之一处
纵深位置：距镜头{数值}米，前景/中景/背景
人物与场景的关系：距{固定物——审讯桌/单向玻璃/铁栅门}{数值}米
（若双人以上）人物A与B的相对距离和朝向
### 6.2 站位衔接示例
【片段A尾部】
嫌疑人坐在审讯室铁椅上，距审讯桌约0.4米，面朝桌子，位于画面中央偏右，距镜头约3米。
头顶单灯冷白硬光（约5200K）垂直下压，面部上半亮下半沉入深影。
嫌疑人双手交握放桌面，身体前倾约10度。

【片段B开头】
嫌疑人的双手仍在桌面，身体前倾角度未变。嫌疑人仍坐在审讯室铁椅上（位置未变）。
审讯者从画面左侧缓慢走近约0.5米，停在距审讯桌约0.3米处，一只手撑在桌沿。
头顶顶灯仍亮，光斑与光比未变。
### 6.3 空间变化必须具象

| 抽象（禁止） | Seedance 2.0 具象 |
|---|---|
| 他走近了 | 刑警从画面背景（距镜头约5米、铁栅门位置）向镜头方向匀速行走3步（约2米），停在距审讯桌约0.5米处——耗时约3秒 |
| 两人对峙 | 审讯者位于画面中央偏左（距镜头约3米），嫌疑人位于画面中央偏右（距镜头约3米），两人隔铁桌相对，相距约1.2米 |
| 从审讯室到现场 | 刑警从审讯室（距镜头约3米）起身，走向铁栅门，推开铁门（门向外旋转约80度，金属声响），跨出门槛进入走廊——走廊荧光灯冷白光瞬间取代审讯室顶灯硬光，再切至雨夜案发现场 |

## 七、运镜规范——Seedance 2.0 摄影机运动

### 7.1 允许的运镜

| 运镜 | Seedance 2.0 描述 | 适用场景 |
|---|---|---|
| 固定 | 摄影机固定不动，画面静止 | 审讯、案发现场、空镜留白、情绪凝视、线索推理 |
| 手持微晃 | 摄影机有轻微不规则晃动（幅度约±2cm），模拟手持的紧张呼吸感 | 抓捕行动、搜查、街头跟踪、情绪波动、主观视角 |
| 缓慢推进 | 摄影机向主体缓慢推进，推进速率约每秒0.2米 | 审讯升温、真相逼近、嫌疑人崩溃、心理压缩 |
| 缓慢拉远 | 摄影机向后缓慢拉远，拉远速率约每秒0.3米 | 离开现场、收束、揭示全貌、人物被黑暗吞没 |
| 跟拍 | 摄影机与人物保持约2米距离同步移动 | 街头盯梢、暗巷追击、夜间蹲守 |
| 摇镜 | 摄影机原地水平/垂直旋转 | 审讯者扫视、白板线索图巡视、视线转移 |

### 7.2 禁用运镜

- 无叙事目的的快速甩镜、急推急拉（推拉速率超过每秒1米）
- 超过3秒的剧烈手持晃动（除非主观受击/眩晕/搏斗叙事）
- 无逻辑花式转场——划屏、旋转、百叶窗、翻页等特效转场
- 摄影机无理由的360度旋转
- 廉价恐怖片的跳切+闪烁（本风格是刑侦而非恐怖片）

### 7.3 真人悬疑刑侦运镜哲学

- 固定机位是审讯戏的第一选择——让观众看到真实的人在真实审讯室里被压迫地存在
- 缓慢推进是审讯升温的核心——速率不超过每秒0.3米，逼近即施压
- 手持微晃在抓捕/跟踪段落使用——但晃动幅度不超过电影纪实风格的常规范围
- 运动镜头的起幅和落幅必须平稳，运动过程匀速——禁止突然加速或急停

## 八、转场规范

### 8.1 允许的转场方式

| 转场 | 视觉执行 | 叙事功能 |
|---|---|---|
| 硬切 | 直接切换 | 同场戏内镜头切换（默认） |
| 光影匹配转场 | 两个场景在相近光影逻辑下切换 | 平行叙事、案情推进。例：审讯室顶灯硬光 → 案发现场勘查灯硬光 |
| 空间匹配转场 | 两个空间在构图或元素上呼应 | 场景跳转。例：审讯室铁栅门关上 → 看守所铁门打开 |
| 空镜过渡 | 插入场景空镜（3-5秒） | 情绪缓冲、章节划分、案情推进暗示 |
| 焦点转场 | 前镜焦点从主体移至背景，后镜从模糊背景中逐渐聚焦主体 | 空间切换、注意力转移（如从嫌疑人脸→单向玻璃后的暗影） |

### 8.2 禁止的转场

- 纯视觉特效转场（翻页、划屏、百叶窗、马赛克、闪烁）
- 无叙事逻辑的旋转/缩放转场
- 廉价恐怖片的跳切+闪光转场
- 同一场戏内使用超过两种转场方式

## 十一、空镜使用规范

### 11.1 空镜不是"没东西拍"

空镜是案情容器。每个空镜必须有叙事目的和具体的视觉内容：

| 空镜类型 | 叙事目的 | 示例 |
|---|---|---|
| 场景建立 | 新空间首次出现——让观众看清这是什么刑侦场所 | 审讯室大全景：铁桌椅、单顶灯光斑、单向玻璃、四周压暗 |
| 情绪缓冲 | 高压迫段落后的喘息 | 案发现场警戒带在风中微动，雨打警戒带 |
| 时间流逝 | 暗示办案时间过去 | 同一白板线索图从稀疏到写满中文与红线 |
| 隐喻留白 | 以物代情 | 桌上凉透的咖啡杯、堆满烟蒂的烟灰缸——又一不眠之夜 |
| 转场衔接 | 前后两个空间的自然过渡 | 走廊荧光灯管——前一场审讯室，下一场是办公区 |

### 11.2 空镜 Seedance 2.0 描述规范

空镜也必须遵循光源+质感+动态的描述铁律：审讯室头顶单灯冷白硬光（约5200K）垂直下压，光斑只覆盖铁桌椅区，
四周墙壁压暗至全黑，光斑外桌面上有一只没收的纸杯，纸杯水面因建筑微震产生极细微涟漪，
烟灰缸上一缕烟在静止空气中缓缓上升打转，单向玻璃后有极微弱的暗影晃动——审讯刚结束。
