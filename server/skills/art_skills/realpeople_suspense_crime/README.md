## 一、风格核心定义

**真人悬疑刑侦写实**是以**真人影视摄影美学**为基准、以**当代中国悬疑/犯罪/刑侦**为核心的视觉风格体系。其核心特征为：

- **真人写实摄影质感**：以真人影视级摄影为锚点，画面呈现真实人物的皮肤纹理、毛发细节、疲态与微表情、肢体语言，杜绝3D建模感、CG渲染感、手绘感。肌肤的眼袋、胡茬、暗沉、细纹——这些被疲惫与高压刻下的痕迹，是本风格最重要的真实证据
- **当代中国悬疑刑侦世界观**：所有场景严格限定于当代中国刑侦空间——审讯室、案发现场、法医解剖室、警局办公区、监控室、雨夜街巷与暗巷、废弃仓库/厂房、地下车库、看守所会见室、停尸房
- **电影级摄影语言**：以院线级悬疑刑侦电影摄影为基准，强调低调暗调与高反差光源调度、单光源硬光的审讯感、手电光束的体积感、屏幕与无影灯的冷白、景深与焦点的情绪压迫、色彩分级的电影感
- **冷峻压抑的影像底色**：在保持专业影像品质的前提下，强调刑侦工作的紧张感、孤独感、真相逼近的压迫感；阴郁冷峻是主调，区别于明亮的都市日常治愈系——这里的光是审讯室头顶那一盏，是雨夜里远处闪烁的警灯，是手电刺破黑暗的那一束

### 创作理念与核心价值

本手册的核心创作理念为 **"暗处见真"**：

1. **暗部的叙事重量**：悬疑刑侦的影像力量藏在暗部。审讯室里那一盏顶灯之外的一切都是黑的，嫌疑人半张脸沉入阴影——观众和审讯者一样，在黑暗里寻找真相。暗部不是"看不见"，是"刻意压下去的克制"，是留给人性悬念的空间

2. **真实的专业感**：刑侦题材不容娱乐化、不容悬浮。警徽、手铐、证物袋、卷宗、白板线索图、执法记录仪——每一个符号都必须经得起职业目光的审视。本手册以真实的中国刑侦工作流为骨架，拒绝戏剧化的廉价犯罪片美学

3. **人性的凝视**：无论嫌疑人还是刑警，每一个人都被摄影机冷静地凝视。疲惫的刑警队长凌晨三点靠在案发现场的警戒线外抽一支烟、嫌疑人被讯问时手指不自觉地摩挲、法医摘下手套时手掌的压痕——本手册的视觉立场是"对处于极端处境中的人的注视"

4. **光源即审讯者**：本风格里，光本身就是审讯者、是窥视者、是真相的探照灯。一束手电、一盏顶灯、一块冷白的屏幕——光源被赋予了叙事主动权，它决定照亮谁、隐藏谁

**核心价值：**

- 为AI视觉创作者提供一套系统化、可复用的真人悬疑刑侦题材提示词方法论

## 四、关键视觉元素

### 4.1 人物视觉元素

真人悬疑刑侦题材的人物视觉以**"真实个体、刑侦气质、疲态在场"**为核心：

- **面容标准**：真人肌肤质感，五官自然立体，疲态是核心证据——眼袋、暗沉、胡茬、冷白或暗沉的肤色、眼周微暗。支持多元面容类型——沉稳老练、锐利果决、阴鸷狡黠、疲惫沧桑、正义执拗、怯懦心虚等
- **发型标准**：利落不修边幅——利落短发、被汗水打湿贴在额头的碎发、扎起后散落的发、胡茬与鬓角的过渡。发丝自然质感，杜绝假发感与僵硬造型
- **服饰标准**：当代中国刑侦着装体系——警服（制式衬衫/夹克/作训服/警衔标志）、便装刑警（皮夹克/夹克衫/深色衬衫/深色长裤）、法医工装（白大褂/防护服）、嫌疑人/线人便装（皱巴的衬衫、洗旧的T恤、廉价的夹克）。面料纹理清晰，褶皱自然，制服有穿脱与佩戴痕迹
- **表情与体态**：微表情真实细腻——眼神的回避与直视、嘴角的紧绷与松弛、眉宇的紧锁；肢体语言自然——疲惫的塌肩、戒备的微缩、审讯时的前倾
- **人物气质维度**：沉稳老练 / 锐利果决 / 阴鸷 / 狡黠 / 疲惫沧桑 / 正义执拗 / 怯懦心虚 / 冷峻理性

### 4.2 场景视觉元素

- **审讯室**：单顶灯硬光下压、铁灰色金属桌椅、墙面软包或冷灰水泥、单向玻璃、铁栅栏门——顶灯之外的一切沉入黑暗，嫌疑人和审讯者被那束光锁定
- **案发现场**：拉起的黄黑警戒带、凌乱的现场痕迹（克制处理的血迹/打斗痕迹/散落物品）、勘查人员、编号物证标签、手电光束、相机闪光
- **法医解剖室/实验室**：无影灯冷白顶光、不锈钢解剖台、器械盘、洗手池、置物柜、口罩与手套、冷峻去情绪化的空间
- **警局办公区**：成排工位、堆叠的卷宗、白板线索图（照片/红线/便签）、照片墙、电脑屏幕冷光、烟灰缸里堆满烟蒂、凉透的咖啡杯——熬夜办案的真实
- **监控室**：一墙多块监控屏冷光闪烁、操作台、键盘、幽暗环境、屏幕光映在值守人员脸上
- **雨夜街巷/暗巷**：湿路面反射街灯、老旧钠灯、逼仄巷道、墙角阴影、架空电线、远处的警灯红蓝闪烁
- **废弃仓库/厂房**：斑驳水泥墙、生锈钢架、破漏天窗透下光柱、地面碎玻璃与积水、空旷回响
- **地下车库**：环氧地坪、承重柱、昏暗日光灯、冷硬回响、孤寂压迫
- **看守所会见室**：透明隔板、对讲电话、铁桌椅、冷光灯管——隔绝而压抑的会面空间
- **停尸房**：不锈钢冷冻柜、冷白灯管、低温感、瓷砖墙面、消毒气味

### 4.3 道具与细节元素

- **执法身份道具**：警徽/警官证/工作证/警衔标志——身份的视觉证明，有日常佩戴的磨损
- **戒具与执法装备**：手铐/约束带/对讲机/执法记录仪/手电/警用伸缩棍——执法的物理符号，金属有使用划痕
- **证据道具**：证物袋（透明塑封+编号标签）/编号物证/封条/现场勘查箱/取证工具——案件物证的标准化呈现
- **法医道具**：医用手套/口罩/解剖刀/器械盘/试管/样本瓶/检验报告——专业医学检验的真实工具
- **案卷与线索道具**：卷宗档案/案件文件夹/白板线索图（照片+红线+便签）/照片墙/打印照片/手写笔记——刑侦推理的视觉载体
- **氛围道具**：凉透的咖啡杯（熬夜办案）/堆满烟蒂的烟灰缸/吃剩的外卖盒——高压生活的真实痕迹
- **痕迹物证**：车牌/指纹卡/足迹石膏模/血迹样本卡（克制）/纤维样本——犯罪痕迹的技术呈现
- **现场道具**：黄黑警戒带/现场勘查灯/三脚架勘查灯/编号牌——案发现场的标志性符号

## 五、严禁内容（优先级最高）

本风格严格排除以下内容类型，确保视觉体系纯净统一：

1. **非真人质感**：3D渲染/CG建模/次世代游戏引擎/动画风格/手绘插画/水彩油画/二次元/Voxel/低多边形等一切非真人实拍影像质感
2. **非当代中国刑侦世界观**：古风/古装/传统中式古建/仙侠/玄幻/武侠/民国/西方奇幻/中世纪/赛博朋克/科幻未来/星际太空/机甲等非当代刑侦背景
3. **非悬疑刑侦题材**：豪门奢华/校园青春/治愈日常/明快高调/古风宫廷/民国谍战等明显偏离悬疑刑侦调性的题材
4. **技术质量缺陷**：低分辨率/模糊/噪点/变形/畸形肢体/五官扭曲/比例失调/抠图感/塑料感/过度磨皮/假面感
5. **审美倾向违规**：过度高饱和/死亡荧光色/廉价滤镜感/过度HDR/刻意阴间色调/廉价恐怖片调色
6. **血腥恐怖过度**：本风格是专业刑侦而非恐怖片。严禁渲染性血腥/恐怖惊悚/尸体特写/恶心器官展示/剥削性暴力。血迹与死亡以克制的、专业的、去情绪化的方式呈现
7. **内容合规红线**：暴露/低俗/暗示性/违法教唆/歧视性表达/政治敏感元素

## 七、使用说明

### 提示词使用原则

1. **前缀先行**：所有生成内容必须首先加载"前缀提示词"中的全局风格锚定段，锁定真人悬疑刑侦写实质感基线
2. **专项叠加**：在全局前缀基础上，按需叠加角色/场景/道具/分镜专项提示词
3. **负面必加**：每次生成必须附带"负面提示词"，规避伪影与风格偏差
4. **迭代优化**：建议首轮生成后根据效果对专项提示词做微调，而非修改全局前缀
5. **平台适配**：本手册提示词优先适配Doubao-Seedream（生图）与Doubao-Seedance（视频生成），部分提示词可能需根据平台特性微调
