## 二、摄影机语法（替代"渲染引擎"）

> 真人悬疑刑侦不依赖渲染管线。画面品质取决于摄影机的选择、镜头的性格、光线的调度。以下为"摄影机语法"核心参数。

### 2.1 画幅与格式

| 参数 | 基准值 | 美学意图 |
|---|---|---|
| 影像格式 | 35mm胶片质感 / 全画幅数字摄影 | 浅景深能力、自然的暗角过渡、微妙的颗粒结构——暗部颗粒是悬疑片的质感密码 |
| 色彩科学 | ARRI Alexa / Sony Venice 类电影色彩科学，略偏冷调去饱和 | 肤色还原自然但偏冷、高光滚降柔和、暗部压深但保留层次、整体去饱和增加冷峻感 |

### 2.2 镜头性格

| 焦段 | 叙事性格 | 典型应用 |
|---|---|---|
| 24-28mm（广角） | 空间包围人物、压迫与渺小、幽闭环境的窒息感 | 审讯室全景、案发现场全貌、废弃厂房探查、嫌疑人被包围 |
| 35mm（小广角） | 主观视点、身临其境、纪实感、对峙的临场 | 审讯对话、抓捕现场、街头跟踪、室内搜查 |
| 50mm（标准） | 人眼等价、客观注视、审讯者的凝视 | 人物肖像、审讯近景、双人对话、线索凝视 |
| 85mm（中长焦） | 压缩空间、窥视感、半张脸沉入阴影的特写 | 审讯特写、嫌疑人面部、监视视角、街对面窥视 |
| 135mm+（长焦） | 极端压缩、追踪感、将人物从黑暗中剥离 | 远距离盯梢、长焦跟踪、心理距离的物理化 |

### 2.3 机位与运动

| 手法 | 视觉心理 | 使用场景 |
|---|---|---|
| 固定机位 | 冷静凝视、审讯者的不动、压迫的累积 | 审讯室、案发现场、空镜留白、线索凝视 |

## 四、全局约束规则

### 4.1 影像真实性约束（必守）

| 编号 | 规则 |
|---|---|
| P1 | 必须以「真人摄影 / 真人实拍 / 真人电影剧照」为生成锚——画面必须读作"摄影机拍下的"，而非"计算机生成的" |
| P2 | 必须指定一个具体的光源逻辑：这场戏的光从哪里来？（审讯室顶灯/街灯/手电/屏幕/无影灯）光源方向、色温、软硬须自洽，且须符合悬疑刑侦的低调暗调基调 |
| P3 | 必须保留人物皮肤的真实质感——毛孔、细纹、痣、疲态（眼袋/胡茬/暗沉/冷白）——杜绝塑料磨皮与AI感假面；疲态是本风格的最高真实证据 |
| P4 | 发丝必须呈现自然状态——被汗水打湿贴在额头、被雨淋湿、扎起后散落的碎发、胡茬与鬓角的过渡——杜绝建模感整齐发块 |
| P5 | 服饰必须体现"穿过"的痕迹——警服的挺括与佩戴磨损、便装的褶皱、皮夹克的磨损、工装的厚实使用感——杜绝全新样板衣感 |
| P6 | 场景必须有"被使用过/被案件发生过"的证据——审讯室墙面的磨损、案发现场的凌乱与警戒带、警局办公区堆叠的卷宗与烟灰缸——杜绝样板间 |
| P7 | 人物必须处于自然体态——疲惫的塌肩、戒备的微缩、审讯时的前倾、被抓捕时的僵硬——杜绝模特式对称站姿 |
| P8 | 必须指定一个具体的当代中国悬疑刑侦空间——拒绝"generic crime scene"或任何无国别标识的架空刑侦场景，须有中文标识与中国刑侦特征 |
