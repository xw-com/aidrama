本手册专为"真人清朝写实"题材视觉创作打造，所有美术提示词、视觉规范和生成内容严格限定于真人实拍级**清代社会**影视美学体系。本风格锚定**清代**（1644—1912），覆盖**宫廷、市井、民间、晚清**四大版图——宫廷只占其一，重点是北京胡同四合院、老字号商铺、晚清茶馆戏台、天桥市井、晚清乡村的社会全景，并在晚清段落允许老照片（早期银盐摄影泛黄/颗粒/黑白上色）质感。

## 一、风格核心定义

**真人清朝写实**是以**真人影视摄影美学**为基准、以**清代社会全景**为核心视觉舞台的风格体系。其核心特征为：

- **真人写实摄影质感**：以真人影视级摄影为锚点，画面呈现真实人物的皮肤纹理、毛发细节、丝绸与棉麻的真实光泽、旗装与长衫马褂的垂坠、四合院与朱门的岁月材质、微表情与肢体语言，杜绝3D建模感、CG渲染感、手绘感与二次元动漫感
- **清代社会世界观**：所有场景严格限定于清代社会空间——宫廷（金銮殿/东西六宫/御花园）只占一部分，更多是北京胡同四合院、老字号商铺（同仁堂/瑞蚨祥式）、晚清茶馆戏台、天桥市井撂地、王府朱门影壁、晚清租界洋场、晚清乡村祠堂打谷场
- **清代服制准确**：满族女子旗装（直筒长袍、马蹄袖、花盆底鞋/马蹄底鞋、钿子/大拉翅/两把头）；汉族女子袄裙（"男从女不从"，汉女仍着明代遗风的袄裙）；男子一律剃发垂辫（前剃后辫）、长衫马褂、瓜皮小帽；官员顶戴花翎、补褂朝珠。严防混入唐宋明元素，严防滑入民国
- **电影级摄影语言**：以院线级真人清代影视摄影为基准，强调自然天光与室内灯火（宫烛/油灯/煤油灯/晚清煤气灯与电灯）的有机调度、构图叙事的专业性、景深与焦点的情绪表达、色彩分级的电影感
- **晚清老照片质感（可选）**：涉及晚清段落时，可带入早期银盐摄影的泛黄、颗粒、银盐冷黑白、手工上色的旧彩色感——参考晚清老北京照片、《大宅门》的晚清影像质地

### 创作理念与核心价值

本手册的核心创作理念为 **"市井朱门，旗汉之间"**：

1. **真实感的审美回归**：真人肌肤的纹理、缂丝的金线、胡同青砖的磨损、四合院影壁的剥落、茶馆盖碗的茶渍——这些真实细节构成了一种生命质感与岁月质感，是3D渲染无法复刻的审美深度。
2. **社会全景即叙事容器**：清代社会是最具戏剧张力的叙事空间。宫廷的权柄、王府的礼法、四合院的家长里短、老字号的商海沉浮、茶馆里说书人的市井春秋、天桥撂地的江湖气、晚清乡村的凋敝、租界洋场的古今激荡——社会空间本身就是一个等级分明、暗流涌动的叙事容器。
3. **服制即身份**：清代的服制是身份的硬通货——顶戴花翎的颜色与花翎眼数、补子的文禽武兽、旗装与袄裙的满汉之别、长衫与短褐的士庶之分。本手册坚持以真实服制驱动造型，反对架空混搭。
4. **克制写实即品格**：本风格为"真人写实清代"，不是仙侠法术，不是动漫玄幻。一切光影、材质、人物以写实克制为底色——市井的烟火气藏在盖碗的茶雾里，不藏在特效里。

**核心价值：** 为AI视觉创作者提供一套系统化、可复用的真人清代题材提示词方法论，建立从概念到成品的标准化视觉创作管线。

**"电影级真人写实清代社会美学"**

## 五、严禁内容（优先级最高）

1. **非真人质感**：3D渲染/CG建模/次世代游戏引擎/动画风格/手绘插画/水彩油画/二次元/Voxel/低多边形/赛璐璐等一切非真人实拍影像质感
2. **非清代/非中国古代**：现代当代都市/**民国**（民国另有 realpeople_republic_era，本风格止于清代1912）/西方/和风日式/赛博朋克/科幻未来/星际太空
3. **跨朝代混搭**：唐制（齐胸襦裙/坦领）/宋制（褙子/抹胸）/明制（袄裙马面混入清代旗装无差别）等元素混入——本风格严格清代服制，旗装有别于前朝
4. **仙侠法术与玄幻特效**：法术光效/真气流转/御剑飞行/玄幻粒子/灵力光环等一切玄幻CG特效

## 六、使用说明

### 提示词使用原则

1. **前缀先行**：所有生成内容必须首先加载"前缀提示词"中的全局风格锚定段，锁定真人清代写实质感基线
2. **专项叠加**：在全局前缀基础上，按需叠加角色/场景/道具/分镜专项提示词
3. **负面必加**：每次生成必须附带"负面提示词"，规避伪影与风格偏差
4. **迭代优化**：建议首轮生成后根据效果对专项提示词做微调，而非修改全局前缀
5. **平台适配**：本手册提示词优先适配Doubao-Seedream（生图）与Doubao-Seedance（视频生成），部分提示词可能需根据平台特性微调
