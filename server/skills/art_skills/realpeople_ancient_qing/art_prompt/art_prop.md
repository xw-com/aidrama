# 真人清朝写实道具图像生成 · 约束手册

---

## 一、道具设计原则

> 真人清朝写实的道具不是"被建模的物件"，而是"被清代社会里的人用过、被岁月盘过的器物"——它在嫔妃手里待过、在龙案上供过、在老字号柜台上算过账、在茶馆方桌上冒过茶烟、在晚清书房里放过唱片。摄影机拍下的是它的此刻。

1. **器物即身份与命运** — 每一件道具都是一个微型的清代叙事容器。顶戴花翎的品级、补褂补子的文禽武兽、鼻烟壶的材质、水烟袋的包浆、留声机的喇叭花——器物自带身份
2. **使用痕迹优先于完美品相** — 真人清朝写实的道具必须有"被用过、被岁月盘过"的证据。全新出厂、样板级别的道具一律不出现
3. **清代社会真实器物** — 道具必须是清代社会中真实存在的器物：朝服补褂、顶戴花翎、珐琅彩粉彩瓷、鼻烟壶、水烟袋、清代繁复雕饰家具、盖碗、算盘、晚清留声机——拒绝无朝代架空物品，拒绝唐宋明器物混入
4. **材质即真实** — 不是PBR参数渲染出的材质，而是摄影机拍下的真实材质行为：丝绸的金线凸起反光、金箔的氧化哑光、珐琅彩的釉光、紫檀红木的繁复雕饰包浆、玻璃鼻烟壶的内画
5. **单视图静物摄影** — 道具以单张静物产品摄影方式独立呈现，非多角度建模展示，非2×2四宫格

## 三、单视图静物摄影规范

> 真人清朝写实道具仅需单张静物产品摄影，非多角度建模展示。以下为单视图摄影的完整规范。

### 画面构成

| 项目 | 摄影要求 |
|---|---|
| 道具呈现 | 道具居中或偏三分线位置独立陈列，完整入画，无裁切 |
| 背景 | 素灰无缝背景纸 #B0B0B0（哑光），或深紫檀桌面/红木台面/米白绫绢台面/老字号柜台木面，根据道具属性选择。无多余物体、无装饰、无文字（道具本身的题字除外，如圣旨/匾额/药帖/算盘） |
| 光线 | 自然柔光或单灯柔光。窗光45°侧入（明亮柔和带自然阴影）、或柔光箱顶+侧补（产品摄影级均匀光线）。光影柔和、方向明确、无硬阴影 |
| 景深 | 浅景深（f/2.8-f/5.6），道具主体清晰锐利，前后微虚化突出主体 |
| 投影 | 道具底部与承载面之间的自然接触阴影——真实的而非抠图或悬浮。阴影柔软、方向与主光源一致 |
| 画面比例 | 建议 1:1 正方形或 4:3，适配单件道具展示 |

### 道具状态准则

| 维度 | 要求 |
|---|---|
| 使用痕迹 | 必须有"被用过、被岁月盘过"的视觉证据——非全新未启用、非样板品相 |
| 清代辨识度 | 清代器物形制/中文（如圣旨/药帖/招牌）/清代工艺（珐琅彩/繁复雕饰家具/鼻烟壶）——拒绝无朝代架空物品 |
| 材质真实感 | 非渲染质感——是摄影机拍下的真实材料行为（光的反射、漫射、透射） |
| 服制等级感 | 礼制重器须有合乎品级的工艺等级（顶戴花翎宝石品级、补褂文禽武兽、朝珠材质） |
| 尺度感 | 通过材质纹理密度、工艺细节暗示实物尺寸，无需参照物 |

## 六、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须是「单张静物摄影」——单视图、非多角度、非2×2四宫格、非建模展示 |
| R2 | 必须指定「素灰背景纸 #B0B0B0」或「深紫檀桌面/红木台面/米白绫绢台面/老字号柜台木面」等真实清代承载面，禁止复杂场景 |
| R3 | 必须指定光源逻辑——窗光或柔光箱，光影方向明确、投影自然 |
| R4 | 道具必须有「使用痕迹/御用痕迹/岁月痕迹」——非全新、非样板品相、非未启用 |
| R5 | 道具必须具备清代社会辨识度——清代形制/中文/清代工艺（珐琅彩/繁复雕饰/鼻烟壶/顶戴花翎）/按身份品级服制 |
| R6 | 必须声明「实物产品摄影 + 非3D渲染非CG」核心锚定 |
| R7 | 材质必须描述为摄影机下的真实表现，而非渲染参数；刺绣须凸起非平面印花；珐琅彩粉彩须粉润堆雕非平面印花 |
| R8 | 清代家具必须为「繁复雕饰（区别明式简洁）+ 镶嵌螺钿/大理石 + 包浆厚重」，不可出现明式简洁家具 |
