# 真人清朝写实场景图像生成 · 约束手册

---

## 一、场景美学原则

> 真人清朝写实的场景不是"被建模的宫殿或街市"，而是"被摄影机选中的真实清代社会一角"。没有渲染引擎、没有贴图——只有实际存在的天光与灯火、真实的朱门青砖与紫檀柜台、胡同与四合院的岁月、茶馆与天桥的烟火。

1. **空间即社会** — 一座空无一人的金銮殿是退朝之后，一条空无一人的胡同是清晨未醒，一间空无一人的老字号是打烊之后。清代社会的每一个空间自己会讲故事——宫廷的权柄、市井的烟火、晚清的苍凉
2. **真实的光，不是渲染的光** — 场景的光只有一个来源：实际的日光（通过殿窗、四合院天井、胡同缝隙）、实际的灯火（宫灯、烛台、油灯、煤油灯、晚清煤气灯）。光的色温和方向必须在物理上说得通
3. **被岁月使用过的清代现场** — 真实的清代社会不崭新。朱门有剥落与掉漆、青砖有磨损、金箔有氧化、清代家具有开裂包浆与繁复雕饰、老字号柜台有包浆、茶馆方桌有油渍——一个完全没有岁月痕迹的场景是样板布景，不是真实清代
4. **清代社会辨识度** — 场景必须有明确的清代辨识度（朱门宫墙黄琉璃瓦/青砖胡同四合院/清代繁复雕饰家具/珐琅彩粉彩瓷/顶戴花翎/旗装辫发线索）。这不是"generic ancient"，这是"清代社会的一个具体角落"，宫廷只占一部分
5. **单视图全景全貌** — 一张照片装下整座殿/院/胡同/茶馆的完整信息。广角或标准焦段，全景深，正面展示空间的全貌与纵深——不是四视图分割，不是多角度拼贴

## 五、单视图全景摄影规范

> 真人清朝写实场景仅需**单张**全景摄影——一张照片装下整座殿/院/胡同/茶馆的完整信息。不是2×2四视图，不是多角度拼接。

### 画面构成

| 项目 | 摄影要求 |
|---|---|
| 空间呈现 | 单张照片完整呈现场景的空间全貌。使用24-28mm广角或35mm，全场地的纵深、宽度、高度在一张画面中全部可见 |
| 构图 | 全景深大景别——前景（宫门/梁柱/纱帐/宫灯/柜台/方桌/胡同门墩）形成天然画框→中景是空间主体→后景向空间纵深或后殿/天空/胡同延伸 |
| 景深 | 全景深 f/8-f/11，从前到后全部清晰。这不是人像摄影——场景的每一个角落都应该能被看见 |
| 人物 | **严禁出现任何人物、人影、人体轮廓。** 场景是空的——但这种"空"有叙事：退朝之后/打烊之后/清晨未醒/人去楼空/市井的静止瞬间 |
| 比例 | 建议 16:9 或 3:2 宽幅——匹配全景空间展示的横向视觉习惯 |
| 色彩 | 由实际光源的色温驱动，不套滤镜。色彩科学参考ARRI Alexa/Sony Venice电影色调；晚清段落可叠加早期银盐摄影泛黄/冷黑白/手工上色淡彩 |

### 空的场景如何叙事

| "空"的类型 | 画面线索 | 叙事暗示 |
|---|---|---|

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须是**单张**全景摄影——单视图、非2×2四视图、非多角度、非turnaround |
| R2 | 必须使用广角镜头（24-28mm）或标准焦段（35mm），全景深 f/8-f/11，完整空间纵深 |
| R3 | 光源必须可追溯——自然光的方向与时刻匹配、灯火（宫灯/油灯/煤油灯/煤气灯）的位置和色温合理 |
| R4 | 场景必须有前/中/后景空间层次，前景画框→中景主体→后景延伸 |
| R5 | 必须有清代社会辨识度——朱门宫墙黄琉璃瓦/青砖胡同四合院/清代繁复雕饰家具/珐琅彩粉彩瓷/顶戴花翎/旗装辫发线索（至少一项） |
| R6 | 必须有岁月痕迹——朱门掉漆/青砖磨损/金箔氧化/清代家具包浆/柜台包浆/招牌斑驳、非样板非全新非效果图 |
| R7 | **严禁出现任何人物、人影、人体轮廓、剪影** |
| R8 | 必须声明"真人实拍摄影 + 非3D渲染非CG"核心锚定 |

| 编号 | 严禁 |
|---|---|
