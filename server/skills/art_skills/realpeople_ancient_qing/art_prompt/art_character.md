## 一、选角逻辑——摄影机前的清代社会人

> 真人清朝写实的起点是"选一个真人演员，穿上旗装或长衫马褂，站进金銮殿、四合院、老字号或茶馆的摄影机前"。清代社会各阶层面孔皆可入画——上至帝王嫔妃，下至掌柜伙计、手艺人、说书人、贩夫走卒、晚清学童。

1. **面孔即命运** — 一张脸就是一段未写的清代故事。本风格不追求"完美的五官"，而追求"值得被摄影机凝视的清代面孔"——有辨识度的不对称、有故事感的微瑕疵、能承载威仪或市井烟火的面孔
2. **真人气韵优先于偶像感** — 清代叙事需要的是"看起来像活在清代社会的人"，而非"看起来像刚从杂志封面走下来的人"。骨相、皮相、神态都要真，妆容为辅，市井百姓甚至素面
3. **服制即身份** — 清代是服制最森严的时代之一。满女旗装（马蹄袖、花盆底鞋）、汉女袄裙（"男从女不从"）、男子剃发垂辫、官员顶戴花翎补褂——身份、满汉、品级全写在服制上，绝不可混搭错乱
4. **同一人物跨角度可辨认** — 正面/侧面/背面/特写四角度必须呈现为同一个人的摄影记录，而非四个相似的人。核心识别点：颌骨轮廓、鼻梁转折、耳廓形状、发际线走向、辫发/旗头结构
