## 一、分镜表定位

分镜表是导演将剧本转化为镜头语言的核心工具。本约束面向 Seedance 2.0 视频生成，所有光影、动作、空间描述均采用模型可执行的具象语言。不做抽象的情感概括，不写模型看不懂的渲染参数。本风格覆盖清代社会全景——宫廷、市井、民间、晚清——分镜表中的人物动作、环境动态、空间逻辑须按清代社会的真实物理与礼法/市井规则具象化。

### 5.3 动作节奏与叙事场景

- **文戏/朝堂礼法**：动作沉稳克制，每个微动作标注时长和轨迹。节奏舒缓——不是慢，是"合乎礼法的不急"
- **市井日常**：动作有市井节奏——掌柜算账的噼啪、伙计跑堂的麻利、说书人醒木的干脆、茶客嗑瓜子的零碎。真实市井的烟火节拍
- **情绪波动**：动作幅度和速度略微变化。人物可能在对话中不自觉地加快护甲/扳指轻叩的频率、呼吸带动肩膀起伏更明显
- **冲突场景**：动作干脆利落，但仍有物理轨迹。推搡/摔物须具体到"右手推在对方左肩前方，对方重心向后偏移约20cm，旗头步摇晃动剧烈"
- 禁止：无叙事理由的快速动作堆砌、无物理逻辑的瞬移、"施了一礼""算了个账"等含糊描述

### 5.4 服饰动态

真人清朝写实的服饰动态是画面的天然资产——不是"布料模拟参数"，而是"旗装下摆随敛衽前倾自然垂坠""马蹄袖起身时自然垂落带回约10cm""长衫马褂下摆作揖时前垂约8cm""步摇流苏随头部微动垂坠晃动约2秒渐止""纱帐被穿堂风鼓起约15cm""花盆底鞋落地轻微叩击"。在分镜表画面描述中标注服饰与首饰的动态细节。

## 六、空间逻辑具象化——Seedance 2.0 空间坐标系统

### 6.1 每镜头必须声明的空间信息
水平位置：画面左/中/右，或画面左侧三分之一处
纵深位置：距镜头{数值}米，前景/中景/背景

### 6.2 站位衔接示例
【片段A尾部】
A掌柜站在老字号柜台后，距柜台约0.5米，面向柜台外，位于画面中央偏右，距镜头约4米。
柜台内侧油灯火从画面右侧低位照入（约2700K暖橙）。
A右手拨动算盘珠，食指距算盘约2cm。

【片段B开头】
A的右手刚拨完一颗算盘珠收回约5cm，扳指仍在原位置附近。A仍站在柜台后（位置未变）。
窗外天色已从黄昏转为蓝调时刻——天空深蓝紫透窗，铺内油灯已为主光源（约2700K暖橙）。
门外幌子已被收起（画面右后侧），门板已上半。

## 七、运镜规范——Seedance 2.0 摄影机运动

### 7.1 允许的运镜

| 运镜 | Seedance 2.0 描述 | 适用场景 |
|---|---|---|
| 固定 | 摄影机固定不动，画面静止 | 朝堂礼法、典礼、四合院对话、空场留白、情绪凝视 |
| 手持微晃 | 摄影机有轻微不规则晃动（幅度约±2cm），模拟手持拍摄的呼吸感 | 暗涌、跟踪密会、情绪波动、天桥市井纪实、主观视角 |
| 稳定器流动 | 摄影机平滑匀速移动，无晃动 | 游廊/胡同纵深、人物登场、茶馆穿行、空间展示 |
| 缓推 | 摄影机向主体缓慢推进，推进速率约每秒0.3米 | 情绪升温、真相逼近、注意力聚焦 |
| 缓拉 | 摄影机向后缓慢拉远，拉远速率约每秒0.3米 | 离别、收束、揭示全貌 |
| 跟拍 | 摄影机与人物保持约2米距离同步移动 | 胡同穿行、市井行走跟随、朝堂跟随 |
| 摇镜 | 摄影机原地水平/垂直旋转 | 视线转移、纵深关系交代 |

### 7.2 禁用运镜

- 无叙事目的的快速甩镜、急推急拉（推拉速率超过每秒1米）
- 超过3秒的剧烈手持晃动（除非主观受击/眩晕/宫变/市井冲突叙事）
- 无逻辑花式转场——划屏、旋转、百叶窗、翻页等特效转场
- 摄影机无理由的360度旋转

### 7.3 真人清朝写实运镜哲学

- 固定机位是朝堂与典礼的第一选择——让观众看到清代社会人在礼法/市井空间里自然存在
- 手持微晃在冲突与市井纪实段落使用——但晃动幅度不超过电影纪实风格的常规范围
- 稳定器流动用于游廊/胡同纵深与人物登场——清代社会的仪式诗与市井纵深
- 运动镜头的起幅和落幅必须平稳，运动过程匀速——禁止突然加速或急停

## 八、转场规范

### 8.1 允许的转场方式

| 转场 | 视觉执行 | 叙事功能 |
|---|---|---|
| 硬切 | 直接切换 | 同场戏内镜头切换（默认） |
| 光影匹配转场 | 两个场景在相近光影逻辑下切换 | 时间流逝、平行叙事。例：A处灯火暖橙 → B处灯火暖橙 |
| 空间匹配转场 | 两个空间在构图或元素上呼应 | 场景跳转。例：金銮殿龙椅的明黄 → 寝宫明黄幔帐；老字号招牌 → 茶馆戏台匾额 |
| 空镜过渡 | 插入场景空镜（3-5秒） | 情绪缓冲、章节划分、时间流逝暗示（如黄昏朱门→月夜胡同） |
| 焦点转场 | 前镜焦点从主体移至背景，后镜从模糊背景中逐渐聚焦主体 | 空间切换、注意力的转移 |

### 8.2 禁止的转场

- 纯视觉特效转场（翻页、划屏、百叶窗、马赛克、水墨化开）
- 无叙事逻辑的旋转/缩放转场
- 同一场戏内使用超过两种转场方式

## 十一、空镜使用规范

### 11.1 空镜不是"没东西拍"

空镜是情绪容器。每个空镜必须有叙事目的和具体的视觉内容：

| 空镜类型 | 叙事目的 | 示例 |
|---|---|---|
| 场景建立 | 新空间首次出现——让观众看清楚这是什么清代场景 | 金銮殿大全景：盘龙柱、藻井、龙椅、丹陛、明黄幔帐；老字号全貌：黑漆金字招牌、柜台、百子药柜 |
| 情绪缓冲 | 高情绪段落后的喘息 | 漏窗外月光沿纱帐滑下，速度约每秒2cm；茶馆散场后方桌盖碗未收 |
| 时间流逝 | 暗示时间过去了 | 同一窗外的天光从午后湛蓝渐变至黄昏暖金再至月夜冷蓝 |
| 隐喻留白 | 以物代情 | 妆台/柜台上半残的灯火，烛泪凝结，灯火明灭；算盘停在某个数，账本翻开 |
| 转场衔接 | 前后两个空间的自然过渡 | 游廊漏窗——前一场寝室，下一场庭院；胡同口——前一场四合院，下一场老字号 |

### 11.2 空镜 Seedance 2.0 描述规范

空镜也必须遵循光源+质感+动态的描述铁律：寝室内灯火从画面左侧低位斜入（约2500K暖橙），
在空荡荡的妆台铜镜上镀一层暖金，铜镜映出空拔步床纱帐，
灯火每秒约2-3次微幅明灭，纱帐被穿堂风鼓起约10cm后回落，
妆台紫檀木繁复雕饰有包浆，护甲盒朱漆边角磨损。
