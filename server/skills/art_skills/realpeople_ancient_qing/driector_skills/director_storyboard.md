本 Skill 专用于**真人清朝写实**风格的分镜提示词生成，适配清代宫廷朝堂、王府门第、北京胡同四合院市井、老字号商海、晚清茶馆戏台、天桥江湖、晚清乡村、晚清洋场等真人实拍清代影视题材的分镜创作。本风格覆盖清代社会全景，宫廷只占一部分，重点是市井/民间/晚清社会生活。

## 一、摄影机前的情绪——面孔、眼神、微表情

> 真人清朝写实的情绪不来自"法术光效"或"渲染参数"，而来自真人演员在摄影机前的微表情与礼法/市井之下的眼神。以下映射面向摄影机捕捉真实清代社会人的方式。

| 情绪输入 | 面容描述 | 眼神描述 | 微表情补充 |
|---|---|---|---|
| 威仪 / 沉稳 | 神情端凝，面部线条端正不紧绷，下颌微收 | 眼神深邃不怒自威，俯瞰式注视，喜怒难测 | 唇线平直，下颌微收，气场如山 |
| 隐忍 / 克制 | 眉眼不抬，面部肌肉收敛 | 目光低垂或平直不游移，将情绪压在眼底 | 嘴角自然平直，呼吸极轻，全身只有眼皮微动 |
| 温婉 / 柔顺 | 眉目舒展，面部柔和 | 眼神温润专注，像在认真听对方说话 | 嘴角自然含一丝温意，不是笑，是有温度 |
| 狠辣 / 凌厉 | 面部线条微绷，藏锋于笑 | 眼神锐利有寒意，眼尾上挑，注视时不躲闪 | 嘴角微扬似笑非笑，护甲/扳指轻叩有声 |

## 四、摄影机语法——镜头选择与运动

### 4.1 焦段选择

| 焦段 | 叙事性格 | 适用场景 |
|---|---|---|
| 24-28mm广角 | 宫殿/朱门吞噬人物，殿宇威压，市井宏大与个体渺小 | 朝堂大全景、宫门王府甬道、胡同纵深、茶馆全貌、晚清乡村 |
| 35mm小广角 | 主观视点，身临其境的市井纪实感，人与社会共存 | 胡同穿行、四合院对话、茶馆跟随、天桥撂地围观 |
| 50mm标准 | 人眼等价，客观中立的注视，最诚实的镜头 | 人物肖像、双人对话、旗装/长衫马褂凝视 |
| 85mm中长焦 | 压缩空间，拉近情感距离，丝绸旗装与顶戴花翎细节突出 | 特写、步摇流苏、顶戴花翎、盖碗茶雾、灯火下的面容 |
| 135mm+长焦 | 将人物从背景中剥离，极端的注视或窥视 | 胡同深处注视、长廊尽头、命运的距离感 |

### 4.2 景别选择

| 景别 | 取景范围 | 叙事功能 |
|---|---|---|
| 大特写 | 眼睛/嘴唇/护甲/步摇/辫发青茬/花盆底鞋落地/盖碗茶雾/朱笔/算盘珠/醒木 | 情绪爆发点、关键信息揭示、感官聚焦 |

| 中近景 | 头顶至腰部 | 人物互动、敛衽/奉茶/递折/算账手势 |
| 中景 | 头顶至膝盖上下 | 人物与场景的初级关系、多人同框 |
| 全景 | 人物全身+部分场景 | 人物在空间中的位置、行动路线、服制全貌 |
| 大全景/空镜 | 场景全貌，人物极小或无人物 | 空间叙事、情绪缓冲、隐喻留白 |

## 六、美学禁止项

以下词汇/风格不得出现于输出提示词中：

- ❌ 3D渲染 / 3D建模 / CG / UE引擎 / Blender / PBR材质 / 次世代建模 / 体积光 / 环境光遮蔽 / 光线追踪
- ❌ 2D手绘 / 插画 / 动画 / 二次元 / 漫画 / Q版 / 赛璐璐 / 低多边形
- ❌ 写实摄影（英文禁止 photorealistic / realistic photography——本风格是"真人实拍摄影"live-action cinematic photography，不是"拟真渲染"）
- ❌ 过度磨皮 / 塑料假面 / 零毛孔 / 硅胶脸 / 蜡像感 / AI感平滑 / 妆容像贴图
- ❌ 仙侠法术 / 玄幻特效 / 真气流转 / 御剑飞行 / 法术光效 / 灵力光环 / 水墨法术特效
- ❌ 现代当代都市 / **民国** / 西方宫廷 / 和风日式 / 赛博朋克 / 科幻 / 西方奇幻 / 中世纪
- ❌ 跨朝代混搭——唐宋明服制（男子束发加冠、唐齐胸襦裙、宋褙子、明式简洁家具）混入清代
- ❌ 男子不剃发垂辫而束发加冠（明代发式）
- ❌ 平面印花冒充刺绣 / 平面金线
- ❌ 人体结构错误 / 肢体畸形 / 面部崩坏 / 比例失调
- ❌ 高饱和荧光色 / 霓虹溢色 / 廉价滤镜感 / 二次元平涂
- ❌ 非清代的架空场景 / 西式城堡 / 日式城堡 / 无朝代辨识度的 generic ancient
