# 日系清新写实风格说明

本风格专为"日系清新写实"题材打造，所有美术提示词、规范和生成内容均严格限定于：

- **现代世界观**：以现代日常生活为背景，涵盖住宅街角、便利店、铁道口、公园、河堤、咖啡店等，杜绝现代元素缺失。
- **真人写实**：所有角色、场景、道具均以真人写实摄影为标准，强调五官、皮肤、发丝、材质等真实细节与胶片质感。
- **日系清新写真**：在写实基础上追求低饱和青绿色调、逆光柔焦与空气感、细腻胶片颗粒与治愈留白构图，整体氛围安静、透明、温柔。
- **治愈氛围**：适合展现日常、青春、思念与成长类故事，强调平凡瞬间里的柔软情感。

## 适用范围

- 日系清新写实题材的AI美术生成（角色、场景、道具、分镜等）
- 需要极致写实、低饱和胶片空气感、治愈留白氛围的视觉创作

## 严禁内容

- 卡通、动漫、插画、二次元风格
- 现代元素缺失、古风/古装/传统建筑
- 高饱和荧光色、浓艳撞色、赛博朋克色调
- 暗示性、暴露、透视等不适宜内容

## 风格体验

在本风格下，您将体验到：

- 角色面容干净、素肌透明感妆容，白裙/浅色系穿搭，发型清爽自然
- 场景通透干净，逆光空气感强，木纹、绿意、白墙等纹理真实且富有生活温度
- 道具、汽水、拍立得、便当盒等均为日常造型，工艺简约，胶片质感细腻
- 分镜与视频均以真人写实为基础，强调留白构图与安静的叙事节奏

---

本风格仅适用于"日系清新写实"相关项目。如需其他风格（如古风、插画、动漫、都市现代写实等），请勿使用本套提示词。
