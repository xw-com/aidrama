## 一、风格基因

| 维度 | 定义 |
|---|---|
| **一级风格** | 日系清新写实（Japanese-Fresh-Photorealism） |
| **二级风格** | 真人写实摄影 · 胶片写真 · 逆光空气感 |
| **情感基调** | 治愈向 — 日常、透明、安静的温柔 |
| **质感锚词** | 低饱和青绿、逆光柔焦、胶片颗粒、空气感 |

## 二、全局色彩盘（风格基线，不是硬锁）

> 目标：统一审美而非限制创作。除「硬约束色」外，其余颜色默认优先使用，可在合理范围内偏移。

### 色彩使用层级

| 层级 | 约束强度 | 说明 |
|---|---|---|
| L1 硬约束 | 高 | 仅锁定角色识别核心：肤色、发色、主服底色的审美方向 |
| L2 软约束 | 中 | 场景色、配饰色、点缀色优先参考色盘，可按镜头与剧情微调 |
| L3 例外机制 | 低 | 节庆/回忆/高潮戏可临时突破局部色彩，但需保留整体冷暖逻辑 |

|---|---|---|---|

| C3 | 青苔绿 | #8FA896 | 树叶、草坪、基调色 |
| C4 | 深栗棕 | #38291F | 发色、眼瞳、阴影 |
| C5 | 雾青 | #AFC5C3 | 天空阴面、浅色外套、牛仔 |
| C6 | 松绿 | #5C7268 | 深绿植、远景压色 |
| C7 | 落日蜜 | #E9B98A | 逆光暖阳、暖点缀 |

### 硬约束色（默认锁定）

| 色项 | 对应色 | 规则 |
|---|---|---|
| 肤色基准 | C2 透明素肌 | 默认优先，允许小幅明度微调，保持素肌透亮 |
| 发色/瞳色基准 | C4 深栗棕 | 默认优先，允许深栗/黑茶轻微偏移 |

### 软约束色（推荐优先）

> C1/C3/C5/C6/C7/C8/C9/C10 为推荐色域，用于浅色穿搭、绿植、天空、暖阳、木器、小物点缀等。可根据镜头氛围做同色相邻近调整。

### 情绪色盘（导演对齐版）

| 情绪场景 | 主色 | 辅色 | 光效与对比建议 | 画面关键词 |
|---|---|---|---|---|
| 街角偶遇（日常） | C1 奶白 | C5 雾青 + C3 青苔绿 | 大平光柔漫射，低对比，空气感 | 清爽、日常、偶然 |
| 心动信号（暧昧） | C10 樱贝粉 | C7 落日蜜 + C1 奶白 | 逆光暖调，肤色微透，背景青绿低饱和 | 心动、透明、靠近 |
| 上学/通勤（日常） | C5 雾青 | C1 奶白 + C8 浅原木 | 顶光柔化，浅景深，干净通透 | 青春、规律、安静 |
| 误会/低落（冷调） | C5 雾青 | C6 松绿 + C9 云灰 | 青灰主导，进一步降饱和 | 淡淡的失落、留白 |
| 和解/回暖（回暖） | C7 落日蜜 | C1 奶白 + C3 青苔绿 | 黄昏逆光，暖光落在发丝，高光轻过曝 | 治愈、释然、温暖 |
| 公园游玩（高光） | C3 青苔绿 | C7 落日蜜 + C1 奶白 | 树影斑驳，光斑散景，明亮通透 | 明亮、雀跃、呼吸感 |
| 铁道口告别（时间感） | C6 松绿 | C5 雾青 + C8 浅原木 | 侧逆光，铁轨延伸纵深，暖光渐退 | 告别、时间流动、安静 |
| 回忆/闪回（柔和化） | C1 奶白 | C9 云灰 + C7 落日蜜 | 整体雾化与轻微过曝并存，胶片偏色但不浓艳 | 旧忆、柔软、透明 |

### 情绪色盘使用规则

| 编号 | 规则 |
|---|---|
| E1 | 每条提示词至少指定 1 个「情绪场景」并绑定主色+辅色组合 |
| E2 | 单镜头主色不超过 2 个，避免颜色叙事失焦 |
| E3 | 情绪切换时优先调整光比与色温，再调整饱和度 |
| E4 | 日系清新默认遵循「青绿底 + 暖透点」：低饱和青绿铺底，暖色只在逆光焦点轻微透出，禁止大面积暖色 |
| E5 | 若与剧情冲突，以情绪色盘优先于通用推荐色，但不得突破严禁项 |

### 色温约束

| 参数 | 值 | 说明 |
|---|---|---|
| 整体色温 | 中性偏冷 5000-5500K（推荐） | 青绿空气感基调 |
| 肤色色温 | 中性 5000-5400K（推荐） | 素肌透亮不惨白 |
| 对比度 | 低至中低（建议保持） | 柔和过渡，宽容暗部 |
| 饱和度 | 低 25-40%（建议区间） | 日系低饱和 |

### 容差与例外

| 项目 | 建议容差 |
|---|---|
| 色相偏移 | ±8° |
| 饱和度偏移 | ±10% |
| 明度偏移 | ±12% |

> 例外场景：黄昏逆光、夏日点灯、情绪高潮镜头可局部提高暖饱和；但禁止高对比重滤镜与浓艳撞色入镜。

## 三、全局约束规则

### 必守规则（所有技能继承）

| 编号 | 规则 |
|---|---|
| R1 | 必须包含「真人写实摄影」风格锚定词 |
| R2 | 必须声明「逆光柔焦 + 胶片空气感」 |
| R3 | 面部必须使用「面容细腻渲染 + 素肌透明感」 |
| R4 | 发丝必须使用「根根分明 + 发丝细腻渲染」 |
| R5 | 纹理必须声明「胶片颗粒细腻 + 纹理细节清晰」 |

### 严禁项（所有技能继承）

| 编号 | 严禁内容 |
|---|---|
| X1 | 严禁「卡通/动漫/二次元/插画风」（日系清新≠日系动漫，必须真人写实） |
| X2 | 严禁「高饱和荧光色/浓艳撞色/厚重滤镜」 |
| X3 | 严禁「现代元素缺失」（必须明确现代日常场景） |
| X4 | 严禁「面部变形/多指/肢体异常」倾向词 |
| X5 | 严禁「裸体/暴露/透视/暗示性描述」 |
| X6 | 严禁「古风/古装/汉服元素」与「赛博朋克/港风浓彩」 |
