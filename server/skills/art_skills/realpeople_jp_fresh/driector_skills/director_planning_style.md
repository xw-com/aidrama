# 日系清新写实风格约束 · 技法参考

---

## 一、色调体系与画面基调

- **色调基底** — 全片以奶白（C1）、透明素肌（C2）、青苔绿（C3）、雾青（C5）为基底色，整体色温中性偏冷（5000-5500K），饱和度低（25-40%），对比度低至中低，呈现通透安静的日系空气感
- **冷暖叙事对比** — 暖色（落日蜜 C7、樱贝粉 C10）只作为逆光焦点与情绪升温信号，冷色（雾青 C5、松绿 C6）用于日常、失落、留白等段落。冷暖切换应与情绪弧线同步
- **冷暖分配策略** — 日常段落以青绿+奶白铺底，心动/和解段落释放黄昏暖光；暖色面积需克制，避免整体变暖失去清新感
- **色盘先行原则** — 段落规划先绑定情绪场景（街角偶遇/心动/失落/和解/告别等），再确定主色+辅色与光影方案，避免"剧情对了但情绪不对色"
- **禁用色域** — 高饱和荧光色、浓艳撞色、厚重滤镜与本风格不兼容


---

## 二、光影方案体系

- **光影即叙事** — 6 套光影方案对应不同情绪段落，导演规划阶段应在段落层面确定光影基调方向，而非逐镜指定
- **光源角度** — 正给镜头默认顺光大平光（干净透亮），情绪镜头转半逆光/逆光勾勒发丝轮廓

| 光影方案 | 方案名 | 色调倾向 | 适用情绪 |
|---|---|---|---|
| A | 大平光漫射 | 奶白 + 雾青 | 日常、上学、散步 |
| B | 窗边柔侧光 | 奶白 + 浅原木 | 咖啡店、公寓室内 |
| C | 黄昏逆光 | 落日蜜 + 青苔绿 | 心动、告别、高光 |
| D | 树影斑驳 | 青苔绿 + 奶白 | 公园、雀跃段落 |
| E | 阴天青灰 | 雾青 + 云灰 | 失落、留白过渡 |
| F | 夜间点暖 | 便利店暖光 + 夜青 | 夜归、治愈段落 |

- **冷暖光分配** — 暖光全片克制使用；失落/留白段落降到最低暖占比，避免情绪与光色冲突
- **氛围方向映射** — 每场戏氛围方向应映射到上述光影方案（A-F）的某一方向，确保视觉一致性

## 三、质感方向

- **胶片写真质感** — 真人写实摄影核心：细腻胶片颗粒、柔和过渡、通透空气感
- **低饱和 + 低对比** — 作为画面质感锚点。不是高对比硬光大片，不是浓滤镜复古，而是可呼吸的日常写真空气感
- **焦段与景深** — 35mm/50mm 为主，浅景深虚化背景，85mm 用于压缩特写；逆光下光斑散景是情绪放大器
- **皮肤质感** — 素肌透明感妆容，保留真实毛孔与细微瑕疵，禁止厚重磨皮
- **高光控制** — 允许天空/窗光等高光轻微过曝，但需保留层次不死白

## 四、日系清新场景空间元素

日系清新世界观特有的场景元素及其视觉叙事功能：

- **街道与电线构图** — 住宅街角的电线杆、电线与天空是天然构图线，制造日常纵深感与生活气息
- **铁道口与道闸** — 时间流动与告别的经典意象，道闸起落直接映射人物心理节奏
- **便利店/自动贩卖机** — 都市夜归的暖点光源，情绪缓冲与治愈容器
- **公园与河堤** — 开阔的绿色呼吸空间，用于情绪释放与段落转场
- **空镜过渡建议** — 天空与电线、风吹草浪、汽水气泡、光斑晃动、纱帘飘动，可作为段落呼吸口与时间流逝暗示
- **留白构图即叙事** — 大量负空间（天空/白墙/水面）承接情绪，转折优先用留白与视线错位承接，减少对白解释负担

## 五、日系清新乐器与环境音

日系清新世界观下的声音元素约束：

### 乐器选择

- **原声吉他** — 日常、散步、青春段落核心乐器，木质感温暖
- **钢琴极简** — 安静、留白、回忆段落的铺底
- **尤克里里/曼陀林** — 雀跃、轻快段落的点缀
- **弦乐轻铺** — 情绪抬升（告别/和解）时进入，音量克制
- **八音盒/玩具钢琴** — 回忆与闪回段的音色符号
- **环境音优先级高** — 日系清新中真实环境声是治愈感关键，配乐不应压过环境与对白

### 乐器组合策略

| 情绪阶段 | 乐器组合 |
|---|---|
| 平稳/开场/收尾 | 原声吉他独奏 或 钢琴极简 |
| 日常推进 | 原声吉他 + 轻打击（沙锤/拍手） |
| 暧昧升温/心动 | 钢琴 + 弦乐轻铺 |
| 雀跃/出游 | 尤克里里 + 口哨/轻打击 |
| 告别/回忆 | 钢琴极简 + 八音盒音色 |

### 日系清新环境音

- **典型环境音层次** — 便利店门铃叮咚 / 铁道口警铃与电车通过声 / 蝉鸣与虫鸣 / 树叶沙沙与风声 / 自行车铃声 / 河堤流水声 / 鸟鸣 / 冰块在玻璃杯中的碰撞声
- **每场戏标注 1-2 个核心环境音**，帮助后续音效设计。环境音层次越准确，日系写实质感越强
- **留白建议** — 日系清新重视"静"：每场戏至少保留 2-3 秒纯环境音无配乐段落；配乐淡入淡出，避免情绪铺满
