# 场景图生成 · 日系清新写实约束手册

---

## 一、场景美学原则

1. **空间叙事** — 场景承载情绪与叙事功能（日常漫步/青春记忆/告别时刻），不是纯背景板
2. **层次纵深** — 所有场景必须具备前/中/后景，杜绝扁平
3. **质感至上** — 原木/棉麻/白墙/绿植/玻璃等材质纹理必须清晰自然
4. **实拍为锚** — 一切画面以真实摄影为标准，拒绝 3D 渲染/CG 动画质感；追求镜头光学特征（浅景深、柔焦、细腻胶片颗粒、轻微漏光）与物理光照（窗光漫射、逆光空气感、树叶间隙光斑）

## 三、室内场景

### 空间规范

| 维度 | 约束 | 提示词 |
|---|---|---|
| 风格 | 日系咖啡店/便利店/公寓/教室，木质+白墙+绿植的自然素材风 | 日系{风格}空间 |
| 材质 | 原木/棉麻/和纸/白瓷/玻璃为主 | 原木桌椅、棉麻窗帘、白瓷杯 |
| 色调 | 低饱和青绿 + 奶白 + 浅木色 | 低饱和、奶白基调、浅木色 |
| 纵深 | 前/中/后景层次 | 前景{元素}、中景{元素}、后景{元素} |
| 质感 | 木纹/布纹/纸纹可辨 | 纹理清晰、质感写实 |
| 光照 | 窗光漫射为主，纱帘柔化，高光轻微过曝，逆光空气感 | 窗边柔光、逆光空气感、纱帘透光 |
| 镜头感 | 浅景深虚化、柔焦、细腻胶片颗粒、边缘轻微暗角 | shallow depth of field、soft focus、fine film grain |
| 瑕疵感 | 木器使用痕迹、杯沿水渍、纸张卷边 | 使用痕迹、生活温度、自然旧感 |

### 室内类型速查

| 类型 | 核心元素 | 氛围词 |
|---|---|---|
| 日系咖啡店 | 原木桌、吧台、杂货架、窗边座 | 安静、光线柔和 |
| 便利店 | 货架、冷柜、玻璃门、杂志架 | 日常烟火、夜归暖点 |
| 公寓房间 | 木地板、矮桌、白窗帘、绿植 | 素朴、松弛 |
| 教室/图书室 | 课桌椅、书架、窗边桌面 | 青春、安静 |
| 玄关/洗手台 | 镜面、木柜、拖鞋、搪瓷盆 | 日常细节、生活温度 |

## 四、室外场景

### 空间规范

| 维度 | 约束 | 提示词 |
|---|---|---|
| 类型 | 住宅街角/铁道口/公园/河堤/商店街 | {场景}，{季节}，{时间} |
| 天候 | 晴/薄云/阴/细雨/初雪 | 薄云柔光、细雨微湿 |
| 植被 | 行道树/草坡/花坛/爬藤（须符合季节） | 行道树、草坡绿意 |
| 水体 | 河面/喷泉需有柔和反光 | 河面微光、波光柔和 |
| 建筑 | 低层住宅、坡屋顶、电线杆、路牌 | 住宅街角、电线与天空 |
| 空气感 | 必须有空气透视与通透雾感，远处偏青偏白 | 远景青白、空气感、通透 |
| 光照 | 自然光为唯一光源，逆光/半逆光优先 | 逆光轮廓、半逆光、自然漫射 |
| 镜头感 | 浅景深、柔焦光斑、细腻胶片颗粒、边缘轻微暗角 | shallow depth of field、soft bokeh、film grain |
| 瑕疵感 | 路面细裂纹/墙面雨痕/长椅掉漆 | 使用痕迹、时间感、自然旧感 |

### 室外类型速查

| 类型 | 核心元素 | 氛围词 |
|---|---|---|
| 住宅街角 | 电线杆、路牌、矮围墙、信箱 | 生活流、散步感 |
| 铁道口 | 道闸、铁轨、警示灯、碎石道床 | 时间流动、告别感 |
| 公园绿地 | 草坪、大树、木长椅、步道 | 治愈、呼吸感 |
| 河堤坡道 | 护栏、斜坡草甸、远山天空 | 青春、开阔 |
| 商店街 | 招牌雨棚、自行车、杂货铺门口 | 日常热闹、烟火气 |

## 五、主视图规范

### 视图定义

> 单画面主视图，从场景中最具代表性的角度拍摄，承载空间叙事与构图重心。

| 项目 | 约束 | 提示词 |
|---|---|---|
| 视角 | 自然观察视角，构图最能体现场景主体与纵深 | hero shot、representative angle |
| 视点高度 | 默认人眼平视高度，特殊场景可俯/仰 | eye level（默认） |
| 构图 | 主体居中或符合三分法，保留留白与呼吸感 | balanced composition、negative space |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 单画面（非拼图、非多视图、非分屏） |
| 人物 | **严禁出现任何人物、人影、人体轮廓** |
| 一致性 | 风格/材质/色调/光线统一 |
| 光线 | 单一光源逻辑，光影方向一致 |
| 画面比例 | 默认 16:9（或按调用方设定） |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 场景必须有「前中后景层次」 |
| R2 | 室外必须包含「空气透视」 |
| R3 | 场景图必须为「单画面主视图」，不得拼接多视图/分屏/网格 |
| R4 | 构图须能代表场景主体并展示前/中/后景层次 |
| R5 | 场景图中**严禁出现任何人物** |
| R6 | 必须包含实拍摄影关键词（real photography / photorealistic / RAW photo） |
| R7 | 必须包含镜头光学特征（shallow depth of field / soft focus / fine film grain 至少一项） |
| R8 | 材质必须带有自然使用痕迹与生活温度，禁止全新无瑕的"CG 感" |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 背景纯白/纯黑/无场景 |
| X2 | 极端天候（暴风雨/雷电/暴雪，除非剧情需要） |
| X3 | 场景无纵深/无层次 |
| X4 | 植被/天候与季节矛盾 |
| X5 | 出现任何人物、人影、人体剪影或人体轮廓 |
| X6 | 画面被拼接成多视图/网格/分屏布局 |
| X7 | 3D 渲染/CG 动画/卡通/游戏引擎质感（禁用 3D render、CGI、Unreal Engine、Unity 等词） |
| X8 | 材质过于干净完美、无任何使用痕迹与生活气息（避免"塑料感"） |
| X9 | 高对比硬光、浓艳饱和色调、厚重滤镜感（破坏空气感与留白） |
