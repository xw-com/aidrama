# 人物基础形象生成 · 日系清新写实约束手册

---

## 一、基础形象原则

1. **面容即灵魂** — 五官是角色唯一锚点，毛孔级精细渲染
2. **角色为本** — 基础着装由角色描述（身份/职业/性别/场景）决定其常规着装；后续特定服化为叠加层
3. **四视图一致** — 面容/体型/发型/基础服装跨视图高度统一
4. **自然真实** — 无妆状态仍需体现角色气质（干净/柔软/安静/元气）
5. **实拍摄影** — 以真实摄影为锚点，保留皮肤真实质感（毛孔/微小瑕疵）

---

## 二、面容约束

> 不再固定五官特征参数，由角色描述（性别/年龄/性格/气质）驱动 AI 自由生成五官，保证人物间外观差异化。

### 通用要求

| 项目 | 约束 |
|---|---|
| 五官 | 由角色描述自然推导，不预设脸型/眼型/眉型/鼻型/唇型 |
| 风格底色 | 真人写实摄影、胶片写真质感、素肌透明感、自然光影、低饱和色调 |
| 气质 | 必须从角色描述提炼整体气质关键词（如干净/柔软/安静/元气），并写入提示词 |
| 表情 | 中性微表情，符合角色气质 |

## 六、基础服装约束

> 基础服装由角色描述（身份/职业/性别/场景）决定其最自然的常规着装，作为该角色「日常默认态」；正式服饰/特殊衍生在服化衍生环节叠加。**禁止内衣打底**。

### 着装选择原则

| 角色身份 | 默认着装方向 |
|---|---|
| 学生 | 白衬衫+针织背心+百褶裙 / 制服连衣裙 |
| 上班/年轻职员 | 浅色通勤装（白衬衫+直筒裤/过膝裙） |
| 居家/休闲 | 棉麻家居服、宽松 T 恤+阔腿裤 |
| 约会/出游 | 白裙/浅色碎花连衣裙/浅色棉麻连衣裙 |
| 运动/社团 | 简约运动装（浅色 T 恤+运动短裙/短裤） |
| 特殊职业 | 对应身份服装（店员/教师/花艺师等） |
| 角色描述未明确 | 白裙或白衬衫+浅色下装、低饱和浅色系 |

### 着装统一规则

- 服装风格须与日系清新写实摄影美学一致（低饱和浅色系、棉麻/针织/雪纺等写实材质）
- 颜色以奶白/雾青/浅原木/淡粉等低饱和浅色为主，无复杂花纹/装饰，便于后续衍生叠加
- 四视图服装款式完全一致
- 基础服装是「日常默认态」，焦点仍在面容与体态
- 严禁内衣/暴露/性化打底

## 八、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须为「自然状态」|
| R2 | 必须根据角色描述声明合适的常规着装作为基础服装（如学生→白衬衫+百褶裙、上班→浅色通勤装、居家→棉麻家居服）；禁止内衣打底 |
| R3 | 必须声明「无发饰、无配饰」 |
| R4 | 必须指定「纯净云灰背景」 |
| R5 | 必须指定「四视图一致性」 |
| R6 | 全身立像必须从头顶到脚底完整展示，严禁裁切 |
| R7 | 必须声明角色身高并通过头身比换算约束全身比例 |
| R8 | 人像特写必须从头顶到锁骨完整展示，严禁裁切头顶 |
| R9 | 皮肤必须保留素肌真实质感与透明感，不可过度磨皮 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 内衣/暴露/性化打底；与角色描述明显不符的着装；过度复杂花纹/装饰干扰后续服化叠加 |
| X2 | 正顶硬光/正底光/彩色光 |
| X3 | 过度美白/过度磨皮至无质感 |
| X4 | 复杂场景背景（必须纯灰底） |
| X5 | 夸张表情/动态姿势 |
| X6 | 全身立像裁切头顶或脚底，必须从头到脚完整入画 |
| X7 | 人像特写裁切头顶，必须从头顶到锁骨完整入画 |
| X8 | 忽略身高和头身比约束 |
