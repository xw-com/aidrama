# 3D潮玩约束 · 3D潮玩手办盲盒 · 技法参考

---

## 一、色调体系与画面基调

- **色调基底** — 全片以潮玩粉（C1）、电光蓝（C2）、奶白（C5）为基底色，整体色温偏中性（影棚主光 5500K），展示柜 LED 偏冷（6000K），饱和度中高（60-75%），对比度中低（35-50%），呈现潮玩手办干净通透、糖果饱满的色调
- **情绪色盘驱动** — 六套情绪色盘（开箱惊喜/限定奢华/萌系治愈/街头酷玩/派对狂欢/收藏静谧）对应不同叙事段落，色盘切换应与故事弧线同步
- **冷暖叙事对比** — 暖色（潮玩粉 C1、芥末黄 C3、薄荷绿 C4）作为开箱期待、治愈、派对段落的视觉信号；冷色（电光蓝 C2、哑光黑 C6、镭射白 C7）用于限定陈列、收藏静谧、神秘隐藏款段落
- **色盘先行原则** — 段落规划需先绑定情绪场景（开箱惊喜/限定奢华/萌系治愈/街头酷玩/派对狂欢/收藏静谧等），再确定主色+辅色与光影方案，避免"剧情对了但情绪不对色"
- **禁用色域** — 高饱和荧光霓虹刺眼色、暗黑恐怖调、传统东方古典风格色（朱红宫墙 / 青绿山水 / 古典写意等）均与本风格不兼容

## 二、光影方案体系（光影矩阵）

- **光影即叙事** — 7 套光影方案对应不同情绪段落，导演规划阶段应在段落层面确定光影基调方向，而非逐镜指定
- **3D渲染光影特征** — 影棚柔光箱干净漫射、镭射/全息反光、展示柜 LED 背光、糖果色高光为潮玩风格的核心光影手段，所有光影方案均须体现 PBR 物理材质渲染质感

| 光影方案 | 方案名 | 色调倾向 | 适用情绪 |
|---|---|---|---|
| A | 柔光开箱 | 奶白底 + 潮玩粉/芥末黄高光 + 干净漫射 | 开箱惊喜、萌系治愈、日常期待 |
| B | 镭射反光 | 镭射白全息 + 电光蓝反射 + 彩虹色散 | 限定奢华、联名稀有、隐藏款揭幕 |
| C | 展柜 LED | 透明亚克力背光 + 冷调 LED + 低阴影 | 收藏静谧、限定陈列、编号展示 |
| D | 派对霓虹 | 糖果色霓虹 + 亮片闪烁 + 高饱和 | 派对狂欢、新品发售、庆典 |
| E | 影棚漫射 | 奶白柔光箱 + 均匀漫射 + 无硬影 | 开箱桌面、小影棚、产品主图 |
| F | 签名高定 | 侧光 + 哑光黑背景 + 单点亮光 | 限量编号、签名款、稀有特写 |
| G | 节日彩光 | 薄荷绿/潮玩粉彩光 + 暖光点缀 | 节日限定、庆祝、圣诞/万圣 |

- **冷暖光分配** — 暖色光（潮玩粉/芥末黄）适用于开箱、治愈、派对段落；冷色光（电光蓝/镭射白）适用于限定陈列、收藏静谧段落。导演可根据叙事需要调整冷暖切换点
- **氛围方向映射** — 每场戏的氛围方向应能映射到上述光影方案（A-G）的某一方向，确保视觉一致性
- **避免硬阴影** — 所有方案默认避免硬阴影，仅签名高定（F）允许侧光形成的柔和明暗对比

## 三、质感方向

- **3D手办渲染为锚** — 潮玩风格的核心：高精度建模、光泽乙烯塑料质感、圆润倒角、镭射全息反光、展示底座，呈现电影级 3D 手办渲染画面
- **光泽乙烯+哑光混搭** — 所有手办角色的材质必须通过 PBR 物理渲染可信：乙烯塑料的光泽高光、哑光部位的雾面对比、亚克力的通透折射、镭射全息的彩虹色散、金属铆钉的冷光泽
- **圆润倒角与 Q 版比例** — 所有造型边缘圆润倒角，无锐利棱角；Q 版大头小身（2-3 头身）比例锁定；禁止写实人体比例与真人肌肤质感
- **底座与展示感** — 手办默认立于展示底座，呈现"产品主图（product hero）"式构图；展示底座是潮玩画面的灵魂元素
- **3D不等于冰冷** — 潮玩强调可爱治愈与收藏精致感，通过糖果色、圆润造型、开箱期待传达情感，而非依赖奇观特效或写实渲染

## 四、潮玩场景空间元素

潮玩盲盒世界观特有的场景元素及其视觉叙事功能：

- **展示柜/亚克力盒** — 天然的框架式构图道具，制造通透层次感与"被珍藏"的叙事。3D 渲染中亚克力的折射与 LED 背光穿透是画面亮点
- **盲盒包装盒/撕口** — 开箱叙事的核心载体：密封 = 期待、撕膜 = 惊喜临近、全开 = 揭晓。3D 场景中纸盒哑光与镭射封口贴的对比是关键
- **展示底座/转台** — 手办的"舞台"，转台旋转展示是潮玩视频的标志性运镜；底座编号/烫金暗示稀有度
- **气球/缎带/亮片** — 派对与发售段的氛围元素，亮片飘洒与镭射反光制造"庆典感"
- **镭射贴纸/编号卡** — 限定身份的视觉符号，全息反光暗示稀有与珍藏价值
- **段落间用场景空镜过渡** — 本风格有丰富的场景资产（不同时段/氛围变体），段落衔接建议用展示柜空镜、转台旋转空镜做情绪缓冲，不要硬切
- **转折点用视觉而非台词** — 优先使用画面手段（光影突变、镭射激活、亮片爆开、景别跳切）而非依赖对白解释

## 五、潮玩音效与音乐

潮玩盲盒世界观下的声音元素约束：

### 乐器与音色选择

- **音乐盒 / 玩具钢琴** — 开箱定调、萌系治愈段落的核心音色，最能表现童趣与期待
- **马林巴 / 颤音琴** — 限定陈列、精致展示段落，清亮的木琴音色适合稀有高级感
- **拨弦小提琴（pizzicato） / 弹拨乐** — 轻快节奏、开箱动作、配件展示段落，跳跃拨弦制造活泼感
- **合成器铺底（synth pad）** — 派对狂欢、霓虹彩光段落，现代电子质感适合潮酷氛围
- **8-bit 方波 / chiptune** — 街头酷玩、复古联名段落，像素游戏音色增添潮玩玩味
- **卡林巴（拇指琴）/ 锅垫琴（glockenspiel）** — 治愈日常、收藏静谧段落，柔和金属音色温暖治愈
- **Lo-fi 鼓点 / 轻打击乐** — 街头、潮玩熊、滑板段落，慵懒节拍适合酷玩氛围

### 乐器组合策略

| 情绪阶段 | 乐器组合 |
|---|---|
| 开箱期待/开场/收尾 | 音乐盒独奏 或 音乐盒 + 卡林巴 |
| 萌系治愈/柔软 | 卡林巴 + 锅垫琴 + 轻弦乐 |
| 限定陈列/稀有高级 | 马林巴 + 颤音琴 + 弦乐铺底 |
| 街头酷玩/潮玩熊 | Lo-fi 鼓点 + 8-bit 方波 + 拨弦 |
| 派对狂欢/发售庆典 | 合成器 pad + 轻打击乐 + 鼓点 |
| 收藏静谧/专注 | 锅垫琴独奏 + 极轻弦乐 |
| 揭晓惊喜（高潮） | 拨弦急促 + 合成器上扬 + 鼓点爆发 |

### 潮玩环境音

- **典型环境音层次** — 撕开封口贴的"嗤"声 / 塑料配件摩擦的窸窣 / 盲盒轻晃时盒内物品晃动 / 展示柜 LED 微弱嗡鸣 / 亮片落下的沙沙声 / 气球摩擦的吱吱声 / 转台电机微转 / 亚克力盒开合的清脆
- **每场戏标注 1-2 个核心环境音**，帮助后续音效设计。环境音层次越丰富，潮玩场景越有沉浸感与开箱临场感
