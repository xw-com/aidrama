# 潮玩道具图像生成 · 约束手册

---

## 一、道具设计原则

1. **潮玩专属** — 所有道具必须为潮玩盲盒世界观专属（包装、底座、配件、身份卡等），禁止写实生活用品
2. **质感极致** — 材质纹理必须清晰可辨（乙烯光泽/亚克力透明/镭射全息/纸盒哑光/金属铆钉）
3. **尺度配套** — 道具须与手办尺度配套（8-12cm 手办世界），通过陈列方式暗示真实尺寸
4. **纯道具独立展示** — 画面中只能出现道具本身，严禁出现任何手办人物、手部、肢体，道具不可处于被持有/佩戴状态，必须以静物陈列方式独立呈现

## 三、多角度设定图规范

### 视图定义

| 位置 | 视图 | 角度 | 要求 | 提示词 |
|---|---|---|---|---|
| 左上 | 正面图 | 正面 0° | 道具完整正面形态 | front view |
| 右上 | 侧面图 | 侧面 90° | 厚度/轮廓/结构清晰 | side view |
| 左下 | 背面图 | 背面 180° | 道具背部结构/装饰 | back view |
| 右下 | 细节特写 | 局部放大 | 材质纹理/工艺细节（镭射/烫金/卡扣） | detail closeup |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 同一画面四宫格（2×2），上下左右四视角 |
| 背景 | 展柜灰纯色 #C8CDD2 |
| 光线 | 均匀柔光，无硬阴影，镭射反光处允许局部高光 |
| 比例 | 每格道具占格内主体 70%+ |
| 投影 | 允许自然地面微投影 |
| 画面比例 | 建议 1:1 |

## 六、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须指定「展柜灰纯色背景 #C8CDD2」 |
| R2 | 必须明确道具材质与工艺（乙烯/亚克力/镭射/纸盒/金属） |
| R3 | 道具造型必须符合潮玩盲盒世界观，禁止写实生活用品 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 复杂场景背景 |
| X2 | 道具与手办人物同画面（本环节为纯道具图） |
| X3 | 出现任何手办人物形象，包括全身、半身、局部（手、手指、手臂等肢体） |
| X4 | 道具处于被持有、握持、佩戴、使用中的状态 |
| X5 | 出现暗示人物存在的元素（如手持痕迹、佩戴视角、使用姿态） |
| X6 | 写实生活用品（必须为潮玩盲盒专属道具） |
