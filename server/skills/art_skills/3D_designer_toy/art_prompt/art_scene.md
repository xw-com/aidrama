# 潮玩场景图生成 · 约束手册

---

## 一、场景美学原则

1. **空间叙事** — 场景承载"展示 / 开箱 / 收藏 / 发售"的叙事功能，不是纯背景板
2. **层次纵深** — 所有场景必须具备前/中/后景，杜绝扁平
3. **质感至上** — 亚克力/纸盒/金属货架/LED 灯带等材质纹理必须超清晰
4. **3D为锚** — 一切画面以 3D 渲染为标准，拒绝平面贴图/2D 插画/CG 动画质感；追求体积光、环境光遮蔽、景深虚化等电影渲染效果

## 三、室内场景

### 空间规范

| 维度 | 约束 | 提示词 |
|---|---|---|
| 风格 | 潮玩展示柜/开箱桌面/潮玩店货架/小影棚/收藏展示墙 | 潮玩{类型}场景 |
| 材质 | 亚克力/纸盒/金属货架/LED 灯带/玻璃门 | 透明亚克力、金属货架、LED 灯带 |
| 色调 | 糖果色彩盘 + 奶白主调 + 展柜灰中性 | 糖果色调、奶白主调、干净通透 |
| 纵深 | 前/中/后景层次 | 前景{元素}、中景{元素}、后景{元素} |
| 质感 | 亚克力折射/纸盒哑光/金属冷光可辨 | 纹理清晰、材质质感精细 |
| 光照 | 影棚柔光箱为主、展示柜 LED 背光、镭射反光点缀 | 影棚柔光箱、LED 背光、镭射反光 |
| 镜头感 | 景深虚化前后景、镜头暗角、色散微痕 | depth of field、lens vignette、chromatic aberration |
| 瑕疵感 | 货架微反光、纸盒棱角锋利、亚克力边缘抛光 | 全新陈列感、棱角锋利、边缘抛光 |

## 五、主视图规范

### 视图定义

> 单画面主视图，从场景中最具代表性的角度拍摄，承载展示叙事与构图重心。

| 项目 | 约束 | 提示词 |
|---|---|---|
| 视角 | 自然观察视角，构图最能体现场景主体与纵深 | hero shot、representative angle |
| 视点高度 | 默认人眼平视高度（展示柜/桌面可微俯），特殊场景可俯/仰 | eye level（默认） |
| 构图 | 主体居中或符合三分法，前/中/后景层次清晰 | balanced composition |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 单画面（非拼图、非多视图、非分屏） |
| 人物 | **严禁出现任何写实人物、人影、人体轮廓**（手办人物由独立资产提供，场景图保持无人） |
| 一致性 | 风格/材质/色调/光线统一 |
| 光线 | 单一光源逻辑，光影方向一致 |
| 画面比例 | 默认 16:9（或按调用方设定） |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 场景必须有「前中后景层次」 |
| R2 | 室外/快闪场景必须包含「空气透视」 |
| R3 | 场景图必须为「单画面主视图」，不得拼接多视图/分屏/网格 |
| R4 | 构图须能代表场景主体并展示前/中/后景层次 |
| R5 | 场景图中**严禁出现任何写实人物** |
| R6 | 必须包含 3D 渲染关键词（3D rendered / volumetric lighting / PBR materials） |
| R7 | 必须包含镜头光学特征（depth of field / lens vignette / bokeh 至少一项） |
| R8 | 材质必须带有陈列/展示质感，禁止脏污破败 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 背景纯白/纯黑/无场景 |
| X2 | 极端天候（暴风雨/雷电/暴雪，除非剧情需要） |
| X3 | 场景无纵深/无层次 |
| X4 | 写实生活化脏乱（必须是潮玩展示/开箱/收藏场景） |
| X5 | 出现任何写实人物、人影、人体剪影或人体轮廓 |
| X6 | 画面被拼接成多视图/网格/分屏布局 |
| X7 | 低精度建模/粗糙贴图/廉价塑料感（禁用 low-poly、rough modeling 等词） |
| X8 | 写实真人质感或写实生活场景（必须为潮玩展示场景） |
| X9 | 传统东方古典风格（东方古韵 / 写意古典等传统东方元素） |
