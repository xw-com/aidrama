# 手办角色基础形象生成 · 约束手册

---

## 一、手办造型原则

1. **造型即灵魂** — Q 版大头小身比例是核心锚点，圆润倒角、线条柔和，呈现潮玩手办的萌系造型
2. **素体即基础** — 基础素体（奶白底色 + 无主题涂装）为底模，后续涂装、配件、底座均为叠加层
3. **四视图一致** — 面容/头身比/素体造型/基础站姿跨视图高度统一
4. **萌系气质** — 无主题涂装状态仍需体现手办气质（萌系治愈/潮酷/呆萌/傲娇）
5. **底座必备** — 手办默认立于透明展示底座之上，体现"产品主图"式展示感

---

## 二、面容约束

> 不固定五官参数，由 IP 角色描述（类型/性格/气质）驱动 AI 自由生成 Q 版五官，保证手办间外观差异化。但所有五官必须符合 Q 版萌系比例。

### 通用要求

| 项目 | 约束 |
|---|---|
| 五官 | 由 IP 角色描述自然推导，但默认 Q 版大眼圆脸、小鼻小嘴 |
| 风格底色 | 3D 手办渲染、高精度建模、光泽乙烯质感、影棚级光影 |
| 比例 | 眼睛占面部 1/3 以上、圆脸或包子脸、五官集中于面部下半 |
| 气质 | 必须从 IP 角色描述提炼整体气质关键词（如萌系治愈/潮酷玩味/呆萌傲娇），并写入提示词 |
| 表情 | 中性微表情（默认微笑或呆萌直视），符合 IP 气质 |

---

## 三、质感约束

> 手办表面非真人肌肤，而是乙烯塑料涂装。按部位区分光泽与哑光。

### 光泽部件（乙烯高光）

| 项目 | 约束 | 提示词 |
|---|---|---|
| 主体涂装 | 光泽乙烯塑料质感、表面微反光高光 | glossy vinyl texture、glossy plastic finish、表面微反光高光 |
| 光泽 | PBR 材质渲染、塑料高光、非哑光 | PBR 渲染、乙烯光泽、塑料反光 |
| 质感 | 高精度建模、圆润倒角、边缘柔和 | 高精度建模、圆润倒角、柔和边缘 |

### 哑光部件（雾面涂装）

| 项目 | 约束 | 提示词 |
|---|---|---|
| 局部涂装 | 哑光部位（如耳朵内侧、足底、配饰局部） | matte finish parts、哑光涂装、雾面质感 |
| 对比 | 与光泽主体形成光哑对比 | 光泽与哑光混搭、光哑对比 |

---

## 四、Q版体型约束

> 潮玩手办不区分写实性别体型，统一为 Q 版大头娃娃比例。所有角色按"系列/类型"而非"性别"定义。

### 通用 Q 版体型

| 项目 | 约束 | 提示词 |
|---|---|---|
| 头身比 | 2 头身至 3 头身（大头小身），萌系公仔比例 | 2-3 heads tall、chibi proportion、大头娃娃比例 |
| 头部 | 占全身 1/2 至 1/3、圆润饱满 | oversized head、圆润饱满头部 |
| 四肢 | 短小粗圆、圆润倒角、无写实关节 | stubby limbs、圆润短小四肢、无写实关节 |
| 手足 | 小而圆、简化造型、无写实手指 | simplified round hands、圆头小手 |
| 体态 | 站立于展示底座、微前倾或正直、萌系端正 | standing on display base、萌系端正站姿 |
| 身高 | 由 IP 设定指定，默认 8-12cm 手办尺度（图面不标尺） | collectible figure scale、8-12cm 手办尺度 |

## 五、基础素体约束

> 仅定义奶白素体造型，主题涂装与配件在衍生涂装环节叠加。

### 通用基础素体

| 项目 | 约束 | 提示词 |
|---|---|---|
| 素体色 | 奶白（C5 #F5F0E8）底色 | milk white base、奶白素体 |
| 质感 | 光泽乙烯为主、局部哑光 | glossy vinyl body、奶白光泽素体 |
| 造型 | Q 版大头娃娃、圆润倒角 | chibi figure、圆润倒角造型 |
| 主题涂装 | 无主题涂装（素体状态） | unpainted blank figure、素体状态 |

## 六、基础发型/头饰约束

> 仅定义基础头部造型，主题头饰（帽子/耳朵/角等）在衍生涂装环节叠加。

### 通用基础头部

| 项目 | 约束 | 提示词 |
|---|---|---|
| 头型 | 圆润饱满、与素体一体成型 | smooth round head、一体成型头部 |
| 五官 | Q 版大眼 + 小嘴 + 腮红圆点（基础款） | big eyes、small mouth、blush dots |
| 头发/头饰 | 无（素体光头或基础头型，等待涂装） | blank head、基础头型 |

## 八、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须为「素体状态（无主题涂装）」 |
| R2 | 必须声明基础素体（奶白 C5 光泽乙烯素体） |
| R3 | 必须声明「无主题头饰、无配件」 |
| R4 | 必须指定「展柜灰纯色背景 #C8CDD2」 |
| R5 | 必须指定「四视图一致性」 |
| R6 | 全身立像必须从头顶到脚底（含底座）完整展示，严禁裁切 |
| R7 | 必须声明 Q 版头身比（2-3 头身大头娃娃比例）并体现全身比例 |
| R8 | 手办特写必须从头顶到胸口完整展示，严禁裁切头顶 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 基础素体以外的任何主题涂装/配件/底座装饰 |
| X2 | 正顶硬光/正底光/浓重阴影 |
| X3 | 写实真人肌肤质感（必须为乙烯塑料涂装） |
| X4 | 复杂场景背景（必须纯色） |
| X5 | 写实人体比例（必须为 Q 版大头小身） |
| X6 | 全身立像裁切头顶或脚底/底座，必须从头到脚完整入画 |
| X7 | 手办特写裁切头顶，必须从头顶到胸口完整入画 |
| X8 | 传统东方古典风格（东方古韵 / 写意古典等传统东方元素） |
