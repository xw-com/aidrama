# 3D潮玩手办盲盒风格

本风格专为"3D潮玩手办盲盒"题材打造，所有美术提示词、规范和生成内容均严格限定于：

- **3D手办渲染**：以三维建模渲染技术呈现潮玩手办、盲盒公仔、设计师玩具（Designer Toy），涵盖 Q 版公仔、限量手办、IP 联名款等
- **Q版萌系比例**：2-3 头身大头小身、圆润倒角、短小四肢，呈现 Pop Mart / Be@rbrick / Sonny Angel 式的可爱手办造型
- **潮玩质感混搭**：光泽乙烯塑料（glossy vinyl）+ 哑光部位（matte parts）混搭，部分区域镭射/全息反光，表面微反光高光
- **糖果色彩盘**：潮玩粉、电光蓝、芥末黄、薄荷绿、奶白、哑光黑为主的糖果色体系，色彩干净通透
- **展示与开箱氛围**：手办立于展示底座或包装场景中，呈现"产品主图（product hero）"式构图与开箱期待感
- **影棚级光影**：影棚柔光箱干净漫射、镭射/全息反光、糖果色高光、展示柜内置 LED 背光，避免硬阴影

## 适用范围

- 3D潮玩手办盲盒题材的 AI 美术生成（角色手办、展示场景、配件道具、分镜等）
- 需要 3D 手办质感、Q 版萌系造型、糖果色彩盘的视觉创作
- 潮玩 IP 开发、盲盒产品主图、设计师玩具概念设计、潮玩短剧动画等应用场景

## 严禁内容

- 写实人物摄影 / 照片级真人质感（手办必须是 3D 渲染的 Q 版公仔，不是真人）
- 2D 卡通 / 二次元 / 扁平插画（必须是 3D 渲染，有体积感与倒角）
- 传统东方古典风格（东方古韵 / 写意古典 / 传统东方绘画等元素）（本风格为现代潮玩，与传统东方风格互斥）
- 粗糙建模 / 低面数 low-poly / 模糊贴图 / 廉价塑料感
- 过度写实的人物肌肤纹理（手办表面应为乙烯塑料/哑光涂装，而非真人皮肤）
- 阴暗恐怖 / 血腥 / 战争题材

## 风格体验

在本风格下，您将体验到：

- 手办角色造型圆润可爱，3D 建模细腻，Q 版大头小身比例，乙烯光泽与哑光部位混搭
- 展示场景干净通透，展示柜 LED 背光与影棚柔光箱结合，糖果色高光与镭射反光点缀
- 配件道具精致小巧，盲盒包装、透明底座、编号卡、镭射贴纸等潮玩专属元素考究
- 分镜与渲染均强调 3D 手办质感、展示感、开箱期待感与影棚级光影
