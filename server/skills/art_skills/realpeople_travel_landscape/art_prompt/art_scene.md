# 场景图生成 · 旅游风光约束手册

---

## 一、场景美学原则

1. **国家地理级风光叙事** — 场景是绝对主角，承载目的地辨识度与史诗感，不是纯背景板
2. **层次纵深** — 所有场景必须具备前/中/后景，广角史诗感与长焦压缩感并重
3. **地貌质感至上** — 岩石/沙地/雪线/植被/水体/古建等材质纹理必须超清晰
4. **实拍为锚** — 一切画面以真实摄影为标准，拒绝 3D 渲染/CG 动画质感；追求镜头光学特征（广角畸变、长焦压缩、景深虚化、镜头暗角、色散微痕）与物理光照（黄金时刻侧逆光、蓝调时刻冷辉、体积光、焦散投影）

## 三、室内场景

> 旅游风光以室外为主，室内仅作为补给/歇脚/民俗体验的过渡空间。

### 空间规范

| 维度 | 约束 | 提示词 |
|---|---|---|
| 风格 | 山间木屋/海岛民宿/古镇客栈/沙漠帐篷，当地民居 | {当地风格}民居 |
| 材质 | 原木/石材/土坯/织物/兽皮为主 | 原木梁、石墙、土坯墙面 |
| 色调 | 大地色 + 原木色 + 当地织物点缀 | 大地色调、原木色、民俗织物 |
| 纵深 | 前/中/后景层次 | 前景{元素}、中景{元素}、窗外{远景} |
| 质感 | 木纹/石纹/织物纹理可辨 | 纹理清晰、质感写实 |
| 光照 | 窗光为主+油灯/壁炉暖点光源，光线漫射，可见光束粒子 | 窗光漫射、壁炉暖光、光束穿窗 |
| 镜头感 | 浅景深虚化前后景、微镜头暗角、自然色温偏移 | shallow depth of field、lens vignette、natural color cast |
| 瑕疵感 | 木梁有使用痕迹、石墙有风化、织物有自然褶皱 | 使用痕迹、自然风化、织物自然垂褶 |
| 窗外 | 必须有窗外景观（山/海/街巷），强化目的地感 | 窗外可见{目的地景观} |

### 室内类型速查

| 类型 | 核心元素 | 氛围词 |
|---|---|---|
| 山间木屋 | 原木梁、壁炉、兽皮、窗外雪山 | 温暖庇护、山居静谧 |
| 海岛民宿 | 亚麻帘、藤编、窗外海景、贝壳 | 轻松惬意、海风通透 |
| 古镇客栈 | 木雕窗棂、青砖、天井、院落 | 古朴烟火、人文归属 |
| 沙漠帐篷 | 帆布、地毯、铜灯、星空缝口 | 苍茫庇护、游牧诗意 |

## 五、主视图规范

### 视图定义

> 单画面主视图，从目的地最具代表性的角度拍摄，承载风光叙事与构图重心。

| 项目 | 约束 | 提示词 |
|---|---|---|
| 视角 | 自然观察视角，构图最能体现目的地主体与纵深 | hero shot、representative angle、landscape composition |
| 视点高度 | 默认人眼平视高度，山岳可俯瞰、峡谷可仰视 | eye level（默认）、high vantage point、low angle |
| 构图 | 主体居中或符合三分法，前/中/后景层次清晰 | balanced composition、rule of thirds |

### 黄金时刻光影规则

| 项目 | 约束 |
|---|---|
| 时段 | 日出后 30 分钟内 / 日落前 30 分钟内 |
| 光位 | 侧逆光为主，低角度斜射 |
| 色温 | 5000-6500K，暖光铺底 |
| 阴影 | 长影拉伸，暗部保留细节不过曝 |
| 高光 | 边缘光勾勒山脊/人物轮廓，避免死白 |

### 蓝调时刻光影规则

| 项目 | 约束 |
|---|---|
| 时段 | 日落后 20-40 分钟 / 日出前 20-40 分钟 |
| 光位 | 天空漫射冷辉，无强直射光 |
| 色温 | 4000-4500K，冷蓝主调 |
| 对比 | 弱对比，保留天空与地面层次 |
| 点缀 | 人造暖光（灯火/帐篷灯）可作为冷暖对比点缀 |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 单画面（非拼图、非多视图、非分屏） |
| 人物 | **严禁出现任何人物、人影、人体轮廓** |
| 一致性 | 风格/材质/色调/光线统一 |
| 光线 | 单一光源逻辑，光影方向一致 |
| 画面比例 | 默认 16:9（或按调用方设定） |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 场景必须有「前中后景层次」 |
| R2 | 室外必须包含「空气透视」与「通透空气感」 |
| R3 | 场景图必须为「单画面主视图」，不得拼接多视图/分屏/网格 |
| R4 | 构图须能代表目的地主体并展示前/中/后景层次 |
| R5 | 场景图中**严禁出现任何人物** |
| R6 | 必须包含实拍摄影关键词（real photography / photorealistic / RAW photo） |
| R7 | 必须包含镜头光学特征（wide-angle / telephoto compression / shallow depth of field / lens vignette / bokeh 至少一项） |
| R8 | 地貌材质必须带有自然风化/真实纹理，禁止全新无瑕的"CG 感" |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 背景纯白/纯黑/无目的地地貌 |
| X2 | 极端天候（暴风雨/雷电/暴雪，除非剧情需要） |
| X3 | 场景无纵深/无层次 |
| X4 | 植被/天候与季节矛盾 |
| X5 | 出现任何人物、人影、人体剪影或人体轮廓 |
| X6 | 画面被拼接成多视图/网格/分屏布局 |
| X7 | 3D 渲染/CG 动画/卡通/游戏引擎质感（禁用 3D render、CGI、Unreal Engine、Unity 等词） |
| X8 | 地貌过于干净完美、无任何自然风化与岁月感（避免"塑料感"） |
| X9 | 光照过于均匀平坦、无景深虚化、无镜头光学特征、无空气透视 |
