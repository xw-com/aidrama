# 旅游风光风格说明

本风格专为"旅游风光"题材打造，所有美术提示词、规范和生成内容均严格限定于：

- **自然世界观**：以山川、海岸、沙漠、古镇、都市天际线、极光等真实目的地为背景，涵盖国家地理级风光与人文纪行，杜绝自然元素缺失。
- **真人写实**：所有角色、场景、道具均以真人写实摄影为标准，强调五官、皮肤、发丝、材质等极致细节与真实质感。
- **风光纪行纪实**：在写实基础上追求国家地理级氛围感，画面明暗对比强烈，细节丰富，整体氛围辽阔通透、大地色系、空气感充盈。
- **旷野氛围**：适合展现震撼、放松、探索惊喜的旅行故事，强调自然广域下的史诗感与人文点缀。

## 适用范围

- 旅游风光题材的AI美术生成（角色、场景、道具、分镜等）
- 需要极致写实、自然广角史诗感、黄金时刻与蓝调时刻氛围的视觉创作

## 严禁内容

- 卡通、动漫、插画、二次元风格
- 自然元素缺失、纯室内封闭空间叙事
- 高饱和荧光色、霓虹色、赛博色彩
- 暗示性、暴露、透视等不适宜内容

## 风格体验

在本风格下，您将体验到：

- 角色面容自然、气质旷达或亲和，服饰、妆容、发型均为旅人写实或当地民俗写实
- 场景空间辽阔深远，地貌纹理超清晰，氛围真实且富有目的地辨识度
- 道具、行李箱、相机、护照地图、纪念品等均为旅行实用造型，工艺精细，质感极致
- 分镜与视频均以真人写实为基础，强调自然光影叙事与目的地人文表达

---

本风格仅适用于"旅游风光"相关项目。如需其他风格（如古风、插画、动漫、都市等），请勿使用本套提示词。
