# 旅游风光风格约束 · 旅游风光 · 技法参考

---

## 一、色调体系与画面基调

- **色调基底** — 全片以沙岩米（C1）、暖麦肤（C2）、大地褐（C5）为基底色，整体色温偏暖（5000-6500K），饱和度中等（45-65%），呈现辽阔通透的自然大地感
- **冷暖叙事对比** — 暖色（黄金暖 C7、落日橘 C3）作为情感升温与目的地抵达的视觉信号，冷色（远山蓝灰 C6、雪山白 C10）用于蓝调时刻、孤寂、旷远等段落。冷暖切换应与情绪弧线同步
- **冷暖分配策略** — 探索与行走段落以中性/微暖为主，震撼与孤寂段落释放冷色；避免全程高暖导致空气感与层次塌陷
- **色盘先行原则** — 段落规划先绑定情绪场景（抵达旷野/漫步探索/登顶远眺/沙漠夕照/蓝调海岸等），再确定主色+辅色与光影方案，避免"剧情对了但情绪不对色"
- **禁用色域** — 高饱和荧光色、强霓虹污染、赛博色彩与本风格不兼容

## 二、光影方案体系

- **光影即叙事** — 6 套光影方案对应不同情绪段落，导演规划阶段应在段落层面确定光影基调方向，而非逐镜指定
- **光源角度** — 正给镜头默认低角度斜射（黄金时刻侧逆光），侧给镜头根据场景与人物关系微调

| 光影方案 | 方案名 | 色调倾向 | 适用情绪 |
|---|---|---|---|
| A | 黄金时刻侧逆光 | 暖金底 + 长影拉伸 | 抵达旷野、史诗震撼、目的地抵达 |
| B | 蓝调时刻冷辉 | 冷蓝底 + 灯火暖点 | 静谧海岸、孤寂夜行、过渡段 |
| C | 正午硬光高对比 | 中性偏冷 + 强明暗 | 地貌纹理凸显、坚毅行进 |
| D | 云海漫射过曝 | 灰白底 + 柔和高光 | 空灵意境、登顶远眺、留白 |
| E | 星空极光长曝光 | 深蓝/墨绿 + 极光漫射 | 神秘奇遇、永恒夜空 |
| F | 阴天雾天漫射冷光 | 灰蓝主调 + 暖色局部 | 低潮段、雨林深处、诗意过渡 |

- **冷暖光分配** — 暖光可全片使用但需分层控制；孤寂/苍茫段落降低暖光占比，避免情绪与光色冲突
- **氛围方向映射** — 每场戏氛围方向应映射到上述光影方案（A-F）的某一方向，确保视觉一致性

## 三、质感方向

- **风光摄影质感** — 国家地理级核心：广角史诗感收远，长焦压缩层叠地貌，景深合成保证前后景皆清晰，渐变滤镜平衡天空与地面光比
- **强对比度 + 极致细节** — 作为画面质感锚点。不是低对比小清新，不是重滤镜氛围化，而是可拍可落地的风光纪实感
- **地貌真实** — 岩石风化、沙地波纹、雪线颗粒、植被层次、水体反光都应符合自然地貌实拍逻辑
- **皮肤质感** — 保留真实毛孔与日晒痕迹，控制磨皮强度，追求"真实但好看"
- **写实不等于平淡** — 通过构图、景别、运动节奏放大情绪感染力，而非依赖夸张特效与过度后期

## 四、旅游风光场景空间元素

旅游风光世界观特有的场景元素及其视觉叙事功能：

- **地平线与天际线** — 风光叙事的核心骨架，地平线位置直接决定画面情绪（低地平线=辽阔史诗，高地平线=压抑孤寂）
- **山脊线/海岸线/沙丘曲线** — 天然引导线构图，制造纵深与视线流动，将观众视线引向目的地主体
- **云海/雾气/星空** — 空气感与时间流逝的载体，可用于段落缓冲与情绪升华，避免硬切
- **天气与时段作为转场** — 日转夜、晴转雾、黄金时刻入蓝调可用于段落情绪缓冲，光影变化即叙事转折
- **空镜叙事为长项** — 本风格以无人空镜叙事见长，风云流动、光影推移、浪涌风草均可承载情绪，须在规划阶段主动安排空镜过渡与视觉转折，减少对人物动作的依赖
- **转折点用视觉而非解释** — 优先使用画面手段（景别突变、光影切换、地平线位移）承接情绪转折，减少对白解释负担

## 五、旅行乐器与环境音

旅游风光世界观下的声音元素约束：

### 乐器选择

- **手鼓/打击乐** — 旷野行进、沙漠、非洲/中东目的地段落核心节奏，最能体现旅途律动
- **笛类（竹笛/排笛/木笛）** — 山川、古镇、亚洲目的地段落的有效主导，悠远旷达
- **弦乐（民谣吉他/马头琴/小提琴）** — 情绪抬升与情感爆发段落的主力铺底
- **世界音乐/环境电子** — 极光、星空、超现实地貌段落的风格增强器
- **环境音优先级高** — 风光片中自然环境声是沉浸感关键，配乐不应压过环境声

### 乐器组合策略

| 情绪阶段 | 乐器组合 |
|---|---|
| 平稳/开场/收尾 | 笛类独奏 或 民谣吉他独奏 |
| 行进推进 | 手鼓 + 弦乐铺底 |
| 震撼/登顶 | 弦乐主导 + 打击乐渐强 |
| 孤寂/苍茫 | 单件乐器独奏 + 长留白 |
| 极光/星空 | 环境电子 + 弦乐泛音 |
| 古镇人文 | 民族乐器（笛/琵琶/三味线等随目的地） |

### 旅行环境音

- **典型环境音层次** — 风声 / 浪涌声 / 鸟鸣 / 沙地脚步声 / 雪地嘎吱声 / 溪流声 / 篝火噼啪声 / 远处钟声 / 市集人声
- **每场戏标注 1-2 个核心环境音**，帮助后续音效设计。环境音层次越准确，风光纪行质感越强
- **留白建议** — 风光叙事应主动安排"纯环境音无配乐"段落，让目的地自身发声，强化沉浸感
