## 二、全局色彩盘（风格基线，不是硬锁）

> 目标：统一审美而非限制创作。除「硬约束色」外，其余颜色默认优先使用，可在合理范围内偏移。

### 色彩使用层级

| 层级 | 约束强度 | 说明 |
|---|---|---|
| L1 硬约束 | 高 | 仅锁定人物识别核心：肤色、发色、主服底色的审美方向 |
| L2 软约束 | 中 | 场景色、品牌点缀色优先参考色盘，可按品类与镜头微调 |
| L3 例外机制 | 低 | 节庆/促销/情绪高潮镜头可临时放大点缀色比重，但需保留明快洁净逻辑 |

### 硬约束色（默认锁定）

| 色项 | 对应色 | 规则 |
|---|---|---|
| 肤色基准 | C2 透亮暖肤 | 默认优先，允许小幅明度/暖度微调 |
| 发色/瞳色基准 | 自然深棕系（深棕/深栗/黑茶） | 默认优先，禁夸张漂色与荧光挑染 |

### 软约束色（推荐优先）

> C1/C3/C4/C5/C6/C7/C8/C9/C10 为推荐色域，用于服饰、场景、道具、点缀光、深色锚点等。可根据品牌品类与镜头氛围做同色相邻近调整。

### 情绪色盘使用规则

| 编号 | 规则 |
|---|---|
| E1 | 每条提示词至少指定 1 个「情绪场景」并绑定主色+辅色组合 |
| E2 | 单镜头主色不超过 2 个，点缀色仅落在产品或人物关系焦点 |
| E3 | 情绪切换时优先调整光比与轮廓光强度，再调整饱和度 |
| E4 | 广告向默认遵循「高调白底 + 活力点缀」：洁净色铺底，点缀色落在品牌焦点 |
| E5 | 若与品牌指定色冲突，以品牌色替代点缀色位，但不得突破严禁项 |

### 色温约束

| 参数 | 值 | 说明 |
|---|---|---|
| 整体色温 | 明亮微暖 5300-6000K（推荐） | 明快洁净商业基调 |
| 肤色色温 | 透亮微暖 5400-5800K（推荐） | 透亮但有血色 |
| 对比度 | 中等（建议保持） | 高调柔顺、层次干净 |
| 饱和度 | 中高 55-75%（建议区间） | 明快商业感、禁荧光 |

### 容差与例外

| 项目 | 建议容差 |
|---|---|
| 色相偏移 | ±6° |
| 饱和度偏移 | ±8% |
| 明度偏移 | ±10% |

> 例外场景：促销节点、节庆礼赠、活力高潮镜头可提高点缀色饱和与占比；但禁止荧光撞色与画面廉价感。

## 三、全局约束规则

### 必守规则（所有技能继承）

| 编号 | 规则 |
|---|---|
| R1 | 必须包含「商业广告摄影」风格锚定词 |
| R2 | 必须声明「洁净高调 + 大面积柔光」 |
| R3 | 面部必须使用「广告级修图质感 + 皮肤洁净透亮」 |
| R4 | 发丝必须使用「造型感清晰 + 发丝根根分明」 |
| R5 | 纹理必须声明「商业修图级洁净度 + 细节超清晰」 |

### 严禁项（所有技能继承）

| 编号 | 严禁内容 |
|---|---|
| X1 | 严禁「卡通/动漫/二次元/插画风」 |
| X2 | 严禁「脏乱/油污/霉斑/破旧等不洁视觉」 |
| X3 | 严禁「廉价影楼风/过度磨皮/网红滤镜感」 |
| X4 | 严禁「面部变形/多指/肢体异常」倾向词 |
| X5 | 严禁「裸体/暴露/透视/暗示性描述」 |
| X6 | 严禁「荧光撞色/阴郁暗黑/哥特风」（必须保持明快洁净） |
