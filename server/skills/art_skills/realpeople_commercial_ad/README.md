# 商业广告风格说明

本风格专为"商业广告"题材打造，所有美术提示词、规范和生成内容均严格限定于：

- **人物生活方式广告**：以真实人物与品牌产品/服务的自然互动为核心叙事，涵盖家庭、都市、度假等生活方式场景，人物始终是画面主角之一。
- **高端广告摄影**：所有角色、场景、道具均以高端商业广告摄影为标准，品牌 TVC 广告片帧质感，洁净高调大面积柔光。
- **明快商业色彩**：整体画面明亮洁净，以云雾白高调为基底，辅以珊瑚活力橙、晴空蓝、薄荷青等活力点缀色，品牌感十足。
- **亲和信任氛围**：适合展现信任推荐、惊喜体验、满足微笑、温馨陪伴等广告情绪，人物笑容亲和、状态上镜。

## 适用范围

- 商业广告/生活方式广告题材的AI美术生成（角色、场景、道具、分镜等）
- 需要洁净高调、明快商业色、品牌 TVC 质感的视觉创作

## 严禁内容

- 卡通、动漫、插画、二次元风格
- 脏乱、油污、霉斑、破旧等不洁视觉与廉价影楼感
- 阴郁暗黑、哥特等与明快洁净基调冲突的风格
- 暗示性、暴露、透视等不适宜内容

## 风格体验

在本风格下，您将体验到：

- 角色面容洁净透亮、笑容亲和，妆发干净具造型感，是品牌信任感的视觉载体
- 场景明亮通透、材质如新，家庭/都市/度假生活场景均可作为品牌叙事舞台
- 道具产品陈列考究，与人物自然互动，工艺细节与洁净度均为广告级
- 分镜与视频以品牌 TVC 质感为基础，强调洁净高调布光与生活方式叙事

---

本风格仅适用于"商业广告"相关项目。如需产品静物 packshot（产品为唯一主角、影棚极简舞台），请改用产品广告风格；如需其他风格（如古风、插画、动漫等），请勿使用本套提示词。
