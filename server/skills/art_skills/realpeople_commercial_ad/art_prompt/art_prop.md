# 道具图像生成 · 商业广告约束手册

---

## 一、道具设计原则

1. **道具即卖点载体** — 道具/产品是品牌叙事的核心资产，造型与陈列服务于卖点传达
2. **质感极致** — 材质纹理必须清晰可辨（金属/玻璃/陶瓷/织物/包装面），工艺细节到位
3. **陈列考究** — 产品须以广告陈列状态出现：正面完整、标识朝向清晰、无遮挡
4. **洁净无瑕** — 商业修图级洁净：无指纹、无灰尘、无污渍、无使用痕迹
5. **纯道具独立展示** — 画面中只能出现道具/产品本身，严禁出现任何人物、手部、肢体，道具不可处于被持有/佩戴/握持状态，必须以静物陈列方式独立呈现

## 三、多角度设定图规范

### 视图定义

| 位置 | 视图 | 角度 | 要求 | 提示词 |
|---|---|---|---|---|
| 左上 | 正面图 | 正面 0° | 道具完整正面形态、标识朝向镜头 | front view |
| 右上 | 侧面图 | 侧面 90° | 厚度/轮廓/结构清晰 | side view |
| 左下 | 背面图 | 背面 180° | 道具背部结构/工艺细节 | back view |
| 右下 | 细节特写 | 局部放大 | 材质纹理/工艺细节 | detail closeup |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 同一画面四宫格（2×2），上下左右四视角 |
| 背景 | 棚拍浅暖灰 #F0EFEB |
| 光线 | 大面积柔光箱均匀布光，无硬阴影，轻轮廓光勾边 |
| 比例 | 每格道具占格内主体 70%+ |
| 投影 | 允许自然地面微投影 |
| 洁净度 | 表面无指纹、无灰尘、无污渍 |
| 画面比例 | 建议 1:1 |

## 六、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须指定「棚拍浅暖灰背景」 |
| R2 | 必须明确道具材质与工艺，标识/正面朝向镜头且清晰 |
| R3 | 道具造型与陈列必须服务于品牌卖点传达 |
| R4 | 必须声明「洁净无瑕：无指纹、无灰尘、无使用痕迹」 |
| R5 | 必须包含「大面积柔光 + 轻轮廓光」布光描述 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 复杂场景背景 |
| X2 | 道具与人物同画面（本环节为纯道具图） |
| X3 | 出现任何人物形象，包括全身、半身、局部（手、手指、手臂等肢体） |
| X4 | 道具处于被持有、握持、佩戴、使用中的状态 |
| X5 | 出现暗示人物存在的元素（如手持痕迹、佩戴视角、使用姿态） |
| X6 | 灰尘/指纹/污渍/使用痕迹等破坏广告洁净感的瑕疵 |
