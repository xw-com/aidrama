# 人物基础形象生成 · 商业广告约束手册

---

## 一、基础形象原则

1. **面容即品牌** — 面容是品牌信任的视觉载体，必须广告级修图质感、洁净透亮
2. **角色为本** — 基础着装由角色描述（身份/职业/性别/场景）决定其常规着装；后续特定服化为叠加层
3. **四视图一致** — 面容/体型/发型/基础服装跨视图高度统一
4. **最佳上镜状态** — 广告演员默认「镜前最佳状态」：妆发干净、体态舒展、亲和力优先，杜绝疲态与不洁细节

---

## 二、面容约束

> 不再固定五官特征参数，由角色描述（性别/年龄/性格/气质）驱动 AI 自由生成五官，保证人物间外观差异化。

### 通用要求

| 项目 | 约束 |
|---|---|
| 五官 | 由角色描述自然推导，不预设脸型/眼型/眉型/鼻型/唇型 |
| 风格底色 | 商业广告摄影、广告级写实质感、大面积柔光、商业修图级洁净 |
| 气质 | 必须从角色描述提炼整体气质关键词（如亲和/可信赖/活力/精致），并写入提示词 |
| 表情 | 亲和笑容或自然愉悦微表情，符合广告镜前状态 |
| 妆容 | 广告妆容：底妆透亮、眉形清爽、唇色健康，禁浓妆脏妆 |

## 三、肤感约束

### 女性

| 项目 | 约束 | 提示词 |
|---|---|---|
| 肤色 | 透亮均匀、全身一致、可偏白/偏暖黄 | 皮肤洁净透亮、肤色均匀 |
| 光泽 | 透亮水感光泽、非哑光非油光 | 皮肤透亮、健康光泽 |
| 质感 | 商业修图级：洁净无瑕疵，保留微毛孔但不显粗糙 | 广告级修图质感、皮肤细腻洁净 |
| 露肤 | 面部/颈部/锁骨/手部/部分手臂 | 肩颈线条干净、肌肤洁净 |

### 男性

| 项目 | 约束 | 提示词 |
|---|---|---|
| 肤色 | 健康均匀、可偏小麦色 | 健康肤色、肤色均匀 |
| 光泽 | 清爽感、局部高光干净 | 皮肤清爽、质感干净 |
| 质感 | 商业修图级：洁净无油光、胡须清爽或刮净 | 广告级修图质感、皮肤洁净 |

## 五、基础发型约束

> 仅定义干净造型发型，发饰在服化衍生环节叠加；广告发型须有「造型感」但不夸张。

### 女性

| 项目 | 约束 | 提示词 |
|---|---|---|
| 发色 | 自然发色（深棕/深栗/黑茶），禁夸张漂色与荧光挑染 | 自然发色、深棕色 |
| 发长 | 及肩/及腰长发或利落短发，由角色设定 | 自然长发、及肩发 |
| 发质 | 发丝清晰、柔顺有光泽 | 发丝根根分明、柔顺光泽 |
| 造型 | 干净造型感：柔顺直发/蓬松大波浪/低马尾/半扎 | 造型感清晰、发丝蓬松柔顺 |

### 男性

| 项目 | 约束 | 提示词 |
|---|---|---|
| 发色 | 自然发色（黑色/深棕），禁夸张漂色 | 自然发色、黑色/深棕 |
| 发长 | 短发为主，由角色设定 | 清爽短发 |
| 发质 | 发丝清晰、质感真实 | 发丝根根分明 |
| 造型 | 干净造型感：清爽纹理/利落背头/自然碎发 | 造型感清晰、清爽利落 |

## 六、基础服装约束

> 基础服装由角色描述（身份/职业/性别/场景）决定其最自然的品牌感着装，作为该角色「广告默认态」；正式服饰/特殊衍生在服化衍生环节叠加。**禁止内衣打底**。

### 着装选择原则

| 角色身份 | 默认着装方向 |
|---|---|
| 都市白领/品牌代言 | 品牌感通勤装（挺括衬衫/针织衫+裤装裙装、质感外套） |
| 居家生活 | 明快居家生活装（针织套装/休闲T恤+长裤，洁净如新） |
| 亲子家庭 | 温馨亲子休闲装（奶油杏/薄荷青浅色系） |
| 度假休闲 | 度假休闲装（轻盈连衣裙/亚麻衬衫/防晒开衫） |
| 运动健康 | 运动功能装（修身运动服，活力点缀色） |
| 美食烹饪 | 洁净围裙/厨房着装（素色为主） |
| 角色描述未明确 | 明快洁净品牌感常服，低饱和底色+点缀色 |

### 着装统一规则

- 服装风格须与商业广告摄影美学一致（明快洁净色调、写实材质、面料挺括）
- 颜色以色盘推荐色为主，可含品牌点缀色，无复杂花纹/装饰，便于后续衍生叠加
- 四视图服装款式完全一致
- 基础服装是「广告默认态」，焦点仍在面容与产品/服务互动
- 严禁内衣/暴露/性化打底

## 八、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须为「广告镜前状态」（妆发干净、体态舒展、亲和力优先） |
| R2 | 必须根据角色描述声明合适的品牌感着装作为基础服装（如白领→品牌感通勤装、居家→明快生活装）；禁止内衣打底 |
| R3 | 必须声明「无发饰、无配饰」 |
| R4 | 必须指定「棚拍浅暖灰背景」 |
| R5 | 必须指定「四视图一致性」 |
| R6 | 全身立像必须从头顶到脚底完整展示，严禁裁切 |
| R7 | 必须声明角色身高并通过头身比换算约束全身比例 |
| R8 | 人像特写必须从头顶到锁骨完整展示，严禁裁切头顶 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 内衣/暴露/性化打底；与角色描述明显不符的着装；过度复杂花纹/装饰干扰后续服化叠加 |
| X2 | 正顶硬光/正底光/彩色光 |
| X3 | 过度磨皮至塑料脸/网红滤镜感 |
| X4 | 复杂场景背景（必须棚拍灰底） |
| X5 | 夸张表情/动态姿势 |
| X6 | 全身立像裁切头顶或脚底，必须从头到脚完整入画 |
| X7 | 人像特写裁切头顶，必须从头顶到锁骨完整入画 |
| X8 | 忽略身高和头身比约束 |
