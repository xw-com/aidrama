# 场景图生成 · 商业广告约束手册

---

## 一、场景美学原则

1. **场景即卖点** — 场景承载品牌叙事功能（使用场景/生活方式舞台），不是纯背景板
2. **洁净纵深** — 所有场景必须具备前/中/后景且明亮通透，杜绝脏乱死角与扁平堆砌
3. **材质如新** — 台面/器具/软装等材质必须洁净无瑕、工艺清晰，处于「广告开箱状态」
4. **TVC 实拍为锚** — 一切画面以高端商业广告摄影为标准，追求大光圈浅景深、可控柔光与洁净高调，拒绝 3D 渲染/CG 动画质感

## 五、主视图规范

### 视图定义

> 单画面主视图，从场景中最具品牌叙事代表性的角度拍摄，承载空间卖点与构图重心。

| 项目 | 约束 | 提示词 |
|---|---|---|
| 视角 | 自然观察视角，构图最能凸显场景卖点与洁净纵深 | hero shot、representative angle |
| 视点高度 | 默认人眼平视高度，特殊场景可俯/仰 | eye level（默认） |
| 构图 | 主体居中或符合三分法，前/中/后景层次清晰 | balanced composition |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 单画面（非拼图、非多视图、非分屏） |
| 人物 | **严禁出现任何人物、人影、人体轮廓** |
| 一致性 | 风格/材质/色调/光线统一 |
| 光线 | 单一光源逻辑，光影方向一致 |
| 画面比例 | 默认 16:9（或按调用方设定） |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 场景必须有「前中后景层次」且整体明亮通透 |
| R2 | 室外必须「空气通透、远景明快」，杜绝浑浊 |
| R3 | 场景图必须为「单画面主视图」，不得拼接多视图/分屏/网格 |
| R4 | 构图须能代表场景卖点（品牌叙事舞台）并展示前/中/后景层次 |
| R5 | 场景图中**严禁出现任何人物** |
| R6 | 必须包含商业摄影关键词（commercial photography / photorealistic / RAW photo） |
| R7 | 必须包含镜头光学特征（shallow depth of field / bokeh / lens vignette 至少一项） |
| R8 | 材质必须洁净如新，禁止灰尘/水渍/使用痕迹等不洁细节 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 背景纯黑/昏暗无层次/无场景 |
| X2 | 极端天候（暴风雨/雷电/沙尘，除非剧本需要） |
| X3 | 场景无纵深/无层次 |
| X4 | 材质脏乱、枯黄破败等与明快洁净基调矛盾 |
| X5 | 出现任何人物、人影、人体剪影或人体轮廓 |
| X6 | 画面被拼接成多视图/网格/分屏布局 |
| X7 | 3D 渲染/CG 动画/卡通/游戏引擎质感（禁用 3D render、CGI、Unreal Engine、Unity 等词） |
| X8 | 脏乱/油污/霉斑/垃圾等不洁视觉（广告世界必须洁净如新） |
| X9 | 光照昏暗阴郁、无景深虚化、无镜头光学特征 |
