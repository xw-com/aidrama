# 商业广告风格约束 · 人物生活方式广告 · 技法参考

---

## 一、色调体系与画面基调

- **色调基底** — 全片以云雾白（C1）、奶油杏（C5）、棚拍浅暖灰（C9）为基底色，整体明亮微暖（5300-6000K），饱和度中高（55-75%），呈现洁净明快的品牌生活感
- **活力点缀叙事** — 珊瑚活力橙（C3）、晴空蓝（C4）、薄荷青（C6）、阳光蜜金（C7）作为品牌活力与情绪高点的视觉信号，只落在产品或人物关系焦点，不铺满画面
- **深色锚点策略** — 深靛蓝（C10）、石板蓝灰（C8）仅用于夜景段落与沉稳表达，避免全片高亮导致层次塌陷；点缀深色让明快更立体
- **色盘先行原则** — 段落规划先绑定情绪场景（品牌亮相/家庭日常/信任推荐/惊喜体验等），再确定主色+辅色与光影方案，避免"剧情对了但卖点不对色"
- **禁用色域** — 高饱和荧光色、阴郁暗黑基调、脏乱低饱感与本风格不兼容

## 二、光影方案体系

- **光影即卖点** — 6 套光影方案对应不同广告情绪段落，导演规划阶段应在段落层面确定光影基调方向，而非逐镜指定
- **光源角度** — 正给镜头默认 30° 柔光箱斜射（洁净平光），侧给镜头默认 45° 侧逆 + 轮廓光勾边

| 光影方案 | 方案名 | 色调倾向 | 适用情绪 |
|---|---|---|---|
| A | 洁净高调平光 | 云雾白底 + 大面积柔光箱 | 品牌亮相、开场收尾 |
| B | 晨光窗逆 | 奶油杏 + 窗光逆射 + 反光板补 | 家庭日常、温馨陪伴 |
| C | 黄金时刻暖阳 | 阳光蜜金 + 侧逆光轮廓 | 情感高光、度假释放 |
| D | 可控硬光动感 | 点缀色底 + 高速闪光凝固 | 活力动感、惊喜瞬间 |
| E | 都市夜景点缀光 | 深靛蓝底 + 暖点缀光 | 高级感、静谧夜叙 |
| F | 阴天柔光外景 | 灰白高调 + 柔光漫射 | 过渡段、纪实生活感 |

- **冷暖光分配** — 暖色光可全片分层使用；深色/冷调段落控制占比，避免与明快品牌基调冲突
- **氛围方向映射** — 每场戏氛围方向应映射到上述光影方案（A-F）的某一方向，确保视觉一致性

## 三、质感方向

- **洁净高调** — 商业广告核心：画面明亮通透、白色有层次、无灰雾感；场景与人物均处「广告开箱状态」
- **商业修图级洁净度** — 皮肤洁净透亮但不塑料，保留微毛孔；台面无水渍、器具无使用痕迹，修图感高级不廉价
- **材质反光控制** — 金属/玻璃/液体反光须受控成型，高光有形不死白，为产品质感服务
- **景深焦点策略** — 大光圈浅景深为默认语言：人物与产品双焦点清晰，背景柔化为情绪铺垫；焦点切换即叙事切换

## 四、商业广告场景空间元素

人物生活方式广告特有的场景元素及其视觉叙事功能：

- **落地窗/岛台/餐桌** — 家庭互动三舞台：窗光造洁净、岛台造食欲、餐桌造团聚，是生活方式品牌的核心视觉资产
- **城市街道/通勤动线** — 都市节奏载体，明快街景与虚化人群衬托人物主角感
- **海滨/草坪/露台** — 度假释放段落的空间解药，用于情绪从日常切换到高光
- **空镜过渡建议** — 产品特写空镜、材质细节空镜（液体倾倒/蒸汽升腾）、光线变化空镜（光斑扫过台面）用于段落衔接，保持品牌呼吸感
- **视觉转折建议** — 洁净高调→暖调高光的渐变=情绪升温；顺光平面→逆光轮廓的切换=人物觉醒/产品登场，优先用光位转折而非台词解释

## 五、广告乐器与环境音

商业广告世界观下的声音元素约束：

### 乐器选择

- **轻快木吉他** — 生活方式广告核心乐器，扫弦即刻建立明快愉悦的品牌基调
- **钢琴** — 温情家庭段、情感收尾段的主力，干净透亮
- **电子节拍** — 都市/科技/活力段落的节奏引擎，推动剪辑卡点
- **尤克里里/口哨** — 度假、亲子、轻松段落的趣味增强器
- **弦乐轻铺** — 情绪抬升与品牌升华段落的铺底，克制不煽情

### 乐器组合策略

| 情绪阶段 | 乐器组合 |
|---|---|
| 品牌开场/收尾 | 钢琴独奏 或 木吉他独奏 |
| 日常生活推进 | 木吉他 + 轻打击 |
| 温情陪伴/家庭 | 钢琴 + 弦乐轻铺 |
| 活力高潮/惊喜 | 电子节拍 + 全频打击 |
| 度假释放 | 尤克里里 + 口哨/轻打击 |

### 广告环境音

- **典型环境音层次** — 咖啡机蒸奶声 / 煎煮滋响 / 牛奶倾倒入杯 / 孩童笑声 / 海浪与海风 / 街道人声远景 / 开瓶气压声 / 鸟鸣与草坪风声
- **每场戏标注 1-2 个核心环境音**，帮助后续音效设计；产品互动音（开盖/倾倒/咬下）优先于配乐，是广告沉浸感的关键

### 留白建议

- 品牌标版/口号出现前预留 0.5-1s 配乐静默，仅保留环境音，让品牌信息落地
- 情绪高点后安排一次配乐抽离（只留环境音），再用音乐收尾，避免全程满铺
