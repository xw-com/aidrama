# 真人仙侠武侠场景图像生成 · 约束手册

---

## 一、场景美学原则

> 真人仙侠武侠的场景不是"被建模的空间"，而是"被摄影机选中的真实古代场所"。没有渲染引擎、没有贴图、没有体积光参数——只有实际存在的自然光、火光与月光、真实的山水与古建、以及中国古代江湖的岁月痕迹。

1. **空间即叙事** — 一个空无一人的客栈大堂不是"空的"，是刚散了一场江湖聚首。一把倒放的条凳、一只没喝完的酒碗、桌上还没收的竹简——空间自己会讲故事
2. **真实的光，不是渲染的光** — 场景的光只有一个来源：实际的日光（穿过云雾、竹林、门窗）、实际的火光（篝火/火把/灯笼/丹炉）、实际的月光（冷银清辉）。光的色温和方向必须在物理上说得通
3. **被使用过/有岁月的空间** — 真实的古代场景不整洁。青石板有苔痕车辙、木构有风雨风化、兵刃架有锈迹、墙角有尘埃。一个完全没有岁月痕迹的空间是影城样板街，不是真人仙侠武侠
4. **中国古代仙侠武侠的真实场所** — 场景必须有古代中国特征（飞檐斗拱/青石长街/木质古建/山水云雾/道观山门）。这不是"generic fantasy"，这是"中国古代江湖的一个具体角落"
5. **单视图全景全貌** — 一张照片装下整个场地的完整信息。广角或标准焦段，全景深，正面展示空间的全貌与纵深——不是四视图分割，不是多角度拼贴

## 五、单视图全景摄影规范

> 真人仙侠武侠场景仅需**单张**全景摄影——一张照片装下整个空间的完整信息。不是2×2四视图，不是多角度拼接。

### 画面构成

| 项目 | 摄影要求 |
|---|---|
| 空间呈现 | 单张照片完整呈现场景的空间全貌。使用24-28mm广角或35mm，全场地的纵深、宽度、高度在一张画面中全部可见 |
| 构图 | 全景深大景别——前景（门框/梁柱/护栏/竹丛/窗棂/帷幕）形成天然画框→中景是场地主体→后景向空间纵深或窗外山景/天际延伸 |
| 景深 | 全景深 f/8-f/11，从前到后全部清晰。这不是人像摄影——场景的每一个角落都应该能被看见 |
| 人物 | **严禁出现任何人物、人影、人体轮廓。** 场景是空的——但这种"空"有叙事：刚散场/即将开战/人去楼空/江湖的静止瞬间 |
| 比例 | 建议 16:9 或 3:2 宽幅——匹配全景空间展示的横向视觉习惯 |
| 色彩 | 由实际光源的色温驱动，不套滤镜。色彩科学参考ARRI Alexa/Sony Venice电影色调 |
| 法术克制 | 阵法/符箓/灵石等可有极克制微光晕作为氛围点缀，非CG炫光、非粒子特效堆砌 |

### 空的场景如何叙事

| "空"的类型 | 画面线索 | 叙事暗示 |
|---|---|---|
| 刚散场 | 八仙桌上酒碗未收、条凳歪放、地上竹简残页、灯笼还亮着 | 刚才有人在这里，现在走了 |
| 即将开战 | 长街清场、店铺门窗紧闭、远处一盏灯笼、青石上落叶 | 有人马上要来，现在是决战前的静止 |
| 人去楼空 | 剑冢中断剑积灰、洞府被封、道观香炉冷灰、地面积尘轮廓 | 曾经有人在此，现在已经离去 |
| 修行的静止 | 蒲团上有压痕、案几上经书打开着、窗外竹影在动、茶盏半温 | 修行的常态、只是此刻没有人入镜 |
| 江湖的夜 | 空荡的长街只有灯笼亮着、客栈大堂油灯摇曳、月下道观静谧 | 江湖睡着了、但空间还醒着 |

| R1 | 必须是**单张**全景摄影——单视图、非2×2四视图、非多角度、非turnaround |
| R2 | 必须使用广角镜头（24-28mm）或标准焦段（35mm），全景深 f/8-f/11，完整空间纵深 |

| R5 | 必须有古代中国辨识度——飞檐/青石/古建/山水/道观等古代中国特征 |
| R6 | 必须有岁月痕迹——青石苔痕/木构风化/墙面斑驳/积尘/非影城样板街非效果图 |
| R7 | **严禁出现任何人物、人影、人体轮廓、剪影** |
| R8 | 必须声明"真人实拍摄影 + 非3D渲染非CG"核心锚定 |
| R9 | 阵法/符箓/灵石等法术元素仅极克制微光晕服务实拍，非CG特效堆砌 |
