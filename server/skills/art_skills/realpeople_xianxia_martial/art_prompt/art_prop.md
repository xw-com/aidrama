# 真人仙侠武侠道具图像生成 · 约束手册

---

## 一、道具设计原则

> 真人仙侠武侠的道具不是"被建模的物体"，而是"被使用过的物品"——它在某位侠客手里待过、在某张八仙桌上放过、在某次对决中格挡过、在某个剑鞘里待了许多年。摄影机拍下的是它的此刻。

1. **物品即叙事** — 每一件道具都是一个微型的江湖叙事容器。剑刃上的缺口暗示一场恶战、酒葫芦的磨损暗示长久陪伴、竹简功法的翻旧暗示反复研读、玉佩的包浆暗示世代传承
2. **使用痕迹优先于完美品相** — 真人仙侠武侠的道具必须有"被用过"的证据。全新出厂的、样板级别的、毫无岁月的道具一律不出现——除非叙事需要"新铸之剑"或"新炼丹药"
3. **中国古代仙侠武侠真实物品** — 道具必须是中国古代江湖/仙侠世界中真实存在的物品：长剑/拂尘/道袍/玉佩/酒葫芦/竹简/丹炉/油纸伞——拒绝无国别的架空物品、拒绝明显非古代元素
4. **材质即真实** — 不是PBR参数渲染出的材质，而是摄影机拍下的真实材质行为：钢锋的寒光与锈迹、丝绸的光泽、青铜的铜锈、玉石的温润、粗布的肌理、木纹的风化
5. **单视图静物摄影** — 道具以单张静物产品摄影方式独立呈现，非多角度建模展示，非2×2四宫格

## 三、单视图静物摄影规范

> 真人仙侠武侠道具仅需单张静物产品摄影，非多角度建模展示。以下为单视图摄影的完整规范。

### 画面构成

| 项目 | 摄影要求 |
|---|---|
| 道具呈现 | 道具居中或偏三分线位置独立陈列，完整入画，无裁切 |
| 背景 | 素灰无缝背景纸 #B0B0B0（哑光），或浅木纹桌面/古旧木桌面/青石台面，根据道具属性选择。无多余物体、无装饰、无文字 |
| 光线 | 自然窗光或单灯柔光。窗光45°侧入（明亮柔和带自然阴影）、或柔光箱顶+侧补（产品摄影级均匀光线）。光影柔和、方向明确、无硬阴影。火光/丹炉类道具可加极克制暖光点缀 |
| 景深 | 浅景深（f/2.8-f/5.6），道具主体清晰锐利，前后微虚化突出主体 |
| 投影 | 道具底部与承载面之间的自然接触阴影——真实的而非抠图或悬浮。阴影柔软、方向与主光源一致 |
| 画面比例 | 建议 1:1 正方形或 4:3，适配单件道具展示 |

### 道具状态准则

| 维度 | 要求 |
|---|---|
| 使用痕迹 | 必须有"被使用过"的视觉证据——非全新未拆封、非样板品相（除非叙事需要新铸/新炼） |
| 古代中国辨识度 | 古代中国形制/纹饰/材质/古代器物特征——拒绝无国别架空物品、拒绝现代元素 |
| 材质真实感 | 非渲染质感——是摄影机拍下的真实材料行为（光的反射、漫射、透射） |
| 法术克制 | 修真器物的微光/法术光晕极克制，作为氛围点缀，非CG炫光、非游戏技能特效 |
| 尺度感 | 通过材质纹理密度、工艺细节暗示实物尺寸，无需参照物 |
