## 一、风格核心定义

**真人仙侠武侠**是以**真人影视摄影美学**为基准、以**中国古代仙侠/武侠江湖**为核心的视觉风格体系。其核心特征为：

- **真人写实摄影质感**：以真人影视级摄影为锚点，画面呈现真实演员的皮肤纹理、毛发细节、微表情与肢体语言，杜绝3D建模感、CG渲染感、手绘感与动漫感
- **仙侠/武侠世界观**：所有场景严格限定于中国古代江湖/仙侠空间——仙山云海峰顶、青石古镇长街、竹林小径、悬崖剑冢、瀑布寒潭、山门道观、江湖客栈大堂、古战场废墟、秘境洞府。法术/剑气特效克制服务于实拍质感，不做CG式特效堆砌
- **电影级摄影语言**：以院线级真人武侠电影摄影为基准，强调自然光与火光/月光谱的有机调度、构图叙事的专业性、景深与焦点的情绪表达、色彩分级的电影感
- **江湖人文温度感**：在保持专业影像品质的前提下，强调江湖的烟火气、师徒/知己/仇敌之间的真实情感连接、刀光剑影间隙的审美提炼

### 创作理念与核心价值

本手册的核心创作理念为 **"写实的江湖"**：

1. **真实感的审美回归**：在AI生成影像日趋泛滥的当下，真人写实质感以其不可替代的真实力量，成为最具情感穿透力的视觉语言。肌肤的纹理、剑刃的寒光、丝绸的垂坠、山岚的流动——这些真实细节构成了一种生命质感，是3D渲染无法复刻的审美深度。

2. **江湖的叙事容器**：中国古代仙侠/武侠是中国观众最熟悉的浪漫叙事空间。仙山云海承载着求道与超脱，青石长街回荡着市井江湖，竹林深处藏着对决与隐逸，悬崖剑冢诉说着传承与陨落——江湖空间本身就是一个巨大的叙事容器，等待被挖掘。

3. **人本主义的视觉立场**：本手册坚持以"人"为核心。无论仙山多么缥缈、剑气多么凌厉，最终回归到人物的情感状态与内心世界。每一帧画面都是一次对侠骨柔情的注视。

4. **实拍与意境的临界点**：寻求"电影的精致"与"武侠的真实"之间的微妙平衡——画面足够美、足够专业、有意境，但不过度依赖CG奇观；人物足够真实、足够生动，但不过度随意而失去审美品质。法术与剑气克制使用，仅作环境光晕，服务于实拍质感。

**核心价值：**

- 为AI视觉创作者提供一套系统化、可复用的真人仙侠武侠题材提示词方法论
- 建立从概念到成品的标准化视觉创作管线
- 降低真人仙侠武侠题材AI视觉创作的技术门槛与试错成本
- 填补当前AI视觉创作领域"真人仙侠武侠题材系统化方法论"的空白

## 四、关键视觉元素

### 4.1 人物视觉元素

真人仙侠武侠题材的人物视觉以**"真实个体、江湖气质"**为核心：

- **面容标准**：真人肌肤质感，五官自然立体，妆容符合古风审美且不过度修饰。支持多元面容类型——清冷出尘、温润如玉、洒脱不羁、狠厉孤傲、天真烂漫、沧桑洒脱等
- **发型标准**：中国古代发式体系，发丝自然质感，杜绝假发感与僵硬造型。支持高马尾、道髻、披发、半束发、双丫髻、簪冠束发等多种古风发型
- **服饰标准**：中国古代着装层次体系——道袍/劲装/战甲/纱衣/布衣/襦裙/深衣。丝绸光泽、粗布肌理、皮甲纹路、纱衣轻透，面料纹理清晰，褶皱自然
- **表情与体态**：微表情真实细腻（眼神、嘴角、眉宇），肢体语言自然不做作，剑客的站姿、武者的步态、修者的端容皆有出处，杜绝僵硬摆拍感
- **人物气质维度**：清冷出尘 / 温润如玉 / 洒脱不羁 / 狠厉孤傲 / 天真烂漫 / 沧桑洒脱 / 妖冶孤绝

## 五、严禁内容（优先级最高）

本风格严格排除以下内容类型，确保视觉体系纯净统一：

1. **非真人质感**：3D渲染/CG建模/次世代游戏引擎/动画风格/手绘插画/水彩油画/二次元/Voxel/低多边形等一切非真人实拍影像质感
2. **非仙侠武侠世界观**：现代当代都市/民国宫廷宫墙/赛博朋克/科幻机甲/太空星际/西方奇幻/中世纪等非中国古代仙侠武侠背景
3. **过度CG法术特效**：堆砌式CG法术/炫光能量弹/粒子特效过载/游戏技能式光效——本风格法术剑气仅作克制环境光晕，服务于实拍
4. **非中国古代语境**：明显非中国古代特征的建筑、服饰、器物（如和服、日式城堡、欧式盔甲等）
5. **技术质量缺陷**：低分辨率/模糊/噪点/变形/畸形肢体/五官扭曲/比例失调/抠图感/塑料感/过度磨皮/假面感
6. **审美倾向违规**：过度高饱和/死亡荧光色/廉价滤镜感/过度HDR/艳俗色调/动漫化滤镜
7. **内容合规红线**：暴露/低俗/暗示性/血腥虐杀/违法内容/歧视性表达/政治敏感元素

## 七、使用说明

### 提示词使用原则

1. **前缀先行**：所有生成内容必须首先加载"前缀提示词"中的全局风格锚定段，锁定真人仙侠武侠写实质感基线
2. **专项叠加**：在全局前缀基础上，按需叠加角色/场景/道具/分镜专项提示词
3. **负面必加**：每次生成必须附带"负面提示词"，规避伪影与风格偏差
4. **迭代优化**：建议首轮生成后根据效果对专项提示词做微调，而非修改全局前缀
5. **平台适配**：本手册提示词优先适配Doubao-Seedream（生图）与Doubao-Seedance（视频生成），部分提示词可能需根据平台特性微调
