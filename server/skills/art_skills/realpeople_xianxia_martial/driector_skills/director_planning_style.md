## 一、色调体系与画面基调

- **色调基底** — 全片以月白（#D8DCE0）、云雾青（#9FB3B8）、玄黑道袍（#2A2D34）为基底色。整体色温分日间中性偏暖（4500-5800K）、夜间冷暖共存（火光/灯笼 2000–2800K + 月光/环境 4100–6000K）。饱和度中低（35-55%），呈现"电影感但不滤镜感"的克制江湖色调——色彩来自实际光源，不来自后期调色
- **光源即色盘** — 不以"主色/辅色"配对，而是以光源的色温和方向来驱动画面色彩。云海晨曦3500-4500K（暖金）、正午5500-6500K（冷白清透）、金色时刻2800-3500K（暖金）、蓝调时刻8000-10000K（深蓝紫）、篝火/火把2000–2600K（暖橙红）、灯笼2200-2800K（暖橙黄）、月光4100-4500K视觉冷银、丹炉/灵火1800-2400K（极暖橙红）
- **冷暖叙事对照** — 暖光（晨曦/夕照/篝火/灯笼/丹炉）用于温情、江湖情义、烟火、悟道新生段落；冷光（月光/正午天光/阴天漫射/蓝调时刻）用于孤寒、肃杀、对决、别离段落。关键转场可通过光源色温切换来暗示情绪转向
- **光源先行原则** — 段落规划先确定"光从哪儿来、什么色温"，再确定画面色调。避免"这个镜头颜色好看但光源说不通"
- **禁用色域** — 高饱和荧光色、廉价滤镜调色（如青橙预设/茶色预设）、CG霓虹溢色、动漫化滤镜、非真实光源产生的异常色偏

## 二、光影方案体系

- **光影即叙事** — 7 套光影方案对应不同情绪段落。导演规划阶段在段落层面确定光影基调方向，而非逐镜指定。每套方案必须指定"光的来源 + 色温 + 光比"，确保可被 Seedance 2.0 物理模拟
- **实拍摄影光影特征** — 自然光与云雾调度、火光/灯笼/丹炉/月光等实用光源、山水青石与兵刃的环境反射、手持摄影的微晃呼吸感、景深变化引导注意力——为真人仙侠武侠风格的核心光影手段

- **冷暖光分配** — 暖色光（晨曦/夕照/篝火/灯笼/丹炉）适用于温情治愈、江湖情义、烟火段落；冷色光（月光/正午天光/阴天漫射/蓝调）适用于孤寒肃杀、对决对峙、别离清冷段落。冷暖切换点即叙事转折点
- **氛围方向映射** — 每场戏的氛围方向应能映射到上述光影方案（A-G）的某一方向。如叙事需要混合方案（如D+G月夜+古镇暮色），需明确主导光源
- **法术克制原则** — 法术/剑气/阵法/符箓等超自然元素的光仅作极克制的环境光晕，服务于实拍质感，禁止CG式炫光、能量弹、粒子特效堆砌。Seedance 2.0 中描述为"克制暖白/淡青微光晕，非CG炫光"
- **Seedance 2.0 光影适配要点**：光源名称可被AI理解（"晨曦穿透云雾斜入"优于"暖色体积光"）。光比数字帮助模型建立明暗意识。多光源场景须明确主光+辅光+环境光的层级

## 三、质感方向——摄影机前的真实世界

> 真人仙侠武侠质感的唯一标尺：摄影机拍到的材质行为，不是渲染引擎生成的材质参数。

- **皮肤质感** — 毛孔可见、T区自然出油反光、颧骨处自然泛红、眼周微暗、风霜日晒痕迹——真实皮肤的"活着"的证据。Seedance 2.0 提示词用"visible skin pores, natural skin texture, not airbrushed，真实皮肤质感"替代 3D 项目的"次表面散射/SSS"
- **发丝质感** — 古风发髻束发处的碎发、高马尾的飘动、披发被山风吹乱、逆光下头发边缘呈半透明暖色轮廓、雨后贴在额前的湿发。Seedance 2.0 用"flyaway hair strands, natural hair movement, backlit hair rim light, wind-blown"替代"物理级发丝模拟"
- **服饰质感** — 丝绸的柔和光泽与垂坠、粗布的粗粝肌理与磨损、战甲的甲片铆钉与碰撞划痕、纱衣的轻透。衣服有"被穿过"的证据——衣摆自然微皱、袖口有穿脱痕迹、道袍被山风吹动。Seedance 2.0 用"fabric texture with subtle wear, natural fabric drape, lived-in costume"
- **山水与古建材质** — 青石板的苔痕车辙、木构梁柱的风雨风化、朱柱漆面的剥落、飞檐的岁月、兵刃的寒光与锈迹。Seedance 2.0 用"weathered ancient Chinese architecture, mossy stone path, real jianghu surfaces, not showroom clean"
- **岁月质感至上** — 材质不可过于干净完美。江湖痕迹（青石苔痕、木构风化、兵刃锈迹、墙面斑驳）不是缺陷，是江湖叙事的基础。禁止"全新样板街"和"无痕效果图"
- **Seedance 2.0 质感适配要点**：避免 "PBR材质""物理级渲染""8K贴图" 等CG术语。改用 "real texture, natural material surface, visible wear and use marks, not CGI"。当描述轻微瑕疵时用 "subtle" 而非 "micro-detail" 等建模术语

## 四、真人仙侠武侠场景空间元素

中国古代江湖/仙侠特有的场景元素及其在 Seedance 2.0 视频中的视觉叙事功能：

- **云雾/山岚/峰顶石台** — 仙侠最核心的意境与构图元素。云雾即光源漫散器——仙岚透光的方向和色温决定整个山间的光影逻辑。云雾分层制造"远/中/近"的多层空间（前景松枝→中景云海→后景峰峦）。Seedance 2.0 中重点描述"sunlight piercing through mist at specific angle"以帮助模型理解光柱与仙岚透光
- **竹林/漏光/竹叶** — 武侠最经典的构图与对决容器。竹林漏光 = 斑驳诗意，竹海深处 = 隐逸或伏击，竹叶被风吹动 = 决战前的紧张。Seedance 2.0 中竹林场景必须明确"dappled light filtering through bamboo canopy"或"wind swaying bamboo leaves with rhythmic motion"等可被模型执行的光学与动态描述
- **青石长街/飞檐/灯笼** — 古镇江湖的核心光源叙事载体。长街青石湿滑反射街灯光 = 雨夜杀机；商铺灯笼暖黄（2200-2800K）= 古镇的体温；月光冷银映在青石上 = 孤寒独行
- **客栈大堂/天井/八仙桌** — 江湖聚合的叙事容器。客栈天井漏光 = 日间自然采光；大堂油灯/灯笼暖光 = 夜间烟火与密谋；二楼回廊俯瞰 = 江湖全景的信息站位
- **道观山门/大殿/香炉** — 宗门气象的信仰空间。山门石阶长长 = 朝拜与登阶的仪式感；大殿香炉青烟 = 信仰与肃穆；长明灯暖光 = 不灭的传承
- **悬崖剑冢/瀑布寒潭/雪岭梅林** — 武侠写意的标志性场所。剑冢万剑倒插 + 暮色 = 悲怆传承；瀑布水汽 + 寒潭碧绿 = 淬剑疗伤；雪岭红梅 + 孤影 = 清冷别离
- **段落间用场景空镜过渡** — 空镜为情绪缓冲，不用硬切。同一空间在不同时段/天候的空镜（如晨雾竹林→月夜竹林）可暗示时间流逝。Seedance 2.0 中空镜需指定光源逻辑，空镜也有情绪
- **转折点用视觉而非台词** — 光影突变（云遮日光→山间突然变暗）、景别跳切（中景→剑指大特写）、空间转场（客栈→悬崖）、焦点漂移——由摄影机完成叙事
- **法术/剑气的克制呈现** — 法术施放、剑气纵横、阵法启动等超自然时刻，以"克制的环境光晕 + 实拍人物动作 + 自然材质反应"呈现，而非CG粒子堆砌。例如剑气以"剑刃寒光骤然增强 + 周围尘土被气劲带起 + 灯笼火焰被压低"等物理可观测的间接效果暗示

## 五、真人仙侠武侠配乐与环境音

### 5.1 配乐乐器选择

真人仙侠武侠配乐以中国传统乐器为主、交响与电子元素克制为辅，追求"意境为先、不抢戏的存在感"：

- **古琴** — 清冷独处、悟道清修、宗师气度段落的核心乐器。泛音与余韵的最佳状态——音符之间的留白和音符本身同样重要
- **箫/笛** — 孤寒、思念、月夜独行段落的核心乐器。悠远苍凉的音色，自带江湖的旷达与哀愁
- **古筝** — 灵动、流水、山林野趣段落的底色。指弹琶音的清亮，自带山水画的意境
- **二胡** — 悲怆、苍凉、别离段落的核心乐器。如泣如诉的音色，江湖的悲欢都在两根弦上
- **中国打击乐（大鼓/编钟/木鱼/铙钹）** — 对决、大战、宗门段落的力量支撑。大鼓的沉雄、编钟的庄严、铙钹的锐利——慎用过度
- **弦乐组（西方弦乐，克制）** — 情感积蓄与释放段落的铺底。中低音区温暖铺垫，高音区用于情绪高点的轻触即收
- **电子氛围 Pad（克制）** — 秘境、洞府、神秘过渡段落的低频铺底。作为"可以被忽略但拿走就不对"的底层存在
- **人声/吟唱（克制）** — 史诗段落、悟道段落的点睛。无歌词的悠远吟唱，营造空灵或悲壮
- 慎用：大型交响乐团全程全奏、重金属失真、高能电子舞曲、动漫化燃向配乐——这些会让仙侠武侠变成"配乐在演戏"

### 5.2 配乐组合策略

| 情绪阶段 | 乐器组合 |
|---|---|
| 平稳开场/江湖日常 | 古琴独奏 或 古琴 + 箫轻和 |
| 仙山清修/悟道新生 | 古琴泛音 + 古筝点缀 + 极轻电子Pad |
| 江湖侠气/高光时刻 | 大鼓 + 弦乐中高音区 + 古筝节奏型 |
| 孤寒独处/月夜思念 | 箫独奏 或 箫 + 古琴稀疏单音 |
| 对决前夜/肃杀紧张 | 大鼓低频 + 二胡长音 + 极轻电子Pad |
| 悲怆别离/传承陨落 | 二胡 + 弦乐组渐强 + 古琴收束 |
| 市井烟火/客栈夜话 | 古筝 + 笛 + 轻打击乐点缀 |
| 秘境探秘/神秘 | 电子氛围Pad + 木鱼/编钟克制 + 人声吟唱 |
| 结尾/余韵 | 古琴单音渐疏 → 箫余韵 → 环境音独奏 |

### 5.3 真人仙侠武侠环境音

> 环境音是真人仙侠武侠场景的"听觉材质"，决定了江湖空间的沉浸感。每场戏标注 1-2 个核心环境音。

**核心环境音层次：**
- **山野自然音**：风过松竹、鸟鸣猿啼、溪流瀑布、落叶簌簌、雪落无声、远山钟声、虫鸣蛙叫
- **古镇人居音**：青石上的脚步、远处的叫卖、茶肆的人声、打铁的叮当、马蹄车辙、灯笼纸面的风响
- **对决动作音**：剑出鞘的脆响、剑刃交击的金属声、衣袂破风、甲片碰撞、竹叶被气劲带起、瓦片碎裂
- **修真氛围音**：丹炉火焰的低频、香炉青烟的微响、诵经的低吟、铜铃轻响、符箓燃烧的细微声
- **静默也是一种环境音**：雪夜的绝对寂静只有远处一声鸦啼、月夜竹林只有风声——这种"声音的缺失"本身就是叙事

音效设计哲学：
- 环境音不是贴上去的，是场景自带的声音
- 关键时刻"抽掉"环境音比"加入"特效更能制造情绪冲击（对决前的极致安静）
- 环境音的变化可以暗示空间转换——从喧嚣长街走进静谧道观，声音突然"变干净了"

## 七、全局叙事约束

- **空镜即情绪** — 每个叙事段落之间建议用场景空镜（同一空间在不同光线下）做情绪缓冲。空镜不是"没东西拍"，是"让观众喘口气"。山岚流动、竹林漏光、灯笼摇曳都是天然的情绪空镜
- **光的连续性与变化** — 同一空间内的自然光角度应随时间连续变化。如果一场论道戏跨越了半个时辰，穿过竹叶的光斑应该移动了一些——Seedance 2.0 能理解这种"合理的不完全一致"
- **人物光源一致性** — 同一镜头内所有人物的面部光源方向必须统一。如果主光从左侧来，所有人的左脸都应该是亮面
- **避免"过度导演"** — 真人仙侠武侠追求"被摄影机捕获的江湖"，不是"被编剧安排的奇观"。允许画面中有不可控的江湖细节（山风扰动道袍、一片红梅突然落下、灯笼被风吹得明灭）
- **静默的价值** — 不必每个镜头都填满动作和台词。一个3秒的静止特写——人物只是呼吸、注视、持剑——往往比任何台词都更有力
- **法术克制至上** — 所有超自然元素（法术/剑气/阵法/符箓/轻功）以"物理可观测的间接效果 + 克制环境光晕"呈现，服务于实拍质感，杜绝CG奇观堆砌。剑气以尘土气劲、灯笼压火、寒光增强暗示；轻功以吊威亚的实拍跃落呈现，非CG飞行
