## 一、分镜表定位

分镜表是导演将剧本转化为镜头语言的核心工具。本约束面向 Seedance 2.0 视频生成，所有光影、动作、空间描述均采用模型可执行的具象语言。不做抽象的情感概括，不写模型看不懂的渲染参数，不做"一道剑光"式含糊意境。

## 三、光影与氛围——Seedance 2.0 物理光源描述

### 3.1 同场戏光影统一

一场戏内不应出现两种以上核心光影方案，除非有叙事驱动的光源变化（如有人点亮灯笼、日出后天光亮过丹炉火、从室内走到室外月下）。光源变化必须在分镜表中标注触发事件。

### 3.2 光源语句法（每个镜头必须包含）
[光源] 主光：{光源类型}，{方向}，{色温值K}，{软硬}
[光源] 辅光/环境光：{光源类型}，{方向}，{色温值K}
[光比] 约1:{X}

### 3.3 情绪 → 光源矩阵

| 情绪 | 光源配方（Seedance 2.0 可直接填入） | 视觉关键词 |
|---|---|---|
| 仙门清修 | 晨曦/天光自然漫射主光（4000-5500K）从画面侧上方斜入，云雾柔化。光比约1:2 | 通透、出尘、低反差 |
| 江湖日常 | 竹林漏光/天光漫射（4500-5500K），自然光为主，无硬阴影。光比约1:2 | 通透、真实、松弛 |
| 客栈烟火 | 篝火/灯笼暖光主光源（2000–2800K），火光跳动映脸，暗部保留物体轮廓。光比约1:4 | 暖调包裹、人情烟火 |
| 月下肃杀 | 月光冷银主光（4100-4500K）从侧上方斜入，剑刃冷反光，远处灯笼暖点2200-2800K。光比约1:6 | 冷暖共存、孤寒肃杀 |
| 悟道清冷 | 晨曦/天光漫射（4000-5000K）单方向光，云雾柔化。光比约1:2 | 通透出尘、低反差 |
| 正邪对峙 | 侧方硬光（月光冷4100K或丹炉暖2000K）单光源，大光比约1:8，暗部深但有微弱轮廓。光比约1:8 | 压抑、肃杀、不确定 |
| 悲怆传承 | 夕照残金或月夜冷银，长阴影到极致，孤光点暖。光比约1:6 | 沉郁暗调、苍凉悲壮 |
| 秘境幽光 | 丹炉/灵火单一暖光源（1800-2400K）形成孤岛式照明，面部一侧亮一侧暗。光比约1:8 | 极简光源、神秘孤绝 |

### 3.4 冷暖色调与叙事阶段

- **冷光主导**（4100K+月光/5500K+正午天光）：孤寒肃杀、对决对峙、清冷独处、月夜
- **暖光主导**（2000–3500K晨曦/夕照/篝火/灯笼/丹炉）：温情亲密、江湖情义、烟火日常、金色时刻
- **冷暖共存**：过渡时刻（蓝调时刻+初亮灯笼）、月夜（冷月+暖灯）、洞府（暗+丹炉暖点）
- **光源变化 = 叙事信号**：窗外山间从晨曦暖金渐变至蓝调冷紫=时间流逝；从客栈暖灯走到月下青石=场景与情绪的切换
- **法术克制**：法术/剑气/阵法/符箓的光以"克制环境光晕+物理间接效果"呈现，不做CG粒子。Seedance 2.0 描述如"剑刃寒光骤然增强约30%，周围落叶被无形气劲带起飘浮约5cm，最近灯笼火焰被压低约2cm后恢复"

### 3.5 Seedance 2.0 光影适配要点

- 色温数字帮助模型校准白平衡倾向：`色温约2400K灯笼暖光` 优于 `暖光`
- 光比数字帮助模型建立明暗意识：`光比约1:6冷暖共存` 优于 `柔和的阴影`
- 光源必须有明确来源：`月光从画面左上方斜入` 优于 `侧光`
- 环境光的反射路径描述：`青石湿滑反射灯笼暖黄光斑` 优于 `地面有暖色反光`

## 四、环境动态——让画面呼吸

### 4.1 动态密度

每 3-4 个镜头至少安排一个有环境动态的镜头。静态文戏也不例外——至少有一个镜头里竹叶在动、灯笼火焰在跳、道袍衣摆被山风吹动。

### 4.2 江湖环境动态元素（Seedance 2.0 可执行）

| 场景 | 可描述的环境动态 |
|---|---|
| 山野/竹林 | 竹叶被风吹动每秒约2-3次微幅晃动、山岚从深处缓慢涌流（约每秒0.5米）、远处鸟鸣惊起、落叶飘落约每秒30cm |
| 古镇长街 | 灯笼在檐下轻微摇晃（约±5度）、远处江湖人缓步走过青石、马匹鼻息喷出白气（冬季）、商铺幌子被风吹动 |
| 客栈大堂 | 油灯/灯笼火焰跳动（约每秒2次微亮微暗）、天井漏光随云朵移动而明暗变化、酒坛旁酒香蒸汽微弱升腾、二楼回廊木质地板轻微吱呀 |
| 道观大殿 | 香炉青烟袅袅上升（约每秒10cm）随风轻摆、长明灯火苗跳动、蒲团旁尘埃在光柱中飘浮、远处钟声余韵 |
| 悬崖剑冢 | 崖风猎猎吹动残剑剑穗（约每秒摆动30度）、断剑上旧布条飘动、远处云海缓慢翻涌、偶尔一只乌鸦掠过 |
| 瀑布寒潭 | 飞瀑持续垂落水汽蒸腾（约每秒上升20cm）、寒潭水面有瀑布激起的涟漪、苔石上水珠滴落 |
| 秘境洞府 | 丹炉火焰低频跳动映壁（约每秒1次）、钟乳石尖水滴缓慢滴落（约每3秒一滴）、灵石幽光极克制微闪 |
| 雪岭梅林 | 红梅花瓣偶尔飘落（约每秒1-2片）、雪花稀疏飘落、寒风吹动发丝与衣摆、积雪从枝头偶尔簌簌落下 |

### 4.3 Seedance 2.0 环境动态描述规范

- 动态必须有具体轨迹和速度：`竹叶被风吹动，每秒约2-3次微幅晃动` 优于 `竹在动`
- 光源动态与空间光源逻辑一致：`云朵遮住日光时，竹林漏光面积缩小约40%，持续约3秒后恢复`
- 禁止无来源的动态：没有山风=道袍衣摆不动。室内无风=灯笼不晃
- 法术/剑气的间接物理动态须具体：`剑指前方时，地面落叶被气劲带起飘浮约5cm，持续约1秒后落下`

## 五、人物动作节奏——Seedance 2.0 物理逻辑具象化

### 5.1 动作描述铁律

所有人物动作必须描述：**轨迹 + 速度/时长 + 身体部位协调 + 对周围物体/环境的影响**。

### 5.2 江湖动作具象库

| 动作 | Seedance 2.0 可执行描述 |
|---|---|
| 拔剑出鞘 | 右手握住剑柄，手腕发力上提，剑刃从剑鞘抽出约30cm时发出金属摩擦脆响，剑身寒光一闪，全程约1.5秒，出鞘后剑尖自然下指约15度 |
| 持剑转身 | 向右缓慢旋转约90度，重心从左脚移至右脚，右手持剑自然随身体摆动约10cm，道袍衣摆被旋转带起约30度角，全程约1.5秒 |
| 收剑入鞘 | 右手持剑，剑尖对准剑鞘口，剑刃缓慢推入约1秒，最后10cm时发出轻微金属入鞘声，左手按住剑鞘口，全程约2秒 |
| 倒酒入碗 | 右手持酒葫芦倾斜约45度，深琥珀色酒液注入粗陶碗中，液面从碗底上升至碗身三分之二处，全程约3秒，酒液表面有轻微波纹 |
| 仰头饮酒 | 右手端碗至唇边，碗口倾斜约30度，酒液接触嘴唇，喉结可见滚动约2次，饮毕将碗放下，酒渍残留在碗沿，全程约4秒 |
| 行礼拱手 | 双手在胸前交叠（左手在外右手在内），身体微前倾约15度，低头约10度，停顿约1秒后直身，全程约2.5秒 |
| 拂尘一挥 | 右手握拂尘柄，手腕发力，拂尘从肩侧向前下方挥出约60度，拂尘马尾自然甩动约20cm，衣袖随之飘动，全程约1秒 |
| 御风/轻功跃落（克制） | 双膝微屈蓄力，随即蹬地跃起约1.5米高，身体在空中保持自然，道袍衣摆与发丝被气流带起飘动，轻盈落在屋顶青瓦上发出轻响，全程约2秒——实拍吊威亚质感非CG飞行 |
| 施法/剑指（克制） | 右手食指与中指并拢前指，剑指动作约0.5秒完成，指尖方向剑刃寒光骤然增强约30%，周围落叶被无形气劲带起飘浮约5cm，最近灯笼火焰被压低约2cm后恢复，环境保持实拍质感非CG粒子，全程约2秒 |
| 静坐调息 | 双腿盘膝而坐，双手自然搭于膝盖，闭目，呼吸轻缓可见胸腔微起伏约每4秒一次，山风吹动几缕散发，全程保持静态约5秒 |
| 竹林行走 | 在青石小径缓步行走，步速约每秒一步，每步踩下时鞋底与青石接触发出轻微摩擦声，竹叶光斑在道袍上缓慢移动，偶有落叶飘落 |

### 5.3 动作节奏与叙事场景

- **文戏/清修**：动作沉稳克制，每个微动作标注时长和轨迹。节奏舒缓——不是慢，是"不赶"
- **情绪波动场景**：动作幅度和速度略微增加。人物可能在对话中不自觉地握紧剑柄、呼吸带动肩膀起伏更明显
- **对决场景**：动作干脆利落，但仍有物理轨迹。出剑/格挡须具体到"右手剑自右下向左上斜削约90度，剑刃距对方颈部约20cm时停住"
- **轻功/身法（克制）**：以实拍吊威亚的跃落、翻腾呈现，标注起跳高度、空中姿态、落地震感，非CG飞行
- 禁止：无叙事理由的快速动作堆砌、无物理逻辑的瞬移、"一道剑光闪过"等含糊意境描述

### 5.4 服饰与发丝动态

真人仙侠武侠的服饰与发丝动态是画面的天然资产——不是"布料模拟参数"，而是"道袍衣摆被山风吹起约30度角""高马尾的散发被气流带起飘动""丝绸内衫在跃落时自然垂坠"。在分镜表画面描述中标注服饰与发丝的动态细节。束发处的碎发、披风的后摆、剑穗的甩动皆是江湖气韵。

## 六、空间逻辑具象化——Seedance 2.0 空间坐标系统

### 6.1 每镜头必须声明的空间信息
水平位置：画面左/中/右，或画面左侧三分之一处
纵深位置：距镜头{数值}米，前景/中景/背景
人物与场景的关系：距{固定物}{数值}米（距山门石阶2米/距悬崖边0.5米/距八仙桌1米）
（若双人以上）人物A与B的相对距离和朝向、剑尖间距

### 6.2 站位衔接示例
【片段A尾部】
A白衣剑修复持剑立于竹林空地中央，距镜头约4米，侧身约30度面向画面右侧。
晨光从画面右上方45°穿过竹叶斜入（约4000K暖金），在A的右脸与剑刃镀上金边。
A的剑尖斜指地面，距地面约20cm。山岚从画面深处缓慢涌来。

【片段B开头】
A的剑刚从地面挑起约30cm，剑尖仍斜向前方。A仍立于竹林空地中央（位置未变）。
山岚已涌至A身后约1米处，远处竹林被雾遮蔽至仅剩轮廓。
画面左侧一盏石灯（距A约2米）亮起暖黄光（约2400K），照在A的左侧脸颊与发髻。

### 6.3 空间变化必须具象

| 抽象（禁止） | Seedance 2.0 具象 |
|---|---|
| 他走近了 | A从画面背景（距镜头约6米、竹林深处）向镜头方向匀速行走5步（约4米），停在距镜头约2米处——耗时约5秒，每步踩落青石有轻微摩擦声 |
| 两人对峙 | A位于画面中央偏左（距镜头约3米），B位于画面中央偏右（距镜头约3.5米），两人持剑对峙相距约2米，A的剑尖指向B的咽喉前方约20cm，B的剑尖斜指地面 |
| 从客栈到月下长街 | A从客栈大堂（距镜头约3米）走向大门，推开木门（门向内旋转约80度）迈出门槛，进入月下青石长街——月光冷银光瞬间取代客栈灯笼暖黄光，青石湿滑反射月光 |

## 七、运镜规范——Seedance 2.0 摄影机运动

### 7.1 允许的运镜

| 运镜 | Seedance 2.0 描述 | 适用场景 |
|---|---|---|
| 固定 | 摄影机固定不动，画面静止 | 文戏对话、空镜留白、情绪凝视、对峙静止 |
| 手持微晃 | 摄影机有轻微不规则晃动（幅度约±2cm），模拟手持拍摄的呼吸感 | 对决紧张、追逐、情绪爆发、林中行走 |
| 稳定器流动 | 摄影机平滑匀速移动，无晃动 | 长街漫游、人物登场、空间展示、过渡 |
| 缓推 | 摄影机向主体缓慢推进，推进速率约每秒0.3米 | 情绪升温、剑意逼近、真相揭示 |
| 缓拉 | 摄影机向后缓慢拉远，拉远速率约每秒0.3米 | 别离、收束、揭示全貌、孤绝感 |
| 跟拍 | 摄影机与侠客保持约2米距离同步移动 | 行走跟随、长街追踪、江湖同行 |
| 摇镜 | 摄影机原地水平/垂直旋转 | 视线转移、山水空间关系交代 |

### 7.2 禁用运镜

- 无叙事目的的快速甩镜、急推急拉（推拉速率超过每秒1米）
- 超过3秒的剧烈手持晃动（除非受击/眩晕/对决混乱叙事）
- 无逻辑花式转场——划屏、旋转、百叶窗、翻页等特效转场
- 摄影机无理由的360度旋转

### 7.3 真人仙侠武侠运镜哲学

- 固定机位是第一选择——让观众看到真实的侠客在真实的江湖里自然地存在
- 手持微晃在对决与情绪段落使用——但晃动幅度不超过电影纪实风格的常规范围
- 运动镜头的起幅和落幅必须平稳，运动过程匀速——禁止突然加速或急停
- 轻功/身法段落可用跟拍或升降，但以实拍吊威亚的物理感为基准，非CG飞行镜头

## 八、转场规范

### 8.1 允许的转场方式

| 转场 | 视觉执行 | 叙事功能 |
|---|---|---|
| 硬切 | 直接切换 | 同场戏内镜头切换（默认） |
| 光影匹配转场 | 两个场景在相近光影逻辑下切换 | 时间流逝、平行叙事。例：A处竹林晨光 → B处山门晨光 |
| 空间匹配转场 | 两个空间在构图或元素上呼应 | 场景跳转。例：客栈门关上的瞬间 → 道观门推开的瞬间 |
| 空镜过渡 | 插入场景空镜（3-5秒） | 情绪缓冲、章节划分、时间流逝暗示。如山岚流动、月下青石、灯笼摇曳 |
| 焦点转场 | 前镜焦点从主体移至背景，后镜从模糊背景中逐渐聚焦主体 | 空间切换、注意力的转移 |

### 8.2 禁止的转场

- 纯视觉特效转场（翻页、划屏、百叶窗、马赛克、法术光效过场）
- 无叙事逻辑的旋转/缩放转场
- 同一场戏内使用超过两种转场方式

## 十一、空镜使用规范

### 11.1 空镜不是"没东西拍"

空镜是情绪容器。每个空镜必须有叙事目的和具体的视觉内容：

| 空镜类型 | 叙事目的 | 示例 |
|---|---|---|
| 场景建立 | 新空间首次出现——让观众看清楚这是什么江湖场所 | 仙山石台大全景：云海翻涌、奇松探崖、远处峰峦 |
| 情绪缓冲 | 高情绪段落后的喘息 | 竹叶光斑在青石上缓慢移动，远处一片落叶飘下 |
| 时间流逝 | 暗示时间过去了 | 同一扇竹林的晨光 → 蓝调时刻 → 月光 |
| 意境留白 | 以物代情、写意江湖 | 八仙桌上半碗没喝完的酒，酒渍残留碗沿 |
| 转场衔接 | 前后两个空间的自然过渡 | 悬崖边的飞檐铃铛——前一场的客栈，下一场是剑冢 |

### 11.2 空镜 Seedance 2.0 描述规范

空镜也必须遵循光源+质感+动态的描述铁律：
晨光从右上方45°穿过竹叶斜入（约4000K暖金），在青石小径投下斑驳的竹叶光斑，
光斑随竹叶晃动而缓慢移动宽度和位置，约5秒后整体变暗约30%——一朵云遮住了日光。
青石板有苔痕与车辙磨痕，竹叶铺地湿润，远处山岚缓慢涌来。
