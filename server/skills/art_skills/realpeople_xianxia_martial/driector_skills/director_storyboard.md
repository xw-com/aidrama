# 分镜提示词 · 真人仙侠武侠 · 风格专属技法

---

## 适用范围

本 Skill 专用于**真人仙侠武侠**风格的分镜提示词生成，适配仙侠清修、江湖恩怨、知己情义、正邪对峙、侠骨柔情等真人实拍武侠影视题材的分镜创作。

## 一、摄影机前的情绪——面孔、眼神、微表情

> 真人仙侠武侠的情绪不来自"法术光效"或"渲染参数"，而来自真人演员在摄影机前的微表情与侠气。以下映射面向摄影机捕捉真实江湖人物的方式。

| 情绪输入 | 面容描述 | 眼神描述 | 微表情补充 |
|---|---|---|---|
| 清冷 / 出尘 | 神情淡远，面部线条松弛不紧绷，眉骨自然 | 目光悠远失焦，像隔着一层山岚看人 | 唇线平直，下颌微收，呼吸轻缓，仙韵自持 |
| 侠气 / 沉稳 | 神情利落，面部线条自然有力 | 眼神笃定坦荡，直视前方不躲闪 | 唇线平直，下颌微收，气场沉稳克制 |
| 悲怆 / 落寞 | 眉眼低垂，面部肌肉松弛 | 目光涣散失焦，望向远处山岚或地面 | 嘴角自然下沉，表情怅然，眼底有沧桑 |
| 温润 / 柔情 | 眉目舒展，面部柔和 | 眼神温润专注，像在认真听对方说话 | 嘴角自然微扬，不是笑，是有温度 |
| 狠厉 / 戾气 | 面部线条微微绷紧，颧骨与下颌发力 | 眼神锐利带寒，注视有力，眼底有戾 | 下颌收紧，嘴角微抿或微扬带冷意，杀气内敛 |
| 警觉 / 戒备 | 面部线条微微绷紧，不夸张 | 眼神锐利但不过度，注视有力 | 下颌收紧，身体语言防御，手按剑柄 |
| 惊愕 / 触动 | 眼尾微抬，眉毛自然上扬 | 眼神骤然聚焦，瞳孔微扩 | 嘴角微启，表情鲜活不夸张 |
| 沉思 / 顿悟 | 神情淡然，眼部周围肌肉放松 | 目光放远失焦，像在看远处山岚又不在看 | 表情平静，可能单手抚剑或手指轻点剑柄 |
| 喜悦 / 鲜活 | 眼角出现自然笑纹，眼型微弯 | 眼神明亮有光，眼角有笑意牵动 | 嘴角上扬，表情生动但不夸张 |
| 疲惫 / 倦怠 | 眼窝微陷，面部整体松弛 | 目光朦胧，眼皮微沉 | 眉眼低垂，发丝凌乱沾汗，表情松弛 |
| 决绝 / 剑意 | 面部线条清晰，下颌微抬 | 眼神笔直向前，剑意凛冽，不回避不躲闪 | 下巴微收或微抬，嘴角微抿，表情果敢但不凶悍 |

## 二、摄影机前的光——光源逻辑与氛围

### 2.1 自然光时刻

| 时刻 | 光源行为 | 色温与色调 | 空间氛围 |
|---|---|---|---|
| 云海晨曦 | 低角度暖金日光穿透云雾斜入山间/竹林；仙岚透光形成可见光柱；长阴影 | 3500-4500K暖金，空气澄澈湿润 | 出尘静谧、悟道蓄势、一切尚未开始 |
| 上午 | 日光升高，冷白清澈，阴影锐利；青石与木构材质清晰；室内门窗光面积最大 | 5000-6000K中性偏冷 | 秩序建立、江湖日常、高效清晰 |
| 正午 | 顶光或近乎顶光，阴影短而浓重；材质反光强；多用于压抑前兆 | 5500-6500K冷调 | 暂停感、烈日下的肃杀前兆 |
| 午后 | 日光偏西，暖调渐强，斜光穿过竹林/飞檐形成长阴影和光斑 | 4000-5000K渐暖 | 慵懒、时间变慢、午后江湖的柔和 |
| 金色时刻 | 极低角度暖金漫射，长阴影到极致，青石飞檐镀金边 | 2800-3500K极暖 | 转瞬即逝的珍贵、温情回忆段落的唯一光源 |
| 蓝调时刻 | 太阳沉入山后，天空深蓝紫，自然光极暗极冷，灯笼/篝火刚刚亮起 | 8000-10000K天空+暖点人工光 | 过渡、别离诗意、白天已尽夜晚尚未接管 |
| 月夜 | 月光冷银清辉为主，地面寒霜微反，剑刃冷反光，远处灯笼暖点 | 月光4100-4500K冷银/灯笼2200-2800K暖 | 孤寒肃杀、月下独行、林中对决 |
| 深夜 | 仅靠火光/灯笼/丹炉——篝火、油灯、丹炉火光。大部分区域沉入暗部 | 暖光源2000–2600K | 孤寒或私密、世界安静了 |

| 情绪基调 | 光线配方 | 摄影约束 |
|---|---|---|
| 仙门清修 | 晨曦/天光自然漫射（4000-5500K），云雾柔化，无硬阴影 | 低反差通透感，浅景深突出人物，仙岚透光 |

## 四、摄影机语法——镜头选择与运动

### 4.1 焦段选择

| 焦段 | 叙事性格 | 适用场景 |
|---|---|---|
| 24-28mm广角 | 山水吞噬人物、江湖苍茫、仙山宏大与个体渺小 | 仙山空镜、长街对峙、剑冢全景 |
| 35mm小广角 | 主观视点，身临其境的江湖纪实感，人与环境共存 | 竹林行走、客栈对话、长街跟随 |
| 50mm标准 | 人眼等价，客观中立的注视，最诚实的镜头 | 人物肖像、师徒对话、情感凝视 |
| 85mm中长焦 | 压缩空间，拉近情感距离，背景虚化突出人物 | 持剑特写、远山望见、月下对视 |
| 135mm+长焦 | 将人物从山水中剥离，极端的注视或窥视 | 孤绝的侠客、远眺、剑意的物理距离 |

### 4.2 景别选择

| 景别 | 取景范围 | 叙事功能 |
|---|---|---|
| 大特写 | 眼睛/嘴唇/剑指/剑刃细节 | 情绪爆发点、剑意关键、感官聚焦 |
| 近景 | 头顶至胸部以上 | 人物情感、对话反应、面部微表情 |
| 中近景 | 头顶至腰部 | 人物互动、持剑手势、剑诀动作 |
| 中景 | 头顶至膝盖上下 | 人物与空间的初级关系、对峙同框 |
| 全景 | 人物全身+部分山水环境 | 人物在江湖中的位置、行动路线 |
| 大全景/空镜 | 山水空间全貌，人物极小或无人物 | 空间叙事、情绪缓冲、写意留白 |

### 4.3 摄影机运动

| 运动方式 | 视觉心理 | 使用场景 |
|---|---|---|
| 固定 | 冷静观察，让剑与风自己说话 | 山门对话、客栈文戏、空镜留白 |
| 手持微晃 | 在场感，呼吸感，对决的临场紧张 | 林中对决、追逐、情绪爆发 |
| 稳定器流动 | 优雅的江湖漫游，诗意 | 长街行走、人物登场、空间展示 |
| 缓推 | 注意力逐渐聚焦、情绪趋近、剑意逼近 | 对话升温、真相逼近、对决前夜 |
| 缓拉 | 拉开距离、揭示全貌、情绪抽离 | 别离、章节收束、空间展示 |
| 跟拍 | 与侠客同行、主观陪同 | 长街行走、追踪、江湖跟随 |
| 摇镜 | 视线转移、空间关系交代 | 人物视线引导、山水与人的关系 |

## 五、固定风格锚定词

**摄影锚定（必选）：**

真人实拍摄影，真人电影剧照，中国古代仙侠武侠，电影级摄影，自然光与火光灯笼月光谱调度，真实色彩科学

**人物质感（含人物镜头时必选）：**

真人写实摄影质感，真实皮肤纹理毛孔可见，不磨皮不硅胶脸，古风发式真实发质有碎发，丝绸粗布战甲面料纹理可见有穿着褶皱，自然微表情，真实江湖肢体语言

**场景质感（含场景镜头时必选）：**

真人实拍江湖场景摄影，真实山水古建材质和岁月痕迹（青石苔痕/木构风化/朱柱漆剥/兵刃锈迹），光源方向明确可追溯，大气透视与云雾自然，非影城样板街非效果图

**参考图一致性锚定（参考图模式必选）：**

保持人物造型、面容、古风发式、服饰与参考图完全一致，保持场景风格与参考图一致，保持光影色彩基调统一，所有镜头呈现为同一人物的连续摄影记录

**风格收尾（固定）：**

真人写实摄影，中国古代仙侠武侠电影质感，电影级摄影画面，非3D非渲染非CG，法术剑气克制光晕服务实拍

**画质锁定词：**

模式A（中文）——默认：

## 六、美学禁止项

以下词汇/风格不得出现于输出提示词中：

- ❌ 3D渲染 / 3D建模 / CG / UE引擎 / Blender / PBR材质 / 次世代建模 / 体积光 / 环境光遮蔽 / 光线追踪
- ❌ 2D手绘 / 插画 / 动画 / 二次元 / 漫画 / Q版 / 低多边形 / 国风插画
- ❌ 写实摄影（英文禁止 photorealistic / realistic photography——本风格是"真人实拍摄影"live-action cinematic photography，不是"拟真渲染"）
- ❌ 过度磨皮 / 塑料假面 / 零毛孔 / 硅胶脸 / 蜡像感 / AI感平滑 / 动漫化滤镜
- ❌ 过度CG法术特效 / 炫光能量弹 / 粒子特效过载 / 游戏技能式光效 / 发光武器
- ❌ 现代当代都市 / 民国 / 宫廷宫墙 / 赛博朋克 / 科幻机甲 / 太空 / 西方奇幻 / 中世纪 / 异世界 / 日式
- ❌ 人体结构错误 / 肢体畸形 / 面部崩坏 / 比例失调
- ❌ 高饱和荧光色 / 霓虹溢色 / 廉价滤镜感 / 动漫化色调
- ❌ 非中国古代仙侠武侠的架空场景 / 无中文古建辨识度的 generic fantasy
