## 二、摄影机语法（替代"渲染引擎"）

> 真人仙侠武侠不依赖渲染管线。画面品质取决于摄影机的选择、镜头的性格、光线的调度。以下为"摄影机语法"核心参数。

### 2.1 画幅与格式

| 参数 | 基准值 | 美学意图 |
|---|---|---|
| 影像格式 | 35mm胶片质感 / 全画幅数字摄影 | 浅景深能力、自然的暗角过渡、微妙的颗粒结构——支撑写意江湖的质感 |
| 色彩科学 | ARRI Alexa / Sony Venice 类电影色彩科学 | 肤色还原自然、高光滚降柔和、暗部不压死且有层次——保留丝绸与兵刃的材质层次 |

### 2.2 镜头性格

| 焦段 | 叙事性格 | 典型应用 |

| 24-28mm（广角） | 山水吞噬人物、江湖苍茫、仙山宏大与个体渺小 | 仙山云海空镜、长街对峙、剑冢全景 |

## 四、全局约束规则

### 4.1 影像真实性约束（必守）

| 编号 | 规则 |
|---|---|
| P1 | 必须以「真人摄影 / 真人实拍 / 真人电影剧照」为生成锚——画面必须读作"摄影机拍下的"，而非"计算机生成的" |
| P2 | 必须指定一个具体的光源逻辑：这场戏的光从哪里来？（日光/月光/火光/灯笼/丹炉）光源方向、色温、软硬须自洽 |
| P3 | 必须保留人物皮肤的真实质感——毛孔、细纹、痣、自然肤色不均——杜绝塑料磨皮与AI感假面 |
| P4 | 发丝必须呈现自然状态——风吹乱的散发、扎束处的碎发、逆光下半透明轮廓——杜绝建模感整齐发块与假发套 |
| P5 | 服饰必须体现"穿过"的痕迹——丝绸褶皱、粗布磨损、领口变形、甲片划痕——杜绝全新样板衣感 |
| P6 | 场景必须有"被使用过/有岁月"的证据——青石苔痕、木构风化、兵刃锈迹、墙面斑驳——杜绝影城样板街 |
| P7 | 人物必须处于自然体态——真实的站姿（重心偏一侧/持剑的随手）、不刻意的表情、符合武人/修者身份的体态 |
| P8 | 必须指定一个具体的中国古代仙侠/武侠空间——拒绝"generic fantasy"或任何无国别标识的架空古风 |
