# 战争纪实约束 · 战争纪实摄影 · 技法参考

---

## 一、色调体系与画面基调

- **色调基底** — 全片以土黄（C1）、橄榄绿（C2）、铁灰（C3）为基底色，整体色温偏暖偏灰（4800-5200K），饱和度低（30-50%），呈现战地纪实的泥土与硝烟质感。全片保持低饱和战地色调基底，局部以锈红（C8）与暖肤（C6）点缀人物焦点
- **火光与信号色克制使用** — 爆炸火光/信号弹/紧急灯等高饱和暖色仅在叙事转折点短暂出现，作为视觉冲击信号而非常态
- **色盘先行原则** — 段落规划需先绑定情绪场景（行军/战斗/等待/回忆/劫后余生等），再确定主色+辅色与光影方案
- **禁用色域** — 高饱和荧光色、商业明快色、时尚都市色、动漫高饱和色均与本风格不兼容

---

## 二、光影方案体系

- **光影即战场** — 6 套光影方案对应不同战场段落，导演规划阶段应在段落层面确定光影基调方向，而非逐镜指定
- **光源角度** — 默认自然漫射+斜侧光，模拟户外战地光照；室内/夜间用局部点光源（油灯/手电/火堆）

| 情绪段落 | 光影方向 | 色调倾向 | 适用阶段 |
|---|---|---|---|
| 行军/等待 | A·漫射灰光 | 土黄+矝烟灰，均匀漫射 | 非战斗段 |
| 战斗/交火 | B·火光闪切 | 锈红爆点+铁灰底，明暗急切 | 战斗段 |
| 夜战/巡逻 | C·局部点光 | 暗夜蓝底+手电/火堆暖点 | 夜间段 |
| 室讯/室内 | D·顶光压光 | 铁灰+炭黑，高反差 | 室讯/指挥段 |
| 回忆/战前 | E·柔焦低饱 | 暖肤+灰白，轻微褪色 | 回忆段 |
| 劫后余生 | F·晨雾漫射 | 灰白+矝烟灰，降饱和 | 结尾/停火段 |

- **冷暖光分配** — 暖灰调（A/E/F）为全片基调，冷调（C 暗夜蓝）仅在夜间段落使用，火光暖点（B）仅在战斗段落短暂出现
- **氛围方向映射** — 每场戏的氛围方向应能映射到上述光影方案（A-F）的某一方向，确保视觉一致性

## 三、质感方向

- **纪实颗粒感** — 战地摄影的核心：可见胶片颗粒、非完美锐度、偶尔的焦段偏移
- **长焦压缩与浅景深** — 远距离拍摄、空间压缩、背景虚化，体现战地记者的距离感与窥视感
- **尘雾介质** — 硝烟灰（C4）作为空气介质贯穿画面，远处偏灰偏低对比，近处保留质感细节
- **非洁净感** — 人物与场景带尘土、汗渍、磨损、补丁痕迹，禁止"洁净无瑕"的商业广告质感

## 四、场景空间元素

战争纪实摄影特有的场景元素及其视觉叙事功能：

- **战壕/掩体/废墟** — 战场核心空间，景即情：战壕泥泞 = 困顿、掩体烛光 = 等待、废墟烟柱 = 毁灭
- **军营/指挥所/野战医院** — 非战斗段落的场景，景即情：军营黄昏 = 思乡、指挥所地图 = 决策、野战床单 = 伤亡
- **村庄/集市/难民营** — 平民生活场景，景即情：集市人声 = 战前日常、难民营帐 = 流离、教堂避难 = 人道
- **铁丝网/弹坑/旗帜** — 战场标识元素，景即情：铁丝网 = 阻隔、弹坑积水 = 伤痕、破旗 = 坚持或投降
- **段落间用场景空镜过渡** — 本风格有丰富的场景资产（不同时段/天候/战况变体），段落衔接建议用场景空镜做情绪缓冲（如远山烟柱→黄昏军营），不要硬切
- **转折点用视觉而非台词** — 优先使用画面手段（火光突变、景别跳切、空镜隐喻）而非依赖对白解释
- **暴力尺度约束** — 战争场面以叙事功能为主，不过度渲染血腥伤口细节；冲击力来自构图与音效而非直观血腥

## 五、配乐与环境音

战争纪实世界观下的声音元素约束：

### 乐器选择

- **低音弦乐** — 核心：大提琴/低音提琴铺底，沉重克制
- **军鼓/小军鼓** — 行军节奏与战斗紧迫感
- **圆号/长号** — 庄严/悲怆/史诗感的铜管色彩（克制使用，非好莱坞大片配乐）
- **独奏钢琴** — 回忆/战后/人性余温段落

### 乐器组合策略

| 情绪阶段 | 乐器组合 |
|---|---|
| 行军/等待 | 低音弦乐 + 远处军鼓 |
| 战斗/交火 | 军鼓急敲 + 铜管短促 |
| 夜间/巡逻 | 低音弦乐 + 独奏钢琴 |
| 回忆/战前 | 独奏钢琴 |
| 劫后余生 | 独奏钢琴 + 弦乐渐入 |

### 典型环境音

- **战场环境音** — 远处炮声/枪声回响/引擎轰鸣/履带碾地/碎石滚落/风过废墟
- **军营环境音** — 行军脚步/装备碰撞/无线电杂音/发电机嗡鸣/炊事叮当
- **自然环境音** — 风吹荒草/虫鸣/雨滴钢盔/溪水/鸟鸣（战后静默中鸟鸣=和平暗示）
- **每场戏标注 1-2 个核心环境音**，帮助后续音效设计
- **留白即张力** — 战斗前/炮击后的突然静默是最强叙事手段，比满配更震撼。关键瞬间（战友倒下/停火/阅读家书）优先去掉配乐只留E环境音
- **避免满配** — 全片配乐覆盖率建议不超过 40%。留白段落的"无声"与配乐段落形成呼吸感，突出真实战场张力
