## 二、全局色彩盘（风格基线，不是硬锁）

> 目标：统一审美而非限制创作。除「硬约束色」外，其余颜色默认优先使用，可在合理范围内偏移。

### 色彩使用层级

| 层级 | 约束强度 | 说明 |
|---|---|---|
| L1 硬约束 | 高 | 仅锁定角色识别核心：肤色、发色、主服底色的审美方向 |
| L2 软约束 | 中 | 战场色、装具色、点缀色优先参考色盘，可按镜头与剧情微调 |
| L3 例外机制 | 低 | 火光/信号弹/回忆/高潮戏可临时突破局部色彩，但需保留整体低饱和逻辑 |

### 硬约束色（默认锁定）

| 色项 | 对应色 | 规则 |
|---|---|---|
| 肤色基准 | C6 暖肤 | 默认优先，允许尘土覆盖下的明度/暖度微调 |
| 发色/瞳色基准 | C10 炭黑系 | 默认自然黑/深棕，允许深褐轻微偏移，禁漂染 |

### 软约束色（推荐优先）

> C1/C2/C3/C4/C5/C7/C8/C9 为推荐色域，用于军服、装具、战场环境、烟雾尘雾、火光余烬等。可根据镜头氛围做同色相邻近调整。

### 情绪色盘（导演对齐版）

| 情绪场景 | 主色 | 辅色 | 光效与对比建议 | 画面关键词 |
|---|---|---|---|---|
| 行军开拔（日常） | C2 橄榄绿 | C1 土黄 + C4 硝烟灰 | 均匀漫射光，低对比，远景尘土扬起 | 队列、尘雾、秩序 |
| 遭遇战前（潜伏） | C4 硝烟灰 | C3 铁灰 + C7 暗夜蓝 | 整体压暗，阴影加深，冷调主导 | 压抑、屏息、一触即发 |
| 突围冲锋（高潮） | C8 锈红 | C3 铁灰 + C10 炭黑 | 局部火光高对比，扬尘逆光，动态模糊克制 | 爆发、混乱、冲击 |
| 战壕守备（疲惫） | C3 铁灰 | C4 硝烟灰 + C9 灰白 | 稀薄顶光，面部半明半暗，低饱和 | 消耗、麻木、坚持 |
| 平民撤离（悲悯） | C9 灰白 | C1 土黄 + C5 焦褐 | 阴天漫射，长焦压缩人群，无强光 | 疏离、沉重、人流 |
| 战友情深（温暖） | C5 焦褐 | C1 土黄 + C6 暖肤 | 篝火/油灯局部暖光，暗部保留 | 微光、依靠、余温 |
| 黎明收整（劫后） | C9 灰白 | C7 暗夜蓝 + C1 土黄 | 冷蓝向微暖过渡，逆光尘雾 | 幸存、茫然、寂静 |
| 回忆/战前（柔和化） | C1 土黄 | C9 灰白 + C2 橄榄绿 | 雾化柔光、轻微过曝，允许偏色但不霓虹 | 旧照、安宁、逝去 |

### 情绪色盘使用规则

| 编号 | 规则 |
|---|---|
| E1 | 每条提示词至少指定 1 个「情绪场景」并绑定主色+辅色组合 |
| E2 | 单镜头主色不超过 2 个，避免颜色叙事失焦 |
| E3 | 情绪切换时优先调整光比与色温，再调整饱和度 |
| E4 | 战争纪实默认遵循「灰底 + 微暖点」：低饱和灰调铺底，暖光只落在人物关系焦点 |
| E5 | 若与剧情冲突，以情绪色盘优先于通用推荐色，但不得突破严禁项 |

### 色温约束

| 参数 | 值 | 说明 |
|---|---|---|
| 整体色温 | 中性 4800-5600K（推荐） | 硝烟天光下可整体压冷 |
| 肤色色温 | 微暖 5000-5400K（推荐） | 风尘状态下保留生命感 |
| 对比度 | 中强（建议保持） | 明暗反差有力但不风格化 |
| 饱和度 | 低 25-40%（建议区间） | 战地低饱和纪实基调 |

### 容差与例外

| 项目 | 建议容差 |
|---|---|
| 色相偏移 | ±8° |
| 饱和度偏移 | ±10% |
| 明度偏移 | ±12% |

> 例外场景：火光、信号弹、篝火、回忆闪回镜头可使用局部高饱和暖色块；但禁止霓虹荧光与时尚大片色彩语言入镜。

## 三、全局约束规则

### 必守规则（所有技能继承）

| 编号 | 规则 |
|---|---|
| R1 | 必须包含「战争纪实摄影 / 战地记者视角」风格锚定词 |
| R2 | 必须声明「低饱和战地色 + 纪实颗粒」 |
| R3 | 面部必须使用「面容细腻渲染 + 皮肤细腻（含尘土汗渍质感）」 |
| R4 | 发丝必须使用「根根分明 + 发丝细腻渲染（含尘土与帽压痕迹）」 |
| R5 | 纹理必须声明「纹理细节超清晰（做旧/磨损/烟熏痕迹）」 |

### 严禁项（所有技能继承）

| 编号 | 严禁内容 |
|---|---|
| X1 | 严禁「卡通/动漫/二次元/插画风」 |
| X2 | 严禁「高饱和荧光色/霓虹色/时尚大片光」 |
| X3 | 严禁「血腥伤口细节/断肢/残躯」等过度血腥残忍的直接描绘 |
| X4 | 严禁「面部变形/多指/肢体异常」倾向词 |
| X5 | 严禁「裸体/暴露/透视/暗示性描述」 |
| X6 | 严禁「美化战争/渲染暴力快感」的表述与构图 |
