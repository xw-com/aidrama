# 人物基础形象生成 · 战争纪实约束手册

---

## 一、基础形象原则

1. **面容即灵魂** — 硝烟污渍与尘汗之下的五官是角色唯一锚点，毛孔级精细渲染
2. **角色为本** — 基础着装由角色描述（军衔/职务/性别/阵营/场景）决定其战地常规着装；后续特定服化为叠加层
3. **四视图一致** — 面容/体型/发型/基础服装跨视图高度统一
4. **实拍纪实** — 以战地记者纪实摄影为锚点，保留皮肤真实质感（尘土/汗渍/干裂/疲态），拒绝干净明亮的时尚大片感

---

## 二、面容约束

> 不再固定五官特征参数，由角色描述（性别/年龄/性格/气质）驱动 AI 自由生成五官，保证人物间外观差异化。

### 通用要求

| 项目 | 约束 |
|---|---|
| 五官 | 由角色描述自然推导，不预设脸型/眼型/眉型/鼻型/唇型 |
| 风格底色 | 战争纪实摄影、战地记者视角、毛孔级精细渲染、写实材质、自然光影 |
| 气质 | 必须从角色描述提炼整体气质关键词（如疲惫坚毅/沉静悲悯/冷硬果决/惊惶未定），并写入提示词 |
| 表情 | 中性微表情，符合角色气质，以克制为主 |

### 战争面容规范（题材专属）

| 项目 | 约束 | 提示词 |
|---|---|---|
| 污渍 | 面部带硝烟灰、泥点、汗渍冲刷痕迹，分布自然不夸张 | 硝烟污渍、面部尘土、汗渍冲刷痕迹 |
| 疲态 | 眼下阴影、嘴唇干裂、面颊风霜，但不憔悴失形 | 疲惫面容、嘴唇干裂、眼下阴影 |
| 眼神 | 疲惫而坚毅，或沉静悲悯，禁止空洞瞪视 | 疲惫坚毅的眼神 |
| 伤情 | 仅允许尘土擦痕、绷带等克制暗示，严禁伤口细节 | 轻微擦痕（可选）、绷带（可选） |

## 三、肤感约束

### 女性

| 项目 | 约束 | 提示词 |
|---|---|---|
| 肤色 | 自然肤色、全身均匀、可偏黄偏粗糙 | 自然肤色、风尘肤色 |
| 光泽 | 亚光为主、汗渍局部反光、无妆感 | 皮肤自然、亚光质感、汗渍反光 |
| 质感 | 细腻、保留毛孔微质感、尘土覆盖下仍见真实皮肤 | 皮肤细腻、毛孔微可见、尘土覆盖 |
| 露肤 | 面部/颈部/手部（战时着装遮蔽为主） | 手部粗糙、指节尘污 |

### 男性

| 项目 | 约束 | 提示词 |
|---|---|---|
| 肤色 | 自然肤色、可偏黝黑、全身均匀 | 自然肤色、晒后肤色 |
| 光泽 | 亚光、汗渍反光、无油光 | 皮肤自然、亚光、汗渍 |
| 质感 | 粗粝可信、可见毛孔、风霜与干裂细节 | 皮肤质感真实、毛孔清晰、嘴唇干裂 |

### 尘土汗水质感规则（题材统一）

- 面部与手部必须带尘土附着与汗渍冲刷痕迹，分布自然，不得覆盖五官辨识度
- 高曝光区域（颧骨/鼻梁/额头）允许汗光高光，其余保持亚光
- 严禁干净无瑕的"偶像剧面孔"与过度磨皮；严禁血污、伤口细节直接描绘

- 平民角色为普通体型，携行囊时体态下沉、步伐沉重

## 五、基础发型约束

> 仅定义战地自然发型，军衔帽饰与装具在服化衍生环节叠加。

### 女性

| 项目 | 约束 | 提示词 |
|---|---|---|
| 发色 | 自然发色（黑色/深棕），禁漂色/染色 | 自然发色、黑色/深棕 |
| 发长 | 军人角色束发收纳于衣领/钢盔内；平民角色可及肩长发凌乱束起 | 低马尾束发、钢盔下碎发 |
| 发质 | 发丝清晰、带尘土与汗湿贴颊 | 发丝根根分明、汗湿碎发 |
| 造型 | 低马尾/发髻/短发的利落束收，无发饰 | 战地束发、无发饰 |

### 男性

| 项目 | 约束 | 提示词 |
|---|---|---|
| 发色 | 自然发色（黑色/深棕），禁漂染 | 自然发色、黑色/深棕 |
| 发长 | 板寸/短寸/利落短发，帽压痕迹清晰 | 板寸短发、帽压痕迹 |
| 发质 | 发丝清晰、带尘土感 | 发丝根根分明、尘土感 |
| 造型 | 极简利落、无造型感、无发饰 | 战地短发、无发饰 |

### 军人发型规范（题材统一）

- 军人发型一律短寸/利落束发，须符合军事条例感；长发披散仅允许平民角色
- 发型须与钢盔/军帽佩戴逻辑兼容（束发收纳、帽压痕迹）
- 严禁染发、油头造型、偶像剧刘海等和平年代造型词

## 六、基础服装约束

> 基础服装由角色描述（军衔/职务/性别/场景）决定其战地最常规着装，作为该角色「战地默认态」；正式礼服/特殊衍生在服化衍生环节叠加。**禁止内衣打底**。

### 着装选择原则

| 角色身份 | 默认着装方向 |
|---|---|
| 陆军士兵 | 作训服/迷彩服 + 作战靴 + 单兵装具（弹匣袋/背囊） |
| 军官 | 军服/作训服 + 衔级标识 + 装具（克制、不夸张） |
| 特战/侦察 | 模块化战术背心 + 作战服 + 战术头盔 |
| 战地医护 | 军绿/灰白医护罩衫 + 医疗挎包 |
| 战地记者 | 军绿摄影背心 + 防护背心 + 相机包 |
| 战时平民 | 旧呢大衣/粗布外衣 + 简单行囊 |
| 角色描述未明确 | 作训服、低饱和土黄/橄榄绿 |

### 着装统一规则

- 服装风格须与战争纪实摄影美学一致（做旧磨损、写实材质）
- 军服年代规则：须与剧情设定年代统一制式（现代=数码迷彩/模块化装具；年代戏=对应年代军服制式），同阵营不得混搭
- 颜色低饱和土黄/橄榄绿/铁灰，无复杂花纹，便于后续衍生叠加
- 四视图服装款式完全一致
- 基础服装是「战地默认态」，焦点仍在面容与体态
- 服装必须做旧：磨损、褪色、泥渍、烟熏痕迹，禁止崭新笔挺
- 严禁内衣/暴露/性化打底

## 八、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须为「自然状态」 |
| R2 | 必须根据角色描述声明战地常规着装（士兵→作训服+装具、医护→医护罩衫、记者→摄影背心、平民→旧衣行囊）；禁止内衣打底 |
| R3 | 必须声明「无发饰、无配饰」（军用装具除外） |
| R4 | 必须指定「纯净灰土色背景」 |
| R5 | 必须指定「四视图一致性」 |
| R6 | 全身立像必须从头顶到脚底完整展示，严禁裁切 |
| R7 | 必须声明角色身高并通过头身比换算约束全身比例；军人体格须符合精瘦结实规范 |
| R8 | 人像特写必须从头顶到锁骨完整展示，严禁裁切头顶 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 内衣/暴露/性化打底；与角色描述明显不符的着装；崭新笔挺无做旧的军服 |
| X2 | 正顶硬光/正底光/彩色光（篝火/油灯暖光除外） |
| X3 | 过度美白/过度磨皮至无质感；完全干净的"时尚大片"面孔 |
| X4 | 复杂场景背景（必须纯灰底） |
| X5 | 夸张表情/动态姿势；空洞瞪视 |
| X6 | 全身立像裁切头顶或脚底，必须从头到脚完整入画 |
| X7 | 人像特写裁切头顶，必须从头顶到锁骨完整入画 |
| X8 | 血腥伤口细节/断肢等过度血腥残忍描绘；美化战争的表达；军服年代混搭 |
