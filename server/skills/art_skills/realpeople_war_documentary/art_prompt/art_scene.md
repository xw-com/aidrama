# 场景图生成 · 战争纪实约束手册

---

## 一、场景美学原则

1. **空间叙事** — 战场不是背景板，断壁、弹痕、散落物品都在无声讲述发生了什么
2. **层次纵深** — 所有场景必须具备前/中/后景，硝烟尘雾是天然的空气透视介质
3. **质感至上** — 焦混凝土/锈蚀钢板/帆布/朽木/泥土等材质纹理必须超清晰
4. **实拍为锚** — 一切画面以战地纪实摄影为标准，拒绝 3D 渲染/CG 动画/战争奇观大片感；追求镜头光学特征（长焦压缩、景深虚化、镜头暗角、纪实颗粒）与物理光照（漫射天光、火光余烬、体积尘雾）

## 二、战场环境影调映射

| 环境 | 主色调 | 辅色调 | 提示词 |
|---|---|---|---|
| 晨雾战场 | 灰白 + 冷蓝 | 土黄、硝烟灰 | 晨雾弥漫、冷灰天光、轮廓柔化 |
| 白昼硝烟 | 土黄 + 硝烟灰 | 橄榄绿、铁灰 | 硝烟遮日、尘土扬起、天光浑浊 |
| 黄昏战线 | 焦褐 + 锈红 | 土黄、暗夜蓝 | 黄昏余烬、长影拉锯、苍凉暖意 |
| 夜战火光 | 暗夜蓝 + 炭黑 | 锈红火光点缀 | 夜幕探照、光锥穿尘、曳光痕迹 |

## 三、室内场景

### 空间规范

| 维度 | 约束 | 提示词 |
|---|---|---|
| 风格 | 前线指挥部/野战医院/军营帐篷/地下避难所/后勤仓库，功能性粗粝 | 战地{功能空间}，功能性布局 |
| 材质 | 帆布/木板/焦混凝土/铁皮/泥土为主 | 帆布褶皱、焦混凝土墙面、铁皮结构 |
| 色调 | 低饱和土黄/橄榄绿/铁灰 + 克制点缀 | 低饱和战地色、土黄橄榄绿 |
| 纵深 | 前/中/后景层次 | 前景{元素}、中景{元素}、后景{元素} |
| 质感 | 帆布磨损/木纹裂痕/金属锈蚀可辨 | 纹理清晰、质感写实 |
| 光照 | 油灯/烛光/野战灯/缝隙天光为主，光线穿尘，可见光束粒子 | 油灯暖光、光束穿尘、缝隙天光 |
| 镜头感 | 长焦压缩、浅景深虚化、微镜头暗角、纪实颗粒 | telephoto compression、shallow depth of field、lens vignette、film grain |
| 瑕疵感 | 弹痕墙面/顶棚熏黑/泥泞地面/散落物件 | 战损痕迹、熏黑顶棚、泥泞地面 |

### 室内类型速查

| 类型 | 核心元素 | 氛围词 |
|---|---|---|
| 前线指挥部 | 沙盘地图、野战电台、苫布桌面、马灯 | 压抑紧绷、临战氛围 |
| 野战医院 | 行军床、医疗箱、纱帘、油灯 | 隐忍伤痛、克制悲悯 |
| 军营帐篷 | 行军背囊、钢盔、步枪架、帆布帘 | 疲惫秩序、战友群像 |
| 地下避难所 | 拱形结构、蜡烛、储水桶、毯子 | 窄迫庇护、平民不安 |
| 后勤仓库 | 弹药箱堆叠、木货架、吊灯、尘雾 | 物资流转、后方纵深 |

## 四、室外场景

### 空间规范

| 维度 | 约束 | 提示词 |
|---|---|---|
| 类型 | 战壕/废墟街区/街垒关卡/断桥渡口/焦土原野/集结点 | {场景}，{环境影调} |
| 天候 | 阴霾/薄雾/细雨/扬尘/风雪 | 硝烟尘雾、阴霾天光 |
| 植被 | 焦黑枯木/荒草/弹坑间杂草（须符合环境） | 焦木剪影、荒草低伏 |
| 水体 | 弹坑积水需倒映天光与硝烟 | 积水倒影、水面浮尘 |
| 建筑 | 半塌民居/弹痕墙面/扭曲钢筋/锈蚀铁丝网 | 断墙残壁、扭曲钢筋 |
| 空气感 | 必须有硝烟尘雾空气透视，远处偏灰 | 远景灰蒙、硝烟空气透视 |
| 光照 | 漫射天光为主，火光/探照灯为戏剧光源 | 漫射天光、光锥穿尘 |
| 镜头感 | 长焦压缩、浅景深、镜头暗角、纪实颗粒 | telephoto compression、lens vignette、film grain、bokeh |
| 瑕疵感 | 弹坑/瓦砾堆/锈蚀/残破旗帜 | 战损痕迹、瓦砾散落 |

### 室外类型速查

| 类型 | 核心元素 | 氛围词 |
|---|---|---|
| 战壕防线 | 沙袋胸墙、交通壕、支撑木桩 | 压抑消耗、坚守等待 |
| 废墟街区 | 半塌楼房、瓦砾街面、断墙窗洞 | 目击现场、肃杀空旷 |
| 街垒关卡 | 拒马铁丝网、路障、检查哨 | 对峙封控、一触即发 |
| 断桥渡口 | 断裂桥面、浅滩、残船 | 撤离通道、生死一线 |
| 焦土原野 | 弹坑、焦木、地平线 | 孤绝苍茫、长焦压缩 |

## 五、主视图规范

### 视图定义

> 单画面主视图，从场景中最具代表性的角度拍摄，承载空间叙事与构图重心。

| 项目 | 约束 | 提示词 |
|---|---|---|
| 视角 | 战地记者自然观察视角，构图最能体现战场主体与纵深 | hero shot、representative angle |
| 视点高度 | 默认人眼平视高度，弹坑/战壕场景可低位 | eye level（默认）、low angle（战壕） |
| 构图 | 主体居中或符合三分法，前/中/后景层次清晰 | balanced composition |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 单画面（非拼图、非多视图、非分屏） |
| 人物 | **严禁出现任何人物、人影、人体轮廓、遗体** |
| 一致性 | 风格/材质/色调/光线统一 |
| 光线 | 单一光源逻辑，光影方向一致 |
| 画面比例 | 默认 16:9（或按调用方设定） |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 场景必须有「前中后景层次」 |
| R2 | 室外必须包含「硝烟尘雾空气透视」 |
| R3 | 场景图必须为「单画面主视图」，不得拼接多视图/分屏/网格 |
| R4 | 构图须能代表场景主体并展示前/中/后景层次 |
| R5 | 场景图中**严禁出现任何人物与遗体** |
| R6 | 必须包含实拍纪实关键词（war documentary photography / photojournalism / RAW photo） |
| R7 | 必须包含镜头光学特征（telephoto compression / lens vignette / film grain 至少一项） |
| R8 | 材质必须带有战损/做旧/烟熏痕迹，禁止崭新无瑕的"CG 感" |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 背景纯白/纯黑/无场景 |
| X2 | 奇观化战争场面（冲天火球/蘑菇云式夸张爆炸，除非剧情需要且克制呈现） |
| X3 | 场景无纵深/无层次 |
| X4 | 植被/天候与环境矛盾（如焦土上繁茂绿植） |
| X5 | 出现任何人物、人影、人体剪影、人体轮廓或遗体 |
| X6 | 画面被拼接成多视图/网格/分屏布局 |
| X7 | 3D 渲染/CG 动画/卡通/游戏引擎质感（禁用 3D render、CGI、Unreal Engine、Unity 等词） |
| X8 | 材质过于干净完美、无任何战损与做旧痕迹（避免"塑料感"） |
| X9 | 血腥残骸等过度血腥残忍的直接描绘；光照过于均匀平坦、无镜头光学特征 |
