# 道具图像生成 · 战争纪实约束手册

---

## 一、道具设计原则

1. **功能可读** — 军械/装具/载具用途一目了然，造型服务于战地功能
2. **质感极致** — 材质纹理必须清晰可辨（军规金属/帆布/皮革/朽木/镜片），做旧必须可信
3. **年代制式一致** — 所有道具必须符合剧情年代与阵营制式，禁止跨年代混搭元素
4. **尺度明确** — 通过参照物或标注暗示道具真实尺寸
5. **纯道具独立展示** — 画面中只能出现道具本身，严禁出现任何人物、手部、肢体，道具不可处于被持有/佩戴/握持状态，必须以静物陈列方式独立呈现；**武器道具须按剧情合理呈现、不美化暴力**

## 三、多角度设定图规范

### 视图定义

| 位置 | 视图 | 角度 | 要求 | 提示词 |
|---|---|---|---|---|
| 左上 | 正面图 | 正面 0° | 道具完整正面形态 | front view |
| 右上 | 侧面图 | 侧面 90° | 厚度/轮廓/结构清晰 | side view |
| 左下 | 背面图 | 背面 180° | 道具背部结构/装饰 | back view |
| 右下 | 细节特写 | 局部放大 | 材质纹理/做旧工艺细节 | detail closeup |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 同一画面四宫格（2×2），上下左右四视角 |
| 背景 | 纯净灰土色 #B7B1A4 |
| 光线 | 均匀柔光，无硬阴影 |
| 比例 | 每格道具占格内主体 70%+ |
| 投影 | 允许自然地面微投影 |
| 画面比例 | 建议 1:1 |

## 四、材质渲染约束

| 材质 | 渲染要求 | 提示词 |
|---|---|---|
| 军规金属 | 磷化哑光/磨砂黑、划痕锈蚀微可见、无镜面高光 | 磷化哑光金属、磨损划痕 |
| 帆布 | 纤维质感、磨损褪色、边缘起毛、褶皱自然 | 帆布纹理、磨损褪色 |

| 朽木 | 木纹裂痕、焦边发黑、潮气浸润 | 木纹裂痕、焦黑边缘 |
| 镜片玻璃 | 尘土覆膜、微裂克制、折射不夸张 | 镜片蒙尘、轻微划痕 |
| 橡胶 | 老化龟裂、哑光无光 | 橡胶老化、哑光质感 |

## 六、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须指定「纯净灰土色背景」 |
| R2 | 必须明确道具材质与做旧工艺（磨损/锈蚀/泥渍/烟熏） |
| R3 | 道具造型必须符合战争世界观与剧情年代制式 |
| R4 | 武器类道具必须声明「按剧情合理呈现、不美化暴力」 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 复杂场景背景 |
| X2 | 道具与人物同画面（本环节为纯道具图） |
| X3 | 出现任何人物形象，包括全身、半身、局部（手、手指、手臂等肢体） |
| X4 | 道具处于被持有、握持、佩戴、使用中的状态 |
| X5 | 出现暗示人物存在的元素（如手持痕迹、佩戴视角、使用姿态） |
| X6 | 崭新无做旧、镜面抛光的"展柜感"；美化暴力的构图与光效 |
