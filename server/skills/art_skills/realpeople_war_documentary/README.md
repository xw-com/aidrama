# 战争纪实风格说明

本风格专为"战争纪实"题材打造，所有美术提示词、规范和生成内容均严格限定于：

- **战地纪实世界观**：以战场与战时后方为背景，涵盖战壕、废墟街区、野战医院、前线指挥部、焦土原野等，杜绝干净明亮的和平都市感。
- **真人写实**：所有角色、场景、道具均以真人写实摄影为标准，强调硝烟污渍、皮肤尘汗、军械做旧材质等极致细节与真实质感。
- **战地记者视角**：以新闻纪实摄影为美学母题，长焦压缩、纪实颗粒、低饱和战地色，画面克制而沉重，强调"我在现场"的目击感。
- **克制而残酷的战争氛围**：以纪实与戏剧张力表达战争的沉重与人性余温，不依赖血腥残忍的直接描绘。

## 适用范围

- 战争纪实题材的AI美术生成（角色、场景、道具、分镜等）
- 需要极致写实、战地纪实质感、低饱和沉重氛围的视觉创作

## 严禁内容

- 卡通、动漫、插画、二次元风格
- 血腥伤口细节、断肢、残躯等过度血腥残忍的直接描绘
- 美化战争、渲染暴力快感的视觉表达
- 高饱和荧光色、霓虹色、时尚大片光
- 暗示性、暴露、透视等不适宜内容

## 风格体验

在本风格下，您将体验到：

- 角色面容带硝烟污渍与尘汗，气质疲惫坚毅，军服作训服与装具做旧真实可信
- 战场空间层次丰富，硝烟尘雾形成天然空气透视，材质纹理超清晰
- 军械、装具、载具、信物等道具均按战地逻辑做旧，年代制式严谨，工艺可信
- 分镜与视频均以战地记者纪实视角为基础，长焦压缩与有限手持呼吸感并存，克制而沉重

---

本风格仅适用于"战争纪实"相关项目。战争与冲突题材以纪实与戏剧张力为主，严禁过度血腥残忍的直接描绘，严禁美化战争。如需其他风格（如都市、古风、动漫等），请勿使用本套提示词。
