# 国风二次元厚涂3D 场景图生成 · 约束手册

---

## 一、场景美学原则

1. **空间叙事** — 场景承载东方意境与叙事功能，以国风世界观为内核，绝非纯背景板；宫阙、江湖、仙山、宅院皆有情绪
2. **层次纵深** — 强制前/中/后景三层递进结构，用厚涂的虚实笔触与空气透视营造 3D 般的空间纵深，绝对杜绝扁平画面
3. **光影塑形** — 明确主光源方向，体积光/斜射光/轮廓光塑造立体氛围；亮部通透、暗部深沉透气，光影是厚涂3D感的灵魂
4. **质感至上** — 木石/绸缎/金属/水面的厚涂质感须饱满可辨：油画笔触塑形、多层罩染色彩、材质高光点睛
5. **国风意境** — 留白构图、烟霭氤氲、飞花落雪等东方氛围元素按需融入，场景须有"画意"而非元素堆砌

## 六、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 所有场景必须具备前/中/后景三层递进层次，杜绝扁平画面 |
| R2 | 室外场景必须包含空气透视，近实远虚 |
| R3 | 必须明确主光源方向，光影塑造立体体积 |
| R4 | 必须包含厚涂质感锚词（厚涂上色/油画质感笔触/立体体积光影至少两项） |
| R5 | 场景图中严禁出现任何人物、人影、人体剪影 |
| R6 | 国风元素须符合中式形制逻辑，杜绝元素堆砌 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 真3D CG渲染感、赛璐璐平涂、外露线稿、扁平插画 |
| X2 | 写实摄影/照片质感 |
| X3 | 背景纯白/纯黑/无有效空间结构 |
| X4 | 荧光色、脏色、高饱和杂乱撞色 |
| X5 | 西式建筑/现代都市/赛博元素混入国风场景 |
| X6 | 出现任何人物、人影、生物主体 |
| X7 | 光照无方向逻辑的平光、死黑一片的暗部 |
| X8 | 图中出现任何文字、水印、标注 |
