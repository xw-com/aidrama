# 国风二次元厚涂3D 道具图像生成 · 约束手册

---

## 一、核心设计原则

1. **功能可读** — 道具用途一目了然，造型100%服务于核心功能，无意义元素零容忍
2. **质感极致** — 厚涂塑形材质：金属/玉石/木/瓷/丝绢/纸的质感须以油画笔触与多层罩染塑造，高光与反光点睛，立体体积感强
3. **国风形制** — 造型以东方古典形制为核心骨架（历朝形制参考），纹样符合传统审美逻辑，杜绝西式/现代元素混入
4. **尺度明确** — 比例零畸变，通过结构比例精准暗示道具真实尺寸
5. **纯道具独立展示** — 画面中只能出现道具本身，严禁出现任何人物、手部、肢体，道具不可处于被持有/佩戴/使用状态，必须以静物陈列方式独立呈现

## 三、四宫格多角度设定图规范

### 视图定义

| 位置 | 视图 | 核心要求 |
|---|---|---|
| 左上 | 正面图 | 道具完整正面形态，结构无透视畸变，核心结构、装饰完整呈现 |
| 右上 | 侧面图 | 道具厚度、轮廓、侧部装饰清晰，比例精准 |
| 左下 | 背面图 | 背部结构、装饰、细节完整呈现，无遗漏 |
| 右下 | 细节特写 | 材质纹理、工艺细节极致清晰，厚涂质感拉满 |

### 画面规范

| 项目 | 强制约束 |
|---|---|
| 布局 | 同一画面四宫格（2×2），四视角严格对应视图定义，无错位、无裁切、无比例失衡 |
| 背景 | 月白纯色背景，无任何多余纹理、图案、场景元素 |
| 光线 | 柔和立体光照，主光源方向统一，无硬阴影，保留金属/玉石高光的自然过渡，无局部过曝 |
| 比例 | 每格道具占格内主体 70%+，居中对齐，四格内道具比例完全统一 |
| 画幅 | 1:1 正方形画幅 |
| 渲染 | 厚涂质感统一：油画笔触塑形、立体体积光影、细节精致 |

## 五、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须指定「月白纯色背景」，禁止任何多余背景元素 |
| R2 | 必须明确道具材质与工艺，厚涂质感塑造到位 |
| R3 | 道具造型必须以东方古典形制为核心骨架 |
| R4 | 必须使用四宫格（2×2）多角度呈现，比例精准，无透视畸变 |
| R5 | 必须包含厚涂质感锚词（厚涂上色/油画质感笔触/立体体积光影至少两项） |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 复杂场景背景、带环境的场景化画面 |
| X2 | 道具与人物/手部/肢体同画面 |
| X3 | 道具处于被持有、握持、佩戴、使用中的状态 |
| X4 | 真3D CG渲染感、赛璐璐平涂、扁平涂色、写实照片质感 |
| X5 | 西式/现代/赛博元素混入道具设计 |
| X6 | 过度曝光的光效、死黑阴影 |
| X7 | 图中出现任何文字、标注、刻度线、水印 |
