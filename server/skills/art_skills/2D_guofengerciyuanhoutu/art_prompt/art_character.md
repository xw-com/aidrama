# 国风二次元厚涂3D 人物基础形象生成 · 约束手册

---

## 一、基础形象原则

1. **厚涂即质感** — 半写实厚涂上色为角色核心质感：无外露线稿、色块塑形、油画感笔触、立体体积光影
2. **韩漫即审美** — 五官与比例走韩漫系流行审美（精致立体、小脸、时尚头身比），由角色描述自然推导
3. **底模即基础** — 基础素色汉服打底 + 素颜，后续服化均为叠加层
4. **四视图一致** — 面容/体型/发型/基础服装跨视图高度统一
5. **国风即气质** — 无妆状态仍需体现角色气质（典雅/温婉/英气/清冷/娇媚）

---

## 二、面容约束

> 不固定五官特征参数，由角色描述（性别/年龄/性格/气质）驱动 AI 自由生成五官，保证人物间外观差异化。

### 通用要求

| 项目 | 约束 |
|---|---|
| 五官 | 由角色描述自然推导，不预设脸型/眼型/眉型/鼻型/唇型 |
| 风格底色 | 韩漫系精致立体五官：小脸轮廓、深邃眉眼、高挺鼻梁、立体骨相；厚涂明暗塑造体积 |
| 气质 | 必须从角色描述提炼整体气质关键词（如典雅温婉/英气凛然/清冷疏离/娇俏灵动），并写入提示词 |
| 表情 | 中性微表情，符合角色气质 |

## 六、基础服装约束

> 基础服装由角色描述（身份/性别/场景）决定其最自然的常规着装，作为该角色「日常默认态」；正式服饰/特殊衍生在服化衍生环节叠加。**禁止内衣打底**。

### 着装选择原则

| 角色身份 | 默认着装方向 |
|---|---|
| 帝后/贵族 | 素色华贵汉服（广袖深衣/齐胸襦裙） |
| 侠客/武者 | 素色劲装短打/交领窄袖 |
| 书生/文官 | 素色圆领袍/直裾长衫 |
| 仙门/修士 | 素色广袖仙裙/道袍 |
| 民间/市井 | 素色襦裙/短褐布衣 |
| 角色描述未明确 | 素色交领汉服（女：襦裙/男：长袍） |

### 着装统一规则

- 基础期为**素色汉服**（单色或同色系渐变），无花纹装饰、无繁复配饰，便于后续服化叠加
- 服装厚涂质感：织物有体积褶皱与明暗转折，绸缎类面料须有柔和反光
- 四视图服装款式完全一致
- 严禁内衣/暴露/性化打底
