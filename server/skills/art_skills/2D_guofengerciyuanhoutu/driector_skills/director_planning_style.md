# 国风二次元厚涂3D约束 · 风格规划技法参考

---

## 一、色调体系与画面基调

- **色调基底** — 全片以中国传统色为基底：月白（C1）、朱砂红（C3）、黛蓝（C4）、鎏金（C5）、墨玄（C6），辅以暖瓷肤（C2）、胭脂粉（C7）、烟青（C8）、藤黄（C9）、黛紫灰（C10）；基底色饱和度中高，厚涂上色须色彩饱满有层次——亮部通透、暗部深沉透气（暗部混入烟青/黛紫灰环境色，禁止死黑）
- **情绪色盘驱动** — 六套情绪色盘对应不同叙事段落，色盘切换应与故事弧线完全同步：
  1. 宫廷华贵（朱砂红+鎏金+墨玄）
  2. 江湖侠气（墨玄+赭石+藤黄灯火）
  3. 仙境空灵（月白+烟青+青碧）
  4. 温婉闺情（胭脂粉+暖瓷肤+藤黄暖光）
  5. 肃杀对抗（黛蓝+墨玄，低饱和）
  6. 夜话清幽（黛蓝+月白+藤黄暖光点点）
- **冷暖叙事对比** — 暖色（朱砂红、藤黄、鎏金、胭脂）作为情感升温与喜庆段落的视觉信号；冷色（黛蓝、墨玄、烟青）用于肃杀、忧郁、清幽段落；冷暖切换点应落在叙事转折处，形成视觉锚点
- **色盘先行原则** — 段落规划需先绑定情绪场景，再确定主色+辅色+点缀色与光影方案，避免"剧情对了但情绪不对色"
- **禁用色域** — 荧光色、高饱和杂乱撞色、脏色污渍感、无国风锚点的现代都市跳色均与本风格不兼容

## 二、光影方案体系

- **光影即叙事** — 7套光影方案对应不同情绪段落，导演规划阶段应在段落层面确定基调方向，而非逐镜无逻辑指定
- **厚涂3D光影核心特征** — 明确主光源方向、厚涂明暗交界塑造体积、轮廓光勾边、亮暗色温对比；体积光/斜射光/烛光是国风氛围的核心手段，景深虚化强化空间纵深；所有光影须呈现手绘厚涂质感（油画笔触的光色过渡），禁止 CG 渲染感的光泽

| 光影方案 | 方案名 | 色调倾向 | 适用情绪与场景 |
|---|---|---|---|
| A | 鎏金华彩 | 朱砂红基底 + 鎏金高光 + 藤黄暖光 + 墨玄压重 | 宫廷华贵、庄严盛典、喜庆盛大、权力叙事 |
| B | 烟青意境 | 月白基底 + 烟青漫射 + 青碧点缀 | 仙境空灵、山水意境、诗意悠远、空镜叙事 |
| C | 烛影温婉 | 胭脂暖调 + 藤黄烛光 + 柔和阴影 | 闺阁温婉、柔情缱绻、日常温馨、私密叙事 |
| D | 冷月肃杀 | 墨玄基底 + 黛蓝硬光 + 高对比明暗切割 | 武侠对抗、危机压迫、冲突肃杀段落 |
| E | 窗纱漫射 | 月白底 + 自然侧光 + 环境反光补光 | 室内日间、日常起居、幽静雅致、生活化叙事 |
| F | 夜话灯火 | 黛蓝夜色基底 + 灯笼暖光点缀 + 月光清辉 | 夜市烟火、夜话独处、月夜抒情段落 |
| G | 残阳苍茫 | 赭石 + 残红逆光 + 长影拉出 | 塞外苍凉、离别悲壮、黄昏抒情段落 |

- **冷暖光分配** — 暖光（藤黄/鎏金/烛光）适用于华贵、温婉、喜庆段落；冷光（黛蓝/月光/烟青）适用于肃杀、忧郁、清幽段落；烛火/灯笼的亮灭可作为强叙事节点的视觉信号
- **氛围方向映射** — 每场戏的氛围方向应能映射到上述光影方案（A-G）之一，确保全片厚涂光影逻辑统一

## 三、质感方向

- **厚涂手绘质感为全片锚点** — 半写实厚涂上色、油画质感笔触、无外露线稿、色块塑形、多层罩染；一切画面不得出现 CG 渲染感、赛璐璐平涂、外露线稿
- **立体体积塑形** — 人物面部厚涂明暗交界清晰（韩漫系立体五官）、服饰褶皱有体积转折、场景建筑有受背光面；全片呈现"绘画出的 3D 体积感"
- **材质厚涂要点** — 绸缎类面料柔和反光、金属/玉石高光点睛、木石材质笔触塑形、水面湿润倒影；材质纹理须饱满可辨，背景可做厚涂虚化
- **岁月质感** — 材质不可过于干净完美：木面有包浆、石阶有磨损、绸缎有自然垂褶、灯笼纸面有纹理，拒绝"塑料感"与"样板间式"画面
- **氛围质感** — 烟霭、光束、飞花、落雪等氛围元素以厚涂虚实笔触融入，服务东方意境

## 四、国风场景空间元素

- **框架式构图元素** — 月洞门、屏风、窗棂、帘幕、廊柱；天然的框架式构图道具，制造"虚实相生"的层次感与空间纵深，可用于叙事中的窥视、隔离、身份隐喻
- **留白意境元素** — 庭院花树、烟雨、竹林、云海、飞雪；留白构图的天然载体，景即情：满庭花开 = 释然、独坐雨中 = 孤寂、落叶纷飞 = 离愁
- **光源载体元素** — 烛火/灯笼/窗光/月光；烛光 = 暖/私密（方案C）、月光 = 冷/清幽（方案F/D）、窗光 = 日常/静谧（方案E）；光源的厚涂光色过渡与明暗层次是画面质感核心
- **建筑标志性元素** — 飞檐翘角、雕梁画栋、朱红宫墙、青瓦白墙、汉白玉阶、酒旗灯笼；建筑须有清晰的受背光面与纹理细节，呈现厚涂体积感
- **市井叙事核心元素** — 青石长街、酒楼茶肆、摊贩云集、灯笼成排；市井烟火段落的核心空间载体，须体现街巷纵深与人群层次
- **段落过渡规则** — 本风格有丰富的场景资产（不同时段/天候/季节变体），段落衔接建议用场景空镜做情绪缓冲，不要硬切；适配空镜：宫墙角楼/云海仙山/街市灯火/庭院花树
- **叙事优先级规则** — 转折点用视觉而非台词，优先使用画面手段（光影突变、景别跳切、虚实空镜隐喻、烛火明灭）而非依赖对白解释

## 五、乐器与环境音

### 乐器选择

- **箫** — 凄凉、孤寂、悲戚段落的核心乐器，最能表现冷清哀婉
- **古琴** — 开场定调 / 平稳段落，体现山水意境与文人风骨
- **琵琶** — 紧张、急促段落的点缀，武侠肃杀场景适用，轮指制造张力
- **二胡** — 情感激荡、悲痛、思念段落，拉弦的哭腔感适合情绪爆发
- **古筝** — 宫廷华贵/节庆段落的氛围乐器，华丽优雅
- **笛** — 江湖游历、市井烟火的轻快点缀
- **唢呐** — 情感波动剧烈段落（大悲大喜、命运转折、高潮），慎用但一用即核弹
- 弦乐铺底可增加电影感但不宜喧宾夺主，可辅以轻微国风电子氛围垫音，禁止脱离国风内核的强电子音效

### 乐器组合策略

| 情绪阶段 | 乐器组合 | 适配说明 |
|---|---|---|
| 平稳/开场/收尾 | 古琴独奏 或 古琴 + 箫 | 山水/庭院开场、全片收尾 |
| 空灵意境 | 箫 + 古琴 + 笛 | 仙境游历、禅意段落、空镜叙事 |
| 宫廷华贵/喜庆 | 古筝 + 编钟 + 弦乐 | 宫廷叙事、节庆盛典、盛大仪式 |
| 悲戚渐浓 | 箫 + 二胡 | 离别、思念、悲戚情绪递进段落 |
| 情绪爆发/命运转折 | 唢呐独奏 或 唢呐 + 二胡 + 鼓 | 生死离别、命运转折、全片高潮 |
| 武侠肃杀/紧张 | 琵琶轮指 + 弦乐衬底 + 战鼓 | 对抗、追杀博弈、紧张追击段落 |
| 温婉日常 | 古筝 + 笛 + 轻弦乐 | 居家日常、闺阁叙事、温馨生活化段落 |
| 市井烟火 | 笛 + 快板节奏 + 环境人声 | 街市群像、市井烟火段落 |

### 环境音

- **自然环境音** — 蝉鸣虫唱 / 溪水潺潺 / 风过竹林 / 夜雨滴檐 / 衣料摩擦 / 环佩轻响 / 鸟鸣啁啾 / 落花簌簌 / 烛火噼啪
- **市井环境音** — 街市叫卖 / 酒楼喧闹 / 马蹄蹄声 / 更鼓梆子 / 茶沸声 / 刀剑出鞘
- **执行标准** — 每场戏标注 1-2 个核心环境音，帮助后续音效设计；环境音层次越匹配叙事，沉浸感越强
