# 分镜表国风二次元厚涂3D约束 · 技法参考

---

## 一、分镜表定位
分镜表是导演将剧本转化为镜头语言的核心工具。以下提供国风二次元厚涂3D风格在分镜表层面的约束规范，**核心准则为「韩漫审美塑人、国风意境塑境、厚涂光影塑形」，全片保持手绘厚涂质感与立体体积光影，禁止 CG 渲染感与扁平二次元**。

---

## 二、核心准则（强制遵守）

1. **风格统一铁律**：所有镜头画面统一锚定「国风二次元厚涂3D」——半写实厚涂上色、油画质感笔触、立体体积光影；国风元素（传统色、东方形制、古典气韵）占比≥70%，杜绝跑偏
2. **气质定位**：韩漫系审美保证人物高级感与流行度，国风内核保证题材厚度与东方意境，二者融合不可偏废——禁止出现纯日漫扁平脸或纯写实人像
3. **节奏统一规则**：全片默认保持东方典雅的叙事节奏，仅强叙事冲突段落可临时突破，且必须标注明确的时长与触发逻辑

---

## 三、光影与氛围

- **同场戏光影统一** — 一场戏内不应出现两种以上光影方案，除非有明确的叙事转折（如日转夜、烛火明灭、室内外切换）；同场戏内主光源方向、色温、明暗对比度必须统一，禁止无叙事逻辑的杂色光乱入
- **情绪色盘绑定** — 每场戏至少绑定 1 个情绪场景：宫廷华贵/江湖侠气/仙境空灵/温婉闺情/肃杀对抗/夜话清幽/市井烟火/悲壮苍凉，并在镜头组内保持主色+辅色连续性；配色参考传统色逻辑：朱砂配鎏金、黛蓝配月白、胭脂点睛、墨玄压重
- **光影描述规范** — 描述光影时须明确：主光源方向与色温、明暗对比强度、轮廓光/体积光的有无；人物面部须有厚涂明暗塑形（半侧光/侧逆光优先，禁止无体积的平光）
- **冷暖色调与叙事阶段匹配** — 肃杀/忧郁/压抑段落使用冷色光（黛蓝+墨玄+烟青），禁用朱砂红/鎏金等高饱和暖色；暖色调仅在华贵、温婉、喜庆、心动段落使用；烛火明灭、光影骤变仅可用于强叙事冲突点，且必须标注时长与触发逻辑
- **光影转场是高级手段** — 转场规范，必须标注光影变化点：
  - 窗纱漫射渐变到月光清辉 = 日转夜的时间流逝
  - 灯笼暖光渐变到夜色冷调 = 热闹到孤寂的情绪切换
  - 宫墙暖阳渐变到大殿阴影 = 室内外空间过渡
  所有光影转场必须保持舒缓节奏，与国风典雅气质匹配

---

## 四、环境动态

- **环境动态增加画面呼吸感** — 每 3-4 个镜头至少安排一个有环境动态的镜头，避免画面"死"掉；动态元素与厚涂氛围质感结合：
  - 合规元素：花瓣飘落、柳絮飞舞、烛火摇曳、纱帐飘动、竹林摇曳、灯笼光影晃动、水面涟漪、烟雾缭绕、落叶纷飞、飞雪飘零、衣袂飘举
  - 动态须有厚涂虚实笔触感（拖影、虚化边缘），强化画面绘画性
- **环境动态与情绪匹配** — 花瓣/柳絮 = 温情与心动、落叶/飞雪 = 离愁与孤寂、烛火摇曳 = 私密与不安、风云突变 = 危机将至；动态元素是情绪的外化，不可无逻辑滥用
- **国风元素优先** — 环境动态核心必须选用国风世界观内的元素，禁止出现现代物件（汽车、电线、广告牌）、西式元素、赛博特效等违和内容

---

## 五、动作与仪态节奏

- **动作核心节奏：缓稳内敛** — 所有人物动作默认从容优雅，起身、转身、抬手应标注"缓慢"/"从容"；**仅在打斗、危机等强叙事冲突段落可标注快速动作，且快速动作时长不得超过单个镜头时长的30%**
- **服饰动态** — 国风服饰的飘动是天然的动态资产：广袖、裙摆、披帛、发带的飘动须在画面描述中体现，增加画面的"活"感；丝绸类面料须标注柔和反光与体积褶皱
- **仪态约束** — 人物举止必须符合东方古典气质：行走稳缓、举手投足含蓄内敛、不出现现代肢体语言（耸肩、摊手、抖腿、大幅度挥手）；女性仪态可柔美婉约或英气飒爽，男性仪态可儒雅端方或豪迈不羁，但均须守住古典气韵
- **武打动作** — 武打段落讲究招式舒展、刀光剑影的凌厉美感：可标注剑光拖影、衣袂翻飞、腾挪转身等动作；武打仍须有国风武术的招式逻辑，禁止无章法的乱斗
- **微表情利用** — 厚涂画风的特长是面部体积与微表情刻画：特写镜头须标注眼神、唇角、眉峰的微表情变化，用面部细节承担叙事

---

## 六、运镜与转场禁忌

- **禁用快速运镜** — 甩镜、手持晃动、高速穿越、频闪跳切、第一人称快速跑动运镜，均与国风典雅气质冲突，全片默认禁用；仅在强叙事冲突（爆炸、生死打斗）的单个镜头内可使用短时快速运镜，且时长不得超过该镜头总时长的20%
- **禁用花式转场** — 划屏、旋转、百叶窗、闪白硬切、无叙事逻辑的故障艺术转场、缩放弹跳转场，均与本风格不兼容；仅可使用符合国风气质的转场：光影渐变转场、元素匹配转场（飞檐匹配飞檐、烛火匹配灯笼）、空间纵深推拉转场、慢叠化转场
- **善用景深与纵深运镜** — 厚涂3D风格的空间纵深感是优势：可利用前中后景做缓慢的推拉/环绕运镜，配合景深虚化强化立体空间感；推荐手法：
  - 从庭院月洞门缓慢前推，纵深穿过框景呈现内景
  - 围绕人物做缓慢环绕，背景灯火/宫墙形成流动纵深
  - 运镜速度默认≤0.5m/s，全程服务于叙事与情绪表达
