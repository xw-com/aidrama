## 一、风格基因

| 维度 | 定义 |
|---|---|
| **一级风格** | 国风二次元厚涂3D（Guofeng Thick-Paint Anime with 3D Volume） |
| **二级风格** | 韩漫人物美学 · 半写实厚涂上色 · 3D 体积光影（绘画出的立体感，非 CG 渲染） |
| **情感基调** | 东方古韵、韩漫时尚审美、电影质感、厚重大气 |
| **质感锚词** | 厚涂上色、油画质感笔触、立体体积光影、韩漫精致五官 |

### 风格融合公式

> **韩漫的脸 + 国风的骨 + 厚涂的皮 + 3D 的光**
> - 人物：韩漫系流行审美（精致立体五官、小脸、时尚比例）
> - 题材：国风世界观（汉服、古建、传统色、东方意境）
> - 画法：半写实厚涂（无外露线稿、色块塑形、多层罩染、油画笔触）
> - 光影：3D 般的体积光影（强明暗对比、轮廓光、空间纵深）

### 「厚涂3D」核心定义

- **厚涂**：色彩层层堆叠罩染，笔触饱满有油画感，线稿被色块吞没，明暗过渡柔和丰富
- **3D 感**：画面呈现强烈的立体体积与空间纵深——面部有立体明暗交界、服饰褶皱有体积转折、场景有前中后景纵深，观感接近 3D 渲染的厚度，但笔触与质感仍是手绘厚涂
- **红线**：禁止出现真 3D CG 渲染词（3D render、PBR、UE5、游戏引擎、建模贴图），"3D"仅体现为体积感与光影厚度

### 用色规则

- 国风配色参照传统色逻辑（朱砂配鎏金、黛蓝配月白、胭脂点睛），杜绝荧光色与无逻辑撞色
- 肤色统一走韩漫审美：白皙透亮、血色健康，禁止灰脏肤色与过度曝光

## 三、全局质感与光影规则

| 维度 | 规则 |
|---|---|
| 笔触 | 油画感厚涂笔触，色块边缘虚实相间；禁止外露线稿、禁止赛璐璐硬边色块、禁止喷枪光污染 |
| 体积 | 所有主体必须有立体明暗结构（受光面/明暗交界/反光/环境光），呈现 2.5D 以上的体积厚度 |
| 光影 | 电影级光照逻辑：明确主光源方向，轮廓光/边缘光勾体积，高光集中点睛；禁止无光源逻辑的平光 |
| 纵深 | 场景强制前/中/后景层次，空气透视近实远虚，可辅以景深虚化强化 3D 空间感 |
| 细节 | 服饰织物质感、发丝体积、金属/玉石高光须精画；细节密度服务于主体，背景可做厚涂虚化 |
| 氛围 | 东方意境优先：留白、烟霭、光影斜入、飞花落雪等氛围元素按需融入 |
