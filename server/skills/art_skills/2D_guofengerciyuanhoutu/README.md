# 国风二次元厚涂3D 风格说明

本风格专为"国风二次元厚涂3D"题材打造——**韩漫人物美学 × 国风题材 × 厚涂3D体积光影**的融合风格，所有美术提示词、规范和生成内容均严格限定于：

- **韩漫人物美学**：韩式 webtoon 流行审美的角色塑造——精致立体五官、小脸深邃眉眼、高挺鼻梁、清透健康肤色，女性 7-7.5 头身、男性 8-8.5 头身的时尚比例
- **厚涂上色**：半写实厚涂技法——无外露线稿、色块塑形、多层罩染叠加、油画般的厚重笔触与饱满色彩层次
- **3D 体积感**：用厚涂画出不输 3D 的立体体积——面部立体明暗、服饰褶皱体积、空间纵深与电影级光影；本质是"绘画出的立体感（2.5D）"，不是 3D 建模渲染
- **国风内核**：古风题材（仙侠/宫廷/江湖/宅门）、汉服形制、中国传统色、中式建筑与纹样、东方意境留白
- **电影质感**：电影级构图与光影层次、氛围感与叙事张力

## 适用范围

- 国风二次元厚涂题材的 AI 美术生成（角色、场景、道具、分镜、视频等）
