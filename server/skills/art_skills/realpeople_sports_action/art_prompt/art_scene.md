# 场景图生成 · 体育运动写实约束手册

---

## 一、场景美学原则

1. **空间叙事** — 场景承载竞技情绪与叙事功能，不是纯背景板
2. **层次纵深** — 所有场景必须具备前/中/后景，杜绝扁平
3. **质感至上** — 跑道/草坪/木地板/金属器械/网格等材质纹理必须超清晰
4. **实拍为锚** — 一切画面以真实体育摄影为标准，拒绝 3D 渲染/CG 动画质感；追求镜头光学特征（高速快门、景深虚化、追焦动感、镜头暗角）与物理光照（赛场顶光、自然光漫射、体积光）

## 三、室内场景

### 空间规范

| 维度 | 约束 | 提示词 |
|---|---|---|
| 风格 | 体育馆/健身房/训练馆/室内赛场，现代功能建筑 | 现代{风格}风格体育场馆 |
| 材质 | 木地板/金属器械架/网格围栏/塑胶地面为主 | 木地板、金属器械架、塑胶地面 |
| 色调 | 中性竞技色 + 跑道红/草坪绿点缀 | 中性色调、跑道红点缀、竞技色 |
| 纵深 | 前/中/后景层次 | 前景{元素}、中景{元素}、后景{元素} |
| 质感 | 木地板纹/金属拉丝/网格纹理可辨 | 纹理清晰、质感写实 |
| 光照 | 赛场顶光为主（高强度均匀照明），可见光束粒子、器械阴影硬朗 | 赛场顶光、高强度照明、光束穿顶 |
| 镜头感 | 高速快门定格、浅景深虚化前后景、追焦动感、镜头暗角 | high shutter speed、shallow depth of field、motion panning、lens vignette |
| 瑕疵感 | 地面有摩擦痕迹、器械有使用磨损、垫子有自然褶皱 | 使用痕迹、自然磨损、垫子自然褶皱 |

### 室内类型速查

| 类型 | 核心元素 | 氛围词 |
|---|---|---|
| 体育馆 | 木地板、看台、顶光、标线 | 竞技氛围、开阔空间 |
| 健身房 | 器械架、杠铃、镜墙、地垫 | 力量感、专注训练 |
| 室内训练馆 | 垫子、网格围栏、标线、器械 | 功能务实、训练日常 |
| 室内游泳池 | 泳道、水面、跳台、看台 | 水光反射、清澈空间 |
| 室内田径馆 | 跑道、起跑器、标线、看台 | 蓄势待发、竞技节奏 |

## 五、主视图规范

### 视图定义

> 单画面主视图，从场景中最具代表性的角度拍摄，承载竞技空间叙事与构图重心。

| 项目 | 约束 | 提示词 |
|---|---|---|
| 视角 | 自然观察视角，构图最能体现场景主体与纵深 | hero shot、representative angle |
| 视点高度 | 默认人眼平视高度，特殊场景可俯/仰 | eye level（默认） |
| 构图 | 主体居中或符合三分法，前/中/后景层次清晰 | balanced composition |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 单画面（非拼图、非多视图、非分屏） |
| 人物 | **严禁出现任何人物、人影、人体轮廓** |
| 一致性 | 风格/材质/色调/光线统一 |
| 光线 | 单一光源逻辑，光影方向一致 |
| 画面比例 | 默认 16:9（或按调用方设定） |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 场景必须有「前中后景层次」 |
| R2 | 室外必须包含「空气透视」 |
| R3 | 场景图必须为「单画面主视图」，不得拼接多视图/分屏/网格 |
| R4 | 构图须能代表场景主体并展示前/中/后景层次 |
| R5 | 场景图中**严禁出现任何人物** |
| R6 | 必须包含实拍摄影关键词（real photography / photorealistic / RAW photo） |
| R7 | 必须包含镜头光学特征（high shutter speed / shallow depth of field / motion panning / bokeh 至少一项） |
| R8 | 材质必须带有自然磨损/使用痕迹，禁止全新无瑕的"CG 感" |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 背景纯白/纯黑/无场景 |
| X2 | 极端天候（暴风雨/雷电/暴雪，除非剧情需要） |
| X3 | 场景无纵深/无层次 |
| X4 | 植被/天候与季节矛盾 |
| X5 | 出现任何人物、人影、人体剪影或人体轮廓 |
| X6 | 画面被拼接成多视图/网格/分屏布局 |
| X7 | 3D 渲染/CG 动画/卡通/游戏引擎质感（禁用 3D render、CGI、Unreal Engine、Unity 等词） |
| X8 | 材质过于干净完美、无任何使用痕迹与岁月感（避免"塑料感"） |
| X9 | 光照过于均匀平坦、无景深虚化、无镜头光学特征 |
