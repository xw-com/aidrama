# 人物基础形象生成 · 体育运动写实约束手册

---

## 一、基础形象原则

1. **体格即灵魂** — 肌肉张力与运动体态是角色唯一锚点，肌理级精细渲染
2. **角色为本** — 基础运动着装由角色描述（项目/位置/性别/场景）决定其常规装备；后续特定服化为叠加层
3. **四视图一致** — 面容/体型/发型/基础服装跨视图高度统一
4. **力量真实** — 无妆状态仍需体现运动员气质（爆发/耐力/专注/坚韧）
5. **实拍摄影** — 以真实体育摄影为锚点，保留皮肤真实质感（毛孔/汗珠/微小瑕疵）

---

## 二、面容约束

> 不再固定五官特征参数，由角色描述（性别/年龄/项目/气质）驱动 AI 自由生成五官，保证运动员间外观差异化。

### 通用要求

| 项目 | 约束 |
|---|---|
| 五官 | 由角色描述自然推导，不预设脸型/眼型/眉型/鼻型/唇型 |
| 风格底色 | 真人写实摄影、肌理级精细渲染、写实材质、赛场自然光影 |
| 气质 | 必须从角色描述提炼整体气质关键词（如爆发/耐力/专注/坚韧），并写入提示词 |
| 表情 | 中性微表情，符合运动员气质，可带专注/蓄势感 |

## 六、基础服装约束

> 基础服装由角色描述（项目/位置/性别/场景）决定其最自然的常规运动装备，作为该角色「训练默认态」；正式比赛服/特殊衍生在服化衍生环节叠加。**禁止内衣打底**。

### 着装选择原则

| 角色项目 | 默认着装方向 |
|---|---|
| 田径 | 田径训练服（背心+短裤/紧身运动服） |
| 球类（足/篮/排） | 球队训练服（球衣+运动短裤） |
| 健身/力量 | 训练背心+运动长裤/压缩裤 |
| 游泳 | 运动训练外套+泳装（非比赛态外搭） |
| 竞技体操 | 体操训练服（紧身体操服） |
| 户外/耐力 | 功能运动服（速干衣+运动裤） |
| 角色描述未明确 | 运动训练服、中性竞技色调 |

### 着装统一规则

- 服装风格须与体育写实摄影美学一致（功能面料、写实材质）
- 颜色中性竞技色，无复杂花纹/装饰，便于后续衍生叠加
- 四视图服装款式完全一致
- 基础服装是「训练默认态」，焦点仍在体格与肌肉张力
- 严禁内衣/暴露/性化打底

## 八、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须为「运动状态」|
| R2 | 必须根据角色描述声明合适的常规运动装备作为基础服装（如田径→训练服、球类→球队训练服、健身→训练背心+运动裤）；禁止内衣打底 |
| R3 | 必须声明「无发饰、无配饰」 |
| R4 | 必须指定「纯净中性灰背景」 |
| R5 | 必须指定「四视图一致性」 |
| R6 | 全身立像必须从头顶到脚底完整展示，严禁裁切 |
| R7 | 必须声明角色身高并通过头身比换算约束全身比例 |
| R8 | 人像特写必须从头顶到锁骨完整展示，严禁裁切头顶 |
| R9 | 皮肤必须保留真实质感，不可过度磨皮；肌肉张力与线条必须可辨 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 内衣/暴露/性化打底；与角色描述明显不符的着装；过度复杂花纹/装饰干扰后续服化叠加 |
| X2 | 正顶硬光/正底光/彩色光 |
| X3 | 过度美白/过度磨皮至无质感 |
| X4 | 复杂场景背景（必须纯灰底） |
| X5 | 夸张表情/非运动动态姿势 |
| X6 | 全身立像裁切头顶或脚底，必须从头到脚完整入画 |
| X7 | 人像特写裁切头顶，必须从头顶到锁骨完整入画 |
| X8 | 忽略身高和头身比约束；忽略肌肉张力与运动体格约束 |
