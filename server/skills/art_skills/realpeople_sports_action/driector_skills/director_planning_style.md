# 体育运动风格约束 · 体育运动写实 · 技法参考

---

## 一、色调体系与画面基调

- **色调基底** — 全片以赛场灰（C1）、健康肤（C2）、器械银（C8）为基底色，整体色温中性偏冷（5000-5600K），饱和度中（45-65%），呈现硬朗真实的竞技赛场感
- **冷暖叙事对比** — 暖色（跑道红 C5、汗珠高光 C7）作为爆发/胜利/情感升温的视觉信号，冷色用于低谷/疲惫/失误等段落。冷暖切换应与竞技情绪弧线同步
- **冷暖分配策略** — 训练与蓄势段落以中性/冷调为主，冲刺与夺冠段落释放暖色；避免全程高暖导致情绪层次塌陷
- **色盘先行原则** — 段落规划先绑定情绪场景（蓄势/冲刺/挫败/胜利等），再确定主色+辅色与光影方案，避免"剧情对了但情绪不对色"
- **禁用色域** — 高饱和荧光色、强霓虹污染、过度赛博色彩与本风格不兼容

## 二、光影方案体系

- **光影即叙事** — 6 套光影方案对应不同竞技情绪段落，导演规划阶段应在段落层面确定光影基调方向，而非逐镜指定
- **光源角度** — 正给镜头默认 30° 斜射（较柔和），侧给镜头根据赛场与人物关系微调

| 光影方案 | 方案名 | 色调倾向 | 适用情绪 |
|---|---|---|---|
| A | 赛场漫射 | 赛场灰底 + 均匀柔和光 | 训练日常、热身叙事 |
| B | 硬侧光聚焦 | 健康肤暖 + 局部硬光 | 蓄势专注、力量展示 |
| C | 顶光竞技混合 | 中性冷白 + 硬朗均匀 | 正式比赛、竞技节奏 |
| D | 黄金时刻逆光 | 跑道红主导 + 金色镀边 | 夺冠辉煌、情感高潮 |
| E | 户外自然光 | 天空蓝背景 + 草坪绿点缀 | 户外耐力、团队配合 |
| F | 阴天漫射冷光 | 灰蓝主调 + 暖色局部 | 失误低谷、疲惫段落 |

- **冷暖光分配** — 暖色光可全片使用但需分层控制；挫败/失误段落降低暖光占比，避免情绪与光色冲突
- **氛围方向映射** — 每场戏氛围方向应映射到上述光影方案（A-F）的某一方向，确保视觉一致性

## 三、质感方向

- **体育摄影质感** — 真人写实摄影核心：高速快门定格竞技瞬间、动感追焦锁定主体、肌肉张力与汗珠肌理可见
- **强对比度 + 极致细节** — 作为画面质感锚点。不是低对比小清新，不是重滤镜氛围化，而是可拍可落地的体育纪实感
- **材质真实** — 运动装备需具备现实可信度：速干面料纹理、橡胶哑光、金属器械反光、木地板纹路、跑道塑胶质感都应符合赛场实拍逻辑
- **皮肤质感** — 保留真实毛孔、汗珠、微小瑕疵与肌肉块面分割，控制磨皮强度，追求"真实但有力"

## 四、体育场景空间元素

体育竞技世界观特有的场景元素及其视觉叙事功能：

- **跑道标线/球场标线/起跑器** — 天然引导线构图道具，制造纵深与竞技聚焦点
- **看台/器械架/网格围栏** — 空间分层与竞技氛围载体，可虚化作为背景层次
- **体育馆/田径场/健身房** — 情绪容器：体育馆偏正式竞技，田径场偏速度爆发，健身房偏力量训练
- **天气与时段作为转场** — 日转夜、晴转阴、黄昏入夜可用于段落情绪缓冲，避免硬切
- **转折点用视觉而非解释** — 优先使用画面手段（高速定格、景别突变、追焦切换）承接情绪转折，减少对白解释负担

## 五、体育乐器与环境音

体育竞技世界观下的声音元素约束：

### 乐器选择

- **鼓点/打击乐** — 蓄势、冲刺、爆发段落核心节奏，最能体现竞技张力
- **电子节奏** — 训练日常、现代竞技、节奏切换段落的风格增强器
- **弦乐** — 情绪抬升与夺冠辉煌段落的主力铺底
- **低频铺底** — 压迫、紧张、低谷段落的氛围承载
- **环境音优先级高** — 体育剧中真实赛场环境声是沉浸感关键，配乐不应压过对白与呼吸声

### 乐器组合策略

| 情绪阶段 | 乐器组合 |
|---|---|
| 平稳/开场/收尾 | 鼓点独奏 或 电子节奏轻铺 |
| 训练推进 | 电子节奏 + 轻打击 |
| 蓄势升温 | 鼓点 + 低频铺底 |
| 爆发/冲突 | 鼓点主导 + 弦乐 + 低频铺底 |
| 夺冠/高潮 | 弦乐主导 + 鼓点 + 电子节奏 |

### 体育环境音

- **典型环境音层次** — 观众欢呼 / 裁判哨声 / 球鞋摩擦地板 / 起跑发令枪 / 器械碰撞 / 喘息声 / 心跳声 / 赛场广播
- **每场戏标注 1-2 个核心环境音**，帮助后续音效设计。环境音层次越准确，竞技临场感越强
