# 体育运动写实风格说明

本风格专为"体育运动写实"题材打造，所有美术提示词、规范和生成内容均严格限定于：

- **竞技世界观**：以体育竞技为背景，涵盖体育馆、田径场、球场、健身房、户外赛道等，杜绝竞技场景元素缺失。
- **真人写实**：所有角色、场景、道具均以真人写实摄影为标准，强调肌肉张力、汗珠肌理、皮肤纹理、运动装备材质等极致细节与真实质感。
- **高速纪实**：在写实基础上追求体育摄影级氛围感，高速快门定格竞技瞬间、动感追焦、强光高对比，整体氛围热血拼搏、力量感与竞技张力十足。
- **拼搏情绪**：适合展现专注、爆发、胜利、疲惫、坚韧等竞技情绪表达，强调赛场下的肌肉张力与运动姿态。

## 适用范围

- 体育运动题材的AI美术生成（角色、场景、道具、分镜等）
- 需要极致写实、肌肉张力、竞技瞬间定格、赛场强光氛围的视觉创作

## 严禁内容

- 卡通、动漫、插画、二次元风格
- 竞技元素缺失、古风/古装/传统建筑
- 高饱和荧光色、霓虹色
- 暗示性、暴露、透视等不适宜内容

## 风格体验

在本风格下，您将体验到：

- 角色体格健硕、肌肉线条分明，运动装备、护具、发型均为竞技写实
- 场景空间层次丰富，跑道/草坪/木地板/金属器械纹理超清晰，氛围真实且富有赛场临场感
- 道具、球类、护具、奖牌、功能配件等均为竞技造型，工艺精细，质感极致
- 分镜与视频均以真人写实为基础，强调高速定格与拼搏情绪表达

---

本风格仅适用于"体育运动写实"相关项目。如需其他风格（如古风、插画、动漫、都市等），请勿使用本套提示词。
