## 一、产品总览

| 模块 | 说明 | 需要登录 |
|---|---|---|
| 展示中心 | 浏览全站发布的短剧作品，可看片、可「做同款」 | 否 |
| 创作流程 | AI 编剧 → 项目 → 大纲 → 资产 → 分镜 → 成片 → 剪辑 | 是 |
| 任务中心 | 所有 AI 生成任务的进度、状态与结果入口 | 是 |
| 积分中心 | 充值（微信支付）、功能定价、流水 | 是 |
| 接单中心 | 发布制作任务单 / 接单交付，平台托管结算 | 是 |
| 个人中心 | 账户资料、设置、邀请 | 部分 |

**积分体系**：1 元 = 10 积分。AI 生成类操作（大纲、分集、生图、视频、合成、剪辑等）按模型与用量计费，每次操作前会弹出「估价确认页」显示模型与预计消耗，确认后才执行；取消运行中的任务可退款。

## 二、快速上手：三步出片

```
① 剧本大纲            ② 资产库                 ③ 分集与成片
导入/粘贴剧本    →    AI 提取角色场景道具   →   生成每镜视频
拆分为分集            AI 生图 / 服饰 / 音色      合成全集 → 加字幕
                                                → 在线剪辑 → 分享/发布
```

1. **进创作**：底部导航中央金色「+」→ 选择「新建项目」（从零开始）/「新建剧本」（AI 帮你写）/「导入剧本」（粘贴已有剧本）。
2. **走三步**：项目工作台的三张流程卡片按顺序点亮，每步完成点「下一步」进入下一环。
3. **出片分享**：分镜全部生成后「合成全集」，在分集页加字幕、剪辑、下载，或一键分享 / 发布到展示中心。

> 提示：AI 操作产生的后台任务都在「任务中心」可见进度，关掉页面任务不中断。

## 三、底部导航与全局入口

底部导航为自绘五槽布局（非原生 tabBar）：

| 槽位 | 名称 | 路由 | 说明 |
|---|---|---|---|
| 1 | 首页（展示中心） | `/pages/showcase/index` | 游客可浏览 |
| 2 | 作品（我的项目） | `/pages/projects/index` | 需登录，游客点击引导登录 |
| 3 | **中央金色「+」** | 打开创作面板 | 新建项目 / 新建剧本 / 导入剧本 三选一 |
| 4 | 任务中心 | `/pages/tasks/index` | 图标带运行中任务数角标（99+ 封顶） |
| 5 | 我的 | `/pages/mine/index` | 个人中心；接单中心入口在此页 |

全局通用交互：

- 各 Tab 页右上角**铃铛**：显示「待处理邀请 + 进行中任务」角标，点击进任务中心。
- 未登录点击需登录功能时，统一弹出登录确认框，登录后自动回到原目标页。
- 展示中心与项目页下拉刷新、列表触底自动翻页。

## 四、看剧：展示中心

### 4.1 展示中心首页

**路由**：`/pages/showcase/index`　｜　**游客可用**

| 功能 | 描述 | 使用方法 |
|---|---|---|
| 剧目推荐列表 | 浏览全站用户发布的短剧（封面、剧名、风格、叙事类型、画幅、集数、播放量） | 下拉刷新、触底自动加载下一页 |
| 搜索 | 按剧目名称检索 | 顶部搜索框输入后确认 |
| 叙事类型筛选 | 按言情 / 悬疑 / 仙侠等 12 类题材过滤 | 点击横向类型 chips |
| 观看 | 进入剧集详情播放页 | 点击卡片或「观看」按钮 |
| 做同款 | 参考该剧自动创建同类型剧本草稿，一键带出风格/画幅 | 点卡片「做同款」（需登录） |

### 4.2 剧集详情（播放页）

**路由**：`/pages/showcase/detail?id=xx`　｜　**游客可用**

- 顶部播放器按项目画幅（9:16 竖屏 / 16:9 横屏等）展示，自动播放，**一集播完自动连播下一集**。
- 「播放列表」网格选集，点击切换，当前集高亮。
- 信息区展示剧名、发布者、播放量、风格标签、简介；点「做同款」跳 AI 编剧。

### 4.3 分享播放页（免登录深链）

**路由**：`/pages/play/share?token=…`　｜　**无需登录，链接 24 小时有效**

由项目「分集与成片」页的「一键分享」生成，面向微信等外部渠道：

- 抖音式上下滑切集、整剧自动连播；点按画面暂停/继续；播完出现「重播」。
- 进度记忆（切回续播）、进度条拖拽、静音切换。
- 链接过期 / 失效时提示「回首页」。

> 分享行为在工作台侧生成链接并复制，本页为纯播放落地页。

## 五、创作流程

### 5.1 AI 编剧（剧本创作）

**路由**：`/pages/create/writer`　｜　入口：底部「+」→ 新建剧本；展示中心「做同款」

四步向导，与 AI「策划」协作完成从想法到剧本：

| 步骤 | 功能 | 使用方法 |
|---|---|---|
| ① 对话生成大纲 | 与 AI 策划聊天打磨创意（题材可选，流式输出，可中断） | 输入想法发送 → 点「生成大纲」（计费确认） |
| ② 分集概要 | 大纲可编辑；AI 按目标集数划分分集并生成每集概要 | 设目标集数（0=自动，最大 60）→ 点「分集+概要」；每集标题/概要可改 |
| ③ 逐集细化 | AI 按大纲扩写每集正文 | 单集点「细化」，或多集点「细化未完成」批量执行；正文可手改 |
| ④ 导出到项目 | 把分集导出为一个正式项目进入制作流程 | 填项目名、叙事类型、视觉风格+画幅 → 点「导出到项目」 |

其他：

- **多草稿管理**：顶部「卷宗」chip 切换 / 删除草稿，「+」新建；剧本名自动保存。
- **做同款**：从展示中心带剧名/简介/风格跳入，自动建稿并把参考信息填进聊天框。
- 每个生成动作都有估价确认页，消耗积分。

### 5.2 新建 / 编辑项目

**路由**：`/pages/projects/edit`（新建）、`/pages/projects/edit?id=xx`（编辑）

| 字段/功能 | 说明 |
|---|---|
| 项目名称 | 必填，最长 40 字 |
| 叙事类型 | 12 种题材：甜宠、都市职场、古风仙侠、喜剧、悬疑、热血、成长、家庭、历史、心理、恐怖、科幻末世 |
| 视觉风格 + 画面比例 | 风格选择器（写实 / 动漫两大类）；比例 9:16 / 16:9 / 1:1。风格将作为分镜/资产/视频生成的提示词依据 |
| 封面（编辑态） | 上传本地图片，或「AI 生成封面」：勾选出镜角色/场景/道具 + 一句描述，异步生成 480p 16:9 封面 |
| 制作人 / 版权（编辑态） | 普通文本 |
| 提交 | 新建成功直接进入项目工作台；编辑成功返回 |

### 5.3 我的项目

**路由**：`/pages/projects/index`（底部 Tab「作品」）　｜　**需登录**

- 概览：进行中项目数 + 活跃任务数。
- 状态筛选 chips：全部 / 大纲 / 素材 / 视频 / 完成。
- 项目卡：封面、状态、三段式进度条（大纲 33% → 素材 66% → 视频 90% → 完成 100%）；共享项目显示「共享 · 所有者名」。
- 打开项目：按项目状态自动跳到对应工作台步骤。
- 卡片「⋯」菜单：打开 / 编辑 / 删除（创建者）或退出（协作成员），删除与退出均有确认框。

### 5.4 项目工作台

**路由**：`/pages/workspace/index?id=xx`（或 `&step=1/2/3` 直达步骤）

项目总览与设置入口：

- **创作进度**：分集剧本数、资产数、成片数三个统计。
- **三步流程卡**：① 剧本大纲 → ② 资产库 → ③ 分集与成片，完成自动打勾，点击进入。
- **项目设置**（需项目设置权限）：
  - 画面比例：9:16 竖屏 / 16:9 横屏 / 1:1 方形；
  - 视觉风格：风格列表选择后「应用」；
  - 字幕设置：字体、字号、离底边距，所见即所得预览，对本项目所有分集烧录生效；
  - 成员管理：创建者邀协作者（见[团队协作](#六团队协作)）。
- 异常兜底：项目被移出/删除时自动回项目列表。

### 5.5 剧本大纲

**路由**：`/pages/workspace/outline?pid=xx`　｜　**创作流程第 ① 步**

| 功能 | 描述 | 使用方法 |
|---|---|---|
| 导入剧本 | 粘贴文本（≤20 万字）或上传 .txt/.md/.pdf 文件 | 点「粘贴剧本」/「上传剧本」→ 导入 |
| 拆分剧本 | 本地同步拆分为分集列表（**零积分、不建任务**） | 导入后点「拆分剧本」 |
| 新增分集 | 手工添加空白集 | 右上角「+」或空态按钮 |
| 分集编辑 | 每集标题 + 正文（≤10 万字），阅读态显示字数与预计时长（约 300 字/分钟） | 点列表项打开弹层 →「修改」 |
| 删除分集 | 删除单集（确认框） | 列表行红色按钮 |
| 导出剧本 | H5 下载 txt（项目名-剧本.txt），其他端复制全文 | 点「导出剧本」 |
| 下一步 | 进入资产库 | 底部按钮（需先拆出分集） |

### 5.6 资产库

**路由**：`/pages/workspace/assets?pid=xx`　｜　**创作流程第 ② 步**

五个资产页签（带数量角标）：**角色 / 场景 / 道具 / 素材 / 视频**。

| 功能 | 描述 | 使用方法 |
|---|---|---|
| AI 提取资产 | AI 从所选分集剧本自动识别角色、场景、道具并建档（已存在的略过） | 点「AI 提取资产」→ 选分集 → 确认（计费） |
| AI 生图 | 为资产生成形象图，可挂**参考图**做图生图（需支持参考图的模型，如 Seedream/即梦） | 卡片「生成图片」→ 确认页选模型/分辨率 |
| AI 润色提示词 | AI 优化资产生图提示词，可附「本次要求」 | 卡片「AI润色提示词」 |
| 批量操作 | 批量生图、批量润色提示词 | 勾选资产 → 动作条按钮；或「全选未生成」 |
| 自定义角色（角色页签） | 按选项组合（性别/发型/脸型/身材/性格/职业等）+ 自由描述创建角色，生成 16:9 三视图设定图 | 「自定义角色」→ 选项 + 描述 → 创建 |
| 编辑资产 | 名称、别名（多个称呼都可匹配）、描述、提示词；角色专属：角色标签、**声音绑定**、**服饰**；数字资产可填豆包资产 ID | 卡片编辑入口 |
| 服饰管理（角色） | 一套服饰 = 一张图；可上传、AI 换装（按要求）、设默认；分镜生成时按集配置使用哪套 | 编辑弹层 → 服饰 |
| 音色绑定（角色） | 为角色选配音音色（系统音色/收藏，可试听、按性别/年龄/场景筛选） | 编辑弹层 → 声音 |
| 参考图 | 生图蓝本（≤10MB 或图片链接） | 卡片右上角参考图图标 |
| 上传 | 图片型资产上传主图（≤10MB）；视频类上传视频（≤200MB）并全屏预览 | 缩略图上传区 |
| 视频转关键帧（素材页签） | 上传视频均匀抽 N 帧（1–50）生成图片素材；视频用完即删 | 「视频转关键帧」弹层 |
| 搜索 / 分页 | 按名称/别名/描述搜索，每页 8 条 | 顶部搜索框、翻页按钮 |

> 建议先调好角色与场景设定再进入下一步——设定会应用到整部剧集中。

### 5.7 分集与成片

**路由**：`/pages/workspace/episodes?pid=xx`　｜　**创作流程第 ③ 步**

按集管理「提取资产 → 生成分镜 → 合成成片」流水线，并集中管理成片。

| 功能 | 描述 | 使用方法 |
|---|---|---|
| 分集列表 | 每集状态：待处理 / 分镜就绪 / 合成中 / 已完成；显示角色·场景数与成片数 | 点击卡片展开详情 |
| 提取资产 | AI 提取本集角色/场景/道具（生成分镜的前置条件） | 展开集 →「提取资产」 |
| 生成分镜脚本 | AI 生成本集镜头脚本，可附「本次要求」；已生成可重新生成 | 展开集 →「生成分镜」 |
| 进入分镜编辑 | 跳分镜编辑器 | 「进入编辑」按钮 |
| 合成全集 | 已生成视频的镜头合成为整集成片；分辨率 480p–4K（记忆上次选择） | 分镜就绪后「合成」卡 → 选档位 → 确认 |
| 成片管理 | 成片列表（字幕版/剪辑版优先排序，角标区分），点封面全屏预览，可删除 | 列表操作 |
| 字幕两段式 | ① AI 语音识别生成 SRT 字幕草稿；② 字幕编辑器校对台词/时间码 →「智能校正」AI 对照剧本修错别字 →「合并字幕到视频」免费烧录出字幕版 | 原片卡片「CC」→「编辑字幕」抽屉 |
| 在线剪辑 | 跳转满页剪辑器掐头去尾 | 成片卡片「剪辑」 |
| 下载 | 单片下载（H5 浏览器下载 / App 存相册）；顶部「批量下载」全部成片（仅 H5） | 卡片「下载」 |
| 一键分享 | 生成免登录播放链接（24 小时有效）并复制 | 顶部「一键分享」（仅创建者） |
| 发布到展示中心 | 填简介（≤500 字）+ 勾选发布分集；幂等（重复发布=更新）；可下架 | 顶部「发布」抽屉（仅创建者） |
| 删除分集 | 二次确认，连带删除剧本/分镜/成片/字幕且不可恢复 | 展开集底部红色「删除」 |

### 5.8 分镜编辑

**路由**：`/pages/workspace/storyboard?pid=xx&eid=xx`（从分集页进入）

单集分镜编辑器：逐镜生成视频 → 合成全集。

| 功能 | 描述 | 使用方法 |
|---|---|---|
| 分镜卡列表 | 每镜一卡：镜号、标题、时长、转场、生成状态；点开展开 | 点击卡头 |
| 底部分镜轴 | 横向缩略图时间轴，点缩略图定位；轴首/镜间「+」插入新镜 | 点缩略图或箭头 |
| 生成视频提示词 | AI 为单镜生成文生视频提示词（生成视频的前置） | 展开镜 →「生成提示词」 |
| 生成视频 | 单镜文生视频，选视频模型 + 分辨率 → 估价确认 → 异步任务；已有视频可重新生成 | 「立即生成视频」 |
| 上传视频 | 本地视频替换本镜（有旧视频时二次确认） | 「上传视频」 |
| 批量生成 | 勾选多镜后：**串行**（按顺序、相邻镜头尾帧衔接，更连贯）或**并发**（最多同时 4 段、更快、不衔接）；关页面不中断，可取消 | 勾选 → 底部两种批量按钮 |
| 合成全集 | 选中已生成的镜合成整集（主合成入口） | 勾选 →「合成全集」 |
| 分镜审计 | 检测缺失资产、时长建议（对白时长 vs 镜头时长）、超 15 秒建议拆分；一键「补充缺失资产 + 按对白延长时长」 | 「审计」→ 报告 →「应用修复」 |
| 编辑分镜 | 标题、镜号、时长（2–15 秒）、转场（13 种特效）、镜头剧本、视频提示词 | 「编辑」表单 |
| 转场设置 | 本镜到下一镜的过渡，默认硬切，7 种快捷档 | 「本镜到下镜」chip 或轴间连接器 |
| 本镜资产 | 展示引用的角色/场景/道具/素材；角色可试听音色；可从资产库添加/移除 | 卡内缩略图区 |
| 按集服饰配置 | 为本集角色指定使用的服饰（不选则用默认服饰） | 导航栏人形图标 |
| 视频操作 | 播放、下载、去除字幕（AI 擦除，按视频模型计费）、H5 端独立窗口在线剪辑 | 已生成视频后的按钮组 |

### 5.9 在线剪辑

| 功能 | 描述 | 使用方法 |
